# L3 月报需求原型

## 一、目标与边界

**目标:** 把 L2 知识图谱(政策 vault + canonical entities + relations + theme crystallizations)派生为决策层可读的月度政策动向报告。

**服务对象:** 公司决策层(对内描述,不用品牌名)

**业务覆盖:** 三大业务 = 加油 / 充电 / 电力(后者含储能·V2G·电力交易)。乡村是关注方向(非业务线)。

**频率:** 每月 1 次,覆盖该月 1 日 - 31 日的政策。

**交付形态(双格式同源):**
- Word docx — 决策层正式文档,可批注/编辑
- HTML 单文件 — 邮件转发,移动端可读

**边界(不做的):**
- 不做季度/年度综述(月度颗粒度即可)
- 不做单业务深度报告(那是 L3 的另一类产出 —「深度报告」,本原型只覆盖「月度简报」)
- 不做实时推送(月底统一交付)

---

## 二、架构

```
prep_docx_data.py  ──→  _docx_data.json
                            │
                            ├──→  render_docx.js   ──→  *.docx
                            └──→  render_html.py   ──→  *.html

render_march_charts.py  ──→  charts/*.png  ──→  (两个 renderer 都消费)
```

**核心解耦:** 数据层(JSON)和呈现层(2 个 renderer)分离。所有内容/字符串/规则修正在 prep 一处完成,docx 和 html 自动同步。

**输入数据来源(L2):**
- `0_raw/policies/*.md` — 政策原文 + frontmatter v3
- `_meta/march_report_batches/_consolidated.json` — Agent 抽取的 march detail(biz_impact / national_source / action_recommendations / summary)+ effective dates
- `1_extracted/entities/_extractions.jsonl` — canonical 实体(用于 §7 主题×省份覆盖)

## 三、内容结构(章节蓝图)

| 编号 | 章节 | 用途 |
|---|---|---|
| 封面 | 标题 + 月份 + 报告日期 + 入库 # 强/中/弱 | 定位元信息 |
| TOC | 10 个 H1 锚点(静态段落,非字段)| 导航 |
| §1 | 月度速览 | 1.1 月度比较表 + 比较图;1.2 本月最重要 2 件事(narrative) |
| §2 | 决策卡片 | 仅 ⭐≥4 业务命中,4 张卡片以内,差异化配色 |
| §3 | 政策全列表 | 3 子表(强/中/弱)+ 相关性饼图 |
| §4 | 重点解读 — 国家级新政 | 3 篇国家级新政深度,每篇:政策核心 / 三大业务影响 / 行动建议 / (定位) |
| §5 | 省级落地证据(国家级追溯)| 链条图 + 5 列追溯表 + linkage 类型说明 |
| §6 | 机会-风险 2×2 矩阵 | 业务相关性 × 行动窗口 |
| §7 | 缺口 / 盲区警示 | 主题×31 省覆盖表 + 本月新填空白 + 持续盲区(高严重度)|
| §8 | 下月 watching list | 4-6 条预期出台/落地 |
| 附录 A | 国家级重要政策生效周期 | timeline 图 + 已失效政策表(政策真空期警示)|
| 附录 B | 重要政策各省覆盖度 | 热力图 + 各主题覆盖详情 + 扩散预期 |

**禁用章节(已淘汰):**
- ❌ 数据健康度小卡(对决策层无价值)
- ❌ 数据出处与方法论附录(工具痕迹)
- ❌ 工具链尾注(Claude / docx-js / token / Agent / 自动生成)
- ❌ 舆论温度计(评论数据不足时降级,等评论发酵后重写,见 TODO)

## 四、内容规范

### 4.1 业务表述

**唯一合法表述:**
- 「公司三大业务」= 加油 / 充电 / 电力(后者含储能·V2G·电力交易)
- 「乡村能源(关注方向,非业务线)」— 单独展示,不计入业务线计数
- Deep dive 的 biz_impact 字段,Agent 输出 4 个 key:`加油` / `充电` / `电力_储能_V2G_交易` / `乡村`,前 3 个统一标签,第 4 个独立小节

**禁用:**
- ❌ 「四大业务」「五条业务线」「六大业务」等任何虚构业务线计数
- ❌ 把乡村作为业务线展示

### 4.2 行动分类

**4 级行动语言(取代过激紧迫感的「立即」):**

| 级别 | 显示 | 触发 | 配色 |
|---|---|---|---|
| A | [趁早行动] | ⭐5 + 业务命中 | 红 #C62828 |
| B | [研究 / 跟进] | ⭐4 + 业务命中 | 黄 #F57C00 |
| C | [跟踪] | ⭐3 + 业务命中 | 绿 #2E7D32 |
| D | [关注] | <3 或弱命中 | 灰 #616161 |

**Agent 输出修正:** Agent 抽出的 action_recommendations 用 `A 立即:` / `A 趁早:` 格式,prep 阶段 sanitize 为 `A 趁早:`。

### 4.3 品牌/工具表述

**对内文档统一用「公司」,不用任何品牌名。**

**禁用工具痕迹:**
- ❌ Claude / Anthropic / GPT / LLM / 大模型 / 语言模型
- ❌ docx-js / matplotlib / Agent / token / prompt / 自动生成 / AI 生成
- ❌ 工具链尾注、版本号、token 消耗

**例外:** 文档元数据 `creator` 字段(Word 文件属性 → 信息面板)非读者可见,可保留工具标识。

### 4.4 emoji 规则

**全文无 emoji。** 所有等级标签用方括号文本(`[趁早行动]`),不用 ⭐ / 🔴 / 🟡 / 🟢 / 🌟 / 🚀。

正文章节序号用「一 · 二 · 三 ·」,不用 emoji 序号。

例外:`⭐` 仅用于重要性打分显示(如 `⭐4` / `⭐≥4`),因这是评分体系约定。

## 五、Fact-check 规则

### 5.1 比较级论断 fact-check

任何「首批 / 首个 / 首破 / 首次 / 创新 / 标杆 / 唯一 / 第一」类比较级论断,**必须 fact-check vault**:

```
论断:省级 X 是 Y 之后省级首批落地
  → 查询:Y 之后所有省/市级 同主题政策,按时间排序
  → 第 1 个出现的才能称「首批」
  → 实际是第 N 个时,改称「第 N 个」+ 列出前序
```

**反例(本轮已修正):** 山东 VPP 方案 3-27 不是 NDRC 357 后省级首批 — 上海 SH_407(2025-06)早 9 个月。山东实际是第 2 个,前序应注明。

### 5.2 国家级 → 省级因果禁忌

**省级专项政策起草周期 = 6-12 月。** 同月发布的国家级和省级政策,**不能画因果链**。

```
正确表述:同源并行
错误表述:本月国家级 X → 本月省级 Y(派生因果)
```

**省级政策的真正源头:** 通常是 1-2 年前的国家级文件路径(如 NDRC 357《2025-04》、新型电力系统行动方案《2025-08》、充电基础设施意见《2023》)。本月国家级新政与本月省级政策属「同根并行」。

### 5.3 linkage 字段修辞错防御

**Agent 抽出的 linkage 字段含 2 部分:**
- 事实段:追溯到的国家级政策标题/文号(机器可校验)
- 修辞段:linkage 描述(如「省级首批落地」「全国首破」)— 易掺入比较级错

**L3 渲染规则:** 只用 linkage 的事实段,不用修辞段。修辞错由 L2/L3 lint 在派生时拦截(见 TODO)。

## 六、§5 落地证据规则(方案 C 强化版)

**§5 不是 §4 的派生章节**,与 §4 并行(§4 = 看本月顶层政策本身;§5 = 看本月省级政策追溯到的早期国家级源头)。

### 6.1 入选范围(窄口径)

- 仅省/市/区级(国家级跳过 — 它们是源头不是落地)
- ⭐≥4 OR linkage 字段非空(从 Agent national_source 抽出即非空,实际等同「Agent 标记了追溯关系」)

### 6.2 表结构(5 列)

| 省级政策 | 文号·日期 | 业务线 | 国家级源头 | linkage 类型 |
|---|---|---|---|---|

业务线由 biz_kws 推导:V2G/车网 / 储能·电力市场 / 充电基建 / 加油 / 设备更新 / 综合(默认)。

### 6.3 linkage 三类

| 类型 | 判据 |
|---|---|
| 直接落地 | 省级文本直接引用国家级文号 |
| 补充细化 | 主题对齐 + 条款扩展(地方实施细则常见)|
| 同向部署 | 主题、目标、节奏与国家级路径吻合,无显式引用 |

**Agent 用旧 taxonomy(直接落地 / 借鉴框架 / 主题对应),prep 阶段重映射:**
- 直接落地 → 直接落地
- 借鉴框架 → 补充细化
- 主题对应 → 同向部署

### 6.4 narrative 必含

§5 引言段必须点出:「同源并行非派生因果」「省级专项起草周期 6-12 月」「追溯到的源头多为 2023-2025 年早期文件」。

## 七、图表规则

**6 张 PNG**(matplotlib 渲染,中文字体 PingFang SC / STHeiti):
1. `01_timeline.png` — 国家级 ⭐≥4 政策生效甘特(800×1200)
2. `02_2x2_matrix.png` — 业务相关性 × 行动窗口(540×386,降宽避溢出)
3. `03_regional_heatmap.png` — 主题 × 31 省热力图(800×220)
4. `04_evolution_chain.png` — 国家级→省级落地链(540×293,降宽避溢出)
5. `05_monthly_compare.png` — 月度入库政策数对比(600×300)
6. `06_relevance_pie.png` — 本月相关性饼图(480×360)

**关键约束:**
- 图宽 ≤ 540 像素(超过 6.27" A4 内容区会被 Word 挤压相邻文字)
- 图独占段落,前后 spacing { before: 280, after: 280 }
- 中心对齐
- chart 文字内不出现品牌/工具/虚假业务线

## 八、Word / HTML 兼容规则

### 8.1 Word 脱钩(避免外发时弹出"外部引用 / 更新字段"提示)

**禁用:**
- ❌ TOC field(`<w:fldChar>` + `TOC \h \o "1-3"`)
- ❌ 任何 field(date / page reference / cross-reference)
- ❌ trackChanges / updateFields / 外部图片链接 / OLE
- ❌ TargetMode="External" 关系

**TOC 实现:** 静态段落 + Bookmark + InternalHyperlink(可点跳,无字段)。

### 8.2 HTML 单文件

- charts 内联 base64
- 内置 CSS(响应式 + print-friendly)
- 章节锚点(href="#s1" .. href="#sb")

### 8.3 文档元数据

- title: 报告主题(如「能源政策月报 2026-03」)
- description / comments: 「公司决策层 月度政策动向」
- creator: 可保留工具标识(隐藏字段)
- 不要在正文/页眉/页脚出现 creator 信息

### 8.4 字体

- Word: Microsoft YaHei(全文统一)
- HTML: PingFang SC / Microsoft YaHei / Hiragino Sans GB(回退链)
