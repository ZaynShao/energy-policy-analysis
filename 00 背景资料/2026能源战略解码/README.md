## 用之前必读

1. **数字一律不可直信。** 凡标 `⚠️数字待核` 的,进入任何成品前必须回原片确认。
   ASR 对数字的错误率是已知问题(见源目录 README「已知质量问题」)。
2. **人名一律略去**,统称「主讲人」——识别器把主讲人识别成了不确定的写法。
3. **「材料里没有」不等于「业务上无关」。** 提要里大量出现「0 次提及」,
   那是**证据为空**,不是**否定证据**。把它当否定用会造成系统性误判,
   典型如柴油/重卡——四段合计 0 次,但这只说明这门课没讲,不说明公司不做。
   凡属此类,`business_strategy.yaml` 里都标了 `evidence: absent` 而不是 `low`。
