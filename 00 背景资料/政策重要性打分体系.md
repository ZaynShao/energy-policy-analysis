# 政策重要性打分体系

> 服务对象：高管团队
> 适用业务：加油站（零售/平台）、充电桩/充换电站、综合能源站
> 核心目标：判断要不要行动、投入多少资源

---

## 业务背景说明

本打分体系围绕以下核心业务逻辑设计：

**充电站不只是用电户，而是电力市场参与者。**

核心业务版块有四个，且权重并列：

| 业务版块 | 含义 | 参与方式 |
|:---|:---|:---|
| 🚗 **加油/油品** | 加油站油品零售业务 | 油品销售、便利店 |
| ⚡ **充电/充换电** | 充电桩/充换电站建设运营 | 充电服务费、充电桩建设补贴 |
| 🔋 **储能/虚拟电厂** | 负荷侧储能资源聚合 | 参与调峰调频、容量市场、需求响应 |
| ⚡ **电力交易** | 充电站作为市场主体参与电力市场 | 峰谷套利、V2G放电、绿电交易、现货市场 |

充电站可以通过以下方式将储能资源变现：
- **峰谷套利**：低电价时段充电，高电价时段放电（V2G）
- **需求响应**：根据电网信号调节充电功率，赚取响应补贴
- **虚拟电厂**：聚合为负荷聚合商，参与容量市场/调峰市场
- **绿电交易**：购买或销售绿证，参与绿色电力市场
- **电力现货**：在电力现货市场中灵活购电，降低充电成本

因此，**电力交易类政策、储能政策、虚拟电厂政策**与充电基础设施建设政策同等重要，都是核心业务政策。

## 第一层：快速决策树

> 高管时间有限，拿到政策先走这棵树，**30秒内判断要不要跟进**。

```
政策发布
  └─ 是否影响四个核心业务版块（加油/充电/储能/电力交易）？
      ├─ 否 → 趋势/合规类 → ★1-2 → "了解"
      └─ 是 → ↓
          是否强制执行（补贴/准入/处罚/电价调整）？
              ├─ 是 → ★4-5 → "立即行动"
              └─ 否 → ↓
                  是否有硬性时间节点？
                      ├─ 是（年内/近期） → ★4 → "优先研究"
                      └─ 否（长期方向） → ★3 → "深度评估"
```

## 第二层：六维打分（综合重要性）

### D1 · 业务关联度（权重 40%）

政策与四个核心业务版块的直接关联。

| 分值 | 含义 | 典型政策类型 |
|:---:|:---|:---|
| 5 | **直接针对核心业务**（充电基础设施建设/运营补贴、加油站转型、油品流通、储能建设、V2G/车网互动、分时电价改革、电力现货市场、需求响应） | 充电基础设施专项、加油站转型、油品流通、V2G试点、分时电价、需求响应规则、虚拟电厂意见、储能建设方案 |
| 4 | **明确影响业务方向**（设备更新、以旧换新、新型储能参与市场、碳市场影响电价） | 设备更新方案、以旧换新通知、储能参与市场规则、碳价影响 |
| 3 | **影响经营环境**（能源转型方向、碳排放双控、新型电力系统框架） | 能源转型意见、碳达峰行动方案、新型电力系统指导意见 |
| 2 | **技术标准/规范**（建设标准、设计规范、资质要求） | 场站设计标准、建设施工规范 |
| 1 | **弱相关**（光伏、建筑、宏观政策） | 光伏政策、建筑标准 |
| 0 | **基本无关** | 无关行业政策 |

### D2 · 直接影响度（权重 40%）

政策对业务的直接作用力，含合规约束和商业机会。

| 分值 | 含义 |
|:---:|:---|
| 5 | 强制执行，不跟随会违规/被罚/失去补贴资格，直接影响充电成本或收入 |
| 4 | 明确指引，直接影响经营策略（电价调整、准入门槛改变） |
| 3 | 规范约束，需调整业务流程或投入资源（新增合规要求） |
| 2 | 参考价值，有则更好无也无妨 |
| 1 | 象征文件，无实质影响 |

### D3 · 发布主体层级（权重 20%）

权威性决定执行力度。

| 分值 | 含义 |
|:---:|:---|
| 5 | 两办、国务院（含国务院发文） |
| 4 | 国家发改委，国家能源局，商务部，工信部 |
| 3 | 其他国务院组成部门（生态、财政、住建、金融监管总局等） |
| 2 | 国务院直属机构/地方省级政府 |
| 1 | 地方政府局部、行业协会 |

### D4 · 紧迫性

硬性截止时间决定行动优先级。

| 分值 | 含义 |
|:---:|:---|
| 5 | 已生效或年内截止，错过多地无资格 |
| 4 | 明确 deadline 在 1-2 年内 |
| 3 | 有框架时间表，近年落地 |
| 2 | 长期方向，暂无硬性节点 |
| 1 | 无时间约束 |

### D5 · 实操性

政策是否可落地执行。

| 分值 | 含义 |
|:---:|:---|
| 5 | 有具体标准、金额、申请流程，可直接操作 |
| 4 | 方向明确，有配套实施细则可查 |
| 3 | 有框架，需要结合地方或企业情况细化 |
| 2 | 方向性文件，缺乏执行细节 |
| 1 | 目标/愿景式表述，无操作性 |

### D6 · 机会窗口

介入时机决定竞争地位。

| 分值 | 含义 |
|:---:|:---|
| 5 | 早期布局阶段，先动有先发优势 |
| 4 | 政策窗口期，仍可进入 |
| 3 | 已有先行者，差异化仍有机会 |
| 2 | 市场接近饱和 |
| 1 | 窗口关闭，跟进意义不大 |

## 综合重要性评分

```
综合得分 = D1×40% + D2×40% + D3×20%
四舍五入取整，范围 0-5
```

### 分级定义

| 分数 | 等级 | 行动定义 |
|:---:|:---:|:---|
| 5 | ⭐⭐⭐⭐⭐ 核心政策 | **一把手工程**，全力督办 |
| 4 | ⭐⭐⭐⭐ 重要政策 | **分管领导主抓**，制定行动方案 |
| 3 | ⭐⭐⭐ 参考政策 | **部门研究**，确定是否跟进 |
| 2 | ⭐⭐ 边缘政策 | **存档了解** |
| 1 | ⭐ 弱相关 | **背景参考** |

---

## 行动分类

> 依据 D4紧迫性 × D5实操性 × D6机会窗口，将政策归入四象限：

| | **实操性高**（可直接执行） | **实操性低**（需细化） |
|:---|:---|:---|
| **紧迫** | 【A】**立即行动** | 【B】**优先研究** |
| **不紧迫** | 【C】**计划跟进** | 【D】**持续跟踪** |

### 机会窗口修正

| D6 | 对行动分类的修正 |
|:---:|:---|
| 5-4 | 机会型政策，行动分类向前跳一档（例：B→A） |
| 2-1 | 饱和型政策，行动分类向后降一档（例：B→C） |

---

## 价值标签

| 标签 | 含义 |
|:---:|:---|
| 🛡️ **合规** | 不跟随会违规、处罚、失去资质 |
| 🚀 **机会** | 存在新收入来源或新市场模式 |
| ⚔️ **壁垒** | 抢先行动可建立竞争护城河 |
| 🔭 **趋势** | 反映行业长期方向，战略布局参考 |

## 元信息写法

在政策文件元信息中新增：

```
**重要性** ⭐⭐⭐⭐ 4分
**行动分类** 【A】立即行动
**价值标签** 合规 + 机会
- D1业务关联：5
- D2直接影响：4
- D3主体层级：4（国家发改委）
- D4紧迫性：4
- D5实操性：4
- D6机会窗口：4
```

## 评分示例

---

**示例1：关于推动车网互动规模化应用试点工作的通知（发改办能源〔2024〕718号）**

- D1业务关联：5（V2G直接是核心业务版块）
- D2直接影响：4（放电参与电网调节，获得补贴收益，直接创造收入）
- D3主体层级：4（国家发改委）
- D4紧迫性：4（试点周期明确，窗口有限）
- D5实操性：4（试点城市、聚合商准入规则清晰）
- D6机会窗口：5（早期布局，先动有先发优势）

综合重要性：5×0.4 + 4×0.4 + 4×0.2 = 4.4 ≈ **4分**
行动分类：A（紧迫+实操+机会窗口5）
价值标签：🛡️合规 + 🚀机会 + ⚔️壁垒
行动建议：立即申报试点城市，布局V2G充电桩，建立聚合商资质。

---

**示例2：关于完善居民电动汽车充电桩用电价格政策的通知**

- D1业务关联：5（分时电价直接影响充电成本和峰谷套利空间）
- D2直接影响：5（峰谷电价差是核心利润来源，直接影响收入）
- D3主体层级：4（国家发改委）
- D4紧迫性：4（已执行，直接影响当期经营）
- D5实操性：5（电价文件，拿来就能算）
- D6机会窗口：5（先调整策略，先受益）

综合重要性：5×0.4 + 5×0.4 + 4×0.2 = 4.8 ≈ **5分**
行动分类：A（已生效+高实操+机会窗口5）
价值标签：🛡️合规 + 🚀机会
行动建议：立即调整充电站运营策略，低谷时段充电、高峰时段放电（V2G）。

---

**示例3：关于全面推进电力现货市场建设工作的通知（发改办体改〔2025〕394号）**

- D1业务关联：5（现货市场价格直接决定充电成本，是核心业务环境）
- D2直接影响：4（现货市场价格直接影响充电站购电成本和利润）
- D3主体层级：4（国家发改委）
- D4紧迫性：5（2025年底前基本全覆盖）
- D5实操性：2（市场规则复杂，需专业团队）
- D6机会窗口：5（早期参与可获得批发市场价格信号优势）

综合重要性：5×0.4 + 4×0.4 + 4×0.2 = 4.4 ≈ **4分**
行动分类：B（紧迫+低实操+机会窗口5提前跳档→A，实际执行视团队能力定）
价值标签：🚀机会
行动建议：组建或引入电力交易研究团队，测算现货市场价格对充电成本的影响，制定购电策略优化方案。

---

**示例4：汽车加油加气加氢站技术标准 GB 50156（住建部）**

- D1业务关联：2（技术标准是合规门槛，不是战略方向）
- D2直接影响：5（不合规不能运营，是准入门槛）
- D3主体层级：3（住建部）
- D4紧迫性：5（已生效，不合规无法通过审批）
- D5实操性：5（强制标准，逐条执行）
- D6机会窗口：1（技术标准不存在窗口期，是基本准入条件）

综合重要性：2×0.4 + 5×0.4 + 3×0.2 = 3.4 ≈ **3分**
行动分类：A（合规必须立即执行）
价值标签：🛡️合规
行动建议：按标准执行，合规审查先行。不计分在战略价值，计分在合规必要性。

---

**示例5：关于进一步构建高质量充电基础设施体系的指导意见（国办发〔2023〕19号）**

- D1业务关联：5（直接针对充电基础设施，且包含V2G/需求响应）
- D2直接影响：4（战略指引，部分条款涉及强制，影响场站建设要求）
- D3主体层级：5（国务院办公厅）
- D4紧迫性：2（2030年目标，无硬性节点）
- D5实操性：3（方向明确，地方配套政策待出）
- D6机会窗口：5（早期布局，先发优势明显）

综合重要性：5×0.4 + 4×0.4 + 5×0.2 = 4.6 ≈ **5分**
行动分类：C→B修正（机会窗口5，提前跳档→B）
价值标签：🚀机会 + ⚔️壁垒 + 🔭趋势
行动建议：纳入战略规划，启动充电基础设施5年布局，优先在大流量场站部署V2G和智能有序充电。
