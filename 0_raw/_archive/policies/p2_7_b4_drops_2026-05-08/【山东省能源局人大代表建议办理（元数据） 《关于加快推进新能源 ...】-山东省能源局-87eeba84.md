# 山东省能源局人大代表建议办理（元数据） 《关于加快推进新能源 ...

## 政策原文

王燕代表：

您提出的《关于加快推进新能源汽车充电桩建设的建议》收悉。在综合省住建厅、省应急厅、省消防救援总队和国网山东电力等部门意见后，提出答复意见如下：

一、我省充电基础设施发展建设情况

（一）强化政策引领。近年来，省能源局会同省有关部门不断优化充电设施发展顶层设计，加大政策支持力度，先后出台了《山东省电动汽车充电设施建设运营管理办法》、《关于进一步加强和规范山东省电动汽车充电设施建设运营管理的实施意见》、《关于加强和规范山东省居民小区电动汽车充电设施建设的通知》和《山东省电动汽车充电设施“十四五”发展规划》，规范充电设施建设运营管理，明确公共场所配建要求，简化建设审批手续，初步形成了覆盖规划布局、建设标准、责任主体、运营管理及服务要求等内容的政策框架体系。

（二）完善充电设施体系。大力推动“互联网+”充电基础设施建设，构建全省充电“一张网”，打造省级充电基础设施信息公共服务平台，研发“齐鲁e充”应用程序，对充电服务开展星级评价，实现省内充电基础设施信息互联互通，充电服务监督能力不断加强，有力促进充电服务市场发展，提升新能源汽车车主充电便利度。截至2022年底，我省公共充电站保有量达到6471座，各类充电桩保有量达到21.47万台。

（三）推进居民区充电桩建设。结合老旧小区改造,统筹利用小区业主共有用地施划停车位、增建立体停车设施,2021年以来,累计通过老旧小区改造加装电动汽车充电桩3038个。将新建居住区充电设施配建要求纳入建设工程规划许可证核发、施工图审查和工程验收范畴。同时,指导各地督促物业服务企业发挥作用,及时告知业主安装充电桩的前提条件和注意事项,对符合相关标准和条件的,配合业主或其委托的建设单位提供图纸资料,协助现场勘查、施工,为业主安装充电桩提供便利。

（四）强化风险防范措施。指导各级消防救援机构扎实运用“消防安全检查日”工作机制，充分依托“一呼百应”、“智慧消防”等机制平台，滚动分析研判新能源汽车火灾形势和安全趋势，定期向相关行业监管部门提示领域内消防安全的突出问题、监管要求、检查要点。印发《山东省消防安全违法行为举报投诉奖励规定》，推动安全风险源头防范能力不断提升、深化群防群治，加强联控联防，2022年全省消防部门累计受理新能源汽车、电动自行车充电桩消防安全举报投诉 277 起，定向发放 2.4 万元奖励金额。针对不同新能源汽车厂家，制定“一企一策”火灾处置对策和应急预案，明确火灾事故处置要点，分类编制技战术方法、处置规程和安全警示，进一步深化与辖区消防救援站联勤联动工作机制，针对性地制定火灾扑救预案、开展日常培训演练，着力提升新能源汽车灾害事故专业处置能力。

二、下一步工作打算

（一）加快充电设施建设布局。加强部门统筹协作，完善居民区充电设施建设推进机制，实施居民区充电基础设施“无证明”报装，推动居民区充电设施建设与改造。新建小区预留充电基础设施建设安装条件，老旧小区鼓励探索多车一桩、临近车位共享等模式应用，推动充电基础设施建设纳入城镇老旧小区改造、城市居住社区建设补短板范围。

（二）完善充电信息服务平台。推进全省充电基础设施数据互联互通，实现信息共享与跨平台、多渠道支付结算。依托全省充电基础设施信息公共服务平台构建充电服务质量评价体系，推动充电运营企业提高充电服务水平，提升充电便利性和用户体验。建立健全省、市、县三级平台监管体系，完善数据服务、安全监管、运行分析等功能，推进跨平台安全预警信息交换共享。

（三）加强配套电网接入服务。积极推动电网规划与充换电设施规划的有效衔接，加大配套电网建设改造投入，保障充电设施科学合理接入和安全稳定运行。持续提升“获得电力”服务水平，落实“三零”“三省”服务举措，积极推广居民充电设施报装接电“联网通办”模式，为充电运营企业和个人提供更加便捷、高效的电网接入服务。

（四）加强安全管控体系建设。积极发挥责任保险风险防控作用，鼓励保险机构开发适合充换电设施的安全责任险等商业保险产品，提升充电安全保障能力。将新能源汽车行业消防安全综合治理列入各级政府年度消防工作目标责任，带动新能源充电桩消防安全管理效能不断提升。持续加强产业“全链条”消防安全管理，会同有关部门研究制定居民区、单位内部等场景充电基础设施建设技术标准、验收规范，做好充电站的规划选址、建设和充电设施设置工作，推动物业企业落实常态化巡逻力量，全面加强对新能源汽车充电桩的管理。

（五）提升全民充电安全意识。多渠道、多角度开展新能源汽车消防安全宣传工作，依托广播、电视、报纸、网络等新闻媒体发布新能源汽车充电消防安全提示，在抖音、快手等新媒体上发布新能源汽车火灾案例，通过网络直播方式广泛宣传新能源汽车充电消防安全常识等内容。

感谢您对我省新能源汽车充电基础设施建设发展的支持和关注。
