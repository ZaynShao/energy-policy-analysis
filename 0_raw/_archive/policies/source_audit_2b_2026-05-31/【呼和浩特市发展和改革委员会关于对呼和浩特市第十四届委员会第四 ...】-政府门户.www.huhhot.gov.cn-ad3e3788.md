# 呼和浩特市发展和改革委员会关于对呼和浩特市第十四届委员会第四 ...

## 政策原文

贵单位提出的《关于推动清洁能源使用促进绿色低碳能源转型的提案》已收悉，现答复如下：

|
提案建议 |
答复 |
|
建议1：加强基础设施建设、提高清洁能源供应量。一是合理调控布局煤炭产能规模。实施能量系统优化，推广先进技术和节能设备，加速推动煤电机组改造升级和工艺流程再造。二是加强运用节能的技术设备和低碳的工艺，煤电企业科学做好电煤储备、提高顶峰发电能力，煤炭企业加快释放煤炭先进产能、增加电煤产量，风电、水电、核电、光电等清洁能源电力供应能力。三是积极发展利用储能“削峰填谷”调节性作用，扩大清洁能源在交通领域应用，加快规划建设充电桩、换电站、加气站、加氢站等配套设施，推进交通基础设施与新能源深度融合发展。 |
市发改委：1.2024年，我市计划的3家燃煤火电企业三改联动改造任务涉及机组容量215万千瓦已全部完成。其中灵活性改造95万千瓦，供热改造120万千瓦。节能降耗改造以“十四五”期间机组供电煤耗降至300克标煤/千瓦时以下为标准，由各家燃煤火电企业根据实际停机检修周期自行立项组织实施。2025年，我市拟进行1项灵活性改造、1项供热改造、4项节能改造，预计于明年6月全部竣工，目前正在有序推进。 2.一是持续提升能源供应保障能力。推动清水河县刘胡梁煤矿、天赐源煤矿完成复工复产和煤矿智能化建设。按照国家、自治区2025年电煤中长期合同签订、履约要求，组织全市六家企业签订中长期协议，已完成协议签订量达到使用量80%的要求，并在网上平台对协议进行公示。 二是积极推动新能源项目规划建设。截至2024年底，全市新能源装机达到702.5万千瓦（风电464.4万千瓦，光伏238.1万千瓦），2024年新增365.8万千瓦，同比增长108.6%。 3.截至2025年6月，全市储能现有装机达到175.7万千瓦，其中抽水蓄能120万千瓦，电化学储能55.7万千瓦。电化学储能电站，已建成并网9个，总容量55.73/160.92万千瓦时。正在建设赛罕区金河镇中电储能30万千瓦/120万千瓦时电网侧独立储能电站与武川远景100万千瓦/400万千瓦时独立储能电站，待建成后总容量达到185.73/680.92万千瓦时。 2024年11月30日我委印发《呼和浩特市氢能产业高质量发展规划》，在技术研发、绿氢生产、加氢基础设施建设等方面作出了部署。 市住建局：我市清洁能源供应不足、基础设施薄弱。在优化产业结构、调整能源结构、加强政策供给和部门协同，亟须更多的系统性政策支持。 1.针对清洁能源供应不足问题，我市2024年通过温暖工程完成大唐托电、金山二期“挖潜扩能”，新增热电联产供热能力3800万平方米。 2.今年我市将实施西热东送工程，解决城区东北区域热电联产热源不足的问题，建设约50公里长输供热管道，将金山电厂三期热源输送到城区东北区域，新增热电联产供热能力2900万平方米。同时继续深入推进供热管网互联互通，具备条件的燃气锅炉逐步实现热电联产热源替代，进一步提升热源的稳定性。推进城区换热站大温差机组改造，今年计划实施10座，进一步提高热源使用效率，释放热电联产供热能力。 |
|
建议2：加强绿色低碳技术研发，推进专业人才培养。一是加强能源关键技术攻关。加大在大功率大规模能量储存技术、煤炭安全开发与清洁高效利用技术，融入内蒙古能源数据平台，推进传统能源与新能源的产业链数据共建共享发展。二是整合高校学科科研平台资源，利用“能源互联网工程”学科，打造综合能源在工程项目建设和后期运维服务的人才技能需求，培养综合能源系统的项目规划建设、调试运维和服务管理型人才，满足我区能源产业对新兴行业领域高级技术人才的迫切需要。 |
市大数据局：依托公共数据一体化管理平台加强能源相关公共数据汇聚、共享、应用。截至目前，平台已归集市发改委煤炭资源开采信息、新能源项目建设信息，市统计局能源消费数据、能源统计年鉴数据等多类能源数据。同时与市自然资源局、供电公司等部门建立沟通对接机制，加强矿山储量数据、光伏发电数据等能源行业数据归集工作，深化能源行业专题数据共享应用，为产业链优化升级、政策精准调控提供有力支撑，为能源产业数字化转型注入数据动能。 |
|
建议3：优化市场能源资源配置、提高绿色能源的接纳、配置和调控能力。一是加快推动一批新能源配套电网项目，在确保安全的前提下加快推进前期、核准和建设工作；做好电网延伸补强配套基础设施建设，充分发挥电网资源优化配置平台作用，服务好新能源项目并网。二是推动新能源积极参与电力市场竞争，完善电价机制，建立公平合理的调峰辅助服务市场，完善搭建电力市场、碳交易市场、绿色配额交易市场。三是以新型电力系统建设为关键载体，推动智能配用电设备、环保型变压器等应用，促进电网装备升级改造，推进智慧煤矿、数字化电厂、智能变电站等建设。 |
市发改委：1.完成电网提升三年行动计划，实施65个项目，完成投资102亿元；启动实施新一轮电网提升三年行动计划，安排项目87个，计划总投资120亿元。 3.按照《内蒙古自治区能源局关于转发国家开展新型电力系统建设第一批试点工作的通知》（内能源电力字〔2025〕308号）及《内蒙古自治区能源局关于转发国家开展新型电力系统建设第一批试点工作补充要求的通知》（内能源电力字〔2025〕374号）要求，市发改委组织申报了3个项目：1.单一方向试点：“全国一体化算力网络”和林格尔数据中心集群绿色能源供给示范项目（方向：算力与电力协同）；2.海量分布式资源协同优化的区域级虚拟电厂项目（方向：虚拟电厂）；3.综合试点：呼和浩特市新型电力系统建设综合试点（包含：算力与电力协同、虚拟电厂），待国家能源局批复。 |
|
当年完成事项： 呼和浩特市发改委： 2024年三改联动技术改造任务已全部完成；完成电网提升三年行动计划，实施65个项目，完成投资102亿元；新能源装机新增365.8万千瓦，同比增长108.6%；新型储能稳步增长，内蒙古呼和浩特可镇100兆瓦/400兆瓦时电网侧储能电站项目已建成。 呼和浩特市住建局： 2024年已通过温暖工程完成大唐托电、金山二期“挖潜扩能”，新增热电联产供热能力3800万平方米。 呼和浩特市大数据局： 截至目前，已归集市发改委煤炭资源开采信息、新能源项目建设信息，市统计局能源消费数据、能源统计年鉴数据等数据，并推进传统能源与新能源的产业链数据共建共享。 | |
|
当年推动工作: 一、呼和浩特市发改委： 2025年，我市煤电机组三改联动任务拟进行1项灵活性改造、1项供热改造、4项节能改造； 二、呼和浩特市住建局： 2025年我市将实施西热东送工程，解决城区东北区域热电联产热源不足的问题。 三、呼和浩特市大数据局： 依托公共数据一体化平台加强能源相关公共数据汇聚、共享、应用，深化能源行业专题数据库建设，并加强共享应用。 |
