# 海南省发展和改革委员会2026年工作要点

## 政策原文

**海南省发展和改革委员会2026年工作要点**


2026年是“十五五”开局之年、高标准建设海南自由贸易港启航之年。省发展改革委将坚定不移落实省委、省政府决策部署，砥砺奋进，紧紧围绕实现“十五五”和自贸港封关运作良好开局，重点做好以下工作。

# 一、强化规划引领和政策调控

**高标准实施“十五五”规划。**印发《海南省国民经济和社会发展第十五个五年规划纲要》，做好规划《纲要》目标任务分解，开展规划《纲要》实施情况年度监测评估，跟踪推动“十五五”重大工程项目落地实施。督促出台省级重点专项规划。

**力促经济实现良好开局、全年高质量运行。**科学设定2026年国民经济和社会发展目标，以体系化管理、项目化推进、闭环式落实的方式，谋实重大项目、重大政策、重大改革、重大平台，确保“十五五”起好步、开局稳。提前谋划一季度各项工作，扎实做好政策衔接、工作衔接、项目衔接，全力争取“一季度”开门红。充分发挥“按季抓、月跟踪”工作机制和“最佳实践典型”激励作用，协同优化高质量发展考核评价体系，引导各市县比学赶超、奋勇争先，凝聚推动经济发展合力。

**切实加强形势分析和政策研究储备。**持续丰富经济形势分析手段、工具、视角，精准务实提出经济工作建议。密切跟踪研究中央已经出台或即将出台的增量政策，及时抓好举措配套和政策落实。根据实际需要持续强化政策研究储备，结合实际抓紧研究制定经济向上向优政策。持续做好宏观政策取向一致性评价，同步充实政策储备，确保政策同向发力、不断加力、形成合力。

# 二、持续扩大对外开放合作

**积极服务海南自由贸易港建设****。**紧紧围绕“二线口岸”监管“前推后移、分类监管、智慧监管、信用监管”的基本思路，持续跟踪封关运作信息化项目运用情况，不断查找薄弱环节和风险隐患，及时配套或补充新增建设项目。持续优化自贸港政策体系，推动国家发展改革委出台优化海南自由贸易港市场准入环境若干措施，及时谋划配套项目、政策措施，确保措施落地见效。加力推动企业所得税优惠政策产业负面清单编制工作。前端入手优化鼓励类行业自行判别辅导机制，扎实做好鼓励类产业认定争议协调解决工作。审慎做好加工增值免关税政策试点企业转备案企业衔接。持续推进数据跨境安全有序流动，推进建设跨境算力设施，争取国家数据局数据领域国际合作试点落地海南，支持我省在对接国际高标准数据保护规则方面先行先试。

**积极吸引外商投资海南。**加大新版鼓励外商投资产业目录宣传，印发《鼓励外商投资产业目录（2025年版）》海南省条目界定指引，启动中西部地区外商投资优势产业目录(海南省)界定指引编制工作，积极引导外资投向四大主导产业。持续做好鼓励类产业认定工作，支持外资企业依规享惠。加强与外资招商重点主体对接，推动更多标志性外资项目落地。

**持续加强对外合作。**优化企业境外投资管理和服务，在澄迈、海口、三亚打造海南省企业境外投资“快捷通道”，积极服务企业高质量出海。认真谋划和“十五五”期间推进“一带一路”建设工作事项和项目清单，统筹推进我省参与“一带一路”高质量发展，推动椰枣种质资源保护与利用中心项目开工建设。

# 三、大力推动构建现代化产业体系

**加大产业政策供给和扩面增效。**探索新形势新要求下产业政策调整优化的新路径。结合自贸港发展，围绕“45432”产业体系，做好产业延链补链先手准备。启动实施重点产业集群壮大提升行动，促进实体经济补链延链、聚链成群。用好用足各类扶持资金、政府投资基金和政策性金融工具等，支持产业发展壮大。

**培育壮大产业发展新动能。**加快商业航天发射场及配套产业重大项目建设。统筹推进智慧海南建设，推动印发实施《智慧海南建设总体方案（2026—2030年）》，加快智慧海南应用场景建设，以数据要素综合试验区建设为抓手，推进数据要素市场化配置改革。印发实施《海南省推动“人工智能+”行动方案（2026—2028年）》，以商业航天、深海、种业为重点推动打造人工智能高价值应用场景。大力发展海上风电，拉动风电装备企业投资升级，打造海上风电装备制造基地。拓展“低空+”应用场景，同步完善低空经济管理办法，力促低空经济总产值超200亿元。推动电力“源网荷储”一体化建设，建设绿色燃料供应中心。健全物流枢纽通道网络，加快推进省级物流园区建设，大力发展跨境物流。

**着力提升园区发展能级。**指导全省产业园区科学编制“十五五”发展规划，进一步明确功能定位、主导产业，争取更多园区纳入国家开发区审核公告目录。进一步理顺园区管理机制和运行机制，推动园区管理向市场化专业化转变。持续深化园区投融资体制改革，支持有条件的重点园区和企业发行金融产品，拓宽融资渠道。支持园区围绕主导产业设立投资基金，形成“一园一基金”发展格局。持续优化园区考核体系，激发内生活力动力。推动产城融合发展，打造园区“15分钟生活圈”。推动三亚崖州湾科技城创建国家级高新区。

# 四、积极扩大有效需求

**精准发力促投资。**高质量编制实施2026年省重大项目计划，力争重大项目年度投资占全省总投资比重明显提高。狠抓“四个一批”项目攻坚，做实“五张清单”，完善项目全生命周期服务平台，全面实施“一码、一图、一表”管项目，建立“投资、项目、园区”问题库，健全重点项目问题解决机制，加快重大项目建设进度。加强项目谋划储备，探索编制全口径政府投资计划，有效运用“两重”“两新”、中央预算内投资、地方政府专项债券等各类政策工具，争取更多项目纳入国家总盘子。动态发布100个左右适宜民间资本参与的重大项目清单，提升民间投资比重。发挥政府投资基金作用，用足专项债用作项目资本金政策，强化财政与金融政策配合，以政府投资有效带动社会投资。

**多措并举扩消费。**深入落实提振消费行动各项举措，聚焦消费回流能级提升、旅游消费提质扩容、传统消费惠民升级、新场景培育突破、消费能力保障强化、清理优化限制性措施等六大方向提出新的政策措施，进一步提振和扩大消费。持续发挥消费品以旧换新政策作用，拉动我省消费稳步增长。不断扩大优质商品和服务供给，促进低空经济、银发经济发展，支持万宁打造高质量户外运动目的地，推动消费扩容升级。

**积极开展招商引资。**聚焦低空经济、绿色低碳、清洁能源等重点产业开展招商工作，深入研究海南自贸港核心政策，找准招商引资突破点，开展“点穴式”招商，积极跟进宁德时代、顺丰集团等企业，做好招商项目谋划，细化招商策略，加快招商进度，促成项目落地。

**主动服务全国统一大市场建设。**围绕“五统一、一开放”基本要求，制定实施海南省落实《全国统一大市场建设指引（试行）》2026年重点举措，认真落实不当干预全国统一大市场建设行为问题线索发现归集和甄别核实机制，进一步推动全国统一大市场建设各项任务走深走实。继续开展违规市场准入负面清单案例排查和整改，清理整治各类市场准入壁垒，营造稳定公平透明可预期的市场环境。积极推进内外资准入协同模式，制定出台第一批内外资准入协同改革事项任务清单。推动出台财政支持降低重点产业物流成本政策文件，实际物流成本下降至15%左右。

# 五、持续推进重点领域改革

**激发各类经营主体活力。**促进国有经济发展。推进国有经济布局优化和结构调整，起草出台海南自由贸易港优化国有经济布局和结构调整指引及行业目录，促进国有资本向“三个集中”聚集。发展壮大民营经济。研究制定海南省促进民营经济高质量发展进一步扩大民间投资重点措施，破解民营企业发展难题，持续优化营商环境，充分激发民间投资活力，推动我省民营经济高质量发展。落实好支持小微企业融资协调工作机制省级工作方案，持续推动各市、县、区级政府建立完善小微融资协调机制，在依法合规的前提下，帮助有真实融资需求的民营小微企业获得融资。进一步畅通政企沟通渠道，及时回应企业诉求。稳步推进要素市场化配置改革，促进各类要素资源高效配置。修订《海南省创业投资工作指引》，做好备案服务。

**持续深化公用事业价格改革**。有效发挥价格在资源配置、成本约束、激励创新、保障民生中的关键作用，探索深化公用事业价格改革与投资联动促进。全面落实新能源上网电价市场化改革方案及配套细则，密切跟踪评估市场运行效果。完善煤电、气电机组容量补偿机制，提升电力系统调节能力。继续推动稳控工商业电价各项措施落地见效。指导各市县严格落实并完善天然气上下游价格联动机制，及时疏导价格矛盾，修订印发《海南省天然气短途管道运输价格管理办法》。加快推进城镇供水价格改革，指导改革滞后市县尽快完成供水价格调整工作，适时优化全省居民阶梯水价制度。推动市县根据污水处理成本、经济社会发展水平等因素，及时合理调整污水处理费标准。

**深化电力市场建设。**科学制定2026年电力交易总体安排，推动省内电量纳入中长期合同管理。推动海上风电、集中式光伏、分布式光伏等新能源项目上网电量全量入市交易，稳妥推进核电参与电力市场交易。降低中小用户入市门槛，全力推进中小工商业用户参与电力市场交易。建立健全售电公司信用评价体系，合理管控售电公司超额收益，确保发电侧价格下降红利精准传导至工商业用户，实现2026年工商业用户平均电价较2025年稳中有降。

**深化招投标领域系统整治。**全力推进招投标领域突出问题系统整治，推动系统整治成果转化为治理效能。加快推动出台《海南省自由贸易港招标投标智慧管理规定》，为“机器管”提供法法律保障。继续扩大“机器管招投标”覆盖范围，推进“机器管招投标”系统数智化升级。探索实施“机器管工程”，构建工程项目全生命周期电子化、智能化管理模式，实现工程项目全过程精准监管。

# 六、加快推进发展全面绿色转型

**滚动实施“****2****+****N****”标志性工程****。**全面落实低碳岛建设各项重点任务，扎实开展海南自贸港零碳园区建设，有计划、分步骤推进海南自贸港各类园区低碳化零碳化改造，争取将更多有条件的园区纳入国家级零碳园区建设名单。深入推进海南热带雨林国家公园国家生态产品价值实现机制试点建设，全力打造国家公园生态产品价值实现的“海南样板”。持续打造以绿色生活方式转变为主要特征的中欧（保亭）绿色数字创新合作区，推动经济社会发展全面绿色转型。加快海南沿海防护林项目建设。

**加快构建碳排放双控制度体系。**围绕“地方碳考核、行业碳管控、企业碳管理、项目碳评价、产品碳足迹”，不断提升“双碳”综合管理能力和水平。推动印发“十五五”海南省碳达峰行动方案，明确各市县预算管理目标，明确重点用能和碳排放单位管理任务。建立省、市县两级碳排放预算管理制度，严格落实固定资产投资项目碳排放评价制度。健全海南自贸港特色产品碳足迹管理体系。加快建设“双碳”综合管理平台，实现对全省能源消费和碳排放的精准监控、管理及数据资产应用。

**持续推进****清洁能源****岛建设****。**推进3个海上风电项目建成并网，推进昌江小型堆示范工程投产、昌江核电二期3号机组并网商运，按照规划进度有序建设光伏项目，加快三亚东气电项目建设，不断提高我省清洁能源装机比例。

# 七、促进区域城乡协调融合发展

**深化拓展省际合作空间。**推动《琼州海峡南北两岸协同高质量发展实施方案》尽快印发强化跨省合作园区统筹管理。深化同京津冀、长三角、长江经济带等区域优势互补，充分挖掘合作潜力，积极谋划标志性合作项目。跟踪推进湘琼、粤琼、浙琼、琼港、深儋合作产业园建设。积极推动落实琼港合作备忘录，筹备做好2026年博鳌亚洲论坛期间琼港高层会见有关工作。

**构建全省区域协调发展新格局。**出台新一轮统筹区域协调发展三年行动方案，加快形成与海南自由贸易港更为适应的“三极一带一区”区域协调发展格局。探索海南“山海协作”模式，建立健全沿海市县与中部市县合作机制，深化重点领域合作，推动跨区域产业链优势互补、基础设施互联互通、基本公共服务共建共享。

**持续提升基础设施互联互通水平。**开工建设湛海高铁，加快三亚新机场、美兰机场三期、儋州机场、东方机场等前期工作，谋划中线铁路项目。推进三亚崖州湾科技城至乐东龙栖湾段改线工程投产、三亚—东方输气管道复线工程开工。推动海南—广东第三回500千伏交流线路工程海南侧开工建设，开展琼粤天然气管道项目前期工作。深入推进海南新型电力系统建设，打造覆盖全岛的坚强韧性电网。积极推进昌化江水资源配置工程、牛路岭灌区、海口经济圈规模化供水工程建设。

**深入推进以人为本的新型城镇化建设。**提升城镇周边地区城镇化水平，加快建设完善城镇功能项目，推动基础设施、公共服务向农村地区延伸覆盖。积极推进乡村全面振兴，推动革命老区等特殊类型地区振兴发展。促进垦地融合发展，推进垦地基础设施、公共服务、社会管理均等化，推进天然橡胶全产业链发展。

# 八、优化公共资源配置和保障改善民生

**提升基本公共服务供给质量。**编制并印发《海南省“十五五”公共服务规划》。加快推进国家区域医疗中心建设。继续实施医疗卫生强基工程，提升县域医疗服务水平。开展医养结合城乡统筹发展工作试点，扩大城乡老年人失能照护服务有效供给。全面建成海南师范大学桂林洋校区，加快建设海口永兴教育城、海南大学崖州校区、海南医科大学桂林洋校区等，以城市为单元整体推进普惠托育服务发展。

**更大力度稳定居民就业。**加强产业园区与教育、高校的联动，畅通毕业生就业渠道。做好农民工就业“稳岗”“承接”，培育壮大县域富民产业。出台《高标准高质量推进以工代赈项目建设三年实施方案》，大力实施以工代赈，拓展村民就业增收渠道。推动保亭公共实训基地项目竣工投用，加快屯昌公共实训基地建设，发挥好已建成的公共实训基地作用，提升受训居民就业能力。

**持续推进公共服务价格管理。**持续强化重要民生商品价格调控，加强节假日、极端天气民生商品价格监测监管，做好保供稳价工作，切实维护市场价格总体稳定。加强新形势下价格认定工作。规范开展成本监审。分类完善幼儿园收费、殡葬服务收费政策，加强旅游景区门票等旅游价格管理。动态调整政府定价经营服务收费目录清单，修订《海南省定价目录》，完善涉企收费长效监管机制。

# 九、牢筑底线思维统筹发展和安全

**维护能源电力安全。**加强电煤中长期合同履约监管，确保电厂存煤天数稳定达到国家常态及迎峰时段管控要求。加快推进昌江核电二期等重大电源项目建成投产，积极推动洋浦绿能等项目落地，构建“核电+风电+气电”的多元可靠电源格局。深入推进“一镇一缆”配网改造工程，提升沿海市县配网防风抗灾水平。全面排查整治能源电力行业安全生产隐患，坚决遏制重特大事故、控制较大事故、减少一般事故，完善应急体系建设，不断提升安全应急能力。

**夯实粮食安全基础。**严格落实耕地保护和粮食安全责任制考核任务，完成迎接2025年考核工作。全面梳理我省粮食仓容和布局情况，测算我省省级粮食仓储仓容情况，完成省级40万吨粮食储备库项目前期工作，力争推动项目年底前开工建设。

**加强宣传稳定社会预期。**及时做好重大政策解读和经济运行态势分析，回应社会关切。加大对自贸港建设成果、经济向好态势、产业发展亮点、民生改善成效的宣传力度，稳定市场主体和群众的发展预期。畅通政企沟通渠道，倾听企业诉求，增强政策透明度和可预期性。

# 十、持续提升发改队伍能力水平

**坚持党建引领。**压紧压实党组全面从严治党主体责任，持续深化党的创新理论武装，落实意识形态责任制，深化落实党建与业务融合行动方案，争创2个“四强”党支部，持续正风肃纪反腐，推进巡视巡查、以案促改促治、审计等问题整改落实，以高质量党建引领发展、保障大局。

**强化作风建设。**严格落实中央关于作风建设有关要求，巩固学习深入贯彻中央八项规定精神学习教育成果，持续开展整治形式主义为基层减负，创新开展“三转变、三跨越”作风建设专项行动，推动发改工作实现从审批向服务、被动向主动、守责向协作的根本转变，以过硬作风为发改工作高质量发展筑牢坚强保障。

**打造效能机关。**持续修订完善内部管理各项规章制度，抓好跟踪问效。梳理优化机关内部工作流程，探索应用人工智能，通过数字赋能促进机关运转效率不断提升。扎实做好法制、保密、安全生产等宣传教育，筑牢守法保密安全意识底线。
