# 绿证管理实施细则落地，超过有效期绿证将强制下架并核销

###### 2026年01月09日 19:21   21世纪经济报道 21财经APP   雷椰

**21世纪经济报道记者雷椰 北京报道**

1月7日，国家能源局发布《可再生能源绿色电力证书管理实施细则（试行）》（《实施细则》）。《实施细则》从职责分工、账户管理、绿证核发、绿证划转、绿证核销、异议处理、信息管理、绿证监管等方面进行全面细化，为相关主体开展绿证管理提供清晰的操作指南。

业内人士向21世纪经济报道记者表示，这些细化规定的补充进一步提升了我国绿证制度的科学性、规范性和可操作性。《实施细则》的出台，是我国绿证制度体系持续完善的重要延续，标志着绿证管理向更精细化、规范化方向迈进。![](https://ocmsmedia.sfccn.com/vod-4310da/image/default/5074B25D104A4ACE98BD874555159AB7-6-2.png)

#### 超过有效期绿证强制下架并核销

近两年来，随着绿证制度加快完善，我国已构建起全范围覆盖、全周期闭环、全过程透明、全环节高效的绿证制度体系。2024年8月国家能源局印发《可再生能源绿色电力证书核发和交易规则》，构建了绿证核发、交易、应用、核销的全生命周期管理机制；2025年3月，国家能源局等多部门印发《关于促进可再生能源绿色电力证书市场高质量发展的意见》，进一步激发绿色电力消费需求、释放绿证市场活力。

在绿证制度逐步健全的背景下，本次《实施细则》的落地时机尤为关键。绿色创新发展研究院（iGDP）能源转型项目主任、高级分析师李鑫迪向21世纪经济报道记者表示，本次《实施细则》出台非常及时，不仅外向型企业需要通过绿证满足国际绿色贸易规则要求，随着2026年可再生能源消纳责任权重逐步分解到重点行业，绿证作为我国认定绿色电力消费的唯一凭证，其重要性日益凸显。

为让绿证管理有章可循，《实施细则》在核心管理环节上进一步厘清边界，尤其对绿证分类、核发对象、核发规范作出了清晰梳理。例如，风力发电、太阳能发电、生物质发电、地热能发电、海洋能发电等可再生能源发电项目上网电量，以及2023年1月1日（含）以后新投产的完全市场化常规水电机组上网电量，核发可交易绿证。

从当前市场交易格局来看，上述可交易绿证中，风电与太阳能发电绿证占据主导地位。

国网能源院碳治理基础研究所筹备组中级研究员吴思向21世纪经济报道记者表示，根据国家能源局发布的2025年11月全国可再生能源绿色电力证书核发及交易数据，市场上最常交易的绿证发电类型是风电、太阳能发电，2025年1—11月，风电绿证交易绿证数量达3.47亿个，太阳能发电绿证交易数量为3.32亿个，分别占全部绿证交易数量的47.7%、45.5%。

储能、自发自用电量领域的绿证规定也更明晰。

“我们注意到相较于之前的规定，在本次《实施细则》中，对储能、自发自用电量的相关规定做了补充和细化。”李鑫迪表示，储能方面，明确独立储能设施放电电量不核发绿证。

同时，对于配备储能的可再生能源发电项目，确保绿证核发仅覆盖可再生能源发电，而确保不包含可能“不绿”的网电：需对发电设施及储能设施分别计量，未分别计量的按上网电量扣减下网电量核发绿证。针对自发自用电量，《实施细则》明确自发自用电量对应绿证不可交易，但生产与用能分属不同主体时，可按实际应用场景划转至用能主体，并以能源管理合同或资金结算证明，确保绿证归属与物理电量消纳一致。

在绿证核销方面，《实施细则》明确，绿证核发机构依托国家绿证核发交易系统按月监测已核发绿证有效期，对超过有效期的按时核销；对已上架且超过有效期的，强制下架并核销。超过有效期的绿证（包括已交易但未核销的绿证）核销后，环境权益归属绿证持有方确定的省级行政区，并由全社会共同享有。

北京电链科技双碳事业部总监郑颖在其文章中表示，本条具有非常重要的制度意义。首次在规则层面明确了超过有效期绿证的环境权益最终归属方式，即在核销后，其对应的可再生能源环境权益不再归属于任何单一市场主体，而是由绿证持有方确定的省级行政区内全体用电用户共同享有。

郑颖表示，这一规定在制度上填补了此前绿证政策体系中“未被声明或使用的可再生能源环境属性如何处理”的关键空白，是后续构建和完善剩余电量消费组合（residual mix）的必要前提。从电力碳排放核算角度看，明确未被核销绿证的最终去向，是完善电力碳排放因子体系、避免环境权益重复应用的核心基础之一。随着该条的明确，可以预期，围绕剩余电量消费组合、电力碳排放因子以及相关核算方法的进一步细化安排，将具备更清晰的制度空间和政策基础，值得持续关注。

#### 提高证电时间匹配精度

我国绿证市场正稳步迈向高质量发展阶段，此次《实施细则》的出台也契合了市场国际化、规模化发展的需求。回顾2025年，中国绿证市场不仅呈现量价齐升态势，而且取得RE100无条件认可国际化突破。值得注意是，本次《实施细则》对“与我国境内有可再生能源电量交换的国外用户”的账户管理也进行了相关的规定。

世界资源研究所可持续转型中心研究员张文佺向21世纪经济报道记者表示，此次实施细则中新增的“国外用户”条款是一个积极的变化趋势，为跨境绿电消费留下了窗口，有助于推动中国可再生能源电力消费向海外拓展。为中国绿证标准的国际互认与应用奠定了长远基础。

除了国际化布局，《实施细则》在绿证核销的时效性上也提出了具体要求，自2026年1月1日起，绿证持有方在核销声明绿色电力消费的绿证时，绿证对应电量生产年份应与绿色电力消费年份保持一致，鼓励绿证持有方提高证电时间匹配精度；核销绿证对应电量原则上不应超过核销场景实际用电量。

郑颖分析，绿证的有效期虽然是两年，但是在声明绿色电力消费时，必须是核销当年的绿证。这意味着，在声明绿色电力消费这一特定场景下，绿证的可使用时间窗口被限定在单一年度内，跨年度使用将不再适用。郑颖建议，有相关需求的企业，如果2025年的绿证采购已经结束，那么从2026年开始，采购当年的绿证用于声明绿色电力消费；如果2025年的绿证还没采购，可以优先考虑采购当年度的绿证声明绿色电力消费。另外，有需求的用户（特别是面对国际规则的用户），可以在目前的年度或者月度匹配的情况下，进一步探索细化时间匹配精度的做法。

针对“证电时间匹配精度”。张文佺表示，“证电时间匹配精度”是绿证向更精细化发展的积极步骤。细则中“鼓励提高精度”的表述，也是顺应了国际长期趋势。目前国内绿证按月核发、按年匹配已是良好实践，但未来必然需要向更细的时间颗粒度发展。

“需要关注绿证时效性及未来匹配精度要求的企业，并不仅限于出口企业，范围可能扩大。目前，采购绿证的需求主要集中在外资企业以及参与全球供应链的中国工厂，例如电子产品、服装纺织等行业以及受国际法规约束、涉及间接排放核算的出口型企业，相关要求的影响正从出口企业向更广泛的、需进行气候信息披露的企业群体扩展。”张文佺表示。
