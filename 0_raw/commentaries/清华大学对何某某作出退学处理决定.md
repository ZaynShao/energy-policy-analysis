# 清华大学对何某某作出退学处理决定

日前，清华大学工业工程系网站发布一则公告：已对工02班本科生何某某予以退学处理。
公告显示，何某某，工业工程系工02班本科生，学号2020080071。
何某某于2023年3月申请休学半年，2023年秋季学期应办理复学手续，但其在学校规定期限内未提出复学申请，院系多次联系均未得到回复。
“因穷尽其他送达方式后仍无法送达本通知，特予公告送达。”公告发出满六十日，即视为送达。
2024年1月，清华大学工业工程系网站曾发布《关于拟给予何某瑞退学处理的告知书》。其内容显示，何某瑞（HAMI***N COREYNI*****S），男，美国国籍，1998年2月16日出生，工业工程系工02班本科生。于2023年3月办理休学半年，2023年秋季学期应办理复学，但院系多次联系均未得到回复。根据《清华大学本科生学籍管理规定》（清校发[2020]38号）第三十九条第（五）项规定，应予以退学处理。
7月1日，现代快报记者联系到清华大学工业工程系办公室，工作人员表示，该学生目前还未与学校联系。
