# 央视《新闻联播》头条聚焦浙江扎实推进共同富裕示范区建设

8月13日晚，央视《新闻联播》头条播出《新思想引领新征程丨做大“蛋糕”缩小差距 浙江扎实推进共同富裕示范区建设》，全文如下：
习近平总书记指出，共同富裕是社会主义的本质要求，是中国式现代化的重要特征。他强调，要在推动高质量发展、做好做大“蛋糕”的同时，进一步分好“蛋糕”，让现代化建设成果更多更公平惠及全体人民。2021年5月党中央赋予浙江高质量发展建设共同富裕示范区的重大使命，总书记要求浙江，“要在推进共同富裕中先行示范。要把缩小城乡差距、地区差距、收入差距作为主攻方向”。五年多来，浙江坚定不移以“八八战略”为总纲领，以“千万工程”牵引城乡融合发展，在探索共同富裕的实践道路上不断迈出新步伐、取得新成效。
今天的浙江，2500多家国家智能工厂昼夜不息，工业机器人精准运转；一批基础大模型每天支撑着全球数百万亿次的词元（Token）处理量，综合性能稳居世界前列。
今天的浙江，宁波舟山港日吞吐量近400万吨、超12万个集装箱，与全球200多个国家和地区紧密相连；广袤乡村平均每天接待游客近百万人次，向世界展示中国乡村的多元魅力。这些，正是浙江推动共同富裕的生动场景。
共同富裕，习近平总书记念兹在兹。在浙江工作时，他就作出“八八战略”重大决策部署，推动实施了山海协作、千万工程等行动，引领浙江率先破解发展不平衡不充分问题。近年来，浙江深入实施“八八战略”，坚持在高质量发展中做大做好“蛋糕”。
浙江省发展规划研究院共同富裕研究中心副主任 潘晓栋：“八八战略”是浙江推进共同富裕的根本指引，其蕴含的城乡统筹、山海协作等理念本身就是缩小“三大差距”的源头活水。浙江扎实推进共同富裕示范区建设，就是要坚持以“八八战略”为指引，一以贯之、久久为功，探索一条高质量发展共同富裕新路子。
浙江把缩小城乡、地区、收入“三大差距”的着力点放在了相对落后的山区海岛县。共同富裕示范区设立之初，全省90个县（市、区）中，相对落后的山区海岛县就有28个，面积占全省近一半，但地区生产总值之和，只占全省约一成。
浙江省发展和改革委员会共同富裕促进处处长 林见：解题思路，是让资源要素在全省自由流动起来，取长补短。我们因地制宜为山区海岛县定制“一县一策”，发展“一县一业”，推动沿海地区与山区海岛县共建“发展飞地”，共享产业平台和科创资源。
升级山海协作，浙江对结对机制进行了优化，从原来的“1对1”迭代为“3对1”，增加了省直单位、经济强县、国有企业等，以需求为导向，与相对落后县开展全方位结对帮扶合作。衢州市柯城区就是其中之一。
浙江省衢州市柯城区副区长 郑航：我们迫切要解决的是传统产业的转型。省经信厅等部门帮助我们，推动产业的提质升级；联动了杭州的余杭、临平打造协作飞地，提升科创载体能级；高校也和我们共建了创新实验室，增强了研发的能力。这些帮扶举措不仅打通了症结，还增添了活力。
正是在这种县域之间、区域之间、部门之间协同的机制探索下，柯城发展起光电（半导体）、新材料等产业，不仅调出了相对落后县名单，还跻身浙江省工业大县。
山海携手缩小地区差距的同时，浙江持续深化“千万工程”，激发乡村发展内生动力。在丽水市缙云县“烧饼办”，地图上每一个图钉就代表一个市场。能把烧饼卖到了全球16个国家和地区，缙云走的就是乡村片区组团发展的路。
浙江省丽水市缙云县农业农村局缙云烧饼品牌服务中心主任 赵佳敏：我们把一个烧饼分解成若干个产业，胪膛村负责芥菜种植和菜干加工，昆洪村主打小麦种植，元古村负责烤炉加工，北山村的烧饼烤制技术比较强，大家优势互补，抱团发展。
片区组团将“千万工程”纵深推进，打破了以往单村发展力量薄弱的局限，以专业分工推动农村一二三产深度融合发展。像缙云烧饼产业链，串联起18个乡镇街道、200多个村，带动5万多农民增收致富。
浙江省丽水市缙云县东方镇新深渡村村民 王丽芬：很多在城里的年轻人都回来了，搞民宿，还搞研学，烤饼都成了游客体验的项目。我们在家门口可以上班了，多好啊。
目前，浙江850多个片区组团发展，覆盖5300多个村庄。乡村产业的“蛋糕”越做越大。今年上半年，“土特产富”全产业链带动651万人就业，促进农民增收270亿元。
浙江省农业农村厅厅长 李迎宾：我们深入践行“八八战略”，围绕“富民”做深做透“强城”“兴村”“融合”三篇文章。进一步提升县城带动能力，迭代实施“土特产富·十群百链”行动，推进城镇基础设施向农村延伸辐射。
共同富裕示范区建设五年多来，浙江实施“扩中提低”改革，持续缩小“三大差距”。全省城乡居民收入倍差从1.96收窄至1.81，连续13年保持缩小态势，为经济大省中最低；今年上半年，全省农村居民人均可支配收入达27555元，同比增长6.0%。
浙江省发展和改革委员会党组成员 黄鸿鸿：我们牢记习近平总书记的嘱托，推动共同富裕先行先试，通过创新驱动、产业升级把“蛋糕”做大做好，在不断夯实共同富裕物质基础的同时，让发展成果惠及更多人。力争到2030年，高质量发展建设共同富裕示范区取得决定性进展，率先呈现基本实现社会主义现代化的生动图景。
