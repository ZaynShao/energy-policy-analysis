# 柳州丨推动智能网联及新能源汽车产业优化提升

为贯彻落实国家、自治区关于发展智能网联及新能源汽车的决策部署，全面落实全市经济工作会议精神，全力以赴打造十大现代化支柱产业，打破产业边界，做好传统与新兴融合文章，推动智能网联及新能源汽车产业优化提升，根据相关文件精神，结合本市产业发展实际，柳州市工业和信息化局制定《柳州市智能网联及新能源汽车产业高质量发展三年行动方案（2026—2028年）》并于近日发布。
《方案》明确：到2028年，柳州市智能网联及新能源汽车产业实现跨越式发展，相关产业年产值突破2400亿元，本地整车年产量突破140万辆，其中新能源汽车突破100万辆。力争培育年产值超1000亿元龙头企业1家，年产值超200亿元企业3家，年产值超100亿元企业3家，智能网联汽车新车渗透率达60％以上，L3级自动驾驶汽车规模化量产，L4级自动驾驶在特定场景商业化运营。到2030年，相关产业年产值突破2600亿元。
主要任务如下：
加快重大工程建设：推进上汽通用五菱、东风柳汽等整车及专用车重点项目，加快动力电池及关键零部件项目建设，完善产业链，打造新能源汽车产业高地。
推进人工智能赋能：以AI为核心，推动国家级创新平台建设，构建跨区域研发创新链条，突破智能驾驶、智能底盘等技术，提升L2级车型占比并争取L3级准入。
关键技术攻关：突破动力电池（固态/钠电池）、电驱动系统技术，结合本地铝、竹资源研发高性能新材料并实现规模化应用，建设新材料产业集群。
推动品牌向上：支持整车企业合作开发高端“智驾”品牌，鼓励个性化高端服务，推动各车企推出新能源新车型和迭代产品，培育具有全国影响力的高端品牌。
产业链强链补链延链：引进智能装备等智能产品补齐短板，拓展热管理等核心部件延伸链条，推动传统产线向智能制造升级，提升新能源汽车关键产业质效。
智改数转网联：推广智能岛制造，开展数字化转型和柔性制造，建设工业互联网平台和智能工厂，联合研发行业大模型，推动“AI+全流程改造”加速智能化转型。
支持“向海图强”：抓住政策机遇，完善“整车出口、散件输出、整车建设”全球化布局，重点拓展东盟等海外市场，推动技术标准与东盟互认，实现从“产品输出”向“规则输出”转变。
加强公共服务平台建设：建设检验检测、中试熟化、知识产权等产业技术基础平台，完善中小企业公共服务体系，提供全方位创新支持，促进科技成果转化。
