# 综研观察｜汤婉月：跨越“中场”——5.5万亿之后，海洋经济如何驶入深水区

//图片来自招商局
8月3日，自然资源部发布上半年海洋经济运行情况。上半年我国海洋生产总值达到5.5万亿元，同比增长5.1%，高出同期GDP增速0.4个百分点，占GDP比重达7.9%。此外，上半年全国新增用海用岛项目1246个，批准用海用岛面积12.3万公顷，涉及投资额超3800亿元。用海用岛是海洋经济的“土地指标”，项目数量与投资额的双双增长，预示着未来2至3年海洋经济的产能将持续释放。
从“资源输出”到“技术驱动”的动能重塑
上半年数据亮点在于增长结构的显著优化。我国海洋经济正在经历从“捕捞+运输+旅游”的传统组合向以船舶工业和海洋工程装备等“硬核制造”为主要引擎的增长模式蜕变。
数据显示，上半年我国海船新接订单量、完工量、手持订单量三大指标分别占全球市场份额的73.9%、55.4%和63.3%，呈现出“通吃全球”态势。不仅是船舶，更是高附加值产品——万箱以上大型集装箱船、超大型原油船、大型LNG运输船等高端船型交付量质齐升，部分船企订单已排至2029年以后，海工装备新承接订单金额同比增长121.9%，占全球市场份额八成以上。船舶和海工装备的全球竞争力，本质上是我国制造业综合实力的集中投射。
此外，海洋新兴产业也在经历从“向海要资源”到“向海要科技”的嬗变。上半年，4项海洋原创新药获准进入一期临床试验，AI打通“从海洋到临床”的转化通道。全球海洋现象智能预报大模型“琅琊”2.0、南溟海洋大模型及海洋数字孪生引擎DTOEngine2.0相继发布，海洋经济正在被数字化重新定义。海洋旅游业态加速迭代，传统的“看海观光”正在向沉浸式、多元化海洋体验转型。
新兴产业的扩容增效、产品结构向高附加值持续跃迁，揭示着我国海洋经济正逐步摆脱对自然资源的初级依赖，转向依靠工业体系、工程师红利和全产业链配套能力驱动的增长模式。
5.5万亿背后的现实制约
“外部需求红利”与“内需动力不足”的温差。造船业新接订单量增长固然惊人，但全球造船周期具有明显的波动性。当前的高增速，既包含了全球航运绿色转型带来的结构性需求，也包含了前期订单集中释放的周期性因素。海洋旅游、海洋渔业等内需驱动型产业的恢复，仍依赖于国内消费大盘的整体回暖，微观主体信心尚未完全修复，海洋经济亟待将“周期红利”转向“结构红利”。
“产业勃兴”与“关键技术卡脖子”的赛跑。海洋新兴产业的发展，不仅是商业赛道的选择，更是国家战略必争之地。在深远海探测、高端海洋传感器、深海作业装备等核心环节，我国仍存在受制于人的短板。当前海洋新兴产业的绝对体量尚小，在外部形势“更加复杂多变”的背景下，基础研究与核心部件自主可控的护城河尚未筑牢。
“新兴”与“传统”的体量不对称。新兴产业增速亮眼，但海洋经济的基本盘仍是传统产业。海洋新药距离商业化还有漫长的研发周期和不确定的审批前景；海上风电的规模化仍面临成本和并网瓶颈；海洋信息服务的商业模式尚在探索。新兴产业从“突破”到“变现”、从“点缀”到“引擎”，还需要时间和投入的积累。
开发与保护的张力。在“除国家重大项目外全面禁止围填海”的政策红线之下，海洋空间的开发需要平衡开发需求与生态保护。当下，赤潮、浒苔绿潮等生态问题仍然存在，“向海图强”与“人海和谐”如何兼顾成为重大涉海项目绕不开的必答题。
对策建议
站在更长的时间尺度上看，5.5万亿只是一个“中场”数字，未来更应该聚焦以下五个要点：
一是从“规模扩张”到“价值跃迁”，重塑考核“指挥棒”。建立以单位海域产出率、海洋产业附加值率、海洋科技成果转化率等为核心的高质量发展评价体系，将海洋生态价值、科技创新贡献度纳入考核框架，引导沿海地区从粗放用海转向集约用海。强化海洋资源配置的产出约束，对低效用海项目实行退出机制。引导企业从加工制造环节向研发设计、品牌营销、售后服务等高附加值环节延伸，全面抬高海洋产业链的价值位势。
二是从“单点突破”到“系统集成”，锻造产业“生态力”。避免以单项技术、单个产品、单家企业为主的零散创新模式，树立系统集成的战略思维。串联深海探测、海洋装备、海洋能源、海洋信息、海洋金融等关键要素，构建覆盖基础研究、技术开发、装备制造、运营服务全链条的完整产业生态。建立跨部门、跨区域、跨学科的科技创新统筹协调机制，组建战略性领域创新联合体，实施海洋产业链“链长制”，形成从“点的突破”到“系统崛起”的范式转换。
三是从“陆海统筹”到“陆海融合”，打破要素“玻璃门”。衔接海上风电与陆上电网，推动绿色能源跨海入户、双向互济；对接海洋生物与陆地医疗体系，促进海洋药物研发与临床应用的联动转化；将海洋渔业融入国家粮食安全战略，夯实蓝色粮仓的供给保障功能；联通港口物流与陆路运输网络，构建多式联运的现代物流体系。强化陆海之间的要素流动、产业耦合与空间协同，拓展海洋经济的辐射纵深与溢出效应。
四是从“技术推动”到“场景牵引”，开辟应用“新航道”。树立以场景创新牵引技术迭代、以应用需求促进产业升级的发展思路，构建海上风电融合制氢、海洋碳汇交易等应用场景，以真实复杂工程环境倒逼关键技术攻关与装备迭代升级。同步拓展“海洋+”消费新场景，推广粤港澳大湾区游艇自由行经验，培育“游艇+文旅”“海岛+康养”“港口+消费”等跨界融合业态，推动海洋旅游从传统观光走向体验化与品质化。建立海洋场景清单发布与“监管沙盒”试点机制，允许新技术、新业态在限定海域试错运行。
五是从“近岸开发”转向“深远海布局”，拓展蓝色“新空间”。统筹谋划深远海发展总体布局，明确深海矿产、深海生物基因、深海空间利用等重点方向与优先序。加快突破深远海探测、深海采矿、深海通信导航等关键技术装备，依托重大科技专项开展深远海先导性试验与示范工程。探索建立深远海开发特殊政策试验区，推行与国际规则接轨的深远海开发管理制度。前瞻布局深海观测网络、海底光缆、深海补给基地等公共平台，为深远海产业化、规模化应用夯实支撑，抢占全球深远海竞争制高点。
