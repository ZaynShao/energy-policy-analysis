# 走进吴为山雕塑工作室：新大众文艺是让人民成为艺术的主人

吴为山雕塑工作室探访：塑造历史先贤，构筑文化丰碑
塑造历史先贤，构筑文化丰碑，显化精神指引、消解历史虚无，是吴为山老师雕塑创作的初心。吴为山老师的600多件雕塑作品在中国大地上、课本中、邮票里都留下了痕迹，也落地了全球三十多个国家的公共场所。这正反映了他创作的核心追求——让先辈形象深入人心，借人物载体讲述民族发展历程与新时代中国故事。
承载文化使命的艺术创作，能够带来深厚的文化底气。坚守人文创作道路，不追逐浮华潮流，深耕历史人物雕塑的创作之路，吴为山老师表示会持续地、坚定地走下去。
吴为山雕塑工作室探访：雕塑是精英的艺术，也是大众的艺术
雕塑属于立体的、空间的艺术，创作者通过对材料雕琢增减，在空间中塑造承载精神内核的实体形象。从人民英雄纪念碑到《艰苦岁月》，诸多经典雕塑跨越时代，发挥着强大的精神引领作用。
从艺术本体来看，雕塑是具备思想、情感、技术多重维度的精英艺术；从传播角度而言，它又是面向全民的大众艺术。所以精英审美与大众审美并非彼此割裂，二者相融共生，不存在无法跨越的界限。而饱含高度思想与真挚情感的精品，才能真正走进大众内心。
吴为山雕塑工作室探访：新大众文艺是让人民成为艺术的主人
党的文艺路线，根本在“人民”二字——服务于人民，从人民中来，再回到人民中去。因此新大众文艺的使命，正是激发全民文化创造力，让人民群众成为艺术创作的主人，最终提升全民族的文化艺术素质与审美认知。
这也恰好响应了当今中国式现代化的需求。中国式现代化的第一条是人口规模的现代化，十多亿人口要变成动力和资源，就必须提高全民族的素质，特别是文化艺术素养与审美水平。故而新大众文艺的意义，不止于带给人们快乐，更在于提升人们的精神境界。
