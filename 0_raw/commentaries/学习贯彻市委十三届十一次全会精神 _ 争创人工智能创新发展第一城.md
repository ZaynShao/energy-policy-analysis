# 学习贯彻市委十三届十一次全会精神 | 争创人工智能创新发展第一城

习近平总书记高度重视人工智能发展，在2026世界人工智能大会暨人工智能全球治理高级别会议开幕式上深刻指出，人工智能是世界经济增长的新引擎和新旧动能转换的加速器，正从“数字世界”走向“物理世界”。省委十五届九次全会对推动创新浙江建设全面成势作出系统部署，提出要以更大力度拥抱人工智能。市委十三届十一次全会贯彻中央、省委部署，明确了建设更高水平创新活力之城的重点任务，进一步强调把争创人工智能创新发展第一城作为首要任务。我们必须聚焦“让人工智能成为最鲜明标识、最核心支撑”这个突破口，全面推进人工智能科技创新、产业发展和赋能应用，把人工智能深度融入到建设更高水平创新活力之城和经济社会发展的各领域各方面，为高质量发展建设共同富裕示范区城市范例注入强劲的驱动力。国家人工智能应用中试基地（具身智能）打造了集场景体验、技术展示、研发合作、产业赋能于一体的综合性展示应用推广平台，引导具身智能技术进一步从实验室迈向现实社会应用。 新华社记者 樊雨晴 摄人工智能，不仅是一个机遇，更是一个时代。多年来，杭州立足数字经济先发优势，抢抓人工智能发展“风口”，先后入选国家新一代人工智能创新发展试验区和人工智能创新应用先导区，在一些领域形成了特色优势。当下，全球人工智能技术创新进入前所未有的活跃期，谁能把握大数据、人工智能等新经济发展机遇，谁就把准了时代脉搏。杭州“十五五”规划明确的“七个重大突破”关键着力点中， “人工智能创新发展第一城建设实现重大突破，创新活力之城的吸引力影响力更加凸显”被放在了首位。今年年初，市委、市政府高规格召开全市争创全国人工智能创新发展第一城暨建设一流创新生态推进大会，部署开展“三大专项行动”和“六大基础工程”，绘就了“第一城”建设的施工蓝图，架构起涵盖算力、模型、产业、开源生态、制度创新等多领域的系统性布局。在“十五五”开局之年的上半场，杭州人工智能创新发展又取得了新成效。杭产大模型保持世界领先水平，国家人工智能应用中试基地数量居全国城市首位，魔搭社区成为全球第二大开源社区，杭州“六小龙”有2家相继上市，全国首部具身智能机器人产业地方性法规正式实施，2026世界数字教育大会、全球人工智能技术大会成功举办，世界人工智能开源大赛拉开帷幕。可以说，杭州有基础，也有责任在人工智能创新发展方面走在前、作示范。争创人工智能创新发展第一城，要秉持世界眼光，积极抢占科技和产业制高点。全会提出，“第一城”建设要努力取得更多突破性进展和标志性成果。下一步，杭州必须强化“舍我其谁”的使命担当，扎实推进国家人工智能应用中试基地建设，持续打通技术研发、中试放大、产业落地关键通道；放大特色优势，支持魔搭社区打造全球开源协作生态，保持开源大模型世界影响力，着力推动具身智能产业园建设，打造具身智能机器人产业集群发展和人机协作标杆城市，制定人工智能产业发展促进条例，打造完善的数据基础制度、国际合作规则、产业治理体系。同时，打造普惠可及的城市智能算力供给体系，强化高质量语料库和数据集建设，构建高效开放的数据要素价值转化机制，夯实人工智能创新发展第一城的基础支撑。
农业采摘训练区的机器人在进行演示。新华社记者 樊雨晴 摄争创人工智能创新发展第一城，要注重场景牵引，推动融合赋能。全会对推动人工智能赋能千行百业作出部署要求。人工智能是引领这一轮科技革命和产业变革的战略性技术，具有溢出带动性很强的“头雁”效应。杭州鼓励引导人工智能运用于政务服务、民生改善、城市治理等真实场景，城市大脑3.0、安诊儿大模型等相继涌现，成为AI赋能各行各业的鲜活例证。面向未来，要深入实施“人工智能+”行动，加快培育具有杭州辨识度的智能产品矩阵，围绕“险、脏、累、烦、难、奇”等场景要求，加大全市域真实场景开放力度，打造具有示范引领性的标杆应用场景，推动人工智能更好赋能经济社会高质量发展。
人工智能的时代浪潮汹涌澎湃、浩荡前行。在这一关键的历史机遇面前，杭州必须肩负起在国家人工智能战略布局和创新浙江建设中的使命和责任，干在实处、走在前列、勇立潮头，把争创人工智能创新发展第一城、建设更高水平创新活力之城摆在重中之重位置，推动新质生产力培育加速成势，为全国全省探路先行。
