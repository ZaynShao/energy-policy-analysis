# 行业要闻 | 输送电量288亿千瓦时 陇电入鲁工程为甘鲁两省发展注入绿色动能

5月8日，全国首个“风光火储一体化”大型综合能源基地外送工程——甘肃陇东至山东±800千伏特高压直流输电工程正式投运一周年，累计输送电量288亿千瓦时，其中，新能源电量占比超过40%，为两省经济社会发展注入了绿色动能。陇电入鲁工程是我国“西电东送”重大工程，工程西起甘肃省庆阳市庆阳换流站，东至山东省泰安市东平换流站，全长915公里。▲这是甘肃庆阳境内的陇电入鲁工程输电线路和配套风力发电机组。受访单位供图国网甘肃省电力公司电力调度中心调度处处长刘克权介绍，陇电入鲁工程属于风电、光伏、火电、储能四类电源“打捆”外送的特高压电网，且新能源高占比。甘肃省风光资源富集，正加快打造全国重要的新能源及新能源装备制造基地。甘肃在满足省内用电需求的同时，正加快推动多条电力外送通道项目建设，目前，甘肃已投运陇电入鲁工程、陇电入湘工程，陇电入浙工程预计今年底带电调试，陇电入川工程争取年内核准开工。（来源：新华社）
