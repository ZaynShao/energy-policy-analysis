# 赵世勇、张忠当选中央纪委副书记

赵世勇同志任中共中央纪律检查委员会副书记，张忠同志任中共中央纪律检查委员会常务委员会委员、副书记。
新华社消息，中国共产党第二十届中央纪律检查委员会第六次全体会议，于2026年8月22日在北京举行。
全会按照党章规定，选举赵世勇同志为中共中央纪律检查委员会副书记，张忠同志为中共中央纪律检查委员会常务委员会委员、副书记。
赵世勇，男，汉族，1966年5月生，四川营山人，中共党员，西南农业大学农学系农学专业本科毕业，四川农业大学农学院玉米所作物遗传育种专业在职研究生学历，农学博士学位，高级农艺师。
赵世勇曾任江苏省副省长，江苏省委常委、省委秘书长，江苏省委常委、组织部部长等职。
此番履新前，赵世勇为中央纪委常委，国家监委委员，中央纪委国家监委组织部部长，二级副总监察官。
张忠，男，汉族，1968年3月生，山东莱州人，大学，工商管理硕士，中共党员。
张忠曾任中央巡视组副部级巡视专员，吉林省委常委、省纪委书记、省监察委员会主任等职。
此番履新前，张忠为中央纪委委员，江苏省委常委、省纪委书记、省监察委员会主任、二级副总监察官。
