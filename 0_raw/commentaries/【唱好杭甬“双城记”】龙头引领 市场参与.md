# 【唱好杭甬“双城记”】龙头引领 市场参与

“十四五”期间，杭甬两地龙头企业率先破题，聚焦杭州、宁波双城特色优势，打通跨城协同的创新链、产业链、供应链，有效丰富了科创研发到产业落地的双城协同场景。
浙江吉利控股集团有限公司是以整车制造为核心、覆盖全产业链的全球化综合产业集团，业务涵盖汽车及上下游产业链、智能出行服务、绿色运力等多个领域，旗下乘用车品牌有吉利、吉利银河、领克、极氪、沃尔沃等。
吉利集团作为杭甬产业协同的重要链接者，构建了“杭州总部决策+宁波智造基地”的双核驱动模式。杭州总部聚焦集团战略管控、前瞻车型定义、智能驾驶算法研发及用户体验中心建设；宁波前湾新区则汇聚了极氪智慧工厂、smart精灵#1生产基地及动力总成、座椅、内饰等数十家核心零部件配套企业。吉利在宁波构建了从核心零部件到整车制造的完整产业链，2025年前湾新区新能源整车产量达到14万辆，助力宁波汽车制造业稳居全市第一大产业，以链主之势牵引双城产业能级跃升。
杭州宇树科技有限公司是“杭州六小龙”之一，专注于消费级、行业级高性能通用足式/人形机器人及灵巧机械臂的自主研发、生产和销售，是全球首家公开零售高性能四足机器人并最早实现行业落地的公司，全球销量历年领先。
宇树科技立足杭甬科技与场景的互补优势，多路径促进两市产业协作。强化平台建设，在宁波海曙落地智能应急机器人产业园，联合多方组建浙江宇蓝智能应急机器人研究院，与浙大宁波理工学院共建“宇树机器人产业学院”；强化场景应用，聚焦宁波舟山港空箱查验、重箱查验两大核心场景，落地智能查验四足机器人项目，3台机器狗同时作业可将以往4至6人1小时以上工作量压缩至20分钟内完成，有效提升港口通关效率。宇树科技正以“杭甬联动”之势，大力书写具身智能赋能实体经济的生动篇章。
浙江大丰实业股份有限公司是国内文体旅全产业链整体解决方案龙头企业，核心围绕文化、体育、旅游三大场景提供一体化科技装备与运营服务，产品广泛落地大剧院、体育中心、主题乐园、央视春晚、大型会展等项目。
大丰实业立足杭甬双城产业差异化优势、互补化格局，成功探索出“杭州创意+宁波智造”的跨城融合发展路径。目前，企业已形成独特的“杭甬双总部”协同架构：杭州总部侧重于创意策划、数字内容研发及智能控制系统开发等前端创新工作；宁波总部依托全球最大文体演艺装备智能制造中心，承担生产制造、工艺优化、工程实施及产业化落地任务。企业在杭州亚运会主火炬塔“钱江潮涌”、杭州宋韵文化沉浸大戏《今夕共西溪》等国内项目，及2026年日本爱知·名古屋亚运会开幕式独家合作等国际案例中，均采用“杭州创意方案+宁波智造设备”协同模式，以双城合力共拓全球市场。
中控技术股份有限公司是以工业数据为基础、AI大模型为核心、全场景智能体为触手的工业AI平台型公司，核心产品被应用在全球50余个国家和地区，服务覆盖化工、石化等数十个重点行业的海内外3.5万余家客户。
中控技术充分发挥杭甬双城互补优势，探索出“杭州研发、宁波应用”协同创新路径。在杭州总部设立技术研发团队，聚焦宁波企业场景需求开展定向技术攻关；在宁波设立本地化公司，配备工艺优化、项目实施、运维服务专属团队，并通过“场景—反馈—优化—再落地”链路闭环，实现杭州技术与宁波场景的双向赋能。其自主研发的时间序列大模型TPT已在宁波多家企业应用，成为行业标杆示范项目。在万华化学（宁波）氯碱有限公司，助力实现年节省原料用量约1000吨，年节电975万千瓦时，年减少碳排放量约5660吨；在镇海炼化分公司，落地常减压装置智能化应用，关键机泵异常预警准确率达95%以上，年均有效减少原油加工损失成本超200万元。
