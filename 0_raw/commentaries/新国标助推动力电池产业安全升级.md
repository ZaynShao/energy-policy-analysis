# 新国标助推动力电池产业安全升级

《电动汽车用动力蓄电池安全要求》正式实施，全方位提高了动力电池行业安全准入底线，助力我国动力电池产业迈向安全提质、技术升级的新阶段。
7月1日，《电动汽车用动力蓄电池安全要求》（GB 38031—2025）（以下简称“新国标”）正式实施，其中将“不起火、不爆炸”列为强制性要求，被业内称为“史上最严电池安全令”。
业内人士认为，新国标正式实施全方位提高了动力电池行业安全准入底线，不仅促进电池企业开展全链条安全技术升级，还将加速行业低端产能出清与格局优化，助力我国动力电池产业迈向安全提质、技术升级的新阶段。
新增多重安全测试
我国是动力电池生产与装车大国。中国汽车动力电池产业创新联盟的数据显示，今年5月，国内动力电池装车量71.9吉瓦时，同比增长25.9%。1—5月，国内动力电池累计装车量259.1吉瓦时，累计同比增长7.3%。庞大市场体量下，新国标的实施为动力电池产品划定统一、严苛的安全准入红线。
在热扩散测试方面，新国标首次要求将电池热失控后的安全防护能力从“着火、爆炸前5分钟提供热事件报警信号”，修改为“不起火、不爆炸（仍需报警），烟气不对乘员造成伤害”。同时，进一步明确待测电池温度要求、上下电状态、观察时间、整车测试条件。
新国标新增底部碰撞测试，通过用30mm直径的撞击头，以150J的能量撞击3次，考察电池底部受到撞击后的防护能力，技术要求为无泄漏、无外壳破裂、无起火或爆炸现象，且满足绝缘电阻要求。
新国标新增快充循环后安全测试，考察动力电池在长期快充循环后的安全性，针对20%SOC充电至80%SOC时，总充电时间不超过15分钟的电池单体，要求电池达到300次快充循环后进行外部短路测试，同样满足“不起火、不爆炸”。
数据显示，截至2024年2月，受访的36家整车和电池企业中，已有78%的企业具备动力电池“不起火、不爆炸”的技术储备，14%的企业预计将在2026—2027年具备此项技术，另有8%的企业将在2030年及以后实现。
目前，头部电池企业已提前完成新国标合规认证，宁德时代麒麟电池、比亚迪第二代刀片电池、欣旺达动力闪充电池3.0等产品均通过新国标全套检测，部分头部企业产品安全标准普遍高于新国标要求。以比亚迪第二代刀片电池为例，在经受300J、1000J、1500J的底部撞击后，电池包均保持“不起火、不爆炸”。此外，该产品完成500次闪充循环后，进行了边闪充至96.4%电量边针刺的试验，最终同样实现“不起火、不爆炸”。
业内专家认为，新国标显著抬高动力电池安全准入门槛，倒逼电池企业搭建全方位安全体系。与此同时，新国标确立的“不起火、不爆炸”硬性指标，也进一步提升消费者对新能源汽车的使用信心。
加速行业优胜劣汰
为达到新国标要求，各家企业需加大动力电池研发投入，短期生产成本将有所上升。但长期看，持续的安全技术升级将全面提升我国动力电池产业综合实力，进一步强化其在全球市场的竞争优势。
新国标带来的升级需求还将沿产业传导至上游，拉动隔热防火材料、锂电改造设备市场。北方工业大学教授纪雪洪表示，一方面，新规抬高电池安全门槛，绝缘、隔热、防火材料刚需显著提升，相关材料供应商将直接受益；另一方面，电池厂商为满足全新安全测试要求，需要对产线工艺、生产设备进行改造升级，这也给动力电池工艺装备企业带来利好。
与此同时，合规门槛提升进一步加速行业优胜劣汰，低端落后产能将持续出清。
“动力电池行业历经多年市场竞争，已出清一批实力薄弱、技术落后的中小产能，而新国标落地再度抬高行业合规门槛，缺乏核心技术储备、资金实力不足的中小厂商将加速出局，行业市场集中度将进一步提升，推动产业向高质量、高安全方向转型。”纪雪洪说。
下一代电池技术迎机遇
值得注意的是，随着动力电池产业不断发展，高安全性的新一代电池产品愈发受到市场认可。业内分析人士认为，新国标将间接推动固态电池技术迭代，加快产业化落地进程。
五矿证券研报指出，新国标将促进电池行业安全升级，企业有望在电池包PACK层面优化热管理、液冷散热系统，及锂电材料热稳定性改进，同时带来电池热安全系统升级的投资机会，推动固态电池产业发展。
东莞证券认为，理论上，固态电池在能量密度、安全性、续航、快充、低温性能和循环寿命等各项性能指标上可以全面超越传统液态锂电池，在新能源汽车、高端储能、低空eVTOL、人形机器人、商业航天等新兴领域均具备广阔的应用前景。
全固态电池不含易燃液态电解液，具备天然安全优势，未来有望成为中长期适配严苛安全标准的核心技术路线之一。目前行业研发与量产节奏持续提速，各大头部电池企业纷纷加大固态电池研发布局。但现阶段，固态电池大规模商业化落地仍难以实现。
有分析指出，安全正构筑动力电池行业全新核心竞争壁垒，企业不再单纯围绕能量密度进行比拼，已迈入技术、品质、安全协同比拼的新阶段。无论布局何种技术路线，企业都应将安全放在产品开发的首要位置，在新国标约束下，唯有兼顾性能、成本与安全的产品才能持续获得市场认可。
