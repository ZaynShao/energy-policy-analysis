# 国航、东航、南航、海航、厦航、川航、天航等，发布通知

多家航空公司发布受台风“巴威”影响航线客票处理通知。
7月11日，今年第9号台风“巴威”携强风雨即将影响我国多地。
日前，国航、东航、南航、海航、厦航、川航、天航等多家航空公司发布受台风“巴威”影响航线客票处理通知，符合条件的旅客可享受一次免费变更或全额免手续费退票服务。
国航
在2026年7月9日16时（含）前购买或换开产生新票号的国航999开头的客票（包括里程奖励客票）；
客票未使用行程涉及旅行日期为2026年7月11日（含）至2026年7月12日（含）之间杭州、温州、义乌、丽水、嘉兴、宁波、台州、衢州、舟山、厦门、福州、泉州、武夷山机场进出港的国航实际承运航班和挂CA航班号的代码共享航班；
在客票有效期内，首次变更至2026年7月18日（含）前的航班，免收变更手续费、子舱位差价及淡旺季差价。在客票有效期内，可以办理未使用航段退票，免收退票手续费。
东航（含上航）
客票中至少含有一段未使用的福建省或浙江省（包括但不限于福州、厦门、泉州、杭州、宁波、温州、台州、衢州、丽水、舟山）进港、出港或经停航班（包括东航或其他航空公司航班），航班起飞日期在2026年7月11日（含）—2026年7月12日（含），同一客票内的其他未使用航段日期不限。
适用于2026年7月9日（含）至航班计划起飞时刻前取消行程的旅客。
办理变更至原航班前后3天（含）以内的航班，可免费变更一次。在客票有效期内，可至原购票渠道办理未使用航段非自愿退票，免收退票手续费。
南航
在2026年7月9日17时（含）前购买，行程涉及福州、厦门、泉州、杭州、台州、宁波、温州、义乌、嘉兴、台北桃园、高雄机场进出港（含经停）的南航航班及使用CZ航班号的代码共享航班，且旅行日期为2026年7月11日（含）至2026年7月12日（含）票号为784开头的南航客票。
海航
适用航班：海南航空福州、厦门、泉州、杭州、宁波、温州、丽水进出港的国内航班（包含海南航空为市场方的代码共享航班）。
适用日期：航班日期为2026年7月11日（含）至2026年7月12日（含）；出票日期或换开日期为2026年7月9日18时（含）之前。
在航班计划出港时间前已取消航班定座的客票，在客票退票期限内至原购票地办理未使用航段全退，免收退票费。在航班计划出港时间前已取消航班定座的客票，可免费变更至2026年7月18日（含）前同航线航班，免收变更手续费，但需收取原票面价与变更后适用舱位票价的票款差额。
厦航
2026年7月9日16时（含）前购买或换开的厦航731开头的客票，且客票未使用行程涉及旅行日期在2026年7月11日（含）至2026年7月12日（含）之间的福州进、出港（含经停）厦航实际承运航班或使用MF航班号的代码共享航班。
首次变更至原航班前后3天（含）以内相同航程的厦航实际承运航班，免收变更费，如发生票价价差按规定收取。在客票有效期内申请退票，免收退票费。
深航
自2026年7月9日0时（含）以后申请客票变更或退票（以取消订座时间为准），凡在2026年7月9日18时（含）前购买或换开产生新客票号的479客票（包括里程奖励客票），行程涉及旅行日期为2026年7月11日（含）至2026年7月12日（含）之间台北、杭州、温州、义乌、丽水、嘉兴、宁波、台州、衢州、舟山、厦门、福州、泉州、武夷山进出港ZH/CA/SC/KY实际承运航班和挂深航航班号的代码共享航班。
天航
适用航班：由天津航空实际承运的涉及福州、厦门、泉州、杭州、温州、丽水、宁波、台州（含经停以上所有涉及航点）进出港国内航班和天津航空为市场方的涉及福州、厦门、泉州、杭州、温州、丽水、宁波、台州（含经停以上所有涉及航点）进出港国内代码共享航班。
适用日期：需同时满足航班日期为2026年7月11日（含）至2026年7月12日（含），出票日期为2026年7月9日18:00（含）之前。
川航
在2026年7月9日16时（含）之前使用876票证填开或换开的客票（包括里程兑免客票）；
客票未使用行程涉及旅行日期为2026年7月11日（含）至2026年7月12日（含）之间福州、厦门、泉州、杭州、宁波、温州、舟山进出港川航实际承运航班及使用3U航班号的代码共享航班；
首次变更至2026年7月17日（含）前川航实际承运的相同航线航班，免收变更费。在客票有效期内至原购票渠道免除退票费办理退票。
山航
在2026年7月9日16时（含）前购买或换开产生新票号的山航324开头的客票（包括里程奖励客票）；
客票未使用行程涉及旅行日期为2026年7月11日（含）至2026年7月12日（含）之间杭州、温州、宁波、台州、衢州、舟山、厦门、福州、泉州、武夷山机场进出港的山航实际承运航班和挂SC航班号的代码共享航班；
首次变更至2026年7月18日（含）前的航班，免收变更手续费、子舱位差价及淡旺季差价。在客票有效期内，可以办理未使用航段退票，免收退票手续费。
春秋航空
适用于2026年7月9日12时（含）前购买，且乘机日期2026年7月11日（含）至2026年7月12日（含）之间，由春秋航空（9C）实际承运的福州、厦门、泉州、杭州、宁波进出港航班。
如选择退票，免收退票手续费；如选择变更至由春秋航空（9C）承运的原航班前后3天（含）以内的航班，如发生票价价差按规定收取，免收变更手续费，免手续费办理仅限一次。
旅客可登录各航司官网，查看客票变更或退票规则。提醒相关旅客，密切留意天气状况和航班状态，建议优先通过航空公司线上渠道，办理客票退改手续。
