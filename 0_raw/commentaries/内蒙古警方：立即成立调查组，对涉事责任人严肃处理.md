# 内蒙古警方：立即成立调查组，对涉事责任人严肃处理

内蒙古达拉特旗警方通报“一辆警车存在擅自更换车标”：成立调查组，对涉事责任人予以严肃处理。
内蒙古达拉特旗警方通报“一辆警车存在擅自更换车标”：成立调查组，对涉事责任人予以严肃处理
8月11日，内蒙古达拉特旗公安局发布情况通报：近日，有媒体报道我局“一辆警车存在擅自更换车标”一事，引发关注。对此，我局高度重视，立即成立调查组，全面开展调查。调查结果将第一时间公布。同时，对涉事责任人依规依纪依法予以严肃处理。
真诚感谢社会各界和新闻媒体的关心监督。
