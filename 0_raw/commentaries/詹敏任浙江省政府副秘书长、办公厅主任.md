# 詹敏任浙江省政府副秘书长、办公厅主任

詹敏任浙江省人民政府副秘书长、办公厅主任，浙江省人民政府参事室主任（兼）。
8月13日，浙江省政府网站发布人事任免通知，决定：詹敏任浙江省人民政府副秘书长、办公厅主任，浙江省人民政府参事室主任（兼），免去其浙江省中小企业局局长职务。
詹敏，男，汉族，1968年4月生，大学学历，中共党员。
詹敏曾任杭州市滨江区区长、区委书记，浙江省能源集团有限公司董事、党委副书记、副总经理，浙江省机场集团有限公司董事、董事长等职。
2023年任浙江省经济和信息化厅党组书记、厅长，浙江省中小企业局局长（兼），至此番履新。
