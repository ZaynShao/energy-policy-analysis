# 特斯拉、谷歌牵头成立联盟，发力储能/虚拟电厂以盘活电网闲置产能

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)  

储能与电力市场获悉，3月10日，特斯拉、谷歌等多家企业共同成立行业联盟Utilize，计划通过电池储能、需求响应、虚拟电厂、电网优化技术等手段，提升美国电网利用率、降低居民与企业用电成本，并满足持续增长用电需求。  
该联盟成员包括特斯拉、谷歌，以及暖通空调设备企业开利（Carrier）、能源服务公司Sparkfund、智能配电盘制造商SPAN、数据中心开发商Verrus、家庭能源管理系统公司Renew Home。  

据了解，该联盟的核心观点是：美国电网在绝大多数时间里并未被充分利用。

  

电网是按照极端高峰用电需求建设的，但大部分时间里大量容量处于闲置状态，这导致消费者每度电的电价远高于合理水平。

  

美国杜克大学针对全美22个地区电力系统的分析显示，美国电网平均利用率仅约**53%**。另外，斯坦福大学一项研究也发现，美国西部输电线路即使在用电高峰时段，利用率也仅为18%–52%，平均利用率仅30%左右。研究人员分析，仅依靠现有电网，就可额外满足76–215GW的用电需求。

  

Utilize联盟估算，如果合理解决这类低效问题，10年内可节省超过**1000亿美元**，在部分情景下最高可节省**1800亿美元**。

联盟成立原因方面，特斯拉储能业务的快速扩张是促使特斯拉加入联盟的原因之一。2025年特斯拉储能装机量达到创纪录的**46.7GWh**，能源业务营收预计同比增长约27%，达到**127亿美元**。同时特斯拉还在通过户用电池Powerwall打造虚拟电厂，推进电网需求侧管理。

  

谷歌则因AI数据中心扩张，用电需求激增。谷歌近期斥资**47.5亿美元**投资AIDC电力基础设施。未来，美国数据中心用电需求预计将从2026年的75.8**GW**，增至2030年的**134.4**GW****。

  

对这些企业而言，利用闲置电网容量意义重大：无需新建电厂或输电线路，就能更快接入数据中心等大功率用电负荷。

  

Utilize联盟同时在推动相关政策落地，目前已取得进展。弗吉尼亚州议会通过法案**，要求大型电力企业监测并上报电网利用率，目前该法案正等待州长签署。**

  

联盟还计划与各州政府合作，通过电池储能、需求响应、虚拟电厂、电网优化技术等手段，让现有电网更高效运行。业内观点认为，提升电网利用率的路径，既能降低电费，又能应对用电需求增长，是具备现实可行性的解决方案。
