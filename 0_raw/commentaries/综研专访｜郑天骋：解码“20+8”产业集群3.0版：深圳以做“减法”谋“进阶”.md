# 综研专访｜郑天骋：解码“20+8”产业集群3.0版：深圳以做“减法”谋“进阶”

7月29日，深圳"20+8"产业集群3.0版正式印发。从2022年1.0版初试啼声，到2024年2.0版微调优化，再到2026年3.0版系统重构，四年三版，一步一阶。
翻开这份最新方案，最直观的变化落在两个数字上。20变成了10，8变成了5。从"20+8"到"10+5"，深圳在产业政策设计上罕见得做了“减法”。
但细看之下，“减法”背后是一套更为精准的产业施策逻辑。综合开发研究院（中国·深圳）企业与市场研究中心执行主任郑天骋在接受记者采访时表示，从面状铺开转向线状攻坚，从平均用力转向分类施策，从政策驱动转向生态驱动，是3.0版最值得关注的含金量。
按产业链逻辑来组织集群门类
3.0版对集群门类的调整力度，远超前两版。有合有拆，标准清晰。
智能传感器并入半导体与集成电路，大健康分别并入生物医药和高端医疗器械，合成生物与细胞与基因合并为生物制造，高性能材料和前沿新材料合为一体，机器人与智能机器人合二为一。与此同时，高端装备与仪器拆分为高端技术装备和精密仪器仪表，低空经济与空天拆分为低空装备与应用和商业航天与航空。
合，是因血脉相通。传感器本就是半导体产业链的关键一环，硬拆成两个集群反而割裂了产业的内在联系。合成生物与细胞与基因，同属生物制造的技术谱系，合并后形成了一个贯通上下游的完整产业逻辑。过去按概念热度而非产业链逻辑去划分门类，只会让政策资源四处散落，难以浇灌出真正的竞争力。
拆，是因路径分化。低空装备与商业航天，技术路线不同、商业模式迥异，混为一谈政策反而找不准靶心。高端装备与仪器一分为二，同样是基于技术特征和应用场景的实质性差异。
郑天骋认为，这是3.0版最核心的变化之一，第一次真正按产业链逻辑来组织集群门类，而非按行政便利或概念热度划分。他将此概括为从"面状布局"转向"线状攻坚"：过去是按领域"铺开"，各区各自发力；如今是按产业链"穿透"，知道每个环节谁强谁弱，才知道资源往哪里投。
"群链一体化"五个字道出的正是此理。先有产业链的精准梳理，才有产业集群的扎实厚度。方案要求"全面摸清产业链关键环节、领域""绘制并动态更新产业图谱"，正是要把这条线真正画清楚。
四档分层，告别撒胡椒面
减法做完，3.0版并未止步。
20个战略性新兴产业集群被划分为四档：优势拓展、战略重点、基础支撑、综合提升。每一档对应完全不同的政策逻辑和资源倾斜力度。
优势拓展类7个，包括新型网络与通信、智能终端、新能源、智能网联新能源汽车等。这些产业集群底子厚、市场相对成熟，政策重心是"以链主企业为核心，推动大中小企业协同融通发展"，即固本强基、巩固优势。
战略重点类6个，包括半导体与集成电路、人工智能与应用、智能机器人、低空装备与应用等。这些产业集群投入大、窗口窄、赌注高，需要"举全市之力集聚资源，以超常规力度支持培育"。说白了，这是深圳要集中火力攻坚的阵地。
基础支撑类3个，包括高性能与前沿新材料、高端技术装备、精密仪器仪表。它们默默为其他产业集群提供底座支撑，要的是"聚焦重点环节靶向发展"，精准对接市场需求，为其他集群增势赋能。
综合提升类4个，包括生物医药与生命健康、数字内容与创意、优势传统产业升级等。这些产业集群处于成长阶段，需要充分发挥新一代信息技术的渗透效应，推动跨界融合。
四档划分的背后，体现的是精细化的资源配置。同一份财政预算、同一套政策工具，在不同集群身上承担完全不同的使命。郑天骋认为，这不是"撒胡椒面"式的平均主义，而是精准识别产业阶段后的差异化配置。产业成熟度不同，政策逻辑就不同；战略紧迫度不同，资源密度就不同，这正是从"粗放施策"到"精准滴灌"的进阶。
提升市级统筹力度
门类精简了，分类精细了，3.0版还在另一个维度上做了文章——空间与保障。
空间布局上，方案将"每个产业集群控制在3至5个区布局"调整为"5至6个区"，同时明确"重大项目由市级层面结合实际跨区布局"。
随着时代发展，单一行政区难以承载完整产业链时，市级统筹就得出面，打破区域壁垒，让产业链上下游在不同行政区之间穿行无阻。
从"区内竞争"到"链上协同"，这不仅是效率问题，更是格局问题。郑天骋认为，深圳内部跨区协同机制一旦跑通，对粤港澳大湾区而言便是制度参照——当产业要素能在深圳各区之间顺畅流动，深港澳之间更高层级的要素流通也就有了可循之径。
保障机制上的变化同样值得关注。"一张办公桌、一间办公室、一层办公楼"的创业空间保障，"一张床、一间房、一套房"的住房供应体系——从创业到安家，覆盖了一个人的完整生命周期。
对于区域产业发展来说，上半场拼的是政策优惠、补贴力度；下半场拼的是生态完整度、制度黏性。郑天骋将这一变化概括为从"拼政策优惠"到"拼生态宜居"，当企业和人才不再为一张桌子、一间房发愁，产业才能真正扎下根来。
与此同时，"补投联动"、企业创新积分信用贷款、政府投资基金多元化退出渠道等制度安排，也共同指向同一个目标：即把企业的创新能力，从难以量化的"软信息"，转化为可授信、可交易的"硬资产"，配合企业分级入库培育与兼并重组支持政策，企业发展环境正从"孵化导向"转向"成长导向"。
郑天骋认为，从2022到2026，三个版本走出一条从粗放到精准、从分散到系统的进阶之路。2025年深圳战略性新兴产业增加值达1.67万亿元，连续四年每年跨越一个千亿台阶。3.0版提出的2030年目标是2.3万亿元。
2025年，深圳战略性新兴产业增加值突破1.6万亿元、占地区生产总值比重达43%。3.0版提出，到2030年，全市战略性新兴产业集群发展壮大，未来产业成形成势，科技创新和产业创新深度融合，制造业加快向高端化智能化绿色化方向提质升级，以先进制造业为骨干的现代化产业体系建设成效显著。战略性新兴产业增加值达2.3万亿元、占地区生产总值比重达45%。（南方+记者 崔璨）
