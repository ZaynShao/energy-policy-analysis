# 人民艺坛 |八月展讯速递（三）

展览名称：丝绸之路——杨晓阳丝路四十年美术创作
暨文献展（贵州）
展览时间：2026年8月7日至2026年8月23日
展览地点：贵州美术馆1、2、3、4、6号展厅
主办单位：贵州省文化和旅游厅、中国文化艺术发展
促进会
主要内容：本次展览汇集了杨晓阳先生近500件精品力作。杨晓阳先生有关丝路题材的创作，始于一次壮游——1985年，他从西安出发，沿丝路古道一路骑行至新疆，历时四个月，在无垠的戈壁与古老的城垣间，亲身感受了西部丝路无与伦比的自然风光、历史风俗与民族风情。此后四十年间，他陆续以丝绸之路为题材创作了大量的艺术作品，本次展览，正是对杨晓阳先生这一恢弘艺术征程的一次全面而深入的梳理与呈现。
展览名称：观妙入真——永乐宫的建筑艺术与传承
展览时间：2026年7月9日至2026年12月6日
展览地点：四川博物院一楼临展二、三、四展厅
主办单位：四川博物院、山西省古建筑与彩塑壁画
保护研究院、山西省永乐宫壁画保护研究院
主要内容：本次展览是永乐宫历次巡展中文物品类最丰富的一站，共展出永乐宫和四川多家博物馆共计125件/套文物，分成“煌煌巨制”“遗珍重光”“巧凝造化”三个板块。“煌煌巨制”板块依托元代道教文物、古建遗存，梳理还原永乐宫建造脉络；“遗珍重光”板块展出永乐宫迁建工程的一手档案史料，致敬祁英涛、柴泽俊等初代文保人的坚守；“巧凝造化”板块借助建筑构件、彩塑残件、3D打印壁画，解析元代壁画与彩塑传统工艺技法。
展览名称：出谷新声寂处来——吴子复艺术回顾展
展览时间：2026年6月30日至2027年8月30日
展览地点：广州艺术博物院
主办单位：广州艺术博物院四楼15号馆
主要内容：本次展览首次完整汇集吴子复在1949年前、1950年至1960年、1970年后（晚年最后十年）等各时期油画、书法、国画、篆刻、印谱、拓片、瓷盘、速写、素描等作品约120件，分为“取诸怀抱”“物我一如”“通会之际”三个单元，并通过辅助陈列板块，复原“子复画室”，展现其与师友交往、对学生教育等重要史料 。
展览名称：戏写——关良的艺术世界
展览时间：2026年7月16日至2026年9月6日
展览地点：浙江美术馆7、8、9展厅
主办单位：浙江美术馆、上海美术馆、上海中国画院
主要内容：作为20世纪极具革新精神的艺术大家、现代戏剧人物画的开创者，关良为中国画的传承与创新，走出了一条独一无二的道路。本次展览展出关良的速写、手稿、草图与珍贵文献，完整还原关良从现场速写、提炼修正到最终成稿的创作全过程，清晰呈现他从观戏写生到笔墨定型的艺术心路。
