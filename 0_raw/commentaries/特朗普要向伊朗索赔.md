# 特朗普要向伊朗索赔

美国总统特朗普发文称，在伊朗要求美国就军事冲突进行赔偿后，他也要向伊朗提出索赔。
美国总统特朗普当地时间8月10日在社交媒体发文称，在伊朗要求美国就军事冲突进行赔偿后，他也要向伊朗提出索赔，并已指示美方谈判代表将这一要求明确纳入今后所有谈判议程中。
特朗普称，伊朗谈判代表正要求就过去5个月军事冲突期间遭受的损失进行赔偿，而“这一议题从未在此前的任何谈判或会议中被提及”。他现在也要求伊朗赔偿“用路边炸弹及在众多冲突中”造成的伤亡，包括赔偿“‘科尔’号驱逐舰遇袭事件中的遇难者家属，以及数千名在战斗中丧生的人员”。
据伊朗新闻电视台8日报道，伊朗最高国家安全委员会秘书佐勒加德尔表示，如果美国不改变其行为，霍尔木兹海峡将维持关闭状态，重开霍尔木兹海峡的前提是美国满足永久停止对伊军事行动等5个条件，其中包括归还伊朗被冻结资产，赔偿相关军事行动给伊朗造成的损失。
2000年10月12日，一艘装载炸药的小艇对正在也门亚丁港补充燃料的“科尔”号驱逐舰发动自杀式爆炸袭击并重创该舰，造成17名美军人员死亡。2019年1月，美方宣布已击毙“科尔”号驱逐舰爆炸袭击事件的主谋贾迈勒·巴达维。
