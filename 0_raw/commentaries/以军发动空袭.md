# 以军发动空袭

以军空袭加沙造成9人死亡。
巴勒斯坦伊斯兰抵抗运动（哈马斯）19日发表声明称，以军当天中午对加沙城市政警察总部发动的空袭造成9人死亡。以色列国防军发表声明说，以军打击针对的是哈马斯军事指挥官。
哈马斯在声明中表示，以军空袭造成9人死亡，其中大部分是警察和工作人员，另有十多名平民受伤。声明指出，以方在与美国特使库什纳就推进停火协议沟通后发动空袭“尤其令人愤慨”，是以色列政府“蓄意破坏”外交努力，试图重新启动对加沙地带的军事行动。
声明驳斥了以方关于袭击哈马斯领导人的说法，称其“纯属捏造”，目的在于掩盖对警察和手无寸铁平民的蓄意攻击。声明要求停火协议的调解国和担保国，特别是美国政府摆明立场，迫使以色列遵守已达成的协议，避免地区重回“战争和局势升级的恶性循环”。
以色列国防军当天发表声明称，以军在加沙地带中部努赛赖特地区打击了一名哈马斯军事分支指挥官，指控其曾潜入以色列领土并参与2023年10月7日的袭击。随后，以军与以色列国家安全总局（辛贝特）在加沙城图法地区打击了另一名哈马斯指挥官，称其策划针对以军部队的袭击。声明称，以军南方司令部部队仍按协议部署在该地区，并将继续消除“迫在眉睫的威胁”。
