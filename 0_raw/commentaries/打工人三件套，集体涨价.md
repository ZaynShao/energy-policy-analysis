# 打工人三件套，集体涨价

但今年，情况变了。电脑涨了，手机涨了，就连每天通勤的小电驴也变贵了。这三样东西，恰好构成了无数打工人的“三件套”——电脑负责生产力，手机负责随时在线，电动车负责每天通勤。它们是打工人保住饭碗的工具。
涨价的背后，是AI数据中心对芯片产能的争夺，也是普通人第一次如此真切地为AI时代的发展买单。
打工三件套，涨价了
柯明最近越来越觉得，自己做了一个错误的决定。
他30多岁，平时爱研究、也爱买电子产品。过去几年，他一直相信，买电子产品要等一等，不仅价格会便宜，也能看到更多的评价。
所以，今年4月，当MacBook Neo上市时，他没有急着下单。4599元的起售价，加上国补，他盘算着，再等等，说不定3000多元就能买到。毕业10年，柯明从来不会买超过5000块钱的笔记本电脑，这是他第一次有机会，用比较便宜的价格入手一台苹果电脑。
没想到，等了2个月，等到却是涨价的消息。短短60天，这台电脑贵了900元，涨到了5499元。刚好跨过柯明心里那条线，他只能放弃。
除了MacBook Neo，6月25日，苹果笔记本电脑全线调价，Air、Pro、mini、iMac各自涨了1500元，Mac Studio涨了3500元。这个时间点，对刚结束高考、准备买电脑的学生来说，开销不算小。
涨价的不仅是苹果，联想、惠普、戴尔、华硕等笔记本电脑品牌，甚至涨得更早。每日人物在比价App上查询联想小新Pro16的价格走势：6月还在4800元左右，7月最高冲到7899元。涨了3000多元，幅度超过六成。原本是5000元档以下的入门级产品，价格门槛被推上去一截。
联想小新Pro16在比价App上的价格变化。图 / 网络
过去常说的“早买早享受，晚买有折扣”，如今已不太适用。但后来，柯明才意识到，电脑只是开始。
6月底，柯明换了手机。他的iPhone13已经用了4年多，电池撑不到三个小时，不换不行了。旧机抵扣1000块，最后他付了4999元，拿到一台iPhone17。
刚换完没多久，iPhone18 Pro便传出涨价消息。研究机构TechInsights预测，新款iPhone需要涨价270美元左右，约合人民币1800元。数码博主@RD观测 在7月14日发微博称，iPhone系列未来涨幅在1500到2000元之间，这还是保守估计。
柯明在公司食堂吃一个月饭，大概900块。也就是说，下一代iPhone涨的价，够他吃两个月。
目前，iPhone尚未明确上调已发售机型的价格，但国产手机已经先行一步。5月份，雷军在公开场合说了一句“换手机要趁早”，当时没太多人在意。后来大家发现，小米、OPPO、VIVO确实都在涨。VIVO iQOO 15，最低配的起售价为4199元，6月份变成4999元。更大容量的版本，涨幅能达到1500元。
部分千元机正在消失。7月份，小米下架了Redmi Note 15的999元入门款，起售价调到1399元。Redmi数字系列，这个市场上最便宜的安卓手机之一，从14C的499元涨到了17C的799元。每日人物在电商平台上看到，14C的4GB+64GB版本已经卖到了699元，同配置，比发布时贵了200元。
如果拿工资对比一下，2026年上半年，全国居民人均可支配收入实际增速约为4.2%。一台入门级笔记本涨了六成以上，一部中端手机三个月涨了近两成。有人开玩笑说，还没等来涨工资，打工的工具先涨了两轮。
更雪上加霜的是，小电驴也越来越贵。
2025年底，铝、铜、铁等原材料价格涨幅超过40%，新国标又要求小电驴必须搭载北斗定位、限制塑料件总量，成本一下子就上去了，很多车型涨了100元至200元。台铃和爱玛的店员告诉每日人物，年初的涨价，在618期间已经回落了，后面大概率不会再涨。
但价格涨上去的印象，已经留在了消费者心里。有人在社交平台上说，以为小电驴撑死了不到1000块，去了线下店才发现，最便宜的也要1699元。锂电池款普遍在三四千元起步，“2026年买不起小电驴”成了一句常有的调侃。
骑小电驴、买平价手机、用入门级笔记本——这是打工人最常见的配置。手机随时回复工作消息，电脑装着全部生产力，电动车负责每天通勤。它们是打工人能够“保住饭碗”的基础工具。
可偏偏集体涨价的，就是这些工具，完全没有讨价还价的余地。小电驴涨价，还可以换公交地铁，手机、电脑动辄上千的涨幅，却躲不掉，也绕不开。
打工人们只想问一句：为什么会这样？
图 /《小巷人家》
涨价的钱，进了谁的兜里？
如果追溯这一轮电子产品涨价的源头，会发现它其实不是今年才开始。
柯明第一次觉得事情不对是在2024年。那年6月，他给爱打游戏的弟弟买了一块CPU，花了2000多元。3个月后，他想给自己也配一台电脑，再点开同一款商品时，价格已经贵了几百块。
这颠覆了他以往的经验。一般来说，电脑配件会随着产品迭代逐步降价，买得越晚，越便宜。2024年初他买了一块显卡，3000元，性能远超七年前同价位的产品，等于变相降价。但这一次，不仅没有降，反而还涨了。
等到2025年8月的时候，他想换两条大容量内存条，按他以往的习惯，从“想换”到“真买”至少会拖半年，反复比价、等降价。但一个研究装机的朋友催他：“赶紧买，再不买就涨了。”他半信半疑地下了单，两条16GB的内存条，454元。
一个月后，同样的商品已经卖到500多元。今年7月，他再次打开淘宝，一条内存条的售价已经来到766元，两条要1532元，比一年前翻了三倍多。
同样的内存条，2025年与今年7月的价格对比。图 / 网络
这是柯明印象中最早感受到电子产品的价格在水涨船高，速度惊人。后来柯明才知道，涨价的背后，是一场发生在产业链最上游的抢货大战。
2025年10月，摩根士丹利发布了一份报告：SK海力士的DRAM库存只够撑2周，NAND只剩4到5周。DRAM和NAND是所有手机、电脑都离不开的东西。DRAM负责临时运行数据，NAND负责长期存储数据。我们常说的某款电子产品的容量是“8GB+256GB”，前面的8GB就是DRAM，后面的256GB是NAND。这两种芯片直接决定了电子产品的成本。
库存告急，价格自然上涨。但问题是，库存为什么告急？答案是AI。
如果把芯片工厂比作食堂，过去有三个窗口，都在给普通消费者做盒饭，也就是DRAM和NAND。AI来了之后，突然出现一种利润高得多的特供套餐——HBM（高带宽内存）。
HBM可以理解成AI服务器专用内存。ChatGPT、DeepSeek、Claude每回答一次问题，都需要大量HBM参与计算。AI模型越大，数据中心越多，对HBM的需求就越惊人。
于是，原本三个卖普通盒饭的窗口，有两个改去做AI特供了。剩下一个窗口继续卖普通餐，但排队的人没少，普通餐的价格只能翻倍，也就是手机、电脑的疯狂涨价。
而这三家窗口，就是全球存储芯片三巨头：SK海力士、三星、美光。它们三家加起来，占了全球存储市场90%的份额。
2026年，SK海力士的HBM产能已全部售罄，目前正在与英伟达、谷歌、微软谈判，准备签订长期协议。美光在财报会议上说，已经和16家客户签了五年长约，对方承诺投入220亿美元。三巨头的大部分产能被AI预订了，留给普通人用的DRAM和NAND，自然就少了。
AI成为了一头抢产能的“巨兽”，而普通消费者被挤到了队伍的末尾。
涨价很快传导到了整条产业链。严馨在一家国内供应链公司工作。从2025年开始，她的加班强度明显上升，报关量一直在增加。内存条、固态硬盘、显卡的报价单，用她的话说，“就是暴涨”。据深网腾讯新闻报道，一颗8GB的内存成本折合人民币约541.78元。千元机“卖一台亏一台”，中高端手机也未必撑得住。今年1月，魅族22Air因为单机成本过高，被迫取消上市。
上游抢不到货，下游开始打二手料的主意。李傅注意到，香港一家专门处理二手电子零部件的工厂，流水线在2025年突然繁忙起来。他和朋友去实地看了一圈，工厂回收了大量二手芯片，挑选、翻新后卖给下游企业。李傅说，这个现象是必然的，新料抢不到，就只能用旧料续命。
压力的终端是消费者。有人开始打起二手市场的主意，希望卖掉旧手机、旧电脑，多少补一点差价。结果却发现，这条路也走不通。
早在今年3月，就有消息说手机回收价“涨疯了”，涨幅高达几十倍。央视记者实地踩点后发现，只有部分机型涨了十倍左右，多数回收点甚至表示没有涨价这回事。7月13日，每日人物向一家二手回收平台求证，对方说只有iPhone16和17最近几天回收价贵了200块，其他机型都没涨。北京一家大型二手机市场的摊位老板则直接表示不可能涨。除非是完全不能用的破机器，拆了卖零件，那确实涨了——5块钱左右。
上游芯片在涨，中间零部件在涨，整机在涨。但到了消费者的二手回收这一环，价格几乎没有动。打工人被夹在中间，没有退路。

AI税，打工人非交不可吗？
柯明的购物车里躺着一块固态硬盘，去年卖499元，现在标价1399元。
同一款，同一个店铺，同一个容量。差了近三倍的价格，买到的是一模一样的东西。技术在进步，AI在爆发，但普通消费者花同样的钱，买到的东西反而缩水了。
有人把这种现象叫做交AI税——消费者为AI基础设施建设支付的隐性成本。
去年卖499元的固态硬盘，如今标价1399元。图 / 网络
AI公司建设数据中心，需要大量HBM，芯片厂商把产能转向HBM，普通消费者需要的DRAM、NAND越来越少，于是手机、电脑越来越贵。最终，AI训练模型的成本，并没有全部留在科技公司账上，而是一层层传导到了普通消费者手里。
换句话说，当你买下一部更贵的手机、一台更贵的电脑时，也在替AI的数据中心买单。
最让柯明觉得复杂的是，他并不是完全没有分享到AI带来的财富。今年年初，他拿出20万元买了一些基金，其中配置了三星、SK海力士等公司的股票。截至7月初，收益已经有40%至50%。
如果只是覆盖自己买电脑、买手机多花出去的钱，这笔收益绰绰有余。但他很快意识到，真正赚到钱的人，从来不是自己这样的散户。从去年1月到今年7月，美光科技的股价涨了大约918%，SK海力士涨了大约989%，三星电子也涨了389%左右。柯明那点收益，在这些数字面前几乎可以忽略不计。
三巨头把产能优先供给AI数据中心，换来了股价的狂飙。再把剩余产能的涨价压力推给普通消费者，换来了利润表的增长。两头，都是赚钱。
今年5月，韩国总统府政策室长金容范以个人身份在网上发了一段话，大意是：韩国应该考虑把AI带来的超额利润返还给国民，并提出了“公民红利”的说法。
这其实指向了一个更大的问题：如果AI创造的是整个时代的新财富，那么普通人除了支付越来越高的消费成本之外，是否也应该分享它带来的收益？
至少到目前，这个问题还没有答案。更残酷的是，打工人交的远不止消费端这一份税。
姜可在美国尔湾一家大型科技公司做工程师。他观察到一件事：自从AI可以Vibe Coding（用自然语言让AI写代码）之后，团队里那些技术一般但善于包装的老员工突然“焕发新生”。他们用AI快速生成大量代码，虽然质量参差不齐，但看起来效率极高，有人甚至因此晋升。但真正需要成长的新人却被堵在了门口，初级的工作都被AI接管了，他们接不到活，学不到东西，升不了职，也加不了薪。
AI让职场的阶层流动变慢了。金字塔底层的入口在收窄，中上层的人借助工具巩固了自己的位置。大水漫过金字塔，最先淹的是最下面的人。
对刚毕业的大学生来说，这意味着他们进入社会后最先接触的那些初级岗位，基础的代码撰写、文案整理、数据录入，正在被AI蚕食。如果这些岗位不再招聘，他们连第一步都迈不出去。
即使靠AI找到了一份工作，工资单上扣完税，来到消费市场，还要再交一份“AI税”。同一个口袋，被掏了两次。
夏彬常常会想起2020年。那一年，她经历了长达一年的失业，好不容易找到一份月薪7000元的新媒体工作。她租下999元一个月的郊区单间，手机还是用了六年的iPhone 6，电脑是姐姐淘汰下来的ThinkPad，用了差不多10年。
入职后，带教编辑布置了任务，排版当天的推文，晚上10点前审核。夏彬坐在出租屋里，对着那台Thinkpad和iPhone6，连点一个保存键都要缓存10分钟。她急得满头虚汗，一边担心赶不上截止时间，一边害怕刚入职就被认为能力不行。
第二天，她咬咬牙下了单，买了iPhone12mini和华为Matebook13，加起来将近1万块。交完房租押金和买完设备，银行卡里只剩下紧巴巴的伙食费。她打开政务小程序，提取了一笔公积金，才勉强撑到第一个月发工资。
那是2020年，一个刚走出失业的人，还能靠“咬牙”扛过电子设备的门槛。如果同样的事情发生在2026年，她甚至不知道自己还有没有“咬牙”的资格。进入职场的门票，已经越来越贵了。AI正在以前所未有的速度改变世界，但这场变化最先送到普通打工人手里的，是一张昂贵的账单。
