# 美国多地高温创纪录

热浪来袭，美国多地高温创纪录。
美国中西部多个城市12日创下有记录以来最高气温纪录，今后几天美国多地仍将被热浪席卷。
美国国家气象局初步数据显示，中部犹他州首府盐湖城和西北部蒙大拿州最大城市比灵斯12日最高温达42.78摄氏度，为两地逾150年有记录以来的最高气温。盐湖城和比灵斯先前最高气温纪录分别为41.67摄氏度和42.22摄氏度。
▲7月9日，在美国亚利桑那州凤凰城，人们在街头跑步。当日，美国亚利桑那州凤凰城最高气温达45摄氏度。新华社记者吴晓凌摄
高温天气预计将持续至14日，令犹他州和科罗拉多州等地扑灭野火的难度大增。
美国国家气象局预测，到15日，全美逾90个地方的高温纪录将被打破或持平，其中不少是夜间高温纪录。在佛罗里达州、得克萨斯州和南卡罗来纳州等多地，夜间气温不低于27摄氏度。
就在一周前，美国东部遭遇热浪，纽约和费城最高温接近40摄氏度。
