# 超800MW/1.6GWh，23个储能相关项目纳入安徽2026重大项目清单

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)  

储能与电力市场获悉，3月16日，安徽省人民政府印发安徽省2026年重点项目清单。  
清单包含23个储能相关项目，其中：  
储能电站类项目8个，总规模超800MW/1.6GWh，项目业主涉及华能、大唐、中广核、中核汇能等。  
储能产能类项目15个，项目业主涉及阳光电源、国轩高科、蜂巢能源等。
