# 美军证实：一架军机坠毁

美军证实一架军机在吉布提坠毁。
美军非洲司令部11日在社交媒体上发文证实，一架军用飞机于9日在吉布提的机场附近坠毁。
美军非洲司令部称，该事件仍在调查中，目前尚无人员伤亡或财产损失的报告。初步迹象显示未发现外部干扰导致坠机的证据。
另有媒体称，一架MQ-9无人机9日在吉布提坠毁。
吉布提位于非洲之角，与阿拉伯半岛南端的也门隔海相望，扼守连接红海和亚丁湾的咽喉要道曼德海峡。
