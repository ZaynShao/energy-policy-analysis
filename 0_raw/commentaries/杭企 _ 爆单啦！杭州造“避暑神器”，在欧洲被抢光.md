# 杭企 | 爆单啦！杭州造“避暑神器”，在欧洲被抢光

今夏，欧洲多国持续遭遇高温热浪侵袭，空调等降温设备需求激增，市场出现“一机难求”的景象。在这场“清凉经济”浪潮中，来自临平经济技术开发区的环境电器龙头企业——浙江欧伦电气股份有限公司，凭借移动空调的强劲表现，迎来销售旺季，销量同比实现快速增长，成为临平智造“出海”的又一亮眼成绩。
“今年欧洲热得早，高温天气持续时间长，我们的移动空调在国外销售情况表现非常好。“欧伦电气董事会秘书郑成福介绍。作为国内环境调节设备领域的龙头企业，欧伦电气自2009年落地临平以来，深耕除湿机、移动空调、车载冰箱和空气源热泵等全品类研发制造，积淀了深厚的技术底蕴与制造实力。其中，移动空调作为核心产品，因无需墙体打孔、消费者可自行安装，十分适配海外市场使用场景。
“客户发给我们的视频和照片真的很夸张，门店早上8点开门，7点多客户就在广场上排队，一开门一窝蜂涌进来，抱了机器自己扛到收银台去结账。”郑成福回忆道，业务员一眼就能认出，被抢购的正是欧伦电气的产品。“今年我们移动空调的销量，在去年的基础上实现了较快的增长。”
欧伦电气移动空调欧洲市场热销，法国线下超市“一机难求”
从销售区域来看，欧伦电气移动空调产品已覆盖整个欧洲市场，英国、法国、德国、意大利等国家下单量尤为突出。此外，日本、韩国、美国、澳大利亚和东南亚市场也是主销地。更值得关注的是，往年八、九、十月本是移动空调的销售淡季，但今年已有部分客户提前沟通产能交付，甚至出现返单和追加订单的情况。“这是一个不同于往年的新现象，也给我们出海增加了更强劲的信心。”郑成福说。
面对旺盛的市场需求，产能成为关键。当前，欧伦电气原有产能利用率已接近100%，产线满负荷运转，扩产迫在眉睫。恰逢上市契机，企业所募资金将全部用于主业扩产与高端技术研发，借助资本市场破解产能瓶颈。“作为一家制造型企业，我们在追求产量的同时，更注重产品的品质和交付能力，希望交付给客户的是能切实解决生活需求的满意产品。”郑成福强调。随着募投项目三期厂房的逐步投用，新释放的产能将为欧伦电气迎战下一个旺季提供更有力的支撑。
从临平出发，欧伦电气的移动空调正跨越山海，为欧洲送去清凉。这家上市企业的加速奔跑，正是临平众多制造业企业勇拓市场、向新而行的生动缩影，也是临平持续优化营商环境、构建企业全生命周期培育服务体系结出的硕果。面向未来，我区将持续坚持智能化、绿色化、融合化发展方向，大力实施“2327X”先进制造业集群培育工程，不断拓展制造业出口新优势，推动更多“临平智造”走向全球。
