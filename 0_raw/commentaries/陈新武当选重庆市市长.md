# 陈新武当选重庆市市长

陈新武当选重庆市人民政府市长。
新华社消息，重庆市第六届人民代表大会第五次会议8月19日选举陈新武为重庆市人民政府市长。
7月31日，陈新武任重庆市代市长。
▲陈新武（资料图）
公开简历显示，陈新武，男，汉族，1968年7月生，工商管理硕士，中共党员。
陈新武曾任湖北省十堰市市长，湖北省发改委主任，湖北省委常委、省委秘书长等职。
2023年7月，陈新武任重庆市委常委、市委秘书长，2024年5月任重庆市委常委、常务副市长，2025年10月任重庆市委副书记、常务副市长，今年1月卸任常务副市长，至近期履新。
