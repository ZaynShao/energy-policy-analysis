# 金杜助力华润新能源完成红筹回A并于深圳证券交易所主板上市

本项目同时创下多个里程碑纪录：深圳证券交易所史上募集资金金额最大的IPO，A股发电行业募集资金金额最大的IPO，深圳证券交易所首家上市的红筹企业。同时，本项目也是香港联交所上市的粤港澳大湾区企业分拆其子公司回深上市的首单案例，作为粤港澳大湾区中央企业高质量发展的标志性先行示范案例，为资本市场创新发展树立全新范本，引领粤港澳大湾区资本市场革新。
华润电力（00836.HK）与华润新能源属于中国华润有限公司旗下综合能源板块，华润新能源作为华润电力（00836.HK）的子公司，系华润电力（00836.HK）旗下投资、开发、运营和管理风力、太阳能发电站的唯一平台。截至2025年末，华润新能源发电项目并网装机容量达4,158.99万千瓦，其中风力发电项目2,763.07万千瓦，太阳能发电项目1,395.92万千瓦，业务覆盖国内31个省（自治区、直辖市、特别行政区），发电站遍布风光资源丰沛区域及消纳优势区域，是国内最大的新能源发电运营商之一。
华润新能源本次公开发行价格为每股10.11元，本次公开发行股份总数（超额配售选择权行使前）为210,725.50万股，本次公开发行股份总数（超额配售选择权全额行使后）为242,334.30万股；募集资金总额（超额配售选择权行使前）约为213.04亿元，募集资金总额（超额配售选择权全额行使后）约为245亿元。
本项目中，金杜律师事务所担任华润新能源的发行人律师，全面参与本项目的上市方案设计与论证、业务体系与股权架构梳理、上市监管部门沟通等全流程工作，为华润新能源提供一体化、全方位的综合法律服务，高效应对大型能源企业红筹回A所面临的跨境监管、资产合规、业务独立等复杂问题，成功护航这一具备行业标杆意义的IPO项目顺利落地。
本项目牵头负责团队成员包括主办合伙人潘渝嘉、王建学、刘晓光、冯霞，团队成员包括刘畅、叶骏、蔡颖漩、安珊、翟煜斌、李欣悦、张雅利、陈佳宝、林珊羽、赵俊杰。金杜金融机构与基金部合伙人李元媛、顾问李欢及团队成员王海蓉亦为本项目提供了专业支持。
