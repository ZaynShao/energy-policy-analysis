# 普京：方案很离奇，不可接受

普京在接受俄记者扎鲁宾采访时称，俄方收到的一些关于解决俄乌冲突的方案“不可接受”。
据俄新社等俄媒22日报道，俄罗斯总统普京在接受俄记者扎鲁宾采访时称，俄方收到的一些关于解决俄乌冲突的方案“不可接受”。
据俄新社等俄媒22日报道，俄罗斯总统普京在接受俄记者扎鲁宾采访时称，俄方收到的一些关于解决俄乌冲突的方案“不可接受”。
▲普京（右）接受采访 图源：塔斯社视频截图
“我认为，有时我们收到的一些方案很离奇、不可接受。我们始终愿意进行对话，但前提是必须基于地面的实际情况。”普京在采访中称，这些方案以前也以某种方式提出过。不过，俄媒的报道没有明确说明这些方案的具体内容。
普京还称，现在谈论可能会达成的协议的基础还为时过早。
截至目前，俄乌冲突已持续超过4年时间。综合乌克兰《基辅独立报》等媒体去年12月报道，乌克兰与美国共同拟定了一份旨在结束俄乌冲突的修订版计划草案，内容涉及如何管理扎波罗热核电站、乌克兰获得安全保障等。另据俄新社今年6月报道，俄罗斯外长拉夫罗夫称，乌克兰必须保持中立、不结盟和无核化。
