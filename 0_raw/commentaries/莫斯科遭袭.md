# 莫斯科遭袭

俄官员称莫斯科地区遭无人机袭击，致3死多伤。
当地时间7月13日清晨，俄罗斯首都莫斯科市长索比亚宁通报称，自莫斯科时间12日20时30分起，超过350架无人机飞向莫斯科地区，大部分在远距离被防空系统拦截，50架无人机在飞近莫斯科过程中被摧毁。
此外，俄罗斯莫斯科州州长沃罗比约夫当地时间13日清晨通报称，在该州十余个区域上空拦截并击落81架无人机。在莫斯科州伊斯特拉市皮奥涅尔斯基镇，无人机坠落造成3人死亡，另有3人受伤，5栋私人住宅发生火灾。在莫斯科州索尔涅奇诺戈尔斯克，一架无人机击中一栋多层住宅楼，致2人受伤。
