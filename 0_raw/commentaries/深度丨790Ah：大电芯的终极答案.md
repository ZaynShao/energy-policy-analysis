# 深度丨790Ah：大电芯的终极答案

2023年，宁德时代、比亚迪、远景等储能头部玩家开始在各大展会上密集发布20尺5MWh液冷集装箱概念。彼时的人们大概没有想到，5MWh的标准会迅速铺开。
2024年起，五大六小招标明确要求"单舱不低于5.0MWh"，314Ah全面替代280Ah——更低的成本、更高的容量、更好的IRR，没人能拒绝。
但314Ah的"红利期"比想象中更短。从314Ah到587Ah、684Ah，再到790Ah甚至1175Ah，容量竞赛成了行业主旋律。
但参数增长的背后，一个关键要素被大家忽略了：314Ah全面替代280Ah是伴随着20尺5MWh集装箱出现的。在当今储能行业波谲云诡的背景之下，电芯多大、集装箱多大、储能单元多大？这三个问题开始变得更加复杂。
大电芯的终极拷问已经变成：在众多容量选项中，什么样的“大”才是“对”的？
远景的答案是790Ah。
这个答案的复杂性在于，它没有一个单一维度的解释。国内与海外市场对储能的评价体系并非割裂，而是优先级不同：国内当前阶段BOP与IRR是显性决策因子，构网与涉网性能正快速从"加分项"变为"必选项"；海外构网能力已成并网准入的硬门槛，通过门槛后，项目之间最终仍要回到BOP优化与全生命周期IRR的比拼。
两个市场看起来是两套评价体系，但指向同一个判断：大电芯的最优解不是参数表上的最大值，而是在真实项目中被验证的系统性优势。
电站规模化是大电芯出现的根本驱动力。
当储能电站从100MWh/200MWh向1GWh甚至4GWh演进时，系统对“颗粒度”的需求发生质变——更大电站需要更少的串并联、更简的调度逻辑、更高的单簇容量。
以250MW/1000MWh、4小时储能项目为例，按GB/T 51048-2025相关设计要求，采用314Ah电芯并按5MW/20MWh储能子阵配置时，全站需使用近100万只电芯；采用790Ah电芯及12.5MWh系统、按12.5MW/50MWh子阵配置时，电芯数量可降至约40万只。容量升级带来的，并不只是电芯数量减少，更是储能系统由“小单元、多阵列”向“大单元、高集成”演进的基础。
那是否意味着电芯越大越好呢？以1175Ah为例，虽然其单位GWh所需电芯数更少，但超厚电极也可能带来能量密度下降、循环寿命缩短、系统往返效率下降，以及热管理难度提升等问题。容量越大，制造一致性、安全设计、电力电子匹配和长期运行可靠性的要求也越高。
因此，容量竞赛的终点不是数字，而是系统权衡。790Ah所处的区间，本质上是对这两方面因素进行综合权衡后的结果。
在制造工艺上，790Ah选择卷绕路线而非叠片。卷绕工艺成熟度较高，生产良率更稳定，自放电故障率相对更低。相较之下，684Ah采用的叠片方案虽然在电极面积利用率上存在优势，但随着切叠频次增加，对异物控制、量产一致性和长期可靠性提出了更高要求。远景从300+Ah、500+Ah到790Ah持续采用卷绕路线，也使其能够在已有制造基础上实现产品迭代与产能扩展。
但制造端只是起点。当单体容量从300Ah、500Ah级进一步进入700Ah以上区间，电芯的内阻、热特性、尺寸和排列方式，都会向PCS控制、热管理、集装箱布局及BOP成本传导。电芯设计与系统设计不再是“先选型、后集成”的串行关系，而需要从系统目标出发同步定义。
这也构成了790Ah与单纯大容量电芯的区别：其价值不在于将Ah数推至更高，而在于能否将容量优势真正转化为站级经济性。
在国内大储市场里，系统效率、循环寿命等指标虽然重要，但不同厂家的测试条件、应用场景和运行策略往往存在差异，横向比较并不容易。相比之下，BOP成本更接近工程结果：它可以直接量化，也能够通过子阵排布、设备数量和施工工程量进行验证。
790Ah的系统价值，首先体现在子阵规模的放大。
在同样的250MW/1000MWh项目中，314Ah级方案通常对应5MW/20MWh储能子阵；587Ah级方案可提升至约6.25MW/25MWh；790Ah配合12.5MWh系统方案后，子阵可进一步提升至12.5MW/50MWh。换言之，790Ah方案相较587Ah方案，可将单个子阵的功率和容量进一步提高一倍。
子阵规模放大后，相同容量电站所需的电池舱、PCS及升压配套、线缆、基础设施和消防分区随之减少。BOP的优化因此不是某一项设备成本下降，而是站级排布改变后形成的系统性压缩。
从成本测算看，790Ah方案将子阵由约6.25MW/25MWh提升至12.5MW/50MWh，相较587Ah方案可进一步节省约800万元/GWh BOP成本；相较314Ah方案，整站BOP节省可超过1500万元/GWh。这里的核心并非电芯单价，而是更高系统集成度带来的设备、线缆、土建和施工成本同步下降。
单箱能量并非可以无限放大。30尺集装箱的道路运输、吊装及现场部署边界，决定了系统单元必须在容量、重量、尺寸和可施工性之间取得平衡。790Ah配合12.5MWh系统方案，正是在不突破运输与吊装约束的前提下，提升单箱能量和子阵集成度的工程选择。
这一优势也反映在占地、施工和运维层面。相较314Ah基准方案，790Ah方案可使占地面积降低约37.6%，基础设施和线缆成本降低约50%，施工效率提升约60%。对于GWh级、尤其是4小时长时储能项目而言，占地减少还将进一步传导至土建和土地租赁成本；子阵和连接环节减少，则有助于降低现场施工复杂度及全生命周期运维压力。
790Ah方案的系统价值，也正在欧洲GWh级储能项目中接受实战检验。欧洲项目开发通常需要经历严格的全生命周期IRR测算。以远景某欧洲项目为例，通过延长设计寿命、降低超配比例、提升系统可用率并优化储能系统往返效率（RTE），项目IRR提升3.18%。目前该项目正在紧锣密鼓交付之中。
这一结果表明，大容量电芯的价值并不止于压缩初始BOP投入，还可通过提升系统可用率、效率和寿命等维度，进一步传导至项目全生命周期收益。至于BOP节省、占地优化和安装效率，则仍应以项目的具体设计和交付数据进行验证。
如果说国内市场检验的是790Ah在站级集成和BOP上的经济性，那么海外市场检验的，则是大容量电芯能否与PCS、控制模型及热管理系统协同，满足构网型储能的技术准入要求。
这两年，中国储能企业的出海正进入密集落地期。行业数据显示，2026年一季度中国企业海外储能订单规模已突破百GWh级别，澳大利亚、欧洲、中东成为核心增量市场——宁德时代在澳大利亚斩获2.4GWh储能系统大单，阳光电源沙特7.8GWh全球最大构网型储能项目全容量并网并中标阿联酋7.5GWh新项目，天合储能在意大利中标250MW/1000MWh项目并拿下海外首单GWh级构网型订单，华为亦中标罗马尼亚风电配套储能项目。
但出海的真正门槛不在订单数量，而在技术适配：欧洲和澳大利亚等市场对构网能力（grid-forming capability）的要求正成为硬性标准。2025年11月，欧洲输电系统运营商联盟（ENTSO-E）要求1MW以上新建储能须具备主动支撑能力；澳大利亚AEMO将构网型BESS列为2026年优先重点。构网能力——即储能系统能否在电网扰动时主动支撑电压和频率——直接关系到能否通过并网认证、能否参与高价值电网服务市场。
远景的突破口在于：产品跑在了标准前面。远景10.x MWh AI储能系统基于产品化平台，采用700+Ah大容量电芯，单柜实现10MWh高能量密度，较传统5MWh方案占地面积缩减26%，辅助功耗降低12%，并搭载智能液冷系统与EnOS智能软件生态，同时具备1.5倍过载能力——而彼时英国的构网标准尚未正式出台。
更大的单簇容量对热管理提出更高要求，远景智能液冷系统通过电芯级温差控制与主动安全策略，将热失控风险前置化解——这是790Ah从"能用"到"敢用"的关键前提。
这种产品跑在标准前面的策略，在实际投标中转化为直接的竞争优势。当英国构网标准最终落地时，其他厂家需要重新设计和验证产品，而远景的方案已经具备投标资格，并凭此连续拿下多个标杆项目——从去年斩获Statera英国最大储能项目，到近期在欧洲连续落下三子，分别携手德国储能开发商ju:niz Energy、全球独立电力生产商Elements Green及英国储能领军企业Pulse Clean Energy，在德国与英国推进合计超2.1GWh储能项目。
构网能力不仅取决于硬件，更取决于软件——即构网控制模型。远景的构网模型已通过欧洲、澳大利亚等市场的第三方机构严苛校验，具备与主流厂商同等的技术准入资格。第三方模型校验是海外投标的标准流程：业主委托独立机构对厂家提供的构网模型进行验证，确保模型预测与实际硬件行为一致。这一环节对厂家的技术能力要求极高——模型不仅要通过静态测试，还要在各种电网扰动场景下表现出与实际硬件一致的动态响应。
而远景的独特优势在于：模型与自研PCS、电芯的软硬一体协同——控制指令无需跨厂商协议转换，响应延迟更低；同时，远景将风电场积累的电网扰动数据反哺模型训练，使其在弱电网、高比例新能源等复杂场景下的动态响应更具实战鲁棒性。这种"硬件可控、模型自研、数据闭环"的全栈能力，是构网性能从"实验室达标"走向"现场可靠"的关键差异。
构网能力的背后，是远景在电力电子领域的长期积累。第三代碳化硅PCS效率达99.3%，系统能效突破91%，并网效率提升50%——这些指标不仅是效率数字，更是构网能力的硬件基础。
790Ah电芯与碳化硅PCS的匹配，决定了电芯的功率输出和过载能力能否有效转化为系统级动态响应能力。若PCS的控制带宽、惯量响应特性与电芯功率特性不匹配，电芯的能力便难以在构网场景中充分释放。这正是大电芯时代电力电子协同设计的核心价值。
电力电子匹配的价值，在国内大储和海外构网两个市场上得到了验证——一个指向经济性，一个指向技术准入。但储能的应用边界正在快速扩张，今天的电芯定义必须经得起明天场景的检验。
AIDC（AI数据中心）算电协同被视为下一个高价值场景，其对储能的需求呈现"墙外+墙内"的双重特征：墙外需要电网侧大容量储能实现绿电直供与峰谷调节，墙内则需要直流耦合储能替代传统UPS，适配800V乃至48V的直流架构。不同市场需求（1500V传统并网/构网型/800V与48V直流耦合）的技术分化，意味着单一电芯难以通吃所有场景——除非电芯设计从一开始就与系统架构深度绑定。
远景在定义790Ah时，已将AIDC等未来场景的系统需求前置纳入产品边界：电芯容量与尺寸预留了向高能量密度直流系统延展的空间，电力电子平台覆盖从1500V并网到800V直流耦合的多电压等级，EnOS软件架构则支持风光储算的实时协同。这与远景在内蒙古赤峰落地的全球首个100%绿电直供AIDC项目遵循同一技术逻辑——不是用今天的790去套用明天的场景，而是在定义790时，就让明天的场景需求反向参与今天的工程决策。
远景更大的布局是Mission Gobi计划——到2030年在全球戈壁荒漠建成5GW规模AI算力中心。这些场站既是当下大储的交付，也是未来算电协同的基础设施储备。790Ah的平台设计，正是为这种"当下可用、未来可延展"的系统级需求而生。
回到最初的问题：什么样的"大"才是"对"的？经过国内大储、海外构网与AIDC前瞻布局的层层验证，答案已经清晰——真正的大电芯最优解，不是单一指标的冠军，而是同时满足客户价值、行业趋势与时间检验的系统级平衡。对客户，它意味着全生命周期IRR的确定性提升；对行业，它顺应了电站规模化与场景多元化的双重演进；对时间，它预留了足够的技术余量，让今天的选择在未来依然成立。790Ah正是基于这一逻辑被定义，也正在被这一逻辑验证。
790Ah在国内BOP、海外构网两个维度上已有实践验证，在AIDC等新兴场景上则完成了技术前瞻定义。三者共同构成当下时点最有力的证据。
如果说314Ah时代解决的是"如何把电芯做大"，那么790Ah所代表的新阶段，真正需要回答的已经是"如何让更大的电芯与系统形成最优匹配"。从这个意义上看，大电芯的竞争并没有结束，只是竞争的评价尺度正在从"参数表"转向"系统最优解"。
