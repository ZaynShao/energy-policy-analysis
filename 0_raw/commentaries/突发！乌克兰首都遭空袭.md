# 突发！乌克兰首都遭空袭

乌克兰首都基辅遭空袭，多次传出爆炸声。
当地时间7月16日凌晨0时46分至1时许，新华社记者在乌克兰首都基辅市听到两轮密集爆炸声。记者看到，有两枚导弹在空中发生爆炸。
乌空军在社交媒体发文称，俄军向基辅市发射了4枚弹道导弹。
基辅市市长克利奇科随后在社交媒体发文说，该市达尔尼茨基区非住宅建筑被导弹碎片击中，斯维亚托申斯基区一处仓库遭袭击。
