# 爆料：沙特、土耳其、巴基斯坦将签署重要协议

爆料：沙特、土耳其和巴基斯坦将于8月7日在沙特签署一项联合防务协议。
接近沙特军方和政府的消息人士告诉法新社，沙特、土耳其和巴基斯坦将于8月7日在沙特签署一项联合防务协议。法新社称，在美伊冲突尚未结束的背景下，中东国家正寻求加强安全合作。
“这一协议已经讨论了很久，但地区局势的发展加速了其签署。”该消息人士表示。另一位接近沙特政府的消息人士也证实了这一消息。
法新社称，沙特王储兼首相穆罕默德预计将在吉达与土耳其总统埃尔多安和巴基斯坦总理夏巴兹会面。根据土耳其总统府的消息，埃尔多安预计于8月7日抵达吉达。夏巴兹已于8月6日到达沙特，他对沙特的访问将持续至8月8日。
数月来，外界一直在猜测沙特、土耳其和巴基斯坦三个国家可能结成战略联盟。巴基斯坦在试图结束美伊战事的调解行动中发挥了重要作用，而土耳其此前在旨在结束加沙冲突的谈判中扮演了外交角色。
报道称，沙特和巴基斯坦2025年已经签署共同战略防御协议，约定第三方针对两国任何一国的攻击将被视为“对两国的侵略”。当时有分析称，在中东地缘安全风险增加的背景下，沙特希望借此实现安全保障合作的多元化，而巴基斯坦则寻求提升战略地位，双方的共同目标是以制度化的安全合作来应对地区局势的不确定性。
