# 年产能65GWh，总投资3.88亿元，三一锂能灯塔工厂项目正式开工

来源：SANY三一锂能
「
储能与电力市场
」
获
悉，
近日，“与锂争锋”
三一锂能灯塔工厂工程
开工誓师大会奠基仪式在湖南长沙经开区三一泵送新城园区举行。
三一锂能灯塔工厂项目规划
年产能65GWh
，预计2027年
7
月建成投产。
项目将全面导入柔性自动化产线、AI智能检测、工业互联网平台等核心技术，围绕产线提级、数智提级、精益提级、绿色提级、人文升级五大理念，打造锂电行业智能制造新标杆。
看个广告休息一下
资料显示，三一锂能是三一集团低碳化转型发展核心业务板块，成立于2022年8月2日，总部落座于湖南长沙三一工业城，是国家级高新技术企业，公司以技术创新与智能制造为双核驱动，主营换电装备、动力PACK、储能系统、电源车等产品的研发、制造和销售，专注于换电站及储能站的投资、建设和运营业务，构建“专用电池研发-智慧储能系统-绿电场景应用”全产业链生态闭环。
