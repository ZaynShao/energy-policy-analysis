# 申报通知|8月31日截止，新一轮“科技新小龙”遴选开始了

1.企业注册满3年，原则上不超过10年且未登陆国内外各级证券交易所。若产出原创性、颠覆性技术或成果且具备产业化能力且在下一个发展周期可实现快速增长的在成立年限上可予以适当放宽。
2.企业需拥有高素质稳定研发团队，核心人员具备专业研发与产业化实操能力。近三年无重大安全生产事故、不良信用记录及违法违规行为。
3. 近三年每年研发投入占同期营业收入总额的比例不低于10%或同期研发投入总额不低于1000万元。
4. 近三年营收或估值年增长率达30%以上，最近一轮企业投后估值不低于3亿元人民币或融资额不少于2000万元人民币。
