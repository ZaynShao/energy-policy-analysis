# 《望潮公约》发起，共建AI+能源产业生态

深入贯彻国家“双碳”目标与数字经济发展部署，推动AI、算力技术与能源产业深度融合，构建安全、高效、绿色、经济、创新、协同的AI算力+数字能源产业生态，助力新型能源体系建设，共筑绿色智算产业生态。在AI拓境论坛上，产业链各方将共同发起《望潮公约》，主要内容如下：
1、坚持绿色低碳理念：锚定国家“双碳”目标，将绿色低碳贯穿AI算力与数字能源融合全过程，推动算力绿色化、能源智能化，提升能源利用效率，降低全产业链碳排放。
2、强化科技自主创新：聚焦AI、能源融合领域关键核心技术攻坚，加快技术迭代升级、规模化场景落地，破解产业发展堵点瓶颈，筑牢技术根基，提升产业核心竞争力。
3、保障安全可靠发展：坚守能源安全、数据安全、系统安全底线，规范技术应用，建立健全风险防控机制，保障能源系统稳定运行与数据安全合规。
4、深化开放共建共赢：秉持开放包容、互利共赢原则，推动产业链上下游资源共享、优势互补，加强跨领域、跨行业协作，共建繁荣生态，共促产业高质量可持续发展。
5、恪守合规诚信准则：遵守法律法规与行业规则，坚持诚信合作、务实履约，规范市场秩序，共同维护公平公正、有序健康的产业发展环境。
6、践行责任使命担当：践行社会责任，积极推广AI算力+数字能源融合新技术、新模式、新应用，助力能源普惠，引导形成绿色低碳、智能高效的能源消费方式。
全体发起单位将自觉履行公约承诺，携手共进、共同发力，加速AI算力与数字能源深度融合、产业提质升级，共筑绿色低碳、智慧赋能的能源新生态。
5月20日，在北京亦庄举行的2026 AI算力与数字能源论坛上，中国能源报携手13家科研机构与行业企业联合发起《望潮公约（AI 算力＋数字能源公约）》，以公约树准则、以自律促规范、以合力谋共赢，共建AI+能源产业协同发展良性生态。
