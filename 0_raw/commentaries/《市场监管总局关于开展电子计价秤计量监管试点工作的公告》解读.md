# 《市场监管总局关于开展电子计价秤计量监管试点工作的公告》解读

发布时间：2026-09-20 15:45

来源：国家市场监管总局

访问量：

【大中小】

【打印文本】

分享到：

为严厉打击“缺斤短两”“作弊秤”乱象，保障消费者合法权益，近日，市场监管总局发布《市场监管总局关于开展电子计价秤计量监管试点工作的公告》（以下简称《公告》）。有关内容解读如下：

**一、问：《公告》出台的背景是什么？**

一是电子计价秤是集贸市场等民生计量交易的核心计量器具，直接关系人民群众消费权益和市场交易公平。近年来，“缺斤短两”“鬼秤”等民生计量突出问题时有发生，引发社会广泛关注。

二是2025年1月8日，市场监管总局制定发布JJF 2184—2025《电子计价秤型式评价大纲（试行）》（以下简称新型评大纲）和JJG 1204—2025《电子计价秤检定规程（试行）》（以下简称新检定规程）两项计量技术规范，分别于2026年1月8日和2027年1月8日实施，从源头封堵电子计价秤“拆机改装、加装作弊程序”的漏洞，夯实电子计价秤防作弊技术要求的制度根基。

三是市场监管总局建设全国电子计价秤智慧监管平台（以下简称平台），贯通生产、型评、检定、修理、监管、使用六个关键环节，推动电子计价秤计量监管由“分段把关”走向“全程贯通”，为推广电子计价秤智慧监管提供了有力的技术支撑。

**二、问：《公告》对生产环节有什么要求？**

生产环节源头设防。新型评大纲是计量器具新产品市场准入的技术准则，对产品技术迭代升级具有重要推动和引领作用。《公告》要求生产者制造以销售为目的的电子计价秤应当取得符合新型评大纲要求的型式批准证书，并严格依照批准的型式制造和销售，具备“开壳锁机、授权解锁、三码一封（生产码、维修码、检定码和铅封）”防作弊技术功能，堵死拆机改装漏洞。

**三、问：《公告》对销售修理环节有什么要求？**

销售修理环节双向禁止。新检定规程自2027年1月8日起正式实施，根据计量法律法规有关规定，计量检定必须执行计量检定规程，未按照规定申请检定或检定不合格的计量器具，不得使用。按原型评大纲生产的电子计价秤，不符合新检定规程要求。《公告》要求，自2027年1月8日起，销售者不得销售不符合新型评大纲要求的电子计价秤；自2027年1月8日起，修理者不得修理不符合新型评大纲要求的电子计价秤（按其他计量技术规范取得型式批准证书的在用网联电子计价秤除外）。电子计价秤修理者须在平台登记并获生产企业授权修理资质，修理电子计价秤时须经平台发放“授权解锁”指令方可维修。此举斩断恶意改装链条，严防借电子计价秤修理环节加装作弊硬件或者嵌入作弊软件程序。

**四、问：《公告》对使用环节有什么要求？**

使用环节精准施策。公平秤是保障集贸市场计量公平的“校验尺”，也是消费者放心复秤的“定心石”。《公告》要求集贸市场公平复核用公平秤自2027年1月8日起应符合新检定规程要求，保障消费者复核数据准确、可靠、可追溯。为保障农副产品、散装食品、生鲜水产等商品称重结果准确，依据计量法律法规要求，经营商户使用的电子计价秤须计量检定合格。《公告》要求对于按新型评大纲取得型式批准证书的贸易结算用电子计价秤，计量检定应当执行新检定规程；2027年1月8日前，对于按其计量技术规范取得型式批准证书的贸易结算用电子计价秤，计量检定仍执行JJG 539—2016《数字指示秤检定规程》，检定周期一般不超过1年，检定合格的可使用至检定有效期届满；对于网联电子计价秤，2030年1月8日起执行新检定规程，确保经营商户留足换秤缓冲空间，最大限度降低经营商户合规成本。

**五、问：《公告》的实施对消费者有什么便利？**

消费者维权更加便捷。消费者“扫一扫”电子计价秤唯一身份信息码即可在平台查询电子计价秤生产信息、修理记录、检定结果等全生命周期的“身份档案”，并可在线向相关市场监管部门反映“计量失准、作弊行为、超期未检”等有关问题。平台是新型评大纲和新检定规程落地的技术支撑，自2026年1月试运行以来，累计入驻电子计价秤生产企业235家、计量检定机构2169家、维修单位2182家。

**六、问：《公告》落地实施具体时间和下一步安排？**

《公告》自2026年9月1日起在河北、浙江、福建三省开始实施，探索可复制可推广的电子计价秤计量监管模式，守牢消费公平底线。

目前，全国存量电子计价秤达433万台，涉及257.08万家经营主体，30160家集贸市场，205家电子计价秤生产企业，10174家销售维修主体；试点三省在用电子计价秤36.55万台件，涉及集贸市场2968家，经营商户26.22万户。下一步，市场监管总局将进一步强化电子计价秤法治监管、信用监管、智慧监管，着力构建电子计价秤生产、销售、检定、修理、使用全链条穿透式智慧监管体系，以数字化监管赋能民生计量，把“关键小事”办成“暖心实事”，维护人民群众消费公平合法权益。
