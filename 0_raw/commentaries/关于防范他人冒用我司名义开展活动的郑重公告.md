# 关于防范他人冒用我司名义开展活动的郑重公告

尊敬的客户、合作伙伴：
近日，我司（上海盖世网络技术有限公司）发现，有不法人员冒用我司及我司员工名义，通过邮件、电话等方式对外联系，谎称代表我司进行采访邀约、业务洽谈等活动。
为保障您的合法权益，我司现郑重公告如下：
一、上述冒名人员并非我司员工，与我司不存在任何关联或授权关系，其一切行为均属个人行为，与我司无关。
二、特别提醒：如您收到以我司名义发出的可疑邮件、采访邀约或合作请求，请切勿轻信，更不要向任何个人账户或不明账户支付任何费用。
三、信息核实渠道：如您对我司人员身份存疑，请通过以下联系方式进行核实，电话：021-39197800/021-39586681；邮箱：info@gasgoo.com。另，我司官方邮箱后缀均为“gasgoo.com”。
四、风险提示： 如您已因冒名人员遭受损失，建议您及时向公安机关报案，同时联系我司告知相关情况，以便我司协助处理。
感谢您一直以来对我司的信任与支持！
