# 内蒙古6GWh独立储能优选：大唐、华润、中节能、上海超威、苏尼特矿业等入选

中节能锡林郭勒盟苏尼特右旗800MWh构网型独立储能项目：优选2家，实施主体为中节能风力发电股份有限公司、内蒙古苏尼特矿业开发有限公司
本次优选5个项目总规模为1.1GW/4.4GWh，实施主体分别如下：
接入四子王旗瑞升变电站：1个300MW/1200MWh项目，实施主体为大唐（四子王旗）风力发电有限公司
接入察右后旗苏墩变电站：2个200MW/800MWh项目，实施主体分别为华润润科新能源（察哈尔右翼后旗）有限公司、上海超威驰能能源有限公司
接入四子王旗红梁变电站：2个200MW/800MWh项目，实施主体分别为乌兰察布核瑞新能源有限公司、内蒙古源通达新能源投资有限公司
