# AI技术资讯丨DeepSeek V4 Pro上线API，xAI Grok4.6评分61，腾讯算力资本开支530亿

今日主线·DeepSeek，xAI Grok，腾讯，阿里Qwen，Anthropic，寒武纪：开源模型与成本战升温，巨头算力资本开支加码，Agent 产品集中落地。
▸DeepSeek：V4 Pro 正式版上线 API，距预览版发布 111 天，补齐 Agent 能力。
▸xAI：Grok 4.6 评分 61，与 GPT-5.6 Sol Max 持平，定价低 60% 以上。
▸腾讯：二季度资本开支 530 亿元，主要用于采购算力芯片，GPU 及 ASIC 储备充足。
1.DeepSeek：V4 Pro 正式版于 8 月 13 日凌晨上线 API 文档，距 4 月 24 日预览版发布已过 111 天，补齐 Agent 能力。
2.xAI：发布 Grok 4.6，AI 智能指数评测获 61 分，与 GPT-5.6 Sol（Max）持平，定价较竞品低 60% 以上。
3.腾讯：二季度资本开支达 530 亿元，主要用于购买算力芯片；GPU 及 ASIC 芯片储备充足，预计明年供应无忧。
4.Anthropic：投资者预计其或于 10 月启动 IPO，估值 2 万亿美元以上；年化营收到年底或达 1000 亿至 1200 亿美元。
