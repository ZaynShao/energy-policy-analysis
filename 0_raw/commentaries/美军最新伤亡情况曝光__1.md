# 美军最新伤亡情况曝光

据美国有线电视新闻网(CNN)报道，五角大楼19日更新统计数据，自2月28日美国和以色列联合发动对伊朗的大规模军事行动以来，美军累计死亡人数达18人，受伤人数达757人。据报道，美国有线电视新闻网(CNN)长期对隶属于美国国防部的“国防伤亡分析系统”网站进行追踪。该数据库近日新增“海外行动”跟踪类别。不过，这一新增类别只列出死亡人员姓名，未提供时间、地点、伤亡原因等具体信息。美国有线电视新闻网(CNN)注意到，美国“国防伤亡分析系统”网站曾多次出现故障，美国国防部在披露战争期间的伤亡情况方面也进展缓慢，而官员则以“安全需要”为由进行辩解。目前，美伊谈判仍处停滞状态。美国总统特朗普8月19日宣布对伊朗实施“毁灭性经济行动”。特朗普还威胁说，任何允许其金融机构、企业、机场或政府实体向伊朗提供任何形式支持的国家，都将面临严重的经济后果。他喊话所有美国盟友与美国一起来孤立和击败伊朗的威胁。
