# 金风科技570余台机组再迎强台风“白海豚”考验

8月9日，强台风“白海豚”在浙江沿海登陆，登陆时中心附近最大风力14级（42米/秒），7级风圈半径超过400公里，影响范围覆盖浙江、上海及江苏南部沿海区域。受此影响，金风科技位于上海、江苏等地的10个海上风电项目全部处于台风影响范围内。台风过境期间，项目现场实测最高风速达32米/秒，570余台海上风电机组均平稳度过台风考验。其中，安装有100台GWH230—8.5MW机组的江苏国信大丰850MW海上风电项目于2025年底并网投运，据统计，台风过境的48小时内，该项目累计发电量约3754.4万度，折算等效利用小时数达45.5小时，实现发电收益约1197.6万元。
▲江苏某项目台风过境实况
这已是金风科技海上风电机组在一个多月内连续经历的第二次强台风考验。今年7月，台风“巴威”以相似路径影响华东沿海，上述区域机组同样保持安全稳定运行。这背后是由“机组产品抗台专项设计、预先精准的气象灾害预警、项目全生命周期防台应急方案”等环节组成的完备抗台链路在发挥关键作用。
在设计阶段，金风科技在IEC抗台风标准之上叠加18项台风工况仿真验证，同时依托激光雷达和机组智能控制系统帮助机组实现“精准对风”，可保证叶片始终处于最小受力角度，避免发生涡激振动。而在气象预测方面，基于高精度气象数据与海量历史台风样本库的智能算法，系统持续推演台风的可能行进路径及对各风场的风圈影响，提前向受影响项目发出分级预警，并依托数字平台为每台机组定制“一机一策”抗台策略。从变桨控制策略调整、偏航逻辑优化到塔基螺栓紧固，数百台机组提前调整至最优姿态，在台风中灵活应对变化，全面保障机组安全。
▲上海某项目台风过境实况
截至目前，金风科技海上风电累计装机容量已近888万千瓦，近1350台海上风电机组遍布于中国的绵长海岸线，覆盖从北到南不同的风资源条件和海洋环境，在长期运行中持续经受复杂风况与多样海况的考验。面对海上风电开发中的差异化挑战，金风科技始终与产业链伙伴协同探索、共同破题，在一个个项目和一次次极端天气考验中积累经验、完善能力。随着技术、产品、工程和运维体系持续进步，海上风电正逐渐成为更加安全、稳定、可靠的能源形式，为全社会绿色低碳转型提供坚实支撑。
