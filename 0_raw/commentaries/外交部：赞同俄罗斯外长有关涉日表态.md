# 外交部：赞同俄罗斯外长有关涉日表态

据报道，俄罗斯外长拉夫罗夫日前表示，希望日本充分认真阅读《联合国宪章》，包括第107条“敌国条款”。外交部发言人林剑19日在例行记者会上说，中方赞同拉夫罗夫外长有关表态。“敌国条款”是《联合国宪章》的重要规定。今年是东京审判开庭80周年，重申“敌国条款”的含义，强调这一条款的约束力，对于捍卫中国人民抗日战争和世界反法西斯战争胜利成果、严防军国主义幽灵死灰复燃具有重要意义。
