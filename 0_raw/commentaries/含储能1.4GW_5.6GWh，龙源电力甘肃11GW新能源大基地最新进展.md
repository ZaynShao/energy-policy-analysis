# 含储能1.4GW/5.6GWh，龙源电力甘肃11GW新能源大基地最新进展

「储能与电力市场」获悉，6月25日，龙源电力甘肃巴丹吉林沙漠基地金塔区域250万千瓦风电项目取得酒泉市能源局核准批复。该项目位于甘肃省酒泉市金塔县，总装机容量250万千瓦，是国家“十四五”电力规划跨省区外送通道甘肃送电四川±800千伏特高压直流工程配套电源基地——甘肃巴丹吉林沙漠基地1100万千瓦新能源项目的重要组成部分。甘肃巴丹吉林沙漠基地1100万千瓦新能源项目，是国家重点 “沙戈荒” 风光大基地，同时为 “陇电入川” 特高压直流工程配套电源，规划总新能源装机1100万千瓦，包含430万千瓦风电670万千瓦光伏，140万千瓦/560万千瓦时储能，外加20万千瓦光热建成后新能源电力将通过跨省特高压通道送往四川消纳，是西北新能源外送核心支撑项目之一。按照项目开发要求，需由一个投资主体一体化开发建设，通过火电与新能源联营，实现各电源优势互补，达到经济效益最优。6月26日晚间，龙源电力（001289）发布关联交易公告，宣布公司拟以2463.17万元现金，收购控股股东国家能源集团持有的国能巴丹吉林（甘肃）能源开发投资有限公司49%股权。交易完成后，巴丹吉林公司将成为龙源电力全资子公司，龙源电力将拥有项目公司完整经营决策权，统筹推进国家级巴丹吉林 “沙戈荒” 风光大基地建设开发。公告及相关信息显示，巴丹吉林公司2023年11月注册成立，注册资本30亿元，此前由龙源电力持股51%、国家能源集团持股49%，核心负责甘肃巴丹吉林沙漠大型新能源基地开发。龙源电力表示，本次股权收购是优化资产配置、提升运营效能的重要举措，收购完成后，巴丹吉林公司将成为龙源电力全资子公司，可更为有效保障巴丹吉林项目推进，进一步巩固本公司在新能源电力市场的竞争优势。本次关联交易符合本公司经营发展的需要，资金来源为自筹资金，定价公允，不会对本公司财务和经营状况产生不利影响，不存在损害本公司及全体股东，尤其是中小股东利益的情形。
2025年1月，该基地配套调峰火电项目已启动建设，包含两座2×1000MW高效超超临界燃煤电厂，同步建设脱硫、脱硝装置，配套建设明沙窝灰场。工程年发电量180亿度，静态总投资1445598万元，动态总投资1493767万元。2024年10月，该基地外送线路陇电入川特高压直流工程配套电源规划方案获国家能源局批复。
