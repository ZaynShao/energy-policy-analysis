# 《高质量数据集测评联合行动倡议》正式发布

在4月29日举办的第九届数字中国建设峰会上，在国家数据局党组书记、局长刘烈宏，福建省省委常委、统战部部长、省政协副主席林文斌的共同见证下，中国电力企业联合会、中国电子技术标准化研究院、中国信息通信研究院、国家数据发展研究院、中国电子信息产业发展研究院、国家工业信息安全发展研究中心、工业和信息化部电子第五研究所、公安部第一研究所及中国航天科技体系与创新研究院等10家单位，共同发起《高质量数据集测评联合行动倡议》。
该倡议旨在通过统一标准规范、统一公约编号、统一标识管理、统一证书模板以及统一发布渠道的“五统一”准则，构建科学、标准、诚信、透明的高质量数据集质量测评体系，推动高质量数据集质量测评标准体系化、流程规范化和结果权威化，提升行业整体公信力与服务水平，推动数据要素价值充分释放和数据集高质量建设。
中电联长期深耕电力数据标准制定、数据安全治理与数据要素应用实践，深度参与国家数据基础设施建设相关工作。此次倡议发布，是中电联响应国家数据要素发展战略的重要体现，也为加快推进电力行业高质量数据集建设、推动电力行业数据标准与国家测评体系对接奠定了基础。
下一步，中电联将严格践行倡议内容，持续深化数据标准与测评能力建设，积极参与行业协同与技术攻关，以标准化赋能电力数据要素价值释放，为数字中国建设贡献电力数智力量。
