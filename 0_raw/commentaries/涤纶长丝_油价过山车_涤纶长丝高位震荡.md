# 涤纶长丝 | 油价过山车 涤纶长丝高位震荡

**导语**

地缘局势多变，油价宽幅波动，加剧涤纶长丝市场观望气氛，然利好难以持续发酵，伴随油价暴跌，涤纶长丝市场陷入涨跌两难境地，局部已开启出货模式。  

清明假期伊始，成本压力下涤纶长丝报价上调百元附近，然因假期市场买气不足，涤纶长丝市场成交重心上调幅度有限。节后首个交易日涤纶长丝市场平价促销，下游用户担心后期采购成本增加，适度补仓，尾盘市场平均产销率145%附近，日内较高产销率500%。

得益于尾盘产销回暖，今日部分涤纶长丝厂商报价窄幅上调，然因油价大幅下调，受其拖累聚酯双原料弱势运行，成本利好难以持续发酵，拖累涤纶长丝市场气氛，多数厂商稳盘观望，个别企业“落袋为安”心态引导下，促销出货。上午涤纶长丝市场成交“冰火两重天”，整体交投冷清，局部产销放量，较高产销率800%-1000%。

如图2所示，地缘冲突爆发以来，涤纶长丝价格走势犹如“过山车”，但相较于去年来言，目前涤纶长丝价格处于相对高点。地缘局势等宏观因素阶段性影响较大，跟随原料价格波动，涤纶长丝市场也上下起伏。目前伊以战事仍未完全终结，油价仍有上行的预期，而成本端剧烈波动，势必会影响涤纶长丝价格走势，因此阶段性、适量补货仍是现阶段下游产业谨慎操作策略。

经历不可抗力事件后，涤纶长丝厂商避险情绪升温。如图3所示，3月份涤纶长丝产能利用率呈现逐渐下调的趋势，前期减停装置延期重启，龙头企业带头自律减产，清明节后涤纶长丝产能利用率降至85%附近，与去年同期相比降幅超10%。综合来看，宏观、成本端短期仍呈现宽幅波动，影响涤纶长丝价格走势，然目前行业综合产能利用率低于同期水平，一定程度上提振厂商心态，市场下探空间相对有限。若油价反弹，市场仍有上行预期。
