# “大走廊杯”2026杭州博士后科创精英赛报名倒计时二周！优质项目请抓紧窗口期

“大走廊杯”2026杭州博士后科创精英赛自7月中旬正式启动全球招募以来，已历时整整一个月。目前报名工作已进入最后冲刺阶段，距离8月28日申报截止仅剩最后两周时间。执委会温馨提醒广大博士后团队抓紧最后的申报窗口，提前准备申报材料，按期提交。
本届大赛由杭州城西科创大走廊管委会、杭州市人力资源和社会保障局、浙江省欧美同学会联合主办，长三角G60科创走廊联席会议办公室、宁波市甬江科创区建设领导小组办公室提供支持，是联动长三角、环杭州湾科创廊道资源，挖掘博士后前沿科创成果、助推科技成果产业化的重要平台。大赛以 “构筑青年英才新高地，打造创新创业新天堂” 为主题，持续做强杭州人工智能第一城核心引擎。
大赛围绕人工智能、集成电路、高端装备、生命健康、新能源新材料五大前沿赛道展开，根据项目发展阶段划分初创组、成长组两大参赛序列，面向全球博士后创业者广泛征集优质项目。国内各大高校、科研机构、新型研发机构、概念验证中心、中试基地及成果转化基地均可推荐优秀博士后创业项目参与申报。
大赛配套政策含金量十足。符合条件的参赛项目，落地大走廊可申领属地人才产业政策支持，包含研发补助、租金补助、创业启动资金；团队人才可申请人才扶持资金、大走廊人才资格认定等；落地注册企业可参保 “创新保”科技保险等（详见后续政策）。
大赛后续赛程安排如下：9月上旬启动初赛，采用专家书面评审方式分赛道筛选晋级项目；9月下旬开展复赛路演比拼；10月中旬举办总决赛。
