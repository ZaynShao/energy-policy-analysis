# 福建丨深耕新能源汽车与零部件赛道

为深入贯彻党的二十大和二十届历次全会精神，以科技创新为引领，加快培育壮大新兴产业、前瞻布局未来产业，在推动科技创新和产业创新深度融合上闯出新路，支撑福建省建设更具全球竞争力的现代化产业体系，福建省人民政府编制《福建省“十五五”新兴产业和未来产业发展规划》并于近日发布。
《规划》明确：
深耕新能源汽车与零部件赛道，建设车能路云一体化生态，打造东南区域新能源汽车制造与出口基地。
