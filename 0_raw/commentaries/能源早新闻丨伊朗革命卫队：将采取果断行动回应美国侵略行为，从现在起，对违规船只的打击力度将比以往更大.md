# 能源早新闻丨伊朗革命卫队：将采取果断行动回应美国侵略行为，从现在起，对违规船只的打击力度将比以往更大

◐625亿元第三批“国补”已下达。据人民日报微信6月26日消息，近日，国家发改委会同财政部，向地方下达了今年第三批625亿元超长期特别国债支持消费品以旧换新资金。截至6月20日，2026年消费品以旧换新惠及1.36亿人次，带动销售额超1万亿元。其中，今年1—5月，限额以上单位中高能效等级家电零售额增长超过30%；新能源汽车市场零售渗透率连续两个月超过60%。【更多详情】
◐“人造太阳”重要突破！全球最大核聚变堆超导磁体通过验收。据央视新闻6月27日报道，中国科学院合肥物质科学研究院等离子体物理研究所“人造太阳”项目取得最新进展，我国两款自主研制的核聚变堆使用的超导磁铁分别完成技术验收和满工况参数测试。国家重大科技基础设施“聚变堆主机关键系统综合研究设施”最大的超导部件——环向场磁体完成最后制备工艺，并通过专家验收。高温超导中心螺管线圈磁体完成满工况参数测试，核心性能达到国际领先水准。【更多详情】
◐全球首座16兆瓦张力腿浮式风电平台“海油安澜号”顺利出港。据央视新闻报道，6月27日，全球首座单机容量最大的张力腿浮式风电平台——“海油安澜号”，在珠海高栏港完成一体化集成后顺利出港，正式向粤东陆丰油田群海域进发。这标志着我国深远海浮式风电技术正从示范应用加速向规模化、商业化迈进。
◐世界第一高坝大渡河双江口水电站并网发电。据科技日报6月27日报道，从国家能源集团获悉，世界第一高坝、国家能源集团大渡河双江口水电站首台机组26日顺利并网发电。该电站是大渡河上游的控制性水库和龙头电站，总装机容量200万千瓦，年均发电量77亿千瓦时，其并网发电意味着我国清洁能源基地建设再添骨干力量。
◐世界额定水头最高、我国单机容量最大抽蓄电站全面投产。据科技日报6月25日报道，从三峡集团获悉，6月25日23点59分，随着最后一台机组顺利完成15天考核试运行，总装机容量170万千瓦的浙江天台抽水蓄能电站实现全面投产发电。该电站是世界额定水头最高、国内单机容量最大的抽水蓄能电站，也是“十五五”时期国内首个全面投产的抽水蓄能电站。电站全面投产，标志着我国在超高水头、大容量抽水蓄能技术领域实现重大跨越。
◐雄安新区天然气供应专线工程正式投用。据央视新闻报道，6月27日，陕京管道雄安新区天然气供应专线工程正式投运，与已供气的蒙西管道形成“双气源”保障，为雄安新区清洁用能提供支撑。雄安新区天然气供应专线线路全长5.8公里，全线设置2座站场，设计年输气能力31.6亿立方米，折合替代标煤约420万吨，减排二氧化碳约462万吨。
◐伊朗革命卫队称将加大打击“违规船只”的力度。据新华社6月28日报道，伊朗伊斯兰革命卫队发表声明称，将采取果断行动回应美国侵略行为，加大打击“违规船只”的力度。声明说：“从现在起，对违规船只的打击力度将比以往更大。无论以何种借口，即使是像这两天那样针对小型目标的侵略，都将遭到毁灭性打击。”
◐坦桑尼亚国家电网故障致大面积停电。据央视新闻6月28日报道，当地时间6月27日晚，坦桑尼亚国家电网发生技术故障，导致大面积停电。停电影响了坦桑尼亚多个地区的家庭、企业和公共机构。坦桑尼亚电力公司表示，其技术团队正在进行抢修工作，分阶段恢复电力供应。
◐欧洲现役最老核电站因高温暂停运行。据央视新闻报道，由于高温天气导致用于冷却核反应堆的河水温度过高，位于瑞士北部的贝兹瑙核电站已于当地时间6月26日暂停运行。这座核电站是欧洲现役最老的核电站。
◐委内瑞拉官员：石油生产未受地震影响。据央视新闻报道，委内瑞拉接连发生两次强震后，当地时间6月26日，该国人民政权油气部长葆拉·埃瑙说，石油生产未受地震影响，委内瑞拉目前日均原油产量为120万桶，政府已评估国内库存情况，国内天然气和燃料供应有保障。“我们处于正常运转状态，所有油井在运转和生产中。”
◐三条世界级高性能碳纤维生产线集中投产。据央视新闻6月28日报道，从中国建材集团获悉，中国建材三条世界级高性能碳纤维生产线集中投产，标志着我国碳纤维产业高质量发展再添重磅里程碑。其中，年产5000吨大丝束碳纤维产线，依托首创干喷湿纺技术，升级风电专用产品，有效降低生产成本，大幅提升行业规模化制造水平。
