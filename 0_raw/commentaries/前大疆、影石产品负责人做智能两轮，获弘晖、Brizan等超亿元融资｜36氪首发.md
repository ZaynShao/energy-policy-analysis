# 前大疆、影石产品负责人做智能两轮，获弘晖、Brizan等超亿元融资｜36氪首发

硬氪近日获悉，智能出行企业“迅路创新”已于年初完成新一轮超亿元融资。本轮融资由老股东Brizan Ventures和新股东弘晖基金领投，红杉资本、顺为资本、初心资本、高秉强教授个人、以及李泽湘教授旗下清水湾基金持续跟投。
融资资金将主要用于产品量产、新产品研发及人才梯队建设。
迅路创新成立于2023年，定位为面向低速短出行场景的智能系统。旗下品牌TARRAN主要面向全球家庭用户提供智能出行的新方案。过去三年，公司已搭建覆盖动力驱动、感知融合、控制算法、人机交互的技术底座，并基于该平台完成多款智能出行产品的量产交付。产品从概念到量产的速度大幅领先于行业，验证了技术平台在不同产品形态实现快速落地的能力，支撑公司持续扩展品类边界。
“不同产品之间，可以复用底层电控、传感器和闭环算法等平台能力。而自研中控2.0将会把所有的技术积累沉淀到一个高效的通用平台上。”迅路创新创始人兼CEO郭灼告诉硬氪。
Cargo Bike是TARRAN选择的首个品类，不仅因为这是一个需求确定的大市场（Cargo Bike正在成为许多欧洲年轻家庭替代第二辆车的主要出行工具），更重要的是，它为上述智能运动系统提供了最佳的训练场。首先，它在重载下的起步、转弯稳定、制动安全对控制算法的挑战远超普通自行车，家庭用户对主动安全、碰撞预警等智能辅助功能也有更强需求；其次，日常接送、购物、通勤等高频真实道路场景，也能持续提供高质量数据；而较高的客单价，足以覆盖相关成本，让智能化在BOM上具备可实现性。

开机
Cargo Bike是技术试金石，也是通向更大平台的最佳商业入口。公司目前已量产两款产品，前置箱式结构的T1 Pro，最大载重220kg，以及长尾车形态的L1，最大载重215kg。产品均配备后向雷达与摄像头、智能灯光、自动脚撑、自动变速及电动升降座管，主要解决家庭用户载娃载物时的满载起步、临时驻车和后方来车感知等问题。
硬氪了解到，电助力拖车是迅路下一阶段重点推进的新品，计划在年内发布。该产品目标是成为全球首款量产的智能拖车。传统自行车拖车多数为纯机械结构，本身没有动力和主动制动，载重过大时，容易发生倾翻事故。迅路则是将Cargo Bike上的电助力与控制系统移植到拖车中。产品加入电机及力矩、速度、位置等多种传感器，通过多套控制算法闭环判断使用者的牵引动作，再提供相应的助力或制动。
“你拖得快，它就走得快；你停下来，它也跟着停。”郭灼解释到，用户可以较轻松地拖动满载产品上下坡，松开牵引后，拖车能够主动制动。产品既可由人牵引，也能挂接普通自行车或电助力自行车，额定载重为60公斤，最高速度可达25kph。与传统拖车不同，迅路的核心能力并非单一硬件集成，而是在长期积累的人机协同控制、动力管理和安全控制算法。
郭灼表示，更长期来看，智能出行的独特价值在于，它既是消费品，也是持续采集高质量真实世界数据的载体——用户高频使用、穿行于真实复杂环境，使其能够覆盖毛细血管级的出行场景，成为积累空间智能数据的强大节点。
渠道方面，TARRAN目前已覆盖德国、瑞士、奥地利、荷比卢、法国、英国及北欧等市场的数百家中高端自行车零售门店，并开始进入法国Cyclable、瑞士AureusDrive等核心连锁渠道。公司还在拓展北美市场，与当地家庭自行车订阅机构及零售服务平台洽谈合作。目前新渠道门店数量增速和产品销量都在快速提升。
郭灼告诉硬氪，Cargo Bike并非快消电子，海外渠道判断一个新品牌能否长期经营，需要持续观察。“这种信用像存钱一样，存两年可能还不够，存到第三年可能刚刚够，之后还要继续存。我们现在正在进入一个增长指数曲线向上快速爬升的阶段。”
迅路创始团队来自DJI大疆创新、安克创新、影石Insta360等科技企业，创始人郭灼拥有16年产品研发与项目管理经验，在大疆作为产品经理负责过多款无人机和初代Osmo手持云台相机，在19年到23年在影石负责GO系列拇指运动相机以及X系列全景运动相机，是主要的产品线研发负责人，团队在机器人传感、电机控制及智能化系统开发上具备深厚积累。
CEO对谈
硬氪：公司进入下一阶段后，最重要的目标和挑战是什么？
郭灼：第一还是把已经交付的产品做好，包括品质、售后和用户体验。欧洲市场非常看重长期信用，这不是一次发布或者一次销量能够建立的，需要持续投入。
第二是保持创新，继续推进系统升级和后续产品。我们的节奏是做N的时候同步做N+1，并规划N+2，但创新不能脱离交付。最大的挑战，是在渠道、出货和团队扩张的同时，继续保证产品品质和现金流安全。
硬氪：为什么不把迅路定义为一家传统电助力自行车公司？
郭灼：我们更希望成为智能两轮领域的硬科技公司。Cargo Bike是当前最成熟的产品入口，但我们真正积累的是电池、电控、电机、传感器，以及人与设备交互的能力。
未来的产品可能是自行车和拖车以外的其他形态，但业务边界仍围绕载人、载物和家庭出行。我们不会追逐短期热门品类，而是在同一用户圈层中，把底层技术逐步延伸到更多产品。
