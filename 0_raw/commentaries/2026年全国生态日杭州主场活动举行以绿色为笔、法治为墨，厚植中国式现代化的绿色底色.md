# 2026年全国生态日杭州主场活动举行以绿色为笔、法治为墨，厚植中国式现代化的绿色底色

8月13日，2026年全国生态日杭州主场活动在滨江区荟鼎智创中心举行。今年是杭州被赋予“生态文明之都”城市定位十周年，也是《中华人民共和国生态环境法典》正式施行后的首个全国生态日。在这两个重要时间节点交汇之际，活动以“厚植中国式现代化的绿色底色”为主题，集中展示了杭州十年生态文明建设成果。
活动现场，正式发布了2026年度“杭州市十大低碳应用场景”入选场景名单，“绿行杭州”碳普惠平台也在活动当天正式上线。省、市、区相关部门以及各区、县（市）政府相关负责人等150余人参加。
十年蝶变
杭州交出绿色答卷
2026年是杭州被赋予“生态文明之都”城市定位十周年。十年来，杭州从“西湖时代”迈向“钱塘江时代”，绿色发展理念贯穿城市每一次跨越。
活动上，滨江区交出了一份亮眼的绿色成绩单：作为国家高新区综合评价第一方阵，滨江区去年单位工业增加值能耗强度仅为全市平均水平的6.4%，能效绝对值居全省、全市第一，已成功创建国家生态文明建设示范区。活动所在的荟鼎智创中心，是浙江省首个工业综合体试点项目，也是滨江区绿色转型的生动缩影。
十大低碳应用场景授牌
品牌效应持续释放
为深入落实国家碳达峰碳中和工作部署，高质量推进碳达峰试点城市建设，总结提炼我市“双碳”工作成效和典型案例，市发展和改革委员会启动了2026年度“杭州市十大低碳应用场景”评选工作。活动现场公布了入选场景名单并为获评单位授牌，集中展示了杭州在能源管理、循环经济、建筑改造等领域的低碳转型典型实践，一批批低碳转型的先行者用实践探索着“绿水青山就是金山银山”的杭州路径，品牌效应持续释放。
“绿行杭州”碳普惠平台正式上线
试运行期间逾65万人次参与
活动当天，“绿行杭州”碳普惠平台正式上线。平台于2025年全国生态日期间发布，2026年4月28日上线试运行。试运行期间，平台累计访问量65万人次，累计权益兑换28279笔。平台以共建、共用、共享为核心理念，打造全公益、零门槛的绿色出行激励平台。市民使用杭州公共交通“一码通”刷码乘坐公交、地铁、水上巴士，系统自动核算碳减排量并发放碳积分。碳积分可兑换公交地铁直充金、市级专家门诊预约号源、漫展门票等多元权益。
活动现场，市领导及市发展和改革委员会、市生态环境局、市交通运输局等有关单位负责人共同登台启动“绿行杭州”碳普惠平台上线仪式，这标志着杭州在碳普惠体系建设方面迈出新的实质性步伐。
“零碳”办会
践行绿色低碳理念
本次活动践行了“零碳”办会理念，活动产生的碳排放由国网杭州供电公司通过捐赠绿证等方式实现碳中和，以实际行动呼应“厚植中国式现代化的绿色底色”的全国生态日主题。
