# 广州丨进一步拓展自动驾驶应用场景

为进一步拓展自动驾驶应用场景，深入推进智能网联汽车（车联网）先进技术示范应用，加速智能网联汽车（车联网）先进技术赋能智慧交通与智慧城市，全面推动广州打造技术领先、应用丰富、产业集聚的万亿级“智车之城”，广州市工业和信息化局组织编制了《广州市智能网联汽车（车联网）示范应用场景目录（第三批）》并于近日发布。
自动驾驶乘用车：利用车联网相关技术，对现有自动驾驶技术和运营手段进行优化。优化远程监管系统，优化安全员配置，降低运营成本，加速推进无人自动驾驶商业化落地进程。
自动驾驶公交车：利用车联网相关技术，优化公交车实时感知能力，打造专属调度系统，降低人工接管频次，提升运营效率，为未来完全无人驾驶公交车规模化推广奠定基础。
自动驾驶专用车：利用车联网相关技术，开发可在指定区域内自动完成特定工作的专用车辆，如环卫车、自动巡检车等，并实现日常运行。降低人力成本，提升城市管理水平。
自动驾驶轻卡：利用自动驾驶技术，针对支线物流场景开发适配的自动驾驶方案，提升运输效率，降低运营成本与安全风险，包括轻型载货汽车、微型载货汽车。
自动驾驶重卡：利用车联网相关技术，开发高快速路场景下的重卡网联自动驾驶方案，实现高速公路重卡单车自动驾驶或编队自动驾驶，并开展示范运行。提升物流安全性，降低运营成本，包括中型载货汽车、重型载货汽车。
功能型无人车：利用车联网相关技术，开发可实现全场景无人驾驶作业，并完成各种服务功能的小型车辆（包括但不限于自动驾驶配送型、环卫型、售卖型、巡检型等），并实现日常运行。
园区物流优化：采用车联网相关技术优化封闭或半封闭园区货流运输系统，优化线路规划，提高货物运输效率，降低人力成本，提高作业精度及安全性，对区域动静态交通环境进行针对性治理。包括但不限于机场、港口、矿山等应用场景。
V2X协同驾驶交通优化：基于车联网相关技术，开发车载引导系统，实现各种道路车辆之间的信息共享，预测路段行车风险并进行适当引导，实现指定范围内事故率的降低及通行效率的提升。
自动驾驶车辆综合服务保障平台：以“检测-诊断-维修-养护”全链条为核心，采用车联网相关技术，构建闭环运维体系。通过智能监测实时追踪，建立分级响应机制，确保高效处置。建立专业运营平台，实现工单智能分配、进度可视化管理。提升服务质量和运维效率，降低运营成本。
陆空一体交通系统：采用车联网相关技术，建设综合性测试与验证平台，支撑智能网联汽车与低空飞行器协同发展，实现车辆与无人机在感知、通信、决策三个维度的全栈式协同验证。
