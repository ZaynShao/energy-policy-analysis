# 高水平对外开放，“十五五”浙江这样布局

8月20日下午，省政府新闻办举行浙江省“十五五”建设高能级开放强省规划新闻发布会（点击蓝字查看详情）。
中新社记者：我们注意到，浙江“十五五”建设高能级开放强省规划中提到要深化贸易强省建设。在这方面有没有什么具体的谋划？
周向军回答，“十五五”时期，浙江将以贸易创新发展，引领贸易强省建设，力争到2030年，货物和服务贸易进出口总额占全国份额达12%左右。重点做好“稳、拓、调、优”四篇文章。
将发挥出口信保小微企业统保平台作用，对年出口额1000万美元以下的企业实行统一保障，让更多中小外贸企业“能接单、多接单”。
同时，做好常态化监测分析，动态跟踪美国、欧盟、中东等重点市场变化，加大物流、金融等配套保障，全力稳产业链、供应链。
将积极开拓国际市场，持续推进“千团万企”拓市场争订单行动，坚持展会“规模不降、力度不减”，每年展会支持目录中，新兴市场占比80%以上，引导企业在深耕传统市场的同时，大力开拓东盟、非洲、拉美等新兴市场。
同时，将大力开拓国内市场，畅通内外贸产品标准、认证衔接，依托专业市场等平台，拓展内外市场渠道。
将加力推进“直播+平台+跨境电商+海外仓”融合发展，推动市场采购创新发展，鼓励高新技术、自主品牌产品出口。积极扩大进口，提升关键装备、优质消费品等进口规模、质量。大力推动贸易投资一体联动，加快完善海外综合服务体系建设，推动对外投资带动出口。
将动态评估政策落实情况，立足企业所需所盼，强化产业、金融、物流、就业等政策集成，根据需要适时推出。构建政府、银行、企业、海关、协会五方联动服务体系，协同开展“千组助万企”行动，常态化召开重难点问题协调会，帮助企业解决实际问题。
光明日报记者：“一带一路”建设加深了各国贸易与人文往来。“十五五” 期间，浙江在共建 “一带一路” 上将有哪些新布局？
闫西安介绍，“十五五”时期，浙江将重点在枢纽通道、开放平台、合作交流、安全保障四个维度上深耕细作，努力实现更深层次、更宽领域的互联互通与合作共赢。
统筹海陆空一体发展，做强国际物流枢纽。
打造世界一流强港，到2030年，宁波舟山港集装箱国际航线突破270条，其中“一带一路”沿线国家航线超140条，与共建国家港口越联越密、越走越亲。
推动金华（义乌）中欧班列集结中心建设，推动班列提质增效和“班列+”融合发展，保持全国“第一方阵”。
积极拓展织密与共建国家航线，开通用好嘉兴机场国际货运航线，让“空中走廊”越飞越宽。
坚决贯彻习近平总书记关于“义乌发展经验”的重要指示要求，持续深化义乌国际贸易综合改革，让“买全球、卖全球”更顺畅。高标准建设大宗商品资源配置枢纽，让产业链供应链的“筋骨”更强健。
推动自贸试验区、开发区、综合保税区争先进位，三类平台各展所长、协同发力，共同构筑高水平对外开放平台矩阵。
统筹推进“一带一路”重大标志性工程和“小而美”项目，让合作成果看得见、摸得着。
稳步扩大服务业开放，深化杭州、宁波服务业扩大开放综合试点，谋划招引一批带动力强的服务业重大外资项目，让更多高端服务要素“进得来、留得住”。
发挥浙江数字经济先发优势，高水平运营中国—阿盟国家人工智能应用合作中心，支持人工智能、云计算服务等领域平台企业乘风破浪、加速出海。
主动应对欧盟碳关税，在绿色降碳领域先行探路，形成更多可复制、可推广的浙江经验，让绿色成为浙江对外合作的鲜明底色。
落实《国务院关于对外投资的规定》，迭代完善境外投资备案管理与服务，引导企业优化海外布局，让企业“出得去”更合规。
健全完善海外综合服务体系，完善海外利益保护和风险预警机制，让企业“走得稳”有保障。
深化政银企对接，用好“一带一路”人民币融资窗口和各类金融专项，为出海企业保驾护航，让企业“行得远”有底气。
浙江交通之声记者：交通物流对高能级开放强省建设非常关键。接下来，浙江在这方面有哪些重点规划和考量？
王新平说，“十五五”期间，浙江将聚焦海陆空协同发力、软硬件同步提升，加快构建内畅外联、通达全球的现代化交通物流体系。主要是四个方面：
持续提升国际航运枢纽能级，以宁波舟山港国际枢纽海港为核心，打造北翼嘉兴长三角海河联运枢纽港，推动南翼环乐清湾集装箱业务发展。
持续提升港口全球辐射力，培育RCEP（《区域全面经济伙伴关系协定》）成员国等新兴市场，拓展非洲、南美等南方国家航线，推动中欧北极航线常态化运营。
持续提升航运服务水平，打造航运服务集聚区，优化航运金融、航运保险等高端航运服务。
到2030年，宁波舟山港集装箱国际航线突破270条，宁波舟山新华·波罗的海国际航运中心发展指数“保6争5”。
提升金华（义乌）中欧班列集结中心集疏运能力，加快境外分拨、集散中心建设，完善华东国际联运港、义乌铁路口岸三期等场站功能。
深化中欧班列市场化运营改革，完善全程时刻表班列、快速班列等差异化服务产品，中欧班列年开行量保持全国第一方阵。
推动国际道路货运发展，鼓励发展TIR（国际公路运输）、GMS（大湄公河次区域跨境运输）等国际道路运输，提升物流通道“韧性”。
增强杭州机场门户型国际航空枢纽功能，打造嘉兴国际一流航空物流枢纽，提升宁波、温州面向特定区域国际航空枢纽功能。
加快拓展国际航线网络，大力引育航空市场主体，发展国内国际互转、国际国际中转。
创新航空物流服务模式，加快布局异地货站，落地前置货站安检互认，扩大敏感货空运业务试点企业和品类范围，提升通关便利化水平。
到2030年，全省国际全货机航线达70条，国际航空货邮吞吐量达64万吨，国际航空旅客数达800万人次。
加快全球贸易网、物流网“两网”融合，深化多式联运高质量发展。
全面推进海港、空港、陆港等实体港数智化改造，迭代升级“四港”联动智慧物流云平台，实现“一网智联”省内和省外重要节点全覆盖。
提升多式联运服务效能，推广金义“第六港区”、CCA“一单制”全程运输等模式，形成“展贸+仓储+物流+金融”的贸易服务闭环，深入推进交通物流降本提质增效。
人民网记者：建设高能级开放强省，离不开制造业做支撑。下一步，浙江在打通制造和外贸、推动产业链上下游协同方面，具体有哪些举措？
娄万总介绍，“十五五”期间，浙江将从四方面持续发力，加强工贸联动、产业链协同，加快建设高能级开放强省。
进一步落实去年省政府出台的加强工贸联动实施意见，围绕“两新”深度融合，推动“人工智能+制造”，支持人工智能、集成电路、高端装备等绿色、智能新产品的研发生产，今年全省已完成新产品立项5090个。
支持先进制造业向研发、设计等现代服务业融合发展。聚焦制造、交通、教育、文旅等优势领域，打造一批高价值标杆场景，开发一批类似AR眼镜等爆款产品。通过“产品+服务+场景”，不断优化浙江制造供给能力。
义乌国际商贸城成交额多年居全国第一。继续发挥义乌国际商贸城、绍兴中国轻纺城等专业市场规模优势，发挥浙江省平台经济、跨境电商领先优势，推动“平台+工厂”“直播+直供”等新模式发展，线上、线下相结合拓展国际国内市场。通过“专业市场+平台经济+跨境电商”，指导企业多元化开拓市场。
体系化打造“浙江制造”品牌矩阵，支持企业参与“礼出之江”“浙产中药”等区域品牌和产业品牌建设。省经信厅专门在萧山机场、高速服务区设立浙江历史经典产业展销窗口，欢迎大家参观打卡。
浙江首创的“十链百场万企”产业链对接活动，深受企业欢迎，已成为全国标志性活动品牌。“十五五”期间，计划每年举办各类对接活动100场以上、服务企业超2万家（次），推动更多的优质中小企业融入产业链。
发挥世界互联网大会乌镇峰会、云栖大会、全球数字贸易博览会、浙江义乌国际智能装备博览会等浙江省展会品牌作用，提升主场服务。
通过“区域品牌+活动品牌+展会品牌”，不断提高浙江产品的含金量、附加值。
以“核心区+协同区”为抓手，发挥“集群+产业链”生态优势，提升浙江“415X”先进制造业集群竞争力。
坚持部省市县四级联动，打造一批工贸协同的样板项目、企业、园区、活动，支持义乌建设全国工贸协同样板地。围绕人工智能等重点产业，推动长三角产业联盟建设，共同打造具有全球竞争力的长三角产业共同体。通过“集群培育+县域样板+区域协同”，提升浙江产业链协同韧性。
浙江在线记者：今年，海关总署出台了综合保税区24条新规。目前浙江省综合保税区整体发展情况如何？接下来，怎样推动综保区扩能提质？
陈海鸣回答，浙江共有综保区13个，整体发展态势较好。
“十四五”期间，浙江综保区进出口值年均增幅高于同期浙江省外贸将近10个百分点。尤其在进口方面，占到全省进口的20%以上，综保区的贡献度比较可观。从刚刚海关总署公布的2025年全国综保区绩效评估“成绩单”来看，浙江目前有4个综保区蝉联全国A类，数量全国领先。
2025年以来，浙江新设立衢州综保区，还加快杭州、舟山港综保区扩区工作，先后得到国务院的批复同意。目前，嘉兴综保区扩区在进一步稳步推进中。浙江获批新设和扩区的项目数量在全国都居于首位，综保区目前已基本覆盖到全省各地市。
跨境电商业务量领跑全国，全国跨境电商业务量前10强的综保区，浙江占6席。另外，浙江综保区积极推进以电子产品为主的多项保税维修业务，不仅在区内得到稳步发展，相关经验还推动了综保区外的相关做法。“十四五”期间，浙江省保税维修业务量增长5.5倍，维修品类、业务推进速度都在全国领先。
今年4月出台的《关于促进综合保税区扩能提质的若干措施》（即24条新规），是自2012年、2015年、2019年之后，海关总署报请国务院出台的推动综保区发展的第4个纲领性文件，意义重大。
面向“十五五”，浙江将紧扣新政24条，持续推动综保区扩能提质。
持续推进保税维修、保税检测、保税研发等新型业态，鼓励企业拓展保税再制造、保税培训等增值服务，推动产业链向高端延伸。
引导各个综保区聚焦适配度高的改革措施重点突破。比如，舟山港综保区作为大宗商品资源配置枢纽的重要平台，杭州海关将支持做优做强保税混矿业务，进一步保障国家战略性资源进口和储备；再比如，支持杭州综保区结合杭州生物医药产业千亿集群和中国医药港优势，争取生物医药监管创新试点尽快落地。
进一步支持综保区和口岸联动发展。上个月，杭州综合保税区航空前置货站已经正式启动，实现“一次查验、机坪直装”的快速通关，投运后，综保区内企业空运出口仓储成本降低15%，运输效能提升50%。这是省内首个航空前置货站。
接下来，杭州海关还将支持省内其他综保区按需设置航空前置货站，以及国际公路运输集结中心等设施，拓展“国际公路运输+保税”“国际公路运输+跨境电商”等新的运输模式，用好保税政策、全球要素和市场资源的协同，推动省内综保区在高能级开放强省建设、畅通国内国际双循环中发挥出积极的、更大的作用。
新华社记者：“十五五”时期，浙江要提升开放平台能级，对此有哪些重点考虑？
周向军说，“十五五”时期，浙江将以六类平台为重点，分类施策、改革突破。
高标准建设大宗商品资源配置枢纽
将推进国际大宗商品储运基地、加工基地、海事服务基地和贸易中心、交易中心建设，力争到2030年，原油年加工能力9000万吨、铁矿石年吞吐量3.3亿吨。
深化义乌国际贸易综合改革
将推动市场采购高质量发展，推动消费品进口机制创新。做好“平台打造＋市场培育＋模式创新”文章，持续拓展义乌全球数贸中心功能。
深入实施自贸试验区提升战略
将围绕大宗商品、数字贸易等领域，开展首创性、集成式探索，推进“自贸试验区+联动创新区+辐射带动区”发展，到2030年，国家级制度创新推广成果累计达55项。
推动开发区、综保区改革创新
将聚焦“优化、规范、功能、提升”四篇文章，加快开发区产业转型升级、科技创新、绿色低碳。推动综保区提质扩能，持续提升外贸贡献度。
打造特色化开放平台
将持续做实金砖国家特殊经济区中国合作中心，推进中国—中东欧国家经贸合作示范区等建设，强化与重点国别、地区经贸合作。
提升展会影响力和拉动力
将高质量举办数贸会、中东欧博览会等展会，培育人工智能等新质生产力展会，做大做强会展经济。
9月23日—27日，将在杭州举办第五届全球数字贸易博览会，这是国内唯一以数字贸易为主题的国家级、国际性、专业型展会，今年主题是“在数贸会遇见AI未来”，将有超2000家企业参展，全面展示“人工智能赋能数字贸易”的前沿成果、创新实践。诚挚邀请海内外企业、嘉宾：相约数贸、遇见未来；相聚浙里、共赢未来。
国际商报记者：宁波舟山港是重要的国际枢纽海港，如何发挥其优势，更好服务国内国际双循环发展，“十五五”时期浙江将在哪些方面发力？
刘德威介绍，“十四五”时期，浙江先后完成宁波舟山港总体规划修编，建成北仑—大榭、穿山和梅山三个千万箱级集装箱泊位群，形成虾峙门、条帚门超大型船舶进出港“双通道”。
宁波舟山港在连续17年货物吞吐量保持全球第一的同时，集装箱吞吐量从2872万标箱增加到4387万，年均增长9个百分点，增速居全球前五大港口之首。去年9月，全球第一条中欧北极集装箱航线在这里成功首航。大宗商品储运基地建设加快推进，长江经济带90%以上的油品、45%的铁矿石从这里中转。宁波舟山新华·波罗的海国际航运中心发展指数排名从全球第10位跃升至第6位。一流强港建设正在把浙江的港口优势、开放优势更充分地转化为联通全球、辐射国内的发展胜势。
“十五五”是总体建成世界一流强港的关键时期，浙江将在向海图强的新征程中，推动宁波舟山港实现高质量发展、展现更大作为。
进一步建强枢纽、提升能级
落实国家关于建设浙江（宁波-舟山）国际物流枢纽的部署，以六横、金塘两个新的大型泊位群为重点，目标是建成五个千万箱级集装箱泊位群和三大亿吨级大宗散货泊位群。加快完善江海、海河、海铁联运，打造能力充分、结构合理、衔接顺畅、组织高效的港口集疏运体系。
到2030年，宁波舟山港集装箱吞吐量将超过5000万标箱，宁波舟山新波指数排名继续进位，港口综合实力实现新的跃升。
进一步畅通循环、链接全球
落实国家建设“物流网”的部署，巩固宁波舟山港欧美传统航线，强化中东、印巴、东南亚，拓展非洲、拉美等方向的航线网络，深入拓展海外物流节点和中西部腹地货源，2030年宁波舟山港国际集装箱航线将不少于270条。
聚力建设国家大宗商品储运基地、舟山江海联运服务中心，畅通能源、矿石、粮食等战略物资进口和中转通道，加快建好畅通国民经济循环的关键纽带和实体经济降本增效的核心底座。
进一步增强韧性、提升治理
主动适应国际海运由“效率优先”向“韧性优先”的转型，积极应对地缘冲突影响，加快壮大本土远洋运输船队。今年将是中欧北极集装箱航线常态化运营的元年，计划安排8个周班航次，8月15日第一个航次已从宁波舟山港顺利启航前往英国，中欧贸易除了苏伊士运河、好望角之外，现在有了第三条海上战略通道。
在“十五五”新起点上，宁波舟山港将全面筑牢“硬指标”，着力提升“软实力”，在全球港航界不断增强话语权、定价权和规则权，为做强国内国际双循环提供更有力的硬核支撑。
浙江经视记者：浙江人工智能创新非常活跃，具体到跨境贸易方面，人工智能应用情况如何？接下来会有哪些具体举措推动跨境贸易更便利更智能？
陈海鸣说，这几年，杭州海关依托浙江数字先发优势，积极构建了“智慧监管、无感通关”的新型监管模式，在省内多个口岸落地了多项智能化监管场景。比如：
在小商品进出口查验领域，积极探索应用AI智能眼镜，进一步实现查验信息秒级比对、风险精准判别，以这种方式大大压缩小商品监管现场的作业时间；
在集装箱空箱监管领域，积极推出“背散射X光集装箱查验系统+机器狗”协同作业的监管模式，实现“机器代人”非侵入式查验，关员远程研判，单箱从卸船到放行最快仅需10分钟，大幅提升了港口物流效率。
在铁矿石远程查验领域，通过智慧化远程查验模式进一步压缩货物提离放行时间近30%。
今年，杭州海关获海关总署批准，将建设海关系统的人工智能融合应用实验室，这将进一步推动人工智能在杭州海关的应用。
杭州海关将以此为契机，立足浙江省创新高地的优势，加快构建“人工智能+大数据+智能装备”的智慧化监管体系，进一步实施好海关“人工智能+”行动，主要从两个方面来实现：
发挥好浙江在跨境电商等新业态领域的先发优势和创新成果，围绕着“无感通关、智能监管、无事不扰、无处不在”，探索海关监管顺势嵌入企业经营、国际贸易物流链条，实现“智慧监管，无感通关”。
同时，进一步推进智能审单、智能审图、“数字关员”等一批覆盖海关通关监管、政务服务等重点领域的“人工智能+”场景在各个关区落地，实现监管作业模式向数字化、自动化、智能化升级。
海关系统的人工智能融合应用实验室落地杭州，杭州海关将抓住契机推进智能装备的研发和应用。同时要建立起人机协同机制，进一步拓展AI智能眼镜应用场景，加快无人机、机器狗、无人车等智能装备的集成应用，进一步实现“机器助人”和“机器代人”。深化移动智能装备的集成应用，打造以人为中心，以智能终端、快检装备、数据平台等为支撑的、多元的协同监管模式。
