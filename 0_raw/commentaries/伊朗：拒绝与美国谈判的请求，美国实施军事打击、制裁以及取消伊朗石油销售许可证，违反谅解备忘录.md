# 伊朗：拒绝与美国谈判的请求，美国实施军事打击、制裁以及取消伊朗石油销售许可证，违反谅解备忘录

伊朗外交部说伊方已拒绝与美国谈判的请求。
▲伊朗外交部发言人巴加埃（资料图）
据伊朗方面当地时间7月11日消息，伊朗外交部发言人巴加埃说，伊朗已拒绝了与美国进行谈判的请求。但他证实有卡塔尔官员到访，讨论伊美停火现状。
巴加埃10日晚说，美国实施新一轮军事打击、制裁以及取消伊朗石油销售许可证，系统性违反了伊美谅解备忘录。
他表示，伊朗只会在对等的基础上履行承诺，并将继续坚持“以承诺换承诺”。他说：“我们不会在没有对等措施的情况下履行任何承诺。如果对方违反承诺，伊朗将采取必要行动，正如我们过去所做的那样”。
巴加埃证实，一名卡塔尔调解人曾于10日到访伊朗东北部圣城马什哈德。他表示，这是调解方的提议，而非德黑兰的要求。他说：“我们没有要求与美国谈判，但基于我们一贯的负责任态度，我们没有拒绝地区调解人访问伊朗的请求。”
他还说，伊朗外交部长阿拉格齐将于11日访问阿曼，双方将围绕霍尔木兹海峡航运安全及相关合作举行会谈。
美国总统特朗普10日在社交媒体发文说：“伊朗要求美方继续‘谈判’，美方已同意这一提议，但向伊方明确表明，停火已结束。”
