# 电力安全保供体系与能力现代化“十五五”实施路径研究

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/MMAb68d5jeYqTAUBA9hN76sgZZBN3nNSTAMdzq4uvV7hOEIeXyYrk3Khjtqg4pPpCRftkLNzZic0gaY7Maaks7A/640?wx_fmt=gif)

  

**【摘要】**当前，我国电力行业加速进入“五高”转型发展新阶段，电力安全面临严峻挑战。为此，需把握“十五五”关键窗口期，确保有效容量和灵活调节能力充裕，高质量推进新能源发展，加快全国统一电力市场建设，并以创新驱动培育新质生产力，推动治理能力与产业体系现代化，为我国电力安全保供体系与能力现代化提供坚实支撑。

**【关键词】**十五五  能源安全  电力安全  能力现代化  

  

当前，世界百年变局加速演进，大国博弈、地缘冲突等多重挑战交织。推进国家安全体系与能力现代化，是防范化解风险挑战，为强国建设与民族复兴伟业提供坚强保障的必然要求。2014年6月，习近平总书记提出“四个革命、一个合作”能源安全新战略，明确了我国能源发展的战略方向，为我国统筹能源高质量发展和高水平安全提供了根本遵循。

近年来，能源绿色低碳转型加速推进，能源电力化、电力能源化和电力综合化趋势不断凸显。能源安全重心正从传统油气安全为主加快向电力安全转移，呈现传统化石能源安全和电力安全并重的整体态势，更长远可能演变为电力安全为主的新格局。规划建设新型能源体系、构建新型电力系统和建设新型电网，是实施能源安全新战略的具体路径。新型电力系统是新型能源体系的关键支撑和中心环节，新型电网则是枢纽平台和核心环节。

“十五五”是构建新型电力系统的关键时期，也是推进电力安全保供体系及能力现代化的关键窗口期。如何有效发挥电力行业在国民经济中的基础和先导作用，有力支撑国家重大发展战略和目标的实现，更好满足人民日益增长的美好生活用电需求，保障电力安全供应，成为必须攻克的核心问题。

  

**一、电力行业发展进入新阶段，**

**电力安全面临挑战**

![image](https://mmbiz.qpic.cn/mmbiz_gif/l9tLq5IzXwI2oUYicSQBjYtQwu0mHqkSYZsDyq6qydeONiatfQQWE6AKAtibHHMl16GiaEn3AeDnicwwmZGKrnZufQQ/640?wx_fmt=gif)

电力行业正在加速进入“五高”转型发展新阶段，未来十年我国全社会用电量仍可能维持“中速”增长，给电力安全保供体系及能力现代化带来挑战。

第一，高比例新能源加剧系统不确定性，推高系统成本。当前，新能源已成为发电装机的主体电源，但其随机性、间歇性和波动性加大了电力系统的不确定性。尽管新能源发电成本大幅度下降，却推高了常规电源、灵活资源、电网等主体投资和运行成本，导致系统成本持续攀升。

第二，高活跃创新和高比例新经营主体带来治理难题。多领域技术创新活跃，新业态、新模式方兴未艾，源网荷储各环节互动增多，新经营主体大量涌现并进入电力市场。在电力系统不确定性增强背景下，经营主体利益多元化加大了电力治理难度，对构建现代电力治理体系提出了更高要求。

第三，高比例电力电子设备削弱系统稳定性。随着大规模新能源发电、高压直流输电、大功率直流负荷等“源网荷”电力电子设备大量并入，电力系统惯量加速降低，传统电力系统稳定基础遭到一定程度削弱，电源支撑不足引发的安全风险日益突出。

第四，极端天气增加电力供应不确定性。近年来，高温热浪出现的频率和持续时间均有所增加，导致制冷负荷短期急剧升高，加剧电力供应的不确定性，极端条件下甚至引发拉闸限电。此外，持续极端高温可能缩短电力设备使用寿命，或导致设备组件突然失效。

第五，用电需求“中速”增长加大保供压力。未来十年，我国全社会用电量有望维持4.0%—6.0%的“中速”增长，年均新增用电量超过6000亿千瓦时、负荷超过1亿千瓦。然而，近些年电力系统有效容量增长不及负荷增长速度，未来电力电量平衡的难度或将不断加大。

  

**二、始终坚持以人民为中心，**

**确保电力系统有效容量**

**和灵活调节能力充裕度**

构建新型电力系统要切实履行党中央赋予电力行业企业的战略使命，以电力保供为前提，决不允许发生大面积“拉闸限电”。

第一，确保电力系统有效容量充裕度。通俗理解，电力系统有效容量即发电有效容量，指电力系统中各类发电机组（含储能）参与承载用电负荷能力的总和。新能源受自然条件影响显著，随机性、间歇性强，出力特性与负荷特性匹配程度较低，其有效容量远低于装机容量。“十四五”以来，全国最大负荷年均增长超过9300万千瓦，而有效发电容量年均增长仅为5300万千瓦，系统有效容量充裕度趋紧。“十五五”及中长期，需优化各类型电源发展定位，推动技术进步，使新能源稳步从发电装机为主体转变为发电量为主体，燃煤电厂从主体性电源转向调节性、支撑性、战略储备性电源，天然气电厂从以调峰为主转向在部分地区兼具电力电量双重保障作用，核电从提供基荷转向兼顾调峰功能，水电从以电量供应为主转向电量供应与灵活调节并重。

第二，确保灵活调节能力充裕度。随着源荷两侧波动持续叠加，电力调峰需求发生深刻演化，需求规模持续扩大，需求类型逐渐多元。与此同时，电力系统调节能力面临传统调节资源逐渐紧缺、增量新型调节资源成本高等挑战。“十五五”期间，系统存量灵活调节能力消耗殆尽、增量调节能力增长与新能源增速不匹配的风险加剧。经初步测算，为实现安全保供，2030年最大周电量调节需求约占同期用电量的20%。这就要求加快发展大容量、长寿命、高安全、低成本的新型储能，特别是具备长周期调节能力的新型储能技术。未来，随着光伏发电大量接入，系统快速爬坡需求大幅增加，需继续推进火电灵活性、深调改造，推动火电增配新型储能。电源侧加大存量挖潜与增量优配，电网侧夯实物理网架及互济条件，负荷侧持续推动资源参与系统调节，助力储能侧资源更大规模应用。统筹优化组合多类型调节资源，规划布局多时间尺度调节资源建设。

第三，始终坚持电力统一调度。在电力转型过程中，源网荷储各环节互动增多，新经营主体大量涌现，利益关系错综复杂，要始终坚持统一规划、统一调度、统一管理，充分发挥统一调度对电力系统运行的协调作用，助力清洁能源高效利用，保障电力系统安全稳定运行。2025年4月28日，西班牙、葡萄牙大停电事故，也充分反映出坚持电力系统统一调度的必要性和紧迫性。

  

**三、大力发展新能源，**

**确保其安全可靠替代传统能源**

电力绿色低碳转型是实现“双碳”目标的关键，大力发展新能源是重要手段。

第一，优化新能源发展布局，提升有效容量率和构网友好性。“十五五”期间，预计新能源装机年均增长超2亿千瓦，成为新增电量的供应主力。为此，需从三方面发力：一是优化新能源并网装机规模和结构。对“风大光小”和“风小光大”省区，优化增量新能源装机规模和结构，推动分布式光伏合理配置储能。二是坚持分布式开发与集中式开发并重。优先鼓励发展“两自四化”（即自平衡、自安全、小微化、绿色化、数智化、共享化）自治型分布式新能源系统或智能微电网。规划布局沙戈荒新能源基地建设，创新海上风电发展模式，在“三北”地区优先发展光热发电。三是着力提高有效容量率和构网友好性。引导风电与光伏合理配比，科学配置储能资源。加快已配置储能但利用效率偏低电站的技术改造。落实新能源调频等涉网性能要求，提升抗扰动能力标准，加快新能源主动支撑与构网型技术创新。加快发展基于同步发电机的光热等新能源发电技术，完善分散式风电和分布式光伏接入系统技术标准规范，切实提高构网性能。此外，持续扩大新能源非电利用规模。

第二，主动顺应电力系统的功能与形态演变。随着电力系统从以化石能源为主转向以可再生能源为主，源荷功能定位和结构形态需进行适应性调整。一是扩大交直流混联大电网规模。要创新建设柔性双向多起点多落点跨区特高压网络，承担电能大容量、远距离输送任务；省内网架则负责区域协调平衡。二是发挥多元要素、微电网协同自治的新型（有源）配电网在配电区域能源平衡与互动的作用。随着巨量新经营主体融入配电网，其功能将由单纯从主网获取和分配电能，转向与主网能量、信息、碳流、价值流的多要素双向互动。三是强化自治型小微系统“就地平衡”作用，以自治型分布式能源系统和自治型虚拟能源系统（如虚拟电厂、聚合商等）为主体的小微系统，与有源配电网协同，实现多类能源网络用能交互与自治协调。

第三，统筹系统成本，推动成本有效消化。预计“十五五”期间，系统总成本将持续上升，年均增长7.8%左右，高于“十三五”以来的年均增速。初步测算，综合考虑各类成本变化趋势，“十五五”期间终端度电成本年均上涨约1分钱，且新能源上网成本降低无法抵消系统成本上升。对此，一方面要发挥市场机制核心作用进行成本疏导，建立“市场主导型”成本疏导框架。另一方面要构建覆盖“市场、政府与社会”的成本疏导体系。通过政府和社会提供配套支持，助力能源市场充分发挥疏导作用，保障市场外成本的有效疏导。

  

**四、加快建设全国统一电力市场，**

**确保电力供需协同**

![image](https://mmbiz.qpic.cn/mmbiz_gif/HFibt1DegKENX1jb4sS45Jzh8B136TSGGwo0eJibf5ia9XTDLwib1CFiaqKo0J7o6L1H3NQ93a843kribrvn6U32Q3Pw/640?wx_fmt=gif)

针对高比例新经营主体涌入电力市场带来的利益多元化挑战，需要充分发挥以电价机制为主的市场机制作用，保障电力供需平衡，促进电力供需协同。

第一，稳步推进各类主体全面入市。一是推动新能源全面参与市场交易。完善“报量报价”“报量不报价”等多元参与模式，结合差价结算机制，实现与现有政策的有序衔接。二是引导储能、虚拟电厂、用户侧资源等新经营主体入市。明确其市场准入条件、交易规则与安全责任，例如允许新型储能作为独立主体或与所属电源联合参与辅助服务、现货交易等。三是健全完善市场退出机制。对不符合安全标准、持续违反市场规则的主体实施有序退出，维护市场公平竞争秩序，形成“多买多卖”的竞争性市场格局。

第二，完善推进科学电价机制。容量电价机制对有效容量、容量市场至关重要。可结合规划和项目核准实际，加快建立基于统一规划的中国特色容量市场机制，在年度执行中通过新增电源项目公开招标，分年确定市场投资主体、购电主体和容量电价，从根本上解决电力保供难题。对于存量电源项目，由政府部门逐一核定容量电价，并根据电力供需状况进行微调。

第三，健全法治保障体系。以“能源法”为统领，以“电力法”“可再生能源法”等为骨干，以行政法规和地方立法为补充，构建全流程、一致性的新型电力系统高质量发展法治保障体系。该体系全面覆盖规划建设、运行管理、市场交易、价格机制、行业监管等各环节；与其他领域法律规定实现有效衔接，进一步强化系统性、整体性与协同性，为行业高质量发展和安全保供提供法治保障。

  

**五、坚持以创新为动力，**

**确保电力安全保供**

推进电力安全保供体系与能力现代化建设，必须紧紧依靠科技创新和体制机制创新，发展以创新为内核的新质生产力，加快打造具有全球竞争力的现代化电力产业体系。

第一，推动有组织电力科技创新，加快实现高水平能源电力科技自立自强。一是将科技创新与新型电力系统转型路径、各类电源资源功能定位转变一体化布局。电力科技创新的战略布局、攻关方向、路线图、突破时间表影响着新型电力系统的路径设计、节奏权衡等。同时，新型电力系统路径规划对源网荷储全环节各类技术路线、创新重点等都有具体要求。二是推进重大工程集成创新与一体化设计。新型电力系统面临的挑战，既包括各领域技术攻关难题，也涉及煤电、可再生能源、核电、电网、氢能与储能等领域的整体集成问题，是一个需要全环节技术分头攻关加集成应用的综合性、系统性工程。三是以场景思维和重大工程设计为牵引，推进新型电力系统集成科技创新。推动全产业链工业化规模的关键技术突破与应用，实现理论、技术、装备、软技术的一体化验证，促进能源供应基础设施系统性革新。

第二，深化电力治理体系改革，加快实现电力治理能力现代化。以安全治理夯实发展基础、以规划治理优化演化路径、以市场治理释放行业活力、以碳治理服务全面绿色转型、以法治治理保障良好发展环境，实现“规划引领、科技为驱，市场配置、电价为基，监管全域、安全为先，法治保障、平等为要”，高质量构建新型电力系统。

第三，推进创新链产业链人才链资金链深度融合，加快建设现代化电力产业体系。通过全方位重塑价值形态、企业形态、循环形态和空间形态，新型电力系统产业链将从以化石能源为底色，演变为以新质生产力为基础、以新能源为主体的新型产业链，在创造和满足高质量用能需求的同时，实现产业链水平全面跃迁。

  

**六、结语**

![image](https://mmbiz.qpic.cn/mmbiz_gif/HFibt1DegKENX1jb4sS45Jzh8B136TSGGwo0eJibf5ia9XTDLwib1CFiaqKo0J7o6L1H3NQ93a843kribrvn6U32Q3Pw/640?wx_fmt=gif)

国家安全体系与能力现代化是实现民族复兴伟业的根基保障，能源保障和安全事关国计民生，是“国之大者”。新型电力系统是“源网荷储碳数智治链”一体化创新发展的经济社会环境巨系统，要坚持以总体国家安全观为指导，既要自觉纳入经济社会发展全局进行战略统筹，做好各阶段“安全、绿色、经济、共享”四重目标的规划优化，又要遵循电力系统发展规律，推进跨行业跨领域资源、全要素协同，有效应对传统与非传统安全挑战，确保电力安全保供，推动绿色低碳转型行稳致远。
