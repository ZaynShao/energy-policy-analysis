# 伊朗最高领袖健康状况披露

据伊朗伊斯兰共和国通讯社10日报道，伊朗总统佩泽希齐扬当天表示，他近期与最高领袖穆杰塔巴·哈梅内伊进行了一次约7个小时的会谈，最高领袖“健康状况很好”。佩泽希齐扬表示，他与穆杰塔巴讨论了伊朗在内政和外交领域面临的挑战，涵盖民生、就业、住房和应对制裁等议题，会谈“非常成功”。穆杰塔巴指出，敌对势力正试图在伊朗国内制造分裂，当前维护国家团结和凝聚力至关重要。据伊朗媒体9日报道，佩泽希齐扬与穆杰塔巴进行了会谈。双方详细讨论了伊朗当前面临的问题和困难，重点涉及保障民众生活需求、当前“第三场强加战争”形势及未来发展、军事领域动态，以及外汇和能源等方面的保障和支出管理问题。双方还就同外国有关方面开展经济互动交换了意见。
