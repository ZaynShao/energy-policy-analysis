# 青岛动力储能电池三年行动计划：电池PACK产能目标提升至80GWh，向大容量电芯、长循环寿命方向转型

到2028年，全市动力及储能电池产业链规模以上企业将突破50家，产值规模突破180亿元。
在关键材料领域，负极材料的全国市场占有率将保持30%以上。在产能方面，电池PACK产能将由目前的24.4GWh提升至80GWh。BMS（电池管理系统）、PCS（储能变流器）、热管理等关键部件的配套能力也将同步提升。坚持“巩固优势、补齐短板”，做强电池关键材料，研发储备新一代电池关键材料生产技术和装备，完善电池基础材料供给能力。支持储能电池企业向大容量电芯、长循环寿命方向转型，积极拓展海外储能市场，全面提升产品竞争力和本地配套水平。全面梳理新能源汽车、储能电站、低空经济等领域的电池应用需求，建立“场景机会清单”并动态更新发布。定期组织整车、储能等应用企业与本地电芯、PACK企业开展供需对接，持续提升动力电池本地配套率。支持企业参与微电网等新型电力系统建设，拓展储能多元化应用空间。鼓励电池企业通过市场化方式降低用电成本，提升产品竞争力，支持电池企业参与绿电交易。结合储能、低速电动车等场景开展示范应用，引导传统石墨负极企业向硬碳负极延伸。
