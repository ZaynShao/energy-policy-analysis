# 实测灵犀专业版，AI 成为下一代办公入口

周一早上打工的崩溃时刻，可能从老板在群里丢来一句：「上季度那个项目，复盘一下，下午开会用。」这种时刻最耗人的，往往不是复盘本身，是开工前的准备：上季度的数据表存哪了、当时那版汇报是哪一稿、老板上次拍板时说过「重点讲结果、别铺过程」。这些东西散在十几个文件夹和几百条聊天记录里，你估计得先花一个小时把它们一件件捞回来。想让 AI 搭把手？可以，但你得先把这一整套背景一字一句讲给它听。更让人泄气的是，下次再来一件类似的活，你还得从头再讲一遍。现在很多人电脑里常开的办公 AI 有五六个，写稿一个、做表一个、做 PPT 又一个，各管一摊。它们都很聪明，但 AI 之间的信息不同步，每次打开都是一张白纸，我得从头交代我是谁、要什么、上次那版长什么样。像每天进公司都要重新办一次门禁、重新跟同事自我介绍。今年到现在，我最深的感受除了「AI 越来越强」，还有就是疲惫。前段时间我去金山办公跟他们聊产品，听到一个有意思的细节：财务的人拿到 AI 生成的表格，第一个动作往往不是看结果，是点开格子看公式。后台用 Python 算出一个数，哪怕算对了也没用，他没法向老板交代这个数是怎么来的。一个不能被你追问、每次都从零开始的助理，再聪明，你也不敢把真正要紧的活交给它。说到底，「做出来」这件事已经不稀缺了。接个大模型谁都能生成一份看着像模像样的东西，发布会 demo 可以很惊艳。真正难的是两件事：它记不记得住你，以及它交的活你敢不敢署上自己的名字发出去。7 月 15 日，金山办公也正式发布了灵犀专业版。在一堆比拼手速的 Agent 产品里，它有点不一样，除了给 Agent 加上手脚，灵犀更多琢磨的是，怎么把那些通用 AI 的能力，做成一个真正认识你的个人办公助理。灵犀专业版不再是 WPS 里的一个 AI 功能。金山把它单独拎了出来，粗暴理解，它就是「金山版 Codex」：WPS 继续管文件的编辑和正式流转，灵犀负责组织你的项目、调动你的资料、执行任务、交付结果。这背后其实也是因为办公的「入口」在快速变化，Agent 时代，真实的工作从来不只发生在一个文档里，它横跨浏览器、本地文件、云端服务和好几拨人的协作，一个嵌在 WPS 里的按钮兜不住这么大的摊子，只有独立出来才装得下。金山办公助理总裁田然给灵犀立了个不算小的目标：再造一个 WPS。至于产品能不能撑得住这样的野心，APPSO 也提前使用了一段时间灵犀专业版。这样想跟大家分享一些有意思的体验细节。真实工作很少从一份干净的文件和一句完整的指令开始。老板的一句批注、几个人互相冲突的意见、跨越多年的旧资料，甚至临时改变的项目方向，都会让任务迅速变复杂。我更关心的是，灵犀能不能理解这些藏在文件和指令背后的关系，并直接交付可以继续使用的高质量成果。在各种办公场景中，表格最容易暴露出表面能用和真正好用之间的差距。我又准备了一份包含 320 条记录的半年度经营数据，里面混有日期格式不一、业务线名称混乱、空值和重复项等常见问题。我的要求是清洗数据，生成各业务线的同比、环比分析，保留公式和条件格式，再制作带经营结论的图表。有些 AI 表格看起来完成度很高，点开单元格后却只有计算结果。这样的文件适合展示，很难继续交给财务修改、核验和维护。数据稍有变化，整张表就得重新生成。灵犀交付的 Excel 更接近一份正常的工作文件。公式、条件格式、图表和经营结论共同保留在表格里，用户仍然拥有后续编辑空间。更让我在意的是，它没有停留在「把数据整理干净」这一步，还根据各业务线的变化给出了经营层面的归纳。原本散乱的 320 条记录，最后变成了一份能够拿去沟通和汇报的分析材料。我一次性上传了四份材料：2018 年编写的李白诗歌单元讲义、32 页传统板书式旧课件、2026 年的新课标教研随笔，以及 40 条历届高二学生的评教反馈。这些资料记录了同一门课在不同阶段留下的痕迹。旧讲义里有完整的知识点和考点，旧课件保留了过去的教学结构，教研随笔写满尚未整理的想法，学生反馈则提供了课堂另一端的真实感受。我让灵犀生成符合 2026 年新高考要求的授课 PPT，加入《长安三万里》的情境引入和「反精神内耗」的主题升华，同时交付一份表现性任务评分量表。四份材料无法直接拼在一起。旧讲义里的知识点仍有价值，传统教学结构需要更新，学生反复提到的「背景太多」「互动不足」，也应该反映在新课件里。灵犀对材料进行了重新筛选和组织。《长安三万里》承担了情境引入的作用，诗歌分析与现实议题产生关联；评分量表也与课堂中的文本理解、合作表达和迁移应用相互对应。多年积累的零散资料，最后变成了一套结构完整、可以继续备课的课程成果。打工人最绝望的时刻之一，莫过于发布会前的紧急改稿。新闻稿、CEO 演讲稿、媒体 Q&A 和 PPT 原本都在强调「高性价比」，老板却临时要求全部改成「高端专业技术」。遇到这种任务，最怕只改了一部分：新闻稿开始讲高端，演讲稿还在讲性价比；PPT 更新了定位，媒体问答却没有准备价格偏高的回应。灵犀围绕新的传播主线同步调整了多份材料：新闻稿重排卖点，演讲稿更换核心论据，PPT 强化技术价值，媒体 Q&A 增加价格问题的回答。原有材料中与高端定位冲突的表述，也被一并识别出来，并进行了对应调整。办公工作很少只围绕一个文件。灵犀能够理解文件之间的关联，让一次方向变化同步作用于整个项目。除了专业 Office 文档交付，灵犀还可以直接生成轻量应用。「灵犀，用 HTML 做一个极简的办公用品申领小系统。表单包含：申领人、所在部门、物品名称、数量。然后再给我（管理员）留一个简单的操作项：可以勾选『已发放』或『缺货待采购』的状态就行。」灵犀最终生成了一个 14KB 的单文件网页。打开 index.html，就能直接看到办公用品申领页面。整个过程没有要求用户理解前端框架、数据库或部署流程。灵犀把需求理解、页面设计、功能实现和文件交付放在了一次对话里。对于办公用品申领、活动报名、信息登记、排班记录等轻量需求，这种能力已经可以解决不少部门内部的小问题。过去需要找开发同事排期的简单工具，现在业务人员自己也能先做出一个可用版本。当然，办公 AI 想成为长期助理，首先得记住用户。灵犀把记忆分成了三个部分：核心记忆、知识库和「自动做梦」。核心记忆保存相对稳定的信息，例如用户身份、沟通习惯、工作方式和文件偏好，并在后续对话中自动带入。知识库会把班级、项目、概念和经验等信息整理成可以检索的条目。「自动做梦」开启后，还可以从近期对话、WPS 云文档和本地文档中提取有价值的信息。我给灵犀设定了一位高中英语教师的身份，并写入授课班级、教学偏好和课件规范。随着项目推进，高三（5）班、高三（12）班和英语备课组等信息，也逐渐进入知识库。后来，我只问了一句：「帮我分析一下，高三（5）班和高三（12）班在英语方面还有哪些需要改进的地方。」灵犀从记忆中调出了两个班级的基础情况、成绩特点和薄弱环节，还调用了此前积累的分析框架。高三（5）班的完形填空和读后续写问题、高三（12）班的阅读理解差异，都被分别整理出来。用户不用重新上传班级资料，也不用再次解释两个班的区别。对一名长期使用同一套资料、持续跟进多个班级的教师来说，省下来的远不止几段提示词。记住用户之后，还要理解一项工作从哪里开始，又和哪些材料有关。灵犀采用了以「项目」组织工作的方式。每个项目可以设置独立指令，添加本地文件，并统一管理对话、产品和定时任务。项目中的资料和要求会持续参与后续工作，不用每次重新上传。我新建了一个名为「高考冲刺」的项目，放入一份高中英语作文文档，并设置了一位高考英语教学助理的长期指令。随后，我在项目中询问近三年广州高考英语作文的难度变化。灵犀直接在项目内搜索资料，整理年度差异和命题趋势，并把分析结果留在同一工作空间中。后续无论继续制作课件、安排练习，还是分析学生作文，都可以沿用已有资料和项目背景。工作空间里还可以保存最终生成的 Word、Excel、PPT 和其他文件，定时任务也与项目放在一起。对于持续数周甚至数月的工作，项目不再是一串临时对话，更接近一套持续更新的工作目录。比如一份《2026Q2 区域市场复盘报告》被发进群聊，产品、销售、财务等同事围绕同一份文件补充项目进度、修正时间节点和财务数据，并直接 @ 灵犀提出修改要求。灵犀会结合群聊上下文，把不同人的意见对应到文档具体位置，完成修改后逐条说明调整内容，并在群内交付更新后的 Word 文件。团队不用再安排一个人整理聊天记录、汇总意见、手动改稿。而整体体验下来，灵犀最有价值的地方，是把长期记忆、项目组织、资料理解和文件交付放进了同一套工作方式里。它会记住用户是谁、平时怎样工作，也能理解一组文件为什么会被放在一起。遇到复杂任务时，它可以调取相关资料，判断哪些信息更重要，再交付可以继续编辑、分享和协作的 Word、Excel、PPT，甚至直接生成一个可用的小应用。办公 AI 真正进入工作，既要回答得快，也要记得住、理得清、交付得出来。灵犀也开始具备了一个办理助理应有的样子。比起全能 AI，我更需要一个记住我的 AI 办公助理从龙虾 OpenClaw 到 Codex，今年掀起的 Agent 的军备竞赛，比的都是能力：谁生成得更快、更漂亮、更全能。但这些能力追到同一水平线上的时间，也越来越短了。你今天能一句话出 PPT，明天友商也能；这家的表格会算函数，那家很快补上。底层就那么几个大模型，大家的手，迟早长得一样快。等干活的能力都差不多了，真正决定 Agent 好比好用的，是它认不认识你，以及怎么在此基础上来构成 Agent Harness。
这已经是不少 AI 产品的共识，这几个月有不少 Agent 产品，包括最近很火的智能体手机，不约而同都在死磕同一个词：「记忆」。Anthropic 工程师 Thariq 不久前提出了一个观点给了我启发：你给 AI 的指令只是一张「地图」，真正干活的地方是「领土」。你没画进地图的路，它全靠脑补。模型越强，越会照着那张残缺的地图一丝不苟地走下去，漏说的地方替你猜，猜错了还振振有词。他给工程师开的药方是一整套画全地图的提示词技巧，可你没法要求每一个天天赶 PPT 的打工人回去学 prompt engineering。对绝大多数人来说，更现实的方式是：让系统自己记住上次那张地图，你画不全没关系，它替你补上。真正有意思的还不是这个，既然记忆会变成标配，光有一个「记忆功能」本身也不会是护城河，大家都能做一个能记事的助理，那么接下来呢？我琢磨来琢磨去，觉得是这么一个问题很关键：用户凭什么愿意把自己多年的工作，长期沉淀在你这一个平台或工具上。记忆是需要靠时间喂养的。一个今天才上线的 AI，就算记性再好，也只能从你按下开始键那一刻起，一点点重新认识你，攒够对你的了解得用上很久。而你过去三年、五年做过的方案、填过的表、改过的稿，那才是最厚的一层「关于你」的资料。谁能接上这层存量，谁的记忆就不是从零开始，距离真正看懂你这个人，也就更进一步。这恰恰是金山办公手里那点别人一时学不来的东西。拿我自己的经历来说。从大学开始我就在用 WPS，工作以后更是一直没换，这些年做过的东西早就一层层躺在里面了，估计很多人也跟我一样。这也意味着，灵犀专业版经你授权去调用这些沉淀时，它对你的了解就不是从今天起算的，而能把你过去很多年攒下的家底盘活成知识库。别的产品得从头和你相互熟悉，灵犀某种程度上「入职」时就已经读过你的履历。在一个地方攒了这么多年，人其实是懒得换的。这些底子既是灵犀的先发优势，也给了用户继续往里把新东西继续往里放的动力。在「中国版 Codex」群雄逐鹿的当下，灵犀其实也比较清醒。它不打算什么都记、什么都干，精力全放在文档、表格、演示、资料整理和办公协作这些金山耕了几十年的地里。至于写复杂代码、啃高度专业的活儿，官方也坦言你可以去找更趁手的工具。这种取舍反而让它在日常办公的能力更扎实。记忆这东西，摊子铺得越窄越深，越容易记得准、记得久。真想什么场景都插一脚，大概率会稀成一笔糊涂账。之前跟田然交流，他还说过一句让我印象很深的话：真正的助理不会每天都从「请问有什么可以帮您」开始。他把灵犀想做的事拆成三层：懂你、懂事、懂交付。这三个词加起来，其实就是一个称职的个人办公助理该有的画像。这三层其实有先后，懂事和懂交付都得长在懂你之上。一个连你是谁都不记得的助理，谈不上懂你的事，也交不出你要的活。记忆是另外两个的地基。没有地基的智能，功能再多也是往上搭积木，看着花哨，一推就倒。当然办公 Agent 的竞争也远没到终点灵犀才刚发布，记性准不准、边界守不守得住、用久了会不会反而越记越乱，都得等更多人用过、用上一阵才有答案。但怎么让一个 AI 真正记住你，确实是所有 Agent 产品的必修课。在狂奔的 AI 圈， 越来越快速的发布会让你兴奋，越来越熟悉的产品才会让你安心。办公这件事说到底，长期的安心比一时兴奋更有价值。再天才的陌生人，每次使唤都得从头交代我是谁、要什么，也不如处了三年的老搭档更值得托付，你递个眼神他就知道该去干嘛。这一年 Agent 们不断给我们增加是一双又一双更快、更强的手。但我真正需要的，就是一个记得住我、能帮我干活的助理。我愿意每天点开它的的理由，不是光看那只手有多巧。是它终于记得，我是谁。
