# 丁二烯 | 周跌16% 后市行情或跌幅收窄

本周，国内丁二烯市场价格持续走弱。以山东鲁中送到丁二烯主流价格为例，日最高跌值达750元/吨，跌幅4.73%，周跌值达2500元/吨，跌幅15.77%。

近期，虽场内需求弱势拖拽影响行情走弱，但场内部分业者仍对本周宽幅走低态势产生疑惑，跌幅超出预期。而究其宽幅走跌原因，具体分析来看：

**供需僵持逐步转向需求弱势影响**

近期，虽国内仍有企业装置停车检修，产量小幅下降，但国内出口消息影响逐步消退，据悉，目前韩国等地区丁二烯的需求“已基本满足”，海外下游企业对5月FOB中国资源几乎没有商谈意愿，而进口船货到港仍旧有限，供应面小幅波动下，对行情影响有限，市场供需格局发生改变，商家报盘不断向下调整，市场行情走弱。

**下游需求提升仍需时间 买盘心态谨慎**

虽随着原料价格的走低，下游行业亏损局面有所好转，但利润修复仍显缓慢，需求提升仍需一定时间，且高价成本压力下，终端客户对高价上游产品接受程度有限，采买意向不佳，因此对丁二烯下游各产品市场价格表现产生持续拖拽作用，进而导致生产成本下降的同时生产利润未有明显改观，因而下游企业装置负荷尚未出现大幅提升，对丁二烯缺乏买盘意愿，拖拽行情走弱。截止收稿，山东鲁中送到丁二烯主流市场价格在13350元/吨，较上周期跌2500元/吨，跌幅15.77%。

**下游逢低买盘跟进略有提升 跌幅或有收窄**

场内业者对后市行情仍存看空情绪，实单成交多以低端价格为主，或将继续拖拽行情走势下行，但由于丁二烯价格逐步跌至低位，部分下游企业及贸易商逢低补库心态渐起，买盘跟进略有好转，且临近‘五一’假期，下游企业或存一定刚需备货情绪，或影响丁二烯市场跌幅收窄。
