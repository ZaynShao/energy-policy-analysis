# 黑龙江、青海“风光打捆”绿电首次“组团”进京

记者7日从首都电力交易中心获悉，首都电力交易中心联合黑龙江、青海电力交易中心，于2026年夏季首次开展黑龙江、青海“风光打捆”绿电进京交易。
本次“风光打捆”绿电交易覆盖度夏及秋冬季用电窗口期，计划输送绿电2.34亿千瓦时（青海1.03亿千瓦时、黑龙江1.31亿千瓦时）。其中，夏季用电高峰期间，黑龙江、青海“组团”输送绿电将达4700万千瓦时。
“青海光伏白天出力较多，黑龙江风电夜间出力较多，根据不同的发电特性进行优化配置，开展昼夜互补、接力交易。”首都电力交易中心副总经理王立介绍。
今年以来，北京不断扩大外调绿电供给，通过创新交易组织模式、拓展绿电应用场景、服务客户多元需求，持续扩容北京绿电“朋友圈”。目前，已有来自华北、东北、西北、西南、华中五大区域的16个省（自治区）及地区向北京输送绿电，今年上半年绿电交易规模超200亿千瓦时，跨区绿电交易电量同比增长88%，有效扩充北京绿电供给与消费体量。
