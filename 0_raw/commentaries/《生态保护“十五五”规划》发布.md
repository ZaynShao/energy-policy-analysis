# 《生态保护“十五五”规划》发布

日前，生态环境部等部门发布《生态保护“十五五”规划》。
以下为原文
关于印发《生态保护“十五五”规划》的通知
环生态〔2026〕47号
各省、自治区、直辖市及新疆生产建设兵团生态环境厅（局）、自然资源主管部门、住房城乡建设厅（委、管委、局）、水利（水务）厅（局）、农业农村（农牧）厅（局、委）、林草局：
为贯彻落实党中央、国务院决策部署，全面加强“十五五”时期全国生态保护工作，我们联合编制了《生态保护“十五五”规划》。现印发给你们，请结合实际，认真贯彻落实。

住房城乡建设部
水利部
农业农村部
