# 原党委书记、董事长朱坚和，涉嫌严重违纪违法

中央纪委国家监委网站7月10日消息，据广西壮族自治区纪委监委消息：广西北部湾投资集团有限公司原党委书记、董事长朱坚和涉嫌严重违纪违法，目前正接受自治区纪委监委纪律审查和监察调查。
据广西北部湾投资集团有限公司（简称“北投集团”）官网显示，该公司为广西壮族自治区人民政府直属大型国有企业、国有资本投资公司，以交通基础设施及城镇综合开发、口岸与园区运营、水务环保、新一代信息技术为主业，以新能源、低空经济、化工新材料、资本投资等为重点培育产业。管理的资产总额4939亿元，位列中国企业500强第389位。
新能源产业方面，建成运营分布式光伏电站25个、风电项目2个，装机容量近38万千瓦，累计发电量超27.6亿度；在建新能源项目14个，装机容量158万千瓦，总投资97亿元。
