# 胡广杰，赴任贵州

胡广杰任贵州省人民政府副省长。
据贵州日报消息，7月13日，贵州省十四届人大常委会第二十四次会议在贵阳举行。根据《贵州省各级人民代表大会常务委员会人事任免条例》的规定，会议决定任命胡广杰为贵州省人民政府副省长。
▲胡广杰（资料图）
公开信息显示，胡广杰，男，汉族，1973年7月生，大学，中共党员。
胡广杰曾任中国海洋石油集团有限公司副总经理、党组成员，中国海洋石油有限公司总裁等职。
2021年任江苏省政府党组成员、副省长，2024年任江苏省委常委、省委统战部部长、省政协党组副书记。至此番任贵州省副省长。
