# 一场讲座干没1.3亿的张小龙，如今全职炒股去了？丨氪代表周报

Momenta港股上市，
总市值突破700亿港元
7月8日，物理AI公司Momenta正式在港交所挂牌上市，股票代码为6880.HK，成为“物理AI第一股”。它的发行价是295.6港元/股，一上市股价就涨超6%，总市值直接突破了700亿港元。
这家公司有多受欢迎呢？这么说吧，公开认购部分超额414倍，国际发售也超额认购了44倍（剔除基石后，绿鞋前），吸引了包括新加坡GIC、贝莱德、奔驰和比亚迪等14家知名机构当基石投资者。
据财联社报道，此次基石投资者阵容强大，基本集齐了国际长线资本的主力阵营。从认购热度来看，Momenta无疑成了近期港股市场上最抢眼的科技新股之一。
为何资本对他如此偏爱？还得是因为人家有硬实力。
目前Momenta主要做的是高阶智能驾驶方案，核心逻辑是靠量产车跑数据来养算法。车卖得越多，路上积累的真实场景数据就越多，算法被训练得越聪明，智驾体验就越好；体验好了，又能吸引更多车企采用它的方案，反过来再增加数据量。
这就是一个不断自我强化的正向循环，业内管它叫“飞轮效应”，其实就是越用越好用，越好用越多人用。
目前已经有超过100万台量产车搭载了它们的系统，全球前十大车企里有9家都是它的客户，合作车型覆盖从十几万的家用车到百万级的高端品牌。
官方说了，本次上市募集的资金，也主要是用来继续搞技术迭代和无人驾驶业务的全球化扩张。据招股书披露，Momenta正在推进L4级完全无人驾驶的商业化落地，同时在德国、日本、美国等地都有布局，目标是做全球性的自动驾驶方案供应商。
只能说，智能驾驶这场仗是越打越热闹了，Momenta拿了钱，离大家“开车不用脚”的梦想又近了一步，就是不知道咱的驾照是不是快白考了？
被DeepSeek面试官质疑抄袭，
华为天才少年回应面试争议
7月6日，前华为“天才少年”李博杰在社交平台公开吐槽DeepSeek的面试流程，提及流程较慢且繁琐，面试官存在态度问题，质疑他抄袭，他感到“被严重冒犯”。
当事人李博杰的来头不小，1992年出生，中科大计算机博士，还是少年班出身，也是华为首批“天才少年”计划入选者之一。入职定级P20（副首席专家级别），在华为2012实验室负责过AI基础设施方向。后来自己创业，现在是Pine AI的首席科学家。
据李博杰在平台上的自述，槽点主要有三个：
笔试通过后拖了半个月才安排面试，其他公司offer都到手了，他反复催促才排上；
面试官迟到，对他介绍的工作内容“毫无感知”，态度轻佻地追问有什么“工程挑战”；
最让他感到“被严重冒犯”的是，代码面试时他用了两个屏幕，面试官说他频繁瞟左边屏幕、怀疑在抄代码，在解释了双屏情况后面试官仍不相信，他当场结束了面试。
面试风波发酵次日，李博杰在接受36氪专访时，还原了事件始末（点击跳转完整文章《华为「天才少年」回应DeepSeek面试争议：想象中的「殿堂」，没能接住敬仰丨36氪独家》）
在李博杰的讲述中，他承认面试存在岗位错配，自己被分配到“开发工程师”岗位，而他更倾向研究类职位。二面时，面试官认为他讲的都是“研究问题”而非“工程问题”，加上被质疑抄袭代码，最终主动终止面试。
他坦言，最大的愤怒来自落差感，DeepSeek在他心中曾是“金字塔尖的殿堂”，但面试体验与想象相去甚远：“我以为这会是一个非常research导向、人才密度极高的地方，它不是藏着掖着自己赚钱，而是把东西贡献给了大家，这点我非常崇敬。也是因为这个，其他公司offer都拿到了，我还一直在等DeepSeek。”
面试结束后，李博杰投诉给了DeepSeek的HR和猎头，猎头说可以道歉，HR则一直没回消息。没有电话沟通直接进入笔试、笔试完需要自己催进展、安排上面试岗位又不匹配……整个面试过程中，所有这些让他感受到傲慢无理的行为，让李博杰决定诉至社交媒体。
二面结束时，李博杰向HR反映面试情况，对方没有回应
截至发稿，DeepSeek方面尚未作出正式回应。
在这场面试引发的讨论声中，有人认为这是大厂招聘流程僵化、工程师文化走向极端的又一个例证；也有人认为，“天才少年”的头衔，是不是就意味着可以获得额外的照顾或优待。你又是怎么看的？
OpenAI发布GPT-Live语音模型，让ChatGPT更像真人对话
7月9日，OpenAI发布了新一代语音模型GPT-Live，现在的ChatGPT能像真人一样跟你聊天了。
以前你跟AI语音对话，基本是“对讲机模式”：你说一句，它等你说完了再回一句。最早的ChatGPT语音甚至要经过三个模型接力：先把你说的转成文字，再用大模型生成回复，最后再把文字转成语音，不仅慢，语气、停顿这些信息也在转换过程中丢了。
后来升级的高级语音模式虽然流畅了一些，但骨子里还是“轮次制”的，得靠检测你有没有停下来判断该不该接话。你要是思考时顿了一下，或者旁边有人咳嗽了一声，它就可能以为你说完了直接抢话，体验挺尴尬的。
这次真的不一样了，GPT-Live这次用了“全双工”架构，说白了就是能一边听一边说，跟你打电话一样自然。
据OpenAI官方介绍，它每秒可以做出多次交互决策，能判断出继续说话、继续听、暂停，还是打断。你说话的时候它会适时发出“嗯”“对”“明白了”这样的简短回应，表示自己在听；遇到需要思考的问题，它可以让你先等一等，自己保持沉默。遇到复杂问题需要搜索或推理时，它还能在后台调用GPT-5.5来处理，前台继续跟你聊着不冷场。
不过首批用户反馈有点两极分化，有人觉得“活人感”拉满，也有人被它频繁的“嗯嗯啊啊”烦到了，觉得太爱插话。
尽管褒贬不一，用户的使用热情并未减退。据官方透露，目前每周已有超过1.5亿人通过语音、听写等功能与ChatGPT交谈。而从7月9日起，这1.5亿用户将陆续迎来全新的语音体验：OpenAI将面向全球ChatGPT用户逐步推出两个版本的GPT-Live：Go、Plus和Pro用户默认使用GPT-Live-1，免费用户则使用GPT-Live-1 mini。
不管你觉得它像真人还是嫌它话多，这次升级都会让AI对话变得比以往任何时候都更像“聊天”，而不是对讲机。
张小龙辞任
粉笔首席执行官、董事会主席
考公机构粉笔的创始人张小龙，7月8日突然宣布辞去公司所有职务，包括执行董事、CEO和董事会主席，连薪酬委员会和提名委员会的职务也一并辞了。今后不再担任集团任何职位，仅保留选择性战略顾问的身份。
官方公告给出的辞职理由是“需处理其他个人事务”，不过这一举动距离他上一场舆论风波才刚过一个多月。
张小龙，图源企业官方
时间拨回到6月3日，张小龙受邀到中国人民大学哲学院做讲座，他临时将讲座主题改成“AI时代的职业生涯规划”，一开场就给学生指路“最有潜力的就业方向是炒股”，还自曝在股市一个月赚了5300万。
但台下学生并不愿意捧他的场，张小龙情绪逐渐失控，当场爆出“你们除了混进体制内考个公务员混吃等死外，没什么本事”等争议言论。舆论发酵后，张小龙曾公开道歉，说自己“确实觉得赚了点钱了不起，有暴发户心态”。这场风波就让粉笔股价单日跌了近9%，市值蒸发约1.3亿港元。
一场演讲风波成了压垮张小龙的最后一根稻草，但粉笔真正的问题，是上市后持续失速的基本面。
2025年，粉笔营收26.77亿元，同比降4.1%，净利润下滑约22.6%，上市以来首度“双降”。据红星新闻报道，“公考三巨头”座次生变：华图山鼎以31.98亿元反超登顶，粉笔退居第二。主业承压之下，粉笔月活用户长期徘徊在910万左右，多年未能突破千万量级的瓶颈。
再加上粉笔押注AI突围，2025年研发投入2.45亿元，推出AI刷题系统班等产品，但全年AI收入仅3810万元，占总营收不到1.5%，尚难对冲主业下滑。资本市场早已用脚投票，股价从9.9港元发行价跌至0.465港元，市值蒸发超96%。
接棒的是在粉笔工作11年的副总裁盛海燕。粉笔需要与争议不断的创始人切割，以换取市场对公司治理的信任。但盛海燕接手的，是一个主业承压、AI故事尚未兑现的摊子。
张小龙的离场只是一个开始，粉笔真正的考验还在后头。
