# 任长宏任辽宁能源董事长

辽宁能源公司董事会选举任长宏任公司第十二届董事会董事长（法定代表人）。
8月18日发布的《辽宁能源煤电产业股份有限公司关于选举董事长及调整董事会专门委员会成员的公告
》显示，
辽宁能源
公司董事会选举
任长宏先生担任公司第十二届董事会董事长（法定代表人）
，任期自本次董事会审议通过之日起至第十二届董事会届满时
止；
增补任长宏先生为第十二届董事会战略委员会召集人。
