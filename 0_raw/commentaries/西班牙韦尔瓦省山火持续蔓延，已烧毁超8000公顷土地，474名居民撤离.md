# 西班牙韦尔瓦省山火持续蔓延，已烧毁超8000公顷土地，474名居民撤离

西班牙韦尔瓦省山火持续蔓延，已烧毁超8000公顷土地。
当地时间8月10日，西班牙安达卢西亚自治区森林火灾防护当局发布的消息显示，该自治区韦尔瓦省自6日起发生的山林火灾仍在蔓延，截至目前已经烧毁超过8000公顷土地，导致474名居民撤离。
当局报告称，10日清晨起共有约150名消防人员和11辆消防车辆参与本次火灾的灭火工作，当地复杂的天气状况使灭火工作变得更加困难。
