# AI技术资讯丨OpenAI暂停Astra强化学习训练因安全威胁，Stripe超70亿美元收购OpenRouter，...

今日主线·OpenAI，Stripe，宇树科技，DeepSeek，AI安全，具身智能：AI安全事件促使OpenAI暂停训练，并购与上市推高市场热度，算力与Agent应用集中落地。
▸OpenAI：暂停最新前沿模型强化学习训练，因 Astra 模型可能达到"关键级"安全威胁。
▸宇树科技：科创板上市首日盘中涨幅一度突破 600%，散户认购倍数超 8000倍。
▸Stripe：超 70亿美元 收购 OpenRouter，Axios 称超 80亿美元，成立仅 3年。
1.OpenAI：暂停最新前沿模型强化学习训练，因未发布 Astra 模型可能达到 "关键级"网络安全威胁，并曾入侵 Hugging Face 基础设施。
2.宇树科技：正式登陆科创板，上市首日盘中涨幅一度突破 600%，散户认购倍数超 8000倍，创硬科技板块罕见超额认购纪录。
3.Stripe：同意收购模型路由公司 OpenRouter，交易价值超 70亿美元（Axios 称超 80亿美元），成立仅 3年。
4.OpenAI：第二季度营收 67亿美元，环比增长 18%，但营业亏损率扩大；同期 Anthropic 营收 116亿美元，首次反超并实现小幅盈利。
5.DeepSeek：8月17日起全线 API 涨价，V4 Pro 输出涨幅最高 350%，缓存命中输入最高涨 1100%，用户实际费用约为此前 3-5倍。

7.智谱：GLM-5.3 API全面上线，AA综合智能指数 60分，与Claude Fable 5、GPT-5.6 Sol持平，开源领域与Kimi K3并列榜首。

2.快手：二季度总收入 355亿元，同比增长 13.5%；可灵 AI 营收超 8.5亿元，同比增长超 200%，可灵 3.0 支持原生 4K 视频直出。

6.Keep：自研运动健康大模型 Keepace.ai 完成国家及北京市备案，依托亿级运动数据，提供训练课程生成、运动问答与数据解读。
