# 新势力，怎么都有一个超跑梦？

跑车盘点
新能源超跑太多了吗
新能源饱和式竞争的影响力无远弗届，就连高处不胜寒的超跑也逃不过？
就在昨天，腾势Z正式开启预售，它是腾势旗下的全新纯电超跑，首搭比亚迪云辇-M磁流变悬架，顶配的Racing
（赛道版
）
118万，零
百加速能达到恐怖的1秒级。
如果算上在售的仰望U9，还处于概念阶段的方程豹SUPER9，比亚迪三大子品牌已经各自都有跑车。
不只是比亚迪热衷造跑车，放眼一看，新能源跑车正在遍地开花。
蔚来、小米、极氪、昊铂都是跑车玩家，极狐、领克都有概念跑车，追觅星空计划还要造搭载火箭发动机的跑车，这两三年在淘汰赛中败下阵去的高合、极越、哪吒，也曾因超跑获得过短暂的瞩目。
中国品牌造跑车从来都不稀罕，但像现在这样密集推出，是不是绝后不敢妄断，但空前却是一定的。
怎么，新势力出来混，都要有一个超跑梦？
从造超跑开始造梦
以今天的视角看，新势力造跑车，不免显得好大喜功，但回溯一下过去，就会发现新势力的破圈，超跑功不可没。
2017年前后，如同《师傅》中要在天津开宗立派必须挨个上门踢馆一般，蔚来靠着EP9也开启了疯狂踢馆模式，先后在法国保罗·里卡尔赛道、上海赛车场、德国纽北等赛道刷新记录。
这其中最受人瞩目的，当属在号称绿色地狱的纽北，EP9取得了6分45秒的成绩，创下了当时最新的量产车最快圈速纪录。
EP9十分高调的全球踢馆，一方面证明了电动汽车的技术实力，另一方面也让中国汽车在国际视野中有了更多存在感。
而这一切又都汇聚到了同一个落脚点——打开蔚来品牌的影响力。
限于148万美元的高价以及赛车设计，EP9只做了少量交付，主要成为了蔚来的吉祥物，同时沿着EP9的脉络，蔚来还发展出了EPclub，量产了ES8等早期产品。
就在EP9到处踢馆的同时，另外一款跑车已经在紧锣密鼓的推进下线了——前途K50。
前途是一个主打跑车的新能源品牌，2018年8月，首款跑车K50正式上市，补贴后全国统一售价为68.68万元。
全新品牌、小众品类、昂贵价格、新能源大势未成，K50如何卖得动？
后来的故事没有起起伏伏，K50上市不到2年，前途陷入业务停摆，成为新势力早期先烈。
EP9打完收工、K50折戟沉沙，不过，中国新能源跑车的故事还在继续，但时间要再过几年了。
2023年4月，哪吒GT发布，20万左右的价格主打平民跑车。
同年10月，昊铂和极氪先后发布SSR和001FR，马力均达到上千匹，零百加速均在2秒左右，个个都是悍将。
如今回看这些车，固然一时瞩目，但却更像是中国超跑掀起新一股高潮前的序幕。
因为转过年来，比亚迪和小米也要征战纽北。
小米率先发布成绩，经过各种意外之后，小米终于在2024年10月28日争取到了1个小时的时间窗口。
就在这1个小时里，小米SU7 Ultra原型车跑出了6分46秒874的成绩，成为纽北全球最快的四门车。
比亚迪则从2024年开始，就长期在纽北驻场测试。
到去年10月份，比亚迪终于官宣仰望U9 Xtreme战绩——6分59秒157，成为纽北量产电车圈速第一。
与此同时，仰望U9 Xtreme在德国ATP测试场还跑出了496.22km/h的全球最高车速。
小米SU7 Ultra纯为赛道而生，雷军甚至打趣道贵到自己都买不起。
仰望U9 Xtreme全球限量发售30台，单台售价超两千万元，中国跑车再一次创下了自己的记录。
精彩还在继续。
追觅的Nebula Next 01 Jet Edition，豪言要装火箭发动机，能达到100kN最大推力，零百0.9秒，真是要“上天”了。
也许是大放厥词，也许是真有实力。
总而言之，中国超跑在新能源范式下，确实正以超跑般的速度向前飞驰。
为什么要造超跑？
造超跑是一件极其费力不讨好的事。
保时捷、阿斯顿马丁、路特斯、法拉利、迈凯伦、帕加尼......活到现在的超跑品牌，翻开它们的历史，没有一个是独立活到现在的，都有过依靠大汽车集团生存的阶段。
这其中，阿斯顿马丁经历过7次破产重组，路特斯经历过5次，几经磨折。
个中原因也很简单，高投入、低产出，动辄几十亿的研发成本投入进去，
最后很有可能一年卖个数千辆
，这必然需要依靠大集团来输血。
对于中国品牌来说，饱和式竞争下，弹药本来就紧张，如果再造超跑，岂不是没苦硬吃？
答案当然是否定的。
仔细一看上面聊到的品牌，但凡活到现在仍然继续卖超跑的，都有两张护身符。
第一张是背靠大集团。
国外超跑踩过的坑，它们不用再踩一遍。在这场烧钱游戏里，家有余粮，心才不慌。
第二张是拉高品牌的需求从未如此迫切。
小米心心念念要跻身高端；比亚迪祭出仰望、腾势、方程豹，在高端市场三路发兵；追觅更不必说，恨不得出手就是全球第一。
当然，超跑能打动人，归根结底还是技术站台。
蔚来EP9、小米SU7 Ultra、仰望U9 Xtreme轮番杀向纽北，创下记录的同时，也是在对悬架、三电、散热、空气动力学等技术指标最严苛的验证。
而这一切，除了帮品牌打出声量以外，还能有机会反哺到各自的普通乘用车上。
那些在极限场景里磨出来的热管理、底盘标定、能量策略，放到日常驾驶里，自然会有更好地表现。
写在最后
超跑从来都是曲高和寡，它的存在更像是表达一种态度：
对汽车可能性的极限试探。
从这一角度看，尽管超跑的涌现看起来像是各大品牌“齐放卫星”，但其实也是它们逼自己走到新能源技术的深水区。
那些通过超跑而来的尖端技术，几年后很有可能成为量产车的底层能力。
超跑是一块磨刀石，刀快了，切什么都顺手。
