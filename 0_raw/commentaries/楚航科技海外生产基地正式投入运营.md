# 楚航科技海外生产基地正式投入运营

加入供应链产业群，请加微信gasgoo88，出示名片
盖世汽车获悉，7月9日，楚航科技宣布，其位于马来西亚吉隆坡的海外生产基地已于近日正式投入运营。此举标志着该公司全球化战略正从前期布局转向实质性深耕。
图片来源：楚航科技
该生产基地是楚航科技与马来西亚上市公司MCE Holdings Berhad战略合作的核心成果。新工厂将主要负责研发与生产应用于智慧出行领域的多款毫米波雷达产品，旨在提升并推动马来西亚及南亚地区在智能辅助驾驶方面的雷达技术发展。
楚航科技方面表示，将以马来西亚为区域支点，辐射整个南亚市场。目前，公司已获得马来西亚本土汽车品牌Perodua的项目订单，并于2025年实现了规模化量产交付，成为国内少数实现毫米波雷达产品出口的厂商之一。此外，其60GHz生命体探测雷达全系产品已通过欧盟CE等严苛标准审核，满足了欧洲新车安全评鉴协会（E-NCAP）关于儿童存在探测（CPD）功能的直接感知要求，在出口合规性方面取得进展。
除马来西亚外，楚航科技已在印度、韩国等海外市场进行布局，并与部分日韩车企建立了战略合作意向。随着马来西亚基地的投产，楚航科技的全球化运营网络进一步完善，旨在为构建更安全的智能出行生态提供技术支持。
