# 铜版纸：一季度价格低位运行 二季度或窄幅下探

【导语**】**2026年一季度铜版纸市场价格延续低位，行业供需双降，购销活跃度偏低，但上游原料成本的支撑仍在。二季度铜版纸原料成本端下跌，需求端对纸价影响由空转多，叠加纸厂挺价情绪，预计纸价先跌后涨，但均价继续下行。

**一季度纸价振幅收窄　重心下移**

2026年一季度铜版纸市场低位运行，振幅收窄，以国内157g双铜纸为例，2026年一季度均价4676元/吨，环比下跌1.61%，同比下跌17.57%；2026年一季度振幅0.86%，环比收窄1.91个百分点，同比收窄4.38个百分点。受春节假期影响，一季度铜版纸市场购销活跃度有所下降，春节前下游需求转淡，市场新签订单不足，经销商出货压力下部分成交价格松动；春节期间市场处于休市状态，价格趋于稳定；春节后纸厂发布涨价函提振市场信心，部分低价上调，但行业开工恢复以及需求跟进不足，仍然限制纸价涨幅。

**供需双降　市场交投偏清淡**

2026年一季度铜版纸产量和消费量较2025年四季度均出现下降趋势，且消费量降幅宽于产量降幅。生产端，纸价下跌且纸厂生产成本压力较大，影响行业整体开工积极性，叠加春节期间行业个别产线阶段性停机，一季度铜版纸产量环比下降4.49%；需求端，1月份出版订单提货的刚需支撑对市场影响有限，且社会订单旺季不明显，春节假期也使得市场交易日有所减少，部分业者停工放假，市场多数时间内交投清淡，一季度铜版纸消费量环比下降9.69%。

**上游浆价涨跌互现　原料成本提供部分支撑**

2026年一季度上游进口木浆现货市场涨跌互现，不同浆种走势分化。春节前下游纸厂原料备货需求回落，且对高价货源接受度偏低，经销商为加速去库积极让利出货，春节后原纸企业开工率有所恢复，但生产加工环节仍面临较大压力，下游补库意向疲软，叠加国内主要港口库存持续高位，进口针叶浆价格持续下跌；进口阔叶浆得益于外盘报价上涨及成本面支撑走强，价格表现相对坚挺；进口化机浆则因阶段性供应偏紧，市场价格出现小幅提涨。

卓创资讯数据显示，一季度进口针叶浆、阔叶浆和化机浆市场均价分别为5313元/吨、4585元/吨、3873元/吨，环比变化幅度为-3.95%、4.12%、1.38%，受此影响，一季度铜版纸主要原料平均成本为3441元/吨，环比上涨1.65%，成本端对铜版纸市场提供部分支撑。

**二季度市场氛围偏空　纸价或遵循季节性下跌规律**

供需端，二季度铜版纸市场供需呈现双增的局面，行业产能相对稳定，纸厂大多维持正常生产节奏，个别产线或有检修计划，预计行业产量环比增加0.71%；4月份新一轮出版招标将陆续启动，一般6月份迎来出版订单提货旺季，且二季度市场整体处于正常购销状态，预计行业消费量环比增加12.89%。

成本端，二季度上游木浆市场仍受行业供需矛盾加剧及下游企业降本诉求的利空因素影响，尽管阔叶浆得益于行业集中度较高及外盘报价上涨，存在价格降幅放缓的预期，但需求端持续疲软的态势，仍对多数浆种价格形成拖累，导致其呈现震荡下行走势。受此影响，铜版纸主要原料成本下跌预期较强，预计二季度主要原料平均成本环比下降1.89%。

![image](https://mmecoa.qpic.cn/sz_mmecoa_png/9w7iaKkib7mX2ZxibzPJ5jtSIzbmWrGrZIHG8sticJIJv8XcrG6lhtFEicKibJhzWTm4rynlSBQJY1S3uvVNILaaIz1TFZaqiaK4lhKOwhK681W7wg/640?wx_fmt=png&from=appmsg)

根据2016-2025年国内铜版纸市场价格的季节性走势规律来看，二季度纸价处于跌势，主要受到出版招标的影响。结合2026年二季度铜版纸市场情况来看，供应端延续宽松格局，需求端受到出版招标的议价推进影响，或施压于纸价，叠加成本端下行预期，预计4-5月份纸价仍存在下跌空间，但考虑到6月份出版订单集中提货，或缓冲部分纸厂的排产压力，且纸厂长期成本压力下改善盈利的诉求较强，6月份纸价将止跌反弹的概率较大。整体来看，预计二季度铜版纸市场价格先跌后涨，均价将继续下跌，国内157g双铜纸季度均价或在4644元/吨，环比下跌0.68%。
