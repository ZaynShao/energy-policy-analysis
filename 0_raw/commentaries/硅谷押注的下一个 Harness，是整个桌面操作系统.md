# 硅谷押注的下一个 Harness，是整个桌面操作系统

作者｜张勇毅
编辑｜靖宇
截止目前，有了 DeepSeek Harness 之类 CLI 产品之后，你电脑里的 AI 几乎已经无所不能：它可以总结网页，润色邮件，改两张图。
目前做不了几乎只有一件事：碰你的电脑本身。
有一个操作系统反过来做了这件事。它叫 Omarchy，一个 Linux 发行版，8 月 14 日发布了 4.0 版本：AI 直接装在系统里，你用一句话告诉它要什么，它替你操作电脑。十天之内，社区给它写了 1,074 个插件。
Omarchy4 桌面｜图片来源：极客公园
这个周末，硅谷有八个人为它掏了 800 万美元。
8 月 21 日，Omarchy 的作者 DHH 宣布成立 Omacom 基金会，首期 800 万美元来自八个人，每人 100 万。
名单里有戴尔的老板 Michael Dell、推特联合创始人 Jack Dorsey、Shopify 和 Stripe 的两位 CEO、Cloudflare 的 CEO、Oculus 的联合创始人，以及 37signals 的两位创始人，DHH 自己是其中之一。
八位创始赞助人，每人 100 万美元｜图片来源：Omarchy
DHH 在中国最为人知的身份，是畅销书《重来》的两位作者之一；在程序员圈，他是 Ruby on Rails 的作者，GitHub 和 Shopify 至今跑在这个框架上。Omarchy 一年前还是他的业余项目，直到它成为被开发者圈热捧的「AI 原生操作系统」，在本月火出圈。
看起来，这次「Linux 桌面元年」这个喊了二十多年的预言，似乎又要成真了：从上世纪末开始，每年都有人宣布今年就是那一年，每年都不是。卡住它的从来是两件事：门槛太高，普通人过不了命令行那一关；生态太薄，过了关也没东西可用。
但这次，Linux 靠的似乎已经不是「更好看」，而是「更方便 AI 使用」。
01
系统即 Harness，Harness 即系统
随着 Omarchy 4.0 的发布，其中的更新说明也列了多条这个新系统的特性，「可配置的默认编程 Agent」在其中赫然在列。这几乎是这个系统的核心卖点之一：这其实并不是我们传统意义上理解的「造一个 AI 操作系统」，这件事更像是造一个 AI 能读得懂的操作系统。
参考更新说明，Omarchy 4.0 整个桌面环境被重写成一个进程，叫 Quickshell，状态栏、启动器、菜单、通知、锁屏全在里面。系统配置全部改成 Lua 脚本。插件就是一个 Git 仓库。外部程序可以直接给这个 Shell 发指令。
也就是说，这个系统里的每一个部件都是文本文件，都能被读、被改、改完立刻看到结果。一个 Agent 需要的四样东西，工具、权限、状态、反馈，它全有。
这个操作系统，本身就是一个 Harness。
Harness 这个词的定义也其实经历过多次改变，但过去一年它一直是应用级的东西，年初刷屏的龙虾 OpenClaw 是，Claude Code 是，DeepSeek Harness 也是。这次 Omarchy 把这一层往下压了一格，压进了操作系统。
于是 Agent 搬进来这个「毛坯房」就顺理成章。在 Omarchy 4.0 里，开机设置阶段你就可以从九家里选一家当系统默认，Claude Code、Codex、Gemini、Grok、Copilot 都在。它以一个独立应用的身份运行，授过一次权它会记住。按一个快捷键，它就在你的系统里，读配置、改文件、跑命令、看结果。
4.0 的状态栏、菜单、锁屏都在一个进程里｜图片来源：Omarchy
我在一台 PC 上试了一天。作为一个过去十几年无数次被命令行劝退的人，第一次用自然语言中文，就把系统修好了，全程没有手动输入一条命令。
拆这堵墙的不只是 Agent，另一半功夫在开箱即用。装机跟着安装器走完就行，按官方发布说明，4.0 把镜像压到了 6GB 以内，安装快了三成。装完不用配任何东西，主题、快捷键、常用软件全是现成的，换一个主题，终端、编辑器、浏览器跟着一起变。
平铺式布局和快捷键有学习成本，但上手之后窗口不用拖、应用不用找，效率比鼠标高一截。系统菜单里还有一个 Learn 入口，快捷键表、Omarchy 手册、Hyprland 和 Arch 的文档都放在手边。过去装 Linux 是你去找教程，这次是教程等着你。
DHH 开发者本人之前就演示过一次：让 Agent 给他写一个「看起来像野马车速表」的测速插件，几句话之后插件装上了。插件能换掉状态栏上的一个组件，也能换掉整条状态栏。4.0 发布一周，插件市场已经超过 500 个，8 月 19 日还办了第一届插件大赛。二十年里卡住 Linux 桌面的生态问题，第一次有了不靠等开发者的解法：想要什么，让 Agent 写一个。
上线一周，插件市场已超过 500 个｜图片来源：Omarchy
对照一下苹果和微软。Apple Intelligence 和 Copilot 做的都是按钮：AI 能看你的屏幕，能读剪贴板，能帮你总结一封邮件，但它改不了系统。封闭系统、签名、沙盒，每一层都是为了不让任何程序碰系统本身，AI 也不例外。
苹果微软目前在桌面操作系统的 AI「难用」，显然并不只是模型能力差的原因，更多在于不敢交出系统。
这个「不敢」也有它的道理。过去四十年，操作系统是给人操作的：GUI 图形界面、窗口、菜单，全是为了让人看得懂、点得动。苹果微软背着几十亿用户，每一次放开系统权限都是一次事故的可能，它们不可能把系统的钥匙交给一个每周都在变的 AI。
Omarchy 押的正是这个硬币的反面：操作电脑这件事要换主体。如果操作电脑的变成 Agent，系统要先让 Agent 看得懂、改得动，人只负责说要什么。
这是「AI 接管」真正的含义：不是替你做决定，是替你操作系统。
讽刺的是，做到这一点靠的不是新技术，是 Unix 五十年前的老规矩：一切皆文件。苹果微软花了二十年把这条规矩藏到图形界面后面，Omarchy 把它重新翻到台前，Agent 正好读得懂。
一个人做的发行版没有几十亿用户的包袱。这还是小厂跑得快的老逻辑，只是这次跑的方向是操作系统的定义本身。
02
模型之上、硬件之下
按基金会公告，这 800 万美元的用途是四件事：持有商标、养基础设施、做推广、资助 Omarchy 依赖的开源项目。第一笔钱给了 Hyprland 的作者 Vaxry，它开发了 Omarchy 中的一个第三方窗口管理器。8 月 19 日项目成立了核心团队，不再是 DHH 一个人说了算。
看名单比看金额更有信息量。这八个行业 CEO 里，戴尔和 Oculus 的创始人是硬件出身，另外六位做的都是软件和平台。100 万美元对他们任何一个人都不算钱，这笔投入更像一张门票：先坐进下一代桌面操作系统的牌桌，再看牌怎么发。
以戴尔为例。过去两年「AIPC」这个概念一直是微软在定义，什么算 AI PC、要什么芯片、预装什么助手，PC 厂商只能跟着走。
但如果下一代桌面的操作者变成 Agent，操作系统就不一定还是 Windows，戴尔手里就多了一条不经过微软的路。4.0 专门给 2026 款 XPS 调了扬声器，Framework 去年就把它列为官方支持的系统，硬件厂商的心思并不难猜。
被 4.0 点名调音的 2026 款戴尔 XPS｜图片来源：戴尔
软件 公司的六位 CEO，为的是两件事，首先是为自家工程师需求更新的平台：Shopify、Stripe、Cloudflare、Block 都养着成千上万名开发者，一个让 Agent 替人操作电脑的系统，省下的全是工程师的时间，37signals 已经宣布三年内把运维和 Ruby 团队全部换过去——100 万美元还不够这些公司发几个人的年薪。
其次是下一代应用分发入口。今天你用什么软件，是自己从应用商店里挑；如果以后装好电脑第一件事是唤出 Agent，那它默认调用谁家的服务，谁就白拿一个新入口。这不全是想象：Omarchy 的官网和软件源镜像，现在就跑在 Cloudflare 上。
以上是我的推测，八个人里没有谁这么说过。但据报道，Omarchy 去年 10 月单月安装量就有 15 万次，这样一个项目，100 万美元就能坐上牌桌，再往后就不是这个价了。
这些人押的不是 Linux 的市场份额，Omarchy 不会替代 macOS 和 Windows，它连 Apple Silicon 都不支持。他们押的是模型之上、硬件之下的一层新东西，这一层正在从应用变成操作系统，而操作系统这一层，已经二十年没有新玩家了。
这个故事其实我们并不陌生：年初的龙虾 OpenClaw 同样是一个人的业余项目，把 Agent 装进你的电脑、给它真实的权限，三个月星数就超过了 Linux 本身，创始人被 OpenAI 招走，项目交给基金会。它还顺手把 Mac mini 卖到断货，据报道 Mac 销量逆势涨了 6%，苹果什么都没做。上一波硬件红利落在苹果头上，这一波，戴尔们不想再当看客。
区别在于，龙虾之后国内几个月冒出七只龙虾，大厂把命令行打包成图标，普通人才真正用上；Omarchy 还停在开发者圈里，那一步打包还没发生——而这可能正是 800 万要买的东西。
上一次有人带着一个系统从开发者出圈，是 2001 年之后的 Mac：Unix 的底子加上好看的壳，先征服程序员，再征服所有人。DHH 对 Omarchy 的定位几乎是同一句话，只是这次壳下面多了一个 Agent。
不过归根结底，Omarchy 4 眼下还是一个半成品。即使是最重要的概念，Agent 这个一等公民也脆弱。Codex 升到 0.149，状态栏的用量显示就坏了；Gemini 的命令行工具改名，默认列表就过期了。九家模型能力的适用范围每周都在改，系统级集成同时也意味着系统级脆弱。
门槛也只拆了一半。AI 替你敲了命令行，但没替办法替你记快捷键，「能工智人」还得承担一定的学习成本，平铺式窗口管理器的学习曲线是英文社区最一致的抱怨。
另外中文仍然是二等公民，输入法引擎要自己装，语音输入基本只认英文。硬件挑人，Apple Silicon 要靠社区分支绕路，NVIDIA 50 系显卡装完黑屏，连专门调过音的 XPS 13 都有人报滚动卡顿。
AI 接管的是操作电脑这件事，接管不了 Linux 的老毛病。该坏的地方照坏，只是现在坏了，有人替你修。
哦顺道一提，Omarchy 这个名字来自 Omakase，日料里的主厨推荐，也是 Rails 一直以来的哲学：别选了，按我配的来。直到 Omarchy 3，这个系统都一直是靠着 DHH 本人的好品味在圈子里小范围口口相传。
4.0 之后，这道主厨推荐变成了自选。系统对 AI 可读可写，意味着每个人都能把 DHH 的口味改成自己的口味。如果这条路走通，以后每个人电脑里的系统，可能都是自己和 AI 一起攒出来的那一个。
写这篇稿子的时候我在办公室，我的主力写稿装备其实还回到了 Mac 上：它也有各种 AI 客户端、也有 CLI，也能总结网页，能润色邮件，改不了这台电脑本身。它只会和我聊天。
但我还是会心心念念家里主机上已经装好的 Omarchy，因为真的有人，在这个系统的体验中，向我们承诺了一个 AI 完全接管操作系统的未来。
