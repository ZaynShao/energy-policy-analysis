# 中能建中电工程“一把手”调整，李屹立暂主持工作

「
储能与电力市场
」
获
悉，7月1日，
中国能建中电工程
召开会议，宣布中国能建党委关于中电工程主要负责人调整的决定。
会上，中国能建党委组织部负责人宣读了干部免职文件：经中国能建党委研究决定，罗必雄同志不再担任中电工程党委书记、董事长职务；
李屹立同志暂时主持中电工程全面工作，
履行法定代表人职责。
看个广告休息一下
李屹立简介
公开资料显示，李屹立此前担任中电工程湖南院党委书记、董事长。
2025年7月，李屹立升任中电工程总经理。
中电工程企业简介：
中国电力工程顾问集团有限公司（简称中电工程）的发展始于1950年，现为世界500强企业中国能源建设集团有限公司的核心子企业。公司旗下拥有国内外27家子企业及118个海外区域分支机构，业务覆盖全球180多个国家和地区，年度新签合同额超4000亿元，实现营业收入近1500亿元。
