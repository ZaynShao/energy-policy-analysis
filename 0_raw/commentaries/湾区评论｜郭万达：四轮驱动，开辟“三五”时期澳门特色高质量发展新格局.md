# 湾区评论｜郭万达：四轮驱动，开辟“三五”时期澳门特色高质量发展新格局

2026年8月18日，《澳门特别行政区经济和社会发展第三个五年规划（2026—2030年）》正式公布。“三五”规划是澳门特区未来五年经济和社会发展的纲领性文件，统领未来五年澳门特区的发展方向和路径，确保澳门特色“一国两制”事业行稳致远。澳门“三五”规划主动对接国家“十五五”规划，抓住以人工智能为代表的全球新一轮科技革命和产业变革的重大机遇，谋划澳门经济朝着更加多元、更高质量的方向迈进。澳门“三五”规划守正创新，求变识变，有许多新思维、新亮点、新举措。澳门“三五”规划着力强调有效市场与有为政府相结合、优势产业与新兴产业相融合、城市更新与横琴发展相支撑、科技创新与人才集聚相协同。“四轮驱动”，将为澳门“三五”时期的高质量发展提供重要保障。
有效市场与有为政府相结合
“三五”规划提出，在更好发挥市场决定性作用和企业主体作用的同时，也要更好发挥政府引导市场预期和制度政策供给的作用。“有为政府”主要表现为在城市发展、产业发展、经济转型过程中，特区政府通过合适的政策工具统筹、引导、推动、监督城市基础设施建设和产业转型升级。“三五”规划提出主要以四大工程项目和政府引导基金为两大抓手，为澳门的高质量发展注入持续强劲的动力。四大工程项目是澳琴国际教育（大学）城建设、澳门科技研发产业园建设、澳门国际综合旅游文化区建设、澳门国际机场横琴前置货站建设。为发挥政府的主导和引导作用，特区政府建立和适时扩大政府引导基金，加大对澳门基础设施和产业发展的投资力度，并吸引社会资本加入，发挥撬动耐心资本、长期资本的“杠杆”功能，基金投入是“政府有为”的重大施政工具，也是积极有效的政策供给。
优势产业与新兴产业相融合
经济适度多元发展是澳门保持长期繁荣稳定的必由之路。“三五”规划提出到2030年非博彩业增加值占本地生产总值的比重达到60%左右，形成产业多元发展新格局，强调要加快推动中医药大健康、特色金融、高新技术、会展商贸及文化体育等重点产业发展，支持传统产业智能升级。特别需要指出的是，“三五”规划提出要发展适合澳门的高新技术产业，重点聚焦数字科技、生物医药、集成电路及航天科技四个优势领域，重点培育具潜力的细分赛道，如人工智能、创新药、航天数据服务等。可以说，在数字经济、智能经济新形态、新业态加速融合发展的时代背景下，澳门的优势产业和新兴产业将呈现融合发展新格局，从适度多元走向更加多元。
都市更新与横琴发展相支撑
澳门未来发展应着力在两个方面，一是把存量空间（澳门本地）发展好，一是把增量空间（横琴合作区）建设好。城市发展的成功经验表明，城市（都市）更新是“老城区”焕发“新活力”的重要途径。做好存量空间的更新与建设，是澳门建设高水平平安城市、韧性城市、智慧城市的需要，也是解决澳门人口老化、基础设施落后、民生改善不足等问题的需要。“三五”规划强调以都市更新为抓手，加强统筹规划、做好顶层设计，加力推进都市更新，完善市政设施建设，提升公共设施服务的稳定性及可靠性，提升居民的居住和生活质量。同时，以横琴合作区为载体，把增量空间建设作为重点，把澳琴一体化作为重要目标推进，不仅在基础设施的“硬联通”上要稳步推进，而且在规则机制“软联通”上要持续深化，在民生服务“心联通”上更要深度融合，在产业协同发展的“要素联通”上力求实现新突破。横琴的价值不在于简单增加澳门的物理空间，而在于把新增空间转化为产业延伸、制度创新和民生拓展的有效空间。
科技创新与人才集聚相协同
科技创新是城市竞争力的综合体现，而人才则是城市竞争力的基石。科技创新越有活力的城市，就越容易吸引人才。而人才越涌入的城市，科技创新也越活跃。高端科技人才缺乏是澳门发展新兴产业、实现科技创新的短板。当前，澳门面临“先有鸡还是先有蛋”的问题：没有研发和科技产业，难以吸引科技高端人才；没有一定规模和质量的科技高端人才，则研发和科技产业难以发展。破解这一难题的突破口，是统筹推进教育科技人才一体化发展，构建集聚国际高端科技人才的核心载体，加快形成科技生态和产业生态。“三五”规划强调，特区政府积极统筹推进教育科技人才一体化发展，强化政策协同与资源统筹部署，培育新质生产力，推进教育体系的高质量发展，促进科技创新，打造国际高端人才集聚高地。同时要围绕科技人才和科研机构，完善法律制度，优化相关政策，便利高端科技人才来澳留澳创新创业。科技创新与人才集聚相协同，将有效解决澳门的深层次制约，实现良性发展。
“三五”规划的发布，表明澳门发展蓝图已绘就，发展目标已明确。规划的生命力在于执行，面对内外环境的复杂变化，澳门社会需要凝聚改革动力和发展合力，有效推进“四轮驱动”，在更好融入和服务国家发展大局进程中，不断开辟具有澳门特色的高质量发展新格局。
