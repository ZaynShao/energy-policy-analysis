# 央视《焦点访谈》关注｜科创如何实现跨越式发展？长三角城市群协同创新给出答案

科技创新是推动高质量发展的核心引擎。日前，“活力中国调研行”记者团走进长三角，聚焦区域协同科创活力。2025年中央经济工作会议作出重大部署，推动北京国际科技创新中心扩围至京津冀、上海国际科技创新中心扩围至长三角，清晰释放重要信号：科技创新不能只依靠核心城市单点突破，更要依托城市群开展区域协同作战。在长三角，上海、江苏、浙江、安徽各有创新所长，四方联动协同，将碰撞出怎样的创新动能？
不久前，国家地方共建人形机器人创新中心中试公共服务平台在上海浦东张江机器人谷投入运行。通过这个平台，人形机器人可以加速从“实验室样机”走向“规模化量产”，助力长三角人工智能产业集群化发展。这样的创新载体持续落地，正是上海加快建设长三角国际科技创新中心的生动缩影。而如何打造区域协同创新样板，上海的核心思路是，一方面发挥自身优势强“内功”，一方面带动长三角协同练“外功”。
上海市委常委、副市长 陈杰：在带动长三角一体化发展方面，上海组建了长三角基础研究联合基金，推动大科学装置向区域内开放共享。制度创新上，2025年，长三角三省一市首次以协同立法的形式，同步实施《关于促进长三角科技创新协同发展的决定》，今年又签订了新一轮合作协议。
高温超导是推动聚变能源从科学探索迈向商业化的核心技术之一。在上海，中国聚变能源有限公司正与长三角的多家企业开展联合攻关。今年5月，该公司入选第三批长三角创新联合体名单。这是长三角地区建立的协同创新机制，目前已经发布36家创新联合体，覆盖核聚变能、人工智能等多个前沿领域。
中核集团中国聚变能源有限公司超导磁体部主任胡新波：项目本身在上海市科委的大力支持下，整个磁体系统包括多个部件分别来自于上海、苏州等地。我们加入长三角创新联合体之后，实现了优势资源互补，强强联合，加速了研发周期的迭代。
近年来，上海加快发展集成电路、生物医药、人工智能三大先导产业，产业总规模已突破2万亿元。在关键核心技术攻关上，上海发挥“龙头带动”作用，依托长三角创新联合体，跨区域整合产业链上下游力量。下一步，上海还将协同苏浙皖三省，加快推进上海（长三角）国际科技创新中心建设。
上海市委常委、副市长陈杰：一方面打造原始创新策源地，把基础研究的“冷板凳”坐热，开展跨区域跨学科联合攻关，打造特色科学数据库，推动科学数据共享；另一方面我们将协同打造国产大飞机等世界级产业集群，在重点前沿领域共同制定或互认产品与服务标准，把长三角产业基础优势转化为战略竞争优势。
长三角协同创新，江苏有明显的制造转化优势。我国公布的首批45个国家级先进制造业集群中，江苏的数量最多，唯一的船舶海工产业集群也来自这里。前不久，在江苏南通，我国自主设计建造的第二艘18万立方米超大型液化天然气运输船顺利交付。这种船舶设计建造难度极高，全球市场曾长期由国外主导，如今在江苏已经可以实现批量化建造。
近年来，江苏把集群培育作为“制造强省”建设的总抓手，让制造业从“规模优势”向“质量优势”转变。
江苏省副省长 沈剑荣：我们的做法是体系化推进，围绕六大新兴支柱产业和六个未来产业，按照一个产业一个专班、一个行动方案等，实施“七个一”工作推进机制。同时我们也抢抓人工智能发展机遇，省政府每个月调研座谈，两个月进行一次场景路演。
在徐州的一家重型机械生产企业的制造基地里，AI技术已经深度渗透关键流程。过去，起重机研发需要人工测算上千项参数，新品从设计到下线得耗时4年。如今，依托模块化生成式研发，两年就可以推出3款新品。新建的智能生产线还可以实现差异化、个性化的定制需求。
徐工集团徐州重型机械有限公司智能制造研究所所长 郭奇：我们深度融合5G全连接、孪生仿真和工业互联网，把400多款产品型号、1200多种定制组合全部纳入了智慧系统，支持全球客户在线参与设计。
近年来，江苏部署开展制造业“智改数转网联”工作，已基本实现规上工业企业全覆盖。目前，全省累计创建领航级智能工厂2家、卓越级智能工厂67家、先进级智能工厂1808家，21家企业入选全球“灯塔工厂”。依托完整的制造业体系，江苏还将重点承接上海原始创新成果产业化，并与浙江、安徽协同联动，打造具有全球影响力的科创中心。
江苏省副省长 沈剑荣：我们将高标准建设南京、苏州两大关键支点。围绕集成电路、人工智能、生物医药等领域组建创新联合体。同时强化规划协同、创新协同、产业协同，不断增强对国际科技创新中心的支撑合力。
数字经济是浙江发展的重要动能，也为长三角科创中心建设搭建了坚实的数字底座。在浙江，“乌镇之光”超算中心建成落地，为人工智能等产业发展提供算力支撑；“三体计算星座”发射成功，把算力送上了太空……由于布局领先、应用场景丰富等原因，浙江的数字经济已连续十几年保持两位数增长，是全国唯一同时获批国家数字经济创新发展试验区、国家数据要素综合试验区的省份。
浙江省副省长 何中伟：浙江始终把数字经济作为建设科创高地的核心内容，统筹推进全省的算力基础设施建设，出台了全国首个省级公共数据授权运营管理办法，进一步推动高水平模型研发，培育高价值应用场景，聚焦大数据、云计算等方向，布局了一批重点实验室，汇聚了一批高水平人才，也实施了一批重大专项。
在中国数安港，各类数据和服务汇聚成一个特殊的“大超市”，人工智能公司训练大模型、医疗器械企业迭代产品需要数据都可以在这里购买。不过，数据不像衣服、家电，没有现成的标价。同一份数据用在不同场景，价值可能相差很大。为了让数据产品的交易更加快捷、顺畅，温州数据交易中心联合上海财经大学等机构共同攻关，推出全国首个能够快速给数据产品估价的智能体——“数衡器1.0”。
浙江省温州数据交易中心副总经理 陈琼琼：“数衡器”的“衡”其实就是一个计价衡量，等于是帮数据超市入驻了一杆公平的秤。通过“数衡器”对数据产品进行定价跟分析，从而促进流通跟应用，赋能千行百业。
近年来，浙江不断推动数字经济发展，布局建设数字经济领域全国重点实验室11家，打造智能物联、高端软件等2个万亿级数字产业集群，以及人工智能、集成电路、智能光伏等多个千亿级数字产业集群，数字经济增加值突破5万亿元大关。下一步，如何更好地发挥自身优势，共同推进上海（长三角）国际科技创新中心建设，浙江也制定了明确的工作目标和实施方案。
浙江省副省长 何中伟：加快三省一市高层次人才互认，做深做透科技创新和产业创新深度融合这篇文章，持续放大数字经济先发优势，进一步推动数据、算力、场景跨区域融通共享，建设一流创新生态。
如何让科创成果从实验室走向生产线，也是激活创新价值的关键一环。在安徽创新馆记者看到，从聚变能源、深空探测，到量子信息、高端医疗等，2700多件科创成果在这里集中展示推广。外形有点像安全帽的新产品，可以为抑郁症、帕金森等疾病提供新的治疗方案。这项科创成果来自中国科学技术大学，目前已经与上海等地的医院开展临床合作，并在安徽实现了设备量产和整机制造的落地转化。
安徽省副省长 任清华：安徽构建“从0到1到10到100”一体贯通的创新生态，比如新兴产业科技创新对应用场景的需求注重“真”，就是要真实场景，不是温室“盆景”。为此安徽建立了机会、能力、案例三张清单，实现场景供需精准匹配。聚焦新需求、新领域、新赛道，催生新产品、新服务、新模式。
科创成果转化中遇到对接不畅、专业能力不足等问题怎么办？2025年，安徽在16个地市创新开展了“城市合伙人”机制，让更加懂技术、懂市场、懂政策的科技服务机构成为“城市合伙人”，实行市场化合作运营。
浙江一家企业研发的新产品可以让机器拥有“嗅觉”，精准识别氢气、一氧化碳等气体，但之前在转化中曾遇到区域产业适配等不少难题。在“城市合伙人”机构协助之下，如今，这项成果成功在安徽蚌埠的“中国智能传感谷”落地转化。
截至目前，安徽已经累计培养了5100多名技术经理人，建立了26个市县级科技分市场和4个成果产业化基地，吸纳70多家专业科技服务机构组成科创服务联盟，并与沪苏浙等地建立常态化合作机制。
安徽省副省长 任清华：我们将聚力打造量子信息、聚变能源、深空探测等科创引领高地。另一方面，安徽将积极促进优势互补，安徽已在沪苏浙设立科创飞地近20个。下一步我们将与沪苏浙一起，构建各展所长相互赋能的区域创新共同体，推动创新链、产业链、资金链、人才链深度融合。
放眼全球，具备重大影响力的国际科技创新中心，普遍以城市群、都市圈为载体发展运行。破除行政区划壁垒，构建开放、协同、高效的区域创新体系，能够充分释放区域整体创新潜能，促进科技创新与产业创新深度融合。当前，北京（京津冀）、上海（长三角）、粤港澳大湾区三大国际科技创新中心同步推进扩围提质，正加快打造具有全球影响力的科技创新高地，必将成为我国建设科技强国的关键战略支点。
