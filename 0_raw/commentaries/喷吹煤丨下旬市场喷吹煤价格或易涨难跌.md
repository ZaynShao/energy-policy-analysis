# 喷吹煤丨下旬市场喷吹煤价格或易涨难跌

【导语**】**3月中上旬喷吹煤市场卖方挺价出货，下游钢厂喷吹煤招标采购刚需跟进为主，控制采购节奏，喷吹煤市场上下游博弈，煤价稳中小幅调整；下旬市场交投情绪有升温，卖方挺价情绪愈加强烈，钢厂采购心态亦有转变，预计煤价或易涨难跌。

**3****月份中上旬喷吹煤市场价格稳中小幅调整**

3月份中上旬受国内重要会议影响，喷吹煤市场供需均有受限，卖方挺价出货为主，钢厂压价控制喷吹煤采购节奏，上下游博弈，叠加国际形势不确定性等因素，喷吹煤市场整体交投不温不火，市场喷吹煤价格稳中小幅调整。截至3月23日，山西晋城地区喷吹煤主流成交价850-910元/吨，较上月底收盘价格重心持平；长治地区喷吹煤成交价890-930元/吨，较上月底收盘价格重心涨5元/吨。具体来看：

**煤企坑口累库压力不大，挺价出货为主**

据卓创资讯跟踪数据显示，截止到3月19日，卓创资讯统计的山西晋城、阳泉、长治地区86家无烟煤矿开工率收于93.02%，较上月底开工率下滑1.17个百分点。3月份国内重要会议期间，喷吹煤矿井开工虽维持在高位水平，但煤企生产保安全意识较强，且井下检修矿井较多，煤质及产量均有受限，影响市场煤供应，在下游刚需消耗支撑下，煤企坑口库存水平增幅不及预期，除个别矿井受客户结构或产量高位等因素影响坑口存累库压力外，多数矿井库存压力不大，叠加国际形势紧张，对能源价格存利好情绪支撑，且原煤竞拍价格持续坚挺，成本端有支撑，中上旬喷吹煤市场卖方以挺价出货为主。截止到3月19日，卓创资讯跟踪统计的49座山西晋城地区主流煤矿坑口原煤库存总计98.64万吨，较上月底增15.21万吨，增幅18.23%，较去年同期低22.66万吨，降幅18.68%。

**钢厂心态谨慎，控制喷吹煤采购节奏**

国内重要会议期间，局部地区钢厂高炉限产，喷吹煤刚需消耗支撑减弱，且钢厂盈利情况一般，对喷吹煤后市看空情绪较强，对高价煤接受度不高，喷吹煤招标采购多适量刚需跟进为主，控制喷吹煤库存维持中低位水平，且存主动降库现象，截至3月20日，卓创资讯跟踪统计的20家河北主流钢厂喷吹煤库存平均可用天数7.5天，较上月底减少1天；山东主流钢厂喷吹煤库存可用天数为8天，较上月底减少1.3天。钢厂喷吹煤招标采购积极性一般限制煤价上行空间。

**下旬市场喷吹煤价格或易涨难跌**

供应方面，预计喷吹煤矿井开工仍在较高水平，部分井下检修矿井下旬生产难有恢复，继续影响市场煤供应，且煤企坑口累库压力不大，叠加国际消息及市场情绪烘托，预计喷吹煤市场卖方挺价信心或继续增强；需求方面，伴随相关煤种均偏强运行，钢厂对喷吹煤后市看空情绪变淡，采购积极性有所提升，部分喷吹煤库存水平偏低及近期高炉存复产预期的钢厂补库意向增强。综上，下旬喷吹煤市场在多重因素推动下，交投情绪或有升温，市场喷吹煤价格预计易涨难跌，涨幅或在30元/吨左右。
