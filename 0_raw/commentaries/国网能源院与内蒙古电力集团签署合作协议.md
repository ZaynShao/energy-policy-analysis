# 国网能源院与内蒙古电力集团签署合作协议

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/MMAb68d5jeYqTAUBA9hN76sgZZBN3nNSTAMdzq4uvV7hOEIeXyYrk3Khjtqg4pPpCRftkLNzZic0gaY7Maaks7A/640?wx_fmt=gif)

  

2月3日，国网能源研究院有限公司与内蒙古电力（集团）有限责任公司在内蒙古呼和浩特举行座谈会并签署合作协议。国网能源院董事、党委书记魏玢和内蒙古电力集团总经理、党委副书记张晓虎出席会议并见证协议签署。国网能源院总工程师、党委委员鲁刚，内蒙古电力集团副总经理王立新代表双方签署合作协议。国网能源院党委委员、纪委书记、工会主席董力通（挂职内蒙古电力集团党委委员、副总经理）参加座谈会。

  

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/vYw27Y7HicGc2XCBvC5oGDVRicWI9bMIUxvSapshM150kMIr9icpd3siaesO1fDJ0VxRojgVUmXWxeNHgibFCCXmoC472yWvxXkjzJxRa5jbLGec/640?wx_fmt=png)

  

魏玢对内蒙古电力集团近年来取得的发展成就表示祝贺，希望双方合作再深化、再拓展、再升级，进一步开启合作新篇章，探索创新党建共学、课题共研、实验室共享，创造性落实好合作协议。

  

张晓虎对魏玢一行到访表示欢迎，高度肯定前期交流合作成果，希望与国网能源院共同发挥双方特色优势，聚焦内蒙古电力集团经营管理、电力市场建设、专家人才支撑，共同开展重大课题研究和实验室建设，推动研究成果落地应用，为电网高质量发展做出贡献。

  

座谈会前，魏玢一行到内蒙古大青山实验室、内蒙古电力调控公司、和林格尔新区城市大脑及数字化展示中心实地调研，了解内蒙古电力集团新型电力系统建设、特高压发展、电力市场建设、新能源利用等情况。双方有关部门和人员参加座谈会。
