# 用不起Token的打工人，被隐形降薪

AI的「大火」一来，Token作为计算燃料，正变得和石油一样珍贵。然而AI繁荣下，一种抽象的景象正在程序员间发生：大厂员工Token用不完，网上求问「如何能快速大量消耗」；小公司程序员却在绝地求生，自费买Token，甚至费劲心思在网上挖免费Token上班。
在程序员的世界里，一种新的阶层差异正在悄然形成——有人是「Token中产」，有人是「Token贫困户」。Token贫困，正让普通程序员经历隐形降薪。
我和一位资深「Token贫困户」程序员小安聊了聊，在他眼里，Token是实打实的钱，是一种新型硬通货。「如果一份工作的薪酬年包里包含了附带多少Token配额，对我来讲会很有吸引力。」但他也感觉荒诞，「我用工资买Token，效率给公司提升了，大模型厂商也赚到了钱。只有我在付费上班，工作量也没见少。」
为了能用上最好、最聪明的模型写代码，他遍寻获取便宜Token的方法。从产业链的上游到下游，从官方订阅到第三方中转，从合规渠道到灰色地带，他研究了个遍。每天不花点时间找Token，他就感觉缺了点什么。
以下是他的捡Token实录，其中包含一些灰色地带，阅读时请自行甄别风险，谨防受骗。
天降大Token
午夜0:30，我正准备关电脑睡觉，有人在群里甩出一串字符，配文：「价值200美刀，先到先得。」
这是一个API Key，调用AI模型的「充值卡」。谁先复制走、粘贴到自己的开发工具里，谁就能花掉里面的Token。「扔key」就像发红包，关键看谁手速快，用的速度快。
我困意一下就没了，条件反射般坐直，复制、粘贴、保存，把白天攒下来还没敢跑的一个开源项目代码，一股脑塞进去让AI扫描。几秒钟后，屏幕上开始滚动返回结果。这是近两周我薅到的最大一笔免费Token，「意外之财」让我产生了极短暂的富足感。
等待的间隙，我又在另外几个微信群、技术论坛之间来回切换，试图再捡一些好心人随手散落的「羊毛」。
近半年，我的生活主要围绕找Token展开。在AI的世界里，Token是模型处理信息的最小计量单位，就像「字」或「词」的碎片。当你问AI一个问题，它会把问题切成一小块一小块的Token，再根据上下文预测接下来要生成什么。
社交媒体上有很多帖子在科普什么是Token图 /社交媒体截图
你发给AI的每一个字，AI吐出的每一行代码，最终都会被拆解成Token来运算与计费。Token像电，也像汽油。没有它，大模型再聪明，也就是一个停在路边的发动机。
刚开始我没觉得AI生成的代码多厉害。早期只是拿它解释报错、写几段简短的代码，处理一些简单的问题。直到有一次使用上Claude，一切发生了改变。
当时因为失业，我和朋友接了一个私活。朋友买了一个Cursor付费会员，那是当时名气最大的AI编程工具，我们用它调用Claude Sonnet大模型的早期版本。
怎么形容呢？简直惊为天人。我想好功能，把需求描述扔进去，它一会儿就写完了。以前一个功能起码写几天，现在不到10分钟就生成出来了，我只需要确认、微调一下就能用。原本要做半个月的项目，两三天就完工了。
社区里，大家对Claude的讨论也很狂热。2025年5月，Anthropic发布商用版Claude Code后，开发者社区炸了锅，有人晒出截图，一个完整的后端服务从零到部署只用了 40分钟。
那是我第一次被AI编程的能力震撼，有种发现新大陆，并省了太多事的狂喜。后来用习惯了，就成了重度用户。
我一边感慨生产力飞升，一边也感受到钱包的拮据。Claude Code 处理一次中等规模的代码重构任务，一次对话轻松消耗数10万Token。如果按照我的开发强度，一个月费用轻松超过2000元，挺烧工资的。

Token用不完 VS Token不够用
我现在所在的公司有70多人，技术人员占一半。入职一周后，负责人在会上说，鼓励大家用 AI，能提升效率就不要抗拒新工具，我当时松了一口气。
上一家公司比较老派，对AI的态度很暧昧。领导嘴上说要创新，具体到个人使用，又把用AI和「偷懒」「能力不行」联系起来。那会儿的同事对AI了解不多，也很少用，我最多拿豆包、DeepSeek问点小问题。在那种保守的环境下，用AI多少带着一点愧疚感和偷摸感。
新公司对AI的开放，也是有边界的。每个月拥抱AI的预算是20美元，刚好是大模型最低档套餐的价格。聊胜于无，但确实是杯水车薪。参考Claude Opus 4.7的定价（输入5美元/百万Token，输出25美元/百万Token），一个重度依赖AI的资深程序员，日均消耗轻松破千万Token。20美元的额度，我常常撑不过一周。
大厂有统一采购、企业账号、团队额度，还有安全合规配置。像我待的小公司没有这么完整的体系，常见方式就是每月给一笔额度报销，超了自己想办法。
刚开始，我也从正规渠道买Token。市面上的AI模型订阅是阶梯式收费：国外入门最低20美元/月，中间有100、200美元档位，最高有250美元/月的；国内头部模型 DeepSeek、Kimi的API按量计费，重度使用每月也要五六百元到1000元人民币。
而真正逼着我必须用上好模型的，是工作节奏的变化。AI对生产力的提升，也让公司对我们程序员有了更高、更快的要求。「这事简单，让AI给你跑一个。」过去需要两周的项目，逐渐被压缩到一周，甚至两三天。要想跟上速度，就必须用上更聪明的模型。
图 /《半熟男女》
而更聪明的模型，意味着更贵的Token。有时候用高级模型做一次稍复杂的技术方案讨论，几美元瞬间蒸发。一次项目紧急，我两天就用掉了500美元的额度，所以越来越多的程序员为了高效率工作，必须自费买Token，并把成本放到自己身上。
自费买Token，这个事情其实挺荒诞的。我用工资买Token，效率给公司提升了，大模型厂商也赚到了钱。只有我在付费上班，工作量也没见少。这是一个怪诞的循环。
网上偶尔刷到大厂程序员的吐槽，方向正好相反。他们部门KPI按Token消耗量来排名，谁用得少就要被谈话，所以，大厂程序员的烦恼是如何快速大量消耗Token。用消耗 Token来量化KPI，这不是看谁花钱多就说谁努力吗？确实是「旱的旱死，涝的涝死」。
而这种「涝」，有时候也涝得离谱。你像Meta这样的公司，一个月就能烧掉超60万亿Token，约9亿美元，之前媒体报道其中一个匿名员工一个月消耗了2810亿个Token。Token中产和我们 Token穷人之间，真是存在巨大鸿沟。
Token 对我来说是实打实的钱，是一种新型硬通货。如果一份工作的薪酬年包里包含了入职附带多少Token配额，对我来讲会很有吸引力。再换个角度想，如果我每个月工资有不少是花在AI模型订阅上，那这也是一种隐性降薪吧。
以Token配额为核心的模式，也催生出了新的工作方式。「一人公司」这两年挺火的，一个人加几个AI工具，能干过去一整支团队的活。北上广推出了免费工位、财政补贴、算力券等激励，还有AI产业园和孵化器提出入驻就送工位、送Token。Token 正在成为某种意义上的「新基础设施」。
眼看着Token越来越重要，大家也得出一个商业机密：卖什么都不如卖Token。无论什么时候，淘金卖铲子，才是终极玩法。
AI浪潮来的时候，所有人都在说要重构生产力。但落到我这样的普通程序员身上，重构之前，先要解决燃料问题。车是好车，路也是新路，但我的油箱只够开两公里。
为薅Token，
程序员四处签到、发帖、解题
为了降低买Token的花销，我开始研究获取免费Token的方法，最先发现的是程序员社区里的「公益站」。
公益站，本质上是一种「民间Token中转服务」。有的站长可能是大厂员工，也有人可能只是手里有闲置额度的技术爱好者。他们把用不完的额度搭一个站点放出来，免费给社区里的人调用。公益站多半图的是一种「江湖名声」。在程序员圈子里，能稳定运营一个公益站，是技术实力和慷慨的双重证明，类似于早年论坛时代的「版主」光环。 也有真公益和软广告之间的灰色地带：前期免费，后期变付费；或者借免费引流，再转向收费套餐。
无论公益站的动机如何，对我这种囊中羞涩的程序员来说，能免费的就是好站。
问题是，真正稳定的公益站名额很稀缺，类似抢火车票，不开放注册，只在特定时间放出少量名额，手慢无。我前后关注了八九个站，蹲守过很多「开放注册」的时间点，但最终只成功注册了四五个，常用的就两个。还有一个口碑很好的公益站，我始终没抢到名额，最后在二手市场花30块钱买了个别人抢到的账号。是的，免费的公益站账号，也有人倒卖。
注册成功只是开始。这些公益站大多有自己的「积分系统」，需要签到、发帖、回复换积分，再用积分兑Token。可以理解为用时间换Token，虽然换算下来时薪很低，但性价比还不错，至少不用自己花真金白银。
有些公益站长甚至把密钥藏进「解密游戏」里，把密钥换成游戏术语、热点新闻，或者程序员才懂的Base64编码。一来增加点乐趣，二来防机器人脚本批量薅。我印象最深的一次，有个站长把密钥设定成了一道复杂的算法题，我花了一点时间解出来后，成就感不亚于上学时算出了一道「加分题」。
但光靠公益站的免费额度也不够，我开始在一些交易平台上买「试用账号」。
AI起来后，一批「AI原生」编程工具出现，比如cursor、windsurf。它们把Claude、ChatGPT 等模型直接嵌进开发环境，订阅一个工具就能调用多家模型。这是它们最大的卖点，也是新用户补贴的重福利区，比如有首月免费、新用户大额度赠送等活动，都是烧钱换用户增长的互联网老套路。
我买的试用账号，就来自这些编程平台的活动。卖家是灰产从业者，他们批量注册试用账号，一天能产出成千上万个新账号，再把每个账号自带的免费额度转手卖给我这种散户。一整套流水线作业，效率极高。
图 /闲鱼App截图
试用账号一度是我的最优选。它便宜、稳定，调用的还是工具里的正版模型，体验和正版用户几乎没区别。最便宜的时候，我买过5毛钱一个的，一口气囤了30个。但一旦被平台发现有人薅羊毛，就可能被直接封号。
再往上一层，是「商业中转站」。如果把卖「试用账号」看作零售，那商业中转站就是批发商做的二次加工。灰产把成百上千个零碎试用账号收进一个「号池」，再开发调度系统：你买它10美元套餐，它从池子里挑5个还有余额的账号合起来给你用。
但坑也不少，有时候返回结果明显质量不行，很可能是小模型冒充大模型在回答。还有安全的问题，你上传的代码会经过谁的服务器、保存多久、是否会被二次使用，你完全不知道。每次我贴代码，都会隐匿一些重要信息。
再往下走，还有一批更烫手的Token，便宜得离谱，花样也更多。不仅有蒸馏的，还有逆向的、缓存的、伪装的、套壳的。听起来像黑市「黑话」，但每种套路都有特殊的工艺。
蒸馏是有人把官方大模型的输出当教材，训练出自己的小模型，再以包月三四十块的价格对外出租；逆向是通过破解官方的接口，把对话窗口的免费额度「搬」成API来卖；缓存就是把高频问答的历史结果存起来，遇到相似请求直接回放，省下真实调用的成本；套壳，就是干脆用国产模型顶上去，对外仍以「官方同款」的名义出售。
所以便宜归便宜，水也确实深。
整个Token交易圈，从公益站到试用账号，从低价中转到各种「黑科技」，都游走在合规边缘。账号随时可能被封、服务随时可能中断、数据安全无从保障，甄别起来需要花费很多时间与精力。为了省买Token的钱，我花掉了大量时间。其实，时间也是钱啊。

每天花几小时管理Token余额
除了公益站和中转站，也有一些其他省Token的方法。比如拼车，逻辑也很简单。一个Claude Max 20x 套餐200美元/月，一个人买，5个人一起分摊，每人40美元，大家共用额度。为了防止某个人用太多，有的发起人还会搭一个简易中转站，给每个人分配固定额度。
拼车帖一般会写「自用、不转卖、不违规调用」，因为一旦触发风控，主账号被封，所有人的钱都得打水漂。我没用过这种方式，也感觉不安全，拼车建立在信任之上，发起人要是跑路了也没招儿。
社交媒体上的Token交流帖图 /社交媒体截图
也有一些风险更高的薅Token方法。比如有人花5000块开了一个AI模型的企业账号，用掉80%的额度后，把剩下的API Key扔到论坛，写上「求封号」，让社区里的人任意使用。一块肥肉被扔出来后，立马涌入一大批像我这种如饥似渴找Token的人。
接下来由于短时间内大量异常调用，平台判定违规封号。而针对企业账号，平台有违规额度剩余费用原路退还的规则。所以靠规则漏洞，不少人借机零成本薅取算力资源，最终实现白嫖。但这类操作多了以后，退款难度变大，很多人「赔了夫人又折兵」。
正规资源对很多普通开发者来说太贵、太远。每一个「投机取巧」背后，都有一批预算不够但又必须使用AI的人。
也有人觉得找Token太难，不如省着点用。我看社交媒体上有人教用文言文跟AI对话，因为文言文更短，Token更省。刚开始我也尝试过省Token，比如能自己写两行代码解决的，不让模型生成；复杂问题先理清楚逻辑，或者用免费模型先问，不会一堆乱需求让AI猜；能用小模型解决的问题不碰大模型，毕竟大模型Token单价至少贵一倍。
但时间久了，我意识到省Token并非长久之计，更重要的还是开源。为了更好地开源，我设计了一套Token能源管理体系。
顶层是公司报销的官方Token套餐，这是最稳定也最稀少的资源。我只在项目初期架构规划时使用。规划做好了，执行阶段就可以用便宜的模型，因为任务已经被拆解成了一个个明确的小块。
第二层是公益站的免费额度，我坚持每天按时签到、保持活跃，以获得Token。我用它来做日常开发，比如写功能代码、改bug、跑测试。
第三层是自费购买的试用账号与中转站，这是托底的。公益站不够用，或者临时需要大量Token的时候，才动用自己充的钱。
我每天平均要花1～2 小时去维护这套体系。最忙的一天，我在不同社区之间跳转了将近4个小时，微信和QQ群加起来三四十个，每隔几分钟刷一次新消息。一旦弹出「福利」，几十上百号人会同时扑过去，谁手快谁能切到一块更大的免费蛋糕。
时间久了，我养成了新习惯：就算手头根本没活，只要打开开发工具，第一件事还是去刷一眼Token余额，接着习惯性地点开几个公益站。一天不去捡点什么，心里就空一块。
为了与时俱进地薅Token，我还会花时间研究模型公司最新的活动与政策。比如看到ChatGPT在一些其他国家有首月免费用的活动，我就尝试跑通这个流程。有个周末，我早上9:00坐在电脑前开始研究，一直到晚10点多才终于注册成功一个账号，流程很复杂也非常浪费时间，你需要国外的电话卡、信用卡、邮箱等等，还会面临各种未知因素导致的失败。
过程里我的情绪是起起伏伏的，高兴收到验证码，一会儿又生气地发现页面怎么都跳不过去，一整天下来屁股坐得生疼。有时候懊恼，为了省点钱搞这么累；有时候也有点成就感，万一流程跑通了，我也可以做个公益站悬「Token」济世。
图 /《凡人歌》
最近我解锁了一个新成就，开发了「密钥轮换器」，把自己购买的试用账号汇集到一起，让系统自动检测哪个还有余额、哪个已经失效，自动化切换。它的工作方式更像一支接力队：前一棒跑空了，后一棒自动顶上，我可以不用管它就能自己切换，这在一定程度让我降低了「颠沛流离」的使用感。
也有一些聪明人把这类工具卖给程序员，按周卡、月卡销售的都有。这对本就Token贫困的人，我感觉是雪上加霜。买试用账号本来就是为了省钱，然后为了管理这些账号还要付费。只能说越来越多的从业者，在Token贫困的程序员身上，发现了更多商机。
在开发工具的过程中，我有时候也能产生一点微小的成就感。虽然贫困，但还是在贫困中创造了一点东西。我感觉我和家楼下的拾荒者很像，挑出一些好东西出来，一点点拼成一个还算听话的小系统。那时候，我感觉自己也不是被动地消费AI，或者被AI奴役，而是绕着它，慢慢造出一点属于自己的东西。
Token 贫困，
普通人在新世界的挣扎
不可否认，Token 带来的效率是恐怖的。但用久了也会发现，它也是一种「毒药」。
当你用上了好模型，就没法再用差的。程序员圈给模型排了座次：像Claude Opus 4.7 这种推理能力强、长文本不崩的，被称为「上等毒药」；GPT‑5.5、Gemini 3.1 Pro 算中等毒药；其他小模型只能算下等。座次背后，其实是一种很现实的东西，算力是要花Token买的，而不同的钱，买到的是不同的脑子。

只要吸过「上等毒药」，就再也放不下了，只能去拼车，去捡Token，这个过程很难停下来。我也发现自己心态有一些变化，比如耐心在一点点丢失，因为用过推理能力强的模型，看便宜模型答非所问就会无语；用过Claude Code 生成代码，就会觉得一行行手写像回到农耕时代。
以前自己一行行搓代码攒下来的手感和直觉，如今在不停回车和「继续」中被多少消磨了一些。也有一些老派程序员还在坚持手写、雕琢代码。有人开玩笑说，再过10年，「古法编程」可以直接申报非物质文化遗产了。
刚入行时，我也相信「古法编程」。一个人，一杯咖啡，一个编辑器，把需求拆开，用灵活的手指把代码写顺，把变量名调整到自己满意。那种手感很慢，但扎实。现在我越来越习惯先让AI给一版，我来审。有时候盯着AI生成出来的代码，我会陷入一种短暂的恍惚：它写得比我快，比我整洁。它像一个干活很快但需要我审核的分身，有时聪明得吓人，有时犯错又理直气壮。更多时候，我说不清是我在用它，还是它在慢慢驯化我。
工具总会反过来塑造使用它的人，只是这次AI反向塑造的速度比过去都快。
还有一些时候，我看到了技术演进所带来的差距。以前人和人的差距是学历、公司、工种，现在又多了算力、模型权限、Token额度。每一次技术升级，大家都欢欣鼓舞地说会带来新的革命。但现实里，门槛常常换了一种形式回来。
一个普通程序员想太多也没用，也不是什么在硅谷用AI改变世界的科学家。人们对 AI的展望非常宏大而美好，但对我来说，处境更现实也更尴尬：你不能不用 AI，因为不用就会落后；你也不能尽情用，因为每一次尽情都要付费。被夹在中间的，是大多数像我这样的人。
从移动互联网到AI，程序员这个职业经历了很多次换装，AI这次更彻底。过去我们是产业升级的主力，现在我们是被产业升级裹挟的人。过去一个产品能不能跑起来，取决于代码写得怎么样；现在，一个产品能不能跑起来，取决于能不能买得起足够的Token。
所以Token贫困，并不是一个「穷」字能概括的处境。它是一个普通人在新的世界逻辑里，试图维持体面、维持手艺、维持生活的挣扎。
我记得许多个找Token的夜晚。有时候提前准备了一长串可以用捡来Token做的事，列得整整齐齐；有时候刚买的试用账号才登录上，就焦虑地想什么时候会被封，要快点把额度都用完。
但也有一些夜晚，我捡到一些新Token。眼睛一亮后，我却突然安静下来。屏幕上光标在输入框里一闪一闪，我盯着对话框，模型似乎在等我说话，但我不知道要发给它什么。
