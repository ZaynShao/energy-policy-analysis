# 国网能源院与国网蒙东电力签署合作协议

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/MMAb68d5jeYqTAUBA9hN76sgZZBN3nNSTAMdzq4uvV7hOEIeXyYrk3Khjtqg4pPpCRftkLNzZic0gaY7Maaks7A/640?wx_fmt=gif)

  

2月2日，国网能源研究院有限公司与国网内蒙古东部电力有限公司在内蒙古呼和浩特举行座谈并签署合作协议。国网能源院董事、党委书记魏玢和国网蒙东电力董事长、党委书记毛光辉出席会议并见证协议签署。国网能源院总工程师、党委委员鲁刚，国网蒙东电力副总经理、党委委员张国力代表双方签署合作协议。

  

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/vYw27Y7HicGf18AjxjFZKZg737oiaxDCdnZlxVicJp2ymJzXo0icPwu6mcs6AUAImjIlgJxzTcsB6t59ct5jUHxbibdKV82cwNgqGjMk4YV7RWicg/640?wx_fmt=png)

  

魏玢对蒙东公司近年来取得的发展成就表示钦佩，希望双方持续发挥互补优势，携手实现合作共赢，立足长期交流合作的良好基础，稳步深化党建共学、课题共研、实验室共享、人才共育、智库共建，以创新举措推动合作协议落地见效。

  

毛光辉对魏玢一行到访表示欢迎，对前期交流合作成果予以高度肯定，希望依托国网能源院研究优势，围绕国网蒙东电力新型电力系统落地方案、公司规划、电力市场机制，共同开展重大课题研究和智库建设，推动重大课题研究成果落地转化与实际应用，切实赋能公司与电网高质量发展。

  

座谈会前，魏玢一行到蒙东电力调控中心实地调研，了解内蒙古东部电网发展、特高压建设、新能源发展、电力市场建设运营等情况。双方有关部门和人员参加座谈会。
