# 伊朗宣布关闭霍尔木兹海峡，中方表态

外交部：霍尔木兹海峡通航问题应得到妥善处理。
伊朗方面于当地时间12日凌晨宣布，鉴于外国势力非法干预造成不安全局面，霍尔木兹海峡即日起关闭。对此，外交部发言人林剑13日在例行记者会上答问时表示，霍尔木兹海峡是用于国际航行的海峡，尽早恢复海峡的安全、自由通行符合各方利益。海峡的通航问题应得到妥善处理。中方愿同有关国家和国际社会就此保持沟通。
