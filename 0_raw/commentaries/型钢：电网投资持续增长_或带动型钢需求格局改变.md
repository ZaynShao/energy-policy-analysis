# 型钢：电网投资持续增长 或带动型钢需求格局改变

【导语**】**国内型钢下游消费领域主要集中在钢结构加工、机械制造、电力以及幕墙等行业，而在电力工程中，型钢可作为铁塔、变电站以及设备支架等部件的钢材材料。随着电网投资的持续增长，电力工程项目增多，对型钢需求量增多，同时预计将带动型钢需求格局改变。

目前，国内型钢下游消费领域主要集中在钢结构加工、机械制造、电力以及幕墙等行业，其中，钢结构加工是型钢最大下游消费领域。根据卓创资讯数据统计，2025年型钢国内下游消费量为4045.02万吨，同比2024年减少1027.01万吨。由于钢结构行业发展高位回落，以及幕墙受房地产运行弱势影响，终端整体对型钢需求缩量，但电力、机械等行业需求增多，在一定程度上减缓了型钢需求缩量的程度。

**钢结构占比下降电力占比上升**

对近5年型钢下游消费走势分析来看，2021-2024年钢结构对型钢的需求占比在44%-51%，呈现先增后降走势，而截至2025年底，钢结构在型钢下游市场需求中的份额为44.38%，同比2024年下滑5.05个百分点，较2021年下滑0.60个百分点。依据先前国家“十四五”规划，到2025年底，全国钢结构用量预计将达到1.4亿吨左右，钢结构建筑占新建建筑面积的比例将超过15%。然而近年来国内经济运行速度趋缓，钢结构行业内卷严重，钢结构加工量呈现高位回落趋势，根据钢结构加工量对粗钢产量的占比保持在11%左右进行推算，2025年钢结构加工量或在1.056亿吨左右，对比2024年1.09亿吨左右的加工量呈现回落走势。与此同时，板材等相关替代品价格下降，以及部分中小型钢结构企业退出市场，导致钢结构对型钢需求的拉动效应有所减弱。

而电力电网在型钢需求结构中的占比震荡提升。2025年电力电网在型钢需求结构中的占比为15.91%，相较2021年提升4.68个百分点，同比2024年提升3.28个百分点。电力电网投资与型钢消费紧密相连，近年来，随着电力电网投资的持续增长，对型钢需求量整体增加。根据国家能源局数据，2023年电网工程投资5275亿元，同比增加5.4%，2024年增至6083亿元，而2025年全年来看，全国电网工程建设完成投资为6395亿元‌，同比增长‌5.1%‌‌。随着光伏、风电等绿色电力分别在西北地区和中东部沿海地区快速发展，这些项目的建设对角钢、槽钢及其后续加工产品的需求量正不断上升。

**电网投资继续增长 电力占比或继续提升**

根据国家电网统计数据显示，2026年1-2月，国家电网累计完成固定资产投资757亿元，同比增长80.6%，同时，在电网生产技改和配网基建项目方面，国家电网已开工16万项，共完成投资337.3亿元，同比增长超150%，电网投资继续保持着增长势头。同时，国家电网‌宣布“十五五”期间固定资产投资总额达‌4万亿元‌，较“十四五”期间增长‌40%‌，‌年均投资预计约8000亿元‌‌。除此之外，2026年的国务院政府工作报告中首次提出实施超大规模算电协同等新基建工程，将算电协同上升为国家级战略部署。

型钢作为电力电网建设过程中使用的钢材产品之一，得益于电网投资的持续投入和各地电网工程的增多，预计电力对型钢的需求量将继续增加，特别是Q345或Q355/Q420高强度型钢的使用量或有继续提升空间。同时电力对型钢需求的增多也将带动型钢需求格局的改变，在房地产行业运行筑底、钢结构加工趋弱、机械行业增速放缓的背景下，电力行业的快速发展将带动电力在型钢消费占比继续提升，预计2026年电力对型钢消费量在700万吨左右，消费占比或达16.57%，较2025年消费占比同比提高0.66个百分点。

展望未来5年来看，国内型钢整体需求量预计震荡增加，2030年国内型钢下游消费量预计在4273.61万吨，较2025年增加5.65%。未来5年型钢下游钢结构、幕墙等与房地产建筑相关企业预计对型钢消费量探底回升、整体增量有限，机械、汽车和造船企业受全球经济低速缓慢增长运行、地缘政治、国际贸易摩擦形势不确定等影响或保持低速增长状态，对型钢需求提振效果有限，而电力电网在算力的高速发展带动下预计发展趋势向好、对型钢消费需求增多，预计电力在型钢消费中的占比将得到不断提升。
