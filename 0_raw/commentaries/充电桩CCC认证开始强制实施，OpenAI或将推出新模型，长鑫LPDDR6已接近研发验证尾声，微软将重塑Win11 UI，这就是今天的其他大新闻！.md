充电桩 CCC 认证开始强制实施
（ 快科技 ）8 月 1 日消息，市场监管总局（国家认监委）自今日起对电动汽车供电设备强制实施 CCC 认证管理，重点检测防触电、短路保护、耐火耐燃等安全指标。
自 8 月 1 日起，新生产、新采购且未获得 CCC 认证的电动汽车供电设备，不得出厂、销售、进口或在经营活动中使用。此前已投入运营的存量充电桩无需强制拆除，但后续扩容、更换新桩时必须采购通过 CCC 认证的产品。
对普通车主而言，今后购买家用充电桩、随车充时应重点查看 CCC 标志。新规实施后，行业安全门槛将进一步提高，缺乏检测能力、压缩安全用料的低质厂商将逐步被淘汰。
OpenAI 或将推出新模型
（ 新浪财经 ）8 月 1 日消息，在 GPT-5.6 系列模型降价后，OpenAI 又传出新一代模型动向。据 The Information 报道，OpenAI 正准备推出暂定名为 “ Astra ” 的新模型系列。
报道称，Astra 将重点提升长时间任务执行能力，支持多个 AI Agent 长时间协同工作，并处理复杂项目及高阶数学问题。 Sam Altman 近日已在华盛顿向政策制定者和监管机构演示该模型。
目前 OpenAI 尚未确认 Astra 的正式名称、发布时间及产品归属。外界猜测，其可能最终命名为 GPT-6，也可能作为 GPT-5 系列的新型号推出。
长鑫存储 LPDDR6 已接近研发验证尾声
（ 第一财经 ）8 月 1 日消息，行业人士透露，长鑫存储 LPDDR6 已接近研发验证尾声，距离小批量导入及正式量产更进一步。此前消息称，其 LPDDR6 已向核心客户送样，有望于 2026 年下半年发布并导入量产。
据悉，长鑫首款 LPDDR6 设计速率为 12800 Mbps，颗粒容量 16GB，在低功耗及可靠性等方面较 LPDDR5X 有明显提升。LPDDR 主要应用于手机、平板电脑等移动设备，研发验证需要完成兼容性、稳定性、性能功耗及可靠性等测试。
目前三星、美光、SK 海力士等厂商均在推进 LPDDR6，其中 SK 海力士已完成产品开发验证并计划下半年供货。若长鑫顺利推进量产，有望成为全球较早量产 LPDDR6 的存储厂商之一。
微软将重塑 Win11 UI
（ 快科技 ）8 月 1 日消息，微软正加速推进 Windows 11 UI 现代化改造，逐步使用 WinUI 3 替换部分沿用多年的旧框架和界面，以解决不同 UI 框架混用导致的设计风格不统一问题。
近期，Win11 资源管理器 “ 属性 ” 、文件复制及自动播放等界面已陆续升级至 WinUI 3 。微软还计划改造右键菜单、文件列表、标题栏、搜索，以及任务栏、开始菜单等关键部分。
由于 Windows 需要兼顾大量旧软件和代码的兼容性，UI 改造将采取渐进方式，预计不会在短期内完成。这也是微软全面革新 Win11 的一部分，最终目标是将其打造为 AI 时代的 Agent OS。
