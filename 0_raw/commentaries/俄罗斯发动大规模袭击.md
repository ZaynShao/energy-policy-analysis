# 俄罗斯发动大规模袭击

乌克兰称俄军大规模袭击造成至少9人死亡。
据乌克兰地方官员和乌国家紧急情况局11日发布的消息，10日以来，扎波罗热、第聂伯罗彼得罗夫斯克、基辅等乌克兰多地遭俄军大规模袭击。截至11日上午，袭击已造成至少9人死亡，另有数十人受伤。
乌克兰扎波罗热地区军事行政长官费奥多罗夫11日上午在社交媒体发文称，过去一天，俄军使用导弹、无人机、多管火箭炮和火炮对扎波罗热地区发动大规模袭击，造成6人死亡，52人受伤，部分基础设施遭到破坏。
▲图源：央视新闻客户端
乌国家紧急情况局11日上午在社交媒体发文称，俄军当天凌晨对基辅市发动导弹袭击，该市一处仓库被击中并起火，过火面积达1200平米，袭击造成1人受伤。目前火势已得到控制。
乌国家紧急情况局说，俄军空袭和炮击还导致第聂伯罗彼得罗夫斯克州3人死亡，5人受伤，当地物流设施遭到破坏。
