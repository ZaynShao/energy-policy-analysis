# 5GWh磷酸铁锂+800MWh钒液流电池储能项目中标公示

![image](http://mmbiz.qpic.cn/mmbiz_gif/NKyhsaKovicKztoic7EG3v5AFw4MHpvajcPhBKeD3tELicseb6XCAM8X3orcFBZSQjZGZq1QyPiaUzdia7uTasrmDMA/640?wx_fmt=gif)

3月18日消息，浙江星辰新能科技有限公司（简称“星辰新能”）2026年度5GWh磷酸铁锂储能项目框架协议采购、800MWh全钒液流电池储能项目框架协议采购、220kV/330kV升压站设备框架协议采购中标结果已公示。

其中，5GWh磷酸铁锂电池框架协议采购中的标段1磷酸铁锂电池框架协议采购中标人是：比亚迪汽车工业有限公司、厦门海辰储能科技股份有限公司、瑞浦兰钧能源股份有限公司、广州融捷能源科技有限公司、楚能新能源股份有限公司。

高工储能了解到，星辰新能作为发起此次招标的采购方，是一家以全钒液流为特色的AI+储能科技企业。公司业务涵盖全钒液流储能系统电堆、电解液生产及系统集成、磷酸铁锂储能系统集成，以及储能电站的投资建设、智慧运营与电力交易，并以自主开发的AI智能引擎贯穿“研发-制造-交付-运营”全生命周期，为储能资产的长期稳定运行提供系统性支撑。

2025年，星辰新能在内蒙古蒙西地区集中开发的三座总规模达3GWh的新型独立储能电站已正式并网投运。从开工到全容量并网仅用时半年，这一行业领先的建设速度与交付质量，为其后续大规模布局积累了宝贵经验。

步入2026年，星辰新能战略布局持续提速，项目落地执行力显著增强。公司已正式开启多个大型储能电站项目招标，重点聚焦关键节点城市与高收益区域进行规模化布局。

通过打造一批大容量、高品质的标杆储能资产，星辰新能一方面为电网安全稳定运行提供重要支撑与调节服务，另一方面也构筑起长期、稳定、可持续的现金流基础，有效推动产业资本与金融资本深度协同、高效融合。此次框架采购招标结果的公示，正是其强劲执行力与规模化扩张步伐的集中体现。

在电力市场化改革持续推进的背景下，储能电站运营收益模式正在发生深刻转变：已从过去依靠政府保障、相对稳定的峰谷价差套利，逐步转向由市场供需决定、收益波动更大的电力现货套利，这对储能运营商的专业能力、运营水平与风险把控能力提出了更高要求，电站运营难度显著提升。

面对日趋复杂的市场环境，星辰新能依托自主研发的星辰AI大模型，将人工智能全面融入电站投资、建设、运维、交易全生命周期。一方面，通过大模型实现电站运行状态的毫秒级监测与主动安全预警，显著提升运维效率、降低运营成本；另一方面，依托高精度AI交易算法，对电价进行精准预测，并动态优化充放电策略，实现电力交易的智能化决策。

这套“预测准、响应快、调度优”的智能运营体系，已在2025年并网投运的项目中得到充分验证，能够高效捕捉峰谷价差、电力现货及辅助服务多重收益，最大化提升电站度电收益与资产回报率。

面向未来，星辰新能将持续以技术创新为核心驱动力，依托工程落地与市场化运营经验，不断完善“储存电、管理电、交易电”全链条一体化能力，助力新型电力系统建设，推动储能产业实现更高质量、更可持续的发展。
