# 申报通知|7月23日截止，关于开展2026年第一批余杭区科技服务券兑付的通知

各有关单位：
根据《余杭区深化创新驱动策略财政扶持政策实施细则》（余科信笺〔2025〕1号），现开展2026年第一批余杭区科技服务券兑付工作。现将相关事宜通知如下：
一
申报条件
1. “海创未来”人才项目。该项目由区委组织部（人才办）牵头负责，具体资质以区委组织部（人才办）确认为准；
2. “金钥匙”项目。该项目由未来科技城牵头负责，具体资质以未来科技城确认为准；
3. 创新创业项目。该项目由区商务局牵头负责，具体以区商务局确认为准；
4. 科技成果转化企业和成立不超过五年的国家高新技术企业。该两类对象由区科技局牵头负责，具体资质以区科技局确认为准。

服务券兑付申请
1.企业可根据需求选择服务券平台提供的服务产品，与服务商签订服务合同，合同签订日期需在服务券有效期内（2025年申请的服务券，有效期可追溯至2025年1月1日）；
2.企业需在服务完成后一年内提交兑付申请，符合条件的企业使用政务网账号登录“余省心”企业人才服务平台-余杭区成果转化服务券模块（https://www.ysx.com.cn/yuhangplatform/web-company-pc-v2/index.html#/company-service-ticket/home），点击“我要兑付”，根据要求上传承诺书、服务合同、付款凭证（发票、银行回单、记账凭证）、服务成果等佐证材料（以系统显示为准）。
本次服务券兑付申请时间截止到2026年7月23日；
