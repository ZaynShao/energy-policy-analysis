# 欧洲今夏约8000万人受高温影响，超额死亡人数超25000人

今年6月中旬至8月中旬，欧洲地区有约8000万人被40摄氏度以上高温笼罩。
法国方面当地时间8月20日消息称，最新数据显示，今年6月中旬至8月中旬，欧洲地区有约8000万人被40摄氏度以上高温笼罩。今年以来，欧洲地区同高温有关的超额死亡人数超过25000人。
根据欧洲干旱观测网站和欧盟委员会联合研究中心的数据估算，今年6月中旬至8月中旬，约8000万欧洲民众居住的区域气温曾突破40摄氏度。这些气温突破40摄氏度的区域主要在法国、西班牙、德国和意大利。此外，超过80%的欧洲民众居住的区域气温曾突破35摄氏度。
世界气象组织本月11日发布公报说，西欧经历了有记录以来最热的6月和7月，且这一趋势8月仍在延续。欧洲是全球升温最快的大陆，而部分地区应对高温天气的准备不足。
高温已在欧洲造成超25000例超额死亡
据悉，今年的高温在欧洲多国引发严重干旱与山林大火，造成农作物减产，并已造成超25000例与高温相关的超额死亡。20日，德国官方卫生机构发布的报告说，约有1.4万人死于高温相关原因；法国卫生部门称已记录超7300例与高温相关的超额死亡；西班牙卫生部门称已记录近4500例与高温相关的超额死亡。
