# PVC粉丨2月份出口创历史新高 3月或环比再度提升

【导语**】**由于1月初公布自2026年4月1日起PVC粉出口退税将取消，后续大陆PVC粉出口成本将明显提升。海外需求方1-2月采购大陆PVC粉货源积极性明显提升，随着出口订单在4月1日前集中交付，2月PVC粉出口创历史新高。3月中东地缘政治因素导致海外PVC粉装置出现不可抗力，海外需求方采购大陆PVC粉货源积极性提升，并对大陆FOB价格接受程度提升，预计3月出口量还将环比提升，4月出口量或环比下降。

**出口退税取消公布后，大陆出口接单及交付明显改善**

自1月8日公布PVC粉出口退税将在2026年4月1日取消以来，海外需求方采购大陆货源积极性明显提升，大陆PVC粉企业出口接单自1月中旬开始保持相对较好的状态，至2月中旬由于临近春节假期，部分生产企业出口接单暂停，加之部分生产企业已经完成2-3月出口订单的销售，所以生产企业出口接单在2月中旬及下旬明显转弱，以交付前期订单为主。与之对应的出口待交付量也在1月末2月初达到高位后，在2月整体呈现明显的下降趋势。而1-2月新增的出口订单多数将于2-3月交付，所以随着订单的交付2月国内PVC粉出口量达到历史新高的44.75万吨，对比2025年同期增加35.74%。

**中东局势紧张，大陆PVC粉出口窗口再度打开**

由于中东局势紧张，原油、甲醇等原料开始出现紧张的情况，部分海外PVC粉装置开始出现因不可抗力而降负荷甚至停车的情况，海外需求方采购大陆货源积极性随之提升，对价格的接受程度也同步提升。由于大陆PVC粉企业在出口退税之前可交付的货源数量有限，部分企业已经完成3月份出口接单，所以大陆PVC粉生产企业部分开始上调4月份出口FOB报价（含税），整体价格上涨幅度较大。而后续海外及大陆乙烯法PVC粉装置还有更多降负荷甚至停车的可能性，所以高价也开始陆续被海外需求方接受。截至2026年3月中旬，大陆PVC粉生产企业电石法5型FOB成交价格已涨至最高905美元/吨，对比2月末上涨260美元/吨左右，乙烯法1000型由于后续企业可能出现降负荷的情况，可售货源有限，企业成交价格涨至最高1100美元/吨，对比2月末上涨超过400美元/吨。随着出口价格的较大幅度上涨，虽然国内现货价格也受地缘政治影响而有所上涨，但涨幅不及出口价格，所以国内PVC粉出口套利空间也有明显扩大，生产企业销售4月份出口货源的积极性随之提升，样本企业出口接单量也于3月有所回升。

**3****月出口交付量或刷新高位，4月出口量或有所减少**

由于1-2月份出口订单多数将于2-3月份交付，2月份部分时间段由于港口仓储、短驳等资源较为紧张，出口订单交付效率或不及3月份，从出口待交付量来看，3月下降幅度较2月有所增加，且3月较2月多三个自然日，所以预计3月出口量将较2月环比提升，有望超越50万吨大关，进一步刷新历史高点。

从4月份预期来看，由于中东地缘政治影响持续时间较长，即使后续霍尔木兹海峡解锁，海外PVC粉装置全面恢复也需要一定过程，海外仍存供应缺口，需求方对PVC粉价格接受程度不断提升，大陆生产企业越来越多开始接收4月份交付的出口订单，贸易环节3月整体出口接单也相对偏好。但由于大陆乙烯法PVC粉装置也同样面临原料短缺的风险，部分乙烯法企业出口接单量受到限制，乙烯法出口价格上涨幅度较大也限制了部分海外需求方的采购数量，所以综合来看，预计4月PVC粉出口量或环比3月有所减少，但或仍然维持在相对偏高的水平。
