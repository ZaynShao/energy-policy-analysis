# 日本电商巨头，被曝涉足进攻型无人机

日本乐天集团被曝涉足武器装备，有日本企业取消合作。
▲2024年5月14日，在东京街头，一名男子走过日本乐天集团的一家店铺。新华社/法新社
近日，有媒体曝出日本乐天集团（Rakuten Group）将与德国赫尔辛公司合作，推动后者向日本自卫队供应进攻型无人机。对此，日本一家企业18日对日本乐天集团的这一做法表示反对，并取消入驻日本乐天集团旗下电商平台。
日本媒体近日报道，核心业务包括电商、金融、移动通信等业务的日本乐天集团将与德国赫尔辛公司合作，协助其进攻型无人机进入日本市场，并争取让相关无人机被日本自卫队引进、未来在日本国内实现量产。
▲图为德国赫尔辛公司展出的HX-2进攻型无人机。新华社/法新社
相关消息随即在日本社交媒体引发诸多批评。有日本网民认为，此举背离日本长期以来强调的和平理念，并担忧日企介入武器装备领域可能加剧地区紧张局势。
18日，经营商品目录杂志和购物网站等业务的日本Catalog House公司在官网发表声明说，日本乐天集团涉足进攻型无人机领域的做法与Catalog House的企业理念不符，因此决定停止在日本乐天集团的平台开店。
Catalog House公司声明强调，日本企业应当坚守宪法第九条的不战誓言。
