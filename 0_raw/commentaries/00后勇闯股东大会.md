# 00后勇闯股东大会

股东大会，一个听上去十分高大上的词语。很多人的感知里，坐在大会现场的人，要么是身家千万的霸道总裁，要么是征战华尔街的投行精英，就算是有普通股东入场，那大概也是颇有家底的成功人士。
谁曾想，如今的股东大会，正涌入越来越多的年轻人。
为了参加腾讯的股东大会，林蔚前前后后花了接近2000块，他把这趟旅程总结为“见见世面”，看一眼马化腾就回了本。虽然所见所闻很难作为可供参考的投资信息，但“看看顶尖公司的掌舵人”在他看来也能值回票价。
可如果是第二次去，就要权衡一下是否值得了。
高大上的会场，来了00后
4月，家住上海的陈峰专程请了一天假，去北京参加泡泡玛特的股东大会。
他没想到，身为80后的自己，竟然已经是场子里少见的“中登”。热闹的会场里有几百号人，基本都是年轻的身影。气氛更是活跃，到了提问环节，年轻人们毫不怯场，举手争抢发言机会。
问的问题，更是一个比一个有意思。有人说自己有鼻炎，知道泡泡玛特开始生产小家电了，就问“能不能生产加湿器”；有人最关注当前的“段永平抄底事件”，直接问王宁如何看待段永平，王宁还真的回答了。
陈峰参加的泡泡玛特股东大会。图 / 讲述者提供
这些场景，和陈峰此前参加的股东大会都不太一样，热闹、有趣，股民和公司管理层之间的关系颇为亲近。参加完股东大会，他就选择加仓，又买了几手泡泡玛特的股票——之所以千里迢迢来参加股东大会，就是因为对这家公司抱有好奇，这一遭下来，他觉得自己更理解了一点，究竟是怎么一群人在关注这家年轻的公司，愿意为它的产品付费。
股东大会，一个听上去十分高大上的词语。一提到它，人们总是会联想到上市公司、资本博弈，还有手握股份、为自身权益发声的各路股东。坐在大会现场的人，要么是身家千万的霸道总裁，要么是征战华尔街的投行精英，就算是有普通股东入场，那大概也是颇有家底的成功人士。
谁曾想，如今的股东大会，正涌入越来越多的年轻人。他们买的股票不一定多，有时候买上一手100股就敢来参会，但这群年轻投资者对一家公司的关注和好奇，或许更加浓烈、直接。勇闯股东大会，是他们除了互联网之外，试图进一步了解一家公司、感受一家公司文化的新渠道。
而要论最受年轻人关注的股东大会，往往集中在当下的明星企业。除了泡泡玛特之外，腾讯、小米、老铺黄金等热门科技和消费公司，股东大会会场的年轻人浓度都很高。
在社交平台上，分享这些公司的股东大会见闻自带流量。相比起管理层们如何念出预制好的财务报告，年轻人们更愿意谈论的，是明星企业家的言谈举止，或者现场到底会不会发放盲盒、玩偶作为礼物，甚至——中午到底包不包饭。
另一位专程请假去内蒙古参加股东大会的95后刘磊，一定程度上就是冲着饭去的。一家位于大草原的企业就地取材，请到场的股东们吃顿烤全羊。
某股东大会现场的烤全羊。图 / 社交平台截图
为此，刘磊专门发了个帖子，寻找参会搭子。其中一个网友与他一拍即合。网友平时炒股亏了不少钱，这次纯是为了体验一下高端的宴会，也顺道旅游一趟，这才紧急买入了100股股票，从石家庄出发，坐着高铁直达内蒙古。最后，大家得出的心得是，烤全羊一般，肉不膻，但蘸料一般，以及6月的内蒙古草还没绿，还是得去南方的公司。
对股东大会感兴趣的年轻人多了，花样也越来越多，还有人甚至发明了“代参加”业务，只为帮无法到场的股民们现场行使投票权。毕竟，路途遥远，股东大会都是在工作日召开，参加一次会议，不仅需要钱，还需要假期和时间。
去年，00后林蔚参加了他人生中的第一次股东大会，那时他重仓腾讯，看到券商有通知可以参加，就买了高铁票，从广东到香港，一来一回成本400块，所幸当天来回，不需要再多一笔住宿钱。
但有些钱是为了面子，不得不花。在林蔚想象里，作为互联网企业里大佬级的存在，腾讯的股东大会应该也是个光鲜亮丽的场合，于是，抵达香港之后，他还特意“斥巨资”在优衣库买了一身薄西装，里里外外花了1000多块。他把西装塞进书包里，到了开会的酒店，专门去厕所换上西装后才敢走进去。
不过，等林蔚认真打量会场，才发现这里没有他想象中严肃。现场穿着短裤、运动装的投资者到处都是，还有e人投资者，穿了一身王者荣耀的皮肤去了。提问环节，所有人都活跃起来，兴致勃勃地抛出对马化腾的好奇。让他有些意外的是，这里能找到比他更年轻的人，比如一些在香港念书的大学生，不过20岁出头，就已经有了不短的“股龄”。
网友们分享自己参加腾讯股东大会的见闻。图 / 社交平台截图
“小登”图体验，“中登”图羊毛
进入5月、6月，各家上市公司进入了召开股东大会的高峰期，奔赴一线的投资者们都有自己的打算。
对一些年轻人而言，这是一种难得的体验。比如为参会花了接近2000块的林蔚，就把这趟旅程总结为“见见世面”，看一眼马化腾就回了本。换句话说，他的所见所闻，很难作为可供参考的投资信息，“只是对创始人的兴趣更加浓厚，想看看顶尖公司的掌舵人”。因此，花掉的成本可以接受，他是在为新鲜、有趣的体验付费。但如果是第二次去，他就要权衡一下是否值得了。
参与股东大会是种难得的体验。图 / 讲述者提供
有人图体验，也有不少人纯粹冲着“羊毛”走一遭。前几年，陈峰最爱参加的，其实是茅台的股东大会。那会儿茅台价格飞涨，消费者们很难买到平价茅台。于是，作为资深股东，他连续参加了三年茅台的股东大会。在他看来，换来换去的管理层说什么不重要，“可能对茅台的理解还没有我深”，他更多是冲着酒去的——到场的股东们，有时候能够用1499元一瓶的原价买到飞天茅台，每人限购一箱。陈峰感慨，在那个白酒还是顶流的年代，很多人远赴茅台镇参加股东大会，甚至愿意跟陌生人拼房，就是为了多买几瓶原价的茅台。
陈峰算过账，一箱茅台6瓶，按照每瓶动辄一两千元的溢价，只要去一趟现场，就能净赚小一万元，足够覆盖掉千里迢迢远赴贵州茅台镇的路费，还能赚不少钱。这笔收益不算少，陈峰记得，那时现场气氛好极了，股票在涨，酒能赚钱，到了晚宴，餐桌上就摆着免费的茅台，每个人都很开心。
因此，茅台的股东大会总是个大场面，陈峰参会的三年，“人一年比一年多”，其中不少人都是买了几百万元股票的股民，把这一趟当做旅游来的。而对于远道而来的股东们，企业也很热情，现场会摆出“欢迎股东回家”的旗帜，还有几十位员工夹道欢迎，排场大得让陈峰受宠若惊。
除了这种万元级别的大手笔，一到股东大会密集开启的季节，很多企业都会面向股东发放一些定向“羊毛”。比如江苏镇江的恒顺醋业今年就宣布，在一段时间里持有100股以上股票的股东，都能得到一份大礼包，包含醋、酱油、料酒，主打一个服务好股东的厨房；而宋城演艺、锋尚文化这样的旅游企业，则选择为股东们提供打折或者免费的景点或者演出门票，算是真金白银地丰富股东们的精神世界；还有一些消费品企业，则会把股东大会现场变成食品品鉴会，好吃的、好喝的，一个不少。
陈峰参加的股东大会，甜点颇为丰富。图 / 讲述者提供
捧出这些“羊毛”的，大多是一些实体企业，它们的特点是股息高、分红多，或许未来的发展前景比不上风口浪尖的科创企业，但主打一个收入和预期很稳定，即使股价很难翻倍增长，靠着分红和羊毛，也能拥有自己稳定的股东群体。
而奔赴内蒙古的刘磊观察到，自己就是这类股票少有的年轻股东。这家以乳制品销售为主的企业，大多数股民年纪偏大，都是四五十岁往上的年纪。他们中的很多人，都是偶然看到了这支股票，觉得还不错就一直拿着，不追求热点或者多高的收益、也不追求公司有多大的变革和发展，每年能产出5%的股息就够了。
这些发现，反倒让刘磊更加坚定了自己的投资选择——这的确是一只更吸引中老年股民的“收息股”，他虽然年轻，但却是不太相信“高风险高收益”叙事的那种人。正因如此，在他的仓位里，类似的收息股能占到90%，就图一个稳定的回报，和在场的叔叔阿姨们心态如出一辙。
而互联网公司的羊毛则是罕见的。林蔚记得，自己一进会场，就有人提醒，腾讯的股东大会不提供酒水、点心、矿泉水，更没有自助餐。这意味着没有羊毛可薅，林蔚一度怀疑，是不是就是用这招，“不让太多散户过去凑热闹？”
遇到类似的情况，陈峰的心态总会变得很复杂，一边觉得企业很抠门，来都来了连个小礼物都薅不着，但另一方面，作为股东之一，他又觉得，“别铺张浪费，节约点好”。
股东大会现场。图 / 讲述者提供
对于聪明的股民们来说，除了羊毛之外，他们还总能从中咂摸出一些有用的场外信息。
比如，来一趟股东大会，约莫就能判断出持有这只股票的大多是哪些人。不是所有股东大会都那么轻松、愉悦。年仅20岁的小麦参加的一场股东大会，只能用“尴尬”来形容。那是一场在深圳召开的股东大会，还在读大学的他闲着没事，正好持有这家公司的股票，就壮着胆子去了。还没进门，就先被董秘拦住，一脸疑惑地问他，“你买了多少股都进来了？”小麦脸色一红，大声回答，“我是来履行我的股东义务的！”董秘听笑了，迅速把小麦带进了会场里。
进去之后，小麦才知道为啥自己这么突兀——现场只有两三个散户，其它全是私募基金、大机构的基金经理，每个人正襟危坐，穿着西装、打着领带，不像自己，穿了条短裤走进人群，活像个愣头青。他很快悟了，自己手里的这支股票，或许没有太多散户投资者。
有的企业办会轰轰烈烈，更保守的企业，对于小股东们就要冷淡不少。陈峰参加过一些上海本地企业的股东大会，场地布置得倒很豪华，高大的办公楼，一股老钱风，但真要开会了，甚至不会让散户投资者们进入会议现场，他只能在另一个地点看大屏幕上的管理层念稿。也有一些企业，现场看上去可能比较寒酸，但对投资者们抱有愿意交流的态度。有一回，他去参加一家小企业的股东大会，直接跟管理层同坐一桌吃饭，最开始，他甚至没有认出来董事长，“以为对方是个工作人员或者保安”。
因此，虽然陈峰同样觉得，股东大会不是他决定是否会继续投资的决定因素，但起码能够帮助他更了解一家企业的风格、当前的经营状态等等。比如，陈峰后来没有再去茅台的股东大会了，但隐约也听闻，晚宴桌上的免费茅台没有了，而是摆上了果汁。
靠炒股跟上浪潮的年轻人
越来越多
股市起伏，一直是时代情绪的观察窗口。这两年，从黄金、港股再到AI、半导体，资本市场推动着不同的造富神话轮番上演，一阵接一阵的热闹吸引着越来越多的股民跑步入场。数据不会骗人，火热的5月，A股新开户276.53万户，较去年同期同比增长77.76%。截至5月末，今年新开户达到了1729.68万户，是去年全年的63%。
蠢蠢欲动的年轻人们当然也在其中——扎堆儿参加股东大会，不过是他们热情涌动的缩影。
作为一个刚刚毕业的大学生，小麦无数次盘算过自己的未来。他很认可老家的一句话，“工字不出头”，意思是单靠上班、打工没有出头之日，更不可能实现阶级跨越。创业曾经是改变命运的一种机会，小麦也想过自己要不要去做电商，只是还没等到他毕业，这个行业的红利似乎就已经卷没了。
更多的机会属于AI，但小麦用“恐惧”形容面对AI发展的感觉——他毕业于普通院校，生活在普通家庭，没有高学历，不知道自己该做点什么。很多时候，他一边用着豆包和DeepSeek，一边感觉自己和AI的距离很远。此时，他唯一可复制的行动是，把年初到手的奖金和一些存款积蓄都去买科创板，他形容自己，只能靠炒股来跟上AI的浪潮，“打工是为了养活自己，炒股才是实现阶级跨越和财富自由的手段”。
图 / 《请和我的老公结婚吧》
每个时代都有新的机会。但在这个强调天才叙事的AI时代，普通年轻人似乎只能通过炒股，来跟风口产生微弱的联系。
林蔚则是出身中产家庭年轻人的一个典型样本。他用来投资的百万元资产，都是父母给的。2020年，林蔚家里一套位于一线城市核心地段的老破小被租户退租了，对于这套房子该怎么处理，一家人商量了很久。和父母的想法不一样，林蔚觉得，房子的租售比并不高，房价的涨幅更令人咋舌，最好卖掉。
这成为家里这几年来最正确的一个决定。最开始，对于卖掉房子这件事，父母还颇有不满，但在那之后，房价一直走跌，父母也没话说了。尚未贬值的固定资产，变成了几百万元的现金流，躺进了林蔚的账户，他随之成了家里的“基金经理”，还给妈妈定下了军令状，要用投资来实现“15%的利率，保守估计也有10%”，一旦达到这个目标，4%以上的收益就属于林蔚自己。
林蔚用“捍卫资产”几个字，来解释自己为什么这么重视投资的原因。他很清楚，父母的这笔资产，很大程度是来自老一辈积累下的时代红利，因为他们很幸运，早早在一线城市买了学区房。但这样的叙事却很难在他身上复现，自己就算再工作20年，也不可能有这样的资本积累。更直接一点说，“我不会再想通过上班来实现阶级的进一步跨越，而更多是通过投资，来实现家庭的资产保值”。
时代红利，听上去那么迷人。它的确是很多人改变命运的原因，更在如今被包装成一个令人向往的幻影。身处迷茫的年轻人很难不想要捕捉它、追逐它，尤其是在AI带来巨大变革的时刻。此时，“害怕吃不到一点时代红利”，反而成为年轻人涌入股市的最直接驱动力。
小麦能感觉到周围同龄人的转变。他今年才21岁，因为父母都炒股，所以早早踏足股市，也一直对风险投资持有开放态度。区别是很明显的，读大学期间，小麦学金融，但全班40个人，只有他一个人在认真琢磨投资，其余同学们要么是考公、考研，要么就是奔着进银行、做保险，很少有人真的对投资感兴趣，但现在，买什么股票、基金，已经成为了大家饭桌上的常见话题。
图 / 《使徒行者》
林蔚也是，身边不怎么研究投资的同学把他当成了指南针，纷纷跟他请教怎么买基金、怎么买股票。他觉得这群人似乎有更加浓烈的“FOMO（害怕错过）情绪”，他们不太在乎投资的长远性，只是不想错过当下的风口。比如有个朋友，一口气拿了6万块钱出来全买某个基金，赚了3000块钱就立刻收手了，转头就把到手的盈利兑现了一个新耳机。
但追逐风口，永远是一件充满风险的事情。直到今天，林蔚还没有实现15%收益的大饼。他开玩笑，自己刚好经历了一个完整的“熊市周期”，他2021年开始炒股，重仓的都是当时涨得一骑绝尘的科技股。但在那之后，这些股票就一路下行，比如腾讯，从当年的700多港元每股跌到了现在的400多港元每股，近乎腰斩。
资本市场的风向，变得太快了。如今，最热闹的股市宠儿又已经调换身位，变成了光产业链、半导体。每次妈妈发来信息问最近股票如何，林蔚只能安慰妈妈“别慌”——目前为止，他已经说了很多次“别慌”。不过，相比起一落千丈的房价，一家人又觉得，股市里的亏损似乎还是可以接受。
