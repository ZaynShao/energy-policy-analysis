# 金杜助力迈威生物完成香港联合交易所主板上市，成功实现“A+H”两地上市

![image](https://mmbiz.qpic.cn/mmbiz_jpg/WWbwrx83bPBKMRJ8TSft8oiaPDrHGsj3ToWgC6UfARGopnvUoVnN2Op7ysXDLAYIk0BVI2LHBZKFkusECgicVRgKLB2ESvqKyMQaIwkAZy4ls/640?wx_fmt=jpeg&from=appmsg)

2026年4月28日，迈威（上海）生物科技股份有限公司（迈威生物，股票代码：688062.SH / 2493.HK）完成首次公开发行境外上市外资股（H股）并在香港联合交易所主板挂牌上市，成为首家以“A股科创板+港股18A”方式上市的未盈利生物科技公司。迈威生物本次全球发售股份总数为47,130,200股（未考虑超额配售选择权的行使），发行价格为每股27.64港元，募集资金净额约11.89亿港元。

迈威生物创立于2017年，是聚焦肿瘤、免疫、眼科、骨科等年龄相关疾病的创新生物药领军企业。凭借自主ADC核心技术平台，创下多项国内首创、行业领先的里程碑成果。核心产品9MW2821为全球首款进入宫颈癌III期临床的靶向Nectin-4 ADC，率先斩获双项FDA认证并获国家药监局突破性疗法认定，领跑国内同类靶点研发。

本项目中，金杜律师事务所担任联席保荐人及承销商境内法律顾问，全面深入参与项目各个环节，协助解决项目中遇到的各项复杂问题，以精益求精、高效的服务赢得了客户和其他相关方的高度认可。

本项目的主要负责人为**牟蓬**、**单颖之**、**杨振华**，项目团队成员包括杨梓、杨翰霖等。
