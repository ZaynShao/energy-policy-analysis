# 清华在智谱上赚了300亿

6月22日盘中，智谱股价一度暴涨超40%，市值突破1.3万亿港元。截至收盘，涨幅虽有所回落，但市值仍站稳万亿港元关口。
海外OpenAI、Anthropic等头部大模型公司估值持续向万亿美元靠近的背景下，智谱也率先成为市值突破万亿港元的国产大模型公司。
从市值排名看，智谱已成为恒生科技指数成分股中，仅次于腾讯、阿里的第三大市值公司。放在A股与港股IPO历史中，智谱上市后一年内的最大涨幅，也已跻身前十。
这轮上涨来得颇为突然。行情始于6月15日，短短5个交易日内，智谱股价便实现翻倍。
若将暴涨简单归因于纳入恒生科技指数，解释力并不充分。智谱早在6月8日便已被纳入指数，且初始权重不到1%，相关被动基金在股价大涨前已有较充裕时间完成调仓。
与股价启动时间更为吻合的，是智谱在6月13日发布最新大模型GLM-5.2，并于6月17日宣布开源。性能方面，GLM-5.2在编程能力上已进入全球第一梯队。根据智谱披露，在全球百万用户参与盲测的前端开发评估系统Code Arena中，GLM-5.2排名仅次于Claude Fable 5。
而恰在此时，Claude Fable 5全球暂停访问，也为智谱提供了向全球市场展示模型能力的窗口。
并非简单的“为了解禁拉股价”
IPO后，智谱流通股本仅1735万股，占总股本比例约3.89%，占可在香港交易股本比例约7.84%。若按万得测算的自由流通股本口径（剔除潜在长线资金）计算，智谱自由流通股本仅约504万股。
流通股本稀缺，客观上带来了显著的流动性溢价。少量买盘资金，便可能推动公司市值大幅上行。
过去，市场上不乏类似案例。部分公司在限售股解禁前，借助流通盘占比低的特点推高股价，随后在解禁后高位减持，导致股价快速回落。
但智谱此轮上涨，可能并非仅由这一因素驱动。
从成交额看，3月至5月，智谱月成交额分别达到393亿、353亿、311亿港元；6月截至22日，成交额更已突破600亿港元。年内累计成交额超过2000亿港元。
在如此庞大的成交规模下，单纯依靠“护盘”资金推动股价持续上行，难度极高。因此，智谱上涨更可能是流通股本稀缺+资本市场看好共同作用的结果，而非简单的解禁前拉升。
当然，7月8日，智谱将迎来2568万股限售股解禁，股东主要包括JSC、泰康人寿、广发基金、JinYi Capital等基石投资者。但从基石投资者结构看，最大持股方JSC背后为北京金控等国资背景，JinYi Capital背后为清华大学教育基金会，凌云光则属于产业资本。整体来看，7月初解禁后公司大概率不会面临集中大幅抛售压力。
相比之下，真正值得关注的压力点，或许在2027年1月。此时原始股东持有的1.7亿股限售股将全部解禁。这也可能解释了为何市场仍愿意在短期解禁前大幅买入智谱。

谁赢麻了？
在智谱市值暴涨中，清华大学或许是最大赢家。
清华大学旗下华控技术转移有限公司是智谱的核心发起方之一，目前持有智谱1553.44万股，持股比例约3.5%。
智谱IPO时，清华大学教育基金会出资的JinYi Capital又作为基石投资者，以约5400万港元认购智谱46.87万股，持股比例约0.11%。
合并计算，清华大学相关主体持有智谱股份对应市值已超过380亿港元。
根据清华大学披露，截至2024年底，清华大学资产管理有限公司合并资产总额为121.39亿元，净资产为77.52亿元。智谱股价大涨，无疑将显著抬升清华大学校办企业资产规模。
除清华大学外，美团也是重要受益方。
目前，美团持有智谱1721.73万股，持股比例约3.9%，对应市值约400亿港元。截至2026年一季度，美团净资产约1500亿元人民币，持有的各类权益类资产账面价值约500亿元人民币。随着智谱二季度市值大幅攀升，美团账面权益类资产规模也将进一步增加。
不过，出于谨慎原则，美团对所持智谱股权采用“以公允价值计量且其变动计入其他综合收益”的会计处理方式。因此，智谱股价上涨虽然会提升美团资产端价值，但并不会直接体现在当期利润中。
另一值得关注的是，社保基金也从对智谱的投资中获得丰厚的浮盈。社保基金中关村自主创新投资基金在2024年参与对智谱的多轮融资，目前持股比例约1.5%，持股市值超150亿港元。
智谱市值的走高，本质上是市场在为领先的大模型技术支付溢价。这也表明，无论是智谱还是其他厂商，只要技术能够对标全球顶尖水平，便能赢得资本的青睐。从这一趋势来看，市场可能正在形成一种共识，即未来大模型产业的发展或将演变为“赢家通吃”的局面。
