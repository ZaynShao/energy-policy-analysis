# 首个构网型国标落地！《电力电子装备和系统的构网性能要求及试验方法》正式发布

据标准定义，构网指具备电压源特性的电力装备和系统，可提供必要惯量、短路容量、有功及无功功率，在稳态、动态、暂态多种工况下维持电力电量平衡，保障电网安全稳定运行；电压源特性核心是装备能够自主建立并维持内电势幅值与频率。
标准首次明确定义“自然响应”——即控制干预发生前，装备基于电压源特性对电网扰动的本能输出。惯量、动态电压支撑均以毫秒级快速性为考核基准，如动态无功电流阶跃上升时间不大于90ms、调节时间不大于500ms。
装备需具备弱电网与孤岛电网适应能力及平滑切换能力；频率适应范围明确为45Hz～55Hz；并网点电压相位需按+5°、-5°、+15°、−15°、+60°、−60°分级施加跳变，每级跳变后保持同步运行不低于20s。
首次提出基于能量的惯量支撑等效计算方法，可将电力电子装备的惯量响应折算为等效同步调相机参数。
标准构建了“5.1通用要求+5.2～5.15专项试验”共15项试验体系，覆盖联网/孤岛切换、惯量响应、相位跳变、电压适应、高低穿、宽频阻尼、动态调压、一次调频、黑启动、电能质量等全场景，在弱网、强网、不同功率水平下逐项验证。
