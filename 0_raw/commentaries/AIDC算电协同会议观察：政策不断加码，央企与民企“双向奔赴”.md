# AIDC算电协同会议观察：政策不断加码，央企与民企“双向奔赴”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIvkAen9S6XF07oChz9czicgoxuFy48ObpkYF6lP8W7UtX3eX0rjovr5qDaEmMpATXU3aLFpP4FX0T7uQgQ5gBD1fftqW9rS3wpg/640?wx_fmt=png&from=appmsg)

2026年3月，“算电协同”首次被写入政府工作报告，正式列为国家级新基建重点工程，标志着这一融合数字经济与新型电力系统的新兴赛道，从产业探索正式迈入国家战略层面。

4月21日，国务院新闻办公室举行新闻发布会，工业和信息化部副部长张云明表示，将深入实施算力强基“揭榜”行动，加快技术和产品创新，开展算电协同政策研究和标准制定，促进源网荷储、绿电直连加速落地。

在国家政策不断加码，推动算电协同产业发展的背景下，能源央企与民营企业各司其职、优势互补，正在逐步重塑算力与能源产业格局，成为推动数字经济与绿色经济深度融合的核心引擎，在全球产业竞逐中助力我国抢占发展先机。

其中，中国石化作为场景创新者与综合能源赋能者，于4月7日与上海海兰云签约启动首个海底数据中心项目，采用“海上风电+海底算力”创新模式。

国家电网作为特高压网络枢纽与电力调度主导者，持续深化青海清洁能源和绿色算力调度中心的电力算力融合调度功能，依托智慧双碳大数据平台、能源区块链技术及±800千伏特高压输电网络，实现西部绿电与东部算力跨区精准匹配，构建“电随算动、算随电优”的双向协同模式。目前已推动全省算力产业绿电使用比例达90%以上，年减少碳排放超14万吨，为全国算电协同发展提供可复制的“青海样本”。

大唐集团则是绿电供应标杆与规模化实践者，3月中标宁夏中卫算电协同绿电项目二期260万千瓦（含60万千瓦光伏+200万千瓦风电）；一期项目总规模200万千瓦，其中50万千瓦光伏已于2025年4月全容量并网，剩余150万千瓦风电计划6月全容量并网，一期全部建成后年供绿电约41.4亿千瓦时，为当地算力集群提供稳定绿电支撑。

中国华电作为战略布局者与新业态探索者，在今年一季度将算电协同列为年度重点工作，聚焦绿电直连、零碳算力园区等领域，推进氢基能源与算力设施融合发展。

与此同时，民营企业作为算电协同产业的创新活力担当与场景落地先锋，凭借决策灵活、贴近市场的优势，与央企形成互补协同，成为产业市场化发展的重要力量。

其中，朗新科技4月10日明确表示将深化与上海临港算力中心的合作，依托自研“朗新九功AI能源大模型”拓展更多算电协同业务场景。其与临港算力共建的虚拟电厂平台，已实现国内首次跨省大规模算力集群的自动化、高精度转移，推动算电协同技术向规模化商用迈进。

协鑫能科作为A股“电力 + 算力”双主业龙头，已投运液冷智算中心，且依托自研 “聚星” 虚拟电厂平台，实现电网到用户、设备的秒级联动调度，优化算电协同盈利闭环，推动算力设施节能与调度智能化双重升级。

海博思创作为国内储能系统集成龙头企业，于今年4月公开披露，将加速推进“算电协同”战略，通过实际项目的逐步落地,打通从发电侧到应用侧的全链条服务能力。
