# 张志安｜媒体客户端2.0：从“看新闻”到“用服务”

近日，复旦大学新闻学院教授、复旦发展研究院传播与国家治理研究中心主任张志安，复旦大学新闻学院博士研究生丁超逸在《传媒》2026年第10期刊发文章《特色、深耕、数智化：系统性变革进程中的媒体客户端》。
文章提出，媒体客户端正从资讯供给载体转向智慧服务综合体，未来需在技术应用、评价体系、生态构建上协同突破，实施高质量、差异化发展路径。
全文如下：
媒体客户端是过去十余年主流媒体落实移动优先战略、推进融合转型的关键抓手之一，是媒体降低对商业平台的依赖、提升自主可控传播的关键举措，基本完成了从无到有、从点到面的渠道布局。然而，数量增长并不必然转化为传播效能，部分客户端面临缺用户、缺影响力、缺运营、缺变现能力的困境，同一媒体集团内部“一报一端”“一台一端”的多端并存格局带来资源分散与同质化竞争，引发注意力稀释、品牌辨识度下降等隐忧。
党的二十届三中、四中全会先后部署主流媒体系统性变革，旨在提高主流舆论引导能力，服务国家治理现代化。面对超级互联网平台占据移动传播主导地位、用户注意力日益稀缺的现实境况，媒体客户端的转型发展对舆论引导、用户积累与商业变现的价值更加凸显。
现有研究主要集中于三个方向。一是媒体转型与运营模式研究。聚焦客户端“新闻+政务服务商务”模式创新，以及从内容聚合向资源服务整合的转型趋势。二是客户端的流量获取与数据可见性研究。分析流量逻辑对新闻生产、组织运作的影响，媒体采取内容池搭建、流量分层调控与考核机制优化等，提升客户端的数据可见性及传播效能，以正能量全媒体产品获取大流量。三是技术驱动下的客户端用户行为与使用研究。基于技术接受模型、创新扩散理论等分析框架，分析用户对客户端的使用动机及用户黏性塑造机制，考察算法推荐、界面交互等技术要素对用户信息接触、互动参与行为的影响，反思客户端用户日活不足、留存率偏低等现实困境。
新闻业创新的理论视角为理解媒体客户端建设与转型提供了分析框架。持续式创新是指媒体客户端的内容创新、流程创新。突破式、颠覆式创新则以模式重塑为核心，涉及市场定位、技术采纳、价值实现的全方位变革。早期客户端建设多遵循持续式创新逻辑，将内容进行移动化迁移，未能突破以广告为主体的盈利模式。近年来，部分媒体客户端尝试从商业模式重塑、媒体组织变革出发开展创新，从业者、组织、技术等要素的有机整合形成创新发生的关键机制。
笔者对当前我国新闻媒体客户端的总体特点与发展态势进行概述，聚焦客户端2.0阶段转型及特色定位、深耕本地的战略选择、智能技术的深度应用，以期为推动媒体客户端高质量发展、调适媒体与平台关系、推进主流媒体系统性变革提供参考。
一、优化供给：客户端2.0阶段转型及特色定位
媒体客户端1.0阶段的主要特征是内容聚合、形态更新与流程再造，媒体普遍采取多端布局策略，不同客户端根据自身定位开展内容与运营探索，积累了一定经验。目前，此类分散化布局已触及增长“天花板”，易造成资源重复投入、分散内耗，难以形成传播合力，制约了媒体的舆论引导效能，难以适应新时代媒体转型发展需求。
进入以“多端合一”为特征的媒体客户端2.0阶段，发展重点转向供给侧结构性改革，即在数量上做减法，在定位上做精品，在影响力上做加法，通过资源、用户、功能的聚合实现结构性调整。例如，浙江日报报业集团将旗下“天目新闻”“浙江新闻”“小时新闻”三端合一，推出潮新闻客户端，汇聚全省101个市县媒体资源，在全国范围内产生示范效应。2025年3月，潮新闻启动新一轮改革，将原有25个部门压缩为12个中心和4个职能部门，通过更轻巧的组织体量、更高效的运营机制，促进技术全面赋能内容生产与用户交互。
又如，上海报业集团旗下解放日报、文汇报、新民晚报客户端实现三端合一，推出全新上观新闻客户端。截至2026年3月，上观新闻全网阅读量超36亿次，日均原创发稿量、原创短视频产量分别达到合并前的3倍多和6倍多。作为资源聚合、提质增效的典型探索，上观新闻的成功实践表明，通过多端合并，能够有效破解资源分散、内部消耗的问题，显著提升传播效能。这一案例为行业转型提供了有益借鉴，尤其是在同一集团内部推进多个媒体客户端整合方面，具有重要启示意义。
此外，江苏广播电视总台组建荔枝新闻中心，基于荔枝新闻客户端打造《荔枝特报》《荔枝锐评》等特色品牌栏目，强化舆论引导力。南方报业传媒集团旗下南都新闻客户端与N视频客户端完成整合升级，打造兼具年轻态、视频化、交互性的南都N视频客户端。四川日报报业集团旗下封面新闻客户端12.0版本上线，以个性化端口、智能检索、电商销售等功能实现差异化定位。
从运行逻辑看，媒体客户端与商业平台并不相同。客户端的价值在于内容与服务的公信力，其核心竞争力源于专业采编与权威信息发布机制，不宜以平台流量逻辑作为唯一指标。媒体客户端的整合应基于定位差异与价值贡献进行科学决策，特别是关注多个端之间是否存在定位与内容的重合度，是否对媒体和媒体集团形成价值支撑，是否真正拥有用户与影响力。
二、深耕本地：接入公共服务、实现用户触达
当前，媒体客户端的发展逻辑正从矩阵扩张转向存量优化。在系统性变革的效果评估中，流量兼具指挥棒和度量衡的作用，媒体进一步聚焦日活、月活规模及用户占有率等指标。除了中央级媒体和少数头部省级客户端着力打造全国性、综合性客户端外，大部分媒体正在加速深耕本地，优化客户端的本地服务功能。
以上海报业集团上观新闻为例，2025年改版后深化与“随申办”合作，升级“民声帮办”专区，增加考试查分、健康医疗等模块，用户可便捷使用各类查询、办理、投诉建议等实用功能。深圳报业集团读特客户端构建“100米互联网生态圈”，汇聚出入境办理、社保查询、户政预约等便民功能，让用户足不出户办政务。济南日报报业集团新黄河客户端与12345热线联动，实现紧急事件2小时内派单，办结率超96%。此类实践表明，政务服务接入能有效提升客户端使用频次及时长，提升公共服务效能。
本地生活的精细化运营是客户端深耕本地的延伸。媒体通过整合文旅、教育、票务等在地资源，打造集资讯、服务、社交于一体的综合生态，推动用户从工具使用转向情感依赖。例如，新黄河客户端依托LBS技术将城市划分为500米×500米网格，可在0.8秒内精准提供此刻身边的生活服务资讯。观海融媒整合珠海文旅资源，推出文旅AI大模型，提供游玩攻略、停车、航班等一站式导览，实现本地生活服务的智能化升级。读特客户端与城市重大活动深度绑定，推出“APEC深圳之约”分端，提供多语种城市指南和商旅服务，将客户端嵌入城市国际传播场景，拓展服务边界、创新服务形态。
深耕本地是媒体客户端应对流量焦虑、强化用户黏性、破解同质化竞争的生存策略。这也是媒体嵌入城市治理、践行社会责任、融入国家治理现代化的战略选择。区域媒体客户端通过优化线上互动、推进地方资源整合，能够更好重建“在场”、维系专业权威。对于区域媒体而言，增强其端口作为所在地方运营关键节点的连接能力和发挥其作为地方党媒的政治优势尤为重要。媒体客户端可成为连接政府、市场与本地居民的公共枢纽，在提升传播效能的同时助力基层治理精细化与公共服务。未来，随着数智技术的深化应用，媒体客户端可进一步深耕本地场景、完善服务生态，通过嵌入城市治理与公共服务成为连接媒体与用户的枢纽。
三、数智赋能：AI驱动的场景构建与生态连接
人工智能技术的规模化落地，推动媒体客户端从流程优化迈向场景重构与生态连接。从平台社会迈向数智社会，新兴技术不再只是新闻生产效率赋能的辅助工具，而是重构传播生态、嵌入城市治理的关键变量甚至结构性力量。
数智技术深度嵌入媒体生产、传播、分发全流程，提升客户端的多维适配能力。 中央广播电视总台央视频客户端的AI体育热点分析工具可全天候聚合全网体育信源，通过热榜采集、话题分析、内容策划与价值挖掘，实时生成小时级热点榜单，显著提升内容生产效率与科学性。其上线多款“一键即用”AI轻应用，覆盖生活服务、趣味互动与创意体验等多元场景，推动AI从后台技术走向前台服务。上海报业集团澎湃新闻通过SUPAI平台，支持文章转视频、数字人播报、自动配音等功能，2025年AI视频工具累计生成视频5.1万条，时长约7000分钟，AI视觉生成量超18.5万张，将AI应用能力沉淀为可复用的后台。封面新闻升级“小封”AI助手，植入巴蜀文化大模型，提供本地智能问答与内容生成，强化地域特色内容生产传播能力。
智能交互与个性化推荐有利于强化连接属性，提升客户端用户黏性。山东广播电视台闪电新闻客户端基于智能技术推出“沉浸式刷视频”模式，通过算法精准匹配内容与需求，进行精细化、差异化推送，契合移动端用户碎片化浏览的行为特征。湖南日报新湖南客户端打造“智媒魔方”，用户可根据兴趣偏好自定义内容模块，实现智能化阅读体验。四川日报报业集团川观新闻上线“知己”新闻助手智能体，基于川报集团“智媒云”行业大模型与“若水”省情语料库核心能力，可对长篇报道或政策文件自动生成全文摘要，帮助用户厘清要点。
智能技术的深度应用，正推动客户端探索全域场景构建与多元生态连接，成为系统性变革的重要驱动力。央广网客户端携手华为云发布行业首创的AI数字人资讯24小时直播产品，上线“央广耳闻”探索车载场景内容服务矩阵，推动媒体客户端适配多终端全场景的连接升维。重庆日报报业集团上游新闻客户端以“帮帮”频道为支点，融合科技、公益、商务等场景，开放“上游智媒大模型”技术接口，共建“AI+媒体+城市服务”创新联盟，将技术作为连接用户与城市生活的智能纽带。封面新闻推出“灵知万象”智媒生态共建计划，聚焦数字文化等方向，拓展多维应用场景。澎湃新闻则启动“上海智造”在地文旅融合项目，探索“AI+文旅”跨界融合新模式。
数智技术的深度嵌入，已逐步覆盖越来越多媒体客户端生产、传播与分发全链条，推动内容形态与运营模式持续优化，提升其在复合场景下的适配能力与运营效能。基于生成式人工智能的用户交互、个性化推送等创新应用，正在重构客户端与用户之间的连接逻辑。为此，媒体客户端持续拓展全域服务场景，推动跨领域、跨主体资源协同，尝试构建开放共享、多元共生的智媒生态体系，深化主流媒体系统性变革。
四、结语
当前，媒体客户端已告别“注重下载量与用户数”的粗放扩张阶段，迈入寻求活跃度、价值深耕和高质量发展的新阶段。媒体客户端正由传统新闻资讯供给载体转向融合共生的智慧服务综合体，并进一步与智慧政务深度打通，全面嵌入城市治理体系，成为集信息传播、公共服务、社会互动、数字生活于一体的城市级数字连接核心入口。这一转型，已持续影响媒体的生产逻辑、服务场景与用户关系，推动其在数智社会建设与治理现代化进程中发挥更为关键的枢纽作用，从而深化主流媒体系统性变革，提高主流舆论引导能力。
