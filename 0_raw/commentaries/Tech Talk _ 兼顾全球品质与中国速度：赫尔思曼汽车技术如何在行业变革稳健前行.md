# Tech Talk | 兼顾全球品质与中国速度：赫尔思曼汽车技术如何在行业变革稳健前行

在本期视频中，我们探访了赫尔思曼汽车技术的中国大本营。赫尔思曼汽车技术中国区总经理史建峰先生，向我们分享了企业在行业变革中的发展战略与技术积累。为了快速响应中国汽车市场的快速迭代，赫尔思曼汽车技术打造了“南通中国总部+上海能力中心”的“双核驱动”战略，旨在实现与客户的紧密协同并确保从概念到量产的高效落地。
同时，视频中详细介绍了一系列前沿的汽车连接解决方案，包括PowerStar系列高压连接器、兼顾微型化与高防护等级的SealStar系列连接器，以及采用高精度包覆成型工艺的CDC底盘悬架线束，展示了其在复杂和严苛工况下的稳健连接表现。
赫尔思曼汽车技术是一家拥有60多年历史的奥地利家族企业，致力于为汽车行业提供可靠的定制化连接器和线束解决方案。自2013年扎根中国以来，赫尔思曼在江苏南通构建了集研发、生产、销售、运营及服务于一体的全链条体系，并于2025年正式启用上海能力中心。其产品广泛应用于新能源汽车高压系统、智能底盘、车身电子等关键领域，凭借深厚的技术底蕴和严苛的质量标准，持续为全球及中国本土客户创造价值。
