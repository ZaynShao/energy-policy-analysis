# 两艘外籍船舶在霍尔木兹海峡碰撞，外籍当事人一致同意适用中国法律，由广州海事法院解决双方实体争议

我国法院成功化解发生在霍尔木兹海峡的外轮碰撞纠纷。
记者8月10日从最高人民法院获悉，广州海事法院近日成功审理并调解一起发生在霍尔木兹海峡的外籍船舶碰撞纠纷案，充分展示了中国海事审判的公正专业和高效便捷。
据了解，“阿达琳”轮和“前线老鹰”轮于2025年6月在霍尔木兹海峡附近海域碰撞后，外籍当事人一致同意适用我国法律，由广州海事法院解决双方实体争议。
广州海事法院在扣押船舶、庭前会议、设立基金、开庭审理、技术事实核查、开展司法调解等多个环节，展现了中国海事法院驾驭复杂疑难海事案件的司法能力和高效务实的司法作风，赢得外方当事人的充分信任，最终促成双方达成和解协议，圆满化解该起标的额高达1.8亿元的外轮碰撞事故责任纠纷。
案件审判长、广州海事法院副院长吴贵宁表示，针对双方及分别委托的航海专家对碰撞责任的意见存在较大分歧，案件审理中创新引入海事技术调查官，依托前期封存的核心证据还原碰撞事故经过，清晰界定会遇态势及过错责任，以中立和专业视角最大限度辅助查明案件相关争议事实，为法院公正裁决提供有力支撑。
