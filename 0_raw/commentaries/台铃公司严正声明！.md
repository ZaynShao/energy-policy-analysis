# 台铃公司严正声明！

8月12日，台铃科技股份有限公司发布声明。
近日，有南昌市民反映，台铃电动车南昌市场2025年1月至5月售出的一些电动车在使用满一年左右出现电池“断格”故障——车辆充满电后会毫无征兆瞬间断电、电瓶直接报废。其中，故障车辆所搭载的电池多为“长新”品牌。
面对质疑，台铃南昌总代理否认存在批量故障，并称车辆配套电池均为原厂统一配送，配套品牌不唯一，不清楚为何故障车辆均使用“长新”电池。
8月12日，台铃科技股份有限公司就此事发布声明称，公司第一时间成立专项工作组开展调查。
经核查，报道中涉及的“长新”牌电池系南昌市湾里区鸿浩电动车行售出的假冒台铃原厂电池，系门店私自所为。该“长新”牌电池由江西春兴新能源有限公司生产，公司与该公司没有任何合作，该公司也未获得公司授权，其生产的“长新”牌电池不是台铃公司原厂配套电池。
台铃公司在声明中表示，公司目前仅授权超威、天能两家公司使用台铃标识生产铅酸电池。公司已启动法律程序，严肃追究违法者的法律责任。
公开资料显示，台铃品牌成立于2003年，专注电动自行车、电动摩托车、电动三轮车的全产业链研发、生产与销售。
