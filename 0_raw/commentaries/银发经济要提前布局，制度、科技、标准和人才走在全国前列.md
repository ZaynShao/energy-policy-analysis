# 银发经济要提前布局，制度、科技、标准和人才走在全国前列

//“深聊会”围绕银发经济的产业发展、民生养老保障、机制创新等展开多维度研讨。
随着人口老龄化进程的加速，如何应对老龄化带来的挑战与机遇，已成为全社会共同关注的时代命题。作为2026年深圳民生实事项目重要内容，同时紧扣市政协提案督办工作要求。日前，一场聚焦“大力发展银发经济、培育高精尖产品和高品质服务模式”的深圳市政协“深聊会”在市政协社会科学界别委员工作站举行。政协委员、专家学者以及来自政府相关职能部门的代表齐聚一堂，围绕银发经济的产业发展、民生养老保障、机制创新等展开多维度研讨。与会各方达成共识：发展银发经济，深圳绝不能只做基础性的保障，还要以产业的视角，发挥深圳的科技、金融及湾区联动优势，为全国培育高精尖银发产品，打造可持续、可示范的深圳模式。
发展银发经济纳入“十五五”规划“AI+养老”成深圳特色
国家在顶层设计上高度重视发展银发经济，将其视为提高人民生活品质、经济发展新动能的重要抓手。在此背景之下，探讨深圳如何实现老龄化压力向高质量发展动力的有效转化，正当其时。
事实上，深圳各职能部门早已提前谋划、前瞻布局。市发展改革委相关负责人介绍，深圳组建了全国首家专门从事养老托育工作的国有企业平台——深圳市幸福健康集团；牵头印发实施的《深圳市社区嵌入式服务设施建设工程实施方案》，被纳入国家城市社区嵌入式服务设施建设范围，积极发展社区养老等服务。此外，深圳已将大力发展银发经济纳入深圳“十五五”规划，研究将银发旅游、智能产品开发、养老服务机器人、外骨骼等创新设备研发等场景建设纳入深圳市公共服务“十五五”规划，努力推进解决银发经济发展中的重点难点问题。
科技创新赋能让深圳银发经济更显“硬核”。市科技创新局相关工作人员表示，深圳已在重点产业研发计划中设立具身智能、创新药械、可持续发展等专项，不断强化AI、机器人、创新药械、高端医疗器械技术创新在养老领域的应用，鼓励企业、高校、科研机构联合开展养老领域的技术研发和创新应用，累计资助多体位模块化下肢运动康复机器人、智能护理机器人等一批攻关项目，同时持续完善养老领域科技创新平台载体建设，助力深圳银发经济高质量发展。市工业和信息化局相关工作人员表示，深圳已正式将“AI+养老”纳入人工智能先锋城市战略，也出台了推动《人工智能全域全时全行业应用方案》，提出推动人工智能+养老服务，推动AI技术在养老场景中的规模化落地和全链条融合。在引导深圳养老产品和服务申报国家目录方面，截至目前，深圳已有32家企业43个产品入选国家老年用品推广目录。市民政局在深聊会现场展示了一组深圳银发经济数据：深圳在全国成立了首个银发经济产业链党委，拥有800多家成员；在全省率先规划编制了银发经济统计分类文件，探索解决以往产业边界模糊、统计依据不足的问题。同时，深圳已全面布局“1+N”银发经济产业园体系，建立了1个虚拟市级产业园、15个实体园区，总建筑面积818万平方米，集聚了超500家企业，形成了AI+高端制造、康养机器人集群，总产值超过300亿元。
直面银发经济难点 破解供给与需求错配
在已有成绩面前，与会专家和委员客观地指出了行业当前面临的困境。不少委员和嘉宾认为，银发经济最重要的难点，是资源配置倾向于建设，鼓励生产，忽略了消费端，从而导致了供给与需求的错配。
市政协委员、社会科学界别召集人，综合开发研究院(中国·深圳)院长助理、智库研究与信息部部长、博士后工作站主任郑宇劼表示，“高精尖产品和高品质服务发展的核心在支付上，而不是在开发上。”郑宇劼举例，日本及西方国家的适老化产品普及依靠保险体系支付。“没人买，大企业就不愿意投入。”郑宇劼同时指出，当前不少适老化产品依靠财政补贴推广，但适老化改造等政策落地基层时，普遍存在采购方与实际使用者脱节的问题；加之各部门场景、数据存在壁垒，优质第三方企业难以触达真实老年消费群体。
龙华区政协委员、龙华区政协社会委副主任，厚德世家养老产业创始人董事长马静认为，当前中国养老的主要服务对象仍是30后至50后老人，他们大多对智能设备接受度低、缺乏信任感。不过，她强调，“随着60后至75后逐渐步入老年，未来的适老化和智能化市场将拥有坚实的接受基础，这也是行业需要‘耐心资本’和周期孵化的原因。”
市政协常委，广东省残联副主席，深圳市重塑未来公益基金会、深圳德臻医院发起人张莹莹则从一线视察中观察到，当前市面上的高端科技产品价位偏高，居家老人根本买不起、用不上，研发端“拍脑袋”导致科技产品与老年人真实需求严重错配。
针对这些供需错配、研发偏离的痛点与难点，与会人员纷纷献计献策。张莹莹提出，深圳应率先出台“老年生活痛点需求白皮书”，停止研发人员闭门造车的“伪需求”，并打造银发智能装备孵化专业区和深圳长者数字化服务小程序，让老年人及家属能一下子就点到小程序里面各类型的服务和产品，以及了解一系列的政策支持。她特别指出，深圳市有条件出台领先的适老化产品和养老服务的地方标准，成立第三方权威认证机构，建立深圳银发优选认证标识，这样可以让更多的产品做到精准化和精细化服务。
市政协委员、社会科学界别召集人，深圳市社会组织总会常务副会长，深圳市浙江诸暨商会会长，广东瑞霆律师事务所主任王丽娜同样指出，要建立老年需求清单攻关机制，瞄准“能救命、能省心、能长用”的产品，形成“需求-研发-应用”的完整反馈闭环，让科技成果快速落地。
深圳市幸福健康产业(集团)有限公司副总经理，深圳市养老服务发展促进会会长倪赤丹则分享了养老企业从业者的经验并且提出建议，他也提到推动建设养老服务圳品深圳标准，并表示政府应推动养老服务新基建，“新基建不仅仅是建养老院和长者中心，还有信息化基础设施；要推动连锁化品牌经营，一街道一主体，避免行业碎片化经营。”倪赤丹说，“深圳作为一个年轻城市，在银发经济产业领域中一定要提前布局，在制度引领、科技引领、标准引领和人才引领四个方向，走在全国前列。”
“养老诈骗”手段不断翻新 要以制度堵漏洞 以监管除盲区
产业的腾飞最终必须落脚于高质量的民生体验。现场委员们不仅关注产业发展，还将目光投向了社会关怀、民生普惠和安全法治。
“发展银发经济首先要开放市场活水，引入更多的资源打造银发产业。同时也要守牢养老的安全底线。”市政协委员，市纪委监委案件审理室副主任周洁指出，目前数字化、智能化的“养老诈骗”手段不断翻新，私域直播存在一定监管盲区，消费领域的预付费跑路涉案金额巨大。她呼吁，深圳要以制度堵漏洞、以监管除盲区、以惩戒强震慑，守护夕阳消费安全，让城市养老既有温度更有法度。市政协委员、社会福利界别召集人，深圳市中汇影视文化科技股份有限公司董事长，红树林基金会联合发起人、执行理事长孙莉莉则就消除老年人的数字化壁垒与权益公平提出了三点建议：一是补齐数字适老短板，由社区党群服务中心、老年学堂联动开设老年人AI技能培训，破解老年人“智能不会用、科技不敢用”的问题；二是破除教育圈层壁垒，整改公立老年大学准入门槛高的不公现状，扩容大众化兴趣课程、康养课程、数字技能课程，让老年大学回归公众民生属性，而不是少数群体的专属福利。三是建议依托深圳山海生态、公园绿道、文化场馆资源，定制银发专属文旅线路、周末轻松休闲产品，培育高品质银发文旅与休闲消费业态，激活老年经济新场景。
此外，提升护工的含金量也是委员关切的重点。市政协委员，深圳市隆德慈善基金会发起人，深圳市利得来实业发展有限公司董事长叶文学结合家属切身体会建议，应把“心理康复与情绪管理”纳入护工必修课，全面提升护理员的综合专业水平，为高质量养老产业注入强大的动能。
特别值得一提的是，与会委员与嘉宾都认为，深圳虽为年轻城市，但在银发经济产业领域中也要提前布局。深圳的银发经济不仅仅局限于“兜底养老”的小切口，它是一项涉及科技高度、产业广度、服务温度和民生公平度的系统工程。发展银发经济、培育高精尖产品和高品质服务，深圳具备得天独厚、不可复制的产业优势。这一课题的深入研究，不仅是为深圳探索新路，更应在更高平台上建言献策的“深圳智慧”，为全国养老产业的高质量可持续发展探索出一条科技与民生融合的深圳方案。
# 委员金句
科技赋能研发与残障群体既是民生温度的刻度尺，也是未来经济高质量发展的新蓝海。
　　—张莹莹(市政协常委，广东省残联副主席，深圳市重塑未来公益基金会、深圳德臻医院发起人)　　
在深圳设立银发科技成果转化“试验场”，把社区养老中心，居家养老的家庭适用点，企业产品先试用，再迭代，后推广，真正实现研发一个、落地一个、好用一个。
　　——王丽娜(市政协委员、社会科学界别召集人，深圳市社会组织总会常务副会长，深圳市浙江诸暨商会会长，广东瑞霆律师事务所主任)　　
银发经济不只兜底养老，立足小切口，解决老人急难愁盼，打造兼具科技高度、服务温度、民生公平度的系统民生工程。
　　——孙莉莉(市政协委员、社会福利界别召集人，深圳市中汇影视文化科技股份有限公司董事长，红树林基金会联合发起人、执行理事长)　　
大力发展银发经济，就是让庞大的老人群体继续走上社会，让他们的生活工作更加丰富多彩。萝卜白菜各有所爱，让他们更好地发光发亮。
　　——叶文学(市政协委员，深圳市隆德慈善基金会发起人，深圳市利得来实业发展有限公司董事长)　　
深圳作为全国最年轻的超大型城市，我们在“十五五”规划中把银发经济列入到我们培育新的经济形态的重要举措，这意味着深圳不仅仅是在被动应对我们的养老保障，而是主动地开发银发经济的价值。深圳的目标不仅仅是建设最宜老的城市，做好本地居民的养老保障，更重要的是我们要成为全国甚至全球的高精尖银发产品研发和先进制造的中心。我们要让全国的老人用深圳的产品。用深圳的科技、深圳的创新，让全国的老人过上更有质量、更有尊严的晚年生活。
　　——郑宇劼(市政协委员、社会科学界别召集人，综合开发研究院(中国·深圳)院长助理、智库研究与信息部部长、博士后工作站主任)
