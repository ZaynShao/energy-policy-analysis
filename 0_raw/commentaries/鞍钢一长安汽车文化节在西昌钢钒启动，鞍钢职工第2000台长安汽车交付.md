# 鞍钢一长安汽车文化节在西昌钢钒启动，鞍钢职工第2000台长安汽车交付

7月15日，“钢骨‘智’造・长‘鞍’同行”鞍钢—长安汽车文化节启动仪式暨鞍钢职工购买长安汽车第2000台交车活动，在西昌钢钒举行。作为鞍钢集团与中国长安汽车深化产业链协同、惠及一线职工的重要举措，本次活动标志着双方合作迈入新阶段。启动仪式前，鞍钢集团与中国长安汽车举行座谈。双方围绕完善协同机制、拓宽合作领域、深挖产业链潜能等进行深入交流，表示将进一步搭建常态化交流平台，筑牢同心共进的情感纽带，共同推动产业链深度融合，以品牌价值跃升赋能产业转型升级，携手服务国家产业发展大局。启动仪式上，攀钢钒、中国长安汽车大客户业务部负责人分别致辞，并为鞍钢职工第2000台长安汽车购车代表，颁发专属纪念钥匙与定制纪念车模。双方表示，多年来，鞍钢集团持续向中国长安汽车供应高品质车用钢材，产品应用于多款主力热销车型，为中国长安汽车高端化、智能化、新能源转型提供了坚实的材料支撑。本次文化节是双方打造央企相融共生、协同发展标杆的实践载体，将以本次活动为起点，持续探索互利共赢新路径。仪式结束后，现场人员共同品鉴车型并试乘体验。据悉，本次文化节将在全国15座城市的鞍钢生产基地及钢加工配送中心巡回开展，中国长安将携全系车型进厂区，同步推出鞍钢职工专属购车补贴和一站式落地服务，职工可在现场品鉴、试驾并咨询专属福利。当日，双方代表还深入西昌钢钒热轧产线及智慧管控中心实地调研，详细了解攀钢高强汽车钢研发生产进展。鞍钢集团汽车材料中心、攀钢国贸、重庆攀中伊红，以及中国长安汽车大客户业务部、采购中心、工会等相关负责人参加上述活动。
