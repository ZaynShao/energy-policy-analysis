# 中国电价凭什么能“稳”住？

同样是14亿人口大国，为何中国能保障基本供电，而印度在热浪中频频陷入大停电？答案指向了电网基础设施与系统韧性的根本差异。
但“不停电”只是及格线。真正考验一个国家能源治理能力的，是在保障可靠供应的同时，让绝大多数民众——无论城市还是乡村、东部还是西部——都能以可负担的价格用上电。
中国做到了。居民电价十几年未涨，第一梯度电价维持在五毛多，远低于欧美发达国家水平。这并非市场失灵，更非财政“暗补”，而是一套贯穿发、输、配、用全链条的系统性成本控制与价格稳定机制。
降成本：源头多项同时发力
电价稳定的根基，不在价格端，而在生产端。中国在三个关键领域持续“死磕”成本，形成了独特的降本组合拳。
这其中，化石能源把效率逼到极致。燃煤发电长期是中国电力的“压舱石”。但今天的火电厂，早已不是二三十年前的老旧锅炉。国内存量及新增合规火电装机中，超超临界及以上高效机组占比高达92.6%，供电煤耗普遍压降至280克标准煤/千瓦时以下，全球领先。火电依托稳定的低煤耗运行，度电成本长期控制在较低水平，成为整个电价体系的“稳定锚”。
国能浙江公司宁海电厂6台机组火力全开丨童俊霖 董廷廷 摄
新能源则用规模砸出价格重塑。如果说火电稳住下限，新能源则不断拉低上限。过去十五年，中国风电和光伏的成本经历断崖式下降：风电由2010年约0.8元/度降至2025年约0.25元/度，下降近三分之二；光伏由2010年约4元/度以上下降至2025年不足0.2元/度，降幅超过二十倍。
这绝非技术奇迹，而是工业规模的必然结果。中国将光伏和风电做成全球最大的产业链——从硅料、电池片、组件到整机装备，全球70%—80%的产能集中在中国。产量越大，技术迭代越快，单瓦成本越低。这一“规模—成本”正反馈循环，至今仍在加速。
降损失：电网损耗省到极致
一个容易被忽视的维度是输配电损耗。电从发电厂送到用户终端，沿途会有自然损耗。中国电力企业联合会发布的《中国电力行业年度发展报告2025》显示，2024年全国电网线损率4.36%，同比降低0.18个百分点，全球领先。浙江则更低。相比之下，印度这一数字高达20%以上，部分地区甚至超过30%。这意味着，每发100度电，印度在路上至少损失20度，这些损耗最终都会摊入终端电价。
中国之所以能做到低损耗，靠的是一系列技术集成：特高压输电大幅降低远距离送电损失，智能电网调度优化潮流分布，无功补偿、动态电压调节等精细化手段广泛应用于各级电网。每一度电的“旅程”都被精心规划。
全国购：改革红利加速释放
当前，我国电力市场建设持续深化，电力中长期、辅助服务、现货等各种市场、各类品种逐渐走向全国。涵盖电力市场各品种各环节的“1+6”基础规则体系初步构建完成，为电力商品自由流动统一“度量衡”，进一步激发市场活力。
借助全国统一电力大市场，西北的风电、光伏点亮大湾区的灯光，西南的水电奔涌进长三角的工厂，电力资源突破地域限制实现“全国购”。一个“统一开放、竞争有序、多级协同”的电力市场体系加速从蓝图走向现实。
甘浙特高压导线如银龙般穿越浙西群山，将西北清洁能源输送至江南腹地丨黄辉 摄
这套电力市场体系实现电力资源在全国更大范围内的优化配置，通过市场充分竞争，实现电价稳中有降，最终受益的是经营主体，是广大电力用户。
源头提效降本、电网减少损耗、市场优化配置三管齐下，构成电价稳中有降的“铁三角”。
稳价格：居民端“不动”，工商业端“向下”
生产端每省下一分钱，最终都传导到价格上。中国的电价分配策略呈现出清晰的“双轨”特征：居民侧长期稳定，工商业侧持续下降。
在中国，居民电价十几年不涨，体现了“民生定力”。按照电力市场的一般规律，居民用户分散、负荷波动大、供电成本高，理应比工商业用户支付更高电价。然而，中国居民用电第一档电价长期维持在每度电五毛多的水平，远低于美国、欧洲等发达国家。对于困难群众，各地也有相应的电费减免或补贴政策。这一价格并非由市场自发形成，而是明确的“保民生优先”政策导向的结果。
从2000年代中期至今，居民电价基本未作大幅上调。在能源价格、人工成本普遍上涨的背景下，这一“稳”字来之不易。
相较居民电价，工商业电价稳中有降形成“神助攻”。与居民电价稳定并行的是，工商业电价在近年持续走低。2019年起，中国将电网环节增值税下调等红利全部让利给终端企业。2025年，国家推动新能源全面入市，绿电交易规模扩大，进一步拉低了工商业用户的平均购电成本。
国网江山市供电公司员工走访企业，与企业负责人一起探讨节能减排方案丨周炫炫 摄
至此，形成了一条独特的电价路径：居民端：稳着不动，甚至享受隐性补贴；工商业端：不升反降，持续释放改革红利。
生产端降下来的成本，没有被截留在中间环节，而是流向两个终端——老百姓的日常用电和企业的经营成本。这正是中国电价政策区别于许多国家的核心特征：降本成果的可及性与公平性。
更难得的是：电价在降，其他指标却在全面上升
通常，压住价格可能伴随服务质量下降或绿色转型滞后。但中国电力系统呈现出一组“逆向”指标：
可靠性持续提升：全国供电可靠率从本世纪初的不足99%提升至2024年的99.924%，用户平均停电时间6.71小时/户。在浙江，年户均停电时间已经降至18分钟，农村供电可靠性也已经达到全国城市平均水平。杭州，常住人口超过1200万的超大城市，2025年户均年停电时间仅3.15分钟。这个数字全国最优、国际领先，达到东京、伦敦等国际都市同等水平。事实上，多数停电已被压缩至毫秒级自动复电，用户几乎无感知。
国网建德市供电公司员工运用带电作业方式更换10千伏寿昌线智能开关，保障周边用户可靠用电丨唐衎 摄
服务不断优化：95598热线、网上国网等渠道让用电服务触手可及，故障抢修效率大幅提高。“三零”“三省”服务全面落地：低压用电“零投资”覆盖160千瓦及以下民营经济组织，杭州、宁波等重点城市放宽至200千瓦，居民与小微企业彻底告别“花钱办电”时代，2025年累计为各类用户节省用电成本超28.98亿元。高压用户接入工程费用分担机制执行率达100%，效率与实惠触手可及。
绿色转型加速：截至2025年底，全国新能源装机突破17亿千瓦，超过火电成为第一大电源。以浙江为例，省外输入电力中清洁电占比超过54%，来自溪洛渡、白鹤滩的水电，以及新疆戈壁滩的风光，正点亮东部沿海的万家灯火。而在省内，截至2025年底，浙江清洁能源装机10054万千瓦，占比达到56.8%。

中国电力系统在“降成本、保民生、促转型”三个目标之间，找到了一条动态平衡的路径。它不是零和博弈，而是通过系统优化实现多赢。
中国电价“人人用得起”的故事，不是市场奇迹，也不单是财政补贴的简单堆砌。它的底层逻辑是，生产端降本、电网侧降损、市场侧降价，三线并进压低度电成本；分配端居民稳价保民生、工商业降价促发展，降本红利精准传导；系统端可靠性与绿色转型同步推进，不因压价而牺牲服务与未来。
所以，下次你打开空调，吹着26度的凉风，不必将其视为理所当然。这套“便宜又可靠”的电力体系，是中国几十年持续投入、技术追赶、体制创新的沉淀。它不是天赋使然，而是一张张电网架起来的，一项项效率提上来的，一代代人干出来的。
