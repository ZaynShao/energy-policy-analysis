# 北京朝阳丨扩大智能网联新能源汽车产业规模

《征求意见》明确：
扩大智能网联新能源汽车产业规模：持续完善产业链生态体系，做大智能网联新能源汽车产业集群规模。依托新质生产力融合示范先导区赋能优势，引导企业布局区域运营总部与科创研发总部。培育壮大智能核心部件、系统解决方案等领域龙头企业，深化与平原新城协同联动，持续完善全链条产业协同发展生态。大力发展新能源汽车消费，支持既有汽车总部企业设立交付中心、结算中心等机构，拓展实体业务领域。依托王四营、金盏、小红门、十八里店等地区，打造新能源汽车产业集聚区，挖掘二手车、汽车租赁、共享等后市场潜力，拓展汽车金融、文化、赛事等后市场消费场景，构建高端、智能、绿色汽车服务生态。
到2035年，绿色产业体系基本建成，智能网联新能源汽车等重点产业实现能级跃升。
打造绿色服务产业高地，发展绿智能网联新能源汽车等特色产业。
优化绿色产品进出口结构，扩大新能源汽车出口规模。
引导企业深耕车网互动(V2G)等新兴智慧能源服务业态。
加强跨省协作，聚焦新能源汽车等绿色产品生产制造，推动与津冀地区产业协同联动。
