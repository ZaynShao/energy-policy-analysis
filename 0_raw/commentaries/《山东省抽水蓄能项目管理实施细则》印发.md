# 《山东省抽水蓄能项目管理实施细则》印发

电网企业要严格执行国家价格主管部门关于抽水蓄能电价机制的有关规定，开展电费结算工作。国家能源局派出机构加强抽水蓄能电站调度运行监管，在《山东省电力并网运行管理实施细则》《山东省电力辅助服务管理实施细则》中明确对抽水蓄能电站调度运行考核指标、标准及相关措施和要求，督促电网企业规范执行考核、信息披露等相关工作。
