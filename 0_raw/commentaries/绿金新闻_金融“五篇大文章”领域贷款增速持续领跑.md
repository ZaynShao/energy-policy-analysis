# 绿金新闻 | 金融“五篇大文章”领域贷款增速持续领跑

近日，六大国有银行相继披露2025年度业绩报告。作为我国金融体系的核心支柱和服务实体经济的主力军，六大行信贷投放的总量、结构与方向备受市场关注。

  

“从年报数据来看，国有大行信贷投放呈现出总量稳、结构优、导向强的特征。在复杂的宏观环境下，国有大行资产规模持续扩张，信贷作为核心资产保持稳定增长态势，彰显出较强的逆周期调节能力，为经济社会高质量发展提供了坚实金融支撑。”苏商银行特约研究员高政扬在接受《金融时报》记者采访时表示。

  

“十五五”规划纲要提出，提升金融服务实体经济质效，大力发展科技金融、绿色金融、普惠金融、养老金融、数字金融，加强对重大战略、重点领域和薄弱环节的优质金融服务。

  

2026年，为支持“十五五”开好局、起好步，国有大行信贷投放将有怎样的规划？信贷投放节奏和结构如何？

  

信贷投放总量稳步增长

  

总体来看，2025年，国有大行加大对实体经济的信贷投放力度。据记者统计，工行、农行、中行、建行、交行、邮储银行六大国有银行当年新增贷款超9万亿元。

  

年报显示，截至2025年末，工商银行全年新增信贷投放、债券投资合计4.8万亿元，创历史新高；农业银行全年贷款新增2.23万亿元，继续领先同业；中国银行境内人民币贷款新增1.81万亿元，增幅9.90%；建设银行贷款总量稳定增长，全部贷款增速为7.47%，高于全社会贷款平均增速1个百分点以上。

  

“在总量引领的同时，我们更加注重投放结构和节奏的优化，制造业、战略性新兴产业、绿色、普惠等重点领域保持较快增长，国有大行服务实体经济主力军的作用得到有力发挥。”工商银行行长刘珺在业绩发布会上表示。

  

“2025年，农行积极贯彻落实国家重大战略，精准对接实体经济融资需求，贷款投放呈现‘总量稳中有进，结构持续优化’的特征。‘三农’和乡村振兴服务更精准，‘扩内需’融资力度更加强劲，‘五篇大文章’金融服务提质增效。”农业银行行长王志恒表示。

  

高政扬对此分析认为，纵观六大行年报中的信贷数据，信贷结构明显向国家重点领域倾斜，金融“五篇大文章”相关领域贷款多数实现两位数以上的较快增长；银行对高端装备、高科技等领域的支持力度也逐步加大，金融资源正加速向新质生产力等国家战略领域集聚。

  

信贷结构持续优化

  

记者梳理各行年报发现，信贷结构优化的成效尤为显著，金融“五篇大文章”领域贷款增速持续领跑。

  

“我们服务科技创新的手段更加完善，向新提质的劲头更足了。”据工商银行副行长王景武介绍，工行制定科技金融发展规划，支持优化提升传统产业、培育壮大新兴产业和未来产业；创新推出颠覆性技术专项贷、积分贷、研发贷、知识产权融资等专属产品，为客户提供更加多元的融资支持。

  

年报数据显示，截至2025年末，工行科技贷款余额6万亿元，专精特新“小巨人”企业有贷户覆盖率超50%，较年初增加22个百分点；承销科创债超1000亿元。

  

据建设银行行长张毅介绍，该行信贷结构持续优化，2025年，建行在金融“五篇大文章”领域贷款均实现两位数增长。其中，科技贷款余额突破5万亿元，增速18.91%，为科技创新提供有力金融支撑；绿色贷款余额达到6万亿元，增速20.54%，助力实现“双碳”目标；普惠贷款余额达到3.83万亿元，增速12.37%，持续拓宽客户覆盖面；养老产业、数字经济核心产业贷款增速分别达到53.06%和18.70%，综合金融服务持续深化。

  

“从信贷结构来看，2026年银行信贷资源有望继续向科技创新、先进制造、绿色转型、普惠小微等重点领域倾斜。同时，在提振消费政策导向下，银行将持续加大对个人经营贷款、个人消费贷款的支持力度。”高政扬表示。

  

2026年六大行信贷路线图明确

  

站在“十五五”新起点上，国有大行围绕实体经济需求、货币政策导向以及全行经营实际，对信贷投放作出规划安排。

  

据王景武介绍，工商银行将聚焦“十五五”规划纲要109项重大工程项目，积极对接“两重”“两新”、新型政策性金融工具、中央预算内投资等清单，重点支持国家综合立体交通网、新型能源体系、现代化水网、新型基础设施、农业农村现代化、城市更新等重大工程项目建设，助力构建现代化基础设施体系。

  

中国银行副行长刘承钢表示，2026年，中国银行将坚持高质量发展要求，继续发挥资本对信贷资源配置的导向性作用，合理进行信贷投放，一是保持信贷总量平稳均衡增长；二是持续优化信贷结构与投向；三是坚持全球化战略核心地位；四是落实好财政金融协同促内需一揽子政策。

  

邮储银行行长芦苇表示，今年，该行将进一步优化信贷结构，并保持总量的稳健。“贷款年增目标和前期增量基本持平，增速高于行业平均约1个百分点。以资本回报为标尺，‘增高去低’，压降低价资产，向‘五篇大文章’、县域等重点领域加大投放，用足贴息、再贷款等政策红利，提高贷款的综合收益。”芦苇说。

  

值得一提的是，今年的《政府工作报告》将“着力建设强大国内市场”列为今年工作任务之首。多家银行在业绩发布会上透露，将锚定拓展内需增长新空间，结合自身优势，围绕重点领域持续加码金融支持。

  

工商银行将围绕现代化产业体系建设提供更适配的金融服务；农业银行将瞄准乡村振兴重点领域和项目服务发力，力争今年县域贷款净增超万亿元，农户贷款余额突破2万亿元；中行将继续开展“万千百亿”惠民行动；建行将重点支持汽车、家电等商品消费和文旅、康养等服务消费。

  

专家普遍认为，整体来看，2026年，在政策引领下，银行信贷有望保持稳健的投放力度，为信贷规模的平稳增长提供支撑。同时，信贷投放有望延续规模稳健、结构优化的特征，进一步凸显高质量发展的核心导向。
