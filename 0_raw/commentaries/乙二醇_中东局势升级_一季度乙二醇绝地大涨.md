# 乙二醇 | 中东局势升级 一季度乙二醇绝地大涨

**导语**

受到中东局势影响，3月份开始乙二醇一改之前的颓势，出现绝地反弹走势，单月涨升近30%，助力乙二醇一季度创近年来最大涨幅。  

| 

乙二醇主流市场月k线及基差走势图 |
| 

![[隆众聚焦] ：中东局势升级 一季度乙二醇绝地大涨](https://mmbiz.qpic.cn/sz_mmbiz_png/jB59BB1tXAV91vmDj9aKFj6KXFtGWJ2Ipd7v0N2h3JzCz5lOOvXAAYWL9iakffBSVSwJJVCtFMZ5oWSVutqPRA1St9rTmPnKYWgNKT4R3viao/640?wx_fmt=png&from=appmsg) |

从上图可以看到，进入2025年三季度以来，乙二醇出现了持续下跌走势，2025年12月，市场价格跌至3500附近价格，刷新五年新低后虽然有所企稳，但是市场积弱难返，2026年1-2月仍然以底部整理为主，2月底，美伊以冲突加剧，伊朗封闭霍尔木兹海峡，在此影响下，乙二醇从底部绝地反弹，月K线以一根巨大阳线收盘。

| 

乙二醇产能变化趋势图 |
| 

![[隆众聚焦] ：中东局势升级 一季度乙二醇绝地大涨](https://mmbiz.qpic.cn/mmbiz_png/jB59BB1tXAWNKZiaFaesXNdCiavHVLwjLs7Q6ibAGibp2OPIeRib2dUbYkmY5P3JckorHOWsXyBCDPibpsjDia5ozAia4KzbbvkYq0FEBR4pCM0EWQw/640?wx_fmt=png&from=appmsg) |

1-2月市场维持低迷主要逻辑是供应端持续压力，国内巴斯夫一体化装置正常投产后，国内产能增加至3082万吨，而主要下游聚酯正好处于春节前后传统淡季，导致供需错配，市场积弱难返，然而3月份地缘冲突彻底扭转了供需格局。

| 

乙二醇开工率趋势图 |
| 

![[隆众聚焦] ：中东局势升级 一季度乙二醇绝地大涨](https://mmbiz.qpic.cn/mmbiz_png/jB59BB1tXAWycU0x2epMPfUoxKeITsAmLPkEcdfSuxMoXA4WllPjY9En1z0grnTCAGohkHmMqp3lTFAHDUb6V3Vx8icaq4g8Iib57sib4FmmMA/640?wx_fmt=png&from=appmsg) |

国产方面，中东原油出口受阻，导致部分炼化企业原料供应紧张，被动削减开工率，下游烯烃产量减少情况下，工厂估先保供效益好的产品，而乙二醇利润来到历史低点，开工率顺势下降明显，3月份国产月均开工率下降至5.27%至59.62%，石油制受影响较大，开工率下滑8.02%至57.32%。

| 

2025年中国乙二醇主要贸易伙伴进口占比图 |
| 

![[隆众聚焦] ：伊朗气田遭袭 乙二醇上涨空间再度被打开](https://mmbiz.qpic.cn/sz_mmbiz_png/jB59BB1tXAVDb5N2NU9zJWjpzZWQLIeDbw1ibFt0eHicV392CH9LRicQJpPPPhv2yQWM47CAskqUpDfbUc8QxVgLP55iaYReo3yg8ahzcVhEKgo/640?wx_fmt=png&from=appmsg) |

进口方面，霍尔木兹海峡的关闭切断中东能化产品的出口，而中国进口依赖度较高的乙二醇有65%以上的进口量来自于中东地区，对进口影响较大，由于中东至中国的货物有25天左右装运期，因此影响滞后，3月底开始，进口乙二醇将进入到货真空期。

| 

2-3月聚酯产业链各产品开工率变化图 |
| 

![[隆众聚焦] ：中东局势升级 一季度乙二醇绝地大涨](https://mmbiz.qpic.cn/mmbiz_png/jB59BB1tXAUNasgT1gg9lSqKcggTIewQQeh9TN0khphGFOCOkPzY8ywuaKzl52DGgk3oKFS4mnUaRpMFFx2BL95fkALibdVibxWMJLQHo1TFw/640?wx_fmt=png&from=appmsg) |

需求情况来看，节后聚酯产品需求恢复尚可，3月综合开工率从春节期间的低位回升至83.12%。  

展望二季度，市场焦点仍集中在中东。受当前冲突影响，能化产品普遍处于大幅溢价状态，一旦战争逻辑消退，多数化工品将迎来溢价的快速修复。就乙二醇而言，虽在大趋势下难以独善其身，但其供需结构在4-5月仍偏强，即便冲突有所缓和，预计仍将表现出较强的抗跌属性。
