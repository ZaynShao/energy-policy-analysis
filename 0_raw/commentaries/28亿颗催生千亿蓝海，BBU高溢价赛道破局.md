# 28亿颗催生千亿蓝海，BBU高溢价赛道破局

2026年8月，一串数字把BBU赛道再次推上风口浪尖。
最新的数据显示，2026上半年全球BBU电芯出货约2.76亿颗——而2024年全年仅0.5亿颗。
有数据更测算，2026年BBU电芯需求近4亿颗，2028年突破12亿颗，2030年逼近28亿颗，将催生破千亿元的新蓝海。
松下、三星SDI产能吃紧供不应求，蔚蓝锂芯印尼2.9亿美元扩产，三星SDI与新普科技2万亿韩元供货合同——一连串热点事件背后，是AI算力把一个曾经不起眼的备电组件推上了命运拐点。
BBU，这个机柜里的"保命电源"，正从"选配"变为"架构刚需"。
台达‑中达电通数据中心电源设计部总监夏丽涛此前公开表示，BBU是AI服务器就近备电的核心方案，部署在机柜侧、贴近负载，能够解决传统集中式UPS距离负载远、效率损耗高、占地面积大的痛点。供电架构正在从集中式UPS走向‘模块化+快速补偿’，BBU是这一转型的关键载体。
从选配到标配：算力功耗的60倍跃迁
BBU为什么火？答案在英伟达的功耗曲线里。
2020年A100单卡400W，机柜不过10—15kW，传统UPS绰绰有余；H100翻到700W、40kW，传统方案勉强顶得住。
拐点出现在Blackwell——B200单卡突破1000W，GB200 NVL72机柜功耗跳到120kW，传统UPS在效率、占地和响应速度上集体崩盘。于是GB200时代BBU第一次以"选配"登场。
到了GB300，英伟达将超级电容与BBU统一纳入机柜，打包成Energy Storage Tray（储能托盘）。进入Rubin时代，标准版让BBU成为强制标配，Rubin Ultra更将BBU升级为柜外电源——没有BBU，供电链路已无法成立。
更严峻的是机柜密度的跨越式提升：Ampere机柜约10kW，Hopper升至40kW，Blackwell升至120kW，到Rubin Ultra NVL576机柜直接飙升至600kW+，相当于60倍跃升。
GPU集群在训练和推理中存在频繁、大幅度的短时功率波动，传统"柴油发电机+UPS"已无法承受毫秒级瞬态功率尖峰。
BBU凭借毫秒级响应、机柜内分布式嵌入、瞬间高电流放电，填补了"稳态供电"与"瞬态负载"之间的缺口。
华为数据中心能源首席专家王亮认为，AI负载存在剧烈脉冲波动，会对母线、电网带来冲击，储能补偿必不可少。但相比服务器侧内置BBU方案，把锂电电池拉远集中部署，配合电解电容、超级电容分级抑制不同量级负荷扰动，在高压直流场景下安全性更占优。
千亿高溢价蓝海
有数据预测，BBU电源全球市场规模2024年为7.88亿美元，2025年9.48亿美元，2031年将达18.77亿美元，2025—2031年复合增速12.1%。
从电芯颗数看膨胀更为惊人：数据测算2026年需求近4亿颗，2028年12亿颗，2030年28亿颗。
以单颗盈利衡量，目前代工模式约2元/颗，联合销售约4元/颗，直供海外可达7元/颗——下游对BBU价格高度不敏感，赋予其远超传统小圆柱电池的盈利空间。
高工产研储能研究所（GGII）预计，到2030年数据中心用电池方面BBU出货将达16—20GWh。
从单瓦时价值看，BBU单体电芯价格约为通用储能电芯的3—4倍（后者集采价0.34—0.39元/Wh），是名副其实的高溢价赛道。
围猎格局：日韩三巨头80%份额，国产加速破局
值得注意的是，当下，BBU千亿蓝海的入场券，目前握在少数人手里。
当前全球BBU电芯超80%份额掌握在松下、村田和三星SDI三家日韩企业手中，蔚蓝锂芯虽为国内最快者，上半年全球市占率也仅不足一成。
7月3日，三星SDI与新普科技签署超2万亿韩元（约96亿元人民币）AIDC电芯供货协议，供应高功率NCA圆柱电芯专用于BBU。
松下则计划2028年将BBU用电池产量提至当前3倍，FY2028数据中心储能销售目标中80%以上项目已锁定。
但格局正在松动。BBU电芯正经历"18650→21700"、"多极耳→全极耳"、"三元→磷酸铁锂"三重迭代。
全极耳是倍率瓶颈的破局者——传统多极耳在大电流下内阻高、温升大，全极耳可将内阻降至5mΩ以下。材料方面，BBU仍以三元为主，但LFP渗透率有望在2027年Rubin放量后加速，全极耳恰好补足其倍率短板，加上AI对安全性要求持续提升，LFP在热稳定性和本征安全上的天然优势正被重新审视。
全极耳与磷酸铁锂的双重技术变局，正在拉平国内企业与日韩巨头之间的工艺差距。
蔚蓝锂芯是国内进展最快者，通过Moli代工间接供货新普、顺达等pack厂，2025年出货约500万颗，预计2026年十倍增长至5000万颗。更重要的是，公司正从代工向直供转型，21700磷酸铁锂电芯已突破，正推进北美头部云厂商验证。马来西亚基地全极耳产线已投产，印尼5GWh基地进一步强化海外交付。
亿纬锂能全系列BBU产品搭载自研21700磷酸铁锂高功率电芯，依托12V/50V/800V全电压矩阵，支持15—30C超高倍率放电，800V单BBU模块可实现25KW+备电，电芯已送台达等头部电源厂商测试，预计2026年5—6月输出A样，2027年规模化放量。
鹏辉能源21700—5000mAh全极耳小圆柱2025年9月批量交付，投产半年即满产满销。比克电池联合Echion开发超高功率2170系列，样品预计2026年底提供。
在鹏辉能源储能产品总监王兵博士看来，算力储能和传统工商业储能逻辑完全不同，瞬时响应、动态稳压、抵抗频繁脉冲冲击才是BBU核心考核指标，不是单纯比拼能量密度。AIDC专用BBU电芯要做到毫秒级充放电切换，扛住算力负载忽高忽低的波动。未来数据中心备电走向机柜侧分布式部署，BBU不再只是电池配件，而是电力稳态系统的核心组成。”
海四达电源也推出了三款BBU圆柱电芯，其中21700—26PS支持23C持续放电，构建完整BBU体系。
产品不是问题，关键在于被写进客户BOM表里的那个"供应商代码"。 BBU电芯导入需经电池集成商、电源厂、服务器厂商和终端云厂商的多层验证，认证周期长达一年以上，完整准入普遍2—3年甚至3—4年。验证内容覆盖倍率、循环寿命、高低温、安全、热管理、一致性、长期供货稳定性和可追溯性。
欣旺达能源科技网络能源产品线研发总工杨孔梁在接受央视财经《经济半小时》节目采访时表示，全球AI算力基础设施扩建不可逆，BBU备电由刚需走向刚需升级。不同算力机型、负载模式，对BBU倍率、散热、循环的要求差异巨大，定制化开发与快速迭代能力，是企业核心竞争力。
据高工储能了解，目前欣旺达AIDC‑BBU产品已经送样海内外云服务商、电源厂商，按市场节奏规划产能。
抢货潮只是前菜，牌桌重排在即
高工储能研判，当前BBU电芯的紧缺与抢货潮，本质是供给侧跟不上需求侧的阶段性矛盾。日韩三巨头虽手握80%份额，但产能扩张远不及AI算力的指数级增长——松下要到2028年才将产量提至3倍，而2026年单年需求就已近4亿颗。
这一时间差正是国产企业的窗口期。未来3—5年21700全极耳将成为主流，LFP有望在Rubin放量后加速渗透。在全极耳产线上中国企业与海外同步推出，迭代效率更高、扩产更快——全极耳时代国产有望抢占更多份额。
但必须清醒认识到的是，BBU赛道天然高壁垒，算力客户对成本容忍度更高，但对可靠性和安全提出了远高于以往的硬性要求。当前手握实际订单、拥有成熟定型产品的企业占比不足30%，漫长认证周期将持续出清实力不足者。
此前，松下能源CEO 忠登和夫在松下投资者日就公开表示，海外高端BBU市场，客户优先考核安全冗余、热稳定性、长期一致性，而非短期成本。AI算力迭代持续拉动BBU升级，高功率长寿命锂电BBU加速替代铅酸、电容方案。
从供电架构演进看，BBU并非孤立赛道——它与超级电容（微秒级）、UPS（分钟级）、大储（小时级）共同构成多层级备用电源体系。GGII预计到2030年数据中心备电结构中大储占87%、UPS占8%、BBU占5%——BBU份额虽小，但单颗价值最高，且是唯一贴近芯片侧的备电单元，战略地位不可替代。
这场BBU抢货潮只是千亿蓝海的前菜。真正的洗牌，将在2027年Rubin放量、全极耳磷酸铁锂规模化导入之后到来。
谁能率先拿到头部云厂商的供应商代码，谁就能在算力供电链路最贴近芯片的位置，站稳脚跟。
