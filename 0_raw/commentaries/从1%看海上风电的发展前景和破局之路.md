# 从1%看海上风电的发展前景和破局之路

我国海上风电装机容量刚刚迈过4700万千瓦，约占全国风电装机的7%，约占全国发电总装机的1%。但正是这1%，却成为我国建设海洋强国和能源强国的重要抓手。
国家能源局最新发布的数据显示，截至5月底，全国累计发电装机容量已突破40亿千瓦。这一规模超过美国、印度、日本、俄罗斯以及欧盟的装机总和。40亿千瓦不仅是电力装机的数字跨越，更是我国能源安全保障、绿色低碳转型、科技自主创新的集中体现。
从装机结构看，可再生能源装机占比由2010年的24%提升至2026年5月的61%。其中，风电装机容量6.6亿千瓦，同比增长17.0%。
单就风电而言，陆上风电是绝对主体，我国海上风电装机容量刚刚迈过4700万千瓦，约占全国风电装机的7%，约占全国发电总装机的1%。但正是这1%，却成为我国建设海洋强国和能源强国的重要抓手。
共识：推动产业加速跑
根据“十五五”规划纲要，到2030年，我国海上风电累计并网装机规模达到1亿千瓦以上。从4700万千瓦到1亿千瓦，意味着未来5年，海上风电装机要实现翻番，相当于再造两个三峡工程。
在日前于上海举办的第十一届海上风电大会上，全国政协教科卫体委员会副主任，中国科协原党组书记、常务副主席，科技部原副部长尚勇表示，科技创新是海上风电产业发展的核心驱动力。我国已建成全球最完备的海上风电产业链、供应链，积累了丰富的工程实践经验，这是我们扩大海上风电开发规模的底气。但也要看到，在基础材料、部分核心部件、深远海施工装备等领域还存在短板。
上海，是我国海上风电的起点。2010年，上海东海大桥100兆瓦海上风电场34台机组全面并网发电，标志着亚洲第一座海上风电场正式建成，也开启了我国海上风电规模化商业化应用的序幕。
上海市政协副主席、党组副书记肖贵玉表示，依托国际科技创新中心优势、高端装备制造的产业根基、对外开放的枢纽能级，上海持续汇聚风电产业链上下游企业与顶尖科研力量，推动产业高端化、智能化、绿色化升级。海上风电已成为上海培育新质生产力、推动高质量发展的重要蓝色引擎。
在此背景下，由长三角三省一市的风电企业、用能企业、重点园区及有关机构共同发起长三角风电伙伴行动，旨在推动海上风电成为实现能源转型、保障能源安全、建设海洋强国、带动经济转型升级的关键抓手。以海上风电发展为牵引，以工业深度脱碳为重点，打造区域绿色协同发展的新样板。
我国离岸300公里范围内海上风能资源经济技术开发量超过27亿千瓦，从资源禀赋、技术成熟度、战略价值等方面来衡量，海上风电开发既大有可为，又任重道远。
当前，政策端和产业端已形成清晰共识：海上风电必须加速推进。面向“十五五”，更需要以“量”的合理增长，推动“质”的稳步提升，实现海上风电从近海走向远海，从国内走向国际，从单一发电走向综合利用。
现状：打破“内卷式”竞争
过去5年，我国海上风电在产业规模、技术创新、产业链配套、发展模式等多个维度实现突破，为“十五五”时期迭代升级奠定了坚实基础。
2021年底，我国海上风电累计装机首次超越英国，问鼎海上风电第一大国。此后，年新增装机和累计装机规模连续多年双双稳居世界第一。当前，我国海上风电装机容量占全球总容量近一半，中国海上风电的一举一动成为全球海上风电产业的风向标。
伴随装机量增长的，是大兆瓦技术、漂浮式技术的稳步推进与产业链的不断成熟。18兆瓦机组实现批量应用、26兆瓦海上风机并网发电、16兆瓦的“三峡领航号”漂浮式平台成功安装，为迈向深远海提供技术支撑；覆盖勘察设计、设备研制、开发建设、运行维护、海洋工程的完整产业体系，为产业高质量发展提供重要保障；江苏盐城、广东汕头等地建成特色产业集群，为探索海上风电融合应用新场景积极试水积累经验。
然而，发展过程并非一帆风顺。2025年我国海上风电新增装机659万千瓦，与行业预期目标有一定差距。业内人士指出，这不是投资意愿问题，也不是技术问题，而是海域的使用和项目审批需要在更高层面进行综合协调。
就行业本身而言，“内卷式”竞争仍是一把达摩克利斯之剑。据业内人士透露，以前海上风机（不含塔筒）的造价约为每千瓦3000元—3200元，今年在江苏的一些招标项目中，价格已经降到2600元左右。在山东，2025年海上风电项目电价尚维持在0.35元/千瓦时左右，2026年已降至0.31元/千瓦时，新项目的电价预期更低。根据测算，上网电价每下调0.03元/千瓦时，项目投资收益率就要下降近1个百分点。
特别是伴随新能源全电量入市，开发企业盈利能力面临考验，成本压力进一步向主机厂商传导。在此背景下，部分整机企业为了短期业绩冒进投标，采取低价“内卷”策略，甚至出现虚报功率曲线、裸保电量等乱象，为行业健康发展埋下隐患。
远景能源风机产品线总经理杨亚文表示，海上风电不是短跑，而是马拉松。行业不能急于求成，要尊重技术规律，把产品验证做扎实，把质量底线守住。海上风电的售后成本比陆上风电要高出5—10倍，一旦质量隐患集中暴露，企业将不得不投入大量资金处理售后问题，最终可能导致项目整体亏损。“我们坚定认为，好的质量才是项目收益的保障，设备可靠、发电效率高，才能多发电、多卖电。”
世界风能协会副主席、中国可再生能源学会风能专业委员会秘书长秦海岩认为，一个健康的产业生态，应该是各方都有尊严地参与其中。甲方尊重乙方的技术积累和制造能力，给出合理的价格和付款条件；乙方珍惜甲方的信任，按时保质交付产品和服务。当前，风电行业已经开始意识到这个问题。部分龙头企业带头调整招标策略，不再唯低价论，而是综合评估技术、质量、服务和价格；一些制造企业也开始学会说“不”，拒绝那些明显不可持续的订单。
破局：推动行业高质量发展
产业发展，安全先行。海上风电任何一处质量瑕疵、一丝安全隐患，都可能引发重大风险，造成巨大损失，重创行业信心。业内普遍认为，在防范和治理“内卷式”竞争的当下，坚守质量安全生命线更具现实意义。
安全和降本是海上风电高质量发展的一体两面，但海上风电降本不能只盯着机组，而是要在基础安装、风机吊装、海缆方案、消纳送出、运维维护等海洋工程的全局视角来统筹考虑。
远景能源海上产品解决方案总监李小刚介绍，他们在输出环节积极尝试优化，输出线路从传统的35千伏提升到66千伏，通过提高送出电压等级降低海缆成本。创新研制风储一体机，通过风储联合，降低整个风场的功率峰值，间接降低送出海缆的容量需求。同时，针对深远海场景，在柔直送出和低频输电等方面积极进行技术储备。最终，以系统思维和全局视野，帮助海上风电项目全链条、多环节降低成本。
肖贵玉建议，要加强产业链上下游合作，实现资源共享、优势互补和成本降低，要积极推进“海上风电+”模式，实现空间立体开发、资源联合利用。
申能（集团）有限公司党委书记、董事长黄迪南认为，发展海上风电，既要深化产融协同创新，激活绿色产业发展动能，又要延伸清洁能源产业链，打造绿色燃料产业特色。
在杨亚文看来，海上风电的终局不是“卖电”。沿海地区是负荷中心，也是高端产业聚集地。海上风电应该与储能、绿氢、绿色算力、零碳产业园深度耦合，从“单一电源”变成“综合能源服务”。这更要求整机商具备“巧发电”的能力：精准预测、智能交易、协同控制。“过去我们只管风机转不转、转多久，现在还要看它什么时候该多转、什么时候该少转、什么时候该停下来做检修——因为电力已经变成可交易的商品，每一度电的价值在不同时段可能差几倍。”
业内普遍认为，既坚守质量底线、保障项目全生命周期安全运行，又不断创新技术和应用场景、实现海洋资源的综合开发利用，海上风电才能真正踏上行稳致远的高质量发展之路。
记者手记
产业长青，离不开“热带雨林式”生态
文丨张子瑞
报价低于成本、承诺超出能力、交付赶工期、售后打折扣……曾经困扰海上风电产业的种种乱象正逐步失去存身之地。行业各界日益形成清晰共识：饿死同行、累死自己、坑死业主的“内卷式”竞争不可持续。做优做强海上风电，离不开良好的产业生态。
自然界的热带雨林，是地球上生命力最旺盛的生态系统之一：参天乔木、万千灌木、藤蔓植物——各类物种既分层生长、错位发展，又彼此依存、循环流转，形成生生不息的有机整体。
产业发展亦是同理。
一段时期内，海上风电行业出现虚报功率曲线、裸保电量等现象，其实质是招投标中低价厮杀、互相压价。企业把精力消耗在内耗竞争上，无暇投入技术研发，上下游相互博弈，整条产业链遭殃。这种“零和博弈”竞争模式，短期看似抢占市场，实则透支产业未来。打造“热带雨林式”生态，正是破解行业内卷、校准产业发展航向的良方。
当前，海上风电产业链加速重构，供应链风险、技术壁垒、资源约束等挑战交织，单一企业、单一环节难以独自应对外部冲击，更需推动政企、产学多方联动，政策、资本、人才、技术要素互通共享。培育“热带雨林式”生态，正是增强产业链韧性、夯实产业安全底座的关键。
海上风电是风电产业的前沿领域，创新成本高、周期长、风险大，仅凭一两家企业难以持续推动。打破资源壁垒，延伸产业边界，促进创新要素自由流动、跨界融合同样需要良好的产业生态。构筑“热带雨林式”生态，正是催生创新活力、拓展产业增长空间的沃土。
历史经验一再表明：做强产业，离不开做优生态。多样性差异化的各类企业各司其职、各展所长，有利于产业向下扎根、向上生长。
2010年10月，我国公布首轮海上风电特许权中标结果，4个项目的中标价均低于后来制定的海上风电标杆电价0.85元/千瓦时，更远远低于上海东海大桥海上风电示范项目确定的0.978元/千瓦时的电价。最终，拿到项目资源的开发企业，因为经济性问题搁置项目。这直接导致我国海上风电在“十二五”时期发展滞缓，既定的装机目标没能如期完成。
面向“十五五”，站在建设海洋强国和能源强国的全新起点上，行业正把历史的教训化作前行的镜鉴：唯有构建大中小企业多元共存、产学研资多方协同、上下游互利共生的良好生态和共赢格局，才能守住产业安全底线、激活持续增长动能，实现海上风电高质量发展。
