# 乌克兰发动袭击

乌军称袭击俄西南部一大型炼油厂。
乌克兰武装部队总参谋部13日在社交媒体上发文称，乌军当天凌晨袭击了位于俄罗斯西南部巴什科尔托斯坦共和国的一大型炼油厂，袭击引起大火。
乌武装部队总参谋部称，袭击目标距离乌俄边境1300公里。乌军将继续打击俄方关键设施，系统性削弱其作战能力。
据报道，遭袭的炼油厂属于俄气萨拉瓦特石油化工公司，该公司是俄最大炼油和石化综合体之一，年炼油能力达1000万吨。
