# 抢滩AIDC：晶澳储能设备交付西北算力产业园

近日，晶澳为西北某地一处算力产业园源网荷储一体化项目提供的15MW/60MWh储能系统设备已全部交付至项目现场。
据高工储能了解，现场调试及系统联调工作正在有序推进，预计本月底完成并网调试。项目将围绕算力产业园绿色用能、稳定供能和能源高效协同需求建设。
晶澳面向算力场景的重要实践
随着算力产业快速发展，数据中心、算力园区等新型用能场景对绿电消纳、电力稳定性和能源调节能力提出了更高要求。储能系统可在源、网、荷之间发挥灵活调节作用，助力提升园区能源利用效率和供能可靠性。
此次项目启动调试，是晶澳面向算力园区场景的又一重要实践。未来，晶澳将围绕更多能源应用需求，推动储能产品与解决方案在算力中心、工业园区、新能源消纳等场景中落地，助力客户实现能源结构优化与低碳转型。
在储能领域，晶澳聚焦源网侧及用户侧等多元应用场景，为大型电站、工商业及户用等多样化场景，提供更安全、高效、智能且高度定制化的产品与服务，致力于提升新能源消纳水平与电网运行灵活性，推动全球能源结构转型与可持续发展进程。
算力“超级周期”下的储能需求
当前，全球AI算力投资进入“超级周期”，头部企业进一步上调了2026年支出指引。其中，仅美国2026年数据中心建设资本支出费用预估就将达到7000-8500亿美元，中国也将达到1300-1400亿美元。
AIDC时代，耗电量也正迎来爆炸式增长。到2030年预计数据中心全球耗电总占比将达到3%，约为1500TWh。
高能耗下AIDC供电呈现出高功率密度、高能效、GW级算力规模等新的需求变化。
AIDC储能能够通过提供“削峰、柔性接入、构网支撑、延缓输电扩容”，降低数据中心对电网瞬时能力与稳定性的要求，从而显著缩短并网周期。
高工产研储能研究所（GGII）预计， 2030年全球数据中心储能锂电池出货量将达到300GWh。
从西北算力产业园的储能设备交付，到光储算融合的纵深布局，晶澳正加速打通“绿色电力”与“智能算力”之间的能源动脉，以领先的光储实力为AI时代提供可靠的绿色能源底座。
