# 远景、国众能源入选，内蒙古乌海600MW/2400MWh储能电站优选结果公示

「储能与电力市场」获悉，8月12日，乌海市乌达区能源局关于2026年再次组织申报独立新型储能电站项目实施主体优选结果公示发布。公告显示，本次优选2个项目，单个储能电站规模300MW/1200MWh，总规模600MW/2400MWh。确定两项目开发主体分别为乌海市景元储能有限公司、乌海市国众储能有限公司。企查查显示，乌海市景元储能有限公司为远景能源有限公司控股子公司；乌海市国众储能有限公司由国众（北京）能源有限公司控股。图源：企查查8月8日，乌海市乌达区能源局关于2026年再次组织申报独立新型储能电站项目实施主体优选公告发布。优选总规模60万千瓦/240万千瓦时（600MW/2400MWh），单个储能电站申报规模30万千瓦/120万千瓦时（300MW/1200MWh），共分为2个独立新型储能电站项目，拟优选项目实施主体2个。接入金湖500kV变电站。8月11日，乌海市乌达区能源局关于2026年独立新型储能电站项目实施主体优选延长申报材料递交时间的补充通知发布，因原截止时间后收到的合格申报材料的实施主体数量偏少，未能形成充分市场竞争，将申报材料递交截止时间由2026年8月10日17:00延长至8月11日15:00。
