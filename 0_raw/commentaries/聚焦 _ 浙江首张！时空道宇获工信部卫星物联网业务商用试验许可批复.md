# 聚焦 | 浙江首张！时空道宇获工信部卫星物联网业务商用试验许可批复

近日，时空道宇正式获得工业和信息化部批复的卫星物联网业务商用试验许可，试验期为两年。期间，时空道宇可依法试点经营卫星物联网业务，依托时空道宇全栈自研低轨卫星物联网星座为全球用户提供广覆盖、低功耗、高可靠的物联网连接服务，在智能网联汽车、工程机械、海洋渔业、能源水利、交通物流、低空出行等领域实现全天候、智能化的卫星物联网服务。同时，开展IoT NTN技术试验，持续加快6G卫星通信技术的研发与商业化进程。
此次获得卫星物联网业务商用试验许可批复，标志着民营企业卫星物联网运营业务纳入国家电信监管体系开展试点，为我国卫星物联网市场化准入积累实践经验。作为 6G 空天地一体化网络的重要基础设施与核心应用场景，卫星物联网是实现全球无缝覆盖、全域万物智联的关键支撑。时空道宇作为国内具备全球规模化商用能力的低轨卫星物联网星座运营商，继一期星座完成组网、实现除南北极外全球实时通信覆盖后，公司持续加快国内及海外市场布局，率先构建起横跨亚、非、拉的太空丝路全球化服务版图。在一期星座组网并开展规模化服务的基础上，同步提速 6G 卫星通信前沿技术攻关，已完成基于3GPP IoT NTN卫星物联网标准的地面试验，相关研发工作稳步推进。
依托全栈自研能力和全球化市场布局，时空道宇已在全球数十个垂直领域落地，携手全球产业伙伴完成多场景商用验证。在智能网联汽车、Robotaxi等领域，已完成商用验证并快速拓展规模化应用落地。同时，聚焦海洋渔业、工程机械、能源水利、交通物流、应急通信等核心赛道，联动产业链上下游生态伙伴，秉持开放合作理念共建产业生态，助力卫星物联网产业由示范试点阶段快步迈入规模化商用新阶段。截至目前，公司全球市场累计订单规模突破亿元，今年将加速推动订单交付节奏，实现全球业务规模化落地。
未来，时空道宇将持续以技术创新为驱动，加快推进星座二期建设，提升星座系统服务能力。同时，以市场需求为导向，加速全球市场拓展，让中国的卫星通信服务走向世界，为全球数字化发展注入新动力。
