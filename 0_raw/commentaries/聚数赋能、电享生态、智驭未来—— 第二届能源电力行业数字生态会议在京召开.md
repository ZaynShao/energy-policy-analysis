# 聚数赋能、电享生态、智驭未来—— 第二届能源电力行业数字生态会议在京召开

7月2日，以“聚数赋能、电享生态、智驭未来”为主题的第二届能源电力行业数字生态会议在京隆重召开。中国电力企业联合会党委书记、常务副理事长杨昆，国家能源局原监管总监黄学农，中国工程院院士、国家电网一级顾问、中国电力科学研究院名誉院长郭剑波，北京市西城区委副书记、区长郅海杰，中国长江三峡集团党组成员、副总经理吕庭彦，国家数据局数字科技和基础设施建设司副司长李建国等嘉宾出席大会。
杨昆在致辞中指出，当前数字生产力正快速崛起，电力行业数字化已从单点试点迈向全链条集成，2025年电力行业数字化直接投入超过420亿元，国家电网、南方电网、三峡集团等企业已陆续推出“光明大模型” “大瓦特模型”等行业大模型，国产化软硬件与安全防护体系全面成型。在国家能源局、国家数据局的大力支持下，中电联成功入选国家数据基础设施建设先行先试单位，积极搭建行业统一电力数据平台。未来，中电联将一如既往发挥好桥梁纽带作用，汇聚行业力量，凝聚行业共识，以数字化转型赋能新型电力系统建设，为推进行业高质量发展、加快建成能源强国贡献更大力量。
黄学农表示，人工智能作为引领未来的战略性技术，正深刻改变全球创新版图、产业发展格局和国际竞争态势。国家能源局深入贯彻党中央、国务院决策部署，推动人工智能与能源融合发展取得积极成效。当前AI应用场景不断丰富，能源行业已有数十个企业级专业模型落地，2025年算力中心总用电量达1700亿千瓦时，八大算力枢纽年均用电增速达39.5%，绿色算力建设提速。面向“十五五”，需从战略统筹、技术攻关、场景落地、算电协同四方面发力，引导产业统筹算力与电源布局。
郭剑波作题为《人工智能技术在新型电力系统中的应用》的主旨报告，指出人工智能在电力系统中的应用主要集中于预测、分类、分析和决策四类，但面临可解释性、安全性、样本稀疏性等挑战，并提出“机理融合、人在回路”的AI落地思路，建议大力推广人工智能技术，同时必须进行安全可信测评。
郅海杰结合“中国数据街”建设介绍了属地产业优势。他表示，西城区作为首都功能核心区，集聚海量央企总部与数据资源，2025年金融资产规模超156万亿元，数字经济增加值超2400亿元，汇聚数据与人工智能企业超2600家，已落地中电联电力可信数据空间等标杆项目。西城区将持续完善“数产十条”扶持政策，启动央地合作AI生态计划、构筑AI产业生态、搭建央地协同创新平台，打造算力、能源、数据融合创新高地。
吕庭彦围绕“数据和人工智能赋能能源电力企业绿色低碳发展”发表演讲，指出新型电力系统数据体量爆发是行业AI优质基石，但同时面临安全隐患增加、知识断层与人才结构性短缺、管理模式与技术变革不匹配三大挑战。他建议从强化顶层设计、夯实技术基石、规划清晰路线、拥抱组织变革四个维度系统推进转型，并呼吁行业共建数据共享平台、统一AI应用标准。
李建国指出，数据基础设施是数智创新的物理依托，高质量数据集是数智创新的核心资源，全国一体化算力网是数智创新的关键底座。当前，全国一体化算力网已列入“十五五”规划纲要109项工程，八大枢纽节点智算规模已占全国80%。希望电力行业在算电协同技术机制模式上加快探索，共同助力全国一体化算力网建设和算力设施绿色发展。
中电联大数据与人工智能分会执行会长王继业指出，“十五五”是人工智能与能源双向赋能、协同发展的关键阶段，各类智能化场景将突破局部试点，实现全行业规模化系统化应用。算力网和新型电网等“六张网”正在大规模建设，AI技术密集迭代，新技术新产品新业态竞相涌现，叠加我国电力和算力的基础优势，必将有力推动AI和能源的协同发展。
会上发布了由中电联大数据与人工智能分会牵头的《能源电力行业数据安全发展报告（2025）》、《零碳园区碳核算技术规范》和《零碳园区评价规范》创新算电协同动态核算机制等八大能源电力数字领域成果，并同步召开了“AI+算电协同与零碳园区”“AI+储能” “电力数字发展趋势”“能源电力数据要素流通新生态”“AI+电力装备”“AI+能源气象” “AI+空间与卫星技术”“电力智能感知技术与应用”等八大重点领域平行专题论坛。
各专题论坛精彩纷呈，研讨深入，交流热烈，来自能源电力央企、通信运营商、算力企业、高校及科研院所的专家学者与行业代表，在各分论坛上就细分领域的前沿技术、落地实践与标准建设展开深入研讨，进一步推动政产学研用多方精准对接，提供了更加丰富的产业落地视角。
本次会议由中电联大数据与人工智能分会与“中国数据街”合作发展联盟联合主办，海光信息技术股份有限公司协办，近700位政产学研用各界代表参加大会。
