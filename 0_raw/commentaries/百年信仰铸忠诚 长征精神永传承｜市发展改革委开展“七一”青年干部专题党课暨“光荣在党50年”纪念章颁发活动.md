# 百年信仰铸忠诚 长征精神永传承｜市发展改革委开展“七一”青年干部专题党课暨“光荣在党50年”纪念章颁发活动

为庆祝中国共产党成立105周年、红军长征胜利90周年，引导传承红色基因、筑牢理想信念，近日，市发展改革委邀请退休老党员为全委青年干部讲专题党课，并颁发“光荣在党50年”纪念章，以一堂浸润初心、叩问使命的红色课堂，引导全委青年干部以先辈为镜、以老党员为师，走好新时代长征路。
活动现场，委机关党委为党龄满50周年的5名老党员颁发“光荣在党50年”纪念章。“光荣在党50年”纪念章，是党中央给予老党员的光荣和褒奖，承载着组织的温暖与认可，更能不断厚植全体党员的荣誉感、归属感、使命感。老党员们数十年如一日践行入党誓词，以长久坚守彰显忠诚担当，为青年党员树立了鲜活标杆。一枚枚厚重的纪念章，让全体参会人员真切体会党组织的温暖关怀，激励大家坚守初心、不改本色，同时也引导老党员持续释放银发余热，续写共产党员的光荣篇章。
活动邀请退休老党员邬楚龙作《百年信仰铸忠诚 长征精神永传承》专题党课。邬楚龙同志有着深厚军旅与党务工作积淀，服役时官至上校，历任团政委、师政治部副主任，荣立二等功、三等功，获评全军优秀基层干部，受邀参加新中国成立35周年国庆观礼。转业后深耕物价管理与机关党建，获评杭州市优秀党务工作者、最美长者。
他结合自身军旅与党务工作经历，以党史、长征故事为切入点，深入浅出讲述信仰力量，整场宣讲饱含真情、史料厚重，让青年干部接受了深刻党性洗礼，大家表示将汲取党史力量，坚定信念、实干律己。
