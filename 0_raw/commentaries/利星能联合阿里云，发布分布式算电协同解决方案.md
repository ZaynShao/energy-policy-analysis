# 利星能联合阿里云，发布分布式算电协同解决方案

随着AI大模型与智算需求的持续增长，算电协同正成为新型电力系统建设的重要课题。打通绿色能源与数智算力的核心链路，已成为行业技术演进的方向。6月3日，在第19届SNEC PV+展会首日，利星能联合阿里云重磅发布利星能“星河”分布式算电协同解决方案。方案针对分布式光储站点的特点深度聚焦，进行了轻量化、模块化设计，支持灵活部署与快速复制。目前，方案已于利星能江西鄱阳零碳工厂成功部署并全线跑通。在发布现场，利星能与阿里云计算有限公司（以下简称“阿里云”）正式签署合作协议，基于阿里云全栈AI技术与千问大模型，共探智算与清洁能源协同的可持续路径。利星能算电业务总监李海军、阿里云能源行业算电协同首席专家黄振代表双方签署合作协议面对AI算力单机柜功率突破MW级的挑战，传统交流供电架构已达物理极限。利星能推出星河800技术架构，以800V 直流方案，实现系统级重构，让分布式算电协同“更高、更快、更强”：>> 更高效率：DC-DC一步直供，端到端效率提升至97.5%以上，远超传统AC方案的85-90%，让绿电直供算力不再有中间损耗。>> 更快响应：直流架构与储能深度耦合，平抑算力波动，支持毫秒级功率调度；模块化部署缩短交付周期，适配分布式场景的灵活部署。>> 更强价值：方案带来硬件层面的降本增效——电流降至AC方案的1/15；释放机房空间，AI加速器密度提升35%以上。同时，绿电通过星河800架构直供算力，使得分布式光储能源资产综合利用率从不足50%跃升至95%以上，推动资产从电价管理迈向算力价值运营。星河800是面向AIDC时代分布式能源与智算场景深度融合的系统级答案，通过协同，以更高的分布式光储资产的综合利用率，推动数智能源迈入算电协同新周期，演绎更强价值。作为该解决方案的首个落地标杆，利星能江西鄱阳零碳智能微电网项目已成功实现从“综合能源管理”向“算力-电力价值转换”的战略升级。利星能算电协同技术负责人丛文卓博士表示：“鄱阳项目的成功落地，标志着分布式光储向算力-电力价值转换的战略升级。通过算力资源的深度参与，系统不仅丰富了微电网内部的柔性调节手段，更让传统的分布式光储资产升维成兼具“电力调节”与“算力服务”双重属性的数智化综合体，实现了从硬件集成向更深度的数字化与资产价值共建的跃迁。在光伏出力高峰期将过剩绿电实时转化为算力资产；在电网波动时由储能系统提供毫秒级支撑。”为满足不同工业园区、企业业主以及能源投资方的实际需求，该解决方案也匹配了丰富的合作机制，可支持资产联合共建、存量升级等多种路径，充分优化前期投入，使高价值商业模式能够迅速复制推广。智算中心对电能质量和供电连续性有着严苛要求。在智算与新能源深度融合的趋势下，算力正演变为一种新型柔性调节资源。本次重磅发布的星河分布式算电协同解决方案首创“设备级、站点级、区域级”全维度全时空架构，全直流耦合，打通源、储、荷路径；系统实现并离网毫秒级切换，确保算力负载在负荷波动或电压跌落时零感知运行。依托自研SESCLOUD数智能源平台，方案实现供需一体化动态匹配。通过算电协同柔性调度，算力的时空迁移特性被转化为电网的灵活性资源，在提升绿电消纳比例的同时，持续降低智算中心整体碳排放，驱动绿色算力与清洁能源的正向循环。作为先行者，利星能正以清晰的落地实例向行业宣告：算电协同正式迈入规模化商用的新阶段，要让更多新型能源资产在当下行业风口找到属于最高的价值变现——而利星能，已经在场。未来，利星能将继续推进技术创新，率先锚定下个周期，为新型能源资产重构价值坐标。
