# 金杜助力久事动娱完成与控股股东久事集团及其关联方资产置换项目

本次交易将为久事动娱带来具有良好发展空间与前景的文体旅核心业务，同时置出亏损较为严重的汽车零部件制造与销售板块业务，以整体提升久事动娱资产质量。置入的标的公司为市场化属性较强且相互间具有高协同性的文体旅业务板块核心资产，交易完成后，久事动娱将转型为业态融合的文体旅交综合上市平台，集合体育赛事运营、体育场馆经营、演艺策划运营、水上旅游、城市交通物流及汽车销售等文体旅交融合业务为一体，成为全国综合性文体旅交产业集团之一。
金杜担任本项目的法律顾问，全程参与了本项目的全部阶段，服务领域覆盖上市公司并购重组、赛事文娱等方面，体现了金杜在复杂交易中“一站式、跨专业、全流程”的综合服务能力。在本项目实施过程中，金杜紧密围绕客户需求，提供了置入置出标的尽职调查、业务整合方案设计及文件起草、本次交易方案设计、交易文件起草、交割等各个环节的法律服务，协助高效高质完成本次交易。
本项目主办合伙人为叶国俊、俞爱婉、张逸瑞。项目团队主要成员包括曹雪莹、冯宝宝、谭然戈、张津豪、张逸松。
