# 油价动荡背后，“交付约束”才是真关键

**油价动荡背后，“交付约束”才是真关键****  
**

杨永明

（中能传媒能源安全新战略研究院）**

导读**  

中东地缘冲突持续升级，国际油价初期受风险溢价推动走高，油市定价逻辑已然转变，霍尔木兹通道通行能力成为核心风向标。尽管国际能源署落地史上最大规模原油储备释放，短暂稳住市场情绪，但海湾原油出口大幅下滑，航运运费与战争保险成本飙升，交付端实质性梗阻并未缓解。多家机构集体上调全年油价中枢，高油价还将抬升通胀、压制经济增长。盘面看似平稳，背后供应链深层风险持续积聚，读懂交付约束才是看清油价走势的关键。  

  

3月以来，美国和以色列对伊朗的军事打击推动中东安全局势显著恶化，国际油价在地缘风险溢价推动下出现阶段性冲高。更具系统性影响的是，伊朗对霍尔木兹海峡的强硬表态与行动，使油市定价核心从供需边际快速切换为通道可用性。结果并非单一油价上涨，而是运费、保险、履约与通胀预期同步抬升，油市进入典型的“交付约束主导”阶段。

回看这一轮冲击的走向，大致是沿着一条清晰的链条展开的：先是冲突升级，接着航道受阻，随后各方表态，然后官方出手干预，最后是市场用实际数据给出验证。3月11日，国际能源署发表声明称32个成员国一致同意释放4亿桶战略石油储备，这是该组织迄今协调规模最大的一次释储行动。3月15日，国际能源署进一步披露落地细节：4亿桶中约2.717亿桶来自政府储备、1.166亿桶来自行业储备、另有2360万桶来自其他渠道；投放品种约72%为原油、28%为成品油，且亚洲和大洋洲率先释放、欧美自3月底起陆续投放。3月19日，国际能源署又更新称相关储备已开始向市场投放，并强调欧洲投放偏成品油、美洲通过增产补充供应，参数仍可能动态调整。尽管释储的“工具箱”已正式打开，节奏和结构也逐步清晰，但核心问题从未改变，市场不缺账面的油，缺的是能安全抵达终端的可交付油。

而市场最关心的“能不能到”，核心症结就在于霍尔木兹海峡这一全球油气贸易的“咽喉要道”，一旦通道风险上升，市场就会把可交付性作为第一定价变量。更关键的是，本轮冲击很快从预期走向实物流量，Kpler统计数据显示，截至3月15日当周，沙特、科威特、伊朗、伊拉克、阿曼、卡塔尔、巴林、阿联酋八国的原油、凝析油和精炼燃料出口量平均仅971万桶/日，较2月的2513万桶/日下降约61%；Kpler还提示实际出口量可能更低，因为部分原油被转入浮式储油而并未真正离开海湾抵达国际市场。海湾八国出口量以六成的跌幅印证了供应梗阻的现实，每一桶无法外运的原油，都在强化市场的紧张预期。

如果说出口量锐减是交付约束的直接体现，那么航运与保险市场的异动，则是将这种约束进一步放大的关键推手。一方面，油轮运费快速上行。波罗的海交易所数据显示，基准油轮日收益一度飙升至42.4万美元；并提到在报价飙升背景下，实际成交反而出现停滞，体现出“买方不敢买、卖方不敢卖”的典型冻结。另一方面，战争险的重新定价直接改变了船舶走一次要付出的成本，需重新考量船舶敢不敢走。财新3月6日报道称，进入波斯湾与霍尔木兹海峡的新战争险合同已敲定，战争险费率为船体重置价值的1%，且每7天续保一次；战前费率约0.25%。同时，油轮日租金一周内一度跳涨至接近80万美元。可见，地缘风险把不确定性变成了实打实的成本，短期内大幅压缩了可用运力与可交付供给。

面对这种全方位的交付梗阻，国际能源署牵头的4亿桶释储为市场提供了阶段性“安全垫”，并通过释放结构和节奏安排强化稳预期效果。同时，国际能源署署长比罗尔也公开表示“如有必要”仍可能进一步释放储备，释放出政策仍在升级的信号。但是，释储能缓解的是供应量的紧张，却难以直接解决交付链条的失灵问题。国际能源署在披露释储落地安排时也明确指出，要真正恢复贸易流动稳定，关键仍在于恢复霍尔木兹海峡正常航运，并完善保险机制、加强对船舶的安全保护。显然，释储能为市场补量，却无法应对供应链梗阻；能补充账面库存，却补不来畅通的航运通道，其政策效力始终受限于交付约束这一核心矛盾。

尽管政策层面已全力对冲，但在交付约束成为油市主逻辑的背景下，机构对油价中枢的判断已普遍出现上移。高盛预计2026年布伦特原油均价为每桶85美元（此前为每桶77美元），WTI均价为每桶79美元（此前为每桶72美元）。巴克莱认为其2026年布伦特85美元/桶预测的风险仍偏向上行；若局势持续至4月底，2026年布伦特远期价格可能重新定价至100美元/桶。渣打也上调了预测，将2026年布伦特预测上调至85.50美元/桶。预测上调并不等于“看多”，它更像是在给市场贴一张标签——风险溢价正在从“短期噪音”变成“中枢变量”。这些机构的预测上调，并非单纯的看多油价，而是向市场传递明确信号，地缘风险溢价已不再是短期扰动因素，或将成为深刻影响油价中枢的核心变量，对市场的影响长期存在。

油价中枢的上移，带来的不仅是能源市场本身的波动，其外溢效应已逐步渗透至全球宏观经济的各个层面。摩根大通观点指出，油价每上涨10%，可能推动美联储最关注的美国核心通胀指标上升0.1个百分点，同时使美国GDP增速下降0.2个百分点。这一量化结论说明，一旦高油价持续不退，各国央行对通胀的容忍度、政府财政对补贴的空间、以及新兴经济体的国际收支压力都会被同步拉紧，油价上涨的冲击从来不是单一维度的，它最先体现在终端加油站的价格上，随后传导至央行的利率决策、各国的汇率走势，最终深刻影响全球经济的增长动能。

判断未来油价走势，不能只盯着K线图的短期波动，更需关注以下指标，如，霍尔木兹海峡通航及护航、保险条件是否改善，尤其是战争险费率回落情况及续保周期优化趋势；海湾八国石油出口量能否从当前低位回升，逐步接近常态水平；油轮运费及关键航线运价能否从高位回落，缓解航运成本压力；国际能源署释储是否如期兑现，是否会上调成品油投放比例或追加释储；各大机构对年度油价中枢的预期是否调整等。这些指标将直接决定油市的走向与风险边界，也是我们研判市场的关键抓手。
