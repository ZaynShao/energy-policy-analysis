# 宁德时代电芯线上直销：100Ah、280Ah（1P）和314Ah上架，中小集成商直采

「
储能与电力市场
」
获
悉，近日，宁德时代正式推出其B2B线上直销平台
“宁德时代商城”
，面向储能系统集成商开放原厂电芯直购通道，并将起订量门槛降至
3箱
。
该商城为纯B2B平台，仅对持有营业执照的
储能集成商
开放注册及采购权限，个人消费者无法购买。
图源：宁德时代商城
首批上架产品为三款磷酸铁锂储能电芯：
100Ah、280Ah（1P）和314Ah
，覆盖户用储能、小型工商业项目及微网备电等应用场景。
最低3箱起订的规则，打破了该行业此前以GWh级长协大单为主的供应模式。
以314Ah电芯计算，3箱对应储能容量约602.88kWh，相当于1至2套工商业储能柜的容量。这一调整使得
中小型集成商能够绕过多级分销渠道，直接获得原厂产品。
直销模式消除了中间商环节，价格透明度相应提升，同时由原厂直供也从制度层面降低了翻新电芯和假冒产品流入的风险。
平台提供线上资质审核、报价查询、在线下单等全流程服务。据官方信息，现货订单付款后发货周期为
2至3天
。
图源：宁德时代商城
看个广告休息一下
图源：宁德时代商城
长期以来，头部电芯企业产能优先保障大型客户的长单需求，中小企业通过贸易商拿货是普遍做法，由此产生了渠道加价和货源不稳定的问题。随着户用储能和中小型工商业项目数量增长，碎片化采购需求逐步增加，宁德时代此举被视为对该部分市场需求的一种回应。
从渠道端来看，原厂直销门槛的降低，可能会对现有储能电芯分销体系产生影响，中间商的议价空间或面临压缩。对于宁德时代自身而言，该平台在保持大客户业务的同时，也为其开辟了一条触达长尾市场的补充通道。
