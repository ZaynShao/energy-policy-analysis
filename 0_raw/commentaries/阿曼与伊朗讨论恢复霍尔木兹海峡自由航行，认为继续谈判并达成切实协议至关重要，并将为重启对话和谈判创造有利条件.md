# 阿曼与伊朗讨论恢复霍尔木兹海峡自由航行，认为继续谈判并达成切实协议至关重要，并将为重启对话和谈判创造有利条件

阿曼与伊朗外长讨论恢复霍尔木兹海峡自由航行。
据阿曼国家通讯社21日报道，阿曼外交大臣巴德尔与伊朗外长阿拉格齐当天进行通话，讨论恢复霍尔木兹海峡自由航行的问题。
报道说，双方认为继续谈判并达成切实协议至关重要，有助于恢复霍尔木兹海峡自由航行、维护地区安全稳定。双方还讨论了最新地区局势的发展，以及如何为重启对话和谈判创造有利条件。
伊朗外交部发言人巴加埃17日表示，伊朗和阿曼正在敲定关于霍尔木兹海峡的谅解协议。巴加埃在例行新闻发布会上说，与阿曼的会谈之所以耗时长，是因为议题复杂、涉及多方，以及一些国家试图破坏谈判进程。
他说，伊阿双方正就联合声明文本交换意见，两国决心制定出一项机制，既能兼顾双方利益与关切，也能满足国际航运相关考量。
霍尔木兹海峡是全球能源运输“咽喉”，此前承担全球约五分之一的原油和成品油运输，也是重要的液化天然气运输通道。中东战事前，通过该海峡运输的原油和成品油规模约为每天2000万桶。
