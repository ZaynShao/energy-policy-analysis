# 浙江省人民政府印发《关于推进脑机接口产学研联动的若干措施》

近日，浙江省人民政府办公厅印发《关于推进脑机接口产学研联动的若干措施》，围绕强化高质量科技供给、畅通成果高效转化路径、加快产品推广应用、打造高能级产业生态4个方面，提出18条支持举措。全文如下：
关于推进脑机接口产学研联动的若干措施
为抢抓发展机遇，建立产学研联动机制，打造具有较强国际竞争力的脑机接口技术和产业创新高地，提出如下措施。
一、总体要求
二、强化高质量科技供给
三、畅通成果高效转化路径
四、加快产品推广应用
五、打造高能级产业生态
