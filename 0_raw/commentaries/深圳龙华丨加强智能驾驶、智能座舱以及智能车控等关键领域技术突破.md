# 深圳龙华丨加强智能驾驶、智能座舱以及智能车控等关键领域技术突破

为科学谋划龙华区工业发展蓝图，推动工业经济实现高质量发展，根据国家、省、市、区关于做好“十五五”规划编制工作有关要求，结合本区工业经济发展情况，区工业和信息化局牵头起草了《深圳市龙华区工业经济“十五五”规划（征求意见稿）》并于近日发布。
《征求意见》明确加速智能网联新能源汽车能级跃升
查阅或下载《征求意见》原文，请访问节能与节能与新能源汽车年鉴网站(http://www.gev.org.cn/) 或点击左下角“阅读原文”。
