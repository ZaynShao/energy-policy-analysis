# 杭企 | "被遗忘的瓣膜"有了国产解药！杭州这家企业的医疗器械，拿下国内首款

近日，据国家药监局（NMPA）官网显示，杭州端佑医疗科技有限公司自主研发的"经导管三尖瓣夹系统"创新产品，注册申请已获批准。
这是国内首款获批的国产经导管三尖瓣缘对缘修复（T-TEER）器械，填补了中国三尖瓣介入治疗领域的技术空白。
放眼全球三尖瓣T-TEER介入赛道，雅培TriClip™、爱德华PASCAL™凭借较早的海外获批资质完成早期临床体系搭建。
NeoBlazar®作为全球第三款、国内首款获批上市的国产三尖瓣缘对缘修复产品，正式填补我国三尖瓣介入器械领域的技术空白，自此国产力量正式跻身全球第一梯队，与国际产品同台竞技，改写全球三尖瓣介入行业格局。
三尖瓣素有"被遗忘的瓣膜"之称。重度三尖瓣反流患者预后极差，而传统外科手术风险高、死亡率居高不下，绝大多数高危患者无法耐受开胸治疗。T-TEER技术的出现，给这群患者提供了一个微创选择。
该产品由夹合器及递送系统、可调弯指引鞘组和稳定器三部分组成。采用介入方式，利用输送系统将夹合器送入右心房，通过手柄控制夹合器夹合瓣膜以减少反流面积，消除或减轻三尖瓣反流。该产品为心脏三尖瓣缘对缘修复产品，预期可帮助解决批准的适用范围内患者严重三尖瓣反流带来的右心负荷过重问题。
