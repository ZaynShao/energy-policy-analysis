# 中国智能家居产业规模已破万亿元

人民网研究院组织编写的智能互联网蓝皮书《中国智能互联网发展报告(2026)》7月29日在北京正式发布。其中，中国移动研究院用户与市场所副所长潘宏筠、技术经理张政、主任研究员赵英、研究员刘维旭、朱晨薇共同撰写的《中国智能家居发展现状及趋势》一文指出，2025年，我国智能家居产业规模已破万亿元，形成了多元主体参与、跨界融合的产业格局。未来产业发展将呈现通信协议双轨并行、终端向具身智能演进、场景聚焦“一老一小”、商业模式前移等趋势。
文章认为，当前，中国智能家居市场正迈入规模扩张与结构升级的关键阶段。一方面，市场规模突破万亿元，但部分品类渗透率仍显著低于欧美，显示出巨大的增长潜力与结构性机遇；另一方面，产业主体多元化，除了传统厂商，科技企业、运营商等多类主体跨界智能家居市场，依托差异化策略推动产业发展。尤为重要的是，互联互通政策在国家与地方层面加速落地，从标准制定走向前置性规范，正从根本上打破生态壁垒，为智能家居的普及与升级铺路。
文章认为，未来智能家居产业将以国际国内通信协议双轨通行为基础，呈现互联互通趋势。通过AI大模型深度赋能终端，具身智能将迎来家庭场景的关键突破。同时，应用场景将重点聚焦“一老一小”的安全守护、健康监测与成长陪伴等主动智能化服务场景。智能家居企业的商业模式也将从单品销售向全屋场景化解决方案转型，进一步推动智能家居产业高质量发展。
文章提出，中国智能家居产业在蓬勃发展的同时，仍面临产业协同不足、数据安全薄弱、智能体验浅层化等关键瓶颈。具体表现在互联互通受到协议碎片化与生态封闭性双重制约、数据采集使用不规范与防护体系薄弱并存、大模型赋能不足与主动服务能力缺失三方面。未来应以标准、安全、应用为核心抓手，系统化赋能智能家居产业高质量发展。打破互联互通壁垒，推动构建可持续发展的产业协同生态。筑牢信任基石，完善全生命周期数据安全屏障。深化智能体验，推动场景驱动的AI 融合创新。
