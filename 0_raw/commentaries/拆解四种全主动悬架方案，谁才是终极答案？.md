# 拆解四种全主动悬架方案，谁才是终极答案？

LAB技术控
全主动悬架，为什么突然成了豪华车的新“军备竞赛”
以前我们聊一台车的悬架系统，关注的往往是双叉臂、五连杆这些结构形式，或者是双腔空悬、CDC这些关键部件。
简单来说，悬架能不能调软硬、车身能不能升降，基本就代表了这台车底盘配置的高低。
但现在，汽车厂商开始卷一个更“狠”的东西：全主动悬架。
全主动悬架“主动”在哪？
48V机电式（电机 + 机械执行机构）
48V电液式（48V电机 + 液压执行机构）
800V高压主动悬架
直线电机
