# 全市服务业大会召开 刘非主持并讲话

刘非在全市服务业大会上强调
做强做优“主动力产业” 着力打造“两地一中心”
为高质量发展建设共同富裕示范区城市范例提供坚实支撑
杜旭亮作部署讲话
13日，全市服务业大会召开。省委常委、市委书记刘非主持并讲话。他强调，要深入学习贯彻习近平总书记关于服务业发展的重要论述和考察浙江重要讲话精神，全面落实全国和全省服务业大会部署要求，推进服务业扩能提质和优质高效发展，着力打造先进生产性服务业集聚地和品质生活性服务业共享地，加快建设东部现代服务业中心，支撑产业升级、畅通经济循环、满足民生需要、带动就业扩容，为高质量发展建设共同富裕示范区城市范例、建设世界一流的社会主义现代化国际大都市提供坚实支撑。市委副书记、市长杜旭亮作部署讲话。
刘非指出，服务业是杭州推动经济社会发展的“主动力产业”，事关产业发展、经济循环、民生就业。要深刻领会党中央决策意图，从全局和战略的高度思考，扛起服务业大市担当，切实增强责任感、使命感和紧迫感，强化争先意识和创新引领，把推进服务业扩能提质当成一件大事来抓，不断抓出新成效，继续走在全国前列。要抢抓发展机遇，突出需求牵引、改革攻坚、科技赋能、开放合作，因地制宜锻长长板、补齐短板，加力推进生产性服务业向专业化和价值链高端延伸，促进生活性服务业高品质多样化便利化发展，加快构建具有杭州特色的现代化产业体系，切实将工作成效体现在服务业新的增长点上、体现在人民群众的满意度上。
刘非强调，要准确把握工作重点，聚焦“6+4”重点领域和省级56条细分赛道，围绕8条杭州特色赛道，加快推动“两地一中心”建设迈上新台阶、取得新突破。要突出人工智能赋能，依托国家人工智能应用中试基地、全球数字贸易博览会、云栖大会等平台载体，深入实施服务业“智改数转”；大力发展Token经济，加快构建Token“生产—结算—应用—出海”服务业全链条。要突出现代服务业和先进制造业、现代农业深度融合发展，推动现代服务业与“296X”先进制造业集群双向赋能，深化国家级“两业”融合试点和国家服务型制造示范城市建设；支持发展创意农业、农文旅产业和专业化农业服务，加强农业数智化服务；推动历史经典产业创新发展，促进茶叶、丝绸、中医药等产业焕发新活力、再创新辉煌。要突出优质普惠共享，完善教育、医疗、养老、托育等基本公共服务体系，提升供需匹配度和服务便利性、安全性，持续扩大文化、旅游、体育等升级类服务供给，适度拓展个性化、高端化服务，更好满足群众对高品质生活的追求。要突出品牌培育和建设，继续做强品牌矩阵，打好品牌策划、宣传推广、价值评估和保护维权的组合拳；持续深化企业梯度培育，更好发挥大企业、大项目的支撑带动作用。要突出深化改革、扩大开放，坚持既“放得活”又“管得好”，积极融入全国统一大市场建设，持续优化清理服务业领域限制性措施，善于运用数字化、智能化、法治化手段加强监管，抓实抓好AI治理工作；积极扩大服务业对外开放，不断提升服务业国际竞争力。要加强统筹协调，加强组织领导，加强调查研究，坚持问计于民、问计于企，强化政策支持，提升能力水平，汇聚强大合力。
杜旭亮在部署讲话时指出，要锚定服务业“两地一中心”建设目标，注重创新驱动、降本增效、民生需要、增强活力，更好发挥政策效应，加快场景创新开放，大力营造公平、法治、充满活力的服务业发展生态，做强“杭州服务”品牌。要聚焦生产环节价值提升、研发设计专业化高端化、市场价值实现、居民日常生活便利化需要、市民对高品质生活的追求、群众多样化消费需求等方面，全量承接好省级细分赛道，并立足杭州优势，深耕特色赛道，依托软件和信息技术服务业深厚的产业基础，做大做强电子商务、云计算与大数据、行业应用软件、数字内容、金融科技等板块，大力发展Token经济、智能体、数据服务、AI场景开放与培育等4大新领域，优化科技成果转移转化和知识产权服务，提升物流仓储、低空物流、大宗商品贸易、企业出海、会展、金融等专业服务水平，推动养老、托育、医疗、物业、家政等居民服务更加普惠优质，扩大文旅商体等便利化服务供给，全力推动我市服务业扩能提质。
市领导黄海峰、朱华、陈瑾、孙旭东、章登峰、宦金元、鲁霞光、金承涛、章燕出席。会上，市领导对全市推进服务业扩能提质行动方案进行解读，通报13个区、县（市）服务业画像和2025年度杭州市总部企业名单；市经信局、市商务局、阿里巴巴（中国）有限公司、杭州无忧传媒有限公司、杭州海兴电力科技股份有限公司、杭州容量互娱科技有限公司作交流发言。
