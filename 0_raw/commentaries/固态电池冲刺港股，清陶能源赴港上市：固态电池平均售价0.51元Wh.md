# 固态电池冲刺港股，清陶能源赴港上市：固态电池平均售价0.51元/Wh

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)  

储能与电力市场获悉，4月8日，江苏昆山的清陶（ 昆山）能源发展集团股份有限公司向港交所提交上市申请书。  
![image](https://mmbiz.qpic.cn/mmbiz_png/nJIHJiauQqnwsUg4Fj8Nse4UlqkQnY51m2ED1mnzg4X0NWyMw9uEJUktiadiaey6n6VTgnsvIHTy2vjK9tLM7IUgcOgLiaqa7uLCibLnsrOd5o9c/640?wx_fmt=png&from=appmsg)  
**

清陶能源**，成立于2014年，是固态电池产业化及商业化的领跑者，拥有先进的固态电池技术和强大的固态电池产品研发与交付能力。专注于研发、制造及销售应用于电动汽车及储能系统场景的固液混合电池及全固态电池。根据弗若斯特沙利文的资料，清陶能源是业内持有固态电池技术专利组合最广泛的企业之一。  
**清陶能源已经将技术能力转化为动力与储能系统两大市场的商业部署。**根据弗若斯特沙利文的资料，2025年，按出货量计，累计出货量全球第一，**市场份额约为33.6%；在中国市场排名第一，市场份额约为44.8%。**2023年至2025年固液混合电池出货量复合年增长率134.1%。****

  

就动力电池而言，截至最后实际可行日期，固态电池产品已搭载于智己、名爵（MG）及福田等知名汽车OEM逾30款乘用车、商用车车型，交付超过16,800套。**  
****

就储能电池而言，率先将固态电池技术引入储能行业，精准锚定高安全需求、高附加值市场，全面覆盖电网、工商业和户用应用场景。**清陶能源**是全球最大固液混合电池储能电站的唯一电池供应商，该电站位于内蒙古乌海，装机容量达800MWh。****

按产品划分，2023年、2024年、2025年清陶能源动力电池收入0.06亿元、0.12亿元、2.37亿元；储能电池收入0.92亿元、2.58亿元、5.92亿元；自动化装备收入1.14亿元、1.15亿元、0.77亿元；其他收入0.36亿元、0.2亿元、0.37亿元。自2024年起，储能电池收入占比首超自动化装备，成为第一大收入源，2025年收入占比达到62.8%。

截至最后实际可行日期，**清陶能源**在中国运营五个生产基地，形成6.8GWh固液混合及全固态电池的年产能规模。这些生产基地位于江苏昆山（两个基地）；江西宜春；四川成都；及浙江台州。此外，在江苏淮安及内蒙古乌海运营材料生产基地，并在广东惠州运营装备生产基地。目前正在建造18.5GWh固液混合及全固态动力电池生产基地。计划在其他城市建造新生产基地，同时进一步扩建部分现有基地。****

  

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/nJIHJiauQqnw86aT81N96jWQgPo54ZwMC6DjrkpCGAicd2tXgQQLHbh5wPL5BPa0zbiasHAxhvgoSDb6DlHYAoBOkK1kzzK6CVwhECNI7Ko0gU/640?wx_fmt=png&from=appmsg)

2026年3月，**清陶能源**在浙江台州生产基地的一条新的主要生产线投入商业运营，为动力电池产品增加了约3.1GWh的年产能。

  

2026年3月，上汽在法兰克福举行的「MGTechDay」上宣布，MG4Urban将成为欧洲首款搭载**清陶能源**提供的固液混合电池的量产电动汽车，预计将于2026年下半年上市。

  

此外，在H轮融资中，**清陶能源**完成了一系列股权融资，据此向一组机构和战略投资者发行了合计40,000,504股普通股，所得款项总额约人民币19亿元。认购分别于2026年1月27日及2026年2月28日分两批完成。

于往绩记录期间录得过往亏损主要归因于以下因素：

  

第一，作为中国固态电池技术产业化的领跑者，从研发驱动型科技企业，逐步发展为具备更全面生产能力的企业。电池制造属于资本密集型产业，固定及半固定成本是销售成本的重要组成部分，于往绩记录期间，很多生产线处于商业化前期及产能爬坡阶段，交付量有限。以有限的商业交付量分摊前述固定及半固定成本，导致单位成本相对较高，毛利率为负值。

  

第二，战略重点是动力电池业务，而在实现能够带来大规模收入的量产之前，需要对工艺及材料优化、设备调试及生产线验证以及试产作出大量的前期投资。

  

第三，已在研发方面进行了大量前期投资。于2023年、2024年及2025年，研发开支分别约为人民币142.0百万元、人民币295.6百万元及人民币376.9百万元，约占收入的57.2%、72.9%及40.0%，分别占当年净亏损人民币853.0百万元、人民币999.1百万元及人民币1,302.3百万元的约16.6%、29.6%及28.9%。

  

未来，将采取拓展新客户、增加订单量，通过制造规模化提升利用率，通过技术进步和规模经济效应降低材料成本，全球市场扩张，提高运营杠杆效应等方面提升财务表现，并网可持续盈利方向前进。  
清陶（昆山）能源发展集团股份有限公司自2016年成立以来，已完成多轮融资。获得了峰瑞资本、**尚颀资本****、中银投资、北汽产投、华睿投资、广汽资本、道得投资、鹃城贷款、淮安城发投、苏产投等企业的投资。**
