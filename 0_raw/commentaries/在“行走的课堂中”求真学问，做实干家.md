# 在“行走的课堂中”求真学问，做实干家

大学生志愿者服务农村基层，怎样才能留得住、干得好？智慧养老模式在边疆民族地区如何落地？无障碍的信息基础设施怎样成为残障青年就业的“电子义肢”？近日，由人民网主办的“青苹计划”大学生社会实践调研活动获奖报告公布，来自9个省（区、市）14所高校的同学榜上有名。这些十分重要、却也容易被忽视的真问题，正是获奖团队力图找出答案的调研课题。

**“当代大学生不止关注自身成长，也关注这个伟大时代”**

“一句彝语语音播报、一台适应山区网络的低功耗设备，就能显著提升民族地区老年人对技术的接受度。”楚雄师范学院应用统计学专业2023级本科生张钊来自云南，他选择在家乡开展调研，把边疆民族地区智慧养老模式作为课题。随着“如何让智能技术更好服务乡邻的养老需求”调研深入，他逐渐领悟到，智慧养老不只是技术的移植，更重要的应是如何更好回应具体的人。他的调研报告最终在参评的357篇报告中脱颖而出，获得一等奖。

在云南省玉溪市峨山彝族自治县，调研团队成员与独居老人长谈（受访者供图）

“青苹计划”征集的有效报告中，青年参与基层治理创新、数字技术赋能乡村振兴方向的选题“断崖式”领先。高等教育出版社党委委员张江艺表示，这类选题比重最大，可以看出当代青年很接地气，愿意奔赴基层，而基层也给了他们足够大的施展空间。“我们欣喜地看到，当代大学生不止关注自身成长，也关注这个伟大时代。他们踊跃出谋划策，积极参与建设，努力把青春华章写在祖国大地上”。

**“这些调研经历让学生们更懂基层，对实现中国式现代化更有信心”**

2018年5月，习近平总书记在北京大学师生座谈会上提出四点希望：广大青年要爱国，忠于祖国，忠于人民；要励志，立鸿鹄志，做奋斗者；要求真，求真学问，练真本领；要力行，知行合一，做实干家。

作为北京大学2025年“力行计划”研究生寒假社会实践团队中的一支，哲学系硕士生陈雨坪所在的小队选择就甘肃省金昌市的数字经济产业发展开展实地调研。调研中，他们遇到了难题：当地政府和企业倾向于介绍发展成果，想还原当地数字经济发展的真实面貌、找准痛点难点，并不容易。为此，同学们尽可能地深入机房、厂房，和一线工作人员面对面交流，在非结构性访谈中不断延展话题深度。通过调研，陈雨坪对“在西北资源型地区发展数字经济的意义”这个问题，有了更深的体会。她将这类地方的数字经济描述为“种子产业”：它是基于宏观战略布局与可持续发展的长远规划，是试图通过弥合“数字鸿沟”与“技术鸿沟”、推动区域与城乡协调发展的一次重要尝试。

北京第二外国语学院的“数字化赋能农村发展”大学生调研团队，则在调研中感受到了乡土社会与时代潮流的碰撞。调研中，密云八家庄村的李大叔介绍，几年前家里有块闲置地想流转，托亲戚、问朋友，但价格不理想。村里使用“北京农村产权交易平台”后，地块信息挂上去，很快就有人竞价。“现在这地会‘说话’了，自己在手机上就能找买家。”

北京第二外国语学院的教师马宪超是这次调研的指导教师。在他看来，理解农村土地流转的难点和乡镇管理者的困惑，对理解乡土社会非常重要，却往往是大学生的知识盲区。这些调研经历让学生们更懂基层，对实现中国式现代化更有信心。

北京科技大学文法学院讲师陈晓红带领青年学子，完成了《人工智能背景下首都教育改革转型与重塑调研报告》。她介绍，同学们没有止步于课题研究，而是走进社区和学校，开展了近20场科技志愿活动，线上线下累计志愿服务300多个小时，将调研的发现努力转化为可落地的治理方案，力求小切口、可执行，在更多层面丰富了调研实践的内涵。

**“学生开始认真思考自己的专业能为这个群体提供哪些切实的帮助”**

已成为福建师范大学体育科学学院硕士生的吕瑞凯，对自己在本科阶段与同学们合力完成的实践调研印象深刻。他们在暑期深入到省内35个县乡，完成了关于大学生志愿者服务基层情况的研究报告。调研团队共十人，年级跨度从大一至大四，来自经济学、心理学、地理学、法学、文学和信息工程等专业，学术背景多元。吕瑞凯很为自己的团队感到自豪，原因在于“团队在开展田野调研时全员出击，在具体环节中则各展所长”。他举例说，团队中有师范方向的同学，很会跟小朋友聊天打开话题，此时再顺势向家长了解子女就学情况就容易多了。最终，他们的调研结论和建议被相关党政部门采纳。

与之类似，聊城大学人工智能与计算机学院的学生提交了关于数字化时代残障青年就业挑战与移动端无障碍帮扶路径的调研成果。学院团委书记张雪介绍，无障碍帮扶是该校学生社会实践的重点方向。看到残障青年的现实需求后，“学生开始认真思考自己的专业能为这个群体提供哪些切实的帮助”，最终形成调研成果，在真实场景中找到了技能应用的落点。

在实践调研中，大学生对社会真实运转的逻辑也有了更深刻的感知。2025年暑期，南京大学新闻与传播专业研究生汪雨霖参加了人民网研究院关于老年人康复辅具的调研。在江苏常州社会福利院康复辅具社区租赁服务指导中心，她看到不少老人前来咨询、试用辅具。她发现，辅具对于老年人是否好用、易租，背后关联的是制度设计、服务供给与真实生活之间的差距。“通过调研，我更加意识到，公共政策与产业研究的价值最终应当落脚于回应真实的社会需求，关照普通人每天正在经历的生活。”

“青苹计划”评审委员会评委、光明日报社教育部主任田延辉认为，社会要启发、引导大学生关注身边具体的真问题，让他们在此基础之上不断拓展知识领域、运用知识技能，进而收获更深层次的思考。

**“帮助青年学子实现从知识接收到价值认同与行动自觉的深刻转变”**

广东交通职业技术学院教师贾行浩和专职辅导员朱哲哲带领学生完成了关于高职大学生群体返乡就业创业意愿影响因素的调研成果，在本次评选中获得二等奖。他们注意到，这些“行走的思政课”也是引导青年深刻感知国情民情、坚定“四个自信”的有效举措，帮助青年学子实现从知识接收到价值认同与行动自觉的深刻转变。

位于福建省的华侨大学以“面向海外，面向港澳台”为办学方针。该校政治与公共管理学院副教授和红指导学生针对闽台乡建乡创模式开展调研。同学们针对具体问题与台胞建筑设计师、社区营造师、企业家等面对面深入交流。学生们发现，“两岸年轻人的差异没有想象中那么大”。大家对社会治理有很多共同理念，台胞也乐于参加政府组织的活动。这些亲身体会远远胜过纸面上的理论阐释。

多位受访师生主动谈到他们参加过的实践平台活动，如“挑战杯”全国大学生课外学术科技作品竞赛和中国大学生创业计划竞赛，寒暑期的文化科技卫生“三下乡”社会实践，以及福建“行见八闽”大思政课研学实践圈等。这些由党委、政府部门和共青团等主导的实践平台，为大学生提供了广阔的历练空间。在祖国大地上感知中国式现代化建设的成就，最生动、最有说服力。

高校层面，社会实践日益成为立德树人的关键环节。中国人民大学团委副书记吴秋翔表示，中国人民大学制定了思政课实践教学方案设计和学分认定规则，从制度上保障了思政课堂与社会课堂的深度融合。每年有8000多名人大师生参与主题社会实践，超万名学生参与常态化实践活动。

福建师范大学团委教师蒲鑫源介绍，该校2025年以“青春为中国式现代化挺膺担当”为主题，围绕8个实践重点方向和11个重点专项活动，组建千支社会实践队共万余名师生赴全国各地。通过社会实践助力学生成长、服务地方发展，提升社会实践的实效性、学术性、长效性。

在努力为大学生营造社会实践舞台的过程中，媒体无疑是不可或缺的一支力量。多位参与“青苹计划”的高校师生建议进一步强化媒体与高校的协同联动，为青年学生参与社会实践、提升综合能力提供多维度展示平台。多年来，人民网以多种方式助力青年成长成才，已成为连接高校智力资源与社会发展需求的桥梁。人民网党委委员、副总裁、研究院院长唐维红表示，大学生群体是党媒应当深互动、强联结的对象，要充分激活并用好青年学子的智慧才干。新一年“青苹计划”将着力提升调研评选活动的多元性、覆盖面、有效性与指导性，从而更好助力青年学子成长成才。
