# 荷兰两周内超额死亡人数超900，高温或成“凶手”

两周内，荷兰超额死亡人数达到911人，高温“极有可能”是导致超额死亡的原因之一。
▲荷兰阿姆斯特丹（资料图）
荷兰国家公共卫生与环境研究所当地时间7月15日说，6月22日至7月5日的两周内，荷兰超额死亡人数达到911人，高温“极有可能”是导致超额死亡的原因之一。
超额死亡人数指特定地点和特定时期估计的总死亡人数与没有健康危机情况下的估计死亡人数之间的差额。统计数据显示，6月22日至7月5日，荷兰各地均记录到超额死亡，其中气温最高的南部和东部地区超额死亡人数最多，达576人。从年龄段看，全国80岁及以上老年人超额死亡人数达547人，增幅明显。
荷兰国家公共卫生与环境研究所说，极端高温下，器官功能相对较弱的老年人尤其脆弱。此外，患有心血管和肺部疾病的人群也面临更高的健康风险，高温可能加重这些疾病症状。
荷兰皇家气象研究所数据显示，6月22日至28日，荷兰遭遇罕见高温天气，最高气温一度达39.4摄氏度。目前，荷兰高温天气仍在持续，多地启动高温应对计划。荷兰政府呼吁医疗机构、护理人员等特别关注老年人、慢性病患者、婴幼儿等人群的健康，做好应急准备。
