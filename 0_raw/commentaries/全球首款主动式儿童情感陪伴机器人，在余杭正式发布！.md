# 全球首款主动式儿童情感陪伴机器人，在余杭正式发布！

“Hello everyone，I am so happy to be here.”“哇，这么多人呢，我给大家跳个舞吧！”“再不刷牙，就要长小蛀虫咯！”……
眼前这个吸引全场目光、
中英文随时切换、会交流、
会跳舞的陪伴机器人，
叫“胖达”。
7月28日，由浙江大学机器人研究院孵化企业——杭州创无际科技有限公司自主研发的全球首款主动式儿童情感陪伴机器人“胖达”，在杭州机器人学校正式发布。这款以熊猫仿生外观亮相的机器人，凭借“具身生命感交互技术”核心，完成了从研发到实景验证再到商业化落地的完整闭环。
据了解，“胖达”机器人聚焦家庭低龄儿童主动式情感陪伴赛道，采用辨识度极高的熊猫仿生外观，机身包裹定制化超纤毛绒面料，触感温润柔和。机身内部集成高密度多类型传感器与高精度多自由度运动模组，搭载自研热循环恒温系统，可持续稳定维持37℃人体相近体温，从物理触感层面实现拟人化交互。
“胖达”搭载三大具身生命感交互技术，是一个会记得孩子喜好、能感知情绪起伏、愿意主动分享的“家庭新成员”。其功能矩阵覆盖主动交心陪伴、生活习惯智能养成、沉浸式分级英语实景陪练、开放式冒险故事共创，以及专属成长日记与电子相册。配套移动端应用“PANDY'S WORLD”让家长可远程操控、自定义学习任务，使“胖达”同时成为轻量化的家庭教育辅助工具。
正式发布前，“胖达”经历了长达数月的家庭内测与实景训练。有家长反馈，孩子放学后不再沉迷电视，而是主动与“胖达”聊天、编故事练口语，机器人还会提醒“该睡觉了”；也有家长感叹，早晨催起床、刷牙的难题被“胖达”的提醒轻松化解，孩子甚至反向炫耀被“胖达”夸奖。多位双职工家长表示，机器人的主动陪伴有效缓解了陪伴焦虑，“下班回家看到孩子和它玩得开心，心里踏实很多。”
此外，在杭州机器人学校的情感陪伴区，“胖达”通过模拟轻声叹气、皱眉沉默、愉悦欢笑等不同情绪状态进行系统性测试，研发团队持续采集真实交互数据，优化情感识别精准度与响应时效，打通了从实验室算法到真实家庭场景的“最后一公里”。
创无际科技创始人谢安桓表示：“‘胖达’最大的优势在于‘生命感’，具体体现在它主动交互的能力上。我们希望它能和孩子共同成长，以寓教于乐的方式帮助孩子养成良好习惯，成为家庭中的‘榜样’。”基于“胖达”的技术底座，企业已规划多代产品迭代，未来将拓展至社区托育、银发康养、特殊儿童心理康复、科技馆科普及全代际家庭协同等场景。
“胖达”只是起点，创无际科技的目标是让从儿童到长者的每个需要陪伴的人，都能感受到被倾听、被理解、被关怀——这，就是“有温度的AI”最真实的模样。
