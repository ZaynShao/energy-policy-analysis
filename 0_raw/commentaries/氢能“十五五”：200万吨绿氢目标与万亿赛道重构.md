# 氢能“十五五”：200万吨绿氢目标与万亿赛道重构

文|钟财富
在全球能源格局重构与国内“双碳”目标纵深推进的背景下，氢能作为多场景适配的未来产业之一，是我国能源转型、终端深度脱碳、保障能源安全的重要抓手。
“十四五”时期，我国氢能产业完成技术积累与初步示范，夯实了发展基础。尽管全球范围内氢能发展的热度有所下降，但这更多是前期盲目扩张后的理性回归。氢能仍将是我国未来实现减排目标的重要支撑。“十五五”将是氢能产业从示范探索迈向规模化、市场化发展的关键攻坚期。
3月25日，第十六届中国国际清洁能源博览会上展出的氢能生产装置模型局部。
过去几年中，我国氢能产业保持较快发展，并在产业规模、成本控制、技术创新等方面建立了国际竞争优势。
首先，全产业规模全球领先，产业链完整性优势凸显。截至2025年年底，国内可再生能源制氢年产能突破25万吨，占全球绿氢总产能的比例超过50%；碱性电解槽全球产能占比超60%，具备绝对产能优势。基础设施与终端应用同步提速，全国加氢站超590座，约占全球总量45%；燃料电池汽车保有量突破3万辆，全球占比达30%。
其次，成本竞争力相对突出。依托国内完备的装备制造体系与西北地区廉价的绿电资源，我国部分地区的绿氢成本远低于欧美日等发达经济体的水平。在海外大批氢能项目暂停、产业热度降低的背景下，我国凭借成本与产业优势，成为全球氢能产业稳健增长极。
再次，技术迭代提速，国产化水平持续攀升。我国氢能技术实现从跟跑到并跑的跨越，中低端技术全面领跑。燃料电池和碱性电解槽技术完全自主可控，核心零部件国产化率大幅提升，这为产业规模化发展筑牢根基。
但当前氢能产业整体仍处于商业化初期，尚未形成内生增长动力，在技术成熟度、产业经济性、支撑体系、政策机制等方面仍存在诸多短板。
氢能面临的最核心挑战仍是经济性不足。可再生能源制氢、氨、醇的整体成本仍明显高于传统化石能源制备路线的成本，即使是在国内可再生能源发电度电成本最低的地区，其可再生能源制氢、氨、醇成本仍然明显高于当地煤制氢的成本。同时，储运、加注环节成本居高不下，国内加氢站平均利用率偏低，产业高度依赖政策补贴，自主造血能力严重不足。
除了经济性，部分领域仍存在技术短板，加之对氢能绿色属性激励不足，这些都制约了氢能的发展。催化剂、质子交换膜、高端树脂等核心材料国产化、自主化率偏低；碱性电解槽成本虽低，但难以适配新能源发电出力波动性的特征。工业领域终端环节缺少绿氢消费激励政策，绿氢低碳价值无法兑现，企业用能替代意愿不足，高溢价出口市场需求面临较大的不确定性。交通领域应用仍高度依赖补贴。随着补贴逐渐退坡，以及重卡应用领域电动重卡竞争力持续增强，燃料电池汽车推广应用和盈利的压力陡增，制约市场内生动力形成。
随着《“十五五”碳达峰行动方案》《新型能源体系建设“十五五”规划》《可再生能源发展“十五五”规划》等一系列顶层规划文件的密集出台，氢能近中期的战略目标、开发与应用模式愈加明晰。
作为我国实现终端领域深度脱碳的关键载体之一，氢能产业发展对我国“双碳”目标落地、产业升级具有多重战略意义。相关文件提出，2030年我国可再生能源制氢产能目标为200万吨，规模为2025年产能的8倍。这清晰释放了氢能由示范应用迈向规模化发展的信号，且上述目标设定立足产业现状，兼具发展决心与现实可行性。
全球氢能行业正经历剧烈的“去泡沫”阶段，各国及区域早期制定的高增长目标普遍面临实现压力。机构分析指出，欧盟氢能“双千万吨”目标的实际实现度或将不足预期一半。与此同时，美国千万吨级氢能规划、日本燃料电池汽车发展目标，实现前景均不容乐观，在“政治愿景”与“产业落地”之间存在严重脱节。
当前，我国氢能在建产能规模已突破100万吨/年，为2030年实现200万吨发展目标筑牢产业根基。政策层面并未设定更为激进的增长指标，凸显清醒务实的发展导向，体现了兼顾产能扩容与行业有序发展的战略布局。
“十四五”时期，国内几乎所有省份都竞相布局氢能产业，部分地区呈现“大干快上、一拥而上”的态势，低水平重复建设问题较为严重，造成了较大的资源浪费。因此，“十五五”时期，更应当引导各地有序发展和重点突破，重点支持在新能源资源丰富、有下游应用场景的地区发展氢能产业，避免全域同质化低水平布局。
从开发模式来看，氢能与新能源的融合开发成为当下的主流路径。通过风光氢储一体化等方式实现新能源与氢能深度融合，既是破解高比例新能源消纳难题的重要手段，也是提升绿氢经济性的关键路径。“三北”地区风光资源丰富，新能源发电度电成本可低至0.10～0.15元/千瓦时，为低成本制氢提供关键支撑。目前已建成和在建的绿氢产能主要集中在这一地区，尤其是内蒙古、吉林、新疆和甘肃等省区。通过风光制氢一体化的方式，绿氢成本可降至15元/千克以内，这方面已经积累了较为丰富的运行经验。
“十五五”期间，依托“沙戈荒”大型新能源基地建设，我国仍将重点在“三北”地区布局风光氢氨醇一体化基地。通过优化风光配比、合理配置储氢储电设施，大幅提升风光氢储系统的自平衡能力，可望实现新能源发电、制氢、储能、用氢全链条协同运行。这在消纳海量富余新能源电力的同时，可以持续降低绿氢生产成本，并为电力系统提供备用支撑。
从应用场景来看，氢能将从单一的交通示范迈向全域多元规模化应用。“十四五”期间，氢能应用集中于交通领域，燃料电池商用车示范是政策主要支持方向，应用场景相对单一、市场体量相对有限。“十五五”期间，应结合绿氢替代在不同领域的技术经济性差异，分阶段推进氢能（重点为绿氢）在工业、交通领域规模化应用，优先布局化工绿氢耦合、氢基绿色燃料赛道。
传统煤制甲醇工艺耦合绿氢，在绿氢替代比例处于较低区间时既可有效管控生产成本上涨，又能通过原料配比优化实现装置适度提产，是现阶段兼顾降碳目标与经济效益的优选路径。因此，近期可结合“沙戈荒”等新能源大基地建设推进绿色氢氨醇基地建设，重点实施煤制氢耦合绿氢示范项目，并逐步扩大项目生产规模，增加绿氢耦合比例。同时结合国际绿色贸易对绿氨和绿醇的需求，持续推进绿色甲醇工程化示范和工艺优化，推动一批有较高绿色溢价的氢基绿色燃料项目落地。
交通领域，应在巩固氢能重卡、氢能物流车等商用车示范优势的基础上，持续提升燃料电池性能与经济性，拓展中远途货运、港口、矿区等专用场景，探索氢能航运、航空等难以电气化的交通脱碳场景，形成规模化交通应用市场。
政策市场协同
加快氢能产业市场化转型
氢能产业规模化突破需政策、市场双向协同发力，推动产业从政策扶持向市场化自主发展转型。“十五五”期间，建议重点从强化政策支撑、推进示范试点、攻坚核心技术等维度持续发力。
首先，持续完善氢能政策，加大对氢能的支持力度。“十五五”期间重点完善消费端氢能支持政策，强化绿色氢氨醇消费引导，促进氢氨醇绿色消费最低比重目标实现，加强与碳考核、碳市场的衔接，将绿氢、绿氨、绿醇全面纳入碳考核、碳市场交易体系，实现低碳减排权益市场化变现。同时，落实、完善绿电直连电价政策，研究对绿色氢氨醇一体化项目自发自用电量给予可再生能源电价附加减免的优惠。
其次，持续推进绿色氢氨醇一体化基地、氢能综合应用试点、绿色液体燃料试点建设。依托“沙戈荒”大基地打造规模化零碳氢能产业集群；分阶段拓展氢能应用场景，近期重点推进工业绿氢替代、氢能重卡示范应用；有序推广氢基绿色燃料在航运、航空领域的规模化应用，探索建筑领域氢能供应、分布式发电场景，构建全域多元应用生态。依托东部示范城市群深耕氢燃料电池装备研发与交通应用。依托西部大基地重点打造绿色氢氨醇规模化产业集群。总结试点成熟模式，形成可复制、可推广的商业化路径，推动全国氢能产业规模化发展。
最后，加大技术攻关力度，推动装备技术进步和成本下降。应以低成本、低能耗、宽动态负荷适应性等为重点，持续提升电解槽技术经济水平。加大对高压储氢、加注及液氢储运装备等关键环节技术的研发投入，突破氢能长距离储运的瓶颈。持续开展燃料电池相关技术攻关，推动催化剂、碳纸、质子交换膜等关键材料自主化替代，推动燃料电池核心部件实现标准化、模块化。依托大基地项目实现绿氢量产降本，推动核心装备迭代扩容、降本增效。
