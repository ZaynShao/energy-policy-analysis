# 综研动态｜“大国博弈下的国际变局与中国‘十五五’展望论坛”在金边举办 曲建副院长担任主讲嘉宾

2026年7月7日，由柬埔寨中国港澳侨商总会、柬埔寨香港商会与香港特区政府驻曼谷经贸办事处共同主办的“大国博弈下的国际变局与中国‘十五五’展望论坛”在柬埔寨金边举行。中国驻柬埔寨大使馆公使衔参赞赵海燕、柬埔寨中国港澳侨商总会会长黄瑞华、香港特区政府驻曼谷经济贸易办事处处长林俊华出席论坛并致辞；中国社会科学院亚太与全球战略研究院首席研究员许利平、综合开发研究院（中国·深圳）副院长曲建担任主讲嘉宾。本次论坛聚焦国际格局演变、中国 “十五五”规划前景及东南亚发展机遇等议题，吸引近300名中柬工商界、侨界人士参会，共同探讨国际变局下的中柬合作新方向。
赵海燕参赞在致辞中表示，中国始终坚持开放合作，以高质量共建 “一带一路”为引领，稳步扩大制度型开放，深化自由贸易协定网络，持续拓展数字经济、绿色经济等合作领域，与世界共享中国超大规模市场红利。在地缘政治竞争加剧的背景下，中国坚持亲诚惠容的周边外交理念，持续深化中柬新时代全天候命运共同体建设，以务实合作成果为地区稳定与发展注入确定性。
他介绍，今年前5个月中柬双边贸易额达93.8亿美元，同比增长22.9%，中国继续保持柬埔寨最大贸易伙伴和最大外资来源国地位；随着中国“十五五”规划落地实施，双方在市场开放、产业协同、互联互通等领域将迎来新的合作空间。赵海燕同时肯定了旅居柬埔寨的港澳侨商连接内地、香港与柬埔寨的桥梁作用，希望广大侨商继续依托东盟、RCEP及中柬自由贸易协定等平台，深化产业链供应链合作，拓展绿色能源、数字经济、现代农业、跨境金融等新兴领域。
黄瑞华会长表示，举办本次论坛旨在搭建高层次交流平台，汇聚各方智慧，帮助侨商与企业界深入研判国际形势，把握中国“十五五”发展机遇，为企业发展和区域合作提供参考。
她介绍，许利平、曲建两位专家长期从事国际关系、区域合作及国际经贸政策研究，具备深厚学术积淀与丰富实践经验，其专题分享将为与会企业拓展合作思路、把握发展机遇提供重要借鉴。未来，柬埔寨中国港澳侨商总会将继续秉持“爱国、爱港、爱澳、爱乡”宗旨，发挥桥梁纽带作用，团结华侨华人与工商界人士，深化交流合作，推动中柬友好合作与区域经济繁荣。
林俊华处长指出，面对复杂多变的国际形势，中国积极践行全球发展倡议、全球安全倡议，坚持合作共赢，为世界和平稳定与发展注入更多确定性。在此背景下，香港将充分发挥“一国两制”下“背靠祖国、联通世界”的独特优势，担当“超级联系人”与“超级增值人”角色，以《香港五年规划》为引领，依托国际金融、航运、贸易及创新科技中心优势，更好融入国家发展大局，深化与柬埔寨及东盟国家的经贸投资合作，服务国家高水平对外开放。
主题分享环节，许利平教授表示，近年来中柬合作持续深化，已形成覆盖基础设施、能源、民生、产业发展的多领域合作格局。西哈努克港经济特区、金港高速公路等项目成为“一带一路”合作的重要成果，有力推动柬埔寨经济发展与区域互联互通；桑河二级水电站、西港燃煤电站及医疗、教育、农业等民生项目持续改善当地发展条件。
他指出，随着中国“十五五”发展战略与柬埔寨“五角战略”进一步对接，“钻石六边”合作框架内的鱼米走廊、工业发展走廊等重点领域将释放更大合作潜力，澜湄合作与RCEP等区域机制也将为中柬产业链、供应链融合提供新动力。
曲建教授表示，“十五五”时期是中国夯实基础、全面发力的关键阶段，规划将围绕高质量发展、科技创新、现代化产业体系建设、扩大高水平对外开放等重点领域系统部署，为2035年基本实现社会主义现代化奠定坚实基础。
中国“十五五”发展不仅关乎自身未来五年方向，也将为柬埔寨等周边国家带来更多经贸合作机遇与区域发展空间，推动双方在产业合作、贸易投资、数字经济、绿色发展等领域拓展更大合作空间，助力区域经济融合发展。
论坛期间，与会嘉宾围绕中国“十五五”规划与柬埔寨“五角战略”的战略对接展开深入交流，结合“钻石六边”合作框架，重点探讨产业协同、区域互联互通与经贸合作新机遇，为深化中柬务实合作、拓展未来合作空间提供了有益参考。（内容来自柬埔寨头条，部分素材来源网络）
