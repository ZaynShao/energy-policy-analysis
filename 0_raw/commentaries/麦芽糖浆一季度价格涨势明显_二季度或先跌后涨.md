# 麦芽糖浆:一季度价格涨势明显 二季度或先跌后涨

【导语**】**一季度国内麦芽糖浆持续上涨，原料成本走高及需求阶段性增加给予市场明显动力，叠加市场情绪的释放，带动一季度麦芽糖浆市场价格整体走高。但随着二季度是麦芽糖浆需求淡季，叠加市场供应预期增量，市场对高价接受度不高，预计二季度麦芽糖浆市场价格或先跌后涨。

**一季度价格涨势明显 修复近一年跌幅**

一季度，国内麦芽糖浆市场整体上涨为主。1月下游春节前的备货生产需求增加，各环节采购积极性较好，市场购销活跃度提升，华北及山东麦芽糖浆生产企业连续上调价格，带动市场重心稳步推涨，至下旬，河南及东北地区生产企业亦上调价格，月内整体价格重心逐步走高。2月春节前期各地市场购销稳定，各地生产企业稳价为主。春节期间市场购销基本停滞，且生产企业多数停机，节后麦芽糖浆生产企业库存压力不大，下游市场处于缓慢恢复阶段，市场交易平平，市场多观望心态，多地市场以稳为主，仅山东地区低价略有走低。3月国内麦芽糖浆先涨后稳。原料玉米及淀粉价格中上旬持续上涨，叠加大宗商品价格整体走高，市场涨价情绪释放，各地生产企业纷纷上调价格，且阶段性有贸易及下游环节补货支撑，带动整体价格重心上扬，下旬各地麦芽糖浆生产企业多数恢复正常开工，货源供应及交货能力提升，但下游终端恢复节奏一般，高价使得各环节采购节奏放缓，多按需采购为主，个别地区价格略有走低。截至3月31日，主产区均价2605元/吨，较2025年底上涨170元/吨，涨幅6.98%，修复了近一年的跌幅。

**玉米价格涨势明显。**一季度，国内玉米价格走势偏强。1月全国玉米价格延续上涨趋势，月均价环比涨。东北、华北等产区基层农户售粮意愿缓慢提升，但市场挺价心态浓厚，整体供应缓慢增量，下游企业、贸易环节积极采购，部分节前备货量提升，供需均存利多。2月全国玉米价格保持上涨势头，月均价环比涨。月内以春节假期为分界点，价格先跌后涨，但节后基层上量不足，下游加工企业、终端养殖单位少量补库，需求增加，市场供需关系偏紧，价格涨幅大于节前跌幅。3月全国玉米价格以上涨为主，月均价环比涨幅扩大。中旬前产区基层供应量增加，但贸易环节采购成本提升，下游各环节积极采购，以及中东局势变化短时助涨市场看涨预期，全国玉米价格涨势加速，下旬随着政策粮持续投放，且下游抵触高价，市场价格小幅回落。截至3月31日，玉米主产区均价2331.26元/吨，较2025年12月31日涨96.42元/吨，涨幅4.31%。原料玉米价格的上涨对麦芽糖浆市场价格形成明显的推动作用。

**基本面整体利多。**一季度，国内麦芽糖浆开工负荷呈现先增后减在回升的态势。1月麦芽糖浆开工负荷为53.87%，环比增加6.52个百分点，月内下游春节前的需求启动，带动市场量价齐升，行业开工负荷环比明显提升。2月上旬行业开工相对偏高，临近春节市场需求节奏放缓，行业开工负荷逐步降低，且春节期间多数停机，部分节后恢复节奏不快，导致行业开工负荷下降，月内麦芽糖浆开工负荷预为37.37%，3月内麦芽糖浆开工负荷预估值为45.20%，价格反弹使得节后生产企业开工负荷恢复节奏较前期预期加快，不过仍低于去年及过去五年同期水平。

从需求端来看，春节前市场需求旺盛，由于今年春节时间较晚，年前市场启动慢于往年同期，部分考虑到生产包装日期问题，下游生产企业多选择在1月份增量生产，1月份啤酒、饮料、糖果、馅料、烘焙及食品类需求进入春节前的生产旺季，各环节采购积极性明显提升，且货源向终端传导节奏加快，整体产销两旺，2月份春节期间购销转淡，各环节多数处于春节假期之中，消化节奏放缓，仅部分规模较大企业保持开工；春节后部分下游陆续复工复产，但整体恢复节奏不快，各产品交易活跃度一般，3月上半月贸易商及下游加工企业建仓及生产性备货增加，各产品货源传导节奏正常，且部分产品出口订单增加，整体需求较上月明显增加，下半月各环节采购节奏放缓。

受开工及需求节奏变动影响，国内麦芽糖浆行业库存呈现整体下降态势，春节前库存下降速度较快，春节后短期回升，3月份整体行业库存稳步减少。截至3月末，行业库存12.24万吨，环比去年12月末下降12.88%，但高于去年同期及过去五年同期均值水平。

**基本面预期平平 二季度或先跌后涨**

**原料玉米预期先弱后强。**4月市场来看，预计市场供应有增量预期，下游刚需预计受到部分来自于替代品的影响，但考虑仍有大型中间商、饲料厂等存在建库可能，预计价格或先跌后涨。5月贸易环节存粮成本提升，市场挺价情绪或依旧存在，对玉米价格形成支撑，但华北地区贸易环节麦收前存腾库需求，市场或存阶段性卖压，价格或窄幅回落，预计5月玉米均价或窄幅上涨。6月初华北部分地区或仍存腾库需求，中下旬贸易环节以运营小麦为主，玉米有效供应或减。随着贸易环节余粮减少，供应或略减，但新小麦上市量增加，饲用小麦使用量或增加，限制饲用玉米需求，供需博弈，预计玉米价格或仍有小幅上涨空间。

**基本面预期提振有限。**3月份行情反弹后麦芽糖浆行业开工负荷恢复较快，货源供应能力稳步提升，4月份市场供应面充裕，下游需求或仍旧处于逐步恢复之中，但下游多处于淡季，市场供大于求基本面或将显现，行业库存预期逐步增加；5-6月份随着气温的升高，糖果类需求将会减弱，不过啤酒及茶饮、冷饮类需求预期增加，市场购销活跃度或提升，不过届时行业开工预期将会稳步提升，市场预期呈现供需双增态势。

**季节性走势下跌为主。**4月市场来看，从过去九年的月均价走势对比来看，二季度整体下跌为主，4月份1年价格上涨、8年价格下跌，5月和6月份价格均为3年上涨、6年下跌，表明二季度市场整体下跌概率明显偏大。

综合来看，一季度市场价格走高是多重利多叠加的结果，尤其是春节后受市场情绪的影响较为明显，但随着市场情绪的释放完毕，预计二季度市场行情将会重回原料及基本面主导，但由于价格反弹至近一年的相对高位水平，市场各环节对高价采购积极性降低，且货源向终端转化节奏不快，预计二季度市场行情或呈现跌后小幅反弹的走势。预计麦芽糖浆主产区均价或在2550-2620元/吨区间运行。
