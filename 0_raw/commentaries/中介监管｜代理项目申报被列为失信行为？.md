# 中介监管｜代理项目申报被列为失信行为？

针对科研经费、财政专项资金的管理办法一直存在不少批评声音。主管部门持续改革管理机制，规范、调整、优化的同时，监管也在不断升级。
近年来，大部分项目都会在申报通知中明确“未委托第三方”，随后又增加了企业自主申报承诺条款，深圳更是将“项目不存在中介代为申请”纳入形式审查要点，广东省工信厅则计划将违规委托代理申报正式列为企业失信行为。
一系列政策信号的密集释放，折射出主管部门对中介代理申报乱象治理的制度闭环。
回顾近年来主管部门对中介代理申报的治理路径，至少存在四种监管路径。
1.通知申明
主管部门发布通知公告都会在文件中提醒警示风险，并发布声明：比如明确“严禁各级工业和信息化主管部门委托任何机构或个人代理本资金项目申报”。
四川科技厅通知中增加“特别申明”
四川省科学技术厅从未委托任何单位或个人为项目申报单位代理项目申报事宜，申报单位必须自主填报项目申报书。凡是购买或委托代写项目申报书，或是提供虚假证明材料的，一经发现并查实，即视为骗取财政资金，一律不予受理、取消申报资格或撤销立项项目，并按规定严肃处理。
2.申报承诺
同时，不少项目增加企业签署的承诺书，承诺“未接受其他机构或个人违规服务代理本资金项目申报，专项资金未用于支付委托任何第三方机构或个人代理协助项目申报的报酬”。
承诺书的引入，将禁止中介代理申报从外部要求转化为企业自主承诺，为后续追责提供了依据。
3.纳入形式审查
以深圳市为例，将“项目不存在中介代为申请等不符合申报要求的情况”正式列入形式审查要点。
深圳市各部门明确规定，申报单位提交申请材料时需认真核查各项要点，“项目经审查不符合下述要点的，形式审查将不予通过”。中介代理申报属于“一票否决”事项，凡存在中介代为申请情形的，将在形式审查环节直接被否决。
4.列入失信惩戒
广东省工业和信息化厅发布的《工信领域企业失信管理规定（征求意见稿）》更进一步，将“企业违背信用承诺，以约定分成等形式委托第三方机构申报财政资金项目的”明确列为失信行为。
一旦被查实，主管部门将依法出具《行政处理决定书》，将企业失信行为信息推送至信用广东平台予以公示。
监管闭环的形成，意味着违规的成本正在急剧上升。无论是申报企业还是服务机构，都需要正视其中风险。
1.“对赌”协议，失去申报资格
部分中介机构与企业签订“对赌”协议，申报成功则按比例分成，申报失败则分文不取，这种模式属于违规行为。
2.约定资金分成，纳入征信管理
以约定分成形式委托第三方机构申报的行为将被认定为失信行为，信息推送至信用广东平台公示。
失信记录不仅影响本次申报，还将对企业后续参与政府采购、申请其他财政资金项目等产生系统性负面影响。
3.违规代理申报，形式审查即被否决
深圳市将“中介代为申请”列入形式审查要点，盐田区在政策宣讲中也明确要求企业“不得以中介机构名义代理申报，不得将资助资金用于支付中介费用”。
福田区更是明确规定，“产业资金项目由企业直接申请，不得委托中介机构办理，一旦发现，取消其产业资金支持资格”。
4.判定违规追回资金，追缴代理机构服务费
对于已获得资助的项目，若事后被发现存在中介代理申报情形，主管部门将依法追回财政资金。
根据相关规定，对骗取财政资金的，视情况取消申报资格，并按有关规定追究法律责任。
