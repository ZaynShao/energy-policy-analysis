# 绿金新闻 | 一张碳标签照亮隐性碳排放 全球供应链掀起碳足迹大考

当动力电池企业出口产品至欧盟、新材料企业为国际品牌供货时，产品碳足迹都是不可或缺的信息。标注产品碳足迹的碳标签，已成为产品获得供应链准入、市场准入的绿色低碳“身份证”。
业内人士表示，近两年产品碳足迹相关业务需求旺盛，推动力主要来自合规要求、供应链准入要求与市场需求。企业梳理碳足迹信息，能够识别生产流程中的节能降碳改造机会；同时，通过搭建数字化管理体系、落实绿色低碳举措，可有效提升自身绿色竞争力。
绿色低碳“身份证”
阳光电源全资子公司阳光慧碳科技有限公司于2021年组建团队，面向企业、园区、工厂等场景提供碳核算、碳减排解决方案及配套服务。阳光慧碳的碳产品负责人李扬告诉中国证券报记者，从前年开始，产品碳足迹相关业务需求快速增长，产品出海是主要推动因素。
李扬透露，在以往交付案例中，以一家国内新材料企业为例，应下游客户要求，企业需要按照欧盟产品环境足迹方法完成相关环境信息披露，其中包含产品碳足迹数据。作为国际品牌的供应商，客户对数据严谨性要求极高，项目团队必须对从数据采集到校验的全流程反复核查。一份符合国际标准的认证报告，成为企业的供应链准入“通行证”。
“当前碳足迹核查需求主要集中于动力电池、新能源汽车、化工、纺织等行业。需求驱动力分为两类：一是海外市场相关合规要求，二是下游供应链低碳准入带来的倒逼作用。”李扬表示。
产品碳足迹，是指产品在整个生命周期中产生的温室气体排放总量，包含从原料获取到废弃处理的全过程，成为衡量产品绿色低碳水平的一个标尺。经过核查后的产品碳足迹数据或输出为一份报告、一份声明，或变身为一张囊括碳足迹信息的标签，成为企业产品的绿色低碳“身份证”。
业内人士普遍认为，驱动国内企业开展产品碳足迹核查的因素来自三方面。首先是法规驱动，如欧盟推出的电池与废电池法规强制要求相关出口企业进行碳足迹核算与核查。“自明年2月起，电动汽车电池、轻型交通工具电池及大容量工业电池进入欧盟市场须配备‘数字电池护照’，涵盖产品碳足迹、供应链尽职调查等信息，如无法达标将不能在欧盟市场上市销售。”李扬说。
其次是供应链准入要求。下游客户基于自身碳管理需要开展供应链碳管控，强制上游供应商提供碳足迹数据，倒逼上游供应商开展碳足迹核查。“全球知名企业，如苹果、三星、大众、特斯拉、宜家、沃尔玛等，已将合规的第三方碳足迹报告列为供应商合作的硬性门槛。”兴业碳金融研究院高级研究员吴艳阳告诉记者。
最后是消费市场的价值驱动。吴艳阳表示：“当前低碳消费趋势愈发明显，消费者愿意为低碳产品支付合理溢价，同时低碳产品在政府采购、绿色项目招投标、绿色信贷中具备显著优势，企业通过碳足迹核查不仅能达到合规要求，还能获得差异化竞争优势。”李扬说，目前在央国企大型项目招标中，产品碳足迹已成为需要考量的要素之一。
获取供应链数据是难点
产品碳足迹的核查工作颇具挑战性。南德认证检测（中国）有限公司碳服务线交付经理王宁介绍，产品碳足迹核查工作流程通常包括确定核算边界、收集数据、建立模型、计算结果、开展核查、形成声明或证书等步骤。
具体到执行层面，李扬表示，团队首先需要对企业生产流程、数据基础进行摸底，然后调研企业组织架构，梳理出重点数据涉及的部门。此外，还需要对企业进行碳足迹政策的解读与普及，为后续工作奠定基础。
在数据采集与核查环节，供应链相关数据的获取、核验是核心难点。“有的企业内部数据基础薄弱，难以获取、验证供应商数据，上游原材料数据的追溯更是一大痛点。”李扬说。
华测检测可持续发展中心华东区市场总监徐志杰表示，获取上游供应商数据是一大工作难点。企业难以获取供应商的生产能耗和排放数据，导致无法准确核算上游供应链的碳足迹。另外，有的企业数据基础薄弱，往往只有总能耗数据，缺乏产线级的精细数据，需要人工进行拆分。在测算产品碳足迹时，这样做会带来较大误差。受访专家表示，在此情况下，核查团队通常会建议企业后续开发、迭代碳足迹管理系统和供应链管理系统。
此外，徐志杰认为，当前产品碳足迹核算与核查标准以及法规要求均不统一，容易导致企业重复投入以应对不同标准。
相关部门正在推动碳足迹相关标准的建立。7月7日，工业和信息化部发布2026年第四批行业标准制修订项目计划，涉及多类产品碳足迹量化标准的制定，包括汽车车轮、铅酸蓄电池、存储设备、耳机、投影显示设备、显示屏等。产品碳足迹数据库建设相关标准的制定也在这批项目计划当中。
推动企业转型升级
王宁在工作中发现，产品碳足迹核查不仅是在计算、验证数字，也是在帮助企业系统性地识别产品全生命周期中的碳排放来源，并进一步推动产品设计、生产管理和供应链管理能力提升。
近期，王宁对一家公司生产的LED显示屏进行产品碳足迹核查，拆解LED显示屏的碳排放来源，涉及电子元器件、金属件、塑料件、包装材料、零部件加工、整机组装、运输等多个环节。“在核查过程中，企业能够更清晰地识别哪些原材料、零部件或生产过程贡献了主要碳排放，从而找到低碳设计、低碳采购和工艺优化的方向。”王宁说，在项目执行过程中，企业建立了废弃物管理系统，建立工时统计台账，使生产数据、能源消耗和物料消耗的管理更加规范，同时在产品设计阶段优化原材料搭配，尝试采用碳排放更低的替代材料。
专家认为，企业往往能在碳核查工作中找到薄弱环节，推动低碳转型。王宁介绍，一家电池企业通过识别不同运输环节的碳排放强度，推动物流供应商提升运输效率、优化货物运输路线。李扬告诉记者，有化工企业利用生产过程中的副产品创造经济价值，实现资源的高效利用与低碳生产。李扬认为，碳足迹核查的价值不止于完成一份合规报告，更在于帮助企业识别减排机会、落地减碳行动，实现“从算碳到减碳”的闭环。
徐志杰表示，在产品碳足迹要求推动下，企业可以通过原材料替代、工艺能效提升、物流与包装减碳等方式，减少产品碳足迹，从而推动生产流程绿色升级，打造长期竞争力。王宁建议，企业应建立产品碳足迹数据平台，将生产环节数据与能源管理系统贯通，可以进一步提升管理精度。
同时，产品碳足迹数据获取需要产业链上下游协作。部分上市公司也在推动供应商开展碳足迹数据协作。首钢股份在近期发布的投资者关系活动记录表中称，2025年公司推动上游38家供应商开展重点物料的碳足迹认证，建立上游物料实景数据因子库，与一汽大众、蔚来、沃尔沃等6家车企签署低碳排放钢合作协议，实现跨领域协同减碳。
