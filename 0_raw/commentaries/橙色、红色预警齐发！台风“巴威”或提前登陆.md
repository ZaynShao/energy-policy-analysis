# 橙色、红色预警齐发！台风“巴威”或提前登陆

台风“巴威”或将提前登陆，中央气象台继续发布台风橙色预警，水利部和中国气象局联合发布红色山洪灾害气象预警。
中央气象台7月11日18时继续发布台风橙色预警：今年第9号台风“巴威”已于今天（11日）中午由强台风级减弱为台风级，下午5点钟其中心位于浙江温岭东南方向约165公里的东海南部海面上，就是北纬27.2度、东经122.4度，中心附近最大风力有13级（40米/秒），中心最低气压为950百帕，七级风圈半径300—500公里，十级风圈半径180—250公里，十二级风圈半径100—120公里。
预计，“巴威”将以每小时30公里左右的速度向西北方向移动，将于11日夜间至12日凌晨在浙江温岭至瑞安一带沿海登陆（台风级，12—13级，33—40米/秒），登陆后向西北转偏北方向移动，强度逐渐减弱。
水利部和中国气象局7月11日18时联合发布红色山洪灾害气象预警：
预计，7月11日20时至7月12日20时，北京东部、天津北部、河北东北部、内蒙古东部、辽宁西部、吉林东北部、黑龙江南部、浙江中南部、安徽南部、福建北部、江西东北部、四川中部等地部分地区发生山洪灾害可能性大（橙色预警），其中，北京东部、天津北部、河北东北部、浙江中南部、安徽南部局地发生山洪灾害可能性很大（红色预警），预警区域涉及的县（市、区）见下表。其他地区也可能因局地短历时强降水引发山洪灾害，请各地注意做好实时监测、防汛预警和转移避险等防范工作。
