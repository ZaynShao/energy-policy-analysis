# 中电联电力检验检测分会正式成立

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/3f8yKfXErDpYxZHc3XfQCDhYFxL97zuUGTibrVEuiaPD2aj5UzcLiaYyvearkD9RvkkYu4kic8SVu9TL4loSq4XZicQ/640?wx_fmt=gif&from=appmsg)

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ApKiaLBgoS3NiaCOAFoiaqtC8hC78SicvTh5EY77FpSXkq5p1iccmibzzL5W68ZgYkROGOUcEicKxnLnTmJzPkBxLEmQltWianOPRp0aHoWDG9ZMBek/640?wx_fmt=jpeg&from=appmsg)

4月10日，中国电力企业联合会电力检验检测分会成立大会在北京举办。中电联党委书记、常务副理事长杨昆，国家能源局电力安全监管司副司长阎秀文、国家市场监督管理总局认可与检验检测监督管理司副司长唐冀平出席会议并致辞。中电联党委副书记、秘书长郝英杰主持会议。

![image](https://mmbiz.qpic.cn/mmbiz_jpg/ApKiaLBgoS3PDUzLwzAnx5yLfxCXg7dhQrlTibq52OKovIqEqAV5zxib0q1e7c5HAIGdWH9SdU3cEhL8o5XzXwKUtuh2sprsBFEg8c6CLOpia4A/640?wx_fmt=jpeg&from=appmsg)

杨昆指出，在“十五五”规划开局、“双碳”目标纵深推进的关键时期成立电力检验检测分会是电力行业响应国家战略部署的重要举措，也是中电联“立足行业、服务企业、联系政府、沟通社会”功能定位的具体实践，对电力检测行业凝聚合力、实现高质量发展具有重要意义，希望分会坚守技术创新方向，加快智能检测装备推广应用，持续提升行业服务能力，全力护航新型电力系统与能源强国建设。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ApKiaLBgoS3MPM1icTEh8egaQ7HDhBiahMlKNGFUE7bIFMibAq0B9ULhicZQrs2yHOOFsphre9bKfnKPxG7uuvHXyLfFmLt79odZuvHCWcqfbj44/640?wx_fmt=jpeg&from=appmsg)

阎秀文表示，电力检验检测是保障电力安全的关键抓手，是电力质量管控的核心支撑，分会的成立对规范行业秩序、推动技术创新、凝聚发展合力意义重大。期待分会聚焦核心使命、筑牢安全根基，强化协同创新、凝聚发展合力，规范行业发展、提升治理效能，以高水平检验检测守护国家能源安全。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ApKiaLBgoS3O44icBsV581aWEK6Rta4lkp3vRAFchxibFEp90ZvE3tEqF01CwglHpXZOLEJpX580ibmGqvd556xovnibLVaKGdSJgp4R88FkEOzI/640?wx_fmt=jpeg&from=appmsg)

唐冀平表示，电力检验检测是保障电网安全稳定运行、助力新型电力系统高质量建设的重要基石，分会的成立将进一步完善电力行业治理体系、凝聚行业合力、共促产业提质升级。希望分会坚守公信力底线、强化技术支撑能力、培育特色行业品牌，为“十五五”时期检验检测工作与电力行业高质量发展注入强劲动能。

![image](https://mmbiz.qpic.cn/mmbiz_jpg/ApKiaLBgoS3PC2YAn7K7JH3VoyYUGBpyNVJqjaZt6IHsbzHUcuIoFFkvTNI58WqOQcsTJPsjhO1ticq9duI1OkJVDEGhav6AgRhsyTEPtXlbs/640?wx_fmt=jpeg&from=appmsg)

会上宣读了分会成立文件，分会首任会长、国家电网有限公司副总工程师兼设备部主任王国春就分会发展规划思路交流发言。中国科学院院士陈维江、中国电力科学研究院有限公司总经理高克利、中国南方电网公司供应链管理部副总经理李有铖、国家能源集团科学技术研究院有限公司副总经理张苏闽、全国无损检测标准化技术委员会副主任委员蒋建生、西安高压电器研究院股份有限公司董事长张晋波分别围绕检验检测前沿技术成果与实践经验作主旨报告。

![image](https://mmbiz.qpic.cn/mmbiz_jpg/ApKiaLBgoS3Na73Vs1EnTgHaJSttRETVzNQ7jcicCZpjUafagUYUqHqGiaYwgyLnK9TicxDb4Uebynjribnpdjo2TLqn4iaP7jRNBMibFu1wRgs0z8/640?wx_fmt=jpeg&from=appmsg)

会议同期召开了分会2026年工作会议，宣读了分会副秘书长任命文件，介绍了分会工作规则，并汇报了2026-2028年三年发展规划（征求意见稿）、2026年重点工作计划（征求意见稿）。与会代表围绕分会职责定位、服务范围、运行机制、能力提升等内容开展深入研讨。

中电联监事长潘跃龙，副秘书长沈维春、丁永福、刘永东，中电联相关部门负责人，以及来自电力企业、科研院所、检验检测机构、设备制造企业的代表共200余人参加会议。会议由中电联（北京）电力检测技术研究院有限公司、中国电力科学研究院有限公司、中电联恒功环保科技（北京）有限公司承办。
