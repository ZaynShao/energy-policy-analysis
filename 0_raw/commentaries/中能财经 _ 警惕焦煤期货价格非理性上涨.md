# 中能财经 | 警惕焦煤期货价格非理性上涨

煤炭市场研报（2026年5月）
邱丽静
（中能传媒能源安全新战略研究院）
◆山西沁源矿难引发区域停产，截至5月28日仍有113座煤矿停产，涉及产能1.25亿吨/年。复产进程偏慢，长治、临汾、吕梁等地部分煤矿仍在等待验收。山西省炼焦煤供应受影响比例从4%扩大至10%，523座样本矿山原煤日产环比减少32.6万吨，焦煤供给短期偏紧格局难改。
◆印尼煤炭出口专营政策将于6月实施，加之2026年工作计划与预算（RKAB）审批收紧及国内市场义务（DMO）比例提升，1—4月我国自印尼进口煤同比已下降8%。澳、俄进口同步减量，蒙煤进口量虽增加61%但难以弥补缺口。1—4月我国累计煤炭进口量同比下降2.1%，外部补充作用明显削弱。
◆电煤需求淡季不淡，截至5月13日当周，沿海八省日耗同比增加7.1%，迎峰度夏备库提前释放；煤化工开工维持高位，非电用煤形成结构性支撑；铁水产量维持240万吨/日高位，冶金煤刚性需求不改。
◆港口5500大卡动力煤报价升至850~860元/吨，年内累计上涨22.4%；但港口库存创年内新高，下游对高价接受度低，钢材价格回落、钢厂利润承压。焦煤期货短期上涨受事件驱动而非需求改善，追高风险较大。
焦煤期货近期走势强劲。
5月26日，大商所焦煤连续主力合约盘中冲上1330元/吨，创18个月新高，收盘涨5.09%，前一交易日涨幅达7.97%。现货市场同步上行，山西吕梁炼焦煤单日上涨100元，报价1700元/吨。资本市场反应积极，盘江股份、平煤股份涨停，新集能源涨超6%。
本轮涨势的直接诱因是5月22日山西沁源留神峪煤矿瓦斯爆炸。这起特别重大事故导致煤矿停产整顿，并引发全省范围的安全大检查。同时，陕西10座煤矿跟进停产自查，合计产能1685万吨。内蒙古鄂尔多斯部分煤矿因完成月度产销任务而停产。供给端收紧的预期，推动了期货和现货市场上涨。
但价格如此大幅上涨，是否合理？
先看停产方面的影响。此次停产多为临时性措施，随着安全检查结束，相关煤矿将陆续复产。山西现有高瓦斯矿井209座，炼焦煤产能约2.8亿吨，占全国炼焦煤总产量的近六成。业内分析认为，不太可能出现长时间大面积停产。安监升级将对违规超产行为形成约束，但对合规生产的矿井影响相对有限。
再看需求端。焦煤下游主要为钢铁行业。5月以来钢材价格持续回落，钢厂利润承压。在事故发生前，焦煤现货价格已呈现走弱态势。中钢协数据显示，5月中旬重点钢企粗钢日产209.6万吨，环比下降0.7%。钢材库存量1877万吨，环比上一旬增加189万吨，增长11.2%。终端需求偏弱，钢厂对高价原料接受度较低，难以支撑焦煤价格持续走高。
动力煤方面，电厂日耗虽同比有所增长，但库存较为充足，现货采购意愿偏低。进口煤价格近期稳中有跌，3800大卡华南到岸价590元/吨，较前期高点下跌15元/吨。中东冲突降温，原油价格回落，进口煤成本下行。夏季用电旺季的预期尚未在现货市场得到体现。
进口端同样构成重要补充。一季度我国从蒙古进口煤炭同比增加80%，其中六成以上为炼焦煤。这部分增量对国内焦煤供给形成有效补充。印尼政府宣布对煤炭出口实行统一管理，市场担忧进口收缩，但具体执行方式和实际影响有待观察。
综合来看，本轮焦煤期货上涨主要受矿难引发的短期供给扰动影响，而非需求改善或供需缺口的根本性变化。停产影响客观存在，但更多是短期和局部性的。需求端缺乏有力支撑，进口端也起到一定对冲作用。
已有市场机构提出煤价具备上涨动力、价格中枢上移等观点。这些判断较多侧重于安监加强和供给收缩，对需求疲弱和进口补充的分析相对不足。短期而言，停产煤矿的复工节奏和安监政策的执行力度仍存在不确定性，价格可能维持一定强势。但中期看，随着停产煤矿陆续复产，供给扰动将逐步消化。钢材需求淡季临近，房地产行业景气度偏低，钢厂利润难以显著改善。届时缺乏需求支撑的焦煤价格，将面临回落压力。
当前焦煤价格处于历史高位，追高风险不容忽视。市场参与者应理性区分基本面驱动与事件驱动，避免跟风炒作。
1.全国煤炭产量环比回落，主产区降幅明显
国家统计局数据显示，4月全国原煤产量为38563万吨，同比下降1.0%，环比下降12.5%。1—4月累计产量为158391万吨，同比微降0.1%。分省来看，4月山西产量10722.5万吨，同比下降3.2%，环比下降7.75%；内蒙古产量9992.3万吨，同比增长1.7%，环比下降20.97%；陕西产量6848.8万吨，同比增长3.9%，环比下降2.45%。新疆产量3507.5万吨，同比下降10.8%，环比下降26.39%。内蒙古环比减量居全国首位，达2651.8万吨。
2.山西煤矿事故突发，复产进程整体偏慢
5月22日，山西长治沁源县留神峪煤矿发生瓦斯爆炸事故，造成多人伤亡。事故发生后，沁源县25座煤矿被叫停，产能2560万吨/年，影响原煤日产量10.53万吨。停产范围迅速扩大，截至5月28日仍有113座煤矿停产，涉及产能1.25亿吨/年，复产进程整体偏慢。长治、临汾、吕梁等地部分煤矿仍在等待验收，晋中42座煤矿停产维持不变。陕西延安复产较快，但产量有所下滑。山西省炼焦煤产量占全国过半，事故后该省炼焦煤供应受影响比例从4%扩大至10%。5月下旬，523座炼焦煤样本矿山原煤日产环比减少32.6万吨，其中山西减少30.6万吨。本次事故对焦煤的供给侧冲击远大于动力煤，短期内炼焦煤供应仍将维持偏紧格局。
1.印尼政策持续加码，外部供应不确定性上升
1—4月，我国自印尼进口煤炭量同比下降8%，背后是印尼政府持续的供给端管控。印尼能矿部加大了对2026年工作计划与预算（RKAB）的审批力度，已有50多家矿商因未能提交获批计划而被冻结许可。同时，印尼国内市场义务（DMO）比例提升至约37%，进一步挤压了出口份额。更值得关注的是，印尼总统于5月20日宣布，将从6月起分阶段实施煤炭出口专营政策，要求所有煤矿出口须经由一家指定国有企业统一办理，此举将给出口市场带来新的不确定性和成本上升压力。综合来看，今年全年印尼煤炭出口量同比下降的趋势已基本确定。
2.主要来源国同步减量，蒙煤增量难以弥补缺口
澳大利亚方面，受日韩等国对高卡煤的强劲需求分流，以及澳洲自身部分煤矿停产影响，其优质焦煤资源偏紧，价格居高不下。1—4月，我国自澳大利亚进口煤炭量同比下降10%。俄罗斯方面，受到岸成本抬升、物流瓶颈（如铁路运力饱和、远东港口冻季发运受阻）以及蒙古煤的强势替代等多重压力，1—4月我国自俄罗斯进口煤炭量同比下降17%。蒙古国成为进口端的唯一增量来源，1—4月我国自蒙古国进口煤炭量同比大幅增长61%。甘其毛都口岸通关效率一度维持高位，5月28日曾激增至1715车/日，但其增量尚不足以完全弥补印尼、澳大利亚、俄罗斯等国减少的供给量，且蒙煤主要影响主焦煤市场，对动力煤市场的补充有限。
3.进口规模总体收缩，补充作用明显削弱
1—4月我国累计进口煤炭同比下降2.1%，4月单月进口量同比、环比分别下降12.5%和15.3%。在国内外价差优势不足及主产国政策双重制约下，进口煤对国内市场的补充作用被显著削弱。
1.电煤需求淡季不淡，旺季备库提前释放
根据CCTD高频监测数据，截至5月13日当周，沿海八省动力煤终端用户日均耗煤水平同比提升7.1%。这一淡季不淡的表现，一方面得益于今年以来全社会用电量的稳健增长，1—4月全社会用电量同比增长5.4%，另一方面也与厄尔尼诺天气背景下市场对今夏高温的普遍预期有关。受看涨预期驱动，下游电力企业迎峰度夏备煤工作明显提前。虽然终端库存有所累积，但拉运和补库需求已在5月份开始有序释放，直接对市场形成了有效支撑。随着夏季用电旺季的正式临近，这部分需求仍有进一步释放的空间。
2.煤化工刚需强劲，非电用煤形成结构性支撑
在国际油气价格高位运行的背景下，煤化工经济性优势凸显，成为今年煤炭需求的重要增长点。据上海钢联分析，煤化工装置维持高开工率，化工煤刚需有力分流了产地货源。CCTD监测显示，煤化工行业开工率整体保持高位，对原料煤的刚需较为强劲。5月非电用煤需求表现强劲，与电煤需求形成共振。虽然近期化工煤需求可能已阶段性见顶，但整体水平仍明显好于往年同期。
3.铁水产量维持高位，冶金煤需求刚性不改
对于受供给冲击最大的炼焦煤而言，其需求端并未同步减弱。据国投期货研究院统计，当前高炉铁水日均产量维持在240万吨左右的高位水平，虽未达到去年高点，但与去年同期淡季水平相当。我的钢铁网数据也显示，钢厂高炉日均铁水产量维持高位，部分低库存企业存在补库需求，焦煤刚需支撑依然较强。5月下旬样本矿山炼焦煤产量骤降的同时，下游采购积极性不减，竞拍市场流拍率降至0%。这意味着对焦煤、焦炭的刚性消耗量依然可观。在供给骤降的背景下，这一刚性需求直接导致了冶金煤市场供需关系的迅速逆转。
1.港口价格持续上行，涨幅有所扩大
5月以来，动力煤市场打破前期僵持格局，价格持续走强。以秦皇岛港5500大卡动力煤为例，年初报价为682元/吨，截至5月中旬已涨至835元/吨，年内累计上涨153元/吨，涨幅达22.4%。仅4月中旬至5月中旬一个月时间，价格从763元/吨攀升至835元/吨，单月涨幅9.44%。
受矿难事故影响，市场情绪快速升温。截至5月25日，“CCTD环渤海动力煤现货参考价”5500大卡、5000大卡、4500大卡三个规格品分别收于838元/吨、751元/吨、656元/吨，环比均上涨4元/吨。至5月27日，三个规格品分别进一步上涨至846元/吨、759元/吨、664元/吨，日环比再涨4元/吨。5月28日，港口市场5500大卡报价已升至850~860元/吨，5000大卡报价755~765元/吨，4500大卡报价660至670元/吨。贸易商挺价惜售情绪浓厚，部分低硫优质煤种价格高位持货惜售。
2.港口库存创年内新高，但同比仍偏低
全国港口煤炭库存呈现先降后升态势。年初库存约7100万吨，2月上旬降至约6100万吨的阶段性低点，此后持续恢复。截至5月11日，全国59个主要港口煤炭库存已回升至7165.6万吨，超过年初水平，创下年内新高。其中，北方港口库存达3730.4万吨，较前期低点增长21.6%；南方港口库存3435.1万吨，较年内低点增长16.4%。
尽管库存总量创年内新高，但同比仍低于去年同期水平。总港存同比偏低8.9%，北方港口偏低12.3%，南方港口偏低5.0%。当前库存增长更多属于季节性修复，尚未对煤价形成明显下行压力。截至5月28日，北方主要五大港库存总量为2895万吨，仍处于相对高位，但下游对高价煤采购意愿不足，北港库存去化缓慢。
1.主产区价格大幅上涨，创年内新高
受供给骤降影响，炼焦煤市场价格显著走强。山西吕梁地区本周煤价整体上涨80~150元/吨，煤矿签单顺畅，部分矿点预售量已至6月下旬。临汾地区价格表现尤为强势，部分高硫肥煤成交价涨至1415元/吨，周环比上涨155元/吨；部分低硫主焦煤竞拍成交价涨至1785元/吨，创近一年来价格新高。5月28日，临汾尧都区高硫强肥煤价格上涨30元/吨至1530元/吨。唐山市场一级干熄焦入炉煤价格上涨40元/吨至1360元/吨。竞拍市场情绪高涨，5月27日竞拍流拍率为0%，下游买货积极性偏高。坑口、竞拍及洗煤厂贸易商报价普遍上涨，涨幅多在50至150元/吨，市场成交顺畅。
2.进口炼焦煤市场涨跌互现，蒙煤通关维持高位
5月28日，甘其毛都口岸蒙5#原煤报价1170元/吨，蒙5#精煤1335元/吨。口岸库存持续累库，已超385万吨，贸易企业报价相对坚挺，但下游询盘价偏低，市场成交冷清。口岸通关延续高位运行，5月28日通关车数超1700车，创近期新高。澳大利亚远期海外炼焦煤一线主焦CFR价格为230.0美元/吨，日环比持平，市场参与者购买意愿趋于谨慎。俄罗斯远期炼焦煤市场报价与还盘差距仍存，交易活动有限。港口海运炼焦煤现货成交平淡，整体资源存量仍处相对高位，期现环节报价相对坚挺，但实盘问价稀少。
1.焦炭市场偏强运行，第五轮提涨预期较强
5月28日，港口焦炭内贸现货交投氛围好转，受期货盘面走高与产地焦炭涨价预期影响，整体询报盘价格走高。部分焦企出现到货困难，有小幅减产，但对整体影响有限。市场预计焦炭第五轮提涨将开启，但钢厂利润偏低，对提涨情绪暂无明确表态。西南、华中、西北地区煤价出现上涨，主产地煤价经过前期上涨后暂稳偏多，个别煤种出现30元/吨的上涨。
2.钢材及铁矿市场震荡运行
5月28日，唐山迁安松汀钢铁普方坯资源上调10元，执行3020元/吨含税出厂。日照港进口铁矿主流品种市场价格下跌2元/吨，PB粉750元/吨。上海建筑钢材价格持稳，螺纹钢报价3130~3250元/吨。杭州热卷价格暂稳，1500卷3420元/吨。钢材出口提供的韧性支撑仍在，但内需表现依然偏疲弱。
一是供给端收缩具有持续性，并非短期脉冲。本次矿难引发的安监升级已超越常规的事故后整顿，正演变为覆盖全行业的超采治理行动。过去游离于核定产能之外的隐性产量将面临系统性压缩，即便停产煤矿逐步复产，其实际出煤能力也将明显弱于事故前。加之6月安全生产月接续影响，民营小矿产能利用率阶段性承压，而产能核增通道收窄，新增产能释放节奏放缓。中期来看，国内煤炭供给弹性已发生根本性削弱，偏紧格局不会因少数煤矿复产而迅速逆转。
二是进口煤补充作用或将弱化，外部供给难以填补缺口。印尼出口专营政策将于6月进入过渡期，统一签约、定价、结算的新模式将增加交易成本与不确定性，印尼煤到岸价格中枢大概率上移。同时，澳大利亚高卡煤受日韩分流，俄罗斯煤受物流瓶颈制约短期内对华出口难有显著增量。蒙古煤虽通关维持高位，但主要填补主焦煤市场，且其增量尚不足以对冲印尼、澳洲等国的减量。综合判断，进口煤对内贸市场的边际补充作用在旺季期间将进一步减弱，国内供需平衡对外部依赖度的降低反而加剧了内贸煤的紧张程度。
三是需求端旺季效应可期，但需关注前置补库的透支风险。厄尔尼诺天气背景下，今夏高温预期较强，电力迎峰度夏需求有望超季节性释放。然而，下游企业基于看涨预期的提前备库行为，已导致沿海样本终端动力煤库存增至3500万吨左右，同比增幅达5%。港口总库存虽同比偏低，但绝对水平处于年内高位。若旺季实际日耗不及预期，流通环节将面临较大出货压力，可能阶段性压制煤价上行高度。
四是煤价上行趋势基本确立，但节奏与幅度受多重因素制约。供给收缩与旺季需求错配的逻辑较为明确，北港5500大卡市场煤价已突破850元/吨，站上年内新高。多家机构上调今年煤价预测，其中中信证券研究将今年二、三季度北港5500大卡均价分别上调至830元/吨和870元/吨，全年均价上调至815至820元/吨。预计三季度煤价延续偏强运行，但上行节奏或呈“快涨慢调”特征。需密切关注政策变量，包括超采行为的查处力度、印尼出口专营政策的落地细节，以及煤价过快上涨可能触发的稳价干预。此外，若夏季降水丰沛导致水电出力超预期，或工业用煤需求季节性回落，也将对煤价形成阶段性压制。
五是投资视角下板块配置价值凸显。煤炭板块前期经历充分调整，而基本面正迎来供给收缩与需求旺季的双重驱动。动力煤龙头企业在长协稳量与现货弹性之间具备平衡优势，焦煤标的则直接受益于主产区供给收缩带来的价格弹性。随着煤价中枢上移确认，板块估值修复空间有望打开。但需注意，若安监执行力度不及预期，或夏季用电需求疲弱，市场可能面临回落风险。
