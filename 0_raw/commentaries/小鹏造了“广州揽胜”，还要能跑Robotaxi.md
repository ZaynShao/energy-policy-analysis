# 小鹏造了“广州揽胜”，还要能跑Robotaxi

“小鹏来了！”

在拥挤的三排六座SUV市场，小鹏汽车也推出了自己的产品。何小鹏在发布会上，高声宣战。

4月15日，深圳。小鹏汽车首款全尺寸旗舰SUV——小鹏GX正式开启预售，预售价39.98万元。纯电版四驱续航750km，超级增程版综合续航高达1585km。

看上去，小鹏是随大流，做了一款“广州揽胜”，尤其是其外观和车身姿态，让人觉得又是“仿造”。但小鹏GX的内在，大不相同。

仅举一例：小鹏GX是小鹏汽车乃至全行业第一款L4硬件预埋的车，承载了小鹏汽车跑通乘用车L4和Robotaxi的使命。

在众多六座旗舰SUV中，小鹏GX有自己的独特底色。

01

何小鹏为自己和朋友圈造的车

“最开始考虑，这款车应该是我、跟我的朋友圈都喜欢想买的一款车。”

和李想类似，何小鹏终于开始为自己造车了。

从成功的企业家角度出发，高端、豪华自然是应有之义，但首先，还是要极度的安全。

因此，何小鹏在介绍小鹏GX的时候，一开始用了大段篇幅介绍其安全性。

小鹏GX先秀的是被动安全，而且直接放大招，来了一个行业首次720度立体五重连环碰撞测试。

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeXe9xib3UDJNdsFDEeGRg5MibZfWmNo8YOeA9nZJbST9rQfibKnTE5bUgVnjXVjPM9s7p01xp9h6JzRjDYmYvWsBA5ibT8RicoS22QY/640?wx_fmt=png&from=appmsg)

这五重碰撞测试是：第一重：底部刮擦，先以30km/h时速托底，再进行700mm深的涉水测试；第二重：100km/h的正面偏置碰撞；第三重：100km/h的正侧碰撞；第四重是100km/h速度下，左后45°追尾碰撞；第五重是顶部2.2吨集装箱离车1米砸顶。

这五重碰撞测试是串行测试，即一辆车连续完成。

其结果当然无意外，小鹏GX成功完成所有挑战。

这一测试远超国标的极端工况，证明小鹏GX的整车安全实力确实强悍。

另外，小鹏GX还配备11个安全气囊，做到行业领先，其中包括零重力座椅坐垫也有2个气囊。

主动安全方面，X-VMC智能融合系统能在冰雪稳行控制、弯道爆胎、动态驾乘等场景带来极致安全保障。更重要的是实现了150km/h的行业最高AEB刹停速度——这意味着危险来临前，它比你更早一步做出反应。同时支持130km/h最高AES避让速度，支持冰雪湿滑低附路面功能，提前预判并规避各类行车险情。

除此之外，小鹏GX还带来了一项重点功能——驾驶员失能辅助系统，将小鹏最强的自动驾驶能力，赋能整车安全中。高速智驾场景下，可精准识别驾驶员失能状态，自动完成双闪警示、连续点刹唤醒、平稳变道、寻找应急区域、制动停车、SOS灯光投影、拨打救援电话、解锁车门全流程操作，即便遇到实线、无应急车道等复杂场景，也可实现跨多车道、路况博弈、自主寻找安全区域，为生命救援抢占黄金时间。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeVUHOObo8u8ib4Rqa8o0JhTHkrtt79xFT8kJXSSE58TNaqlwwSibodIEOxclJtIlQ91f5pKdKKiahGUMh9ZKEZy6xNlhALiaGxzOag/640?wx_fmt=png&from=appmsg)

在被动安全、主动安全之外，小鹏GX还破天荒，引入了航空级冗余安全，覆盖转向、制动、驱动、通信、供电、解锁六大核心维度，与小鹏汇天的飞行汽车共享技术。这意味着即便在系统层面出现故障，车辆依然有Plan B、Plan C、Plan D。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeVDb0QBU2DFUHmx4QfibUwRK320diayUlCgMW5O07JK2naOhtticl5ywXnhJ9me4QTxVmSqKNmZcF5rVyucgQDYR1aMAxIjwcxfhA/640?wx_fmt=png&from=appmsg)

不过，安全往往不是显性卖点，小鹏GX还有其他。

操控从来不是大车的强项，但GX想改变这一刻板印象。原生线控底盘集成X-VMC智能融合系统、线控液压制动、双腔空气悬架、智能四驱、线控后轮转向，全维度重构大车操控体验。线控前轮转向带来极致手感、极致舒适、极致安静三大提升，全速域都能拥有最佳指向精度，低速丝滑，高速稳健。  

基于线控和后轮转向，小鹏GX还将推出微动泊车模式，智驾泊车方向盘转角只有±10º，泊车过程更加从容安静。百公里制动距离34.4米，达到全尺寸大六座SUV最优水准——紧急情况下，可以为你多预留半个车身的安全距离。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeWicIO7ODFxumDE9VdibRIBdW1h9aeTCMGK98SRBQweQNq29xf0KjricfgNPsjQ8SmQ0gRHHr8xNVc9ficOOIIlkwPguIkcljuTWM4/640?wx_fmt=png&from=appmsg)

空间方面，小鹏GX承接了小鹏X9的空间魔术技能。首先，小鹏GX尺寸很大，长宽高5265mm*1999mm*1800mm，搭配3115mm超长轴距。

有此做基础，小鹏GX没有做传统大型SUV的长鼻子，而是将更多空间留给座舱。一二排空间超豪华D级车，第三排空间比肩顶级 MPV，更是同级唯一实现第三排座椅0-180°靠背电动调节、可完全平躺的车型。同时，小鹏GX还配置两把零重力座椅，一把飞航舒享座椅，让你随时可以躺平。

其次，小鹏GX在空间灵活性上也拉满。小鹏GX是全球唯一搭载三排电动三折叠大六座SUV，第三排支持两个座椅独立收纳，并且小鹏GX可根据出行需求灵活切换4/5/6座空间模式。全车更配备62处收纳储物空间，满足家庭出行的全场景储物需求。

在舒适配置性上，小鹏GX也卷得更上层楼。仅举两个例子：其一，冰箱是AI无菌风冷双开门双温区车载冰箱，是行业首个拥有杀菌功能的风冷无霜车载冰箱，满足健康锁鲜需求。其二，小鹏GX还搭载全球首发AI调光隐私玻璃，有0.16s行业最快变色速度。

4月15日主要是小鹏GX的技术发布会，而且偏重安全技术，其动力、续航和功能、体验，包括智驾智舱，还没有透露很多信息。

但是，小鹏GX在“揽胜”的外衣下，已经体现出了智能电动汽车时代全尺寸SUV的新功能和新体验。

02

能跑Robotaxi的豪华SUV

更何况，这还是一款希望能跑Robotaxi的SUV。

之前，小鹏汽车放出了不少L4测试的图片和视频，里面的测试车，就是小鹏GX。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/RaRCbSicibjeWexOYKV6DkXKYaQsJSKCKY2sEhEl0GYwQB3E8NoDrtF1knN6vFibYAtgoYVbRjjqQCG5DicibTTGWhNkqI4odAP0OAI1cAmdJb7c/640?wx_fmt=jpeg&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=6)

小鹏的L4测试车辆正是小鹏GX

何小鹏介绍，小鹏GX是中国首款全栈自研前装量产Robotaxi原型车。只不过，对于面向私人消费市场，小鹏GX将Robotaxi能力下放，以面向L4时代的底层架构，给消费者提供智驾能力。

小鹏GX在算力方面更进一步，搭载4颗小鹏自研图灵芯片，算力至高3000TOPS。3颗和此前车型的配置相同，新增1颗，用作冗余备份。

软件算法方面，小鹏GX也搭载小鹏第二代VLA，带来了强大的园区漫游能力。即使在暴雨、大雾、暗光等复杂场景中，小鹏GX也能通过园区漫游功能顺利前进，并实现对障碍物的精准避让。

同时，第二代VLA也还在持续不断进化，实现智能驾驶、语音控车、智能灯语三大功能的深度融合，支持高速服务区无需接管自主泊车、VLA+VLM语音控车前行、智能灯语表达。

此外，小鹏GX座舱搭载了侧端VLM大模型，支持本地模糊语义对话，模糊地点搜索、复杂路线选择、高情商对话、自定义趣味互动，像人类一样理解和反馈，更懂你更好用。

当然，如果是Robotaxi版本，它还会有独特的功能，比如，识别打车手势、靠近停车等等。

小鹏已经计划要推进Robotaxi的上路测试和应用。不过，特斯拉设计的CYBERCAB，像是Model 3的减配版。但小鹏要用旗舰、全尺寸SUV来跑Robotaxi，是不是太奢侈了？

何小鹏表示小鹏GX不会是后面Robotaxi的主力车型，但是测试阶段需要用这款车。因为小鹏GX是全新平台，第一次把全部的冗余都上了。

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeUxD32Mzhq1ibjuSqtWW57qcrTaTs0csrWfcnOvuecycHN3VQCFL6JqA0KeiaNOoXmEibyHWBs40icnY7WMEtXqT4bnDB6pFm9K5tc/640?wx_fmt=png&from=appmsg)

何小鹏（左）接受媒体采访

何小鹏认为，Robotaxi对车辆的需求，与旗舰SUV目标用户的需求高度契合。

“全部冗余对于大部分人，是不需要的。但是全尺寸、高端SUV用户，这些冗余大部分都需要，比如说线控的冗余，制动的冗余，转向的冗余……它是最佳的模块化平台。所以用一款大车来探索Robotaxi，将来再做一款全新的4门车来真正进入全球的Robotaxi市场。”

在发布会后的群访环节，有媒体提出小鹏如何看待豪华的问题。

何小鹏认为，豪华的定义不是固定的。“如果今天我们穿越回100年前，在那个时代你觉得的豪华跟今天看到的豪华又不一样。你会觉得那个时候的豪华可能叫复古豪华，比如红木家具。”

对于小鹏所主张的科技豪华，何小鹏说，要往未来看，往更年轻的心态看。

从航空级安全冗余、能跑Robotaxi的底层架构、塑造百变空间的底盘和座舱来看，小鹏GX正在定义面向未来的豪华属性。

小鹏制造的“广州揽胜”，绝非传统揽胜。

还有媒体问何小鹏，GX要达到怎样的目标。

何小鹏表示，目标就是进入Top3。“这个目标挺高的，我们会全力以赴。”
