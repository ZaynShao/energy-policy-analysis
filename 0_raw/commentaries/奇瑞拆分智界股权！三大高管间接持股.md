# 奇瑞拆分智界股权！三大高管间接持股

车东西6月30日消息，根据企查查上的数据显示，安徽智界新能源汽车有限公司股东信息发生变化，奇瑞汽车股份有限公司持股比例由100%下降至85%，其余15%的股权由芜湖瑞启股权投资合伙企业（有限合伙）持股7.5%、芜湖瑞联股权投资合伙企业（有限合伙）持股7.5%。▲安徽智界新能源汽车有限公司股东信息（图源：企查查）
芜湖瑞启股权投资合伙企业（有限合伙）的合伙人包括郭锐和芜湖瑞曜企业管理咨询有限公司，其中郭锐出资比例0.01%，芜湖瑞曜企业管理咨询有限公司出资比例99.99%，芜湖瑞联股权投资合伙企业（有限合伙）的合伙人同样包括郭锐和芜湖瑞曜企业管理咨询有限公司，其中郭锐出资比例0.01%，芜湖瑞曜企业管理咨询有限公司出资比例99.99%。▲安徽智界新能源汽车有限公司股东信息（图源：企查查）
芜湖瑞曜企业管理咨询有限公司的股东则包含了郭锐、赵长江和朱小冬，其中郭锐持股比例40%，赵长江持股比例30%，朱小冬持股比例30%。综上进行计算，此次变化后，郭锐合计间接持有安徽智界新能源汽车有限公司股权约6%，赵长江合计间接持有约4.5%，朱小冬合计间接持有约4.5%。今年4月2日，智界汽车宣布郭锐出任董事长兼首席执行官，全面负责公司经营管理工作。▲智界汽车董事长兼首席执行官郭锐
据悉，郭锐毕业于北京大学信息科学技术学院，获理学博士学位，2017-2021年曾担任华为终端大中华区首席营销官（CMO）。2021年8月他作为创始团队成员加入独立后的新荣耀，全面负责荣耀品牌营销体系建设，2025年12月12日官宣辞去荣耀品牌营销总裁、集团首席营销官（CMO）、管理团队（EMT）成员、投资决策委员会（IRB）委员职位。同样在今年1月13日，赵长江在社交媒体上发文，正式宣布加入鸿蒙智行旗下智界汽车，任智界汽车执行董事及执行副总裁。根据公开资料显示，2009年赵长江大学毕业就加入比亚迪，后升任比亚迪汽车销售有限公司总经理、腾势品牌事业部总经理等职位。▲智界汽车执行董事及执行副总裁赵长江
关于安徽智界新能源汽车有限公司，2025年8月7日，智界汽车曾在社交媒体上发文表示，智界品牌正式进入2.0阶段，其中包括成立智界新能源公司，产销服将一体化独立运作。▲智界汽车在社交媒体上发文
