# AIDC储能会议观察：UPS“变局”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIufYh8MHIiaAIdO7jm2ca2YKABBp1sk1icZGbpy8dEzLe27bPyL7wt2YBUicfZuv7aeV3EN8K3VoZoqsVJnb5NSuFntKOC1VMbg9A/640?wx_fmt=png&from=appmsg)

  

AIDC（人工智能数据中心）对算力需求的大幅攀升，正在从根本上重塑其对供电系统的需求。

  

当前，AIDC采用的主流电源架构仍然是传统UPS的交流供电体系，但AIDC的高能耗需求，为供电系统带来了高功率、高波动、高容量等挑战，长期来看，这将促使电源架构从传统UPS走向高压直流、设施级模块化与多端口SST。

  

![image](https://mmbiz.qpic.cn/mmbiz_png/bhqZZ4eZhIvnvcRx2ejVRp9K9L9Sf3vjpolibeEr3gJsic5FQpoGIZxUQuianCBLG10mdrB8iayDldsvBs1h8Aft6US37XR1XL8XfI1BTa8BNOM/640?wx_fmt=png&from=appmsg)

  

但短期来看，AIDC的兴起带动了对UPS需求的爆发式增长，企业在订单“接到手软”的同时，也必须直面AIDC的新要求，这也为格局固定的UPS行业带来了新的变量。  

  

在数据中心高密化、绿色化等发展趋势带动下，UPS产品正向着大功率、节能低碳、模块化、集成化方向发展，同时，也需要适配新的电源架构体系，与BBU、柴油发电系统等形成更复杂的协同工作机制。

  
  
  

****传统UPS行业格局****  
  
  

据QYResearch数据，2025年全球UPS市场销售额达到127.3亿美元，预计2032年将达到197.6亿美元，年复合增长率（CAGR）为7.1%。其中，2025年中国UPS市场规模达27.9亿美元，约占全球市场的22%，预计到2032年，中国市场规模将攀升至47.4亿美元，全球占比将提升至24%。

  

当前，全球及中国UPS市场已形成较为稳定的竞争格局，呈现出“头部集中+长尾分化”的结构特征。

  

第一梯队是维谛技术（Vertiv）、伊顿（Eaton）、施耐德电气（Schneider Electric）等国际老牌电力基础设施企业，这些国际巨头凭借技术积累、全球供应链和高端市场经验，在大型数据中心、金融、电信等领域占据重要份额，尤其在高端、高可靠性需求场景优势明显，其UPS产品占据了全球60%的市场份额。

  

第二梯队企业由科华数据、华为、科士达、台达、山特、英威腾、易事特等国内企业组成，它们通过技术自主研发、模块化设计及本土化服务，在国内市场快速崛起，且逐步拓展海外市场。在政策推动、国产替代趋势加强的背景下，本土厂商依然空间巨大。随着国内AIDC建设速度加快，这些具有更强的交付能力和更具竞争力的成本结构的国内企业，正在加速向高压直流供电、液冷供电系统、模块化电源柜、智能运维等方向迭代。

  

此外，还有上千家中小厂商组成的第三梯队，主要依靠价格竞争。2025年1月1日国内正式实施的《数据中心能效限定值及能效等级》（GB40879-2025），要求新建A级数据中心UPS效率不低于96%，预计将淘汰部分高耗能产品，加快行业出清。

  
  
  

****AIDC风潮下的新变局****  
  

  

先行者卡位，迟缓者掉队。AIDC的兴起并非简单的“UPS需求增长”的新故事，而是一场深刻的行业洗牌，既考验企业的技术储备，也考验其战略决断力。

  

UPS产品正从内部开始变革。新的国家标准倒逼电源系统能效提升，UPS开始向模块化、高频化、锂电化、智能化方向发展。

  

国内高频UPS已经成为市场主流，渗透率也有望由2024年的78.3%提升至2027年的90%。头部企业如施耐德电气、华为已在2026年推出98%能效的模块化UPS方案，标准该技术进入落地阶段。

  

UPS市场中，锂电渗透率约30%，正在逐渐加速替代铅酸，这一过程在AIDC中尤为迅速。

  

南都电源预测，到2026年全球数据中心对高压锂电的需求将达20GWh左右，2030年可能突破100GWh，增长主要来自：AIDC新建项目几乎全部采用高压锂电；传统数据中心中锂电替代铅酸的渗透率逐步提升，预计2030年可达80%。

  

在此背景下，双登股份、国轩高科、南都电源、昆宇电源、雄韬股份、盛弘股份等锂电UPS供应商2025年订单高增，欣旺达、海辰储能等产业链企业也快速构建了完备AIDC产品矩阵。宁德时代更是豪掷41亿元，认购HVDC龙头中恒电气49%股权，拿下AIDC新门票。

  

此外，为应对高功率密度挑战，行业正从传统UPS向高压直流（HVDC）、SST方向演进，UPS企业也在积极跟进新的技术趋势。

  

其中，阿里联合中恒电气、台达推出了巴拿马电源，台达该产品在线运行数量已超500套，维谛、施耐德在着力推进 800VDC+Sidecar路线，华为也在积极打造弹性供电与模块化基础设施。

  

总体来看，UPS行业正在面临技术路线、锂电替代、供应链格局三重之变，头部企业凭借模块化、高压直流及智能化卡位优势加速领跑，而技术储备薄弱者将面临出清。未来几年，谁能在能效、密度、协同方面率先突破，才能定义下一代数据中心供电标准。
