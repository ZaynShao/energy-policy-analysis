# 关注 | 让惠企红利精准落地，市经信局召开服务券合规工作专题会议

服务券惠及面扩大，已有超1000家企业领券
今年，市经信局联合市财政局对服务券管理办法进行了全面升级，服务领域从原来的部分类别扩大到数字赋能、管理咨询、法律维权、绿色低碳等10大类，基本覆盖了企业从初创到成长阶段最迫切的外部需求。自6月25日启动，目前领券企业已突破1000家。
会议明确，对存在违规行为的服务机构，一经查实，将作平台清退、追回补助资金、三年内禁止申请公共政策支持资金、记入信用档案等处理；涉及虚构交易、套利等严重违法行为的，移交司法机关处理。
市经信局中小企业发展处负责人向服务机构提出五点要求：第一，坚守真实服务底线，严禁各类虚假交易。第二，规范合同与价格管理，做到公开透明、公平合理。第三，严格兑付资料合规，杜绝材料弄虚作假。第四，抓实服务质量管理，兼顾合规性与实效性。第五，主动接受监督监管，明晰违规惩戒后果。
规范使用服务券，这几点要牢记
广大中小微企业也要注意，服务券的规范使用，需要服务机构和中小微企业双向发力、共同守护。在此提醒广大用券企业：
一是严禁与服务机构串通，签订虚假合同、编造虚假服务内容，套取财政资金；
二是严禁配合机构“走过场”式服务，对企业自身没有实际需求、没有真实接受服务的交易，不得确认验收；
三是严禁与中介机构合作，通过“介绍客户、虚假服务、按比例分成”等方式骗取补贴；
四是严禁倒买倒卖服务券，服务券仅限本企业使用，不得转让、买卖、质押或挪作他用。
服务券虽小，承载的却是政府支持中小微企业发展的决心，也考验着每一家服务机构的诚信与担当。把服务做实，把台账做细，让政策红利真正落到企业身上，才是这项工作的意义所在。
