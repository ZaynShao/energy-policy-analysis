# 委内瑞拉一油井突发爆炸

委内瑞拉西南部一油井爆炸致12人受伤。
据委内瑞拉媒体29日援引阿普雷州公民安全局消息人士的话报道，该州一口油井当天发生爆炸，造成12人受伤。
报道称，事故发生在靠近哥伦比亚边境的拉维多利亚镇附近。事发地附近居民已被疏散。
阿普雷州公民安全局称，爆炸由“可燃气体泄漏”引起。截至目前，委内瑞拉国家石油公司尚未就此事发布任何信息。
