# 再次征求意见｜科技创新如何奖补？

2026年，中国产业政策领域迎来深刻变革。
国务院常务会议明确提出建立全国统一的地方财政补贴负面清单管理机制，《公平竞争审查条例》已明令禁止“给予特定经营者选择性、差异化的财政奖励或者补贴”。
市场监管总局近期部署开展2026年度公平竞争审查抽查，重点瞄准地方违规财政奖补政策措施。
一、合规之下的研发费补贴模式
1. 实施研发机构建设奖补
企业按“六有”标准建设研发机构并完成市级备案，且当年实际研发投入20万元以上，按10%奖补，最高10万元；完成自治区级备案且研发投入50万元以上，按12%奖补，最高20万元。
2. 实施研发活动“破零”奖补
对研发活动实现“破零”且研发投入10万元以上的规上工业企业，给予10%的研发经费奖补，最高10万元。
3. 开展研发机构提级奖补
对通过自治区级备案且在专职人员、研发投入、成果产出等方面较上一年度实现较大提升的研发机构进行奖补，支持科技领军企业、链主企业组建高能级平台。
4. 发挥链主企业创新引领作用
支持科技领军企业、链主企业牵头组建创新联合体，以“链主带动、协同攻关、成果共享”方式引导中小企业开展产业链协同创新。
5. 强化高企“升规”激励
对首次纳入规上企业统计，且上年实际研发经费投入不低于50万元的高新技术企业，一次性奖补5万元。
6. 实施规上工业企业“高新化”奖励
对新认定为高新技术企业，且上年实际研发经费投入不低于100万元的规上工业企业，给予一次性奖励10万元。
7. 开展企业创新诊断
8. 推动诊断成果转化落地
支持诊断凝练形成的研发投入100万元以上的科技项目列入广西科技计划自筹经费项目；支持以“揭榜挂帅”方式招引科研主体开展技术攻关。
9. 实施人才引育激励
支持“双清零”企业与自治区卓越工程师创新研究院等平台深度合作，对引进毕业年度博士、硕士的企业分别给予一次性引才补贴4000元/人、3000元/人。
二、重新定义“奖补挂钩指标”
负面清单禁止的是与产值、销售额、税收等经营成果挂钩的奖补，但并未禁止与研发投入、研发机构建设、人才引进等创新行为挂钩的激励。
广西《激励措施》的制度设计，清晰勾勒出三条转型路径：
1. 补贴研发：高企和上规的奖补挂钩研发投入
高企“升规”激励要求“上年实际研发经费投入不低于50万元”，规上工业企业“高新化”奖励要求“上年实际研发经费投入不低于100万元”。奖补的触发条件是研发投入，而非企业规模或纳税贡献。
2. 从“直接给钱”转向“购买服务”
第七条设立创新诊断专项经费，政府购买第三方专业机构的诊断服务；第八条支持“揭榜挂帅”方式招引科研主体，财政资金的使用方式从“奖补”变为“服务采购”，既符合公平竞争审查要求，又切实解决了中小企业“不知道往哪创新”的核心痛点。
3. 创新平台的补贴不在投资建设和认定，而是以研发费投入为依据
研发机构建设奖补的核心挂钩指标是“当年实际研发投入”，而非研发机构的硬件投资额或认定等级。奖补比例（10%/12%）和封顶额度（10万/20万）均以研发投入为计算基准。
三、结束语
负面清单不是产业扶持的“休止符”，而是“换挡期”。负面清单明确“清单之外的领域，地方仍可根据实际，对国家战略科技力量、中小微企业普惠性支持等领域给予合规补贴”。
各地如何因地制宜做好产业发展政策措施，正在考验地方官员的政治和技术水平。
