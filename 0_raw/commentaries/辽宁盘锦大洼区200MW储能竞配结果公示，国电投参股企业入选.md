# 辽宁盘锦大洼区200MW储能竞配结果公示，国电投参股企业入选

「储能与电力市场」获悉，7月13日，辽宁盘锦市大洼区人民政府发布关于盘锦市大洼区20万千瓦新型储能项目竞争性配置结果的公示。经过第三方专业机构组织专家对项目的评审，确定推荐沈阳和平调频储能电站有限公司盘锦市大洼区20万千瓦新型储能项目作为大洼区参与全市竞争性配置项目。天眼查显示，沈阳和平调频储能电站有限公司为寰宇新能（辽宁）新能源科技有限公司与沈阳航空油料有限公司合资公司，其中寰宇新能（辽宁）新能源科技有限公司为国核投资有限公司旗下公司。国核投资有限公司成立于2014年5月，注册资本1亿元人民币；国家电投集团产业基金管理有限公司为公司参股股东，持股比例20%。国核投资有限公司重点布局新型储能、光伏、风电、核电产业链投资，是辽宁区域多个储能项目的投资方。图：沈阳和平调频储能电站有限公司股权穿透图
