# C Talk | 李尔Enrique Orta：以中国市场为创新增长引擎，持续卓越运营并提升客户价值

加入整车产业群，请加微信gasgoo2015，出示名片
对话 | C Talk栏目主理人、盖世汽车CEO兼资讯总编 周晓莺
撰文 | 盖世汽车编辑 占亚娥
在接受盖世汽车《C Talk》专访时，李尔（Lear）连接器系统（Connection Systems, CS）与电气分配系统（Electrical Distribution System, EDS）全球副总裁 Enrique Orta 分享了公司如何把握汽车电动化、智能化发展机遇，并通过持续创新与卓越工程能力，为客户创造更大价值。
随着汽车电子电气（E/E）架构持续演进，连接器系统和电气分配系统的重要性日益提升，这进一步彰显了李尔电子电气业务在支持汽车行业变革和满足客户不断发展需求方面的关键作用。
观看完整《C Talk》专访，聆听 Enrique 对下一代汽车架构发展趋势以及李尔未来战略布局的深度解读。
李尔连接器系统和电气分配系统全球副总裁Enrique Orta（图右）与盖世汽车CEO兼资讯总编周晓莺（图左）
以下为访谈实录
对话
业绩增长背后的四大核心驱动力
Q
周晓莺：我们看到，尽管行业面临诸多挑战，李尔第一季度交出了一份非常亮眼的成绩单。您认为支撑李尔持续增长的核心驱动力是什么？
Enrique Orta：关键在于做好自己能掌控的事情。对我们来说，持续且稳健的增长根基在于卓越的运营表现，这也是李尔最具代表性的优势。我们的运营能力备受认可，是一家稳健、值得信赖的供应商，这也是我们成功的关键。
第二点当然是产品。我们拥有合理且完善的产品组合，涵盖连接器系统、电气分配系统、电子产品以及座椅业务，因此具备独特的市场定位。在全球Tier 1供应商中，李尔具备差异化竞争优势。
第三点是我们IDEA by Lear™的实施。IDEA代表——创新驱动、数字引领、产品增值和智能制造，如今已融入公司DNA。IDEA by Lear™是公司持续推动战略落地的框架，帮助我们实现标准化、自动化、数字化以及持续创新，从而更快响应市场需求。IDEA by Lear™也促使我们的员工以不同的方式思考，主动担当，并持续创新。因此，我们非常自豪拥有IDEA by Lear™这一战略框架。
最后一点当然是客户关系。我们不会想当然地做任何事，而是始终为客户创造更大价值，这是我们始终坚持的原则。因此，我们不断提升了市场份额以及与传统客户合作的深度；与此同时，我们也获得了许多新客户，主要来自中国。我们非常自豪能够获得客户的认可，我们荣获了通用汽车“年度供应商”称号，这对我们是极大的认可。当然，不仅仅是通用，我们也获得了众多中国客户的认可，以及其他传统客户的高度评价。
因此我可以非常自豪地说，第一季度我们的业绩表现十分强劲，客户认可也创下新高，不仅体现在各类奖项上，也体现在我们获得的众多新业务上。
A
连接器与电气分配系统，
成为智能汽车的骨干架构
Q
周晓莺：您认为连接器系统和电气分配系统在公司增长战略中发挥怎样的作用？
Enrique Orta：随着汽车不断向电动化发展，互联化程度不断提升，我们看到电气分配系统和连接器系统正成为整车的骨干架构。
过去，汽车线束只需要关注电源分配，如今，线束不仅需要分配电源，还传输信号，并且车内承载的信号越来越多：比如车辆的各类安全系统，比如车辆与驾驶员、乘客、以及云端之间的连接。车辆中的连接器数量也在不断增加，因为如今车辆架构也有很大的变化：例如有很多客户采用区域控制器架构，也有客户采用中央计算架构。电气分配系统也在不断演进，随着电动化的发展，如今我们开始讨论高压系统。所以上述零部件的重要性比以往更高。
图片来源：李尔
第二点，这些年来李尔一直在成长，努力从零部件供应商转型为系统供应商。因为客户的期待也在演进，过去，客户采购的是单独的零部件，如今，他们更需要系统集成。系统集成意味着客户希望获得更强的功能、更低的复杂度，当然，还希望整车更轻量化，而李尔在这方面具备独特优势。
同时，我们看到随着汽车不断演进，中国也在其中发挥着重要作用，推动整个汽车产业加速电动化并快速引入自动驾驶技术。在这一过程中，我们的产品在整车中的重要性正不断提升，也因此，我们获得了客户的广泛认可。近期，我们与中国客户达成了许多新的业务合作；与此同时，在传统客户方面，我们也赢得了通用汽车T1全尺寸SUV平台的部分业务，这还只是开始。
连接器系统和电气分配系统将变得越来越重要，且与汽车电动化、数字化的发展越来越强相关。而李尔始终站在行业前沿，为客户提供完整的整车电子电气架构解决方案，无论是依托我们的产品，还是将我们的产品与其他方案进行系统集成。
A
创新不是目的，创造客户价值才是
Q
周晓莺：从技术创新到产品落地、再到商业化应用，实际上这是一个非常漫长的过程。那么李尔如何将技术创新转化为可持续的竞争优势？
Enrique Orta：“中国速度”正在助力这一过程。过去，产品周期很长，例如从线束设计到实现量产需要经历很长时间；如今，我们看到这一周期正在大幅缩短，很多中国车企要求从项目定点到量产只需要六个月，这是一种范式转变。
我认为非常重要的是企业必须具备适应这种速度的能力。因此，我们看到仿真技术变得非常重要，我们能够模拟车辆性能以及系统表现，而无需像过去一样制造实体原型，这加快了产品上市速度，也提升了响应速度，同时也让产品调整更加灵活。另外，建立完善的数字化体系非常重要，要覆盖所有流程，不仅是制造流程，还包括所有工程相关环节、供应链和商业化流程。同时，在可能的范围内实现工程化、智能自动化。因为我们希望确保创造价值，为客户创造价值，也为李尔创造价值。
因为如今，行业对创新、数字化、自动化以及工程能力的要求都达到了前所未有的高度。而产品设计方式决定了未来的量产方式，也决定了最终交付给客户的方式。因此，与客户提前开展合作，打造优秀的产品设计让产品更易于实现量产，这是我们的关键所在。
A
中国——全球汽车创新、
速度和能力的重要源泉
Q
周晓莺：今年正值李尔进入中国30周年，在此之际，您如何评价中国市场的价值？
Enrique Orta：中国市场正经历一场变革。过去，我们来到中国主要是为了实现产品制造和本地化生产；而如今，中国正在输出工程能力和创新，尤其是在汽车制造领域，同时也带来了更多客户机遇，因为越来越多本土客户正在成长为全球化车企。
另外一点就是“中国速度”，它是一种真正具有创新意义的模式。“中国速度”催生了持续创新的需求，也要求企业能够快速响应变化。
因此，我们将中国视为创新、速度和能力的重要源泉。
A
Q
周晓莺：所以李尔会将中国的创新成果推广到全球市场吗？
Enrique Orta：当然，如今我们在中国开发的产品已经开始在全球量产。而过去正好相反，以前我们的连接器、端子或线束都在德国或北美完成研发，再到中国量产，而今天很多创新来自中国，研发也来自中国，我们正借助这一优势将创新产品推向全球量产。
图片来源：李尔
A
Q
周晓莺：所以30年前，李尔帮助国际车企进入中国市场；而如今，李尔正帮助中国车企走向全球。
Enrique Orta：没错，并且这是一个非常积极的转变。
过去，大量国际车企进入中国市场，那时传统车企都在寻找新的市场和新的增长机会，而中国车企正在向全球车企学习如何建立制造体系，福特汽车、通用汽车都是学习对象；
而今天，我们看到的现象完全相反：中国车企正将汽车销往全球，如今，中国已经拥有许多实力强劲的品牌，它们逐渐成长为全球化玩家，它们不再只是依靠成本优势，而是带来了大量创新以及众多新技术，也带来了“中国速度”以及极具竞争力的产品。今天，国际传统车企开始把中国车企视为学习和借鉴的对象。
有些人可能把这种趋势视为一种威胁，而李尔则将其看作一种机遇，因为这将推动并促使整个汽车行业迎来新一轮变革，而最终受益的始终会是那些更强大、更灵活以及能力更强的企业。而我们相信，李尔将成为中国车企最强的合作伙伴之一。
A
以全球能力，助力中国车企走向全球
Q
周晓莺：那么在越来越多中国本土车企加速全球化布局的过程中，李尔能够为他们提供哪些支持？
Enrique Orta：李尔在这方面具有独特优势。李尔已经深耕中国30年，这30年来我们建立起独一无二的基础能力，在全球处于领先水平。
李尔首先能提供的是全球化布局，我们拥有全球化制造网络，几乎覆盖全球所有主要市场；
第二点是我们拥有强大的工程能力，多年来，我们不断积累经验、持续优化包括电气分配系统、连接器系统、电子产品以及座椅在内的产品设计，这也是我们的重要优势；
图片来源：李尔
第三点是我们的运营执行能力值得客户信赖，我们是一家以服务、成本竞争力和质量赢得客户信赖的供应商。中国车企出海时，需要熟悉当地法规要求的合作伙伴，比如欧盟即将实施一系列新法规，因此深入了解当地法规至关重要。
此外，我们在全球各个地区都拥有强大的本地供应链体系。目前我们看到许多中国车企正在出海，他们未来会需要在本地采购，而这正是我们的优势所在，因为我们拥有全球布局、本地支持的运营体系。
总的来说，我们具备独特优势，能够支持中国车企拓展全球其他市场。事实上，我们已经在这样做了。我们正与许多中国本土客户合作，支持他们进入欧洲、南美等市场。我们始终与他们同行，也因此获得了大量新的合作机会。
A
企业经营，就像一场铁人三项
Q
周晓莺：您是一位积极参与铁人三项运动的爱好者。那么，您的运动经历对您的决策思维方式有何影响？
Enrique Orta：我一直进行长跑运动，最近几年，我开始尝试铁人三项，因为它和长跑有很大不同。铁人三项更具挑战性，一场比赛需要完成三项运动：游泳、骑行以及跑步。
我认为，运动既要专注于短期目标，做好当下正在进行的事情；同时也要关注整场比赛的整体表现以及长期表现，这和企业经营非常相似，它也需要韧性、需要耐力，也需要持续稳定的表现，同时还要在每一个项目中发挥出色，但最终还要看整体表现。
我经常和团队分享这些理念，我拥有一支非常优秀的团队，我为他们感到骄傲，他们具备上述特质，具备抗压能力、拥有韧性，也保持着持续稳定的执行力。他们清楚，我们需要完成短期目标，但同时也必须着眼于长期机会。这就是将运动精神很好地映射到企业经营中的方式，也是商业和运动之间的共通之处。
A
Q
周晓莺：最后，您是否还有什么想对观众总结或补充的内容？
Enrique Orta：当前市场确实充满波动，但李尔始终保持着稳健的业绩表现，我们持续实现了富有韧性的增长。
第一，运营能力是我们业务的基石；第二是我们的产品组合，随着汽车不断演进，我们向车企提供的产品也在不断变化；第三，电气分配和连接器系统成为整车架构的核心骨架；第四，IDEA by Lear™对我们非常关键；最后一点就是中国，中国市场非常重要，随着中国车企走向全球，李尔已经准备好成为它们的全球合作伙伴。
A
