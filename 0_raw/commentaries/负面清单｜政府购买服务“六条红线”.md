# 负面清单｜政府购买服务“六条红线”

财政奖补负面清单之外，政府购买服务负面清单同样是地方主管部门、企事业单位必须高度重视的合规监管内容。
近年多起审计案例认定“将应当由政府直接履职的事项外包”：主管部门问责、合同无效、服务机构退款，违规问题导致的多方损失风险值得警惕。
政府购买服务不是“政府想买什么就买什么”，属于负面清单的就是无效合同。
（一）不属于政府职责范围的服务事项；（二）应当由政府直接履职的事项；（三）政府采购法律、行政法规规定的货物和工程，以及将工程和服务打包的项目；（四）融资行为；（五）购买主体的人员招、聘用，以劳务派遣方式用工，以及设置公益性岗位等事项；（六）法律、行政法规以及国务院规定的其他不得作为政府购买服务内容的事项。
1.不属于政府职责范围的服务
纳入部门“三定”规定的职责内容不得纳入政府购买服务范围。一旦纳入购买范围，合同无效，资金无法列支。
多地财政部门已明确将以下事项列入购买服务负面清单：
行政权力类：行政决策、行政许可、行政处罚、行政强制、行政确认、行政复议等行政管理事项
内部管理类：编制部门工作规划、撰写日常调研报告、编制单位内部工作制度、梳理工作台账资料
公文党建类：公文起草、党建纪检、微信公众号编辑、财务记账
其他禁止类：制作内部会议席卡、组织单位内部文艺汇演、内部考核督查检查
3.政府采购法律法规规定的货物和工程
政府购买服务的对象是“服务”，不是货物，也不是工程。将货物和工程采购伪装成服务购买，属于典型的规避政府采购程序的行为。
4.融资行为
比如，利用或虚构政府购买服务合同进行融资；为建设工程变相举债；通过政府购买服务违规向金融机构及融资租赁公司等非金融机构融资等。
5.变相用工
以政府购买服务名义变相用工，是审计发现的高频问题。比如，以“政府购买服务人员”“购买岗位”形式聘用人员；在核定的编制、员额以外，以劳务派遣方式用工；将属于就业扶持政策的公益性岗位混淆作为政府购买服务。
6.上级禁止事项
比如，多地负面清单已将违反过紧日子要求的购买服务事项单列。
二、风险识别与建议
警惕To G业务合规风险，需要谨慎识别招标公告，比如：
采购公告中出现“商业推广”“品牌营销”“市场策划”等字样；
采购需求中出现“起草”“审批”“执法”“处罚”“监督检查”等行政职权类动词；
采购需求中实质性内容为设备采购、工程建设，却以“服务”名义发包；
采购公告中要求供应商“先行垫资”“带资建设”或“以项目收益权作为还款来源”；
采购需求实质是“派人干活”而非“购买服务成果”等行为，违规采购即使中标并签了合同，也面临被认定无效的风险，已收款项可能被追回。
同时，在参与招投标中，除了事先筛查，中标后签署合同前应逐条核对合同服务内容。发现违规内容，拒绝签署并书面告知采购人该事项属于负面清单禁止范围。
如果如已签约但发现属于负面清单范围，应立即书面通知采购人暂停履行，并保留所有沟通记录。
审计一旦追责，这些记录是证明你“已尽到合理注意义务”的关键证据。
