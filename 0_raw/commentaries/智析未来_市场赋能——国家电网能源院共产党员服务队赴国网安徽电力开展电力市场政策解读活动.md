# 智析未来 市场赋能——国家电网能源院共产党员服务队赴国网安徽电力开展电力市场政策解读活动

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/vYw27Y7HicGeHOjiaAucZTtdY9Q8hJwCg2KviarZgTxiasx7tavicPR8lIaMStLoksNRSStricLKaaz9Dicl0AuxfO4bdNyIiagA9xPHM5RgeLuX2go/640?wx_fmt=gif)

  

  

  

![image](https://mmbiz.qpic.cn/mmbiz_png/0QgZZ2Qm4j69XWTbl7TtwMf0KbdTUdg8pRnFgiagHe8g2qg0T8icWP0Z3h9HDx3rtp8L0p2mbicEYFa0N8UBicyBQw/640?wx_fmt=png)

4月9日，国家电网能源院共产党员服务队走进国网安徽省电力有限公司，开展全国统一电力市场关键政策解读活动。此次活动是国家电网能源院共产党员服务队“智析未来”能源政策解读系列活动之一，通过精准传递国家深化电力市场建设的政策导向，助力省公司准确把握政策要求，科学研判发展趋势，切实提升市场运营能力。国网安徽电力副总经理、党委委员励刚，国网能源院党委委员、副总经理（副院长）李健出席活动，国网安徽电力相关部门、国网安徽经研院，院党建部、战略所、财审所相关同事参加。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/vYw27Y7HicGeuHjnYbeMafuSMj2ggMFiaIoXber288SneAXL24UOvB5YE1Pz52jHw2rAImL4php0ekMX2neKnugibYLW2wiacpw7A82l94QpZiaw/640?wx_fmt=jpeg)

  

  

  

活动中，战略所张高博士围绕全国统一电力市场体系建设现状、面临的新形势新要求、深化市场建设的关键举措三个方面作专题主讲，用专业视角解读政策内涵、回应行业热点，帮助参会人员更加全面准确理解电力市场相关内容，为后续相关工作的开展夯实了基础。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/vYw27Y7HicGff9PnMd9RuDdAY6jR5wC10VkQr4nDibvejHkNFWohkBdz4CiaRZBaII2nOpfanhGkhOvNgw476uKyeWvjVyibibJ2eU0Hiacn71f0A/640?wx_fmt=jpeg&from=appmsg)

此次活动是能源院共产党员服务队深度服务系统内单位的又一次生动实践，有效促进了宏观政策与微观执行的上下贯通，充分彰显了共产党员服务队的使命担当。下一步，能源院共产党员服务队将继续以能源政策解读系列活动为载体，持续开展专业化、定制化的服务，为公司系统内外单位精准赋能，为能源电力行业高质量发展贡献智库力量。
