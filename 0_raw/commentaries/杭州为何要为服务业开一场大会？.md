# 杭州为何要为服务业开一场大会？

杭州服务业高质量发展特别报道
今年以来，服务业被摆到了更加重要的位置。
4月，国家召开新时代以来全国首次服务业大会，全面部署服务业扩能提质行动。6月，浙江省服务业大会召开，提出加快打造现代服务业强省。8月，杭州也将召开服务业大会，为全市服务业高质量发展进一步明确路线图。
这场会议，对杭州意义不小。2025年，全市服务业增加值达到16997亿元，同比增长5.3%，占GDP比重73.8%，对GDP增长贡献率达73.4%。服务业是杭州经济发展的压舱石。
记者 陈中秋 摄
但真正值得关注的，不只是服务业“体量大”，而是杭州正在推动服务业从规模扩张走向能级跃升。
一条逐渐清晰的服务业发展路径
观察杭州服务业，不能只看今年这一次大会。2022年开始，杭州每年都围绕服务业高质量发展作出重要部署，且重点不断递进。
2022年，杭州召开全市推进现代服务业高质量发展大会，核心是把服务业放到城市经济基本盘中重新审视，推动现代服务业提质增效。
2023年，全市现代服务业高质量发展大会继续召开，重点转向平台、项目、企业、政策等系统推进，进一步夯实现代服务业发展基础。
2024年，杭州召开全市生产性服务业高质量发展大会，服务业发展的重心更加聚焦：不只是做大服务业规模，更要提升服务业对产业链、创新链、价值链的支撑能力。
到2025年，杭州市生产性服务业促进会成立。杭州推动生产性服务业发展，开始从政策引导、项目培育，走向政企联动、多方协同的组织化推进。
这条脉络很清晰：从现代服务业整体提质，到生产性服务业重点突破；从政府部门推动，到行业平台协同；从“服务业大市”，走向“服务能力强市”。
数据也印证了这种变化。2025年，在一季度增长5.0%的承压态势下，杭州服务业上半年回升至5.7%，前三季度保持5.6%，全年实现5.3%的稳定增长，继续发挥稳经济“压舱石”作用。
更重要的是，服务业增长的结构正在变。
2025年，杭州营利性服务业增长7%，拉动服务业增加值3.1个百分点，是服务业增长的主要支撑。其中，信息传输、软件和信息技术服务业营收连续11个月保持两位数增长，全年增长13.4%。
这说明，杭州服务业的增长，越来越依靠知识、技术、数据、人才这些高价值要素。换句话说，杭州服务业的“含科量”正在提高。
一座城市的“隐形竞争力”
服务业想要优质高效发展，生产性服务业是关键。什么是生产性服务业？
简单说，就是嵌入生产过程、提升产业附加值的服务。比如一部手机，硬件之外，操作系统、应用软件、芯片设计、专利技术、供应链管理、品牌营销、金融服务等，往往决定更高的价值分配。
它看不见、摸不着，却决定产业链的效率和高度。
国际上常用“两个70%”观察经济发展水平：服务业增加值占GDP比重达到70%，生产性服务业占服务业增加值比重达到70%。杭州早已跨过第一个门槛——2023年杭州服务业占GDP比重达到70%，2024年生产性服务业增加值占服务业增加值的58.8%（2025年数据未出）。
这也是杭州持续加码生产性服务业的深层逻辑。
生产性服务业不是一个单一行业，而是一张嵌入产业链、创新链、资金链和供应链的复杂网络。数字服务、科技服务、金融服务、物流服务、商务服务，分别连接研发、制造、交易、融资、流通、出海等环节。
正是这种“全链条渗透”的特性，让它成为城市产业升级的关键支点。
一个正在成形的生产性服务业体系
去年1月，杭州专门为生产性服务业成立了一个协会——杭州市生产性服务业促进会。
成立这样一个协会，本身就释放出明确信号：杭州推动生产性服务业发展，已经不只是出台政策、培育企业、谋划项目，而是要进一步搭建政企联动、多方协同的组织平台。
成立之初，促进会发展会员单位603家，这些会员单位及其下属在杭企业营收占全市生产性服务业的82%，占全市服务业的77%。截至目前，促进会会员企业已达到629家。
它是杭州生产性服务业主力军的集结平台。它要做的，不是“开会联谊”，而是推动企业之间发生更多业务连接、资源连接和产业连接。
发展生产性服务业，最终要落到产业升级上。
制造业要提高附加值，必须向研发设计、工业软件、供应链管理、品牌服务、金融服务等环节延伸；服务业要拓展产业链，也要更深嵌入制造和实体经济场景。杭州一直强调“两业融合”，逻辑就在这里。
杭州的优势，是数字经济基础深厚。杭州获批中国软件名城、国家新一代人工智能创新发展试验区、国家人工智能创新应用先导区，拥有全国首个服务型制造研究院，累计入选2个国家级两业融合试点、22个省级两业融合试点。
2022年以来，杭州就提出全力打造全国先进生产性服务业集聚地。2025年首部生产性服务业蓝皮书发布，软件产业技术联盟组建，4个国家人工智能应用中试基地正式落地运营，中国数谷入选国家数据产业集聚区试点；4家中试平台入选工信部首批重点培育名单，“3+N”产业基金集群规模突破3000亿元，国家骨干冷链物流基地、杭州综合保税区空港片区等平台相继落地。
这些动作共同指向一个目标：让杭州服务业更深地进入产业链、价值链和创新链。
一次面向下一阶段的再出发
杭州召开服务业大会，表面上看是部署服务业工作，深层看则是一次城市发展战略的再聚焦。
从2026年的工作思路看，杭州将实施服务业扩能提质行动，研究出台服务业扩能提质方案，打造一批辨识度高、竞争力强的服务业细分赛道。
生产性服务业方面，杭州将发布2026杭州市生产性服务业蓝皮书，开展首部生产性服务业立法，推动数字服务、科技服务、金融服务、物流服务、商务服务、节能环保服务向专业化和价值链高端延伸。
生活性服务业方面，杭州将继续推动住宿餐饮、养老托育、健康服务、居民服务、文商旅体等领域向高品质、多样化、便利化发展。
一座城市的竞争，表面看是项目竞争、企业竞争、产业竞争，深处看是服务能力的竞争。
今天的杭州，正在把那些“看不见的能力”变成新的城市硬实力：软件、算法、资本、物流、检测、设计、法务、会展、咨询、供应链、数字贸易；也在把那些“看得见的体验”做得更细更暖：餐饮、住宿、问诊、托育、演出、夜间消费街区。
杭州要做的，不只是服务业大市，而是服务能力强市；不只是数字经济高地、先进生产性服务业集聚地，也是一座更宜居、更好逛、更有烟火气和国际范的现代服务业之城。
