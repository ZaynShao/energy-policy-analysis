# 七万亿的大棋局，深圳先落子了

日前，深圳市委召开了一场专题会议。市委书记靳磊主持，市长覃伟中作工作安排，市政协主席林洁出席。高规格的阵容传递出一个清晰信号：深圳要抢抓机遇，高质高效推进“六张网”规划建设。
“六张网”是什么？
水网、新型电网、算力网、新一代通信网、城市地下管网、物流网。这六个词涵盖了传统与新型、实体与数字基建，是现代化基础设施体系的重要组成部分。
今年4月28日，中央政治局会议首次提出加强“六张网”规划建设；5月9日，国务院常务会议部署；5月22日，国家发改委通报将抓紧出台相关规划和实施方案。短短两个月，“六张网”从政策概念变成了一场正在加速落地的国家级基础设施大行动。据国家发改委透露，今年“六张网”及重点领域建设投资超过7万亿元，“十五五”时期累计投资规模预计达20至25万亿元。
“六张网”绝不仅仅是修水库、铺光纤、建管廊那么简单。这是一场关乎城市未来承载力、产业竞争力和安全韧性的系统性重构。深圳为什么能率先行动？优势在哪，短板在哪，下一步怎么做？
“六张网”，网住的是什么
“六张网”表面上是六类基础设施，本质上是一张覆盖城市生命线、能源动脉、数字神经和物流循环的超级网络。
水网，不只是修水库、挖河道。它要承载防洪排涝、跨流域引调水、农田灌溉、城乡供水等一系列功能。对深圳这样的超大城市来说，更重要的是“洪涝潮”综合防护。比如，暴雨来了，水排得出去吗？海水倒灌，挡得住吗？
新型电网，要从“发输变配用”的单向直线，变成能接纳风电、光伏，能柔性调度、智能运行的复杂系统。深圳的高端制造、人工智能、超充站……电网调度跟不上，产业就得停摆。
算力网，是你刷视频、用云盘、跑AI模型背后看不见的支撑。深圳要发展人工智能，算力就是水和电。没有算力，大模型就是纸上谈兵。
新一代通信网，5G深度覆盖、6G预研、光网、卫星互联网——目标是“无处不在、万物互联”。
城市地下管网，包括燃气、供热、排水、综合管廊……这些城市的“里子”，平时看不见，但对城市的正常运转至关重要。
物流网和每个人的生活息息相关。从田间地头的生鲜到工厂的原材料，从跨境电商的包裹到低空经济的无人机配送，这张网的通畅程度，直接决定商品贵不贵、企业赚不赚、人民富不富。
更关键的是，这六张网不是各管一摊。
算力网要24小时运转，服务器得用电，离不开新型电网；电网的智能调度，又需要通信网传数据、算力网做计算；地下管廊里走的水管、电缆、光缆，本身就是水网、电网、通信网的物理交汇点。它们是一个有机整体，牵一发而动全身。
推进“六张网”，深圳优势在哪？
深圳推进“六张网”，最大的底气是“手里有牌”。
算力是深圳的硬通货。中国算力网的总调度中心就设在深圳南山的鹏城实验室——这意味着深圳不仅是算力的使用者，更是全国算力网络的核心调度者。这座城市的半导体产值超过千亿，高性能通用计算芯片研发走在全国前列。到2026年，深圳的实时可用智能算力将超过80E FLOPS，这是什么概念？足够支撑多个国家级AI大模型的训练需求。南山、宝安、龙岗、龙华、前海、河套、光明科学城——算力高地正在深圳遍地开花。
新一代通信网方面，5G网络质量和应用场景建设走在全国前列，“双万兆”网络正在加速普及，6G技术研发和国家级互联网骨干直联点也在同步推进。深圳还在构建全球首个市域级“5G+毫米波+卫星”低空全覆盖安全网络——为低空经济这张未来的产业名片铺好通信路基。
新型电网同样有料。深圳已建成全国首个超大城市数字电网、首个坚强局部电网。电力行业的首个多模态预训练大模型“祝融2.0”就在这里落地。南方电网深圳供电局构建的“城市+电网”数字孪生平台，打通了电网与政务数据壁垒——电网不仅是输电的管道，更是一个会思考的智能系统。
但最具“深圳特色”的优势，藏在看不见的地下。深圳在城市地下综合管廊领域探索出了一种独特的混合所有制模式——市属国企与央企合资成立专业化运营公司，不仅解决了管廊建设“钱从哪里来”的难题，更实现了入廊管线有偿使用协议签约率100%、日常维护收费率100%。这在全国是独一份。全省推广的10项管廊经验中，深圳占了7项。
在更宏观的层面，深圳还打造了全市域统一的时空信息平台（CIM平台），融合了15万宗土地、65万栋建筑物等核心信息，精准描摹地下管网、交通流量等城市细节。这个数字底座，恰恰是“六张网”从“各自为网”走向“协同共舞”的关键基础设施。
短板在哪？如何破局？
深圳“六张网”建设已有较好基础，但优势明显，短板也同样存在，远未到可以松口气的时候。
综合开发研究院（中国·深圳）企业与市场研究中心执行主任，经济学博士后郑天骋认为，
深圳“六张网”建设首要问题是协同融合不足。他观察到，各类基础设施长期分领域规划、分条线建设，算力网、通信网、电网之间联动还不够深入，城市地下管网与各类线缆、管线设施的统筹仍需加强。部分区域还存在重复开挖、重复建设、资源利用效率不高等问题——老百姓戏称的“拉链路”，根源就在这儿。
其次是区域建设不均衡。原特区内基础设施成熟度较高，但原特区外——龙岗、龙华、光明、坪山的部分片区，在供水保障、电网承载、地下管网、通信算力配套等方面仍有明显短板。随着深圳“20+8”产业集群在西部和北部加速布局，产业跑在了基础设施前面，这个缺口正在被拉大。
第三是产业适配性有待增强。郑天骋特别强调，高端制造、人工智能、生物医药、低空经济等产业对高可靠供电、高品质算力、低时延通信、智慧管网等提出了更高要求，但基础设施对新质生产力的支撑作用还需要进一步释放。简单说，产业升级对基础设施的需求是“硬指标”，目前还有落差。
如何破局？
日前的市委专题会议给出了具体部署：现代化水网要突出集约高效、安全可靠；新型电网要突出扩容提质、智能灵活；算力网要突出系统布局、灵活供给，更加注重算电协同；新一代通信网要突出高速泛在、融合赋能；城市地下管网要突出协同联动、安全韧性；物流网要突出内外通达、高效流通。
郑天骋建议，深圳紧扣四个关键词：统筹、补短、赋能、提效。
统筹是前提，要依托CIM时空信息平台和数字孪生城市建设，推动水网、电网、算力网、通信网、地下管网数据互通、规划衔接和功能联动，真正把六张网拧成一股绳。
补短是硬任务，重点推进原特区外片区基础设施提质升级，加快老旧水网、地下管网和薄弱区域电网改造，把历史欠账补上来。
赋能是目标，围绕战略性新兴产业和未来产业发展需求，深化算电协同、网产融合，让基础设施不再“被动配套”而是“主动适配”。
提效是保障，坚持政府统筹、市场参与、适度超前，拓宽社会资本参与渠道，强化土地、资金、人才等要素保障，推动重点项目加快落地。
“六张网”建设不是单一的基础设施工程，而是深圳面向未来重塑城市承载力、产业支撑力和安全韧性的系统工程。
深圳有先发优势，也有制度创新的底气；有清晰的短板，更有务实的路径。关键是把这些优势转化为实实在在的落地成效——让水网更安全、电网更智能、算力更充沛、通信更通达、管网更韧性、物流更高效。这既是深圳的责任，也是深圳的机遇。（南方+记者 崔璨）
