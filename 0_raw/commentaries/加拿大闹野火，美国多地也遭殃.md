# 加拿大闹野火，美国多地也遭殃

加拿大森林野火导致多地空气质量急剧恶化，烟霾还“跨境”影响到包括纽约在内的美国多个城市的空气质量。
眼下，加拿大已进入野火季。连日来，席卷该国安大略省西北部的森林野火导致多地空气质量急剧恶化，最大城市多伦多当地时间7月15日空气质量指标在世界主要城市中排名垫底。加拿大烟霾还“跨境”影响到包括纽约在内的美国多个城市的空气质量，引发健康警告。
▲7月15日，加拿大多伦多市区笼罩在山火扩散的烟尘中。新华社发（邹峥摄）
社交媒体上流传的一段视频显示，加拿大国家铁路公司的一列货车13日行驶至安大略省阿姆斯特朗附近时，被熊熊燃烧的野火完全“合围”，列车驾驶室被大火映照得一片通红。阿姆斯特朗距离多伦多500多公里，加拿大国家铁路公司发表声明说，已暂停阿姆斯特朗附近的铁路运营，当地居民已于13日晚疏散。
据路透社报道，截至15日，加拿大境内有835处在燃野火，其中112处被评估处于失控状态。多数野火出现在中部的马尼托巴省、萨斯喀彻温省和安大略省。
加拿大环境部将多伦多市15日的空气质量指数评为10+，表明处于“极高风险”水平。据气象部门预测，这一糟糕状况或将持续至16日晚。为此，多伦多市还取消了与美加墨世界杯有关的一些室外活动。
加拿大政府说，今年该国野火季开局比2023年和2025年来得缓慢，但由于全国气温高于往年水平，各地发生野火的可能性更高。
▲2023年6月30日，美国纽约的建筑笼罩在烟雾中。新华社记者刘亚南摄
近年来，美国广大地区受加拿大野火烟霾影响已成夏季常见现象。今年同样如此，纽约市等地的空气质量因此明显下降。纽约相关机构发布警报，敦促居民15日和16日减少剧烈户外活动。
纽约州州长凯西·霍楚尔在社交媒体上说，加拿大野火产生的烟霾导致全州空气质量不佳，呼吁民众尤其是有健康问题的人要多加小心。
美国国家气象局预测，烟霾影响或持续至本周末。
“对纽约市来说，最糟糕的情况可能还没出现。五大湖地区、纽约州北部以及新英格兰地区恐怕也还没经历最严重阶段。”美国哥伦比亚大学拉蒙特-多尔蒂地球观测站研究人员丹·韦斯特维尔特说。
