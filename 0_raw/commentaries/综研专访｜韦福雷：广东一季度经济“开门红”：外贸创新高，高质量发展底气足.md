# 综研专访｜韦福雷：广东一季度经济“开门红”：外贸创新高，高质量发展底气足

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/QIJgF5A55WYNvVexb6mF4CWiaHHErtJzFAVCRWM3otgSUmvYS7libfQJdEj1HkBu3FicrTaCdPt5OSicVj7XoibocQTibeQbibJiagr39xsUnGjsPSM/640?wx_fmt=jpeg&from=appmsg)

日前，广东省统计局公布一季度经济运行简况。数据显示，今年以来，广东经济运行总体延续回升向好态势，开局良好。根据地区生产总值统一核算结果，一季度，广东实现地区生产总值34950.34亿元，按不变价格计算，同比增长4.6%，创下了近五年一季度增长新高。

细看这份成绩单，高质量发展的成色究竟如何？AI热潮对于广东又将带来哪些影响？外贸逆势扩容的真实支撑是什么？南都湾财社记者就此采访了综合开发研究院（中国·深圳）财税贸易与产业发展研究中心主任韦福雷。

在他看来，在当前国际环境复杂动荡、外部不确定性加剧的大背景下，经济体量庞大的广东，一季度经济交出了超预期的亮眼成绩单，为全年经济发展打下坚实开局基础。

**工业发展：AI产业强势赋能，产业链优势持续释放**

在一季度的经济增长中，工业领域表现突出，规模以上工业增加值增长5.4%，其中计算机、通信和其他电子设备制造业增长13.4%。AI浪潮对于广东经济发展有哪些引领作用？这种增长态势能否持续？

韦福雷指出本轮AI红利广东充分受益、优势显著。广东拥有雄厚的ICT产业根基，已形成完善的AI全产业链布局，覆盖硬件制造、算力配套等上下游全环节，充分享受AI产业发展红利，产业竞争优势持续巩固。从行业端来看，光模块、PCB等核心企业订单供不应求，部分订单已排至两年后，行业增长具备长期持续性。

在他看来，龙头企业成为产业升级的重要支撑。华为营收恢复至制裁前水平，比亚迪布局新能源汽车与高端芯片领域，立讯精密等传统制造企业加码新兴产业研发配套，全省产业体系完备、产业生态完善，具备强劲的全球市场竞争力。

韦福雷补充道，AI产业的辐射效应的持续扩大，Token出海成为全新增长赛道。汕头已构建起Token出海完整生态闭环，依托海上风电等绿色电力资源，叠加出海光缆枢纽的区位优势，未来广东将依托硬科技实力，结合绿色数据中心建设，从单一产品出口，延伸至AI算力服务输出，形成产业新增长点。

**外贸出口：市场多元布局，贸易模式加速革新**

一季度广东进出口总额达2.54万亿元，增长19.4%，规模创历史新高。外向型业态活跃度提升，在外部环境复杂严峻的情况下，广东外贸实现“逆势扩容”的关键原因是什么？

韦福雷认为广东、深圳两地出口整体表现亮眼，在全球贸易环境严峻复杂的形势下实现逆势扩容。核心支撑一方面源于大湾区完备的产业链生态，产业基础扎实、供给能力强劲；另一方面，贸易市场持续多元化，与“一带一路”沿线的国家贸易规模稳步提升，不断开拓海外新市场。

“当下中国外贸发展逻辑正在发生深刻转变，告别过去规模化、低成本、价格竞争的传统模式。”韦福雷强调道。中小微企业、初创群体崛起，聚焦海外垂直细分场景，走精细化、高附加值发展路线。这类经营主体运营成本低，深耕小众赛道，依托大湾区完整产业链配套，精准匹配定制化需求，收获更高产品溢价。

此外，韦福雷表示，新模式与大型企业形成错位发展、互补共生格局，大厂持续深耕大众化主流市场，中小主体抢占垂直细分赛道，既能消化区域富余产能，又能提升外贸整体产业价值，成为外贸增长的全新潜力点。

**产业转型：投资力度加码，制造升级稳步推进**

设备工器具投资激增42.3%，先进制造业占比升至56.7%。大规模设备更新政策效应是否超预期？制造业高端化转型是否已跨过关键拐点？

在韦福雷看来，一季度广东产业转型升级步伐加快，企业技改投资意愿强烈，全省设备投资同比增长42.3%。在整体经济承压环境下，企业主动加大设备更新、技术改造与研发投入，是产业升级的积极信号。产业结构持续优化，先进制造业增加值占规模以上工业比重提升至56.7%，高端化发展趋势明确。

韦福雷同时提醒，制造业全面高端化的转型拐点仍需理性看待。目前国内已在高端装备、核心设备等领域实现自主突破，但关键元器件、核心基础材料等环节国产化占比偏低，量产、良率不足，仍受外部供应链制约。短期无需刻意追求拐点论断，坚守自主可控与国产化替代方向，稳步推进产业升级，是长期发展核心。

**消费市场：新兴消费增势强劲，内需潜力持续释放**

社会消费品零售总额增长2.5%，通讯器材类激增26.9%，但PPI下降、CPI低位运行。企业实际盈利感受与宏观数据之间是否存在“温差”？消费复苏的可持续性如何判断？

韦福雷认为宏观经济数据与企业经营、居民实际感受存在明显温差，K型分化特征显著。新兴产业、高端制造、新赛道行业高速发展，传统产业则面临要素成本上涨、市场需求萎缩的双重压力，利润空间持续压缩，行业发展冷暖不一。

在他看来，当前居民储蓄意愿居高不下，多年来全国居民年度存款保持稳步增长，核心原因并非收入不足，而是居民预防性储蓄需求强烈，就业预期、收入稳定性、社会保障体系等因素，制约了消费意愿释放。

韦福雷进一步强调道，从短期来看，唯有依托专项消费刺激政策，才能快速撬动消费潜力；依靠市场自然修复，消费大幅回暖的难度较大，复苏进程具备较强不确定性。

**全年展望：增长基础稳固，二季度聚焦精准发力**

基于一季度“开门红”，全年增速预期是否上调？二季度广东应在哪些领域精准发力，才能将“开局好”转化为“全年胜”？

韦福雷表示，依托一季度良好的经济开局，广东完成全年经济发展目标具备充足支撑，全年经济平稳上行、超预期完成任务的概率较高。现阶段发展重心逐步从单纯追求GDP增速，转向高质量发展，新质生产力培育、产业结构优化、高端产业转型，成为经济稳定运行的核心底气。

对于二季度发展方向，韦福雷认为将聚焦多重关键方向：一是做强制造业基本盘，持续推进强链补链，深化制造业数字化、智能化改造，依托AI赋能实体经济，围绕产业智能化、绿色化、融合化发展要求，落实节能减排政策，以创新与绿色低碳筑牢工业竞争力。

二是抢抓对外开放机遇，借助深圳承办APEC会议的重大契机，深化与各经济体的经贸合作，推进制度型开放，扩大优质产品出口，提升外贸综合效益。同时依托国际盛会带来的人流、流量红利，直接拉动文旅、零售等线下消费增长。

整体而言，广东依托完善的产业体系、多元的市场布局与持续的创新投入，经济内生动力不断增强，随着各项精准施策落地，一季度开门红优势将持续转化为全年稳定发展的坚实动能。（南方都市报 记者 吴鸿森 / 封面图由Veer提供）
