# 俄军对乌克兰炼油厂实施集群打击

俄称空袭乌港口，乌称打击俄物流枢纽。
16日，俄罗斯方面称，俄军继续对乌克兰港口基础设施及用于乌军利益的海上船只实施打击，并对乌克兰军工企业和炼油厂实施了集群打击。
乌克兰方面称，乌军袭击了俄罗斯大型物流枢纽，并打击了俄导弹系统。
俄称空袭乌港口 打击乌军工企业
俄罗斯国防部16日通报称，俄军当天空袭了位于敖德萨港、为乌军运输物资的货轮等船只，攻击了敖德萨港附近的无人艇生产车间和维尔科沃港附近的乌克兰巡逻艇停泊区。另外，在敖德萨以东的黑海水域，俄军打击了一艘向乌克兰运输西方国家武器的干货船。
通报还称，俄军当天使用陆基、空基高精度武器及远程攻击型无人机，对乌克兰基辅的军工企业、波尔塔瓦州的一家炼油厂及第聂伯罗彼得罗夫斯克州的一家冶金厂实施了集群打击。
乌称打击俄大型物流枢纽和导弹系统
乌克兰国防部16日在社交媒体发文称，乌军当天凌晨对俄罗斯大型电商平台野莓公司位于莫斯科州的物流枢纽发动了大规模无人机袭击。乌国防部称，该物流枢纽占地25万平方米，是野莓公司最大的仓库设施。截至目前，野莓公司的10处大型仓库已有7处因乌军袭击而停止运行。
乌克兰海军同一天称，乌海军当天凌晨打击了俄军部署在克里米亚的“棱堡”导弹系统及发射阵地。乌海军称，一直以来，俄军频繁使用“棱堡”导弹系统发射“缟玛瑙”超音速导弹和“锆石”高超音速导弹，对乌克兰南部及其他地区发动袭击。
