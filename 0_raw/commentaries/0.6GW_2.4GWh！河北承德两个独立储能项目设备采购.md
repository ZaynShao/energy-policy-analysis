# 0.6GW/2.4GWh！河北承德两个独立储能项目设备采购

河北交投晟德承德县300MW/1200MWh储能电站项目磷酸铁锂电池储能系统设备采购
围场德御电网侧独立储能综合示范项目储能系统设备采购，包括297MW/1188MWh磷酸铁锂电池和3MW/12MWh全钒液流电池储能系统
招标基本情况如下。
招标人为河北交投德泰新能源科技有限公司。
招标储能系统容量为300MW/1200MWh，供货范围包括但不限于：磷酸铁锂电池、变流器（PCS）、变压器、直流汇流设备、电池管理系统（BMS）、能量管理系统（EMS）、储能系统测量计量、备品备件、专用工具、附属设备（包括预制舱及内部的配电、火灾报警、消防、自用电、照明、电缆等）及其箱体内所有电气元件等的供货、工厂试验、包装、运输、交货，现场指导舱体安装以及负责舱体内所有设备、设施安装及单体调试、协助配合验收及成套设备质保期服务等。
交货期：计划设备于2026年9月30日开始供货，11月25日前全部完成供货。
投标人业绩要求：2023年8月1日至投标截止日，国内累计达到5000MWh磷酸铁锂电池储能系统设备合同业绩，并且单份合同储能系统容量均须不小于100MWh。
交货期均为：计划设备于2026年9月30日开始供货，2026年11月30日前全部完成供货。
投标人业绩要求
磷酸铁锂储能系统部分：2023年8月1日至投标截止日，国内累计达到5000MWh磷酸铁锂电池储能系统设备合同业绩，并且单份合同储能系统容量均须不小于100MWh。
全钒液流储能系统部分：2023年8月1日至投标截止日，在中国境内具有1项单个项目规模不低于6MWh的全钒液流储能系统设备合同业绩，且运行时间不低于1年（从并网时间或运行验收完成时间或调试验收完成时间计算）。
