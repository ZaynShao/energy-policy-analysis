# 文科生也能拿百万大奖，科目三脱口秀全网整活！智元灵创创意大赛来了

新智元报道
今年，人形机器人可太火了。
然而，普通人也能指挥一台能跑能跳的双足人形机器人吗？
答案是，可以！
最近，智元首届「灵创创意大赛」正在火热进行中，平台上已经出现了不少优质作品。
这场比赛的口号，太让人心动了：人人都是机器人导演。
不会写代码，不懂机械，不懂专业动作设计，也能玩机器人？是的。
更离谱的是，你甚至不需要拥有一台机器人。比赛要用的顶级真机，官方管够。
只要你有足够的脑洞，想要搞点大事情，带着你的创意，就可以来报名了，还能瓜分上百万的奖金池。
以往，机器人比赛都是「理工科大佬」的专属游戏。文科生、艺术生、视频博主、乃至普通网友，虽然看着心痒痒，但只能旁观。
但这一次，智元的「灵创平台（LinkCraft）」来了。
灵创平台是全球首个0代码、0门槛的机器人内容创作与演绎平台。
可以说，它就是机器人界的「剪映」，把传统机器人动作开发的复杂流程，全部变成了肉眼可见、鼠标可拖拽的「一键式」操作。
这次智元灵创创意大赛的参赛作品，就是在这里做出来的。
首先，它搭载了一个逆天的「动作模仿」功能，可以利用AI捕捉动作并进行云端模仿学习。
只要你上传一段普通的MP4视频（比如你跳了一段科目三，或者打了一套军体拳），系统会自动精准捕捉视频里的人体动作，瞬间转换为机器人能看懂的动作脚本！
有动捕经验的老手，也可以直接上传BVH动捕文件。
如果是舞蹈大佬，想要做高精度、高动态的全身复杂动作呢？也没问题！上传视频后，云端AI会直接帮你搞定全身动作复现。
其次，平台内置的「语音演绎」功能，还能让你直接上传音频，或者对着麦克风录一段脱口秀。
你可以用文字转语音、唱歌换音、语音换音，平台支持中文、英文、日语、韩语、西班牙语等多种外语。
更妙的是，系统不仅能自动识别文字，还能根据你选择的「场景」，自动帮你插入对应的肢体动作和表情！
比如，你可以选一个「生气」的情绪音色，机器人会立刻换上一副气鼓鼓的表情，一边摊手一边用网络热梗吐槽你的朋友，这节目效果，绝了。
在灵创的创作面板上，有一个类似视频剪辑软件的「时间轴」，你可以把「动作A」、「表情B」、「语音C」像拼积木一样拖拽到时间轴上，充分发挥想象。
而且，平台还自带海量的「官方素材库」（比如河南太极、咏春拳等），你可以直接点击「做同款」，一键复制到自己的空间，进行二次魔改！
一个零基础的小白，甚至可以在灵创平台上拍出一部由人形机器人主演的微电影。
这次大赛，面向高校学生、内容创作者、AI工具爱好者以及所有泛用户群体。
只要你敢想，灵创平台为你准备了四个极其对味的赛道。
选一个你最擅长的，就可以让机器人替你「出道」了。
赛道一：「舞蹈」
街舞、民族舞、国风舞、女团K-Pop、甚至广场舞！用你的编排，让机器人展现出极致的动作美感与舞台张力，跟上节奏、跳出风格。
赛道二：「武术」
太极拳、跆拳道、散打、咏春、少林功夫……你可以用AI动捕，把一代宗师的招式「注入」机器人的灵魂。
一台人形机器人在台上打出一套行云流水的咏春连环日字冲拳，叶问看了都得点赞。
赛道三：「语言」
如果你是个段子手，这个赛道非你莫属！脱口秀、单口相声、小品、短剧、甚至是魔性配音，都可以尝试。
你可以给机器人写一段台词，配合时间轴上的搞笑动作，让它成为下一个「脱口秀大王」。
赛道四：「热梗整活」
如果你爱搞抽象，这就是属于你的赛道。热梗复刻、搞笑挑战、反差萌演绎……在这里，你可以让机器人模仿网络热门表情包，或者跳个魔性舞。
只要你的脑洞足够大，你就是整活赛道的王！
有人会问：线上编排得很嗨，但真机跑起来翻车了怎么办？
这不，灵创平台官方的宠粉操作来了：作品创意入围后，在决赛准备期间，你的创意将1:1在真实的顶级人形机器人身上完美重现！
作品提交后，灵创平台的技术人员会代为下发到真机上运行，并且用高清摄像机录制下真机的实际表演视频，回传给你。
想象一下这个画面：你在宿舍里啃着外卖、拖着时间轴改稿；几百公里外，一台人形机器人正一丝不苟地替你走位彩排。
你还没见过它，它已经把你的作品从头到尾演了一遍。你可以隔空验证、随时调整，官方会提前替你踩坑。
一个机器人不够过瘾？好消息是，本次赛事限时开放了全新的「多角色同台编排」功能！
最多4个机器人角色同屏编排，2个、3个、4个，随你选。
比如，你可以编排一部短剧：1号机器人演男主，2号演反派，3号和4号在旁边跳伴舞。
不同动作、不同语音、不同表情，在同一个舞台上同框飙戏，一台完整的机器人群像剧就这么诞生了。
心动了？先看看这场比赛怎么打。
初赛全程线上：通过灵创平台大赛专区提交作品，就算报名成功。每条赛道选出5份入围作品，四大赛道共20份，晋级线下环节。
征集期内，每天点赞第一的作品，还能直接抱走「每日人气奖」：300元京东卡，天天开奖。
对了，每人可以提交多个作品，各作品独立参评——拿不准哪个创意能打？都交上去！
初赛结束后，官方将公示入围名单，并同步公布各赛道命题。入围创作者围绕命题准备两个新作品，一个打复赛、一个打决赛。
接下来，就是9月的线下创作营，分为三个阶段：
设备体验与真机调试：上手真机、计时试跑，提前摸透你的「机器人演员」；
线下复赛：每赛道5进3，决出12强；
线下决赛：12强巅峰对决，现场颁出各赛道金、银、铜奖！
对了，线下评分表里还藏着一个可爱的细节：机器人装扮占30分，仅次于创意表达的36分。
给你的机器人演员做造型、置办戏服，几乎和创意本身一样值钱。（Cosplay大佬狂喜）
划重点：入围选手的往返交通和住宿，全部由组委会承担。你只管人到，剩下的官方全包。
不止如此，入围后你还将有机会优先体验灵创平台未公开的新功能，并且获得灵创平台官方团队的一对一技术支持，把你的创意打磨成未来的官方真机展示标杆作品。
这次的总奖金池高达百万，只为寻找那个最有才华的你。
金奖（每赛道1个）：现金80000元 + 官方周边 + 人才中心能力认证
银奖（每赛道1个）：现金50000元 + 官方周边 + 人才中心能力认证
铜奖（每赛道1个）：现金20000元 + 官方周边 + 人才中心能力认证
优秀作品奖（复赛未晋级的8个作品）：现金10000元 + 官方周边
也就是说，只要入围并到场，人人有奖金，保底1万元起！
对于在校学生和应届生，还有一条专属通道：大赛中表现优异者，免简历初筛，直通智元灵创团队的实习面试。
赛后，官方还将从全部参赛创作者中选出首批「灵创达人」，解锁一批普通用户摸不到的高阶权限。
就算没杀出重围，奖也照样有你的份。
大赛特设「全民参与奖」，零门槛参与。
只要你在抖音、小红书、B站、微博 这四个平台的任意一个，发布与本次大赛相关的内容：可以是参赛作品，可以是观赛感受，可以是你的吃瓜吐槽，甚至是你剪辑的二创搞笑视频！
发布时带上话题#灵创创意大赛 #人人都是机器人导演，即获对应平台的抽奖资格。
线下决赛结束后，全民参与奖的名单将与决赛获奖名单同步公布：四大平台各随机抽取100位幸运儿，每人送出300元京东卡和官方限量周边。
还等什么？赶紧上车吧！
初赛很简单：只要在灵创平台完成作品并提交即可。
要想得高分，记住要靠点赞积累人气，台本写得细的话，还有额外加分。
1. 点击「阅读原文」登录灵创平台官网，直通大赛
2. 在首页点击「创作新作品」，选择「灵犀X2」或「远征A3」机器人。
3. 导入你的视频/音频，开始你的表演！
4. 遇到不懂的？点击官网上的「产品手册」，保姆级教程带你起飞。
