# 北奔重汽300kW氢燃料牵引车正式下线

近日，由北奔重汽牵头、联合上海重塑能源科技有限公司组建创新联合体协同攻坚的“揭榜挂帅”专项项目取得重大成果——300kW大功率氢燃料牵引车正式下线，并顺利完成国家机动车产品公告申报，进一步完善公司高功率氢燃料电池重卡产品矩阵。该车型搭载300kW大功率燃料电池系统，系统峰值效率达65.95%，具备优异的质量功率密度与体积功率密度，车辆融合电堆自主加热、BOP定向排水、系统热质量轻量化、空压机余热回收四项核心低温适配技术，可在-40.2℃极寒工况下实现快速冷启动，整车搭载基于智能动态规划的燃料电池能量管理核心技术，持续将氢、电双动力源维持在高效运行区间，兼顾绿色低碳属性与运营经济性。该“揭榜挂帅”项目不仅实现了单一车型的技术突破，而且有效带动区域氢能装备制造产业集聚，搭建起上下游协同联动的产业协作链条，同步培育出一批氢能车辆研发、制造领域专业技术人才与攻坚团队，为内蒙古自治区打造清洁低碳现代能源体系注入坚实动能。
