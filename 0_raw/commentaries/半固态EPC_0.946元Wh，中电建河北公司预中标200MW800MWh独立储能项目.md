# 半固态EPC 0.946元/Wh，中电建河北公司预中标200MW/800MWh独立储能项目

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)  

储能与电力市场获悉，3月25日，华蓄新能源（北京）有限公司200MW/800MWh半固态独立储能项目EPC工程总承包中标候选人公示发布。

  

中标详情如下（报价区间0.946-1.012元/Wh）：

  

中国电建集团河北工程有限公司投标报价75644.2867万元，折合单价0.946元/Wh，成为第一中标候选人；  
中国电建集团河南工程有限公司投标报价79176.331205万元，折合单价0.990元/Wh，成为第二中标候选人；  

中能建建筑集团有限公司投标报价80998万元，折合单价1.012元/Wh，成为第三中标候选人。

根据招标公告，项目位于河北省承德市承德县境内，新建200MW/800MWh储能站一座，包括规划布置、储能系统、电气一次、电气二次、通信、给排水及消防、供暖通风及空调、土建等。

  

招标范围为储能系统工程、220kV升压站工程、送出工程的勘察及设计、设备及材料采购、工程施工等，满足上述所有条件的EPC“交钥匙工程”。
