# 政策铺路、资本加码、产业赋能 深圳OPC成新赛道

![image](https://mmbiz.qpic.cn/mmbiz_jpg/QIJgF5A55WYEGJjwyIlf54B2vbhiasiaZ7ac5SiaKS3yPEiaVkAibMG9Y56Folhug608eD57wbh0ZV5BZcU2WxChaKZiajBSB5hqu0N8H8RTklbAo/640?wx_fmt=jpeg&from=appmsg)

在AI技术重构产业分工的背景下，“一人公司”（OPC，One Person Company）正从个体创业现象，升级为深圳培育新质生产力、激活实体经济活力的重要抓手。记者获悉，深圳已构建“市级统筹+分区错位+专项赋能”的OPC发展体系，市级行动计划锚定方向，各区依托产业禀赋精准布局，龙岗区更是推出“龙虾十条”专项政策，叠加资本、算力、场景等全要素支持，推动OPC成为深圳产业升级的新增长极，抢占AI时代创业赛道制高点。

**市级统筹定调：政策筑基，锚定OPC产业新赛道**

产业创新的背后，离不开顶层设计的精准引领。今年以来，OPC模式在深圳实现从“个体探索”到“城市级布局”的跨越，核心支撑源于《深圳市打造人工智能OPC创业生态引领地行动计划（2026—2027年）》的正式印发。该计划明确提出，大力培育产业发展新业态新模式，构建产业集聚、创新活跃的人工智能OPC创业生态，推动OPC与深圳实体经济深度融合。

据悉，深圳已筛选并公布首批10个OPC社区，覆盖南山、福田、宝安、罗湖、龙岗等核心城区及产业新区，形成全域覆盖、协同联动的布局网络。这些社区作为OPC培育的核心载体，重点整合算力、数据、资本、场景等关键生产要素，为个人创业者提供“从创意到产业化”的全周期支撑，破解个体创业面临的资源分散、门槛较高等痛点。

综合开发研究院（中国·深圳）金融发展与国资国企研究所执行所长余凌曲认为，在人工智能显著降低研发门槛的背景下，个体创业正逐渐成为科技创新体系的重要补充力量。深圳布局OPC，立足自身约5万亿元规模的实体经济基础、高度集聚的电子制造与供应链网络，将OPC打造为创新节点，通过激活个体创造力，补充产业链细分赛道，提升产业整体韧性与创新密度。

**分区精准布局：依托产业禀赋，构建差异化OPC生态**

依托各城区产业基础差异，深圳各区推出差异化举措，培育与辖区资源禀赋最适配的OPC团队，形成各具特色的发展格局。

近日，南山区官宣2025年GDP达1.01万亿元，成为全国首个万亿GDP地市辖区。该区以“模力营”为核心载体——深圳市首批重点建设的OPC社区之一，打造大湾区规模最大的人工智能垂直领域孵化加速器，面积超10万平方米，已吸引超700家企业申报，近200家优质企业获准入驻，总估值超200亿元。南山区对OPC的培育呈现“软硬通吃”特点，软件端，AI规上企业超1300家，AI产业集群增加值占深圳市约60％；硬件端，集聚机器人优质企业超200家，包括优必选、众擎、逐际动力等，形成从核心零部件到整机研发制造的完整产业链。政策层面，2025年南山区创新推出“六个一”“六个券”政策体系，其中“六个一”已升级形成2.0版，“六个券”即模型券、贴息券、技改券、流量券、保险券、消费券，为OPC从创新起步到市场拓展提供全方位支持。

宝安区作为深圳产业大区，拥有制造业全部31个大类，集聚制造业企业5.8万家，规上工业企业5588家，培育了5个千亿级战新产业集群。该区聚焦OPC硬件创业，以“场景+金融+制造”构建全国首个面向OPC硬创业的系统性产业支撑体系，依托粤港澳大湾区场景创新中心（智能制造）建设开放全域应用场景，通过“宝景创享”品牌提供各类场景支持；依托“宝企金服”品牌整合资源，降低创业门槛，2025年“宝企金服”投融资大会推动超500亿元投融资签约；依托粤港澳大湾区工业互联网公共技术服务平台，为OPC提供从小批量试产到规模化生产的全链条制造服务。

福田区华强北街道则推动“一米柜台”焕新升级，华强北OPC创新社区紧扣区域产业基础，引导创业者聚焦AI+硬件、机器人与智能终端、智能制造与供应链服务、跨境电商与涉外应用四大核心赛道，配套推出“支持OPC11条”，从五大维度为AI创业者提供“从创意到市场”的全周期保障。目前华强北集聚商事主体超11.5万家，年交易额超4800亿元，年海外包裹量超4亿件，产品覆盖全球180多个国家和地区，形成“三圈联动”的产业生态。

罗湖区作为深圳最早的高密度建成区，在深圳市首批10个OPC社区中独占两席——π创空间、璞跃创新中心，该区提出集中力量打造“场景城区”，开放金融、医疗、文旅消费、城市治理等领域海量场景。在2026“深港同心，罗湖创景”场景创新大会上，罗湖区发布2026年首批“创新机会清单”，41个机会项目涵盖六大核心领域，预计撬动投资超亿元。

龙岗区近日就《支持OpenClaw&OPC发展的若干措施（征求意见稿）》公开征询意见，推出被称为“龙虾十条”的专项政策。该政策成为深圳首个聚焦OPC与开源AI智能体工具协同发展的区级专项政策，标志着深圳OPC支持政策从“普惠型”向“精准型”“专业化”升级。

**生态赋能见效：OPC激活创新动能，重构产业分工逻辑**

余凌曲表示，AI技术的普及大幅降低了创业门槛，让个人创业者成为科技创新体系的重要补充力量。“未来创新结构可能呈现‘大企业+OPC’的协同模式，大企业提供平台和应用场景，个人创业者则成为新的创新节点。”他还认为，OPC相关政策能更好传导深圳“工业第一城”的动能，补充大企业“不愿做、做不了、做不好”的细分领域，提升产业链韧性与密度，推动生产效率、组织形式发生变革。

从市级行动计划的顶层设计，到各区的差异化布局，再到龙岗“龙虾十条”的专项加码，深圳正通过全方位、多层次的支持体系，推动OPC模式快速发展。专家认为，随着OPC逐渐嵌入深圳万亿级制造体系，城市创新将呈现更加密集的分布式结构，越来越多创意从个人和小团队中诞生，并在产业链中完成快速验证。OPC不仅为个体创业者提供了低成本的创业路径，更在重构深圳的产业分工逻辑、提升产业链韧性，为深圳在人工智能时代的产业竞争中抢占先机，探索出全新的城市创新答案。（证券时报 记者陈霞昌 / 配图来自深圳市工业和信息化局）
