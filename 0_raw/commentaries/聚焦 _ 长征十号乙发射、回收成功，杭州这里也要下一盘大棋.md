# 聚焦 | 长征十号乙发射、回收成功，杭州这里也要下一盘大棋

7月10日12时15分，长征十号乙运载火箭在海南商业航天发射场发射升空，将卫星顺利送入预定轨道，火箭一二级分离约6分钟后，一子级垂直返回，在海上回收平台通过网系捕获方式成功回收，发射及一子级回收任务取得圆满成功。
此次任务是我国首次成功实施运载火箭一子级可控回收，同时也是全球首次运载火箭网系回收。长征十号乙运载火箭成为我国首型成功实施回收的重复使用运载火箭。
据央视新闻报道，长征十号乙运载火箭由中国航天科技集团有限公司所属中国运载火箭技术研究院抓总研制。就在不久前的6月18日，中国航天科技集团有限公司刚刚与浙江省签署深化战略合作框架协议。
根据协议，双方将围绕服务国家发展战略大局，在太空人工智能、商业航天、“航天+”新兴产业和创新生态等方面开展深度合作，推动实现航天事业、航天产业与浙江省经济社会深度融合，共同培育发展新质生产力。这无疑为央地合作模式的深化探索，以及商业航天产业的能级跃升，打开了全新的想象空间。
事实上，中国航天科技集团有限公司与浙江早已结缘。中国空间技术研究院（中国航天科技集团第五研究院）是其在“长三角”地区的重要落子。早在2021年，中国空间技术研究院与杭州深化央地合作，目前在西湖区云栖小镇建成16条产线，形成年均300颗卫星的配套能力，其中不乏激光终端、太阳翼等关键部组件。
此外，中国空间技术研究院还在西湖区云栖小镇开了一家“超市”——东方红天选超市。它不卖日用百货，而是把商业卫星部件、软件及相关服务统统搬上了架，几乎包括整条卫星产业链，目前已上线300余款产品。
当火箭端的成本“天花板”被捅破，产业链下游的降本增效便成为新的焦点。西湖区已经在卫星制造端埋下伏笔。
云栖小镇的云栖九天，就在用3D打印重新定义卫星制造，一是大幅减重降本，采用3D打印的多孔金属材料，可使卫星主体结构减重30%。按每公斤10万元的发射成本计算，单颗卫星即可节约发射成本约120万元。二是生产周期减半，卫星研发制造从“以年为单位”的迭代，压缩至“以月为单位”，整体生产周期缩短了50%。
当火箭可以“回收再用”，卫星可以“打印快造”，发射端与制造端双向降本，商业航天的爆发拐点，或许比想象中来得更快。
西湖区是杭州商业航天产业的重要一极。以云栖小镇为主平台，该区集聚300余家商业航天生态企业，入选全省商业航天未来产业先导区培育名单。当下西湖区正锚定“AI+商业航天集聚区”“太空智算策源地”总目标，重点攻坚AI+制造、数据应用、卫星出海、供应平台、科普旅游五大领域，全力构建“创新策源、核心智造、场景应用”三位一体的产业生态，全力推动云栖小镇实现从云计算到太空智算的“二次飞天”。
