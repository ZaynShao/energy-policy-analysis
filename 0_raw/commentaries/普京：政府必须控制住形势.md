# 普京：政府必须控制住形势

普京就燃料问题最新表态：相关问题正在解决中，政府必须控制住形势。
综合塔斯社等俄罗斯媒体当地时间8月23日报道，俄罗斯总统普京在接受俄记者扎鲁宾采访时表示，俄政府必须控制住燃料形势。
▲普京（右）接受采访 图源：塔斯社视频截图
谈及燃料问题，普京说：“前天，我们与总理会面并讨论了这一话题。并非所有问题都已得到解决，相关问题正在解决中。总理正在关注这些问题。一个特别委员会已经成立。”
“民众生活中存在一些不便之处，当然，政府必须控制住形势。”普京补充说。
近期，俄罗斯不少地区出现燃油供应紧张。俄罗斯副总理诺瓦克7月8日在一场会议上称，乌克兰针对俄燃料和能源设施等民用基础设施的袭击导致多家炼油厂遭到破坏。7月30日，俄政府出台临时禁令，禁止出口汽油、柴油、船用燃油和轻质瓦斯油，该禁令于2026年8月1日至2027年1月31日有效。据俄媒8月19日报道，诺瓦克表示，俄罗斯已经开始进口燃料，并通过必要法规允许生产部分低排放等级的燃料。
