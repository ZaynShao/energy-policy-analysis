# 综研观察｜韦福雷 念淞元：穿透所谓“产能过剩”迷雾，推动共赴“中国机遇2.0”共赢新局

7月28日，商务部发布了《关于所谓“产能过剩”问题的中方立场》，系统回应了国际社会针对我国新能源、高端制造产业的片面指责。当下部分国家所谓的“产能过剩”早已脱离纯粹经济学范畴，沦为其实施贸易保护、阻滞全球产业转型的地缘政治工具。透过舆论的迷雾，这场争议的本质并非中国产能供给过剩，而是全球产业规则失衡和发展路径选择的分歧。与其炒作中国“产能过剩”，不如放下地缘博弈算计，对内深耕创新、对外扩大开放，持续释放“中国机遇2.0”红利，携手共建公平、开放、稳定的全球产业体系，创造各国共赢的新局。
//比亚迪“开拓者1号”滚装船抵达深圳港小漠国际物流港。（新华社发）
供需底层逻辑：全球增量空间广阔，先进产能是“中国机遇2.0”的供给底座
美西方国家刻意炒作中国“产能过剩”，既无视全球持续扩张的市场需求，也扭曲了全球产业链迭代的客观规律。比如，被贴上“过剩”标签的“新三样”（新能源汽车、锂电池、光伏产品）、信息消费“新三样”（智能网联新能源汽车、智能手机和电脑、智能机器人），均处于全球绿色转型、AI算力基建扩张的长周期赛道，市场需求远未触及天花板。各国碳中和、数字化升级将持续释放海量订单，国内企业扩产是基于全球长期需求的前瞻性布局。据国际能源署（IEA）测算，2030年全球新能源汽车需求将达4500万辆，光伏新增装机需求将达820吉瓦。现有产能不仅不过剩，反而存在巨大的供需缺口。
我国出口竞争力早已完成从低价优势到技术创新的切换，动力电池、智能整车等领域持续多年研发积淀，核心技术指标大幅优化，依托新质生产力形成的先进产能，正是“中国机遇2.0”的核心支撑。“中国机遇2.0”，区别于过去依靠低成本劳动力、初级加工品出口的发展阶段，是以高端绿色制造、数字智能产业、成熟产业链配套为核心，向全球输出高可靠、高技术的解决方案，为各国绿色转型、工业化升级提供普惠供给。
客观来看，国内部分细分赛道存在同质化内卷的结构性矛盾，但这是产业快速扩张期的阶段性问题，并非全行业系统性过剩。我国持续推进全国统一大市场建设，综合整治“内卷式”竞争，打造市场化法治化国际化一流营商环境，维护公平竞争市场秩序，坚持创新驱动产业发展，推动企业专精特新、差异化发展，进一步夯实“中国机遇2.0”的产业根基。
//一家风电设备制造企业厂区内的叶片。（新华社记者 连振 摄）
“产能过剩”争议的本质：双标与零和思维，阻挠“中国机遇2.0”惠及全球
针对中国产能的无端指责，根源在于发达经济体固化的双重标准与零和博弈思维，本质是其无法适应全球产业格局多极化的焦虑投射。欧美相继出台巨额产业扶持法案，设置本地含量、本土生产硬性门槛，依靠财政补贴保护本土产业链，却单方面将中国合规透明、普惠内外资的产业政策污名化，形成完全失衡的评判体系，刻意割裂全球产业链。
美西方国家将新兴产业竞争视作非此即彼的对抗，刻意忽视中国产业给全球带来的实质性红利，刻意淡化“中国机遇2.0”的普惠价值。国际可再生能源署数据显示，中国技术与规模化制造大幅压低全球风光发电成本；欧洲央行测算证实，自中国进口绿色产品能够显著降低各国进口物价，缓解全球通胀压力。与此同时，我国超5万家海外企业、3万亿美元境外投资存量近九成布局于发展中经济体，持续助力后发国家工业化，正是“中国机遇2.0”落地全球的直观体现。
刻意炒作“产能过剩”，既违背市场经济基本规律，也人为阻断全球共享“中国机遇2.0”的通道，拖累全球绿色与数字转型进程。
//中国（上海）自由贸易试验区临港新片区拍摄的特斯拉上海超级工厂。（新华社记者 刘颖 摄）
推动全球共赢的发展路径：坚持创新提质扩大开放，共享“中国机遇2.0”红利
全球绿色革命、人工智能赛道蕴藏巨大增量市场，产业发展远未到零和竞争阶段，封闭割裂只会抬高全人类转型成本，延缓碳中和与数字化发展进程，错失共享发展红利的窗口。
我国持续加大基础研究投入，引导企业摆脱低价内卷，聚焦核心技术攻关，优化区域产业布局，淘汰低效落后产能，推动产业从规模扩张转向价值创造，持续丰富高端绿色、智能装备供给，筑牢“中国机遇2.0”的产业内核。秉持“相通则共进，相闭则各退”的核心主张，不搞单纯产能输出、不搞产业垄断，而是依托自身完备产业链与创新能力，为全球提供低成本、可落地的绿色数字化解决方案。
“相通则共进，相闭则各退”，与其反复纠缠“产能过剩”，不如携手做大全球市场，充分释放“中国机遇2.0”的普惠价值。各国应抓住绿色与智能变革的时代机遇，摒弃贸易保护主义思维与双重评判标准，回归世贸组织多边框架协商统一公平的产业补贴规则，共建开放稳定、互利共享的全球产业链，形成全球合作共赢的发展新格局。
