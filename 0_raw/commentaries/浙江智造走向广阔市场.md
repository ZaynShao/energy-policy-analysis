# 浙江智造走向广阔市场

在浙江人形机器人创新中心，机器人既能搞定家政清洁，也能提供陪护照料。化身“智能店长”的NAVIAI，抓取成功率达99.9%；中心与方太联合打造的机器人总厨COOK，依靠视觉、力觉融合感知，可一气呵成跑完22步完整烹饪流程；面向康养场景，机器人还能完成抓取餐具、舀取食物、平稳递送等一整套精细照料动作。
“我们提供了覆盖数据处理、模型训练、机器人运维开发的工具链，致力于加快人形机器人的开发与落地。”浙江人形机器人创新中心有限公司首席科学家、总经理熊蓉说，人形本体只是切入口，解决真实场景泛化难题才是主要目标。中心希望打造通用、易用的具身智能机器人，让技术走出实验室，真正改变生产生活方式。目前，相关产品已在服装制造、物流搬运、汽车装配、商超零售等多个细分行业实现应用落地。
浙江是我国人工智能创新发展高地，已初步形成覆盖芯片、大模型、智能体、应用服务的人工智能全产业链格局。数据显示，2025年，浙江省人工智能核心产业营收达7131亿元，同比增长20%；今年前5个月，核心产业营收达3384亿元，同比增长23.6%，核心企业增至2065家。
对人工智能来说，算力是“加速器”、数据是“燃料”、模型是“引擎”。浙江省发展改革委党组成员、副主任闫西安说，浙江将统筹推进算力、数据、模型等基础性工程，加快构建新型算力体系，提供效率更高、成本更低的算力服务；同时打造高质量数据集和语料库，推动数据资源化、市场化。此外，还将加快建设医疗等领域的国家人工智能应用中试基地，加强新业态发展的政策支持和服务保障。
材料科学的突破是浙江创新的另一条战线。陶瓷颗粒从8米高处坠落完好无损，金属线材兼具柔韧特性与超高强度，超高纯纳米氧化硅异形结构磨料实现千吨级年产量……在甬江实验室，一系列前沿材料技术令人眼前一亮。实验室于2021年5月正式揭牌，是浙江省打造新材料科创高地的重要举措，也是宁波市重点打造的科创平台。这里汇聚优秀科研团队与高端学术人才，致力于打通材料创新全链条，目前多个重点科研领域进展迅速，一批前沿技术实现产业化应用。
甬江实验室党委书记、主任崔平说，实验室坚持“源于需求、先于产业、服务产业”的发展思路，聚焦前沿材料、智能制造领域持续攻坚突破，多项创新成果填补国内空白、引领国际发展方向，在先进结构陶瓷、半导体热场材料等多个赛道取得关键性进展，不少成果已落地服务实体产业。
浙江创新的版图还在向民生健康领域延伸。针对儿童弱视开展融合功能训练的二类医疗器械、服务视障群体出行的智能导盲杖……走进中国眼谷孵化园展厅，各类眼视光产品琳琅满目。中国眼谷理事长、温州医科大学附属眼视光医院终身名誉院长瞿佳介绍，科创园区以眼视光产业为特色，入驻企业超770家，集聚科研人才2400余名，打通了从研发到批量生产的完整链条，具备规模化量产能力。
“浙江省全面推进科技创新和产业创新深度融合，上半年规上工业增加值增长8%，好于预期、高于全国、领跑东部。”浙江省经信厅党组成员、副厅长黄旭荣介绍，上半年，浙江数字经济核心产业增加值预计增长10%以上，连续6个季度保持两位数增长。其中，核心制造业增加值预计增长15%以上，具身智能、人工智能服务器等智能终端增势向好。
