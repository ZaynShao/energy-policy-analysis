# 氯化铵 | 集中检修 能否触动氯化铵市场调涨的神经？

自去年11月底，国内氯化铵市场止跌反弹，虽然12月调涨频繁，但涨幅较小，春节后，正值春耕需求释放，而联碱企业无库存，叠加中东冲突带动化肥多产品大幅上涨，氯化铵借机，进入快速上行通道，以华东地区干铵价格为例，截止3月末，氯化铵价格较节前上涨230元/吨，涨幅51.11%。当前氯化铵市场止涨，暂时维稳。5月将迎来一波集中检修，能否再次触动氯化铵市场调涨的神经？

据悉，除了去年以来一直停车的130万吨产能外，春节后至5月涉及560万吨产能停车检修，停车产能占全国总产能的1/3，供应收紧，加重联碱企业挺价心态。

另外，虽然当前氯化铵收单情况一般，但各联碱企业前期待发充足，且在持续走货下库存无压。此外，虽然出口管控，但有前期出口订单仍在执行，所以联碱企业当前主要兑现前期合同为主，对于市场稳价起到重要作用。

不过复合肥企业目前处境不佳。原料成本持续高位，国际局势不稳，硫磺硫酸居高难下，硫基复合肥成本坚挺，同时磷肥仍存走高预期，复合肥企业对于高成本原料采购积极性明显下降，消化库存为主，补库谨慎。虽然氯化铵价格相对稳定，但复合肥企业在下游需求转弱，新单收单推进缓慢下，生产积极性受挫，对氯化铵的采购也大打折扣。

综合来看，当前联碱企业双吨利润尚可，但纯碱价格偏弱下，对氯化铵的挺价意向更浓，叠加后期装置检修供应收紧，利好可见。而夏季肥用肥尚早，复合肥企业短期多选择降负来缓解当前高成本压力，所以氯化铵刚需仍存缩减预期。供需两弱，短期氯化铵市场或处于僵持博弈状态，价格涨跌两难。
