# 瑞浦兰钧重庆30GWh基地封顶

加入供应链产业群，请加微信gasgoo88，出示名片
盖世汽车获悉，7月2日，重庆青拓新材料年产70万吨不锈钢冷轧项目开工暨重庆瑞浦兰钧30GWh电池项目封顶活动在重庆涪陵高新区举行。现场同步签约6个先进材料配套项目，协议总投资超300亿元。
图片来源：涪陵发布公众号
重庆瑞浦兰钧30GWh电池项目首期规划12GWh储能及动力锂电池产能，主要生产适配乘用车、商用车的动力电池及家用、工商业储能产品。该项目由青山实业与上汽集团共同推进。投产后可补齐涪陵新能源汽车电芯制造环节，为涪陵智能网联新能源汽车及零部件产业集群提供支撑。
同期开工的重庆青拓新材料年产70万吨不锈钢冷轧项目总投资20亿元，占地400亩，将建设全流程数字化冷轧生产线，产品以200系、300系、400系不锈钢为主。项目预计2027年6月建成投产，全面达产后年产值可达100亿元。该项目的落地填补了重庆高端冷轧不锈钢产能空白。园区同步预留1600亩拓展空间，未来可延伸“冶炼—热轧—冷轧—深加工”产业链条。
两大项目与华峰铝业45万吨新能源汽车高端铝板带箔项目、鑫源汽车数字工厂等项目形成产业协同，推动涪陵金属材料和新能源汽车产业集群发展。涪陵正依托“10+N”产业链实施链主伙伴计划，推动产业从企业集聚向生态协同演进。
