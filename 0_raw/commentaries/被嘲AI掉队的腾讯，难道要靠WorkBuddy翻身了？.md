# 被嘲AI掉队的腾讯，难道要靠WorkBuddy翻身了？

腾讯说他们做 AI，是以为上了船，后来发现那个船漏水了。。。
细想一下还真是，元宝在公众号、视频号评论区还能稳定刷新，但 APP 本身，好像已经很久没啥声响了。
混元模型也是最近 Hy3 正式版发布之后，讨论度和口碑才有点起色。
还有 QClaw，ima 知识库，Marvis 等等，似乎腾讯一直缺少一个真正火出圈了的纯 AI 产品。
但在最近，有个叫 WorkBuddy 的刺儿头很显眼，貌似正在尝试扛起这杆大旗。
5 月 13 日发布的腾讯 Q1 业绩公告中，WorkBuddy 的日活干到了同类型的国产榜首，跟它一起提及的，是《王者荣耀》、《三角洲行动》这种当红炸子鸡。
那它真有这么好用么？
我们也下回来用了一段时间，你别说，怪不得口碑不赖，这味道还挺正的。
简单说，WorkBuddy 这么来劲儿，主要是干活儿的那套流程相当成熟，很省心。
首先就是界面，如果你见过 Codex，那打开 WorkBuddy 会有种熟悉的感觉，因为布局设计，功能区划基本没啥两样。
三块儿内容，左边是基础菜单和项目空间，中间是聊天区，右边是能展开的交付物的预览，看生成的文档或者网页长什么样。
好的设计它就是这么心有灵犀。
其次就是连接即时通讯软件的能力，也就是龙虾火出圈的那个场景：手机下令直接干活。
WorkBuddy 这儿，腾讯自家的微信，QQ 能连，隔壁的飞书，钉钉也能连，而且配置起来可能就是扫个码的事儿，比 OpenClaw 简单多了。
再加上微信 AI 才刚刚内测，战未来的想象力就已经拉满了。
不过这么长时间用下来，要说我真拿手机下了多少命令，倒也没有，因为平时工作，屁股都焊在工位上，没啥远程需求。
但它还能把输出结果存到你的工作空间，发到微信或者飞书里，不用来回倒腾，这点倒是挺有用的。
所以要说最核心的干活能力，还是跟模型配套的一系列基础设施，无论是轻度的办公体验，还是稍微难点的代码开发，它搭建得都不赖。
在办公上，感受最深的一点其实是本地化，之前的工作空间在云端，你给个参考得上传，搓个 Demo 得下载。
但 WorkBuddy 这种就不用，每新建一个项目空间，就对应你电脑本地的一个文件夹，AI 的吃喝拉撒全在里面，一清二楚。
实际处理文件的话，它还内置了很多模板工作流，同一份 PPT，简单描述直出的，比起用了工作流的，就会差很多。
下面就是写完提示词直接开始的，出品质量全凭模型干拉，得到的结果也比较糊弄。
基本就是个烂大街的赛博电子风，AI 味儿溢出屏幕，还有字符错行，唯一可取的就是蓝绿配色，对应 Xbox 和 PS，应付交差还行，做展示就有点丑拒了。
没办法，那种一句话 XXXX 的美好想象，除非 AGI 降临人世，否则只能在视频宣传片里看见。
但选了模板后，效果就会提升一大截，这里选日常办公里内置的「幻灯片」，点击后，输入框里会多个「幻灯片」的黑色块，里面浓缩了它对 PPT 的所有理解，会跟你的要求一起打包发送给模型。
一套组合技下来，AI 味儿就淡了很多，它选了一套机密档案的风格参考，页面上设计了一些印章，编号之类的小元素，氛围渲染得好多了。
但注意，咱不建议点设计创意里的那个「PPT 设计」，它会联动另一个腾讯的设计软件，效果一般就算了，还没法直接导出 PPT，相当鸡肋。
除此之外，还有效果更好，更进阶的玩法，也是 WorkBuddy 好用的另一个原因：「技能商店」
咱搓的是 PPT，就去里面找 PPT 技能，具体操作起来，先去左边「专家-技能-连接器」选项里，找到技能商店，然后搜索 PPT，把这个广受网友好评的「归藏的 PPT Skills」装上，里面内置了几种模板，相当好看。
然后在下命令之前，点击+号，选中这个杂志风的技能，再说要求就行了。
虽然还是 DeepSeek-V4-Pro，但这视觉的质感马上就不一样了，skill 的沙丘暖棕色调，配上杂志风格的字体，看起来就有种老式报纸的感觉。
而且脱开视觉，内容排布也合理得多，里面有详有略，还单独把唬人的金句拿出来放大了，比默认风格的纯表格堆砌顺眼得多。
这么一个简单的任务跑完，WorkBuddy 的功能基本就了解差不多了。
这其实就是业内人说的「Harness」，大白话说就是个壳子，能装不同的模型，也能接形态各异的工具手脚，DIY 成最适合你工作流的形状。
当然，咱推荐它除了因为这个壳子用起来不赖，还因为它里边的模型用起来实惠。
一来能接第三方模型，二来它自己平常活动就挺多，每天领个 100 积分，主流国产模型，像 DeepSeek，GLM，Kimi，Minimax 等等都能用，偶尔还给你来个 1 折 2 折的倍率。
而且它家混元 Hy3 模型刚发，8 月 5 日前都可以免费蹬，香的一批，后面任务我也换成了 Hy3 来跑。
不过，办公顺手只是一方面，支撑它干到这个份额的，我觉得还有它不错的代码开发能力。
而这才是更考验 Agent 应用的地方，因为实际开发中，跟 AI 的拉扯往往需要数十个回合，期间每多一个需求都可能扯出来一堆小坑。
你让它扒个数据，可能会被拦截；让它开发程序，又会被一堆弄不清的权限配置卡住。
这些小坑你很难用指标去量化，也不好像 Benchmark 那样跑个分，但又确实影响体验。
不过 WorkBuddy 用下来，会稍微丝滑那么一点。
比如让它去 GitHub 上找个聚合新闻的小项目，然后拉到本地二次开发，基本就没啥卡壳，拉下来就直接启动，也不用配置什么环境。
二次开发也一样，让它丰富一下新闻的展示效果，它会先理解仓库，再进行微调。
但 hy3 模型只有二十多万的上下文，肯定塞不进整个仓库，那就得压缩。好在它的压缩方法还不赖，没丢失太多信息，而且操作的时候基本感知不到。
最后它借用了原来灰色小字的空间，把播放数量，简介之类的信息放了进去，不影响原来的布局，基本符合要求。
一般来说，开发完自然是要上线的，这步放到平时就得跳转到第三方去接仓库，改配置，但 WorkBuddy 这儿已经打包好了。
技能商店里就有很多接口，像白嫖额度非常高的 Vercel，注册一下就可以免费部署网站，但稍微有点网络门槛。
还有「腾讯云 CloudBase」的连接器，更简单一些，后面连的是腾讯云开发的服务器，新用户能嫖一个半年套餐，额度不多，但也能跑跑小项目。
对话框里开启这个连接器，然后让它部署就行了，唯一要手动点的，就是允许和确认，过一会儿网站就上线了。
而且这还是带后端的复杂网站，要是不用抓数据缓存的静态网页，搓个整活儿的 SBTI 人格测试，或者小游戏，那连接器都不用。
你就直接让它部署，它会免费给你托管到自带的服务器，去设置里的数据管理，点开「我发布的应用」就能看见自己搓过的东西。
没错，这个 OpenAI 前几天才上线的新功能，WorkBuddy 反而早就实装了，要不说人能干到第一呢。。。
所以项目跑完也能感觉到，它不是那种效果拔群的突出，而是使用体感很丝滑。
虽然中间的很多小坑还在，但你不用跳出去手动配置，授权后在应用内就解决掉了，无非是找一找连接器，装一装技能。
再加上腾讯本身的产品线铺得很开，文档，开发，邮箱，通讯软件，对接上这套全家桶，基础的办公任务就很好跑通了。
不过话说回来，都是摸着石头过河，所以这里边也有很多鸡肋的地方。
比如这个「专家团」，你以为是一句话召唤一个团队合作，但其实一般的预设都很死板，它研究的方向跟你预想的可能根本不一样，容易越跑越偏，Token 消耗还贼大。
而且它还没 Git 树，你搞个新功能哪出错了没法退回旧版本，只能从头再来，有点磨人。
所以对不少人来说，和 Codex，Claude Code 这类的 Agent 工具相比，WorkBuddy 暂时还是个平替。
甚至都很难说是性价比平替，因为人家也能接其他模型套壳用。
但在门槛这块，在一些轻度用户的使用体验上，那 WorkBuddy 就是秒杀。
而且这些普通 C 端用户的需求是实打实的多，WorkBuddy 看中的就是这部分缺口。
毕竟如果光会聊天，AI 是撑不起现在的泡沫的。
怎么把参数越来越猛的模型用到生产中，这事儿不止腾讯一家在研究。
但它这手低门槛，强生态的组合，搭配上相对成熟的 Harness 框架，用户用着就是比别家舒坦，这里边的优化适配肯定没少费心思。
如果你之前嫌麻烦没试过这类工具，那确实可以试试 WorkBuddy，它可能不是最好的，但上手入门选它没毛病。
