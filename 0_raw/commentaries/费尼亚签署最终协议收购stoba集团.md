# 费尼亚签署最终协议收购stoba集团

加入供应链产业群，请加微信gasgoo88，出示名片
2026年7月3日，盖世汽车获悉，多元化工业供应商、全球燃油系统、电气系统及售后市场解决方案领军企业费尼亚（PHINIA Inc.，纽约证券交易所代码：PHIN）于2026年6月30日宣布，已签署最终协议，将收购全球高精密零部件、系统及定制化制造解决方案技术合作伙伴——stoba集团（stoba Group）100%的股权。本次交易预计将于2026年第四季度完成，尚需获得相关监管机构批准并满足惯例的交割条件。
图片来源：费尼亚
stoba集团在精密工程及先进制造领域拥有深厚的专业能力，其在高精度零部件加工、电化学加工（ECM）、激光焊接与钻孔等方面的技术积淀尤为突出。
费尼亚认为，此次收购将进一步完善公司现有产品组合，提升其在全球范围内提供高精密零部件、系统及集成解决方案的能力。与此同时，交易还将增强供应链的稳定性与韧性，并拓展公司在复杂零部件制造、先进工程技术及系统集成方面的综合实力。
通过此次收购，费尼亚将在多个战略性行业进一步扩大业务布局，覆盖乘用车、商用车、非道路机械、工业领域、高端装备制造、半导体、航空航天与国防等板块。
作为由原博格华纳燃油系统和售后市场部门分拆成立的企业，费尼亚近年来持续通过战略收购完善技术版图——2025年完成对SEM公司的收购后，公司已形成“喷射+点火+控制”的完整系统能力。此次将stoba集团纳入麾下，标志着费尼亚在精密制造与系统集成领域再下一城。
费尼亚总裁兼首席执行官Brady Ericson表示：“预计将利用现有流动资金完成此次交易，同时保持充足的财务灵活性，以支持公司其他战略重点的发展。”
