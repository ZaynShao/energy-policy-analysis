# 你的公积金，还能这么用！

近期，全国多个城市密集出台住房公积金优化调整政策，使用场景更广、支取更灵活，具体都有哪些变化？
多地解锁公积金新用法
近日，北京落地公积金装修提取新政，明确自住住房产权人及配偶可凭合规装修增值税发票，按票面金额50%申请提取住房公积金，单套房屋最高可提取25万元。同时，设置十年提取间隔，并对装修企业资质作出明确要求，进一步规范资金使用。
在安徽淮北，居民可以根据厨卫改造、全屋装修的施工进度，灵活选择一次性或者分多次提取公积金。自新政策实施以来，当地装修提取业务已办理1934笔，提取总金额超1.9亿元。目前，淮北市住房公积金管理中心已陆续推出住宅适老化、适幼化改造公积金提取业务。
湖南郴州近期明确，新增车位购置、物业费缴纳等提取场景，市民可申请提取住房公积金。而且所有新增业务全部开通线上办理通道，大幅简化办事流程。
而在陕西延安，当地近期一次性推出七大新增提取场景，全面覆盖冬季取暖费、车位储藏室购置等日常住房支出，精准贴合当地家庭常态化安居消费需求。
从买房到入住之后的日常居住开销，住房公积金的使用边界不断拓宽，各地还配套设置票据核验、额度上限等规则，兼顾惠民实效与资金安全，让政策既“放得开”也“管得住”。
增加提取频次
资金使用更灵活
在拓宽公积金使用场景的同时，多地还积极同步优化支取规则，提高公积金的提取频次，进一步释放资金灵活使用的效能。
以往不少城市办理提取住房公积金用于商业房贷，执行按年度提取的模式，一年只能支取一次。8月15日起，湖北武汉正式实施住房公积金提取优化新规，缴存职工正常偿还商业房贷满六个月，即可按月申请提取公积金，累计提取总额不超过商业贷款本金，实现公积金资金逐月对冲还贷压力。
广西柳州也对住房公积金提取规则作出调整，放开按月还贷提取的同时，增设额度跨年结转机制，当年没有使用完毕的可提取额度，可以顺延至下一年继续使用，减少额度闲置浪费。
专家表示，各地相关政策各有异同，但均立足公积金民生属性，体现民生导向，在支持力度、方向上都更加灵活。
从按年提取到按月可提，多地政策调整的核心，是让住房公积金支取节奏匹配老百姓真实的资金支出节奏。需要提醒的是，灵活提取不等于无限制支取，提取总额严格受贷款本金、个人账户余额约束，各地细则存在差异，缴存职工办理前，要通过官方渠道核对本地政策，合理规划资金使用。
从“一人可用”变成“全家能用”
住房公积金除了自己用，各地住房公积金优化调整还有一大亮点，升级了家庭互助机制。多地放开代际互助通道，聚焦居家养老、育儿安居，支持适老化、适幼化改造，让住房公积金从“一人可用”变成“全家能用”。
针对以往公积金家庭互助互济受限、覆盖面窄的问题，江苏苏州近期出台新政，放宽直系亲属互助使用门槛，即便亲属户口不在一起，也可互助使用公积金，用于支付购房首付、分摊房贷月供、缴纳购房契税，有效降低年轻群体安家置业的经济压力。
近日，广东珠海正式落地公积金“全家帮”提取模式。明确缴存职工可使用本人公积金账户余额，为配偶、父母、子女的自住住房开展装修改造，支持子女帮扶父母翻新老旧住宅、改善居家居住环境。
代际互助的政策深度赋能老旧小区更新改造。在湖南岳阳，当地允许居民提取住房公积金，分摊老旧小区加装电梯的个人出资费用，有效降低居民改造门槛、盘活存量住房资源。当地相关业务已办理107笔，累计提取金额536.09万元。
专家介绍，这类代际互助新政精准补齐了以往住房公积金使用的短板，破除家庭成员使用限制，盘活家庭闲置资金，满足养老、育儿居住改善需求，实现从“单人可用”到“全家共济”的升级。需要注意的是，互助提取仅限自住住房，群众办理业务需提前核对属地细则、备齐相关亲属证明材料。
