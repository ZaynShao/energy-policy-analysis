# 美媒：美对伊战事损失至少45架“死神”

美媒：美对伊战事损失至少45架“死神”无人机，约占美军该型无人机总数的25%。
据美国《华盛顿邮报》13日援引美国官员的话报道，美军在与伊朗的战事中损失至少45架MQ-9“死神”无人机，约占美军该型无人机总数的25%。
报道说，美伊战事爆发前美军拥有约185架“死神”无人机。该型号无人机主要用于执行侦察和定点打击任务，被频繁用于霍尔木兹海峡附近。无人机通常低空飞行且速度慢，相对容易被防空系统击落。不过，美官员表示，并非所有损失的“死神”无人机都是被击落的，一部分是在与操作员失去联系后坠毁，但数量不详。
报道还说，根据所搭载的传感器和武器类型不同，一架“死神”无人机的造价在3000万美元至5000万美元之间。这意味着在伊朗战事持续消耗美军武器库存之际，仅“死神”无人机一项的损失可能就已超过13亿美元。
