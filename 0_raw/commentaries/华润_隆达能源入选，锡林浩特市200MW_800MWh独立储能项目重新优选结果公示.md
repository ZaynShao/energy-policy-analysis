# 华润/隆达能源入选，锡林浩特市200MW/800MWh独立储能项目重新优选结果公示

申报项目名称：华润隆达锡林浩特市塔拉200MW/800MWh储能电站项目
建设规模：200MW/800MWh
实施主体：锡市隆达能源有限责任公司、华润新能源（锡林浩特）有限公司（联合体申报）
接入站点：塔拉500千伏变电站
项目建设地点：锡林浩特市境内。
项目接入：塔拉500千伏变电站。
项目建设规模：规模20万千瓦/80万千瓦时，拟优选项目实施主体1个。
技术类型：独立新型储能电站采用构网型技术，优先支持压缩空气、全钒液流、钠离子等技术路线。
