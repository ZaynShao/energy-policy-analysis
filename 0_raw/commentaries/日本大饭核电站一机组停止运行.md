# 日本大饭核电站一机组停止运行

日本大饭核电站3号机组因发电机异常停止运行。
▲资料图
当地时间8月8日23时55分左右，位于日本福井县的关西电力公司大饭核电站3号机组，因发电机内部装置出现异常，相关警报被触发，反应堆自动停止运行。关西电力表示，此次事故不会对周边环境造成放射性影响。
关西电力旗下同样位于福井县的美滨核电站3号机组，今年5月也曾出现因汽轮机发生蒸汽泄漏而采取手动停机措施的情况。
