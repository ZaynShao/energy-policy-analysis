# 博泰车联再获大单

加入供应链产业群，请加微信gasgoo88，出示名片
盖世汽车获悉，8月19日，博泰车联（02889.HK）发布自愿性公告，宣布收到某头部OEM新能源车企的项目定点通知，被选定为下一代全新车型8397座舱平台的供应商。
图片来源：博泰车联
据悉，8397已正式明确为该头部车企的平台化配置，结合博泰目前在供的8295等平台产品，博泰已实现对该头部车企座舱平台的全系覆盖，双方合作已向多平台深度合作全面升级。博泰表示，此次合作未来将进一步向主流热销车型延伸。
作为高通第五代座舱计算平台，8397具备强大算力底座，可支撑多模态感知、本地大模型推理等前沿能力。博泰将基于该平台搭建搭载物理AI、全域智能体的新一代车载交互系统，实现环境实时推演、主动出行服务等智能化功能。
博泰车联是业内少数同时深度绑定华为与高通双生态的智能座舱解决方案核心供应商，在高通8295/8397与华为麒麟9610A三大核心平台上均实现了规模化布局。公司认为，此次项目定点标志着其基于高端座舱平台搭建物理AI、车载智能体系统的技术方案已获主流车企广泛认可。
该项目落地将持续夯实博泰车联在新能源乘用车领域的市场份额，强化其在车载前沿AI场景化应用的领先优势。自2025年9月上市以来，博泰车联已累计获得多个高端智能座舱重要定点项目。
