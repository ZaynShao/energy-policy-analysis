# 普京登岛，日本急了

俄罗斯总统普京登上南千岛群岛（日本称北方四岛），日本外务大臣茂木敏充对此提出强烈抗议。
俄罗斯总统普京当地时间8月13日登上南千岛群岛（日本称北方四岛）。日本外务大臣茂木敏充随后对此提出强烈抗议。
▲图片来源：俄媒报道截图
俄罗斯克里姆林宫在社交媒体上发布消息说，普京视察了伊图鲁普岛（日本称择捉岛）上的一家水产品加工厂，并在岛上会见了萨哈林州州长利马连科，他还视察了一所学校和一家医院。
消息说，普京与水产品加工厂员工交谈，并与他们合影留念。他还品尝了当地生产的鱼子酱。俄媒体报道说，这是普京首次登上南千岛群岛。
茂木敏充就普京登上择捉岛提出强烈抗议，并称北方四岛是日本的“固有领土”。
因在南千岛群岛（日本称北方四岛）的归属问题上存在争议，俄日在二战结束至今未缔结和平条约。
