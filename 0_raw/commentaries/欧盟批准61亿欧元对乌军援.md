# 欧盟批准61亿欧元对乌军援

欧盟委员会批准向乌克兰提供61亿欧元国防援助。
当地时间24日，欧盟委员会批准向乌克兰提供61亿欧元国防援助，用于采购乌克兰急需的导弹防御系统、弹药和雷达。
乌克兰总统泽连斯基23日在会见媒体代表时说，为获得真正的安全保障，乌克兰不会寻求加入北约之外的替代方案。
泽连斯基说，如果乌克兰加入北约，将获得资金、武器合作等方面的一系列机会。他表示，今年乌方还需要欧盟提供300亿欧元（约合350.43亿美元）贷款用于弥补财政赤字，此外，乌克兰还面临270亿美元的国防预算赤字。“如果我们被纳入北约预算范围，我们会更加强大。”
