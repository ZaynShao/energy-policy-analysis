# 综研观察｜从区块链到大模型，为什么都在谈“Token”？

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/QIJgF5A55WYlkM43uHlHHy0ZO4SSxbWxmzPv3pUnVJvOddsh0iaVURqUJ8S4qKRwa09iardVVEFuM8FtnM3iaQGmZv68UbqbB96rOy07y6AL4s/640?wx_fmt=jpeg&from=appmsg)

近几年，“Token”这个词越来越频繁地出现在不同领域。在区块链世界，它曾是财富的象征；在今天的人工智能大模型领域，它又成了衡量算力与成本的单位。为什么一个简单的单词，能跨越区块链与人工智能两个领域，并同时成为核心概念？

![image](https://mmbiz.qpic.cn/mmbiz_png/QIJgF5A55Wa4Y45XlTZqlp5uxwTy2DSEh2XGxicFNE8ibYEYcOewSz7OZibd9GaA8Z4N4TD82Sta6sBaEbhcgkJ38TEmXNqw3dudGJu2bUyu4A/640?wx_fmt=png&from=appmsg)

**溯源：Token的本意，从来不止“代币”**

回归单词本身，Token的英文本义是“令牌、标记、凭证”，本身是一个中性词，只是不同技术领域赋予了它不同的使命，才衍生出五花八门的叫法。

早在几千年前的苏美尔文明，人们用黏土做成不同形状的“小筹码”来代表羊羊、谷物或劳动力，这就是最早的Token。它不具备金银那样的内在价值，但它代表了价值，是一种信用凭证。在区块链和AI大火之前，Token其实就已经出现在互联网领域，我们日常登录网页、使用APP时收到的验证码、登录令牌，也叫Token，它是一种临时身份凭证，用来验证用户权限，用完即失效，和金融、计算都无关。无论形式如何变化，Token始终围绕一个核心，它是一种被系统认可的“标记”，用来代表某种权利、信息或身份，这也成为后面区块链和AI两种形态的共同起点。

![image](https://mmbiz.qpic.cn/mmbiz_png/QIJgF5A55WYWmjg0ZEO4iaP8BVicrYewP4T5T2JwhdkGJTuY2JibUVViaoLCISiaIiaFa2ZDKfge8iapgGicrHMVdpRTB9MkBQiazZTb8HeaiaSvtzWN8/640?wx_fmt=png&from=appmsg)

**初代Token：区块链世界的数字权益凭证**

最早出圈的区块链Token，是很多人对Token的第一印象。在区块链生态里，Token是核心载体，伴随比特币、以太坊的兴起，逐渐被大众熟知，这个阶段的Token，核心定位是去中心化的价值与权益凭证。

**常见叫法：代币、通证、加密代币。**早期行业内最通俗的叫法是代币，因为它具备一定的交易和流通属性，能在加密市场买卖，很多人误以为它就是虚拟货币。但随着行业规范化发展，更精准的叫法是通证，全称“可流通的加密数字权益证明”，这个定义更贴合它的本质，也淡化了单纯的货币属性。

**核心含义与用途。**区块链Token的本质是把现实世界或数字世界的权益，通过区块链技术进行加密、确权和流转，它不只是钱，更是一种权利载体。比特币属于区块链原生Token，是比特币网络的价值载体，依靠去中心化共识机制，成为一种数字稀缺资产；以太坊的ETH，既是网络手续费的支付工具，也是参与链上治理的权益凭证；还有各类NFT，属于非同质化Token，代表数字作品、艺术品、藏品的专属所有权，实现了数字内容的资产化。区块链里的Token，核心是“价值”，它有所有权、可流通、可交易、能代表权益，依托区块链的不可篡改、去中心化特性，构建了一套全新的价值流转体系，它的价值来源于市场共识和生态应用。

这个阶段的Token，诞生于Web3.0和去中心化金融浪潮，主打“去中介化”，实现点对点的价值转移。它的发展围绕资产确权、生态激励、金融应用展开，一度成为加密行业的核心符号，也因为市场波动和监管规范，逐渐回归“权益凭证”的本质，褪去过度投机的色彩。

**AI时代的Token：AI大模型的最小计算单元**

随着ChatGPT等大模型火爆全球，“Token”这个词在大模型时代再次发生了跃迁。在AI语境中，Token成为大模型处理文本信息时的基本语义和计算单位。

**常见叫法：词元、AI Token、计算令牌。**在AI大模型领域，比较易懂的中文叫法是词元，也有技术人员直接称其为AI Token、计算令牌，还有专家学者建议叫语元、子词、模元、模币、算币、托肯等各种叫法。截至目前，尚未有一个统一的中文叫法。

**认知切片：Token是大模型处理文本的切分单位，AI将文本拆解为Token序列。**计算机不识字，只认识数字。为了让AI理解人类语言，我们需要把句子“切碎”。“苹果”可能是一个Token；“Apple”可能是一个Token；甚至一个复杂的长单词会被切成几个子词Token。英文中“ChatGPT is amazing!”被切分为[“Chat”,“G”,“PT”,“is”,“amazing”,“!”]，中文则按字/词分割，这种切分也直接影响模型性能。

**效率密码：Token是衡量AI算力成本的计价砝码，Token数量决定AI服务定价。**AI时代的Token是计量单位，很多AI工具按Token收费，是因为每处理、生成一个Token，都需要消耗算力、电力和存储资源，Token数量直接对应计算成本。就像电费按“度”算，AI服务按“百万Token”算。Claude 3 Haiku每百万Token仅收费0.25美元，而GPT-4 Turbo高达10美元。开发者必须精打细算，像管理云服务器资源般优化Prompt（提示词）长度。近期随着“小龙虾”爆火，OpenClaw已经成为单月消耗Token最多的应用，一个月内烧掉的Token高达10.2万亿。

这个阶段的Token，诞生于通用人工智能爆发期，核心是服务于AI的语言理解与内容生成，主打“生产力工具”属性。它没有交易价值，不能买卖流通，数量多少和算力消耗、文本长度挂钩。AI Token不只是文字专属，如今多模态大模型兴起，图片、音频也会被拆分成对应的Token，已成为AI处理所有信息的基础计量单位。

**Token正成为数字经济时代的通用语言**

从过去十年的演化来看，Token一直在“泛化”。未来，随着技术的进一步发展，Token或许还会衍生出更多含义，出现更多新叫法，例如Agent之间的交互单位（AI Agent Token）、人机协作中的“任务Token”等等。它的外在形态在变化，但底层逻辑正在趋同，即把复杂世界，拆解为可计量、可计算、可流转的最小单位。它背后反映的是一个更大的趋势，人类正在把世界拆解成可以被机器理解和处理的最小单位。

这种趋势，正在被产业实践不断强化。2026年3月16日，阿里巴巴集团宣布正式成立Alibaba Token Hub（ATH）事业群，旨在围绕“创造Token、输送Token、应用Token”构建完整的AI生态体系。‌‌黄仁勋在GTC 2026上提出了更宏大的“Token经济学”，未来的数据中心将不再是存储数据和运行软件的机房，而是“生产Token的工厂”。他甚至给出了Token作为“大宗商品”的五档定价——从免费层到每百万Token150美元的顶级层，价格差异取决于模型的规模、上下文长度以及响应速度。这些信号背后，其实指向同一个方向，无论是价值、数据，还是智能，都在被“Token化”。理解Token，不只是理解一个词汇的变化，更是在理解未来的世界将如何被计算、被定价，以及被连接。

**从“看懂Token”到“用好Token”**

当Token从区块链走向AI，从“价值载体”演变为“计算单位”，它已经不只是一个技术概念，而开始成为数字经济运行的一种基础逻辑。

**第一，企业和个人层面：从“持有Token”转向“管理Token”。**无论是调用大模型、构建智能应用，还是进行内容生成，Token都直接对应成本。未来企业不仅要管理资金、人力，也要管理“Token消耗”，提升Prompt设计能力、优化模型调用效率，正在成为新的“数字运营能力”。对于大众而言，要学会像管理资产一样管理“智力额度”，通过精简冗余的提示词来降低费用。同时，在享受AI带来的高效 Token输出时，要保持对原始事实的核查能力。

**第二，平台层面：构建“Token驱动”的生态体系。**Token在平台中承担“连接器”的角色，连接用户、开发者与服务。区块链通过Token进行激励分配，AI平台通过Token进行算力计价，本质上都是在用Token构建一套可持续的运行机制。未来，谁能设计出更高效的Token机制，谁就更有可能形成生态优势。

**第三，产业层面：Token正在成为新型基础设施的一部分。**随着“Token工厂”“Token计费”等模式出现，Token已经不只是应用层概念，而逐渐嵌入算力、数据中心等底层体系。可以预见，Token将像“电力单位”“流量单位”一样，成为数字经济运行的基础计量标准之一。

**第四，治理层面：区分不同类型Token，实施分类监管。**区块链Token具有金融属性，涉及交易与投资，需要重点防范风险；而AI Token本质是计算计量单位，更接近于“技术资源”。如果简单用同一套逻辑进行监管，容易出现错配。未来，更合理的方式是按照“价值Token”和“功能Token”进行分类治理，在防风险与促创新之间取得平衡。
