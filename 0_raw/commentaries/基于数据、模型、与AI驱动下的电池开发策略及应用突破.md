# 基于数据、模型、与AI驱动下的电池开发策略及应用突破

演讲嘉宾： 黄之问 孚能科技美洲区销售与市场总监
主要内容：动力电池研发正由经验驱动转向数据、模型与AI协同驱动。面对高镍、硅碳、电解液和工艺快速迭代，传统长周期寿命验证反馈过慢，亟需以全域仿真和机器学习提升研发效率。孚能已构建覆盖材料、电芯、模组、系统、制造工艺和市场运营的多尺度仿真矩阵，可将产品开发验证周期缩短50%以上、验证成本降低30%以上。其基于最小实验数据的寿命预测方法，仅利用前50 EFCs早期测试数据，即实现开环模型电芯组级MAPE 6.4%、闭环模型MAPE 7.2%，并将1C慢速循环验证周期由1333天缩短至33天、能耗由8.523MWh降至0.468MWh，为电池开发从长周期验证转向早期决策提供了新路径。
