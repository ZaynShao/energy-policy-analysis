# 阿布·哈桑·阿拉，被打死

以军称打死真主党一名高级指挥官。
以色列国防军16日发表声明说，以军15日在黎巴嫩南部发动袭击，打死黎巴嫩真主党“巴德部队”一名高级指挥官阿布·哈桑·阿拉。
声明称，阿拉曾参与策划和推动多起针对部署在黎南部“安全区”的以军士兵的袭击。多年来，阿拉负责指挥真主党多个作战部门，针对以军士兵和以色列平民发动袭击。
声明称，此次行动是对真主党此前袭击“安全区”内以军士兵的回应。阿拉被打死将“严重削弱”该部队的指挥和管理能力。以军将继续采取行动消除相关威胁。
另据声明，以军还打死了真主党“拉德万部队”一名营级指挥官。
黎以美三方6月26日在美国华盛顿完成谈判后，宣布达成框架协议。根据协议设想，以军将从黎南部部分地区撤出，由黎巴嫩军队接管当地安全事务。但自协议达成以来，以军仍多次对黎境内目标发动军事打击。
