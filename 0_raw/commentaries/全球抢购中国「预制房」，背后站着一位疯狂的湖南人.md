# 全球抢购中国「预制房」，背后站着一位疯狂的湖南人

在国外，能从中国网购到最离谱的产品是什么？答案是：房子。
从中国下单一套房，你只要等着快递上门，然后拆箱、展开房子、通水通电，三四天就能搬进去住。
听起来很魔幻，但这种现象在全球150多个国家和地区越来越流行。
更夸张的是远大科技集团的张跃，他要造整栋“预制小区”“预制摩天大楼”。在工厂里造好楼房模块，然后像拼乐高一样组装，他甚至要在国外的著名旅游城市，建起一座高达1037米、共258层的超级大厦，目前已经完成了设计和风洞测试。
张跃背后，是一条正在加速奔跑的中国产业链。从2015年到2025年，中国预制建筑出口额从14.72亿美元增至43.39亿美元。今年一季度，出口更是同比猛增45%。预计到2030年，这一市场规模将增长至1428亿美元。一个万亿级的市场正在形成。
从中国邮寄一套房
YouTube上，一对美国夫妻火了。
他们从中国网购了一套73平方米、精装修的两居预制房，并把安装过程拍成了视频。
房子在河北衡水的工厂里预制完成，独立卫浴、厨房和水电系统全部集成好，然后折叠打包进集装箱，漂洋过海运送到美国。这对夫妻要做的，就是找个平整的地面，把它落地展开、接通水电，就可以直接入住了。
YouTube博主晒出的预制房
重点是房子只需1.58万美元，加上运费和税费，折合人民币约20万元，远低于自建成本。并且因为没有浇筑地基，税务官将其定性为临时建筑，连房产税都免了。
“多么棒的小房子啊，中国人真聪明！”评论区里不少人追着问购买链接。
为什么中国预制房在海外这么受欢迎？
眼下，欧美国家正面临住房短缺。美国住房供应缺口达403万套，西班牙缺70万套，澳大利亚更是计划5年内新建120万套住宅补充供给。
与此同时，发达国家的建筑工人严重不足。仅美国，建筑工人缺口就高达50万，助推人工成本一路飙升。YouTube上那对夫妻算过一笔账：如果自建住房，光人工费就要20万美元，工期还得半年以上。
于是，从中国网购预制房成为部分海外家庭的选择。目前，中国预制房出口占全球市场的12.3%，稳居世界第一。
这些还只是基础的预制房，一个小区、一整栋摩天大楼照样能预制。
在阿联酋的阿布扎比，矗立着一栋升级版预制房。整栋楼由259个模块单元组成，从中国工厂运到施工现场，像搭积木一样吊装组建。仅用96个小时，一栋16层的住宅楼就拔地而起。
远大阿布扎比“活楼”，图源：远大科技集团
没有漫天尘土，没有嘈杂的工地。更让当地人服气的是，这栋住宅完全按照阿联酋的高标准建造，个别科目比欧美建筑标准还严格。
大楼内部配备了特制的中央空调和自研的新风系统，能过滤空气中99.9%的污染。即便在以奢华著称的阿联酋，这栋楼的内装水准也堪称顶尖。
打造这一项目的，是远大科技集团的创始人张跃。
神速的背后，是他已经深耕预制建筑18年，他是国内入行最早、投入最大、扎根最深的企业家。而张跃的故事，远不止于此。
他是中国第一位拥有私人飞机的人，也是第一位拿到飞行驾照的企业家。
出生于湖南郴州的张跃，原本是一名美术老师，却格外痴迷技术创新。1988年，28岁的他与弟弟张剑注册远大热工研究所，发明了无压热水锅炉，靠专利转让赚到第一个100万元。
1992年，他们又研发出国内第一台直燃式非电空调，到1996年，远大年销售额接近20亿，利润破3亿。
那一年，马云还在四处推销他的“中国黄页”，雷军正因为“盘古”项目的失利经历至暗时刻，而张跃已经是商界风云人物，频繁登上各大媒体头条。他一度买下七架私人飞机，中国第二个拥有私人飞机的浙商裘德道，比他足足晚了十年。
在体验过财富之巅的滋味后，张跃渐渐从对名利的追逐中解脱出来，开始关心更高维度的命题：社会需要什么？人类需要什么？
2008年，就在远大非电空调稳居全球领先地位时，张跃突然宣布进军建筑业。而这一切的起点，源于汶川地震后他的一次深度思考。
房产界的另类
2008年，目睹地震现场倒塌的建筑后，张跃意识到钢筋混凝土的局限性，他想发明一种抗震、环保健康、使用寿命还足够长的新材料。
在他看来，互联网等新技术发展的速度已经够快，人类最基本的衣食住行却进化得太慢了。长达数千年的建筑史上，真正称得上革命的只有两次：一次是4000年前埃及人发明玻璃，让阳光照进了房屋；另一次是200年前英国人约瑟夫·阿斯普丁发明了水泥，才有了现代高楼大厦。
第三次建筑革命是什么？张跃想要回答这个问题。他奔赴美国、日本、欧洲等地寻找答案，最终将钢结构建筑作为研究重点。
2009年，远大成立全资子公司“远大可建”，张跃一口气定下六项建筑标准：九度抗震、五倍节能、十倍寿命、百倍净化、100%钢结构、1%建筑垃圾。
这之后的十年，正是中国房地产的黄金时代，无数后起之秀趁势崛起，把张跃的资产排名远远甩在身后，他像个独行者，不去拍地卖房赚快钱，而是一头扎进建筑材料的原始创新里。
2010年的上海世博会上，远大用24小时建起6层高的远大馆，建筑标准做到了九度抗震、六倍节材、五倍节能，第一次让外界看到了他的想法不是空谈。之后，远大更是只用15天就建成岳阳湘阴30层高的T30酒店、19天建成57层的“小天城”，平均每天建3层。
到2015年，远大在六年内迭代了五代钢结构技术，拿下“世界高层建筑学会全球奖创新奖”，但就在这年的10月10日，张跃一夜无眠，沉思到凌晨四点，做了一个让所有人都不理解的决定，他在纸上写道：
“全力开发宇宙飞船外壳那样的蜂窝板，终止钢结构建筑，创造一种终极结构材料。”
当时，远大的钢结构工厂化建筑已经全国领先，放弃成熟的技术体系，转而去赌一个颠覆式的新方向，怎么看都不明智。
张跃的理由很简单，他认为此时的钢结构建筑还是没有达到他当年定下的标准。这条路，他还要往前走。
但这条路注定难走，研发一种前所未有的材料，烧钱也烧时间。
1995年到2015年，整整20年远大没有向银行或第三方借过一分钱，但2016年开始，为了加大研发力度，张跃破例开始贷款，两三年间砸进去30亿，加上此前累计的50亿研发成本，总投入约80亿。
而在时间的投入上，10年时间，在张跃看来是：“我从来没有浪费过时间。”
冯仑讲过一段往事，有次他去见张跃，发现这个人把自己关在园区里搞研发，三年愣是没走出过园区大门，没参加过任何社交应酬。
从2015年起，远大投入了1000多名研发人员，经历了100多次重大失败，测试了上百种耐高温材料。终于在2018年10月，开发出张跃心目中的终极结构材料：不锈钢芯板。
图源：远大科技集团
这种材料由两块不锈钢板夹着薄壁芯管，经1100℃铜钎焊而成，比混凝土轻10倍，寿命是钢铁的20倍，强震之下可能会变形，但绝不会倒塌。
材料有了，但用它能打造什么样的建筑？2020年疫情期间，韩国的一个紧急订单，恰好为远大带来了灵感。
少数派的时代
当时，韩国正面临医疗资源挤兑，客户提出不要简易预制房，要落地就能运转的“医院”。
张跃用极短时间就拿出了方案，以不锈钢芯板为主体材料，在工厂中把病床、卫生间、臭氧消毒设备等集成模块，运到韩国现场安装。从接洽到交付，只用了23天，就打造出专业级别的负压病房，让客户非常满意。
这次紧急任务让张跃有了一个更大胆的想法：用模块化技术，造一栋高层住宅。2021年，他用这种方式在长沙搭建了首个11层住宅项目，将这种建筑命名为“活楼”。
“活楼”一经问世，就引起了菲律宾开发商RGJ的兴趣，双方达成合作后，仅用了9天就在菲律宾建成了一栋12层的精装修公寓。迪拜塔的开发者穆罕默德·阿拉巴尔先生也注意到了“活楼”，邀请远大在阿布扎比打造一栋50米高的住宅楼，单个项目价值高达1.25亿元。
“活楼”内部装饰，图源：远大科技集团
5年来，远大“活楼”在国内市场已售出约10万平方米，海外约3万平方米。
不过，“活楼”面临的考验也不少。标准化模块如何适配个性化需求？各国落地政策的差异怎么应对？都是现实难题。
但张跃本人，始终很乐观。
“全球建筑市场有1300万亿，5%就是65万亿的规模。哪怕只撬动一小块，也足够大。”
财富的增值，早已不是他的追求。远大官网上有句标语：从1988年创业以来，远大从未模仿过同行业技术，总是用独创技术为世界带来改变。
这种执念，或许源于幼年学美术时，长辈的一句话：“临摹是奴才，创作是天才。”
张跃的办公室里，最显眼的是办公桌旁的300个小格子，分门别类堆叠着上万张卡片，密密麻麻几十万字，记录着他对技术和产品的思考。要找什么信息，最多5秒他就能翻找到。
图源：潇湘晨报
比起身为一个企业家，张跃更像是技术狂人，骨子里流露出的，全是对原始创新的极度渴求。
张跃的第三次建筑革命能成功吗？没有人能打包票，但中国企业界需要张跃这样的少数派。
乔布斯、马斯克、张雪，其实都是这样的少数派。他们往往年纪轻轻就手握巨量财富，财富的自由带来了一种自主，驱使他们去追求那些真正具有革命意义的创新。
如今，中国企业里这样的少数派正在崛起。
DeepSeek正面叫板闭源巨头，星际荣耀研发出可回收的液氧甲烷火箭，人造太阳EAST打破世界纪录。
从跟随模仿，到定义标准。中国经济不断进化的力量，到底从何而来？
看看这些企业就知道了。他们不追风口、不赚快钱，偏要一头扎进最难的原始创新里，用十年、二十年去做一件别人看不懂的事。
当越来越多的少数派从边缘走向舞台中央，中国企业的故事，就不再只是规模第一，而是创新第一。
