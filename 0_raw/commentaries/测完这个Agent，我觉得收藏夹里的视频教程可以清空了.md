# 测完这个Agent，我觉得收藏夹里的视频教程可以清空了

有句话叫，在 AI 时代只要你学的慢，你就不用学。
因为就算了学会了，过几天大模型或者工具一更新，AI 比你做的还好，那你不就白学了嘛？
虽然听起来有点离谱，有时候这话还真没毛病。

有一说一，就在不久前，要做这样一个AI视频还是个非常精细的手艺活。
虽然 seedance2.0 极大拉低了创作门槛，今年开始网上的 AI 短剧、视频都很牛逼。（ 以至于每次网友看到这些的时候都会感慨 749 局到底花了多少钱。。。）
但你要真想做出来一个有完整剧情的视频，那么幕后工作量也没少太多。前段时间俺们编辑部办了个 AI 视频大赛，随便去一个同事做的工作流都跟电路板一样复杂。。。
像我这种不懂的，直接劝退了。
这也导致我一度认定，这辈子估计和做 AI 短片无缘了。。。
结果一位LibTV的朋友就告诉我：兄弟，话不要说太早。
他们 LibTV 最近出的这个 Agent 模式，里边有一货架的 Skill，从输入创意到分镜、生图、视频、剪辑、合成，他们都全包了！
我去，你是说我压根不用学习，一句话就能搓出前面这种效果的视频？合着哥们收藏夹里的教程都白收藏了？？？
