# ABS：出口强势开局 产销协同韧性可期

【导语**】**国内供应增加，节前备货需求集中释放以及以价换量等驱动之下，2026年1-2月中国ABS出口强势开局。借助规模化生产和价格优势，国内厂家和贸易商持续开拓出海机会，4月出口市场规模依旧可期。

2026年1-2月中国出口ABS树脂总计7.03万吨，同比增加76.46%，同比增速可观。出口均价1435.35美元/吨，较去年同期下滑16.27%。受国内供应增加，节前备货需求集中释放以及以价换量驱动之下，1月出口规模再创造历史新高至4.19万吨，虽然2月出口规模环比下降31.99%，但同比提升47.71%，2月总量处于近年同期高位。2025年12月和2026年1月中国ABS产量连续两个月创历史新高，双双突破68万吨，在规模化生产持续增长趋势下，国内厂家和贸易商积极开拓出口方向，促进产品利润改善。（1-2月总量包含税则号39033010进口量约1.93万吨；税则号39033090进口量约5.10万吨。）

****出口国继续增多 东南亚仍是主要方向****

1-2月中国ABS出口按贸易伙伴来看，出口伙伴涉及80个国家和地区，较去年同期增加9个，其中东南亚出口方向最多，出口前三位的贸易伙伴均来自东南亚，其中越南位居首位，其次是泰国、印度尼西亚，出口量分别在2.63万吨、0.81万吨、0.38万吨，占比分别在37%、12%和5%。对越南出口量占比超过总量的三分之一，近年来中国部分小家电、玩具、文具等行业在越南布局，其对中国货源需求体量处于首位，同比增幅也超过56%。此外同比增幅可观的地区集中于欧洲、南美等，如意大利、波兰、巴西、墨西哥等。

**一般贸易占比继续提高 贸易商出口量居多**

从出口贸易方式来看，1-2月一般贸易总量达到6.61万吨附近，占比94%，较去年同期增加85.02%。一方面出口市场分布广泛且在总需求占比在6%附近，中国厂家和贸易商暂不考虑垂直销售，出口货源的主力买家仍以出口国贸易商为主，此部分贸易商借助地缘优势，对当地下游用户可提供更加全面和专业的产品售后。此外进料加工贸易占比较去年同期下降约3个百分点至4%，整体来看下游用户对中国货源的黏性仍有待提高。

**浙江、广东、辽宁主要发货地优势明显**

中国ABS出口按照发货地统计维持明显的地域性，按地区占比排名来看，主要分布在华东、华南、东北，中国ABS产能主要集中于华东、东北，但由于港口和贸易商分布优势，实际出口地区集中于华东和华南。1-2月出口量前三名为浙江、广东及辽宁。从增幅来看，浙江地区同比增幅超过104%，浙江地区主要出口品牌集中于LG甬兴、浙石化以及宁波台化ABS，2025年浙石化到达160万吨/年，进入头部企业行列，并且产能占浙江地区产能的51%，规模化产量提升助力其出口份额也有相应增多。

![image](https://mmecoa.qpic.cn/mmecoa_png/9w7iaKkib7mX2siccAz3c1BNLUkzviafaCxPjrdttwljQOjoiacibmTgQsSI5DJPmH03PcF5UU8VmEicHCrscUP1OYjPmjKv63euRCwrIkMXial9TQQ/640?wx_fmt=png&from=appmsg)

**未来三个月出口量或仍有冲高机会**

地缘扰动之下，3月份以来韩国和中国台湾地区部分ABS工厂陆续宣布不可抗力。3-5月受韩国、中国台湾地区产量预计下降、成本高企等影响，中国ABS出口空间依旧可期。虽然中国ABS企业亦有减量计划落地，但外盘价格明显高于内盘，套利差以及中国新的出口退税政策延续退补等助力，中国ABS出海速度有望继续加速。预计未来三个月中国ABS出口量或同环比持续高增长，月度出口量预计在3.9-4.5万吨之间，单月出口量或在4月份创新高。
