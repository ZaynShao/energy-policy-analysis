# 舍弗勒，利润率提升了

加入供应链产业群，请加微信gasgoo12，出示名片
盖世汽车获悉，舍弗勒集团近日公布了2026年上半年财务数据。在整体市场环境持续承压的背景下，舍弗勒上半年实现营收116.67亿欧元，与去年同期的118.45亿欧元基本持平，按固定汇率计算，营收同比增长0.4%。
图片来源：舍弗勒
盈利能力方面，舍弗勒上半年不计特殊项目的息税前利润达5.49亿欧元，高于去年同期的4.82亿欧元，对应息税前利润率为4.7%，亦优于去年同期的4.1%。
从区域市场表现来看，以固定汇率口径统计，各区域表现分化。美洲区和亚太区营收分别同比增长0.9%和7.1%，而欧洲区和中国区营收则分别同比下降0.5%和3.7%。
分事业群看，舍弗勒电驱动事业群表现突出，上半年实现营收25.78亿欧元，按固定汇率同比增长7.7%，增长主要得益于亚太区和欧洲区的产能爬坡。动力系统与底盘事业群营收为42.47亿欧元，按固定汇率同比下降3.4%，原因包括产品组合的战略性优化，以及中国区、欧洲区等市场内燃机技术相关需求的走弱。
车辆全周期服务事业群营收为16.01亿欧元，按固定汇率计算与去年同期基本持平，价格因素的积极影响抵消了销量因素。工业事业群营收为31.81亿欧元，按固定汇率同比增长1.0%，这主要得益于航空航天及工业轴承业务的良好表现。
基于上半年的业绩表现，舍弗勒维持了此前公布的2026年全年预期不变，即全年营收目标在225亿至245亿欧元之间，不计特殊项目的息税前利润率为3.5%-5.5%，不含并购活动现金流入和流出的自由现金流预计在1亿至3亿欧元之间。
舍弗勒集团首席执行官克劳斯·罗森菲尔德表示，尽管全球市场环境充满挑战，但集团凭借多元化的业务布局，包括四大事业群及人形机器人等新增长领域，实现了稳健的盈利表现，并能灵活应对市场变化。
