# 泽连斯基：乌方已启动远程打击行动，对俄罗斯境内多处石油设施实施打击

泽连斯基称乌军对俄境内多处石油设施发动打击。
当地时间7月9日，乌克兰总统泽连斯基在社交媒体称，乌方已启动远程打击行动，对俄罗斯境内多处石油设施实施打击。
泽连斯基表示，本次打击目标分布俄罗斯多个地区，打击纵深跨度极大。乌克兰国家安全局作战人员摧毁了斯塔夫罗波尔、特维尔两座油库；乌国防力量打击了一处距前线约800公里的燃料储备设施。此外，乌军袭击了俄罗斯乌法市一输油泵站，并对罗斯托夫地区一石油装载码头实施打击。
目前，俄罗斯方面对此暂无回应。
