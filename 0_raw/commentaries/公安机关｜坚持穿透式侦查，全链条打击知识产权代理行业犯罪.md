# 公安机关｜坚持穿透式侦查，全链条打击知识产权代理行业犯罪

一、公安强调打击知识产权代理行业犯罪
去年公安部要求“监管执法衔接和行刑衔接”，行业规范整治与产业发展同步推进。
2026年7月9日，重庆市作为地方实践，联合14个部门出台《加快推进知识产权服务业高质量发展的若干措施》，市公安局刑侦总队负责人明确表示，公安部门将联动多部门打通线索移送通道，坚持穿透式侦查，全链条打击知识产权代理行业犯罪。
如今不少代理机构打着“包过高新认定、包拿补贴”的幌子，协同空壳企业伪造专利、研发材料骗取财政奖补，犯罪链条呈现团伙化、跨区域、产业化特点。
以代理机构协同造假为例，其作案手法有：一是承诺“包过认定”“包拿奖补”，收取高额服务费；二是协助企业伪造全套申报材料，批量操作空壳企业申报；三是操控企业资金流转，截留奖补资金分成；四是跨区域团伙作案，多地注册空壳企业骗取补贴。
针对此类犯罪，公安机关以“查清资金闭环、穿透傀儡主体、摧毁犯罪网络”为目标，坚持“穿透式侦查、全链条打击”，以诈骗罪为主攻罪名，同步打击上游注册空壳公司、中间造假申报、下游洗钱套现的全链条犯罪。
规范整治只是打击知识产权代理行业犯罪的一部分任务，以政策引导赋能知识产权服务业高质量发展才是主题。
重庆市做法，由市知识产权局、市发展改革委等15个部门联合出台，具体围绕三大发力点，提出18条举措。
一是聚焦重点领域，打造高水平服务支撑能力
推动知识产权服务业赋能科技创新、产业发展、乡村振兴、对外开放，并与生产性服务业融合发展。如鼓励服务机构参与组建产业知识产权创新联合体，拓展海外服务网络，提升国际化服务水平。
二是聚焦全链条服务，构建高质量服务供给体系
围绕知识产权创造、转化、法律、数据信息及公共服务五个维度，优化服务供给质量，拓展服务领域，让企业从申请、运用到保护全程得到有力专业支撑。如推广《专利商标代理服务政府采购需求标准》，推动代理服务“优质优价”；建设国家级产业知识产权运营中心；支持服务机构深度开发利用知识产权基础数据，构建数据仓与服务底座。
三是聚焦监管与激励，营造高能级行业发展环境
强化政府监管、行业自律、机构自治、社会监督协同发力，推动行业协会规范化建设。
分级分类培育高水平服务机构，支持区县园区建设知识产权服务业集聚区；加大金融与政策支持，鼓励区县设立知识产权服务高质量发展专项资金。
三、结束语
重庆的实践表明，国家政策效力取决于地方执行力度，亦折射出知识产权代理行业治理的深层逻辑。
当下的知识产权代理行业，合规是红线，造假即犯罪，任何侥幸终将付出沉重代价，别说下一世还做代理人的胡话。
闻一多先生提出“戴着镣铐跳舞”，大抵也适合我们的现状。
科技与政策服务，并非在规则束缚中被动起舞；而是以约束为基石，倒逼专业能力的精进与服务模式的创新，方能在行业重塑中行稳致远。
