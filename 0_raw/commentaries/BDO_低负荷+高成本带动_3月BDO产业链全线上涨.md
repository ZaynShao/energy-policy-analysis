# BDO | 低负荷+高成本带动 3月BDO产业链全线上涨

**导语**

受产能利用率低位及中东局势紧张推高原材料价格等影响，BDO产业链相关产品在3月均出现了不同程度的上涨。短期成本面及供应端支撑仍存，产业链存继续上探预期，但需关注成本向终端传导情况。长期来看，随着行业产能利用率提高，供应端支撑减弱。及国际形势缓解，原材料价格回落，下游入市观望情绪增加，BDO产业链或存回落风险。  

**多重利好支撑，BDO产业链产品共振上行**

进入3月后，受中东局势紧张等影响，大宗产品价格震荡上行，其中和BDO相关的是上游原料甲醇及顺酐。受供应偏紧及成本面带动等影响，甲醇、顺酐价格较2月底涨幅分别达到32.49%和56.45%。而高成本向下传导，叠加3月检修装置较多，供应量缩减；及竞拍价格不断推高，推动BDO市场价格持续上涨，其中华东散水涨幅达10.81%。终端下游产品亦在成本面带动、供需端利好等支撑下，均出现不同程度的上涨，具体表现如下表所示。

**BDO产业链各产品维持低位运行**

受原料价格高位及计划内检修等影响，3月上中旬BDO产业链各产品负荷维持偏低位运行，其中表现最为明显的是BDO及主力下游PTMEG、PBT，均较2月底出现不同程度下滑，短期亦无明显提负预期，因此供应端利好支撑延续。

**原材料价格高位，BDO产业链利润依然亏损居多**

虽BDO及下游产品行情均出现不同程度的上涨，但依然处于亏损状态甚至部分产品亏损空间拉大。其中上游电石、甲醇等涨幅均高于BDO，导致BDO亏损空间较2月底扩大。而PBT、PBAT则是因为上游原料PTA、己二酸等产品大幅走高，亏损压力加剧。TPU、PU浆料及氨纶是因为己二酸、纯MDI及DMF等宽幅上涨抑制利润增加。NMP因另一主要原料一甲胺大涨，导致成本压力增加。整体来看，原材料涨幅高于下游，成本传导不畅，导致下游接货情况暂一般，刚需合约订单跟进为主，现货采购积极性不高且对高价抵触。后续成本重压下或限制终端下游开工热情，进而影响对原料BDO需求量。

短期来看，4月BDO供应量依然偏少，供应端利好仍存，支撑供方挺市心态。但终端下游需求短期无增量预期，且成本传导存阻，对高价原料议价情绪浓郁，将压制原料涨幅。隆众资讯预计，4月BDO市场偏强震荡；但5-6月来看，随着检修装置重启，供应量增加，行业供需差距再度扩大，业者采销心态谨慎，市场盘面或存回落风险，继续关注供需端变化及成本传导影响。
