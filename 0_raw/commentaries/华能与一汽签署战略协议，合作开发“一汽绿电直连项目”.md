# 华能与一汽签署战略协议，合作开发“一汽绿电直连项目”

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)

内容来源：华能吉林发电有限公司  
储能与电力市场获悉，3月11日，一汽绿电直连项目签约仪式在一汽能源公司举行。华能吉林公司董事长、党委书记唐剑平出席签约仪式，并与一汽能源公司董事长、党委书记孙飞进行会谈。华能吉林公司副总经理王晗临、一汽能源公司总经理赵杰参加并代表双方签署协议。  
  
据悉，此项目是吉林省内首个“央央合作”绿电直连项目，开发建设风电20万千瓦。  
![image](https://mmbiz.qpic.cn/mmbiz_png/nJIHJiauQqnx2nlkqDHT25vTPvzHa71DKYwKic7qc28qKFdOficYib1ziajrlsPYibsF7YxMzwSlWBoXEfut2O9esgiaAuNebf0UKZcYSFZm3oE5g8/640?wx_fmt=png&from=appmsg)  

看个广告休息一下![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ibQ6Q066YicvUrISt2HTHibzQLHagVXTI0icHuu8j9l7VicIMYkGQ4a0sZubzCiaYLVbnQtvbYmZqkYcicIBJRaHbpdXQ/640?wx_fmt=jpeg&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=1)

  

唐剑平表示，“一汽绿电直连项目”是省内首个“央央联合”开发建设的绿电直连项目，华能吉林公司将发挥能源央企优势，高标准推进项目建设与运营保障，以可靠绿电供给、高效能源服务，为一汽新能源汽车产业高质量发展提供有力支撑。  
孙飞对华能吉林公司在省内电力、能源领域做出的贡献予以赞扬，对华能人不断开拓进取的敬业精神表示称赞。他表示，下一步双方将共同推进项目指标获取、建设进程，助力一汽打造绿色供应链，更愿以此为契机，共同开发探索其它绿色能源产业。
