# 高企骗补案｜张某批量注册41家公司获补贴1171万

高企骗补已成为财政专项资金领域最为普遍的违法犯罪类型之一，尤其是广东凡x海706专案、上海x邦706案件都是务机构主导、企业被动参与。
与此同时，也有企业自行实施的高企骗补案件。部分企业主发现高企认定奖补的灰色漏洞后，通过批量注册空壳公司、伪造全套申报材料等方式，直接套取补贴资金。
一、高企奖补的漏洞
湖北省武汉市江汉区人民法院（2026）鄂0103刑初232号刑事判决书披露：
2019年至2024年期间，被告人张某利用其名下或由其实际控制的某甲公司、某乙公司等41家企业，通过合同造假、科研人员造假等编造虚假申报资料将上述企业包装成科技创新企业的方式，从武汉市科技创新局及其下属区科创局骗领高新技术企业补贴资金共计人民币1171万元。
2019-2022年，为鼓励企业科技创新，武汉市及各区对首次认定和重新认定的高新技术企业均给予财政奖励，市区两级政策叠加，甚至达到30万元/家。
2022-2024年武汉一直在严查高企虚假认定，不少服务机构被牵连，但都积极退款并未被审计单位移送公安机关。
本次审判案件并未牵涉服务机构，而是2024年8月至11月，武汉市审计局对科技局主要领导的审计中发现的线索。
2024年底审计局约谈张某涉嫌诈骗政府专项补助资金，同时向公安机关移送案件线索；2024年12月至2025年2月，张某退回赃款350万元；2025年5月27日公安局将张某刑事拘留，2025年7月3日正式逮捕。
二、案件定性的新提法
广东案件服务机构全包造假，上海案件知识产权造假为主，而本次案件的爆发核心点在于企业财务问题，公诉方认为：
张某通过虚构企业研发费用、高新技术产品、科研人员等方式将上述企业包装成科技创新企业，通过了高新技术企业认定，其中2019年4家、2020年5家、2021年26家、2022年6家。
以此骗领高新技术企业培育补贴资金共计1171万元，其中市级资金595万元、区级资金576万元。
1.退款依然计入诈骗数额
审计约谈后张某退回350万元，但法院认为其通过多个虚假科创企业分批申领财政补贴，全部被骗取的专项资金均系其诈骗行为所造成的国有财产损失；
同时，法院认为张某通过40余家公司专业化流水线造假，长期职业化作案，拿到补贴后长期控制、转移、私分使用，犯罪既遂状态持续多年。
可见，即便退款也不扣减犯罪总额。
2.审核疏忽与中介背书的责任分配
被告认为
“科技局审核疏忽与中介恶意背书的行为应当分担其的主观恶性与责任。”
张某认为是科技部门履职不力或业绩压力而“选择性失明”；同时，财务数据也是中介恶意兜底造成了犯罪，这里的中介应该是审计报告提供机构。
法院并未在判决书中提到如何划分责任，可见并未采纳。
反而在文书中多次提到“被害单位武汉市科技创新局”，被害单位追缴款项，何来承担履职不力呢？
这为产业主管部门追缴专项资金提供了实践，参考《退回财政资助资金｜企业不执行，主管部门如何追缴？》。
3.关于案件的社会危害性
这是一个重要的判决因素，法院认为被告人张某骗取科创专项资金的行为，社会危害性突出，这是第一次把一个高企骗补提升到如此高度：
造成巨额国有财政资金流失，挤占合规企业创新扶持资源；
严重扰乱科创领域公平竞争秩序，阻碍创新政策落地；
损耗行政资源开展核查、赃款追缴工作，损害政府某信力；
作案模式存在不良示范风险，滋生同类骗取财政资金犯罪。
4.不认定为偶犯
偶犯是量刑的重要依据，但法院认为被告人张某可认定为初犯，其并非偶犯。
张某为套取科创专项资金，经周某策划，长期系统性伪造申报资料，分批次持续实施诈骗，犯罪行为具有预谋性、持续性，并非临时起意的偶发犯罪。
三、结束语
类似前不久杭州判定代理合同无效，警示了治理逻辑的深度重构。
畏则不敢肆而德以成，无畏则从其所欲而及于祸；从赶超体制转向高质量发展，是时候审视曾经的赚钱方式了。
——本回完——
