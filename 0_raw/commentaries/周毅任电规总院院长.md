# 周毅任电规总院院长

中国能建电力规划设计总院领导班子调整。
8月20日，中国能建电力规划设计总院召开会议，宣布中国能建党委关于电规总院班子调整的决定。
会上，中国能建党委组织部有关负责同志宣读了干部任职决定：周毅同志任电力规划设计总院党委副书记、院长，电力规划总院有限公司党委副书记、董事；饶建业同志任电力规划设计总院党委常委、副院长，电力规划总院有限公司党委常委、副总经理。
