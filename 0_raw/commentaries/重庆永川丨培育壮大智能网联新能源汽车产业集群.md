# 重庆永川丨培育壮大智能网联新能源汽车产业集群

《纲要》明确：培育壮大智能网联新能源汽车产业集群，整体推进“车路云网图”一体化建设，构建西部领先的“整车+零部件+后市场”产业链生态，建设智能网联新能源汽车之都重要承载区。
支持整车企业打造具有全国竞争力的旗舰车型和主力产品矩阵，提升汽车产业链主导力和控制力。推动传统整车企业加快新能源化、智能化产线升级改造，推动皮卡、SUV等主力车型规模化搭载智能座舱、高级辅助驾驶系统，构建中高端纯电、增程、混动全谱系产品矩阵。加快招引市场竞争力强、技术迭代快、具有高附加值的无人车、专用车、特种车整车制造企业。系统构建涵盖垂直起降场、智能路网及指挥管控中心的全要素测试环境，支持全球整机企业来永开展研发测试，积极融入飞行汽车整机供应链。提速发展智联电动车产业，不断提升智联电动车续航里程、辅助驾驶能力和感知交互水平。
聚焦长续航、高安全、智能化发展方向，引导传统汽车零部件企业开展适应性技术改造与产品迭代升级，推动关键零部件与整车同步研发、同步设计、同步测试验证，培育壮大智能座舱、智能车控、智能驾驶及“三电”等关键环节，实现产业链上下游深度协同、集群化发展。鼓励整车企业与零配件供应商、改装企业、行业协会等多元主体联动发力，搭建新能源与智能汽摩维修技术服务平台，培育发展汽车拆解回收利用、动力电池循环利用等绿色低碳产业，积极布局汽车改装、房车露营等后市场新业态，延伸拓展产业价值链条。加快培育汽车再制造产业生态，引导汽车改装产业、二手车市场交易等有序发展。支持组建氢燃料电池汽车租赁运营平台，推动氢能车辆规模化投放。
大力发展自动驾驶技术，拓展“车路云一体化”应用场景，建设全国领先的自动驾驶商业化运营城市。建成投用中国西部自动驾驶示范应用中心，推进测试道路全域提质，全面提升云控平台运营管理效能。开展智慧公交、智慧乘用车、城市物流等多场景应用试点，打造冷链物流、重卡、城市环卫等氢能应用标杆场景，形成“虚拟仿真+封闭试验+开放测试”的全链条试验检测能力，全力打造西部领先的智慧出行应用新生态。建设智能无人驾驶重卡运营平台，围绕凤凰湖园区至朱沱港段货物运输需求，开展L4级自动驾驶重卡编队测试、运营。鼓励龙头企业参与组建“人工智能+汽车”生态联盟。进一步加密超充站、换电站布局，提高充换电基础设施服务水平。
建成汽摩零部件产业园二期等特色产业园。开工建设新能源自动驾驶宽体矿车科技产业园。引导本地精密结构件、汽车电子等优势企业融入飞行汽车整机供应链，助推整机项目落地。组建重庆市永川区新能源重卡动力电池应用联盟，推动新能源重卡充换电电池、电机、电控等相关配套项目落地。招引低速物流车、安防巡逻车、市政环卫车等生产企业。
探索智能无人驾驶多场景、多元化应用，落实无人驾驶在公共交通、物流运输、城市治理等领域的场景建设、测试应用与产业培育，推动无人驾驶的规范化、规模化、商业化运营。
