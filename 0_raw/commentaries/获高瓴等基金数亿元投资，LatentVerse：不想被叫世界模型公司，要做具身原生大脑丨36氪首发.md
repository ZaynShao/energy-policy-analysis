# 获高瓴等基金数亿元投资，LatentVerse：不想被叫世界模型公司，要做具身原生大脑丨36氪首发

具身智能赛道可能已经不需要再多一家世界模型公司了——但一位2001年出生的研究员，还是选择了在这个大热时分下场创业。
“市面上做世界模型的公司太多了，很多公司没有自己的特点。”LatentVerse创始人胡钰承说。不过，他不想被归入其中任何一家，LatentVerse要做的也不是世界模型。
这位2001年出生的研究员，如今是清华大学交叉学院在读博士生。今年4月，他从字节跳动Seed离职，和来自清华大学、南洋理工、北京大学、Qwen、字节、小米等机构的成员，共同创立了“潜界科技”（LatentVerse），定位是做原生具身基座模型。
LatentVerse CEO胡钰承
“智能涌现”独家获悉，具身智能公司LatentVerse已完成数亿元人民币种子轮融资，第一轮投资方包括高瓴创投、清流资本、智元、星动纪元及英诺天使等基金。
过去两年，VLA（视觉-语言-行动）是具身智能最主流的技术路线。从RT-2到大热的Pi-0.5，行业的默认演进路线是——只要把视觉语言模型接上动作输出，再喂足够多的机器人操作数据，模型就能学会在物理世界中行动。
但VLA有一个根本性的限制：它只能利用带动作标注的数据。这些数据靠摇操机械臂采集，一小时成本平均要千元以上，还需要专门的摇操员，效率较低。
另一条路线是纯世界模型——通过视频生成预测未来状态，再映射为动作，数据获取成本更低，互联网上的视频都能够被纳入到训练中。但它无法利用通用视觉语言数据，缺少VLM带来的语义理解和涌现能力。一个只会预测画面变化的模型，也无法理解“把杯子递给客人”的指令意味着什么。
LatentVerse选择的是第三条路线：不做VLA也不做如今大热的WAM，而是把VLM和世界模型统一在同一个架构里。
实际上，胡钰承是最早一批证明“世界模型能直接指导机器人动作”的研究者。2024年初，他提出多模态扩散VLA（PAD），同年11月提出首个实现闭环推理的视频动作模型VPP，后者被业界称为WAM（World Action Model）的开山之作，后来，NVIDIA在此基础上开发了DreamZero。
而在加入字节Seed后，他主导了BagelVLA系列具身基座模型的研发，相关工作的发表时间，甚至早于Physical Intelligence的代表性工作Pi07。
在工业界的经历，让胡钰承看到一个重要技术拐点的到来：要达到物理AGI终局，关键在于解决数据瓶颈——纯VLA或纯世界模型路线都走不到终点，需要一个将理解、预测与动作统一在同一架构中的基座模型。
而随着数据采集成本的降低，进入2026年，数据成为具身智能最重要的问题，这也逐渐成为具身智能领域的共识。
押注统一触觉动作模型
LatentVerse正在训练的第一款模型UTAM（Unified Tactile Action Model，统一触觉动作模型），由团队此前提出的UAM（统一动作模型）演进而来，同时输出视觉、语言和触觉反馈信号。
更具体地说，这个模型内部包含四个专家模块，形成一条完整的执行链：视觉语言专家负责理解任务意图；世界模型专家将过去从视频中学到的技能组合起来，规划出新的任务流程；动作专家从前两者的推理链中生成一个粗粒度的动作表征（Latent action），相当于“伸手去拿杯子”这样的大动作指令；最后由高频推理的触觉专家将这个粗动作解码为精细的末端控制信号——比如手指触碰杯壁后实时调整力度和姿态。前半段是开环执行，后半段是触觉闭环修正，类似人类“先伸手、再凭手感微调”的操作逻辑。
模型路线的选择，来自团队押注的场景反推。“泛化、长程与灵巧不是三个彼此独立的技术指标，而是机器人商业化必须同时满足的能力条件。”胡钰承说，“我们认为具身基座模型应该拥有更强的泛化通用能力，比如家庭场景。”
LatentVerse押注的技术路线，会涉及更多的数据采集维度，以及更长程的任务。比如，机器人要在酒店清理房间、狭小的空间打包饮品、在家庭中抓取柔软物体等等。
在LatentVerse的框架里，机器人进入真实场景需要同时具备两种能力：认知智能和接触智能。认知智能负责理解指令、规划步骤——这是VLA和世界模型已经在做的事。
但光有认知不够，最后一厘米的接触信息决定了机器人能否真正完成操作。比如，水杯外表是否光滑、柔性物体抓取时是否产生了形变等等，这些信息纯靠视觉无法获取，必须通过触觉反馈实时修正。
这些任务需要的不只是预测下一帧会发生什么，而是同时具备理解指令、规划步骤、预测物理变化、感知接触并生成精确动作的能力。
在前两年，具身智能赛道能够做到的是一些固定场景——比如工业等的一些精准操作，但在VLA等路线上要做到能力泛化，依然很难。
统一具身模型路线的优势在于，能利用的数据范围远大于纯VLA。只要跟操作有关的视频、跨本体的机器数据、通用VLA数据，全部能纳入训练框架，当数据规模上来之后，模型对场景和物体的泛化能力会显著提升。
但难点也是明显的：可使用的高质量数据不足。即使在过去，具身智能赛道的发展，也迅速扩大了数据采集的规模，但这些数据大多是为特定任务采集，很难复用在通用任务能力的训练中。
胡钰承表示，要想在同一模型路线上实现能力跨越，“一是数据规模要上来，二是模型要能利用海量数据——不只是自己采集的，还包括互联网规模的视频数据、跨本体的异构数据，数据处理维度也更复杂，需要描述整段任务怎么做拆解，用在不同的训练阶段中。”
正因为如此，在成立的数月中，LatentVerse已经搭建了一套覆盖数据采集、数据处理到模型训练的完整链路，这首先包含自研的数据采集管线，以及LatentVerse正在训练的具身原生世界模型。
从部署端看，原生的具身模型也有结构性优势。
当前，具身智能普遍面临“Demo好看但难以规模化部署”的问题，核心原因是模型鲁棒性不足——真实场景中光照改变、人为干扰、场景布置不一致，都会导致失败率远高于Demo。“VLM专家则可以产生人类意图、理解物理信息并做出下一步判断，世界模型专家能吃海量数据提升对场景、物体、任务的鲁棒性，并将离散的文本转化成语义丰富的视觉信号。”胡钰承说。
技术比VLA更难，
场景比工厂更广
原生具身模型路线能跑通的前提，是数据。
选择这个训练路线，代价是训练难度陡增：数据处理上需要把长程任务拆解成若干步骤并逐步标注，比处理图片或文本复杂得多；训练需要多阶段、多任务同时进行；WAM路线依赖扩散模型，就拿推理延时来说，就是一个尚未完全解决的工程问题。
“我们的团队做过纯VLA路线，也做过纯世界模型，所以知道各自的局限在哪。”创始人胡钰承说。另一个例子是，LatentVerse的另一位联创则是负责灵巧手算法与运动控制，能够补上控制侧的短板——从本体到人手数据链路打通后，LatentVerse希望能够建立起具身场景的数据飞轮。
为此，LatentVerse也组建起了一支年轻精炼的团队，算法团队覆盖具身智能核心算法模块、灵巧手、仿真、三维视觉等机器人相关的细分领域。
目前，LatentVerse的数据策略分为三层：摇操数据（VR采集、带精确动作标注）只训练动作专家；人手采集数据（如Ego-centric）和开源视频数据训练理解与世界模型专家。
在数据采集端，LatentVerse押注无本体数采路线，团队也正在自研一款数采手套，并且已经和一些数采基地建立了初步合作。“现有的数采手套还不足够满足我们的要求。”胡钰承表示。以后，通过可穿戴设备让非专业人士参与数据采集，甚至融入日常生活，LatentVerse的数采方案将单小时采集成本从千元级别降到百元以内。
不过，决定模型能力的，更多是数据质量，以及如何使用数据。
LatentVerse团队的另一个稀缺性在于：团队核心从2024年初，就开始做统一模型路线，而大多工作都是开创性的而非跟随路线，并成为行业重要的技术根基。
比如，LatentVerse的联创张荐科，是具身智能领域多项开创性工作的主导者——从HiRT（具身智能快慢系统，被Figure的Helix沿用）到UP-VLA（首个生成理解一体化具身模型），再到VLM4VLA，系统性证明了VLM作为具身基座的固有局限。
“具身模型的能力涌现不能简单照搬LLM的发展路径。在推动数据规模化的同时，也应充分利用各类异构数据中的结构化信息，构建统一表征。”胡钰承说。
按LatentVerse的规划，一个季度后，公司将发布第一个参数量为16B的具身基座模型，一年到一年半内，就将积累数十万小时训练数据。
在场景选择上，LatentVerse会希望将触觉等更复杂维度的信号纳入模型，把通用性、泛化能力做出来后，覆盖更广泛的工业、商业、家用等场景。
这源于LatentVerse团队对世界模型的不同理解。在他的定义里，任何预测next token的模型都可以算世界模型，各家真正的路线区别在于怎么定义状态空间，“我们认为，我们是具身原生的世界模型，是for robotics的世界模型。”
这个定义背后，实际是一个场景的判断。具身智能之所以只能在垂类场景用得上，主要原因是大脑能力不够。只有把通用性和泛化能力做到位，才能进入家庭这样的非结构化场景。
“具身智能要跨越的，是认知与接触之间的最后一厘米。”在胡钰承看来，机器人不能只学会看懂世界，还要学会触摸世界。而首先，要先让机器人先学会在真实世界里提供实用价值。
