# AIDC算电协同会议观察：千亿级液冷“风暴”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIvkAen9S6XF07oChz9czicgoxuFy48ObpkYF6lP8W7UtX3eX0rjovr5qDaEmMpATXU3aLFpP4FX0T7uQgQ5gBD1fftqW9rS3wpg/640?wx_fmt=png&from=appmsg)

在数据中心赛道，风冷已在AI时代“失效”，液冷正在成为资本新一轮的宠儿。

AI等新的应用场景出现，对算力设备和承载算力的数据中心均提出更高的要求，让数**据中心的架构从原来的IDC和服务器机房****加速****演进成AIDC智算中心**。

相比传统数据中心（IDC），人工智能数据中心（AIDC）惊人的功耗密度，已经远远超过了传统空气散热的物理极限。

传统数据中心单机柜功率通常在5kW至10kW之间，但AI场景下高密度算力集群的单机柜功率已飙升至60kW至100kW，部分高端智算场景甚至突破130kW，国内外厂商近期更是发布了单机柜功率超过900kW的兆瓦级解决方案。

因此，此前行业延续十几年的主流方案——空调风冷方案已经无法再满足需求，新建的大型数据中心项目中，已经普遍采用液冷方案。

数据中心液冷，指的是在数据中心用液体带走IT设备（服务器、芯片、存储）产生的热量的一整套冷却技术和系统。

在算力设备以及数据中心机房的高热密度趋势和高能效散热要求的双重推动下，液冷技术正加速导入，并推动整个产业链加速升级与重构，成为满足高效温控与绿色低碳发展的必然选择。

**液冷三大主流技术路径**

当前，数据中心液冷技术主要包括冷板式液冷、浸没式液冷和喷淋式液冷三大路径，主要区别体现在对服务器的散热方式不同。

具体而言，**冷板式液冷**是一种间接接触型冷却方式，是将需要散热的元件固定在冷板上，液体通过冷板将热量带走实现散热；

**浸没式液冷**是一种直接接触型液流，是指将发热元器件完全浸没在冷却液中，吸收元件的热量。

**喷淋式液冷**是一种直接接触型冷却方式，通过向需要散热元器件喷淋冷却液带走热量；

总体来看，冷板式液冷因其成熟度和兼容性，仍是当前主流；浸没式液冷则凭借更优能效在高算力场景中具备潜力；而喷淋式液冷尚处于验证阶段。

**千****亿****级****液冷市场**

液冷板块已成为AIDC概念下涨势最“凶猛”的一个类型。

日前，谷歌宣布新一代TPU V7单芯片功耗高达980W，已突破传统风冷物理极限，因此谷歌强制要求其100%采用液冷散热方案。据悉，谷歌已与中国液冷设备厂商英维克等企业洽谈采购数据中心冷却系统，以应对AI算力快速增长带来的散热需求。

除了谷歌，英伟达、微软、英特尔、AMD以及华为、寒武纪等，也已经或正在将液冷作为其AI芯片的关键散热方案。预计到2026年，液冷在AI芯片领域的渗透率将接近50%。

相关数据显示，AIDC单GW造价近513亿美金，其中IT设备占比84%，工程建设占比8%，供配电占比5%，冷却设施占比3%，25-28年全球AI数据中心预计将新增50GW需求，约40万个GB200机柜。

据英维克介绍，目前单GW液冷价值约18.61亿美金，约占整个算力中心3.6%份额，预计25-28年液冷市场规模将达到744.2亿美金，约5200亿人民币规模，年增速约30%。

目前，在智算中心散热这片蓝海市场，已涌现出三家具备全产业链能力的领军企业，分别是英维克、申菱环境与高澜股份。

作为营收规模领跑者，英维克是业内少数实现液冷全链条自主研发的企业，其产品覆盖CDU分配单元、冷板、快速接头等核心部件，形成精密热管理系统，进入英伟达、英特尔等科技巨头供应链。

高澜股份是特高压纯水冷却设备龙头，近年来正积极打造数据中心液冷作为第二增长曲线，将特高压领域积累的高可靠设计技术迁移至数据中心赛道，重点布局浸没式液冷等高毛利领域。

申菱环境将CDU液冷分配单元作为核心突破口，CDU产品在中国市场占有率领先，自研的CDU300系统机房PUE能耗指标≤1.15，数据服务业务收入2025年上半年同比增速达43.77%。

此外，国内还有一批在液冷领域各具特色的企业，包括浸没式液冷领军者曙光数创、液冷服务器整机龙头浪潮信息、风液同源先行者依米康、机房环境与液冷系统方案商佳力图，冷却液核心厂商巨化股份、新宙邦等，以及圣阳股份、康盛股份等液冷产业链企业。
