# 重实战·真干货丨第五期零碳园区建设重点培训班来了

首批共有52家园区入围国家级零碳园区建设名单，按照“十五五”规划部署，全国将建成100个左右国家级零碳园区，零碳园区建设正从地方零星试点迈入全国统筹布局新阶段，规模化建设进程全面提速！
当前零碳园区申报持续升温，但行业普遍面临落地难题——政策标准研判不准、顶层规划体系缺失、碳核算边界模糊、源网荷储与电碳协同落地困难、长效盈利路径不明等。
深度拆解零碳园区建设背后的政策逻辑、实施路径与商业价值，系统破解政策标准研判、规划方案编制、项目工程建设、技术路径选型、碳资产精细化管控、示范申报创建、长效运营管理全链条痛点，中国能源报、中国能源经济研究院零碳园区专委会、中国开发区协会碳中和专业委员会、上海质量管理科学研究院将于9月10—11日在上海联合举办“第五期零碳园区建设重点培训班（上海站）”。
本次培训依托长三角先行产业实践优势，坚持实操导向、成果导向，邀请政策权威专家、一线项目操盘负责人、标杆园区运营团队现场深度授课，搭建集政策解读、顶层规划、技术路径设计、数智化运维、碳资产管理、典型案例复盘、产业资源对接于一体的实操学习平台，助力推动零碳园区从规划蓝图转化为落地实景。
