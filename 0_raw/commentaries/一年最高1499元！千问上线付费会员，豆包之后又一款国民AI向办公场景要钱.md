# 一年最高1499元！千问上线付费会员，豆包之后又一款国民AI向办公场景要钱

分析师/贾玥
就在昨晚，千问App办公助理功能正式推出付费会员体系。三档套餐价格同步曝光：高级会员连续包月19元，精英会员49元，旗舰会员128元。年付价格分别在200元至1499元之间。视频生成额度单独开售，26元购买10个额度，968元购买500个额度。
这距离6月24日豆包推出68元至500元三档专业版会员，才过去不到两个月。今年春节期间，千问还投入了30亿元红包拉新，豆包之前也长期以免费使用为主。两家头部AI应用先后推出付费服务，标志着国产AI助手正在集体从"免费圈地"转向"分级收费"。
目前，这两款产品的基础问答功能仍然免费开放，但PPT生成、数据分析、视频制作等办公场景被划入了付费区。两巨头在收费策略上思路各异，背后的动因也有迹可循。
两款产品都采用了"基础功能免费、高级功能付费"的框架，但在产品形态、定价策略和用户筛选方式上，差异相当明显。
首先，定价起点差距悬殊。豆包标准版68元/月，直接瞄准愿意为效率付费的重度用户。千问高级会员19元/月，是目前国内大厂AI应用中最低的付费门槛。千问选择低价策略并非出于慈善——作为月活第二的跟随者，它需要通过更低的尝试成本把用户拉进付费漏斗，再逐步引导升级。豆包月活已超过3.45亿，不需要拉新，只需要在存量用户中进行分层运营。
其次，收费的拆解方式不同。豆包走的是"会员全家桶"路线，购买一档会员，办公任务、视频生成、深度分析、批量处理全部打包解锁。标准版提供5倍额度，加强版20倍，专业版50倍。千问则采取了更灵活的方式：办公助理会员和视频生成额度分开售卖。只做PPT的用户可以只买19元档，重度视频生成用户单独购买额度包即可，不必为用不上的功能付费。
再者，价格上限反映了战略定位的差异。豆包专业版年费5088元，面向企业级商用场景。千问旗舰年费1499元，目前仍锚定个人和轻办公场景。豆包试图打造覆盖C端到B端的"AI能力层"，千问更像在搭建一个"办公场景入口"，先把用户圈进付费习惯里。
最后，用户策略截然相反。豆包手握数亿月活，当前任务是筛选付费用户、减轻算力成本压力。千问用户基数明显小于豆包，所以用低价降低门槛、先圈人再谈升级。一个像漏斗的窄口，一个像漏斗的宽口，背后是两套不同的商业化思路。
总而言之，如果说豆包用68元筛选重度用户，那么千问就是用19元降低尝试门槛。一个面向存量做分层，一个面向增量做拉新，看似都在收费，实际各自打的算盘并不一样。
千问办公助理8月7日刚刚上新功能，8月10日就挂出付费价格，商业化节奏推进得相当快。豆包从免费到收费，间隔时间同样很短。两家为何选择在这个时间窗口齐齐行动？把目光从收费模式的差异转向两家共同的处境，真相就浮出水面了。
第一，大模型调用量的增长远超预期。截至2026年4月，豆包日均Token调用量突破120万亿，是2024 年推出时的1000倍。字节跳动2025年全年资本开支超过1500亿元，其中约900亿用于AI算力采购。千问同样面临类似压力——春节期间日活峰值冲到7352万，活动结束后用户规模回落，但烧掉的算力成本已经实实在在支出了。每一次"帮我生成一份PPT"或"分析这份数据"的指令，背后都是GPU集群在持续消耗。
第二，获客成本高企，免费模式难以持续。据DataEye研究院预估，2026年春节期间AI产品营销战总花费超过100亿元。千问App投入约60亿元，折算单个日活获客成本约144元。豆包的获客成本在84到113元之间。花大价钱买来的用户如果始终无法变现，就会变成持续的亏损来源。资本市场也不再只为"用户数"鼓掌，投资人需要看到实际收入。
第三，AI Agent的普及让算力消耗上了一个台阶。早期AI产品主要处理简单问答，对话几次就结束。现在的AI智能体能够直接执行复杂任务：写代码、处理表格、批量分析、操作本地电脑。单次Agent运行的Token消耗量是普通对话的数十倍甚至上百倍。用户越多、任务越复杂，算力成本就膨胀得越快。
第四，行业竞争的逻辑正在发生根本变化。过去两年，国内大模型行业陷入价格战和免费策略的囚徒困境，各家都在烧钱抢市场。但芯片涨价、服务器成本上升、HBM存储价格高企——算力成本的全链条上涨迫使行业必须回答一个核心问题：AI公司能不能靠产品本身实现收支平衡？
两家头部厂商先后迈出收费这一步，与其说是某一家企业的主动选择，不如看作整个行业在算力成本重压下做出的集体调整。免费策略完成了培育市场的历史任务，但"谁来承担持续运营的成本"这个问题，终究要有一个答案。
理解了两家厂商的处境之后，再来看一下普通用户每个月实际要承担多少费用，脉络就更清楚了。结合当前主流产品的定价，可以从三个使用深度来拆解。
轻度用户，每月大致花销20-50元。这类用户主要用AI写文案、翻译资料、做简单问答，大部分需求落在免费额度以内。千问办公助理的免费体验额度约为13次，用完后次日刷新。只要不频繁生成PPT或进行深度分析，免费版基本够用。偶尔超限的话，19元/月的高级会员可以覆盖轻度办公需求。
中度用户，每月大致花销150-300元。这是目前绝大多数上班族的真实区间，每天需要AI协助写周报、做PPT、处理表格、整理会议纪要。以豆包标准版68元/月为例，5倍额度对高频办公基本够用。但许多用户同时使用多个工具——腾讯WorkBuddy个人版99元起、千问办公78元/月（公测折扣价）——几项叠加，月支出很容易突破200元。当然更常见的情况是"多工具堆会员"：写代码用Cursor，做PPT用豆包，深度分析用Claude，单项费用不高，合在一起钱包压力明显增加。
重度用户，每月大致花销500以上，甚至1500元以上。程序员、内容创作者、数据分析师是这一档的主要人群。Cursor Pro月费20美元（约145元），ChatGPT Pro月费200美元（约1450元），ClaudePro月费20美元。再加上豆包专业版500元或千问旗舰128元，月支出超过1500元并不罕见。有用户在社交平台晒出账单，半年AI工具开销累计超过9000元。值得注意的是，绝大多数公司不报销AI工具费用，这些支出属于个人自费。
还有一个定价细节值得留意：千问将视频生成额度从会员体系中独立出来，按量销售。据千问AI平台官方定价，1080P视频生成约1元/秒。如果把这个高成本模块打包进办公订阅，重度用户很快就能把月费“用回本”——这恰恰解释了千问为何选择将其剥离出来单独计费，用按量付费覆盖成本，避免因部分重度用户过度消耗而整体亏本。
从免费到19元，从68元到500元，再到上千元——不同使用深度的用户站的位置完全不同。轻度用户可以继续零成本使用基础功能，中度用户每月多支出一顿工作餐的费用，重度用户的开销则已经变成一笔不可忽视的月度固定支出。费用梯度的拉开，本质上是厂商在用价格把不同消耗量级的用户区分开来。
目前来看，AI办公费用梯度已经形成，每月账单的多寡很大程度上取决于用户自己的选择。面对不可逆转的收费趋势，普通用户仍然有一些方法可以控制支出，避免盲目氪金。
一，可以先用免费额度，再决定是否付费。WorkBuddy免费版已延期至8月31日；千问办公公测期间新用户注册即赠送2000积分，公测第一周每日登录还可额外领取500至2000积分。把各个平台的免费额度先用透，判断哪个工具真正符合自己的工作习惯，再考虑开付费会员，而不是一上来就订阅最高档。
二，要选择适合自己使用强度的档位，不要为冗余功能买单。以智谱GLM Coding Plan为例，Lite版月费118元、Pro版538元，两者价差超过400元。如果只是偶尔用AI辅助写代码、处理小型项目，Lite版的积分额度通常足够覆盖日常需求；只有需要高强度、大规模代码开发的用户，才需要考虑Pro及以上档位。先评估自己的实际使用强度，再选择对应档位，可以有效避免为用不上的额度买单。
三，尝试国产替代和组合使用来降低总成本。Copilot价格偏高时，可以关注国内的AI编程工具——阿里Qoder、腾讯CodeBuddy、智谱CodeGeeX等产品已具备相当的市场竞争力。同样，如果Claude的预算吃紧，豆包和千问的办公任务模式也能覆盖文档处理、PPT生成、数据分析等常见办公场景。总之预算有限时，组合使用不同工具往往是更灵活的选择。
四，订购团队套餐，有效降低人均成本。如果团队多人使用同一款AI工具，可以优先了解企业版套餐——豆包、千问办公、腾讯WorkBuddy等均提供企业方案，通常包含共享积分、更高额度和API权限，单位成本往往低于各自单独订阅个人版。但切勿尝试代充、账号拼车等灰色渠道——这些服务多用黑卡下单，平台一经发现即封号，且国家安全部已提示这类“AI中转站”存在资料被留存倒卖的风险。为省几十元搭上账号安全和工作文档，得不偿失。
免费且好用的AI产品正在减少，但用户仍然可以通过理性选择控制支出。一个朴素的判断标准就可以帮用户过滤掉大部分不必要的开销：只问自己一个问题，这个功能这个月能不能帮我省出比会员费更多的时间或金钱？能，就付；不能，就先用免费版撑着。不为"将来可能用得上"的冗余功能提前买单，这笔账就不算亏。
AI行业的免费时代不会彻底终结，基础问答和日常对话将继续免费开放。但办公、创作、数据分析等生产力场景正在被逐一划入付费区。对普通用户而言，这不是只能被动接受的变化，而是一次重新审视工具价值的机会。当AI从"尝鲜玩具"变成"工作工具"之后，值不值得花钱，判断标准始终是同一个：它能不能帮你把时间换成钱，以及换回来的钱是否超过了那张价签。
