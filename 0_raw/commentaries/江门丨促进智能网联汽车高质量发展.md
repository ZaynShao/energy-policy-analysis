# 江门丨促进智能网联汽车高质量发展

为了促进智能网联汽车产业高质量发展，推动创新应用，强化安全保障，加快发展新质生产力，根据有关法律法规，结合本市实际，江门市人大常委会办公室制定《江门市智能网联汽车发展促进条例（草案修改稿征求意见稿）》并于近日发布。
《草案修改稿征求意见》适用于本市行政区域内智能网联汽车产业发展、技术创新、推广应用、安全保障等相关活动。
总则：明确立法目的（促发展、保安全）、适用范围、基本原则，并细化市、县（市、区）政府及工信、交通、公安等多部门职责，同时建立容错免责机制以鼓励创新。
产业发展：规定政府通过制定产业政策、支持研发创新、推动产业集聚、统筹资金支持、强化人才引进与培养，以及加强宣传引导，全方位构建智能网联汽车产业发展生态。
推广应用：规范道路测试、示范应用及商业化收费的申请与互认程序；明确应急处置、数据存储和事故分析要求；支持开放公交、物流等多场景应用及功能型无人车发展，并推动通信、算力等基础设施建设。
安全保障：从行车安全、交通安全、定期评估与应急管理、网络和数据安全、产品质量安全及保险服务六个方面，对应用主体和生产者提出具体安全管理与合规要求。
法律责任：规定测试示范期间交通违法按现行法规处理；明确不配备驾驶人的事故处置、报警义务；确认交通事故责任认定原则，并明确由应用主体承担赔偿责任，可依法向第三方追偿。
附则：对“道路测试”“示范应用”“安全员”“应用主体”等核心术语进行定义，并明确条例的施行日期。
