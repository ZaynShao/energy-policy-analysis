# 刚花600亿买下Cursor，马斯克又要对Devin下手

新智元报道
刚花600亿美元买下Cursor，马斯克转头又盯上了Devin。
8月19日，彭博社独家爆料，SpaceX曾接洽AI编程创业公司Cognition，探讨潜在收购。Cognition就是自主AI软件工程师Devin的开发商。
马斯克又开始蠢蠢欲动。
结果比较尴尬。Cognition创始人兼CEO Scott Wu当天就在X上甩了一句话回去——
「这不是真的。我们对SpaceX团队非常尊重，但Cognition不卖，我们也没有进行过相关谈判。」
彭博的说法要更绕一层。据知情人士透露，SpaceX确实主动向Cognition提出了收购意向，但Cognition没有接招。
不过双方还在谈另一件事——让Cognition使用SpaceX的算力资源。要知道，马斯克手里现在攥着Colossus，仅一个集群就塞了超过22万块英伟达GPU。
更关键的是，这些机器已经不只给自己用。今年5月，连Anthropic都接入了Colossus算力。
有个细节。就在一周前，马斯克关注了Cognition的官方X账号。
Scott Wu，1997年生，美籍华裔，路易斯安那州长大，父母是从上海移民到美国的化学工程师。
哥们12岁就开始写代码。2011年，他拿了全美MathCounts冠军。2012到2014年，他连续三年在国际信息学奥林匹克竞赛（IOI）上摘金，最后一年直接拿了全球第一名。
在编程圈最硬核的评价体系Codeforces上，他是「传奇大师」（Legendary Grandmaster），峰值积分3350。
哈佛本科毕业后，Wu先是联合创办了AI社交平台Lunchclub担任CTO，入选过2020年福布斯30 Under 30。
2023年，他跟两个同样是IOI金牌得主的老战友Steven Hao和Walden Yan一起，在纽约一间公寓里创办了Cognition。三个创始人一共拿过5块IOI金牌，而公司早期的核心团队总共攒了10块。
有意思的是，Cognition最早其实是做加密货币的。
直到ChatGPT横空出世，硅谷集体转向，他们才果断掉头，一头扎进了AI编程这条赛道。用Wu自己的话说，「让AI写代码这件事，本质上是一道深度算法题」，恰好是他们最擅长的。
2024年3月，Devin正式亮相，号称「全球第一个AI软件工程师」，一炮打响。到今天，Cognition自己的代码库里，89%的代码都是由Devin自己写的。
Cognition 2023年成立，2025年9月融了4亿美元，投后估值102亿美元。8个月后的2026年5月，又拿到超过10亿美元融资，投后估值260亿美元，Lux Capital、General Catalyst和8VC领投，Founders Fund、Elad Gil等跟投。
现在它又在谈新一轮，目标估值至少400亿美元，比上一轮再涨50%以上。
收入这条线增长更猛。5月披露的ARR是4.92亿美元，现在已逼近10亿美元量级，三个月翻了一倍。企业使用量连续6个月保持月环比50%的增长。客户名单里有奔驰、高盛、花旗、NASA、美国陆军和海军。
7月，谷歌把Windsurf的核心团队挖走之后，Cognition火速接盘了Windsurf剩余的IP、产品和250人团队。
收编了IDE和Agent两条产品线之后，它现在是仍然保持独立的最大AI编程公司，没有之一。
马斯克先买Cursor、再盯Devin，因为这两个东西压根走的不是一条路。
Cursor是一个交互式代码编辑器，帮你补全、重构、调试。本质是让程序员提效的工具。
Devin走的是另一条路，你把一个完整的软件工程任务丢给它，它自己拆解需求、自己写代码、自己跑测试、自己Debug，端到端把活干完。
说白了，Devin就是冲着程序员这个岗位本身去的。
用行业术语的话说，Cursor是「副驾驶」（Copilot），Devin是」自动驾驶」（Autopilot）。
当然，截至目前，收购貌似谈崩了。但算力合作还在谈。
翻译过来就是，股权我不给你，但你的机器我可以用。
这就有意思了。独立公司拼产品、拼收入都还有胜算，唯独算力这一样自己不行，只能从马斯克、微软、谷歌这些手里买。
Cursor卖掉了，换来Colossus那22万块GPU。Cognition不卖，也一样要用SpaceX的机器。
两条路走到最后，站在算力上游的还是同一批人。殊途同归。
AI编程正在从帮人写代码，变成让Agent直接把整个软件工程做完。这条路越往前走，对算力的胃口越大，留给独立公司的那道门就越窄。
Scott Wu这次说了不卖。但下一次600亿美元推到桌上的时候，这个答案不知道还能不能是同一个。
