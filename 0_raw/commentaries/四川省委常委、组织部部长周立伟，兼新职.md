# 四川省委常委、组织部部长周立伟，兼新职

周立伟兼任四川行政学院院长。
7月13日，四川省人民政府网站发布最新人事任免。四川省人民政府决定：周立伟兼任四川行政学院院长。
▲周立伟（资料图）
周立伟，男，汉族，1971年10月生，黑龙江省双城人，研究生，工学硕士、工商管理硕士，中共党员。
周立伟曾任中国海洋石油集团有限公司副总经理、党组成员，中海石油炼化有限责任公司党委书记、董事长等职。
2023年1月任山东省副省长，2024年12月任山东省委常委、组织部部长。
今年7月任四川省委常委、省委组织部部长、省委党校校长。至此番兼任新职。
