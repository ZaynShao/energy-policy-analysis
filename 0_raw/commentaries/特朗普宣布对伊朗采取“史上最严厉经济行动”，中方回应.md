# 特朗普宣布对伊朗采取“史上最严厉经济行动”，中方回应

8月20日，外交部发言人林剑主持例行记者会。
彭博社记者提问，美国总统特朗普宣布对伊朗采取“史上最严厉经济行动”，包括对中国从伊朗购入的石油“采取措施”等，这样的威胁性的措施对于中方会有什么样的影响？外交部对于特朗普所宣布的措施有什么样的评论？
▲林剑资料图。图源：外交部网站
林剑表示，制裁施压无助于问题的解决。中方呼吁相关各方采取负责任的举措，通过政治外交途径解决问题。
