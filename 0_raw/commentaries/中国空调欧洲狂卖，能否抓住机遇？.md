# 中国空调欧洲狂卖，能否抓住机遇？

封面来源｜pexels
中国制造的空调在欧洲热销。家电巨头美的集团推出的无需安装的“移动式”空调产品，2026年年初至6月下旬的出货量已达到20万台，是2025年全年的2倍。面对国内市场低迷，中国家电企业希望以此次成功为契机，进一步开拓海外市场。
7月，在位于广东省广州市南沙的美的工厂内，装箱后的移动式空调“PortaSplit”不断被叉车装入集装箱。集装箱分别装上卡车，运往连接中国与欧洲的海运线路以及国际货运铁路“中欧班列”的集散地。
欧洲6月下旬遭遇创纪录的高温，法国和德国气温超过40摄氏度。在空调需求急剧增长的背景下，“PortaSplit”成为畅销产品。美的7月下旬透露，自6月以来又新增了16万台PortaSplit的订单。欧洲部分地区甚至出现库存售罄、难以购买的情况。
据国际能源署（IEA）统计，2025年欧洲家庭空调安装率仅为23%。欧洲拥有大量老旧公寓，为保护建筑物，对在外墙打孔等安装工程存在限制。即使没有相关限制，空调安装费用也较高，而且很多情况下很难预约到安装服务。
美的很早就注意到了这些问题。美的空调欧洲产品经理赵阿立表示，欧洲当地团队掌握了消费者需求并提出了相关方案，这是产品开发的契机。为了克服欧洲安装空调的难题，美的国内研发部门与位于意大利的设计部门耗时3年开发出了PortaSplit。
PortaSplit的售价约为1000欧元（约合人民币7786元）。无需专业人员安装，消费者可以自行安装。室外机重量约10公斤，一般人也可以搬动，可以安装在窗户或阳台门的外侧。室内机配有轮子，可以在地板上移动使用。
美的表示，此前市场上也存在移动式空调，但售价200至300欧元左右的低价产品存在制冷效果差、噪音大等问题。PortaSplit解决了这些问题，因此销量迅速增长。
家电巨头海信集团在欧洲的空调销量也大幅增长。在法国，1至6月的销售额同比翻番，整个西欧地区则增长两成。据中国海关总署统计，1至6月中国对欧洲出口的空调相关产品中，对法国出口额同比增长8成，达到14亿元人民币；对荷兰出口额增长6成，同样达到14亿元。
另一方面，中国国内空调销售表现低迷。据调查公司北京奥维云网大数据科技统计，同期中国国内空调销量同比下降6%，为5967万台。房地产市场低迷导致住宅销售减少，是主要背景。
出口方面，对美国和俄罗斯的出口也有所减少。1至6月中国空调出口额同比下降9%，降至1136亿元人民币。在国内市场以及欧洲以外市场出口均出现下滑的情况下，中国家电企业希望借助空调在欧洲市场的热销扩大商机。
美的空调欧洲地区销售总监熊学勤表示：“中国企业通过向市场推出具有独创性的产品，可以打破海外市场对中国品牌只是‘OEM（贴牌）厂商’的固有印象”。
如果能够像此次PortaSplit一样，迅速响应海外当地消费者需求，并将相关产品投入其他市场，将有助于提升中国品牌的知名度和可信度。对于在海外市场迎战中国企业的日本、欧美等企业而言，如果不能持续提升竞争力，也可能被中国企业抢走市场份额。
