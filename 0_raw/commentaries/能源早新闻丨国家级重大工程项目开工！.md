# 能源早新闻丨国家级重大工程项目开工！

◐《中国供电发展报告（2026）》发布。7月1日，国家能源局发布《中国供电发展报告（2026）》。其中指出，中国已建成全球规模最大的电力供应体系，2025年全国全社会用电量首次突破10万亿千瓦时，服务电力用户体量位居世界首位，供电水平跻身国际先进行列。世界银行新一轮企业调查结果显示，中国“获得电力”主要评价指标在已公布的经济体中表现卓越，达到或接近国际最佳水平。当前，全国电力供应能力充裕，能源绿色低碳转型步伐加快，电力供需形势总体平稳有序。【更多详情】
◐全国首条海河联运枢纽零碳航线开通。据新华网报道，6月30日，随着“宁远电鹏”轮满载集装箱缓缓驶离浙江嘉兴港独山港区，开往宁波舟山港金塘港区，标志着全国首条海河联运枢纽零碳航线正式开通。“宁远电鹏”轮总长127.8米、宽21.6米，可装载742标准箱，采用10个标准化箱式电池作为核心动力，总储电量约2万千瓦时，预计每年可节约燃油约800吨、减少二氧化碳排放超2000吨。
◐内蒙古美岱抽水蓄能电站项目开工建设。据内蒙古日报7月1日报道，日前，国家抽水蓄能“十四五”重点实施项目——内蒙古美岱抽水蓄能电站项目在土右旗开工建设。项目总投资82亿元，总装机容量120万千瓦，配备4台单机30万千瓦可逆式水泵水轮发电机组，计划2032年实现首台机组投产发电。电站满发时长可达6小时，设计年发电量15.26亿千瓦时，每年可消纳风电、光伏等新能源电量26亿千瓦时。
◐三峡枢纽2026年上半年通过量达7664.2万吨。据新华社报道，7月1日上午从交通运输部长江航务管理局获悉，今年1月至6月，三峡枢纽通过量达7664.2万吨。其中，保障2204.67万吨民生物资、69.95万吨重点急运物资过坝。今年上半年，三峡船闸共运行4527闸次，通过船舶1.7万艘次，通过量达7432.5万吨；三峡升船机共运行2129厢次，通过船舶2156艘次，运送旅客32.8万人次，运送旅客人次同比上升13.6%。
◐一季度电力行业信用电力指数同比小幅增长。据中新网7月1日报道 ，从日前在北京召开的2026年电力行业信用体系建设工作会议获悉，2026年电力行业信用电力指数第一季度监测情况报告显示，本季度信用电力指数行业标准值为73.13分，较上季度增长0.22分。725家集团中，341家企业得分超行业标准值，占比47.03%。
◐广州新沙港口岸上半年外贸汽车出口量同比增逾169%。据中新网报道，6月30日从广州海事局了解到，广州新沙港口岸今年1至6月外贸汽车出口量同比增长169.7%，其中新能源汽车出口量同比增长81.7%，外贸汽车出口规模持续扩大。
◐印度7月1日起取消汽柴油销售限制。据中新网报道，路透社消息，印度政府日前发布行政令称，将于7月1日起取消6月实施的汽油和柴油销售限制。受中东局势影响，为防止国内燃油短缺，印度此前禁止商业燃油买家在零售加油站购买汽油和柴油，并对每日柴油购买量设置上限。相关限制措施将于7月1日起解除。
◐市场服务机构：霍尔木兹海峡航运活动持续恢复。据新华社6月30日报道，市场服务机构克普勒公司数据显示，24艘油轮和货船于6月29日通过霍尔木兹海峡，表明这一全球重要能源运输通道航运活动持续恢复。彭博社援引克普勒公司数据报道说，包括原油运输船和液化天然气运输船在内的24艘船舶当天通过霍尔木兹海峡。数据还显示，6月30日海峡航运活动进一步增加，一艘巨型油轮以及若干小型船只驶入波斯湾，反映出航运市场对该地区通航状况的信心有所回升。
◐四川电网12项迎峰度夏电网重点工程完成带电试运行。据中新网报道，6月30日从国网四川省电力公司获悉，四川省2026年12项迎峰度夏电网重点工程全部完成带电试运行，28项配套保供工程同步落地投用，该省电网供电承载与资源调配能力实现全面升级，为今夏电力安全可靠供应夯实基础。
