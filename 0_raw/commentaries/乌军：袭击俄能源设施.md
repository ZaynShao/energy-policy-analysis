# 乌军：袭击俄能源设施

乌军称袭击俄西北部一能源设施。
乌克兰武装部队总参谋部14日在社交媒体发帖说，乌军袭击了俄罗斯西北部列宁格勒州一座能源设施。
乌武装部队总参谋部说，乌军13日至14日夜间袭击了俄大型天然气生产商诺瓦泰克公司位于乌斯季卢加港的凝析油加工和转运综合体内的两处设施，现场起火。
媒体报道显示，该综合体主要将稳定凝析油加工为轻石脑油、重石脑油、航空燃油及柴油，其中部分产品供应俄罗斯武装部队使用
