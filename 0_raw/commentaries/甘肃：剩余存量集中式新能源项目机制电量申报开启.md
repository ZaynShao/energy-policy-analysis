# 甘肃：剩余存量集中式新能源项目机制电量申报开启

申报主体为2025年6月1日以前（不含6月1日）投产的集中式新能源存量项目，包括前期已申报但需进一步核实确认的自主化示范风电项目、扶贫类、分散式风电及国家能源局以国能新能〔2014〕541号批复的风电项目，以及未参与前期申报的其余存量项目（不含光热+项目）。
申报期限为8月17日8:30至8月21日18:00，上述新能源企业在新能源云平台完成企业信息、项目信息和机制信息的填报提交工作。项目申报电量不得高于已确定的可申报电量规模上限，详见附件。项目信息提交后，平台将对相关信息自动封存，不可更改。
根据甘发改价格〔2025〕516号要求，不参与首次申报的存量集中式新能源项目，视为放弃机制电量，并不再纳入机制执行范围。单个新能源项目在确定的规模范围内每年自主申报纳入机制的电量，但不得高于上一年（不含全额纳入机制电量的项目）。
8月24日8:30至8月28日18:00，国网甘肃省电力公司组织开展机制电量申报审核工作，对审核未通过项目于8月25日21:00前予以回退，反馈回退原因、需补充修改资料。新能源企业须在8月27日18:00前完成修改并重新提交，逾期未重新提交或提交后仍未通过审核的，视为放弃申报资格。
6月16日，国网新能源云发布国网甘肃省电力公司关于组织开展第一批存量集中式新能源项目机制电量申报工作的通知。详见：甘肃
