# 【21世纪经济报道】从“建立”到“深推”，第二批国家级零碳园区申报在即

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/vYw27Y7HicGeqQ10C4JZvC6H55buZYCJHDXg9ibxcK4DW9lNeNDD3f9Eictibma09FnpT6bpLf6fwvvh8F2nQD30mj4LI28Ik0GZG6m8u433F14/640?wx_fmt=gif)

2025年政府工作报告提出“建立一批零碳园区、零碳工厂”，今年政府工作报告则明确提出“深入推进零碳园区和工厂建设”。多位业内人士向21世纪经济报道记者表示，零碳园区作为“双碳”目标落地与产业绿色升级的核心载体，正在迈向高质量建设新阶段。

  

从2024年中央经济工作会议要求“建立一批零碳园区”，到2025年首批国家级零碳园区建设名单出炉，零碳园区的发展规划逐步落地、层层深化。如今，首批入选建设名单的52个园区已全面进入建设实施期，行业关注度持续攀升。

  

记者从多个渠道获悉，第二批国家级零碳园区申报工作或于近期启动。在多重利好与机遇叠加下，零碳园区的发展路径、申报筹备及建设实践成为行业关注焦点。

**从“建立一批”到“深入推进”**

![image](https://mmecoa.qpic.cn/sz_mmecoa_gif/tYBGQJ9TRKmFIILGaibFDkS34XqEkpLjjNmnO9DaxMqgjQBiaczN0icQqhBd0R6jaMk3gxHqQzgbrlvuTKia1FCPEQ/640?wx_fmt=gif)

今年政府工作报告对“零碳园区”的表述从“建立一批”变为“深入推进”。

  

2024年中央经济工作会议要求“建立一批零碳园区”，零碳园区相关政策陆续出台。2025年3月，政府工作报告再次明确部署“建立一批零碳园区”。此后，国家发展改革委、工业和信息化部、国家能源局印发《关于开展零碳园区建设的通知》，提出了加快园区用能结构转型等8方面重点任务，以及国家级零碳园区建设“1项核心指标+5项引导指标”的指标体系。

  

同年10月，在介绍和解读党的二十届四中全会精神新闻发布会上，国家发展改革委党组书记、主任郑栅洁表示，“十五五”时期，力争建成100个左右国家级零碳园区。同年12月，首批国家级零碳园区建设名单公布，共纳入52个园区，首批名单实现31个省（区、市）和新疆生产建设兵团全覆盖。

  

结合首批名单建设实践，中国节能协会副秘书长兼碳中和专业委员会秘书长张军涛向21世纪经济报道记者表示，从2026年的政府工作报告来看，零碳园区的建设已经正式从早期的试点示范期，迈入了一个“规模化推广”与“深水区攻坚”相结合的新阶段。从“建立一批”到“深入推进”，标志着零碳园区从前期探索，转向全面铺开，成为构建新型能源体系、培育新质生产力的核心载体。我国零碳园区建设已呈现出三个显著的阶段性特征：空间布局全域化、建设路径规范化、产业融合深度化。

  

中咨公司资源与环境业务部气候应对处处长木其坚向21世纪经济报道记者表示，从“建立一批”到“深入推进”，这种表述的变化非常精准地概括了当前零碳园区建设所处的关键阶段——从“大写意”走向“工笔画”。目前，绝大多数入选园区的工作重点也正反映了这一阶段的特点，主要集中于两件事：一是按照国家要求，编制详细的实施方案；二是开始接洽潜在的能源建设方和产业投资商，为后续建设做准备。所以，“深入推进”正是对当前工作重心的准确描述，即从确立概念、筛选名单，进入到实质性方案落地和建设的深水区。

**首批入选园区如何接住红利**

![image](https://mmecoa.qpic.cn/sz_mmecoa_gif/tYBGQJ9TRKmFIILGaibFDkS34XqEkpLjjNmnO9DaxMqgjQBiaczN0icQqhBd0R6jaMk3gxHqQzgbrlvuTKia1FCPEQ/640?wx_fmt=gif)

首批国家级零碳园区产业以低能耗、低污染、高附加值的新能源集聚型产业为主，核心覆盖三大方向：新能源装备制造、先进装备制造和绿色算力与特色产业。匹配不同园区产业复杂度与转型难度，园区建设周期集中2025—2027年、2025—2028年、2025—2030年三个梯度。

  

“我们接触的不少入选单位，他们都说每天都是应接不暇的状态。这种忙碌，正是‘深入推进’最真实的写照。”北京中创碳投科技有限公司首席双碳官孟兵站表示，“深入推进”标志着零碳园区跨入了全新阶段，工作的重心转向“落地”。

  

2026年如何对园区建设进行阶段性衡量，成为行业关注的关键问题。零碳园区建设指标体系的核心指标是单位能耗碳排放，按照园区年综合能耗规模分为两类：20万—100万吨标煤园区≤0.2吨/吨标煤；≥100万吨标煤园区≤0.3吨/吨标煤。达不到核心指标要求的园区，原则上不得申请验收。

  

孟兵站表示，关于零碳园区“建不建成”的核心就在园区验收的那一年，核心数据要达标。为了达到这个目标，必须在验收之前，把当初在设计方案里的新能源项目、储能项目、节能减排项目等真正落地，并且投入运营。

  

这还涉及一个现实的问题——项目进度。零碳园区从纸面到落地，中间隔着“千山万水”。

  

孟兵站表示，项目落地、资金来源、设备运营等整套流程走下来需要时间。“深入推进”这四个字，落实到操作层面，就需想尽一切办法，把方案里的项目，真金白银地投下去，实实在在地建起来，顺顺当当地运营好。

  

在诸多项目环节中，新能源、储能的落地值得关注。孟兵站介绍，当一个园区进入国家级零碳园区名单后，便迅速吸引社会各界的广泛关注。园区内新能源与储能项目的落地，并非传统意义上的政府招商引资，而是在政策框架引导下，由市场机制主导形成的资源配置结果。园区入选后，各类新能源企业主动参与竞争，凭借技术方案的优势胜出并参与项目投资建设。项目资金可以包括银行提供的优惠贷款等。企业的盈利渠道则涵盖售电收入、储能服务等市场化收益。换言之，唯有经过审慎测算、确认具备合理投资回报率的项目，企业才会真正投入真金白银。

  

张军涛向记者表示，尽管已遴选出首批建设名单，但必须正视其建设周期之长，现实挑战依然严峻。例如，绿电直连涉及的基础设施投资巨大，需要协调电网、用户、政府等多方。绿电的“电能量”与“环境价值”在当前市场机制下尚未得到充分反馈，制约了企业的投资意愿。

  

“因此，在迈入新阶段的同时，我们必须在技术层面、机制、管理协调同步加强，才能确保零碳园区建设行稳致远，真正成为驱动中国经济绿色高质量转型的新引擎。”张军涛表示。

  

木其坚表示，国家级零碳园区标准具有很高的创新性和挑战性，例如要求“碳能比”控制在0.2以内，以及绿电直连直供比例达到50%以上，需要下一些细致功夫。他认为，当前零碳园区建设有四大核心任务需要深入推进。

  

一是能源基础设施建设。这是实现零碳的“硬件”基础，需构建包含电源、智能微电网、储能及用能端改造在内的一体化能源系统，并将电、热等多种能源形式进行整体优化设计，这是实现绿色、安全、经济平衡的关键。

  

二是精准招商引资。需瞄准对电价敏感、受国际绿色贸易规则影响或面临碳排放双控压力的企业，从当前情况看，不少符合这一“画像”的企业已开始与园区接洽。

  

三是投融资模式创新。零碳园区建设本身是符合绿色金融等相关资金支持方向的，但关键在于算好包含电、热、虚拟电厂等在内的“综合收益账”。目前因无成熟案例参考投资周期，追求稳定回报的资本多持观望态度，决策灵活、能够接受一定不确定性的企业可能具备先发优势。

  

四是智慧能源管理系统。作为破解“绿色、低价、安全”不可能三角的“软件”核心，可以算是零碳园区建设皇冠上最璀璨的“明珠”。需要依靠高度智能化的指挥系统，高频次动态决策用能策略，直接决定了园区的商业化可行性，既是挑战也是巨大的市场机会。

**第二批如何申报成功率更高**

![image](https://mmecoa.qpic.cn/sz_mmecoa_gif/tYBGQJ9TRKmFIILGaibFDkS34XqEkpLjjNmnO9DaxMqgjQBiaczN0icQqhBd0R6jaMk3gxHqQzgbrlvuTKia1FCPEQ/640?wx_fmt=gif)

关于第二批国家级零碳园区的申报备受市场关注。21世纪经济报道记者就此多方求证了解到，业内人士透露，全国零碳园区建设现场推进会上曾提及相关内容，但具体安排仍以官方后续发布的正式文件为准。

  

从首批国家级零碳园区的申报推进节奏可作参考，2025年7月8日《关于开展零碳园区建设的通知》正式发布，明确8月22日前各地区需将推荐园区名单及建设方案报送至国家发展改革委（环资司），且各地区推荐园区数量不超过2个。同年12月26日，首批国家级零碳园区建设名单正式公布。从申报《通知》发布到完成地方推荐材料报送，间隔时间不足两个月，这也意味着有意参与第二批申报的园区，需提前统筹谋划、做好各项筹备工作。

  

对于有意向申报第二批国家级零碳园区的单位，木其坚建议，零碳园区不是普适性要求，对于周边可再生能源资源、产业园区自身的产业基础和发展定位都有一定要求，不是所有园区都必须或适合建设零碳园区。在申报前，务必实事求是地评估自身资源禀赋，科学合理地评估零碳园区建设的技术可行性与经济可行性，如果确有条件，可以提早谋划，但若园区基本条件不符，则应把工作重心放到园区节能降碳、循环经济乃至绿电直连等工作中，不宜仅为了“戴帽”而申报。

  

博众智合能源转型清洁电力项目主任尹明也认为，要找准内在驱动力。成功项目均来自行业自身对绿色能源的迫切需求，而非追逐概念。首批项目集中在新能源、数字经济等本就需要绿色转型的领域。零碳园区是有严格排放标准与监管的实体项目，绝不能沦为金融炒作工具。唯有内在转型需求与外部政策激励有机结合，方能催生高质量项目。

  

在此基础上，具体如何申报？**国网能源院碳治理基础研究所筹备组专家汤芳**向21世纪经济报道记者表示，建议重点要完成几项核心工作，例如完成申报主体资格梳理与申报范围划定，对标首批要求完成现状摸底与短板补齐。

  

“还要完成高质量建设方案编制，这是申报的核心材料，根据去年零碳园区申报大纲模板（今年模板或将发生变化），需结合园区资源禀赋、产业基础，制定差异化建设路径，明确建设目标、重点任务、重点项目、实施周期、保障措施，重点突出园区的特色优势、可复制性和落地可行性，明确量化的阶段性目标，确保方案可考核、可落地。”**汤芳**说。

  

此外，**汤芳**表示，要搭建完善的碳管理体系与数字化管控平台，锁定核心支撑项目与资金保障。“还要完成省级主管部门前期对接与沟通。国家级申报实行‘地方申报—省级审核推荐—国家遴选确定’的流程，各省推荐名额普遍不超过2个，竞争极为激烈。园区需在一季度主动对接省级发展改革委、工信厅、能源局等主管部门，汇报申报筹备情况，争取纳入省级推荐名单，这是申报成功的关键前提。”
