# 内蒙古3.2GWh项目进展：星辰新能成为乌拉特后旗项目实施主体，锡林浩特启动储能项目优选

项目建设地点：锡林浩特市境内。
项目接入：塔拉500千伏变电站、灰腾梁500千伏变电站。
项目建设规模：单个独立新型储能电站规模不低于20万千瓦/80万千瓦时。塔拉500千伏变电站接入容量为20万千瓦，灰腾梁500千伏变电站接入容量为40万千瓦。
若按塔拉500千伏变电站、灰腾梁500千伏变电站满容量接入、配置4h储能系统估算，则本次优选总容量为600MW/2400MWh。
技术类型：独立新型储能电站采用构网型技术，优先支持压缩空气、全钒液流、钠离子等技术路线。
根据优选结果显示，确定乌拉特后旗星钒200MW/800MWh全构网型独立储能电站项目实施主体为内蒙古乌拉特后旗星钒信储能有限公司。
据天眼查显示，内蒙古乌拉特后旗星钒信储能有限公司（以下简称“钒信储能”）第一大股东为海南省储信合新能源有限公司，持股88%。向上股权穿透后，海南省储信合新能源有限公司85%股权由海南极云序科技有限公司持有。需要注意的是，浙江星辰新能科技有限公司也持有钒信储能一定的股份。
