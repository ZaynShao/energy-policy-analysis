# BBA又杀回来了！原生纯电平台+中国大脑，合资车企开启纯电2.0时代

从油改电到原生平台，还换上“中国大脑”，BBA这次来真的了。车东西7月15日消息，日前，全新奔驰纯电GLC SUV正式上市。新车采用了800V碳化硅平台，搭载电动两档变速箱，其辅助驾驶系统由奔驰与Momenta携手打造，也采用了奔驰自研架构+中国专属解决方案来打造智能座舱，产品迎来全方位革新。▲全新奔驰纯电GLC上市
自2019年奔驰首款纯电SUV EQC入华以来，BBA三家相继推出了各自的首款纯电SUV产品，完成了从燃油时代向电动时代的第一次探索。但这一代产品更多承担的是过渡角色，在平台架构、续航补能以及智能化能力等方面，仍延续着燃油车时代的技术思路，最终未能帮助三家在快速发展的中国新能源市场建立起领先优势。在智能化、电动化、本土化的热浪席卷下，随着全新奔驰纯电GLC SUV的上市，德系豪华三强在中型豪华纯电SUV市场上，先后亮出了各自的底牌。宝马携全新iX3长轴距版重归中国市场，预计今年四季度开启交付；去年8月上市的奥迪Q6L e-tron又在今年4月10日新增3个版本，将起售价进一步杀到27.98万元。▲全新宝马iX3、全新奔驰纯电GLC、奥迪Q6L e-tron
至此，BBA三家中型纯电SUV集齐，均搭载着自家的原生纯电平台和中国本土智驾智舱方案，终于从“油改电过渡”进入了真刀真枪的正面战场，BBA纯电2.0时代正式开篇。
与7年前的“油改电”不同，全新奔驰纯电GLC、宝马全新iX3长轴距版和奥迪Q6L e-tron，三款车全部基于BBA各家全新原生纯电平台开发，搭载800V高压平台，在智驾和智舱方面还引入了中国本土方案。判断一台电动车是否是“原生”纯电，可以从平台入手。全新奔驰纯电GLC是奔驰首款基于MB.EA架构打造的车型。MB.EA是奔驰专为中大型乘用车打造的纯电架构平台，与之并行的还有AMG.EA性能电车专属平台和VAN.EA纯电MPV专属平台。▲奔驰三大纯电平台
宝马全新iX3长轴距版基于宝马新世代纯电专属平台Neue Klasse打造，从底层布局上解决了过去油改电车型的空间妥协、架构落后、快充拉胯三大顽疾。奥迪Q6L e-tron也是奥迪首款基于PPE纯电平台打造的量产车型。PPE（Premium Platform Electric）是奥迪与保时捷联合开发的第二代原生豪华纯电平台。相比此前油改电过渡时期采用的MLB Evo豪华燃油平台，整车空间利用率和电动化集成度更高。▲奥迪PPE豪华纯电平台（图源网络）
从技术路线来看，在原生纯电平台下，三家的思路大同小异。官方数据显示，全新奔驰纯电GLC、宝马全新iX3和奥迪Q6L e-tron分别最高支持320kW、400kW和270kW的直流快充；全新奔驰纯电GLC需要22分钟完成10%至80%补能，另两款车需要21分钟；全新奔驰纯电GLC和奥迪Q6L e-tron在CLTC工况下最高续航分别为703km和709km，宝马全新iX3则将续航带到了900km以上。▲BBA三款纯电中型SUV具体信息
奔驰采用全新EDU（Electric Drive Unit）电驱总成，并通过碳化硅逆变器提升效率；宝马搭载了第六代eDrive技术，引入了全新圆柱电芯、电驱和能量管理系统；奥迪PPE平台也重新设计了电驱及热管理系统。从结果看，更智能、更高效的三电系统，是三家老牌车企德系工程能力的自然蜕变。它们在机械时代积累的“三大件”经验，在电动化时代找到了新的落脚点。完成三电系统迭代的同时，在智能化深水区里，BBA三家也都找到了在中国新能源市场实现翻盘的关键筹码——绑定中国本土智驾和智舱解决方案，换上“中国大脑”。辅助驾驶方面，奔驰和宝马都选择与Momenta联手。其中，奔驰全新纯电GLC搭载了强化学习模型，支持城区领航功能，可以做到“全国都能开”。奔驰还与Momenta携手测试世界模型，将在Momenta合作伙伴中首批上车世界模型，即将交付“车位到车位”的辅助驾驶能力。宝马全新iX3长轴距版同样采用Momenta辅助驾驶方案，强调为中国复杂环境量身定制，系统稳定且注重人机共驾体验。奥迪则选择与华为合作，在Q6L e-tron上搭载华为乾崑辅助驾驶系统，支持高速NOA、城区NOA和全场景泊车等。▲三款车所搭载的智驾方案
三家的智能座舱同样遵循“在中国，为中国”的转型逻辑。奔驰全新纯电GLC提供“奔驰自研架构+中国专属解决方案”的MB.OS操作系统，搭载奔驰中国本土团队研发的读心语音助理，还引入了豆包大模型和超拟人TTS技术，目前专属AI管家月均用户渗透率约98%。宝马全新iX3长轴距版在搭载宝马全景iDrive X系统的同时，集成本土阿里巴巴AI大模型和DeepSeek技术，打造具备多智能体协同能力的AI个人助理；奥迪Q6L e-tron则在保留最新一代奥迪MMI智能座舱体系的同时，为中国用户定制全场景语音助手，强化中国本土智能生态。整体来看，BBA三家都清醒地认识到了自身在智能化配置方面的短板，集体借力中国智驾技术和智舱方案，以“原生纯电平台+中国本土智驾智舱”双管齐下，试图重新夺回豪华电车市场话语权。
要读懂BBA为什么几乎在同一时间推出基于全新平台打造的中型纯电SUV，首先要看BBA当下面临的困境。从中国市场看，BBA的燃油车业务与早期油改电产品正同时遭遇挑战。长期以来，奔驰GLC、宝马X3、奥迪Q5L等车型一直是豪华中型SUV市场的重要销量支柱。但随着新能源汽车的快速普及，燃油车正在从新车市场的主角变成配角。▲老款奔驰GLC、宝马X3、奥迪Q5L（图源网络）
乘联分会数据显示，2026年6月全国乘用车市场零售的160.2万辆中，新能源乘用车零售渗透率达到62.8%，常规燃油乘用车份额37.2%，车市呈现“燃油车内销崩塌、新能源强势主导”的局面。与此同时，BBA此前为了应对市场变化推出的“油改电”过渡车型，也一直处于一个相对尴尬的阶段。奔驰EQC、第一代宝马iX3、奥迪e-tron这些车多为BBA燃油车型的“油改电”衍生，在智能化体验、续航补能、本土化适配等方面相对脱节，在中国市场都出现过数万元至十余万元不等的终端优惠，市场销售压力较大。▲奔驰EQC、第一代宝马ix3、奥迪e-tron（图源网络）
在这一过程中，以理想L7、问界M7、小米YU7等为代表的中国本土新能源品牌，也开始进入BBA长期占据的30万以上豪华SUV市场腹地，以超大空间、豪车级舒适性配置和先进的辅助驾驶系统，成为消费者的心头好，长期霸榜该价格带销量排行榜前几名的位置。压力还蔓延到了海外市场。这几年，中国新能源车出海规模快速扩大，不断挤占BBA海外市场的份额，进一步压缩了其营收空间。中汽协数据显示，2025年中国新能源汽车出口总量达261.5万辆，同比增长1倍。但BBA这边全球销量却在下滑。根据官方数据，2025年奥迪全球累计交付新车162.36万辆，同比下降2.9%；2025年奔驰全球累计交付新车180.08万辆，同比下降9%。▲2025年奔驰宝马奥迪销量数据
同时，中国新能源品牌在智能驾驶、智能座舱、电池技术和用户生态方面形成的产品特点，也正在随着其出口的扩大进入更多海外市场，并推动全球汽车行业重新审视智能化能力在豪华车型竞争中的重要性。对于德系三强来说，无论是中国市场还是海外市场，继续依赖燃油车利润、用油改电产品参与市场竞争的策略似乎已经走不通。持续承压的营收，挤压着BBA三家电动化转型慢慢试错的时间。集中资源推出原生纯电平台，并通过本土化智驾智舱方案弥补短板，是BBA转型自救之路必须做出的回应。▲2025年奔驰宝马奥迪营收表现
不可否认，无论是全新奔驰纯电GLC、宝马新世代iX3长轴距版，还是奥迪Q6L e-tron，都能看出三家拿出了满满的诚意来迎合中国消费者的喜好。经过数十年发展，BBA三家在全球市场建立了成熟的品牌体系、销售网络和售后服务体系，这些积累并不会因为动力形式的变化而消失。在30万至50万元市场，品牌影响力依然是消费者购买决策的重要因素，“三叉星徽”、“蓝天白云”和“四环”所承载的社交价值，目前仍是同价位中国本土新能源品牌难以完全替代的资产。此外，三款新车还延续了百年德系品牌在底盘调校和转向手感上的工程积累。其中，全新奔驰纯电GLC引入了S级同源的AIRMATIC空气悬架、ADS+减振技术和后轮主动转向技术，还针对中国路况做了调校，滤振舒适兼顾操控灵活性。▲奔驰纯电GLC SUV底盘
但我们也知道，在中国市场，BBA三家单靠工程底蕴和品牌积淀，不足以赢下电动化的下半场。它们想要逆风翻盘，难度着实不小。首先，三款新车进入的中型纯电SUV市场早已是一片红海，问界、蔚来等品牌以家庭空间、智驾能力和无忧服务等为核心卖点，圈定了各自的用户群体，迅速站稳脚跟。三款新车所搭载的800V高压平台、空气悬架、高阶智驾等配置，在同价位中国新能源品牌中也已不是稀缺项。与此同时，过去几年中国本土新能源品牌在产品体验和服务模式上更贴近本土需求，从座舱交互逻辑到补能网络布局都更早响应用户需求，这种先发优势意味着，当BBA开始推出对标的智能化方案时，中国品牌已在用户心智中完成了“智能电动车该是什么样”的定义。再者，此次BBA三款新车在智驾和智舱上都采用了中国本土供应商主导的方案，这种做法虽然能够缩短产品上市周期，降低生产成本，但其算法和整车硬件更新的节奏不再完全由BBA独立掌控，对中国供应商可能存在着不同程度的依赖，一定程度上会影响技术更新的主导权，也会带来同质化风险。最后，三家在场景创新方面略显滞后。这两年，中国品牌正在尝试用“场景定义汽车”，使车辆从出行工具“摇身一变”成为移动生活空间，给用户提供更丰富灵活的出行体验。比如问界M9搭载的智能投影大灯可实现户外电影投影，满足家庭出行露营观影需求；预计在8月中下旬上市的小米增程新车澎程N90露营版也将搭载升降顶篷版车顶。至少从目前公开的配置表看，BBA三款新车在这一维度上仍保持着相对传统的产品设计。▲问界M9智能投影大灯（图左）和小米增程新车澎程N90升降顶篷版车顶（图右）
2019年，当奔驰EQC带着燃油车平台的痕迹进入中国时，这个市场还愿意给德系豪华品牌留出试错的时间。七年后，规则悄然改写，能留在牌桌上的车企，需要同时具备优秀的整车工艺、超长续航、体面均衡的智能化体验和对用户需求的快速响应。全新奔驰纯电GLC SUV、宝马全新iX3长轴距版、奥迪Q6L e-tron是BBA三家在电动化方向上集体调整后交出的一份完整答卷。但产品到位只是第一步。配置清单上的对齐，不等于体验上的超越；供应商方案的集成，也不等于智能化能力的自主可控。当下，竞争已经从“有没有”进入到了“好不好用、够不够聪明、能不能持续进化”的阶段。三款新车的上市，让BBA拿到了重回主赛场的入场券。接下来，真正的考验才刚刚开始。
