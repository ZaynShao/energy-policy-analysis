# IIGF新闻 | 中财大绿金院研究成果荣获“运河上的‘大思政课’”学术研讨会征文评比一等奖

7月11日，由运河城市大中小学“运河思政”一体化联合体主办，淮北师范大学、北京物资学院联合承办的运河上的“大思政课”学术研讨会在淮北师范大学滨湖校区成功举行。教育部社科司教学与出版处处长范丹卉，安徽省委教育工委副书记(正厅级)蒋家平，安徽省社科联党组成员、副主席林勇，淮北市委常委、宣传部部长姚珂，淮北师范大学党委书记毕明福，北京物资学院党委副书记张懿，天津美术学院党委副书记陈占权，安徽省大运河文化研究会会长、安徽大运河文化研究中心主任余敏辉，江苏省教育厅社政处处长邹燕，浙江省教育厅宣传教育与统战处处长谢才波，北京市通州区委教工委副书记陈洁，淮北市教育局党组书记、局长郑晓野等领导，以及来自大运河沿线八省市有关机构等近150位代表参会，共话运河文脉赋能创新路径，共筑大中小学思政教育一体化高质量发展新格局。会议还举行了“运河学子万村行”实践启动仪式，并为本次研讨会征文获奖代表颁奖。
本次研讨会征文评比活动共计收到征文204篇。专家组按教学案例和研究论文两类分别评比，其中评定优秀研究论文一等奖14篇、二等奖28篇、三等奖42篇。中央财经大学绿色金融国际研究院健康金融实验室主任任国征提交的论文《大运河文化助推高校思政课话语权传播》荣获一等奖。
《大运河文化助推高校思政课话语权传播》一文指出，今年是习近平总书记在哲学社会科学工作座谈会上发表重要讲话十周年。十年来，习近平总书记关于学术体系、学科体系和话语体系的重要论述为研究我国红色文化传播和绿色文旅产业注入了强大思想动力。文章围绕大运河文化融入中国学校思政课的方法与路径，将绿色文旅和红色文化融合发展，将文旅产业和话语传播协同推进，将运河文化与旅游金融同步发力，深入挖掘、系统分析大运河文化的文化内涵、产业转化和金融扶持，以此构建新时代高校思政课话语权。
本次研讨会是运河沿线八省市思政教育领域的高端学术交流活动，既总结了“运河思政"建设的阶段性成果，也为下一阶段深化大中小学思政教育一体化、推动运河文化资源创造性转化为育人资源明确了方向。与会代表一致表示，将以此次研讨会为新起点，协同落实《北京共识》，共同打造全国“大思政课"建设的示范样板，为教育强国、文化强国建设贡献运河力量。
