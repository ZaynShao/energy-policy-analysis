# 杭州市菜篮子价格监测周报（7月20—7月26日）

✦
•
✦
监测数据和市场巡查情况显示，上周（7月20—7月26日）杭州市菜篮子商品供应充足，猪肉、蔬菜价格环比上涨，鸡蛋、水果价格呈下降态势，水产品价格涨跌各现。具体情况如下：
✦
•
✦
肉禽蛋
猪肉价格环比微涨：猪肉零售均价17.52元（每500克，下同），涨幅0.11%。分部位看：猪全精肉16.8元，跌幅0.18%；猪肋排28.18元，涨幅0.21%；猪五花肉16.57元，涨幅0.06%。鸡蛋6.12元，跌幅0.33%。其余品种零售价格总体平稳。
蔬菜
蔬菜价格环比微涨：纳入监测的蔬菜品种零售均价5.77元，涨幅0.52%。具体来看，青菜3.76元，涨幅1.9%；菠菜7.26元，涨幅4.01%；茄子5.3元，跌幅2.21%；花菜5.81元，涨幅0.69%；冬瓜2.61元，与上期持平。其余大部分品种零售价格变动幅度在5%以内。
水产
水产品价格涨跌各现：其中，鳙鱼12.59元，涨幅0.48%；鲫鱼17.6元，跌幅0.28%；明虾24.36元，跌幅1.54%；带鱼29.19元，涨幅0.97%。
水果
水果价格环比下跌：水果零售均价4.93元，跌幅0.6%。分品种看，苹果8.14元，涨幅0.87%；梨4.46元，跌幅1.76%；橙子5.46元，跌幅0.18%；香蕉3.87元，跌幅0.77%；西瓜2.74元，跌幅2.49%。
