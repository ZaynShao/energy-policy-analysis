# 聚焦对接国际气候准则 助力全球绿色供应链合规与透明——“迈向COP31企业脱碳行动”首场沙龙在京举行

8月6日下午，“迈向COP31企业脱碳行动系列沙龙”首场活动在北京亚洲金融大厦顺利举行。本次沙龙以“对接国际气候准则——全球绿色供应链的合规与透明度”为主题，由中国能源研究会外事工作委员会主办，由《中国能源报》提供媒体支持。在全球气候治理加速转向制度落实、欧盟CBAM正式开征以及ISSB等国际准则全面推进的背景下，活动吸引了来自国际组织、行业协会、知名智库、金融机构及新能源龙头企业的数十位专家代表，共同探讨中国企业如何打通数据壁垒、应对规则演变，实现从适应规则到参与定义规则的跨越。
在主旨发言环节，与会资深专家与代表围绕国际准则演进与企业应对策略展开了多维度解读。资深能源专家安丰全教授指出，气候合规早已超越单纯的“成本项”，成为中国企业参与国际竞争的核心能力分水岭，市场正经历从“质优价廉”向“低碳透明”的深度转变。国际可持续准则理事会（ISSB）理事冷冰强调，ISSB准则旨在建立企业与投资者的高效对话，企业应结合本土土壤、聚焦战略与风险管理讲好合规故事；商道融绿董事长郭沛源系统阐述了转型债券与碳市场等金融工具对实体能源转型的赋能路径；鼎力可持续公司气候变化总监赵俊峰则深度剖析了SBTi 2.0新规对范围三减排及可信数据链条的硬性要求。
随后展开的圆桌讨论气氛热烈，来自高校智库、行业协会与领军企业的嘉宾进行了深度交锋。哈工大商学院院长马涛、中电联副主任张晶杰、中央财经大学教授许寅硕、固德威研究院院长张可男及协鑫集团总监胡珺等专家，重点围绕“数据资产化”与“供应链国际互信”发表了见解。与会嘉宾一致认为，合规成本转化为市场溢价的关键在于建立财务级可追溯、可验证的数据体系；同时，中国企业既要尊重既有国际规则、通过技术创新将合规力转化为产品力，也要立足我国强大的绿电与制造供应链优势，积极参与全球碳因子与底层标准的制定，推动零碳电力与绿色供应链的国际互认。
研讨结束后，主办方还宣布启动“CLI气候领导力计划”暨全球优秀案例征集活动。该计划将遴选在“气候与能源协同”领域具有前瞻性与实践示范意义的典型案例编入年度报告，并计划于2026年11月在土耳其安塔利亚举行的COP31联合国气候变化大会官方边会上向全球发布，集中展现中国企业的绿色低碳转型成效。
会议最后，与会专家与企业代表前往北京龙德缘电力科技发展有限公司进行实地参观考察，现场观摩并深入了解了龙德缘智能微电网系统的运行机制与技术示范成果。本次实地考察通过“理论研讨与实景体验”相结合的方式，展示了分布式能源的高效利用与智慧管理，为中国企业落实微电网脱碳实践与绿色供应链转型提供了宝贵的现场经验。
