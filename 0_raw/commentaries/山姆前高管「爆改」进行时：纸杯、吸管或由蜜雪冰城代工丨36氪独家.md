# 山姆前高管「爆改」进行时：纸杯、吸管或由蜜雪冰城代工丨36氪独家

此前有消息称，离开山姆中国首席采购官职位后，张青已于近期加入博裕资本，担任运营合伙人，并将参与博裕与星巴克中国合资公司的业务运营。
据36氪独家了解，张青由博裕主管国际消费项目的高管亲自引入。虽在合资公司尚无正式职位，但张青近期开始规划星巴克供应链改造的相关战略，并频繁参与星巴克中国的高管会。
2025年11月，博裕资本以约40亿美金估值，出资约24亿美元，收购星巴克中国60%股权，双方成立合资公司共同运营星巴克中国业务。星巴克中国是博裕今年最重视的消费项目，星巴克的改造则是博裕当下最关切的事情。
据36氪了解，张青空降并火速上岗，与星巴克中国改造进度不如预期有关。一位接近该收购案的人士告诉36氪，签署合约时，基于不更换现有管理团队的前提，博裕曾承诺星巴克总部三件事情：加快上新速度；实现产品降价；加速开店，扩充至2万家门店。
在双方的对赌协议中，也包含了明确的业绩对赌条款，如“营收复合增速”和“门店扩张”：增速方面，如果低于GDP+2%，星巴克有权溢价8%回购股权，超额完成则额外收取2%的管理费；门店方面，未来每年需要净增约1200家。
成立合资公司后，星巴克不再披露据中国业务的具体数据。据36氪了解，在降本的目标之下，星巴克中国门店数量经历了一番调整，在刚过去的财季（5月-7月）里首次出现了负增长。此外，星巴克中国的营收增速也没有明显增长。
为了拉动业绩，星巴克中国CEO刘文娟上半年做了许多尝试：
一、亲自带队研发新品，主推高蛋白拿铁，渗透健身场景，以期拉动销售。此外，尝试年轻化，效仿瑞幸，联名泡泡玛特旗下的潮流IP MOLLY，在150家主题门店推出“MOLLY爱的这杯”软雪星冰乐及限定周边。
二、推动线上订单的系统化，比如将多个渠道的数据打通，此前星巴克的会员数据是无法多平台共享的，如果会员在淘宝闪购、微信小程序等三方渠道下单，积累的星星将无法同步至星巴克官方账户里，这导致用户在使用星星兑换饮品时较为不便。
三、裁员和降低人工成本，比如取消14薪、修改员工合同，除店经理以外的大部分员工改为兼职合同、取消部分带薪假期。
据36氪了解，以上动作有一定的引流和降本效果，但对星巴克中国大盘整体的增长贡献较为有限。
一位前星巴克高管对36氪评价：“Molly（刘文娟）是比较稳健的职业经理人风格，但星巴克需要的是更彻底的改革。”36氪此前曾报道，刘文娟过去的成绩之一是数字化和打造线上零售业务，包括即时零售业务（啡快和专星送）和星巴克自营的线上商店：这一策略使星巴克的线上订单一度超过50%，但外卖业务也造成客单价和利润率的下降。
内忧外患之下，博裕对张青委以重任，对星巴克进行供应链改革，同时在门店运营层面提效，都是为了寻找更优的成本模型，以适应下沉年代消费市场发生的诸多变化，更好的应对竞争。
36氪此前曾报道，星巴克的单杯成本是瑞幸的1.5-2倍，一个重要原因就是供应链成本较高。36氪从星巴克供应链相关的多位人士处获悉，张青的改革涉及供应链的各个方面，包括寻找国内头部的优质供应商，加速本土化。这意味着，星巴克的牛奶、咖啡豆、烘焙和周边产品或将迎来全新的面貌。
与国外主力产品是星冰乐不同，星巴克在中国最畅销的产品和瑞幸一样，也是拿铁，所以牛奶的成本是否能压下来很关键。36氪了解到，除了制作冰镇浓缩的冰博克牛奶不会更换，脱脂牛奶、纯牛奶和燕麦奶都有可能更换供应商。
星巴克中国此前没有采购独立权，均包含在星巴克全球采购体系内，后者有一套严格准入体系，也拥有长期的固定合作伙伴，比如燕麦奶只用国际知名品牌Oatly，但这也导致成本较高。
星巴克中国的咖啡豆可能也不再与全球供应链绑定，转而更多使用国产咖啡豆供应商。36氪此前曾报道，由于昆山烘焙工厂仍归属星巴克全球，生产成本很高；上游豆子也由全球总部采购，运输费用昂贵，风味也会受到影响。
另外，星巴克的高毛利很大一部分来自杯子、包袋等周边产品的高销售。据了解，张青团队也在接触新的供应商，这意味着毛利还能有一定的提升空间。
不过由于零售业务早已出售给雀巢集团，比如瓶装咖啡、薄荷糖等包装商品，这仍然属于星巴克全球的管辖范围，本次供应链改革将不会涉及。
上述知情人士告诉36氪，这一系列措施若能按部就班落地，星巴克的供应链成本能降低30%-40%。一位接近星巴克供应商称：“张青的规划很清晰，但改革供应链挑战巨大。”
张青在供应链改造上颇有经验，曾在山姆有过许多成功的尝试。例如山姆和蒙牛的合作，一度在供应商圈子被奉为美谈。一位山姆供应商曾告诉36氪，在张青主导下，山姆联手蒙牛开发了MM鲜牛奶（山姆会员店自有品牌Member's Mark旗下的乳品系列），并给与最大程度的引流帮扶，至今该产品都是山姆MM系列的王牌产品，而蒙牛选择给山姆贴牌也是基于山姆强大的产品销售能力。星巴克或许也有机会复制类似的成功案例。
对星巴克中国而言，另一个重要的变化是门店运营层面的改革。
星巴克目前的策略是一边调整直营店，关闭低效率门店，一边尝试以特许经营的方式加速扩张门店。一位星巴克的员工称，特许经营门店在一二线城市的郊区和中大的城市都会覆盖，也会有一些特殊点位，比如景点、各类会场。但寻找合适的特许经营合作方也并非易事，据36氪了解，星巴克中国目前仍在接触中。
张青还主张推行物料的标准化使用，减少浪费和损耗。过去，星巴克为了鼓励门店员工创造性，一定程度上给予店员DIY饮品的空间，但这也导致杯损率超过10%。
在经历了长达半年的调整和等待，星巴克中国迎来了新的操刀者，这个曾经的咖啡王者在经历时代巨变和新的资本操盘后，能否得到新的发展机遇，很大程度上取决于新来者的改革能否奏效。
