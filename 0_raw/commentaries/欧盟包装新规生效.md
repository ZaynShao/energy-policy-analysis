# 欧盟包装新规生效

欧盟包装新规生效，降低环境污染和健康风险。
欧盟出台的商品包装新规12日起正式生效，以减少包装废弃后所致环境和健康风险。
欧盟希望到2030年将废弃包装的总量较2018年减少5%，到2040年减少15%。为实现这一目标，欧盟规定从2030年起，生产商和进口商须确保使用尽可能少的包装，新鲜农产品的一次性塑料包装将被禁止。
在回收环节，所有包装必须实现“经济上可行”的可回收利用，一次性塑料饮料瓶须含有一定比例的回收塑料。为促进循环使用，可重复使用包装将从2029年2月起加贴清晰标识，与一次性包装明显区分；针对塑料瓶和易拉罐的押金返还制度也将在未来几年内逐步推行。
新规还对包装中“永久性化学物质”含量设限，并要求制造商必须提供信息以配合相关部门溯源调查。
“永久性化学物质”主要是指全氟和多氟烷基物质（PFAS），广泛应用于工业生产及消费产品，包括纺织品、消防泡沫、医疗器械、涂料、个人护理产品、建筑材料等。研究人员认为，某些PFAS可能与多种健康问题相关，包括癌症风险增加、胆固醇水平升高及免疫系统受影响等。
据悉，近年来，受网购和“即买即走”消费模式推动，欧盟包装垃圾总量大幅增加。欧盟统计局数据显示，欧盟人均每年产生约180公斤包装垃圾。上述包装垃圾中，约35.3公斤是源自化石燃料的塑料，2023年仅有42%被回收利用。有欧洲官员称，包装材料约占欧洲塑料消费总量的40%，加剧了欧洲经济对石油供应的依赖。
欧盟官员表示，对不合规产品，成员国将优先采取警告而非处罚措施，给企业留出整改时间。今年晚些时候，欧盟委员会将就统一标签展开磋商，进一步便利消费者参与垃圾分类。
