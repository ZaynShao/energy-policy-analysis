# 每周AI信息参考：国务院：支持采购大模型、智能体服务

**01  国务院：支持采购大模型、智能体服务  
**国务院4月21日发布《关于推进服务业扩能提质的意见》。其中提出，加快软件和信息服务创新发展。软件领域，深入实施“人工智能+”行动，加快智能编程工具研发使用，支持采购大模型、智能体服务。加强基础软件生态、开源社区建设。优化智慧视听系统生态。信息传输领域，适度超前建设移动物联网。发展卫星互联网应用服务。数据和信息技术领域，深入实施工业互联网创新发展工程。推进工业数据筑基行动，培育数据合作联合体，建设一批高质量行业数据集。发展数据标注、认证等专业服务，探索建立分类分级的数据确权、评估、定价机制。**02  DeepSeek-V4预览版上线，实现国产算力跑国产模型**4月24日，DeepSeek-V4预览版上线并开源，推出旗舰版（Pro）和轻量版（Flash），两个版本均支持100万tokens超长上下文及非思考模式、思考模式。V4-Pro参数总量1.6万亿，激活参数490亿；V4-Flash参数总量2840亿，激活参数130亿。DeepSeek-V4开创了压缩稀疏注意力（CSA）、重度压缩注意力（HCA）两种新型注意力交替构成的混合注意力机制，在Agent能力、世界知识和推理性能上实现国内与开源领域领先水平。该模型已适配华为昇腾、寒武纪等8种国产AI芯片，标志着国产大模型在前沿能力迭代、推理成本优化与国产算力生态适配上取得阶段性突破。**03  腾讯阿里字节布局3D世界模型与空间智能**腾讯4月16日发布并开源混元3D世界模型2.0（HY-World 2.0），切入物理世界的3D数字化需求。该模型可理解文本、图片、视频等多模态输入，实现3D空间的自动生成、重建与模拟，支持Unity、UE等游戏引擎对接。阿里巴巴ATH事业群同日推出开放式世界模型Happy Oyster（快乐生蚝）。该模型基于原生多模态架构，可生成动态三维环境，契合影视制作、游戏开发场景需求。4月23日，字节跳动Seed团队发布3D生成大模型Seed3D 2.0，推动3D生成从单体模型向可交互、具身智能场景级构建演进。**04  OpenAI发布GPT-5.5和Images 2.0**4月24日，OpenAI发布GPT-5.5。该模型强化了智能体编程、计算机使用、知识处理等企业级基础应用，以及数学运算、早期科学研究能力。OpenAI称，GPT-5.5擅长编写和调试代码、在线搜索、分析数据、创建文档和电子表格、操作软件，以及在不同工具间灵活切换直至完成任务。有科技自媒体称，GPT-5.5标志着AI从问答工具向自主完成复杂计算机任务的代理系统全面演进。在此之前，OpenAI于4月22日发布了AI生图工具ChatGPT Images 2.0，首次内置思考能力，新增联网检索功能，单次提示最多生成8张图像。**05　谷歌云发力构建企业AI操作系统  
**4月22日，在谷歌云年度大会上，谷歌云推出Gemini企业级智能体平台（Gemini Enterprise Agent Platform），该平台在Vertex AI基础上扩展而来，增加了智能体集成、安全防护、DevOps、编排调度等多项新功能，旨在为企业构建管理AI智能体的中枢系统。谷歌CEO托马斯·库里安（Thomas Kurian）称，企业AI已走出试点实验阶段，全面落地的关键在于统一技术栈，把计算、网络、安全、数据引擎与应用平台端到端打通，最大化释放企业AI价值。Gemini Enterprise现已演进为端到端系统，旨在充当连接企业数据、人员与目标的纽带，将原本割裂的流程整合为智能工作流。谷歌云将这一愿景定义为“智能体驱动型企业”（Agentic Enterprise）的蓝图。

人民网、传播内容认知全国重点实验室****智能产品**“初芯”智能体平台：集大模型应用、知识管理、智能开发于一体，具有意识形态安全、数据隐私保障、一站式零门槛、赋能深度场景优势，智能体可用于智能传播、智慧舆情、文旅健康、生活服务等各类场景。主流价值语料库：赋能大模型价值观对齐。优选入库9600多万篇基础语料、39万对问答语料、500多万对图文语料，已在一批主流大模型厂家得到应用验证。人民智媒大模型：面向党政服务、媒体服务的大模型应用基座。基本解决大模型政治方向、舆论导向、价值取向、事实幻觉等问题，能够协助党政机关、企事业等单位构建各类模型。“写易”智能创作引擎：面向公务人员、媒体从业者、国企管理者等用户，提供智能写作、智能审校、写作素材知识库调用等服务。“自在”心理疏导大模型：提供心理疏导、情绪管理、亲子交流和家校共育等服务，已上线国家智慧教育公共服务平台。校园端支持家校心理数据统计与筛查分析。人民审校和内容风控大脑：提供时政信息表述审校、综合信息审校等内容安全服务，支持文本、图片、音视频等多模态内容审校，可在内容发布前辅助审校，也可在内容发布后开展多平台巡查和风险筛查。语料社区：致力于打造共创共享的全模态AI语料生态平台，打通语料采集、标注、应用全流程链路，旨在破解高质量中文语料不足和共享难等问题，为人工智能产业发展构建安全、开放的数据基石，促进区域文化数字化建设，助力区域内机构实现语料资源互补互通。“初见”智能体：汇聚三甲医院专家科普以及国家卫生健康委、体育总局推荐的体重和健身知识，提供健康体重管理建议和多元健身课程，是一款简单实用的健康体重管理助手。AI经贸文旅智能体：形成平台、数据、算力、算法、模型、智能体“六位一体”创新架构，提供多语种智能翻译服务，实现政策智能查询、智能商贸匹配、智能展销、智能行程规划等应用，满足经贸文旅领域多维度需求。已在广西桂林、宁夏银川落地。智能硬件“AI之眼”：集成麦克风、摄像头等传感器，面向文博智能导览、户外活动和运动场景，实现多模态交互、智能讲解、导航导览三大核心功能。人民数据确权“三证”：通过108项数据确权实质性审查，为符合审查条件单位颁授“数据资源持有权证书”“数据加工使用权证书”“数据产品经营权证书”，支持快速融资。**来源**｜人民网研究院
