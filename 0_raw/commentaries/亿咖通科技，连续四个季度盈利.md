# 亿咖通科技，连续四个季度盈利

加入供应链产业群，请加微信gasgoo88，出示名片
盖世汽车获悉，亿咖通科技（纳斯达克股票代码：ECX）日前发布2026年第二季度未经审计财报。数据显示，亿咖通科技当季总营收达到2.25亿美元，同比强劲增长45%。同时，其经调整后的EBITDA（税息折旧及摊销前利润）实现50万美元，这标志着其已连续四个季度达成整体盈利。
图片来源： 亿咖通科技
从收入结构看，作为核心支柱的商品销售收入录得1.96亿美元，同比增幅达50%，成为驱动总营收增长的关键引擎。盈利质量的提升同样突出，亿咖通科技本季度毛利率较去年同期大幅提升9个百分点至19.8%，带动毛利润同比飙升165%，显示出业务规模效应与产品附加值提升的双重正向作用。
业绩的显著改善，很大程度上得益于高价值产品出货结构的战略性优化。本季度，亿咖通旗下的安托拉®与派克®解决方案合计出货量在公司总出货量中的占比跃升至42%，而去年同期这一比例仅为20%。其中，安托拉®系列出货量同比增长52%，派克解决方案出货量同比增幅更超过20倍。
在推进现有业务增长的同时，亿咖通科技在战略布局上亦动作频频。报告期内，其完成了对Flyme软件业务的协议收购，旨在强化车载操作系统与软件平台的自研能力，为软件定义汽车提供更完整的解决方案。此外，其与TPK合作开发的ORCA激光雷达平台也取得阶段性进展，预计将于2028年实现海外量产。
客户合作与项目储备方面，亿咖通科技同样展现出良好的发展势头。第二季度，其成功助力4个汽车品牌的9款新车型实现量产上市，并新增33个车型项目定点。截至6月底，其技术解决方案已累计搭载于全球超过1200万辆汽车之上。
