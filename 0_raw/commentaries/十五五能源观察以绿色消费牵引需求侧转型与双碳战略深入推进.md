# 十五五能源观察|以绿色消费牵引需求侧转型与双碳战略深入推进

消费是“十五五”规划的核心关键词之一。在国际环境复杂多变、国内经济结构调整与新旧动能转换的宏观背景下，坚持扩大内需成为国家重要战略基点，“大力提振消费”也被列为建设强大国内市场的首要任务。“居民消费率明显提高、内需拉动经济增长主动力作用持续增强”成为“十五五”时期我国经济社会发展的重要目标之一。

  

**消费：撬动经济增长与规模化减排的关键支点**

  

  

消费既是国家经济增长的重要驱动力，也是实现大规模减排的重要突破口。需求侧解决方案是实现《巴黎协定》气候目标战略的关键组成部分。联合国环境规划署（UNEP）报告指出，家庭消费所产生的碳排放约占全球总排放量的三分之二。政府间气候变化专门委员会（IPCC）在第六次评估报告中首次纳入了需求侧减排的章节。报告指出，通过需求侧的缓解措施以及服务提供方式的创新，可使终端用能部门的全球温室气体排放量到2050年减少40%至70%。国际能源署（IEA）《2050年净零排放路线图》中提出的净零排放情景表明，到2030年，社会行为的改变将贡献17亿吨二氧化碳当量的减排量。此外，需求侧解决方案还兼具显著的社会、环境和经济协同效益。与多数供给侧技术相比，需求侧解决方案通常伴随更少的环境风险，有助于更好地维持地球边界（planetary boundaries）。

  

**在中国经济迈入140万亿元关口，“双碳”战略深入推进、各行各业加速转型的背景下，以绿色消费促进产业变革将大有可为。**鉴于中国庞大的人口基数和消费市场规模，消费端不仅是排放的重要来源，更是影响生产结构和供给方向的关键变量。“十四五”时期，我国消费市场规模稳居全球第二，社会消费品零售总额先后突破40万亿、50万亿元，绿色消费市场规模也逐步扩大，展现出强劲的增长势头和巨大的发展潜力。

**推动绿色消费的重要意义**

  

  

以绿色消费作为关键抓手，通过需求侧转型牵引产业高质量发展，将有望形成“以绿色消费牵引绿色供给”的乘数效应，从而加速市场化、规模化减排进程，对于实现长期气候目标、推动经济社会绿色低碳转型具有重要意义。将节能、减排与低碳等要求融入消费决策，将需求侧选项转化为产业转型动力，有助于培育产业新动能。需求侧转型所形成的“拉力”与供给侧技术创新的“推力”形成合力，可共同推动产业加速转型升级，在供需两端形成“需求引领供给、供给激发需求”双向互促的良性循环。与此同时，通过价值链传导实现绿色溢价的分散吸收，也有利于产业链整体实现协同升级。从“十四五”时期数据来看，绿色消费在食品、汽车和家电等领域的拉动效应最为显著，有助于快速带动市场扩容与技术迭代，并进一步强化企业在低碳设计、绿色制造及全生命周期碳排放管理方面的能力。

**通过推动绿色消费，积极为消费转型创造条件，提升公众在碳减排行动中的参与度与行动力，有助于促进社会绿色生产生活方式的形成。**“十四五”期间，我国大力实施消费品以旧换新政策、开展绿色供应链建设、健全绿色循环回收体系。2026年1月，商务部等9部门联合发布《关于实施绿色消费推进行动的通知》，围绕健全绿色消费激励机制，提出7方面20条具体举措，涉及产品供给、消费模式、循环回收等多个环节。“十五五”时期，美丽中国建设的首要系列目标明确为：“绿色生产生活方式基本形成，碳达峰目标如期实现，单位国内生产总值二氧化碳排放降低17%，清洁低碳安全高效的新型能源体系初步建成”。为了实现这一目标，我国以鼓励节约、政策激励和引导全社会参与为关键发力点，将在“十五五”期间加快构筑促进公众绿色生活方式形成的政策体系和长效机制。

**推动绿色消费从“政策驱动”向“市场驱动”转变**

  

  

消费转型是一个由个体行为、社会文化、制度环境、商业模式与技术创新等多维度因素共同驱动、相互作用的系统性过程。这一过程既依赖于制度体系的不断完善，也离不开绿色产品标准等市场基础设施建设的健全、市场激励机制的优化、以及绿色产品和服务供给能力的持续创新。单一的信息倡导或轻推式干预，往往难以对消费端产生持续且显著的影响。关键在于通过系统性变革重塑消费决策情境，例如借助标签化信息、绿色默认选项、社会规范传播以及价格信号等多元机制的协同作用，将外部引导逐步转化为内生动力，从而有效放大政策工具的综合效果，推动消费模式向绿色低碳方向实现规模化转型。

从实践来看，我国已在多层面展开探索，推动绿色消费的市场化支撑体系加快成形：

  

- 

在绿色消费市场基础设施建设方面，我国正加快构建绿色产品标准标识体系。“十四五”期间已累计发布绿色产品评价标准40项，能效、水效标准66项；出台《能源效率标识管理办法》《水效标识管理办法》；先后发布18批共47类能效标识产品目录，备案企业超过2.6万余家、备案产品型号达400万个。进入“十五五”时期，我国将在现有碳足迹管理体系基础上，进一步健全完善绿色产品标准体系，明确到2027年制定出台100个、到2030年制定出台200个重点产品碳足迹核算规则标准，为绿色消费提供更加坚实的支撑。

  

- 

在市场化激励机制方面，我国持续深化以碳普惠为核心的实践探索。近年来，各地围绕个人碳账户与碳普惠机制开展了多种形式的试点。以浙江、武汉等地的碳普惠平台为例，这些平台依托数字化技术，将个人的低碳行为转化为各类权益，并与消费优惠、金融激励等实际应用场景相结合，初步形成了从行为引导到价值反馈的闭环机制。“十五五”时期，我国将进一步探索建立线上线下通兑通用的绿色消费积分体系，持续激发公众践行低碳生活方式的稳定动力。

  

- 

在服务供给创新方面，绿色消费的新业态、新模式和新场景加快涌现。通过节能改造、绿色采购和资源循环利用等举措，绿色商场、绿色饭店、绿色餐厅等实践快速推进，推动传统服务业向绿色低碳方向转型升级，生态旅游、零碳旅游等绿色消费新业态、新场景不断兴起。二手商品流通也正从过去的“节约型选择”，逐渐转向兼具绿色属性、个性与数字化特征的新型消费模式，日益成为循环经济体系中的重要一环。

  

**引导全社会参与 **

**加速形成绿色生活新风尚**

  

  

推动绿色生产生活方式系统性变革，离不开政府、企业、消费者等多元主体的共同参与。在此过程中，应充分发挥不同消费群体在需求侧转型过程中的主体作用，尤其注重培育和激发青年群体在推动绿色消费、发展循环经济以及引领生活方式改变中的关键作用。“十五五”规划明确提出要拓展政府绿色采购的产品范围和规模，这将为引导全社会绿色消费起到明确的示范作用。

  

研究显示，不同收入群体在消费与排放贡献方面存在显著差异，未来有必要进一步探索差异化的政策工具和经济激励机制。与此同时，应尤其关注青年这一最具潜力的行动主体。一方面，青年群体数量庞大，是未来消费结构与生活方式的塑造者。另一方面，青年对可持续发展议题的关注度普遍较高，具备较强的消费创新意识和数字传播能力，是创新理念与社会行动的重要力量。相关研究也表明，青年群体在绿色消费认知与实践意愿方面普遍高于其他年龄群体，是连接传统产业转型与新兴业态培育的重要桥梁。

**在上述背景下，近年来，落基山研究所在推动青年参与绿色低碳行动领域开展了一系列实践，从不同层面探索了青年创新与行动倡导的多元路径。**在海南自贸港，落基山研究所与合作方携手举办了国际青年创新创业大赛，聚焦绿色发展与创新实践、激发青年群体参与零碳转型的积极性。在“2023零碳使命国际气候峰会”上，发起“我是零碳未来人”行动倡议；在2024年全国生态日山东活动中，参与发布《青少年“零碳岛”建设烟台宣言》；在BEYOND Expo2025亚洲拉丁美洲科技论坛上，发布“零碳青年”绿色发展行动倡议，并邀请青年影响力人物王俊凯出演倡议影片，借助其公众影响力，进一步扩大议题传播范围，凝聚青年共识，提升社会关注度，激发青年群体在零碳行动中发挥更积极的引领作用。
