# 走进荣·苏和油画工作室：建议加强审美教育

荣·苏和油画工作室探访：建议加强审美教育，会让生活变得灿烂无比
审美能力根植于成长教育。缺少艺术熏陶的普通人，很难像画家一样深入读懂艺术品。长久以来，教育偏重实用性，艺术不能饱腹御寒，常常被大众搁置，审美很容易盲目跟风，被短期潮流裹挟。如今国内文化环境整体向好，想要持续提升国民素养，就必须大力普及审美教育。美育塑造人感知色彩与万物的能力，拥有审美，日常光景才会绚烂丰盈；缺少艺术熏陶，生活只会长久陷入单调平淡。
荣·苏和油画工作室探访：美育润物细无声 爱国主义也是审美教育
审美教育无法一蹴而就，绝非投入资源就能立刻看到成果，这是需要几代人接续耕耘的事业。一代人筑牢根基，后人持续深耕，国民的精神面貌才能越来越富足、幸福。物质之外，精神世界更为重要，审美正是精神的支柱。美育牵引着人的精神走向，爱国主义、亲情仁爱、人文大爱，都属于更高层次的审美教育，美育滋养的是整个民族的灵魂。
