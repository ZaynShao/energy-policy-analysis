# 内蒙古通辽：立即成立追责问责调查组

停业、拆违、追责，内蒙古推进重大事故隐患整改。
8月19日，总台报道了中央安全生产考核巡查组在内蒙古赤峰、通辽等地开展的明查暗访中，发现的燃气、消防等领域重大事故隐患。
内蒙古自治区党委、政府高度重视，自治区安委办对曝光及反馈的问题隐患，实行全程跟踪督办，确保整改闭环。同时，坚持举一反三，推动进一步压紧压实安全生产责任，全面排查整治同类风险，坚决防范遏制事故发生。
收到整改通知后，通辽市立即成立重大事故隐患追责问责调查组，制定专项整改方案，督促各属地政府压实责任、有序推进整改。同时，依法依规对涉事企业及责任人实行“一案双罚”，并在全市通报，对相关监管部门和责任人严肃追责问责。涉事液化气站被责令停业整顿，私拉电线已全部拆除，电动车停放区迁至站外安全区域，气瓶按待检、不合格等类别分区存放，每个气瓶均贴有检验标签和追溯二维码。经逐项复核，所有隐患已整改到位。当地同步开展燃气厂站专项排查整治。
通辽市山水工程建设项目因施工现场存在安全隐患被责令停工整改。属地主管部门及建设施工单位迅速压实整改责任，实行“问题清单、责任清单、整改清单”闭环管理。整改后，科尔沁草原山水林田湖草沙一体化保护和修复工程现场安全警示标识完备，材料堆放规整，电梯井及临边位置加装标准化防护栏杆和安全防护网，脚手架全面排查加固，办公区与施工区实现物理分隔，所有隐患已整改到位。
