# 引领小微“大时代”，天合富家携“富盈”生态开启V100计划

一座城市的屋顶，可以承载多少能源未来？
作为全球数智能源引领者，天合富家给出的答案是，每座城市的小型工业厂房、商业网点、公共机构建筑、农业设施、乃至别墅及住宅等，皆是小微分布式光储的典型应用场景。未来，每个屋顶都可以成为一座小型绿色电站，由此筑牢能源转型金字塔的底座。
8月18日，佛山，“小微聚·大时代”——《中国小微分布式光储发展白皮书》发布会暨天合富家V100计划启动仪式上，天合富家联合行业力量发布的白皮书，首次明确了“小微分布式光储”的系统性定义，一套基于小微分布式的系统性打法正式亮相，从硬件到软件、从开发到运营、从融资到交易的富盈AI⁺新生态就此开启。
5000亿赛道启幕，小微光储打开增量新空间
行业各方对“小微分布式光储”的聚焦，绝非偶然。
继136号文发布以来，新能源全面市场化带来的振荡尚未平息，政策与市场组合拳又持续打开新的空间。一方面，“装机即收益”的红利期已然终结，“运营价值优先”的逻辑推动规模扩张转向运营深耕；另一方面，分布式光伏80%接入限制的松绑，叠加配储经济性显著改善、虚拟电厂国标实施在即等背景，分散的小微资源迎来全新价值出口。数据更为直观——截至今年上半年，全国分布式光伏累计装机576GW；预测到2030年，该数字有望达到1000GW，其中超过三成为小微分布式项目。
在天合富家总经理金锐看来，《白皮书》的发布可谓恰逢其时：“正是在这样的背景下，天合富家联合行业力量，首次对‘小微分布式光储’进行了系统性定义，为行业提供统一的基础沟通框架，为政策制定者提供分类管理依据，为金融机构提供差异化产品设计基础。”
根据定义，小微分布式光储具备三大核心特征：
装机边界明确划定在单体装机容量400kW以下
坚持自发自用、就地消纳的核心原则
根据实际资源与用能条件灵活配置储能。
按此范畴，以预测数据为基础，2026—2030年，小微分布式将保持年均30GW以上的装机增长。“这意味着，五年新增市场规模将超过5000亿元，这是下一个十年最值得深耕的产业赛道。”金锐表示。
前景广阔，挑战也不容回避。天合富家战略发展部负责人沈超坦言，小微分布式光储赛道快速扩容，但整体仍面临资金获取、风控管理缺失、专业能力不足、交付保障薄弱、并网政策复杂、后期运维缺位、收益核算不透明等多重核心痛点。这些痛点从项目开发到后期运营贯穿全链路，若不能有效攻克，将直接制约市场的持续增长。此外，小微分布式光储市场的区域分化特征明显，各地形成了差异化的发展逻辑，找准适合自身的商业模式至关重要。
四方共赢生态圈，直击行业痛点的“富盈”解法
看起来美、做起来难，有没有一套解决方案能够真正击中核心要义？会议现场，天合富家副总裁、户用BU负责人杜东亚进行了拆解与破局。
小微工商业市场呈现的四个特征——客群广泛、总量庞大但高度分散，业主决策对投资回报极为敏感，市场驱动力由政策转向市场，以及渠道为王——叠加前述核心痛点，恰恰为有准备的玩家打开了广阔的市场切入点。
“天合富家的破局之道在于，构建一个平台、渠道伙伴、资本和业主的四方共赢生态圈。在此，每个角色各司其职、各取所需。企业业主提供屋顶，渠道伙伴负责开发交付，金融资本提供资金，而天合富家作为平台，提供产品、AI中台、品牌和助融服务，成为整个生态的核心枢纽。”杜东亚表示。
在这个生态中，天合富家的自我定位是“小微分布式光储标准引领者、AI数智化运营商、原装光储系统供应商、绿色金融连接器、全生命周期增值服务商”，旨在为生态伙伴提供全链路价值赋能。
本次会议正式发布的第一个核心概念——“富盈AI⁺ 生态”。这一生态的架构可以概括为：以户用光伏代理商体系为渠道底座，以“富盈”AI数智化平台为技术引擎，以“平台+代理商+资本+业主”四方共营为机制内核，用标准化产品、增值化服务、透明化数据、平台化风控，破解小微工商业分布式光伏批量化落地的行业难题。
敢于直击核心痛点的底气，则与富盈AI⁺的支撑密不可分。深度融合人工智能与小微工商业场境匹配，富盈AI⁺中台构建了从“前端获客-智能评估-快速测算-助融服务-施工管控-智能运维-能源管理-运营增值”的全链路数字化闭环。其中包含的12大功能模块，覆盖资信评估、秒级收益测算、智能图纸设计、项目全流程数字化管控，较使项目前期风险筛查效率大幅提升，测算显示可降低项目违约风险约60%。
千亿赛道邀约，并肩共建小微光储生态新格局
本次会议重磅发布的第二个核心概念——“1+X+O”战略，据天合富家户用营销中心负责人李强介绍，不仅夯实了小微分布式业务底座，也在为整个行业提供全新范式。“1”代表户用光伏从单一卖电站升级为“硬件电站底座”；“X”包含从小微工商业到储能、充电，再到分布式算力等多元场景，探索更多能源应用价值；“O”则是AI驱动的全周期运营增值，依托天盈AI与天益AI两大核心技术“双脑”，覆盖运维、电力交易、碳资产管理等持续收益。这意味着，当渠道伙伴从“安装队”进化为“运营商”，天合富家的小微分布式光储生态真正具备规模化复制的根基。
一溪不载千帆，百川方成大海，小微分布式光储的爆发不可能靠企业单打独斗，万木争荣才是山林气象。这也是天合富家联合多方生态伙伴共同发布白皮书的深层逻辑——构建一个开放、协同、共生的小微光储生态圈。为此，天合富家将在全国率先遴选100家具备战略眼光的渠道伙伴，“V100招商计划”在发布会上正式启动。
先破解小微分布式批量化落地的行业难题，再为渠道伙伴提供全方位赋能。打破传统模式，天合富家为渠道伙伴提供品牌赋能、原装系统设备包、助融服务、标准化云管理平台、开发赋能工具包、运维/能管平台、以及绿电交易和碳交易等增值服务。以负荷消纳为王、以光储融合破局、以智能运维保障、以聚合交易增值、以资本杠杆增效，最终目标就是实现“伙伴赚到钱、业主省到钱、资本敢投钱、企业共发展”的新生态。
为满足不同需求，天合富家还提供了五大差异化路径，适配不同资金实力和战略诉求的渠道伙伴，包含富业模式（业主自投）、富商模式（代理商投资EMC）、富融模式（第三方投资EMC）、富合模式（合资EMC）、富享模式（五年送电站）五大模式。在此过程中，补齐渠道伙伴的专业短板，从而打造出可被批量复制的标准化模式。“无论哪种类型的渠道伙伴，无论面对哪种类型的业主，我们都有相应的合作模式来匹配，这也为规模化、标准化开发市场提供了坚实基础。”杜东亚表示。
随着“V100计划”的启航，小微分布式光储有了更清晰的坐标，从“统一认识”走向“行动落地”。天合富家正以开放共赢的姿态，助力合作伙伴持续升级进化——这是一场从“能源消费者”到“能源产消者”的社会角色重塑，未来将成为中国能源转型最真实的注脚。
