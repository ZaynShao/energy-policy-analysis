# 工业级磷酸一铵 | 工业一铵稳居高位 成本倒挂+需求刚性 后市或再迎窄幅上涨

当前73%工业级磷酸一铵价格处于近三年高位，目前市场主流均价参考6900-7100元/吨，较2026年初累计上涨500元/吨，涨幅7.6%左右。当前市场核心格局呈现“成本高位支撑、企业生产承压、价格高位坚挺”的特征，市场供需维持紧平衡，低价流通货源偏紧，高价成交以刚需小单为主。

从成本来看，磷矿石、硫磺（折算为硫酸—一吨硫磺生产3吨硫酸），合成氨三大核心原料为主，硫磺作为本轮成本上涨的核心变量，受地缘冲突、国际航运影响，截止目前长江港颗粒硫磺现货价格6300元/吨，较年初涨幅51.8%，按生产一吨工业级一铵消耗1.77吨硫酸来算，仅硫磺一项工铵成本增长1268.5元/吨，叠加磷矿石高位，合成氨补涨，工铵成本端构成强支撑，企业普遍面临成本倒挂，工厂生产承压。

供应端来看，主流工厂开工暂稳，在成本承压下，个别企业存停产或降负操作，截止本周，行业整体开工率维持在67.16%，较上周下浮1.45%。企业多采取限量接单，执行前期订单发运为主，市场低价货源偏紧，持货商挺价惜售。

需求端，自2022年新能源汽车渗透率提升带动磷酸铁锂需求爆发，叠加农业水溶肥等领域需求增长，形成供需缺口，2022年度农需占比约24.65%，新能源需求占比约为16.9%，随着新能源领域的快速发展，2026年新能源产业，工业级磷酸一铵作为核心原料，需求保持刚性增长，成为核心支撑。占比涨至52.77%，春耕周期内，农业端水溶肥推广及种植结构优化，带动工业级一铵需求，采购维持刚需，占比32.25%，整体维持“农业刚性托底、新能源稳步增量”的双轮驱动格局，但在工业一铵高价影响下，当前市场接受度有限，下游采买维持小单刚需补库为主。

整体来看，工铵在成本支撑强劲下，价格下行空间被锁，仅能随原料小幅波动，供应端在成本倒挂下，开工或有下滑趋势，现货减少，工厂挺价惜售，需求端农需春耕即将收尾，但新能源刚需持续，整体需求韧性仍强，暂无下降可能。短期工铵仍处于成本强支撑，供应紧平衡格局，工铵价格高位僵持，但不排除窄幅上涨可能，后市还需重点关注原料价格，下游需求及企业政策情况。
