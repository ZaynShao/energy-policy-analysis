# 突发！乌克兰发动袭击

乌军袭击俄船只和炼油厂。
乌克兰武装部队总参谋部12日在社交媒体发文称，当天凌晨，乌军袭击了俄罗斯萨马拉州塞兹兰炼油厂，此外，乌方还袭击了俄方在亚速海水域的10艘油轮和4艘渡轮。
乌武装部队总参谋部称，袭击导致塞兹兰炼油厂爆炸起火，受损情况正在核实中。该炼油厂是俄罗斯石油公司旗下最大炼油厂之一，去年8月曾遭乌军袭击。
乌方还说，乌军对亚速海水域的10艘油轮和4艘渡轮实施打击，俄方使用这些油轮和渡轮运输石油和后勤物资。
近期，乌军在亚速海水域接连对俄油轮等目标发动大规模袭击，试图进一步削弱俄作战能力。
