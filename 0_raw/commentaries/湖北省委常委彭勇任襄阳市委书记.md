# 湖北省委常委彭勇任襄阳市委书记

彭勇任湖北省襄阳市委委员、常委、书记。
据湖北发布微信公众号消息，8月23日，湖北省襄阳市领导干部会议召开，宣布襄阳市委主要领导职务调整的决定。省委决定，彭勇同志任襄阳市委委员、常委、书记；吴海涛同志不再担任襄阳市委书记、常委、委员职务，另有任用。
公开资料显示，彭勇，男，汉族，1970年11月出生，大学学历，工商管理硕士，中共党员。
彭勇曾任中国华能集团有限公司重庆分公司副总经理，中国华能集团清洁能源技术研究院有限公司副总经理，华能集团技术创新中心副主任，中国华能集团有限公司人才基地建设管理中心主任，华能置业有限公司总经理、党组成员，华能黑龙江发电有限公司执行董事、党组书记，北方联合电力有限责任公司总经理、党委副书记等职，于2020年7月由内蒙古华能热电股份有限公司董事长调任中国大唐集团有限公司副总经理、党组成员。
2023年12月，彭勇调赴湖北履新，后获任副省长。2025年2月，彭勇任湖北省委常委、省委秘书长。
