# 行业要闻 | 全国首批电碳算协同撮合交易在南方电网开展

记者从南方电网公司获悉，5月19日至30日，全国首批电碳算协同撮合交易在南方电网陆续开展。来自贵粤鲁三地的高校和算力企业，首次通过电碳算协同交易形式，实现闲置算力资源与实际需求一键匹配、即时成交，标志着我国绿色算力服务迈入“按需取用、即用即付”的新阶段。
记者获悉，该批次交易中，算力购买方为贵州大学、山东金现代信息产业股份有限公司、法狗狗（深圳）科技有限公司，出售方为贵州联通。算力需求方只需通过南网在线APP电算协同专区，在手机上发布需求、时限和预算，后台即可调用电碳算协同运营平台，将卖方闲置算力盘活为可调节柔性负荷，根据电价波动动态编排算力任务，实现供需智能匹配。用算方轻点鼠标即可“一键下单”算力，无需包年租用，按任务、按量灵活取用。
“相比市场流行的按单块GPU实际使用小时数计费的‘卡时租赁’模式，‘算力撮合’模式则更以‘算力任务’为核心，实现资源按需调用、按实际使用计费，推动用算业务从‘固定租用’向‘按需取用’转变。”南方电网贵州电网公司电力交易中心副总经理朱刚毅说。
法狗狗（深圳）科技有限公司总经理庞雨秾表示，“通过撮合交易，企业能用更少、更清洁的电办更多的算，灵活便捷，更贴合企业经营实际。南方电网电碳算协同运营平台，就像一个能统筹调配算力的资源池。手里有富余算力的企业可以直接上架共享，有算力需求的单位，照着自己的任务多少、用时长短和预算多少，直接按需挑选下单，就能轻松拿下高性价比算力服务。”
南方电网电算工程公司电碳算协同运营平台项目专家商莹楠表示，算力是数字经济的坚实骨架，电力是产业运转的鲜活血脉。我们在算力骨架和电力血脉之间搭建了一座智能“桥梁”，打通了电力与算力的数据壁垒，让难以直观感知的算力运转情况，转变为一目了然的用电、碳排放统计数据，让电价波动、绿电资源成为调配算力的“指挥信号灯”，科学引导算力资源流向性价比更高、绿色属性更强的区域。
南方电网数字电网集团（贵州）有限公司相关负责人表示，“随着平台的进一步深化应用，可有效优化供给侧的算力成本结构，最终为算力需求方提供更绿色、普惠的算力服务。”（来源：中国电力报 李东海、黄雅熙、刘思捷、杨培文）
