# 全网群嘲的《牛来》反向爆火，热搜第一，股民追捧

猫眼数据显示，该片上映10天，累计票房仅为7700余元（截至14日16时45分），总观影人次200余人，单日最高观影人数仅十余位，创下本年度院线动画电影票房最低纪录。然而8月15日，《牛来》综合票房及场次突然暴涨，截至发稿，累计票房已超22.8万元，单日暴涨超2860%，总票房（含预售）已达43.2万元。
有网友发帖称，建议明年大年初一安排《牛来》，替换《熊出没》。还有网友评论称“看这电影的是不是都是股民”。
据了解，《牛来》主创仅两人，出品方为大连璟园文化影视传媒有限公司，该公司的法定代表人就是该片导演兼编剧、配音演员。公司曾用名为“大连璟园装饰工程有限公司”，主营室内、外装饰装修工程设计、施工等业务，2021年7月才更名转型涉足影视行业。
导演的一位亲友表示，这是导演和他妈妈两人，亲力亲为创作的电影。用时5年，没请团队，全靠手搓。亲友说，最感动的是导演的妈妈，他们是一个普通的家庭，没有投资，就自己做。她支持孩子，不只是动动嘴皮子，而是边学边练，亲身投入电影创作，片尾曲都是妈妈自己唱的。她从精神到行动上，都在支持自己的儿子。
看过的网友调侃：AI盛行的时代，还有这种水平的人坚持手搓，勇气可嘉。
据荔枝新闻报道，记者多次尝试联系导演采访，均未获应答。影片发行方在接受记者采访时谈到，导演是熟人朋友，当初看到成片时曾劝导演别上了，但他坚持想上，“好不容易做出来了，就帮他上一下院线。”
