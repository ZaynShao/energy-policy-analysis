# 解读《碳达峰碳中和综合评价考核办法》

文|朱朝勇 张引璐 王芬芬 石晨曦
4月23日，中共中央办公厅、国务院办公厅印发《碳达峰碳中和综合评价考核办法》（以下简称《考核办法》）。《考核办法》首次以党内法规形式，对科学有序开展碳达峰碳中和综合评价考核工作作出系统部署，明确了谁来考、考核谁、考什么、如何考等要求，为全面实施碳排放总量和强度双控制度提供了有力保障，对引导和督促各地区党委和政府树立和践行正确政绩观，推动经济社会发展全面绿色转型具有重要意义。
《考核办法》构建了“5+9”综合考核指标体系，涵盖5项控制指标和9项支撑指标，形成了“硬约束”与“软引导”相结合的制度框架。
5项控制指标包括碳排放总量、碳排放强度降低、煤炭消费总量、石油消费总量、非化石能源消费占比，均为对实现碳达峰目标起决定性作用的指标，构成了“总量约束、强度约束、结构约束”的刚性底线。9项支撑指标包括节能、工业、城乡建设、交通运输、公共机构、碳排放权交易等重点领域具有代表性且对“双碳”目标实现具有支撑作用的指标，将“双碳”考核要求从宏观目标延伸至关键领域，是保障“双碳”目标落地的基础支撑项。
《考核办法》将“碳排放总量”和“碳排放强度降低”设定为控制指标，将此前能耗双控的关键指标“单位地区生产总值能源消耗降低”调整为支撑指标。这意味着碳排放已经成为最终约束目标，而降低能耗是减排的一项重要手段。这将倒逼各地加快优化能源消费结构，大力发展非化石能源，用同样的能源消耗实现更少的碳排放，推动节能与降碳协同增效。
《考核办法》明确了综合评价考核的主体、对象、内容和程序，体现出组织架构集中化、考核流程标准化、结果约束刚性化等机制特征，为科学有序开展考核、推动“双碳”目标实现提供了制度保障。
考核主体打破单一部门主导模式。《考核办法》明确“党中央集中统一领导，由中央组织部统筹指导，由国家发展改革委会同有关部门实施”，打破了以往由单一部门主导模式，构建了中央统筹、国家发展改革委组织实施、专业部门分工评价、各地方落实、社会监督的多层级考核体系。
考核对象扩展至省级党委和政府。《考核办法》明确被考核对象为各省（自治区、直辖市）党委和政府，由以往能耗双控时期的省级人民政府扩展至省级党委和政府，同时强调“实行党政同责、一岗双责”，意味着省级党委和政府对碳达峰碳中和负有同等责任，进一步压实了地方责任。
从目标分解方式来看，《考核办法》不再沿用此前“自上而下”方式，而是采用“上下结合”方式，即由各地根据实际情况，因地制宜提出本地各项指标目标，由党中央、国务院审核校准后，作为开展考核评价的依据。这种方式突出了分类施策，兼顾了各地区的功能定位和资源禀赋，体现了对刚性约束和弹性调控的统筹兼顾。
考核流程规范清晰。《考核办法》细化了考核实施路径，规范了考核评价全链条管理，明确构建“地方自评、部门评价、综合核验、综合评定”的闭环考核流程，各环节权责清晰、层层递进，有利于保障考核工作的规范高效运行。
考核评价转向“目标达成判定”。《考核办法》明确了考核方式和数据来源，不再沿用此前“赋值打分、汇总排名”的方式，而是根据年度目标完成情况实行“达标与不达标”判定，并在此基础上进一步分为“优秀、合格、不合格”三个评价结果等级，强化了考核的刚性约束与政策导向。数据来源以国家统计体系为主，确保了数据的统一准确。对于统计数据缺失的情况，允许采用碳市场数据及各部门统计、调查数据作为补充，以提高数据的完整性，避免因数据缺失影响评价结果。
考核结果分级处置并嵌入干部管理体系。《考核办法》建立了与考核结果挂钩的差异化激励约束机制，根据考核评价结果，对“不合格”地区、“合格”但部分指标未达标地区及“优秀”或单项指标突出的地区，实施差异化管理。同时，《考核办法》明确审定后的考核结果将抄送中央纪委国家监委，并作为地方奖惩、干部考评的重要参考，标志着“双碳”工作成效正式纳入干部政绩评级体系，将显著增强地方党委及政府推进“双碳”工作的政治自觉，激发其内生动力。
考核引入动态监测预警机制。《考核办法》进一步引入动态监测预警机制，在原有年度考核基础上，由国家发展改革委、国家能源局等部门定期监测全国及各省（自治区、直辖市）碳排放量、煤炭石油消费、新增用电量、新增清洁能源电力消费量等关键指标，及时识别偏离目标趋势，对相关地区提醒预警，实现提前干预。这一机制有效推动“双碳”工作管理从事后评价转为事中管控与事后评价相结合，大幅提升考核的科学性、时效性与约束力。
一是地方发展逻辑或发生改变。《考核办法》确立“党政同责、一岗双责”原则，将考核对象同步覆盖省级党委和政府，考核结果直接嵌入干部管理体系。这一制度定位将“双碳”工作从相关部门的业务工作提升为党委和政府的重大政治责任。在这一导向下，地方政府的发展逻辑也将进一步从“以经济发展为中心”转向“经济与减排双约束”。同时，碳约束在项目审批、产业布局及投资决策中的权重也将提升。
二是企业减排责任将全面压实。地方政府的刚性考核压力将逐级传导至各类市场主体，显著影响企业的发展与转型。电力、钢铁、建材、化工、有色等高耗能行业是重点减排对象，碳排放管控水平直接关系企业合规经营、项目审批、政策支持，绿色低碳产业将获得更多政策与资源倾斜。这将倒逼企业加快转变发展理念，重构生产经营模式，主动开展碳排放管理，推进节能降碳技术改造。唯有主动适应变革、积极践行低碳发展的企业才能在新的考核制度下赢得可持续发展空间。
三是碳市场的资源配置作用将进一步发挥。《考核办法》落地实施后，碳排放双控约束由指导性要求全面转为刚性约束，碳减排成为地方政府必须抓实抓牢的重点任务。在政策倒逼下，地方政府将推动辖区内碳市场重点排放单位主动谋划减排路径、精准实施减排措施，改变以往被动合规履约的管理模式。长期来看，《考核办法》实施将显著增强碳市场在引导资源配置、激励技术创新、压实减排责任等方面的关键作用，有利于提升碳市场活跃度、流动性与定价效率，最终实现有效市场和有为政府协同发力。
四是绿电绿证消费需求有望增长。非化石能源消费占比被纳入核心控制指标，成为地方考核评价的重要依据，将有效推动绿证、绿电消费需求增长。一方面，工业、城乡建设、交通、公共机构等重点领域将加速推进终端电气化改造，用电需求将持续扩大，带动绿电消纳规模提升。另一方面，绿电绿证将成为企业降低自身碳排放的重要路径，或将推动重点用能单位开展常态化采购，推动绿电绿证市场与碳排放双控制度深度衔接，助力碳达峰目标如期实现。
五是碳管理业务需求有望增长。随着《考核办法》正式落地，自上而下的考核压力会带动各类市场主体主动开展碳管控，碳管理市场将迎来扩容。碳排放核算与核查是保障数据真实性的基础，碳咨询规划为政府和企业提供专业降碳方案，碳资产运营助力企业减排成果转化为经济效益，碳监测依托技术实现实时预警、杜绝“纸面降碳”，碳培训则夯实行业人才基础。各类业务协同发力，将推动碳管理行业潜力持续释放。
