# 16万亿韩元！三星SDI拟建全固态电池/磷酸铁锂储能电池/钠电池产线

「
储能与电力市场
」
获
悉，
7月3日消息，外媒报道，
三星SDI
计划到2040年投资总额25万亿韩元，用于布局下一代电池技术。其中，
16万亿韩元
（约合人民币708.8亿人民币）计划在韩国蔚山市建设
全固态电池以及用于储能的磷酸铁锂电池和钠电池产线。
另外9万亿韩元将用于天安工厂，将其打造为下一代电池研发制造中心。
具体来看，三星SDI计划于
2027
年率先在
韩国本土实现固态电池商业化落地
，成为首家完成该技术商业化的本土电池企业，为抢占全固态电池市场先发优势。
图源：网络
看个广告休息一下
据公开信息，三星SDI已敲定在蔚山布局钠离子电池产线，该项目此前处于量产可行性评估阶段。业内预测，继磷酸铁锂电池之后，钠离子电池将作为下一代持续提升市场渗透率的储能电池。三星SDI重点瞄准AI数据中心不间断电源赛道，将钠离子电池作为该场景的核心配套产品进行布局。三星SDI将依托蔚山基地完成多款下一代电池的量产工艺验证，待规模化生产方案成熟后，再逐步向全球各地工厂复制产能、拓展海外市场。
另有消息，三星SDI已与电池模组厂商
新普科技
签署约2万亿韩元电芯供货协议，产品将用于AI数据中心BBU备用电源场景。受益于全球数据中心投资热潮，公司圆柱电池出货量持续走高，产线产能利用率维持高位。
