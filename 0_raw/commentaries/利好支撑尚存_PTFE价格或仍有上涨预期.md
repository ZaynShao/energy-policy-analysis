# 利好支撑尚存 PTFE价格或仍有上涨预期

【导语**】**2026年一季度，聚四氟乙烯（PTFE）市场告别2025年的疲软阴霾，迎来“先抑后扬”的强势反转。在原料成本激增15%的硬约束与供应端扰动频发的双重共振下，市场价格重心从3.9万元/吨一路上涨至5万元/吨附近，创出近期新高。

**一、市场复盘：从“先抑后扬”到“两极分化”**

从2025年至2026年的PTFE悬浮中粒市场价格走势来看，市场呈现出显著的“先抑后扬”与“两极分化”特征。2025年市场整体表现疲软，价格重心长期处于低位徘徊。期内虽有小幅波动，但缺乏明显的上涨动力，显示出需求端的乏力与供需关系的宽松。进入2026年，市场格局发生根本性逆转。一季度价格便开启了强势拉升模式。年初受供应不稳定担忧扰动，而后又受到成本端强力支撑，PTFE悬浮中粒价格（以AAA级为例）从1月份的39000元/吨低位起步，一路震荡上行。特别是进入3月份后，上涨势头显著加速，最高触及50000元/吨的水平，不仅迅速扭转了去年的颓势，更创下了近期新高。

**二、核心驱动：成本激增15%，重塑价格底部**

2026年一季度以来，聚四氟乙烯（PTFE）市场最核心的定价逻辑已由供需博弈转向成本驱动。上游原料价格的持续攀升，正在从根本上重塑PTFE的价格体系。据卓创资讯最新数据显示，进入4月份以来（截至4月16日），PTFE的理论生产成本已攀升至37089元/吨的高位。回顾今年1月，这一成本仅为32348元/吨。短短不到四个月的时间内，理论生产成本绝对值增加了4741元/吨，增幅高达15%。在成本持续走高的倒逼下，生产企业让利空间被大幅压缩，甚至逼近盈亏平衡线。为覆盖成本、维持正常运营，企业不得不持续上调报盘价格，这种由成本驱动的涨价具有极强的刚性。随着报盘价格的持续上移，市场价格重心也随之稳步上行，形成了“成本推涨-报盘上调-重心抬升”的完整传导链条。

**三、行情推演：供应隐忧叠加成本倒逼，合力支撑多轮上行**

1-4月份，PTFE市场经历了一轮由供应扰动到成本倒逼的连环上涨行情，卖方主导权逐步强化。1月末，受氟聚合物生产原料引发剂面临更替问题的影响，市场对未来供应稳定性产生担忧，生产企业挺价惜售情绪迅速升温，报盘价格借机进一步上调。春节假期结束后，随着产业链各环节陆续复工复产，下游需求有序恢复。前期上调的高价报盘在实盘中得到顺利落实，各家企业接单情况理想，库存压力较小，因此市场中无明显让利意愿释放，价格坚挺态势得以巩固。而后受中东局势扰动，上游原材料价格出现明显上涨，叠加运输费用等物流成本的增加，生产企业成本压力陡增。在成本倒逼与供应收紧的双重作用下，卖方挺价意愿进一步增强，市场价格重心随之持续上移。

**四、后市展望：短期卖方挺价心态坚挺，新单价格重心或存上移预期**

综合市场情况来看，聚四氟乙烯（PTFE）市场正处于“强成本支撑”与“弱需求承接”的激烈博弈阶段。在供应与成本端，支撑逻辑依然坚挺。原料端方面，无水氢氟酸价格仍有上涨预期，三氯甲烷价格维持高位维稳，成本底部支撑持续增强；供应端方面，卖方延续挺价惜售策略，低库存运行使其在价格谈判中占据主动，短期内难有明显让利空间。然而，需求端的制约因素也不容忽视。随着价格攀升至高位，下游业者畏高情绪渐起，采买心态趋于谨慎。目前市场主要以刚需采买为主，大规模补库需求难以释放，这在一定程度上限制了价格进一步明显上涨的空间。基于此，预计下半月聚四氟乙烯悬浮中粒（AAA级）价格或仍有小幅探涨预期，运行区间或在49000-52000元/吨。
