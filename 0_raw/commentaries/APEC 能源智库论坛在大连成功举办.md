# APEC 能源智库论坛在大连成功举办

2026年8月20日，APEC能源智库论坛在大连成功举办。本次论坛由中国石油集团经济技术研究院（国家高端智库）主办，全球化智库（CCG）协办。作为2026APEC中国年能源领域重要系列活动之一，论坛以“平衡安全与转型：构建亚太稳定繁荣的能源未来”为主题，来自17个APEC成员经济体，以及中国参与APEC能源合作伙伴关系网络成员单位、国际组织、智库和科研机构共计100余位代表齐聚一堂，共谋亚太能源合作。
论坛致力于搭建高水平能源智库交流平台，凝聚各方智慧，促进APEC各经济体的深度对话与务实合作。中国国家能源局国际合作司副司长熊敏峰，中国石油集团原董事长、世界石油理事会原副主席周吉平，中共大连市委常委、市政府副市长邱宝林，APEC能源工作组主席单卫国依次致辞。嘉宾们表示，能源是亚太经济繁荣的基石，面对当前复杂多变的国际能源形势，亚太各经济体应通过机制化合作，进一步消除壁垒，统筹能源安全与绿色转型，加强关键核心技术协同创新，推动区域能源市场互联互通，筑牢开放韧性的亚太能源保障体系。
论坛上，中国石油集团经济技术研究院执行董事、院长陆如泉发布《中国-APEC能源合作启新程：以能源合作携手共促亚太共同繁荣》报告。
陆如泉表示，中国-APEC能源合作成果显著，覆盖传统能源、新能源、电力等多个领域，贯通投资、贸易、基础设施等全链条，形成供需互补、绿色赋能、互通稳链、协同善治的能源合作格局，为区域能源共同安全与可持续发展积极贡献“中国力量”。务实能源合作深度契合各经济体共同利益，是凝聚多边共识的重要领域，中国坚持互利共赢、求同存异的合作理念，与APEC经济体在包容共赢、多元转型、互联互通、机制赋能等领域形成了广泛共识。报告提出了中国-APEC能源合作未来愿景，倡议各经济体守牢安全韧性、践行普惠包容、加速低碳转型、坚持创新驱动、深化协同共治，共筑普惠、创新、协同的亚太能源共同体。
主旨研讨环节
太平洋经济合作理事会联合主席、中国太平洋经济合作全国委员会会长詹永新，巴布亚新几内亚国家能源局局长罗纳德·梅克塔，国际可再生能源署国家合作与伙伴关系司副司长毕努·帕尔坦，亚太能源研究中心（APERC）主席入江一友发表主旨演讲，从政策引领、区域协同、绿色转型等多维度研判亚太能源发展趋势。
专题研讨环节
二十余位嘉宾聚焦能源安全与区域韧性、能源技术与创新合作、多边合作与智库网络建设三大议题展开热烈讨论。与会嘉宾一致认为：在全球能源转型加速推进的时代背景下，需强化区域能源系统韧性建设，亚太地区应发挥引领作用，以务实合作回应时代课题；要加大氢能、储能、CCUS等领域前沿技术联合研发与成果转化力度，推动多经济体实现联合研发、协同制造、标准互认，加快亚太整体能源转型步伐；区域内智库应构建常态化政策协同对话机制，畅通数据共享通道、共建跨区域知识平台、设立滚动研究清单，为APEC能源议程提供更具针对性的政策建议与可落地的行动方案。
中国石油集团经济技术研究院副院长朱颖超作闭幕总结发言。他表示，本次APEC 能源智库论坛研讨充分、务实高效，形成五方面重要共识：平衡能源安全与绿色转型、完善应急响应深化协同保障、构建开放包容的技术合作生态、发挥二轨优势助力科学决策、完善能源服务助推共同繁荣。下一步中国石油集团经济技术研究院将着力推动论坛实现常态化运行，努力打造成为服务APEC能源合作进程、推动亚太能源智库对话交流的重要平台。
