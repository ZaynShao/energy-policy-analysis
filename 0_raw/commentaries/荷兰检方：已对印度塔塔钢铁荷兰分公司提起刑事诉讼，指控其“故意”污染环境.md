# 荷兰检方：已对印度塔塔钢铁荷兰分公司提起刑事诉讼，指控其“故意”污染环境

印度塔塔钢铁荷兰分公司因污染环境被起诉。
荷兰检方8日宣布，已对印度塔塔钢铁荷兰分公司提起刑事诉讼，指控其“故意”污染环境。
检方调查发现，塔塔钢铁荷兰分公司位于阿姆斯特丹以西艾默伊登镇一座炼钢厂在防治环境污染方面“做得不够”，焦炉维护也不到位，且存在无证运营等违规行为，给周边环境和居民生活带来负面影响。
按检方说法，调查仍在进行，尚不清楚这家公司荷兰籍高管是否会被追责。
塔塔钢铁荷兰分公司当天回应说，“不认同”相关指控，表示近年来已大幅减排整改，且排放量符合标准，称荷兰检方“没有必要”针对“数量有限”的污染事件提起诉讼。
荷兰政府委托开展的研究显示，涉事炼钢厂是荷兰温室气体主要排放源之一，给周边居民带来健康问题。2024年，该厂曾因焦炉违规排污被荷兰有关部门“盯上”，一度面临关闭风险。
阿姆斯特丹地方法院定于11月20日就此案举行首次审讯。
