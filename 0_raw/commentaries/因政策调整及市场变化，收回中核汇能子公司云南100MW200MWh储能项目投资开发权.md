# 因政策调整及市场变化，收回中核汇能子公司云南100MW/200MWh储能项目投资开发权

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)  

储能与电力市场获悉，3月18日，泸水市发展和改革局发布关于收回泸水汇能新能源有限公司泸水市100MW/200MWh共享储能电站项目投资开发权的公告。  
公告显示，因国家政策调整及地方市场变化，泸水汇能新能源有限公司所涉泸水市100MW/200MWh共享储能电站项目尚未通过投资决策，无法按约定推进项目投资建设。  
经公司研究决定，现收回泸水汇能新能源有限公司上述项目投资开发权。公示期为3个工作日，公示期满无异议后，将严格按照规定选取新投资主体，同步协调做好项目转接，确保项目后续投资建设有序推进。  
据企查查显示，泸水汇能新能源有限公司是中核汇能有限公司的全资子公司。该公司注册资本100万元人民币，成立于2022年3月。![image](https://mmbiz.qpic.cn/sz_mmbiz_png/nJIHJiauQqnyEm6bXIOUbNTR51xADiaT0TxPFXiabmv2r21WmMODCelOVZNPFQptL5kpiaziavl88jv46TPDbMtRvVwGJ4VIaiaibBmwbePmgCj4nY/640?wx_fmt=png&from=appmsg)
