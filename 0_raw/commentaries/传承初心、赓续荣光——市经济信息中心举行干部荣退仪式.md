# 传承初心、赓续荣光——市经济信息中心举行干部荣退仪式

为传承弘扬老干部的优良作风与宝贵精神，推动初心使命薪火相传、事业荣光赓续不绝，7月23日下午，市经济信息中心举办“传承初心、赓续荣光”干部荣退仪式。中心领导班子成员、退休干部、各科室代表及年轻干部代表齐聚现场，共忆奋斗岁月，共话精神传承。
中心领导依次为朱向民、周祖发、张宏、李迎春、王建龙五位退休干部披上荣誉绶带，将沉甸甸的认可与敬意送到老同志身边；年轻干部代表手捧鲜花走上台前，向老前辈躬身献花，用最真挚的方式致敬老一辈奋斗者的坚守与付出。
在荣退感言环节，五位退休干部依次发言，深情回望了扎根岗位、与单位共成长的奋斗历程，分享了工作中沉淀的宝贵经验与人生体悟，向年轻干部传递殷殷嘱托、寄予深切期望。
随后，两位年轻干部代表依次作表态发言，纷纷表示，老前辈们身上的敬业精神、务实作风与扎实本领是最宝贵的财富，在今后的工作中将以老干部为榜样，主动传承优良传统，把老前辈的经验智慧转化为履职尽责的实际能力，在各自岗位上奋勇争先、不负期许。
座谈交流中，中心领导、各科室代表也畅所欲言，追忆共事点滴、畅叙同事情谊，在温暖的交流中凝聚起传承奋进的共识。
殷殷嘱托，砥砺奋进前行
中心主任陈涛在总结讲话中，向光荣退休的同志致以诚挚的祝贺和崇高的敬意，对大家多年来为中心事业发展付出的辛勤汗水与作出的突出贡献表示衷心感谢。他强调，老干部是中心发展的见证者、开拓者、建设者，他们积淀的优良作风与宝贵经验是推动事业前行的不竭动力。希望退休同志退休不褪色、离岗不离情，继续关心支持中心各项工作，常“回家”看看；同时勉励全体年轻干部要接过前辈的“接力棒”，传承初心、勇担使命，共同推动中心各项事业再谱新篇。
