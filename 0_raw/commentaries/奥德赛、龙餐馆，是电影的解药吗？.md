# 奥德赛、龙餐馆，是电影的解药吗？

截至8月14日，豆瓣8分以上的新片至少已有5部。沈腾迎来职业生涯最高开分，诺兰带着2.5亿美元的《奥德赛》和稀缺的IMAX规格入场，国产动画、成熟IP和超级英雄电影均未缺席。这并非今年的孤例。2025年暑期档同样高分片扎堆，8分以上院线新片达到了7部，头部影片平均评分处于近几年高位。大盘同样给出了积极信号。据官方及平台数据，今年暑期档票房与观影人次同比均小幅增长，分别达到了94亿和2.5亿人次（截至8月中旬）。愿意走进影院的人，比去年更多了。只是这份回暖还没有追上2023年的高点：那年暑期档最终票房突破200亿元，观影人次超5亿。8分仍是好口碑，明星仍有号召力，IP和工业规格也依然有效。变化在于，这些过去反复奏效的因素，如今越来越难稳定转化为大票房。即便明星、口碑、制作规格同时叠加，也未必能让一部电影从核心受众扩散至更广泛人群。从好电影到全民爆款之间的转化，变得更难预测。《奥德赛》《欢迎来龙餐馆》这样既叫好、又有卖相的电影，能不能成为电影的那味解药？现在或许还给不出答案。《奥德赛》正式上映之前，一位诺兰影迷坚信，这部电影在中国内地的票房一定能破10亿元。这种乐观并非没有理由。正式上映前，《奥德赛》已经连续两个周末在国内点映。首轮只开放北上广深部分IMAX影院，平均上座率高达94%；8月8日第二轮点映当天，它只拿到0.4%的排片，却贡献了8.8%的单日票房。中国电影博物馆IMAX GT厅的点映场，183元的电影票，经常几分钟内售罄。在二手市场，普通座位被炒到500元，中间的黄金座更是挂出1500元，溢价近十倍。罗永浩甚至在社交平台发文，代友出价2000元求购4张票。但正式上映后，首先被打破的不是票房纪录，而是部分影迷对票房的预期。截至8月14日，《奥德赛》上映前点映与预售票房已突破1亿元，但上映首日票房仅约5600万元，预测最终票房不足8亿元。这说明核心影迷的观影热情并没有扩散至更广泛的受众。IMAX厅和普通厅的上座率也差异明显。7亿多的预测票房不算太差，但一部几乎叠满了导演号召力、全球口碑、工业规格和IMAX稀缺性的电影，这个成绩，多少还是有些令人惋惜。《欢迎来龙餐馆》可能是今年暑期档最接近“天选爆款”的电影。文牧野导演，沈腾主演，点映三天票房过亿，豆瓣开分8.4，目前已经升至8.5。上映第四天，累计票房接近5亿元，猫眼专业版预测，其总票房在25亿元左右。放在今年暑期档，25亿元已经足以竞争冠军。但对沈腾这位个人主演票房突破400亿元的国民级“卖座王”而言，这部新片虽然拿下了他个人的最高口碑，但目前的票房走势并未展现出与口碑同步的爆发力。作为参照，沈腾参与的《你好，李焕英》，豆瓣开分8.1左右，最终票房54.13亿元；《满江红》开分8.0，拿下45.44亿元；《飞驰人生2》开分8.2，最终票房33.98亿元。当然，上述几部电影都有春节档加持。但即便只放在暑期档里比较，《欢迎来龙餐馆》目前展现出的爆发力，也很难让人联想到过去那些真正意义上的“奇迹”。2015年的《西游记之大圣归来》，从低排片一路逆袭，成为国产动画工业化的标志性事件；2019年的《哪吒之魔童降世》，则从一部动画电影不断扩散成全民话题，最终冲过50亿元。档期够长、观众够多，暑期档一直被认为是最容易发生逆袭的档期之一。一部电影只要口碑足够强，往往就有机会跑出一条上升曲线：核心观众先进场，口碑在社交网络扩散，更多路人被吸引进影院，排片随之上涨，票房继续反哺热度。《八仙！》豆瓣开分8.3，是今年表现最好的国产动画之一，截至8月12日累计票房约15亿元；《三国第一部：争洛阳》同样拿到8分以上，却一度上映两周，票房还徘徊在亿元线附近，最后退档；《去你的岛》开分8.0，也没有立刻把口碑变成同等量级的票房。一位业内人士此前对“定焦One”表示，过去，豆瓣8.0分本身就可以成为撬动票房的理由，但未来这条“金线”会越来越往上移。“金线”为什么会往上移？在一位资深电影制片人看来，原因很简单——让观众专门买一张票、花两个小时走进电影院，正在变得越来越难。现在的娱乐市场供给，随时随地，近乎无限。短视频十几秒就能提供一个笑点或反转，游戏、直播和社交平台持续制造即时刺激，AI又进一步降低了内容生产的成本。相比之下，看电影反而成了一种相对“重”的娱乐消费。观众需要考虑交通和场次，两个小时不能快进、不能倍速，再加上票价、餐饮，一次观影的时间和金钱成本都明显高于刷视频或追剧。这意味着，除了“好看”，还需要另外一个更明确的理由把观众从手机前拉进影院。今年暑期档的几部头部影片，恰好展现了几种不同的到场理由。《功夫女足》豆瓣只有6.4分，票房却超过22亿元，并在暑期档前半程长期领跑。它最大的招牌就是周星驰。对于大量普通观众而言，“周星驰新片”本身就是一个足够简单的大众消费入口。《奥德赛》走的是另一条路。影片在IMAX厅和普通影厅之间明显不同的热度，说明不少观众购买的不只是故事，也包括一种难以在家复制的观看方式。而且，对核心影迷来说，《奥德赛》更像一次带有仪式感的“朝圣”。因此，特殊影厅的IMAX票可以被炒到上千元。沈腾提供了最初的明星信用，文牧野提供品质预期；点映之后，8.4分以上的口碑进一步将明星驱动转化为情绪传播。观众进场不只是为了“看沈腾”，也是因为社交网络不断强化一个判断：这是一部既有娱乐性、又可能带来情绪共鸣的电影。明星、名导、口碑、稀缺性，仍能把电影做成档期里的头部，只是越来越难再往上走一步，变成全民向的爆款。没有这类标签的8分电影更难。《三国第一部：争洛阳》评分不低，但题材存在天然受众边界；《去你的岛》同样拥有不错口碑，却缺少周星驰、沈腾或IMAX这样能够在上映初期被普通观众迅速理解的消费标签。这种动员能力并非取之不尽。明星和IP会被反复消耗，特殊格式和高规格影厅能够制造稀缺感，却天然更集中于核心影迷和一线城市。今年较典型的案例是《给阿嬷的情书》。影片豆瓣开分9.0，之后一度升至9.3，进入暑期档后仍贡献了接近6亿元票房。现在，对于一部缺少明星、IP和工业奇观的影片而言，想单纯依靠口碑突破圈层，可能需要的已经不只是“不错”，而是接近9分的压倒性评价。当“到场理由”越来越难找，电影行业正在出现两种相反的方向。诺兰没有压低成本，也没有迁就流媒体观看习惯。相反，他拿出2.5亿美元，把一部近三小时的古希腊史诗全部用IMAX摄影机拍摄，大量采用实景、实船和物理特效。全球真正能放映70毫米IMAX胶片版本的影院只有约41家，稀缺的放映设备本身，也成了电影体验的一部分。截至目前，《奥德赛》的全球票房已经突破11亿美元。在很多从业者看来，这像是一次“电影性”的胜利——当观众越来越习惯在手机和电视上看故事，影院就必须提供别处无法替代的东西。他自己曾提到，《奥本海默》接近10亿美元的全球票房和随后的奥斯卡成功，“给了我选择”。环球影业愿意为《奥德赛》投入如此高的预算和制作周期，本身建立在诺兰过去二十多年积累的信用上。主演马特·达蒙也不认为这是一种正在回归的常规生产方式，如今几乎不会再有导演，以如此规模、不依赖绿幕完成一部史诗片。拍摄《奥德赛》时，他甚至把它当成“自己的最后一部电影”来对待。而且，这条路的结果，可能不是所有电影都越来越豪华，而是资源进一步向少数头部项目集中。过去两年，AI已经开始进入概念设计、分镜、特效和视频生成等环节。它最直接的意义，是把一部分过去昂贵、耗时的影像生产变得更便宜。就连马斯克，也宣称要用Grok Imagine重新拍一部《奥德赛》。对于越来越难靠票房覆盖成本的电影来说，降成本本身就是一种生存方式。过去只有大制作才能承担的视觉效果，未来可能由更小的团队完成；一些因为预算无法启动的项目，也可能因此获得机会。但AI解决的是“怎么更便宜地生产内容”，并没有解决“为什么观众要为这部内容走进影院”。恰恰相反，当内容越来越多、生产越来越快，“看到一个故事”的成本越来越低，影院电影面对的注意力竞争只会更激烈。今年《奥德赛》在中国宣传期间，一段没有讨论票房、明星甚至IMAX设备的采访意外出圈。播客主播仲树问诺兰：如果荷马是一个文明上升时代的吟游诗人，那么今天的诺兰，是不是一位“为迟暮文明歌唱的吟游诗人”？这句话之所以击中很多人，或许正因为电影行业也处在类似的过渡期。导演、明星、口碑和排片依然重要，却越来越难稳定地转化成票房；AI带来的低成本影像时代已经露出轮廓，但新的商业规则还没有真正建立。《奥德赛》最后，奥德修斯和珀涅罗珀离开伊萨卡，驶向夕阳。珀涅罗珀说，“文明会再次崛起。”奥德修斯接着说，“新的黎明终会照亮黑暗的世界。”对于今天的电影行业，这或许也算一个并不悲观的结尾。一个时代正在退潮，下一个时代会到来，只是还需要时间。
