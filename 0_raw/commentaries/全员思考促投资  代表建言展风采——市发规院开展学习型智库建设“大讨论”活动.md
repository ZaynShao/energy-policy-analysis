# 全员思考促投资  代表建言展风采——市发规院开展学习型智库建设“大讨论”活动

为推动落实“全员善思考、人人做研究”理念，市发规院聚焦“必须坚持投资于物和投资于人紧密结合”主题，开展为期1个多月的学习型智库建设2026年第一期“大讨论”活动，并于近日举办了优秀成果演讲分享会。委党组成员、院长陈晨出席会议并讲话，委机关党委、规划处、综合处、投资处负责人，院领导班子成员和全体干部职工参加会议。
陈晨院长从“为什么要开展‘大讨论’、此次‘大讨论’成效特点，以及下一步怎么做”三个方面作了讲话。他指出，智库要姓“智”，研究是我们院每个人职业生涯的第一生命。开展“大讨论”的目的，就是要在全院落实人人做研究的理念，发现一批有水平、有能力、有见地的年轻人，提升干部的思维深度和敏锐性，打破思维壁垒，开展跨领域、跨专业的研究。
陈晨院长认为，尽管是第一次举办，但这次整个活动准备充分、组织精心、有声有色，达到了全院人员研究能力的大摸底和大练兵的效果。他从审题、理解、分析、立意、论证、举措等6个方面，对思考交流材料进行了点评，指出此次43份思考材料，内容覆盖面广，事关杭州投资领域的方方面面；尤其是9名代表的发言，与市委、市政府重点工作进行了对接，有思想、有碰撞、有感悟。
陈晨院长强调，要尽快在全院形成共识，把“大讨论”活动固化下来，形成院学习型智库建设的重要载体。他要求下一步做好3件事：一是将这次活动的43份思考材料在全院共享，让大家相互学习、相互借鉴、取长补短。二是好中选优，从中精挑出6篇优秀成果汇编成册，报委领导参阅。三是策划举办第二次“大讨论”活动，围绕“服务业发展与改革”主题，沉下心、静下心，进行真思考，深琢磨，形成高质量交流文章。
会上，9名代表紧扣主题，依次作了演讲发言。大家表达顺畅、图文并茂、逻辑清晰、观点鲜明。
演讲结束，由委相关处室负责人组成的评委组，对代表发言情况进行了打分，评出相关奖项并现场颁奖。
