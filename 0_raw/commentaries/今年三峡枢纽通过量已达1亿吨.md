# 今年三峡枢纽通过量已达1亿吨

截至2026年8月13日0时40分，三峡枢纽通过量达1亿吨。
从长江三峡通航管理局了解到，截至2026年8月13日0时40分，三峡枢纽通过量达1亿吨。
其中，三峡船闸运行5863闸次，通过船舶21562艘次，通过量9727.6万吨；三峡升船机运行2557厢次，通过船舶2590艘次、旅客44.6万人次。共保障2846.8万吨民生物资、77.8万吨重点急运物资便捷过坝。
自2011年首次突破1亿吨大关以来，三峡枢纽年通过量已连续15年保持高位运行，且2021—2025年连续5年突破1.5亿吨，持续为长江经济带产业链供应链稳定、沿江地区民生物资保供及长江流域经济社会高质量发展提供了坚实支撑。
