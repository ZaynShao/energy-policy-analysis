# 0.83元/Wh，河北100MW/400MWh储能项目EPC中标公示

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)  

储能与电力市场获悉，3月16日，滦平周营子10万千瓦40万千瓦时独立储能示范项目EPC中标结果发布。  
  
中京建设集团有限公司中标该项目，中标价格33177万元，折合单价0.83元/Wh。工期/交货期为120天。  
根据招标公告显示，招标人为承德桂达科技有限公司。本项目位于承德市滦平县，建设1座电化学储能电站，容量为100MW/400MWh，主要由三部分组成，分别为储能系统、储能升压站、送出线路。  
具体建设规格如下：本储能电站共配置100MW/400MWh储能系统，储能系统共有1.25MW/5MWh储能单元80套，将上述储能单元划分为5个储能子系统，每个储能子系统由16个储能单元构成，1#-5#储能子系统容量为20MW/80MWh，本项目共有5回储能集电线路接入220kV储能升压站35kV母线侧。
