# 肇庆丨重点发展新能源汽车及零部件制造产业

肇庆市人民政府近日印发《肇庆市国民经济和社会发展第十五个五年规划纲要》，《纲要》明确“十五五”时期全市经济社会发展的指导思想、基本原则、发展目标和要求，谋划重大战略、部署重大任务，作为战略性、宏观性、政策性规划，是政府履行经济调节、市场监管、社会管理、公共服务和生态环境保护职能的重要依据，是未来五年市经济社会发展的宏伟蓝图和全市人民共同的行动纲领。
《纲要》明确：
加强新能源汽车及零部件制造产业强链延链：依托肇庆大旺新能源智能汽车产业城等重点产业载体，深化整车、“三电”系统、汽车电子、智能网联部件等关键领域研发制造，攻坚产业链核心环节，打造成为一流的新能源汽车制造基地。支持建设大型产业集聚区新能源汽车核心部件供给地。结合肇庆生态优势打造“绿色智能汽车”品牌标签，强化产业品牌与质量建设。拓展产业链延伸环节，推动新能源汽车及零部件制造产业与软件服务、汽车后市场服务深度融合。力争到“十五五”期末，新能源汽车及零部件制造产业产值突破1000亿元。
