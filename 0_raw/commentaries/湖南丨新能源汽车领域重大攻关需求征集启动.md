# 湖南丨新能源汽车领域重大攻关需求征集启动

一、重点领域
聚焦国家和湖南省重大战略，以补链强链延链为导向，重点围绕新能源汽车整车及动力电池原材料、新型动力电池、智能汽车底盘、智能座舱、轻量化车（机）身、车规级芯片、高效驱动电机电控电驱总成、高可靠性大功率充换电设备、汽车软件、车载功能器件、智能驾驶系统、智能远程操控系统等关键核心系统及零部件。
- 聚焦国家和湖南省重大战略部署，重点解决制约新能源汽车发展的重大技术难题，突破产业关键产品（技术）和共性技术。
- 技术指标（性能参数）达到国内外同类产品先进水平，能够实现国产化替代，或能填补行业空白，解决“卡脖子”问题。主要技术指标和产业化目标可量化、可考核，主要技术指标一般不少于5项。
- 市场用户和应用范围明确，产业化前景清晰，市场规模较大。
- 需求提出单位具有较强实力的研发机构和稳定的创新研发团队，在创新投入、商业模式、经营管理、市场推广等方面具备良好基础和较强优势。
- 需求提出对象为省内重点产业链链主企业、行业龙头企业、产业链关键环节企业、国家单项冠军企业、国家专精特新“小巨人”企业、国家技术创新示范企业，及以上企业牵头组建的创新联合体，或省级及以上制造业创新中心建设单位。
此次攻关需求征集将作为后续攻关榜单凝练及有关项目推荐的重要依据。
