# 河北邢台一锂电车间突发爆炸，事故原因仍在调查

「储能与电力市场」获悉，7月6日下午，河北省邢台市宁晋县万方科技产业园内一处锂电池生产车间发生爆炸事故，现场出现明显冲击波，周边建筑及民居受损严重。
据了解，宁晋县万方科技产业园聚集了北奥锂电、烁日、欧达等多家新能源企业。园区一期项目6个车间于2023年开园，二期项目8个车间正在规划中。当地政府工作人员透露，暂未收到人员受伤、遇难的上报消息。当地已成立专项调查组，针对车间爆炸诱因、生产安全管理等内容开展全面核查，事故具体成因、直接财产损失等细节仍在进一步调查核实中。
截至7月13日，宁晋县政府官方平台尚未发布本次事故正式书面通报，行业媒体及地方媒体报道信息均来源于现场走访、群众目击与相关部门口头回应。
