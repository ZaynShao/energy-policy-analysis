# 硫磺 | 山东液体硫磺市场强势上行后转弱 高位博弈下的拐点初现

**导语**

近期，山东液体硫磺市场经历了强势上涨后高位走弱的快速转变。行情转向主要因为地缘政治局势的转向、供需双方待市情绪、库存水平等多重因素的影响。整体看市场交投氛围由强转弱，库存承压下资源点出货增量，下游需求端则谨慎跟进，行情呈现高位弱侧运行。

山东液硫价格与镇江港主流颗粒价格对比来看，多数时间固体价格高于液体，清明节前液体市场一度冲高至6850元/吨，高出固体主流价400元/吨左右，然而节后市场却受国际局势缓和消息陆续走弱。

清明节前受多重利好因素共同提振，山东液体价格强势冲高。首先因地缘风险持续升级，硫磺供应紧缺预期加剧，港口资源暂不出货，地炼出货量也相对有限，整体供应紧缩。加上下游商户的积极运作，竞拍成交气氛火热，促成行情稳步上移，地炼成交价格上涨至6850元/吨附近。

节后山东液体硫磺市场强势上涨势头戛然而止，市场走势转为弱势震荡下行，首先价格高位透支需求，下游采购心态彻底转向谨慎。当山东液体硫磺价格突破 6800元/吨关口后，下游企业成本压力剧增，高价接受度大幅下降，整体交投气氛迅速转淡，竞拍积极性明显下滑。加之地缘政治风险降温，市场看涨预期快速消退。再有供应端惜售情绪松动，出货意愿逐步提升。截止目前，山东液体主流价格下滑至6500-6650元/吨。

需求方面：山东作为国内液体硫磺消费核心区域，下游硫磺酸、钛白粉、己内酰胺等行业刚需稳定。除东明旭阳装置节后停车检修10天左右，目前暂无过多明确停车检修消息释放，整体需求端较为稳定。不过市场价格处在下行通道，买涨不买跌为市场惯例，下游采购心态谨慎，刚需少量补库为主。

综合来看，山东液体硫磺市场先涨后弱的行情，是由于地缘政治冲突引发的供应担忧、供需紧平衡、市场看涨情绪共同推动价格快速冲高，随后在高价抑制需求、地缘风险消退、供应端松动的作用下，市场缓慢理性回归。

短期来看，山东液体硫磺市场将维持高位震荡弱稳运行态势。需求端来看下游谨慎采购交投偏弱气氛已经显现，业者观望情绪浓厚。供应方面近日炼厂清库现象明显，竞拍挂量处在增加，供应较为宽松。因此价格上行动力不足。后续需重点关注中东地缘局势变化、山东地炼竞拍成交与出货节奏、下游企业库存及采购意愿、进口硫磺到港量与港口库存变化等重要影响因素。
