# 交通部等部门：加强自动驾驶、车路协同等重点方向标准研制

标准化为交通运输发展提供统一规则、质量底线和协同目标，是支撑现代化综合交通运输体系建设的重要基础。根据有关文件，交通运输部、市场监管总局、国家铁路局、中国民航局、国家邮政局联合制定《综合交通运输标准化发展“十五五”规划》并于近日印发。
推动跨领域深度融合：公路沿线电动重卡充（换）电站、加氢站、车网互动相关标准，新能源重卡车站通信及新能源重卡和充换电设施技术、运营服务、安全检测与评估、智能充换电服务网络标准。
推动交通动力低碳替代：新能源汽车故障诊断、维修数据、维修服务要求；电动营运车辆动力蓄电池检测、更换、维修标准。
加快交通运输数智化升级标准专项行动：大通道货车、城市客车、接驳车自动驾驶运行服务相关标准；无人快递车技术标准；车路协同路侧设施、信息交互标准。
加快推进新能源汽车维修等标准外文版翻译。
加强自动驾驶、车路协同等重点方向标准研制。
