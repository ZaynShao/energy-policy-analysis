# 情报·锂电 | 国轩将美国小镇告上法庭索赔2370万美元，在北美打响“尊严与尊法”的保卫战

国轩将美国小镇告上法庭索赔2370万美元，在北美打响“尊严与尊法”的保卫战
情报焦点
新能源出海的浪潮中，我们见过强强联手的凯歌，却很少见到如此一地鸡毛的“退场大戏”。还记得此前备受瞩目、总投资高达24亿美元（约合人民币170亿元） 的国轩高科密歇根电动车电池零部件工厂项目吗？在经历了数年的政治拉锯、地方居民罢免官员、以及州政府撤回补贴等一系列魔幻操作后，这个一度被寄予厚望的超级项目已经彻底“停摆”。
但故事并没有结束。近日，国轩高科美国子公司（Gotion Inc.）正式向美国联邦法院提交诉状，要求违约的密歇根州绿色宪章镇（Green Charter Township）赔偿至少2370万美元（近1.7亿元人民币）的巨额损失！
“蜜月”变“战场”：一个被政客和罢免毁掉的24亿大单
把时间拨回2022年，当国轩高科宣布将在密歇根州大急流城附近的绿色宪章镇投资建厂，并承诺创造2350个高薪工作岗位时，密歇根州州长及当时的小镇管理层几乎是夹道欢迎，甚至批下了数亿美元的巨额财政补贴。
但随后，事情的发展逐渐走向失控。由于大选年地缘政治升温，国轩高科母公司的中国背景被当地部分保守派政客拿来大做文章。
2023年11月： 愤怒的当地反对派选民发起投票，竟然直接把当时投票支持国轩项目的小镇所有民选官员全部“罢免（Recall）”了。
2024年初： 带着“反国轩”口号上台的新一届小镇管理层，一上任就强行单方面撤销了之前与国轩签署的发展协议，甚至断掉了工厂急需的市政供水许可。
2025年底： 在地方经年累月的诉讼和反对声中，密歇根州经济发展机构（MEDC）最终也扛不住压力，直接宣布国轩项目因毫无进展而“违约”，取消了后续补贴。随后，州司法部长更是当起“债主”，要求国轩退还之前用于买地的2367万美元补贴。
索赔2370万！国轩的诉状揭开了美国地方的“双标”
眼看投资数年、花去无数心血和资金的项目在政治内耗中被活活拖死，国轩高科这次不再忍让。在向密歇根州西区联邦法院提交的最新修正诉状中，国轩不仅直指小镇新政府公然违反2023年签署的、具有法律效力的发展协议，更是将索赔清单一笔笔列了出来：
💸 管理和营销费用： 50万美元
🏢 行政、员工薪资及基础设施投入： 5600万美元
📐 建筑与工程设计费用： 730万美元
📉 以及未来预期利润的损失、天价律师费、和因小镇阻挠导致被州政府索要的2370万美元退款。
国轩的律师在联邦法院的文件中愤怒地表示：“小镇的行为不仅表现出对合同义务的持续违约，更表明在他们充满敌意的持续反对下，国轩任何试图推动项目前进的努力都变得毫无意义（Futile）。”
换句话说，国轩用事实证明：不是我不建厂，是你们新上台的官员为了政治私利，把我的路全部堵死了！
小镇慌了：怎么赔得起两千万？
国轩这记法律重拳，直接砸在了这个只有几千人口、预算本就捉襟见肘的美国小镇的“七寸”上。
面对随时可能到来的千万美元天价赔偿，绿色宪章镇现任的主管杰森·克鲁斯（Jason Kruse）在接受当地媒体采访时显得忧心忡忡。他坦言，为了应对国轩过去两年的起诉，小镇甚至不得不挪用了当地仅有的不到20万美元的大麻税收来支付律师费，许多本应开展的基础设施项目已经停工。
克鲁斯承认：“我们小镇靠着极其微薄的房产税和很低的州政府财政分成运作。如果法院最终裁定我们必须向国轩支付这2300多万美元的赔偿…我无法想象这个小镇该怎么撑下去。”
如果国轩胜诉，这个曾经为了政治正确而盲目排外的美国小镇，极有可能面临直接破产的窘境。
结语与出海思考
国轩高科在密歇根的这场跨国诉讼，是给所有出海的中国新能源企业上的一堂极其深刻且昂贵的法律与政治课。
它无情地戳破了某些西方市场标榜的“绝对契约精神”——在政治选票和地缘博弈面前，已经签署并生效的商业合同有时甚至不如一张废纸。但同时，国轩选择在联邦法院强硬起诉、索赔数千万美元的举动，也向外界展示了中资企业利用当地法律武器进行自我防御的果敢与智慧。
商业的归商业，政治的归政治。当政客用口号绑架经济时，最终买单的往往还是普通的当地纳税人。国轩高科能不能在这场天价索赔案中逆风翻盘？我们拭目以待。
