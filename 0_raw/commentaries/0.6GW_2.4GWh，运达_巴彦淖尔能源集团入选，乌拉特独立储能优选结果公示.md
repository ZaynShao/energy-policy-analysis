# 0.6GW/2.4GWh，运达/巴彦淖尔能源集团入选，乌拉特独立储能优选结果公示

优选方及优选项目的基本情况如下：
优选方：乌拉特中旗发展和改革委员会。
项目建设地点：乌拉特中旗境内。
项目接入：巴中500KV变电站。
项目建设规模：总规模60万千瓦/240万千瓦时，单个储能电站申报规模需大于等于20万千瓦/80万千瓦时。
技术类型：独立新型储能电站采用构网型技术，优先支持压缩空气、全钒液流、钠离子等技术路线，鼓励实施长时储能电站（时长4—8小时）。
