# 东莞丨规范功能型无人车道路测试与商业应用

为促进功能型无人车应用推广与产业发展，规范本市功能型无人车道路测试与商业应用工作，保障道路交通安全，依据相关法律法规，参考相关政策文件，结合本市实际， 东莞市工信局、公安局、交通局联合制定《东莞市功能型无人车道路测试与商业应用工作管理办法 (试行)》并于近日印发。
《办法》适用于在东莞市行政区域内开展的功能型无人车道路测试与商业应用。功能型无人车具备自动行驶功能，无驾驶人员、搭载自动驾驶系统，为低速电动轮式车辆，主要用于物流配送、环卫作业、安防巡逻等应用场景，包括低速无人配送车、低速无人环卫车、低速无人巡逻车等。
总则：明确办法的制定目的、适用范围、关键术语定义（功能型无人车、道路测试、商业应用、主体、安全员）、遵循原则，构建市联席工作小组的协同管理机制，明确各部门职责分工。
基本要求：规定开展道路测试与商业应用的主体、安全员及无人车车辆必须满足的硬性条件。强化主体责任与安全保障，要求主体具备民事赔偿能力、网络数据安全机制及风险应急预案；严格安全员资质；明确车辆技术标准（限速45km/h、双模式切换）及强制保险（不低于300万元）。
道路测试申请及审核：详细规定道路测试的申请材料、审核流程（初审、评审、发证）以及延期、跨省互认的简化程序。实施“申请-评审-通知书”的准入制度；建立跨省测试结果互认机制，降低企业重复测试成本；明确测试有效期及延期规则。
商业应用申请及审核：规定从道路测试迈向商业化应用的过渡条件、申请材料、审核流程及延期管理。设置“门槛制”，要求车辆完成规定时长（240小时/1000公里）的无事故测试后方可申请商业应用；采用与测试阶段一致的编码规则，实现车辆全生命周期管理。
路测试与商业应用管理：规范车辆运营过程中的动态管理，包括车辆增补、信息变更、运行规则、安全保障及违规处理措施。明确车辆路权规则（靠右行驶、限速、禁并排）；实施“一车一码”与车身标识管理；建立违规“约谈-暂停-整改-恢复”的闭环监管机制，对多次违规者终止资格。
交通违法与事故处理：明确发生交通事故时的责任认定依据、处理流程、赔偿机制及数据留存要求。事故处理遵循现行交通法规；实行“保险赔付+主体补足”的赔偿原则；建立严格的强制报告制度（严重事故1小时内报告）和事故“暂停”机制，要求主体保证数据原始性与可追溯性。
附则：说明封闭/半封闭场地的管理方式、车辆编码规则、办法解释权及施行日期。
