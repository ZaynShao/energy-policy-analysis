# 三条太空光伏技术路线，谁能叩开商业化大门？

****文|韩静****

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/MXc0xWvrXHfwSNJvCM30T2K1PG1C1VlibUkWGUXGYIne4uFPU6nm1qfibic2THQ9Uwa4sJdib7AnWFHfBFSoSLbn57ic9CMtVQaAMxAewB9pez3Q/640?wx_fmt=jpeg&from=appmsg)

3月14日，在首届上海商业航天大会暨展览会上展出的卷绕式柔性太阳翼。  

3月12日，2026年上海商业航天大会暨展览会在上海浦东国际博览中心举行，由中国航天科技集团上海航天技术研究院研制的多款新型航天产品集中亮相。其中，本届大会的“明星产品”之一，便是堪称卫星的“能量心脏”的卷绕式柔性太阳翼。  
据悉，卷绕式柔性太阳翼是新一代轻量化、高收纳比、高效率空间能源系统的代表。该产品搭配柔性伸展机构与高度集成化柔性薄膜基板，发射前可紧密收卷在直径小于100毫米的卷轴上，紧贴卫星本体。入轨后，依托储能伸展机构平稳展开，形成大面积连续发电面，如同一幅太空画卷徐徐铺展，实现从“极致收纳”到“高效供电”的无缝衔接。  
作为卫星的“能量骨架”，卷绕式柔性太阳翼需直面太空极端温差、高强度宇宙辐射、微陨石撞击等多重环境考验，而与之配套的光伏电池同样置身极端环境，对材料、结构与可靠性提出了极高要求，使得整体技术难度与系统复杂度呈指数级提升。  
在此背景下，太空光伏产业要实现真正意义上的产业化落地，需完成技术路线的科学选择与充分验证。  
目前，行业呈现出三条清晰的技术路线格局：砷化镓（GaAs）电池、P型异质结（HJT）超薄硅片电池和钙钛矿电池。三者性能、成本、应用场景差异显著，代表了不同阶段的解决方案。  
砷化镓电池是当前太空光伏的绝对主流。它的优势无可替代，其转换效率超过30%，抗辐射性能优异，可在太空中稳定服役15～20年。航天科技集团八院811所研发的三结砷化镓电池，已广泛应用于我国各类高轨卫星与深空探测任务。但它的短板同样突出：成本过高。砷化镓电池依赖稀有金属镓、锗，原料成本高昂，量产单价高达1000元/瓦（约合140美元/瓦）。原材料稀缺、制备工艺复杂，导致产能有限。这种“贵族电池”显然无法支撑未来低轨卫星星座的大规模部署需求。  
晶硅电池（P型HJT为主）被视为中短期的主力方案。它的核心优势在于性价比高，即转换效率虽低于25%，但成本也降至数十元/瓦。更重要的是，它可以制成50～70微米的超薄硅片，重量较砷化镓方案减轻25%以上，完美匹配低轨卫星的轻量化需求。此外，其产业进展也在加速。东方日升的超薄P型HJT电池已通过欧美主流商业卫星厂商的认证，实现小批量交付。招商证券的研报认为，SpaceX目前的方案倾向此类技术路线。  
钙钛矿及叠层电池则是长期的技术方向，被视作终极解决方案。它的潜力惊人，理论转换效率超40%，实验室叠层效率已突破34%，重量较砷化镓电池减轻90%以上，理论量产成本仅为砷化镓的十分之一。2026年，钙钛矿电池迎来在轨试验的密集落地。2026年1月，协鑫光电的钙钛矿组件随“鸿鹄二号”卫星入轨，开展全球首次钙钛矿组件空间搭载试验，重点测试其在零下150摄氏度至零下120摄氏度极端温度下的抗辐射性及稳定性。几乎同一时间，聚焦于高效钙钛矿太阳能电池研发与产业化的科技公司Singfilm Solar交付了全球首批Zenith系列柔性超薄钙钛矿组件，其基底仅50微米厚，计划于第四季度搭乘SpaceX猎鹰火箭，开启为期一年的在轨验证。  
然而，钙钛矿的长期在轨稳定性仍需验证，量产技术尚未成熟，产业链配套不完善。从实验室数据到可靠的太空服役，钙钛矿还有很长的路要走。  
不难看出，三条技术路线对应的是三种产业化节奏，即砷化镓守住高端市场，HJT抢占低轨卫星窗口期，钙钛矿押注更长远的未来。唯有在成本、性能、量产三大维度上找到最佳平衡点，才能从概念走向现实，真正叩开太空光伏的商业化大门。
