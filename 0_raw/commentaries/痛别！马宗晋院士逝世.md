# 痛别！马宗晋院士逝世

中国共产党优秀党员、中国科学院院士、我国著名地质学家和灾害学专家、中国地震局地质研究所原所长、研究员马宗晋同志，因病医治无效，于2026年8月15日8时35分在北京逝世，享年93岁。
马宗晋院士1933年1月出生于吉林长春，1978年加入中国共产党。1955年毕业于北京地质学院普查系，同年进入北京地质学院工作。1957年至1961年在中国科学院地质研究所构造学专业读研究生，1961年毕业后留中国科学院地质研究所工作。1967年调入新成立的国家科委京津地区地震办公室，1971年国家地震局成立后进入国家地震局分析预报室工作，1980年进入新组建的国家地震局分析预报中心工作，1988年调入国家地震局地质研究所工作，1991年当选为中国科学院学部委员（院士）。曾任原国家科委、国家计委、国家经贸委自然灾害综合研究组组长，国家减灾委员会首届专家委员会主任，国家汶川地震专家委员会主任，中国地质学会常务理事等职。曾获李四光地质科学奖，国家科技进步奖二等奖、国家自然科学奖三等奖、中青年有突出贡献专家、全国劳动模范等多项奖励和荣誉。
马宗晋院士是中国构造解析和地震分析预报体系的重要奠基人，是中国综合减灾领域的开拓者。他完成的节理定性、分期、配套等中、小尺度构造解析研究，对推动我国构造研究以及矿田构造研究产生了重要影响，其成果和方法在国内构造地质教学中广为选用；构建的长、中、短、临渐进式地震蕴育模式与工作程序延用至今，在地震预报中广泛应用；提出的全球三大构造系统与非稳态、非对称地球动力模型，开辟了现今地球动力学新思想；提出的灾害自然和社会双重属性、灾度概念，开创了我国自然灾害综合研究的新领域。作为首席科学家设计的中国地壳运动观测网络、中国大陆构造环境监测网络，从根本上改善了地球表层固、液、气三个圈层的动态监测方式，对中国的科学、社会和经济发展有重要影响。指导完成的亚洲含油气盆地编图和我国大型叠合盆地多期构造变形和分期差异变形研究，得到我国油气部门的广泛认可与运用。
