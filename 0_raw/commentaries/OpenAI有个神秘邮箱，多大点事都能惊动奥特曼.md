# OpenAI有个神秘邮箱，多大点事都能惊动奥特曼

大公司病几乎是企业成长的必然产物。
规模扩大后，流程变多，审批变长，决策变慢，一点点摩擦不断累积，最终拖累整体效率。
OpenAI 正在快速扩张，员工规模预计年底超过 8000 人。在这个体量下，它是怎么保持动作快速的？
《财富》最近的一篇报道，提到了一套 friction 机制。
在 OpenAI，一封邮件可能直接改变一个团队的工作优先级。
这个邮箱是 friction@openai.com。friction 意为「阻力」或「摩擦」。员工遇到技术系统故障、内部流程失灵，甚至办公室停车位不足，都可以直接发邮件上报。
OpenAI 领导团队会筛选这些问题，一旦被认定值得解决，相关事项便会进入快速处理通道，重要问题还可能惊动 CEO 山姆・奥特曼或总裁格雷格・布罗克曼。
OpenAI 几乎不怎么用邮件，内部基本全靠 Slack 沟通，但这个 friction@ 是个例外。
任何员工都能把问题送到 CEO 面前
据《财富》报道，friction@ 处理的问题大小不一。
为了缓解停车位紧张，OpenAI 曾启动一项试点，优先为通勤距离较远的员工安排车位。还有员工提出，公司需要改善 API 额度发放流程，确保额度能够稳定、大规模地分配。
一位 OpenAI 前员工认为，这套机制让管理层能够直接获得一线反馈，问题无需经过层层汇报，也能在积累成更大麻烦前得到处理。
「任何人都可以把大公司里的那些狗屁问题直接反映给 Sam，他们也真的会采取行动。」这名前员工说，「如果想毫不留情地清除官僚主义，就必须狠得下心。」
随着 OpenAI 快速扩张，这条通道变得更加重要。该公司预计到今年年底员工总数将超过 8000 人，办公室遍布美国及其他国家。组织规模越大，审批、协作和资源分配带来的摩擦也越多。
新来的 CEO，把这个邮箱制度化
friction@ 邮箱在 OpenAI 内部存在已久，最初并未得到广泛使用。
2025 年秋天，Fidji Simo 加入 OpenAI，担任应用业务 CEO。上任后，她用三个月时间在公司内部做「倾听巡访」，与各层级员工交谈，集中了解公司内部的问题。员工反复提到一个担忧：公司越来越大，还能否保持原来的行动效率？
Fidji Simo 认为，官僚主义通常不会突然出现。一次没必要的会议、多加的一道审批、一个微小的挫败，每次可能只会让工作困难 1% 或 2%。这些问题很容易被忽视，但长期叠加，最终会显著拖慢整个组织。
她随后为 friction@ 系统搭建了更清晰的处理流程，安排 OpenAI 战略计划与运营副总裁 Irina Kofman 专门负责监控邮箱、追踪问题进展。公司还开始每月通过 Slack 向全体员工通报进展。
今年 7 月初，Fidji Simo 因健康原因离开 OpenAI，将精力转向自己的医疗创业公司。这套机制仍被保留下来。
有人叫好，有人叫苦
并非所有员工都喜欢 friction。
一位 OpenAI 前团队负责人表示，自己任职期间曾收到「几十封」friction 邮件。对于长期人手不足、任务超负荷的团队，每次越级上报都可能打乱原有安排。
OpenAI 的工作文化一向以高强度著称。员工长时间工作，常常忙过晚饭时间甚至一直干到深夜。在这种环境下，一封 friction 邮件就可能突然触发一场并不受欢迎的「救火行动」。
「只要 Sam 和 Greg 觉得某件事值得处理，只要这个问题说得通，一项 friction 任务就会立刻启动。负责造成堵点的一方，差不多只能被告知闭嘴照办，这绝对不是开玩笑，你必须放下手头的一切。」
速度是唯一优先级
在争相打造和发布最新 AI 模型的激烈竞争中，只要能消除任何一点拖慢速度的因素，其他代价似乎都可以暂时让路。
2025 年 12 月，OpenAI 曾在内部拉响「红色警报」，要求员工集中资源推进战略产品，以应对谷歌和 Anthropic 等竞争对手。在这种环境下，任何内部堵点都可能影响产品进度。
friction 机制也让人想到亚马逊的「问号邮件」。过去，客户向杰夫・贝索斯投诉后，如果问题值得调查，他会将邮件转给相关团队，正文只有一个问号。收到邮件的团队必须立即调查并解决问题。
亚马逊主要处理外部客户投诉，OpenAI 聚焦内部堵点，两者采用了相似的管理方式，由最高管理层直接介入，压缩沟通链条。
其他 AI 公司，各有各的解法
OpenAI 的竞争对手也在寻找自己的管理方法。
Anthropic 选择提高内部信息的透明度。员工拥有公开的 Slack Notebook，用来分享想法和工作进展，其他人可以随时查看，也可以直接挑战管理层的判断。
CEO Dario Amodei 经常在 Slack 发布长文，解释公司战略和重要决策，再由员工展开公开讨论。这让决策背景能够长期保留，也减少了信息在层级传递中的损耗。
https://www.businessinsider.com/anthropic-open-culture-employees-argue-ceo-dario-amodei-slack-2026-4
Anthropic 还强调高信任、低自我的组织文化。员工需要直接沟通，主动承担紧急任务，并优先寻找简单、可行的解决方案。
谷歌直接压缩管理层级。到 2024 年底，公司已经削减约 10% 的经理、总监和副总裁岗位；2025 年，管理三人及以下小团队的经理数量较一年前减少 35%。部分管理者转为个人贡献者，以缩短决策链条。
friction 折射出 OpenAI 扩张中的现实难题。公司希望继续保持初创团队的反应速度，同时还要管理一个数千人的全球组织。这套机制能否长期有效，最终取决于高层能否准确判断优先级，以及执行团队是否拥有足够资源。
