# 中国空调在欧洲卖爆了，老外急到用 AI 跟黄牛抢货

最离谱的是，一台空调硬是被抢出了演唱会门票和限量球鞋发售时的阵仗：海外网友蹲库存，跨境找货，还有人把 AI Agent 都派上了用场。为了买到一台美的移动式空调 PortaSplit，奥地利人 Denis Yurchak 折腾了整整两天：开车横穿 200 公里，多方周转，甚至让 3 个 AI agent 全天候盯着库存。看完他发布的复盘推文，你很难判断它到底是一篇买空调日记，还是一集 AI agent 实战课。而这个故事要从欧洲热浪说起。5 月底以来，欧洲被创纪录的热浪反复炙烤，德国、西班牙、法国、英国接连破纪录。但空调这种在中国相对普遍的东西，在欧洲渗透率只有 20% 出头。一方面，为了维护历史建筑的外观，当地政府对安装空调施加了极其繁琐的限制。且基于环保价值观，当地政府甚至呼吁居民不要使用空调，宣称「最好的空调是一棵树」。另一方面，除了审批困难，专业安装成本也极为高昂。在欧洲，高空作业和钻孔安装通常需要聘请专业工人，安装费用经常高达 1000 欧元，甚至超过了空调设备本身的售价。但如上所述，奈何今年欧洲是真的热，结果就是大家集体抢购空调，三星、美的、三菱电机的销量全线暴涨。其中最抢手的，是美的那台叫 PortaSplit 的便携空调。卖到什么程度？部分渠道直接断货，在一些二手平台上，PortaSplit 被加价到两三倍，部分离谱报价直奔好几千欧。美的 Portasplit 官网🔗 https://www.midea.com/uk/air-treatment/porta-split-air-conditioner.portasplit他自己说，整整找了两天，能看上眼的就这一台，但全欧盟几乎哪都买不到。而两天后，维也纳气温要冲到 38 度，用他的话说，那会变成「人间地狱」。普通人到这一步，大概就认命了，开窗、买冰块、扛过去。Denis 的选择是：开三个 AI agent，全天候帮他扫货。同时，自己也一直在盯着市场上的空调。推文🔗 https://x.com/denisyurchak/status/2069866683586445766接下来的剧情，基本可以当爽文看了。agent 很快定位到，欧盟里还有存货的国家是匈牙利。Denis 联系了当地经销商，对方说只能匈牙利境内发货。他身边没有匈牙利的熟人，于是开始挨个给当地快递公司打电话。面对语言不通这关，Denis 很快想到一个聪明的办法，那就是把 GLS 物流公司快递经理用匈牙利语说的话录下来，丢进 AI 里，然后搞清楚该怎么跟人沟通。更绝的是通话本身。跨欧盟国家拨号费用很高，他干脆掏出自己写的 VoIP 应用，靠它扛过了 30 分钟的排队等待。由于没有寄件人指示，快递公司不肯收他的包裹。Denis 再次更改策略，给边境附近 10 家酒店打电话，问能不能帮他中转一个 50 公斤的大箱子。打了大概 20 通，终于有一家答应了。那天凌晨两点，他睡不着，在网上漫无目的地刷，盘算着要不要干脆花几百欧亲自跑一趟匈牙利。就在这时，手机弹出一条通知。是他的 AI agent，它在奥地利本地找到了一台。林茨（奥地利城市），全国仅剩的同款一台，距离他住的地方 200 公里。Denis 抓起手机飞快填完预订表，心满意足地睡了。第二天早上，他买了杯咖啡，开车 200 公里去取空调。到店发现，价格涨了 100 欧，从 749 欧涨到 849 欧。Denis 决定硬刚，要求见经理，最后店家同意按预订价卖。他形容自己当时高兴得像个孩子，全国仅剩的一台，归他了。Denis 最后说，他现在反而感激这场缺货和热浪，因为在一片酷暑恐慌里找空调，变成了一场真正的冒险。究其原因，别看 PortaSplit 是美的一款便携分体空调，但参数确实能打：12000 BTU、3.5kW 制冷，能压住 42 平米的房间；能效 A++、SEER 6.1；带热泵，冬天还能制热；静音模式 39 分贝。拿过 iF 设计奖、德国创新奖，还被《时代》评为 2025 年度最佳发明之一。🔗 https://time.com/collections/best-inventions-2025/7318415/midea-portasplit/传得还有鼻子有眼，还配了一串精确到小数点的数字：制冷剂卡在 1.99 公斤，刚好躲过法国 2 公斤的强检红线；噪音卡 35 分贝，贴着德国夜间扰民法的边界；SEER 卡 6.1，踩着瑞士 A++能效的最低门槛。可惜我查找了官方和欧洲经销商资料，发现热闹归热闹，但部分数字对不上：比如 12000 BTU 版用的是 R32 制冷剂，充注量 0.62 公斤，不是传说里的 1.99；静音模式标称 39 dB(A)，也不是 35 dB(A)。更重要的是，德国夜间 35 dB(A)通常说的是纯住宅区受影响点的噪声评价值，和厂家标注的室内机静音模式噪声不是同一个东西，不能直接拿来对照。美的 Portasplit 用户手册参数截图 🔗 https://www.midea.com/content/dam/midea-aem/uk/air-treatment/porta-split-air-conditioner/Portasplit-User-Manual-ENG.pdf所谓的踩线神话，部分是网友自己脑补出来的戏剧版，当段子乐呵乐呵可以，当真就不值当了。不过「卡 BUG」这个说法，内核是真的。它确实绕开了欧洲装空调最难的两道坎，只是手法则朴素得多。欧洲传统分体空调，室内外机得现场连管、抽真空、灌制冷剂，法律规定必须由持 F-Gas 证的工程师上门干，意大利涉及 F-Gas 固定空调安装且未使用合格人员时，最高罚 10 万欧。为此，PortaSplit 的解法是，整个制冷回路在工厂就焊死封好，室内外机靠一根 2.7 厘米厚的扁管永久连着，用户全程不碰制冷剂。英国经销商页面更是大大方方地表示，不需要 F-Gas 工程师。欧洲老房子要么是历史保护建筑不让钻孔，要么租房派根本没有改建权，西班牙挂个室外机还得过业主委员会投票。PortaSplit 那台 9.9 公斤的室外机不上墙、不钻孔，靠金属支架挂在窗台上，密封套件堵窗缝。要搬走，把室外机从支架上提回屋里就行，所谓「违建」十秒消失。所以美的确实在租房派和老房子这个被传统空调放弃的市场里，硬生生切出了一片蓝海。靠的是「出厂密封+免钻孔」这个产品设计，就足以成功卡 Bug。如果只是一个奥地利小哥的奇遇，用高科技抢空调这事也就乐呵一下。问题是，Denis 远不是个例。把镜头拉到德国，你会看到一整套被热浪逼出来的民间技术动员。最典型的是一个叫 braucheklima.de 的网站，名字直译过来就是「我需要空调」。开发者叫 Adrian Kübel，他干了件特别朴素又特别极客的事：写脚本去爬德国 Bauhaus、OBI、Hornbach、Toom 等几大建材连锁的实时库存数据，把全国 1100 多家门店哪家还有 PortaSplit 现货，全做成一张地图。绿点代表有货，红点代表没货。整张地图一片血红。1100 多家门店里，只有 3 家还剩现货。Amazon、eBay？售罄。连什么都卖的 AliExpress，搜 PortaSplit 也只剩替换滤芯。这网站还能设邮件提醒，一旦某家店补货，秒推到你邮箱。有一说一，要是抢演唱会门票、抢限量球鞋也能有这套系统，那该多好啊（doge）。库存可视化只是入门，开发者的玩法，远不止盯着地图刷新。德国科技媒体 heise 报道称，有不少买家怀疑，市面上的现货正在被自动化脚本（bot）批量秒杀。逻辑不难理解。手动刷新网页，永远抢不过机器。于是有技术背景的网友开始写 Python 脚本，挂个无头浏览器，盯着电商接口里的库存状态。一旦 JSON 里那个字段从「售罄」变成「有货」，脚本毫秒级自动加购、填信息、下单，一气呵成。要知道，放在两年前，写这么个 bot 还得有点编程底子。但放在现在，门槛被 AI 抹平了。把需求丢给 Codex，让它生成一段抢购脚本， 稍微打磨一下，几分钟就能跑起来。更进阶的，是把爬虫脚本接到 Telegram、Discord 的 API 上。建个频道，后台脚本一旦监测到库存变动，立刻给频道里成百上千的订阅者推送带直达链接的通知。一条消息出去，线上买家蜂拥而至。买到手，对一部分硬核的开发者来说，故事也才刚刚开始。比如有人在 3D 打印模型站 Thingiverse 上发了专门给 PortaSplit 设计的管线适配器，优化窗缝密封。还有人盘算着把空调接到阳台光伏上，搞出了一个「只要有太阳，空调就免费吹」的离网终极形态。顺带一提，今年 1 月美的给 PortaSplit 推了个固件更新，增加了室外静音模式，号称能再降 6 分贝噪音。这个新功能刚出，HA 社区马上就有人在 GitHub 开 issue，研究怎么把它也接进本地控制。属实是，厂商前脚更新，社区后脚跟进。这股劲头，确实只有刚需能逼出来。绕了一大圈，再回到 Denis。这条推文之所以在海内外传播如此之广，不光是因为空调，是因为它把 AI agent 用出了大多数人没想到的姿势。过去聊 Vibe Coding，过去聊 Vibe Coding，多少带点程序员自娱自乐的味道，话题也基本绕着写代码转：让 Claude、Cursor 帮你生成函数、改 bug、搭项目。Karpathy 当年提这个词时，定位也只是「适合搞周末玩具项目」。但 Denis 这一套，还有 braucheklima.de、那些抢购 bot 的开发者，在这些场景里，AI 并不是用作正经代码业务，而是扫描全欧盟库存、把匈牙利语录音转成沟通方案、生成抢购脚本、写 YAML 配置、凌晨两点默默推那条关键通知。代码只是手段，目的是在物理世界里更好地生活。当然，准确地说，是更凉快地生活（手动狗头）。他自己满世界打电话、联系酒店、规划匈牙利之行，忙活了一整套，最后真正解决问题的，是 agent 在凌晨两点扫到的本地货源。人在前台手忙脚乱，AI 在后台稳稳兜了底。时至今日，我们依然能在很多社交平台上看到 AI 无用论大行其道。但热浪不挑人，它也能让越来越多人，第一次有机会认真琢磨 AI 到底能帮我干点啥。而 AI agent 进入现实世界，未必会先从宏大叙事开始，也可能从一台抢断货的空调开始。✉️ 邮件标题「姓名+岗位名称」（请随简历附上项目/作品或相关链接）
