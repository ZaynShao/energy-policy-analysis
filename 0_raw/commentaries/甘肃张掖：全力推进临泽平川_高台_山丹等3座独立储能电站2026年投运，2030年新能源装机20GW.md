# 甘肃张掖：全力推进临泽平川/高台/山丹等3座独立储能电站2026年投运，2030年新能源装机20GW

通知中还强调了推动消纳能力快速提升，具体包括：
推动负荷项目与新能源一体化发展，确保新能源开发规模、建设时序与全市新建负荷项目投产节奏、电力消纳能力精准匹配、高效衔接。推广绿电直连、智能微电网、虚拟电厂等就近消纳模式，打造零碳低碳园区。
持续推进新型储能建设。全力推动临泽平川、高台、山丹等3座独立储能电站建设，确保2026年顺利并网投运。同步加快谋划储能电站的前期工作，进一步提升系统调节能力。加快盘道山、皇城抽水蓄能电站建设进度，确保按期投入使用，积极争取丹霞、青龙沟、白杨河等抽水蓄能电站纳规实施。
将巴丹吉林沙漠（张掖）基地建设作为强化新能源大规模开发的关键举措，全力推动项目落地实施，做好配套风光资源保护，推动项目获得国家认可，力争配套调峰的抽蓄电站在“十五五”期间开工建设。
