# 小米增程首车内饰外观全公开！雷军发视频解读，已在工厂试产

车东西7月9日消息，今日，小米官方放出了关于小米汽车第二个产品系列SkyNomad小米澎程SUV系列的更多信息。其中最值得注意的是小米澎程SUV一张侧面的外观图片，从图中可以看到小米澎程SUV的车身线条，同时车顶搭载了激光雷达，还采用了半隐藏式门把手的设计。▲小米澎程SUV侧面
小米澎程官方还公开了关于小米澎程SUV部分内饰信息，可以看到小米澎程SUV在内部空间上有很多独特的设计，包括可以灵活布置的座椅布局和可以移动中控中岛。▲小米澎程SUV内饰
而关于小米澎程系列的发布时间，小米创办人，董事长兼CEO雷军在社交媒体上发文中提到“很快，澎程系列即将发布”，还在解读视频中提到小米澎程系列目前已经正在北京亦庄的小米汽车工厂试产。▲雷军介绍小米澎程系列已经试产
今天一天，小米创办人，董事长兼CEO雷军在社交媒体上频频发文，介绍了小米澎程SUV系列的产品定义、车内空间等方面。▲雷军在社交媒体上发文
根据雷军的介绍，小米澎程在2023年初规划立项，目标要用智能定义空间，打造一个“活的空间”，驾驶时能载下家人、朋友和行李，甚至宠物，确保每一位乘员都有足够宽裕、舒适的乘坐体验，驻车时可以切换成一个人的工作室、两个人的咖啡馆，三个人的会客厅，或全家人的游乐场。为了实现这个目标，雷军表示小米从2023年年初开始打造了一个全新的平台架构——小米昆仑架构，在SUV的形态下，通过车内纯平地板与长滑轨设计，让澎程拥有了空间切换的能力。同时，小米澎程官方在社交媒体平台上发布了小米澎程SUV部分内饰信息。从后排向前可以看到，小米澎程SUV采用了悬浮式中控屏的设计，中控中岛可以在滑轨上前后移动，还可以在杯架上扩展出桌板，前排两个座椅可以转向车后，车顶疑似有后排吸顶屏。▲小米澎程SUV内饰
从前排向后可以看到，小米澎程SUV的两个第二排座椅可以在滑轨上大范围移动，第二排座椅有面积很大的腿托，同时采用了安全带位于座椅上的设计，看起来有零重力座椅功能。▲小米澎程SUV内饰
从车尾向前看，小米澎程SUV在7座布局的情况下依然能在后备厢中放入至少7个行李箱，可以看到第三排左右两个座椅扶手上有杯架，杯架上方看起来是一组实体按键，说明小米澎程SUV第三排座椅或许有电动调节和座椅通风加热等功能。▲小米澎程SUV内饰
在小米澎程SUV第二排和第三排车窗内侧，可以看到疑似手动遮阳帘，在B柱上有空调出风口和方便上下车的把手，前排仪表台上有疑似HUD的开口。小米澎程官方还发布了三张小米澎程SUV的“户型图”，在“看起来SUV，坐进去MPV”这张图片中，首先可以看到小米澎程SUV的第二排车门打开角度很大，可以达到90°，从座椅布局来看是此前展示的前排座椅向后转且中控中岛向后移动的布局。▲小米澎程SUV“户型图”
“买到车的人很多，买到空间的人很少”这张图片中的座椅布局更概念一些，描述了一个类似“卧室”的空间布局，后排放了一张大床。▲小米澎程SUV“户型图”
在“1个人的工作室，2个人的咖啡馆，3个人的会客厅，全家人的游乐场”这张图片中，甚至出现了单个座椅位于车辆中央的布局，可能概念的成分更多一些。▲小米澎程SUV“户型图”
不过在目前暂时还没有官方透露的是升降顶篷，根据此前的谍照等信息，小米澎程SUV或有升降顶篷版，车顶设有可升降结构，升起后拓展上层空间，实现类似“车房一体”的效果。▲编号为052、053的伪装车或搭载升降顶篷（图源网络）
车东西还在小米汽车递交的专利文件中找到了或是这台增程SUV的顶篷设计，其为一套“免工具、秒安装”的原厂顶篷系统。▲专利文件披露的车顶帐篷组件的剖面结构示意图
总的来看，小米澎程SUV系列无论是在外观、座椅布局，还是可能的升降顶篷版，都与小米汽车现有的SU7/YU7系列有很大的变化。就像小米创办人，董事长兼CEO雷军在社交媒体上发文中提到的：“SU7/YU7系列，是‘驾驶者之车’；小米澎程系列，是‘智能可变大空间SUV’。这是小米造车5年多来，面向不同的用户需求，交出的两份不同的答卷。”随着小米澎程SUV系列外观内饰更多信息的公开，相信距离其发布会也已经越来越近，其最终的售价和市场的表现值得持续关注。
