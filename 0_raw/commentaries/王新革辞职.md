# 王新革辞职

王新革辞去中国石油集团工程股份有限公司（以下简称“中油工程”）总经理等职务。
8月15日，中油工程发布公告称，公司董事会于近日收到董事、总经理王新革女士提交的书面辞职报告。王新革女士因到龄退休，申请辞去公司董事、总经理、董事会战略与ESG委员会委员和董事会提名委员会委员职务，辞职报告自送达公司董事会之日起生效。辞职后，王新革女士不再担任公司任何职务。
