# 一个被低估的千亿新战场正在觉醒

加入供应链产业群，请加微信gasgoo88，出示名片
2026年刚过去一半，行业里一个反差感极强的现象已经藏不住了：各家发布会都在讲“AI大模型上车”“智驾算力破千TOPS”“座舱Agent主动服务”，但真正决定用户冬天敢不敢开纯电北上、决定智驾芯片能不能不降频、决定超充桩前排队时间的，却是一套长期被视作“幕后配角”的系统——热管理。
图片来源：摄图网
这不是危言耸听。英伟达Thor车端芯片热流密度已冲到250W/cm²，局部热点超500W/cm²；2029年7月1日，乘用车空调GWP>150冷媒（即R134a）将被强制禁售，留给行业的窗口只剩不到3年；冬季制热能耗占纯电整车电耗的“大头”，传统规则式控制已兜不住多热源耦合的复杂工况。
“AI定义汽车”这句话喊了一年多，但热管理才是那台被AI重新定义的第一个“非智驾”核心系统——它正从被动散热的“保姆”，变成主动调配整车能量的“管家”。
AI驱动的预测性智能控制：从“规则库”到“神经网络”
传统热管理控制的逻辑，是工程师预设几千条“if-then”规则——温度低于X度开PTC，高于Y度开压缩机。但当车上有电池、电驱、座舱、智驾芯片、车载冰箱五六个热源要统筹时，规则库就崩了。“越智能越敏感，越容易出错，零部件切换频次高了，对可靠性和稳定性的挑战就非常大。”近日，在第四届汽车热管理全场景创新发展论坛上，泛亚汽车新能源热力学技术经理 周达美点出了痛点。
解法是用AI把控制逻辑重写。法雷奥平台首席产品技术负责人曾力克在现场给了一套很落地的路径：
• 多区风量AI分配：空调箱风道涉及内外循环、冷暖风门、除霜等多变量耦合，传统正向算法做不到精准恒定。法雷奥用神经网络训练台架数据，再迁移到改款车，把风量波动压到1%以内，用户无感。
• 传感器虚拟化：用神经网络模型预测出风口/车内温度，替代部分物理传感器，降本。
• 自动标定：把工程师的标定思路喂给AI，让控制器自己调参数图，把数月工作缩到数周。
• 故障预测：采集制冷剂不同泄漏量（20g/50g/80g）下的系统特征训练模型，能输出0–200g的泄漏值——这比传统“漏一半才发现”的阈值报警精细得多。
东风汽车研发总院刘俊团队走得更靠前，做的是车云协同+MPC（模型预测控制）：基于行程预测、路况、用户习惯，提前储热/预冷，短途出行不盲目加热电池，长途一键备车提前把电驱/电池水温拉到合适区间，充电前预判预热水管降快充时间。“混动和纯电车的高低温续航、亏电油耗，都能从这里抠出空间。”刘俊说。
行业数据能给个参照：基于AI预测性热控架构，整车冬季续航可提升20%，某头部新势力今年2月一次OTA不改硬件就把旧款冬季续航提了8%。2028年新车AI热管理搭载率预计破90%——这不是“要不要上”的问题，是“晚了就被对标打”的问题。
但法雷奥曾力克也提了个清醒的判断：AI本质是概率生成，天然带幻觉，“现阶段不能让AI生成完直接跑，必须加人工规则和review”。可解释性、ISO 26262功能安全、SOTIF预期功能安全，是AI热管理绕不开的三座山。
系统高度集成化：从“分散管路”到“双间接架构”
集成化这句口号行业喊了五年，但2026年的新共识是——集成不是把零件塞在一起，是架构级重构。
特斯拉2020年扔出八通阀（Octovalve）之后，国内跟得很快。智己汽车热管理总监王天英把路线讲得更透：行业正从“一体式热泵”再往前走一步，到“双间接系统”——制冷剂封闭在机舱内的一个小一体机里，只留三根水管进座舱，水侧耦合电池/电驱/座舱。
智己自己ITMS 3.0纯电平台和ITM 4.0增程平台已经跑通这套逻辑：
• 计侧流道板0.82kg，行业最轻；
• 制冷剂充注量压到120g量级，碰撞泄漏风险大幅降低；
• 整车厂端不做制冷剂加注，供应商封好一体机过来装，“整车制造成本反而是降的”（王天英与原话确认）。
• 能效上，中国汽研测评空调在+40℃/-20℃都达一级。
海力达亚太研发总监王益民从零部件侧补了一刀：冷媒侧五通阀“已经到头了，重点是往水侧卷”——海力达两位三通已量产超两年，五通阀B样兼容R290，陶瓷阀芯内泄漏2mL/min（1MPa下耐久4万次后），寿命15年/30万公里。冷媒侧五通是天花板，水侧九通才是下一战。
但集成化也有“副作用”。长安汽车热系统集成高级主管李京苑在分享里坦承了踩坑：“间接式热泵比直接式大概多100W电耗，我们在低温测试里发现，部件共用+补液管设计会带来‘串水漏热’，低温回路电池残冷时能有几点几升流量、几十瓦的漏热。”——集成度越高，系统级漏热、维保总成更换成本、故障定位难度全都会往上跳，这是主机厂和Tier1接下来要一起解的题。
海立新能源陶宏给的判断挺犀利：“新能源汽车热管理系统，会从现在复杂多样化探索，逐渐向简单、经典、可靠、低成本收敛，像传统车一样稳定下来。压缩机厂现在大量定制工作（安装点位/接插件/通信协议全不一样）对降本没帮助，标准化是行业一起做的事。”
高算力芯片散热：热流密度250W/cm²下的“隐形瓶颈”
这一块是2026年最容易被“AI定义汽车”叙事盖住、但工程端最头疼的章节。
数据先摆出来：L4/L5智驾算力突破1000TOPS，英伟达Thor已到2000TOPS，制程4nm/5nm，热流密度250W/cm²，局部超500W/cm²，3D封装让热耦合更复杂。车端环境还要叠高温/高原/高寒/高频振动——传统风冷和被动散热已经出局，冷板式液冷是智驾域控的主流方向。
但液冷“上车”不是把数据中心方案搬过来就行，车载有三个独特痛点：
1.凝露：冷却液温度低于域内露点时，流道外壁结露滴到电路上直接短路。华为MDC做法是外壳开孔+e-PTFE透气膜，更进阶的是“透气阀+干燥剂”CMD结构。
2. 密封与泄漏：O型圈老化+管路振动，某车企已有因O型圈失效召回的案例。氟橡胶O型圈目前还得从日/德采购，成本占系统15%–20%。
3. 低温流动性：-40℃下水基冷却液粘度剧增，泵可能起不动，换低粘度硅油成本还需再提升。
材料侧也在跟进。一汽研发总院材料开发首席齐丹在论坛里点了一条卡脖子链：“氮化硅散热基板，进口粉体380–400元/公斤，国产如果能做到120–150元/公斤，降本空间很大——但高导热（目标110W/m·K以上）氮化硅粉体，国内还落后日韩。”更前瞻的金刚石纳米膜，“没有想象中那么贵，但汽车应用上还有技术问题”。
热管理的外溢也在发生。空调国际热管理技术副总监辜积峰在论坛里讲了人形机器人方案：伺服关节换热量占整机60%–80%，算力芯片（英伟达AGX类）热流密度150–300W/cm²，芯片>85℃就降频——“机器人其实有点像人，多点散热，我们想做的是仿生‘血管式’水套嵌到所有发热部件，胸腔集中散热”。这跟智驾域控液冷是同一套技术母体，只是空间更抠、重量更敏感。
一个容易被忽视的信号：热管理正在从“车”蔓延到“机器人+低空+eVTOL+AI算力中心”，同一套液冷/相变/高导热材料技术，能卖四次。这是零部件厂的第二增长曲线。
政策驱动的绿色化转型：2029年7月1日这个硬时间点
最后一章必须落到政策上——因为这是未来3年倒逼热管理变革最强的那只手。
生态环境部等部委印发的《中国履行〈蒙特利尔议定书〉国家方案（2025—2030年）》写得很死：2029年1月1日前HFCs受控用途使用量至少削10%，汽车行业自2029年7月1日起，禁止新申请公告的M1类车辆空调系统使用GWP>150的制冷剂。R134a（GWP=1430）直接出局，窗口期不到3年。叠加R134a配额已被“焊死在现有水平”，三代制冷剂价格已经创十年新高——不是“换不换”的问题，是“现在不定路线2027年就来不及量产”。
目前三条路线并行，但各有各的账：
海立新能源热管理系统首席技术专家陶宏在论坛里给的判断挺务实：“COP和充注量永远是要做好的课题，环保在经济上必须可持续，否则做不下去。R1234yf至少还能用到29年节点，不用一蹴而就。”但他也确认霍尼韦尔正在跟中国政府/工厂协商国内产能——言下之意，29年之后1234yf的供应和成本还会有波动。
刘俊团队已经在做R290双二次回路间接式热泵，“跨代兼容设计，接口变更就能实现R1234a/R290/R744三种冷媒切换”——这是一种“不把鸡蛋放一个篮子”的打法。
商用车侧的账更能打动决策者。北汽福田热管理开发部副部长 福田黄嘉悦在现场算过：“4.5吨纯电动物流车年跑10万公里，热管理能效优化10%，年省约2.4万元，相当于净利润+15%——货运行业净利率普遍不到5%，这笔账直接关系企业生死。”政策+TCO 双重驱动下，商用车的低GWP切换反而会走得比乘用车更坚决。
结语：
回到开头那个问题——AI定义汽车时代，热管理如何发展？
答案已经不是“把散热器做大、把阀做多”那种线性迭代，而是四个维度的同时跃迁：
• 控制侧：规则→AI预测+MPC+车云协同，冬季续航+20%是可量化的第一波红利；
• 架构侧：分散→双间接+多通阀+标准化，但要警惕集成带来的漏热与维保成本；
• 对象侧：从保三电→兼顾智驾芯片/机器人/低空，热流密度250W/cm²是新的工程天花板；
• 合规侧：2029年7月1日是硬倒计时，R1234yf过渡+R290/R744双轨是未来3年最确定的投资方向。
热管理正在从“被动保障硬件不超温”的辅助子系统，变成“主动定义续航、体验、安全”的整车能量调度中心——这句话过去两年还像口号，2026年的论坛听完，已经是各家PPT上在跑的项目了。
智己王天英那句“双间接是‘最后一公里’，很快了”，法雷奥曾力克那句“AI生成的反直觉策略，如果价值好，工程师要向AI学习”——这两句放一起读，大概就是这一年热管理人的心态缩影：架构的“最后一公里”在踩，控制的范式在换，政策的倒计时在走。
慢不下来了。
