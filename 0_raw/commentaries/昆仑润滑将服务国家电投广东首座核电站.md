# 昆仑润滑将服务国家电投广东首座核电站

通常来说，核能无法直接转化成电能。核燃料在反应堆压力容器中，通过核裂变产生能量，将液态水加热成蒸汽，然后水蒸气推动汽轮机组做功发电。广东廉江核电项目是国家电投集团在广东首座开工建设的沿海核电项目，一期工程建设2台CAP1000压水堆核电机组，是国内首台采用海水二次循环冷却的双背压凝汽器核电机组，所用机组由东方电气集团东方汽轮机有限公司生产。
由于核电项目对设备、材料及服务的管理要求极高，油品验收小组逐项复核昆仑KTL46汽轮机油（核电专用）理化性能、清洁度、抗氧化性、抗乳化性等关键指标，并现场审查质量记录和出厂检测报告。经综合评估，油品验收小组一致认为油品质量满足CAP1000堆型汽轮机技术规范及廉江项目技术条件要求，同意通过验收并发运。
据悉，该项目一期工程两台机组计划于2028年建成投运，投运后年发电量约200亿千瓦时，可满足约400万户家庭全年用电需求。
