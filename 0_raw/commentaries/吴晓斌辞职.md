# 吴晓斌辞职

吴晓斌辞去大唐华银电力股份有限公司（以下简称“华银电力”）副总经理职务。
8月20日，华银电力发布公告称，因工作调整，吴晓斌先生不再担任公司副总经理职务。根据《中华人民共和国公司法》《大唐华银电力股份有限公司章程》等相关规定，公司董事会接受吴晓斌先生的离任申请，其离任手续将按照相关规定办理。吴晓斌先生已做好有关工作交接，其离任不会影响公司正常的生产经营。
