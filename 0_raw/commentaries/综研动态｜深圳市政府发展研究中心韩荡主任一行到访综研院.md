# 综研动态｜深圳市政府发展研究中心韩荡主任一行到访综研院

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/QIJgF5A55WZGzBK8dVic7XlbHFeaste7NoaaoVSOzYQ4swJMVzrhOgR9S3d8bZI4ehPgxxOeJrQAPiaLXgjAaqKJVdsIjHxTr9wOcaqF6PHWs/640?wx_fmt=png&from=appmsg)

3月11日，深圳市政府发展研究中心党组书记、主任韩荡一行到访综研院，与院长刘国宏、常务副院长郭万达及相关研究骨干进行座谈，双方围绕深化合作、共同服务深圳高质量发展等议题展开交流。

刘国宏院长对韩荡主任一行的到来表示欢迎，并详细介绍了综研院的发展历程、研究特色、国家高端智库建设情况。他指出，综研院始终立足深圳，服务国家战略，在政府决策咨询、产业规划等方面积累了丰富经验，将一如既往支持市政府发展研究中心的工作，主动对接需求，共同推动深圳智库事业发展。

郭万达常务副院长回顾了双方长期合作历程，表示未来将继续发挥实体型智库优势，聚焦“政府所需、研究院所能”，产出更多针对性、可落地的研究成果，以更好服务深圳经济社会的高质量发展。

韩荡主任对综研院服务深圳决策咨询工作表示肯定与感谢。他指出，当前深圳在软性产业、平台经济发展方面仍有空间，希望双方围绕这些深层次问题加强合作研究，从城市基因、产业规律等底层逻辑出发，理清问题根源；同时加强人文社科研究与智库建设，聚焦宏观性、战略性、前瞻性课题，推动智库成果更好转化为服务城市发展的实践举措。

会上，双方还围绕当前经济形势、新质生产力培育、产业政策优化等方面进行了深入交流。市政府发展研究中心经济发展处处长陈明、国际交流合作处处长邓莉莎、办公室主任胡华巍、经济发展处博士后刘源；综研院院长助理、智库研究与信息部部长郑宇劼，院长助理、数字经济与全球战略研究所所长曹钟雄，公共政策与社会治理研究中心主任王梅，公共经济研究所所长汪云兴，智库交流与合作部部长刘志杰，通证数字经济研究中心主任李恩汉等参加座谈。
