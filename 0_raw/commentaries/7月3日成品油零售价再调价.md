# 7月3日成品油零售价再调价

自7月3日24时起，国内成品油价格预计下调820元/吨，折算每升下调0.65元左右。
7月3日24时，国内成品油价格调整窗口期将再度开启。金联创预计，按照现行成品油价格形成机制，综合近期国际市场油价变化情况，自7月3日24时起，国内成品油价格预计下调820元/吨，折算每升下调0.65元左右。
此次调价是6月两轮下调后的第三次价格调整，将形成2026年全年首次油价三连降行情。
以普通家用轿车油箱50升，调价后加满一箱92号汽油，预计直接省下30元左右；经常跑长途、油箱60升的SUV，单次加满能省近37元；对于货车、客运车辆这类高油耗营运车辆，长期用油成本减负效果会更加明显。
文丨本报记者 渠沛然
