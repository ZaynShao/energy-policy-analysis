# 电池厂商上半年业绩普涨

整体来看，上半年国内电池行业景气度攀升，也为下半年稳健发展打下扎实基础。
宁德时代、瑞浦兰钧等多家电池企业日前披露半年报及业绩预告，整体经营数据稳中向好，释放出行业强劲复苏积极信号。业内有分析指出，下游多赛道需求集中释放，为电池企业打开广阔增长空间，带动订单规模扩容与盈利水平改善。与此同时，高质量发展已然成为主旋律，头部企业凭借技术、产能等综合优势不断巩固市场地位；一批中小企业聚焦细分场景寻求差异化突围。整体来看，上半年国内电池行业景气度攀升，也为下半年稳健发展打下扎实基础。
多家公司业绩实现高增长
从已披露的2026年半年度业绩数据来看，企业业绩普遍跑出高增速，展现出强劲的发展韧性。其中，作为全球锂电龙头，宁德时代上半年实现营业收入约2769.17亿元，同比增长54.80%；归属于上市公司股东的净利润约432.84亿元，同比增长41.98%。
瑞浦兰钧预计其今年上半年净利润超过去年全年。数据显示，瑞浦兰钧上半年实现营业收入约145亿—152亿元，同比增长约52.8%—60.1%，同期净利润预计达7亿—8.5亿元。相比之下，2025年瑞浦兰钧净利润约为6.81亿元，且去年上半年公司处于亏损状态，净亏损约0.63亿元。
亿纬锂能、国轩高科等企业上半年业绩表现同样不俗。亿纬锂能预计实现净利润31.3亿—33.71亿元，同比增长95%—110%；国轩高科预计实现净利润12.0亿—15.5亿元，同比增长227.31%—322.77%；鹏辉能源预计实现净利润8亿—8.66亿元，而去年同期亏损8822.67万元，同比实现大幅扭亏为盈。
终端需求放量推动订单量增加、全球市场份额稳步提升，是推动本轮电池厂商业绩增长的重要驱动力。国轩高科在公告中表示，该公司加快研发产业化落地，推进产品迭代升级，优化客户结构，加强海内外市场开拓，市场占有率稳步提升，业绩稳健增长，归属于上市公司股东的净利润显著增长。
瑞浦兰钧则称，电池产品出货量增加带动收入增长，规模效应和降本增效措施同样带动毛利提升。
储能业务成为“第二增长曲线”
值得一提的是，多家电池企业储能业务表现亮眼，逐渐成为推动公司业绩上行的“第二增长曲线”。
以宁德时代为例，上半年该公司动力电池系统收入约1921.25亿元，同比增长46.02%；储能电池系统收入约532.61亿元，同比大幅增长87.54%，成为增速最快的主要业务。同时，其储能电池系统毛利率为23.96%，高于同期动力电池系统的20.63%。
纵观上半年，宁德时代在储能领域布局动作频频。国内市场，与海博思创签署为期3年、总规模达60吉瓦时的钠离子电池储能战略合作协议；海外市场，在德国、西班牙、智利、马来西亚、澳大利亚等国家中标多个储能系统集成项目。
高工产研锂电研究所初步统计数据显示，2026H1中国锂电池出货约1.2太瓦时，同比增长超50%。2026H1中国储能电池出货量约485吉瓦时，同比增长超80%。
从行业层面来看，电池行业增长逻辑已发生显著切换，由过去新能源车单一拉动转向储能、海外出口等多元支撑新格局。有分析人士预测，未来伴随着国内项目集中释放及海外持续抢装，储能赛道有望延续高景气，继续领跑电池行业整体增速。
研究机构EVTank在《中国锂离子电池行业发展白皮书（2026年）》中预计，全球锂离子电池出货量在2026年和2030年将分别达到3016.3吉瓦时和6012.3吉瓦时，其中对于2026年全球锂离子电池出货量的预期相比2025年版本白皮书提高17.3%，主要增长动力来自储能电池的需求。
由“数量驱动”转向“价值驱动”
全球化布局也是电池企业寻求新增长的重要方向。从上半年来看，多家企业加快“走出去”步伐，海外投资计划密集公布。
亿纬锂能在5月宣布与印度能源企业Godawari New Energy（GNEPL）签订8吉瓦时储能大电池供应订单，并规划在未来5年合作60吉瓦时；早在1月，中创新航与葡萄牙政府完成投资合同签约，投资项目位于葡萄牙锡尼什，规划建设锂电池工厂，总投资20.67亿欧元，预计2028年全面投运。
宁德时代也在半年报中提及，随着海外基地建设、运营逐渐成熟，该公司以领先的产品及优质的服务持续助力VW、Stellantis、BMW等海外客户取得亮眼市场表现。此外，持续推进海外服务网络及能力建设，上半年专业服务站新增覆盖东欧、非洲、南亚地区的8个国家，同时落地沙特、乌兹别克斯坦宁家服务海外体验中心。
全球锂电产业正进入高质量发展新周期。业内有观点指出，随着国内针对锂电行业的“反内卷”治理持续深入推进，尾部产能将加速出清，同时各大电池企业纷纷聚焦安全、续航、成本、寿命等维度开展技术攻坚，加大研发投入，推出高附加值产品，为出口结构优化奠定基础。
中国化学与物理电源行业协会披露，2026年1—6月，我国锂离子电池出口数量达26.19亿个，同比增长21.49%；出口额为486.49亿美元，同比增长42.72%。上半年我国锂离子电池出口整体呈现量价齐升、市场分化显著、结构持续优化的特点，增长由“数量驱动”转向“价值驱动”，高附加值动力电池、储能电池出口占比提升，产品结构升级成效显著。
