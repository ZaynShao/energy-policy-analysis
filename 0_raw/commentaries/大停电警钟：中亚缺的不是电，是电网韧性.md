# 大停电警钟：中亚缺的不是电，是电网韧性

8月14日下午，中亚国家统一电力系统发生大范围扰动，哈萨克斯坦、吉尔吉斯斯坦、乌兹别克斯坦和塔吉克斯坦部分地区相继出现停电、电压波动或电网解列，阿拉木图、比什凯克、杜尚别等城市受到不同程度影响，一些地区交通、通信和市政设施短时运行异常。
事故因何而起，各方尚有不同表述。哈萨克斯坦国家电网运营商KEGOC认为，吉尔吉斯斯坦托克托古尔水电站两台机组短时退出运行、约600兆瓦发电功率骤然损失，是此次扰动的初始触发因素；吉尔吉斯斯坦方面则强调，初始扰动不能简单等同于其他国家部分电网随后停电的直接原因。目前，各方已成立联合委员会展开技术调查。
在事实彻底厘清之前，真正值得深究的，不是把责任简单归咎于哪个国家、哪台机组，而是一个局部扰动，何以迅速跨越国界，演变为波及四国的区域性电网事件？
答案指向一个更深层次的命题：中亚电力基础设施现代化，已经到了必须加速推进的时候。
中亚统一电力系统形成于前苏联时期，其优势在于跨国调剂水电、火电和负荷，实现区域资源互补。但随着设备老化、负荷增长、新能源大规模接入，这套高度互联的系统正面临新的安全考验。世界银行评估显示，上述四国大量电网与发电设施继承自前苏联时期，运行30年以上的设施占比约为44%至75%，部分设备已超过理论使用年限，区域电力损耗总体处于较高水平。乌兹别克斯坦的情况颇具代表性：截至2024年，该国配电网技术损耗约13%，过半配电设施运行超过30年，政府正推进总投资需求约30亿美元的配电网现代化计划。
就此而言，此次停电更像一记警钟。对中亚国家而言，未来电力投资的重心，不能只是“多建几座电站”，而必须从发电侧延伸至输电网、配电网、调度系统、继电保护、储能和数字化控制体系。电网不仅要有“输送能力”，更要有“抗冲击能力”；不仅要回答“有没有电”的问题，更要回答“一个节点发生故障之后，整个系统能否迅速隔离、快速恢复”的问题。
在这方面，中国经验具有很强的现实参照意义。经过长期大规模建设，中国已形成世界上规模最大、技术最复杂的交直流混联大电网。截至2025年底，我国已建成投运45条特高压输电通道，“西电东送”能力达3.4亿千瓦，同时支撑超过18亿千瓦新能源接入和消纳。更重要的是，这种优势并不止于某一类设备，而是一种系统性能力——从规划设计到装备制造，从特高压输电到智能调度，再到工程总承包和长期运维，中国已形成完整的电力建设产业链。而这，恰恰是中亚当前最需要的。
吉尔吉斯斯坦能源部在建电站管理机构董事会主席巴克特·巴克塔耶夫告诉《中国能源报》，中国能源技术目前在吉尔吉斯斯坦的运行表现可靠，包括南北电网以及比什凯克相关电网项目。中国能源技术处于国际先进水平，因此与中国投资和技术合作相关的能源项目，在吉尔吉斯斯坦具有很强的吸引力。
此次事故发生后，吉尔吉斯斯坦电力系统较快恢复至正常频率，并一度向周边系统提供约250兆瓦功率支援；乌兹别克斯坦方面特别强调，自动化装置和电池储能系统在抑制功率下降、弥补瞬时功率缺额方面发挥了重要作用。这些细节提示我们，中亚电网升级已不能停留在简单“以新换旧”的层面，而应朝着自动化、数字化、储能化、智能化的方向整体跃升。这也意味着，新的合作空间正在打开——从500千伏骨干网架改造到跨国输电通道建设，从老旧变电站升级到智能保护和调度系统，中国企业完全有条件从以单体工程和设备出口为主，转向“规划咨询＋设计建设＋装备供应＋数字化系统＋运维服务”的全生命周期合作。
一次大停电，不会改变中亚能源合作的大方向，却提醒各国：现代能源体系的竞争，归根结底不仅是资源和发电能力的竞争，更是电网韧性和系统治理能力的竞争。中亚能源资源富集，但要真正转化为稳定、安全、可交易的电力，必须有一张更坚强、更智能、更具韧性的现代化电网作为支撑。
从这个意义上说，此次停电传递了一个明确的信号：未来十年，中亚很可能迎来一轮持续时间较长的电网更新和能源基础设施现代化周期。对已经积累全球领先电网技术、完整装备制造体系和大规模工程经验的中国企业而言，这片市场不仅“大有可为”，更应成为共建“一带一路”能源合作从“电站建设”迈向“现代电力系统建设”的重要新空间。
