# 经研院召开“两优一先”表彰大会暨 警示教育大会

7月3日，中国石油集团经济技术研究院（简称经研院）召开“两优一先”表彰大会暨警示教育大会，深入学习贯彻习近平党建思想和习近平总书记在庆祝中国共产党成立105周年大会上的重要讲话精神，认真贯彻落实集团公司有关会议和文件工作部署，动员经研院广大党员干部大力弘扬伟大建党精神，牢固树立和践行正确政绩观，学习先进典型、汲取案例教训，校准发展方向、压实党建责任，锚定“十五五”发展目标攻坚克难，扎实推进经研院“双一流”建设。集团公司总经理助理、经研院党委书记陈发晓出席会议并讲授树立和践行正确政绩观学习教育专题党课，党委副书记、执行董事、院长陆如泉主持会议。
会议现场
会议传达学习了中央庆祝中国共产党成立105周年大会精神，以及集团公司“两优一先”表彰大会精神，通报经研院获评集团公司党组、直属党委“两优一先”情况，宣读经研院“两优一先”表彰决定，为获得表彰的先进集体和个人颁奖。5名代表结合科研咨政、支部建设、基层管理等岗位实际，分享实践感悟。会议传达学习了集团公司警示教育会精神，通报了集团公司《树立和践行正确政绩观正反面典型案例》。
集团公司总经理助理、经研院党委书记陈发晓讲话并讲授政绩观学习教育专题党课

经研院领导为获奖代表颁奖

经研院在京领导班子成员、首席专家、院长助理、中层干部、支部委员及党员代表等90余人参加会议。
