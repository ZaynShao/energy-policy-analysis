# 乌克兰石油天然气董事会主席科列茨基，获任乌克兰新总理

谢尔盖·科列茨基被任命为乌克兰新一任政府总理。
据央视新闻消息，当地时间7月16日，乌克兰最高拉达（议会）以289票赞成的投票结果，同意任命谢尔盖·科列茨基为乌克兰新一任政府总理。
15日，乌克兰总统泽连斯基向乌克兰最高拉达（议会）提名谢尔盖·科列茨基为乌总理人选。
▲谢尔盖·科列茨基 资料图。图源：央视新闻
公开资料显示，科列茨基1978年出生于乌克兰卢茨克市。他在大学期间攻读机械工程、商业经济学和石油与天然气开采专业。
1999年至今，科列茨基深耕石油天然气与商业领域，历任多家能源企业高管。自2025年5月起，担任乌克兰石油天然气公司董事会主席。
▲乌克兰前总理斯维里坚科 资料图。图源：央视新闻
7月12日，泽连斯基在社交媒体发文说，为保障落实新的政治战略，他决定重组内阁，建议斯维里坚科卸任总理职务，将其调任全新设立的重要岗位，专职负责乌克兰与核心国际伙伴的合作工作。
13日，斯维里坚科向乌最高拉达递交了辞呈。
14日，乌最高拉达（议会）审议批准了乌总理斯维里坚科递交的辞呈。按照乌法律规定，现任内阁将随之自动解散。报道说，斯维里坚科的辞呈获258票支持，超过批准所需的最低票数226票。
此外，泽连斯基还于12日表示，作为新战略的核心内容，乌克兰将对各重点外交方向实行专人负责机制。其全新外交布局主要包括以下内容：
•深化对美安全合作，推进“爱国者”导弹系统生产许可等双边防务合作事宜；
•助力欧洲反导项目建设；
•加速入盟进程，全方位深化与欧盟的多领域合作；
•修复与波兰、匈牙利等邻国的双边关系；
•拓展与中东、海湾地区及各大国际组织的合作，争取更多国际力量支持，推动俄乌冲突政治解决，保障本国经济与安全发展。
