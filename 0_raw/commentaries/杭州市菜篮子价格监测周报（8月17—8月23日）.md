# 杭州市菜篮子价格监测周报（8月17—8月23日）

✦
•
✦
监测数据和市场巡查情况显示，上周（8月17—8月23日）杭州市菜篮子商品供应充足，鸡蛋、蔬菜价格环比上涨，猪肉、水果价格呈下降态势，水产品价格涨跌各现。具体情况如下：
✦
•
✦
肉禽蛋
猪肉价格环比微跌：猪肉零售均价17.44元（每500克，下同），跌幅0.11%。分部位看：猪全精肉16.78元，涨幅0.42%；猪肋排28.15元，跌幅0.35%；猪五花肉16.38元，跌幅0.3%。鸡蛋6.31元，涨幅3.27%。其余品种零售价格总体平稳。
蔬菜
蔬菜价格环比上涨：纳入监测的蔬菜品种零售均价6.19元，涨幅4.92%。具体来看，青菜4.79元，涨幅12.18%；土豆2.92元，涨幅0.34%；茄子5.81元，涨幅4.68%；花菜5.88元，涨幅2.44%；萝卜2.28元，涨幅0.88%。其余大部分品种零售价格变动幅度在5%以内。
水产
水产品价格涨跌各现：其中，鳙鱼12.6元，涨幅0.08%；鲫鱼17.78元，跌幅0.61%；明虾24.92元，涨幅1.14%；带鱼29.15元，涨幅1%。
水果
水果价格环比微跌：水果零售均价4.98元，跌幅0.2%。分品种看，苹果8.2元，跌幅1.09%；梨4.55元，涨幅2.48%；橙子5.51元，跌幅0.72%；香蕉3.77元，跌幅2.58%；西瓜2.89元，涨幅3.21%。
