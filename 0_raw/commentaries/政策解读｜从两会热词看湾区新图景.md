# 政策解读｜从两会热词看湾区新图景

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/QIJgF5A55WaOU64ALmerOgxk0q9icd38o69IwWF78t2npRYiccRVay10RHvMB6UNLynL3Pv2Dj7MAD4fcJNEibzY0MolaiaoAFlfz1aw7ajibWIk/640?wx_fmt=png&from=appmsg)

2026年3月5日，十四届全国人大四次会议开幕，在政府工作报告中，提及高质量发展21次、新质生产力6次、创新71次、开放18次。今年的政府工作报告直接提及粤港澳大湾区2次，明确建设粤港澳大湾区国际科技创新中心，打造世界级科技创新策源地；支持粤港澳大湾区打造世界级城市群（这是自2017年以来，粤港澳大湾区连续第十年出现在政府工作报告中）；也强调，支持港澳更好融入和服务国家发展大局，发挥港澳背靠祖国、联通世界的独特优势和重要作用，促进香港、澳门长期繁荣稳定。今年是“十五五”开局之年，也是《粤港澳大湾区发展规划纲要》发布七周年，这些“两会热词”及对大湾区的新表述，既是国家经济社会发展的重要指引，也是粤港澳大湾区打造国际一流湾区、擘画发展新图景的行动坐标，从中可以更加清晰地看到粤港澳大湾区未来发展的几条新路径、几幅新图景。

![image](https://mmbiz.qpic.cn/mmbiz_png/QIJgF5A55WbqzqUMR8PRVF1Nyia6WAht4UjmSMBPAZiaM4U68rGwMByibk2m2AAOZEzPl5oRhNaQsNSQCOia2Iey6XJvfszOL6ep8cEDL2CKHKc/640?wx_fmt=png&from=appmsg)

**久久为功 纵深推进粤港澳大湾区建设**

自2017年以来，粤港澳大湾区连续第十年出现在政府工作报告这份国家年度发展蓝图之中，从最初“研究制定发展规划”的起步，到如今“打造世界级科技创新策源地的战略部署”，从“研究制定粤港澳大湾区城市群发展规划”到“出台实施粤港澳大湾区发展规划纲要”，从“落实粤港澳大湾区发展规划纲要”到“更好发挥高质量发展动力源作用”“提升创新能力和辐射带动作用“，再到今年的“打造世界级科技创新策源地”和“打造世界级城市群”。这些表述无不锚定建设富有活力和国际竞争力的一流湾区和世界级城市群的目标，无不紧扣成为新发展格局的战略支点、高质量发展的示范地、中国式现代化的引领地的“一点两地”定位，这说明中央久久为功建设粤港澳大湾区的战略部署，将会滚动推出务实的举措，不断纵深推进粤港澳大湾区打造国际一流湾区。

**推动科技创新和产业创新深度融合**

今年政府工作报告明确提出，“推动科技创新和产业创新深度融合。建设北京（京津冀）、上海（长三角）、粤港澳大湾区国际科技创新中心，打造世界级科技创新策源地。”科技创新和产业创新，是发展新质生产力的基本路径，政策重心正由“重研发投入”向“重转化实效、重产业化落地”延伸，促进二者的融合，将科技创新成果应用到具体产业和产业链上，才能优化提升传统产业，培育壮大新兴产业，前瞻布局未来产业，才能提升全要素生产率，才能加快将科技创新成果转化为现实生产力，为发展新质生产力、实现高质量发展注入强劲动能。粤港澳大湾区经济总量从2017年的10万亿元到2024年突破14.79万亿元，超越了纽约和旧金山两个世界级湾区，2025年有望超15万亿元，以不到全国0.6%的国土面积，创造了全国1/9的经济总量。粤港澳大湾区拥有一批在全国乃至全球具有重要影响力的高校、科研院所、高新技术企业和国家大科学工程，广深港与广珠澳两条科创走廊串联起区域内最活跃的创新要素，世界知识产权组织发布的《2025年全球创新指数》百强创新集群榜单上，“深圳—香港—广州”集群首次跃居全球第一，超过了“东京—横滨”集群、珠澳集群连续两年入围全球百强。这说明粤港澳大湾区依托科技创新和产业创新的雄厚基底+快速融合，不断打通从“实验室”到“生产线”的梗阻，在不断把科技优势转化为产业竞争力和新质生产力，这个曾经的世界工厂，正成为全球科技成果转化高地和产业创新高地，并且快速迈向具有全球影响力的创新策源地。

**“制造+服务“推动产业体系向新向上向强**

今年政府工作报告中提及，深化先进制造业和现代服务业融合发展试点。2018年中央经济工作会议提出，要推动先进制造业和现代服务业深度融合，坚定不移建设制造强国。 2019年国务院办公厅印发的《关于推动先进制造业和现代服务业深度融合发展的实施意见》。随着新一代信息等技术的发展，产业交叉融合发展，产业边界日趋模糊，先进制造业和现代服务业协同和深度融合已成为发展新质生产力、构建现代化产业体系，以及实现中国制造向中国创造转变的关键。广东是制造业大省，2025年工业规模约占全国八分之一，拥有全部31个制造业大类，全省工业增加值4.89万亿元，高新技术企业超7.7万家。深圳的规上工业总产值、工业增加值已连续4年保持全国城市“双第一”。广东也是服务业大省，2025年服务业增加值8.5万亿元，占全国的10.5%，连续41年居全国第一。当制造业的“硬实力”与服务业的“软支撑”相互耦合，联合港澳“超级联系人”与服务业优势，广东发力“制造+服务”，将推动整个产业体系加速向新向上向强，实现高质量发展。加快形成“制造+服务”的乘数效应，这不仅是大湾区高质量发展要回答的“必选题”，更是已经落到实处的“实践题”。所以，今年新春广东高质量发展大会将两业协同作为主题。

**进一步扩大高水平对外开放**

今年政府工作报告中提及，“进一步扩大高水平对外开放。坚持合作共赢，稳步扩大制度型开放，拓展国际循环，以开放促改革促发展。”“以服务业为重点扩大市场准入和开放领域““支持港澳更好融入和服务国家发展大局，发挥港澳背靠祖国、联通世界独特优势和重要作用，促进香港、澳门长期繁荣稳定。“粤港澳大湾区因开放而生、而兴、而强，在“一个国家、两种制度、三个关税区、三种货币、三套法律体系”的条件下建设，具有天然的跨境性，开放的基因与生俱来，同时拥有特别行政区、经济特区和自由贸易试验区等对外开放平台，是“新发展格局的战略支点”。目前，粤港澳大湾区在港口集装箱吞吐量、机场客运量、进出口贸易总额、实际利用外资总额、世界500强企业总部和PCT国际专利申请量等外向型发展指标上，已基本比肩纽约湾区、旧金山湾区和东京湾区，如2025年，大湾区内地9市实际使用外资1057.3亿元，增长14.6%；进出口贸易达9.15万亿元，较2020年增长35.2%，年均增速6.2%，占全国外贸比重达20.1%，对全国外贸增长的贡献度为18%。当前，内地与港澳交流合作持续深化，加快推进规则衔接和机制对接，实现“硬联通”“软联通““心联通“，并且不断深化改革和推进制度型开放，在一般制造业领域已基本实现了全面对外开放，但在服务业对外开放、信息服务互联互通、国际高标准经贸规则对接等领域还存在较大的提升空间，理应成为国家正在积极推动加入《数字经济伙伴关系协议》和《全面与进步跨太平洋伙伴关系协议》的压力测试区、先行试验区。
