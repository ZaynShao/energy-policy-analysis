# 0.3GW/1.2GWh！河北交投隆化郭家屯独立储能项目储能系统采购

项目概况：河北省承德市交投隆化郭家屯独立储能项目，建设储能系统容量为300MW/1200MWh，配套建设1座220kV升压站。
招标范围：储能系统容量为300MW/1200MWh，供货范围包括但不限于：磷酸铁锂电池、变流器(PCS)、变压器、直流汇流设备、电池管理系统(BMS)、能量管理系统(EMS)、储能系统测量计量、备品备件、专用工具、附属设备等的供货、工厂试验、包装、运输、交货，现场指导舱体安装以及负责舱体内所有设备、设施安装及单体调试、协助配合验收及成套设备质保期服务等。
交货地点：河北省承德市隆化县项目现场。
交货期：计划设备于2026年9月30日开始供货，11月30日前全部完成供货。
投标人业绩要求：2023年7月1日至投标截止日，国内具有累计达到5000MWh磷酸铁锂电池储能系统设备合同业绩，且用于计算上述累计业绩的每一份单项合同，其储能系统容量均须不小于100MWh。任何容量小于100MWh的合同，不计入累计业绩。
项目不接受联合体投标。
