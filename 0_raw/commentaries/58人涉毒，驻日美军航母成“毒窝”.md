# 58人涉毒，驻日美军航母成“毒窝”

曾在日本驻扎的美军“里根”号航空母舰58名水兵因涉毒受到处分。
美国媒体当地时间6月26日爆料，曾在日本驻扎的美军“里根”号航空母舰一度成为“毒窝”，58名水兵因涉毒受到处分，其中6人被送上军事法庭。
美国《星条旗报》援引法庭文件和美军官员的话报道，2023年3月，以日本横须贺为母港的“里根”号上一名水兵在岸上军营里坠亡，经尸检发现其体内有致幻药物残留。美国海军部刑事调查局人员查看这名水兵的手机后，发现新的线索，随即启动更大范围调查，最终挖出“里根”号水兵中的毒品网络。
根据报道，调查人员“发现和捣毁一个持有、服用和传播毒品的网络”。其中一名水兵于2022年2月至2023年5月先后7次通过美国邮政局邮递服务收到致幻药物，每次数量从350片至1000片不等。他还在“里根”号水兵中分发这些毒品。
报道说，这名水兵和其他5名水兵被送上军事法庭，受到监禁等惩处。另有52名水兵因服用毒品受到纪律处分。
“里根”号航母2024年春季结束在横须贺为期近10年的驻扎，返回美国。
