# 智库专家看两会 | 陆如泉：关于能源强国建设的思考

**陆如泉**

能源战略学者

中国石油集团经济技术研究院院长

中国石油集团国家高端智库研究中心常务副主任

2026年政府工作报告提出，制定能源强国建设规划纲要。这标志着我国开启了以能源高质量发展支撑中国式现代化的新征程。

  

**01**

**能源强国的内涵以及我国建设能源强国的重大意义**

建设能源强国是当前及今后一个时期我国在能源领域新的战略总目标。综合各方观点看，能源强国的核心内涵是**从依赖资源与资本转向依靠技术与体系，从追求规模优势转向构建质量胜势。其本质是实现能源供给保障、技术引领、产业竞争、系统协同和治理引领的“五个强大力”。**能源强国是我国建设中国特色社会主义现代化强国的重要基石，与制造强国、科技强国等共同构成了强国体系的支柱。

  

**建设能源强国是从国家发展与安全全局出发的必然要求。首先，建设能源强国是支撑现代化强国建设的物质基础。**中国式现代化需要坚实的能源“底座”。由于人工智能与算力的爆发式增长，以及城镇化的稳步推进，预计“十五五”时期，我国每年新增用电量巨大。建设能源强国是为了保障经济社会发展和人民美好生活的用能需求。**其次，建设能源强国是增强国家安全与战略主动的关键。**当前，能源已成为大国战略博弈的焦点。作为全球主要能源进口国，我国需要通过建设能源强国，将能源饭碗牢牢端在自己手里，提升在国际竞争中的主动权和话语权。**第三，建设能源强国是推动绿色转型与引领全球变革的路径。**能源领域是二氧化碳排放的主体和实现“双碳”目标的主战场。建设能源强国，能够加快绿色低碳转型，同时凭借我国在新能源领域的产业和技术优势，为全球能源转型与气候治理贡献中国方案。

  

**02**

**我国已具备从能源大国迈向能源强国的基础**

经过多年发展，我国已具备建设能源强国的坚实基础。**一是供应保障强大。**近十年，我国能源自给率稳定保持在80%以上，已建成全球门类最全、规模最大的能源体系。**二是绿色转型领先。**我国已建成全球最大、发展最快的可再生能源体系，风电、光伏发电装机连续多年稳居世界第一，每消费的3度电中有1度是绿电。**三是产业优势突出。**当前，我国拥有全球最完整的新能源产业链，同时具备全球领先的化石能源加工与油气装备制造能力。**四是科技创新突破。**我国已在特高压输电、深地油气钻探、先进核电、智能电网、新能源储能等领域实现全面引领。**五是国际合作广阔。**尤其在油气领域，中国作为全球主要的石油天然气进口国，与全球几乎所有的油气出口国建立起稳定的合作关系，对提振我国能源国际话语权和影响力具有关键支撑。

  

**03**

**我国建设能源强国的路径与挑战**

未来5-10年，建设能源强国的中心任务是加快建设清洁低碳、安全高效的新型能源体系。关键路径包括：**大力提升新能源主体地位。**坚持风光水核等多能并举，持续提高新能源供给比重，到2030和2035年，非化石能源占能源消费总量比重分别达25%和30%以上。**稳妥推动化石能源转型。**推动煤炭和石油消费达峰，加强化石能源清洁高效利用与兜底保障。主要是实现煤炭稳产稳供，推动油气增储上产，确保能源安全平稳过渡。**着力构建新型电力系统。**提升电网对高比例可再生能源的消纳和配置能力，提升电力系统的灵活调节和安全韧性水平。**强化科技创新驱动。**攻关关键核心技术，前瞻布局氢能、核能、长时储能等未来产业，推进“人工智能+能源”融合试点。抢占能源科技战略制高点，培育能源领域新质生产力。**深化体制机制改革。**持续深化全国统一电力市场建设，健全适应新型能源体系的市场机制和价格机制。激发市场主体活力，优化能源资源配置效率。

  

分能源品种来看，总体路径为**做优煤炭、做稳石油、做实天然气、做大新能源、做强二次能源（电力）。所谓做优煤炭，**即一方面要发挥煤炭在能源供应的兜底保障作用，另一方面须在兜底保障和降碳降耗上取得平衡，优化发展。**所谓做稳石油，**就是无论什么情况下，年产2亿吨石油的“底线”必须保住，这是确保能源安全主动权在我手中的关键。**所谓做实天然气，**就是天然气产业必须以实实在在的储产量、价格、消费和政策，推动天然气在我国一次能源消费结构中的占比不低于10%。**所谓做大新能源，**新能源必将成为未来新增能源供应的主体，这已成为全国共识。**所谓做强电力，**即建设以新能源为主体的新型电力系统，筑牢能源安全转型的“主动脉”。

  

总体看，我国正开创一条全新的能源强国之路。该路径与应对气候变化、推动可持续发展的全球目标一致，本质是通过我国在全球化石能源市场中的地位以及在新能源技术、装备、标准和系统上的全球引领优势，实现能源的联通、自主、安全、绿色与强盛。
