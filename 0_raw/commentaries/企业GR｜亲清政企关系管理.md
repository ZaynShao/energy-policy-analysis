# 企业GR｜亲清政企关系管理

中国经济在赶超体制结束后正式进入高质量发展时代，发展逻辑的转换带动政企关系深刻重塑。
亲清政企关系之下，不少企业对如何与政府打交道感到迷茫，走得太近怕踩红线，离得太远又错失机遇。
一、构建亲清政商关系
兰小欢教授在《置身事内》中提到：
在我国，政府不但影响“蛋糕”的分配，也参与“蛋糕”的生产，所以我们不可能脱离政府谈经济。
政策是最大的营商环境，从产业扶持、税收优惠到资质认定、项目申报，企业的发展几乎每一步都与政府政策息息相关。
近年来，从中央到地方密集出台了构建亲清政商关系的一系列政策文件，意味着政府正在主动打开与企业沟通的大门。
对企业而言，必须靠近政府，及时掌握政策动向、充分享受政策红利、有效表达行业诉求。同时，GR部门的核心价值之一正是亲近政府，帮助企业有能力、有方法、有策略地走进去，将政府资源转化为企业的竞争优势。
成功的政策背后是成功的协商和妥协，而不是机械的命令与执行。
所以企业GR在产业政策引导中，必然离不开相关政府部门的支持。
正式文件印发之前必须向政策制定部门、相关部委、内部各司局、行业协会、智库机构、行业专家、地方政府等及时反馈政策诉求；接下来，在征求意见阶段，通过被征求意见单位书面反馈政策建议，以专业且符合产业发展的逻辑完成政策引导工作。
二、政企交流的合规风险
过去的政商关系中，权力寻租的现象并不鲜见。企业绑定权力的模式代价是惨痛的，不仅面临巨大的合规风险，更可能在权力更迭中遭遇灭顶之灾。
勤上光电的案例是典型教训。
2007年至2012年间，勤上光电实际控制人李旭亮为谋求企业在科技项目申报、产品推广等方面的支持，向广东省科技厅原厅长李兴华贿送35万股原始股、公司干股及现金，又向时任东莞市科技局局长、广东省科技厅副厅长叶某图行贿共计541万元。2013年，李旭亮因接受调查，又向时任广东省纪委常委曾某荣行贿。
法院最终认定：
勤上集团和李旭亮多次向国家工作人员行贿，共计人民币1068万元，港币10万元，勤上集团犯单位行贿罪，判处罚金300万元；李旭亮犯单位行贿罪，判处有期徒刑二年，缓刑四年。
去年豪尔赛公司案例同样警示风险。因涉嫌单位行贿罪被立案调查，法院判决公司犯单位行贿罪，判处罚金700万元；前董事长戴宝林犯单位行贿罪，获有期徒刑三年、缓刑四年，并处300万元罚金，公司所退违法所得被追缴。
豪尔赛于公告中表示：
罚金和所退违法所得共计2851万元，占公司最近一期经审计归属于母公司股东的净利润（绝对值）的15.90%。
今日宣判无期徒刑的许家印更是值得引以为鉴。
恒大集团及许家印通过行贿等手段取得金融机构控制权，违法套取信贷资金、保险资金归恒大集团使用，实施了单位行贿、违法发放贷款、违法运用资金等犯罪行为。
当然，警惕合规风险不是畏首畏尾、不敢作为，而是要求我们在合规框架内积极作为，比如不搞利益输送、不走权力路线、不踩纪律红线，将政企关系建立在政策沟通、价值共创的阳光下。
其一，警惕利益输送的灰色地带，企业应建立清晰的内控标准，明确政企交往中“什么不能送、什么不能请、什么不能承诺”；
其二，守住信息合规的边界， GR岗位天然掌握政府沟通渠道和密件政策信息，必须严格区分“公开政策信息”与“涉密申报信息”，尤其在当下网络、社群、微信传播风险下要警惕信息安全；
其三，防止过度依赖个别官员，企业的GR策略应着眼于与政府部门的制度化对接，而非维系与个别官员的私人关系；过度依赖关键个人，是企业合规管理中最隐蔽也最危险的方式。
三、结束语
在亲清政企关系成为政策主旋律的今天，企业需要找到正确的政企相处之道。
靠近政府，读懂政策意图、用好制度红利、把握产业方向，将公共政策转化为企业发展的实际助力；同时，远离权力、拒绝灰色交易、严守合规底线、坚守市场逻辑，不走权力路线。
