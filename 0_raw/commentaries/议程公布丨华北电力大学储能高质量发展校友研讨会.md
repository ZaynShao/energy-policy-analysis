# 议程公布丨华北电力大学储能高质量发展校友研讨会

为深入贯彻国家 “双碳” 发展战略，推动储能产业创新发展，促进华电校友、业内同仁在储能领域的技术交流、资源对接与产业合作，“2026年第1期储能高质量发展校友研讨会”将于2026年8月22日（星期六）在北京举办。
本次研讨会既面向校友，也热忱欢迎广大行业专家、企业代表及各界有识之士踊跃参与。扫描下方二维码即可完成报名，席位有限，诚邀您尽早锁定参会资格，期待与您共话储能未来！
后续还将不定期举办研讨活动，常态化联动各地能源主管部门、电网公司、电力交易机构，各区域校友组织举办区域研讨，聚焦各场景产业实操痛点深度交流。
