# 深圳优良创新生态让独角兽“翩翩起舞”

独角兽企业是衡量城市创新活力、新质生产力发展水平的核心风向标之一。在胡润研究院刚刚发布的2026全球独角兽榜单中，深圳44家企业上榜，位居全球城市第六位。回看过去10年，深圳独角兽企业从10家增长到44家，从互联网、消费硬件等产业起步，到“硬科技”扛起大梁，数字的跃升，折射出深圳创新生态优化、产业赛道迭代的进阶之路。
从数量攀升看成长支撑
独角兽公司一般指成立不超过10年，估值超过10亿美元，小部分估值超过100亿美元的企业，可以说是新产业、新技术、新业态、新模式的典型代表。
早在2017年，胡润研究院首次发布了大中华区独角兽指数。彼时，深圳以10家独角兽企业位列第四，包括大疆、菜鸟网络、微众银行、优必选、大地影院、乐信集团、土巴兔等企业，互联网行业仍为主流；2018年深圳上榜企业增至15家，全棉时代、奥比中光、丰巢科技以及跨越速运等企业冲上榜单；2019年，胡润研究院首次发布全球独角兽榜单，深圳18家企业上榜排名第六。
自此，深圳独角兽企业步入高速增长通道。上榜企业从2020年20家增长到2021年的32家，2022年稳定增至33家。2024年，上榜企业再度迎来跨越增长达42家，2025年3家独角兽企业完成上市“毕业”，数量回落至37家，再到如今冲高至44家。10年间，深圳独角兽企业总量实现3.4倍增长。
“独角兽企业的快速增长、持续扩容，源于深圳独有的创新发展沃土。”综合开发研究院（中国·深圳）财税贸易与产业发展研究中心主任韦福雷认为，创业投资和耐心资本是支持独角兽企业发展的关键要素。深圳创业投资综合实力位居全国前列，引导金融资本投早、投小、投长期、投硬科技，为企业成长提供资本支撑。“此外，深圳的创新资源和成果集中在企业，在市场化导向下，产业转化和企业成长就能够非常迅速。”
从产业分布看赛道布局
10年间，独角兽企业的分布领域持续扩容，产业的“新陈代谢”也折射出深圳不断涌现的新赛道新布局，产业结构持续优化。
从行业分布看，2017年上榜的10家深圳独角兽企业中，互联网服务、互联网金融、机器人领域分别有2家，房产服务、文化娱乐、物流服务、硬件各1家。到了2021年，入选的32家企业涵盖的领域悄然生变，以人工智能、新能源、消费、机器人等行业为主，奥比中光、碳云智能、越海全球、百果园、喜茶等，比亚迪半导体、华大智造、酷开科技和开沃汽车、顺丰快运和丰巢科技纷纷上榜。
此后，深圳的独角兽企业“硬科技”特征愈发明显。2025年37家企业中半导体行业占比最多，包括嘉立创、比亚迪半导体、航顺芯片、云英谷、飞骧科技和云豹智能；人工智能与机器人行业位居第二，共有5家独角兽企业上榜，包括引望智能、大疆、元象、元戎启行和思谋科技。这些企业在各自赛道里均处于领先地位，具有强大的市场竞争力和发展潜力。
再看今年，深圳44家独角兽覆盖15个行业。机器人领域聚集8家居首，包括大疆及年内新晋的智平方、众擎机器人、自变量机器人等5家，与北京、上海同量；半导体6家，AI领域5家。
“深圳有着大量的国家级高新技术企业，就像是养了一池的鱼，在良好的产业生态下，不断有‘鲤鱼跃龙门’成长为独角兽企业。”韦福雷表示，从早期的物流、互联网以及网红企业，到如今的具身智能、数字能源、半导体以及集成电路等，在成熟产业出现衰退前，深圳就已经开始谋划新的增长领域，产业结构不断实现梯度转型，传统产业向新质生产力迭代。
从企业更迭看创新生态
持续扩容的独角兽队伍，深圳孵化全球独角兽的独特模式或从榜单中可看出。
每年上榜的深圳独角兽企业中，都有不少来自深圳大厂培育孵化企业的身影。比如金融科技独角兽微众银行诞生在腾讯构建的社交与金融生态；人工智能独角兽引望智能成长于华为构建的智能汽车产业生态；半导体独角兽比亚迪半导体从比亚迪构建的新能源生态中成长；消费电子独角兽荣耀成长于华为智能终端生态体系；大数据独角兽平安智慧城市成长于平安集团构建的数字经济生态。
今年新进榜单的卓驭科技，前身为大疆的车载事业部，2023年从大疆分拆独立运营，专注于研发覆盖高速、城市、泊车全场景的高阶智能驾驶系统，2025年9月获得中国一汽超36亿元战略投资后估值超100亿元。
正是得益于由产业链“链主”构建的产业生态和全产业链创新优势，越来越多的全球独角兽企业在深圳诞生。这些企业与“链主”企业在整体创新生态中进行高效协作，降低创新成本，提高创新效率。
“今年首次入榜的拓竹科技，是深圳近年来涌现出来的典型企业，它既有硬科技的支撑，也有国际化的视野。”韦福雷分析道，深圳有很多企业，从创业开始瞄准的就是国际市场，利用国内的产业链、供应链，迅速打造出面向海外消费市场的产品，从而实现自身的迅速发展。（深圳特区报 记者 邹媛 /制图 南方日报 记者李荣华）
