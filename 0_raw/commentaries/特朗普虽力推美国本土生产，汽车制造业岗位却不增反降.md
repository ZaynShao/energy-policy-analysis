# 特朗普虽力推美国本土生产，汽车制造业岗位却不增反降

加入供应链产业群，请加微信gasgoo88，出示名片
盖世汽车讯 据外媒报道，特朗普政府将振兴美国制造业作为施政核心，希望通过大规模关税政策创造就业岗位。但美国劳工统计局的数据显示，汽车制造业就业岗位正在减少。
特朗普8月4日在社交平台TruthSocial发文称：“制造业正蓬勃发展！数万亿美元新增投资涌入美国，更多工厂落地，更多工程项目开工，高薪岗位接踵而至，这份成果有目共睹。”
但美国汽车零部件行业的现实却并非如此。美国劳工统计局初步的季节性调整后数据显示，7月美国机动车及零部件企业就业人数下滑约1%至96.45万人；而新关税政策生效前的2025年3月，该数值为97.53万人。
图片来源：美国白宫
这组数据与特朗普希望依靠关税恢复美国制造业就业的核心目标形成反差。行业岗位流失，主要来自零部件供应商裁员；车企普遍普及自动化，同时成本持续抬升，进一步加剧就业收缩。
8月7日发布的最新就业报告，暴露特朗普政府面临的现实矛盾：美国对汽车行业企业加征关税，初衷是把制造产能和就业带回本土。过去一年，在上述政策推行期间，美国汽车制造业岗位小幅减少，原因包含裁员、员工主动离职、退休、人员离世，以及人员流失后企业冻结招聘。
中西部经济政策研究所经济学家Frank Manzo表示：“汽车行业是关税政策冲击的重灾区。部分企业得到政策保护，但大量其他企业承受成本上涨带来的负面影响。”
关税并非唯一影响因素。电动车普及速度不及预期，零部件厂商承受巨大压力，产线改造投入没能换来预期投资回报。伊朗战事推高石油及其衍生品价格，抬升多个制造业领域的生产成本。
尽管面临诸多挑战，美国整体制造业活动仍在扩张。美国供应管理协会（ISM）备受关注的指数显示，7月制造业经济活动连续第七个月实现扩张，该指数读数创下2022年5月以来新高。
但制造业产出增长，并没有转化成更多就业岗位。
这反映出汽车零部件企业自动化程度不断提升。人工智能热潮带动股市大涨，同时也让制造企业更愿意在产线上部署机器人来提高产能。Frank Manzo称，多年来美国工厂一直在持续提高自动化水平。
不过长期来看，产业回迁战略仍有望为美国创造更多制造业岗位。丰田7月宣布，计划在圣安东尼奥投资36亿美元建设总装工厂，将Tacoma皮卡的生产迁回美国本土。本田正考虑在北美建设第八座整车工厂；福特计划2030年将部分林肯车型的生产从中国转移至美国。戴姆勒卡车也计划今年动工新建工厂，预计2029年投产。
零部件制造岗位缩减，经销商端就业保持稳定
7月可以获取汽车制造业整体就业数据，但零部件供应商与汽车经销商的就业统计仅更新至6月。
汽车经销商整体就业市场基本平稳。
6月初步数据显示，新车经销商就业人数较5月减少2,000人，但和去年同期基本持平。
美国汽车经销商协会首席经济学家Patrick Manzi表示：“汽车销量依旧稳健，但同比需求没有出现大幅上升或下滑。市场环境并不支持企业大规模扩招或是裁员。”
经销商端就业保持平稳，数据却呈现出明显分化：零部件供应商岗位缩减，整车总装厂岗位有所增加。
美国联邦政府初步统计数据显示，6月汽车零部件供应商就业人数同比减少1.3万人，降幅2.5%，反映出零部件厂商仍难以消化关税压力，同时还要面对电动车普及放缓带来的冲击。
美国劳工统计局数据显示，零部件企业岗位流失的同时，整车总装工厂就业人数增加5,000人，同比增幅1.7%。
多位经济学家向《美国汽车新闻》表示，这种分化说明：车企比较容易把柔性产能和整车总装环节回迁美国，但价值链上游环节的回迁，即便能够落地，也需要更长时间。
汽车研究中心行业经济学家Tyler Harp说道：“即便车企在某座工厂开启第三班生产、提升整车产量，但配套供应链未必会同步迁回美国。在过渡期内，我们依然需要依赖进口零部件。”
此外，美国零部件厂商既为本国工厂供货，也向加拿大、墨西哥及海外工厂供货。受特朗普关税冲击，加拿大、墨西哥汽车生产陷入停滞甚至下滑，也会传导至美国本土零部件企业，令其遭受损失。
Tyler Harp称：“美国本土产量在增长，但加拿大和墨西哥产量持平甚至出现下滑。我认为这会给美国零部件供应商带来相当大的风险。”
