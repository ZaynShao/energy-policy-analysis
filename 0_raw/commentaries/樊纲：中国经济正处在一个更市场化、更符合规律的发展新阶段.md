# 樊纲：中国经济正处在一个更市场化、更符合规律的发展新阶段

樊纲现场图。
8月12日，2026博鳌系列活动全体大会在海南召开，中国经济体制改革研究会副会长、综合开发研究院（中国·深圳）原院长樊纲发表“全球变局的宏观周期与中国经济成长”的演讲。
中国经济结构性调整，触底过程可能快于日本当年
樊纲表示，中国经济正经历一次更符合市场经济规律的结构性调整，房地产市场已出现较为快速的价格出清，触底过程可能快于日本当年。
中国40余年高增长未出现大的经济衰退，当前这轮调整源于市场泡沫、投机和过热后的自然破裂，政府行政手段虽在抑制泡沫阶段发挥了作用，但应对萧条仍有提升空间。
值得关注的是，货币政策在低谷期效果有限，资金空转现象明显，他认为应该进一步加大财政政策力度。目前每年1万亿特别国债仅占GDP约0.7%，拉动经济力度仍显不足。
从需求侧看，中国长期“重供给轻需求”的结构性问题正得到正视。樊纲指出，当前“十五五”规划已将市场需求视为最稀缺资源，宏观经济学本质上是需求决定论。消费观念也出现积极转变，年轻一代科技新贵开始注重居住品质，大城市豪宅成为市场销售主力，这标志着新经济增长逻辑的开启。
樊纲强调，中国经济正处在一个更市场化、更符合规律的发展新阶段。
中国新能源产业有望为全球能源转型提供关键支撑
樊纲表示，新能源发展过去的主要驱动力来自低碳和应对气候变暖。但近年来，随着中东战事升级，各国深刻意识到化石能源在供应安全和地缘政治上的脆弱性，能源安全由此成为新能源发展的全新引擎。
太阳能则是最平等、最安全的能源。无论在戈壁、水面还是屋顶均可发电，不受地理和资源分布限制，而核电、风电、水电乃至石油天然气均有明显的不平等性。
樊纲认为，可以预见，未来5至10年，全球将大力推动清洁能源，尤其是太阳能。若中东冲突持续，油价上涨乃至供应中断风险加剧，加之AI产业对电力需求激增，新能源的发展将变得更加迫切。
在这一领域，中国恰好处于全球领先地位，拥有先进的光伏技术和庞大的产能，具备强大的出口能力。新能源产业已成为中国极具前景的朝阳产业，有望为全球能源转型提供关键支撑。
他表示，这不仅是应对气候变化的举措，更是保障国家能源安全的战略选择。中国应抓住这一机遇，巩固和扩大技术优势，推动新能源产业链持续升级，为全球绿色低碳发展贡献中国力量。
中国新的增长点、新技术和产业正在成长
樊纲表示，中国已告别廉价劳动力比较优势，但通过后发优势成功转化为创新能力，形成新增长动力。
中国过去依赖劳动力便宜的比较优势，随着收入增长，这一优势在与泰国、马来西亚等同等国家竞争中已丧失。但好在后发优势发挥作用，通过学习引进消化吸收，逐步积累创新能力。经过四五十年努力，中国在AI、新能源、生物科技等高新产业形成新赛道。同时，传统制造业也达到世界级竞争力，欧洲近期大量进口中国风扇、空调等产品即为例证，出口成为经济增长重要支撑。
与日本30年萧条相比，中国有三点显著不同。第一，日本市场出清缓慢，房价下跌拖了20年才触底，而中国房地产出清更为迅速。第二，日本当时城市化已基本完成，农民不足劳动力5%，城市化发展动力不足，而中国城市化率仅64%，城市化潜力尚未充分释放，仍有持续增长的空间。第三，日本当时缺乏新技术与新产业，且半导体等优势产业转移海外，中国则拥有蓬勃发展的新兴产业，如新能源、AI等，且传统制造业持续升级，真正换了赛道。
樊纲表示，虽然当前增速放缓，但中国拥有新的增长点、新技术和产业正在成长。同时，要注意用好城市化政策，让外来劳动人口真正融入城市，释放需求潜力。总体看，中国经济正处于新旧动能转换期，具备持续发展的基础，应当保持信心。（凤凰网）
