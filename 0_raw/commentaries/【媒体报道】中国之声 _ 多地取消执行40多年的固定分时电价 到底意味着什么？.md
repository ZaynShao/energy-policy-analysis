# 【媒体报道】中国之声 | 多地取消执行40多年的固定分时电价 到底意味着什么？

今年以来，国内电力市场迎来新变革：贵州、湖北、陕西等地宣布，取消固定分时电价。这意味着电费何时贵、何时便宜，不再由当地政府部门统一规定，而是跟着市场行情走。我国执行了40多年的固定分时电价机制，为何会在今年被各地纷纷取消？电价“随行就市”到底会带来哪些影响？对大多数普通居民而言，每个月的电费账单会跟着变吗？
固定分时电价机制，简单来说就是政府部门根据用电规律将一天中的用电分为高峰、平段、低谷等固定时段，并设定相应的固定价格浮动比例，高峰时段电价贵，低谷时段电价便宜。希望通过价格的手段引导用户错峰用电，从而更好地保障电力系统的稳定运行。中国电力企业联合会规划发展部副主任韩放表示，这套机制的设定跟电力的基本特性直接相关 。
韩放：电与其他品种不同，是即发即用的，需要供应与使用时时匹配。我们一天24小时用电，夜间用电较少，白天用电较多。高峰时段就需要很高的电力供应能力，这会导致成本升高。在此背景下，我们出台了分时电价，即不同时段价格不同。例如用电高峰时段电价相对较高，鼓励用户在可调节的情况下将用电需求转移至电价较低的时段，从而使用电需求在全天相对均衡。这对系统运行和经济性都比较有利。
华北电力大学 电气与电子工程学院教授丁肇豪表示“固定分时电价机制”从20世纪八十年代就已经开始在我国施行，在过去的很长时间它都发挥着很好的电力调节作用。
丁肇豪：传统电力供需的规律相对比较固定，因为原先的供给以火电为主，占比高，供给比较可控、稳定；用户的高峰和低谷也有相对稳定的规律。因此，固定的分时峰谷电价时段比较明确，也能发挥较为清晰的引导作用。所以过去这么多年我们也一直在坚持。
但是，今年以来，贵州、湖北、陕西等多地都宣布，取消这种固定分时电价，电价依然会在不同时段展现出不同的价格，但是电费何时贵、何时便宜，不再由当地政府部门统一规定时段，而是跟着市场行情走。丁肇豪强调，供需关系决定电力价格，改变了定价规则自然是因为我国的电力供应和需求都发生了明显的变化。
丁肇豪：从供给侧来看，电源结构发生了变化。原来我们主要是稳定可控的火电，但现在风电、光伏持续发展。原本负荷较高、电力供给紧张的中午，由于光伏发电大增，现在反而变成供给相对宽松、价格较低的时段。而晚高峰则因光伏出力下降，再叠加居民和工商业用户负荷增加，供给更为紧张。如果我们沿用原有的固定分时峰谷时段，就无法真实反映电力系统的供需特性，出现该便宜时不便宜、该贵时不贵的错位和价格扭曲。第二，负荷方面也有一些变化。像电动汽车、新的工业负荷（如数据中心）、用户侧储能等负荷进入系统，改变了电力系统供给和需求的时段分布，使得原有分时电价更难以真实反映供需信号，进一步说明固定时段的分时电价有调整的必要性。
刚刚说的跟着市场走，这个市场就指的是电力市场。从2015年开始，我国着力建设电力市场机制，去年底，我国省级电力现货市场实现基本全覆盖。丁肇豪说，电力现货市场如同“电力股市”，通过实时竞价，形成准确反映当下电力供需情况的真实电价，引导电力资源在全国范围内高效配置。
丁肇豪：现在我们有了现货市场，它可以按1小时，甚至15分钟或更短的周期来反映电力供需变化，从而形成更动态、更精细的时段价格信号。既然市场能够发现不同时段的电力价值，我们就没有必要再为这些进入市场的用户保留一个行政制定的固定分时电价。因此，我们希望利用市场，充分发挥市场的价格信号来反映系统供需；让大家感受到的信号，以及大家响应价格信号所做出的反应，是真实地在帮助电力系统改善电力平衡。
目前，已经有越来越多的地区明确取消固定分时电价，改革进度根据各地电力市场建设进展等情况略有不同。但可以肯定的是，计划主导的固定分时电价正逐步退出，市场化分时电价将成为主导。
不过，在各地纷纷取消固定分时电价的消息传出后，引发了很多关注。大家担心电价随行就市会导致剧烈波动，尤其很多居民用户担心自己的电费账单会上涨。针对这些疑惑，韩放给出了明确答案：取消固定分时电价只针对进入电力市场的工商业用户，对普通居民用电没有影响 。
韩放：居民、农业以及学校、机关、医院等公益性用电，属于国家保障性用电，这一政策对这些用户没有影响。文件明确，只针对市场化的工商业用户。此外，目前还有一些中小用户由电网代理购电，其价格由政府核定，变化也不会太大。影响较大的是真正完全进入市场化的用户，即规模较大的工商业用户，他们通过售电公司代理购电，其价格将随行就市，与实际市场价格挂钩。
那么，普通居民真的完全感受不到变化吗？也不尽然。 当居民开着电动汽车去公共充电桩充电时，也会体验到市场化分时电价带来的不同：充电电价不再按固定的峰谷时段起伏，而是随电力市场真实的供需波动实时变化。正如丁肇豪所言，取消固定分时电价的意义，正是让用户响应电力系统运行状态发出的“真信号”，而非人为制定的信号，从而更好地促进新能源消纳和电力系统的稳定运行。
丁肇豪：进入市场的用户所感受到的价格信号，不再是传统行政制定的峰平谷固定时段和固定定价，而是电力系统实际运行状态的体现——例如光伏出力突然减少时，供需趋紧；光伏大发时，供需宽松。通过电价信号将更真实的电力系统运行状态反映出来。这并非涨价或降价的问题，而是让大家对价格信号的响应是对真实信号的响应，而不是对人为制定信号的响应。这样可以更好地服务于能源电力系统的发展建设，也有助于促进新能源的消纳。（来源：中国之声）
