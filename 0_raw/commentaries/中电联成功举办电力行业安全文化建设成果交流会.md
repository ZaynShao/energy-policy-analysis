# 中电联成功举办电力行业安全文化建设成果交流会

6月29日，中国电力企业联合会电力安全生产与应急管理分会联合中国电力企业管理杂志社在浙江海盐成功举办电力行业安全文化建设成果交流会。中电联党委副书记、秘书长郝英杰出席会议并讲话，监事长潘跃龙作主旨发言。来自国家电网、南方电网、中国核电、中国华能、中国大唐、中国华电、国家电投、国家能源集团等电力企业及所属单位代表200余人参会。
郝英杰在讲话中指出，近年来我国电力安全生产总体水平大幅提升，在安全文化建设领域涌现了一大批可复制、可借鉴的典型成果。随着新能源装机在电力系统中占比不断攀升，全面建设新型电力系统面临新挑战。各电力企业要提高政治站位，坚持以习近平新时代中国特色社会主义思想为指导，全面落实党中央、国务院关于安全生产工作的决策部署，牢固树立“人民至上、生命至上”的安全发展理念，发挥安全文化带动引领作用，进一步统一思想、凝聚共识，守安于心、践安于行，奋力开创电力安全文化建设新局面，为新型电力系统和新型能源体系建设保驾护航，推动电力行业安全发展、行稳致远。
潘跃龙在发言中指出，安全文化建设是打通“思想”与“行动”的治本之策，是守护能源安全的内在保障，是应对新型风险的治本良方。要深刻把握新时代电力安全文化建设的时代使命，正视当前安全文化建设存在的突出问题，推进文化嵌入治理机制、走进现场，推动电力安全文化延伸，大力推行安全文化建设“五个强化”——强化思想引领、强化制度建设、强化行为养成、强化科技支撑、强化成果转化，全面夯实电力行业本质安全根基。
会议组织与会代表参观秦山核电科技馆，切身感受“核电红船”品牌安全文化建设成效。
