# 特变电工新能源：大功率跟/构网型组串式PCS“亮剑”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIu7QMTpOjQ9FdWMLoVYJDAelEScibfRwm0aTFDgrj7z0cwSzGG75Q3HYL3frVZGl2TvbUZcEcKdfjb8CUCVOSUToo0kpu7bp4Nc/640?wx_fmt=png&from=appmsg)

特变电工新能源在ESIE 2026上重磅推出了两款定义下一代标准的关键新品：**构网型组串式储能变流器与500kW组串式光伏逆变器**。两款新品分别针对储能系统与光伏发电的核心电能转换环节，可视为新型能源系统的“心脏”与“引擎”。

其中**构网型组串式储能变流器**是特变电工新能源对储能系统核心——变流器（PCS）的一次彻底重构。**其最大亮点在于采用了全智能液冷散热与超高功率密度集成设计**。通过创新拓扑与热管理，实现同等功率等级下体积更小、重量更轻；相较前代机型，体积密度与重量密度均大幅提升。这使得储能电站的占地面积得以大幅压缩，特别适用于土地资源紧缺或改造升级项目，直接降低初始投资与土地成本。

在光伏侧，特变电工新能源将组串式逆变器的单机功率推向了**500kW**的全球新高度。产品适配5/5.5MW光伏大基地子阵设计，通过支持直流1600V与交流1000Vac的更高电压平台，有效降低了系统线损与平衡系统成本，相比主流330kW方案，预计可为电站带来显著的初始投资节约。
