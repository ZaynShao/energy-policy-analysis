# 年中大家谈｜聚智创新谋长远，决胜一流启新篇

在集团公司2026年年中工作会议上，戴厚良董事长强调必须加快提升科技创新能力，加快建设国家战略科技力量和能源与化工创新高地，这为经研院推进“双一流”智库建设标定了新方位。我们要精准识变应变，以软科学研究数智化重塑为牵引，打造标志性成果，主动嵌入能源强国建设大局、深度融入集团改革发展全局。为凝聚共识、决胜下半年，经研院微信公众号今起开设“年中大家谈”专栏。
首期特邀戴家权、张运东、刘佳三位首席专家，围绕科技创新与智库建设分享真知灼见：
深耕模型强预测，数智赋能助决策
戴家权
首席经济学家
集团公司年中工作会议强调“探索无尽前沿、矢志创新攻坚”，并明确提出着力强化人工智能赋能科技创新、引领科研范式变革，为软科学创新清晰指明了方向。作为国家高端智库和集团公司决策参谋部，软科学研究的科技创新，核心在于理论框架的创新、研究工具的革新和研究范式的升级。近几年，经研院大力实施数智赋能工程，建成了油气市场模拟与价格预测重点实验室，推动软科学研究加速向科学化、数智化转型。其中，重点实验室在油气市场定量化模型体系建设和大数据、AI技术应用中取得初步突破，打造的一体化研究工作平台及市场预测技术达到国内领先水平，有力支撑了集团公司生产经营决策。实践证明，软科学创新必须坚定走“定量化、模型化、数智化”之路。
下一步，我们将按照经研院年中工作会部署，以科技创新为牵引，持续深化理论、工具和范式创新，加快构建具有经研院特色的理论方法体系，不断提升研究的前瞻性、精准性和实效性，以更高水平成果服务集团公司高质量发展。
识变应变谋长远，惟精惟勤启新篇
张运东
首席专家
集团公司年中工作会锚定全面建成国家战略科技力量与能源化工创新高地的目标，动员广大干部员工探索无尽前沿、矢志创新攻坚。面对新形势，我们必须主动识变、科学应变，把创新主动权握在手中。当前，全球科技革命与产业变革加速演进，我国正从全球科技的“参与者”向“开拓者”跨越，能源行业面临绿色低碳转型与数字化变革的双重倒逼。经研院长期深耕油气市场研判、能源地缘政治分析、科技创新管理等优势领域，积累了穿透周期的分析方法和扎根一线的实践认知。我们必须胸怀“国之大者”、深耕“企之要者”，向上精准对接国家和集团公司战略需求，向下深度嵌入产业实践，构建起有经研院特色的学术、学科和话语体系，真正发挥“看桅杆”的前瞻洞察作用。
下一步应聚力三方面：一是聚焦能源强国、国企改革、新质生产力等重大命题，产出标志性成果；二是围绕高水平科技自立自强，系统开展颠覆性技术布局预测和科技体制机制改革研究；三是形成特色研究方法、工具模型和理论体系，提升软科学的硬支撑能力。以“功成不必在我”的境界和“功成必定有我”的担当，久久为功，书写科技创新驱动高质量发展的时代答卷。
把准定位担使命，潜心治学出真知
刘 佳
首席专家
把准定位，在变局中担起智库使命。当前全球能源秩序正经历大分化、大重组、大变革，智库研究比以往任何时候都更需要前瞻谋划与主动作为。作为连接战略研究与产业实践的桥梁纽带，我们始终坚持服务大局、学术为本、从严从实的导向，力争在能源大变局中发挥好“参谋部”和“思想库”作用。
深耕厚植，在研究实践中锤炼真学问。从能源行业改革发展的丰富实践中提炼真问题、真研究问题，持续产出原创性、前瞻性成果，保持清醒的学术自觉，不逐一时热闹，久久为功夯实能源特色的学科体系、学术体系、话语体系根基。
矢志一流，努力服务科学决策需要。我们将始终胸怀“国之大者”、心系“企之要情”，以“板凳甘坐十年冷”的定力潜心治学，打造更多具有“经研院学派”标识度的成果，为中国哲学社会科学自主知识体系建设注入能源智慧、贡献智库力量，以一流资政成效支撑能源强国建设、赋能美好生活。
