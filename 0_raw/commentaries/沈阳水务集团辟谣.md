# 沈阳水务集团辟谣

沈阳水务集团发布公告：“全市停水”是假消息。
尊敬的用户：
近日，多个微信群、短视频平台流传“沈阳全市停水”相关不实消息，引发市民恐慌，对此沈阳水务集团郑重辟谣：该网传信息为虚假谣言。目前我市各水厂、供水管网、泵站运行平稳，不存在全市范围停水安排。仅个别小区因暴雨停电、管线抢修出现短时局部停水，各营业分公司均第一时间开展送水、抢修保障工作，全力快速恢复供水。
全市停水、检修等重要通知，仅通过集团官方公众号发布，非官方渠道消息请勿轻信转发。请市民理性辨别，不造谣、不信谣、不传谣。
如有用水疑问，可拨打24小时服务热线96681核实。
沈阳水务集团有限公司
2026年7月14日
