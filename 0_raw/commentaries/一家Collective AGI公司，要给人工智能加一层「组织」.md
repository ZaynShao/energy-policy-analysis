# 一家Collective AGI公司，要给人工智能加一层「组织」

过去几年，AI行业最清晰的一条路线，是不断把单个模型做得更强。
更大的参数、更多的数据、更强的推理，让单个模型能够处理越来越复杂的任务。但当AI开始从聊天框进入机器人、无人机、工业和城市系统时，问题也发生了变化。
真实世界的系统，很少只依靠一个模型运转。
一支机器人队伍里，每台机器拥有不同的传感器、算力和任务；一套低空安全系统里，可能同时有摄像头、雷达、无人机、边缘设备和不同算法。单个模型再聪明，也不会天然知道这些设备应该怎么分工、什么时候协作、出了故障以后谁来补位。
当智能的要素越来越多，怎样把它们组织起来？——这正是沌序科技想回答的问题。
今年4月，沌序科技正式成立，这家脱胎于中国科学院自动化研究所复杂系统认知与决策国家级重点实验室的公司，有一个听起来有些令人意外的目标。
作为一家人工智能公司，沌序科技没有把目标放在大模型及相关方向上，而是试图在大模型等现有智能单元和应用之间增加一层新的能力——Organization Layer，组织层。
这不是一件小事。计算机时代，新的一层Operating System Layer出现，带来了微软、苹果。AI时代，新一层Intelligence Layer出现，带来了OpenAI、Anthropic。甚至可以说，信息革命的每一次跃迁，都源于计算架构中一个新层级的出现。
在沌序科技的技术逻辑里，模型负责产生个体智能，而组织负责产生群体智能：把不同能力、不同成本、不同形态的智能体连接起来，让它们能够协作、反馈、调整，最终使整个系统获得单一个体原本不具备的能力。
简单来说，大模型解决的是一个智能体“够不够智能”的问题，沌序科技想解决的是：当越来越多拥有基础智能的个体出现以后，怎么把它们组织起来——甚至，让它们涌现出更高的智能。
公司把这个目标称作Collective AGI，通用群体人工智能。这也是沌序科技创始人兼董事长蒲志强研究了十多年的问题。三十八岁的他，是复杂系统认知与决策国家级重点实验室副主任、中国科学院自动化研究所研究员、国家优青。
2024年，蒲志强与团队一起讨论分布式群体智能
只是十多年前，它还没有Collective AGI这样一个听起来足够前沿的名字。那时吸引二十多岁的蒲志强的，是一只蚂蚁。
智能的另一种来源
一只蚂蚁能做的事情很少。但一群蚂蚁之间没有一个居中发号施令的“司令官”，却可以完成觅食、筑巢等远超单一个体能力的复杂行为——指引这一过程的，甚至只需要一到两条简单规则。
依靠群体智能，不懂建桥的蚂蚁却可以搭建一座桥（AI制图）
复杂科学对这种现象的概括很简单：群体智能的本质，是通过合适地组织简单规则产生高级智能。“也就是说，不是1+1=2，而是1+1>2。”令蒲志强真正感兴趣的，正是那个“多出来”的部分。在复杂科学的研究里，这种现象常被称作“涌现”。
尽管这门研究在2021年获得了诺贝尔物理学奖，但在十多年前，这还是一个非常冷门的方向。蒲志强后来回忆，如果一个方向已经很热，路径也已经十分明确，他反而未必愿意进去。
“没什么需要纠结的。”他觉得群体智能足够前沿，但又不是为了前沿而前沿。放在今天的人工智能时代，它触碰的是一个更本质的问题：智能一定来自于越来越强大的个体吗？还是个体之间通过组织关系本身，也可能产生智能？
这个问题他解了十多年。蒲志强一直强调研究要解决“真问题”，这让他的研究很早就从算法和仿真走向真实世界。
2020年前后，他开始把群体智能用于真实足球比赛的研究。足球其实是一个很直观的群体智能系统。一支球队里，没有哪个球员掌握全部信息。每个人只能看到一部分场面，但球队必须不断做出整体决策：下一脚球传给谁，谁应该跑位，对手换一种打法以后怎么调整。
蒲志强想解决的，也不只是比赛结束以后再做数据统计，而是“事中”和“事前”的问题：比赛走到这里，下一步应该怎么踢？如果换一个球员，会发生什么？面对不同风格的对手，是否能够提前推演？
团队甚至做过反事实推演，并试图把这套系统进一步变成一种“虚拟教练”。2025年，在一个特定的复杂决策实验里，团队尝试让两个自建的亿级参数规模的模型协同工作，同等条件下，与当时千亿级参数的通用大模型进行比较，在该任务上得到明显更好的实验结果。
对蒲志强而言，这并不只是“小模型战胜大模型”的故事，而是一个更朴素的证据：个体不必无所不能，通过合适地组织规则，也能产生更高级的能力。
团队利用真实欧冠比赛数据，运用群体智能，亿级参数模型“战胜”千亿级参数模型
只是，足球场上的球员逐渐变成了无人机、摄像头、雷达和不同算法，然后是机器狗、机器人。问题其实没有变，每个个体掌握的信息有限，能力也各不相同。真正困难的，是让它们在一个不断变化的真实环境里完成分工、协作和调整。
而当这些实验室研究进入真实世界，也开始给这项研究留下另一种东西：数据和工程经验。
在第一个真实世界应用场景低空安全方向，蒲志强的团队已经积累约50TB多模态无人机探测数据，覆盖可见光、近红外、热红外、雷达等不同模态；同时还有1500万帧有效标注目标样本和2000多次相关实验。
这些数字的意义并不只在于“大”。算法在仿真里成立，不代表换一种天气、一个背景、一台摄像头以后依然成立；无人机在理想环境中能够协同，也不代表遇到通信延迟、设备误差和节点故障时还能正常运行。
真实场景一边检验技术，一边也在生产下一轮技术所需要的数据。
从早期集群管控、多智能体博弈，到无人机蜂群和低空安全异构管控，同一个问题被反复放进不同系统里验证。算法、数据、专用模型和软硬件协同经验，也在这个过程中留了下来。
这构成了沌序科技与很多早期AI创业公司不同的地方：公司是新的，但它所需要产品化的能力并不是新的，理论搭建、数据积累和工程底座在创业前就已然具备。
把“关系”变成产品
技术积累得足够久，并不意味着一定要成立公司。事实上，在蒲志强给这件事设计的路径里，公司恰恰被放在了最后。
大约从2023年前后，他开始更认真地考虑群体智能的产业化。团队内部形成了一条顺序：真实应用——真实系统——产品——公司。先进入真实环境，确认技术确实能够工作；再从一个算法走向完整系统；系统跑过之后，还要判断其中有多少能力能够沉淀成产品。到了最后，才需要一家公司。
蒲志强判断“是不是时候到了”，看的也不是有没有一个漂亮的Demo，而是另一个更现实的指标——复用。
一开始，团队做的仍然是一个个具体项目。客户来一个需求，就解决一个问题。不知不觉，几年时间团队做了上亿元的项目。但这样的项目做多了，蒲志强慢慢发现了一个变化：一些原本需要重新开发的能力，开始可以在不同项目之间重复使用。
“只差最后一公里。”他这样描述那个阶段。最后一公里，不再适合在研究所里完成。
市场随后把这一步推得更快。一次在行业展会上的露面，吸引到30多家机构表达合作意愿，千万元级市场需求一下子堆在了面前，这让蒲志强意识到：“it’s time”。
蒲志强后来把它叫作“订单倒逼式创业”：不是先成立一家使命为Collective AGI的公司，再去寻找一个可以验证故事的场景；而是技术已经有人想用，公司反过来成为必须补上的一环。
今年4月，沌序科技成立。公司成立后的5月和6月，被内部称作“市场月”。几位分管不同领域的联合创始人都必须去见客户、摸需求、找合作。
两个月以后，团队没有任何人担心市场了，“需求都堆满了！”
这个时候，他开始担心产品。
因为需求足够多，有时反而会把一家技术公司拖回最熟悉、也最危险的路径：这个客户要一套方案，下一个客户再定制一套。项目越来越多，收入也可能增长，但底层能力始终无法沉淀。
蒲志强选择克制。不是每一个需求都立刻接住，而是先判断：做完这个项目以后，到底有什么能够留下？
这也是“复用”真正进入商业世界之后的含义。对于沌序科技来说，需要被复用的并不只是某一个模型，而是不同模型和设备之间“怎么配合”这件事，能不能被复用。
低空安全成为了最早的试验场。一套现实的低空系统里，可能已经有来自不同厂商的摄像头、雷达、无人机、边缘设备和处置终端。它们各自能完成一部分任务，但过去很多时候仍然需要人把这些环节串起来。
沌序科技在中间加上一层“群智大脑”。前端接入感知设备，中间进行信息融合、判断和调度，后端再连接执行设备；不同模块也可以根据客户已有系统拆开部署。
从这个角度看，沌序科技真正想产品化的，并不是一台雷达或者一架无人机，而是它们之间群体智能的组织关系。
沌序科技内部有一个略显技术化的说法，叫“组织蒸馏”。简单理解，一次有效的协作，能不能变成下一次还可以继续使用的经验规则，甚至到最后，是一个个公式。
如果几台设备经过很多轮运行，形成了一套有效的分工和协作方式，系统希望把它沉淀下来。下一次换设备、换任务时，不必再次从零开始；新的运行结果又继续反馈回来，让这套组织方式不断调整。
于是，一个项目留下来的不只是数据和模型，还包括“怎么组织这些智能”。这也是从人工智能走到Collective AGI——通用群体人工智能最关键的一步。
这件事实现，将拥有巨大的产业意义，它可能会直接改变AI产业的成本结构和市场规则：不是只有最强模型才能做出强大AI。
为什么是沌序科技？
沌序科技面对的并不是一片无人区。恰恰相反，“怎么组织越来越多的智能体”，正在变成AI行业共同关注的问题。
软件世界里，大模型厂商正在把多Agent协作和工作流编排做成基础能力；物理世界里，Shield AI、Anduril等自主系统公司也在让不同平台、传感器和无人系统协同工作。
甚至到了2026年，类似的产品边界仍在继续扩张。Applied Intuition推出了面向Physical AI的Agentic Platform，希望把AI、数据、开发工具和真实物理系统连接起来。
这些市场上的相邻玩家，一类从大模型和Agent出发，解决软件世界里的工作流编排；另一类从无人机、机器人和自动驾驶等物理系统出发，把自主决策软件不断往上抽象。沌序科技却是从一个完全不同的范式出发——群体智能。
群体智能是一种完全不同的智能范式
这也决定了它和大模型公司的关系，并非简单竞争——Organization需要模型。在沌序科技的系统里，能力更强的通用模型可以负责复杂推理，专业模型负责垂直任务，小模型和端侧设备处理低成本、低时延需求；Organization负责根据任务组织这些不同能力。
这是一条可以和基础模型厂商合作的路线，而不是在大模型之外重建一套AI。模型能力继续增强，对沌序科技未必是坏消息——可供组织的节点越强、越多样，组织问题反而可能更重要。
但仅仅看到这个需求，还不足以解释为什么是沌序科技。它目前真正有辨识度的地方，是将几种能力同时叠在了一起。
第一，十多年的群体智能研究。沌序科技不是在Agent热起来以后，才开始研究多个智能体应该如何协作。从集群管控、多智能体博弈，到异构协同和真实无人系统，这条研究线远早于公司的成立，团队深刻理解群体智能底层的跨学科机理。
第二，长期进入真实物理系统留下的数据和工程经验。几十TB数据只是最容易量化的一部分，更难复制的是换设备、换环境、通信波动、节点失效之后，系统还能不能继续工作的经验。
第三，软硬结合的路径选择。团队既有群体智能、大模型、多智能体强化学习背景，也有雷达、无人系统和系统集成能力。这使它既不同于纯软件Multi-Agent公司，也不只是传统硬件厂商。
此外，沌序科技还有一个很难从零复制的起点：它并不是一个孤立的教授创业项目。更准确地说，它根植于自动化所长期的、成体系的相关科研积淀，这家诞生了许多AI领域知名创业者的科研院所，是复杂科学和人工智能在中国最早进行布局的科研机构，人工智能的布局始于1990年代，而复杂性科学的研究则最早可追溯至钱学森时代。
蒲志强把研究所和公司的关系形容为一道“旋转门”：研究所保留更自由、更前沿的探索，一些研究成熟以后进入公司；公司在真实产品和客户中遇到的问题，又可以反过来形成新的研究课题。
一家普通创业公司需要在有限融资周期里，同时完成基础研究、算法验证、数据积累、软硬件适配和产品化，因此会无比艰难，或者周期需要拉得很长；但在沌序科技启动时，其中相当一部分前置积累已经发生。
十多年的群体智能研究，真实物理世界的数据和系统经验，软硬件结合的工程能力，中科院科研体系的持续连接，以及已经出现的真实市场需求——单独看，每一项都不能构成绝对壁垒。叠在一起，它们构成了沌序科技现在最难复制的起点。
但起点足够特殊，并不意味着终点已经成立，它最终能不能从众多人工智能公司之中，走成一个新的产品层，则是另外一个问题。
把自己从中心拿掉
不可否认，真正决定沌序科技上限的，仍然是“复用”。低空安全不是最终的产品定义，而是第一块足够复杂的验证场。
今天组织的是摄像头、雷达和无人机，下一步可能是机器人，再往后也可能是软件Agent和不同基础模型。公司希望把接入、调度、协作、反馈和验证能力从具体设备里抽出来，逐步走向面向物理世界的Organization OS。
这也是它最现实的商业悬念：在低空里形成的调度和协同能力，换到机器人以后还能留下多少？今天组织硬件的方法，明天换成模型和Agent，还能不能使用同一套底层能力？
如果每进入一个行业，都必须重新做一套系统，沌序科技最终仍然是一家复杂系统公司；只有当“组织”能够脱离具体设备和场景，被重复调用，它才有机会成为一个真正独立的产品层。
Collective AGI的上限，最终也要落回这个非常具体的问题。有意思的是，这套技术判断最后也落到了蒲志强自己身上。
从种子轮交割完成不到3个月，沌序科技很快长到50多人，从研究所出来的只有约10人，其余大多来自外部。蒲志强没有把原实验室整体搬过去。他需要市场、财务、人力、工程，需要那些和科研团队完全不同的人进入系统。
他甚至把公司的协作方式称作“群体智能架构”。全职团队之外，一些分散在大厂、开源社区和其他机构的人，也以外围协作的方式参与进来。他希望不是所有东西都从中心发出命令，而是让不同的人在清楚的边界里自行连接。
蒲志强承认，自己其实是个“细节控”，公司刚开始运转时，什么都伸手去抓。后来事情越来越多，他开始放权：该放出去的就放出去，放出去以后就信任；自己真正抓住的部分，再抓得很细。
一个研究了十几年“群体如何不依赖全能中心”的人，也开始学习不让自己成为公司的那个中心。
很快，这个关于“群体”的问题，还会以另一种形式出现在即将举行的WRC（世界机器人大会）“CONFLUENCE群智会”上。这也将是一场聚集了国内群体智能前沿领域科学家和众多优秀产业界人士的闭门讨论。
这场由沌序科技联合36氪举办的活动，在签到环节，也设计了一个和“涌现”有关的小实验：不同的人围坐在一起，从一个圆心开始，在纸上留下自己对群体智能的关键词，再把它传给下一个人。
没有标准答案，也没人知道最后会出现什么图案。蒲志强听完设计，觉得很好，“不确定才好玩。”
这句话听起来像是在评价一个活动，也很像他过去很多年的选择——他喜欢去没有答案的地方探索，却又习惯把眼前能够确定的事情一件件做完；他研究有限个体如何组成群体，又在创业之后学习把自己从组织的中心拿掉。
到了WRC，他也会重新成为群体中的一个节点。不同的人，带着不同的经验、判断和问题进入同一个空间。最后会长出什么，没有人知道。
蒲志强大概也不知道。但他希望可以努力创造，创造涌现。
