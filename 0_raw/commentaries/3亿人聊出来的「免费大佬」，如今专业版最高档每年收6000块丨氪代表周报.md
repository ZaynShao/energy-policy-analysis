# 3亿人聊出来的「免费大佬」，如今专业版最高档每年收6000块丨氪代表周报

豆包付费专业版来了，
高级版500元/月你会买吗？
铺垫了许久之后，豆包终于在6月24日正式推出专业版订阅服务。
收费分三档：68元/月标准版，200元/月的加强版，500元/月的高级版（连续包月情况下）；豆包还贴心地为大学生准备了半价福利，学生认证后标准版只要38元。
不同价位的主要区别，就是“干活儿额度”不一样，高级版能干标准版10倍的活儿。而专业版在高级版的基础上，又多了个“办公任务模式”，方便咱们职场牛马“使唤”豆包干更多事儿——比如整理电脑文件夹、帮你做PPT、写个带数据库的小网站，甚至还能定时让它自动干活。
虽然免费版也能体验这个模式，但用的是“普通引擎”，付费用户用的是“Pro引擎”，跑得更快、更能打。
为什么豆包要开始走付费这条路了？归根结底4个字，入不敷出。
据晚点LatePost此前报道，豆包每天服务成本达数千万，但每天收入不足百万，主要来源还是电商佣金。字节每年在AI基础设施上砸2000亿，总得看到回头钱。所以现在让重度用户付费，核心不是为了割韭菜，而是被算力成本逼的。
但付费订阅制真的能让AI赚到钱吗？答案尤未可知，要知道OpenAI做到全球最大，付费转化率也才5.6%，甚至200美元/月的Pro会员还在亏钱。加上国内用户对AI产品忠诚度不高，虽然豆包目前是国内使用人数最多的AI软件，日活有3.36亿，但人均每天使用时长也就10分钟。
最后，对于咱们普通人来说要不要为豆包掏钱付费？看需求。如果你只是偶尔查资料、聊聊天，免费版真够用了。但如果你需要大量让AI帮你写报告、做表格、写代码，那68块一个月可能比请个实习生更划算——至少它不会摸鱼。
当然，最终值不值，还得你亲自试了才知道。
微信迎来史上最大更新，
原生AI助手开启小范围内测
微信最近开始小范围测试一个叫“小微”的AI助手，很多人管它叫微信史上最大更新，因为它不只是加个聊天机器人，而是把AI整个塞进了微信的角角落落。你可以试试在微信左上角能不能找到到一个绿色小眼睛图标，或者从主界面轻轻右滑，看“小微”会不会现身。如果这两种方式都找不到它，那也别急，正式版应该已经在路上了。
作为史上最大更新的“小微”具体能干啥？你可以把它想象成一个“能帮你干活”的智能对话机器人。跟它说句话，它就能帮你处理不少日常操作。比如发消息、定闹钟提醒、看朋友圈动态，甚至转账。不过涉及到掏钱的时候，输密码这一步必须由用户亲自操作，AI包不了。
在36氪此前的报道中就提到（点击跳转测试详情）“小微”能读取公众号文章、视频号内容，并迅速为你总结要点；可以分析你发送的图片和文件；更特别的是它还有记忆功能，能做个性化推荐，比如听音乐，它会基于你过往的听歌偏好生成专属歌单。
除此之外，“小微”最令人印象深刻的能力，体现在处理步骤繁琐的标准化流程上。比如在规划行程、订机票酒店这类步骤繁琐的事情上，它却效率惊人。五分钟就能帮你填好携程订单，还会通过多轮提问多轮提问帮助你完成信息收集，你只需要最后付款确认。
当然了，也有很多是它不敢做、也不能做的的事：不能代发朋友圈、不能看你有没有收到某个朋友的消息、不能一次读取多条聊天记录、不能定时发消息。凡是涉及隐私或社交分寸的事，它都会主动退一步。毕竟好用归好用，微信也不敢放开了让AI随便折腾。微信有超过14亿用户，在隐私安全上必须谨慎。
如果哪天你发现微信左上角多了个“小微”图标，不妨跟它聊两句。看看它是真能省事，还是只会卖萌。
港股智谱暴涨
总市值突破1万亿港元
2026年6月22日，智谱收盘2410港元，总市值1.1万亿港元。这家公司1月8日才上市，发行价116.2港元，不到半年涨了20倍。
港股“全球大模型第一股”智谱再次走出极端行情。据财经天下此前计算，当天智谱的市值超过中国平安，相当于两个美团，或者三个京东。而腾讯2004年上市后，花了将近十年才摸到万亿港元门槛，智谱只用了不到六个月。
本次暴涨的直接原因，很多人归结为马斯克“送了个大礼”。
6月18日，马斯克被网友问到“中国大模型预计何时能达到Anthropic的Fable水平？智谱GLM-5.2无疑缩短了差距。”马斯克回答说：“可能2027年一季度。”
随后，智谱创始人唐杰又在这条内容下跟帖回复：“用不了那么久”，两人的这次隔空对话，被市场解读为马斯克承认智谱已进入全球第一梯队。
加上美国Anthropic刚对部分开发者“断供”，智谱刚好开源了新模型接住需求，时机精准得像提前排练过。
但其实根本原因，还是商业逻辑跑通了。
目前大模型行业轮流降价，利润率逼近零，智谱却逆势而行。2026年以来连续涨价三轮，累计涨了83%，价格几乎追平ChatGPT和Claude。更关键的是，涨价之后，调用量反而涨了400%。 21世纪经济报道此前提到，摩根大通专门对比了智谱和另一家降价的公司，结论是维持智谱“增持”，把对方下调到“中性”。道理很简单，能涨价还不丢客户，这叫有“定价权”。
有人说是泡沫，有人说这是AI时代的新定价逻辑。但不管怎样，一家年入7亿的公司把市值干到1万亿，这事儿本身就是个现象级剧本。
SK海力士已提交美国IPO申请
暂定7月10日登陆纳斯达克
韩国市值最高的公司SK海力士，终于把赴美上市的日子定下来了，7月10日，纳斯达克见。
据SK海力士6月24日披露，计划发行最高约294亿美元（约45.45万亿韩元）的存托凭证（ADR），承销商阵容相当豪华：美国银行、花旗、高盛和摩根大通。
流程也在同步推进。韩国监管审查最快7月3日就能完成，之后就是向美国SEC提交注册文件。说白了，就是把韩国股票“打包”成美国投资者熟悉的凭证，放到纳斯达克交易。
那为什么要去美国上市？SK海力士今年3月就透露过，想借AI热潮圈一波全球粉丝。
公司坦诚表示，赴美上市能让投资者更多元，估值也能“更配得上自己的实力”。毕竟SK海力士是英伟达HBM芯片的头号供应商，据Counterpoint数据，2025年Q4全球HBM市场独占57%，把三星（22%）和美光（21%）远远甩在身后。
除此之外，SK海力士的业绩确实太能打了。
财报显示，一季度营业利润约254亿美元，营收约341亿美元，同比翻了近两倍。股价更是坐上了火箭，6月24日收盘数据，年内涨幅已近300%，市值约1.19万亿美元，韩国股民怕是做梦都能笑醒。
