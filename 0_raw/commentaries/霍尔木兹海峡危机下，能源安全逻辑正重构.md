# 霍尔木兹海峡危机下，能源安全逻辑正重构

随着霍尔木兹海峡的运输中断，海湾地区在全球能源供应版图上的定位有所改变，地缘风险敞口、基础设施安全等因素，正加速推动全球能源安全逻辑重构。
近期，美国与伊朗围绕霍尔木兹海峡的博弈呈现高强度对峙、封锁与反封锁的态势。有分析认为，霍尔木兹海峡动荡不安，正在永久改变全球能源安全逻辑，即便这条海峡重新开放并回到稳定通航状态，各国和行业也会有所忌惮，物理通行恢复并不意味着信心可以随之恢复。
事实上，围绕霍尔木兹海峡的运输中断，打破了一个长期存在的假设——这条“能源咽喉”始终保持可靠通行状态，但随着这种“确定性”骤然消失，海湾地区在全球能源供应版图上的定位已变成“核心风险源”，尽管该地区油气仍不可或缺，但地缘风险敞口、基础设施安全等因素，正在加速推动全球能源安全逻辑重构。
恢复通行并不意味着信心跟着回归
阿联酋《国民报》撰文称，霍尔木兹海峡长期关闭，暴露出全球能源体系脆弱性，也正在深刻改变国际社会关于能源安全、能源转型和气候变化的讨论方向。
睿咨得能源咨询公司新兴市场与国家石油公司部门负责人施赖纳·帕克表示，围绕霍尔木兹海峡的事态发展表明，复杂系统只有在承受压力时才会显现其真实特性，这条“能源咽喉”动荡不安，迫使能源行业寻找新的支点，并可能改变长期能源投资策略。
霍尔木兹海峡危机之下，各国政府重新审视政策，资本重新评估风险，市场建立新的平衡，即便海峡重新开放并回到稳定通航状态，但行业对其信任也很难回到最初的“零风险预期”状态。
“恢复通行并不意味着信心能够重建，资本将永久性地为通行韧性赋予更高溢价，而此前那种被视为理所当然的无忧通行假设，已一去不返。”施赖纳·帕克坦言。
霍尔木兹海峡的重要性，不仅在于通过的油气数量，更在于经济、金融和地缘政治体系在一个极为狭窄的走廊内高度汇聚带来的敏感度和脆弱性。替代性出口路线无疑能增强韧性，但无法消除根本性脆弱。每一条管道、出口终端和绕行路线都需要数年投资、建设、协调才能建成，而破坏它们则容易得多。这种非对称性无法通过任何工程手段或投资予以消除，只能被持续性地管理与对冲。
海湾地区仍然是全球最大、成本最低的油气产地之一，未来数十年也仍将是全球最重要的油气来源之一，其资源品质、生产成本依然无可比拟，但战略地位所依赖的“航运确定性”已被削弱。“秩序可以被重建，但永远无法以完全相同的形态、无法不付出额外代价地重建。”施赖纳·帕克强调。
海湾国家发展战略将面临长期调整
对海湾国家而言，这或许意味着一场关于能源安全和国家发展战略的长期调整，他们已无法将希望仅寄托于霍尔木兹海峡畅通，保障能源安全不再意味着守住本国生产设施，也包括把能源资产、运输能力和市场布局分散到不同地区。
沙特已经开始审视通往红海的原油管道。路透社指出，沙特考虑进一步扩大通往红海沿岸的原油管输能力，新增规模最高可能达到每天200万桶，并已就有关安排与邻国开展初步讨论，这意味着沙特未来可能进一步提高绕过霍尔木兹海峡向外输送原油的能力。
阿联酋同样在加速布局。阿布扎比早在2012年就启用了连接哈卜善和富查伊拉的原油管道，使部分原油可以绕开霍尔木兹海峡直接从阿曼湾出口。阿联酋目前正加快建设第二条通往富查伊拉的输油管道。同时，阿布扎比国家石油公司也开始更加灵活地调整原油销售和运输方式，通过增加现货招标、拓展新客户和交易商、采用船对船转运等方式，提高能源供应链的灵活性。
与沙特、阿联酋可以利用部分陆上输油管道绕开海峡不同，卡塔尔为了降低相关风险，则更多需要从全球能源资产和供应网络层面寻找答案。事实上，卡塔尔近年来已经持续扩大海外能源布局，其持股70%的美国Golden Pass液化天然气出口终端项目已启动生产和出口，凸显“本土资源+海外资产”布局在分散供应链和地缘政治风险方面的战略价值。
尽管布局各异，但海湾国家不太可能实现全面“去霍尔木兹化”。国际能源署估计，目前有可能绕开霍尔木兹海峡的原油管道输送能力约有350万至550万桶/日，而2025年通过霍尔木兹海峡的原油接近2000万桶/日。现有替代管线和港口能力远不足以取代全部海峡运输量，真正实现全面“去霍尔木兹化”既不现实，经济成本也极其高昂。
能源供应来源多元化将是大势所趋
霍尔木兹海峡动荡局势终会恢复平静，但市场对风险的记忆不会立即消失，即便航道重归通畅，信心的损失也需要更多时间来恢复，全球能源供应结构调整将更多体现为供应来源多元化，而非海湾能源供应主导地位被取代。
比如，那些拥有竞争性资源且市场准入具有韧性的产油国，战略地位会逐步增强；那些可以通过出口路线多元化、扩大提高采收率、开拓新的深水机遇或加速技术创新的国家，能够有效降低对单一通道的依赖，从而在韧性溢价逐步提升的新格局中保持乃至增强其相对优势。
睿咨得能源咨询公司指出，霍尔木兹海峡动荡局势，给大西洋盆地带来了契机，巴西、圭亚那、加拿大、美国等产油国的战略地位进一步提升。当同等经济性叠加较低的地缘政治风险敞口时，这些产油国变得更具吸引力。
国际能源署数据显示，3月以来，美国、巴西、委内瑞拉等大西洋盆地多个产油国原油出口量增长超过300万桶/日，缓解海湾供应下降所带来的缺口。
美国财政部长斯科特·贝森特日前表示，随着地缘政治局势变化，今后越来越多能源运输将绕过霍尔木兹海峡。“这条海峡正在逐步丧失战略重要性。”他说，“经由霍尔木兹海峡运输的能源中，有超过50%甚至70%今后将逐步改由地下管道输送。”
美国有线电视新闻网汇编数据显示，截至8月中旬的过去两周，超过80%的船舶选择经由阿曼一侧穿行霍尔木兹海峡。美伊6月中旬签署谅解备忘录之后，霍尔木兹海峡一度重开，形成由伊朗管控的北部航道，以及阿曼一侧美军提供通航协助的两条南部航道即“阿曼航道”。后来，美伊围绕霍尔木兹海峡控制权又起冲突，伊朗宣布再次关闭这条海峡。
