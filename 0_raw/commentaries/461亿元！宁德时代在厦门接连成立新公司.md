# 461亿元！宁德时代在厦门接连成立新公司

「储能与电力市场」获悉，,8月12日，由宁德时代100%全资持股的时代电服（厦门）控股有限公司正式注册成立，注册资本61亿元。企查查显示，时代电服（厦门）控股有限公司注册地址在厦门火炬高新区，经营范围包括人工智能基础软件开发、新能源汽车电附件销售、数据处理和存储支持服务、信息技术咨询服务、新能源技术开发、电池销售、储能技术服务、充电基础设施相关业务等。
4月，宁德时代设立时代资源集团，注册资本300亿元，着力建设面向全球的矿产资源运营中心，向上游矿产资源环节强化布局。6月，宁德时代零碳科技（厦门）有限公司注册落地，注册资本100亿元。新公司将搭建完整零碳业务矩阵，覆盖零碳制造基地投资、国际技术服务与授权、技术研发、展示体验、海外零碳项目投资五大核心业务平台，锚定零碳技术与产业投资赛道。加上此次61亿元成立的时代电服（厦门）控股有限公司，宁德时代今年以来在厦门设立公司注册资本达到了461亿元。此外，宁德时代近年来还在厦门持续加码私募基金投资，深耕新能源产业布局。
- 2021年，宁德时代认缴出资3亿元，设立私募基金博裕四期（厦门）股权投资合伙企业。
- 2022年，宁德时代再次出资3亿元，参与设立厦门隐山股权投资合伙企业（有限合伙）。
- 2025年，宁德时代认缴7亿元，作为有限合伙人之一参与投资“福建时代泽远碳中和股权投资基金合伙企业（有限合伙）”。
