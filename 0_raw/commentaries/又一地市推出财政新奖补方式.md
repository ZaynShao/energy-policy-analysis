# 又一地市推出财政新奖补方式

一、x市出台“先拨后股”方式
近日《x市先拨后股方式支持产业科技创新融合试点办法》正在征求意见；与其他地方围绕研发投入、绩效目标进行的奖补支持不同，x市更进一步，结合市场方式彻底改变政府补贴的无偿资助模式。
1.不再是“无偿补贴”
传统财政奖补多为无偿资助，且资金拨付后缺乏有效约束。
x市将“无偿拨款”与“股权投资”相衔接：先期以无偿补贴资金支持企业开展产业科技创新和成果转化，当企业达到约定的市场化股权融资条件时，无偿补贴资金自动转化为相应股权。
与其他地方“拨投结合”、“先拨后股”科技项目不同，x市产业奖补项目大多纳入该体系，实现财政资金从“消耗型投入”转变为“循环型投资”。
2.合规的支持方式
x市避开负面清单雷区，将支持对象精准聚焦于五大领域。
科技研发方面，对科技型中小企业按不超过项目新增研发投入的30%分档给予最高1000万元资助，对新型研发机构根据绩效评价给予最高300万元研发运营资助；
成果转化方面，对科技型中小企业根据转化成效给予最高200万元资助，对成果转化平台实施的项目，财政资金按机构出资1:1配套支持；
企业孵化方面，支持引进孵化独角兽、潜在独角兽企业，按上年度研发经费投入的15%给予最高200万元、100万元资助；
人才创业方面，对领军人才企业给予最高500万元、领军团队企业最高1000万元项目支持；
产品研发测试方面，对制造业单项冠军、专精特新“小巨人”企业按研发投入10%给予最高1000万元支持。
可见，能获得地方补贴的项目也就剩这些了。
3.多部门协同发力
本次政策由科技局、工信局、财政局共同制定，“先拨后股”模式对重大科技成果转化项目先行拨付财政资金，待项目市场化融资时转化为相应投资权益，既破解了早期研发的“市场失灵”困境，又回归市场化资本。
多部门协同把科技的研发、人才、创新平台，工信的单冠、专精特新等分散的奖补项目集中纳入统一框架，避免了各自为政的弊端。
二、“正面清单”式的合规补贴逻辑
当前，地方普遍反映“政策识别难、执行标准不统一”。
合规的奖补政策是支持方向和支持方式的统一，实践中可以归纳出一个简单的“方向+方式”框架。
1.支持方向
研发投入、测试创新，按企业实际研发投入的一定比例（如20%-30%）给予资助；
产业安全，关键技术攻关、成果转化、人才创业等产业基础；
市场失灵，人才培训、基础设施、前沿技术、共同技术平台、服务平台；
公共服务，稳岗补贴、就业创业支持、农业农村农机支持、养老卫生；
绿色低碳，节能改造、循环经济、绿色工厂、零碳工厂、认证体系。
3.绩效闭环管理
“花钱必问效，无效必问责”，将产业扶持资金列入重点评价范围，综合研判投入产出效益，同时明确退出周期。
三、结束语
从支持产业化到支持研发投入，强调的是技术创新；从支持投资到支持市场，解决的是消费问题；从支持申报单位本身到支持外部赋能，体现的是政策竞争中性。
有为政府和有效市场有机结合的第一步是，市场的归市场，政府的归政府；这或许才是奖补清理之后，地方产业政策转型的真正方向。
