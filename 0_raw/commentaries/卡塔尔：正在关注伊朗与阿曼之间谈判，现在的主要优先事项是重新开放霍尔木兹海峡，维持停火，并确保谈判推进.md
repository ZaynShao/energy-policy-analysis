# 卡塔尔：正在关注伊朗与阿曼之间谈判，现在的主要优先事项是重新开放霍尔木兹海峡，维持停火，并确保谈判推进

卡塔尔呼吁重新开放霍尔木兹海峡。
▲霍尔木兹海峡（资料图）
卡塔尔外交部发言人安萨里11日在新闻发布会上表示，卡塔尔正在关注伊朗与阿曼之间谈判，最近几天已听到双方积极的表态，并正在等待新的进展。安萨里称，卡塔尔现在的主要优先事项是重新开放霍尔木兹海峡，维持停火，并确保谈判推进。卡塔尔支持一切促使局势缓和的努力，卡塔尔现阶段的最低要求是根据国际法恢复霍尔木兹海峡地区的海上航行自由。
