# 【成员单位风采】史逸泰克贸易(上海)有限公司

为深度赋能产业协同发展，充分挖掘并展示联盟各成员单位核心竞争力，打通行业供需对接壁垒、凝聚产业发展合力，联盟常态化开展成员企业专题推介宣传。聚焦零部件产业链优质企业资源，全方位呈现会员单位的企业实力、核心技术、创新产品与产业优势，助力优质企业品牌出圈、精准链接行业资源、拓宽产业合作渠道。
本期联盟成员专题推介，为大家带来：【史逸泰克贸易(上海)有限公司】企业及产品全维度介绍。
关于联盟
2010年12月，在科技部支持下，电动汽车产业技术创新战略联盟(以下简称“联盟”)在北京正式成立。联盟是科技部认定的国家A级产业技术创新战略联盟、是国家重点研发计划新能源汽车专项项目申报推荐机构、是为我国新能源汽车产业及企业提供全方位服务的协同创新平台。
联盟设立了理事会、技术专家委员会和秘书处三级机构。截至目前，联盟有136家成员单位，其中整车企业13家、零部件企业82家、科研院所37家、行业机构4家。联盟下设动力电池、电驱动系统、充换电设施、智能底盘、汽车电子电气架构、汽车芯片、汽车量子技术、低空动力、车载光通信、前瞻技术识别10个协同创新工作组，分领域开展技术路线研究、前瞻技术识别、团体标准制定和技术交流等工作。
联盟联合行业优势资源，以产业和企业需求为牵引，累计承担5项国家重点研发项目，获国拨经费近6.9亿元，带动企业配套投入25.3亿元。自筹经费6500余万元，组织80多项共性技术课题，累计发布团体标准110多项，推动成果在联盟内高效共享，形成 “国家引导、企业协同、成果互通”的创新生态。
