# 储能拯救不了“三星SDI们”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIsObEicAfPoPHXgQLMx1qD0j6fWU8kkJ1X209ibq41RqZeLA8aSlknFVWyHJJASB6poD0X5XibIm3vZkqW6OBgrr0sHFvehqQ8WNg/640?wx_fmt=png&from=appmsg)

近日，三星SDI在美国储能市场斩获巨额订单，风头一时无两。若将视线从储能这个细分市场的“局部战役”拉升到全球电池产业的“整体战场”，韩国电池企业是否会重复它们在动力电池赛道输给中国企业的老路？

先来看事件。2026年3月，韩国电池企业迎来了高光时刻。三星SDI宣布其北美子公司与一家美国能源公司签署了价值约10亿美元（约69亿元人民币）的储能系统电池供应合同，供应期持续至2029年。几乎在同一时间，美国官方证实，LG新能源去年7月那笔价值43亿美元的巨额电池订单，买家正是特斯拉，这些电池将用于特斯拉的Megapack储能系统 。

这一连串的订单似乎向市场传递了一个信号：韩系电池依然能打。尤其是在美国这个关键市场，得益于《通胀削减法》（IRA）构筑的对华高关税+本土制造补贴双重壁垒，叠加AI算力爆发催生的数据中心储能需求，韩企正将大量闲置动力电池产线转向储能，在美国市场找到了阶段性避风港。

然而，储能订单的“喜报”有多响亮，动力电池领域的“耳光”就有多疼。SNE Research发布的最新数据显示，2026年1月，全球动力电池装机量榜单呈现出极端的分化格局。中国企业的优势已从“领先”演变为“统治”：宁德时代以45.2%的份额一骑绝尘，比亚迪以13.8%紧随其后，仅这两家中国巨头的合计份额59%就已是韩国三家头部企业总和的近5倍。

更为突出的是，中韩企业增长态势已然截然背离。中国领先电池厂商中，中创新航以3.8GWh装车量、51.5%的同比增速排名全球第四，为前十企业中增速最快；国轩高科、蜂巢能源、亿纬锂能分别位列第六、第八、第九，均实现正增长。

LG新能源、三星SDI、SK On三家韩企却包揽了榜单的跌幅前三，装机量全线两位数负增长，合计市场份额从去年同期的16.3%骤降至12%。其中三星SDI跌幅最深，同比锐减24.4%，排名滑落至第十位，徘徊在榜单边缘。

SNE Research报告提及，韩系企业失速主要受美国市场影响。随着美国《通胀削减法》电动车补贴退坡，美国需求骤降，导致深度绑定通用、福特、宝马等车企的韩系电池厂遭遇重创。但这或许只是表象，更深层的结构性顽疾在于战略误判。

在技术路线上，当中国企业早已围绕成本更低、适配储能和入门级电动车的磷酸铁锂（LFP）技术构建起完整产业链时，韩国企业却长期固守三元锂电池路线，对LFP的量产犹豫不决。而后面对储能市场的爆发和车企降本压力，韩企不得不匆忙“补课”：

三星 SDI自2023年3月启动磷酸铁锂研发，2025年底确定商业化落地；LG新能源于2023年筹备量产，2025年实现供货；SK On则在2024年明确战略并启动研发，计划2026年正式量产。

反观中国企业，比亚迪早在2002年就启动了磷酸铁锂技术研发，宁德时代的布局可追溯至‌2010年代初期。中国是全球磷酸铁锂技术产业化与规模化的核心推动者，布局起步早、周期长、政策与产业协同推进。截至目前，中国企业已经占据全球磷酸铁锂市场90%以上份额，在储能这一细分市场市场份额更是达到约95%。

整体来看，韩系电池企业在专利布局、成本控制与产能规模上仍处于被动地位。值得注意的是，中韩两方电池产能利用率鸿沟十分巨大。韩国三大电池企业开工率仅徘徊在50%左右，而宁德时代、比亚迪的产能利用率高达90%。这不仅是数字的差距，更是规模效应、成本控制能力和市场消化能力的代际差。

或许有人会问，既然储能市场如此火爆，韩企能否像当年在动力电池领域一样，再次发起冲锋？答案恐怕是悲观的。储能业务虽然体量巨大，但本质上是一个比动力电池更看重成本效益比的赛道。中国企业凭借极致的成本控制和规模化能力，在这一领域拥有压倒性优势。

目前韩系电池企业在美国市场斩获的储能订单，更多是依托前期本地化投资与被动防御性策略进行维系。中长期来看，面对中国电池企业在全球供应链、成本、技术与规模上的全面竞争，韩国厂商的盈利空间与全球份额仍将持续受到挤压。

当中国企业在动力和储能两条战线上同时推进技术迭代和成本革命时，留给韩国对手的时间和空间，真的不多了。
