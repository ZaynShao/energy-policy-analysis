# 地方绿金 | 重庆永川落地“碳配额跨履约期质押+融资担保”业务

2026年4月，重庆市生态环境局、中国人民银行重庆市分行等部门联合印发《重庆市创新开展碳配额融资服务绿色低碳高质量发展十条措施》，明确碳资产“可估值、可质押、可回购、可处置”，标志着重庆金融业支持实体经济绿色转型迈出关键一步。
在中国人民银行重庆市分行指导下，中国人民银行永川分行积极对接辖区生态环境局，掌握重点碳排放企业名单，打通政银企信息壁垒，引导金融机构精准创新碳金融产品，成功发放全国首单“碳配额跨履约期质押+融资担保”贷款200万元，将“沉睡”的碳资产转化为信贷资金，为全国碳金融发展提供了可复制范本。
重庆美力宁科技公司是一家从事新型建材研发生产的企业，当前正处在转型升级的关键期，技术改造和工艺升级面临不小资金压力。受限于土地、厂房等传统抵押物不足，企业的传统授信通道不畅。与此同时，企业碳账户上长期持有碳配额近3万吨，却因缺乏成熟融资渠道而“沉睡”。对此，重庆三峡银行主动摸排情况，积极响应企业需求，组建“碳金融服务小组”提供精准服务。重庆三峡银行永川支行现场核实企业生产经营状况、碳排放报告及配额清缴记录，积极与重庆碳排放权交易中心沟通，查询企业碳配额历史持仓及冻结情况，为后续授信夯实基础。
考虑到碳配额价值不足、流通率低、履约期短等难点堵点，重庆三峡银行与重庆永川中小企业融资担保有限公司合作探索引入担保机制分摊风险，并通过合同条款设计成功打破履约周期壁垒，创新推出“碳配额跨履约期质押+融资担保”的业务模式。重庆永川中小企业融资担保有限公司评估企业碳配额在二级市场的变现能力及处置路径，出具《碳配额质押担保风险评估报告》，明确反担保措施及风险分担比例，为后续担保额度核定提供依据。重庆三峡银行明确质押率上限，参照重庆碳市场近期成交均价对碳资产估值，并在重庆碳排放权交易中心完成质押登记。
在多方的共同努力下，重庆三峡银行在短期内向企业发放200万元贷款，让碳资产真正从“账上数字”变成了“手中资金”，为民营企业绿色发展注入了强劲动能。
