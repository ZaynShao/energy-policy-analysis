# 全国性行业协会商会党委印发《关于在防汛救灾工作中充分发挥全国性行业协会商会基层党组织战斗堡垒作用和广大党员先锋模范作用的通知》

近日，全国性行业协会商会党委印发通知，就深入贯彻落实党中央决策部署和习近平总书记关于防汛救灾工作的重要指示精神，在防汛救灾工作中充分发挥全国性行业协会商会基层党组织战斗堡垒作用和广大党员先锋模范作用提出明确要求。通知强调，全国性行业协会商会各级党组织要提高政治站位，坚持把做好防汛救灾工作与正在开展的树立和践行正确政绩观学习教育结合起来，引导行业协会商会落实防灾救灾社会责任，助力保障人民群众生命财产安全和社会大局稳定。要充分发挥行业协会商会党组织政治功能和组织功能，引领带动广大会员单位，结合实际积极做好工作。特别是要动员与防汛救灾工作密切相关的应急救援、水利电力、交通运输、医疗卫生等行业协会商会，立足专业特长和资源优势，切实发挥作用。行业协会商会党员负责人要以上率下、带头作为，广大党员要立足岗位充分发挥先锋模范作用。要加强对防汛救灾一线党员关心关爱，及时总结宣传先进典型，激励带动全国性行业协会商会广大职工为防汛救灾贡献力量。（来源：中央社会工作部）
