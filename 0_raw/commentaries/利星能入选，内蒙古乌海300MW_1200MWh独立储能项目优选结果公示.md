# 利星能入选，内蒙古乌海300MW/1200MWh独立储能项目优选结果公示

公示期限：2026年8月18日。
项目建设地点：乌海市乌达区境内
项目接入：金湖500kV变电站。
项目建设规模：30万千瓦/120万千瓦时，拟优选项目实施主体1个。
技术类型：独立新型储能电站采用构网型技术，优先支持压缩空气、全钒液流、钠离子等技术路线，鼓励实施长时储能电站（时长4—8小时）。
乌海市景元金湖300MW/1200MWh独立储能电站项目：实施主体为乌海市景元储能有限公司
乌海市国众金湖300MW/1200MWh独立储能电站项目：实施主体为乌海市国众储能有限公司
乌海市星恒能源有限公司金湖300MW/1200MWh独立储能电站项目：乌海市星恒能源有限公司
