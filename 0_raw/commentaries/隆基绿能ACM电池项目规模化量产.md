# 隆基绿能ACM电池项目规模化量产

近日，隆基绿能ACM（纳米合金矩阵式接触）电池项目在西咸生产基地正式量产，成为隆基绿能新型电池技术规模化落地的关键里程碑。
隆基绿能研发团队历时近十年持续攻关，在ACM电池材料、工艺与设备方面取得多项核心突破。在性能表现上，经德国哈梅林太阳能研究所认证，隆基绿能ACM电池效率达到27.6%；经TÜV莱茵认证，ACM组件功率达到672瓦。
量产导入数据显示，ACM技术使量产转换效率提升0.2%-0.3%，组件功率提升3-5瓦，已完成吉瓦级标杆性量产导入，在稳定性与可靠性上均实现行业领先。
隆基绿能创始人、首席技术官李振国表示，围绕ACM技术，隆基绿能已搭建起涵盖核心材料、工艺制程与设备适配的全链条知识产权体系，构筑了坚实的技术护城河，后续将持续深化供应链协同，进一步巩固技术领先优势。
自2025年12月量试线完成首单交付以来，ACM技术从实验室迈向量产，研发与制造端高效协同，快速完成设备迭代与工艺核验。隆基绿能电池制造中心负责人何江涛表示，BC 2.0与ACM组合工艺的落地，是隆基绿能在电池效能升级与技术迭代层面的重要突破。
在多基地联动协同下，新材料工厂从立项到量产仅用时三个月，产能爬坡周期较常规缩短20天。该技术可实现快速导入，为多基地规模化复制奠定了坚实基础。
隆基绿能董事长、总经理钟宝申表示，ACM电池产线代表了行业顶尖制造水准。站在规模量产的新起点，隆基绿能将把快速量产经验转化为标准化能力，稳步推进多基地产线爬坡扩能，在保障品质的前提下持续推进新型电池技术的迭代升级。
随着隆基绿能ACM电池产线的稳定运行，隆基绿能将持续聚焦技术创新，深化研产联动，为客户提供高效、可靠的光伏产品，为行业高质量发展贡献力量。
