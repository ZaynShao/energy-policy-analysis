# 业主指定！湖南宇迈能源独揽中国电建500MW/2GWh构网型储能系统大单

该项目位于新疆维吾尔自治区和田地区和田市建材产业园区，总容量为500MW/2000MWh，采用磷酸铁锂电池技术路线。
项目建设内容涵盖一座500MW/2000MWh构网型独立储能电站，包括35kV集电线路、储能单元电池舱、储能变流器、升压箱变等核心设备；同时配套新建一座220kV汇集站，本期建成2台250MVA主变，35kV侧按双受电断路器单母线分段接线设计，本期建成Ⅰ、Ⅱ、Ⅲ、Ⅳ段母线及每段5回出线，共计20回。此外，项目还包含配套送出工程，拟以1回220kV送出线路接至观景220kV变并网，送出线路长约5.5公里。
