# 周立伟已任四川省委组织部部长

周立伟已任四川省委组织部部长、省委党校校长。
据四川省委党校官网“校院领导”一栏最新显示，周立伟已任四川省委组织部部长、省委党校校长。
川观新闻7月7日消息，近日，中共中央批准：周立伟同志任中共四川省委委员、常委。
▲周立伟（资料图）
公开简历显示，周立伟，男，汉族，1971年10月出生，黑龙江省双城人，1996年3月毕业于天津大学化工系，获工学硕士学位，2009年12月获休斯顿大学EMBA，教授级高级工程师。
2024年12月，周立伟任山东省委常委、省委组织部部长，至近期调整。
