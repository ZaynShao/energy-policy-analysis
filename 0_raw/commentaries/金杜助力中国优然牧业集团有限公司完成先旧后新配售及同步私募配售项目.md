# 金杜助力中国优然牧业集团有限公司完成先旧后新配售及同步私募配售项目

本次同步私募配售的认购方为博源投资控股有限公司，一家优然牧业控股股东内蒙古伊利实业集团股份有限公司（简称伊利集团，股票代码：600887.SS）的全资子公司。鉴于该认购安排，本次交易涉及清洗豁免申请，并已于2026年5月20日获得香港证券及期货事务监察委员会批准清洗豁免。本项目的顺利完成，标志着优然牧业成为首家完成涉及清洗豁免的先旧后新配售及同步私募配售的香港上市公司。
优然牧业是全球最大的原料奶供应商，其业务覆盖乳业全产业链，包括原料奶生产、奶牛饲料供应及育种，以及其他反刍动物养殖产品的生产、销售及贸易。优然牧业的股份自2021年6月起在香港联合交易所主板上市。
伊利集团是亚洲规模最大的乳制品企业，于2025年跻身全球乳业品牌前五名。其主要从事各类乳品的生产与销售，产品涵盖液态奶、奶粉、酸奶、冰淇淋、奶酪等。在巩固核心乳业业务的同时，伊利集团持续拓展产品版图，积极布局矿泉水、植物基饮品及乳酸菌饮料等新业务板块。
在本项目中，金杜律师事务所分别为优然牧业及伊利集团提供法律服务。优然牧业项目团队由合伙人孙凯牵头，团队成员包括尹绍桦；伊利集团项目团队由合伙人骆伟德牵头，团队成员包括刘宇轩及尹晓鲁。
