# 台风来袭，这些企业安全防范要点要记好！

台风天气
企业应该怎样做好防范
台风期间施工事故发生的规律和特点
1.三十米以上高空作业因大风、强降雨等恶劣天气易发生高处坠落事故。
2.临时用电线路搭设、漏电保护器设备和外电防护因高温潮湿漏电，易发生触电事故。
3.斜坡、高切坡附近的建设工程，基础开挖、基坑支护、管沟开挖和支护工程，因强降雨、大风等恶劣天气易造成山体滑坡、坍塌事故。
4.强降雨天气，一旦发生山体滑坡或泥石流，山区公路路段、桥涵可能遭受严重毁坏，对山区公路建设人员造成严重威胁。
5.水利施工(包括建筑施工、各类危房和临时建筑物、各类土方施工)易发生坍塌伤人事故。
6.受极端恶劣天气或路况、车辆、驾驶人员等相关因素影响，施工企业自用的运输施工人员和物资车辆容易发生交通事故。
施工事故预防措施
1.设备管线等保温层的保温皮要紧固无开裂，各类警示标牌要稳固。
2.对施工工地存在滑坡、崩塌、洪水、泥石流等地质灾害危险的隐患进行认真排查，做好支护等措施，防止坍塌。
3.严格落实台风期间不能施工的要求，停止一切施工作业。
各生产经营单位须结合自身实际，认真落实以下防范措施：
1.召开复工安全生产会议。对防御台风、暴雨工作作个小结，明确台风、暴雨后的安全生产工作要求，明确复工前各岗位、各人员职责要求。
2.制定落实复工复产工作方案。针对台风对本单位产生的破坏和影响进行评估，作一次危害分析，对存在的安全问题和产生的安全隐患，提出针对性整治措施，要明确分工和要求，落实安全管理责任，把复工复产安全工作谋划部署到位。
3.对员工开展复工复产安全教育和安全培训。教育员工强化安全意识，严守安全操作规程和劳动纪律，提高台风、暴雨后的安全意识。同时要针对台风暴雨的影响、隐患和复工复产工作中的注意事项及防范措施，对员工进行培训，做到管理人员和所有员工专项培训全覆盖，不培训不上岗。
4.对单位现状开展一次全面的安全检查，包括检查电气线路和配电设施、检查所有设施设备、检查建筑安全和周边环境。同时做好厂区清淤、排涝、维修、有限空间作业等的安全管理，严防触电、坠落、窒息等次生事故发生。
5.落实设备检修试运行。对排查发现存在安全隐患的设施设备，要立即进行检修，特别是危险设备和危险场所，如喷油喷漆等，要进行彻底检修；对所有设施设备，特别是电气线路，必须进行试运行，无问题后才能正式复工。
6.重点加强周边环境地质灾害的防范。由于台风后地面积水多，并继续有强降雨，各生产经营单位应组织力量对单位周边的围墙、广告牌、边坡等进行认真的检查，重点防范滑坡、地陷、坍塌事故的发生；对发现的隐患要及时处理，不能及时处理的，要设置警戒线，限制人员进入。
