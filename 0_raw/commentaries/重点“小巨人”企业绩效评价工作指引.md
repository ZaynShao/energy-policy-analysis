# 重点“小巨人”企业绩效评价工作指引

1.资金使用评价
专账核算：企业要对财政奖补资金实行专账核算，按照财务规章制度和会计核算办法进行财务处理；
资金用途：严禁用“白头单”入账或套取资金，不得用于工资、水电费、房租费、物业费、餐饮费等日常运转支出，不得用于房屋、基金、股票、期货等投资性经营支出；
拨付要求：不得用于业务接待和其他违规支出，不得用于平衡本级财政预算。
2.资金管理评价
重点“小巨人”企业所获奖补资金，支持“小巨人”企业加大科技创新投入，以及提升协作配套能力。
打造新动能：从人才、组织机构、设备条件等方面，加强企业创新能力建设，打造创新团队；
攻坚新技术：突破关键核心技术，产生原创性、颠覆性科技新成果；
开发新产品：以科技创新引领产业创新，加快科技成果向现实生产力转移转化；
强化产业链：加大产业化投入，着力提升产业链供应链韧性和安全水平。
3.绩效目标评价
根据《新一轮第一批专精特新“小巨人”企业年度绩效目标完成情况表》对企业绩效目标完成情况、推进计划完成情况、投资情况等材料进行收集，逐一进行现场核查。
二、自评报告以及佐证材料清单
企业基本情况：简要描述企业所属领域、主要产品、技术优势及在产业链中的定位，突出企业在细分市场的专业优势和不可替代性。
推进“三新”“一强”计划的完成情况及经验做法：完成情况方面，需对照年度绩效目标完成情况表逐项填写；
经验做法方面，简要总结企业在技术攻关、人才引育、产学研协同、产业链配套、资金管理等方面的可复制、可推广经验，重点突出某一方面的创新做法和示范意义。
取得成效，分四个方面阐述：关键核心技术突破（突出原创性和行业引领性）；经济效益与市场竞争力提升（填写主营业务收入、净利润、主导产品市场占有率等指标）；
产业链供应链支撑作用（强调对上下游的带动作用和产业安全贡献）；社会效益与行业影响（体现就业、绿色发展、行业标准等方面的贡献）。
自评结论：在“超额完成”“完成”“未完成”中选择对应结论；如存在未完成指标，须逐条说明原因及后续整改措施。
知识产权方面提供新增I类知识产权证书或受理通知书，参与制修订的标准；
首台套提供认定文件、新产品鉴定报告、检测报告及实现进口替代/填补空白的相关证明材料、发达国家或地区认证证书；、
产业强链要有企业配套合同及发票，以及其他与绩效目标完成情况相关的证明材料。
