# 河北省政府投资基金清单：固态、钠离子、全钒液流等储能电池研制/绿电算力一体化等

新型储能（C26化学原料和化学制品制造业、C38电气机械和器材制造业）：固态、钠离子、全钒液流等储能电池研制；储能领域关键材料及核心部件研发；储能产业规模化发展。算力产业：算力基础设施建设（E49建筑安装业、I65软件和信息技术服务业等）：全国一体化算力网络京津冀国家枢纽节点建设；京津冀一体化算力网、省级算力资源池、张廊智能算力廊道等构建；通算中心、智算中心、超算中心等建设；绿电算力一体化协同发展。
高效光伏（C38电气机械和器材制造业）：新型薄膜、异质结、钙钛矿等新型光伏发电技术研发和产业化；光伏组件轻量化、抗衰减等技术升级；柔性光伏组件、光伏建筑一体化组件等特色产品研制；光储一体化技术研发与应用。
高端风电（C34通用设备制造业、C38电气机械和器材制造业、C39计算机、通信和其他电子设备制造业）：大型高端风电整机研发制造；风电主轴轴承、齿轮箱、高性能碳纤维叶片等核心零部件生产；新型传动、智能控制、在线监测、安全防护、风电蓄能等关键技术攻关。绿色氢能（C34通用设备制造业、C38电气机械和器材制造业）：氢能“制储输用”全产业链构建；大型化低能耗制氢装备、高压气态储氢瓶、液氢储运容器等氢能装备研制；氢燃料电池及核心零部件研发生产。
