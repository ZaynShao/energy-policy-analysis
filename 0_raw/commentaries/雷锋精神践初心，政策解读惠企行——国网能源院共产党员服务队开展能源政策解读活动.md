# 雷锋精神践初心，政策解读惠企行——国网能源院共产党员服务队开展能源政策解读活动

4月1日，国家电网能源院共产党员服务队走进长沙县新型电力系统临空经济示范区，与湖南经研院能源中心党支部、国网长沙县供电公司“电雷锋”共产党员服务队联合开展“雷锋精神践初心，政策解读惠企行”主题共产党员服务队活动。

  

  

  

本次活动邀请了蓝思科技、上汽大众、中铁建、山河智能、三一集团、金科景朝等企业参加。共产党员服务队队员、财审所副所长张超，从政策出台背景、主要内容、未来方向等方面，介绍了2025年以来出台的新能源入市、新能源就近消纳以及新型储能容量电价等政策机制，并重点分析了价格政策对新能源及储能企业的发展及经营相关的影响。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/vYw27Y7HicGcTHoJfhmyRyPzzQ5ib2KJDfW973soYnqRnsp8SOfJYfpXlLcvzMibxZu3cC5e6sG5vPQ2WIyW0avr6j6YrfkeIGicCynlqK1JnTo/640?wx_fmt=jpeg&from=appmsg)

在政策讲解与互动交流环节，服务队队员针对企业提出的政策疑点、发展难点逐一解答，对于如何适应电力市场化改革、实现企业长远稳健发展，提出了意见建议，彰显了党员服务队工作宗旨。
