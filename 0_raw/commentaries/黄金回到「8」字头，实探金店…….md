# 黄金回到「8」字头，实探金店……

“给我来一个20克的。”
“我要一个生肖羊的。”
“咱一个一个来，都别着急！”
25日上午，北京市西城区菜百首饰总店投资金条柜台的销售人员扯着嗓子应对着前来选购的顾客。
25日，现货黄金跌破4000美元/盎司关口，上海黄金交易所Au99.99（黄金现货实盘合约）价格重回“8”字头，日间收盘价为874.95元/克。各大品牌足金首饰报价多在1220元/克左右。
25日上午，中新经纬来到菜百首饰总店。开门前，门口就已经聚集了不少等候的顾客。九点半门店正式营业，大批顾客进门后，第一时间直奔四楼投资金条专区。
25日上午9点25分，投资者在菜百首饰门口等候 中新经纬李自曼 摄
整个上午，菜百投资金条柜台爆满，销售人员一刻不停忙着开票、出货。中新经纬在现场看到，10克、20克这类小克重金条最抢手。有出手阔绰的顾客直接入手200克，还有投资者背着双肩包买走14根金条。接近中午12点时，10克基础投资金条、20克生肖马金条卖断货。
中新经纬以投资者的身份与顾客交流发现，不少人是趁着今天金价下跌前来抢购金条。
北京投资者王欢（化名）表示，看到金价降了，今天一早就来菜百，先买了一个项链吊坠，又以870元/克的金价，买了40克金条。
“今天菜百开门时投资金基础价在875元/克左右，等了一会儿降到870元/克左右，我就直接下单了。”
25日上午9点30分左右菜百投资金条柜台 中新经纬李自曼 摄
有着多年黄金投资经验的投资者张红（化名）表示，金价后续可能还会下跌，但目前金条价格较年内高点每克下跌近400元，可以适当买入。
“我今天一早就来了，自己的孙子近期要过生日，所以想趁着当前‘8’字头的价格先买30克金条，送给孙子。”张红说。
以26550元买下30克金条后，张红并未着急离去，而是和其他投资者交流起经验，讨论金价下跌至600元/克的可能性。
除了年纪稍长的投资者，还有年轻投资者请假来买金条。投资者刘丽（化名）表示，昨天金价一直跌，她忍住没买。眼看今天又跌，想着趁着价格下跌抓紧上车。
“我请了两个小时事假，专门来菜百，公司距离菜百40分钟车程，买完我再回去上班。”刘丽说，她第一次下单时金价为872.8元/克，后面金价跌至870元/克，她便排队换了新的订单票据，最终以870.1元/克的基础金价购入30克投资金条。
中新经纬了解到，在菜百首饰投资金条柜台开完购买单据后，单据上的金价一个小时内有效。在一小时内，无论实时金价如何变化，顾客付款均以票据上为准。
部分投资者先在自己认为合适的价位开好单据，便在旁边继续观察金价变动情况，如果金价下跌，他们会请工作人员重新更换为价格更低的单据。顾客换到自认为合适的价位后，在收银台缴费，拿着缴费单才能在取货处拿到金条实物。
有顾客在872元价位开出票据后，眼见金价滑落至870元，便立刻加入换票长队，盯着盘面细微波动反复调整。
上午10点20分左右，菜百投资金基础价格一度跌至869元/克左右，瞬间不少顾客涌向柜台换票。现场工作人员也前来维持秩序，让大家排队换票。
在收银区和取货窗口，三个收银窗口都排起长队。有一位投资者对着排队的顾客说：“我的票还有10分钟过期，能不能让我先付款。”
投资者在收银台排队缴费 中新经纬李自曼 摄
中新经纬在现场看到，一些顾客直接提着现金付款，也有人把多张银行卡的余额都刷完。
“您这100克需要88310元，这卡里的钱不够了，剩下的怎么支付？”菜百首饰销售人员询问缴费的顾客。
“我还有其他几张卡，您都刷一下，剩下的不够我再用微信或者支付宝付。”该顾客边说边拿出了剩下的几张银行卡，全都刷完后，又用微信支付了几千元。
相比投资金条，足金首饰的价格并没有降多少。整个菜百首饰一楼大厅的足金首饰柜台相比投资金条柜台要冷清很多，不少柜台只有销售人员单独站在那里。
一位菜百首饰销售人员表示，金价较之前有所下滑，这两天也有不少顾客前来选购。“如果金价还跌，我自己也会考虑买点儿。”
Wind显示，截至25日发稿前，现货黄金报3979.88美元/盎司，较1月份历史峰值已回调近30%。
此轮金价下挫，主要受美元指数走强、美联储加息预期升温以及前期获利盘集中出逃三重因素叠加影响。
值得注意的是，此前长期看多黄金的国际投行已纷纷调转口风——高盛将2026年末目标价从此前的5400美元大幅削减至4900美元，德意志银行亦将三季度均价预期下调至4300美元附近。多家机构研判认为，若美联储后续真的重启加息，黄金价格可能仍有下跌空间。
