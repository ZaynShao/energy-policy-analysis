# 市政协召开“攻坚绿电消纳，建设新能源高地，打造全国能源资源战略保障基地”专题协商会

乌鲁木齐晚报讯（全媒体记者贾梦妍）7月22日，市政协召开“攻坚绿电消纳，建设新能源高地，打造全国能源资源战略保障基地”专题协商会，充分发挥专门协商机构作用，搭建交流平台，以高质量协商成果为我市经济社会高质量发展贡献智慧和力量。

会上，六位政协委员紧扣主题、踊跃建言，行业专家也紧扣主题、直面痛点，发言既立足于对全市能源发展大局的宏观把握,又聚焦消纳堵点作了精准的“解剖麻雀”，提出的对策建议既有战略高度又有落地抓手，很多建议务实管用、含金量高。

市发改委、国网乌鲁木齐供电公司等部门的负责同志与委员们进行了面对面协商交流，积极回应关切，对进一步攻坚绿电消纳明确了思路和举措。

会议指出，要提高政治站位，深刻认识攻坚绿电消纳对推动高质量发展的战略意义，找准找实破解消纳难题的切入点和发力点，真正把我市的“风光”资源优势转化为高质量发展胜势。要坚持问题导向，集中力量破解制约绿电消纳的痛点堵点，发挥政协优势，为打造新能源高地持续汇聚智慧和力量。

会议强调，要持续深化协商调研，用好“乌鲁木齐·齐商量”协商平台，邀请更多一线企业、技术专家、利益相关方深度参与，真正把情况摸透、问题找准、对策提实，拿出一批能落地、可见效的高质量提案和社情民意信息，广泛凝聚各界共识，汇聚攻坚克难合力。

市政协党组书记杨文光出席会议并讲话；副市长姜子刚，市政协党组成员哈米提·买买提伊明参加会议。
