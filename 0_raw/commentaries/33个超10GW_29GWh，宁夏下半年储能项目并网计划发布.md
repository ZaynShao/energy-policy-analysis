# 33个超10GW/29GWh，宁夏下半年储能项目并网计划发布

吴忠市：计划并网规模最大，12个项目，规模4.74GW/12.34GWh
中卫市：6个项目，规模1.82GW/5.84GWh
宁东：3个项目，规模1.33GW/5.01GWh
石嘴山市：6个项目，规模1.26GW/3.24GWh
银川市：5个项目，规模0.8GW/2.2GWh
固原市：1个项目，0.1GW/0.4GWh
文件还要求，各地市、宁东能源主管部门要加强清单动态管理，做好协调服务与精细调度，及时清退长期未实质性开工或实质性开工后不及时跟进建设的项目，支持符合条件的项目补充调入，确保按期完成全市并网任务。
在接入复核、接网工程、调度命名、并网协议、停电计划、调试运行等环节加强指导服务，压缩并网验收用时，坚持急事急办、从简从快，确保到期即并、应并尽并。
支持储能并网任务完成好的地区及企业优先开展新增风电项目核准、新能源项目接入评审和电网项目纳规，同时将并网任务完成情况纳入各地市、县区年度效能目标管理考核体系。
