# 架构即优势，小鹏凭借VLA2.0重回T0梯队

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/RaRCbSicibjeWukd3ibuH4Eic9kxjrYcjfDdXJ4vzibWoqrFKZ169pdoyqzSvoC7XCyiaQOZ3EviaIZHiaTvIplAiatFCCvFibxR9XDszpxK954Y1Uvu8/640?wx_fmt=jpeg&from=appmsg)

# ****  
****

“ L2，就是一个缝合怪。”

“好的智驾应该像坐电梯一样，按下启动键，就能够从家里到达公司。”

“我们的第二代VLA重构的模型范式直奔L4的终局。”

“3年甚至不用3年，我们的汽车一定要能够自己可以开。”……

3月2日，在小鹏第二代VLA媒体体验日上，小鹏汽车董事长何小鹏放出了一系列豪言。而诸多已经体验产品的媒体、KOL、KOC也已经按捺不住，在社交媒体大赞进步巨大、小鹏智驾进入T0梯队。

自成立以来，小鹏就以智驾为突出卖点，但在领先车企都加码智驾之后，小鹏智驾的竞争力不再明显。但此次小鹏以第二代VLA为框架，大胆喊出跨越L3、直奔L4，以及做“国民智驾”，“让妈妈都爱开”，体现出超强的技术自信。

搭载同一技术的小鹏Robotaxi已开启公开道路测试，今年内小鹏Robotaxi将开启试运营。这意味着小鹏将继特斯拉之后，成为全球用一套系统跑乘用车和Robotaxi的车企。

汽车智能化之后，竞争规则彻底改变。在智驾方面，技术范式革命带来的提升，远胜于埋头苦干。不仅于此，技术范式选择的正确或错误，可能导向天堂与地狱。

**01****  
**

**第二代VLA****支持下，妈妈都敢开智驾了**

在第二代VLA媒体体验日之前，小鹏汽车邀请了一批食堂阿姨——大部分是小鹏员工的妈妈来体验。

何小鹏解释说，这个想法来自于他自己的体验。何小鹏的妈妈一开始乘坐辅助驾驶车辆时，非常担心，到了现在，才感觉到真正是丝滑，放心。“如果L4或者Robotaxi应该是所有的人，不管你开车还是不开车，不管你擅长开车或者是一个新手司机，都敢开。”

何小鹏也在发布会上说，要做“妈妈也能安心开的国民智驾”。

之所以强调这一点，何小鹏表示，是针对此前L2辅助系统的三大痛点，首当其冲就是不安心，另外两个是使用场景受限、效率不高。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeXCWpfQ0rNN1UyroBledibBHy0Sic8JfsYJbHw8Y9fH50Bz91E0d88968QlIqpjTnrasBEXp0ibd7q9QlxrU0Ibk6BVmyjAv2PoOU/640?wx_fmt=png&from=appmsg)

何小鹏总结了四大不安心的智驾场景，包括异形车辆能否识别绕行；路边车辆突然开门能否避让，颠簸路段或减速带能否舒适通过；以及夜间行人或障碍物能否及时发现。

在测试视频中，这些场景第二代VLA版智驾都已经能够做到。尤其值得一提的是，在夜间颠簸的烂路，第二代VLA版智驾也能够自动绕行。这意味着以视觉为中心的小鹏智驾，对于负高度地形也能够很好的理解并做出决策。

智驾的安心感还和智驾的舒适度紧密相关。为此，小鹏汽车还特意开发了一个小程序“洒了吗”来评估智驾体验。

第二代VLA肯定用这一小程序测试了。何小鹏介绍，第二代VLA和此前的智驾辅助系统相比，舒适度大幅提升。比如，基本消除了重刹、急加速、顿挫；安全接管减少60%；另外路面障碍物识别能力、侧后车辆识别能力、前车轨迹预测能力、夜间决策能力都大幅提升。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeWbNVuBUcSrRY92bxzaDVe5nzOQ7M9bxvQdEicuiajiatlTHH8TTXMYxH9sz02MtHU4OftVkq17fkIfic7hjpPYpiaHmHeWUiaOVjeDk/640?wx_fmt=png&from=appmsg)  

L2级辅助驾驶第二大痛点是使用场景受限。  

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeUaZwriaTGOlkuKz9qvac9rY8r3Z9XqqR1MvYD5fAauZicYthdHkmuDkNygJKrnNqiadAYpnFQtNuKxGLzsMicC2zakNWHgr7m0EEg/640?wx_fmt=png&from=appmsg)

而第二代VLA已经没有了场景限制，甚至连乡村土路，乃至暴雨道路都能开。

不过，何小鹏也坦言，并不是所有场景的体验都一样好。

“在城区里面，其他的辅助驾驶大概是70分，我们可能是99分；但是在小路的情况下，可能他们开的是10分，而我们开的是75分；在停车场的情况下他们可能是0分，我们可能是60分……但是我非常有信心的是在今年年内，我们所有的道路都会跟城市主干道一样，开到99分。”

L2级辅助驾驶第三大痛点是效率不够高，老司机嫌智驾开得太肉。  

“我们的第二代VLA在通行效率上，已经初步比肩老司机人驾了，我讲的还是初步，因为我相信今年我们还有巨大的提高。”何小鹏说。

他举了一个测试例子，在广州小鹏第二代VLA的智驾从A点到B点，用时43分钟，比导航预估时间少1分钟，而L2级辅助驾驶需要48分钟，至于L4的Robotaxi，用了49分钟。从综合行车效率而言，第二代VLA提升了23%。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeXXJYC0N5vh9DHY14rPawMbJC2p189SzjlmZbuemw9FytdyYJAsPbct78jm7ia6PCTvMKFOicZh6Xib0nMicGgh3IbVFc164zCibVIQ/640?wx_fmt=png&from=appmsg)  

何小鹏还表示，第二代VLA不仅开得好，而且还开得很聪明。他播放了两段视频，第一个视频中，第二代VLA的车型会主动靠边避让后方过来的救护车。在第二个视频中，第二代VLA的车型碰到查酒驾的交警，能够自动停车和启动。

这两个片段呈现出AI模型的“涌现”特征，第二代VLA可能会未经训练地、不可预测地习得某些能力，令人惊喜。

何小鹏在活动上介绍的这些第二代VLA的能力，部分已经被早期体验的一些媒体、KOL、KOC所确认。

小鹏汽车计划3月下旬，将逐步面向用户开始全量推送第二代VLA。在售车型中，同一天发布的X9纯电版以及此前的超级增程版的Ultra和Ultra SE版本，P7 Ultra、G7 Ultra（纯电）将首批推送。4月份，其他车型的Ultra和Ultra SE版本也将全量推送。  
  
不出意料地话，第二代VLA的搭载，将给小鹏产品在智驾层面的竞争力带来一次明显提升。如何小鹏所说，“它是小鹏和其他的自动驾驶企业拉开差距的一个起点，它也可能是目前中国最好用的自动驾驶。”

**02  
**

**智驾一号位，“轮”到刘先明**

在何小鹏之后，刘先明登上了活动的讲台。

他是小鹏汽车通用智能中心负责人，如今小鹏智驾的一号位。

小鹏智驾开发，历经传统的自动驾驶开发理念，从地图、规控、软件，发展到规控+模型的混合。

而刘先明代表的，则是完全不一样的技术路线。

刘先明在活动后的采访中，解释小鹏的路线和其他车企的不同时说，“问题核心就是你是做自动驾驶还是AI？”

刘先明明确说：“我们做的是一个AI，不是专门只是用来做自动驾驶。”

所谓做AI，指的是用AI的规模法则，来开发自动驾驶所需要的物理世界模型。而规模法则，就是L4能力=模型x算力x数据x本体。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeX2Oz54GQ1kdXbicqVeE4qmezpmNf2AFqZoeA1MFpgxks3ViadEmYTKoiaJqTT6rGn6slVNUHTUrFZfiaOHqpwvkq6yjVcPzqW4SVI/640?wx_fmt=png&from=appmsg)  

在模型层面，第二代VLA是原生多模态物理世界大模型。关于模型，智驾行业有VLA、世界模型的不同表述。刘先明表示，“概念之争没有必要。世界模型本质上是对世界3D空间的理解、运动规律的理解，最终以一种形式展现出来，这个和VLA本质没有什么太大的区别。”

正因为如此，小鹏的第二代VLA，不仅是自动驾驶模型，还可以应用在Robotaxi、飞行汽车和人形机器人上。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeU61DcJlvvKX4XzY9QRtosQWswR2RjdPh7iaLssWVRMP3tkNB1XcOSahaggDQIHv6RLtG5K4M7b5Osw7r4OnU4kRFcxDbKR3W2o/640?wx_fmt=png&from=appmsg)  

在算力层面，刘先明强调“有效算力”的概念。有效算力的提升，需要将芯片-编译器-模型做联合优化。小鹏坚持的软硬一体研发，不仅自研了图灵芯片，而且根据芯片定制化图灵结构的模型，还自研了自动化编译体系，使基座模型的编译效率提升12倍，大幅优化算力利用率，降低模型推理时延。

刘先明称，最终，单颗图灵芯片的有效算力接近于10颗英伟达Orin-X。

在数据层面，第二代VLA累计使用50PB训练数据，每秒处理约53亿字节视觉信息，每版模型的训练数据达到4万亿Tokens。

基于领先的AI基础设施，自2025年科技日以来小鹏汽车开发了468版模型。

这样的迭代速度确实闻所未闻。不过，这也契合刘先明以AI方式开发的逻辑，对比其他自动驾驶的架构，第二代VLA迭代速度有了质变。“我们现在追求的是不仅跑得快，加速度还在持续变大。”

和VLA1.0相比，VLA2.0最大变化是，把此前视觉（V）—语言（L）—动作（A）流程，简化为从视觉信号-直接输出车辆控制指令（转向/油门/刹车），去掉了“语言转译”这一环节，延迟从200ms降低到80ms，安全冗余提升。

另外，小鹏汽车智驾的VLA和智舱的VLM大模型将实现跨域融合，让汽车进化为能同时为用户提供主、被动能力组合的超级智能体。

在体验层面，小鹏座舱助手会类似于特斯拉Grok，车主可以通过语音，下达驾驶指令，甚至其他和驾驶、出行无关的指令，智能座舱都能执行。

刘先明负责的通用智能中心，业务涵盖智驾和智舱。他个人的核心任务之一，也是打通智驾和智舱。

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeXIz8kylkG3QytrRp1zx1MJWVwAtQuJsOKqCASqy8bQIOc8K9WfMHdrYSONqGficTiavZZz8sk4fzFObFmLm8Kodv85oPhGphef0/640?wx_fmt=png&from=appmsg)  

刘先明在小鹏汽车受到重用，也是当今自动驾驶开发的趋势。不少企业的技术架构乃至组织模式，也在替换为“AI native”（AI原生）的架构，比如，取消规控团队，将智驾智舱融合等等。而且，技术领头人也开始变为AI、机器人、计算机科学方面的顶级人才。

当然，毫无疑问地是，小鹏汽车不仅这么做，而且做得早，做得坚决，也已经在呈现结果。

**03  
**

**架构即优势，小鹏再领跑**

第二代VLA在手，何小鹏如今也是信心满满。

在汽车领域，他和刘先明打赌，刘先明要在8月将小鹏智驾的国内表现提升到特斯拉在美国湾区的水平，否则刘先明要在金门大桥裸奔。

同时，第二代VLA也将覆盖小鹏几乎所有车型。而且在出海方面，小鹏第二代VLA即将开启全球路测，并计划于2027年开启全球交付。此外，大众将成为小鹏第二代VLA的首发客户。

在Robotaxi方面，目前，搭载小鹏第二代VLA的Robotaxi已开启公开道路测试，今年内小鹏Robotaxi将开启试运营。

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeWoztTa4ebJsHhVAHjW0PO86d93BNYUhHt2epoutDcCJU8yF5ibQ9AfpcZHhSFeTyMicjajIicwpzG4kVtwTviaHqgm1mgTcMp2pTw/640?wx_fmt=png&from=appmsg)

小鹏GX的L4级测试车

  

而且，今年小鹏还要实现人形机器人量产、飞行汽车的量产，两者也都将应用第二代VLA的成果。

  

在领先行业的技术架构引领下，小鹏智能化优势一时间呈现大爆发之势，不仅是国内在售车型的竞争力，而且扩展到海外，还有商业模式的创新，更有多智能物种的协同。

  

类似于特斯拉，小鹏布局芯片、操作系统、基座模型，不仅在打智能汽车的仗，还布局Robotaxi、人形机器人、飞行汽车。

从这些角度，小鹏是唯一能和特斯拉正面PK的中国选手。在中国而言，小鹏智驾也将重新成为智驾领先者，引领技术范式的迁跃，乃至消费者认知的重大变革。
