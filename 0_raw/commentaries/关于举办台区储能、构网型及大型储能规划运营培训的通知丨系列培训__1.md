# 关于举办台区储能、构网型及大型储能规划运营培训的通知丨系列培训

关于举办台区储能、构网型及大型储能规划运营培训的通知
各单位：
当前，我国新型电力系统建设加速推进，储能作为支撑新能源消纳、保障电网安全稳定运行、提升电力资源优化配置效率的核心关键环节，已进入规模化、规范化、高质量发展新阶段。同时台区分布式储能广泛落地、大型集中式储能项目批量投产、构网型储能技术逐步替代传统跟网型储能成为电网调频稳压核心方案，这些新型储能项目的科学规划、合规建设、高效运营专业能力至关重要。
为帮助各单位从业人员精准把握最新储能政策标准、技术迭代趋势与市场化运营规则，系统掌握台区储能、大型储能、构网型储能差异化规划方法、运维要点及盈利模式，破解项目规划不合理、运营效率低、技术适配不足、安全管控薄弱等行业痛点，全面提升这些储能项目全生命周期管理水平，助力储能产业合规、安全、高效发展，中国能源报特举办储能、构网型及大型储能规划运营专项培训，培训结束后，将将发放《中国能源报》社有限公司中国能源经济研究院“新型储能规划运营”结业证书。
具体安排如下：

2.算力企业、数字信息化服务公司、综合能源服务公司以及大型用电用能机构等；
3.高校、科研院所、投资、律所等机构；

储能行业基础知识及安全要求
台区储能规划设计与精细化运营管理
大型储能项目开发建设与市场化运营
网侧大型储能规划与各省配储项目实践
构网型储能核心技术、应用场景与运维管控
零碳园区建设与绿电直连中的储能协同
储能在智算中心的应用及核心要求
储能设备出海碳关税壁垒及应对策略
储能主要海外市场情况与海外市场运营
