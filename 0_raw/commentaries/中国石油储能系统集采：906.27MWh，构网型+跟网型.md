# 中国石油储能系统集采：906.27MWh，构网型+跟网型

本项目采购划分为4个标包，总采购容量为906.27MWh。其中包含1个构网型标包，采购规模为6.27MWh；剩余3个标包为跟网型，合计采购规模900MWh。
0.5C：采购规模20MWh
0.25C：采购规模886.27MWh
投标人磷酸铁锂储能系统中使用的电芯和储能变流器（PCS）必须是中国石油天然气集团有限公司供应商资源库中电芯和储能变流器（PCS）有效的一级物资供应商；
不接受联合体投标。具有独立法人资格的磷酸铁锂储能系统制造企业，若单位负责人为同一人或存在控股、管理关系的不同单位，不得同时参加本项目的投标，否则相关投标均无效。
