# 地方绿金 | 新疆首批生态产品价值（VEP）质押贷款落地伊犁

本网讯 记者张乐 通讯员魏玲玲 杨晓艳 马舒娟报道 近日，在中国人民银行新疆维吾尔自治区分行的指导下，中国人民银行伊犁哈萨克自治州分行与本地高校在绿色金融领域加强合作，推动新疆首批特定地域单元生态产品价值（VEP）质押贷款成功落地。新疆农商银行伊宁县支行、新疆银行分别以405亩玉米种植、4000亩辣椒种植项目的VEP价值为质押参考，共落地1900万元VEP质押贷款，标志着新疆在探索生态产品价值市场化与绿色金融创新领域取得突破性进展。
据悉，此次创新实践中，两家企业的VEP测算均由伊犁师范大学资源环境系团队承担。中国人民银行伊犁哈萨克自治州分行与伊犁师范大学专业团队联动，对比国内经济结构类似地区VEP核算标准，最终选取《特定地域单元生态产品价值核算及应用指南》《农用地估价规程》及《陆地生态系统碳汇核算指南》等国家和地方标准作为核算方法。伊犁师范大学专业团队根据植被生物量、水源涵养、气候调节、释氧、生态系统固碳、生物多样性维持等多维度评价指标，将无形的生态价值量化为可评估、可质押、可融资的资产，为金融机构提供了科学、可验证的生态价值量化依据。
VEP生态产品价值质押贷款是金融机构以特定地域单元生态产品的供给服务、调节服务和文化支持服务三类生态价值的核算量化作为质押参考创设的一种绿色贷款产品。基于此次核算的特定区域玉米和辣椒种植农田情况，调节服务类价值核算依据《陆地生态系统碳汇核算指南》，采用“碳库差别法”对玉米和辣椒种植农田的固碳功能进行专项核算——覆盖地上生物质、地下生物质、枯落物、土壤有机碳四类碳库，并以国内核证自愿减排量（CCER）市场成交价格为基础进行价值量化，为未来企业整体碳汇核算迈出了探索步伐。
伊犁某旅游开发管理有限公司位于伊宁县萨地克于孜乡，此次VEP评估对象为405亩玉米种植基地。经核算，物质供给类生态产品价值（扣除耕地等生态要素）为8398.21元，405亩农田年均固碳量达2498.05吨二氧化碳当量，调节服务类（碳汇）价值为28.63万元，最终该基地VEP总价值为29.47万元，新疆农商银行伊宁县支行依托这一生态价值认定，成功为企业发放700万元VEP质押贷款。
在推动本地VEP核算的同时，中国人民银行伊犁哈萨克自治州分行推动新疆银行和伊犁师范大学开展合作，同步探索跨区域核算服务。沙湾市某农业科技有限公司位于沙湾市安集海镇，企业以4000亩辣椒种植基地为评估对象。经测算，该基地特定地域单元生态产品总价值为4531.53万元，其中，调节服务类（碳汇）价值为282.11万元。新疆银行以此次核算报告为重要参考，向企业成功发放1200万元流动性资金贷款，形成了“生态资源核算—VEP价值评估—质押授信—产业反哺”的良性发展闭环。
