# 甘肃1月电力市场：调频补偿5363万元，现货日前均价0.256元/kWh，实时均价0.254元/kWh

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)

「储能与电力市场」获悉，4月21日，甘肃电力交易中心发布2026年1月甘肃电力市场运营报告。  

  

**重点内容如下：**

截止1月，甘肃电力交易中心共注册市场主体9071家。其中独立储能企业21家；辅助服务聚合商12家，虚拟电厂2家。

  

现货市场方面，日前市场平均价格256元/兆瓦时，日前市场均价最高331元/兆瓦时，最低152元/兆瓦时；  
实时市场平均价格254元/兆瓦时，实时市场均价最高398元/兆瓦时，最低78元/兆瓦时。

  

辅助服务市场方面，1月，调频市场随现货市场运行，贡献调频里程251.3万兆瓦。

  

省内辅助服务市场中调频辅助服务市场产生补偿费用5362.88万元。其中电网侧储能分摊费用90.06万元。

  

截止1月，甘肃全省发电装机容量12482.67万千瓦，同比增长 23.95%。全省发电设备平均利用小时数为206小时，同比持平。

  
**

装机容量/发电量/发电小时数**

  

装机容量方面，截止1月，甘肃全省发电装机容量12482.67万千瓦，同比增长 23.95%。

  

水电971.99万千瓦，同比增长0.06%，占总装机比重（下同）7.79%；  
火电3428.56万千瓦，同比增长32.63%，占27.47%；  
风电4100.10万千瓦，同比增长25.59%，占32.85%；  
太阳能3949.22万千瓦，同比增长22.72%，占31.64%；  
生物质32.8万千瓦，同比增长5.81%，占0.25%。

发电量方面，1月，全省完成发电量264.21亿千瓦时，同比增长27.32%，环比增长3.67%。

  

水电16.50亿千瓦时，同比下降8.12%，占总发电量比重（下同）为6.24%；

  

火电154.82亿千瓦时，同比增长31.44%，占58.60%；

  

风电56.73亿千瓦时，同比增长30.18%，占21.47%；

  

光电33.06亿千瓦时，同比增长22.29%，占12.51%；

  

其他（储能、生物质）3.1亿千瓦时，同比增长166%，占1.18%。

**

市场主体**  
1 月，共有224家市场主体完成市场注册，其中电力用户214家、发电企业9家、售电公司1家（本地注册）。  
截止1月，共注册市场主体9071家。  
发电企业1671家（火电48家，水电835家，风电276家，光伏488家，风光电厂6家，其他发电18家）；  
电力用户7008家（批发用户261家，零售用户6747家），售电公司356家（在甘注册91家，外省推送265家）；  
独立储能企业21家；  
辅助服务聚合商12家，电网公司1家，虚拟电厂2家。  
**省内现货市场运行情况**  
1 月，省内现货市场发电侧正偏差电量73.05亿千瓦时，负偏差电量-48.56亿千瓦时，正负相抵后，净偏差电量24.49亿千瓦时。  
日前、实时市场最高/最低出清电价均达到650元/兆瓦时和40元/兆瓦时限价，

  

日前市场平均价格256元/兆瓦时，同比下降5.8%，环比下降17.6%，日前市场均价最高331元/兆瓦时，最低152元/兆瓦时；  
实时市场平均价格254元/兆瓦时，同比下降16.9%，环比下降17.2%，实时市场均价最高398元/兆瓦时，最低78元/兆瓦时。

**辅助服务市场**运行情况****  

1月，调频市场随现货市场运行，贡献调频里程251.3万兆瓦。  

费用分摊情况方面，1月，省内辅助服务市场中调频辅助服务市场产生补偿费用5362.88万元。依据《甘肃省电力辅助服务市场运营规则》（甘监能市场〔2025〕213 号），调频辅助服务市场补偿费用由电力用户用电量、电网侧储能下网电量和未参与电能量市场交易的上网电量共同分摊。

  

电力用户分摊调频辅助服务市场费用5230.64万元，  
电网侧储能分摊费用90.06万元，  
未参与电能量市场交易的发电主体分摊费用42.18万元。  
**中长期市场**运行情况****  

1月，省内中长期市场按自然日连续运营，总成交电量81.99亿千瓦时（含绿电、融合交易净增量），成交均价232.89元/兆瓦时。

  

从交易品种来看：

  

直接交易成交电量37.02亿千瓦时，成交均价227元/兆瓦时；

  

代理购电成交电量40.17亿千瓦时，成交均价247.97元/兆瓦时；

  

绿电交易成交电量0.4亿千瓦时，成交均价212.34元/兆瓦时；

  

D+2日滚动交易成交电量36.45万笔，净成交电量4.4亿千瓦时，成交均价143.81元/兆瓦时。

  
**

整体结算情况**  

1 月，省内结算电量128.83亿千瓦时，均价269.96元/兆瓦时。

  

外送电量99.14亿千瓦时，均价246.925元/兆瓦时，

  

外购电量1.75千瓦时，均价415.665元/兆瓦时，

  

低价保供电量3.4亿千瓦时，均价111.2元/兆瓦时，

  

绿电结算电量（省内+省间）9.99 亿千瓦时，均价216.559元/兆瓦时，

  

代理购电结算电量40.17亿千瓦时，均价247.974元/兆瓦时。
