# 国家电网：前两月4537公里线路投产，同比增长超80%

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/3f8yKfXErDpYxZHc3XfQCDhYFxL97zuUGTibrVEuiaPD2aj5UzcLiaYyvearkD9RvkkYu4kic8SVu9TL4loSq4XZicQ/640?wx_fmt=gif&from=appmsg)

国家电网前两月投产110千伏及以上交流线路长度同比增长超80%  

国家电网公司深入贯彻落实党中央、国务院决策部署，坚持电力发展适度超前，主动对接国家重大战略部署，全面加强电网建设和升级改造，加快投资落地形成实物工作量。据统计，1~2月，国家电网公司投产110（66）千伏及以上交流线路4537公里，同比增长81.5%，有力带动上下游发展。  
![图片](https://mmbiz.qpic.cn/mmbiz_png/XXLkiawamPztdbfKPRH4QbZGh3kniaOE4yw7wLscBh8ZLIXJVgIN9bzWCq6NwJ6yyTSJyWzheJDjibqic4vrGiboBSO6NSVrDuosv4Via74uxPHLQ/640?wx_fmt=png&from=appmsg&wxfrom=13&tp=wxpic#imgIndex=1)

▲国网冀北电力施工人员在承德东至滦县双回（第四通道）500千伏线路工程展放导线  
年初以来，国家电网公司电网建设保持强劲势头，重点工程建设稳步推进，各级电网协调发展，为实现“十五五”良好开局提供有力支撑。承德东至滦县双回（第四通道）500千伏线路工程投运，进一步提升承德绿电至唐山电网送出能力；西十高铁（湖北段）220千伏外部供电工程线路投产送电，为西十高铁按期投运提供可靠电力保障；江苏淮安上河220千伏输变电工程建成投产，有效满足区域新能源并网与消纳需求；新疆吐鲁番中节能221团升压汇集站220千伏送出工程竣工，有力保障了50万千瓦光伏项目电力送出。  
![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/XXLkiawamPzswZiblIqPuz7flVLefjnxd2uXeL7Ger2ecbPhJQEk6O9Vn49ib5ECXcD1vK7FPBQ3SFHHPFFOBxQjqyaDUiaGiaBicb7fLkyZzI4b0/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=2)

▲国网湖北十堰供电公司员工在西十高铁（湖北段）220千伏外部供电工程现场架设输电线路  
国家电网公司主动加强与各级政府部门的沟通协调，加快项目前期工作，推动工程有序核准建设，为工程依法合规、快速落地创造有利条件；科学统筹工程建设安全质量进度，合理编排工程计划，优化建设时序安排，保证任务节奏均衡有序；深化工程分级分类管理和提级管控机制运转，充分运用合理工期，推动建设计划刚性执行，确保建设任务务期必成。

▲江苏淮安上河220千伏输变电工程  
当前，国家电网公司电网工程建设正全面加快推进。国家电网公司将认真落实全国两会精神，统筹好安全质量进度，安排好各类要素资源，全力推动工程建设，持续优化电网结构，为服务经济社会高质量发展提供安全可靠的电力保障。（来源：国家电网有限公司）
