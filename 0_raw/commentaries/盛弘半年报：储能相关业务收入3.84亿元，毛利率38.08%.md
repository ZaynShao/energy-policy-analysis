# 盛弘半年报：储能相关业务收入3.84亿元，毛利率38.08%

营业收入17.59亿元，同比增长29.16%。
归母净利润2.28亿元，同比增长44.11%。
扣非净利润2.28亿元，同比增长50.45%。
工业配套电源业务，实现销售收入4.41亿元，同比大幅增长57.81%，营收增长最高，毛利率61.94%。
新能源电能变换设备业务（主要为储能变流器等业务），实现销售收入3.84亿元，同比增长35.32%，毛利率38.08%，增长10.29个百分点。
2026年上半年，盛弘股份实现营业收入17.59亿元，同比增长29.16%，营业收入实现稳步增长。
报告显示，盛弘股份目前共有4大业务板块：工业配套电源业务、新能源汽车充换电服务业务、新能源电能变换设备业务、电池化成与检测设备业务。
其中，储能主要归属于新能源电能变换设备业务，包括但不限于模块化储能变流器、直流变换器、集中式储能变流器、储能变流器升压系统等设备，主要应用领域包括新能源发电站配储、独立储能电站租赁、工商业园区 削峰填谷、光储柴微电网或应急备电等场景。
4大业务板块的具体收入及毛利率情况如下：
工业配套电源：营业收入4.41亿元，同比大幅增长57.81%，毛利率61.94%。
新能源电能变换设备：营业收入3.84亿元，同比增长35.32%，毛利率38.08%，较去年同期增长10.29个百分点。
电动汽车充电设备：营业收入7.48亿元，同比增长18.25%，毛利率30.43%，同比下降4.43个百分点。
电池检测及化成设备：营业收入1.33亿元，同比减少0.18%，毛利率30.98%，同比下降8.32个百分点。
从营业收入增长上看，工业配套电源业务表现最为亮眼，同时毛利率也最高。新能源电能变换设备业务也保持了良好增长态势。电动汽车充电设备业务虽然营业收入同比增长，但毛利率却下滑了4.43个百分点，盈利能力下降。电池检测及化成设备业务营业收入与毛利率双降。
工业配套 电源、新能源电能变换设备、电动汽车充电设备销售收入增加，共同带动了盛弘股份上半年营业收入的稳步增长。
图源：盛弘股份2026半年报
应收账款增减，存货规模扩大
报告显示，盛弘股份2026年上半年应收账款10.43亿元，较上年末9.6亿元，增长8.64%，占总资产比例达到了24.61%，较上年末增长了1.55个百分点。应收账款的增加，有可能给企业的资金周转带来更大压力。
另外，在存货方面，盛弘股份2026年上半年存货余额为7.47亿元，较上年末6.4亿元，增长了16.72%，占总资产比例17.63%，较上年末增长了2.26个百分点。报告解释，存货增长的原因主要系本期销售额增加对应备货金额增加所致。
图源：盛弘股份2026半年报
另外，盛弘股份2026年上半年的研发费用为1.58亿元，占营业收入的8.97%，较去年同期增长14.87%，维持了持续稳定的研发投入。
