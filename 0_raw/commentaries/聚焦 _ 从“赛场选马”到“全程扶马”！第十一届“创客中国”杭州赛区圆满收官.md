# 聚焦 | 从“赛场选马”到“全程扶马”！第十一届“创客中国”杭州赛区圆满收官

创业组数量首次“跑赢”企业组
产业基金全程护航
本届大赛报名总数372个，其中创业组报名量首次超过企业组。最终晋级决赛的25个项目中，创业组占14席，企业组占11席——这是“创客中国”杭州赛区办赛十一年来的第一次。
“创客”二字，终于真正站到了舞台中央。创业组项目多为高校院所孵化的早期科技成果转化项目，创始人不少是在校博士生或刚毕业的年轻学者。他们的项目或许尚未大规模量产，但技术原创性极高，如具身机器人高性能控制系统、氪工质霍尔推进技术、类脑智能芯片……每一个名字背后，都是一颗等待破土的种子。

这正是大赛创办的初衷：发现那些尚在实验室里、但有望长成参天大树的“好苗子”。今年,由杭州市科创集团运营管理的润苗基金首次深度参与大赛项目对接，从报名阶段即介入跟踪，将投资视野延伸至赛场之上，决赛25强中，润苗基金已投8家，其中7家来自创业组。某种意义上，创业组的“逆袭”，也与润苗基金“投早、投小、投长期、投人才、投硬科技”的定位不谋而合，让资本与政策的目光，从“摘果子”转向“种树”。
人工智能项目翻番
赛道全面“换挡”未来产业
从参赛领域来看，今年同样释放出鲜明信号：不再以传统的数字经济、软件信息为主打，而是全面向国家战略方向靠拢。
决赛25个项目覆盖智能物联、高端装备、新材料、绿色能源等五大产业生态圈，同时向具身智能、人工智能、类脑智能等未来产业延伸。其中，具身智能、人工智能等新势力项目数量较上届翻番，这与杭州重点布局的“296X”先进制造业集群方向高度契合。
创业组中，既有依托浙江大学、北京航空航天大学、中国科学院大学等顶尖高校孵化的硬核科技成果转化项目，也不乏聚焦前沿方向的年轻团队。企业组则汇聚了一批已深耕产业一线、完成多轮融资的优质企业，覆盖AR光波导、混动倾转旋翼eVTOL、商业航天核心芯片等细分赛道，其中多家已入选国家级专精特新“小巨人”或省级专精特新企业。

冠军项目直击“卡脖子”
4D世界模型估值超百亿
获得创业组一等奖的“国产高端装备数字光阀底层核心芯片”项目，主攻高端装备的“底层核心”赛道。这颗被称为高端装备“瞳孔”的芯片，在激光直写光刻、PCB数字曝光、半导体数字光刻等关键环节决定着装备的精度与速度，长期以来被海外巨头垄断。团队历时多年攻关，完成从底层设计到量产验证的全链路突破，这不只是一个项目，而是一条产业链的“补位”。
企业组一等奖得主魔芯科技，凭借“KOKONI-World 4D世界模型”杀出重围。这套全国产自研的4D世界模型，能够实时重建与编辑动态物理场景，在具身智能、数字孪生、消费娱乐等赛道已跑通商业化。成立四年，魔芯科技已完成多轮融资、估值超百亿，投资方阵容里既有国家社保基金、深创投等国家队，也有华为、联想等产业方。这条“技术+资本+场景”的闭环，正是它筑起商业壁垒的关键。
如果把决赛名单摊开来看，几乎每个项目背后都对应着一个亟待破解的行业命题。依托诺奖得主直接持股的晨伫生物，是全球唯一能解析蛋白质从“休眠”到“激活”完整动态过程的企业，让AI制药不再停留于“算得快”，而是真正“算得准”；专注高危工业场景的旷行科技，手握全球最大的高危工业异常数据库，让机器人在矿山、油气化工等“人不愿去、不敢去”的地方替人值守；新型前沿材料MOFs工业级智能制造项目，则以自主突破的成型及界面集成工艺，将这一曾困于实验室的前沿材料推向能源、环境、生物医疗等真实产业场景。三个项目，三种路径，共同指向同一件事：好技术，要长成好产品。

比赛采用路演加答辩的形式，25个项目要在有限时间内亮出技术家底，直面来自红杉资本、赛智伯乐、浙商创投等7位资深评委的轮番拷问，条分缕析、见招拆招之间，技术含金量与商业化诚意一览无余。
十一年孵化492家专精特新
赛后签约才是“下半场”
作为发掘和培育专精特新企业的重要赛事，“创客中国”杭州赛区已走过十一个春秋。累计吸引超3200个项目参赛，216个项目在市级获奖，其中12个项目斩获省赛一等奖，4个项目摘得全国总决赛一等奖，培育出492家省级专精特新企业和108家“小巨人”企业。
颁奖典礼上，杭州市经信局党组成员、副局长李明松表示，当前杭州正聚焦省“415X”和市“296X”先进制造业集群建设，“创客中国”大赛正是培育专精特新企业和新质生产力的重要抓手。“希望大家保持敢为人先的锐气和十年磨一剑的定力，把技术做深、把产品做精、把企业做强。”
杭州联合银行党委委员、副行长沈基良亮出一组数据：作为连续第十一年深度参与大赛的伙伴，杭州联合银行累计服务科创企业突破万家，服务历届参赛企业超500家、授信总额超100亿元；杭州每三家“专精特新”企业中就有一家在联合银行开户，每四家获股权融资的科创企业中就有一家接受过服务。
现场，大赛组委会为杭金投·数字金融产业生态中心、杭州市创业投资服务中心等8家机构颁发“优秀合作伙伴”奖项，为萧山经开区国控集团、浙大创新创业研究院等10家单位颁发“优秀组织机构”奖项，并为十位创业导师授予“十佳创业导师”荣誉。

更值得关注的是赛场之外的“下半场”——部分获奖项目与杭州市科创集团、杭州联合银行现场签署润苗基金及银行信贷合作协议。这意味着，比赛落幕后，资金与资源将接力进场。这也释放出第三个信号：大赛的功能正在从“赛场选马”走向“全程扶马”。
本次活动由浙江省经济和信息化厅指导，杭州市经济和信息化局（杭州市数字经济局）、杭州市萧山区人民政府主办，杭州市工业和信息化服务中心（杭州市中小企业服务中心）、杭州市萧山区经济和信息化局承办，杭州联合银行、杭州市科创集团有限公司、杭州市融资担保集团有限公司、杭金投·数字金融产业生态中心协办，浙江乌镇街科技有限公司执行，总决赛专场由杭州宜人科技有限公司协办。
