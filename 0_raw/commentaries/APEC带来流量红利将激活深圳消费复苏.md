# APEC带来流量红利将激活深圳消费复苏

![image](https://mmbiz.qpic.cn/mmbiz_jpg/QIJgF5A55WY6iaXsKTrSicicvTfP6BqIsfibrsGAOQFd3kib8IV0qZQNO4YTDC6icx62fasM2866KoOOPGn6WzApYG8v61QKzOuUu4UKUv36XibzjM/640?wx_fmt=jpeg&from=appmsg)

4月22日，深圳市统计局发布2026年一季度深圳经济运行情况。根据广东省地区生产总值统一核算结果，2026年一季度深圳市地区生产总值(GDP)达9594.13亿元，同比增长5.8%。在“十五五”规划的开局之年，深圳经济不仅实现了平稳起步，更在结构优化与动能转换上展现出显著成效。针对这一成绩单，综合开发研究院(中国·深圳)财税贸易与产业发展研究中心主任韦福雷在接受南方都市报采访时表示:“从起步开局来看，这是一个非常好的信号，为实现全年5%的增长目标奠定了坚实基础。”

**规模以上工业增加值同比增8.7%，新质生产力成核心增长极**

韦福雷指出，深圳一季度最明显的特征是工业生产的加速回升与外贸结构的持续优化。

一季度，深圳全市规模以上工业增加值同比增长8.7%，比上年全年加快3.3个百分点。主要行业大类中，计算机、通信和其他电子设备制造业增长13.9%。韦福雷强调，高技术产品产量保持快速增长，其中，工业机器人、3D打印设备、锂离子电池产品产量分别增长74.2%、71.8%、25.9%，“这些高技术产品表现出极强的增长势头，这正是深圳创新活力和新质生产力厚积薄发的集中体现”。

作为全国“外贸第一城”，深圳的外贸引擎在今年一季度表现出极强的爆发力。一季度，全市进出口总额13166.13亿元，同比增长33.6%。高新技术产品出口增长21.5%。韦福雷分析称，这代表着出口结构在不断优化，向高端化迈进。

**固投扭负为正，科研和技术服务业投资增长达173.8%**

此外，值得注意的是，全市固定资产投资同比增长0.2%，上年全年为下降21.7%；扭转了去年下降的趋势。其中基础设施投资增长31.2%，科学研究和技术服务业投资增长竟然达到173.8%的高增长。

对此，韦福雷表示，深圳的创新始终基于市场的需求和企业投入。科创投资接近两倍的增长，是非常明显地“跨越式”投入。

**深圳服务业同比增长5%，增速稳健结构亮点突出**

一季度深圳服务业同比增长5%，韦福雷表示，增速稳健但结构亮点突出，金融业，信息传输、软件和信息技术服务业，科学研究和技术服务业分别增长9.7%、7.3%、5.9%，呈现挺好的增长态势。

他进一步指出，深圳早在两年前就召开服务业高质量发展大会，当前“深圳先进制造业和高端服务业协同发展成效已经显现”，深圳已经从过去“工业立市、工业强市”逐步向高端服务业与制造业双轮驱动发展。

**消费复苏偏弱，APEC将成关键催化剂**

一季度社会消费品零售总额增长0.5%，餐饮收入增长6.1%，商品零售下降0.3%，消费复苏仍显乏力。韦福雷直言，“相对来说，消费的话就是复苏乏力，略显疲软一点”，并表示，这是普遍现象，背后是居民存款持续高增、预防性储蓄意愿较强，消费心态偏谨慎。

但他对APEC会议带来的拉动效应充满信心:“APEC直接推动了场馆、道路、地铁等一系列基础设施的建设改造，为投资由负转增提供了支持”，同时，会议带来的国际流量、会展与旅游红利已开始显现，“流量红利将对消费最直接拉动，有效激活深圳消费复苏”。（南都N视频 记者 黄璐）
