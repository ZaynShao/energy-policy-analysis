# 原副总经理韩玉明，非法收受巨额财物

中央纪委国家监委网站8月21日消息，据山西省纪委监委消息：日前，经山西省委批准，山西省纪委监委对潞安化工集团有限公司原副总经理韩玉明严重违纪违法问题进行了立案审查调查。
经查，韩玉明理想信念丧失，纪法底线失守，无视中央八项规定精神，收受礼品、礼金，违规发放、领取奖金；违背组织原则，在职务调整中为他人谋取利益并收受财物；廉洁底线失守，利用职权为亲属经营活动谋利；不正确履行职责，违规推进项目建设，造成资金浪费；利用职务便利，为他人在企业经营等方面谋利，并非法收受巨额财物。
韩玉明严重违反党的组织纪律、廉洁纪律和工作纪律，构成严重职务违法并涉嫌受贿犯罪，且在党的十八大后不收敛、不收手，性质严重，影响恶劣，应予严肃处理。依据《中国共产党纪律处分条例》《中华人民共和国监察法》《中华人民共和国公职人员政务处分法》等有关规定，经山西省纪委常委会会议研究并报山西省委批准，决定给予韩玉明开除党籍处分；由山西省监委给予其开除公职处分；收缴其违纪违法所得；将其涉嫌犯罪问题移送检察机关依法审查起诉，所涉财物一并移送。
