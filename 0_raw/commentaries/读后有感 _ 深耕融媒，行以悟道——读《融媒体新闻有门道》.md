# 读后有感 | 深耕融媒，行以悟道——读《融媒体新闻有门道》

中国新闻奖是经中央批准常设的全国优秀新闻作品最高奖。自1991年设立至今三十多年来，已有9200余件作品获奖，这些作品树立了新闻报道的“样板”和“标杆”，成为优秀作品与经典案例的宝贵资源库。《融媒体新闻有门道：中国新闻奖融合创新作品解析》一书综合评析第31届至第34届中国新闻奖媒体融合奖项获奖情况，系统概述了融媒体新闻的核心策略与实操指向。
新书出版后，获得读者广泛好评，认为该书总结过往、立足当下、放眼未来，清晰拆解了融媒体新闻创作与媒体融合发展的“门道”。
今天，我们刊发中国传媒大学电视学院2025级博士生高瑶撰写的评论文章《深耕融媒，行以悟道——读〈融媒体新闻有门道〉》一文，在阅读中深度理解融媒创作奥秘。

高瑶
深化主流媒体系统性变革，是党的二十届四中全会作出的重大战略部署。行业步入改革攻坚期，发展模式转向一体化生态融合。打破媒介壁垒、创新内容表达、拓展媒体功能、走好群众路线成为主流媒体必须破解的现实课题。
《融媒体新闻有门道：
中国新闻奖融合创新作品解析》
出版：人民日报出版社
《融媒体新闻有门道：中国新闻奖融合创新作品解析》立足时代背景，以第31届至第34届中国新闻奖融合创新作品为研究样本，总结实践规律，为融媒体新闻高质量发展提供了务实且深刻的解答。
纵览全局明方向
《融媒体新闻有门道》聚焦我国媒体深度融合发展阶段，以“融到深处，回归内容”为主线，梳理总结融媒实践成果、创作逻辑与行业变革，全方位解读融媒体新闻的发展规律与实践路径。
本书以中国新闻奖评选规则的演变切入，清晰勾勒媒体融合的发展脉络。第28届中国新闻奖首次设立媒体融合专项奖项，此后两届不断细分短视频、移动直播、融合创新等作品赛道。至第32届，评选体系迎来重大革新，打破报纸、广播、电视、新媒体之间的介质壁垒，奖项不再按媒介划分，转而依据体裁、题材设置，并新增融合报道、应用创新等专项奖项。此外，第31届融媒体相关作品总占比为22%，第32届至第34届这一占比持续上涨，最高突破30.8%。数据背后，是主流媒体主力军全面进军互联网主战场、媒介边界消融的行业现实。
本书提炼出五大创作取向，成为新时代主流融媒作品的价值标尺。优秀作品坚守政治高度，紧扣党中央决策部署，聚焦重大主题宣传；兼具时代向度，记录脱贫攻坚、科技发展等时代成就，关注社会治理与民生前沿；深挖思想深度，摒弃网络碎片化、浅表化表达，做到形短意长；葆有新闻锐度，以突发事件、典型人物等鲜活素材串联宏大叙事；锤炼专业精度，依托新闻“四力”开展深度采访与舆论监督，巧用技术与创意赋能内容表达。

依托海量案例，本书归纳出融媒体新闻四大发展趋势：VR、大数据等技术告别单纯炫技，转向优化用户体验、挖掘内容价值；借力中华优秀传统文化开展创意创作，提升作品艺术内涵；落实“新闻+政务服务商务”模式，拓展媒体社会服务与治理功能；坚持开门办报，吸纳受众参与内容生产，走好全媒体时代群众路线。同时，本书秉持思辨精神，正视行业挑战，深入主流媒体系统性变革、探讨生成式人工智能与新闻真实性的冲突等深层命题，行文既有扎实的实践总结，又具备高远的行业洞见。
深耕实践析门道
《融媒体新闻有门道》跳出理论空谈与碎片化案例盘点的局限，立足本土媒体融合实践，形成了独有的研究特色与意义，主要呈现四大突出亮点。
第一，样本权威、数据扎实，理论深度扎根一线实践沃土。本书选取中国新闻奖这一国内新闻行业最高奖项的融合创新作品作为研究对象，样本覆盖中央、省、市、县四级主流媒体，囊括短视频、H5、移动直播、融合专题等各类融媒形态，覆盖面与代表性强。大量运用奖项统计、传播数据来梳理行业发展轨迹，观点与创作规律均结合具体作品展开拆解，从选题策划、叙事表达、技术运用到传播效果逐层分析。以作品印证观点、用数据反映变化，真正实现了理论研究与行业实操的深度融合。
第二，贯通顶层政策与基层创作，宏观视野与微观解读相辅相成。媒体融合是国家层面的重大战略，其发展方向始终以中央政策、会议精神为根本遵循。本书系统梳理近年来媒体融合的政策演进脉络，深入解读提升新闻舆论“四力”、“新闻+政务服务商务”、走好全媒体群众路线等要求。同时，聚焦基层创作，详解如何将宏观政策导向转化为接地气、有温度的融媒内容，让作品做到“上接天线、下接地气”。双向对照的研究视角，打通了顶层设计与一线执行的壁垒，为媒体管理者和采编人员理解政策、开展工作搭建了有效桥梁。
第三，提炼专业创作范式，为融媒体新闻树立清晰行业标尺。针对当下融媒形态多元、创作标准模糊，部分作品重形式、轻内涵的行业问题，本书总结五大创作取向，搭建起完整的融媒体新闻评价体系。书中强调主流媒体要坚守政治站位和思想引领，在碎片化传播环境中保持内容深度，同时立足“四力”筑牢专业根基，做好深度采访与舆论监督。结合不同产品形态总结的创作技巧，形成了可复制、可推广的创作范式。
第四，前瞻研判发展趋势，理性思辨行业痛点与未来方向。本书在总结成果之余，放眼未来研判行业走向。一方面，肯定技术赋能、文化赋能、服务赋能、用户赋能带来的行业新变化，认可沉浸式传播、中华优秀传统文化的创造性转化与创新性发展、媒体参与社会治理、用户共创等新型融合模式的价值。另一方面，保持思辨态度，不盲目追捧新技术，面对人工智能、虚拟数字人等新技术热潮，书中明确要求坚守新闻真实性底线，保持审慎态度，厘清技术工具与新闻本体的边界。媒体融合已进入攻坚期，仅靠技术叠加难以为继，必须推动体制机制、组织架构、生产流程的系统性变革，实现从“物理相加”到“化学相融”的质变，这些清醒客观的判断，使本书超越了方法论的意义，更具备引领行业长远发展的价值。
守正创新行致远
媒体融合行至十余载，从探索起步到深度变革，主流媒体在转型路上不断突破、不断成长。全书始终恪守“融到深处，回归内容”的核心逻辑，反复印证一个真理：无论媒介形态如何迭代、传播技术如何革新，优质内容永远是融媒体新闻的立身之本，技术、创意、形态、服务都是为内容赋能的手段，而非最终目的。
当前，我国正全力推进全媒体传播体系建设，塑造主流舆论新格局，主流媒体系统性变革的大幕已然拉开，媒体融合依然任重道远。机遇与挑战并存的当下，既需要勇于创新的探索精神，也需要沉淀经验的理性思考。《融媒体新闻有门道》总结过往、立足当下、放眼未来，清晰拆解了融媒体新闻创作与媒体融合发展的“门道”，能够助力各级主流媒体找准方向、补齐短板、深耕内容、创新表达，持续推动传统媒体与新兴媒体真正融为一体、合二为一，让主流声音在全媒体时代传播得更远、更深入、更有影响力。
《融媒体新闻有门道：中国新闻奖融合创新作品解析》
内容简介
本书概述了融媒体新闻的核心策略与实操指向，综合评析第31届至第34届中国新闻奖媒体融合奖项获奖情况，并从中精选获奖作品，从报道升维、主题引导、全球叙事、融媒创新、技术赋能等五个部分，邀请创作团队分享创作体会和创新经验，展示主流媒体在内容创新、技术先导、体制机制改革等方面取得的成果，呈现融合新闻作品的时代性、代表性、先进性、探索性。本书旨在记录这一波澜壮阔新闻生态的演变历程，希望为新闻从业者、研究者及传媒学子提供借鉴，为加快推进主流媒体系统性变革贡献一分力量。
