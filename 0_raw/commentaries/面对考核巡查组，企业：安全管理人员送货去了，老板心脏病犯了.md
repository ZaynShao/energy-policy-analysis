# 面对考核巡查组，企业：安全管理人员送货去了，老板心脏病犯了

中央安全生产考核巡查组第十一组在天津明查暗访，开展现场核查并督促隐患闭环整改。
中央安全生产考核巡查组第十一组（以下简称考核巡查组）在天津明查暗访时，高度重视群众反映和职工报告的问题隐患线索，及时开展现场核查并督促隐患闭环整改。
考核巡查组发现，在诸多线索中，有4条线索同时指向天津四环汽车内饰件有限公司。线索显示，该企业存在消防控制室无人值守、租赁车间无消防设施、在办公楼3楼违规搭建员工宿舍、违规储存危险化学品等问题。近日，考核巡查组前往该企业进行现场核查。
“你们的安全管理人员呢？”
“去送货了，不在这儿。”
“那让你们企业负责人过来吧。”
“我们老板心脏病犯了。”
考核巡查组进行现场核查时，该企业安全管理人员和负责人始终未到现场。考核巡查组只得向企业行政主管人员核查有关情况。
考核巡查组首先来到该企业消防控制室，发现消防控制室内无专人值守。
“你们消防控制室的值班人员呢？”
面对询问，企业行政主管人员未能给出明确答复。
随后，考核巡查组前往该企业办公楼3楼核查违规搭建线索，发现企业在原有建筑基础上私自搭建员工宿舍，并分隔出9个房间供员工居住。
经核查，宿舍无固定消防设施，大多数灭火器已失效，一旦宿舍发生火灾，极易造成群死群伤。
考核巡查组从企业行政主管人员的介绍中得知，企业将部分厂房及办公区域租给第三方生产、仓储企业。考核巡查组要求现场核查租赁合同及双方消防安全管理职责划分的相关资料，但是直至考核巡查组离开时，企业行政主管人员也未能提供。
针对该企业违规储存危险化学品的线索，考核巡查组逐一排查该企业生产区域内的办公楼、车间、仓库以及院内空地，发现其储存了聚醚多元醇、组合聚醚、发泡组合料等化学品。
考核巡查组专家现场调阅上述化学品安全技术说明书等信息，结合危险成分总含量、闪点等参数进行分析研判，最终认定上述化学品不属于危险化学品，但仍须加强化学品仓储和使用安全管理。考核巡查组在检查时发现，该企业仓库内化学品堆放无序，且仓库防水、防火条件亟须改善。
针对检查中发现的问题，考核巡查组严肃指出该企业的安全管理漏洞，并责令当地监管部门立即督促指导企业彻底整改。
考核巡查组在离津前再次前往该企业复查。复查发现，企业违规搭建的员工宿舍已被拆除，员工已搬至周边合规住所；消防控制室内有两名持证人员在岗值守。同时，企业向考核巡查组提供了厂房租赁合同及相关安全管理协议，明确了消防安全相关方责任。针对化学品储存安全风险，企业行政主管人员表示将尽快落实整改要求。
