# 明知有毒仍产销！五大化工巨头遭起诉

美国纽约州总检察长Letitia James办公室官网发布的新闻，宣布起诉3M、杜邦等化工企业。
据美国纽约州总检察长办公室发布的消息称，7月9日，总检察长Letitia James于当日在奥尔巴尼州法院提起诉讼，将3M、杜邦（DuPont）、科慕（Chemours）、科迪华（Corteva）及EIDP公司告上法庭，指控其通过销售含有全氟和多氟烷基物质（PFAS）的消费品，造成纽约州数十年的环境污染与健康危害。
PFAS被称为“永久性化学物质”，在自然界中极难分解。因其具有防水、防油、耐高温等特性，自20世纪40年代开发以来，被广泛应用于化妆品、不粘锅、防水服装、食品包装等数百种消费品中。
声明指出，某些PFAS与癌症风险增加、出生缺陷、妊娠并发症、高胆固醇及激素问题等健康风险相关。
Letitia James指控这些公司早在上世纪便已知晓PFAS的毒性及其在人体和环境中长期累积的特性，却长期向公众隐瞒。此外，揭露1970年代3M研究人员已在员工和公众血样中检测到PFAS；1981年杜邦秘密监测50名接触PFAS产品的女员工，7名怀孕员工中有2人所生婴儿出现眼部和鼻孔缺陷，杜邦却放弃研究并继续生产销售。1983年3M科学家已得出结论认为PFAS可能通过废水污染水源，但此后数十年间未采取任何实质性措施应对。
Letitia James在声明中表示：“像3M和杜邦这样的大公司明知故犯地销售有毒产品，威胁纽约市民的健康，污染我们的环境长达数十年。是时候让他们为自己造成的损失付出代价了。长期以来，我们的社区一直不公平地承担着保护人们免受这些有毒永久性化学物质侵害以及清理其污染的费用。”
诉讼要求法院判令被告承担环境清理费用、向消费者充分警示产品风险，并支付损害赔偿金和民事罚款。Letitia James指控这些公司违反了纽约州消费者保护法，通过欺诈性宣传将含有有毒化学物质的产品标榜为安全，并在此过程中非法牟利。
值得注意的是，美国多州已与涉事企业达成天价和解：2025年5月，3M公司同意向新泽西州支付4.5亿美元，源于其工厂造成的PFAS污染索赔；2025年8月，杜邦、科慕和科迪华三家公司向新泽西州支付20亿美元，以解决全州范围内的PFAS污染及相关环境索赔；2026年6月，科慕公司与美国环保署达成4.5亿美元和解，针对其向多地水道非法排放PFAS的指控。
