# IIGF专刊 | 国际绿金专刊：IFC发行20亿美元绿债；新加坡发布基于ISSB标准的可持续披露准则草案；欧洲议会环境委员会支持扩大CBAM范围

本期国际绿色金融专刊将为您介绍2026年7月全球绿色金融领域的最新发展和动态。IFC发行20亿美元绿色债券以支持发展中国家可持续投资，绿色气候基金向湄公河区域注入5000万美元生态转型资金。在亚洲，新加坡发布基于ISSB标准的可持续披露准则草案，韩国扩大ESG强制披露范围，东南亚自然碳汇项目达成大额前向采购协议；在欧洲，欧盟拟调整碳市场规则，欧洲议会环境委员会支持扩大CBAM范围，欧盟通过修订版ESRS标准简化企业可持续信息披露要求；在非洲，南非《绿色金融分类法》深化应用；在美洲，加拿大可持续金融分类法引入“减排”类别引发能源转型争议，巴西全球最大牛肉和禽肉生产企业之一JBS取消2040年价值链净零目标。
