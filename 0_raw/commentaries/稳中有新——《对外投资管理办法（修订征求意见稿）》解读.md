# 稳中有新——《对外投资管理办法（修订征求意见稿）》解读

如您希望下载PDF版本，请点击文末“阅读原文”获取。
背景
国家发展改革委2026年8月21日在其门户网站上公布《对外投资管理办法（修订征求意见稿）》，公开征求公众意见，截止日期为2026年9月20日。
作为2026年7月1日施行的行政法规《国务院关于对外投资的规定》（国务院令第837号，“国务院《规定》”）的配套规章，《办法（修订征求意见稿）》整体延续了《企业境外投资管理办法》（国家发展和改革委员会令第11号，“11号令”）的框架结构，同时将国务院《规定》的有关原则性规定予以落地细化，增强法规规章的衔接。
此外，11号令自2018年3月施行至今已逾八载。伴随中企出海投资的蓬勃发展，国家发展改革委在实践中沉淀了丰富的实操经验，本次修订亦将上述经验凝练升华，旨在为未来的对外投资提供更为明晰的实践指引。
《办法（修订征求意见稿）》的稳和新
1. 适用范围与国务院《规定》一致，居民个人对外投资有了新的合规途径
长期以来，在国务院《规定》实施前，境内居民个人对外投资的主要规定是《国家外汇管理局关于境内居民通过特殊目的公司境外投融资及返程投资外汇管理有关问题的通知》（汇发[2014]37号，“37号文”）。37号文的适用场景较为有限，主要涉及境内居民通过境外特殊目的公司境外投融资及返程投资的外汇登记。37号文特别指出，境外特殊目的公司登记不具有证明其投融资行为已符合行业主管部门合法合规的效力。[1]
国务院《规定》第二条明确投资者包括境内的企业、其他组织和居民个人，首次将居民个人纳入。据此，《办法（修订征求意见稿）》第二条重申投资者包括境内的企业、其他组织和居民个人。这确认了居民个人的对外投资主体地位，意味着境内居民个人对外投资将有法可依，有利于境内居民个人依法依规开展对外投资活动。
在具体监管措施上，本次《办法（修订征求意见稿）》对企业、其他组织和居民个人一视同仁，这不仅有助于简化法律适用，也将促进对外投资多元化发展。
《办法（修订征求意见稿）》没有规定溯及既往，预计投资者的存量对外投资无需补办核准、备案。
2. 核准备案范围和程序保持基本不变，延续了分类分级的监管模式
《办法（修订征求意见稿）》继续执行11号令项下的核准、备案及报告分类监管模式[2]，核准备案制度保持不变。
本次《办法（修订征求意见稿）》保留了敏感类对外投资项目核准、非敏感类直接对外投资项目备案的现有监管模式，并同时明确了境内其他组织和居民个人的备案层级：其他组织的备案机关参照企业执行（即中央管理的其他组织，备案机构是国家发展改革委；地方管理的其他组织，且中方投资额3亿美元及以上的，备案机构是国家发展改革委，中方投资额3亿美元以下的，备案机构是注册地的省级发改部门），境内居民个人的备案机关为投资者户籍所在地或者经常居住地的省级发改部门。上述机制的延续有利于投资者更好适应。
同时，《办法（修订征求意见稿）》与国务院《规定》衔接，完善了境外再投资报告制度，将境外再投资报告范围，从11号令的大额非敏感类对外投资，调整为投资者通过其控制的境外企业、其他组织开展的非敏感类对外投资。[3]需要注意的是，境外再投资涉及的核准和报告的监管边界限于投资者“控制”的境外企业和其他组织进行的再投资。对于境内投资者非控制的境外企业和其他组织所开展的境外再投资活动，则不触发上述再投资报告义务。
境外再投资报告、前期工作情况报告、对外投资完成或终止情况报告、对外投资信息年度报告、重大不利情况报告等对外投资信息报告均是告知性的，不是行政审批。投资者按规定报送有关信息即可，无需等候发改部门的批准。
3. 在境外证券市场等金融市场投资依旧适用其他规定，政策保持稳定性和清晰度
近年的实践表明，11号令主要面向对外直接投资，如果投资者通过证券市场收购上市公司股票获得被投资企业的控制权，或者持股比例达到10%以上，这就构成了对外直接投资，因而属于11号令的管辖范围。从《办法（修订征求意见稿）》第七十三条可以看出，本次修订延续了上述管辖范围。
目前，境内企业、居民个人等投资者可以通过合格境内投资者、港股通、跨境理财通等方式开展对外证券投资。根据《办法（修订征求意见稿）》第七十三条，除少数构成对外直接投资的情形之外（如获得被投资企业控制权、股比达到10%的整数倍），境内企业、居民个人等投资者通过合格境内投资者、港股通、跨境理财通等方式开展对外证券投资，依旧适用有关部门规定，不需要进行发改部门的核准、备案、报告。
4. 风险防控和对外投资保护有了新举措
在完善对外投资完成或者终止情况报告、重大不利情况报告的基础上，《办法（修订征求意见稿）》创设了前期工作情况报告（适用于中方投资额1亿美元及以上以及关乎我国与有关国家外交关系的对外投资）[4]、对外投资信息年度报告制度，覆盖对外投资的前、中、后期，有利于主管部门与投资者合力防范对外投资风险、维护海外资产安全。
预计国家发展改革委后续将制定发布格式文本及附件清单，以供实操遵循。
5. 法律责任条款对标国务院《规定》
国务院《规定》明确了投资国家禁止的对外投资、未按规定履行境外投资核准备案手续、以不正当手段获得境外投资核准备案等违法违规行为的处罚措施[5]。
本次《办法（修订征求意见稿）》充分贯彻落实国务院《规定》内容，援引了相关法律责任，没有新增处罚措施。
结语
本次《办法（修订征求意见稿）》稳中有新，既保留了11号令的核准、备案、报告的监管模式，同时作为国务院《规定》的配套文件，将国务院《规定》的有关内容落到实处。总体来说，《办法（修订征求意见稿）》符合业界预期，保持了政策的稳定性和延续性，有利于对外投资高质量发展。
建议关注国家发展改革委后续发布的格式文本、办事指南和常见问题解答等。
