# 广州石化加热炉烘炉插上智能化“翅膀”

7月13日，广州石化新建100万吨/年重整联合装置顺利完成首批5台加热炉烘炉工作，这是该公司首次深度应用智能控制系统进行烘炉，实现升温、恒温过程自动化控制，为石油化工装置加热炉烘炉作业提供了可借鉴的经验。
广州石化锚定“智能化”方向，加快推进智能化技术在新装置建设及生产操作环节的深度应用，将RTO（在线优化）和AIPC（高级智能过程控制）两大核心技术嵌入安全绿色高质量发展技术改造项目新建重整联合装置。该装置自去年12月机械竣工以来，项目团队以系统调试促工程收尾及开工，截至目前已完成AIPC控制器28组串级回路功能测试及配套DCS（集散控制）组态测试，8类辅助开停车功能模块已全部就位。
加热炉烘炉作业是新装置投产前的关键一环，本次烘炉引入燃料气点火后，DCS负责数据采集与指令下发，AIPC负责模型运算与策略输出，形成闭环联动。在升温阶段，通过智能提降温模块自动调节燃料气流量，实时比对炉膛温度数据，将升温速率偏差控制在最优范围；进入恒温段后，系统自动执行各恒温段操作，实时监测温度分布并调节阀门开度，确保炉膛温度场均匀稳定。
“与传统烘炉作业相比，智能控制系统的深度应用改变了以往依赖人工经验的操作模式，解决了控温精度难以保证的难题，大幅降低了操作人员的劳动强度。”该公司信息中心副经理黄海彬说。下一步，他们将朝着“泛在感知、实时分析、模型驱动、人机协同、敏捷响应、全局协同、动态优化”的方向，推动新建重整联合装置开工提速提效，为以二次创业推进高质量发展注入数智动能。
