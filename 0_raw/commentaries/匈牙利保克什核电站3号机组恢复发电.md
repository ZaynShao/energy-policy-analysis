# 匈牙利保克什核电站3号机组恢复发电

匈牙利唯一的核电站——保克什核电站3号机组恢复发电。
匈牙利总理毛焦尔·彼得22日宣布，得益于紧急工程施工作业及多瑙河水位回升，该国唯一的核电站——保克什核电站3号机组已于当天恢复发电。
毛焦尔当天在核电站现场表示，3号机组的6号汽轮机已重新联网恢复发电。本月早些时候，干旱引发的多瑙河极低水位严重限制冷却水吸入，导致部分机组被迫停运。
为保障冷却水供应，匈牙利政府日前实施紧急应对措施，开始建造水下潜坝，并在河道中有控制地沉入两艘80米长的驳船。毛焦尔表示，这些措施已使核电站附近多瑙河水位抬升约15厘米。
此前，持续酷暑和旱情导致多瑙河水位降至历史低位，直接威胁保克什核电站的安全运行。8月初，水位下降迫使该核电厂大幅削减产能，危机最严重时仅有一台汽轮机维持运转。随着多瑙河水位状况改善，第二台汽轮机已于8月10日恢复并网。
“若一切顺利，核电站将于下周三（26日）恢复至2000兆瓦的全额产能，全部8台汽轮机将再次投入运行。”毛焦尔说。
保克什核电站位于匈牙利首都布达佩斯以南约100公里处，拥有4座VVER-440型反应堆机组，共配备8台汽轮机组，是该国重要的电力来源。
