# 菲尔兹奖｜属于高层次人才哪个级别？

与之同等级别的荣誉还包括诺贝尔奖、图灵奖、沃尔夫数学奖、阿贝尔奖、拉斯克奖、克拉福德奖等。
当然，在国内层面，中国国家最高科学技术奖、中国科学院院士、中国工程院院士、中国社会科学院学部委员等同样代表着顶尖学术地位。
1. 无锡市：A3类，购房补贴150万元
根据“太湖人才计划”人才分类认定标准，无锡市将高层次人才划分为A、B、C、D四大类，其中A类又细分为A1、A2、A3三个层级。
菲尔兹奖、图灵奖获得者被划入A3类。A1类为诺贝尔奖获得者（不含和平奖）和中国国家最高科学技术奖获得者，享受500万元购房补贴；A2类为中国科学院院士、工程院院士及美、日、德、法、英等20余个国家最高学术权威机构会员，享受200万元购房补贴。
A3类包括菲尔兹奖、图灵奖等国际奖项获得者，享受150万元购房补贴。
值得关注的是，在无锡的分类中，新加坡、韩国、乌克兰等国家院士被列入A2类，而菲尔兹奖、图灵奖得主却被归入A3类。
换言之，在无锡的人才政策体系中，菲尔兹奖得主的认定级别甚至低于部分国家的院士，也低于省级顶尖人才。
无锡的分类标准引发网友广泛质疑。
2. 杭州市：A类顶尖人才，“一事一议”
杭州市将高层次人才分为A、B、C、D、E五个层级。根据《杭州市高层次人才分类目录》，菲尔兹奖、图灵奖、普利兹克奖获得者被直接纳入A类（国内外顶尖人才），与诺贝尔奖获得者、国家最高科学技术奖获得者、两院院士并列。
在待遇方面，杭州A类人才购房补贴实行“一事一议”。部分区域对A—D类人才的购房补贴最高可达800万元。
3. 郑州市：A类顶尖人才，排位靠前
郑州市将高层次人才分为顶尖人才（A类）、国家级领军人才（B类）、地方级领军人才（C类）、地方突出贡献人才（D类）。
根据郑州市高层次人才分类认定标准，菲尔兹奖、图灵奖、普利兹克奖获得者被列入A类顶尖人才。在A类人才的具体排序中，菲尔兹奖仅次于诺贝尔奖，排在第一款的第二位。
4.深圳市海外高层次人才A类
深圳市海外高层次人才A类中包括诺贝尔奖、菲尔兹奖、两院院士，菲尔兹奖得主排在院士之前。
值得关注的是，本次获奖者邓煜来自深圳，进一步提升了主管部门对该奖项的认同度。
三、结束语
各地对菲尔兹奖得主的认定级别和待遇差异显著，折射出当前地方人才政策在国际顶级荣誉认定标准上的分歧。
对地方政策制定者而言，应以国际视野客观认识菲尔兹奖的学术地位，给予其相匹配的层级定位和待遇保障，方能在全球人才竞争中占据主动。
同时，庆贺中国学者获奖之余，更需清醒认识到：王虹、邓煜的研究生教育及获奖主要工作均在海外完成，中国在高层次人才培养方面仍有明显提升空间。
可以预见，以此次突破为契机，国内将在基础研究人才培养体制和科技项目管理机制上推进系统性改革。
科技项目，尤其是基础研究类项目的申报导向、评价标准和支持方式，必将迎来深刻调整。
