# 2027年|电子信息领域设备更新项目储备启动

近日，2027年超长期特别国债支持电子信息重点领域设备更新项目储备工作已在全国逐步铺开。
根据《工业和信息化部规划司关于开展电子信息领域设备更新项目储备工作的通知》（工规函〔2026〕815号）要求，各省市、自治区正积极布置申报2027年超长期特别国债资金支持电子信息领域设备更新储备工作。
一、积极储备2027年
参考2026年安排，2027年电子信息领域设备更新预计仍仅有一批次机会，建议企业积极布局储备；利用容缺入库机制，先完成项目备案和储备申报表，尽早录入国家重大项目储备库。
最终的范围和要求或许有新的变化，通知要求储备的依据是：
《关于做好2026年超长期特别国债支持电子信息重点领域设备更新谋划准备工作的通知》
1.支持范围，部分领域可能新增对高端化、智能化、绿色化设备的重点支持
2.投资门槛和基本要求
2026年电子信息领域单个项目固定资产投资已降至不低于100万元，预计2027年将继续保持这一低门槛政策，持续加大对中小企业设备更新的支持力度。
2027年可能是中小企业享受超低门槛政策的最后窗口期，部分领域要求200万到500万不等，具体参考官方文件。
补贴规则，预计继续按照不超过核定固定资产投资（含工业软件、基础软件）的15% 给予补贴。
项目基本要求变化不大，比如在建项目投资进度不超过80%，新建项目须在2027年能够开工，建设周期原则上不超过2年等。
二、储备机制重大变化
2027年超长期特别国债设备更新项目储备打破以往“手续齐全方可入库”的硬性要求，实行容缺入库、先占坑、后补手续的灵活机制。
所有设备更新类补助项目，必须先录入国家重大项目储备库，生成项目入库回执，才能进入后续申报流程。
非储不报，容缺范围：环评批复、节能审查意见、用地规划许可、安全评价、水土保持批复等；入库同步提交《手续办理进度说明》，标注每项手续办理节点、预计办结时间。
三、结束语
各地储备要求时间不一，比如G省要求8月7日各地报送完成，Y省8月11日提交所有材料。
核心都在于非储不报，工信厅按照部里要求印发预通知，时间紧、任务重，多省（市）已经向地市区发布储备要求，通知辖区内企业摸排项目，加快完成项目必备手续。
同时，“本次超长期特别国债资金仅支持纳入设备更新指导目录内的设备更新需求，对目录之外的设备更新需求不予支持。”
另外，每年公开的设备更新通知，今年要求“请严格控制本通知知悉范围，严禁通过互联网、手机、微信等传播使用或对外公布”，各地申报企业必须结合历史通知文件和当地主管部门传达的精神才能做好2027年规划。
最后，必须祝福大家继续争创2027年超长期特别国债红利申报小能手！
