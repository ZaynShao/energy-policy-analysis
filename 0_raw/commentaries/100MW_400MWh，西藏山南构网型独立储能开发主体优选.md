# 100MW/400MWh，西藏山南构网型独立储能开发主体优选

项目名称：山南市100MW/400MWh构网型电网侧独立储能项目。
建设地点：山南市行政辖区域内（开发主体自主选址，最终以批复文件为准）。
项目规模：额定功率100MW，额定容量400MWh，储能时长4小时，标准电网侧独立储能配置。
项目类型：构网型电网侧独立储能电站。
建设内容：新建一座100MW/400MWh电化学储能电站，配套建设升压站、送出线路及相关附属设施。（最终以电网接入批复方案为准）。
项目投资：根据项目所在地实际情况，具体以接入电压等级、储能单元配置为准。
建设周期：2026年建成投产。
比选人资格方面，公告要求同一实际控制人、控股集团仅允许1家全资或控股企业参与本次的比选申报，关联企业不得同时申报。自有资金占项目总投资比例不低于国家规定的20%，项目其余建设资金须提供商业银行出具的正式专项授信批复文件，授信额度足额覆盖剩余投资、定向用于本项目建设。
接受联合体申报，需提交完整联合体协议，明确牵头单位及各方权责。联合体成员总数不得超过2家。
获取时间：2026年6月25日至2026年6月30日，工作日上午9:30-12:30，下午3:30-6:00（北京时间）。
获取地点：山南市能源局1217办公室（山南市乃东区湖北大道徽韵科技文化中心12楼）。现场领取材料。
递交截止时间：2026年7月9日上午10:00（北京时间）。
评审时间：2026年7月9日
原文如下：
深入贯彻落实《西藏自治区能源局关于落实“十五五”电力保供方案推动若干项目实施的通知》文件精神及《西藏自治区“十五五”电力保供方案》有关工作部署，加快推进新型储能项目建设，提升电网安全稳定运行水平，现就山南市100MW/400MWh构网型电网侧独立储能项目开发主体进行公开比选，欢迎符合资格条件的潜在开发主体参与。
1.项目概况
1.1 项目名称：山南市100MW/400MWh构网型电网侧独立储能项目。
1.2 建设地点：山南市行政辖区域内（开发主体自主选址，最终以批复文件为准）
1.3 项目规模：额定功率100MW，额定容量400MWh，储能时长4小时，标准电网侧独立储能配置。
1.4 项目类型：构网型电网侧独立储能电站
1.5 建设内容：新建一座100MW/400MWh电化学储能电站，配套建设升压站、送出线路及相关附属设施。（最终以电网接入批复方案为准）
1.6项目投资：根据项目所在地实际情况，具体以接入电压等级、储能单元配置为准。
1.7建设周期：2026年建成投产。
2.比选范围
比选项目开发主体。中选人负责项目的投资、建设以及后续运营管理。
3.比选申请人资格要求
3.1 在中华人民共和国境内依法登记注册的企业法人，具备独立承担民事责任的能力，经营范围包含储能、电力或能源相关业务。
3.2 同一实际控制人、控股集团仅允许1家全资或控股企业参与本次的比选申报，关联企业不得同时申报。
3.3 认缴注册资本≥1亿元人民币，实缴资本≥5000万元人民币。
3.4 近2年经第三方审计的财务报告，净资产负债率≤70%。
3.5 自有资金占项目总投资比例不低于国家规定的20%，项目其余建设资金须提供商业银行出具的正式专项授信批复文件，授信额度足额覆盖剩余投资、定向用于本项目建设。
3.6 信用状况良好，无失信被执行人、重大税收违法、近三年内无重大安全生产事故、工程质量事故、电力市场违规违约记录，无储能项目烂尾、逾期并网、恶意弃标等行业不良履约记录。
3.7 近5年内（公告发布之日起倒推）在国内至少具有1个已并网投运的电网独立储能项目的开发业绩（联合体可合并计算）。
3.8 接受联合体申报，需提交完整联合体协议，明确牵头单位及各方权责。联合体成员总数不得超过2家。
