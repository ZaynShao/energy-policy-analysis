# 磷矿石 | 3月磷矿石进口同比+146% 4月预期趋缓

2026年3月，国内磷肥市场保供平稳，下游磷肥企业开工率持续高位，磷酸铁与磷酸铁锂产能利用率稳定在80%，需求端支撑坚实。受湖北主要矿山休采影响，国内磷矿石供应趋紧，企业积极扩充进口渠道，当月进口量达18.2万吨，有效缓解原料压力，保障磷化工产业链稳定运行。

3月中国磷矿石进口量达18.2万吨，环比大幅增长88.18%，同比飙升146%，其中未碾磨磷矿石进口18.02万吨，已碾磨磷矿石进口1931吨，1—3月累计进口总量52.28万吨，同比增长102.8%。按照进口单价来看，进口均价为80美元/吨，较1—2月平均单价下降4美元/吨，显示成本压力有所缓解，进口规模与价格走势量增价稳，为磷化工产业链提供坚实原料保障。

2026年3月未碾磨磷矿石进口总量180193吨，总金额14365794美元，均价80美元/吨。埃及是最大来源国，贡献超93%的进口量，均价80美元/吨；巴基斯坦进口量次之，均价略高于埃及；澳大利亚、刚果共和国进口量极少，均价远高于平均水平。已碾磨磷矿石‌进口总量1930.6吨，总金额186503美元，均价97美元/吨。埃及是主要来源国，进口量占总量的99.7%；加蓬进口量极少，均价6172美元/吨；以色列进口量可忽略。

2026年3月磷矿石进口贸易的区域分布中广西是核心贸易区域，进口量占比38.07%，远超其他地区；福建省、湖北省紧随其后，占比分别为28.86%、23.04%，其中福建货源主要流入湖北地区，三者合计占比超90%。海南省、贵州省、山东省进口量占比在2%-3.5%之间，广东省、江苏省、安徽省占比均为1%，上海市、云南省无进口量。整体来看，磷矿石进口贸易集中在少数沿海及磷化工产业基础较好的省份，区域集中度高。

4月南方主产区湖北复产，供应端释放增量，缓解了此前区域性紧张态势。但下游磷肥及湿法净化磷酸受硫磺、硫酸价格高位影响，生产成本承压，企业开工意愿受限。多数企业优先保障春耕保供，计划履约后启动阶段性检修，4-5月磷矿石下游开工率或阶段性下滑，对磷矿石需求支撑减弱，预计4月磷矿石进口量将低于3月。
