# 香港联交所就《上市规则》第十五A章优化结构性产品上市制度建议刊发咨询总结，金杜协助业界参与

香港联合交易所有限公司（“**联交所**”）于2026年4月20日发布了检讨第十五A章——结构性产品的咨询总结（“**咨询总结**”）。

咨询总结是继联交所于2025年9月30日发布的咨询文件（“**咨询文件**”）后作出的总结。咨询文件就规管结构性产品在联交所上市事宜的香港联合交易所有限公司证券上市规则（“**上市规则**”）第十五A章（“**第十五A章**”）提出全面修订的建议。

咨询总结[1]及新常问问题[2]已于联交所网站发布。此次修订是近二十年来针对第十五A章最重大的一次更新，旨在推动产品创新和提升市场效率，同时维持稳健的市场质素和投资者保障标准。我们预期更新后的上市制度有助于提升市场上的产品多样性。

**01**

**第十五A章主要修订概览**

旨在支持发行灵活性和产品多样性的改革，包括：

 - 

**衍生权证的最低发行价**由0.25港元下调至0.15港元；

 - 

**取消牛熊证的最低发行价**的规定；

 - 

**衍生权证及牛熊证发行时的最低市值**由1,000万港元下调至600万港元；及

 - 

**扩大衍生权证及牛熊证代表一股股份的换股比率的范围**，为发行人在产品结构设计上提供更大灵活性。

旨在强化发行人及担保人资格规定的改革，包括：

 - 

**最低资产净值规定将**由20亿港元上调至50亿港元；

 - 

**合资格发行人及／或担保人须受联交所认可的监管机构监管**；及

 - 

**信贷评级规定**将要求发行人及／或担保人集团从其所寻求信贷评级的所有信贷评级机构取得投资级别的信贷评级。

**02**

**联交所采纳的业界提交意见中的建议**

联交所采纳了业界在咨询回应中提出的多项建议和澄清，进一步的澄清和优化措施，以精简运作要求、并提升市场效率，包括：

发行计划可依赖超过一年期限的担保，前提是有关担保已妥善执行，且根据相关管辖法律下具有强制执行力。

澄清适用于发行人及担保人有关监管状况的资格规定，并将相关指引于联交所网站上公布。

有关信贷评级下调公告及合资格发行人和担保人监管状况变更的持续披露责任。

澄清适用于发行人及担保人的财务资料披露规定。

**03**

**实施时间表及过渡安排**

联交所将分两个阶段实施修订安排：

主要产品规定的相关修订将于**2026年5月1日**生效；及

余下的修订将于**2026年7月1日**生效，并设有适用于现有发行人的过渡安排。

现有发行人及担保人将享有**12个月的过渡期**（自2026年7月1日至2027年6月30日），以符合新的发行人资格规定、相关披露要求及持续责任。

任何于**2026年7月1日或之后**申请成为合资格发行人的新申请人，均须全面遵守新的资格规定。

**展望**

此次修订在投资者保护与优化上市结构性产品市场的运营实务之间取得了适当的平衡。结构性产品市场在香港资本市场中发挥着至关重要的作用，我们相信此次修订将进一步巩固香港作为全球领先的结构性产品发行和交易中心的地位。

金杜律师事务所香港办公室银行与金融部合伙人马绍基（Richard Mazzochi）及萧乃莹（Minny Siu）与市场参与者紧密合作，支持联交所推进相关制度现代化的工作。金杜团队从法律和监管角度向联交所提交了咨询回应，并协助亚洲证券业与金融市场协会（“ASIFMA”）代表其上市结构性产品工作小组编制及提交业界的综合回应。

我们的团队在过去二十多年来一直与结构性产品市场参与者紧密合作，参与新产品开发及监管改革。金杜拥有领先的结构性产品业务和丰富的实践经验，为全球和区域金融机构提供香港监管动态、产品结构、文件编制和持续合规方面的法律意见，能够协助市场参与者顺利过渡至更新后的第十五A章制度。我们期待继续协助市场参与者实施相关修订，并就此次修订对结构性产品在香港的发行和合规方面的广泛影响提供法律意见。
