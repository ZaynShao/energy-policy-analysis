# 油价、金价、银价，都涨了

8月7日国际油价、金价、银价上涨。
7日，中东地缘风险升温，市场担忧原油供应受影响，国际油价上涨。此外，美国非农数据不及预期削弱美联储加息预期，叠加美元走弱等因素，国际金价和银价均上涨。
7日国际油价上涨
受也门胡塞武装袭击沙特、伊朗审议霍尔木兹海峡通航限制草案等事件影响，中东地缘风险升温，市场担忧原油供应受影响，7日国际油价上涨。
截至当天收盘——
纽约商品交易所9月交货的轻质原油期货价格收于每桶78.18美元，涨幅为1.15%；
10月交货的伦敦布伦特原油期货价格收于每桶83.55美元，涨幅为1.29%。
7日国际金价和银价齐涨
7日，美国非农数据不及预期削弱美联储加息预期，叠加美元走弱等因素，国际金价和银价均上涨。
截至收盘——
纽约商品交易所12月交割的黄金期货价格报每盎司4399.70美元，上涨2.32%；
9月交割的白银期货价格报每盎司63.499美元，上涨3.07%。
