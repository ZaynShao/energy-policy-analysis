# 杭甬“双城记”｜发展中国家女性教育能力建设研修班在杭州宁波开展现场教学

为深入落实全球妇女峰会精神，推动“一带一路”框架下的妇女发展合作，6月26日至7月4日，发展中国家女性教育能力研修班走进杭州、宁波两地。来自10个国家和1个国际组织的29名学员通过为期9天的沉浸式考察，深刻感受杭甬“双城记”的发展脉搏。
本次研修是贯彻落实习近平总书记在全球妇女峰会上的主旨讲话精神、全面推进“一带一路”建设、一体落实四大全球倡议、服务构建新发展格局、为全球妇女事业发展贡献中国智慧与中国力量的具体行动，也是全球妇女能力建设中心成立后举办的系列培训项目之一，同时又是浙江省近期接待的第三批发展中国家妇女发展研修班。
作为“全国人工智能创新发展第一城”的争创城市，杭州是展示中国女性在数字浪潮中创新蝶变的“重要窗口”；作为世界货物吞吐量第一大港与制造业单项冠军之城，宁波则是展示女性在实体经济、海洋经济领域深耕发展的“鲜活样本”；杭甬双城联动，共同展示了中国女性教育从理论到实践、从传承到未来的完整生态链。研修期间，学员们深入探寻中国式现代化进程中多元主体协同推进女性发展的创新实践，学习我国构建女性全生命周期教育赋能和发展创新的有益经验。
顶层设计强根基：
妇联构筑“娘家人”温暖港湾
女性教育的发展离不开坚实的组织保障。通过妇联组织引领妇女发展案例教学，学员们系统了解了浙江妇女儿童工作在政策倡导、资源整合、平台搭建、实践赋能等方面的生动实践；在浙江省妇女干部学校，学员们通过交流座谈，探寻了女性教育培训阵地建设的“浙江实践”，学习了培养高素质专业化妇联干部队伍、提升女性职业技能的具体做法，从中汲取引领妇女发展的宝贵经验。
数实融合赋新能：
见证“她力量”硬核崛起

在数字经济与先进制造业的浪潮中，学员们深刻见证了科技企业在推动女性教育与发展中的社会责任。在蚂蚁集团，大家深入了解“数字木兰”计划如何通过数字技术赋能女性发展；通过互动分享，解析阿里巴巴如何将平台优势转化为女性成长的教育资源。在文三数字生活街区，学员们沉浸式体验DeepSeek大模型、脑机接口仿生手等前沿科技，感受“科技+教育”融合实践对青少年科技素养的培养。此外，在关于浙商精神与女性创业的专题课程中，学员们体悟了浙江女性敢为人先、百折不挠的奋斗底色，为推动本国女性创业积蓄精神动力。

跨越钱塘江，学员们将目光投向宁波的硬核制造。在吉利集团梅山极氪工厂，数字孪生、工业互联网、柔性制造等先进技术展现了中国智能制造的蓬勃活力，让大家深刻感受到教育培养人才、科技驱动创新、产业引领发展的良性循环，看到越来越多女性通过技能提升投身新质生产力建设。在宁波舟山港四期码头和中国港口博物馆，学员们近距离感受世界一流智慧港口高效运行，循着海上丝绸之路的发展脉络，深入了解宁波依港而兴、向海图强的发展历程，切身感悟中国坚持高水平对外开放、促进合作共赢的发展理念，也更加认识到开放合作为妇女成长和经济社会发展创造的广阔空间。
文脉传承育匠才：
搭建从学术到职场的阶梯
在科技革命与产业变革的交汇点上，为女性构筑从学术攀登到职场进阶的坚实阶梯是赋能女性发展的重要命题。学员们参访西湖大学，深入了解该校如何通过“西湖女性科学家发展支持计划”等举措培养基础研究与前沿科技领域拔尖女性创新人才，来自南非国家的学员奇利齐·佩图妮娅·内希东戈洛韦对西湖大学的先进技术、完备设施和高质量发展赞不绝口，认为这正是她们要学习取经之处；同时，她还表示人工智能的发展提升了女性教育工作者和科研人员的工作效能，提高了知识共享的有效性和可靠性；走进中国丝绸博物馆与万事利集团，见证了AI设计与数字化生产如何让千年丝绸技艺成为女性创新创业的新赛道。在宁波职业技术大学、宁波大学女子学院，大家直观感受到校企合作与产教融合为女性提供从职场启蒙到实战赋能的系统化教育；在永旺村“三关六码头”电商直播基地，大家在非遗体验中感受传统文化转化为现代商业价值的无限可能，了解“妈妈的味道”等特色品牌从手艺传承到产业发展的转变，看到女性如何依托电商直播等新业态实现家门口高质量就业创业；在宁波诺丁汉大学，通过数智时代的管理认知与女性领导力课堂教学，大家共同探讨了女性管理者如何以坚韧、包容的领导力推动企业创新。多元教育场景极大地拓宽了女性职业边界，生动展现了教育链、人才链、创新链、产业链深度融合的发展图景，为女性提供了全方位、多层次的能力支撑。
终身学习进社区：
打造“没有围墙”的成长空间
教育不仅发生在校园，更融入社区生活的肌理。在杭州市上城区社区学院，学员们考察终身教育发展情况，重点观摩了弯湾融合共享体，并了解社区“阳光妈妈”投身助残志愿服务、在奉献中实现自我成长的动人故事。在宁波市妇女活动中心，大家实地考察学习该中心立足女性成长需求，搭建线上线下一体化服务载体，打造妇女群众信赖依靠的温暖家园的特色做法；在宁波少年儿童图书馆，学员们深刻感受到“儿童友好”“分级阅读”“智慧多元”的科学理念，并了解到宁波作为全国首个实现市、县两级少儿图书馆全覆盖的城市，如何以优质公共文化服务夯实终身学习基石。基里巴斯学员梅里·泰耶表示，宁波少儿图书馆为孩子们提供了丰富的体验活动，她将鼓励自己学校的孩子掌握更多实操技巧，培养探索能力。同时，她也将把中国的现代技术理念带回国内，鼓励大家学习借鉴。多层次、多元化的公共服务体系，让女性在社会治理与家庭建设中持续获得成长的动力，努力实现个人价值与社会价值的全面提升。
从钱塘江畔到东海之滨，这场跨越杭甬的研修之旅，不仅是一次跨国界的知识分享，更是一场关于女性发展的深度对话。多元主体协同育人的“浙江样本”，为全球女性教育提供了可借鉴的实践路径。愿这份跨越山海的共识化作推动各国妇女事业前行的不竭动力，让女性智慧在构建人类命运共同体的征程中奔涌不息、奋勇向前，照亮更加平等、包容、繁荣的未来。
