# 人工智能语料呈现六大核心发展趋势

人民网研究院组织编写的智能互联网蓝皮书《中国智能互联网发展报告(2026)》7月29日在北京正式发布。其中，上海库帕思科技有限公司行业研究员仪孝伟撰写的《人工智能语料发展现状与趋势》一文指出，人工智能语料是驱动大模型性能的关键生产要素。目前国内语料供给已初具规模，行业市场规模持续高速增长，完整产业生态加速构建，整体呈现六大核心发展趋势。
一是从互联网知识向学术密集转变。早期大模型依赖海量互联网文本，虽知识面广但存在噪声大、事实准确性不足、逻辑链条不完整等缺陷。学术密集型语料则特指从经过严格同行评议的期刊论文、学术专著、专利文献等萃取的高质量信息，其演进趋势是构建高信噪比、逻辑严谨、富含知识密度的语料库。
二是从两维平面向立体高维转变。核心是语料的形态从单一的文本“二维平面”，扩展为融合文本、图像、音频、视频、3D点云等“立体高维”综合体。演进趋势是实现多模态信息间的对齐和融合，以构筑逼近真实世界的虚拟学习环境，训练出能够像人类一样理解世界的通用AI。
三是从关注规模的预训练向聚焦质量的后训练转变。大模型发展正从依赖海量通用数据的“预训练”阶段，转向依托高质量数据的“后训练”阶段。后训练语料主要包括微调（SFT）数据、人类反馈强化学习（RLHF）数据、价值对齐数据等，直接实现能力的行业适配，教会AI“说话做事的规矩”，对齐人类偏好及价值观。
四是从通用向通专结合和场景适配转变。即AI发展从追求“一个模型解决所有问题”的通用主义，转向“通用+专业”的协同模式。演进趋势是形成“三个同心圆”语料体系，最外圈层是广泛的通用语料，中间圈层是行业级语料，内圈层是具体企业或场景的私有化、个性化语料。
五是从原生数据向合成数据转变。旨在克服高质量原生数据的稀缺性，使用AI生成符合要求的训练数据，解决数据瓶颈。同时也是提升大模型鲁棒性、保护数据隐私的有效手段。合成数据在关键特征和统计分布上与真实数据高度相似，且合成数据不存在任何真实个体信息。
六是从项目制向平台化嵌入式服务转变。语料服务的商业模式面临根本性转变，传统项目制“数据售卖”方式正被“咨询+定制+应用+增值服务”的嵌入式语料服务模式替代，运营模式的平台化和生态型成为主流，“AI应用”正悄然带动“数据飞轮”。
