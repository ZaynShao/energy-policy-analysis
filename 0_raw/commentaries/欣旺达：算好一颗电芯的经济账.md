# 欣旺达：算好一颗电芯的经济账

在四川德阳，欣旺达588安时大容量电芯产线正开足马力。一颗电芯，如何撑起一座电站二十年的经济账？这家锂电企业的探索，给出了自己的价值答案。
储能行业的发展逻辑正在改写。
136号文落地一年多来，新能源上网电量全面入市，执行多年的强制配储政策随之退出；今年上半年，全国27个省份电力现货市场陆续转正，储能开始以独立主体身份直面电价波动。政策与市场双重换挡，把一个根本问题摆到全行业面前——脱离行政指令，储能如何凭借自身价值立足？
在业内人士看来，发挥出其特有的使用价值，是新型储能发展的唯一出路。储能必须回归商业本质，在真实的市场环境中检验价值。“用得起来”的储能正在“挣到钱”。制度设计也在跟进。“十五五”规划首次提出置信出力考核，行业评价标准从“装了多少”转向关键时刻“顶不顶得上”。

从“配不配”到“赚不赚”，储能正告别容量竞争，迈入价值竞争。竞争逻辑的变化，最终传导至产业链上游的电芯环节。在四川德阳，欣旺达588安时大容量电芯产线正开足马力。一颗电芯，如何撑起一座电站二十年的经济账？这家锂电企业的探索，给出了自己的价值答案。
大电芯成价值竞争“入场券”
“过去几年，中国储能产业已经从跟跑走向领跑。任何一个走向成熟的产业领域，都会经历从规模竞争到价值竞争的转变。”欣旺达电子股份有限公司董事长王威认为，新型电力系统对储能的要求，已从过去简单的“装得上”，转向今天的“用得好”——更低的全生命周期成本、更优的项目投资回报、更可靠更安全的运行，以及被资本市场认可的可融资性。
价值竞争，电芯先行。在王威看来，大电芯是这场竞争的“入场券”。“电芯容量提升，意味着同等规模的电站可以使用更少的舱体、更简的接线、更小的占地，初始投资随之摊薄。电芯寿命延长、能效提升，则直接增厚电站二十年运营期的收益。”但他特别强调，“绝不是把电芯做大那么简单。电芯越大，对本体安全、循环寿命、能量密度、系统集成和一致性交付能力的考验越大，要让每一度电、每一分投入，在二十多年的生命周期里经得起检验。”
竞争逻辑的变化，市场端感知最为直接。从280安时成为主流规格，到迭代至314安时，如今行业正迈向500安时以上。欣旺达电子股份有限公司储能板块产品总经理孙瑞介绍，今年上半年国内电芯集中采购中，500安时以上大容量产品的招标量明显放大，预计下半年起大电芯将在国内市场渐成主流。从全球看，2027年储能新增装机有望达到太瓦时级。
从拼价格到算全生命周期的账，电芯成为价值创造的起点。欣旺达围绕不同技术路线和容量段构建大电芯矩阵——588安时卷绕电芯主打平台化与规模化交付，684安时叠片电芯追求能量密度，与系统集成商联合定义、匹配不同技术方案。“市场是多样的、包容的，客户也需要不同选择。”孙瑞说。
近5年来，欣旺达研发投入150亿元，授权专利8000余项。王威称：“‘用心做好每一块电池’，我们希望让每一座储能电站，都成为新型电力系统中安全可靠、可被信赖、可被融资的优质资产。”
电芯、系统、平台的三重协同
走进欣旺达德阳基地电芯车间，AGV小车沿黄色标线往来穿梭，机械臂将极片精准叠放；产线末端，每颗电芯都要进入工业CT设备“体检”，内部结构在屏幕上三维成像，微米级缺陷一览无余。这座位于四川什邡的基地占地680亩，是欣旺达588安时、684安时大电芯的首个量产基地，也与欣旺达全球储能制造布局形成协同，为国内及海外市场提供稳定的产品供应和交付保障。
经济性是一道综合题。按平准化储能成本的算法，分子是初始投资与运营成本，分母是全生命周期吞吐量；落到电芯层面，能量密度决定占地与集成成本，寿命与能效决定长期收益。588安时电芯给出的答案是：能量密度417瓦时/升，支撑20尺标准集装箱容量达6.26兆瓦时，较上一代提升25%；70%健康度下循环寿命1万次，覆盖电站二十年服役期；0.25P充放电能效96.5%，全生命周期充电成本显著下降；电芯缺陷管控达十亿分之一级，今年年中已在行业内率先实现量产。
一颗电芯，衍生三款系统。6.26兆瓦时液冷储能系统面向大型电站，以“少舱体、简接线”摊薄配套设施成本；3.13兆瓦时液冷储能系统采用10尺柜设计、单舱24吨，灵活拼舱适配多元场景；3.13兆瓦时交直流一体系统将PCS内置集成，出厂前完成预制预调，实现从“电池单元”到“电站单元”的跨越。系统层面算下来，同等规模电站电池舱数量减少20%，占地节省最高20%，现场安装工时减少18%，全生命周期度电成本下降约10%。
“储能电站是要运营二十年的资产，这是平台从设计开始最根本的出发点。”欣旺达动力科技股份有限公司储能产品开发专家魏臻博士介绍，三款产品共享同一颗电芯、同一套热管理架构和安全技术标准，客户可获得统一的技术迭代、备件运维与数据平台。
制造端是这笔账的最后落脚点。德阳基地毗邻川西水电与锂矿资源，六大主材当天可达；基地测试中心具备完善的测试与验证能力，每颗电芯出厂前均须经过二十余道检测。“我们做的东西，做好了叫电池，做不好叫炸弹。”德阳欣旺达新能源有限公司总经理唐浩然说，对热失控严防死守，正是经济性最前面的那个“1”。
从产品出海到体系出海
价值竞争的赛场，不止在国内。
“中国是全球最大的储能市场，必须守住。”孙瑞介绍，国内市场上，欣旺达在独立储能主战场持续发力的同时，针对电价水平与收益率现状，向“储能+X”细分场景要利润，石油、移动储能等场景均已落子。去年以来，国内市场进入相对稳定期，海外部分地区需求则增长较快，两个市场正形成互补。海外的打法与国内不同：欧洲市场以供应电池系统为主，北美市场以供应电芯为主，为本地集成商提供配套；产能端，泰国基地已投产314安时、684安时电芯，匈牙利基地兼作欧洲储能备件与售后中心，辐射重点项目与客户。
出海，合规先行。孙瑞透露，588安时平台国内认证以及欧洲、美国、澳大利亚三大区域认证已基本完成，下半年将陆续启动发货。产品设计也为全球化“量体裁衣”，针对部分海外港口吊机限重的现实，10尺柜可现场拼舱、最多“一拼八”，化解大容量系统的运输吊装难题。
全球化的深层支撑是体系能力。如今，欣旺达在全球布局了11大制造基地，构建起从矿产材料、电芯到系统集成的全产业链一体化能力，连续入选彭博新能源财经全球一级储能厂商及可融资性企业榜单。在孙瑞看来，全球产能布局既是应对贸易环境变化的主动选择，更是客户本地化服务的要求，贴近市场，才能把交付和服务做扎实。
从卖设备到卖系统，从产品出海到体系出海，中国储能企业正不断深化全球化布局。在业内人士看来，全球市场的竞争，归根到底仍是全生命周期价值的竞争。一颗电芯的经济账，最终算的不是电芯本身，而是一座储能电站全生命周期的安全、效率、成本与收益。谁能把安全、可靠与收益写进电站的二十年，谁就能在全球能源转型的进程中站稳脚跟。
