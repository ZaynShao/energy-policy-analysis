# 建设工程施工合同中总承包人与分包人或非法转包、违法分包主体与实际施工人之间约定的管理费是否有效？

01
问题解析
在建设工程领域，建设工程施工合同中约定“管理费”的情况时有发生，其中既包括建设工程总承包模式项下的总包管理费、总包服务费等，也有转包、违法分包和借用资质挂靠等情形下，转包人、违法分包人与实际施工人约定的所谓管理费、挂靠费等。由于现行法律法规并未对建设工程施工合同中约定的“管理费”作出明确规定，实践中，关于“管理费”的约定是否有效，具体应该如何计算等经常存在较大争议，因此厘清管理费的性质以及管理费的司法认定与裁判规则较为必要，可以更好的规避相关风险，本文就此具体分析和讨论如下：
1. 何为企业管理费？
根据《建筑安装工程费用项目组成》中的相关规定，企业管理费是指建筑安装企业组织施工生产和经营管理所需的费用。包括管理人员工资、办公费、差旅交通费、固定资产使用费、工具用具使用费、劳动保险和职工福利费、劳动保护费、财务费等。因此管理费的本质是因建设工程施工过程中的工程组织和管理行为产生的成本，所耗费的人力、物力和财力事实上已经融入到了建设工程之中，实际是建设工程价款的组成部分之一。
2. 建设工程施工合同无效情况下，管理费的约定是否有效存在一定争议
在建设工程施工合同有效的情况下，基于意思自治的原则，对于合同约定的管理费计取一般争议不大。但在建设工程施工合同无效的情况下，实践中存在一定不同认识。一种观点认为，无论合同是否有效，只要建设工程经竣工验收合格，均可参照合同约定计取管理费。
还有一种观点认为，因转包、违法分包、出借资质行为导致承包人与实际施工人签订的转包合同、违法分包合同无效，作为合同约定内容之一的管理费也应一并无效。另外，建设工程质量涉及公众安全，《建筑法》、《民法典》等相关法律法规对转包、违法分包、出借资质行为都予以否定性评价，承包人因转包、违法分包、出借资质而获得管理费，属于非法所得，不应得到支持。
3. 承包人实际参与施工管理和组织协调工作是支付管理费的重要依据
结合最高人民法院法官会议纪要的精神和司法实践的相关裁判观点，我们认为，在建设工程施工合同无效的情况下，合同中关于管理费的约定是否可以参照适用需要具体问题具体分析，其中应以承包人是否实际参与建设工程施工管理和组织协调工作等作为是否支付管理费的重要依据。
如果转包、违法分包或者有资质的承包人仅仅给予工程或出借资质但没有实施具体的施工管理行为，属于非法牟利，对于该些承包人提出的支付管理费的请求，一般不予支持。如果转包、违法分包或者出借资质的承包人在给予工程或出借资质后也实施了一定的施工管理行为，则应当综合考虑承包人的支出成本、合同各方的过错程度、实现利益平衡等因素，参照合同中关于管理费的相关约定予以处理。
4. 结论与建议
因此，承包人主张管理费的，应当在建设工程施工合同中对管理费及相关计算依据进行明确约定。另外，在整个建设工程施工过程中，承包人应尽可能参与施工管理和组织协调工作，确保履行了合同约定的工程管理和监督等职责，包括但不限于派遣相关人员，实际控制和管理相关工程费用的支付，推进和保证施工进度，对工程质量进行管理、控制、监督和检查等，同时留存好参与建设工程项目管理过程的全部书面文件材料，为后续可能发生的纠纷和争议做好证据准备。
02
相关案例
案例1：贵州甲建筑工程有限责任公司、李某建设工程施工合同纠纷再审审查与审判监督民事裁定书（案号：（2019）最高法民申763号）
再审法院最高人民法院认为：二审法院依法查明案涉工程为冉某借用甲公司资质承接工程后全部转包给李某、刘某，且甲公司在（2015）遵市法民商终字第180号案件中也称“涉案工程系冉某借用上诉人资质挂靠承建”，故《目标责任书一》是借用资质承接案涉工程而签订的协议，《目标责任书二》是案涉工程非法转包协议，二审法院据此认定上述两份协议无效，并无不当。
根据《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》第二条之规定工程款可参照合同的约定计算，但并不代表相关条款独立有效。故二审法院认为冉某与甲公司之间的管理费约定，以及冉某与李某、刘某之间的转包费的约定均为无效条款，亦不存在适用法律不当的情形。一、二审中甲公司或冉某并未举证证明其对涉案工程实际提供了管理服务，且二审法院另查明在（2017）黔03民终4669号民事判决书中甲公司明确称“被上诉人甲公司以内部承包的方式将工程款转包给冉某以后其完全退出该工程的管理，并收取管理费”，故二审法院认定其未对涉案工程进行管理，无权收取管理费，不缺乏证据证明。甲公司及冉某支付的工程款在扣除管理费后并未超出刘某、李某应得之工程价款。故二审法院对甲公司提出李某、刘某应返还其超付工程款的主张不予支持，不缺乏事实依据和法律依据。
案例2：河南甲建设集团发展有限公司、黄某等建设工程施工合同纠纷民事申请再审审查民事裁定书（案号：（2021）最高法民申3897号）
再审法院最高人民法院认为：根据查明的事实，甲公司虽然名义上将承包乙公司的工程内部承包给黄某，但实质上是没有资质的实际施工人黄某借用有资质的甲公司名义施工，原审根据《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》第一条第二项规定，认定《建设工程施工合同》与《工程施工内部承包协议书》无效，具有事实和法律依据。
黄某与甲公司之间系借用资质关系，但建设工程领域借用资质的行为违反了法律的强制性规定。故原审不予支持甲公司二审上诉请求黄某按照案涉工程价款的1.2%计取收益费，适用法律并无不当。
案例3：周拥某、甲建筑安装工程有限责任公司建设工程施工合同纠纷二审民事判决书（案号：（2018）最高法民终587号）
二审法院最高人民法院认为：（三）关于扣除管理费。《建设工程内部承包合同》第三部分专用条款的第42条补充条款第3款约定：“承包人交纳工程总价款的2%给发包人作为公司及项目部管理费用，此管理费在每次工程款支付时发包人按比例从工程款中扣除”。现周拥某也确认周良某系甲公司的项目负责人、张某系甲公司项目副经理，故其对于甲公司实际派员参与了案涉工程管理的事实并无异议。
《建设工程内部承包合同》无效系因违反禁止违法转包的强制性规定，实际施工人周拥某没有资质而借用甲公司名义，对违反禁止非法转包也是明知的，故其不能依据内部承包合同无效而主张不予扣除甲公司应当收取的管理费，反而因合同无效而获益。甲公司实际参与了案涉工程的施工管理，其在应付款项中主张扣除相应的管理费用属于相互履行的抗辩，并非必须通过反诉提出，原审参照合同约定的工程总价款的2%在应付款项中扣除管理费用，并无不当。
案例4：马某与甲公司、甲公司宁夏分公司建设工程施工合同纠纷再审审查与审判监督民事裁定书（案号：（2019）最高法民申2732号）
再审法院最高人民法院认为：（一）对于管理费的认定问题。首先，协议书第七条“甲方的权利义务”中约定了甲公司宁夏分公司为马某提供服务，对工程的施工等情况进行检查、监督和指导，根据工程需要甲公司宁夏分公司为马某配备工程技术管理人员等。与此相对应，本案再审审查询问中，马某认可甲公司定期检查工程进度，并称其对外是以甲公司名义进行施工，案涉项目在上报相关材料时也是以甲公司的工作人员作为项目经理进行上报的。因此马某再审申请称甲公司并未参与工程管理，与事实不符，甲公司在案涉工程施工中参与了管理，实施了管理行为。协议确认无效后，马某对于甲公司的实际管理行为应当支付对价。
其次，马某再审申请时承认协议无效是双方过错所致。任何人不得从自己的过错中获利，马某亦不能从其违法行为中获得利益。如果认定管理费不应从工程款中扣除，不仅导致马某对其过错不承担任何责任反而获得比订立协议可预见的更高的工程款，与《中华人民共和国建筑法》、《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释》规定的立法目的不相符，还会以此鼓励违法行为，扰乱建筑业市场秩序。对于马某再审申请所称的管理费属于违法所得的问题，违法所得应当由有权机关没收，与本案中马某是否承担此项费用属于不同的法律关系。协议书因违反法律规定而无效，并不影响协议中对相关费用比例的约定是双方的真实意思表示，因此对于马某应当缴纳的管理费可参照协议书的约定认定。
再次，协议书第三条3.1.1约定“乙方（马某）按承担工程项目结算总额的3.8%向甲方（甲公司宁夏分公司）缴纳管理费”，该条3.1.2约定“乙方（马某）需承担工程项目总额1%的招投标相关费用”。协议书中将管理费和招投标相关费用进行了分别约定。而原判决扣除工程总价款的3.8%即1,639,167.8元，不仅包含了管理费而且包含了招投标相关费用，此认定结果并无不当。
案例5：江苏省甲建筑安装集团股份有限公司、孙某建设工程施工合同纠纷二审民事判决书（案号：（2019）最高法民终1779号）
二审法院最高人民法院认为：关于涉案管理费。涉案《工程内部承包合同书》约定“合同价格：审计结算价下浮8%。”一审法院将该约定定性为总包单位收取8%的管理费并无不当，本院予以确认。
因《工程内部承包合同书》无效系因违反禁止违法转包的强制性规定。实际施工人孙某、鞠某并不具备施工资质而借用甲公司名义，对违反禁止转包明知，其不应从违法行为中获利。对于孙某、鞠某依据《工程内部承包合同书》无效而主张不予扣除管理费的上诉请求，本院不予支持。同时，因涉案《工程内部承包合同书》无效，甲公司主张按照协议约定收取8%的管理费也依据不足，一审法院根据本案合同履行的实际情况等因素，将双方约定的按照审计结算价下浮8%调整为下浮4%并无不当，本院予以维持。
案例6：史某、谭某建设工程施工合同纠纷再审审查与审判监督民事裁定书（案号：（2021）最高法民申5472号）
再审法院最高人民法院认为：四、关于管理费的问题。双方在案涉承包协议第二条中约定以甲公司与乙公司施工合同总造价10%收取管理费。因该承包协议无效，故不可完全按照该约定计取管理费。史某作为实际施工人虽对案涉工程进行管理，但在2014年1月史某因车祸住院后案涉工程由乙公司实际控制并支付工程费用。故可以认定双方均对工程实施了管理行为。二审依据乙公司的管理行为，认定乙公司可收取220万元管理费，符合本案实际情况。史某认为乙公司不应当收取管理费的意见，无事实依据，本院不予支持。
案例7：海南甲建设集团重庆有限公司、乙建筑有限公司等建设工程施工合同纠纷民事申请再审审查民事裁定书（案号：（2021）最高法民申5161号）
再审法院最高人民法院认为：2.关于甲公司应得工程价款数额的确定问题，本案中，乙公司承包案涉项目后并未进行施工，而是违法分包给甲公司等主体进行实际施工，并以相关部门最终审定结算价的78%作为最终结算价收取相关的管理费用。针对管理费的问题，应在查明乙公司是否存在管理的基础上结合本案具体情况依法公平合理处理。如果乙公司参与工程管理，则可根据参与工程施工管理协调程度等具体情况酌情支持一定的管理费。二审判决未查明有关事实，仅以甲公司自愿按审计价款的78%计付其应得工程总价款，此属对自己民事权利的自由处分为由认定甲公司应得工程价款的数额，有失妥当。
