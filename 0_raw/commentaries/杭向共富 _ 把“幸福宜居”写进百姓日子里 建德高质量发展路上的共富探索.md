# 杭向共富 | 把“幸福宜居”写进百姓日子里 建德高质量发展路上的共富探索

在建德，幸福宜居是什么样的？
5月中旬，一场万亩茶田时装秀在大同镇西乡茶园火热开启，当天直播间观看人数累计突破2万，茶叶订单已接60多单；下涯镇之江村的“90后”王嘉岚在自家的山风农场办了一场摄影展，用影像力量持续赋能乡村振兴；航川村民宿经营者董大姐送走上海客人，灶上又炖起了土鸡煲；李家镇的陆金香老人，准时接过送餐志愿者的保温桶，饭菜还是热乎的……
这些热气腾腾的日常拼在一起，就是“幸福宜居”最真实的体现。
2021年，浙江被赋予高质量发展建设共同富裕示范区的重任，杭州扛起“头雁”担当。建德闻令而动：从2021年“全面建设‘宜居建德’、全力推动共同富裕”，到2024年全力打造“幸福宜居之城、文旅共富样本”，再到2026年，路径愈发清晰。
五年一步一个脚印，当初的目标，正变成千家万户的烟火气、田间地头的新希望。
共同富裕，核心在统筹，关键在联动。建德立足山水生态与乡村资源，以党建联建为纽带，打破村域界限、整合全域资源，推动强村带弱村、抱团共发展，让“文旅共富样本”从蓝图变为实景。
航头镇航川村的故事很有说服力。2022年，村集体经营性收入刚破100万元，建德市派来的乡村振兴特派员陈友明提出：要做普通人住得起的普惠民宿，干净实惠。2023年，他和村两委动员12户农户“试水”。“那时候心里没底，就想着跟着试试，没想到一开就火了！”民宿经营者董大姐回忆，开业头8个月，6万人次涌进小村，经营户户均月入3万元。土鸡、土鸡蛋、时令蔬菜刚摆出来就被抢空。
但新问题也来了：从杭州过来要转三趟车，各家民宿服务水平参差不齐。2025年，航头镇以航川村为核心，联合周边6个村组建“139乡宿”党建联建联合体，联动交通、文旅等20余家单位，开通全省首条乡村“游运”专线：杭州东站直达村口，139元包往返车票、一晚住宿和三餐。“以前从杭州过来要扛着行李折腾大半天，现在专线直通民宿门口，两个半小时就到。”民宿云逸轩老板娘许在容高兴地说。一年时间，专线运送5800余人次，创收42万余元。
如今，航川村民宿增至42家，村集体经营性收入翻番至200万元，年接待游客超20万人次。这一模式已覆盖建德、淳安2县7镇15个村，预计全年带动经营户增收3000万元，真正实现“一村兴、一片旺”。
乾潭镇安仁片区同样尝到抱团的甜头。安仁村带动周边5个村成立共富联合体，把闲置荒坡变成杜鹃花海共富工坊。“以前只能外出打工，顾不上家里。现在在家门口上班，还能照顾老小，日子越过越踏实。”前陵村村民夏大姐笑着说。五年来，该联合体招引亿元以上项目8个，2025年六村集体经营性收入达1570万元，带动300余名村民就近就业。杨村桥镇“互助长宁”联合体则让5个村抱团发展，搞采摘、进集市、上直播。“以前圣女果零星卖，价格低还卖不动。现在5个村一起干，销路一下子打开了。”龙溪桥村党总支书记章志松说。截至目前，片区累计销售农产品500余万元，村集体增收850余万元，村民户均年增收超3万元。
截至2025年底，建德已建成9个重点共富联合体，覆盖40余个村，村集体经济年均增长15%以上，低收入农户收入年均增长12%以上。片区组团发展，成为建德打造文旅共富样本的鲜明标识。
幸福宜居，根基在产业，活力在人才。建德是农业大市，山多地少。过去村民多靠“土里刨食”，土地零散、设施落后，种得多、赚得少；年轻人嫌农村苦，纷纷外出务工。这五年间，农业“标准地”改革成为突破口——既盘活了土地，也引回了人才。
2021年，杨村桥镇党员洪拥军带头拆了自家旧式草莓棚。“以前自己租地、自己搭棚，东一块西一块，费钱又费工。现在村集体统一流转土地，镇里统一建好钢架大棚，农户直接‘拎包入住’，只管专心种草莓，收入比以前翻了好几倍。”如今，草莓“标准地”已建5660亩，全产业链产值50.8亿元，带动1.6万莓农户均年增收30万元。
不止草莓。五年来，建德把“标准地”推广到水稻、茶叶、蔬菜、蛋鸡等产业。大同镇建成茶叶“标准地”2000余亩，推行“村民流转获租、政府统一开发、大户拎包入住、村集体入股、农户务工”模式，让村民实现“一份土地三份收入”——土地流转有租金、茶园务工有薪金、村集体分红有股金。2025年，大同镇所有行政村集体经营性收入均超50万元，农村居民人均可支配收入增长8.2%。目前，建德已累计建成“标准地”12万亩（含草莓“标准地”），带动村集体增收2000万元、农户增收1.5亿元。
产业有了，人怎么回来？技能和平台是关键。建德打造“建德师傅”一站式孵化基地，聚焦草莓、豆腐包、家政服务等富民产业，构建“标准开发——技能培训——统一评价——实景实训——创业帮扶”五步闭环。“以前没技术，只能打零工，收入不稳定。现在有了手艺，年收入比以往提高两成以上。”打造“建德阿姐”家政品牌的余兵燕说。截至目前，建德累计培育4.2万余名建德师傅，带动就业11.2万人，全产业链产值达113亿元。
年轻人回来了，乡村就有了新气象。5月16日大同镇西乡茶园那场茶田秀就是最好的证明。策划者徐登峰介绍，自2025年3月接手片区运营以来，茶园已举办主题活动30余场，接待5000余人次。“以前守着茶园只会采茶卖青叶，赚点辛苦钱。现在年轻人回来搞露营、办茶田秀，我们帮着布置场地，每个月能多赚两千多块。”镇源村梅大姐笑着说。
为了让青年留得下、干得好，建德出台专项扶持政策，每年安排2000万元以上专项资金，搭建青创空间，构建“引育留用”全链条支持体系。五年来，累计引育超2万名青年投身乡村，其中现代“新农人”8307人，农创客3973人。
幸福宜居，落脚点是百姓安康、生活舒心。五年来，建德聚焦“一老一小”、弱势群体，把民生实事办到群众心坎上。
这样的温暖，可以从一张“幸福方桌”说起。李家镇李家村78岁的陆金香独居多年，过去最发愁的就是做饭。“年纪大了，手脚不利索，一顿饭常常凑合一整天。”2022年，“幸福方桌”银龄助餐行动开展后，她再也没为吃饭操过心。“无论刮风下雨，每天两顿热乎饭菜准时送上门。志愿者还帮我测血氧、教我用急救包，比我闺女还细心。”
2023年底，建德全面启动“幸福方桌”扩面提质三年行动，打造“中心食堂+助餐点+送餐上门”体系。截至目前，全市投入运行老年食堂119家、助餐点136个，村社服务覆盖率达98%，日均服务6000名老人。这张“方桌”还延伸出了健康检测、便民代办、探亲陪伴等暖心服务。
李家镇新联村73岁的宝根爷爷患有智力障碍，唯一的亲人是远在龙游的77岁姐姐。自2023年起，村里为他开通专属“探亲专线”——只要他想姐姐了，村干部就第一时间安排行程、全程陪护。“每年村干部都陪着我们相见，心里踏实又温暖。”姐姐攥着弟弟的手，眼眶湿润。建德市相关负责人介绍，“幸福方桌”还联动公安打造反诈阵地，推行“智能预警+联动劝阻+综合治理”模式，涉老诈骗降幅位居全省前列。
兜底保障同步跟进。目前，建德全市已建成233个共富工坊，吸纳9700余人次就业，重点帮扶低收入农户、农村剩余劳动力。通过“政府+企业+农户”利益联结机制，城乡收入倍差缩小至1.63。位于寿昌镇山峰村的乡村909“趣”玩共富工坊，将村里闲置用房改造成集旅游集散、产品展销、研学体验、餐饮于一体的“乡村欢乐世界”，已带动周边20余人从事餐饮服务，其中低收入农户5人，人均年增收达2.5万元，村集体年增收20万元。
共富路上风正劲。五年来，建德以抱团破困、产业筑基、民生提质，走出了一条城乡共荣之路。乡村更美丽、产业更兴旺、百姓更富足——是答卷，也是新起点。
这方水土，终不负每一位赶路人。
