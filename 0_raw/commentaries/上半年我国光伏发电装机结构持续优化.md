# 上半年我国光伏发电装机结构持续优化

国家能源局8月14日发布的统计数据显示，2026年上半年我国光伏发电建设保持较快增长态势。今年1~6月，全国新增并网光伏发电容量共计7176.8万千瓦，其中集中式光伏电站新增2954.7万千瓦，分布式光伏新增4222.1万千瓦，分布式占比约58.8%，户用光伏新增2183.1万千瓦，占全部新增的30.4%。
从各省份情况看，上半年新增装机超过500万千瓦的省份有江苏、云南、四川、河南、广东和浙江。其中，江苏以860.9万千瓦的新增容量位居全国首位，累计并网容量达9829.2万千瓦，逼近亿千瓦大关。云南新增729.5万千瓦，主要集中在集中式电站，达670.4万千瓦，累计容量6215.6万千瓦。河南新增758万千瓦，且全部为分布式光伏，其中户用光伏高达671.5万千瓦，显示出中部地区户用市场的强劲活力。
在累计装机规模上，山东、江苏、河北、新疆、宁夏等省（区）位居前列。山东累计并网容量9658.9万千瓦，其中分布式光伏6168.6万千瓦，户用光伏2967.5万千瓦，户用规模全国领先。河北累计容量8686.8万千瓦，分布式光伏3822.4万千瓦，户用2457.1万千瓦。新疆累计容量9488.2万千瓦，以集中式电站为主，达9444.3万千瓦，分布式仅43.9万千瓦。宁夏累计4398.8万千瓦，集中式占比超过93%。此外，内蒙古、青海、甘肃等西部省份集中式光伏占绝对主导，内蒙古累计6238.5万千瓦，集中式占5722.4万千瓦；青海累计4284.9万千瓦，集中式达4235.1万千瓦。
值得关注的是，部分省份分布式光伏增速显著，江苏、浙江、安徽、福建、江西、湖南、广东等南方省份的分布式累计装机均已超过集中式装机。其中，安徽分布式累计4225.1万千瓦，占总容量的71.2%；湖南分布式累计2193万千瓦，占总容量的74.5%；福建分布式累计1735.6万千瓦，占比高达92.0%。与此同时，户用光伏在河南、山东、河北、安徽、江苏等省份发展尤为突出，河南户用累计3438.7万千瓦，山东2967.5万千瓦，河北2457.1万千瓦，安徽1915.2万千瓦，江苏2409.6万千瓦，上述五省户用合计占全国户用总容量的近六成。
业内人士表示，2026年上半年我国光伏发电装机结构持续优化，分布式光伏尤其是户用光伏继续保持快速增长，中东部地区分布式主导地位进一步巩固，西部地区则以大型集中式电站为支柱，全国光伏发电多元化发展格局愈发清晰。（来源：中国电力报 记者冯聪聪）
