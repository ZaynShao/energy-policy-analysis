# **综述**

本期，国际原油涨跌互现，但均价上涨，美伊虽就停火释放表态，但美以伊军事冲突未止、霍尔木兹海峡航运受阻，叠加中东产油国减产，原油供应风险持续加剧。国内炼厂供应呈现收窄，低价资源外流增多，影响高价出货，4月CP出台大幅上涨，进口成本接近8000元/吨支撑心态，周后期出现全国范围内的推涨。

近期液化气市场关注点：

1）中东局势不确定性偏强，消息面变化对市场心态影响尤为显著；

2）沙特阿美公司2026年4月CP出台，丙烷750美元/吨，较上月上调205美元/吨；丁烷800美元/吨，较上月上调260美元/吨；

3）供应波动有限，但原料短缺对PDH企业影响逐步体现，化工需求下降。

**一、4月CP大涨 带动液化气价格高位上推**

本期国内液化气市场延续上涨行情，供应偏紧和成本端是主要支撑。地缘紧张局势持续，市场对供应收紧的预期正逐步转为现实，叠加4月进口成本大幅上涨，市场情绪不断升温，进一步助推上行行情。尽管随着价格持续攀升，需求端表现偏弱，采购节奏明显放缓。周初市场涨幅收窄，局部高价区域受周边低价资源冲击，一度陷入短暂僵持。自4月沙特CP官价公布后，进口成本大涨拉升价格重心，打破僵局月初市场再度进入上行通道。其中，因东南亚多地LPG供应持续紧张，华南转出口需求及价格同步攀升，区内销售压力下降，进一步提振本地行情，因此华南涨幅尤为显著。当前南北价差拉大，跨区域套利活动增多，也对外围市场形成提振。本醚后碳四市场呈震荡上涨走势。周内国际油价涨跌互现，消息面支撑有所减弱，好在市场供应持续收紧，供需基本面形成新支撑，价格得以维持高位震荡。

#### **二、供应收窄 炼厂持续降库**

预测：供应端或有缓慢下滑，主要基于企业降负较多。未来三周预期国产供应量或下滑，或降至50.2万吨左右，总计降幅2.7%。未来三周预期到港量在15-40万吨。

1、转出口增加，港口库存下降

截至2026年4月2日，中国液化气港口样本库存量：232.57万吨，较上期减少1.4万吨或0.6%。本期，国际船期到港量56.7万吨，环比增加0.35%，以华东为主。截至4月2日，本月到船量11.2万吨，环比减少40.11%。本期港口到船波动有限，供应端变化不大。需求方面，化工需求下降，不过华南出口利润可观，转出口量增加，华东同样积极出货为主，整体需求提升，因此本期港口库存出现小幅降库。

3、消息面影响仍在，炼厂库存小幅下降

截至2026年4月2日，中国液化气样本企业库容率水平在24.55%，较上期下降0.37个百分点。周期内，所统计样本企业所在地区中，3个地区库存上涨，3个地区库存下降，1个地区保持稳定。周内虽然液化气依旧受消息面主导，但基本面影响也有抬头，国内市场表现两极分化，南方地区受低供支撑，价格持续攀升，短暂引发下游畏高情绪，也吸引了外部资源流入补充，北方各地厂家依靠跨区套利运货南下，成功完成去库，总体看各地厂家出货相对顺畅，最终企业库容率出现小幅下降。

下周来看，地缘局势影响仍在，国际原油高位震荡，消息面依旧对国内市场影响明显，且进口资源流入不畅，国内整体供应偏低，基本面存在支撑，预计双重利好支撑下，下周国内生产企业库容率仍将有所下降。

下游深加工需求：本周液化气需求量总计129.28万吨，环比下降0.34%。未来三周，预计两大下游总需求呈下降趋势，第三周消费量预计降至126.2万吨，总计降幅2.38%。

#### **四、供应收窄预期偏强 重心震荡上移**

下周重点关注上下游装置开工变化。

供应：未来三周，国产供应量或缓慢下滑。

下期，国内生产企业暂无开停工计划，但生产企业降负行为或仍持续，预计下周国内液化气商品量或有下滑，总量或在51万吨左右。未来三周，中海油泰州石化检修，部分企业或恢复资源内调。整体来看，国产供应量或缓慢下滑，预计供应量或在50.2万吨。

需求：未来三周，燃烧与化工需求预期均有转弱。

燃烧需求（预期下滑）：未来三周气温升高，终端燃烧消费能力预期将有下滑。

烯烃（预期先增后降）：短期或因河北新启元烷基化装置复产带动，预计国内烯烃开工率将出现上涨，而后续看科德化工烷基化装置存检修计划，预计将导致国内烯烃需求量将出现下滑。

烷烃（预期下降）：下周来看，暂未有企业开停工消息，不过因前期停工企业较多，因此预计下周中国烷烃需求量仍有下降。长线来看，卫星化学PDH二期预计重启，不过东华茂名PDH以及科德顺酐计划停工，因此预计未来三周烷烃需求量呈下降趋势。

进口成本：下周来看，国际原油受地缘政治影响仍宽幅在宽幅震荡区间内整理，市场预期也随之变化莫测，受此影响纸货市场价格跟随原油调整，并且5月市场可见卖家报盘，对市场涨幅也有压制，预计未来一周外盘市场或出现一定走跌，考虑到市场供应恢复期较长，预计跌幅有限，后期观望地缘局势变化的指引。

国际原油：预计下周国际油价存上涨空间，WTI或在101-108美元/桶、布伦特或在103-113美元/桶的区间运行。预测下周油价趋势的核心逻辑为：中东军事升级预期升温，霍尔木兹海峡航运实质性受阻态势未改，原油供应端风险持续抬升，地缘不确定性对油价的支撑作用显著增强。

丙烯：综合来看，高位成本对丙烯价格构成底部支撑，叠加供应紧张格局短期难以缓解，丙烯长线偏强趋势明确；短线价格亦存在小幅上行动能，预计下周国内丙烯市场维持高位运行，价格或在8500–9000元/吨区间震荡整理。

MTBE：预计下期MTBE市场或区间震荡整理。重点关注：1.供应面。滨州大有新建异构装置开工，预计资源供应或增加。2.需求面。汽油方面，预计国际油价存上涨空间，且新一轮成品油零售限价预期上涨，消息面利好油市，成品油行情有望保持坚挺走势，同时清明小长假临近，中下游商家将适当补货；3.出口面。仍需密切观望新出口订单商谈情况，但目前活跃度一般；4.成本面。原料价格高位运行，尤其进口成本高企，成本支撑动力充裕。综合下预计MTBE市场或保持区间整理态势，终端需求存有抑制，但厂家生产成本较高，相互博弈下市场以区间震荡整理为主，届时观望原油运行态势零星波动整理，预估下周山东地区MTBE价格在7200-7400元/吨。
