# 财经早餐丨每日财经三分钟新闻报道07月13日

► 美军：本周对伊朗发动第三轮打击，目标约140个，伊朗革命卫队宣布关闭霍尔木兹海峡。
► 长鑫科技：IPO将于7月16日申购，拟募资295亿元，为今年A股最大IPO。
► 国家统计局：2026年全国夏粮产量3014.9亿斤，首次突破3000亿斤。
01 今日财经头条
- 央视新闻/美军中央司令部：美伊冲突升级，美军于7月12日对伊朗发动本周第三轮打击，目标涵盖约140个军事设施；纽约原油暗盘应声上涨3.27%。
- 伊朗革命卫队：宣布因不安全局势，暂时关闭霍尔木兹海峡，任何船只不得通行，直至美国停止干预。
- 央行货币政策委员会：二季度例会新增“结构分化”判断，指出经济运行面临“供强需弱、外部冲击、结构分化”三重维度压力。
- 长鑫科技：国产存储芯片巨头长鑫科技IPO将于7月16日网上申购，拟募资295亿元，为2026年A股最大IPO。公司预计上半年营收1100亿至1200亿元，同比增长超612%。
- 国家统计局：2026年全国夏粮产量达3014.9亿斤，首次突破3000亿斤大关，比上年增长0.7%；单产378.8公斤/亩，22个产区实现增产。
- 中国石化：完成对中国航油的重组，后者正式成为其二级全资子公司，标志着2026年首个央企集团层面重组落槌。
02 宏观与政策
- 国家发展改革委：在已安排1亿元基础上，再追加1亿元中央预算内投资，支持广西应对台风灾后恢复。
- 国家发展改革委：紧急安排1亿元中央预算内投资，支持浙江开展台风“巴威”灾后应急恢复。
- 国家防灾减灾救灾委员会：针对台风“巴威”影响，启动国家四级救灾应急响应，并派出工作组赴浙江指导救助。
- 水利部：针对受台风“巴威”影响的江苏、安徽、江西、山东四省，于7月12日10时启动洪水防御Ⅳ级应急响应。
- 应急管理部：会同国家粮食和物资储备局，向浙江、天津、安徽调拨折叠床、被褥等共7万件中央救灾物资。
- 国务院常务会议：研究新兴支柱产业培育工作，要求全链条推动规模化发展，加强基础研究和关键软硬件攻关，引导各地因地制宜、错位发展。
- 国家信息中心：高频数据显示，2026年上半年我国经济稳中有进，人工智能、人形机器人等领域投资热度攀升，战略性新兴产业创新活力显现。
- 国家医保局：加快推进长期护理保险制度，17个省份已出台实施方案，参保覆盖达3.2亿人，全国长期照护师持证人员突破5万人。
03 环球视野
- 美军中央司令部：本周第三轮打击瞄准约140个伊朗军事目标，包括导弹发射阵地、海军设施及通信网络，旨在削弱其干扰霍尔木兹海峡通行的能力。
- 伊朗革命卫队：对中东多处美军军事设施发动报复性打击，冲突波及霍尔木兹海峡航行权，市场担忧此举或推高全球油价及通胀压力。
- 英国海上贸易行动办公室：一艘集装箱船在霍尔木兹海峡附近遭袭受损起火，船员弃船，事件疑与伊朗警告射击有关。
- 约旦政府：三枚伊朗导弹落入其境内，未造成人员伤亡；约旦武装部队已处于最高戒备状态。
- 卡塔尔内政部：因伊朗袭击启动安全与民防应急预案，弹片坠落造成3人受伤，含一名儿童。
- 美国总统特朗普：要求官员研究澳大利亚规模达3.1万亿美元的私人养老金体系，计划将其作为美国养老改革的参考范本。
- 央视新闻：乌克兰总统泽连斯基宣布启动内阁改组，提议总理斯维里坚科卸任并调任新岗位，本届内阁将随之整体解散。
- 英国《银行家》：2026年全球银行1000强榜单出炉，中资银行包揽前四，共22家进入百强，邮储银行首次跻身十强。
04 A股与港股
- 证券时报：A股上市券商2026年中期业绩预告密集披露，已有10家预喜，中信证券、国泰海通等头部券商上半年业绩创历史新高，投行与财富管理成第二增长曲线。
- 洛阳钼业：预计上半年归母净利润155亿至165亿元，同比增长78.76%至90.29%，主因铜产品量价齐升及巴西金矿业务并表。
- 杉杉股份：预计上半年净利润7.5亿至9亿元，同比增长262%至334%。
- 宁波富邦：预计上半年净利润5000万至6000万元，同比增长416.54%至519.85%，核心业务已全面转向电接触材料。
- 港股IPO：上半年84家新股合计募资2104.91亿港元，其中24家A+H上市企业以不足三成数量拿走近六成融资份额。
- 恒久退：公司股票进入退市整理期已满15个交易日，7月13日为最后交易日，将于7月14日被深交所摘牌并终止上市。
- 摩根大通：于7月7日增持快手-W约3076.03万股，每股均价约41.57港元，持股比例升至6.34%。
- 下周预告：7月15日国家统计局将公布6月工业增加值等数据；7月16日长鑫科技启动募资295亿元的IPO项目。
05 产业与公司
- 特斯拉：已下达Optimus人形机器人零部件采购指引，要求9月前实现周产1000台，年底前达周产2000至2500台。
- 智谱：创始人唐杰发布内部信，启动“Touch High”战略，未来两年将战略性投入冲击AGI底层技术，不追求短期变现。
- MiniMax：创始人闫俊杰发布内部信，宣布即日起至AGI实现前不再领取任何薪酬，展现“All in”决心。
- 鼎龙股份：上半年预计营收19.25亿元，同比增长约11%；归母净利润5.1亿至5.4亿元，同比增长63.96%至73.61%，半导体材料板块景气上行。
- 多氟多：预计上半年盈利4.5亿至5.6亿元，同比大幅增长776.68%至990.98%，受益于储能市场及六氟磷酸锂产品量价齐升。
- 巨力索具：发布澄清公告，否认“国内唯一网系回收索具供应商”及“与航天科技集团签超20亿元订单”等不实传闻。
- 大庸古城：耗资24亿元打造的文旅综合体由张家界、电广传媒、芒果超媒联合重启，7月10日举行开城仪式。
- 一周并购：本周18家A股公司披露并购重组进展，烽火通信拟以5亿元收购藤仓烽火60%股权；吉利与格力签署战略合作协议。
06 商业风向标
- 燃气轮机需求激增：受AI数据中心建设驱动，过去三年燃气轮机价格累计上涨约300%，GE Vernova股价过去六个月涨超70%。
- 2026世界人工智能大会：将于7月17-20日在上海举行，将展出华为Atlas 950超节点、MiniMax M3多模态大模型等前沿成果。
- 国际低空经济博览会：将于7月22-25日在上海举办，航空工业、亿航智能等企业参展，多家eVTOL真机将首发首秀。
- 电影《功夫女足》：周星驰导演新片上映2天票房破4亿元，预测总票房涨至18.65亿元，但豆瓣开分6.6，口碑两极分化。
- 离境退税2.0：“全流程无纸化”与“小额抽检制”7月1日实施后，有效提升外国游客购物体验，入境旅游流量正加速转化为消费增量。
07 投资与观察
- 全市场ETF：7月6日-10日规模增加890亿元，总规模回升至4.76万亿元，科创50及半导体主题产品持续吸金。
- 华安证券：认为市场短期调整基本到位，长鑫存储7月16日开启申购引发部分资金抢跑，调整幅度已与历史可比情形相当。
- 机构策略：业内分析认为，A股科技板块短期交易拥挤，市场正进入风格均衡化阶段，建议把握“科技轮动+防御配置”策略。
- 圆信永丰基金：AI算力需求扩大存储芯片景气度，看好国内半导体设备和材料国产替代，中期收入增长空间大。
- 中信证券：港股未平仓卖空比例仍处高位，预计未来有较大回落空间，短期建议关注创新药、航空、机器人和强工业属性金属板块。
- 兴证策略：积极信号正在积累，市场拥挤度指标已处底部区间，AI产业展现出明确的商业化兑现与增长势头，可密切关注科技龙头业绩等验证信号。
