# 从百年煤城到中国新能源电池名城，一座资源型城市的新能源突围答卷

编前：在“双碳”目标与新质生产力发展背景下，锂电产业成为城市高质量转型、制造企业全球竞争的重要赛道。枣庄市聚焦资源型城市转型发展，深耕锂电领域二十余年，建成完整锂电产业集群，相关产业布局被纳入山东省“十五五”新型电池制造重点规划；欣旺达落子枣庄打造北方核心智造基地，政企携手探索出一条特色产业发展之路。
近日，中国能源汽车传播集团党委书记、董事长、总编辑兼《中国汽车报》社社长、《中国能源报》总编辑谢戎彬，与枣庄市委书记翟军、欣旺达集团创始人王明旺开展深度对话，以政企双视角互为印证，梳理枣庄市锂电发展实践、政企协同模式，为各地新能源产业集群建设提供参考。
对话嘉宾
谢戎彬：中国能源汽车传播集团党委书记、董事长、总编辑兼《中国汽车报》社社长、《中国能源报》总编辑（左）
翟军：山东省枣庄市市委书记（右）
王明旺：欣旺达集团创始人（中）
转型底色——枣庄锂电基底与欣旺达落户逻辑
谢戎彬：枣庄从煤城转型为中国新能源电池名城的实践备受行业关注。请介绍一下当前枣庄新能源产业的发展情况。在打造新能源产业集群、构筑新能源产业生态方面，枣庄有哪些得天独厚的优势？
翟军：近年来，枣庄锚定“资源型城市绿色低碳转型发展引领市”定位，实施“强工兴产、转型发展”战略，将新能源产业作为产业能级跃升的头号工程，招引欣旺达、中创新航等30余家行业龙头骨干企业落地，形成覆盖正负极、电解液、溶剂、隔膜、检测检验、终端应用、拆解回收的完整产业链。2025年全市新能源上下游企业达到280家，锂电池出口额占全省总额近2成，全市新能源及储能装机历史性超过煤电装机，成功实现从“百年煤城”到“中国新能源电池名城”的华丽蝶变。
枣庄拥有四大独特优势。一是产业先发基础扎实，拥有140余年工业积淀，2003年即布局锂电产业，培育出全国首家磷酸铁锂电池出口企业和首个登陆央视的锂电自行车本土品牌，产业链完整度位居北方前列；二是区位交通优势突出，枣庄地处苏鲁豫皖四省交界，高铁、高速、运河贯通，翼云机场即将建成投运，多式联运降低物流成本；三是政策保障体系完备，在全国率先出台锂电产业专项法规《枣庄市锂电产业发展促进条例》，推行“链长制”，形成法规、规划、政策多层保障体系；四是省级战略高位加持，山东省“十五五”规划明确提出“要发展壮大新兴产业，培育壮大枣庄等新型电池制造基地”，把“枣庄打造新能源电池名城”列入区域能源发展样板，将欣旺达二期、中创新航基地两大项目列入省级重点工程，省领导多次现场调研指导。
▲中国能源汽车传播集团党委书记、董事长、总编辑兼《中国汽车报》社社长、《中国能源报》总编辑谢戎彬
谢戎彬：对“产学研企”等产业链上下游各环节的参与者而言，枣庄最大的吸引力是什么？如何推动政企双方战略同频、协同发力？
翟军：枣庄对产业链参与者的吸引力体现在四点。一是全链条配套成本优势，“上下楼就是上下游、左右邻就是产业链”，可大幅降低企业协作成本；二是法治与政策双重保障，长期扶持政策持续落地；三是丰富的应用场景，传统能源转型升级及丰富的风光资源提供广阔试验空间；四是完备的要素支撑，2025年盘活闲置厂房23万平方米，引导金融机构开发“锂想贷”等系列产品，全市8所技工院校中有6所已开设新能源相关专业，实现“招生即招工，入校即入企”。
另外，枣庄建立“链长+链主”双牵引机制，实施项目专班全流程服务，制定精准招商措施，深化为企服务。例如，通过举办产业链供需对接活动，推动64家新能源企业建立市内供需合作关系，2025年合作金额近9亿元，实现了政企双方战略同频、协同发力。
谢戎彬：接下来聚焦企业视角，作为全球前十的动力电池企业，欣旺达选择落户枣庄是基于怎样的机缘？从选择、考察到最终落户的过程中，给您留下最深刻的经历是什么？站在企业角度，您认为，枣庄最能打动企业投资和落户的关键是什么？
王明旺：欣旺达落户枣庄，我们看重一件事——产业链的完整。也是我们战略布局与枣庄城市发展高度契合的双向选择。近年来，我们持续完善全国产业布局，重点深耕北方新能源市场，而枣庄深耕锂电产业二十余年，产业链基础扎实、产业定位清晰，与我们动力电池、储能全链条发展的战略规划高度匹配。同时，四省交界是加分项，配套客户，物流近，反应快区位可就近配套客户，有效压缩物流成本。
落地全程最深刻的感受是枣庄高效务实的专班服务，服务团队是真懂电池，从工厂布局能耗指标、到产线、产能，从用地、审批、员工配套全流程闭环跟进和落实。
基于三个方面的考虑，坚定了我们百亿级投资决心。一是枣庄拥有完整的锂电产业链，相关上、下游的配套企业，一链拉动；二是政府兑现承诺执行力强，签约后专人驻场，各类配套诉求快速解决；三是枣庄具备长期培育产业的战略定力，充分理解锂电重资产、长周期的行业特点，这份耐心是制造业最看重的软实力。目前，欣旺达在枣庄已形成从研发、制造到回收的全链条布局，成为欣旺达布局的核心战略支点。
谢戎彬：从企业视角来看，政企高效协同的关键是什么？
王明旺：欣旺达落地枣庄全过程就是政企协同的成果。枣庄布局锂电不是短期跟风，而是二十年持续深耕的长期战略，完整产业链是我们选择此地的核心前提。项目对接阶段，招商团队对锂电技术、产业链痛点的理解程度和专业响应速度超出预期；落地后服务团队闭环解决厂区配套、用工、能耗问题，招商承诺全部兑现。
这个过程中，我最深的感悟是，政府懂产业，企业才敢长期投资。枣庄吃透锂电上下游发展痛点，深知电池企业落地需要什么生态配套。这种“懂”，本身就是营商环境最硬的软实力。
赛道升维——枣庄顶层规划与欣旺达全球站位
谢戎彬：“十五五”时期，为实现山东省“要发展壮大新兴产业，培育壮大枣庄等新型电池制造基地”，将“枣庄打造新能源电池名城”的战略目标，枣庄市将从哪些方面持续发力？
▲山东省枣庄市市委书记翟军
翟军：“十五五”时期，我们将坚持“提质扩规并重、内育外引并举”，巩固壮大锂电产业链，前瞻布局固态电池、氢燃料电池等新赛道，构建“核心引领、多元布局、上下游协同、全链条融合”的产业发展生态，力争到2030年全市锂电池产能突破300GWh，营收突破1000亿元。
具体来看，一是优化新能源电池产业布局，依托欣旺达、中创新航两大龙头，引导各区（市）差异化发展新型电池、源网荷储云、储能控制系统；二是延链补链强链，绘制产业链全景图，抢占固态电池、氢燃料电池等行业新赛道，支持企业强化同新能源汽车、储能、消费电子等领域产业协同配套，提升供应链韧性；三是拓展新能源电池应用场景，扩大在可穿戴设备、新能源工程车辆、电动船舶、低空经济等场景的电池应用；四是推动新型储能多元发展，布局熔盐储能、抽水蓄能，推进“人工智能+新型储能”模式创新，拓展新型储能发展空间。
谢戎彬：翟书记从城市顶层维度，明确了枣庄未来五年延链、拓景、布局前沿赛道的完整举措。城市产业目标落地离不开龙头企业的支撑。当前国内锂电行业竞争加剧，欣旺达如何找准自身定位？
王明旺：今年前4个月，全球动力电池装机量TOP10里，7家是中国企业。这一数字背后，不是规模扩张，而是国内锂电产业市场化竞争中，磨炼出的硬核竞争力。中国拥有全球最完整的锂电池产业链，从上游材料到下游应用，每个环节都充分竞争，倒逼技术迭代、成本优化、创新速度。
欣旺达1997年做消费电子电池起家，消费电子对电池的严苛要求，锻炼了我们在制造一致性、品质管控、供应链响应上的底层能力，这些能力后来平移到了动力电池、储能赛道。
欣旺达聚焦高价值细分赛道建立领先优势。HEV我们从2026年第一季度开始已经排名全球出货量第一，我们的15C极充在超充技术维度也是行业引领者。低空经济、智算中心储能这些新赛道，我们也在提前卡位。我们坚持差异化、价值化、全球化路线，深耕超快充、低温高性能及HEV混动电池赛道。锂电是长期马拉松，欣旺达追求的是在对的赛道上，做得足够深、足够稳、足够久。
谢戎彬：基于欣旺达在枣庄锂电产业集群中的核心地位，枣庄市对欣旺达助力城市转型有着怎样的期许？
翟军：欣旺达是枣庄新能源电池产业的核心链主企业，带动了多家配套企业同步落户，成为枣庄锂电产业高质量发展的强力引擎。
对于欣旺达，我们有三点期许。一是希望欣旺达持续扩大产能规模，将枣庄基地打造成为其在北方地区乃至全国、全球范围的核心制造支点。枣庄市将充分发挥“链长制”和重点项目全生命周期管理服务机制的作用，在土地供应、能耗指标等关键要素上实行“顶格协调、提级办理”，确保企业扩产需求得到优先满足。
二是希望欣旺达优先落地新技术新设备，在枣庄基地率先导入国际领先的自动化生产线、数字化管理系统和智能化检测设备，围绕高安全、长寿命、低成本等指标开展攻关。枣庄市将全力支持企业建设技术创新中心和重点实验室。
三是希望欣旺达加强产学研深度融合，开放更多生产场景、技术工艺，联动枣庄学院、枣庄职业学院以及各类省级以上创新平台，共建实验室，设立定向培养班，实施“工程师+工匠”双元育人计划等方式，地方人民政府将扮演“撮合者”和“服务者”的角色，完善产教融合激励机制，开展关键共性技术协同攻关。
谢戎彬：欣旺达承载着枣庄市的深深期许。那么，欣旺达枣庄基地的具体布局、未来发展规划如何？该基地在集团全球产业版图中承担着怎样的核心战略定位？
▲欣旺达集团创始人王明旺
王明旺：我们在枣庄的高新区落地山东欣旺达基地，周边集聚十余户上下游配套企业，实现电芯制造、PACK集成、光储充应用、废旧电池再生闭环发展，形成隔墙配套、就近协同的产业生态。
未来规划分三步走。一是推进百亿级扩建项目投产，打造行业智能化灯塔工厂；二是扩容大容量储能专用产线，承接电网级、工商业级的储能订单；三是完善锂电循环产业，落地固态电池产线，打通“生产—应用—梯次回收”的绿色产业链，同步依托产业基金吸引上下游集聚，打造北方锂电产业高地。
欣旺达覆盖消费、动力、储能三大场景，消费电池以华南基地为核心，枣庄聚焦动力、储能双高增长赛道，承接北方整车与全球储能市场需求，补齐集团北方大型产能缺口，枣庄基地已成为北方核心智造枢纽、超快充与储能技术量产主阵地、华北整车配套核心供应基地。南北产能互补、国内海外市场联动的全球制造格局，是支撑欣旺达动力、储能业务规模化扩张、完善全国产业版图的战略支点。
创新赋能——全域强链与龙头品质实践
谢戎彬：创新是锂电产业核心竞争力。在打造新能源及动力电池产业创新链，营造良好创新氛围层面，枣庄做了一系列卓有成效的工作，包括国家锂电池产品质量检测检验中心落户枣庄，并先后搭建新能源创新平台184个。未来，在持续挖掘企业及产业链创新活力、充分发挥集群优势、持续优化营商环境等方面，将开展哪些重点工作？
翟军：枣庄将从三个方面持续发力。一是持续挖掘创新活力。充分发挥山东科技大市场枣庄分市场、山东省锂电产业创新创业共同体等平台作用，引导支持链主企业发挥头雁作用，积极创建制造业创新中心、重点实验室、企业技术中心等高水平创新平台。大力推动企业技改升级，落实技改补贴等惠企政策，鼓励企业加大技改投入，建设智能工厂、数字化车间，全面提升企业生产效率、产品质量和数字化、智能化水平。
二是充分发挥集群优势。鼓励引导企业深化产学研协同创新，加强与国内重点高校院所合作，建强锂电产业学院与产教融合共同体，推行“订单式”人才培养、“科技副总”派驻模式，推动前沿技术成果在枣转化落地。建立“‘链主’企业出题、配套企业答题、政府搭台赋能”的融链固链机制，链主定期发布供需清单，带动中小企业同步技术升级，筑牢产业链安全底座。
三是进一步优化营商环境。牢固树立“服务企业就是服务发展大局”的理念，实行“一对一”帮包服务，推动政策直达快享、落地见效；执行“要素跟着项目走”机制，推动土地、能耗等核心要素资源，向符合条件的新能源企业和重点项目集聚；建立企业诉求台账，接诉即办、限时办结。
谢戎彬：产业创新落地离不开龙头企业自身的技术深耕与品质坚守。“用心做好每一块电池”是欣旺达长期坚守的企业信条，能否结合枣庄基地的实践，讲讲属于欣旺达的“枣庄故事”？
王明旺：“用心做好每一块电池”是欣旺达贯穿全产业链的底色，在枣庄基地已落地成看得见、摸得着的完整的实践场景。我们的基地已搭建了95%自动化智能产线，全流程数字孪生管控，从原材料入厂到成品出库，激光检测、X-RAY、在线CT实现无损筛查，AI系统实时站岗，严苛落实品控，坚守不良品零流出。
HEV赛道，我们靠的是“高功率+高可靠”的双轮驱动。2019年推出第一代HEV电芯后，累计装车超百万辆，在零下35度极寒环境也能冷启动。
超充技术上，我们从2019年开始布局，2022年量产全球首款4C闪充电池，去年推出的闪充4.0已实现15C极充、1分钟补能150公里，比加油还快。
储能赛道，我们同样精益求精，“长循环、不衰减”。自研长循环电芯落地园区光储充驿站，上万次循环稳定运行，服务工商业与电网储能的高能需求。
我们的用心，更延伸至全生命周期绿色闭环。去年竣工的滕州回收项目，年处理废旧锂电池能力达到10万吨，锂、镍、钴等有价金属回收率超过95%，真正实现了“从废料到新品”的循环。这不仅是欣旺达对环境的承诺，也是对客户、对社会的一份长期责任。从研发、智造、应用到回收，枣庄基地以精工制造践行长期主义，助力枣庄“中国新能源电池名城”建设。
