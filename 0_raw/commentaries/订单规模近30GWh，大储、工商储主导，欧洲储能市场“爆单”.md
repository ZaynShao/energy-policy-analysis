# 订单规模近30GWh，大储、工商储主导，欧洲储能市场“爆单”

![image](https://mmbiz.qpic.cn/mmbiz_png/bhqZZ4eZhIs6lCP0ES86cSlPbiavncM6vg6uhs6HfeV2JiclxbeNqTVdwxibnaTsMjvIibmZQT7mBbwq4wnrcO9G04Lict7Edm427G31iajZib2VdI/640?wx_fmt=png&from=appmsg)

“今年欧洲市场的争夺肯定会更加激烈，越来越多的企业都在加大欧洲市场的拓展步伐。”一家已经在欧洲储能市场深耕数年的系统集成企业海外销售总监告诉高工储能，在三月的罗马尼亚、波兰和意大利三大储能展会上，国内有代表性的储能企业都有参展，尤其是波兰和意大利展，参展的中国储能企业更多。

这一方面展示出欧洲市场对于中国储能企业的强大吸引力，更从另一个侧面说明了欧洲储能在2026年依旧延续了过去一年的高增长态势。

这一点从今年开年以来多家国内头部储能企业爆出的订单信息也可见一斑。

天合储能2026年欧洲区域签约订单突破6GWh，更值得关注的是天合储能在欧洲市场项目布局已覆盖英国、德国、意大利、西班牙、葡萄牙、波兰、罗马尼亚、比利时及希腊等十余个国家。

瑞浦兰钧在意大利国际可再生能源展与7家欧洲合作伙伴签署供货协议，未来2年内将交付共计8.3GWh储能系统。

更值得注意的是，与此前两年不同，在户储依旧保持增长的情况下，2026年欧洲储能市场的订单更多是大储项目和工商储项目。

“今年欧洲户储还会继续增长，但大概率大储和工商储的增长都是倍数级的。”前述的储能企业海外销售总监表示，大储和工商储是今年重点投入资源的领域，目前已经有多个项目在洽谈中，有个别项目已经基本敲定。  
  

******欧洲储能市场“爆单”******  
  

  

2026年开年以来，中国储能企业海外市场订单全面爆发，在这其中，欧洲市场依然占据着主导位置。

此前的2月2日，英国投资管理公司施罗德的能源转型投资平台施罗德Greencoat与宁德时代、香港私募基金Lochpine Capital更是达成了容量高达10GWh的储能合作。

阳光电源在3月也与瑞士公用事业级储能开发商Delta Capacity签署1GWh框架协议，为其欧洲电网侧项目提供PowerTitan 2.0液冷储能系统。

据高工储能不完全统计，2026年以来，中国储能企业在欧洲市场签订订单数量超过15个，订单规模更是接近了30GWh，在全球市场订单中位居出海目的地首位。

3月11日，海博思创宣布在欧洲多个区域斩获关键订单，订单总规模超4GWh。同时海博思创在欧洲的业务版图更是拓展至15个国家。

海博思创方面表示，在欧洲储能市场，海博思创已取得一系列重要突破，以硬核技术产品与全栈式服务能力，持续赋能欧洲构建绿色、韧性的能源体系。

“在能源安全与电力系统灵活性需求双重驱动下，欧洲储能市场正进入新一轮发展阶段。”天合储能方面统计称，目前天合储能2026年在欧洲区域的签约订单规模已超过6GWh，较此前预期明显提升，2026年欧洲市场出货占比预计将进一步提高。

事实上，欧洲市场近几年来一直保持着高速的增长，此前的2023年，欧洲户储市场大爆发，虽然此后的两年欧洲户储市场增速开始变慢，但依旧保持着一定的增长。

2025年末，欧洲户储市场已经开始明显升温。虽然德国户储市场已然放缓增长脚步，但荷兰、波兰、英国等国家都从政策层面推动户储装机。

荷兰取消净计量政策后，存量光伏用户被迫增配储能，预计将带来20GWh以上的增量；匈牙利推出1000亿福林户储补贴，覆盖每户超80%投资成本，波兰则计划拨款5亿兹罗提延续“我的电力”补贴，进一步降低居民安装门槛。

英国则从政策层面强制推动，2026年起明确要求新建建筑必须配置光伏，同步推出150亿英镑“温暖家园计划”，推动光储热泵协同发展，有望带动300万户家庭新增光伏，对应24GWh户储增量，成为欧洲市场的新增长引擎。

在欧洲户储市场升温的同时，大储和工商储市场更被国内一众储能企业视为今年欧洲市场的关键之战。  
  

******“激战”欧洲大储、工商储******  
  

  
****

近期，中东局势的波动引发了全球对于能源安全的重新审视，欧洲天然气价格应声上涨，也让储能作为“预备能源”的价值愈发凸显。

“欧洲趋于国家众多，普遍电网条件不佳，再加上近几年风电光伏装机量的不断上涨，对于大储和工商储的需求是巨大的。”有熟悉欧洲储能市场的系统集成企业负责人告诉高工储能，去年以来，欧洲很多国家还出台了相关政策来推动大储工商储相关并网审批和补贴。

这也意味着，不管是从政策端还是需求端，欧洲大储和工商储市场的爆发依然箭在弦上。

天合储能方面就表示，欧洲储能项目商业模式相对成熟、收益结构稳定。随着市场需求持续增长与项目储备不断扩大，该区域正逐步成为公司储能业务的重要增长引擎。

有市场分析认为，除了政策方面的推动，欧洲大储和工商储市场的爆发背后一方面是可再生能源发电占比的不断提升，另一方面则是欧洲各国老旧电网设备应对灵活性调度下自身对储能的需求。

锦浪科技董秘张婵表示，对公司而言，欧洲仍是海外第一大市场，新兴市场主要以东南亚、非洲地区为主。从目前市场态势来看，欧洲市场在公司海外业务中的占比预计还会进一步提升。

锦浪科技方面预计，2026年其工商储出口欧洲地区占比约50%，西欧、北欧、东欧为核心主力市场。

泽塔电源也看好2026年工商储在欧洲市场的增长。泽塔电源董事长涂继军告诉高工储能，目前泽塔电源工商业储能主要深耕于北欧等市场。

在大储方面，包括欧盟、英国和此前大停电的西班牙都颁布了相关法令推动大储的进一步渗透。

欧盟在2025年提出到2030年实现储能装机从**当前61GWh跃升至500-780GWh的雄心目标，**实现10倍增长，以配合其45%的可再生能源占比，保障电网稳定和灵活调度。

西班牙则发布《皇家法令法7/2025》，**将储能项目纳入“紧急审批”绿色通道**，消除并网风险，还将向电网送电的储能设备纳入电力基础设施，与发电厂、输电网等传统电力基础设施并列，为储能项目的落地和运营提供了极大便利。

英国也发布《清洁能源2030行动计划》，**计划到2030年将电池储能容量提升至23 - 27GW，并建立4 - 6GW的长时储能系统**。

而随着欧洲储能市场尤其是大储和工商储市场的倍数级增长，国内储能企业也加快了在欧洲的产能部署。

近日，外媒消息称海辰储能正在规划在西班牙北部的纳瓦拉建设电池和储能系统制造厂，初期投资约4亿欧元（约32亿元人民币）。

阳光电源也在2月宣布将在波兰投建首座欧洲制造工厂，规划年产20GW光伏逆变器及12.5GWh储能系统，旨在缩短交货周期、强化本地服务能力。

此外，包括宁德时代、国轩高科、亿纬锂能等企业都已在欧洲部署了储能电池和系统产能。

高工储能调研的多家头部储能企业都表示，看好2026年欧洲大储和工商储市场的大爆发，而中国储能企业有望凭借产能技术和供应链服务优势在欧洲市场占据更多的市场份额。
