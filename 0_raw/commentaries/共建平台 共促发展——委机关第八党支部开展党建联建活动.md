# 共建平台 共促发展——委机关第八党支部开展党建联建活动

为深入学习贯彻习近平新时代中国特色社会主义思想，落实基层党建提质增效工作要求，推动党建与业务深度融合，7月3日，杭州市发展改革委机关第八党支部联合南京银行杭州分行第二党支部和营业部党支部，赴临平区运河街道新宇村开展“双碳”之鑫党建联建活动。
大家沿着习近平总书记的足迹，实地调研“李伯伯家庭农场”，深入了解新宇村发展历史与生态效益、农业发展成效，深刻领悟总书记“三农”情怀。
循迹溯源后，三方支部集中开展座谈交流。大家围绕绿色金融、生态发展，热烈探讨资源共享、优势互补合作路径，致力为杭州“碳中和、碳达峰”作出积极贡献。会上，全体党员干部重温入党誓词，进一步坚定理想信念。
为深化党建合作，三方共同签署了党建联建协议书，进一步夯实共建平台，巩固共建机制，着力打造党建联建特色品牌。
活动还邀请了中共杭州市委党校毕钰洁讲师讲授专题党课，为党员干部开展思想教育，指导大家提高党性修养、提升履职能力。
