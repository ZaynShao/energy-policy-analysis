# 国产电动挖掘机，全球下单！

目前，我国已成为全球工程机械第一产销大国。越来越多电动化、智能化产品和整体解决方案加快走向海外。
目前，我国已成为全球工程机械第一产销大国。今年上半年，我国工程机械出口金额同比增长21.7%，出口规模持续扩大。
越来越多电动化、智能化产品和整体解决方案加快走向海外。
在柳工挖掘机智慧工厂，一批电动挖掘机正在加紧生产，即将发往海外矿山。相比燃油设备，这些电动工程机械能耗仅为三分之一。今年前7个月，工厂单月下线挖掘机同比增长超40%，产品已远销170多个国家和地区。智能化、绿色化正成为中国工程机械拓展海外市场的新优势。
产品加快走出去的同时，中国企业的技术和生产能力也在加快出海。在印度尼西亚卡拉旺，一家工程机械企业将自主研发的工业软件和大数据算法用于当地工厂，提前发现设备异常，减少停机时间。
三一重工印尼公司制造总经理丁世锋介绍，以前更多是出口产品，现在输出的是技术、质量体系、完整的供应链，以及数字化解决方案。在未来，要让更多中国自主研发的软件技术和人工智能技术在当地落地应用。
数据显示，2020年至2025年，我国工程机械行业出口规模实现近3倍增长。今年上半年，出口金额达到343.73亿美元，同比增长21.7%；其中，对欧盟、东盟出口分别增长28.9%和23.6%。出口规模扩大的同时，企业交付的也不再只是单台设备，适配不同市场需求的绿色方案、数字技术和持续服务，正在成为中国工程机械开拓全球市场的新优势。
