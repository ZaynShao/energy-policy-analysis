# 通知 | 关于举办“一起益企·小微你好”暨杭州市工程类职称评定政策解读活动的通知

各有关企业：
为深入贯彻落实"一起益企·小微你好"中小企业服务行动部署，紧扣中小企业在落实政策、引育人才、数智化转型等方面的痛点难点，帮助企业专业技术人员准确理解各级工程师职称申报政策、流程及评审要求，经研究决定开展本次职称评定政策解读活动，现将有关事项通知如下：
一、组织单位
指导单位：杭州市经济和信息化局（杭州市数字经济局）
主办单位：杭州市工业和信息化服务中心（杭州市中小企业服务中心）、浙江省物联网产业协会
二、时间地点
时间：2026年8月11日（星期二）14：30半天
地点：杭州市华辰银座酒店4楼华鸿B厅（杭州市上城区新塘路342号）
三、活动议程
1.中级工程师申报实操讲解（杭州市经信局职改办）；
2.物联网专业申报总体安排、申报条件、评审条件及量化赋分标准深度解析（浙江省物联网产业协会）；
3.物联网安装调试员职业技能等级证书申报指南（浙江省物联网产业协会）；
4.全体参会人员交流答疑。
四、参加人员
1.拟申报中、高级职称的在职在岗专业技术人员；
2.各企业单位人力资源（职称）管理部门负责人或经办人等。
五、其他事项
请于8月10日17：00之前扫描下方二维码进行报名（详见附件），未尽事宜，请联系杭州市工信服务中心陈老师，联系电话：0571-87292011,；浙江省物联网协会罗老师，孙老师，电话：0571-88366896。
