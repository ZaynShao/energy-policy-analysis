# 智库建设｜扎根市场破题解局 弄潮特区谋远献策——专访综研院院长刘国宏

# 编者按
社会智库是中国特色新型智库的组成部分。改革开放以来，我国社会智库发展步伐加快，在咨政建言、理论研究、社会服务、人才储备、国际交流等方面发挥着积极作用。作为国内外知名的社会智库，综合开发研究院（中国·深圳）（简称综研院）始终心怀“国之大者”，以服务党中央决策与改革开放大局为安身立命之本，通过政策咨询、第三方评估、公共传播等多元方式，畅通民意、凝聚共识、服务社会，探索出一条市场化、社会化的智库发展之路。
2015年，综研院入选首批国家高端智库建设试点单位。为深入研究社会智库的建设运营规律，近日《新华智库研究》专访综研院院长刘国宏，解码社会智库在服务党和政府科学民主依法决策、推进国家治理体系和治理能力现代化、提升国家软实力等方面的积极作用，为新型智库建设提供更多参考借鉴。
刘国宏
综合开发研究院（中国·深圳）
院长
《新华智库研究》：综研院是我国创办较早的公共政策研究咨询机构，请介绍综研院的核心定位与发展沿革。
刘国宏：综研院于1989年2月14日在深圳正式成立，以“立足深圳、面向全国、走向世界”为办院方针，实行理事会领导的体制，聚集综合性专家队伍，广揽海内外学者精英，为经济社会发展提供研究咨询服务。综研院创办伊始，以社团性质登记注册、民间机构运作。1993年1月，纳入深圳市差额拨款事业单位，实行属地化管理。1993年至2015年，综研院进行新型智库发展探索，管理体制与运行机制不断完善。同时，在制度改革、对外开放、区域经济、产业政策、深港合作、企业管理等领域，承接完成大量课题研究与咨询任务，成为国内为数不多在社科研究领域拥有国家工程咨询甲级资质的单位，初步蹚出了一条市场化、社会化发展的新路子。
2015年12月，综研院作为社会智库入选首批国家高端智库建设试点单位，积极探索社会智库体制机制的改革创新，坚持和完善理事会领导制。实行国家高端智库首席专家制度、选题务虚会与学术评议制度，由研究人员在开放式务虚会上汇报选题方向，并作讨论交流；确定选题及立项后，由首席专家牵头学术审议小组审定，指定专人负责跟踪研究。同时，构建业务形势分析会制度，加强对市场化咨询项目的统筹协调。2019年，在国家高端智库建设试点工作3年综合评估当中，综研院被列为表现最好的一档。截至2025年底，综研院上报高端智库报告237篇，被采用50篇，高质量完成上级交办的研究任务和决策部门交办的课题190余项。
回顾过去30余年的发展历程，综研院始终牢记办院方针，坚守综合性、社会性、公共服务型的政策和咨询机构的核心定位。目前，综研院有理事20名，主要由专家学者、企业家和社会活动家组成。全院设4个职能部门、不同专业领域的12个研究所和12个研究中心；另设一个分院（前海分院），重点服务前海蛇口自贸片区发展；设有应用经济学博士后工作站；创办发行经济类学术期刊《开放导报》及《中国宏观经济月报》。综研院还是广东省习近平新时代中国特色社会主义思想研究中心研究基地、深圳市人文社科重点研究基地（开放型经济与大湾区研究中心），是南方重要的高层次人才和干部培养基地。2025年，综研院市场化咨询收入约占总收入83%；共有员工170余人，研究人员占比85%，硕士以上人员占比85%，海外留学回国人员占比25%左右，拥有30名注册咨询工程师及城乡规划师。
《新华智库研究》：综研院长期围绕公共政策开展研究咨询，近年来在服务国家决策方面开展了哪些工作？产出了哪些具有影响力的成果？
刘国宏：作为立足地方的社会智库，综研院在长期探索中形成研究与咨询并举的业务特色。
一是发挥长期积累和专业特色做好咨政研究。我院入选国家高端智库建设试点单位以来，高度重视国家高端智库建设各项工作，一批成果被决策机关采用，为党和国家了解情况、研判形势、科学决策提供了参考。此外，我院还承接地方政府政策咨询课题。围绕粤港澳大湾区建设，以及深圳、港澳、广东其他地区和山东、福建、四川、广西、江西、新疆、内蒙古等区域经济社会发展，开展五年规划编制、新质生产力发展、产业政策研究、区域协调发展、国资国企改革、招商引资合作等领域课题研究，服务地方公共政策供给，赋能政府民生服务优化。
二是高质量完成中央交办的各类研究任务。高质量完成领导机关交办的系列研究课题，成果得到决策部门的肯定。首席专家樊纲2016年、2020年先后参加经济形势专家座谈会和经济社会领域专家座谈会，就宏观经济形势、“十四五”规划编制等提出意见和建议。
三是开展服务高水平对外开放的政策咨询。聚焦开发开放和区域协调合作，承担商务部等有关部委和部分地方关于边境经济合作区、跨境经济合作区、自贸试验区等研究工作。比如，承担西藏、云南、新疆、内蒙古等地的边境经济合作区和跨境合作区的一批规划课题，深度参与了新疆自贸试验区、内蒙古自贸试验区的申建政策咨询工作。
《新华智库研究》：近年来，综研院在理论创新与研究方法探索方面，开展了哪些主要工作？有哪些典型成果？
刘国宏：综研院充分发挥社会智库市场化与开放性优势，以深圳以及我国改革开放的鲜活经验为理论源泉，以解决现实问题和满足决策需求为出发点，积极探索跨学科、跨领域、跨国界的调查研究，以咨政研究和咨询实践推动理论创新，以理论创新指导咨政研究和咨询实践，既要做“Think Tank”，也要做“Do Tank”，以科学精神、多方共识服务科学民主决策。比如，在长期服务区域开发开放中，综研院形成了“123”规划体系，即基于“1套政策法规+产业与空间2大规划+开发模式、投融资、招商运营3个报告”的系统方法论，服务工业园区、自贸片区、跨境经济合作区、东道国经济特区等开发开放咨询项目。此外，在长期服务国内城市金融中心建设和地方金融业发展实践中，形成了“钱才集聚论”“法市辐射论”等理论。2025年9月19日，在中国社科院举办的“第八届中国智库建设与评价高峰论坛”上，综研院“以市场化体制机制改革创新引领社会智库高质量发展”“推动全球金融中心指数（GFCI）国际联合研究”两项成果，获评中国特色新型智库建设十年回顾特色案例。
《新华智库研究》：舆论引导是国家高端智库的重要职责之一。综研院在国内外学术交流合作、讲好中国故事、增强智库国际话语权等方面开展了哪些工作？
刘国宏：综研院紧密结合自身研究方向、区位资源，发挥社会智库体制机制灵活优势，积极搭建民间桥梁，沟通全球智慧，持续强化“点对点”“片对片”的国际交流模式。
一是围绕重点地区开展经贸对话。选择发展规模相似、研究方向相近的国外智库及研究机构作为重点对接对象，持续合作开展国际交流，在服务国家外交方面发挥了社会智库的独特作用。如，与东南亚相关智库多次联合主办全球华人经济和科技峰会，会议已成为连接中国与东盟乃至全球华商的重要桥梁；以地方和次区域合作为切入点，与相关美国智库联合举办中美湾区对话会，就旧金山湾区、粤港澳大湾区经济发展、合作前景等议题开展交流；与部分欧洲智库重点开展针对共建“一带一路”和中欧投资关系的联合研究；与部分非洲智库多次开展经济特区与工业园区建设会议，将经济特区发展经验系统性地分享给非洲伙伴。
二是“走出去”与国外智库开展交流合作。从2016年开始，我院与英国智库Z/YEN集团联合发布全球金融中心指数（GFCI），至今已连续发布20余期，对促进我国金融中心建设、提升国际影响力发挥了重要作用，也为深化智库交流合作、争夺金融话语权，发出金融中心建设的“中国声音”提供了重要抓手。
三是发挥首席专家的国际影响力。我院首席专家樊纲多次接受国际媒体采访，受邀出席达沃斯世界经济论坛年会、博鳌亚洲论坛、文化强国建设高峰论坛等国际会议并发表演讲，解读中国经济发展的逻辑与成就。
四是抓重要节点做舆论引导。我院已构建通讯、内刊、月报、期刊、评价指数、研究报告、政策解读等面向社会大众的智库产品体系。在改革开放周年等重要时间节点，通过策划专题、出版著作，接受采访等形式总结经验，发布研究成果，凝聚社会共识，营造良好氛围。如2025年深圳经济特区建立45周年之际，我院出版《深圳逻辑》一书，引起较大的社会反响。
《新华智库研究》：综研院在社会服务方面开展了哪些工作？有哪些特点？
刘国宏：综研院坚持探索通过第三方评估咨询以及公益资助等方式，履行好智库社会服务的核心职能。
一是开展多类第三方评估工作。我院积极承接各级政府以及国有企业政策实施效果、公共服务满意度、重大项目建设评价等领域的第三方评估工作。如2024年我院承担国家发展改革委关于深圳综合配套改革的中期和终期评估工作，总结推广深圳综合配套改革经验。
二是“走出去”推广中国经验。自“一带一路”倡议提出以来，我院积极拓展国际业务，推广中国经济特区和产业园区发展经验，通过“走出去”承接共建国家和地区的相关咨询项目，先后在埃塞俄比亚、刚果共和国、巴基斯坦、肯尼亚、柬埔寨、智利、格鲁吉亚、亚美尼亚、哈萨克斯坦等国开展境外咨询。随着“一带一路”建设不断深入，我院还承担了中国—东盟产业合作区、中国—拉美地方经贸合作示范区等研究咨询项目。
三是持续开展公益资助探索。我院发起设立深圳市综研软科学发展基金会和深圳市马洪经济研究发展基金会，评选和颁发“中国软科学奖”，表彰在经济、法律和社会治理等领域中，具有前瞻性、创新性和重要实践应用与政策参考价值的优秀软科学研究成果。此外，搭建政产学研对话平台，资助公共政策研究、学术交流与公益智库活动，服务公共利益与社会发展。
《新华智库研究》：综研院在智库人才培养、团队建设、学术生态营造等方面有哪些经验？
刘国宏：综研院入选国家高端智库建设试点单位之后，坚持研究与咨询并举，以研究带咨询，以咨询促研究，实现二者有机统一。在此基础上，培养了一批以咨政服务为核心，兼具理论素养、政策视野、实践能力与传播能力的智库人才，致力于将研究成果转化为决策参考、发展方案和社会共识。
综研院积极探索智库人才留用和评价机制创新。一是建立有效的激励、奖励配套机制。根据研究工作的需要，引导有能力、有积累的研究人员组织成立新的研究部门，带出新团队、开辟新业务。同时在合法合规的前提下，赋予课题负责人一定的经费自主分配权，调动团队负责人和课题负责人的积极性、创造性。二是改革创新人才评价机制。探索多元人才评价体系，从政策研究能力、咨询市场接单能力、公共舆论影响力等维度探索对“智库人才”的全面系统评价。
《新华智库研究》：请介绍一下综研院推动机制和制度创新的主要情况。这些创新对综研院的发展发挥了哪些作用？对深化推进我国新型智库建设有哪些启示？
刘国宏：综研院坚持实体智库运作模式，长期以来重点培育锻炼兼具研究与咨询能力的智库人才队伍。
一是围绕提高服务决策能力，全面培养智库研究人才。把“国家全局性战略性问题研究”作为工作的重中之重，设立专项资金，鼓励研究人员进行理论研究和学术交流，出版专著，支持参加全国性和国际性的学术研讨会、论坛等，提升理论研究水平，扩展智库研究视野；深耕专业特长领域，重点打造特色优势团队，基于长期积累和发展比较优势，打造深圳经济特区发展、港澳经济发展、粤港澳大湾区建设、地方金融中心建设、境内特殊经济功能区与境外经贸合作区建设、全球产业链供应链发展、“一带一路”国际合作等特色领域的专业研究能力和专业研究团队。
二是充分发挥首席专家“头雁”引领带动作用。在首席专家带领和指导下，研究人员通过承担咨询课题，不断提高咨询的理论水平和政策水平。首席专家全程参与和把控研究报告的提纲思路、讨论修改等关键环节，确保高质量产出成果，同时提高团队的智库研究与写作水平。
三是务实高效利用和发挥“外脑”作用。充分发挥外聘专家的理论专长或贴近实践的优势，设立智库专家咨询委员会，对综研院重点研究方向提供咨询和意见，开展学术交流合作，提高研究咨询工作质量。研究团队可结合实际研究咨询工作需要，向院里推荐特聘专家人选；也可针对具体课题项目，聘请外部专家参与研究咨询。
《新华智库研究》：今年是“十五五”开局之年，“十五五”期间综研院在智库建设、研究方向、机制创新等方面有哪些规划？
刘国宏：“十五五”期间，综研院将抢抓战略机遇，直面风险挑战，推动核心竞争力提升和业务模式创新，奋力开创社会类国家高端智库高质量发展新局面。
一是强化使命担当。牢记国家高端智库使命，强化社会智库担当，围绕战略性、前瞻性问题，做好策论报告和课题研究，形成更多高质量成果，积极服务党和国家决策。聚焦“十五五”时期重大战略任务，特别是在复杂多变国际形势下的科技、产业、投资、消费以及粤港澳大湾区高质量发展等重大问题研究，擦亮综研院品牌。
二是加大市场开拓力度。采取全员营销策略，加大对重大课题、重大项目的统筹协调，做好品牌与公共关系管理，提升团队协作水平。积极对接地方政府及主要决策部门，建立常态化沟通机制，促进咨询业务特别是大项目的拓展。探索国际化业务空间和业务延伸方向。
三是构建数字能力。成立AI工作小组，统筹研判、及时跟踪AI发展趋势，谋划应对策略，务实推进数字工具应用，提升智库科研、传播与管理的智能化水平。择机整合内外部数字资源，推动AI技术赋能和服务模式创新的双向联动，构建全流程贯通、多场景协同、高效率运转的智库数字支撑体系，打造面向未来的技术领先型智库。
四是培养人才梯队。挖掘具有前瞻性、战略性视野的新一代智库领军人才，培育更多明星学者和明星研究人员。完善人才管理制度，做好青年人员的培养和梯队建设。创造更多舞台和条件，帮助年轻人拓宽认知广度，提高研究深度。
《新华智库研究》：习近平总书记近期就推动哲学社会科学高质量发展作出重要指示，要求努力开创哲学社会科学高质量发展新局面，为中国式现代化建设贡献更多智慧和力量。今年又是总书记在哲学社会科学工作座谈会上发表重要讲话十周年，请结合综研院探索实践，为“十五五”时期推进中国特色新型智库高质量发展提出思考建议。
刘国宏：一是坚持专业化深耕，锁定特色研究方向，持续培育专属研究团队，积累长期研究咨询经验与成果，构筑不可替代优势。二是建设雁阵化队伍，构建以领军人才为头雁的人才梯队，从根本上保障智库服务专业性、体系化和可持续。三是坚持实质大于形式，始终围绕智库服务决策核心功能，用好外部专业力量，以扎实调研成果彰显智库价值。四是建议政府有关部门进一步支持智库发展。引导各类智库参与各级政府重大决策，加大财政资助力度，支持探索AI赋能智库研究、政策咨询的新范式，加快培育具有重大影响力和示范引领作用的新型智库。五是进一步强化智库专家参与公共决策的角色定位。建议立法明确智库专家参与决策咨询和论证的情形，保障政府决策的前期论证、中期监督和后期评估等各个环节的专家参与权。在专家咨询过程中，提供充分的背景信息和相关数据，保障专家的知情权、话语权。同时，建立专家咨询意见采纳、反馈机制，并在一定范围内公开。
