# 区经信局组织召开全区“小升规”工作推进会

会上，区统计局工业统计科对工业“小升规”工作要求和注意事项进行专题辅导，各镇街平台就当前“小升规”培育企业、新建投产升规项目储备情况以及存在问题进行汇报交流。
针对下一步扎实做好工业“小升规”企业培育工作，会议提出三点要求：
一是科学把控工作节奏。要紧密跟踪培育企业和储备项目进展情况，紧盯重点产业项目，持续做好优质潜力企业摸排，着力提升培育企业项目能级。
二是高度重视月度升规。要落实专属“陪跑员”全程跟踪、上门辅导，针对生产经营过程中的问题诉求，提早介入、靠前服务，科学指导企业月度升规。
三是持续做好增量培育。一方面，要着力做好优质企业挖掘，精准服务优质骨干企业，高效承接内生裂变项目；另一方面，紧扣“296X”先进制造业集群建设部署，主动引进成长性好、带动性强的优质产业项目，坚持多点发力、分类培育，全力以赴挖掘“小升规”增量贡献。
下一步，区经信局将务实推进会议各项部署落地见效，以“小升规”培育工作为抓手，为全区工信经济高质量发展注入强劲动能。
