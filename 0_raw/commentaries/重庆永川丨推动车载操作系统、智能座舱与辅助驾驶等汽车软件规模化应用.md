# 重庆永川丨推动车载操作系统、智能座舱与辅助驾驶等汽车软件规模化应用

《征求意见》明确：
构建以汽车软件等为特色的行业应用软件产品矩阵，推动车载操作系统、智能座舱与辅助驾驶等汽车软件规模化应用。面向车联网等关键领域安全防护，发展车联网安全等领域信息安全防护软件。
紧盯智能网联新能源汽车等新质赛道，深化自动驾驶等领域研发服务能力建设。
大力招引检验检测机构和检验检测装备制造企业，重点发展新能源汽车等检验检测服务，推进智能检测装备产业高地建设。
扩大新能源物流车在城市配送、邮政快递等领域应用，完善新能源车辆充电、加氢等基础设施布局。
聚焦永川智能网联新能源汽车及零部件等产业，引导银行机构创新“链主企业+上下游”供应链金融模式。
鼓励制造企业、高校和设计机构等单位，组建新型工业设计研究院，承接智能网联新能源汽车等领域的核心技术装备与关键零部件的工业设计重大创新攻关项目。
推动传统语音呼叫向网联汽车等领域拓展。推动会展与智能网联汽车等产业联动、融合发展。
建立智能网联新能源汽车及零部件等重点产业人才需求机制。
积极布局自动驾驶测试、新能源汽车维修等新职业培训。对接国家职业技能等级标准，结合永川产业特色，开发汽车软件工程师、自动驾驶测试工程师等特色职业技能等级，建设考核评价站点。
