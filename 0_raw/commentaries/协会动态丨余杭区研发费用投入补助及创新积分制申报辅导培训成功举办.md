# 协会动态丨余杭区研发费用投入补助及创新积分制申报辅导培训成功举办

6月26日，余杭区研发费用投入补助及创新积分制申报辅导培训在人工智能小镇成功举办，帮助区内科创企业精准吃透创新积分制，规范研发费用归集，确保研发投入“应统尽统、应享尽享”。活动吸引了近140名科创企业负责人及财务人员参加。
活动伊始，省科技厅成果处陈国正围绕科技创新再贷款和“创新积分制”工作展开介绍。他深入阐释了科技金融工作的重要意义，并详细介绍了创新积分制的推荐标准、信息征集规范以及工作推进情况。招商银行杭州分行童恺同步补充解读创新积分制配套金融服务相关细则。
随后，余杭区科技局楼攀针对区级研发费用投入补助申报工作展开专项授课。他从申报主体资质、申报流程、材料准备等基础要求入手，完整演示申报系统实操流程，并梳理申报高频易错问题进行解答，指导企业规范完成申报工作。
思润会计师事务所陆锦垚围绕研发补助审计核查要点展开辅导。他结合2025年度最新审核标准，重点讲解审计资料准备要求、申报数据异常排查与整改方式、审计现场取证规范等核心内容，指导企业提前做好审查准备工作。
杭州昊博企业管理咨询有限公司章燕萍就企业研发费用归集与加计扣除合规展开分享。针对研发人员薪酬、研发设备折旧、委托外部研究开发费用等各类研发支出的归集范围、分摊方式、账务处理规范进行逐一讲解，确保企业研发费用归集真实、精准、合规。
培训尾声，参会企业结合自身经营、申报过程中遇到的疑难问题现场提问，授课老师逐一细致解答，现场学习交流氛围浓厚。
下一步，协会将持续聚焦辖区科创企业发展痛点与服务需求，持续搭建政企沟通、专业赋能平台，助力企业规范创新管理，实现高质量发展。
