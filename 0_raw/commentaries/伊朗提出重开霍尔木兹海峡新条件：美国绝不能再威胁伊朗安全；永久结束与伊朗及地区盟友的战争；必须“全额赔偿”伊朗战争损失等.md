# 伊朗提出重开霍尔木兹海峡新条件：美国绝不能再威胁伊朗安全；永久结束与伊朗及地区盟友的战争；必须“全额赔偿”伊朗战争损失等

伊朗外长阿拉格齐表示，霍尔木兹海峡重新开放还取决于其他条件。
伊朗外长阿拉格齐当地时间8月8日表示，伊朗与阿曼有关霍尔木兹海峡的协议“接近达成”，但这并不意味着霍尔木兹海峡重新开放，海峡的开放还取决于其他条件。
协议已接近达成
8月8日，阿拉格齐在德黑兰举行的一场新闻发布会上说：“与阿曼的谈判围绕一条临时航道展开，我们已经非常接近达成协议，但即使伊朗与阿曼敲定这条航道，也并不意味着霍尔木兹海峡将重新开放。海峡的开放还取决于其他条件，这包括美国违反谅解备忘录应作出赔偿。我必须明确说明，当前局势恶化正是美国违反该谅解备忘录所造成的后果。”
伊朗提出新条件
伊朗伊斯兰共和国广播电视台8日播出了伊朗最高国家安全委员会秘书穆罕默德·巴盖尔·佐勒加德尔发出的一则正式声明。声明向美国提出以下条件：
•美国绝不能再威胁伊朗的安全。
•永久结束与伊朗及其地区盟友的战争。
•必须解除对伊朗的海上封锁。
•必须从该地区撤军。
•必须“全额赔偿”伊朗的战争损失。
•全面解除对伊朗制裁。
•“无条件”解除伊朗被冻结的资产。
佐勒加德尔表示，霍尔木兹海峡的重开与伊朗同阿曼之间的谈判无关，而是取决于美国是否完全接受伊朗的条件。“一旦美国接受伊朗的条件，海峡必将重新开放。”
“现在是最佳时机”
当地时间8月8日，伊朗总统佩泽希齐扬表示，现在是与美国达成协议的“最佳时机”。佩泽希齐扬说：“当人们谈到何时能达成协议时，我认为现在就是最佳时机，因为现在伊朗团结一致，力量强大，而且我们是这场战争的胜利者。”
伊朗学生通讯社援引佩泽希齐扬的话报道说，伊朗方面认为美国“不可信赖”。不过，佩泽希齐扬同时表示，战争不可能一直持续下去，伊朗愿意在同美国达成的谅解备忘录的基础上继续寻求外交努力，但前提是美国不再破坏双方之间的信任。

双方仍在“博弈之中”
当地时间8月8日，美国副总统万斯在参与美国福克斯电视台一档直播节目连线时表示，美国和伊朗正处于“博弈之中”。他说：“我们现在正处于这场博弈的中期。这件事还没有结束，当然也不再是开始阶段了，我们正在运用一系列手段——外交、经济、军事手段——来确保我们为美国人民争取到最好的结果。”
