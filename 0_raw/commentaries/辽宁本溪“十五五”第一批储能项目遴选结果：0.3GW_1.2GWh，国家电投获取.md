# 辽宁本溪“十五五”第一批储能项目遴选结果：0.3GW/1.2GWh，国家电投获取

「
储能与电力市场
」
获
悉，
2026年6月26日，辽宁本溪市发改委发布本溪市“十五五”第一批新型储能项目遴选结果。
本溪本电新能源有限公司申报的
国家电投南芬区200MW/800MWh储能项目、国家电投本溪县100MW/400MWh储能项目
，为最终确定的入选项目。
根据文件，入选单位应立即按照要求办理投资决策文件、接网批复意见及土地手续等相关前置要件，并于8月31日前将关材料报送至市发展改革委。
看个广告休息一下
企查查显示，本溪本电新能源有限公司为国家电投集团100%控股的企业。
