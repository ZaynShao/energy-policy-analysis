# 上海丨围绕重点区域发展智能网联新能源汽车产业

《规划》明确：
提升全链条货源组织能力，为汽车配件、新能源汽车等出口提供稳定的跨境物流通道。
智能网联新能源汽车产业重点围绕嘉定汽车产业园区、张江高新区金山园、浦东金桥、临港等区域，发展完善零配件共享仓、售后备件仓、成品分拨中心、智能制造循环取货体系等。
金山亭卫工业物流园区重点服务智能出行和装备（新能源汽车）等产业。
支持新能源冷链车辆应用。
推动绿色运输装备迭代升级，重点推进港口集疏运换电重卡、城市末端配送新能源车的规模化应用，完善充换电桩等配套设施布局。
鼓励保险机构聚焦新能源物流车等领域，开发专业化、定制化保险产品。
探索试点无人车在城市配送、园区物流、医疗急救、应急保障等场景的商业化运营。
