# 派能科技8MWh储能系统亮相：基于601Ah电芯，聚焦4小时场景

![image](http://mmbiz.qpic.cn/mmbiz_gif/NKyhsaKovicKztoic7EG3v5AFw4MHpvajcPhBKeD3tELicseb6XCAM8X3orcFBZSQjZGZq1QyPiaUzdia7uTasrmDMA/640?wx_fmt=gif)

“储能项目的本质是投资项目。”派能科技张鹏博博士点破了当前大容量储能竞赛的核心逻辑。4月1日，派能科技在ESIE 2026展会上正式发布了基于601Ah大电芯的8MWh储能系统，从电芯到系统均由派能科技研发生产制造，剑指4小时长时场景。![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIsnmhoW7xqpF0q7ao72cNgrkcRkOC8uZ7D9AHAq72FHqLF5hbr6O11MDXJsoHwV8cpAl5DJSiah1ibNFq0yOKniao4jkb0Tzr2rS0/640?wx_fmt=png&from=appmsg)

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIuEaUfNWhjibvgP8DQ6D1zQmoiaghfgRW3113LUPCGPkvWwhrF8Cr8PIFfQjO8zCGqX1flKV63TsJKf0kXbZkKaK2tMakgvDery8/640?wx_fmt=png&from=appmsg)

派能科技张鹏博博士介绍，本次展会上派能科技带来的两款新电芯——588Ah和601Ah，分别面向2h和4h及以上时长场景。其中，601Ah大电芯能量密度达425.8Wh/L，循环寿命突破12000次，能效高达96.5%。该款电芯在能效、安全、寿命三个方面显著提升。在能效提升方面，通过在多功能粘结剂、改性石墨、电解液多组分协调、LFP动力学改性等方面进行材料技术革新重构高能效标准；在寿命提升方面，通过精确正负极匹配、负极膨胀抑制、界面自修复、梯度孔隙设计等体系平台创新，解锁超长电芯服役周期；在高安全性方面，通过产热抑制和可燃气体抑制核心技术进一步提高电池安全。张鹏博博士表示，基于601Ah电芯打造的PyOcean系列8MWh储能系统，是围绕“资产收益导向”进行设计，聚焦IRR、LCOE与现金流稳定性三大投资核心指标。以800MWh储能电站为例，8MWh储能系统在系统层面零件总数减少50%、占地降低38%、施工量减少10%，直接降低约10%的投资总额。PyOcean储能系统搭载了高精度SOX算法、全域均衡与MCDC簇间均衡等核心技术支撑运营期收益，具备15分钟精准预测可用功率、可放电量最高提升7%、系统真实D0D提升3%、日历寿命衰减降低5%、非均衡状态下投运，减少停机维护时间等优势，在度电收益增加、偏差考核偏差率下降、提升调频响应K值等方面提升储能项目运营周期收益。![image](https://mmbiz.qpic.cn/mmbiz_png/bhqZZ4eZhIueSntsDiaVKibAYlbCK7ZUajSoicmIajcU3K7U1RuxiagRerdBibYbKwMbVuCxqjON1k4R9FGYiaSD10SPQ7KVVdlA4EHH0ru4v8V10/640?wx_fmt=png&from=appmsg)

大容量储能电芯及系统解决方案的发布，正式宣告派能科技源网侧储能、独立储能的产品和市场应用进入高速发展的快车道。在发布会上，派能科技分享了多个不同场景项目落地情况，包括浙江台州3132kWh用户侧储能项目、浙江北麂岛10MWh海岛微电网项目、芜湖垃圾处理厂光储一体化项目、江苏华电仪征80MWh源网荷储项目，以及宁夏永宁200MW/400MWh独立储能项目，全面呈现了派能科技在海岛、工厂及源网侧等多场景的系统化应用能力。![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIuCia0KfU2MpJfMo1E79iaAmdEHNzwQnOrVdvVafA2iaHYXocliaS0LQ7zkAWTmBnJdDCUOpCsH80bG4N3YKoM6xaXnWH7hetsFQ6A/640?wx_fmt=png&from=appmsg)

宁夏永宁200MW/400MWh独立储能项目面向迅猛发展的大储市场，派能科技谋定而后动，举出了一张“我们不仅是电池供应商和系统集成商，也是储能全场景解决方案专家，更是您的储能资产价值伙伴。”定位清晰的身份证。
