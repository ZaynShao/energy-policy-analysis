# 韩国一化工冶炼厂发生火灾

韩国一化工冶炼厂发生火灾，政府提醒民众警惕有毒气体泄漏。
当地时间9日12时36分左右，位于韩国庆尚北道的一处化工冶炼厂发生火灾。韩国消防部门13时10分左右将火灾应对级别上调至“第二级”，目前正在全力进行灭火作业。
截至目前，暂无人员伤亡报告。当地政府已向居民发送紧急通知，提醒民众小心火灾造成冶炼厂内有毒气体泄漏。
