# 储能大电芯竞赛再提速，远景动力宜昌基地量产790Ah电芯

2026年7月15日，远景动力宜昌超级工厂正式举行投产仪式，首批搭载790Ah储能大电芯的产品发运德国。这标志着全球首个百GWh级储能全产业链基地进入实质运营阶段，也意味着储能大电芯的容量“锚点”正从500+Ah快速推升至700+Ah区间。公开信息显示，远景动力宜昌超级工厂分两期建设，一期40GWh电芯产能于2025年10月开建，用时不足一年即投产；二期规划60GWh电芯产能与60GWh储能系统产能，于2026年4月启动建设，全面达产后将形成覆盖电芯到系统的全链条高端供给能力。投产仪式上，远景动力中国区总裁赵卫军透露，宜昌工厂790Ah储能电芯超过50%产能已获得海外客户订单，实现“投产即交付、交付即出口”。这一方面反映海外市场对中国高质量储能产能的持续接纳，另一方面也表明本轮扩产建立在明确的市场需求之上。宜昌超级工厂此次量产的790Ah电芯，是当前全球最大方壳卷绕电芯，也是远景动力以系统思维定义电芯标准的旗舰成果。在此之前，业内普遍将587Ah视作卷绕工艺的容量瓶颈。 该款790Ah电芯体积能量密度突破440Wh/L，循环寿命超12,000次，电芯RTE高达96%。依托底层材料技术创新与全工序AI智能管控，远景动力有效破解大电芯安全与量产一致性难题，790Ah电芯已通过多项高风险测试，并获全球主流权威机构认证。相较于行业主流587Ah电芯，远景动力790Ah电芯能够大幅降低储能电站全生命周期度电成本，搭载该款电芯的12.5MWh AI 储能系统，配合全新一代PCS、AI温控技术，系统能效超过92%；结合物理AI能力，可带动项目内部收益率（IRR）提升4%-8%，为客户创造全链路价值增值。远景储能产品总工程师徐中华此前告诉高工储能，在790Ah电芯研发过程中，采用系统全局包括材料、工艺、装备、电网友好、场站友好、国家标准等多个方面综合最优解来推演和验算得到。徐中华表示，行业普遍认为500+Ah是卷绕工艺极限，但远景通过三年以上系统性研发，从材料、工艺到装备、系统应用全链条验证，确认790Ah具备工程落地条件。结合自研上游装备创新，严苛测试与海外大规模交付实践，为这款全球最大卷绕电芯提供了技术可行性与市场信心。作为大容量电芯的首倡者，远景动力率先完成从300+Ah、500+Ah到700+Ah系列大电芯的迭代开发与规模化交付。回顾其技术迭代路径，从2021年最早量产300+Ah电芯，到2025年500+Ah电芯“量产即出海”，再到2026年的790Ah电芯规模化量产，远景动力在大容量电芯演进的关键节点上多次提前布局，成为较早实现定义与量产交付的参与者之一。其背后并非单一产品能力，而是围绕“电芯—系统—能源管理—全生命周期服务”构建的完整链条，使电芯设计能够与储能系统及实际应用场景形成协同。远景的大电芯产能扩张，基于明确的全球订单支撑，宜昌工厂790Ah储能电芯超过50%产能已获得海外客户订单。正如赵卫军所言，远景始终坚持发展高质量产能，以技术创新为核心、以全球市场需求为导向、以产业链协同为支撑、以绿色制造为基础，而宜昌基地是远景打造高质量产能、服务全球市场的又一重要布局。当前全球能源转型纵深推进，AI数据中心等新兴场景需求集中释放，新型储能产业迎来确定性增长。今年以来，远景在欧、非、北美、亚太等核心市场接连斩获重磅订单，覆盖储能电芯、系统集成、风光储氢一体化等多元场景。欧洲是远景2026年海外订单最密集的区域市场。7月，远景宣布先后与德国ju:niz Energy、全球独立电力生产商Elements Green及英国Pulse Clean Energy达成合作，项目总容量超2.1GWh。其中，与Elements Green合作的德国Stadorf项目（400MW/1600MWh）为该国当前最大单体储能项目。北美则是远景今年海外订单体量最大的区域市场。6月，远景斩获AIDC储能领域重要电芯订单，将在三年内向美国储能集成商Prevalon供应超过10GWh储能电芯及模组产品。5月，远景分别与加拿大Cape Breton China Corp及开发商Abraxas达成合作，涉及风储一体化及风储氢大型综合项目。在非洲市场，远景提供的新型电力系统方案助力埃及Obelisk项目（1.1GW光伏+100MW/200MWh储能）竣工，该项目为非洲最大光储混合电站。同期，远景还在南非、亚太、中亚等新兴区域斩获多笔实质性订单或合作协议。远景海外订单的持续增长，不仅源于790Ah电芯本身的技术领先，也来自其背后的全栈产品技术底座和系统能力。从电芯、PCS、系统集成、BMS到AI大模型赋能的智能调度平台，远景打通了“发电—储能—用电—调度”全链路，形成软硬一体的系统级解决方案。也正因如此，790Ah电芯并不是孤立的单一产品，而是远景储能系统能力中的关键底座；宜昌基地的投产，也不仅意味着大电芯产能释放，更意味着远景全栈能力在全球市场的进一步落地。这是其能够快速获得海外高端客户认可、实现“投产即交付”的重要原因。对比许多储能企业，远景还有一个重要的差异化竞争优势在于全球本地化能力。截至目前，远景已在中国、日本、美国、英国、法国及西班牙布局14大电池超级工厂，全球累计交付储能电芯超100GWh，参与储能项目超400个。欧美高端市场客户尤其重视本地化生产和项目可融资性，这放大了远景的先发优势。较早进入海外市场、积累大量交付案例、建立本地生产能力，使其在获取新订单时具备更低的信任成本和更高的品牌溢价。从行业整体来看，国务院印发的《“十五五”碳达峰行动方案》明确提出，2030年国内新型储能装机容量力争达3亿千瓦；叠加全球能源转型与AI数据中心等新兴场景需求释放，新型储能长期增长逻辑并未改变。不可忽视的是，产能升级正在加速行业分化。远景动力宜昌基地超50%大电芯产能提前被海外客户锁定，从一个侧面反映出当前市场竞争的关键变量：具备全球化交付能力、深度绑定终端需求、并拥有系统级解决方案的高质量产能，正在获得更强的市场确定性。
