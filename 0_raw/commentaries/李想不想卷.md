# 李想不想卷

理想L9要大换代了。

理想L9是对理想汽车极其重要的一款车——尽管理想ONE是开山之作，也是一炮打响，但在理想汽车员工眼中，理想L9是他们真正骄傲所在——不仅充分展现了团队的想法与才华，而且成为扛鼎之作，并且重塑SUV的审美，引发众多模仿者。

从2022年到2025年，理想L9热卖约25万辆。不过，最近两年，在诸多跟随者的追击下，理想L9的吸引力有所下降。

理想L9的状态，实在是理想汽车的写照。

全新一代理想L9将达到多高的高度，也将是理想汽车能反弹的高度。

2月6日，全新理想L9进入404批工信部公告公示，披露了一些核心信息；同一天，理想汽车创始人李想也在微博、B站亲自解读全新理想L9。理想汽车如何定义、如何操盘理想L9，也基本展示在行业面前——

升级是必然的：尺寸更大、纯电续航更长、能耗更低、算力更大……这都是理想的友商们的常用套路。

意外的是：绝没有一丝价格战的嫌疑，因为“终极版本理想L9 Livis”售价高达55.98万元”，比现在顶配理想L9，贵了12万。

李想说：  

“全新一代理想L9的进化不是去卷参数升级，而是创造体验代差，是打造一辆真正懂你的、有生命力的车。”

李想还说：

“全新理想L9，不仅是一台好车，更是具身智能机器人的开山之作。”

在如此之卷的中国汽车市场，“不卷”岂不是缴械投降？

在自动驾驶还未实现、辅助驾驶事故天天上头条的今天，“具身智能机器人”说的是不是太早了？

李想，当然有他的逻辑。

01

一台好车

当理想L9换代之际，几乎没有人会怀疑，全新L9还将会是一台好车。

因为即便是现款理想L9，都还是一款非常能打的产品，其设计、智驾、智舱、尺寸、空间都是一流。

但是，2022年推出的理想L9，平台周期是4年，碰到2024年、2025年友商新平台的产品，有点“拳怕少壮”的感觉。比如，CLTC纯电续航里程280公里虽然已经很不错，但架不住一些后来的车型推出300公里甚至更多的新品。

因此，当采用全新平台的全新理想L9推出时，补足老平台的缺憾，理想L9面对友商时，几乎又是全面领先之势。  

就拿全新理想L9和现款理想L9来比较说明吧。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeWY8Slgib6JYPwuzMt3R1wibVB5bu3o3YicJ9ZlYNo0SFgf8fLC1fW9ZbFAm4yyjOtCs0oqQe0ayzDRtbRoAuLn4cXh7yialO6lLYQ/640?wx_fmt=png&from=appmsg)

首先，设计方面，尺寸更大、颜色更豪华了。

长宽高5255*2000*1810毫米，轴距3125毫米。车长和轴距有37mm和20mm的提升。  

前悬更短、后悬更长，能够让其比例更显豪华，相信也能让它已经非常突出的空间体验，更上一层楼。

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeVUC8LtiaWXYQUI7icW6R3IR7lgp4Ql1gJUGeicFb7qxCaJR7KGm8fWKom6yDuEVpiaFo3aZshPQX5BKNfuymzLicwWS8h3WqmZadics/640?wx_fmt=png&from=appmsg)

外观上，新增钛金色和双拼色。

李想也在微博上说：

我"听劝”了：全新一代理想L9将提供定制版双色车身，采用三重喷漆与无阶差手工打磨的专属工艺。极致科技与极致审美，我们不做选择。

尤其在理想官方宣传片里，能看到全新理想L9劳斯莱斯一般质感的“紫金”双拼色，贵气逼人，总算让嫌理想设计不够“显摆”的消费者没啥可挑剔的了。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/RaRCbSicibjeUvuiaiaZI5BRmsWwdGHODRxG9vCtzVmLVc1lQr57rlrRh9mArt46DPJ7Xuct6LWIfUQAich6jmib0KWQwbkc4O4uPoW7C86iaDZOLw/640?wx_fmt=jpeg)

其次，全新一代增程系统亮相，强者更强。

理想汽车可以说是现在大行其道的增程技术路线的开创者。如今超级增程、超级混动的大发展，至少有理想汽车的引领之功。

很多人只是赞赏理想汽车的“巧思”，但其实理想汽车的增程技术，也是业界顶尖。

从和公告公示一同发布的免车船税新能源汽车目录看，全新理想L9的电池包电量72.7度，WLTC纯电续航340公里和332公里（约等效CLTC纯电续航420公里和410公里），官方表示，这是同级最长纯电续航。

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeWq1qiaps8pIjp5Po0EvWkBlptuEcozbKln2HKiamrn7YrVFytXLvcWmXhr0icUCBZHgAXcAZNMqkFKuaibpxYdJaRt0oOYpE8mRZQ/640?wx_fmt=png&from=appmsg)

而且，理想官方也表示，这个平台是800V的增程，能够在理想已经大规模建设的5C超充站轻松补能。

在能耗方面，全新L9的油耗将达到6.3L/100km，理想官方称实现同级最低油耗表现。

纯电里程、超充功率和能耗这三个指标，能够补上全新理想L9目前的所有缺陷，并且再度引领市场。

第三，全新理想L9还可以选配官方前装电动拖车钩；标配米其林PS5，最高提供22寸轮毂与285mm胎宽，21寸同样配备285mm宽胎，全系高规格，而且兼顾视觉张力与操控性能；还可以选择高亮灰饰条等配置……让9系SUV所在乎的场景需求、功能需求和情感价值拉满。

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeWLYkbXdc3JZbHh1sClNZayMQOLjm8LY9hOlkhVT6pOjLIwKaSJmnVm79vhw4XAGuuNNoEibuUTQE0dxU3QuveZXibrX4pWOQicTs/640?wx_fmt=png&from=appmsg)

对于一款“好车”而言，悬架可以说是最硬核指标。理想L9在之前引领空悬、双腔空悬、双腔双阀空悬的基础上，全新理想L9又在悬架方面带来了终极大杀器：全主动悬架。

李想说：

“全球首次在60万以内配备800V全主动悬架系统：单轮超万牛举升力，无需防倾杆，毫秒级瞬时响应，实现‘反物理’的车身姿态。L9 Livis 不仅是极致舒适的‘家庭旗舰’，更拥有顶级操控与驾驶乐趣。”

和被动悬架（钢制弹簧）、半主动悬架（空气弹簧、CDC、磁流变减振器）不同，主动悬架既不是完全被动地承接、减振，也不是仅仅调节阻尼和刚度，而是可以主动地“推、拉、举、压”，真正做到舒适、操控和平稳三者兼具。

目前全球而言，仅有保时捷、奔驰、等少数车企的少数车型搭载了主动悬架。但是，60万以内采用800V全电动主动悬架的，全新理想L9应该是首家。

由此，李想也是颇为自信：

“500万以内最好的SUV回来了。”

02

具身智能机器人

说全新理想L9是一台好车，争议可能不大。

但是说全新理想L9是“具身智能机器人”，大众可能理解有难度。

李想主要提出了三个方面的理由。

首先是前面提到的全主动悬架系统——这表明全新理想L9拥有了如同机器人一般能够电动快速灵活控制的“硬件本体”。

其次，全新理想L9还有“全球首个‘完全体’全线控底盘”，“包含线控转向、四轮转向与全球首个全电控机械制动（EMB）。转向-制动-电驱实现多重交叉安全冗余，拥有如神经系统般的‘直觉级’响应，完成从‘人驾原生’到‘人机共驾原生’的全面进化。”  

第三，“全球最强算力2560 TOPS的超强大脑”。

理想L9 Livis搭载2颗 5nm自研马赫100芯片，有效算力是英伟达Thor-U的3倍，并搭载覆盖全车360度的激光雷达。“这是目前全球最强的智驾大脑，没有之一。”

这其中包含众多重磅信息，但也将带来巨大的讨论。

比如，全新理想L9将实现线控转向、四轮转向等——蔚来的粉丝会说，线控转向蔚来是首家；比亚迪的粉丝会认为，e四方早就实现了四轮独立转向……不过，理想强调的是“完全体”。

再比如，全新理想L9将开始搭载自研芯片了——蔚来、小鹏的粉丝会说，蔚来小鹏早就做到了。就论算力而言，小鹏的才算最强大脑吧。

不过，理想、蔚来、小鹏都是自研芯片，但架构不同，如何能够用好算力，成为最强“大脑”，还要观察。

除了这些硬件，在软件层面，李想认为，全新理想L9也有了敢称为具身智能机器人的一个重大突破。

李想在B站的视频中说，全新理想L9从2DViT发展到3D ViT……真的像人一样的去感觉世界。

所谓，2DViT和3D ViT，都指的是用Transformer模型去构建世界的方式，但2D ViT是基于2D图像来生成，而3D ViT是基于3D时空数据。

而此前做不到，如今可以做到，李想称，原因也是自研芯片——算力是当前最好芯片的3倍，采用数据流架构，能够自己编写编码器。

有了更强感知（Livis将有四激光雷达），更强的模型和算力，就如同人一样有了更强的“眼睛”和“大脑”。

有了主动悬架、全线控底盘，相当于有了比人还要好的肢体的灵敏程度。

“眼睛”“大脑”“肢体”加起来，所以李想称理想全新L9是具身智能机器人。

更长远来看，李想之前就已经表达了要做“硅基家人”，也就是机器人的想法。

这次，李想在B站视频中进一步阐述了实现路径。

李想先说，当前在家庭中，司机和保姆（家政）都是影响巨大的角色，但二者角色不仅仅是单一功能。

像司机其实也是个人助理，还会帮忙去接孩子、做保养、去取东西。

李想认为，未来3-5年，理想汽车一定可以实现司机的功能。“L4自动驾驶的汽车会是我们生活中一个最重要的硅基人。”

至于家政型机器人，李想认为，最快3年，最晚5年一定能进入到每个家庭。

这里，李想其实也暗示，还会去做家政型保姆机器人。

当然，目前来说，李想就只有全新理想L9。

在工信部公示的图片中，全新理想L9可以选择“L9 Livis”车标。Livis无疑会让人想起钢铁侠的Jarvis——他的个人智能助理。

这确实是一个很好的开始。

03

如何逃离“内卷”？

为什么李想不满足于做一台好车，还得做具身智能机器人呢？

过去十年，理想造车，已经做得非常好。但是，这不能形成有效的防火墙——增程很好，马上被抄，甚至后来者还有“后发优势”；大六座很好，马上被抄；冰箱彩电大沙发很好，马上被抄……

这使得2025年的理想，产品处处受制。

理想如何反击？更快节奏地推进“汽车”的迭代，自然是应该的，所以，理想也加快了汽车平台迭代节奏，将从4年一代，加速到3年一代。

但是，究其本质，很难和对手拉开绝对差距，很难避免被“内卷”。

所以，理想的打法，就是通过“具身智能”部分，彻底和竞品拉开距离，形成壁垒，让后来者，难以复制。

在视频中，李想说，

“未来3-5年中高端汽车的竞争，其实就是一个具身智能的竞争。”

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeVRuULd7oegVYAOq4ryFykeVPcYl9LTeiabjIJLfcwusPEWtpEZUnAGE96UxPPAIE1IhGsfTQLwicF3HOWkKCGC9C4lyp1cgObd8/640?wx_fmt=png&from=appmsg)

他拿智能手机做类比，苹果最核心的壁垒是芯片和操作系统。而芯片和模型的联合设计，是汽车具身智能化以后的竞争的一个核心，也是用户价值的核心。

“芯片和模型，决定了技术能力的上限和壁垒。软件本体AGENT、硬件本体具身，会决定实际的体验到底会达到什么样的程度。”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeW5ETtlVvOsZldtiaiaViaymatDK1rThvVAr7lu0ibJSWk3iaRL1OmG10ftGwPQwQ9iaoVMRjJOZQ0zyKtWTiaKC168qdF4t0bAJ89nvE/640?wx_fmt=png&from=appmsg)

李想说，基于这样的理解，理想从2022年开始就来设计芯片，从2023年开始做基座模型。

“那时候大家都不太理解。但我觉得当大家体验了新的L9以及拥有理想L9以后，大家就会对我们很早做这样的投资、这样的判断，有一个不同的理解和真实的体验。”

依靠芯片和操作系统，苹果逃离了安卓系统、高通芯片的内卷，成为手机行业的利润大户。

理想如今像复制这一策略，有远见作为支撑，也需要实力和执行。  

这个逻辑，让我想起《星际穿越》等有关黑洞的电影和科幻小说——

只有你自身飞离黑洞的力量更大时，才能避免被黑洞吞食。

也就是说——

只有进化到别人想卷你也卷不到的程度，才能真正逃离内卷。
