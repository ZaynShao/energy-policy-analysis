# 晶澳科技与越秀资本达成战略合作

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)

「储能与电力市场」获悉，4月24日下午，晶澳科技董事、晶澳智慧能源事业部分管领导、晶澳储能董事长靳军辉一行到访越秀资本，双方围绕企业经营发展及业务合作进行了深入交流，并签署战略合作协议。  

  

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/nJIHJiauQqnwhdGRkEzRWnZB5kOZwAVk0jUDRsSDfsADuTq7pllhEYHdgHlhgl5mIDHU0gfsQojjRS1HiaCF9uSKjLum8fjHKjiaCjxb3YuHJs/640?wx_fmt=jpeg&from=appmsg)

  

越秀资本党委书记、董事长李锋对靳军辉一行的到访表示热烈欢迎，并介绍了越秀资本的绿色金融业务发展情况和“十五五”发展战略，表示越秀资本与晶澳科技建立了良好的合作基础，未来在国家绿色低碳转型和新型能源体系建设中存在广阔的合作空间，希望双方进一步深化在产业基金、融资租赁、期货等方面的业务合作，携手拓展绿色低碳产业生态和服务粤港澳大湾区新能源产业发展。  
靳军辉介绍了晶澳科技产业布局和智慧能源发展情况，表示晶澳科技正从光伏向储能、风电、虚拟电厂、零碳园区等综合能源领域拓展，未来希望与越秀资本发挥产业与金融优势，加强产融协同，持续拓宽合作领域、丰富合作模式，共同推动新能源产业和区域经济发展。

  

![image](https://mmbiz.qpic.cn/mmbiz_jpg/3NXPErG1Zr3xmmyrp0IJIbaQuThuvqBY7g0JtzvT5ib6njbcfic1CGX6208gQhwzlTvBMdvQPLPOkwOvbPQbiantX7U7w8b54ic9Ojyrz0jJZk4/640?wx_fmt=jpeg&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=2)  

晶澳智慧能源事业部总裁施俊，晶澳科技全球供应链中心总裁武廷栋，晶澳科技财经管理中心总裁孙鹏等相关负责人及越秀资本党委副书记、副董事长、总经理吴勇高，越秀产业基金董事长卢荣，广州期货总经理周小涛，越秀租赁首席风险官陈军参加了交流。
