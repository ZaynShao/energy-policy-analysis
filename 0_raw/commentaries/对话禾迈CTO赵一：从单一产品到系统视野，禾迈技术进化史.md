# 对话禾迈CTO赵一：从单一产品到系统视野，禾迈技术进化史

实现真正的光伏+储能双轮驱动
过去几个月，“光储融合”从技术理论和市场宣言迅速膨胀成新能源光伏和储能行业里的关键词。
行业的目光转向背后是切实的焦虑。
一方面，经过了二十余年的高速野蛮生长，光伏产业暴露了当前新能源发电在新型电力系统中的短板——光伏装机量占比和光伏发电量占比之间差值不断拉大，也意味着大量光伏绿电的浪费， “弃光现象严重”；电网应用负荷的峰谷波动性与光伏发电峰谷的严重不匹配现象愈加严重。储能正是试图补上这个短板，让光伏学会新型电力系统的稳定可靠、经济高效、清洁低碳的规律、因果。
也就是说，光伏与储能的关系，本质上是缺陷互补与价值重塑的关系。
另一面，储能在经历了政策驱动下的快速增长后，正走向市场交易型驱动的价值重构探索，需要从单体设备领先走向系统级协同，从而让光伏+储能实现1+1＞2的下一阶段。
只是，当产业资源、资本、技术都倾注于此，光储融合到底如何上岸，人们没有标准答案。
在禾迈股份副总裁、CTO赵一博士看来，禾迈在光储融合的战略转型中，技术研发端正是遵循了从单品有竞争力到整个系统有竞争力，及至整个矩阵产品有竞争力的系统级协同升维法则，从而实现了光储的双轮驱动。
系统视野下的技术升级
光储市场发展进入下半场，政策日趋规范，躬身入局者面临更大的市场与风险挑战，业务重心从过往的“低头狂奔”转为价值深耕与场景细分。加强光储系统级精细化协同与管理，也成了诸多光储厂商必备的“破局之道”。
这就好比一套严密精巧的机器，倘若每个齿轮都有1%的转动不畅，天长日久累积下来，必然对整套系统的运行效率有不小的折损。
“光储融合”四个字说来简单，但十分考验企业的技术底座是否扎实、技术能力是否足够创新，水面之下的积累决定其系统级协同的执行力度和效果。
在当下阶段，光储企业一旦启动“融合”的开关，首要任务就是梳理和升级技术底座。
这是一个不小的挑战，就像是“翻修一栋老房子”，在保留甚至是强化原有基座的同时，针对储能更加多元化的场景需求、更加复杂的系统集成、乃至于整个研发团队的系统级能力的问题，进行彻底翻新和升级。
赵一和他的技术研发团队要做的事情有很多，但核心目标就一个：建设扎实稳定的技术体系 ，让禾迈实现真正的光伏+储能双轮驱动。
禾迈总裁杨波曾表示：光储行业仍处于长期的黄金赛道。未来光伏与储能将深度融合、一体发展，光储充一体化的模式将成为主流。禾迈要在新能源领域成为一个伟大的全球性公司，就必然要做转型。
在禾迈从单纯光伏微逆头部厂商向全面光储解决方案提供商的战略转型进程中，储能技术研发和产品体系建设显得尤为重要。
赵一博士告诉高工储能，从研发底层逻辑到产品架构矩阵成型，禾迈在技术端正逐渐摆脱“单点产品制造”的角色，去承担一个“系统构建者”的身份。
“禾迈的战略让我们从户用到工商业再到大型电站去做多元化的发展，从电力电子产品讲，我们是拓展整个产品线，从最小功率的几百瓦微逆产品扩展到目前储能PCS最大单机3.45MW。”赵一博士表示，在进入储能领域后，储能对场景理解的要求更深，系统复杂度更高，如何让整个研发组织体系去匹配更多元复杂的场景解决方案成为禾迈面临的关键问题。
电力电子和电力系统是禾迈一直重点布局和已经具备极强优势的领域，同时经过从2021年到2025年这5年的不断积累，禾迈在以电芯为基础的储能系统集成也有了自己独特的认知和丰富的技术积累。
目前，禾迈已经构建起覆盖大型电站、工商业、户用及DIY等多场景的全系列储能产品及光储全场景解决方案，以满足全球市场多样化多场景需求。
“针对于从小功率到大功率，从光伏到储能产品再到光储融合的解决方案，我们都推出来了，也做到了业内较强的竞争力。”赵一博士认为，禾迈在研发端的投入一直是非常大的，也希望原理性的东西做扎实，研究明白，然后再往前走，这一直是禾迈的技术底色。
高工储能查阅年报资料获悉，2021年-2025年，禾迈累计研发投入超过10亿元，近三年，禾迈研发投入占比一直保持在12%以上，其中2025年，禾迈研发投入占营业收入的比例为18.06%。
5年，奔跑在储能技术创新路上
回头看禾迈转型上半场的这五年多时间，既是禾迈储能业务从0到1再到N加速跑的五年，更是禾迈朝系统化、精细化、场景多元化再深一步的五年：
初期，先重点做储能的场景需求分析剖析，而后又启动了对储能产品的定义，即用场景需求来驱动产品的底层逻辑；
再到中期，在场景需求洞察和产品定义有一定成效后，首先升级了整个的产品研发体系，而后开始具体的产品开发端，将户储、工商储和大储的产品研发聚焦各个应用场景，给客户提供不同的价值，以此达到储能系统级最优、最大化的效率。
2022年，禾迈推出了第二代户用储能系统、第一代工商业储能系统和源网侧储能系统。
2023年，禾迈又打造了全新适用于工商业及源网侧的储能PCS产品。
“在这一过程中，禾迈鼓励研发和产品走到用户前端，让研发跟产品团队前置到客户层，让他们去理解具体的应用场景和客户需求痛点。”在赵一博士看来，禾迈全球的营销体系和服务体系，让禾迈的储能研发站在了相当高的起点之上。
以禾迈在SNEC2026上重磅发布的HoyPrime AC 6.261MWh交直流一体机产品为例，其正是面向大型储能场景打造的核心支撑，背后直指当下大型电站项目业主对系统效率、安全可靠、项目交付、电网主动支撑和长期运行收益等关注的重点和痛点。
高工储能在现场注意到，HoyPrime AC采用了交直流一体设计，将电池系统、自研HPCS460、PCS级控制及系统级管理能力深度集成，形成更高集成度的一体化储能系统方案。通过簇级精细化管理、多级动态SOC均衡、分仓隔离及多级消防等设计，全面提升了系统在线率、可靠性与全生命周期运行表现。
这一产品的发布，不仅强化了禾迈在光储一体化解决方案领域的战略定位，同时也是禾迈从单一产品输出，走向面向大型储能全场景的系统方案交付的真实映射。
这些技术不断向前迈进的背后，其实反映的是禾迈一直践行的理念：以稳定技术及可靠产品为基石，致力于引领智能能源行业的变革之路。
而这一理念，禾迈已坚持了近二十年。
双轮驱动：技术与市场并行
任何市场的底层逻辑，永远是需求决定供给，再顶尖的技术产品方案也必须与深厚的场景土壤、完整的商业链路相结合，才能从美好的愿景，真正走向规模化应用的星辰大海。
如今全球尤其是中国正在迈入“风光新能源成为主导能源”的历史变革期，但大量风光绿电的浪费，消纳问题已经成为制约绿电进一步应用发展的关键阻碍。供应端大量绿电无法消纳，弃风弃光现象愈演愈烈，而在需求端，以AIDC为代表的新兴超级负荷则受困于指数级增长的算力需求与电力供给“线性级”增长之间的结构性脱节。
面对这样的行业共性难题，禾迈走出了一条差异化道路，没有被短期风口裹挟，始终保持光储融合的战略定力，坚持“技术与市场双轮驱动”。
在赵一博士看来，一方面，禾迈在微逆侧积累了非常多有用的技术经验，对于储能的产品研发和应用奠定了良好的基础。
“禾迈微逆的质保期是25年，基本是电力电子或者说整个光伏应用领域最长的质保周期，所以我们对怎么设计一款高可靠性高寿命的产品，同时去验证应用它非常有心得。”
其次，禾迈遍及全球190多个国家和地区的业务，也积累了不同电网下多元场景的经验。其中关键的通信技术、云平台的底层技术等都给开拓包括储能在内的新领域带来了非常好的参照。
最为关键的是，禾迈秉持着以市场需求和客户痛点为基础，倒推技术研发和产品落地，真正实现了技术和市场的双轮驱动。
“微逆安全、高效、易用等针对于用户的底层逻辑同样适用于储能市场。通过保证电芯的一致性，提升整个系统的效率，来给客户提供更大的价值回报。”赵一博士表示， 光储双轮驱动和技术市场双轮驱动的意义就在于更贴近客户，给客户创造更大的价值，而不是陷入价格竞争内卷的局面。
对于储能安全，禾迈同样有着自己的独特见解，即通过本征安全的系统架构设计来实现安全性的最大提升。
“在系统级端通过簇级精细化管理，独立运行，互不干扰，热管理设计以及参数的主动监测预警等一整套完整的安全设计体系，以主动干预的设计思维来将安全提升到更高的层次。”
赵一博士认为，产品形态与客户的需求和商业模式息息相关。禾迈要做的就是深入本地了解客户需求产生的原因。
光储融合在研发端需要考虑技术底层的兼容，就是如何站在用户底层需求和对系统最佳的角度去提升安全性、效率以及可扩展的能力。
禾迈在技术领域的目标是希望在技术底层扎实和技术平台完善的基础上通过快速适配，来满足应用前端不同的需求。
