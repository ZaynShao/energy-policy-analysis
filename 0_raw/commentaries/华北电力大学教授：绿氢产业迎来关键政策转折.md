# 华北电力大学教授：绿氢产业迎来关键政策转折

文|刘建国
2026年，绿氢产业迎来关键政策转折。
国家发展改革委、国家能源局印发的《新型能源体系建设“十五五”规划》，首次在国家级能源规划中将氢能、绿色燃料纳入非化石能源供给体系，并提出了2030年可再生能源制氢规模达200万吨的目标。6月，国家发展改革委等四部门联合发布《可再生能源消费最低比重目标和可再生能源电力消纳责任权重制度实施办法》（以下简称“《办法》”），自8月1日起施行，首次将可再生能源非电消费纳入最低比重目标考核体系，绿色氢氨醇等非电能源产品由此获得制度化需求支撑。
政策虽已释放明确信号，但产业内部的结构性矛盾依然突出。制取端规模不断扩大、储运端弱和应用端散的失衡格局，使得经济性提升和场景突破成为绿氢规模化发展的关键因素。
新疆维吾尔自治区阿克苏地区库车市已建成投产的库车绿氢示范项目氢气储罐。
3月，工业和信息化部、财政部、国家发展改革委联合印发《关于开展氢能综合应用试点工作的通知》（以下简称“《通知》”），明确到2030年城市群终端用氢价格降至25元/千克，力争在部分优势地区降至15元/千克左右。上述价格目标基本达到工业领域炼化、绿色氨醇等主要场景的经济性门槛。
但现实差距不容忽视。中国氢能联盟研究院的数据显示，截至2026年2月，全国生产侧氢价指数约25.9元/千克，消费侧约44.1元/千克。需要指出的是，上述价格主要反映的是副产氢的市场行情，而非绿氢的实际成本。据上海环境能源交易所数据，7月13日，中国绿氢价格28.36元/千克，较副产氢生产侧价格高出约2.5元/千克，差距尚在合理范围内。然而在消费侧，据行业反馈，当前终端用氢均价约为35元/千克，部分地区达50～60元/千克。这些价格同样以副产氢为主，距目标成本仍有逾50%的降幅空间。绿氢若要达到同等终端价格，面临的成本压力更为突出。
成本高企首先来自电力端。电力成本占绿氢生产成本的60%～70%，是最大成本构成项。据测算，若电价为0.3元/千瓦时，仅电费成本就有16.5元/千克，叠加设备折旧与基建摊销后，总成本超过20元/千克；若电价降至0.15元/千瓦时，电费成本可压缩至10元/千克以内，终端用氢成本才有望控制在15元/千克左右。
然而，电价并不是简单地与氢气价格挂钩，还取决于制氢的电力是来自电网还是绿电直连。并网制氢利用电网低谷电价，电解槽年工作小时数可达6000～8000小时，设备折旧成本低，但要承担过网费、容量费等各种附加成本。离网制氢采用绿电直供的方式，最低电价可至0.15元/千瓦时，但风光年利用小时数合计仅1000～4000小时，电解槽等固定资本投入的单位分摊成本大幅上升，还面临着波动性的挑战。此外，有些氢能示范项目，也在尝试弱并网的方式，通过电网来做安全构网保障，制氢的电力大部分来自可再生能源而不是电网，从而保证制取氢气的绿色属性和相对低成本。
中石化新疆库车氢能示范项目提供了重要的观察窗口。该项目设计年产氢气2万吨，所制氢气通过管道输送至6千米外的塔河炼化，替代天然气制氢。项目运行中，电解槽实现近10%的效率提升。7月8日，中国石化宣布该项目全部52台电解槽首次实现100%满负荷连续运行，稳定达到2万吨/年的设计产能。
作为连接制氢与用氢的关键环节，储运是另一个硬约束。绿氢资源在西部、市场在东部的空间错配，通过管线可以实现大规模低成本输送氢气，打通氢能应用的输送堵点，为绿色氨醇以及冶金等大规模用氢提供解决方案。我国氢气长输管网总里程不足200千米，和美国以及欧洲的千米里程相比，存在不小差距。此外，交通领域需求的氢气主要通过高压长管拖车运送到加氢站，储运成本占终端售价的30%～40%，当运输距离超过200千米时，运输成本将占氢气总成本的50%以上，这也制约了氢能交通的发展，是迫切需要解决的问题。
打破绿氢成本困局，需要超越单点突破的思维，在制度与市场的交汇处构建系统性合力。
制度层面，《办法》首次将非电消费纳入可再生能源消费最低比重目标考核。重点用能行业可再生能源非电消费最低比重目标可通过可再生能源制氢氨醇等综合利用方式完成。这意味着绿氢、绿氨、绿醇等产品不再仅仅是市场自发选择的替代品，而是被纳入强制性消费考核体系。对于钢铁、化工、数据中心等重点用能行业而言，消费绿氢正在从“可选项”变成“必选项”。这一制度安排为绿氢创造了稳定的需求预期，有效对冲“产得多、用不掉”的市场风险。
市场层面，碳排放权交易体系为绿氢的绿色溢价提供了变现通道。全国碳排放权交易市场持续扩容，企业使用绿氢替代化石燃料制氢所减少的碳排放配额，可以通过碳交易获得收益。按每生产1吨绿氢减排约20吨二氧化碳估算，随着碳配额逐步收紧、碳价持续上行，绿氢相对于灰氢的成本劣势有望逐步收窄，直至形成反向优势。
跨区域资源配置同样亟待制度与市场协同破题。当前，“十五五”规划已提出统筹布局“西氢东送、北氢南运”等跨区域输氢通道，推动氢能基础设施与电力、交通、工业等领域基础设施统筹规划、一体建设。长输管道被视为大规模、长距离输送的最经济选择，但建设周期长、初始投资大。未来需要制度层面明确管网的规划、建设和运营机制，市场层面形成合理的管输定价和成本分摊机制，才能真正打破绿氢资源与市场的空间错配。
此外，《通知》明确，通过“揭榜挂帅”方式遴选城市群率先开展试点，中央财政采取“以奖代补”方式给予奖励。这种“制度定规则、市场找路径”的机制设计，既为地方和企业保留充分的探索弹性，又通过财政激励降低先行者的试错成本。
上述《通知》将氢能应用场景从单一的燃料电池汽车拓展为“1+N+X”体系：1类燃料电池汽车通用场景，N类工业领域应用场景（绿色氨醇、氢基化工原料替代、氢冶金、掺氢燃烧），X类创新应用场景。
不同场景对氢价的承受能力差异显著。据行业测算，氢能交通在终端氢价25元/千克时可形成商业闭环，绿氢炼化为12～14元/千克，氢能发电的商业化门槛为10～12元/千克，绿氢冶金则需降至9元/千克以下方能具备经济性。25元/千克和15元/千克两个政策锚点，分别对应氢能在交通场景和工业领域展开正面竞争的分水岭。
氢能交通场景最受舆论关注，但不管是重卡、公交还是乘用车，迄今尚无企业完全实现盈利。例如山西鹏飞集团依托其煤焦化产业链，副产氢充足且价格便宜，同时拥有丰富的氢能重卡应用场景。然而，由于存在氢能重卡购置成本高、氢能储运基础设施不完善、为客户创造价值不明显等瓶颈，其大规模商业化推广仍面临挑战。
美国、韩国、日本等国家虽已率先进入相对大规模的应用阶段，但同样面临不同程度的商业化困境。美国加州氢价高达12～18美元/千克，全美公共加氢站不足70座；韩国政府计划投资推广7820辆氢能车辆，但2025年前九个月现代Nexo销量不足3500辆，同期纯电动车注册量约12万辆；日本2025年氢燃料电池乘用车全年仅售出431辆，全国142座加氢站陷入运营困境。反观我国，截至2025年年底累计建成加氢站574座，2025年燃料电池汽车销量同比增长52.9%，达8000辆，但加氢站建设进度仍相对落后于部分预期，面对纯电动汽车的激烈竞争，氢能乘用车推广面临着经济性不足和加氢基础设施的双重阻力。
相较之下，工业场景的规模化探索已初见成效。中国能建吉林松原绿色氢氨醇一体化项目一期建设80万千瓦新能源发电装置，可年产4.5万吨绿氢、20万吨绿氨和绿色甲醇。项目已于2025年12月正式投产，并通过欧盟国际可持续性发展和碳认证（ISCC）。7月28日，国家电投集团3750吨产自吉林大安的绿氨经陆路运抵江苏连云港，装船起航发往韩国，创下全球最大单批次绿氨出口纪录。这批绿氨产自2025年7月投运的国家电投吉林白城大安风光制绿氢合成氨一体化示范项目，该项目配置800兆瓦新能源装机，年产绿氢超3万吨、绿氨18万吨。上述项目的共同逻辑是：将绿氢转化为绿氨、绿醇，既可以出口创汇，也可以在国内用作燃料或化工原料，从而绕开了氢储运和加注的基础设施短板。
但场景创新的可持续性不能寄希望于出口单一通道，完全依赖“海外消纳、国内生产”的模式既不稳定，亦难以支撑产业长期发展。《办法》将可再生能源非电消费纳入国内消纳责任权重考核，是拉动终端消费的长久之计。与此同时，“技术出海、海外建厂、服务全球”的模式，也能与国内市场的稳步培育形成互补。中石化炼化工程集团签约沙特延布4.2吉瓦电解水制氢项目，预计于2030年正式投入商业运营，建成后每年可生产40万吨绿氢、280万吨绿氨，将成为全球最大规模的绿氢/绿氨生产综合体。
数据中心绿氢直供有望成为场景中的突破口。随着人工智能、云计算等产业的爆发式增长，数据中心对稳定、清洁的电力需求急剧上升。绿氢、氢基绿色燃料已被纳入算力设施清洁能源直供选项。它既可解决数据中心低碳转型的痛点，又能为绿氢创造一个高附加值、高稳定性需求的规模化应用场景。这一模式有望继交通和工业之后，开辟氢能新的规模化需求道路。
总体而言，绿氢经济性的提升是一项覆盖制取、储运、应用全链条的系统工程。制氢端的技术迭代与成本压降是基础，储运端的基础设施完善是保障，氢能多场景规模化应用是关键，制度与市场在各环节的有效协同则是贯穿始终的支撑条件。从政策到市场、从制取到应用，只有当全链条各环节形成正向循环，绿氢才能真正跨越经济性的门槛，完成从政策驱动的示范产品向市场驱动的能源商品的质变。
（作者系华北电力大学教授、氢能技术创新中心主任）
