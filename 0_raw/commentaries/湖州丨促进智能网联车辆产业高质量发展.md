# 湖州丨促进智能网联车辆产业高质量发展

智能网联车辆产业融合人工智能、高速通信、环境感知等前沿技术，是发展新质生产力的关键赛道。为了促进智能网联车辆产业高质量发展，推动创新应用，强化安全保障，加快培育新质生产力，根据有关法律、法规，结合本市实际，湖州市人大常委会制定《湖州市智能网联车辆产业创新发展条例》（以下简称《条例》）并于近日发布。
《条例》着力加快市智能网联车辆创新应用的步伐。除道路测试、示范应用之外，还将示范运营、商业运营也一并纳入创新应用活动范畴，明确支持开展创新应用活动的相关场景，依法稳妥有序推进规模化示范运营、商业运营，逐步开放全域道路。《条例》将于7月1日起正式施行。
《条例》适用于湖州市行政区域内智能网联车辆的产业发展以及创新应用、安全管理、服务保障等相关活动。
总则：明确立法目的、适用范围、基本原则、政府及部门职责分工、社会组织职责和宣传引导等。
产业发展：规定规划引领、产业链培育、项目招引、技术创新、平台建设、数据赋能、产业融合等产业发展支持措施。
创新应用：规定制定应用细则、开放应用路段、建设基础设施与服务管理平台建设迭代，支持全域开放与异地互认等创新措施。
安全管理：规定产品安全、管理安全、网络安全、数据安全与地理信息安全等安全保障措施，并明确事故处理规则。
服务保障：规定人才、标准、检测、知识产权、资金和保险等支持保障措施和宽容试错机制。
附则：规定相关名词定义和施行日期。
