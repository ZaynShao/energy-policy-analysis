# 【走进企业】50余家零部件企业走进理想汽车开展技术交流对接

2026年6月25日，由中国汽车工程学会、理想汽车主办、汽车供应链创新分会协办的“走进理想汽车”活动在常州成功举办。本次活动围绕整零协同的核心需求，从近200家报名企业中遴选53家学会团体会员单位，以及电动汽车产业技术创新战略联盟、中国智能网联汽车产业创新联盟、汽车轻量化技术创新战略联盟的成员单位参与。温州（瑞安）协同创新中心专门组织企业代表团出席。活动通过实地参观、专题分享、互动对接等形式，为汽车产业链上下游企业搭建了高效的交流合作平台。
中国汽车工程学会副秘书长、汽车供应链创新分会秘书长李顺虎，理想汽车供应链副总裁、汽车供应链创新分会副主任委员孟庆鹏出席活动并致辞。
中国汽车工程学会副秘书长、汽车供应链创新分会秘书长李顺虎
李顺虎副秘书长对理想汽车精心承办本次活动表示衷心感谢，并称赞理想汽车供应链团队作风务实、扎实笃行，为行业整零协同树立了优秀样板。他表示，学会将持续发挥桥梁纽带作用，促进整零协同创新，助力我国零部件企业发展。
理想汽车供应链副总裁、汽车供应链创新分会副主任委员孟庆鹏
孟庆鹏副总裁回顾了理想汽车的供应链变革历程。他表示，历经数字化深耕，理想汽车供应链流程点亮率、数字化率指标均落地扎实、表现卓越。如今正从ISC迈向ASC智能组织变革，将持续提升产业链整体能力，全力打造卓越而智能的“理链”生态。
整车电动智能底盘电子制动负责人陈琰围绕《全线控底盘量产开发实践》，介绍了理想汽车集EMB线控制动、四轮线控转向与全主动悬架于一体的全线控底盘，并介绍了理想汽车与供应商伙伴深度联合开发、全栈自研的协同创新机制。
理想汽车整车电动智能底盘电子制动负责人陈琰
理想汽车供应链采购技术中心工业化负责人雷江波
理想汽车供应链数智化效能负责人林业宁
随后，在“与理想对话”企业互动交流环节，参会企业与理想汽车团队就技术创新、产品升级和产业协同等话题展开了深入交流。这种精准对接、深度融合的模式，为产业链上下游企业提供了宝贵的合作机会。
孟庆鹏副总裁与企业代表交流
企业代表参观理想汽车智能制造成果展示
活动最后，孟庆鹏副总裁表示，理想汽车将持续以开放心态深化整零协同与联合创新，与合作伙伴文化同频、共建卓越而智能的“理链”生态，实现合作共赢。
此次“走进理想汽车”活动的成功举办，不仅展现了理想汽车开放合作的创新生态，也为汽车产业链上下游企业搭建了高效的交流平台，受到参会企业的高度评价。未来，中国汽车工程学会将持续推进此类活动，为构建更具韧性和创新力的汽车产业生态贡献力量。
