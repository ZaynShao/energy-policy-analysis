# 深圳光明区丨推动车规级芯片向高可靠性、高算力、低功耗方向演进

为贯彻落实国家、省、市关于推进新型工业化系列部署，主动顺应新一轮科技革命和产业变革趋势，全面塑造产业发展新优势，加快构建以新质生产力为核心的现代化产业体系，深圳市光明区工业和信息化局研究起草了《光明区加快推进新型工业化“十五五”规划（征求意见稿）》并于近日发布。
《征求意见》明确：
新一代充换电：把握深圳启动“超充之城2.0”建设机遇，面向重卡等商用车超充换电、乘用车闪充等应用场景需求，开展高性能功率半导体、大功率液冷充电模块、高效热管理系统及兆瓦级充换电终端等关键零部件与装备的研发制造。前瞻探索无线充电、车网双向互动等前沿技术，推动光储充一体化及兆瓦级充换电终端集成应用。
提升充换电产业能级：支持企业提升充电模块核心制造能力，打造集研发创新、智能制造、总部办公于一体的综合性产业平台；持续加大超充、闪充等高功率充电技术及设备应用，支持企业布局光储充和车网互动一体示范项目，打造区域性综合能源示范。
支持企业开发面向车载显示等专用显示领域的系统级解决方案。
面向智能网联车等应用需求，支持车规级MEMS惯性传感器、硅基光子芯片、CMOS-MEMS集成智能传感器芯片的研发与产业化。
面向智能网联车等未来产业，推动车规级芯片等向高可靠性、高算力、低功耗方向演进。
