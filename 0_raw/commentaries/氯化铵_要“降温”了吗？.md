# 氯化铵 | 要“降温”了吗？

近期国内氯化铵市场不断升温，截止3月18日，华东地区氯化铵（干铵）价格涨至630元/吨，周环比上涨8.62%。联碱企业惜售控单，贸易商持货待涨，下游复合肥企业开工率提升，对氯化铵补库积极，同时外围美以对伊朗的军事行动节节升级，伊朗卡喉封锁霍尔木兹海峡，全球供应链受创，国内化肥多产品持续推涨。

对比尿素，氯化铵价格此波上涨真是一飞冲天。以江苏地区干铵价格为例，春节后价格顺利调涨30元/吨，短短二十天，价格跳涨至630元/吨，较节前上涨50%。春节前下游抄底补库，联碱企业大量收单，积极清库，节后春季需求释放，而联碱企业无量提供，供需失衡矛盾凸显，价格不断飙高。而尿素受指导价影响，节后涨幅明显受限，不足4%。下游复合肥在氮磷钾各方成本加压下，价格被动走高，当前价格较节前仅上涨2.17%。  

不过如火如荼的涨势被近日的政策消息扰动，二元肥出口管控以及国家启动国储氮磷及复合肥提前投放，在当前春耕用肥季，无疑给与保供、稳定化肥价格再次干预。那么对近期大幅上涨的氯化铵市场是否也给出了“止涨令”？

首先，二元肥出口受限以及释放国储，这势必将加大国内供应量，填补内需缺口，而随着春季用肥结束，内需收紧，供应趋于宽松，因此价格推涨受阻，这也迎合了国家保供稳价的指导意义。

其次，虽然复合肥企业已开启夏季肥的生产，但目前走货仍以兑现前期待发为主，高价货源有限，另外在当前政策指导下，复合肥企业对于原料的采买以刚需补库为主，所以采购节奏放缓，在一定程度上或将抑制原料的过快上涨。

如上所述，需求端屏障缓慢升起，但供应端仍存利好支撑。目前至6月底共有六家联碱企业计划内检修，涉及年产能600万吨。虽然检修存在时间上的差异，但相对集中的检修必将导致供应量难增。在需求弱化下，供应收紧仍将给与氯化铵市场较强的托底。

整体来看，氯化铵市场供需矛盾尚存，双轮驱动仍在，但未有进一步激化的风险，所以近期的政策给氯化铵厂商设置了心理上的推涨障碍，叠加供需面的阶段性变化，所以预计氯化铵此波上涨或遇瓶颈，节奏放缓，或将走的更长！
