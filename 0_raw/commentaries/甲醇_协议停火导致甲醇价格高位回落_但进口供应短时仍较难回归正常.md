# 甲醇 | 协议停火导致甲醇价格高位回落 但进口供应短时仍较难回归正常

**导语**

协议停火后，本周甲醇期货没有再度上演前面两周的“V”型走势，重心震荡向下，高低端波幅568元/吨，极致表现在4月8日当天。停火对海峡通行的预期，使得全球市场买盘开启谨慎模式，担心价格大幅回撤。若战争正式结束，价格有所回归是理所当然，但战后可能带来的全球性能源补库需求、滞胀等预期，将使得整体能化商品很难回归至战前的价格水平。  

本周国际甲醇（除中国）开工继续下降至47.07%，停火协议前，美国以色列袭击了不少伊朗的公共设施（恢复情况有待跟踪），严重影响了当地甲醇装置的氧气及电力供应，配合着一些工厂的避险情绪，伊朗装置全线停车，并大概率短时较难恢复；据本网了解，即使正式停战，也仍将严重影响中国地区后续几个月的进口供应。截至目前，本月中东主力区域发船12万吨，或仍有少量库存可发，后续的发运体量则完全由重启进度决定。

非伊方面，若海峡通行，波斯湾内库存及浮仓的发出进度较为关键；东南亚地区则仍需持续跟踪部分大型装置的恢复情况；南美地区则天然气供应偏紧，南半球后续即将进入冬季，进入5月将开启常规的例行限气阶段。若无波斯湾内非伊货源补充，仅靠其他地区，5月中国甲醇进口供应将大概率再度环比4月明显回落，具体核心还是由海峡通行的船货情况决定。

综合来看，在国产开工提升空间有限的背景下，内地货顺流将导致产区库存仍有下降空间，后续随着企业库存见底或使得国产套利减量，进口货成交好转将使得社会库表需回升，从而继续助力沿海去库。

对于MTO工厂来说，利润表现与原料供应稳定都是核心。隆众预计，进口供应问题将势必影响沿海地区MTO未来的开工运行情况（供需双减），近期沿海不同烯烃工厂的终端产品表现略有差异，部分产品跟进乏力，因此周内有不少烯烃负荷预期变动的传闻。此外传统下游方面，因碳四紧张，山东地区地炼开工已经受到影响，部分工厂报出停车检修计划且时间较长，将影响内地主销区的消费能力。随着交割月的日益临近，密切留意内地强弱、区域价差，对05合约的影响；预计5-9月差或表现偏强。
