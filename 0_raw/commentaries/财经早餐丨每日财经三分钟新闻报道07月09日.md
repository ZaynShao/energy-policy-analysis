# 财经早餐丨每日财经三分钟新闻报道07月09日

01 今日财经头条
- 央视新闻/CNN：特朗普宣布美伊停火协议“已结束”，美军可能再次打击伊朗。受此影响，霍尔木兹海峡油轮通行“基本停止”，国际油价盘中大幅飙升。
- 伊朗消息人士：伊朗不会放弃霍尔木兹海峡管理权，若遭受打击将全面关闭海峡，并对敌方实施至少“两倍于对方”规模的报复性回击。
- 伊朗军方知情人士：为回应美方空袭，伊朗计划对美军中东基地发动“大规模报复性”导弹及无人机行动，防空网络已做好拦截准备。
- 港股市场：恒生科技指数受央行支持香港资本市场承诺的提振，大幅收涨 4.97% ，恒生指数亦飙升 2.99% 。
- 央行货币政策委员会：召开2026年二季度例会，指出外部环境更加复杂多变，国内经济面临“供强需弱、结构分化、外部冲击”三重挑战，重申实施适度宽松的货币政策。
02 宏观与政策
- IMF：发布最新《世界经济展望报告》，将2026年全球经济增长预期小幅下调至 3% ，但将中国经济增长预期上调至 4.6% 。
- 央行货币政策委员会：二季度例会建议增强政策前瞻性灵活性针对性，继续实施适度宽松货币政策，加大逆周期和跨周期调节力度，把握好力度、节奏和时机。
- 美联储会议纪要：所有官员支持6月维持利率不变，但少数官员认为有加息理由，多数指出AI需求、中东冲突及关税使通胀仍维持高位，可能需进一步收紧政策。
- 应急管理部：针对超强台风“巴威”预计于11日在福建福清至浙江温岭一带登陆，国家防总启动浙江、福建防汛防台风四级应急响应。
- 市场监管总局：披露2026年上半年深入整治“内卷式”竞争工作进展，拟通过修改《价格法》完善对低价倾销等不正当价格行为的认定规则。
- 国家能源局：当前迎峰度夏保供全面展开，全国电力供需总体平衡，华东、华中、南方部分省份供应偏紧，通过跨省跨区互济可基本消除。
- 财政部/应急管理部：紧急预拨 5000万元 中央自然灾害救灾资金，用于支持湖北、甘肃的龙卷风及山体滑坡灾害应急抢险救灾工作。
- 国家气候中心：监测显示赤道中东太平洋海温持续攀升，预计今年夏秋季节将形成一次东部型强至超强厄尔尼诺事件。
03 环球视野
- 美国中央司令部：美军对伊朗发动新一轮打击，旨在进一步削弱伊朗威胁霍尔木兹海峡航行自由的能力，这是连续第二天的军事行动。
- 美股市场：中东局势紧张升级，道指收跌 576.76点 至 52348.39点 ，跌幅 1.09% ；纳指涨 0.20% ；标普500跌 0.28% ，布伦特原油期货收涨 5.43% 至每桶 78.19美元 。
- 欧洲股市：德国DAX指数跌 2.29% ，法国CAC40跌 2.29% ，英国富时100跌 1.84% ，中东局势紧张令投资者避险情绪升温。
- 韩国KOSPI指数：收盘暴跌 5.35% ，较6月历史高点回落逾20%，进入技术性熊市。监管层警告半导体板块过度集中是核心风险。
- 俄罗斯副总理诺瓦克：俄政府已实施柴油出口禁令，7月起开始进口石油产品，以应对炼油厂遭袭影响及国内燃油需求激增。
- 新西兰联储：正式宣布加息重新开启货币政策紧缩周期，引发市场对全球央行货币政策走向的广泛关注。
- 美国财政部：计划与贸易代表办公室等协作拟定西班牙商品清单，供特朗普考虑实施禁运；特朗普威胁切断与西班牙所有贸易往来。
- 欧盟常设法院：驳回苹果公司上诉，维持欧盟委员会将其App Store及iOS操作系统认定为《数字市场法》下“守门人”的监管决定。
04 A股与港股
- A股市场：7月8日继续缩量调整，沪指收跌 0.49% 至 3970.88点 ，近3800只个股收跌，成交额降至 2.58万亿元 ，市场情绪谨慎。
- 长鑫科技：披露科创板上市招股意向书，申购日为 2026年7月16日 ，代码“688825”，拟公开发行 66.88亿股 ，最高发行总股数可达 76.91亿股 。
- A股业绩预告：截至7月8日21时，共有171家上市公司披露半年度业绩预告，其中 150家预增 ，占比87.72%，化工、有色及电子行业表现突出。
- 浪潮信息：预计上半年净利润 26亿-31亿元 ，同比增 226%-288% ，走出“一字涨停”，市值升至 1148亿元 ，全天成交 31.93亿元 。
- 高德红外：2026年半年度业绩预告显示，预计归母净利润在 12.70亿至14.50亿元 之间，较去年同期增长 601.93%至701.41% 。
- 大洋电机：因实控人夫妇涉及 55亿 股权分割的离婚诉讼，公司股价7月8日跌停，市场担忧股权结构变动及可能的变相减持风险。
- 港股智谱：AI公司智谱上市后首次大规模限售股迎来解禁，涉及超400亿港元市值，但股价低开高走大涨 13.35% 。
- 摩根大通：将赣锋锂业A股评级由“中性”上调至“超配”，目标价 80元人民币 ，预期上涨 42% 。
- 港股基石投资：年内已有 502家 机构参与港股IPO认购，瑞银环球资产管理以 17家 新股排名第一，泰康人寿、高瓴旗下HHLR紧随其后。
- 盛新锂能：发布半年度业绩预告，受益于锂盐产品量价齐升，预计上半年归母净利润达 10亿至12亿元 ，同比实现扭亏为盈。
05 产业与公司
- AI算力产业链：浪潮信息、光库科技、江波龙等多家公司2026年上半年业绩预增，上下游全面迈入“业绩兑现”阶段，受全球AI算力基础设施建设驱动。
- 苹果公司：宣布与博通达成为期五年的重大芯片供应协议，总金额将超过 300亿美元 ，旨在扩大美国本土制造并生产超150亿颗芯片。
- 京东方A：发布2026年半年度业绩预告，预计归母净利润为 50亿元至55亿元 ，同比增长 54%至69% ，LCD及柔性AMOLED业务驱动增长。
- 沧州大化：预计2026年半年度净利润 1.01亿元 ，同比增约 330.75% ，主因TDI产品市场价格大幅提升及特种PC市占率增长。
- 蓝色起源：贝佐斯旗下太空公司启动首轮外部融资，募资规模 100亿美元 ，投后估值高达 1300亿美元 ，紧随SpaceX的IPO进入资本市场。
- Meta：宣布在加拿大艾伯塔省兴建 1吉瓦 超大数据中心，总投资额 130亿加元 ，为加拿大首个算力基地，全球数据中心将增至33座。
- 欧菲光：宣布成立“江西欧菲光学微纳器件有限公司”，聚焦光模块及光互联领域的光无源器件，涵盖光纤阵列、光学玻璃等研发制造。
- SpaceX：与AI编程公司Cursor联合发布Grok 4.5模型，面向金融、法律、编程等专业领域，旨在缩小与Anthropic、OpenAI等竞争对手差距。
- 梅赛德斯-奔驰：二季度华交付量超 11万辆 ，城区领航辅助驾驶已实现全国覆盖，并计划在年内实现首批“物理AI”上车。
06 商业风向标
- 海口海关：2026年上半年海南离岛免税购物金额达 199.2亿元 ，同比增长 18.8% ，赛事、会展与节假日客流对消费拉动效应显著。
- 联合国自动驾驶全球法规：由中国、欧盟、美国等牵头制定的自动驾驶系统全球技术法规获批发布，标志着全球标准体系历史性突破。
- Waymo：宣布未来数周将在圣迭戈、拉斯维加斯等四个美国新城市推出无人驾驶出租车服务，进一步巩固对特斯拉和Zoox的商用化领先优势。
- A股算力产业链：截至7月8日已有20多家公司业绩预增，AI大模型商业化落地带动算力硬件、存储及租赁服务盈利增长，跨界收购热度持续。
- 香港黄金清算系统：7月7日黄金中央清算及结算系统启动试营运，多家国有大行完成首日多笔黄金交易与清算，巩固国际金融中心地位。
- 文化和旅游部：2026年全国暑期文旅消费季启动，全国各地将举办超 3万场次 活动，合计发放超 4.5亿元 消费补贴。
- 新京报贝壳财经：发布《2026年上半年企业家信心指数》为 61.59 ，显示企业正通过技术创新、人工智能与全球化布局来探索新的增长路径。
