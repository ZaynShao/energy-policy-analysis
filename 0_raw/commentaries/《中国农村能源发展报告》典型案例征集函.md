# 《中国农村能源发展报告》典型案例征集函

为系统总结我国农村能源转型成效、凝练农村能源革命的鲜活经验，中能传媒能源安全新战略研究院正在组织编制《中国农村能源发展报告》。报告聚焦农村能源转型关键领域，挖掘各地创新实践、成熟路径与标杆模式，提炼可复制发展经验，为国家相关政策制定、行业技术迭代、基层实践推广提供参考。现面向全国公开征集农村能源发展典型案例，作为报告的核心基础素材与全国示范推广样本，诚邀各单位踊跃推荐或自荐。
本次征集案例紧扣我国农村能源发展主要场景，聚焦但不限于以下七个领域：
1.农村电网建设与升级（配电网改造、智能化、供电可靠性提升等）。
2.农村清洁取暖（“太阳能+”、热泵、生物质取暖、煤改电/气等）。
3.分布式新能源开发与就地消纳（屋顶光伏、农光互补、源网荷储一体化等）。
4.生物质能与沼气利用（秸秆资源化、畜禽粪污制气、生物天然气等）。
5.农业生产用能电气化（粮食烘干、温室大棚、茶叶/烤烟加工等）。
6.农村充换电基础设施（充电桩下乡、新能源农用车配套等）。
7.偏远地区供能保障与微电网探索（独立供电区改造、风光储微电网等）。
1.所有报送案例需包含：案例完整名称，实施落地地点，项目启动及建成投运时间，相关核心数据（装机规模、改造体量、用能成本变化、农户/集体增收、清洁能源占比等），以及联系人及联系方式（以便核实补充）。
2.内容聚焦具体项目、具体村镇、具体场景，避免全域宏观总结、空泛政策表述，重点突出创新模式、技术路径、运维机制、收益分配、解决的行业痛点、可复制推广经验。
3.每个案例配套至少一张高清实景图片，图片格式不限，需画面清晰，可用于报告插图及公众号宣传。

1.本次征集的优质典型案例，将择优收录进《中国农村能源发展报告》公开发表成果，部分典型案例将被推荐至我院微信公众号、行业平台进行专题宣传。
2.报送单位需保证案例及图片素材真实，所有报送案例版权归报送单位所有，我院仅用于报告编制、学术研究、公益宣传、成果推广，不作任何商业用途。
3.报告发布后，将向入选案例的报送单位寄送报告正式出版物。
1.各单位可根据自身业务特色，多案例同时报送，不限数量。
2.优先收录创新性强、落地效果好、解决行业痛点突出、具备全国复制推广价值的一线实操案例。
