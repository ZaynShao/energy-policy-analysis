# 金杜助力创业板首家未盈利企业大普微成功在深交所首次公开发行股票并上市

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/WWbwrx83bPD3e2HzibTHmG0KYL86dl6g0Bsib2FLKhCZ28xm8cWyYDU8FrtkiaIK9ciaTgia4VgQos9IzEUWCVia3uctlFtufRrVZj280xUiaMSSWU/640?wx_fmt=jpeg&from=appmsg)

2026年4月16日，深圳大普微电子股份有限公司（简称大普微，股票代码：301666）成功登陆深圳证券交易所创业板，本次首次公开发行A股股票4,362.1636万股，发行价格46.08元/股，募集资金总额20.10亿元。大普微系创业板首家未盈利、首家设置特别表决权的企业，同时也是首家专注数据中心企业级SSD的存储上市公司。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/WWbwrx83bPBK47Diclg271ohVY8AhNla5VXHIib9mvmn3WJYfwbjtyT4BylYlZBO6N1MxOTNdde4gf0duyJLZHRO1Hia6m5XDOt6c9POSE8mpU/640?wx_fmt=jpeg&from=appmsg)

从左到右：唐诗君、徐辉（合伙人）、牟蓬（合伙人）、杨亚飞（大普微董事长、总经理）、朱劲松（大普微副总经理、董事会秘书）、杨振华（合伙人）、王安荣（顾问）、刘苇茜

大普微成立于2016年，专注于数据中心企业级SSD，是业内领先、国内极少数具备数据中心企业级SSD“主控芯片+固件算法+模组”全栈自研能力并实现批量出货的半导体存储产品提供商。大普微产品在下游互联网、云计算、通信运营商、AI模型训练&推理、金融和电力等领域的数据安全、高效、可靠存储中发挥关键作用。公司在国内企业级SSD市场中占有率稳居市场前列，也是中国极少数已实现向Google等海外客户供货的企业级SSD厂商。随着大普微本次成功发行上市，将与国产存储产业链核心伙伴共同构筑企业级存储产业新格局，推动形成覆盖NAND Flash、DRAM等关键领域的完整布局。

本项目中，金杜律师事务所担任发行人律师，凭借在半导体行业领域丰富的项目经验，全面参与大普微架构调整、融资、改制、法律尽职调查、上市方案论证，以及上市申报、审核问询和注册等核心法律工作，为公司提供了充分的法律论证和落地执行方案。金杜始终秉持专业尽责、精益求精的服务宗旨，为公司提供专业、优质、高效的法律服务，助力大普微圆满完成本次发行上市，获得了客户及合作方的高度赞赏。

本项目由合伙人**牟蓬**牵头，项目负责人为合伙人**徐辉**、**杨振华**及顾问**王安荣**，主要团队成员包括唐诗君、刘苇茜。合伙人**虞磊珉**以及律师梁嘉欣为本项目提供了外汇相关法律服务支持。
