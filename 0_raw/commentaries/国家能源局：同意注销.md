# 国家能源局：同意注销

7月8日，国家能源局综合司发布《关于同意注销浙江百丈漈一级水电站大坝安全注册登记证的复函》。
以下为原文
国家能源局综合司关于同意注销浙江百丈漈一级水电站大坝安全注册登记证的复函
国能综函安全〔2026〕29号
大坝安全监察中心：
《关于注销浙江百丈漈一级水电站大坝安全注册登记证的请示》（坝监专委〔2026〕49号）收悉。经研究，函复如下。
一、浙江百丈漈一级水电站总装机容量3.12万千瓦，属于小水电，地方水行政主管部门已同意办理大坝注册登记，浙江能源监管办和水电站大坝主管单位也已同意注销大坝安全注册登记证，符合水利部、原国家工商总局、原国家安全监管总局、原国家电监会联合印发的《关于加强小水电站安全监管工作的通知》（水电〔2009〕585号）和《国家能源局综合司关于小水电大坝办理注册登记注销手续有关事宜的复函》（国能综安全〔2016〕154号）规定。我局同意注销浙江百丈漈一级水电站大坝安全注册登记证。
二、请你中心依规办理浙江百丈漈一级水电站大坝安全注册登记证注销手续，并及时将注销情况书面告知大坝运行单位、大坝主管单位、浙江省能源局、浙江能源监管办以及地方政府水行政、防汛抗旱主管部门。
三、自浙江百丈漈一级水电站大坝安全注册登记证注销手续办理完毕之日起，我局不再承担该水电站的安全生产和大坝运行安全监管责任。
国家能源局综合司
2026年6月30日
