# 磷矿石 | 1-2月进口总量同比增加143%

2026年1—2月，中国磷矿石进口总量达34.07万吨，其中未碾磨磷矿石进口33.8万吨，占总进口量的99.2%；已碾磨磷矿石进口2752吨。月度分布上，1月进口24.39万吨，2月为9.68万吨，呈现明显回落趋势。同期，磷矿石进口平均单价为84美元/吨，较2025年12月的98美元/吨下降14美元/吨，降幅达14.3%。

2026年1—2月中国磷矿石进口总量为34.07万吨，其中未碾磨磷矿进口总量达33.8万吨，已碾磨仅2752吨。主要来源国为约旦、埃及与巴基斯坦，其中约旦进口24.55万吨，埃及7.88万吨，巴基斯坦1.37万吨，三者合计占未碾磨进口总量的99.6%。已碾磨磷矿石几乎全部来自埃及，进口量为2752吨。

2026年3月，湖北多数磷矿山持续休采，国内供应受限，叠加春耕旺季需求释放，企业原料采购意愿强劲。受磷酸铁、磷酸铁锂高开工率拉动，湿法净化磷酸及工业级磷酸一铵产能利用率显著提升，带动高品位磷矿石需求明显增长。在内供不足背景下，进口端延续增势，预计3月磷矿石进口量将进一步扩大，以保障下游产业链稳定运行。
