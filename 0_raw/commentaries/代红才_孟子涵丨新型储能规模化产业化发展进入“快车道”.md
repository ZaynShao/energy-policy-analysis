# 代红才 孟子涵丨新型储能规模化产业化发展进入“快车道”

![image](https://mmbiz.qpic.cn/mmbiz_png/vYw27Y7HicGdBK6FmUEViaxa6wjdsuibzJSYpDk8hvr0CLicyITfm8cuEZPbjXicYLiavzkEV71BV5BVRUMGHEc4feVXly2ib4IIxoib0ahYyDaCfQk/640?wx_fmt=png)

  

国家发展改革委、国家能源局印发的《新型储能规模化建设专项行动方案（2025～2027年）》提出，2027年，全国新型储能装机规模达到1.8亿千瓦以上。新型储能作为支撑新型电力系统的重要技术和基础装备，正式进入规模化、产业化发展的“快车道”。

**装机规模跨越式增长，利用效率稳步提升**

![image](https://mmecoa.qpic.cn/sz_mmecoa_gif/tYBGQJ9TRKmFIILGaibFDkS34XqEkpLjjNmnO9DaxMqgjQBiaczN0icQqhBd0R6jaMk3gxHqQzgbrlvuTKia1FCPEQ/640?wx_fmt=gif)

截至2025年年底，我国已建成投运新型储能装机规模达到1.36亿千瓦/3.51亿千瓦时，与“十三五”末相比增长超40倍。从技术路线看，锂离子电池储能占据绝对主导地位，装机占比超95%。2025年9月，锂离子电池储能系统成本已降至约0.5元/瓦时，工程总承包成本降至约1元/瓦时，较2021年下降约67%，经济性显著提升。

  

新型储能利用效率稳步提升，用户侧储能项目表现突出。据国家能源局初步统计，2025年全国新型储能等效利用小时数达1195小时，较2024年提升近300小时。

  

分类型看，用户侧储能因运营模式清晰，且得益于多地优化的电价政策，可实现“两充两放”，利用小时数相对较高。电源侧储能受技术经济性制约，目前多以配合新能源运行为主，缺乏有效调用补偿机制，利用小时数相对较低。

  

分区域看，浙江、江苏等地对独立储能实施充电价格优惠等政策，激励其按调度指令运行，利用小时数显著提升。西藏的储能绝大部分为光伏配建项目，配置时长长（平均4.2小时），利用小时数也较高。

**新型储能向着需求旺盛、技术多元、作用凸显、规划革新的方向发展**

![image](https://mmecoa.qpic.cn/sz_mmecoa_gif/tYBGQJ9TRKmFIILGaibFDkS34XqEkpLjjNmnO9DaxMqgjQBiaczN0icQqhBd0R6jaMk3gxHqQzgbrlvuTKia1FCPEQ/640?wx_fmt=gif)

规模将持续稳步增长。作为战略性新兴产业，新型储能对增强电力系统调节能力至关重要。尽管强制配储政策调整，但为了提升竞争力，新能源全面入市后将产生主动配储需求，加之容量补偿政策逐步出台、成本持续下降，新型储能发展正由“政策驱动”转向“市场驱动”。

  

技术路线将更趋多元化。“十五五”时期，锂离子电池凭借成熟度和成本优势仍将占主导地位，装机占比预计保持在90%以上，并向着大容量、长寿命、高安全及构网型方向发展。压缩空气储能、液流电池储能、钠离子电池储能、飞轮储能等新型储能技术将凭借在特定场景中的比较优势进一步实现商业化发展。为满足跨日、跨季节等更长时间尺度的调节需求，热储能、氢储能等长周期新型储能技术有望得到规模化示范应用。

  

电网规划思路与时俱进。新型储能规模化发展将改变电网规划边界，电网规划需将新型储能纳入电力电量平衡，并考虑其有效容量系数及饱和效应。储能可通过削峰填谷改变传统负荷特性，缓解供电压力。电网企业可通过引导新型储能合理布局，解决电网部分节点重过载问题。

  

商业模式向多元化演进。从长期看，随着电力现货市场价差拉大、辅助服务市场品种增加（如备用、爬坡、惯量支撑等），以及虚拟电厂、绿电直连、零碳园区等新业态发展，新型储能盈利渠道将不断拓宽，商业模式日趋多元。

**可从规划引领、技术创新、拓展商业模式和完善市场价格机制等方面引导新型储能高质量发展**

![image](https://mmecoa.qpic.cn/sz_mmecoa_gif/tYBGQJ9TRKmFIILGaibFDkS34XqEkpLjjNmnO9DaxMqgjQBiaczN0icQqhBd0R6jaMk3gxHqQzgbrlvuTKia1FCPEQ/640?wx_fmt=gif)

加强统筹规划，引导新型储能科学合理布局。坚持需求导向，深入分析“十五五”及未来电力系统调节资源需求，综合考虑抽水蓄能、新型储能等调节资源，结合地区源荷发展规划、网架建设等实际情况，科学制定新型储能发展规模、布局和建设时序，因地制宜合理布局不同技术路线，在建设节奏上做好衔接，既保证充裕度，又为合理的市场竞争留出空间。

  

关注高安全性、长寿命、长时新型储能技术发展。加快研发电力系统专用长寿命、低成本、高安全性的新型储能技术，集中攻关大容量储能并网、构网型储能集成运行控制、规模化储能聚合调控等紧迫性工程应用技术，推动新型储能并网关键标准制定出台。打造新型储能领域全国重点实验室，构建大容量、高压化、构网型新型储能并网实证测试平台，培养国际一流的新型储能集成与应用综合实验能力。聚焦各类应用场景，关注多元化技术路线，鼓励创新技术试点示范，推动新型储能技术产学研用一体化发展。

  

创新应用场景和商业模式。从技术应用、系统协同、机制保障等多维度协同发力，创新新型储能应用场景，推动新型储能发挥多重价值。在热能价值挖掘上，通过推广熔盐、相变等场景化储热技术、构建“储电-储热”联动系统；在制氢价值支撑上，探索富余电力制氢调峰模式并建立电价联动机制；在绿色价值转化上，强化新型储能对新能源电量消纳的支撑作用，将新型储能项目纳入碳减排与绿证体系，探索“新型储能+虚拟电厂”低碳服务，把新型储能的低碳效益转化为可量化的环境与经济价值。

  

完善新型储能参与市场机制和容量补偿机制。研究完善新型储能参与电力市场的实施细则，引导电源侧储能与新能源作为整体参与现货市场交易，提升辅助服务市场补偿标准，探索新型储能参与爬坡、备用、惯量等交易。建立完善的容量补偿机制，合理扩大现货市场限价范围，提高储能电站收益。
