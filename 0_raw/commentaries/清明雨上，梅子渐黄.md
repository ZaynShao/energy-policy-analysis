# 清明雨上，梅子渐黄

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/MXc0xWvrXHeABpwGufvOsF56Cz65FTQxLTNalEOPzGvajVFJUIibA0BdojwjzCTgjjsNBQlNMcqAwhXBibsmmTzZQ8xerQfG473OpGdtHlTWg/640?wx_fmt=jpeg&from=appmsg)

文/石头梅子也被称为青梅或酸梅。“梅子成阴，海棠初谢，小园才过清明。”青梅在清明前后开始挂果，但不等它成熟便被忙碌的人们采摘，趁着“半青半黄”之际经过一番加工后退去酸涩，呈现微酸沁甜、酸甜相宜的风味。古时作为进贡给皇家贵族的珍品，今日的梅子已成为寻常可见的食物。梅子可作消遣零食，也可以加入甘草、山楂、陈皮以及洛神花煮酸梅汤。“妾发初覆额，折花门前剧。郎骑竹马来，绕床弄青梅。”李白的《长干行》家喻户晓，诗中“青梅”象征着两小无猜爱情的青涩美好。今时，也有歌手从产自顺德、作为广式烧鹅“最佳伴侣”的酸梅酱中得到了灵感，将带有些许青涩的爱情比作酸酸甜甜的梅子酱写入歌词中，回味那份美好。![image](https://mmbiz.qpic.cn/mmbiz_jpg/MXc0xWvrXHcsgIKeb2zKmibZIwBJlV9jn3e3gjTnw2PyribJR6aslATppcSzOIIYfjJPxsXw7lr6OR5cS3qAYk2JczvwuvMwCficuy6GgU1gDQ/640?wx_fmt=jpeg&from=appmsg)

《本草纲目》记载：“梅实采半黄者，以烟熏之为乌梅，青者盐淹曝干为白梅，亦可蜜煎、糖藏，以充果饤......惟乌梅、白梅可入药。 ”《尚书·说命》中有“若作和羹，尔唯盐梅”。梅子乃是调味所需，是古时制作羹汤类美食的必备材料，小小的梅子除了盐渍当佐料、糖渍做成果脯蜜饯，还可入药、入酒，用途颇广。众多古文典籍都记载了梅子的同一个特点，那就是五味之首——酸。《本草崇原》里写道：“梅花放于冬，而实熟于夏，独得先春之气，故其味酸，其气温平而涩，涩附于酸也。”《景岳全书》形容梅子：“味酸涩，性温平。”《本草纲目》记载其“所主诸病，皆取酸收之义”。清道光二十七年，久病成医的新科进士刘鸿恩喜用乌梅入药，后来被尊称为“乌梅先生”。他在50多岁时辞官，潜心研读历代医学著作，又系统地将自己诊治疾病的心得编成四卷《医门八法》，提出“即儒书以推医理，医理自明”；以阴、阳、表、里、寒、热、虚、实的“医门八法”治疗杂病。他开方时重视敛肝，乌梅为敛肝补肝之上品。全书62个杂病中，有52个病方选用有乌梅，他视乌梅为知己，自称“乌梅学究”。根植于中国本土几千年，梅子也被不少文人墨客赞颂。宋代汤恢在《八声甘州·摘青梅荐酒》中写道：“摘青梅荐酒，甚残寒，犹怯苎萝衣。”同朝代晏殊在《诉衷情·青梅煮酒斗时新》中写道：“青梅煮酒斗时新，天气欲残春。”陆游亦有诗云：“煮酒青梅次第尝，啼莺乳燕占年光。”淫雨霏霏，乍暖还寒，清明梅黄之际，青梅无疑是当仁不让“煮酒”的主角。不过这种陈酿后得到的黄色酒饮最初呈乳白色，“浊”得很，本质上类似于米酒。自汉朝有了酒曲及谷物配方，再到唐朝才拥有了真正意义上的“酒”。现在市面上的青梅酿属于低度果酿，口味甘甜，虽和三国时期的“煮酒”不同，但给人带来的“夏早日初长，南风草木香”闲适自在的心境却是一样的。
