# 每周AI信息参考：国家数据局将2026年数据工作明确为“数据价值释放年”

**01  国家数据局将2026年数据工作明确为“数据价值释放年”  
**国家数据局局长刘烈宏3月23日在中国发展高层论坛2026年年会上发表演讲表示，国家数据局将2026年数据工作明确为“数据价值释放年”，聚焦数据赋能人工智能创新发展，将深入实施强基扩容、标注攻坚、提质增效、应用赋能、管理服务、价值释放六大行动，力争形成一批高质量数据集，实现供给量、质齐升，使人工智能深入千行百业、加速人工智能与实体经济的深度融合。刘烈宏还阐述了4个人工智能发展新趋势：行业高质量数据集正取代通用语料成为决定模型落地效果的关键变量；人工智能正经历从数字模拟向物理交互的范式跃迁；Token“词元”不仅是智能时代的价值锚点，更是连接技术供给与商业需求的“结算单位”，为商业模式落地提供了可量化可能；安全合规成为AI治理焦点。3月24日，国务院新闻办公室就第九届数字中国建设峰会有关情况举行新闻发布会，国家数据局局长刘烈宏表示，国家数据局持续培育“为高质量数据付费”的市场共识，推动行业高质量数据集在数据交易所挂牌、上架、交易。支持数据流通服务平台、数据商等机构提供流通交易的服务，鼓励各类数据流通服务机构探索多样化的高质量数据集流通利用模式，推动高质量数据集供需有序对接，支持行业高质量数据集流动起来。刘烈宏介绍，到2026年3月，我国日均Token的调用量已经超过了140万亿，相比2024年初的1000亿增长了1000多倍，相比2025年底的100万亿，三个月时间又增长了40%多。日均Token调用量的大量增加，充分表明中国的人工智能发展进入了快速增长阶段，应用场景在不断深化，也标志着数据集的供给在大量增加，数据要素的价值在不断释放，数据要素赋能人工智能创新发展进入了良性互动的阶段。**02  张亚勤院士：当前人工智能发展主要呈现三大趋势  
**3月25日，在博鳌亚洲论坛“‘AI+’：数智赋能产业升级”分论坛上，中国工程院院士、清华大学讲席教授、清华大学智能产业研究院院长张亚勤提出，人工智能领域研究、技术、产品呈现融合特征，新一轮人工智能发展以数据和场景为核心驱动。当前人工智能发展主要呈现三大趋势：第一，从生成式AI迈向智能体AI；第二，从信息智能向物理智能和生物智能延伸；第三，从AI技术走向“AI+”。AI不再只是一项关键技术，而是融入各行各业的经济工具，代表一种“AI思维”，大小企业都需用AI思维进行管理，变革底层理念。张亚勤建议，所有智能体，无论实体机器人还是数字智能体，都必须对应明确责任主体，做到可追溯、可确权，厘清其归属方并承担相应责任。面对智能体等新技术新业态，需要科学家、工程师、企业家以及政策制定者、决策者等共同携手、通力合作。博鳌亚洲论坛2026年年会与会嘉宾认为，中国的人工智能发展已在国家战略、产业规模和技术能力方面形成较为完整的体系，处于全球AI发展的第一梯队。中国AI市场规模全球领先，应用场景涵盖制造、金融、智慧城市及互联网服务，形成大规模落地能力。**03  昆仑万维发布2026 AGI战略和三大核心模型  
**3月27日，昆仑万维在中关村论坛年会上发布2026 AGI战略。天工AI董事长兼CEO周亚辉发表题为《2026昆仑万维AGI战略发布：从全模态突破到AI平台经济》的演讲，提出昆仑万维2026年的AGI战略升级为“3+1”生态架构——以4个SOTA大模型为底座，支撑3个AI原生平台+1个超级智能体。其中，DramaWave、Mureka和猫森学园三个平台的底层逻辑是SOTA AIGC大模型×内容生产×内容分发；另外的“1”——Skywork Super Agents，则定义为面向全球所有内容创作者的操作系统。周亚辉表示，2028年是平台经济年，昆仑万维有望成长为一个AI native的平台经济体。昆仑万维首席科学家、香港中文大学教授成宇发布Matrix-Game 3.0游戏大模型、SkyReels V4视频大模型、Mureka V9音乐大模型，旨在推动游戏、视频、音乐领域从技术突破到产业落地。其中，Matrix-Game 3.0的创新在于通过“数据—模型—推理”协同优化，首次将开源世界模型推向带有记忆能力的长时序一致性+高质量+实时交互的统一框架。SkyReels V4取得音画一体双流联合生成架构、全模态理解和精准控制、全模态强化学习体系、攻克电影级画质与高效生成的平衡难题四大技术突破。Mureka V9在混音质量和整体听感等多个维度持续进化，迈向音乐创作意图的可控表达。**04  全球首个通用智能人“通通”3.0发布  
**3月29日，在2026中关村论坛年会通用人工智能论坛上，北京通用人工智能研究院发布全球首个通用智能人“通通”3.0和具身智能核心引擎“通脑”。相较于前代，“通通”3.0在空间智能、认知智能与社交智能三大核心维度实现跨越式升级。“通脑”旨在打通通用智能体与物理机器人的双向通路，通过构建“数据—大脑—小脑—本体”协同发展技术路径，推动具身机器人从遥控演示迈向自主决策、持续学习和跨场景泛化能力阶段。“通脑”将“通通”的核心技术优势迁移至多类型机器人中，通过融合全身运动控制、强化学习、世界模型与场景解译，让机器人拥有和物理世界交互的能力，让通用智能落地于现实世界。**05  OpenAI、谷歌、Anthropic三大AI巨头密集布局桌面Agent  
**OpenAI计划将ChatGPT平台、代码智能体Codex、浏览器产品Atlas整合为一款桌面超级应用，并计划收购为开发者打造Python工具的初创公司Astral。谷歌则在AI Studio全新接入Antigravity编码AI智能体，秘密内测代号为Janus的Gemini Mac桌面应用，首次为Mac打造原生AI客户端，重组了Project Mariner浏览器Agent团队。Anthropic上线Claude Code Channels，搭配Claude Cowork与Dispatch实现桌面文件操作与远程任务调度。三大AI巨头系列布局快速抢占开发者与企业市场，意味着桌面智能体竞争加剧。
