# 只因讲述巴以冲突，这个游戏被海外平台拒绝了300次。

居住在巴勒斯坦坦图拉村的卡德拉是一位正值新婚的母亲。
一天，他想给田间劳作的丈夫准备一个惊喜，一顿浪漫的早餐。
但当两人享用早餐之际，一群以色列士兵来到了村里，他们以“清除军事威胁”为由，将包括卡德拉丈夫在内村民带走，然后开火枪决。
在惨叫和枪声中，卡德拉目睹自己所爱的一切被彻底摧毁。
崩溃中她狂奔回家，抱起刚出生的婴儿襁褓，一路逃出村庄，可此时她才发现，襁褓里装着的不是婴儿，只是一块枕头。
这段故事来自尚未发售的众筹游戏《枕边之梦》，而它最大的特色是；这是一款由现居巴勒斯坦的开发者，以巴勒斯坦真实历史为原型而开发的巴勒斯坦游戏。
《枕边之梦》的核心机制是主角卡德拉错抱的那块枕头。
因为亲眼见证了屠杀，卡德拉患上了PTSD，在逃亡路途中，她不得不强迫自己相信枕头就是自己的孩子，只有这样才能感到一丝慰藉。
在游戏里玩家需要抱着枕头，以看清周遭现实，躲避敌人。一旦放下，黑暗就会袭来，让创伤吞噬一切，游戏也会GAMEOVER。
即便尚未发售，《枕边之梦》也已展现了完整的创意，美术风格颇为鲜明，按常理，这样的项目往往会被独游发行商看中，给予支持并顺利开发。
但游戏开发者拉希德·阿布埃德经历的却是被整个游戏业排挤，遗忘在世界边缘。
在提出《枕边之梦》前，拉希德·阿布埃德曾是一名软件工程师。
他曾给瑞典，沙特企业做过软件程序，人生的第一份工作甚至是给联合国系统做基础外包。
但因为国籍特殊，拉希德只能在约旦河西岸的巴勒斯坦定居点线上工作，闲暇时间他会自学unity，corona，作为工作的补充。
他曾想过投身游戏，但因为种种现实困难，拉希德始终不能下定决心，只是将游戏当成爱好。
一切变数发生在2014年。
那一年，加沙战争打响，拉希德在电视上亲眼看到加沙地区被导弹轰炸。其中有一幕，是父亲失去孩子后在残垣中绝望哭泣。
拉希德此时刚成为一名父亲，这些画面让他不得不问自己，假如这事发生在他身上，他能承受吗？
他选择用游戏寻找答案。
在《枕边之梦》立项前，拉希德制作的首款与巴勒斯坦有关的游戏名为《莉亚与战争阴影》。
游戏的美术和玩法借鉴自拉希德本人最喜欢的游戏《Limbo》，用UNITY制作。
玩家扮演一位巴勒斯坦父亲，试图带着女儿逃离轰炸。
游戏流程仅有十分钟，逃亡时，玩家会能看到飞机和导弹轰炸城区，电场和医院。白磷弹在天空洒下形成致命的死亡空间。
流程里，玩家会遇到不同的选择，但无论怎么选，结局都以莉亚死亡而告终。
因为拉希德认为，大多数战争游戏总会给玩家力量和胜利，但《莉亚》不同，它需要让玩家感受到身为平民的无力——即使你做出了看似正确的选择，也不能救下任何人，这就是巴勒斯坦难民所经历的。
2016年，《莉亚》以免费形式上架IOS和谷歌商店，即便作为游戏来看流程极短，玩法也较为单调。但游戏中对巴勒斯坦难民近乎白描式的展现依然引起了许多共鸣，在谷歌商店拿到了4.7的高分。
评论区清一色好评，玩家通关后都不免动容。
《莉亚》还获得了国际移动游戏大奖东北非赛区的“最佳叙事”奖，让拉希德一度成为国际上最知名的巴勒斯坦独立游戏开发者之一。
但当它试图用荣誉背书，为后续的《枕边之梦》企划寻找发行商时，迎接他的却是无情的拒绝。
根据拉希德统计，他一共被全球发行商和各种文化基金拒绝了近300次。他试图获得发行商们的开发支持，或者为他的游戏提供一个方便的销售渠道。
但结果却事与愿违，有的发行商认为拉希德的游戏在政治上过于敏感，有的则认为它缺少商业价值。
也有一些的发行商在认真看过《枕边之梦》DEMO后，给出了不错的评价，觉得游戏画面成熟，玩法有创意，但结果一样是不提供任何资助。
因为仅仅是冠上“为巴勒斯坦游戏做发行”名声，就已经是整个公司不能承受的风险。
拉希德的遭遇其实并不特别，长久以来，围绕巴勒斯坦开发者的荒诞层出不穷。
在一位油管博主的采访里，拉希德这样说：
“作为巴勒斯坦人，我们就像从地图上抹去了一般，访问任何网站都找不到我的国家。银行系统完全没有，连想出售游戏的方式都几乎没有.....讲述巴勒斯坦人的故事，似乎一直是一件被禁止的事情。”
对于地球上绝大多数地区的独立游戏开发者来说，一款游戏的失败通常意味着游戏卖不出去。
但在巴勒斯坦，开发者需要首先证明，自己的国家和身份在这个地球上是否存在，自己的游戏是否能被允许开发。
早在2008年，名为哈立德·阿布·阿尔的巴勒斯坦开发者就曾尝试在线上商店发行一款名为《iHang》的猜词游戏。
这款游戏不包含任何关于战争，难民，甚至没提到巴勒斯坦一个字，但在注册开发者账户时，依然无法通过审核。
平台无法识别他的银行，也无法把游戏收入汇入他的账户。哈立德尝试前往约旦开设银行账户，但依然因为身份问题没有成功，游戏最终也没有发行。
对于一些政治化的指控，拉希德也曾表示疑惑。
“（有些人）认为这款游戏带有政治色彩，（但很奇怪）这款游戏中没有（加入）任何国家标识，一切都只是在讲述一个父亲想要保护家人的故事。但对他们来说，这却是政治性的。”
因为无法获得融资，拉希德只能经营一家坚果店维持生活，《枕边之梦》拉希德也没有放弃，但只是作为副业。
2024年，拉希德看到了众筹。他最初试图选择kickstarter 与indiegogo这些成熟的“众筹平台”，但和之前一样遭遇了失败。
最后他被迫选择了LaunchGood，这是一个面向穆斯林募捐的小众平台，拉希德选择它的理由，是因为网站注册时允许选择巴勒斯坦地区。
除了用社交平台宣发，《枕边之梦》在众筹页面也事无巨细的陈列了游戏规划。
游戏整体背景是1948年的5月15日，那一天被巴勒斯坦人称“Nakba”，即阿拉伯语中的“灾难日”。
游戏里把枕头当做孩子的母亲，灵感则取自巴勒斯民间故事。
拉希德筹集的金额比例有明确的分配列表。
比如美术考据，关卡设计，工作室的成员构成，游戏开发所需要的时限等等。
整个项目规划严谨，目前看不出虚假的迹象，而这也延续到游戏本身的另一个特色——大量还原的真实照片。
拉希德把团队考据的大量巴勒斯坦历史信息都放在了众筹页面。
从1948年坦图拉的村庄地图，到游戏逃亡时会经过的各个城市。
数个巴勒斯坦工业区，海岸，遗迹，历史细节，文化符号，甚至是后来人们找到的“万人坑”，游戏均以半写实的方式进行了还原。
就像《刺客信条》还原各个时代地区的历史风貌一样，拉希德希望《枕边之梦》也能还原真实的巴勒斯坦历史。
真实，是拉希德想要表达的核心立场。
用它自己的话说，他想讲的是一个已经发生的故事和已经发生的事实，游戏中一切象征性的表述不为别的，都是为了展示“事实。”
可能是因为在游戏圈多年的遭遇，让拉希德非常清楚，相比容易被曲解且带有偏见的政治内容，游戏更应该以中立普世的角度讲述。
所以在一切文字或视频采访中，拉希德会极力避免政治话题的表达。他会避开当下巴以冲突的讨论，然后以“人性”和“理解”的角度来引导采访话题。
“村庄被毁，难民失去家园，这些被迫迁徙带来的心理创伤，会对他们的意识和灵魂造成深刻的影响....
所以我们讨论的其实是关于人性的一面（而不是政治），是那些在灾难中幸存下来的人们的影响.....我只是想用这种真实的方式来表达，但我没法控制世界上其他人怎么想”
当然，偶尔他也会提到游戏想表达的另一层内核——他看到很多欧美游戏会将阿拉伯人塑造成恐怖分子，杀戮他们是英雄行为，这些游戏中的阿拉伯人，只是像工具人一样用来美化战争。
但他最气愤的还不是这些偏见和曲解，而是这些游戏的开发商明明做了那么多中东背景的关卡，却没人愿意多花一百美元，来认真校对一下阿拉伯语。
所以拉希德需要用自己的游戏，主动挑战这些刻板印象，改变人们对阿拉伯人的看法。
其实在整个众筹计划里还包含一个副本，假如拉希德失踪、监禁或者死亡，游戏会以某种方式继续推进。
因为拉希德现居的约旦河西岸，军事逮捕和暴力事件依然层出不穷。
在当下，靠着坚果店为生的拉希德，每天经过的道路常常受到暴力活动的影响，他需要频繁经过以色列检查站，很多时候，自己和顾客都没法安全抵达，店铺也时常空置。
他无法保证自己一定能活到游戏完成。
但他希望即使自己不在了，这个故事仍然够抵达玩家面前。
写到这，我不免想起另一款很喜欢的游戏《皇牌空战：贝尔卡战争》。在这个游戏结尾，玩家需要面对最终BOSS“片翼精灵”。
和传统游戏里试图毁灭或称霸世界的反派不同，“片翼精灵”想做的是通过引爆核战，来消灭“国家”和“民族”的概念，最终一劳永逸的解决人类无止境的争端。
在战斗中，片翼精灵还会通过战斗机无线电质问玩家——“在空中，你能看到国境线吗？它给我们带来了什么”。
在《皇牌空战》的语境下，这句话是嘲弄主角总被看不见的国界线束缚，自己虽是反派，但本质是主角的一体两面。
从玩家视角出发，识破片翼精灵的诡辩并不难，但放在游戏行业，巴勒斯坦开发者却似乎正被这道“看不见”的国界线真正束缚着。
单论游戏本身，《枕边之梦》注定不会成为大作，能在2026年登录STEAM页面，对拉希德就已是极大的成功。
但在游戏之外，《枕边之梦》或许还有更特别的价值。
它在用特殊的身份冲击着虚拟和现实的边界。
它也在提问，在没有真正战火的游戏世界，思想和理念是否能被立场和政治扼杀？
这个问题或许没有完美答案，但拉希德在尚未封禁的INS上曾给自己的坦图拉村原画评价了这样一句：
“坦图拉村海岸在历史上美的令人窒息，仿佛置身夏威夷，巴勒斯坦是失落的天堂，那里的人民从未忘记他。”
