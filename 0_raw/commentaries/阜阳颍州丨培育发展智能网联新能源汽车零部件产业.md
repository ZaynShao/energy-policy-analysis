# 阜阳颍州丨培育发展智能网联新能源汽车零部件产业

安徽省阜阳市颍州区人民政府办公室近日印发《颍州区国民经济和社会发展第十五个五年规划纲要》，《纲要》主要阐明“十五五”时期经济社会发展指导思想、主要目标、重点任务和保障举措，引导规范经营主体行为，是政府依法履行职责的重要依据，是全区人民共同奋斗的行动纲领。
《纲要》明确：
着力培育省级新质生产力产业基地——智能网联新能源汽车：抢抓省委、省政府支持汽车零部件产业向皖北地区延伸布局政策机遇，主动对接、积极融入、差异发展，培育发展智能网联新能源汽车零部件产业。聚焦核心零部件领域，重点布局电机、线束、传动件、轻量化车身和结构件、电驱动系统等。把握汽车智能化与网联化发展趋势，重点布局智能座舱域控制器、车载显示模组、车载语音交互系统等部件，大力发展车载操作系统、驾驶辅助系统、车载娱乐系统等车载软件。围绕智能驾驶与车路协同领域，依托园区等封闭场景，提升在特定场景下的系统解决方案能力。引育后市场优质服务企业，鼓励智能网联新能源汽车服务业多元创新。
