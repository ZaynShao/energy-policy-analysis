# 产业向新、结构向优！深圳外贸稳健有韧性

//盐田港码头，集装箱有序装载上船发往全球各地。（盐田国际集装箱码头有限公司 供图）
近日，深圳市2025年国民经济和社会发展统计公报（以下简称“公报”）发布。数据显示，2025年，深圳外贸顶压前行，全年进出口总额45533.89亿元，比上年增长1.4%，其中，出口略降，进口高增，高新技术产品与外商投资企业双爆发，呈现整体稳健向好，产业向新、结构向优发展的显著特征。
总额创新高，结构再优化
公报显示，2025年深圳外贸总额45533.89亿元，创历史新高，持续位居内地城市首位。其中，出口27387.81亿元，下降2.6%；进口18146.08亿元，增长8.0%，进口连续三十三年居内地大中城市首位。在出口微降的情况下，高新技术产品却逆势大增，出口12765.95亿元，比上年增长10.1%，占出口总额比重达46.6%。
对于2025年深圳外贸“出口微降，进口高增”“高新技术产品出口飙升”的原因及释放的产业信号，中国（深圳）综合开发研究院前海分院副院长、可持续发展与海洋经济研究所所长胡振宇分析指出，2025 年深圳外贸出口回落主要受全球主要经济体通胀高企、需求收缩，外部市场整体偏弱，部分传统劳动密集型产品竞争力下降、贸易壁垒与供应链重构等因素影响，属结构性调整期间的正常波动。进口高增则与高新技术产业扩产、内需持续恢复、稳外贸政策落地见效等有关。
从进出口产品结构看，2025年，深圳高新技术产品出口大增，占出口总额的46.6%。进口方面，随着高新技术产业扩产，核心零部件、先进设备、关键原材料进口需求上升。同时，受内需持续恢复带动，能源、消费品、中间品进口增加。显示高附加值产品已经成为深圳外贸核心支撑，出口正从规模优先转向质量优先，进口结构正逐步从“消费品”为主转向“生产资料、技术设备”为主，以及内外需协同驱动、产业链升级提速、技术竞争优势正在逐步替代成本优势等诸多向好、向优变化，释放出贸易格局更趋合理的积极信号。
新设外资企业同比增长超6成
2025年，外商在深投资企业活力迸发，增速创近年来新高。全年新设立外商直接投资企业15906家，比上年增长63.3%。实际使用外商直接投资金额504.84亿元，其中东盟国家实际投资金额为45.97亿元，增长55.0%。
胡振宇指出，这与深圳整体营商环境，市场化、法治化、国际化程度，以及高端产业集群集聚、RCEP生效、大湾区规则衔接等产业及政策红利有关。随着全球供应链“近岸+友岸”重构，深圳成为亚太供应链核心节点，也是吸引外资布局的重要原因之一。
“随着全球资本配置中国核心资产趋势不变，深圳高新产业与制度优势的持续吸引，外企进出口有望稳步回升至历史高位，中长期保持高景气。”胡振宇表示。
新业态加速崛起，其它贸易出口高增
在贸易方式上，数据也呈分化态势。2025年，深圳以一般贸易出口的货物总额为15689.29亿元，同比下降7.8%，以加工贸易、其他贸易出口的货物总额为5286.48亿元、6412.03亿元，同比分别增长1.3%、9.2%。
“这是外贸市场化、多元化、高端化转型的必然结果。”胡振宇分析指出，一般贸易下降，主要受国际市场对传统商品需求放缓影响。加工贸易微增得益于深圳产业链升级带动精密制造、高端加工回暖。而跨境电商、市场采购、保税维修等其他贸易的大增，则折射出外贸新业态的强劲爆发力。
跨境电商、市场采购贸易及海外仓等新模式的发展演进，大幅降低了贸易门槛与成本，助力企业快速拓展海外中小客户市场。随着全球供应链的重构，保税维修、研发进口替代等推动贸易形态持续创新，各类新业态加速涌现。与此同时，外贸企业积极调整外贸策略，从过去依赖传统大宗的一般贸易，转向小批量、多批次、高灵活度的新型贸易，多种因素共同推动其他贸易形式成为新的增长极。
胡振宇认为，未来，深圳的贸易方式将持续维持多元化发展格局，一般贸易仍将占据主体地位，新业态贸易成为增量主力，推动外贸整体结构韧性稳步增强。（深圳商报·读创客户端 记者 罗凯燕）
