# 红杉中国，投资张雪机车了

中国风险投资史上有很多outlier，张雪机车就是其中一个。
在很多人看来，风险投资行业最浪漫的地方就在于，它始终着眼于未来，愿意相信人们的理想、执着、努力这些人类进化过程中，最重要的品质。在这样的设定下，张雪机车作为一个充满理想、执着、努力的创业故事，在此之前并没有太多中国VC的身影，实在是有些让人遗憾的。
好在，故事还在继续。就在刚刚，投中网独家获悉，张雪机车获得了红杉中国的新一轮独家投资。
双方对投中网表示，此番合作将围绕企业治理、人才建设、产业资源和全球化发展等方面。张雪机车将继续聚焦发动机、整车、产品研发和赛事验证，而红杉将结合自身在企业治理、人才网络、产业生态和全球资源方面的经验，为公司的长期发展提供支持。
张雪表示：红杉中国的加入，为张雪机车增加了一位能够长期同行的伙伴。接下来团队会继续把发动机和整车做好，继续上赛道验证，也继续听用户的真实反馈。中国高性能摩托车有机会赢得全球用户，这件事需要耐心，也值得长期投入。
红杉中国合伙人苏凯认为：张雪对产品近乎执着的追求——那份对机车和赛车的长期热爱，让张雪既懂用户，也愿意为产品长期投入。我们相信，世界级产品往往诞生于对极致永不妥协的追求。红杉愿意与这样的创业者长期同行，一起挑战世界级的产品和世界级的赛场。
张雪机车的这半年
其实早在今年4月，就有老股东剧透了张雪机车的新一轮融资，而且估值攀升速度惊人。
从无人问津到争先恐后，是什么支撑起了这样的K线？最容易想到的答案，就是“热度”。这也没错，自今年3月首次在WSBK（世界超级摩托车锦标赛）的WorldSSP（中量级竞赛）组别中首次夺得冠军之后，张雪机车陆续在5月2日的匈牙利站、5月16日的捷克站、6月13日的意大利站分别拿到了冠军。其中在捷克站，张雪机车刷新了赛道圈速记录。在意大利米萨诺站，张雪机车跑出了当日单圈最快车速。
这些成绩是足够帮助张雪机车维持“出圈”状态的。一个具体的例证是，在知名体育内容社区直播吧，5月17日张雪摩托夺得赛季第5冠的战报评论接近4000条，6月13日夺得赛季第6冠的战报评论量超过了3500条。这个数字显然赶不上受众最广的足球篮球，但也明显碾压了网球、斯诺克、乒乓球这些人们印象里认知度更高的运动。只有4月份赵心童与丁俊晖在斯诺克世锦赛上的世纪大战、7月世界女排联赛总决赛中国女排奇迹逆转美国女排的评论量，和张雪摩托的战报持平。
但这是竞技体育的逻辑，风险投资人不会按照竞技体育的逻辑来评价张雪机车。实际上相比起张雪机车在半年内6次夺冠，一个更值得关注的数据是在没夺冠的比赛中，张雪机车也分别夺得过第4（荷兰站）、第7（阿拉贡站）、第8（英国站）这样的名次。而WSBK单站发车参赛的选手大约在20-25人之间。
这意味着张雪机车通过不断参赛，完成了一个消费品牌成型过程中的最关键验证：稳定性。冠军之外大量的中等偏上的名次，非常具体地证明了张雪机车能够在不同赛道、不同性能平衡条件下都能维持稳定的高性能状态。基于这个前提进一步推论，张雪机车似乎具备了规模化量产、面向普通消费者市场的条件，理应给出更高的估值。
事实上在过去的半年时间里，张雪机车也确实在“爬产能”。
根据公开报道，自年初以来张雪机车就在推进扩产计划，尝试将原本年产2万台、日产200台的一期基底扩大至年产300万台。6月，张雪机车以4848万元拍下了重庆两江新区J10单元05街区001地块，并于次月与供应商签署合作协议，准备将这块用地建成“年产50万台”的“摩托车研发生产基地”。曹斌也在凤凰财经的这次专访透露了类似的消息，表示“高信资本原本预计公司需要3至5年才能进入稳定经营状态，实际发展速度远超预期”“目前单月交付量已经突破1万台”。
另外实际上在过去的半年时间里，张雪机车曾经有过两次重大产品安全事件。一次是820RR上市后发现泄压阀O形圈装配错误，因此紧急召回了首批交付的286台机车。另一次是820RR在交付后，部分车主反映辆怠速时机油泵供油不畅，暂停生产和交付。
这两次产品安全事件后，张雪机车先是重新设计机油泵、修改模具，并为车主提供免费更换、保养和延长质保，随后又在7月进行了服务渠道调整，包括且不限于张雪个人社交平台账号私信停止处理用户咨询、不再通过抖音受理订单查询、售后、维修质保和故障反馈、相关业务统一转向张雪机车APP、官方小程序等正式渠道等等。
从品牌的逻辑来看，这完全可理解成张雪机车完成了成立以来，第一次完整地、以规模化销售、面向普通消费者为前提，建设了销售体系和售后体系。再具体到风险投资人的视角，当一个品牌从产品到服务体系都做好了进入市场的准备，估值是完全有理由看涨的。
为什么是红杉中国？
不过相比起张雪机车的“热度”，真正让人感到意外的是红杉中国。
近几年来，人们早就习惯了将红杉中国和科技联系在一起。尤其是2025年年底红杉中国推出了全新的视频播客栏目《the prompt》，第一期节目的主题还是《AI时代如何发生》，全面拥抱AI的姿态非常彻底。而关于张雪机车的崛起，人们的共识是这是“中国制造的胜利”，是完整且过硬的产业链+庞大且扎实的人才储备，才让一个从前公司净身出户且只有初中学历的中年人，拥有了白手起家追赶一线品牌的可能。
事实上，红杉中国一直在大消费领域持续活跃布局，自2025年以来参与股权投资或者并购的知名品牌就包括老牌音响品牌马绍尔（Marshall）、智能床垫独角兽Eight Sleep、情感陪伴潮玩Fuzozo芙崽、AI智能项链OdyssLife、户外外骨骼品牌Hypershell，以及智能眼镜的新晋独角兽Even Realities等。而在此之前，泡泡玛特、鸣鸣很忙也都是红杉在消费领域的代表项目。
红杉中国的投资团队也在近几年的一系列播客、圆桌对谈和专访中对投资“消费类科技产品”的逻辑有过详细表述。例如在今年1月更新的视频播客《硬件投资进化论：热赛道与反共识》里，红杉的投资人就曾经提到，红杉早在2023年底就形成了一个认知，制造业快速发展带来了明显的“技术下放”，成本、供应链能力也在同步改善。在这个前提下，消费电子领域已经具备了活跃投资的前置条件。此前消费电子领域的预冷，只是过去缺乏足够成熟、足够便宜的技术去实现，很多消费需求长期存在。
“前几轮中国消费电子出海主要出售制造效率和性价比；现在创业公司开始有能力定义新品类、制定价格，并从一开始进入全球高端市场”。
这些判断与张雪机车的发展轨迹能够做到一一对应的，包括“出海定义高端市场”这个看起来最高难度的环节其实也进入了验证阶段。据报道，早在6月24日张雪机车就完成了对欧洲市场的首批出口，从重庆果园港启程，经上海运往波兰。虽然目前并没有公布实际的订单量、具体型号、用户反馈，但能够完整走完“海外订单、出口报关、批量发运”已经是不错的起点。
可以说，作为中国市场嗅觉最敏锐的风险投资机构，作为最能诠释中国制造业发展成果的消费品牌，红杉中国投资张雪机车基本就是逻辑上的必然。唯一的悬念就是在拿到最新的一笔融资后，张雪机车将把充足的弹药用在哪里？
从现有的资料来看，最重要的可能还是产能。张雪机车曾经在2026年年初进行过年度规划，提出了销量5万到6万辆、产值18亿元左右的目标，而实际上2025年——也就是第一个完整销售年度——张雪机车交付的产品大约为25000辆。也就是说顺利实现年初规划的交付目标，意味着张雪机车需要一年内实现产能翻番。而在扩产能的过程中，仅新生产基地的地皮就花费了超过4000万元的投入，张雪机车也不仅仅希望这块新的基地“仅供生产”。根据规划，两江新区的这块基地“集制造基地和研发中心于一体”。
想要顺利推进这一切，张雪机车都有必要储备足够的资源，为成为“真正大厂”之后的各种不确定性做足准备。从这一点来看，见证了无数“从1到100”的红杉，也确实是最好的一个选择。
