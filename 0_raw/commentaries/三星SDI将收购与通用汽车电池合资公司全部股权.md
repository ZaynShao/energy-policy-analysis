# 三星SDI将收购与通用汽车电池合资公司全部股权

加入供应链产业群，请加微信gasgoo88，出示名片
盖世汽车讯 8月11日，韩国电池厂商三星SDI表示，鉴于电动汽车需求不及预期，公司将终止与通用汽车在美国印第安纳州设立的电池合资企业协议，并收购通用汽车持有的49.99%的股权。
三星SDI在监管申报文件中称，计划将这家合资企业（SDI-GM Synergy Cells Holdings）转为全资子公司，以此应对储能系统、电动汽车等多领域的电池市场需求。该公司表示，随着企业转为全资运营，原有投资计划将作出调整，但具体投资方案尚未敲定，后续将按照监管规定另行披露。
图片来源：三星SDI
三星SDI在声明中指出：“作出股权结构调整，是考量双方合资项目官宣以来市场环境发生的变化，其中包括电动汽车需求增速低于预期。双方现已决定，不再依托合资公司开展合作，转而探索其他合作模式。”
另外，三星SDI公司还透露，已与通用汽车签署协议，联合研发下一代方形电池，未来有望应用于电动汽车领域。路透社今年早些时候曾报道，受电动汽车需求疲软影响，该工厂建设进度有所放缓。该合资项目于两年前对外公布，最初规划年产能27GWh，目标是2027年实现量产。
去年9月美国最高7,500美元的联邦税收优惠政策到期后，通用汽车等多家车企缩减了电动汽车生产规模。车企虽持续生产并销售电动车，但已下调工厂产能以匹配市场需求。
值得注意的是，今年3月，通用汽车与LG新能源同样宣布，计划改造美国田纳西州另一座电动汽车电池工厂，转而生产储能系统电池。
