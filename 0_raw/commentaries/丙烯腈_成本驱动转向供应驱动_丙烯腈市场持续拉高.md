# 丙烯腈 | 成本驱动转向供应驱动 丙烯腈市场持续拉高

3月初以来，受到中东局势冲突影响，丙烯腈上游端原油、丙烷及丙烯等供应趋紧，同时原料价格整体大幅上涨，成本端压力及生产缩量隐忧下，丙烯腈供应商被动推高报价，现货市场价格亦在恐涨氛围中快速上推。与此同时东北亚部分装置停车或降负，海外供应已然缩紧，外盘价格高涨则再度刺激国内市场追高。截止到4月初国内丙烯腈市场价格跃上12000元/吨，达到自2022年初以来的最高水平。此轮丙烯腈价格开启上涨以来，涨幅达到4700元/吨，增长比63.1%。

不过，丙烯腈价格持续高涨亦引发下游用户抵触情绪，产业链成本向下传导不畅，下游行业尽管有跟涨但涨幅偏缓，各行业利润已然显著压缩，其中腈纶及ABS行业理论利润再度呈现负值表现，也因此两大下游领域工厂采取降负措施，内需整体表现减弱。供需差来看，3月份国内供需差有所扩大，如图2所示。不过由于外盘价格高涨刺激出口增加，丙烯腈国内行业库存仍保持下降表现，供应商销售亦无压力，从而给予涨价条件。

3月底开始，海油富岛20万吨丙烯腈装置如期停车检修，浙江石化一套装置也因故停车，接下来吉林石化部分生产线及科鲁尔化学亦有检修计划，预计4月份中旬国内丙烯腈行业产能利用率将降至七成偏下水平，供应缩量将逐步落地。但同时接下来腈纶及ABS行业开工负荷下降，需求亦有减弱预期。不过4-5月份出口量或相对可观，预计4-5月份供需差仍保持较低水平，支撑丙烯腈价格保持高位运行，此外需关注原料丙烯价格走向。
