# 四川：支持算力园区开展绿电直连，数据中心可参与电能量/辅助服务需求响应等

「储能与电力市场」获悉，8月13日，四川省发展和改革委员会等部门关于印发《四川省推进算力网建设的若干政策措施（试行）》的通知（川发改数据〔2026〕338号）发布。
通知指出，优化全省算力区域布局，打造攀西—川西北算电融合发展带。支持凉山、甘孜、阿坝、攀枝花依托清洁能源资源，统筹布局“源网荷储”一体化大型算力设施，打造重点承接模型训练、大数据分析、影视渲染、数据备份等非实时、可迁移算力需求的算电融合发展带。建设算电融合零碳算力园区。鼓励整合攀西—川西北水风光储资源，在甘孜新都桥、阿坝红原、凉山盐源等地集中布局建设零碳算力园区。支持算电融合项目和算力园区采用绿电直连（含单用户和多用户）供电模式，余电上网比例可放宽至20%，支持开展多用户绿电直连；按直供新能源配置规模的2倍给予算电融合项目运营企业（仅限一个投资主体）额外新能源配置规模。新能源就近消纳项目暂按下网电量缴纳系统运行费、三项价差费用（燃煤机组运行成本补偿费用分摊、燃气发电上网电价与市场价格间的价差费用分摊、省间外购差额资金分摊），自发自用电量暂免缴纳政策性交叉补贴新增损益。降低用电成本。支持数据中心作为电力市场主体参与电能量、辅助服务、需求响应等市场化交易，优化批零传导机制，推动数据中心根据市场价格信号灵活调整用电时段，以市场化方式降低用电成本。鼓励有关地方按规定将留存电量优先用于算力企业。对2027年底前已建成或实质性开工的受限断面内万卡集群算电融合项目免收高可靠性供电费用。提质建设一批算力产业园区。鼓励有条件的地方依托现有算力园区提质建设一批城市边缘算力设施，重点支持雅安大数据产业园、德阳天府数谷、中国（绵阳）科技城人工智能产业园、内江东兴区算力产业园、宜宾长江上游大数据产业园、达州数字经济产业园等提档升级、加快建设。完善算力园区基础设施建设。推动通信骨干网、城域网与算力园区直连，加快实施“毫秒用算”专项行动计划。统筹布局算力园区主供电源和备用电源，支持算力园区建设智能微电网。通过地方政府专项债券、政策性金融工具等优先支持符合条件的算力园区基础设施建设。支持建设算力调度平台、算力超市、词元（Token）工厂等算力公共服务设施，省级预算内基本建设投资按照项目核定总投资的15%给予支持，单个项目支持额度不超过1000万元。支持建设万卡集群。重点招引基础电信运营商、头部模型大厂在成都平原算力核心区、攀西—川西北算电融合发展带布局建设万卡级以上智算集群，综合应用财政、金融、绿色电力等政策工具支持大型、超大型算力设施项目落地。对集群范围内符合有关条件的大型及以上算力中心建设项目，省级预算内基本建设投资按照项目核定总投资的15%进行支持，单个项目支持额度不超过1000万元。责任编辑：尹思琦
