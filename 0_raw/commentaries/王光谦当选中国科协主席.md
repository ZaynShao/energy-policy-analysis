# 王光谦当选中国科协主席

王光谦当选中国科协第十一届全国委员会主席。
中国科学技术协会（中国科协）第十一届全国委员会第一次会议7月11日上午在北京举行。
▲中国科协两任主席握手。中新社记者 孙自法 摄
会议选举产生中国科协新一届领导机构，王光谦当选中国科协第十一届全国委员会主席，尤政、包为民、冯身洪、乔杰（女）、向巧（女）、李路明、吴骊珠（女）、陈卫、陈薇（女）、陈学东、陈建峰、贺军科、莫则尧、徐涛、高鸿钧、廖湘科等16人当选副主席。
于俊清等56人当选中国科协第十一届常务委员会委员。会议通过授予中国科协荣誉职务决定，授予万钢中国科协名誉主席、马伟明等33人荣誉委员职务。
王光谦简历
王光谦，男，汉族，1962年4月生，河南镇平人，民盟成员，1989年12月参加工作，清华大学水利水电工程系水力学及河流动力学专业毕业，研究生学历，工学博士学位，教授，中国科学院院士。
现任十四届全国政协副主席，民盟中央常务副主席。
