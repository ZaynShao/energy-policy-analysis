# 国务院国资委党委书记、主任程福波到中国石油调研

8月14日，国务院国资委党委书记、主任程福波到中国石油调研保障能源安全、科技创新和产业发展、深化改革和党的建设等工作。
程福波深入了解企业智能运营中心运行情况，与集团领导班子座谈交流，并听取工作意见建议。他指出，中国石油的发展史是一部艰苦奋斗的创业史，见证了我国石油工业从弱到强发展历程。特别是近年来企业坚决落实党中央、国务院决策部署，积极应对国际局势动荡、行业形势变化，持续加强油气勘探开发和增储上产，形成国内原油产量、国内天然气产量当量、海外油气权益产量当量“三个1亿吨”格局并不断巩固，有力保供应、稳市场，高质量发展迈出坚实步伐，充分彰显了能源保供“顶梁柱”作用。
程福波强调，中国石油要突出抓好能源保供，加大增储上产力度，统筹高效勘探和效益开发，着力增强优质资源获取能力，把能源饭碗端得更牢；抓好转型升级，找准发展方向，提升自主创新能力，在深地深海能源、高端化工新材料等领域加强应用基础研究和基础研究，强化关键核心技术攻关，推动传统产业智能化、绿色化、融合化发展，因地制宜发展新兴产业，培育壮大新动能新优势；扎实推进稳增长提效益，保持对市场供应跟踪研判，及时调整经营策略，狠抓降本增效，合理扩大有效投资，提升高质量发展成色；抓好新一轮国资国企改革方案落地见效，加快构建与世界一流企业相适应的体制机制，进一步加强穿透式监管，压紧压实生态环境保护责任，坚决守住安全生产风险底线。要坚持党的领导加强党的建设，持续树立和践行正确政绩观，弘扬石油精神和大庆精神铁人精神，纵深推进全面从严治党，充分发挥高质量党建引领保障作用。
中国石油集团党组书记、董事长戴厚良在座谈时表示，中国石油坚决贯彻党中央、国务院决策部署，积极应对各种风险挑战，“十四五”整体基本实现高质量发展，“十五五”开局之年各项工作取得新进展新成效。中国石油将深刻领会和把握党的二十届四中全会精神，认真贯彻国家及中央企业“十五五”规划纲要，勇担“建设能源强国、赋能美好生活”战略使命，努力建设基业长青的世界一流综合性能源与化工公司；深刻理解、全面把握党中央对形势的科学判断和做好经济工作的重大决策部署，认真落实中央企业负责人研讨班部署要求，凝心聚力强创新、促转型、稳增长、抓改革、防风险，全面完成年度生产经营目标任务，努力实现“十五五”开新局、上台阶；锚定建成国家战略科技力量和能源与化工创新高地的战略目标，以支撑高质量发展为主题，以加快高水平科技自立自强、引领发展新质生产力为主线，以进一步全面深化科技体制机制改革为根本动力，探索无尽前沿、矢志创新攻坚，持续提升自主创新能力和科技实力，为建设能源强国、赋能美好生活提供强力支撑。
周心怀、段良伟、谢军、宋大勇，以及双方有关部门负责同志参加会议。
