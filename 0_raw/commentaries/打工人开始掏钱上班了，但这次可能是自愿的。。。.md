# 打工人开始掏钱上班了，但这次可能是自愿的。。。

腾讯今年靠着 WorkBuddy 来了一把逆风翻盘，谁急了我不说。
就在前几天，字节把飞书的产品团队拉进了豆包，负责跑市场的GTM团队，则是并到了火山引擎里。
但如果你以为这次整合，是因为飞书混得太差，那就格局小了。
字节这一手，明显是在为接下来的一场硬仗做准备。
这么说吧，去年大厂们还在一股脑往程序员的电脑里挤，忙着开发各种Coding Agent，但这半年，产品名字已经开始集体从 Code 变成了 Work。
真不是我瞎掰啊，除了字节以外，阿里最近把QoderWork、悟空和 MuleRun 整合成了一个千问 Work，腾讯眼看 WorkBuddy 势头不错，顺手也把 QClaw 的相关业务和团队也并进来了。
更早一些，百度推出 DuMate，月之暗面上线 Kimi Work，就连明明已经有 Codex 的 OpenAI，也另外做了一个 ChatGPT Work。
发现没，不管是模型厂还是互联网大厂，都开始往办公 Agent 上堆人、堆产品、堆资源。
但，为什么是办公Agent？
先说结论，倒不是因为代码不香了，而是办公的市场更大，money更好赚。
过去一年，什么Claude Code、Codex、Vibe Coding火得不得了，大伙儿都在讨论AI Coding的出现是不是要给程序员干死了。
但现在回过头来看，AI Coding 更像是一场范围有限的试验，验证的是 AI 到底能不能替程序员工作。
AI Coding再火，服务的也只是一个相对垂直的人群，程序员、极客、Vibe Coding爱好者终究还是少数人，会高频写代码的人那就更少了，很难成为几十亿人每天都会打开的产品。
你要问什么场景用 Agent 的频率更高？那当然是一周 5 天、每天 8 小时起步、一上就是几十年的班啊。
前阵子世超看了个报告，说是今年 6 月份，中国 PC 端 AI 原生办公智能体市场的总访问量突破 6000 万次。
这意味着，已经有相当一部分人把工作交给 AI 去做了。
注意啊，这里说的把工作交给 AI，不是简单的让 AI 写份周报、查个资料，这么说吧，你每天在工位上干啥，它就干啥。
我举个简单例子，你要给客户回个邮件，以前可能是邮件让 AI 写，然后你再复制粘贴到邮箱，检查一遍点击发送。
但现在你告诉 Agent 具体需求，它会自己打开邮箱、结合上下文生成回复、发送邮件，必要时可能还会调用一下可能蒸馏了前同事的skill。
以前的 AI 提供答案，现在的 AI 交付结果。
当然，发邮件只是一个例子。真正让办公 Agent 有机会跑起来的，是绝大多数办公室的工作，本质上都是高频、重复、标准化。
电脑里的工作，无非就是各种网页、文档、表格、邮箱、系统里来回切换，这些工作重复、繁琐，但都有标准的操作流程和规则，也有相对应的工具可以调用。
所以理论上，只要你把需求说清楚，再给权限，Agent就能自己去调工具、跑流程，把活干完。
世超最近在网上刷到过不少，打工人分享自己是咋用办公 Agent 的，就比如一个 Shopify 的卖家，把选品、上架、管理这些工作全部丢给了AI，还有HR让AI去招聘软件上筛选候选人、打招呼。
工作跟写代码八竿子打不着的人，也可以成为 Agent 的用户。
根据 OpenAI 发布的报告《知识工作新时代》，在 Codex 的用户中，知识工作者的占比已经达到了 20%，且他们采用和增长的速度超过开发者的 3 倍以上，这些人包括了产品经理、项目经理、设计师等等非技术人员。
当然了，办公市场大、有需求是一方面，对于大厂来说，卷办公 Agent 还有一层更现实的考量。
过去两年，C 端的大模型产品面临一个尴尬的问题，就是大家都在用，但很难赚钱。
聊天、问问题、写文案，这些需求虽然高频，但真正愿意持续付费的人，其实没有那么多。
因为聊天不是刚需，上班才是。
你想想，Office 时代，大伙儿其实就已经有付费习惯了，可能只是为了一个PDF编辑或者批量打印，就掏钱开会员。企业更不用说了，一套办公软件往往一买就是几百、几千个坑位。
还有一点很容易被忽略，就是 Coding Agent 再火，买单的往往只是研发团队。
但办公 Agent 面向的是一整家公司，HR、财务、法务、销售、运营、市场、行政。。。几乎所有的非技术员工都有可能成为用户。
这也就不难理解，为啥今年大家突然集体从 Coding 转向了 Working。
不过需要注意的是，办公 Agent 跟之前的给办公软件加个 AI 按钮，完全不是一回事。
过去一两年，大厂一直在给办公软件加 AI，Word 多了一个 Copilot，飞书、钉钉、WPS 也接入了大模型。
办公方式本质上没有变，还是人打开软件，AI 只是偶尔帮你完成其中的一步。
但现在干活的是 Agent，咱们要做的只是把业务经验、流程跟AI讲清楚，至于 CRM 怎么点、ERP 怎么填、哪个系统藏在哪个二级菜单，慢慢都会变成 Agent 要操心的事情。
当然了，世超聊这些不是为了给 SaaS 软件判死刑，换个说法是这些软件可能会退到后台，从咱们每天直接操作的工具，变成 Agent 可以随时调用的一套能力。
大伙儿应该也能看到，今年有越来越多的平台开始重视自己的 CLI（命令行界面）、API 能力，这些操作说白就是为了适配Agent的干活习惯。
所以大厂现在卷办公 Agent ，争的也不仅仅是一个办公产品。
毕竟以后上班，你打开的第一个软件，可能也是最后一个软件。
