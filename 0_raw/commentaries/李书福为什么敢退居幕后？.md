# 李书福为什么敢退居幕后？

一项人事变动，让吉利汽车亮眼的半年报，都没那么引人注意了。
这项变动便是：李书福辞任吉利汽车控股有限公司（0175.HK，下称吉利汽车）董事会主席，由安聪慧接任。
吉利汽车执行董事桂生悦评价这一变动时说，这是“去家族化的宣言，标志着吉利汽车已经从创始人驱动的创业期和发展期，迈向了由制度和团队驱动的成熟期。”
这是8月17日，吉利汽车在发布半年报后，抛出的一颗更重磅的“炸弹”。
如果横向看，老牌民营车企三强中，比亚迪王传福经常出席发布会，并且带领团队走访一线；长城魏建军也经常为发布会站台，甚至不辞辛劳打造个人IP，拍摄了大量视频；唯有李书福，不仅近些年不怎么露面，而且在最重要的岗位上“退居幕后”，交棒安聪慧。
李书福为啥就有这个福分，说“退”就能“退”？
01
业绩正红火
上半年，国内乘用车总销量同比下跌21.1%，是20年未见的下滑。
但就在这样的“寒冬”里，吉利汽车交出了一份量、价、利齐升的半年报。
量：上半年公司总销量突破142万辆，增长1%，总营收达1736亿元，同比增长15%；
价：单车收入同比提升16%至11.2万元；
利：核心归母净利润达96.8亿元，同比劲增46%。
唯一可能有争议的是，以常规的会计规则统计，公司净利润90.91亿，同比下跌2%。
核心归母净利润和常规的统计的净利润差别是外汇汇兑和金融资产减值。这也表明，去年和今年的汇兑收益差距对吉利汽车的影响巨大。
桂生悦在发布会上提及了中汽协的统计：2026年上半年，整个中国汽车行业的平均利润率已经跌到了1.6%。换句话说，吉利的盈利能力是行业平均水平的3倍以上。桂生悦说：“吉利汽车获得了将近100亿元的核心归母净利润，我们的净利润率达到了5.6%，处于整个中国头部地位。”
出口更是超预期。上半年出口销量达47.4万辆，同比大增158%，单月出口连续突破10万辆。
资金储备也很充裕。截至6月末，吉利汽车资金储备达695.6亿元，创下历史高位。
展望下半年，吉利汽车业绩也很乐观。以海外销量为例，吉利汽车2026年海外销量目标已从64万辆上调至92万辆，并冲击100万辆。
桂生悦在发布会上放话：“我相信在不远的将来，令人惊艳的财报会出现。”
在这样一个良好业绩的当下，李书福交接班，企业内外都不会有太大波澜。
02
人才有梯队
吉利汽车此次人事调整，是一轮新老交替——
李书福虽然辞任董事会主席，但继续担任浙江吉利控股集团董事长，并出任吉利汽车终身荣誉主席；
安聪慧出任董事会主席，同时继续担任浙江吉利控股集团CEO；
桂生悦卸任行政总裁，改任董事会副主席，继续担任执行董事；
淦家阅接任行政总裁（即CEO）。
尽管这次人事调整突然发布，但对于接班人选，外界不会意外。
以安聪慧为例，他1970年生，在吉利体系内工作了30年，曾出任吉利汽车集团CEO、极氪智能科技CEO。
安聪慧同学
李书福评价他：“安聪慧同学是吉利体系内培养出来的优秀职业人才，德才兼备，品学兼优，事业心坚定，意志力超强，是吉利汽车产业的骨干人才。”
而淦家阅是1981年生的新生代，也已经在吉利工作多年，接任行政总裁之前已经深度参与日常运营。他此前已经担任了吉利旗下的乘用车业务板块吉利汽车集团的CEO。
李书福在业绩会发布会上的视频演讲中说，“人是企业文化传承、价值观取向的核心要素，人力资源是企业第一资源，人才战略是吉利战略的基础性战略，为此吉利专门成立了人才集团。”
他还介绍，今年吉利人才集团还发起了“两个人才发展项目”。
当然，吉利不是今天才开始培养人才。
“几十年来，我们坚持多层次人才培养能力的形成与发展，尤其是基础性技师技工人才、制造与质量管理人才、工程研发人才、设计创意人才、经营管理人才、营销与售后人才、跨国服务人才及人工智能、航空航天、新能源等产业方向的人才培养，我们坚持‘尊重人、成就人、幸福人’的人才培养理念，让同路人携手合作，协同发展。”李书福说。
安聪慧、淦家阅就是典型例子，他们都是大学毕业即加入吉利，吉利自己培养出来的人才。
这场人事变动，可以说是李书福给全体吉利人传递了一个信号。如桂生悦所说：“对内部人才而言，也是天花板被打破的信号，这会极大地激发出全体员工的奋斗热情。”
安聪慧也在发言中说：“我们要让能打胜仗的人有舞台，让每一位奋斗者都能与企业同成长同进步。”
吉利以集团成立来论，已有40年，以开始造车来论，已经29年，确实已经积攒了一大批“能打胜仗的人”和“奋斗者”。这也是李书福敢退的底气之一。
03
技术有积累
李书福敢“退”，还因为吉利已经筑就了智能电动汽车全面的技术底座，并归结到全域AI技术体系中。
吉利汽车对外表示，公司目前是全球唯一拥有智能汽车、芯片、具身智能机器人、AI大模型、卫星等天地一体化科技生态的车企。
在当今火热的智能化领域，吉利汽车的布局很广。
吉利汽车以大算力、大模型、大数据方面的优势积累，构建起行业领先的底层技术基座，形成涵盖芯片、大模型、物理AI的全栈能力，并在智驾、座舱、架构、底盘、能源、安全等方面，达成全域智能渗透。吉利将以WAM世界行为模型为核心，“超级Eva + 千里浩瀚G-ASD”为两大支柱，并向全域AI的N类能力延展，搭建“1+2+N”多智能体协同框架。
桂生悦在谈到智能化时说，“过去几年，大家对于吉利在智能化方面的表现不是很认同。”但是，现在，“已经到了一个头部的地位……随着时间的推移，一定会来到一个比较突出的地位。”
而在新能源、节能汽车技术方面，吉利通过布局浩思动力、吉曜通行、星驱科技三家“隐形冠军”企业，构建从底层材料到系统集成的全链路闭环，完善三电领域的垂直整合生态体系。i-HEV智擎混动、雷神AI电混2.0、神盾金砖电池、吉利银河雷霆16合1智能电驱等标杆技术，已搭载吉利量产车型，并向技术普惠方向发展。
下半年，吉利汽车将发布进阶版WAM世界行为模型、千里浩瀚G-ASD全新升级，及AI越野架构、全地形AI数字底盘等技术。此外，吉利汽车还设立“2030实验室”，聚焦声学、光学、全域安全、功率半导体、数字底盘、具身智能、数据科学、大模型和智能体等前沿领域，储备面向2030年的前瞻颠覆性技术。
安聪慧说，“吉利作为技术驱动型企业的认知和优势已经形成。”
作为新任董事主席，安聪慧还给投资者发了一个“大红包”。他说，“将已经形成的和已经在培育的一些业务并入到上市公司。”他提到的业务包括电池、电驱、电子电器，都已经是大规模供货的业务。
吉利汽车在人事调整和业绩发布日大涨4.77%
这就是李书福敢“退”的“底气”——业绩在高位、人才有梯队、技术有储备。
民营车企的创始人交棒，是一道艰难的命题。多少企业因为创始人“退”而“塌方”。李书福用一场精心设计的人事变革，向外界宣告：吉利的未来，不靠创始人，而靠制度和团队。只有此前在制度和团队上投入了足够的时间和资源，才能期望结出丰硕的果实。
