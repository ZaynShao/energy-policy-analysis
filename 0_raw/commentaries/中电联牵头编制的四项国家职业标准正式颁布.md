# 中电联牵头编制的四项国家职业标准正式颁布

近日，人力资源社会保障部办公厅、国家能源局综合司联合发布了《光伏发电运行值班员L》《供热管网系统运行工》《送配电线路工》《发电设备安装工》《电机检修工（风力发电机检修工）》等五项国家职业标准，其中前四项标准均由中国电力企业联合会牵头组织编制。
国家职业标准通过规范职业功能、工作内容、技能要求等，构建科学、统一、可操作的人才评价与培训依据，推动电力行业技能人才队伍建设更规范、更专业，提升行业人才服务整体水平。
中电联长期深耕人才标准制定，深度参与国家职业标准体系建设，持续引领电力行业技能人才评价体系发展。此次标准发布，体现了中电联积极响应国家关于加强新时代高技能人才队伍建设的战略部署，大力推动电力行业人才培养专业化的重要成果。
下一步，中电联将紧跟技术进步和产业发展需求，持续加大国家职业标准开发力度，全力推动各项国家职业标准宣贯和落地实施，加快配套国家职业技能等级认定培训教程开发，更好促进电力技能人才培养，为推动新型电力系统建设、加快实现“双碳”目标提供坚实的人才支撑，助力电力行业高质量发展。
