# 极端高温或令欧盟国家损失约1800亿欧元

今夏欧洲遭遇的极端高温将让欧盟国家承受约1800亿欧元经济损失。
总部位于荷兰的特里奥多斯银行评估，今夏欧洲遭遇的极端高温将让欧盟国家承受约1800亿欧元经济损失，大致相当于2025年欧盟国内生产总值（GDP）的1%。不过，数据没有涵盖人员伤亡的关联损失。
▲8月11日，在荷兰泽弗纳尔市洛比特水文站附近的莱茵河一处港口，两条船搁浅。新华社记者邵海军摄
据欧洲新闻电视台12日报道，特里奥多斯银行从农作物和乳制品产量下降及其导致的食品价格上涨、发电量、货运量以及劳动生产率等方面追踪经济损失情况，得出上述数字。其中前三项以欧盟平均水平为基准量化。影响最大且最难准确估算的是劳动生产率，特里奥多斯银行参照德国安联集团的跨国研究数据进行评估。
依照特里奥多斯银行说法，鉴于欧盟经济今年预计增长约1.1%，1800亿欧元的损失将令欧盟经济几乎陷入停滞。
另外，特里奥多斯银行根据受影响行业产出的占比、通勤时间、空调普及率及气候适应能力对欧盟各经济体打分，结合今年异常高温的天数，得出的结论是：法国损失最重，预估其经济增长将下降1.4个百分点。
近期，高温、干旱、山火等侵袭欧洲多地。世界气象组织11日发布公报说，西欧经历了有记录以来最热的6月和7月，且这一趋势8月仍在延续。
