# AI技术资讯丨DeepSeek Harness星标超7万，智谱GLM-5.3发布，苹果阿里合训中国版模型

今日主线·DeepSeek，智谱GLM-5.3，苹果，阿里千问，开源大模型，算力芯片：开源模型与Agent密集发布，中国模型能力加快追近海外，算力与AI工厂订单持续升温。
▸阿里千问：开源 Qwen3.8-27B，270 亿参数，上下文 1M Tokens。
▸DeepSeek：Harness v0.1 开放测试，GitHub 超 7 万星。
▸智谱：GLM-5.3 发布，能力比肩 GPT-5.6 Sol。
1.阿里千问：正式开源 Qwen3.8-27B，原生多模态稠密模型，270 亿参数，支持 262K 原生上下文并外推至 1M Tokens，性能超越 Qwen3.7-Plus。
2.DeepSeek：Harness v0.1 开发者预览版开放测试，GitHub 超 7 万星；V4 Pro 同日发布，API 价格上调并采用峰谷分时定价。
3.智谱：发布基座模型 GLM-5.3，基座 7000 亿参数 不变，编程与网络安全表现突出，能力可比 Fable 5 与 GPT-5.6 Sol。
