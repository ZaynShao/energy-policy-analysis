# 路空一体 智联未来丨国内首个“路空一体”国家级测试基地，南方试验场正式投用！

近日，国家智能网联汽车质检中心（广东）（筹）+广东省低空经济中试平台（筹）能力发布会暨南方试验场启用仪式在广东韶关举行。
本次活动以“路空一体 智联未来”为主题，由中国中检指导，中国汽研、广汽集团、中国质量认证中心、粤检集团、韶关金财联合主办，南方试验场公司承办。活动设置核心能力发布、战略合作签约、实景动态演示、三大研讨会等系列环节，全面展现国内首个飞行汽车领域国家级研发测试中心的测试能力与产业愿景。
广东省人大常委会党组副书记、副主任叶贞琴，广东省市场监督管理局党组书记、局长陈新烈，韶关市委书记陈少荣，广汽集团党委书记、董事长冯兴亚，中国中检党委副书记、总经理李永吉出席活动并致辞；中国中检党委委员、副总经理万鑫铭，中国汽研党委书记、董事长周玉林，党委副书记、董事、总经理刘安民出席活动；副总经理王锐主持活动。来自政府机构、国家部委、协会高校、行业企业、科研院所等政企产学研的领导以及媒体记者等数百位嘉宾莅临发布会共同见证。
核心能力发布，筑造路空一体测试高地
在核心能力发布环节，南方试验场公司董事长、总经理向华荣介绍了国家智能网联汽车质检中心（广东）（筹）和广东省低空经济中试平台（筹）的能力布局。国家智能网联汽车质检中心（广东）（筹）以“334N”为核心架构——即“低空+试验场+试验室”三位一体一站式服务能力，围绕单车智能、车路协同、路空一体构建三大技术路线，测试服务覆盖智能网联汽车、低空飞行器、新能源、整车四大类产品及100多个测试场景，具备最高时速280公里、最高高度1200米的测试能力。
作为省内首家“智能网联汽车+低空飞行器”中试平台，平台创新提出三条中试线，旨在解决智能网联汽车、飞行汽车、eVTOL等测试中“测不全、测不准、怎么测”等难题，覆盖智能网联汽车性能、低空飞行器试飞及“车-机-网-空”跨域协同验证。此外，南方试验场围绕“智驾测试+低空测试+整车道路测试”打造核心服务能力，其中硬件设施包括长达8.5公里、最高时速280公里的高速环道，直径300米的国内单体最大动态广场，占地3645平方米的国内试验场首个综合服务机库，以及飞行汽车动力系统试验室等。同时，南方试验场建有6条长直线滑行跑道、4个以上垂直起降停机坪、240kw超充、5G-A基站、低空数字化监管平台，致力于打造外场适航试飞全能力，构建具备适航验证服务核心能力的“封闭试验-半公开探索-公共示范”全链条试验验证体系。
多项合作成果落地，构建产业协同生态
发布会现场举行了多项签约、揭牌与启动仪式。南方试验场公司联合韶关市、新丰县人民政府签署南方试验场二期建设投资协议，积极推进测试能力拓展。韶关市智能网联汽车道路测试示范项目正式启动，打通封闭场地与开放道路的场景联动。韶关市低空飞行器协会宣告成立，搭建政企协同桥梁。广东省低空飞行器试飞基地、路空一体测试基地相继揭牌，分别聚焦低空经济创新载体与路空一体技术标准平台。产学研合作方面，中国汽研与广东高域科技有限公司、广东省垂直起降飞行器制造创新中心、四川沃飞长空科技发展有限公司等企业签约共建联合研究中心，同时由中国汽研南方试验场公司、华南理工大学、广汽高域、中国联通广东分公司共同发起的低空全链路通讯验证实验室揭牌，填补行业空白。
实景演绎未来交通 路空协同触手可及
动态演示环节，广汽高域GOVY Aircab飞行汽车完成双机编队飞行，从动态广场、坡顶广场垂直跃升至60米高空，表演直立起飞、空中悬停、双机精准降落等动作。18台智能网联汽车在地面协同穿行，生动演绎路空协同场景。
静态展示区集中呈现广汽、比亚迪的热门乘用车，及滴滴自动驾驶与广汽埃安合作打造的新一代Robotaxi。慧仑科技第四代具身智能人形机器人“GoMate Mini”也现身动态展示区，全景呈现“路空一体”技术图景。
在试乘试驾环节，数百位嘉宾零距离体验了高速环道、耐久可靠性路面等34种特征路面，了解了试验场为车辆性能与可靠性验证提供的测试环境。滴滴自动驾驶的新一代Robotaxi于去年7月率先在南方试验场完成行业首个以自动驾驶状态开展的耐久可靠试验。依托试验场专业严格的检测体系，充分验证了车辆在复杂工况下的稳定性能与自动驾驶能力。目前，该车已在广州和北京开展常态化道路测试。
南方试验场的正式启用，不仅为智能网联汽车与低空飞行器提供了国内首个、能力完备的“路空一体”国家级测试验证平台，更在于以“测试+研发+中试+孵化”的全链条创新模式，攻克了跨界产品在测试验证领域的核心难题，填补了我国在适航验证与融合安全领域的关键基础设施空白，将加速技术迭代与商业化进程。作为产业发展的“加速器”与“连接器”，这里将持续吸引全球创新资源，推动从标准制定、技术研发到产业落地的系统性突破，加速新质生产力形成，为粤港澳大湾区建设世界级科技创新高地注入强劲动能。
