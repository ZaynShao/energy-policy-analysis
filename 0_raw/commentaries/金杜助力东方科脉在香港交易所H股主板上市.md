# 金杜助力东方科脉在香港交易所H股主板上市

东方科脉作为全球电子纸显示器行业的知名企业，已建立自主设计及制造电子纸显示模块的能力，专注于研发、生产和销售涵盖各种颜色和尺寸的电子纸显示模块。公司的产品组合应用于智能零售、智慧办公、智慧教育、智慧物流、智能交通、电子阅读器以及新兴应用等多元化应用场景，助力物联网时代更智能的生活和工作方式。
在本项目中，金杜律师事务所担任东方科脉的国际制裁法律顾问，就美国出口管制、经济制裁、美国对外投资审查以及关税等方面提供专业法律意见。金杜团队结合公司的业务情况以及产品特性，针对相关规定下的各要点以及实践中的常见问题进行了全面分析，并就联交所提出的问询作出专业答复，助力东方科脉圆满完成上市。
本项目主办合伙人包括纽约办公室合伙人Meg Utterback及上海临港办公室合伙人戴梦皓，项目团队核心成员包括陈若思、曹逸晨、袁梅紫。
*本文对任何提及“香港”或“香港特别行政区”的表述应解释为“中华人民共和国香港特别行政区”。
