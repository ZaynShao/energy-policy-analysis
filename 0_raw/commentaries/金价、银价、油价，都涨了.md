# 金价、银价、油价，都涨了

8月14日，国际金价、银价、油价上涨。
14日美国三大股指集体下跌
美国商务部14日发布的数据显示，7月零售数据在各个层面都令人失望，美国国内消费正显现出疲软迹象。此外，AI板块部分公司股价出现回调也拖累市场整体表现。14日美股集体下跌。截至当天收盘，道琼斯工业平均指数比前一交易日下跌0.20%；标普500指数下跌0.17%；纳斯达克综合指数下跌0.28%。
14日欧洲三大股指涨跌不一
受矿业股因铜价下跌而回落，以及中东地缘冲突带来的不确定性增强等因素影响，14日欧洲三大股指涨跌不一。截至当天收盘，英国富时100指数下跌0.21%，法国CAC40指数下跌0.16%，德国DAX指数上涨0.53%。
14日国际油价上涨
由于美国威胁对伊朗实施“前所未有”的经济孤立措施，并暗示可能对伊朗维持无限期海上封锁，国际油价14日上涨。截至当天收盘，纽约商品交易所9月交货的轻质原油期货价格报每桶82.40美元，涨幅为1.42%；10月交货的伦敦布伦特原油期货价格报每桶88.52美元，涨幅为1.67%。
14日国际金银价格上涨
受美元指数下跌等因素影响，国际金银价格14日上涨。截至收盘，纽约商品交易所12月交割的黄金期货价格报每盎司4437.30美元，涨幅为0.38%；9月交割的白银期货价格报每盎司65.108美元，涨幅为0.18%。
