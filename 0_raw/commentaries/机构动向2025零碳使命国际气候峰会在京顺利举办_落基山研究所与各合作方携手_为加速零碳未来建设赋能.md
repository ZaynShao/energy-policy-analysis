# 机构动向|2025零碳使命国际气候峰会在京顺利举办 落基山研究所与各合作方携手 为加速零碳未来建设赋能

**10月24日，由凤凰卫视、落基山研究所（RMI）、世界自然基金会（瑞士）北京代表处（WWF）主办，北京市企业家环保基金会（SEE 基金会）、大道应对气候变化促进中心（C Team）、凤凰网财经联合主办，珠海格力电器股份有限公司作为创益同行伙伴的第五届零碳使命国际气候峰会2025（以下简称“峰会”）在北京顺利举行。**今年恰逢《巴黎协定》签署十周年，也是中国提出“双碳”目标五周年，标志着全球气候行动迈入更加关键的阶段。峰会以“十年共识·五年同行”为主题，汇聚来自中国政府、驻华使馆、中外企业、国内外环保机构等多个领域的专家代表，通过高层对话、论坛研讨、案例分享等多元形式，共商创新解决方案，推动全球气候公正转型进程，加速零碳未来建设。

**凤凰卫视董事局主席兼行政总裁徐威在开幕致辞中表示**，应对气候变化，致力实现碳达峰、碳中和是当今世界的主流思潮。中国在2024年提前六年实现了风电、太阳能发电装机12亿千瓦目标，并于今年9月宣布新一轮国家自主贡献目标。这些积极进展不仅重振了全球减排信心，也让我们有更大动力把愈来愈多的共识转化为成果，一起创造更加美好的未来。

**推动新能源重卡规模化应用 重塑行业格局**

10月24日下午，落基山研究所举办了主题为“冲向零碳·重卡能行”的分论坛，正式发布了由落基山研究所牵头合作方共同发起的“冲向零碳”新能源重卡运行实景展示项目的阶段性成果。来自交通领域的专家、企业代表和行业研究机构齐聚一堂，围绕新能源重卡在中国的发展前景与未来路径展开深入交流。论坛旨在总结气候治理经验，凝聚未来合作共识 ，见证跨领域、跨国界的协作成果，为全球碳减排与绿色转型注入动能。

  //  

**交通运输部公路科学研究院原主任、二级研究员虞明远致开场辞，**他提出，交通运输绿色低碳高质量发展将会成为未来的工作重点之一，物流作为实体经济的动脉，正加速向集约、高效、绿色方向发展，而重卡新能源化正是实现这一转型的关键环节。

**会上，落基山研究所交通、氢能和清洁技术投融资部门主任王喆代表团队介绍了“冲向零碳”新能源重卡运行实景展示项目。**在项目运行周期内，共覆盖21辆重卡，完成了为期一周、累计153车日的实地运行，相关数据已上传至活动官网 （https://rol.rmi.org.cn/）。基于实测数据的初步分析结果表明，在集疏港运输和砂石土料运输等场景中，充/换电重卡的百公里运营成本较传统柴油车可节省50%以上、碳排放减少约40%。测试期间，三种新能源重卡技术路线均能满足中短途运输需求，其中，电动重卡日均里程约300–400公里，氢能重卡可接近600公里，充分证明了新能源重卡在商业化应用方面的可行性。
