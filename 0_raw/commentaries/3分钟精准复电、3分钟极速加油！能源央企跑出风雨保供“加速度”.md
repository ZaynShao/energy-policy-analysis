# 3分钟精准复电、3分钟极速加油！能源央企跑出风雨保供“加速度”

今夏我国南方、中部地区频发极端天气。受台风“美莎克”及其残余环流叠加水汽影响，广西、湖北、甘肃等省区普降特大暴风雨，接连发生水库溃坝、山体滑坡、房屋倒塌、电力中断等灾情，人民群众生命财产安全与地方经济发展遭受损失。
习近平总书记对防汛救灾工作作出重要指示，指出“要全力组织抢险救援、伤员救治、群众安置等工作”，强调“扎实做好防灾救灾各项工作，确保人民群众生命财产安全”。
灾情就是命令，保供就是责任。面对严峻考验，多家能源央企闻“汛”而动，坚持人民至上、生命至上，以快速响应、全域驰援、精准保供的硬核担当，筑起了一道坚强的能源保供堤坝。
闻“汛”而动，筑牢抢险救灾“生命线”
7月4日起，南宁普降暴雨到大暴雨、局地特大暴雨，日雨量最大达637.0毫米，65条河流82个站超警。横州市校椅镇六蓝村的六蓝水库，这座1960年建成、总库容9552万立方米的中型水库，承载着周边4个乡镇15万多亩农田灌溉和城区备用水供给重任，在持续暴雨中承受着极限考验。
7月6日凌晨2时30分，水库水位达到111.20米，超过设计洪水位0.91米。清晨6时，水库全开泄洪闸全力泄洪，但来水量远超泄洪能力，坝体外坡护坡层最终达到承载力极限。当日上午，巡查人员发现坝体出现两处破损缺口，垮塌总长约50米，东坝头外坡两层护坡被洪水冲毁。
险情发生后，当地应急指挥部门将距离六蓝水库17公里的中国石油广西销售云表加油站定为抢险救灾临时指挥部。这座平日里为过往车辆服务的加油站，瞬间变身为整场救援行动的前沿阵地和能源枢纽。
▲中国石油广西销售云表加油站为救援人员提供了休整的落脚点与免费物资。
“险情发生时，站里停水停电，连信号都断了。接到救援指挥部的征用指令后，我们没有任何犹豫，所有员工立刻进入‘战时状态’。黑夜中，大家打桶、装油，装油、打桶……冲锋艇、运输车，一辆接一辆从加油站出发，奔赴抢险一线。既然把站交给前线当指挥点，我们就要守住这条‘生命补给线’。”云表加油站经理周丽红说道。
中国石油第一时间启动应急保供机制，油品调度、人员调配、后勤保障三条线同步推进，一条“绿色保供通道”在风雨中紧急打通，确保救援车辆和冲锋艇的油料供应不断档、不缺位，全力保障抢险车辆和民生用油，坚决守住城市运行的能源保障底线。
▲中国石油广西销售公司员工为防城港市防汛抢险冲锋舟加注燃油。
广西钦州同步打响昼夜抢险攻坚战。7月6日23时58分，国家危险化学品应急救援茂名石化队接到广东省应急管理厅及国家安全生产应急救援中心的指令，紧急驰援广西钦州抗洪抢险。茂名石化迅速抽调特勤中队、炼油中队、高端碳中队共27名指战员，组成一支精锐的救援突击队。他们驾驶着包括“龙吸水”垂直供排水抢险车、排水模块皮卡、应急通信指挥车在内的7台救援车辆，携带便携水泵、橡皮艇、救生衣等各类专用装备器材奔赴广西，协同当地救援队伍开展排涝除险、转运受困群众等作业。
▲国家危险化学品应急救援茂名石化队会同当地救援队伍开展排涝除险、转运受困群总等作业，全力以赴协助当地加快恢复生产生活秩序。
电力保供，须臾不松。南方电网7月7日召开应急会商会，迅速部署防汛救灾各项工作，强调要坚持人民至上，全力保障各级政府指挥机构、群众生产生活和重要用户电力安全可靠供应，同时前置统筹调派全网骨干力量携带大批应急装备驰援广西。
受持续暴雨冲击，广西贵港、防城港等地，多区域居民用电供应承压。南方电网广西梧州网区火速集结支援队伍奔赴贵港，涉水深入受灾点位排查隐患、抢通线路，全力保障排涝设施与居民生活的电力供应。7月7日，南方电网广西来宾供电局支援抢修队伍对防城港卓富小区开展临时低压转供电工作，为小区450余户群众提供临时电力保障。
发电企业同样坚守保供阵地、稳产兜底。国家能源集团广西公司第一时间启动重大气象灾害（台风）Ⅲ级预警，全面启动应急处置流程，聚焦保安电源、柴油发电机、各泵坑排水泵、户外大型机械等关键设备设施，严格遵照应急预案落实各项防控举措。同时，重点对电气、热工保护设备、油库防雷设施、输电线路及存放物件等进行专项检查，对排查发现的隐患问题立行立改。目前，公司火电机组安全稳定运行，全力保障区域电力安全稳定供应。
华能广西分公司闻“汛”即动、快速响应，第一时间启动防汛防台风三级应急响应，全力筑牢防洪度汛、稳产保电坚实屏障。各场站严格落实应急预案，及时将风机切换至台风保护模式，全程盯守设备运行工况；对受电网侧内涝影响的升压站，严格遵照调度指令实施停电避险，同步组织运维队伍昼夜开展场内排水、线路巡检、塌方路段清障等抢险作业。
此外，华能金康风电场项目部紧急驰援属地村委，调集施工人员40余人、挖机铲车等机械设备26台，全力疏通塌方受阻路段，冒雨抢通生命通道保障急症患儿就医，助力周边村镇恢复道路通行与物资运输。经过全员昼夜奋战、协同攻坚，公司生产运行总体平稳可控，切实守住区域能源供应安全底线。
科技赋能，跑出应急抢修“加速度”
7月6日晚，台风“美莎克”残余北上环流与梅雨锋水汽交汇，导致湖北遭遇短时强降雨、雷暴大风天气。黄冈、黄石、鄂州多地出现罕见楔形龙卷风，全省53个乡镇阵风风力超8级，造成部分区域供电线路设备受损。
▲7月7日，湖北省供电系统170余人星夜兼程驰援黄石市大冶金牛镇。图为各地方供电公司应急队伍合力抢修受损线路。曹祥魁/摄
“应急电源车接入完毕，可以送电。”7月6日22时，黄石大冶市金牛镇10千伏高南线抢修现场，供电员工熊有光完成3000千瓦中压应急电源车参数核验后，按下启动按钮，该供电线路即刻恢复供电。
万家灯火重现的背后，是国网湖北电力抢修人员的昼夜奋战。供电运维人员曹浩带队连夜特巡110千伏宫牛线，累计排查出10余处线路异物隐患。
“彩钢瓦一旦搭上导线，极易引发短路，危及整条线路。”曹浩介绍，夜间高空作业视线差、操作难度大，但隐患不消除，电网安全就无从保障。他们迅速登塔作业，用绝缘操作杆小心剥离、取下彩钢瓦。从深夜到凌晨，该线路异物全部清理完毕，110千伏宫牛线恢复平稳运行，村庄的夜色再次回归灯火如常。
历经多次极端灾情淬炼，我国电网企业应急抢险已从单纯依靠“人海”抢修，升级为资源统筹、区域协同、科技赋能于一体的系统性救灾体系。特别是数字化、智能化技术，正成为抢修的“加速器”。
面对湖北多地线路受损，国网湖北电力充分发挥配电自动化、供电服务指挥平台等数智系统作用，极大提升了故障研判精度和抢修指挥效率。
7月6日19时59分，鄂州10千伏城24凤凰一回线突发过流故障。就在故障发生的同一瞬间，配电自动化系统自动研判、精准定位，迅速将故障区段从配电网络中“切割”出去，非故障区域随即转入备用线路供电。从故障发生到送电完成，非故障区域恢复供电全程不过3分钟，最大限度压缩停电影响范围、保障群众不间断用电。
▲7月6日晚，国网鄂州供电公司抢修队伍在10千伏谢东线隔离故障并对非故障区域利用发电车转供。李彤/摄
针对黄冈黄州区受灾严重的10千伏路口线戚家岭台区，国网湖北电力采用移动发电装备构建灵活的供电“战术”，确保用户“停电不停用”。7月7日凌晨4时30分，供电中心带电作业班周密、唐超等火速赶赴现场。抢修人员并未直接开始抢修受损线路，而是优先接入中压移动发电车，布设绝缘遮蔽，确保不间断供电。随后，他们在带电工况下完成清障、杆塔加固作业。抢修队伍从抵达现场至恢复供电，仅用时26分钟。
截至目前，国网湖北电力已在受灾重点区域前置部署876名抢修人员、225辆应急抢修车、25台应急发电车，并从其他地市紧急跨区调集了千余名抢修人员和大量装备。截至7月7日21时35分，受灾重点区域供电已全面恢复。
全国电网系统联动发力、跨区域联动支援广西重灾区抢险保供。7月7日，贵州电网公司自毕节、凯里、安顺等地抽调1000余名精锐人员，配属30台应急发电车、无人机及卫星通信设备开赴贵港市。
“我们经历过贵州榕江、从江抗洪保电，对水淹配电房勘查和排涝后复电流程比较熟，这次把经验带上。”贵州毕节供电局生产技术部负责人王丰带队冒雨出发。贵州安顺供电局党员突击队抵达后，立即使用无人机对贵港受淹片区线路走廊进行低空巡视，半小时生成杆塔倾斜、树障压线等隐患图谱，为后续抢修方案制定赢得宝贵时间。
云南电网组建162人成建制支援队，调派30辆应急发电车、28辆越野车等奔赴贵港市。车队配备卫星电话及应急物资，同步建立小时级信息汇报及后台安全监控机制。通过实时共享台风路径预测及受灾区域电力设施损毁评估数据，指挥部可动态调整支援部署，确保救援力量精准投放。
国家级电力应急基地（南方）应急特勤队发挥“国家队”硬核实力，派出50名抢险人员携带632台套排涝、通信、照明、后勤、水上运输等特种应急装备，跨海驰援海南后火速转战广西。7月7日，特勤队在南宁宾阳县凤凰印象小区地下车库开展排涝作业——小区地下车库积水约1万立方米，相当于4个标准泳池水量，地下配电房完全被淹，3400余户居民停电。特勤队启用大流量排涝车等应急设备，不间断轮班开展抽排作业，为抢修复电扫清障碍。
南网产业发展集团通航公司组织15支无人机队伍携带27台多旋翼巡检装备赶赴钦州开展空中勘灾，增配5台大载重无人机抵达南宁横州、贵港执行应急作业。目前已完成160千米线路巡查，排查电网故障隐患89处，为抢修复电提供了详实“画像”。
全国一盘棋，彰显央企“大担当”
灾难无情，人间有爱。在防汛抢险、救灾保供的关键战场，各大能源央企勇担能源保障重任，齐心协力打好打赢防汛救灾这场硬仗，更将暖心服务延伸至受灾群众急难愁盼的细微之处，以全方位、精细化、有温度的服务诠释了“人民至上、生命至上”的初心使命，彰显央企责任担当。
▲7月8日，南方电网广西百色供电局驰援队伍党员突击队在钦州市彰泰红小区排涝抢修一线排查。王亚玲 柏兴兴/摄
7月6日，在广西南宁宾阳县露圩高速出口，群众在转移过程中，车辆在深水区熄火，正在周边开展电力线路勘测的南方电网广西南宁宾阳供电局工作人员看到后，迅速与交警及群众合力将车辆从水中推出，车辆和人员成功脱困。
海上防汛安全同步严密筑牢。在接到乌石油田群作业平台的借助码头撤离求助后，大唐雷州发电公司第一时间启动应急响应，联动边检、海事等多方部门打通应急避台“绿色通道”，紧急调离重件码头在港船舶，清空作业停靠区域，科学规划上岸人员转运路线，高效完成1船次共97名海上作业人员的安全撤离，全力筑牢海上安全防护屏障。
聚焦群众需求，精准纾困解难。湖北黄冈龙卷风灾后，大量车辆被树木砸损、积水浸泡、线路受潮。车辆的损毁是继生命安全之后的第二大焦虑。针对受灾车辆的维修难题，中国石化湖北黄冈石油分公司依托全市21家易捷养车门店及湖北首座易捷钣喷中心，推出了优先接诊、优先定损、优先维修的“三优”专项服务。更令人暖心的是，他们联动多家主流保险公司，提供报案、定损、维修结算一站式代办服务。
“车子被树砸了，本来以为要跑保险公司、修理厂好几个地方，在这里一站式就办好了，效率很高，确实省心。”一位正在办理手续的受灾车主感激地说道。保险公司人员也表示，他们进驻易捷养车门店设立联合服务点，打通了定损理赔直连通道，车主无需往返奔波，只要在门店提交相关材料，现场即可完成查勘定损，后续理赔款直接对接门店结算，真正实现了“最多跑一次”。
在全力保障油品供应的同时，中国石化湖北黄冈石油分公司推出了多项暖心便民举措，让灾后重建之路变得不再那么艰难。
“我们是离启辰物流园最近的加能站，在确保站内员工人身安全的基础上，连夜开通了绿色加油通道，所有应急救援车辆不用等、优先加，全力保障抢险一线的用油需求。”中国石化黄冈明珠加能站站长任超说道。此举赢得救援应急车辆司机的一致点赞：“连日来我们连轴转开展救援，油表亮了都不敢随便找地方加油，就怕排队耽误救援进度。到这里走绿色通道直接进站，两三分钟就加满了，真是给我们抢出了宝贵的抢险时间。”
中国石化湖北黄冈石油分公司副经理江韬表示：“灾情就是命令，我们第一时间统筹全公司保供与服务资源，推出一系列便民纾困举措。下一步我们会持续做好油品保供，不断升级易捷养车服务，全力助力受灾群众尽快恢复正常生产生活。”
聚焦重点区域、重点人群保电需求，南方电网精准施策、靶向保供。“应急指挥部、抢险救援接驳点、人员安置点不能没有电。”在南宁横州市，部分供电线路和设施受损，部分区域主动停电避险，广西南宁横州供电局总经理潘红梅介绍，为了保障校椅镇应急指挥部紧急用电，供电人员赶赴现场迅速完成线路接驳、发电车调试等工作，于7月6日14时接通发电车应急电源，同时调派一台13千瓦应急发电车挺进云表、马岭一带临时安置点，保障受灾群众用电。
在防城港市，广西来宾供电局支援抢修队伍连夜架设临时电缆，保障中帝园小区、卓富小区等居民用电。在钦州市，当地供电局在多个小区内设置便民充电点，为群众解决燃眉之急。
当前，部分区域水势尚未消退，南方电网公司坚持“水涨电停避险、水退人进电通”原则，在确保人身安全的前提下科学有序抢险，全力守护人民群众生命财产和电网安全稳定运行。
截至7月8日11时，南方电网公司保持防风防汛二级应急响应，累计投入应急抢修人员2.8万人次、抢修车辆8985辆次、应急发电车208辆次、应急发电机450台次开展抢险救灾。
从星夜千里驰援的能源补给线，到科技赋能的数智化抢修，再到延伸群众细微需求的暖心服务，各大能源央企在面对极端灾害天气时，千方百计筑牢能源安全防线，用实际行动为受灾地区早日恢复正常生产生活提供坚实的能源保障。
