# 财经早餐丨每日财经三分钟新闻报道07月05日

► 中国人民银行：将开展买断式逆回购操作，规模 10000亿元，期限3个月。
► 贵金属：本周伦敦现货黄金涨1.18%，国内足金饰品价格升至 1260元/克 左右。
► 英伟达：推出“AI算力伙伴计划”，承诺回购云服务商闲置GPU。
01 今日财经头条
- 中国人民银行：将开展买断式逆回购操作，规模 10000亿元，期限 3个月，旨在维护市场流动性，支持债券市场稳健运行。
- 市场行情：本周国际金价结束四周连跌，伦敦现货黄金上涨 1.18%，COMEX黄金期货周涨约 2.1%，国内品牌足金饰品价格同步上调至 1260元/克 左右。
- 英伟达：推出“AI算力伙伴计划”，承诺回购云服务商闲置GPU，以自有雄厚资金扶持AI芯片采购生态。
- 沪深北交易所：就再融资规则修订征求意见，拟引入向特定对象发行股票储架发行制度，实现“一次注册，分次发行”，小额快速融资上限拟提升。
- 三星电子：消息称其计划三季度将DRAM平均售价环比提高 20%，上游部品涨价或传导至终端，但机构预计合约价涨幅将收窄至 13%-18%。
- 上海航运交易所：本周中国出口集装箱运价综合指数报 3326.87点，较上期上涨 2.7%，多数航线市场运价继续上行。
02 宏观与政策
- 中国人民银行：将开展买断式逆回购操作，规模 10000亿元，期限 3个月，旨在维护市场流动性，支持债券市场稳健运行。
- 国家数据局：印发《数据产权登记工作指引（试行）》，将建设全国统一的数据产权登记体系，降低数据流通交易成本。
- 市场监管总局、商务部：就《电子商务法（修正草案征求意见稿）》公开征求意见，拟扩大法律调整范围、健全平台责任制度，强化常态化监管。
- 航空公司：自 2026年7月5日 起，国内航线燃油附加费下调，800公里（含）以下每航段 50元，800公里以上每航段 100元。
- 海南省住房公积金管理局：自 7月6日 起，开展提取住房公积金支付物业费业务，进一步拓宽公积金使用范围。
- 云南省商务厅：7月起新增 9类 家电数码补贴产品，按销售价格 15% 给予补贴，每件不超过 1500元。
- 多地推进网约车“一车一码”：济南7月15日前完成合规网约车标识全覆盖，乘客可扫码验资质。
03 环球视野
- 伊朗局势：当地时间7月4日，伊朗在首都德黑兰为已故最高领袖阿里·哈梅内伊举行公众告别与悼念仪式，预计 1500万至2000万 民众参加。
- 俄罗斯总统普京：表示必须继续对乌克兰军工综合体及相关设施进行大规模打击；俄军6月对乌境内军工、能源设施发动 5次 大规模打击。
- 俄乌冲突：俄国防部称6月27日至7月3日打击乌克兰多处军用设施；乌方称其无人机袭击克里米亚俄军用机场，至少 7架 战机损毁。
- 俄罗斯国防部：提议乌方于莫斯科时间6日12时至18时停火，以便移交乌军阵亡遗体；乌总参谋部否认俄控制康斯坦丁诺夫卡。
- 乌克兰总统泽连斯基：表示可在乌克兰境内生产“爱国者”导弹，并承诺为美国行动提供支持，乌军正面临拦截导弹短缺问题。
- 美国极端高温：持续笼罩中部和东部，华盛顿特区取消独立日游行，最大电网运营商PJM启动联邦级预警，要求用户削减电力消耗。
- 伊朗外交部副部长：警告霍尔木兹海峡并非域外国家展示军事力量的场所，该海峡安全应由沿岸国家共同维护。
- SK海力士：将于7月6日启动美国存托凭证簿记建档，7月9日确定发行价，次日于纳斯达克上市，拟融资最高 294亿美元。
04 A股与港股
- 指数表现：本周沪指累计上涨 0.41%，深证成指下跌 1.17%，创业板指下跌 4.16%，个股分化明显，部分ST及高位股跌幅居前。
- 资金面：本周沪深两市股票型及跨境型ETF合计净流入 60.6亿元，行业主题ETF净流入 661亿元，半导体、卫星等题材获资金青睐。
- 业绩预告：多家公司披露2026年半年度业绩预告，江波龙预计净利润同比增长最高超 74000%，驱动因素为需求回暖及产品涨价。
- A股回购：上半年累计回购 648.39亿元，注销式回购占比超 50%，央企回购参与度提升。
- 韩国投资者：上半年买入中国资产 28.19亿美元，A股买入额同比增长 130.55%，聚焦北方华创等AI硬科技。
- A股并购重组：本周共 17家 公司披露进展，恒尚节能、埃斯顿等多股连板。
- 定增动态：7月4日，鹏鼎控股、中旗股份、阿科力披露定增预案，募资规模分别不超过 96.0亿元、6.4亿元、3.75亿元。
- 解禁高峰：下周市场解禁，屹唐股份解禁市值超 650亿元，居首位。
05 产业与公司
- 华为半导体：何庭波发布“韬定律”V2版本，新增量产实测数据与核心工艺描述，进一步阐释以时间常数为核心的后摩尔时代缩放理论。
- 三星电子：受AI需求驱动，晶圆代工4nm工艺基本售罄，8nm接近满载，已启动配额机制，订单积压额约 50万亿韩元。
- 功率芯片：慕尼黑上海电子展反映AI产业链涨价向元器件延伸，20余家功率芯片厂商计划7月1日起新一轮涨价，单轮涨幅普遍 10%-15%。
- 铠侠：推出第九代NAND闪存，实现 4.8Gb/s 接口速度，植入位密度提升 59%，写入及读取功耗效率分别提升 18% 和 30%。
- 宁德时代：为新能源重卡提供全系列电池，配套骐骥换电体系可实现 5分钟 整车换电，全国已布局 300余座 换电站。
- 中国广核：广东太平岭核电 2号机组 于7月4日首次并网发电，向投产迈出关键一步。
- 康希诺：国产首个组分百白破疫苗盼康欣®已获多省准入，预计7月获首批批签发，将逐步打开市场。
- 大疆创新：对影石专利维权升级，已在中国多地法院就影石Luna系列产品提起诉讼，请求停止侵权并赔偿经济损失。
06 商业风向标
- 智谱AI：推出GLM-5.2，编码和代理能力媲美美国领先产品且成本极低，中国大模型正改写硅谷价格竞争格局。
- 豆包平台：智能体功能将于 2026年7月15日 下线，用户可于10月15日前备份数据，字节旗下猫箱App将继续提供智能体服务。
- 高盛研报：DeepSeek自7月中旬起实施高峰时段价格调整，综合均价约每百万Token 0.35美元，国内AI模型价格战开始转向理性定价。
- 家电出口：欧洲极端高温致中国空调出口翻倍，格力、TCL移动空调售罄，海信车间两班倒不停工。
- 中国品牌汽车：据韩媒，4月中国车在韩国进口车市场首次超日本，凭借智驾技术与智能座舱受青睐。
- 上海之夏：2026国际消费季正式启幕，持续至10月，推出家庭亲子优惠、文博展览特惠及宠物联名套餐，打通吃住行游购娱链条。
