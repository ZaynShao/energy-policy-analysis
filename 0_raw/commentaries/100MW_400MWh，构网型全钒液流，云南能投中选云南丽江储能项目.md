# 100MW/400MWh，构网型全钒液流，云南能投中选云南丽江储能项目

「储能与电力市场」获悉，云南能源投资股份有限公司发布《关于拟投资建设丽江市宁蒗县100MW/400MWh全钒液流独立共享储能项目的提示性公告》。
公告透露，云南能投成功中选丽江市宁蒗县100MW/400MWh全钒液流独立共享储能项目社会投资人，该项目已正式列入2026年云南省新型共享储能项目清单。该项目规划建设容量为100MW/400MWh，拟选场址位于宁蒗县烂泥箐乡，采用构网型全钒液流电池储能系统。项目主要是为宁蒗县及丽江市片区新能源集中接入解决受阻、提供削峰填谷、调峰调频的服务。根据通知要求，项目开工后投产并网时间最长不得超过2年。云南能投表示，近年来公司持续深化丽江新能源布局，2025年至今已先后拿下永胜、华坪、古城多地风电、光伏项目开发权，新能源版图持续扩张。公司正在推进的昆明安宁350MW压缩空气储能示范项目，叠加本次全钒液流储能项目落地，将进一步完善公司新型储能业务布局，助力云南新能源规模化发展，提升区域电网新能源消纳与电力调节能力。责任编辑：丁凯乐
