# 量大管饱的游先看，把今年顶流游戏都攒来了

上周，小发一次性玩到了世嘉，CYGAME以及GAMEFREAK的新作。上一次小发能同时玩到这三家新游还是在东京电玩展，这次却是B站游先看。
没错，不到一个月，B站就又把局攒起来了。小发也没想到，继上回“瑞典版腾子”IOI跑来国内做宣发之后，几个顶流日厂也按耐不住，跑到国内做首曝了，只能说B站游戏区大手确实越伸越大了。
这回有相当多全新的一手内容，绝对的量大管饱，所以还是老规矩，大伙扶好坐稳，小发即刻带大家云逛展。
首先是世嘉场，带来的两款游戏分别是《索尼克赛车》和龙组全新作《异于天堂》。
《索尼克赛车》去年已经发售，作为《马里奥》赛车同类型的游戏，玩法比较爽快，也有很多IP联动，比如这次小发就试了海绵宝宝，我的世界，P5里的雨宫莲等等。
实话说，用海绵宝宝开着香蕉车比赛，路上还和末影龙肩并肩的场面也够神奇了。
这次的升级主要是中文配音，整体质量不错，就是不知道世嘉是不是以后游戏都会有中配。
然后，是世嘉今年最重磅的新作《异于天堂》。依然是如龙组最拿手的黑道题材，不过设定上既不是续集，也不是外传，而是一杆子支到了上世纪的日本，从大正到昭和时代，讲述如龙里最大黑帮，东城会的建立故事。
之前的预告片也主打一个严肃，有点日本教父创业史的意思。而且这次还请来了一大批明星助阵，别的不说，光ADO的主题曲就把大伙惊艳了一把。
不过这次试玩没有剧情内容，只是详细展示了战斗系统。
小发感觉，《异于天堂》无论是操作模式和节奏，都和《如龙》系列完全不同。玩家的轻重攻击，都不再像《如龙》那样按方块和三角，而是绑定在了左右四个肩键上。按下后分别代表左右手的轻重攻击，有点像打拳击。
战斗动画虽然也有如龙式的夸张，但手感偏写实，比如发力打中人之后，会有明显的反冲感，硬直也更大，被敌人躲开攻击会出现趔趄的小动作，甚至倒地后还可以左右滚来躲避敌人的追击。
主角依然可以用各种武器，BOSS战有个太刀哥，主角默认使用一把菜刀，打起来非常吃亏，但换成势大力沉的撬棍后，就变得容易不少。
整体难度有提升，但也有完美闪避，反击，处决追击如龙经典操作，上手不难，小发玩着很顺畅。
其他内容不多，但制作人给小发说目前放出来的消息都只是冰山一角，毕竟游戏横跨整整五个时代，也是龙组全新投入的IP，不知道发售后能不能一鸣惊人。
世嘉之后，就是CYGAMES的《碧蓝relink 无尽黄昏》。
这游戏是两年前发售的《碧蓝relink》的大型扩展包，但说是扩展，小发觉得更像把原版内容重做了一遍。
因为按照官方说法，他们加了相当于原版主线长度的内容，而且从头到尾完全进行了一波翻新。
比如六名新角色，全新的召唤兽系统，额外的天赋强化，仓库整体优化，因子爆率提高等等。
小发试玩后，觉得召唤兽和天赋系统是最有意思的。
召唤兽可以直接操作进行战斗，而且全程无敌，有各种强力技能，演出也非常酷。天赋系统则类似《暗黑破坏神》里的专精系统，不同专精能够直接改变游戏玩法。
新角色因为时间有限，小发只玩了玛琪拉菲菈。这角色主打反差萌，内心是大小姐，身材却是小萝莉。使用飞剑当武器，能够全程放风筝，动画相当华丽。人物配音则是大名鼎鼎的早见纱织，只能说CY人设这块给大伙拿捏的死死的。
再然后，就轮到了游戏业技术力的巅峰，任天堂摇钱树，宝可梦唯一指定公司GAMEFREAK了。
但这次GF的《轮回之兽》，不说和宝可梦毫无关系，也得是天差地别。首先请宝粉们欢呼，GF终于用上虚幻5了，堪比80岁老头学会智能机，起码是能联系上了。
先简单介绍一下游戏吧设定，游戏整体是科幻末世风。说是4026年，世界被“ 孽蚀 ”侵蚀，大多数动植物乃至人类都因为腐化嗝屁，部分人类放弃了肉身，把灵魂塞进机器，赛博转身成了“魔像”。
当然也有主角这样天赋异禀的，不光肉身能活，还获得了特殊能力。
具体到游戏里，就是能随时随地用头发生出藤蔓，可以当勾爪，还能搭桥，当电梯，相当方便。
游戏的整体玩法有点类似《尼尔机械纪元》的ARPG探索，融合《只狼》的拼刀战斗系统。
既要在末世中探索，搜集资源，了解真相，也得注意弹刀，闪避和暗杀。敌人都有架势条，打满就能破防施展处决，非常只狼。
唯一不同的是，主角有一个白狼伙伴——小库。战斗中可以像回合制游戏选技能那样让小库释放技能辅助战斗。
试玩时间是两小时，小发体验了一张开放地图，一段线性故事章节，总体氛围还是挺到位的，而且主角是石川由依配音，性格也主打冷漠，一度让我以为玩的是GF版的2B。
但小发得说，目前《轮回之兽》的问题也不少，比如游戏探索玩法比较平淡，都是大伙很熟悉的那套杀怪，找钥匙，打BOSS的流程，至少试玩部分爆点不多。
其次，GF技术力依然稳定发挥。虽然用上了UE5，但依然各种穿模，光影错位，纸片式的树叶和草地，手感也忽好忽差，拼刀非常爽，但走路又有点飘，画面乍一看不错，细看有些建模又很粗糙。
GF再努把力吧，哥们对你要求也不高，正式版BUG少点，能达到平均线就行。
说完前面几家日厂，再聊聊咱们国产新作。实话实说，这次几个国产新作，除了规模较小之外，创意和技术真不亚于上面几个成熟大厂。
首先是最重磅的《猿公剑：白猿觉醒》，游戏24年就公布过一次，不过那时卖相一般，借鉴了大量魂的玩法。
但这次试玩，画面有进步不说，玩法也完善了不少。
游戏围绕一套被制作组称为“避青入红”的系统，简单来说像是结合了《荣耀战魂》的方向格挡与《卧龙》的化劲系统。
玩家按住格挡键，就能启动“避青”状态，此时在被击的瞬间按下方向键，角色就能施展出一套帅气的闪避并同时还击，还可以大量削减敌人精力条。
这套系统集闪避，反击，削精三位一体。面对一些特殊招式，如果施展避青的方向与敌人招式来袭的方向完美对应，则可以施展出一套帅气处决。小发试玩过程中真就有种化身武林高手，从容有余，出手精准的爽感。
关键“避青入红”的玩法并不是孤立的，游戏中没有单独的闪避和翻滚键，所以面对敌人要么卡好距离，要么靠避青入红化解，化解失败则会变成普通的格挡。但这会让武器耐久值下降。
而武器耐久值也相当重要，主角设定中拥有一个铸剑匣，无论进攻还是防守，武器耐久值都会消耗，一旦耗空就需要重新铸剑。
所以虽然游戏看起来很”魂“，有做篝火，升级加点，一侧打不开的门。但玩起来却更贴合动作游戏里的连段，见招拆招，乐趣独特。
试玩最终的“猿公”BOSS，正面几乎无敌，玩家只能看准地方出手，使用“避青入红”才能打出伤害，整场战斗如同跳一场编排致密的舞蹈，紧张刺激，交互拉满。
其他诸如手感，音效都做的都挺扎实，制作组说目前团队一共才25人，这么小的团队，能做到如此程度小发真的佩服。
再往下，则是体量更小的《百夜地府》。
这游戏玩法是模拟经营，玩家要扮演一个地府管理员，管理地府，建设鬼门关，孟婆汤，引导灵魂升天一整套流程。
游戏主打双点医院那种Q版幽默风格，核心流程也是制造建筑，管理流水线那套，需要玩家一边替地府赚冥币，一边满足灵魂转世的需求，扩展地块，升级建筑等等。
题材比较新鲜，而且制作组一共就三人，完成度却相当高，发售后估计能成为一个小精品。
最后则是《怪兽幻想》， 属于Q版怪猎+生存建造+RPG探索为一身。
简单来说，玩家可以选择不同的职业，在游戏中狩猎巨型的怪兽，并用它们的尸体材料打造装备或发展营地。游戏卖相还不错，太刀侠一出来血脉都觉醒了，除此之外还有弓箭手，法师，等等职业，算是比较丰富。
生存方面有建造，挖矿，钓鱼，捕虫这些，制作组表示未来还会加入新的内容，后续可以期待一下。
那以上，就是这次游先看的所有内容了。如果要小发给一个评价，可能是“成熟”。
这个成熟不单单是B站挑选这些游戏的眼光越来越成熟，也说明中国游戏市场越来越成熟。
无论是海外大厂，还是国内的新秀，拿出来的东西都是经得起检验，没有任何藏着掖着，直接就能上手试玩的。
这就比那些放个PV预告，LOGO动图，甚至干脆就是PPT加几行字的游戏，要成熟太多。
不避讳，不害怕，正视优势与缺陷并逐渐补强。这种意识，对游戏这种复杂工业支持的产业必不可少，而现在国内游戏产业正在走向这条路，小发还是很欣慰的。
而且小发这波不光是现场爽玩，爽完之后还意犹未尽，巴不得游戏赶紧发售，希望以后的游戏，也都能有这种劲头，如果真能实现，那咱们国内玩家可就真有福了。
