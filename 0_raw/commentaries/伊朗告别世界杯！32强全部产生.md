# 伊朗告别世界杯！32强全部产生

世界杯32强全部产生。
当地时间6月27日，美加墨世界杯J组末轮比赛结束，奥地利队、阿尔及利亚队搭上淘汰赛“末班车”。至此，世界杯32强全部产生，以下为32强名单。
A组：墨西哥队、南非队；
B组：瑞士队、加拿大队、波黑队；
C组：巴西队、摩洛哥队；
D组：美国队、澳大利亚队、巴拉圭队；
E组：德国队、科特迪瓦队、厄瓜多尔队；
F组：荷兰队、日本队、瑞典队；
G组：比利时队、埃及队；
H组：西班牙队、佛得角队；
I组：法国队、挪威队、塞内加尔队；
J组：阿根廷队、奥地利队、阿尔及利亚队；
K组：哥伦比亚队、葡萄牙队、刚果（金）队；
L组：英格兰队、克罗地亚队、加纳队。

哥伦比亚队vs加纳队。
伊朗告别世界杯
在刚刚结束的美加墨世界杯小组赛J组末轮比赛中，奥地利队与阿尔及利亚队最后时刻3:3握手言和，双双晋级32强淘汰赛。
奥地利队三战积4分，以小组第二晋级，淘汰赛首轮将对阵西班牙队。阿尔及利亚队同积4分，因净胜球劣势排名小组第三，获得最后一个32强名额，淘汰赛首轮将面对瑞士队。
伊朗队在所有小组第三名排序中位列第九，告别本届世界杯。
