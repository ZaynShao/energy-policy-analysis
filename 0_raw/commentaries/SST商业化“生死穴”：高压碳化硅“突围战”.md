# SST商业化“生死穴”：高压碳化硅“突围战”

英伟达发布AIDC 2.0白皮书，确立下一代AI工厂800VDC高压直流供电标准，明确34.5kV中压直入、模块化功率块、固态全域保护三大方向。
几乎同步，臻驱智慧能源发布国内首款可量产35kV/5MW固态变压器，敲定四季度批量交付，搭载的正是其自研的3300V全SiC功率模块。
更值得关注的是，此前一周内，晶能微电子发布面向SST的自研SiC功率模块首倡"AI级SiC模块"，芯联集成推出3300V平面栅SiC MOSFET专为中压SST定制并已送样，瞻芯电子搭建起完整3.3kV产品矩阵斩获首批商业订单。
国产SiC产业链正从单点器件替代走向"芯片—模块—系统"纵向协同的首次公开预演。 但从"心脏外采"到"芯片自供"，这条路仍差最后一口气。
阳光电源副董事长顾亦磊此前在接待机构投资者调研时曾表示，碳化硅是实现SST高效率、高功率密度的基础。但高压SiC器件长期工况可靠性、成本仍是工程化核心矛盾。
阳光电源判断2026‑2027年以示范验证为主，2028年才会迎来SST大规模商用拐点，器件端成熟度会直接决定行业落地节奏。
传统变压器为何彻底跟不上？
英伟达下一代Rubin Ultra单机柜功耗干到600kW，再往后的Feynman直奔MW级。传统供电链条冗长：电网高压→10kV进园区→油浸变压器降到380V→UPS→整流器变直流，每一手都有损耗、占地、发热，且笨重无法灵活调配。
传统变压器是50Hz工频电磁设备，适配平稳匀速的民用场景。但AI算力负载完全相反——GPU集群以毫秒级步长吞吐兆瓦级功率，大模型训练产生高频剧烈脉冲波动。当单柜功耗冲向100kW、园区光伏与储能需要与电网双向对话时，传统变压器短板被完全暴露。
西电电力电子技术中心主任许崇福此前亮出实测数据：同等2.4兆瓦功率下，SST相较传统变压器铜材减少超50%，单台年节约56万度电，占地缩减一半以上。2024年全国数据中心平均PUE达1.46，近四成电力损耗在多级变压和散热环节。
英伟达的方案是：从34.5kV高压电网一步到位变成800V直流，砍掉中间大半环节。实现这一想法的硬件载体就是SST——抛弃传统铁芯工频变换逻辑，依靠碳化硅器件高频开关实现电压变换、功率调控、故障保护、能源调度一体化。
而SST的心脏，正是长期被英飞凌、Wolfspeed、罗姆、安森美把持的高压SiC MOSFET。
SiC：SST从实验室走向商用的关键拐点
SST在实验室躺了大半个世纪，为何2026年迎来商业化元年？答案藏在新能源汽车主驱大规模采用SiC MOSFET这条隐秘链路上。
每年数百万辆电动车的装车验证，既跑出了SiC可靠性，也把芯片价格从高位拉下。正是汽车主驱极端工况下积累的可靠性数据与量产工艺被迁移至SST场景，让SST终于跨越从"实验室技术"到"商业化落地"的门槛。
Wolfspeed数据更具说服力：其10kV SiC MOSFET可在10000Hz以上运行，而传统6500V硅IGBT因高开关损耗仅限于几百赫兹，使基于硅IGBT的高压SST"不切实际"。更高开关频率直接减小磁性元件尺寸——所需磁线圈和磁芯尺寸随频率增加而减小。
英飞凌科技（中国）技术总监田斌直言："碳化硅是SST的心脏。"
但行业专家指出一个被忽略的隐忧：SST对碳化硅的可靠性要求可能比汽车主驱更高、更隐蔽。
单台SST内置数十颗高压SiC模块，成百上千颗芯片并联或串联运行，任何一颗芯片因长期高dv/dt、高温循环产生栅氧退化或焊料疲劳，都可能引发整机宕机。传统静态老化设备无法模拟高频动态开关及温度交变过程，国内目前缺少可覆盖2000V以上高压、支持动态功率循环、能进行上千小时加速老化的国产可靠性测试设备。
除可靠性外，更为关键的是成本问题。
华润微董秘吴国屹透露，据公司器件业务线测算，SST整机中碳化硅模块成本占整机25%‑30%，为整机第一大元器件成本。
台达‑中达电通资通讯基础设施事业部总经理顾中林在此前的集装箱式SST直流移动智算中心发布会上也公开表示，SST整机性能的天花板由碳化硅器件决定，没有碳化硅的高频、低损耗特性，兆瓦级SST的小型化目标很难实现。但现阶段高压SiC模块成本占整机比重偏高，规模化降本是产业共同课题。
国产高压SiC突破
当前SST核心功率芯片仍高度依赖进口，1700V以上中高压段长期缺位，业内戏称"整机热、器件冷"。但国产突破正在密集涌现。
芯联集成3300V平面栅SiC MOSFET核心价值在于：将适配10kV场景的母线电压抬至1800—2200V，级联数量减少约60%，功率单元总量减60%，综合系统BOM成本降20%—35%。
单颗3300V虽比1200V贵数倍，但因总量骤减、辅件暴降，整机总成本反降。选择平面栅而非沟槽栅体现了工程克制——沟槽栅在3300V档位氧化层可靠性在量产规模上未被充分验证，平面栅成熟度高、良率更可控，要的是"能规模出货、客户敢用的器件"。
瞻芯电子搭建了覆盖管芯、分立器件、大功率模块的完整3.3kV产品矩阵，XPak半桥模块常温直流载流750A、峰值脉冲1500A。
合肥安海半导体6.5kV与10kV系列SiC MOSFET芯片良率均突破80%实现量产，成为全球率先以高良率量产超高压芯片的厂商之一。
但必须清醒。芯联3300V仍处送样阶段，量产良率爬坡是现实短板。国内高压SiC专用驱动IC生态仍薄弱。磁性材料仍部分依赖海外供应商。单一芯片突破救不了SST的系统复杂性。
SST对SiC的意义不止于"量"——单个SST模块SiC芯片用量可接近1000颗。更深层的意义在于，SST是SiC从车规走向电网等超高压市场的关键跳板。
同时，这也与碳化硅在高压储能系统中的渗透形成共振。
阳光电源Powertitan 3.0首次在大储应用SiC；特斯拉Megablock沿用成熟SiC逆变器技术；比亚迪自研SiC PCS构建GW级构网方案；国电南自实现全国产化碳化硅构网型PCS核心器件100%国产替代。工商业侧，盛弘股份发布全球首款SiC工商业模块化储能变流器。
大储系统正朝高功率、高密度方向迭代，500Ah+大电芯让电池簇电流倍增，2000V高压架构对器件绝缘与损耗提出严苛要求。碳化硅开关损耗大幅降低，系统效率突破99%以上。
行业预计2026年碳化硅PCS在大储领域渗透率有望突破10%，碳化硅MOSFET价格年均降幅15%—20%，与硅IGBT价差持续缩小。
回到SST领域，台达集团判断到2030年SST中性预测数百亿、乐观预测千亿。
高工储能认为，SST并非简单设备升级，而是"硅进铜退"的电力系统底层革命。百年工频被动配电体系已无法承载GW级AI超级工厂的发展需求，以SiC+SST为核心的主动式、高频化、智能化电力架构是行业迭代的必然趋势。
但真正的决胜点不在于谁先发布量产通稿，而在于谁能率先在全链条可靠性上撕开一道口子。
下一代SST能否换"心"，取决于国内SiC产业能否把"中压长期挂网"这套比车规更严苛的筛片与验收规范先跑通固化。
正如许崇福所言，SST工程化有三道生死坎，排在第一位就是高压碳化硅器件长期运行可靠性。
