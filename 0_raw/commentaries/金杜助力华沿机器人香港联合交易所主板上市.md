# 金杜助力华沿机器人香港联合交易所主板上市

![image](https://mmbiz.qpic.cn/mmbiz_png/WWbwrx83bPCUzibxcp1YvJ7O6wukEA00PonlPbh2rib6NLaVicdnr1bFMYGibplSCrqCRGhWXyH1N4HWPwMlQWbNc1EXhppMbeu4hWjQk941NQg/640?wx_fmt=png&from=appmsg)

2026年3月30日，广东华沿机器人股份有限公司（简称华沿机器人，股票代码1021.HK）首次公开发行H股股票并在香港联合交易所主板成功上市。华沿机器人本次全球发售H股的股份总数为80,785,000股（绿鞋前），发售价为17.00港元/股，募资总额约为13.73亿港元（绿鞋前）。

华沿机器人是一家协作机器人公司，从事面向工业自动化应用的协作机器人及核心运动部件的研发、生产和销售。于2024年按收入计，华沿机器人是中国第二大协作机器人公司，也是全球前五大协作机器人公司，华沿机器人亦是全球五大协作机器人企业中收入增长最快的公司。

本项目中，金杜担任发行人中国境内律师以及数据合规顾问，充分彰显了金杜全方位、一体化的综合法律服务能力。金杜团队全面深入参与本项目各个环节，凭借丰富的资本市场业务经验以及对于监管要求和机器人行业的深刻理解，高效推进项目的执行工作，主导并协助华沿机器人解决项目中遇到的各项境内法律问题，为本项目提供了专业、优质、高效的服务，助力华沿机器人圆满完成本次上市发行。

本项目的主办合伙人为**周蕊**、**田维娜**、**骆霄**，项目团队成员包括刘璋儒、韩天骄、罗心悦等。在数据合规方面，由合伙人**傅广锐**及团队成员艾天心、徐丽娟等提供支持。
