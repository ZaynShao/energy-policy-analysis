# 人民网发布“媒体语料服务平台”项目

5月26日，在2026中国媒体融合发展论坛上，人民网正式发布“媒体语料服务平台”，为媒体行业提供一站式的语料服务解决方案。
当前，数据赋能人工智能迈入新阶段。人工智能发展从通用大模型向行业垂域模型、代理型人工智能形态演进，对数据的需求也从基础语料到行业高质量数据集拓展。
人民网党委书记、总裁范正伟在论坛上表示，随着AIGC的普及，“生成即传播”成为新的信息触达模式。无论是算法还是语料，都关乎大模型的政治方向、舆论导向和价值取向。在此背景下，语料的价值愈发凸显，媒体的责任更加重大。
近年来，人民网持续深耕语料建设。2023年，在人民日报社统筹部署下，人民网依托传播内容认知全国重点实验室，着力建设“主流价值语料库”，并入选国家数据局高质量数据集典型案例。为了更好服务语料生产，在人民日报社指导下，人民网于5月9日启动“主流价值语料生态联盟”。
此次发布的“媒体语料服务平台”，是联盟打造的第一个系统性成果。据介绍，该平台集成联盟成员专业能力，通过“云基座”“加工器”“标准尺”“安全盾”“产权锚”五大工具，为媒体同行提供一站式的语料服务解决方案。
具体来看，人民网联合中国电信天翼云，打造可靠、安全的云专区，为数据处理与模型训练提供算力底座；集成科大讯飞、同方知网等成员的智能技术，提供从数据清洗、标注到预处理的轻量化工具链；联合北京大学等高校智库，共同探索媒体语料建设的标准与规范；携手源自清华大学的荆华密算，通过密态计算技术，确保高质量语料流通安全；同时，人民网旗下的人民数据，提供语料产权管理方案，为媒体语料构建产权基础。
语料筑基，应用开花。近年来，人民网打造的一系列人工智能创新成果，正展现出从底层语料到上层应用的实践能力。
“人民智媒大模型”运用价值导向纠偏的强化学习技术、知识增强策略，为智能问答、文章创作、润色审校等内容生成提供支持，能够协助党政机关、企事业等单位构建各类模型。
“人民审校”内容审核风控平台提供时政信息表述审校、综合信息审校等内容安全服务，支持文本、图片、音视频等多模态内容审校，可在内容发布前辅助审校，也可在内容发布后开展多平台巡查和风险筛查。
“自在”心理大模型以“心理测评+疏导咨询”为核心功能，帮助家长和教师对孩子进行心理疏导、情绪管理、亲子交流、家校共育等。2025年3月，成为教育部向全国教育系统推荐的唯一AI心理应用，上线国家智慧教育平台。
AI经贸文旅智能体提供多语种智能翻译服务，实现政策智能查询、智能商贸匹配、智能展销、智能行程规划等应用，满足经贸文旅领域多维度需求。已在广西桂林、宁夏银川落地应用。
近期发布的《2026年数字经济发展工作要点》明确指出，丰富数据资源运营、数据技术创新、数据分析应用等服务供给。与会嘉宾表示，从建设“主流价值语料库”到推出“媒体语料服务平台”，人民网正以系统性变革的姿态，推动主流媒体在人工智能时代守正创新，为网络生态治理和网络强国建设贡献媒体力量。
