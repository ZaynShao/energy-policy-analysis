# 大走廊动态｜云门中心、云城天街等项目火热加载中

好消息！
近日，云门中心、云城天街综合体项目、
杭州西动车所上盖住宅
及幼儿园项目
都迎来了新进展！
一起来“云监工”吧～
云门中心项目总建筑面积约99.5万平方米，由4栋超高层塔楼及“云门”组成。其中，A塔楼“金手指”建筑面积约17.4万平方米，地上61层，以320米高度成为目前杭州已封顶的最高建筑；B塔楼高300米，C、D塔楼均为213米，共同构成气势恢宏的“云门中心”建筑群。
云门中心实景 摄于2026年5月
A塔楼塔冠已于5月22日成功合龙，目前正在进行水平圆管补杆工作，预计月底前全部施工完成，同时幕墙已施工至46层；B塔楼顶部塔冠钢结构已全部施工完成，目前正在进行塔吊的拆除工作，同时幕墙已施工至44层；CD塔楼外立面幕墙及油漆工程已施工92%，室内正在进行机电安装及粗装修工作。
“金手指”合龙实景 摄于2026年5月
项目预计于2028年整体完工。
近日，备受关注的云城天街综合体项目建设再提速——目前，项目正在全力进行地下室顶板浇筑施工，其中超塔部分已完成浇筑冲出“正负零”。预计今年9月开放办公示范区。
项目实景 摄于2026年6月
云城天街综合体位于杭腾未来社区东北角，总建筑面积约36万平方米，涵盖约13万平方米的龙湖天街（地上6层、局部7层，地下4层）、约200米的甲A级超塔办公中心、高端行政酒店式公寓及邻里服务中心等多重业态。
云城天街效果图（过程稿）
项目以“云上方舟”为设计主题，极具未来感与科技气息。
项目航拍实景 摄于2026年6月
作为龙湖在杭州的第10座天街，也是杭州首个“L1+”级天街、龙湖最高量级的旗舰作品，项目将引入超300家时尚跨界品牌，融合新兴生活体验、未来科技展示、无边界景观餐饮社交空间、亲子家庭聚场、云上食空等多元业态，创造前所未有的购物新体验。未来，这里不仅是消费的目的地，更是社交、休闲、娱乐的理想聚场。
杭州西动车所上盖住宅
及幼儿园项目新进展
杭政储出【2023】158号地块住宅及幼儿园项目正式取得杭州市规划和自然资源局核发的《建设工程设计方案确认书》。这标志着项目在规划设计阶段取得关键性突破，为后续申领《建设工程规划许可证》及全面开工建设奠定了坚实基础。
项目位于杭州西站西北侧约4公里处，地处杭州西动车所上盖北区域，紧邻地铁19号线苕溪站。作为云城西超级未来社区首宗出让地块，项目总用地面积约12.2万平方米，规划建设25幢5至17层住宅建筑及1所12班幼儿园。
项目鸟瞰效果图（过程稿）
项目容积率仅1.6，属于低密度大体量社区，致力于打造以轨道交通为驱动、以产业集聚为引擎、以综合配套为支撑的TOD品质社区。
住宅效果图
（过程稿）
值得关注的是，位于同一上盖区域的杭政储出【2023】158号地块54班中小学及广场项目目前已进入实质性施工筹备阶段。这座九年一贯制“空中花园”学校将充分利用动车所上盖的独特地形，创新性地将校园与运动广场、绿化景观立体融合。
54班中小学及广场项目鸟瞰效果图
住宅、幼儿园、中小学等项目齐头并进，从学前教育到义务教育无缝衔接，为未来居民铺就一条“家门口”的优质成长之路。
