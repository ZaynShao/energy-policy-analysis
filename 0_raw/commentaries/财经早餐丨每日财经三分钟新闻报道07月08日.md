# 财经早餐丨每日财经三分钟新闻报道07月08日

► 美国中央司令部：美军已对伊朗发动一系列打击，回应霍尔木兹海峡商船遇袭。
► 国家外汇管理局：6月末我国外汇储备 34163亿美元，较5月末下降 260亿美元。
► WTI原油：日内涨近 6%，突破 72美元/桶。
01 今日财经头条
- 美国中央司令部：美军已对伊朗发动一系列打击，以回应伊朗此前对霍尔木兹海峡内三艘商船的袭击。
- 国家外汇管理局：截至2026年6月末，我国外汇储备规模为 34163亿美元，受美元指数上升及资产价格变化影响，较5月末下降 260亿美元，降幅 0.75%。
- 国际原油市场：受美国撤销伊朗石油制裁豁免及美军打击伊朗刺激，WTI原油日内涨幅接近 6%，突破 72美元/桶；布伦特原油涨超 2%，报 73.5美元/桶。
- 美股市场：三大指数集体收跌，道指跌 0.25%，纳指跌 1.16%，标普500指数跌 0.45%。半导体板块领跌，油气板块走高。
- 费城半导体指数：暴跌超 6%，闪迪跌超 11%，美光科技跌超 6%。三星电子二季度营业利润创纪录，但其股价仍跌近 7%，韩国KOSPI指数一度跌超 8% 触发熔断。
- A股市场：沪指失守 4000点，收跌 1.26% 报 3990.24点，成交萎缩至 2.6万亿元，近 4800只 个股飘绿。
02 宏观与政策
- 国家发改委：下达2026年第三批“两重”建设项目，安排超长期特别国债 1935亿元，全年共 8000亿元 支持 1417个 重大项目。
- 中国人民银行：截至6月末，我国黄金储备达 7544万盎司，环比增加 48万盎司，已连续 20个月 增持黄金。
- 央行行长潘功胜：将扩大债券通“南向通”年度投资净额度至 8000亿元，并将“南向通”债券纳入回购支持范围，深化内地与香港金融互联互通。
- 市场监管总局：上半年整治“内卷式”竞争，对拼多多、美团等 7家 电商平台罚没合计 35.97亿元，并督导货拉拉落实反垄断合规整改。
- 市场监管总局：正在推进《价格法》修改工作，拟完善低价倾销等不正当价格行为认定规则，并对《公平竞争审查条例实施办法》进行修改完善。
- 金融监管总局：联合上海市政府印发《关于加快上海国际再保险中心建设的若干措施》，推出 8条 具体政策，引导机构向临港新片区集聚。
- 国家数据局：印发《数据产权登记工作指引（试行）》，构建全国统一数据产权登记体系，推动数据要素市场化配置。
- 国防部：中国海军战略核潜艇组织潜射战略导弹试射，为年度军事训练例行安排，已向有关国家通报。
03 环球视野
- 霍尔木兹海峡局势：连接波斯湾的关键水道接连发生船只遇袭，卡塔尔LNG运输船及沙特油轮受损，美军随后对伊朗发动打击。
- 美国总统特朗普：在北约峰会上重申美国应控制格陵兰岛，威胁若欧洲持续反对将撤出全部驻欧美军。
- 法国经济与财政部长：将2026年经济增长预期从 0.9% 下调至 0.7%，为年内第二次下调，主因首季经济萎缩及中东冲突影响。
- 英国央行：发布金融稳定报告，指出人工智能加深股价泡沫和网络攻击风险，并提议降低银行杠杆比率资本要求 20个基点。
- 北约盟国：已同意至少 500亿美元 国防工业协议，11国采购瑞典萨博GlobalEye侦察机，部分取代美国同类装备。
- 乌克兰总统泽连斯基：在北约峰会期间敦促加大对乌防空援助，称已同美方讨论“爱国者”防空系统生产许可问题。
- 欧洲债市：英国10年期国债收益率上涨 5.6个基点 至 4.847%，法国10年期国债收益率上涨 5.8个基点 至 3.792%。
- 欧盟统计：2025/26年度大豆进口量达 1408万吨，较前一年度的 1453万吨 下降；软小麦出口量为 2342万吨，同比增加。
04 A股与港股
- A股市场：量价齐跌，沪指失守 4000点，收报 3990.24点， 4797只 个股下跌， 46只 跌停，医药、大消费领跌。
- 半年报预告：截至7月7日21时， 125家 A股公司披露半年度业绩预告，其中 110家 预增，占比 88%。
- 招商证券：预计2026年上半年归母净利润为 100亿元至110亿元，同比增长 93%至112%，经营业绩创历史同期新高。
- 中远海控：7月7日首次实施A股回购，回购股份 300万股，成交金额约 4136.17万元，旨在维护公司价值及股东权益。
- A股并购重组：2026年上半年全市场近 2000家 上市公司披露并购重组进展，交易总价值逾万亿元，超七成标的集中于新质生产力领域。
- 渤海租赁：上半年预盈 30亿~36亿元，同比扭亏，飞机租赁业务增长及债务重组收益 约16亿元 为主要驱动。
- 锦浪科技：预计上半年归母净利润同比下滑 23.61%~31.91%，但二季度扣非净利环比预增超 630.34%。
- 宜宾纸业：走出“五连板”后披露预亏，上半年归母净利润亏损 4100万~6150万元，醋酸及造纸业务承压。
- 中国石油化工股份：在港交所连续 12个交易日 回购，累计斥资 1.81亿港元。
05 产业与公司
- 浪潮信息：预计2026年上半年归母净利润 26亿元至31亿元，同比增长 226%-288%，AI算力需求驱动业绩大幅提升。
- 复旦微电：预计2026年上半年归母净利润 8亿元至10亿元，同比增长 313.19%-416.49%，扣非净利润预计 3.5亿元至4.5亿元。
- 松发股份：预计2026年上半年归母净利润 36亿元，同比增长 456.33%，受益于全球造船市场高景气周期及船舶交付量提升。
- 海通发展：预计2026年上半年归母净利润 5亿元至5.5亿元，同比增长 475%至532%，全球干散货航运市场运价回暖推动业绩增长。
- 妙可蓝多：2026年上半年实现营业收入 33.04亿元，同比增长 28.71%；归母净利润 1.51亿元，同比增长 13.74%。
- 欧菲光：预计2026年上半年归母净利润亏损 3.6亿元至4.6亿元，亏损主因存储芯片价格上涨导致下游需求走弱及政府补助减少。
- 国家医保局：在第12批国家集采中，某进口原研药企提交虚假专家联署建议函干扰定品，超八成签名非本人签署，医保局予以严厉批评。
- 亚马逊：已完成多期限债券发行定价，规模总计 242.5亿美元，票面利率区间为 4.6%至6.25%。
- 英伟达：SemiAnalysis爆料称Kyber NVL144机架可能延迟超 12个月，因PCB中板制造工艺面临重大挑战。
06 商业风向标
- 沙特阿美：大幅下调8月亚洲市场原油售价，降幅达 26年来 最高。花旗预计布伦特原油年底或下探至 60-65美元/桶。
- 盖蒂图片社：正式终止对Shutterstock的 37亿美元 并购计划，英国监管机构此前设置审批阻碍，该交易曾获美国司法部批准。
- 世界杯转播权竞标：奈飞、迪士尼和YouTube均表现出竞购意向，版权套餐价值预计高达 20亿美元，国际足联将在未来三个月展开正式谈判。
- Rivian Automotive：股价周二暴跌 18%，此前宣布公开发行 7500万股 A类普通股，预计募资约 15.1亿美元。
- 沃尔玛：宣布在全美门店推出大规模夏季降价，涵盖数千种商品，但消费者抱怨产品质量下滑与“缩水式通胀”问题。
07 投资与观察
- 纳斯达克100指数：Kalshi预测平台交易员认为，2026年下半年该指数再大幅上涨概率有限，年底收于 30000点 上方概率约 50%。
- 摩根大通：维持半导体板块“增持”评级，预计2026年全球半导体收入有望同比增超 90% 至 1.5万亿~1.6万亿美元。
- 高盛策略师：认为资本密集型公司本财报季有望公布稳健业绩，且将持续跑赢轻资产类股，投资者在这些领域布局仍显不足。
- 阿波罗首席经济学家：警告七巨头以外公司尚未展现AI投入带来的盈利提升，标普500其余 493只 成份股利润率变化对整体估值至关重要。
- 资金面观察：跨季扰动消退后DR007回落至政策利率下方，多家机构认为资金面偏紧阶段或已过去，央行呵护流动性态度明确。
- Strategy：出售 2.16亿美元 比特币用于分红安排，市场短暂承压后快速修复，比特币重新站上 64000美元 关口。
