# 0.6GW/2.4GWh，构网型，内蒙古乌拉特中旗2026储能电站实施主体优选

优选方及优选项目的基本情况如下：
优选方：乌拉特中旗发展和改革委员会。
项目建设地点：乌拉特中旗境内。
项目接入：巴中500KV变电站。
项目建设规模：总规模60万千瓦/240万千瓦时，单个储能电站申报规模需大于等于20万千瓦/80万千瓦时。
技术类型：独立新型储能电站采用构网型技术，优先支持压缩空气、全钒液流、钠离子等技术路线，鼓励实施长时储能电站（时长4—8小时）。
优选工作时间、地点安排为：
企业报名和申领优选文件时间：2026年7月3至7月6日每日上午9:00至下午17:00。
申报企业递交申报材料时间：2026年7月13日上午10:00前。
申报企业递交申报材料地点：2026年7月13日上午10：00前将纸质版递交至呼和浩特市腾飞南路九二大厦14层1402室，逾期不受理。电子版与纸质版不一致时，以纸质版为准。
