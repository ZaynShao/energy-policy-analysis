# 山东一大型井工铁矿启动联合试运转

8月18日上午，山东能源鲁西矿业会宝岭公司凤凰山铁矿启动联合试运转，这是该矿井从基建转入生产运营阶段的重要里程碑，标志着山东能源集团战略性矿产保障能力建设进入新阶段。山东能源集团党委书记、董事长李伟出席活动并宣布启动联合试运转。
▲山东能源集团党委书记、董事长李伟讲话。
李伟表示，凤凰山铁矿是山东能源集团落实国家能源资源安全战略、培育战略性矿产资源的骨干项目。要以联合试运转为契机，锚定“创建全省非煤矿山行业标杆”发展定位，紧扣“安全、绿色、智能、高效”四型矿井建设目标，深化落实治本攻坚三年行动，统筹矿石开采、尾矿处置、固废利用、生态修复全链条管控，加快数字转型赋能，推动铁矿高标准投产、高水平运营、高质量发展。要按照“五大控制”和“四个一”机制要求，精益求精、细化任务，把凤凰山铁矿打造成为效益工程、示范工程，为山东省非煤矿山行业转型升级打造标杆样板。
山东能源集团是山东省能源行业的国有资本投资公司，承担着“保障能源安全、优化能源布局、优化能源结构”的主体责任。目前，已形成以煤炭、电力及新能源为基础，高端化工及新材料为增长极，现代物流贸易为联通纽带，战略性矿产资源为储备支撑的“3+1”主业体系。
▲山东能源鲁西矿业凤凰山铁矿大景。
凤凰山铁矿位于山东省临沂市兰陵县境内，铁矿石资源储量1.64亿吨，设计采选矿石能力400万吨/年，铁精粉生产能力100万吨/年，是山东能源集团落实山东省委、省政府关于筑牢矿产资源安全底线、推动战略性矿产增储上产工作部署，重点建设的大型现代化铁矿。项目达产后，将与会宝岭铁矿协同构建千万吨铁矿工业园区，为山东区域塑强金属矿山发展动能、服务区域经济社会发展提供坚实支撑。
