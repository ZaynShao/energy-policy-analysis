# 电池消费税落地，新能源车会涨价吗？

# 编者按
近日，长达十年的电池消费税免征政策正式终结。与汽车密切相关的锂离子蓄电池将如何征收消费税？对应汽车成本上涨多少，新车价格会大规模上调吗？今年一系列汽车税收政策调整，还会有什么“续集”？油电同权的系统性改革会有哪些新动向？北京交通广播记者戚天就这些问题对有关专家进行了专访。
//电池包生产线。（新华社记者 周牧 摄）
电池：免税退坡“分步走” 精准“滴灌”新技术
近日，财政部、海关总署、税务总局发布公告，自2026年9月1日起，电池消费税政策分步调整，与汽车密切相关的包括锂离子蓄电池、钠离子电池、固态电池、燃料电池，其中最常见的锂电池将从今年9月1日起，按照2%税率征收消费税，明年9月1日起，按照4%税率征收消费税。
这次调整不是新增税收，而是免税政策逐步退出。早在2015年2月，我国首次将电池纳入消费税征收范围，基准税率为4%。当时，国内锂电、光伏等产业处于成长期，为了培育新能源产业链，我国对锂离子蓄电池、太阳能电池等七类技术先进或环保型产品实施全额免税。经过十年扶持，我国已成为全球锂电池生产、消费及出口第一大国，形成了全球产能规模最大、产业链最完整、最具全球竞争力的电池产业体系。
不可否认，我国锂电行业存在盲目建设，低价无序的“内卷式”竞争。综合开发研究院（中国·深圳）财税贸易与产业发展研究中心主任韦福雷告诉北京交通广播，部分电池企业为抢订单采取低价竞争策略，导致行业陷入价格战泥潭，治理行业内卷是税收调整的最核心原因。值得注意的是，今年1月的锂电池出口退税调整，与这次消费税调整，在原因和效果上高度相似，构成产业反内卷的政策“组合拳”，推动我国电池产业从规模扩张向高质量发展转变。
具体来看，电池消费税调整采用较为平缓的分步走方式，比如锂离子蓄电池先从2%税率起征，一年后恢复到4%全额征收，而光伏电池的免税退坡节奏再延后半年，减缓对产业的冲击程度。同时，政策调整保持差异化，在2028年12月31日前，对钠离子电池、固态电池、燃料电池等免征消费税。韦福雷介绍，燃料电池、钠离子电池和固态电池尚处产业化早期，免税政策会促进前沿技术加速突破，培育新兴产业，抢占未来制高点。
电池成本增千元，车价会涨吗？
新政实施首先影响电池产业，韦福雷分析，锂电池行业将加剧分化，头部企业凭借规模效应和较强议价能力将部分税负向下游传导，但二三线企业议价空间有限，利润承压，会加速低效产能出清。
与公众直接相关的新能源汽车，会因为动力电池征税而涨价吗？中信证券的分析报告显示，对一辆单车60KWh的电动汽车而言，2%税率对单车成本影响大约在468元，4%税率则对应936元。申银万国的报告显示，2%税率下60kWh 乘用车电池成本增量约480元，4%税率下约1000 元左右。
今年，汽车行业跌入利润低谷，上半年行业利润率3.4%，显著低于全国工业平均值。整车制造利润率更是低到1.5%，意味着一辆10万元的新车，车企利润仅1500元。后续动力电池税收成本上升1000元左右，再加上芯片、钢铁成本上行，将给车企带来较大压力。
韦福雷认为，头部与自产电池的车企，能够凭借规模效应和成本控制能力，通过内部消化大部分成本。但是，外部采购的车企压力较大，新增的税收成本将成为压垮弱势车企的“最后一根稻草”，加速行业洗牌。对于消费者来说，在汽车市场竞争如此激烈的当下，车企难以将成本全部转嫁给消费者，车价全面上涨的可能性很低。
乘联分会秘书长崔东树指出，新政规定，纳税人自产自用的应税电池产品，不缴纳消费税，意味着整车企业自己造电池并直接装车，可以合法避税。在新政助推下，整车企业造电池，或整车联合相关企业共同造电池的趋势将日益明显，掌握动力电池核心能力是车企构建长期竞争力的关键，更多车企造电池有利于中国汽车产业做大做强。
油电同权，下一只靴子何时落地？
从更宏观的视角看，电池消费税不只是单一行业的税收调整，还涉及“油电同权”的系统性改革。今年1月1日起，新能源汽车购置税由“全额免征”调整为“减半征收”，单辆车最高减税额不超过1.5万元。7月3日，财政部等部门联合发布公告，自2027年1月1日起，取消对节能汽车减半征收车船税政策，取消对纯电动商用车、插电式（含增程式）混合动力汽车、燃料电池商用车免征车船税政策。
购置税、车船税、电池消费税的免征起始点在2012年到2015年间，彼时我国新能源汽车刚刚萌芽，长达十几年的扶持政策让它从“蹒跚学步”到全球领先。今年多项免税政策退出，覆盖新能源汽车生产、购置、保有环节，意味着全产业链普惠补贴正式终结，这更像是新能源汽车产业的“成人礼”。
未来的汽车税收政策还会如何变化？新能源汽车消费税可能是一大方向。近日，北京大学中国财税研究中心主任、经济学院教授、国务院参事刘怡在税务总局主管的《国际税收》杂志发表文章《汽车消费税制度完善与税收分享机制设计》。文章指出，目前燃油车被纳入消费税小汽车税目，比如乘用车按气缸容量大小适用1%-40%消费税税率，同时汽油消费税税率为每升1.52元，而绝大多数新能源汽车基本不用缴纳消费税。对此，刘怡建议将新能源汽车全面纳入消费税“小汽车”税目，采取较低起步税率、分阶段逐步到位的渐进式调整，新增财政收入下划给地方政府，引导地方改善消费环境。
乘联分会秘书长崔东树认为，“油电同权”的大幕正式拉开，后续有望迎来统一路权规则、试点里程计费、建立“购置税费+财产税费+道路使用费”的现代化汽车税制体系，最终实现所有车辆“同路、同责、同税、同规则”的成熟市场格局。（北京交通广播 记者 戚天）
