# 杨昆会见德国法兰克福展览有限公司副总裁睦佑航

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/3f8yKfXErDpYxZHc3XfQCDhYFxL97zuUGTibrVEuiaPD2aj5UzcLiaYyvearkD9RvkkYu4kic8SVu9TL4loSq4XZicQ/640?wx_fmt=gif&from=appmsg)

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ApKiaLBgoS3NZU0zg9bhvHMuCkD90QNn95HcdkgBRdoibf0ZzPvyXSA0msyg0deiaGq6lrr5yG7DME5tY53M5dhXHibANblbfCJsRC4bAFDs7YM/640?wx_fmt=jpeg&from=appmsg)

3月30日，中国电力企业联合会常务副理事长杨昆在本部会见德国法兰克福展览有限公司（以下简称“法兰克福展览公司”）副总裁睦佑航一行，双方围绕国际展览合作和新能源电力设备领域协同发展等内容开展座谈交流。

杨昆对睦佑航一行到访表示热烈欢迎，对法兰克福展览公司长期以来在全球会展领域的专业影响力表示赞赏，介绍了中国电力行业发展现状，以及“双碳”目标引领下中国新能源产业的发展成就与未来愿景，强调中国正加快构建新型电力系统，新能源装机规模持续扩大，为电力设备领域国际合作提供了广阔空间。杨昆同时介绍了中电联的会员范围、职能定位与行业影响力，指出中电联作为电力行业的桥梁纽带，在服务企业发展、推动行业交流、促进国际合作等方面发挥着重要作用。

睦佑航对中电联的热情接待表示感谢，介绍了法兰克福展览公司的发展历史、全球业务布局及核心展览项目，重点推介了公司在建筑电气领域的建筑照明展、供热展、电力电子展等知名展会，以及展会在促进行业技术互通、赋能国际贸易方面的实践成果。他表示，法兰克福展览公司在国际资源整合、品牌运营、专业展会策划等方面具备显著优势，期待与中电联在电力领域开展深度合作。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ApKiaLBgoS3P6WoWRK7JGjkDiaVZMqgoCvgZ9wD6icAyPMuubkAlPzTcRFjxqeFjSrpC2kytj45RVK5FN5BBWace3L5xRV4E5pZ7bmpvkKSsrg/640?wx_fmt=jpeg&from=appmsg)

座谈期间，双方就后续合作方向进行深入探讨，重点围绕合作办展的可行性、主题方向等内容展开交流。此次座谈为中电联与法兰克福展览公司的后续合作奠定了坚实基础，为探索电力行业国际展览新模式提供了清晰路径。双方将通过推进后续合作，进一步畅通中国电力设备出口渠道，增强中国电力企业国际竞争力，为全球能源转型与电力行业可持续发展贡献力量。
