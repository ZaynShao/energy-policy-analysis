# 泽连斯基要导弹，特朗普：我们也想要

综合乌克兰《基辅独立报》等媒体报道，对于乌克兰总统泽连斯基呼吁向乌方提供更多导弹，美国总统特朗普当地时间8月6日作出最新表态。
根据白宫社交媒体账号发布的视频，有记者8月6日提到，泽连斯基发表乌克兰迫切需要远程导弹或者“爱国者”导弹系统的言论。特朗普对此回应称，“我们也想要导弹”。
▲特朗普当地时间8月6日回答记者提问 图源：白宫社交媒体账号视频截图（环球网）
据《基辅独立报》报道，特朗普还称，美国前总统拜登曾向乌克兰提供大量弹药。特朗普补充称，向乌克兰提供军事援助使美国库存大幅减少，美国正重建自己的武器库。
特朗普当地时间8月6日在社交平台上发帖称，美国“拥有大量弹药”，尤其是“某些类型弹药”。不过，他当天对记者称，美国“某些威力巨大的弹药的供应几乎无限”，但其他一些类型弹药的供应“相对紧张”。
据媒体此前报道，泽连斯基7月28日在访问美国期间表示，他与特朗普讨论了“爱国者”防空系统拦截弹的生产许可等问题。特朗普同月31日称，美国尚未同意授权乌克兰生产此类武器，“我们正在讨论”，转让这类技术“必须非常谨慎”。俄罗斯于当地时间8月4日晚至5日凌晨对乌克兰发动袭击。泽连斯基8月5日在社交平台上发帖，再次敦促伙伴提供拦截弹。
