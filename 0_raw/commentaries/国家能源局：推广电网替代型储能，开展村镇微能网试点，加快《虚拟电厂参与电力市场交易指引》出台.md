# 国家能源局：推广电网替代型储能，开展村镇微能网试点，加快《虚拟电厂参与电力市场交易指引》出台

关于开展试点示范，构建可复制推广经验模式方面，指出国家能源局会同生态环境部、农业农村部等部门联合组织开展农村能源革命试点建设，先后公布两批23个试点地区。下一步，国家能源局将继续深入推进农村能源革命，研究开展村镇微能网建设试点工作，协同推进电力与非电开发利用，提升用能清洁低碳水平和自主平衡保障能力，为建设农村新型能源体系探索解决方案。
