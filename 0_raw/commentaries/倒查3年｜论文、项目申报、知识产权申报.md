# 倒查3年｜论文、项目申报、知识产权申报

我校少数科研人员在论文撰写、项目申报、知识产权申报等科研活动中存在不规范问题，对学校学术声誉、科研诚信体系建设造成不良影响。为全面排查风险、整改隐患、肃清学术风气、压实主体责任，经学校研究，决定在全校（含各附属医院）范围内开展近3年以来所有科研活动全面自查自纠工作。
二、哲学社会科学领域倒查3年
江苏多所高校相继宣布，在全校开展哲学社会科学领域科研诚信专项排查整改工作，对近三年哲学社会科学类科研项目、成果、经费、学术活动开展逐件核实。
比如，南京医科大学康达学院科技处6月25日在通知中要求，
各学部/部门需要围绕哲学社会科学领域涉及抄袭剽窃、数据造假、重复发表、不当署名以及虚报、套取科研经费等问题开展全面自查，重点针对近三年来教职工发表的社科类论文和取得立项的社科类科研项目开展集中排查，做到应查尽查，逐件核实，形成学部/部门专项排查工作情况报告，在7月5日前提交电子版。
苏州高博职业学院科研处6月24日介绍，为严格落实《省教育厅办公室关于开展高校哲学社会科学领域科研诚信问题专项排查的提示函》（苏教办社函〔2026〕11号）工作部署，压紧压实各单位科研管理主体责任，全面排查社科领域学术不端、经费违规等风险隐患，在全校开展哲学社会科学领域科研诚信专项排查整改工作。
本次排查围绕哲学社会科学领域，重点针对近三年来（2023年1月至今）立项的各级各类项目、科研平台，以及对应科研经费、科研成果、学术活动等全流程工作。对涉及抄袭剽窃、数据造假、重复发表、不当署名以及虚报、套取科研经费等问题开展集中自查。
三、结束语
规范的风终于是吹到了“学术论文、科研项目、知识产权、科研获奖等科研板块”。
各地态度明确，对于主动报告的问题，学校将依规采取勘误、撤稿等补救措施，符合从轻处理情节的可从轻处理。
但若在自查过程中没有报告，在此次专项活动后被查出的科研失信案件，将按照《科研失信行为调查处理规则》从重处理，并上报上级行政主管部门和对外公布。
