# 吉林独立储能：调频带热市场，前7月备案75GWh+，阳光/远景/晶科/禾迈等集中布局

吉林的储能市场关注度，在2026年不断上升。1-7月间，吉林省累计备案的储能项目数量达到了146个，总规模达23.46GW/76.08GWh。这其中，独立储能项目是绝对的增量。124个，总规模23.31GW/75.35GWh，占比超99%。值得注意的是，124个独立储能项目中，包括了29个，总规模4.15GW/6GWh的混合储能项目，“锂电+飞轮” “锂电+超级电容”的组合，显然在能量型应用以外，吉林的独立储能更是瞄准了调频辅助服务等功率型应用。2026年3月，吉林能源局发布《吉林省电力市场运营规则及配套实施细则（试行4.1版本）》，该实施细则包括了8个细则文件，涵盖电力现货市场、中长期市场、调频辅助服务市场，以及注册、管理、运营、结算等各环节的具体规定。聚焦到独立储能，该实施细明确了独立储能可通过参与电能量（现货+中长期交易）、调频辅助服务获取收益，吉林独立储能的发展路径和盈利预期逐渐明确。2026年5月，吉林省发改委、国家能源局东北监管局、吉林省能源局三部门联合印发《关于明确储能价格政策有关事项的通知》。通知明确独立储能容量电价标准为330元/kW·年，按8小时折算，进一步补齐了容量电费的收入空缺，至此吉林省独立储能的收益模式确定为“电能量（现货+中长期交易）+调频辅助服务+容量补偿（市场）”，市场对吉林独立储能的关注度也由此进一步提升。2026年1月，东北地区首个电网侧一次调频储能项目，如实智慧吉林松原宁江50MW/100MWh独立储能一次调频项目投运。市场一线人士表示，该项目目前在调频领域取得了很好的应用效果，收益颇丰。作为该项目的实施方，北京如实智慧电力科技有限公司，显然也从第一个项目中获得了发展的信心，7月底，该公司的梅河口如实新盛新能源有限公司50MW/100MWh调频储能电站项目开工，继续聚焦调频，致力打造一座技术领先、安全可靠的现代化调频储能电站。招投标市场同样活跃。目前吉林四平市梨树海邦200MW超级电容锂电混合储能独立储能项目、吉林四平市梨树海邦200MW超级电容锂电混合储能独立储能项目、吉林白城市镇赉杏花100MW/130MWh调频储能电站、吉林白城市镇赉杏花100MW/130MWh调频储能电站、吉林省通榆县傅家100MW飞轮+电化学混合储能项目等多个调频项目均处于招投标过程中。预计未来数月，吉林将迎来储能项目建设和投运的高峰期。2026年上半年，吉林省的电力市场及储能相关政策出台频繁：3月，吉林能源局印发《吉林省电力市场运营规则及配套实施细则（试行4.1版本）》。
4月，吉林省能源局印发《吉林省新型储能高质量发展规划（2024-2030年）》。
5月，吉林省发改委、国家能源局东北监管局、吉林省能源局三部门联合印发《关于明确储能价格政策有关事项的通知》。
以上政策在为吉林省独立储能构建起“电能量（现货+中长期交易）+调频辅助服务+容量补偿（市场）”的收益模式的同时，也制定了清晰地发展目标和应用方向。其中，《吉林省电力市场运营规则及配套实施细则（试行4.1版本）》《关于明确储能价格政策有关事项的通知》确定了吉林独立储能的盈利模式，具体如下。而《吉林省新型储能高质量发展规划（2024-2030年）》则提出了吉林省的储能发展目标：到2027年，新型储能规模不低于1GW，新型储能年等效充放电循环达到300次。到2030年，新型储能规模不低于3GW。具体到独立储能，该文件也明确了重点的发展区域以及应用形式：
在新能源富集地区重点布局调节型储能，如吉林西部松辽清洁能源基地、送出断面；
在负荷中心地区优先布局保供型储能，如吉林中部负荷密集接入、电力供需形势紧张、电力需求波动大、输电走廊和站址资源紧张的地区布局新型储能；
在网架薄弱地区试点布局保障型储能，如吉林东部电网边缘和末端布局新型储能，优化电网结构，增强电网的韧性与可靠性，保障偏远地区的电力供应。
从顶层规划指导，到落地市场规则，吉林省的组合拳收到了明显的效果，2026年上半年，该地区的储能开发热度持续高涨。市场端的反应最为明显，据「储能与电力市场」统计，2026年1-7月，吉林省累计备案储能项目146个，总规模达到了23.46GW/76.08GWh。这其中，大量的项目正在进行可研等前期工作，预期后续月份吉林储能市场将迎来一波招投标、开工建设的高峰。1-7月吉林省的项目备案详情如下。
备案124个项目，规模23.31GW/75.35GWh，其中单体规模≥600MWh的项目共60个，合计规模14.4GW/60.47GWh，占备案总规模的79.48%（GWh）。
备案18个项目，规模0.14GW/0.34GWh，项目类型涵盖光储一体化、光充储一体化等多种应用场景。
除此之外，还备案了3个可再生能源储能项目、1个火储联合调频项目。
从月度趋势看，备案数量从1月的10个攀升至5月的33个峰值，此后虽有回落但仍在高位运行。3—6月成为储能备案规模集中释放期，单月规模均突破10GWh。其中5月达到阶段性高峰，备案33个项目，规模5.29GW/18.7GWh，是统计期内备案数量与规模最高月份。
技术路线方面，瞄准调频辅助服务，混合储能项目表现亮眼。1-7月共有29个混合储能项目备案，合计规模4.15GW/6GWh。这些项目多采用“锂电+飞轮”“锂电+超级电容”的技术组合方式。值得一提的是，吉林四平新开区200MW/645MWh项目备案，打破了普遍以锂电池为基础的组合模式。该项目采用“钠离子电池+飞轮”组合方案，为混合储能的多元化发展提供了更多参考样本。
此外，压缩空气储能项目备案3个，合计规模1.05GW/7GWh。分别为：
- 靖宇县佑白350MW/2800MWh空气储能建设项目 
- 延边州赛延储能科技有限公司350MW/2100MWh空气储能电站建设项目 
- 吉林市350MW/2100MWh空气储能电站建设项目 
从项目业主看，华能、华电、大唐、国家电投、中广核等央企，重点在白城、长春、松原等区域集中布局，累计备案25个储能项目，规模达2.59GW/7.83GWh。与此同时，阳光电源、远景、晶科、禾迈股份、易事特、中天科技、正泰电器、飞毛腿等民营企业均有项目完成备案。
地市分布方面，白城市以备案5.62GW/17.7GWh的规模居首位，长春市以备案5.23GW/17.35GWh的规模位居第二，松原市以备案4.08GW/13.38GWh的规模位居第三。通化市、四平市备案项目规模较小，规模未超过2GWh。
项目数量方面，白城市、长春市均备案35个储能项目，并列第一。松原市次之，备案了23个项目。通化市、白山市均仅有6个备案项目，数量偏少。
投资规模方面，松原市投资规模最大，达到了251.3亿元；其次是白城市，240.72亿元。四平市投资规模相对较小，投资金额未超30亿元。
