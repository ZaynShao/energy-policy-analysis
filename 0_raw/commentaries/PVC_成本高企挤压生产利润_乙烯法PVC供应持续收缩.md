# PVC | 成本高企挤压生产利润 乙烯法PVC供应持续收缩

背景：本周国内PVC乙烯法生产企业产能利用率在63.12%环比减少4.08%，同比减少8.97%。高企的原油及乙烯成本下，企业亏损压力增加，叠加全球PVC需求疲软与区域电石法市场竞争，预计未来三周企业负荷延续下降趋势。

**区域局势影响，能源高企叠加供应紧张推升原料成本**

受中东局势影响，3月份国内乙烯市场看涨情绪浓厚，然下游对过快过高的涨势接受能力有限，4月国内乙烯市场延续弱势运行，随着国内供应整体充裕，议价重心逐步向下游转移，亚洲区域裂解装置开工率维持低位，中国以外其他国家及地区乙烯资源相对短缺，因此价格表现相对偏强。

3月份亚洲乙烯市场对于进口乙烯资源的供应紧张局势预判远超人民币市场，由于原油及石脑油价格上涨过快，市场对于北亚后续裂解装置运行稳定性的担忧增加，短期内价格急速拉涨，单日涨幅最高达6%，进入4月份亚洲乙烯价格窄幅下行，然价格基数依旧偏高，主要支撑来自亚洲石脑油裂解装置整体开工率偏低，以及韩国、中国台湾以及东南亚等地持续释放乙烯买盘意向，而中国则由于其国内价格偏低，成为亚洲市场的价格洼地，从亚洲最大的进口国角色转化为出口国，货源持续出口至亚洲其他国家及地区。

进入3月以来，国内电石法与乙烯法市场价差快速拉大，最高价差幅度超过1800元/吨，而常规乙电价差在150-300元/吨范围，从图3可见，乙电价差在3-4月长期在800-1700元/吨范围，受急速及高位的乙烯法原料成本压力影响，下游难以有效传导，反而因成本压力过大下游企业转为减产或减少乙烯法原料用量转用电石法原料替代，导致国内众多五型、七型、三型原料在软管、板片材、包装、新型建材等领域转用电石法降低制品成本

截止16日，国内PVC乙烯法生产企业产能利用率在63.12%环比前一周减少4.08%，同比去年同期减少8.97%。在高企的原油及乙烯成本下，如图4国内乙烯法PVC生产企业亏损压力增加，叠加全球PVC需求疲软与区域电石法市场竞争，我们看到乙烯法PVC生产企业产能利用率延续下降趋势。

**区域高成本与需求竞争下 乙烯法供应料将持续减少**  

地缘冲突的缓和仍存在较大不确定性，尤其原油高价的波动及乙烯成本与价格能否回归正常周期仍是不确定因素，远期乙烯价格仍将经历一个“先抗跌（消化前期供应缺口带来的成本）、后回调（供应恢复）”的过程，如此看对于PVC区域供应修复需要较长周期时间，由此，乙烯的供应紧张态势及乙烯价格高企仍难以避免，势必加剧乙烯法PVC生产企业亏损压力，生产企业将面临亏损加剧风险、减产减亏困局、高成本低售价等局面，国外PVC生产企业则多选择减产保价策略，而国内PVC生产企业选择停产减亏、减产减亏、减产保价等不同选择方式。

4月中下旬，国内乙烯法生产企业临时停车、减产仍将加速，叠加企业检修计划，未来三周国内乙烯法PVC产能利用率预计将延续下降趋势，预计下周产能利用率将降至58%附近，远期最低或低至50%以内。
