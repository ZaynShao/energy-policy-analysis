# 【季度展望·甲苯】一季度涨势强劲 二季度或先扬后抑

【导语**】**一季度，受地缘扰动及供需偏强提振，山东甲苯价格一度上涨至11000元/吨，创下近十年来高位水平。宏观因素主导是此阶段价格走势的核心驱动因素，另外供需格局偏强，叠加相关产品上涨带动，亦给予甲苯市场一定助力。展望二季度，行业进入传统检修季，部分装置计划检修及降负荷，供应端仍有支撑。需求端来看，油品端需求有望出现阶段性提升预期。但是因地缘局势仍不稳定，市场风险犹存，预计二季度市场或呈现先扬后抑走势。

**2026****年一季度国内甲苯市场呈现震荡上涨的走势。截止到3月31日，江苏甲苯一季度均价为6143元/吨，环比上涨17.52%，同比下跌3.59%，季度内各月均价在历史五年当中由中下逐步提升到中上水平。**一季度，国内虽有部分新增甲苯装置投产，但因新增产能规模有限，对整体市场供应影响较弱。与此同时，地缘政治局势持续扰动，导致原料供应趋紧，叠加国内部分装置进入检修或降负运行阶段，市场整体供应端呈现收窄态势，对国内甲苯市场形成一定支撑。需求方面，一季度恰逢元旦、春节传统假期，受季节性因素带动，油品领域需求阶段性回暖；叠加纯苯价格上行，推动甲苯歧化装置利润空间扩大，歧化需求亦出现阶段性提升。在供需基本面偏强的支撑下，叠加地缘因素带来的成本端走强，一季度国内甲苯市场整体震荡上行，部分区域价格一度冲高至近十年高位水平。

**总供应环比下降2.19%，对市场支撑力度逐步增强**

一季度，国内甲苯市场总供应量环比下降2.19%，供应端收紧对市场支撑逐步增强。供应缩减主要受两方面因素驱动：一是装置检修集中，3月地缘局势影响下原料供应偏紧，部分企业检修计划提前，当月共有5家企业装置陆续检修，计划内与计划外停车并存。二是原料紧张导致部分企业开工负荷下滑，华北、华南地区降负荷尤为明显。多重因素作用下，一季度甲苯行业整体开工率降至77%左右，创下2025年二季度以来新低。供应持续收缩使得局部市场货源偏紧，有效支撑甲苯价格上行，成为一季度市场上涨的重要推动力。

![image](https://mmecoa.qpic.cn/sz_mmecoa_png/9w7iaKkib7mX2y0xnwT9ibkluMFpEc6fzjh0F8urSZTdAO7sreMxscFt3xFvZRfTiabcXlCphFSoetEI9EicXck4ta0yXgeRmPy7s9Mhx1O75B0w/640?wx_fmt=png&from=appmsg)

**化工端需求逐步提升，给予市场有力支撑**

一季度国内汽油需求整体以阶段性波动为主。1月受春节传统消费旺季带动，汽油需求阶段性回升；2 月节后复工节奏偏缓，油品需求随之转淡。3月地缘局势推升原油价格，带动汽油价格上涨，油品端需求呈现阶段性回暖，山东地炼汽油船运新增订单回升至40万吨以上，间接为甲苯市场提供了阶段性需求支撑。与此同时，纯苯价格持续走高，使得甲苯歧化装置利润大幅改善。一季度甲苯歧化利润升至758元/吨，环比增长122.94%，同比宽幅增长4637.50%。在高利润驱动下，企业歧化装置开工积极性提升，甲苯化工需求稳步增加，进一步为甲苯市场行情上涨提供支撑。

**二季度，国内甲苯行业迎来集中检修期，部分企业装置检修及降负运行将进一步带动供应端收紧，对甲苯市场形成较强支撑。需求方面，油品需求有望逐步回暖，化工端刚需仍存，对甲苯价格形成一定利好。不过当前地缘局势仍存在较多不确定性，市场情绪及原料波动风险仍不容忽视，甲苯行情或将在多空博弈下呈现先扬后抑走势。**

**供应端存缩减预期，给予市场有力支撑**

二季度国内甲苯市场步入传统集中检修季，泰州石化、金陵石化、扬子石化、中金石化等多家企业均有装置检修计划。叠加部分原计划三季度检修的企业存在提前至二季度执行的预期，行业检修规模进一步扩大，届时检修产能或在400万吨左右。同时，部分企业仍有降低开工负荷的可能，供应端继续收缩。受集中检修与降负预期共同影响，预计二季度国内甲苯行业整体开工负荷或降至70%左右，市场供应端收紧趋势显著，将对甲苯市场形成持续支撑。

**整体需求端存提升预期，给予市场一定助力**

进入二季度，随着清明、五一等小长假相继到来，国内出行及物流活动逐步回暖，油品市场将迎来季节性复苏，带动终端需求有望迎来阶段性回升。当前甲苯与纯苯价差仍保持千元左右价差，芳烃歧化装置需求支撑延续，叠加仍有部分外需，甲苯整体需求表现稳健。不过市场仍面临较多不确定性，国际地缘政治冲突持续扰动原油供应预期，油价波动风险加剧，或将通过成本端传导至芳烃及油品市场，对整体行情形成阶段性影响。后续需密切跟踪原油走势、装置开工变化及内外贸需求恢复节奏，警惕价格大幅波动带来的经营风险。

**油价或高位波动，成本驱动或先强后弱**

二季度原油价格大概率维持宽幅震荡格局，价格中枢存在高位回落可能，具体拐点仍需密切跟踪地缘冲突进展及缓和态势。结合情景分析、预测模型并经专家修正后判断，两油主流运行区间或在84-110美元/桶。成本端驱动预计先强后弱，难以对甲苯市场形成持续有力支撑。

综合来看，二季度国内甲苯市场供需偏强给予市场一定支撑，但仍受多重不确定性因素影响。供应方面，供应收紧趋势明显，为市场提供有力支撑。需求端方面，小长假带动出行及物流回暖，助力油品市场季节性复苏，叠加甲苯与纯苯价差支撑歧化装置需求，且外需尚存，整体需求有望稳步提升，给予市场一定助力。但是成本端来看，二季度原油价格大概率宽幅震荡，价格中枢存高位回落可能，成本驱动或呈先强后弱态势，难以持续支撑甲苯市场。整体来看，二季度甲苯市场供需虽有一定支撑，但需警惕地缘冲突引发的油价波动及需求不及预期等风险带来的价格下调预期，密切跟踪相关影响因素变化。综合分析，未来三个月国内甲苯市场或呈现先强后弱走势为主。预计4-6月份国内甲苯市场月度均价分别为7700元/吨、7000元/吨、6700元/吨。
