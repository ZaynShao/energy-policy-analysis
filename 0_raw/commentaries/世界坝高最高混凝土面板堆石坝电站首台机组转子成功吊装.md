# 世界坝高最高混凝土面板堆石坝电站首台机组转子成功吊装

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/3f8yKfXErDpYxZHc3XfQCDhYFxL97zuUGTibrVEuiaPD2aj5UzcLiaYyvearkD9RvkkYu4kic8SVu9TL4loSq4XZicQ/640?wx_fmt=gif&from=appmsg)

4月11日，世界坝高最高混凝土面板堆石坝电站——华电金上拉哇水电站首台（4号）机组转子顺利完成吊装，标志着机组进入总装冲刺阶段，为确保按期投产发电奠定坚实基础。

拉哇水电站位于四川省巴塘县与西藏自治区芒康县交界的金沙江干流，是国家“十五五”规划重点建设的金沙江上游水风光一体化基地重要组成部分，总装机容量200万千瓦。本次吊装的转子直径13.43米，高3.10米，总重量约1007吨，是拉哇水电站机组重量最大的部件。

![image](https://mmbiz.qpic.cn/mmbiz_jpg/2K941YJfPg89zzyc6VM7sfgEffC2uJmHibMBmrw65eSuG7cyQv2dMtYxQrosfwlgy09RIjttNxJMoB1SjwpibFnYgRJwwtLpTicZ5FzK7FiaLIk/640?wx_fmt=jpeg&from=appmsg)

为确保首台（4号）机组转子顺利吊装，华电金上公司巴塘分公司（拉哇分公司）精细制定“一吊一策”管理措施，有效克服现场交叉作业面多、安全管控难度大等挑战，高质量完成支架组焊、立筋加工、磁轭叠装及磁极挂装等工序，转子圆柱度为0.3毫米，远高于国标要求的0.5毫米优良标准，一次通过整体耐压试验，为打造精品机组打下坚实基础。

![image](https://mmbiz.qpic.cn/mmbiz_jpg/2K941YJfPg9GNynibrSqibs6sHKcJz50ZnV6qVvXicZguTn6ibpLZia6eGic4m5pRoyqJRmHOU1viaEcIkk697olBmS5nsoODEtod6icGmLib09nibQpA/640?wx_fmt=jpeg&from=appmsg)

据悉，拉哇水电站计划今年11月实现导流洞下闸，年底首批机组具备投产发电条件，电站全容量投产后多年平均发电量为90亿千瓦时，每年可节约标准煤约277万吨、减少二氧化碳排放741万吨，将有效支撑国家主要流域水风光一体化先行基地建设和清洁能源外送。
