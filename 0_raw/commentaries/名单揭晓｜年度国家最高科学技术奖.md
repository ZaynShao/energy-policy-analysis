# 名单揭晓｜年度国家最高科学技术奖

2025年度国家最高科学技术奖授予中国科学院物理研究所陈立泉院士和中国电子科技集团有限公司（第十四研究所）贲德院士。
陈立泉开创了我国固态离子学研究先河，研制出我国首块锂电池，建立首条中试线，开启了我国锂电池产业化进程；突破了磷酸铁锂、钴酸锂等关键材料知识产权壁垒，坚定捍卫了我国锂电池发展权益，为我国锂电池产业全球领先作出了卓越贡献。
贲德成功研制出我国首部机载脉冲多普勒火控雷达、首部大型远程相控阵预警雷达，突破的脉冲多普勒和相控阵两项现代雷达根技术，引领我国雷达陆海空天预警探测体系发展，已装备数千部骨干雷达，铸就了我国制信息权的“火眼金睛”，为国防安全作出了卓越贡献。
从本届获奖项目可观察到三大趋势变化：
二、科学技术奖新格局
2025年度国家科技奖的揭晓，不仅是对优秀科研成果的嘉奖，更折射出我国科技评价体系的全新走向。
评奖周期拉长，竞争倍增。根据新修订的《国家科学技术奖励条例实施细则》，国家科技奖由一年一评改为每两年评审一次，三大奖每次授予总数不超过300项。折算下来，年均获奖数量从约300项压缩至约150项，申报难度和竞争激烈程度大幅提升。
制度持续完善，评审趋严。2025年6月，科技部公布第三次修订的《实施细则》，强化提名者责任、建立评审信誉管理机制、实行科研诚信审核制度。提名须聚焦“真正作出创造性贡献的科学家和一线科技人员”，行政或辅助人员不得作为候选者，同时明令禁止“打招呼”“跑找要”等干扰行为。
对于企事业单位而言，新格局下的创奖申报应提前规划：
第一，立足“四个面向”，紧扣国家战略需要与中长期科技规划，凝练在基础研究、关键核心技术攻关、发展新质生产力等方面的创造性贡献。
面向世界科技前沿、面向经济主战场、面向国家重大需求、面向人民生命健康
第二，突出成果转化实效，关注实际应用价值，科技进步奖明确要求“成果转化程度高，创造重大经济效益”，企业牵头申报更具比较优势。
第三，提前谋划提名准备。评奖周期延长至两年一次，企事业单位应尽早启动项目培育和申报摸底，通过各级科技主管部门、相关学会协会、院士提名等渠道积极对接。
第四，坚守科研诚信底线，提名者对材料真实性负全责。在评奖日益规范的当下，唯有真材实料的硬核成果方能经得起严格检验。
