# 土耳其：追捕内塔尼亚胡

土耳其司法部长阿肯·居尔莱克说，已寻求国际刑警组织对以总理内塔尼亚胡等人发布“红色通缉令”。
土耳其司法部长阿肯·居尔莱克当地时间8月21日在社交媒体发文说，作为对以色列武装干预向加沙地带运送人道主义援助物资船队的司法程序的一部分，土已寻求国际刑警组织对以总理内塔尼亚胡等人发布“红色通缉令”。
▲内塔尼亚胡（资料图）新华社发
居尔莱克在帖文中说，以涉嫌“种族灭绝”罪对内塔尼亚胡等人的逮捕令已于7月由土耳其法院发出。之后，土耳其司法部要求内政部寻求发布针对内塔尼亚胡等人的“红色通缉令”，以便对其进行国际追捕，目前相关材料已经转交外交部。
发布上述逮捕令的土耳其伊斯坦布尔第11重罪法院，目前正审理国际人道主义船队遭拦截案件。根据土方指控，以色列方面涉嫌在国际水域武装干预试图向加沙地带运送人道主义援助的平民，并拘押相关活动人士。
由数十艘船只和来自40多个国家的众多志愿者组成的“全球坚韧船队”，于去年9月启航，旨在突破以色列对加沙地带的海上封锁，向当地运送包括食品和医疗物资在内的人道主义援助。然而，以色列军方在加沙附近公海拦截全部船只，扣押这些活动人士并分批驱逐出境。一些活动人士说，他们在拘禁期间遭到以方虐待和侮辱。
“红色通缉令”由国际刑警组织应成员国请求发布，必须符合国际刑警组织的章程和规则，它可以同时向所有成员国警方通报国际通缉逃犯的相关信息，但不具备强制力。每个成员国自行决定“红色通缉令”的法律效力以及本国执法人员的逮捕权。土耳其和以色列均为该组织成员国。
