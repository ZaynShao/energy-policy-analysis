# 市市场监管局举办树立和践行正确政绩观学习教育第三期读书班

浏览次数：706信息来源：机关党委发布时间：2026-06-30 15:21

_字号：_大中小下载我要纠错打印收藏

6月28日下午至6月29日，市市场监管局举办树立和践行正确政绩观学习教育第三期读书班暨党组理论学习中心组（扩大）学习会议。

读书班期间，通过个人自学和集中学习相结合方式，原原本本研读习近平总书记关于树立和践行正确政绩观的重要论述，集中学习了市级层面工作专班有关文件、政绩观偏差典型问题的通报，传达学习了市委树立和践行正确政绩观学习教育读书班暨市委理论学习中心组学习会议精神。采取“重点发言+随机点名”方式，围绕“为民造福是最大政绩”“坚持高质量发展要成为领导干部政绩观的重要内容”“坚持功成不必在我、功成必定有我，以实干出政绩”主题开展交流研讨，8名局领导班子成员、副处级以上领导干部和随机选取的5名科室、二级机构负责人作交流发言。

会议强调，一要站稳为民立场，厚植民生导向。坚持以群众满意为评判标准，紧盯食品安全、特种设备、消费维权等民生领域，深化放管服改革助企纾困，力戒形式主义，做实民生实绩。二要聚焦主责主业，服务高质量发展。立足全市绿色振兴发展大局，抓好质量强市、知识产权、公平竞争、包容审慎监管，以高效监管赋能产业升级、优化营商环境。三要强化实干担当，务求务实成效。胸怀长远格局、主动履职尽责，破除躺平畏难思想，守牢安全底线、攻坚改革难题，多做打基础利长远工作。四要严守纪律规矩，永葆清廉本色。紧盯廉政风险，持续锤炼党性、改进作风，锻造忠诚干净担当的市场监管干部队伍。
