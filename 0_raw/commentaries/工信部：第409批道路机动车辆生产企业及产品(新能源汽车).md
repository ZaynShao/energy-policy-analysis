# 工信部：第409批道路机动车辆生产企业及产品(新能源汽车)

8月13日，工业和信息化部正式公告《道路机动车辆生产企业及产品（第409批）》，依据同一型号判定原则归纳后，通过技术审查的新能源汽车产品共计478个。
总体情况：共计有217家企业、210个品牌、478个产品型号进入新产品公告目录。其中汽车生产企业有81家259个产品型号列入，民用改装生产企业有136家219个产品型号列入。
燃料种类：本批次纯电动产品共计415个（包含：乘用车31个，客车31个，客车底盘3个，专用车315个，专用车底盘35个）；插电式混合动力产品56个（包含：乘用车20个，客车1个，专用车29个，专用车底盘6个）；燃料电池产品6个（包含：客车1个，专用车3个，专用车底盘2个）；甲醇产品1个（包含：客车1个）。
产品类型：专用车共计390个型号（包含底盘43个）；客车共计37个型号（包含底盘3个）；乘用车51个。
