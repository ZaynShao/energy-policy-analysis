# 库博能源冲刺港股：营收7亿，净利5381万，九成收入来自海外

营业收入分别为4.52亿元、4.94亿元和7.03亿元；
同期毛利分别为1.03亿元、1.32亿元和1.81亿元；
毛利率分别为22.9%、26.7%和25.7%；
海外收入分别占公司总收入的81.3%、53.4%及87.9%，其中欧洲是公司的最主要市场；
来自五大客户的总收入分别占总收入的70.9%、55.2%及50.6%。同期，最大客户所产生的收入分别占公司收入的46.4%、15.6%及22.8%。
