# COP29| “发展新质生产力：探索中国企业应对气候变化新路径”主题边会在COP29“中国角”成功举办

![image](https://mmbiz.qpic.cn/mmbiz_png/hCTyPplPRu0iaDeiaFadwgeNBaLFibuhCiczROI8yNwMgpgPy6DPuEVlY44ZiaRt64dmyzr54MkJLaQc8nVVIPlnSnQ/640?wx_fmt=png&from=appmsg)

  

  

**11月20日，由中国企业联合会、中国企业管理科学基金会主办，落基山研究所、中国可持续发展经济导刊协办的“发展新质生产力：探索中国企业应对气候变化新路径”主题边会在《联合国气候变化框架公约》第二十九次缔约方大会（COP29）“中国角”成功举办。**来自国际机构、智库、跨国公司、中国企业以及专业媒体等的代表出席，共同探讨中国企业在发展新质生产力的过程中应对气候变化的举措和路径。

  

  

  

中国企业联合会常务副会长朱宏任做主旨发言。发言指出，中国企业是新质生产力的实践主体，也是应对气候变化的积极贡献者。通过推动中国企业在产业链供应链中充分发挥示范引领作用，可引导更多的企业积极应对气候变化，推动中国企业的可持续发展。下一步，推动企业可持续发展的标准化工作、企业绿色发展经验的总结与推广，以及进一步开展国际交流与合作是重点工作方向。

  

**在主旨演讲环节，落基山研究所常务董事Thomas Koch Blank分享了在供给、需求、政策、金融等多相关方参与的全生态系统解决方案下全球能源转型的路径和未来展望，并以钢铁行业为例，阐述了行业企业、政策制定者、金融机构和上下游产业链利益相关方如何相互配合的洞察。**多方参与的全生态系统方案可以有效支持企业弥合转型成本差距，实现向近零碳生产的平稳转型。落基山研究所同期发布了《加速首批突破性近零碳钢铁投资与部署——中国篇》双语报告和《迈向共创共享的零碳能源未来一全球农村能源合作社的经验与探索》英文执行摘要。

《迈向共创共享的零碳能源未来一全球农村能源合作社的经验与探索》英文执行摘要

  

**成果发布环节，中国企业管理科学基金会理事长缪荣代表中国企业联合会、中国企业管理科学基金会，和落基山研究所联合编委会，发布《2024中国企业绿色低碳发展优秀实践精选案例(中英文版)》（以下简称“《案例》” ）。**在《案例》的征集评选中，共征集到涵盖电力、钢铁、煤炭、冶金、材料、工程机械、石化、化工、交通运输、信息通讯、金融等碳达峰碳中和重点领域和行业的案例432项，反映了中国各类型企业在碳排放控制和节能降耗增效、绿色制造、新能源开发建设、绿色低碳技术的创新与推广、资源循环利用、双碳达标服务体系建设等方面的最新成功实践，展示了中国企业探索绿色低碳转型路径、实现高质量可持续发展过程中取得的阶段性成果。《案例》在技术的先进性、创新性和运行管理的有效性等方面为广大企业提供了有效参照，助力中国企业进一步实现绿色低碳发展。

  

国际质量科学院院士、原国家质量监督检验检疫总局总工程师刘卓慧作为代表发布了中国首个《企业碳达峰碳中和管理通用要求及评价指南》（以下简称“《指南》” ），并介绍了依据《指南》对部分企业进行评价的情况。先进管理企业在双碳管理中取得的突出成效从数据上予以呈现 。**落基山研究所是《指南》的主要起草单位之一。**《指南》从企业碳达峰碳中和总体目标的设定、实现目标的方法和行动方案、指标体系的建立和实施路径、重点任务和保障措施、组织领导、能力建设、评价与改进等多要素多维度，提出了较为系统、科学的管理和评价方法标准，既有中国特色又符合国际惯例，为企业开展“双碳”管理工作提供了实施指南和评价依据。

  

联合国国际劳工组织公正转型行动项目经济学家马雷克·豪斯多夫、联合国国际劳工组织理事会正理事、国际雇主组织亚洲区域副主席桑娅·贾娜尼(Sonya Janahi)围绕为企业创造有利环境、发展绿色产业，中国企业的成功经验以及国际合作的重要性发表了主旨演讲。新疆华源控股集团有限公司董事长李俊、帝斯曼—芬美意Bovaer®高级副总裁马克·范·纽兰德(Mark van Nieuwland)、河钢集团战略研究院高级研究员郑仲、国际雇主组织气候变化和绿色经济顾问罗伯特·马宁克维克(Robert Marinkovic)和中国可持续发展经济导刊主编于志宏在实践分享环节做了分享。

  

**落基山研究所常务董事兼北京代表处首席代表李婷表示：**“企业在全球应对气候变化中发挥着重要作用，是能源转型进程中关键的实践者和推动者。在此过程中，充分发挥企业的领导力，并建立完整的支持体系和多方协同机制尤为重要。未来，落基山研究所将继续与合作伙伴一道，支持企业的绿色低碳转型，并通过持续推动政策、金融、市场等多方力量的协同提供全生态系统支持，为创造清洁、繁荣的零碳共享未来赋能。”
