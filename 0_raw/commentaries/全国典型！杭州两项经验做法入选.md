# 全国典型！杭州两项经验做法入选

为贯彻落实党中央、国务院有关部署要求，持续推进城市儿童友好空间建设，住房城乡建设部、国家发展改革委、国务院妇女儿童工作委员会办公室总结了各地在制度机制创新、儿童友好街区和社区建设、公共服务设施适儿化改造等方面的典型经验做法，形成由住房城乡建设部等三部门印发的《城市儿童友好空间建设可复制经验清单（第三批）》，杭州两项经验做法入选！
道路空间适儿化改造
杭州市全域推进儿童友好通学路建设，打造 174 条舒心通学路。各区政府相关部门、街道、学校等多方主体对设计方案进行联合审查，围绕平整度、顺畅度、安全度、趣味度等方面对道路进行提升改造，铺设新道板、增设蓝绿标线、提升路面透水性，因校施策进行差异化建设。上城区坚持片区统筹、连片实施，多校共建通学路网；西湖区蒋村街道立足湿地生态文化，结合街道全域完整社区建设工作打造充满人文意趣的通学路。
公园绿地适儿化改造
杭州市临平区立足 “一米高度” 对临平公园及周边地区实施适儿化改造。盘活公园周边低效用地，建设临平山图书馆，设置儿童阅读区、非遗体验区、音乐厅等功能空间；对儿童游乐园、动物园实施升级改造，增设无动力游乐设施，引进萌宠小动物，完善公共服务配套，丰富儿童体验；增补绿道，串联动物园、游乐园、烈士纪念碑、图书馆等节点，构建连续贯通、功能复合的亲子游憩廊道。
此次两项经验做法入选国家可复制经验清单，是对杭州儿童友好空间建设工作的充分肯定。下一步，杭州将深入贯彻落实《关于在全社会推进儿童友好建设的意见》，坚守 “一米高度” 视角，充分转化运用本次入选的经验成果，持续深化通学路、公园、街区、场馆等各类儿童友好空间适儿化改造，迭代健全制度机制，不断打造群众可感可及的儿童友好微场景、微服务，放大试点示范辐射效应，产出更多可复制、可推广的杭州实践，奋力擦亮国家儿童友好城市建设的杭州金名片。
