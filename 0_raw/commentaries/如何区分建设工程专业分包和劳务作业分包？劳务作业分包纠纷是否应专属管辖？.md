# 如何区分建设工程专业分包和劳务作业分包？劳务作业分包纠纷是否应专属管辖？

01
问题解析
在建设工程领域，承包人将劳务作业内容进行分包，是具体施工工作开展过程中的常见情形。但在实际操作中，劳务作业分包与工程专业分包这两个概念常常被混淆，导致在建设工程项目管理、合同签订以及责任划分等方面出现诸多问题。另外，目前没有法律法规明确规定建设工程劳务作业分包合同是否适用建设工程施工合同纠纷案件的不动产专属管辖规定，导致实践中不同法院存在不同认识。本文就上述问题具体分析和讨论如下：
1. 何为劳务作业分包和建设工程专业分包？
根据《房屋建筑和市政基础设施工程施工分包管理办法》的相关规定，劳务作业分包，是指建设工程施工总承包人或专业承包人将其承包工程的劳务作业发包给劳务承包人完成的活动。建设工程专业分包，是指建设工程施工总承包人将其所承包工程中的专业工程发包给具有相应资质的其他建筑业企业完成的活动。两者之间虽然均属于建设工程施工过程中不同内容的分包，但还是存在较大区别的。
2. 建设工程专业分包和劳务作业分包的具体区别
第一，合同标的不同。建设工程专业分包的种类包括土石方工程、消防设施工程、建筑防水工程等。劳务作业分包的种类包括木工、砌筑、抹灰、钢筋、混凝土、脚手架、焊接、架线作业等。建设工程专业分包的标的是建设工程中非主体部分的工程，而劳务作业分包合同的标的主要是劳务，一般与工程成果无关。第二，施工内容不同。建设工程专业分包中，承包人以自身的设备、材料、技术等独立完成工程内容。劳务作业分包中，承包人提供的是劳动力，实际由分包人提供技术和管理，两者结合才能完成相应工程内容。第三，责任承担不同。建设工程专业分包中的承包人就完成的工作成果与分包人向发包人承担建设工程质量的连带责任。劳务作业分包中的承包人仅对施工内容承担合格责任。第四，程序要件不同。建设工程专业分包必须按照约定或经发包人同意。而劳务作业分包限于劳务分包合同双方当事人，无须经发包人或总包人的同意。
3. 劳务作业分包合同纠纷是否适用不动产专属管辖规定，实践中存在两种不同观点
一种观点认为，劳务作业分包的承包方式是提供劳务及小型机具和辅料。从整体上考虑，木工、砌筑、抹灰等工作都在施工过程中投入到建设工程本身，实际影响建设工程的价值和质量，符合不动产纠纷专属管辖的立法目的，应当适用专属管辖。另一种观点认为，劳务作业分包本身并不涉及建设工程的工程造价鉴定、质量鉴定、建设工程优先受偿、执行拍卖等事宜，不符合建设工程施工合同的特征，不宜按照不动产纠纷确定管辖，应当按照一般合同纠纷确定管辖。
4. 结论与建议
我们认为，劳务作业分包合同纠纷应当适用建设工程施工合同纠纷案件的不动产专属管辖规定，主要理由如下：第一，有明确的法律依据。《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第五条明确规定了劳务分包合同的效力问题，且《最高人民法院新建设工程施工合同司法解释（一）理解与适用》甚至直接将劳务作业分包合同的性质定义为建设工程施工合同关系，因此应当按照建设工程施工合同纠纷，适用不动产纠纷确定管辖。
第二，劳务作业分包中相关款项的计量、计价实际与建设工程本身紧密相关，工程依附属性较强，且在案件审理过程中，劳务作业分包纠纷启动建设工程造价鉴定的概率与其他建设工程施工合同纠纷案件基本相同，因此不宜将劳务作业分包合同从建设工程合同类型中予以排除，应当适用建设工程施工合同纠纷案件的不动产专属管辖规定。
02
相关案例
案例1：石嘴山市甲建筑有限公司、西安乙劳务有限公司建设工程分包合同纠纷再审民事判决书（案号：（2018）最高法民再333号）
一审法院宁夏回族自治区石嘴山市中级人民法院认为：在合同履行过程中，甲公司仅提供主材，案涉工程均由乙公司自行筹备建筑器材，组织施工人员按合同约定的工期进行施工，工程进度和施工人员受乙公司的掌控、支配和管理。据此，乙公司与甲公司所签订的《主体结构劳务合同》，名为劳务合同，实为专业分包合同。从事专业工程承包应当具有相应的资质，乙公司作为劳务公司不具有相应的施工资质，其与甲公司所签订的《主体结构劳务合同》违反法律规定，为无效合同。
二审法院宁夏回族自治区高级人民法院认为：分包分为专业工程分包和劳务分包，专业工程分包是指施工总承包企业将其所承包工程中的专业工程发包给具有相应资质的其他建筑企业即专业分包工程承包人完成的活动。劳务分包是指施工总承包企业或者专业承包企业即劳务作业发包人将其承包工程中的劳务作业发包给具有相应资质的劳务输出承包企业即劳务作业承包人完成的活动。专业工程分包指向的标的是分部分项的工程，计取的是工程款，其表现形式主要体现为包工包料；劳务分包合同指向的是工程施工的劳务，计取的是人工费，表现形式为包工不包料，俗称“清包工”。依据乙公司提交的《建筑企业资质证书》，其具备建筑行业劳务施工的资质。双方订立的《主体结构劳务合同》约定，甲公司将案涉工程劳务发包给乙公司施工，乙公司承包形式为包人工及少量的周转设施料等，故双方所订立的合同属建设工程劳务分包合同，合同内容不违反法律禁止性规定，该合同是双方当事人真实意思表示，应认定为合法有效。一审将案涉合同认定为专业分包合同，并以乙公司不具备相应资质承揽工程违反法律禁止性规定为由认定合同无效不当。
再审法院最高人民法院认为：甲公司与乙公司签订《主体结构劳务合同》，涉案工程的主材由甲公司提供，乙公司实行包人工、周转设施料、辅料、机具方式，系双方当事人真实意思表示，合同不违反法律禁止性规定，合法有效。
案例2：四川甲建筑工程有限公司、卿某等建设工程分包合同纠纷民事指定管辖管辖裁定书（案号：（2023）最高法民辖132号）
最高人民法院认为：本案管辖争议的焦点问题是如何确定诉争法律关系的性质。区分建设工程分包合同纠纷和劳务合同纠纷,应当根据当事人之间诉争的法律关系,从当事人之间有无控制、支配和从属关系,工作场所、时间是否限定,以及工作内容侧重劳务提供还是工作成果交付等因素进行判断。本案中,当事人约定的工作内容为“A工程的施工图、工程量清单、会审纪要、设计变更、技术核定单等所涵盖的所有砌体砌筑等为完成砌体工程作业所需的工作以及甲方要求的砌体工程所涉及的工作内容”。同时,根据工程验收情况收取进度款,当事人之间相对独立,不存在劳务关系中的工资支付、教育监督等支配与被支配、管理与被管理关系。因此,本案属于建设工程分包合同纠纷,应当按照不动产纠纷确定管辖。因工程项目所在地在云南省楚雄市人民法院,云南省楚雄市人民法院对本案具有管辖权,裁定将本案移送四川省简阳市人民法院处理不当,本院予以纠正。
案例3：陕西甲建筑劳务有限公司与乙建设集团有限公司、乙建设集团有限公司青海分公司管辖裁定书（案号：（2017）最高法民辖终43号）
二审法院最高人民法院认为：本院经审查认为,乙公司青海分公司系就A工程中的部分工程作为发包方与作为承包方的甲公司签订了《建筑工程劳务承包合同》,A工程属于建设工程,乙公司青海分公司与甲公司在《建筑工程劳务承包合同》中亦明确约定:“依照《中华人民共和国合同法》和《中华人民共和国建筑法》,结合本工程的具体情况,经双方充分协商一致签订本合同”。因此,该合同系平等主体之间就建设工程设立民事权利义务关系的协议,而非用人单位与劳动者之间确立劳动关系的协议。故乙公司主张本案纠纷应适用劳动仲裁前置程序,缺乏事实和法律依据,本院不予支持。
原裁定依照《中华人民共和国民事诉讼法》第三十三条“下列案件,由本条规定的人民法院专属管辖:(一)因不动产纠纷提起的诉讼,由不动产所在地人民法院管辖”和《最高人民法院关于适用的解释》第二十八条第一款、第二款“民事诉讼法第三十三条第一项规定的不动产纠纷是指因不动产的权利确认、分割、相邻关系等引起的物权纠纷。农村土地承包经营合同纠纷、房屋租赁合同纠纷、建设工程施工合同纠纷、政策性房屋买卖合同纠纷,按照不动产纠纷确定管辖”的规定,结合本案工程施工地位于青海省的有关事实和相关规定,认为本案应按照不动产纠纷专属管辖原则确定管辖法院,确认青海省高级人民法院对本案具有管辖权是正确的。至于甲公司是否具有建筑企业资质的问题,对于本案管辖权的确定没有影响。综上,乙公司的上诉请求缺乏事实和法律依据,本院不予支持。原裁定认定事实清楚,适用法律正确,依法应予维持。
案例4：乌鲁木齐甲劳务有限公司、乙工程有限公司劳务合同纠纷民事指定管辖管辖裁定书（案号：（2023）最高法民辖39号）
最高人民法院认为：本案系劳务合同纠纷。从本案起诉情况看,甲公司主张与乙公司存在着劳务合同争议,请求法院判令乙公司支付已结算的劳务费。尽管案涉劳务合同发生在建设工程施工过程中,但是,建设工程施工合同纠纷审理过程中,往往涉及建筑物工程造价评估、质量鉴定、留置权优先受偿、执行拍卖等,由建筑物所在地法院管辖,有利于案件审理与执行,因而按照不动产纠纷确定管辖。本案中,甲公司依据案涉劳务分包合同,起诉请求判令乙公司支付劳务费。从案涉劳务分包合同内容看,甲公司以固定单价方式分包案涉工程并以包清工形式施工,施工完成后双方已对劳务费进行了结算。可见,本案纠纷并不涉及建筑物工程造价评估、质量鉴定、留置权优先受偿、执行拍卖等,不宜按照不动产纠纷确定管辖,本案可以按照合同纠纷确定管辖。
案例5：李某、甲集团有限公司劳务合同纠纷民事指定管辖管辖裁定书（案号：（2023）最高法民辖76号）
最高人民法院认为：本案系劳务合同纠纷。一般来说,在起诉与受理阶段,人民法院应当根据当事人主张的法律关系性质确定案由,进而审查是否具有管辖权。本案中,李某主张与甲公司存在劳务合同纠纷,诉请判令甲公司支付欠付的劳务费,案涉劳务合同发生在建设工程施工过程中。对于建设工程施工合同引发的纠纷,往往涉及建筑物工程造价评估、质量鉴定、留置权优先受偿、执行拍卖等内容,由建筑物所在地法院管辖,有利于案件审理与执行,因而按照不动产纠纷确定管辖。但是,案涉合同名称为甲公司A铁路XXX标工序劳务作业合同书,主要内容是:甲公司负责供应材料,李某组织人员编入甲公司架子队管理,为甲公司提供劳务,按照劳务作业完成工序项目的工程量和劳务单价计算劳务费。可见,案涉合同并不符合建设工程施工合同的特征,不宜按照不动产纠纷确定管辖,应当按照一般合同纠纷确定管辖。
案例6：李某、大连甲建设工程有限公司等劳务合同纠纷民事指定管辖管辖裁定书（案号：（2021）最高法民辖56号）
最高人民法院认为：在民事案件起诉与受理阶段,人民法院可以根据原告诉讼请求涉及的法律关系性质,确定相应的案由。本案中,李某以与甲公司存在劳务施工合同纠纷为由,向法院提起诉讼,请求判令支付工程款。从李某起诉提供的案涉合同内容看,李某以包清工的形式承包施工,预埋安装A地块电气工程,涉及到配电箱、设备、线缆、管线、灯具、开关、插座等所有电气系统预留。同时,案涉合同约定“甲公司对工程质量、技术、进度、环境、职业健康、安全、文明施工及成本进行全面控制”,“随时检查工程进度、质量、环境、职业健康、安全及文明施工,对工程施工进行全过程控制;组织生产例会,协调安排整个工程生产;组织对工程对施工验收和工程技术资料的收集、汇总;组织安排工程移交的维修保修工作;在乙方进场一周内,对乙方进行书面对环境及职业健康、安全教育、技术及现场文明施工教育、成品保护教育”。从上述合同约定来看,甲公司对李某的工作有管理、监督、教育等职责,而建设工程通常具有资金投入量大、工程复杂、技术含量高、专业性强的特点,尤其是建设工程的质量不仅涉及发包人的利益,而且更关系到社会上不特定第三人的人身财产安全,甚至是关系到国计民生和社会稳定。因此,法律对建设工程施工合同承包人的主体资格有特殊要求,在建设工程施工合同中,发包人与承包人之间具有相对的独立性。故本案不属于建设工程施工合同纠纷,而应确定为劳务合同纠纷。大连经济技术开发区作为被告住所地的法院,对本案具有管辖权。辽宁省高级人民法院关于案涉基础法律关系为建设工程施工合同纠纷、本案应当适用不动产专属管辖的报请理由,缺乏事实和法律依据。
