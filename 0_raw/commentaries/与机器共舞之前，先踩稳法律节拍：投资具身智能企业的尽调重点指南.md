# 与机器共舞之前，先踩稳法律节拍：投资具身智能企业的尽调重点指南

2026年，具身智能的浪潮已从实验室席卷至产业前线。投资者在追逐硬件与软件算法所释放的商业潜力时，往往过于关注技术演示效果，却低估了其法律风险的复杂性与严重性。

人工智能（AI）行业的法律尽职调查，因技术新颖性、数据高度依赖及监管环境快速演变而面临独特挑战。对于具身智能这类“人工智能与硬件交叉”的领域，其技术复杂性与法律监管合规要求更为突出，对尽职调查工作的专业性与综合性提出了更高要求。因此，投资具身智能企业，已超越传统的财务、法律或技术尽调范式，必须从审查“公司”升级为解构由代码、硬件、数据、人才与全球差异化监管构成的复杂系统，该系统任一环节的合规漏洞，都可能引发系统性风险。

本文旨在提供一份务实的深度指南。我们将穿透技术光环，直指其下的核心法律与合规风险，助您构建更全面的投资风险评估框架。

**01**

**行业本质与尽调范式重构——为何传统框架已然失效？**

**1. 行业速写——我们到底在投什么？**

在深入法律风险分析之前，必须先理解我们面对的技术客体。具身智能（Embodied AI）不仅仅是“人工智能+机器人”，而是人工智能通过物理本体与环境交互实现“知行合一”的综合智能。[1]具身机器是“感知-决策-控制-执行”的闭环系统——摄像头、雷达把世界变成数据；模型理解、规划“要怎么干”；控制器把意图拆成电机/关节的指令；执行器完成动作；再把结果和日志回到系统里迭代。因而，其产业链条长且互相交叉：

**上游：**受制于地缘政治的芯片、传感器、精密传动与执行系统。

**中游：**体现核心壁垒的“脑”（多模态大模型）、“小脑”（控制算法）与“身体”（整机集成）。

**下游：**受严格场景规制的工业、医疗、家庭、公共领域。

**2. 法律风险的“叠加与放大”效应**

为了精准定位法律风险，必须将技术架构映射至法律合规领域：

例如，一旦发生数据泄露，对互联网公司可能主要意味着罚款与整改，但对具身智能企业，则可能同时触发：数据安全法合规责任、用户隐私侵权诉讼、国家安全审查、训练数据污染导致模型退化/失效、产品责任与召回等连锁效应。这种“一损俱损”的连锁反应，要求尽调必须具备系统性与前瞻性。

**3. 新尽调范式：从“静态文件审查”到“动态系统评估”**

传统科技企业的尽调侧重历史与现状，而具身智能尽调必须评估企业在动态环境下的持续合规能力与规模化交付能力。核心问题是：当监管政策变化、供应链中断、核心人员流动时，企业的“技术-法律-运营”架构能否有效应对？为了更直观地展示与传统科技企业投资尽调的差异，我们简要对比如下：

**02**

**聚焦三大核心维度：技术、人才、产品的合规能力深度评估**

- 

**维度一：知识产权与核心技术——评估壁垒的真实性与牢固度**

**（1）专利组合的质量与防御价值**

**风险点：**具身智能的专利保护必须同时覆盖软件与硬件层面，覆盖从核心算法、机械结构到系统集成形成完整链条。实践中，一些企业专利数量庞大，但其中相当部分属于外围或辅助性专利（如外观设计或非核心功能改进等），并不能形成专利壁垒。相反，涉及核心技术的“硬”专利（如独特关节设计、高动态平衡算法等）有时并未掌握在企业自身名下，或者依赖第三方授权。例如，某企业宣称“自主研发导航系统”，但经核查发现核心SLAM算法实际来自高校授权，一旦授权到期或合作关系变化，相关技术基础可能受到影响。

**尽调关键：**除核查知识产权、算法等IP的权属外，对于知识产权的核查不能仅满足于专利清单，需分析其在核心关键技术节点（如动态平衡、柔性抓取、人机交互安全）上的专利布局范围和密度。应重点核查：

 - 

**IP权属清晰度：**需明确核心算法、软件代码、硬件设计等成果究竟源于企业自主研发，还是来自创始人原单位职务成果、高校合作项目或开源技术。尤其需关注：

 * 

核心技术人员是否可能涉及前雇主的职务发明或竞业限制问题；

 * 

对于 “教授创业”型公司，创始人仍在高校任职的，应明确相关专有技术的归属及其落脚点，如技术成果仍归属于高校，后续如何实现成果转化及商业化安排；

 * 

与高校、科研机构等合作研发产生的成果，其知识产权归属及未来收益如何分配；

 * 

在一些商业合作场景中，例如本体公司与垂类模型公司合作进行数据训练，或机器人公司与上市公司针对特定应用场景联合开发技能模块，相关成果的知识产权及后续收益分配亦需明确；

 * 

政府科研项目或补贴资金是否附带成果归属、使用或转化方面的限制。

 - 

**硬件专利：**应重点关注核心零部件（如灵巧手关节模组、高精度传感器）及整体结构的创新专利。建议警惕企业是否拥有真正的“高价值专利”，而非仅仅追求数量。通常而言，一件高质量的专利，应能通过层级化的权利要求设计，在同一申请中核心发明点需覆盖到最小可销售单元，直至整体集成产品方案。

 - 

**软件/算法专利：**这是当前专利布局中难度较高也最为关键之处。单纯的算法或数学方法难以获得专利保护，但如果算法与具体的硬件结合解决特定物理世界问题（如基于力反馈的精准抓取控制方法），则往往具备很强的可专利性。此外，还需评估核心算法是否适合以专利方式进行保护。对于不易被逆向工程、公开后可能削弱竞争优势的技术，一些企业会选择通过商业秘密而非专利进行保护。

 - 

**FTO（自由实施）风险的动态管理：**机器人领域长期存在由传统工业巨头、科技公司和学术机构共同构成的“专利丛林”。因此，FTO分析不宜仅在投资或者交易前进行一次性检查，而应形成持续性的动态评估机制，尤其关注标准必要专利（SEP）潜在风险，尽管在机器人本体领域目前尚不普遍，但如果涉及通信模块（5G、Wi-Fi）的系统中SEP风险往往难以避免。

**（2）数据合规：从采集到训练的全链条合规**

具身智能用到“人-机-场景”的视频、声音、动作与空间信息，天然触及个人信息、敏感信息、重要数据、测绘数据及跨境传输。

**数据来源的合法性评估：**用于训练动作模型的网络爬取视频，是否侵犯著作权？公共场所采集数据的授权是否完备或完成匿名化处理？是否可利用客户现场数据（如工厂操作视频）训练优化的模型？

**个人信息与敏感信息合规：**是否进行场景化的个人信息影响评估（DPIA）？是否执行最小必要、并落实告知同意（尤其在B2B场景）、去标识化/脱敏、留痕与删除机制？是否采集、处理生物识别信息（面部、步态、声纹）？是否能满足主体权利请求（查、删、撤）？是否触及军工、医院、校园等特殊场景的特别规则？

**地理信息与测绘风险：**机器人构建的高精度环境地图（SLAM），若包含地理坐标信息，极易被认定为“测绘活动”。根据中国《测绘法》，无相应资质（如导航电子地图制作甲级）的企业从事此类活动，将面临业务停摆乃至刑事责任。这是当前一个关键且隐蔽的合规风险点。

**数据跨境传输合规：**为优化算法将国内采集的敏感场景数据传至境外服务器训练，或在中东部署的机器人将数据回传中国，可能触发中国个人信息保护法、欧盟General Data Protection Regulation（GDPR）、沙特Personal Data Protection Law（PDPL）等法规的跨境传输要求。

- 

**维度二：人才资本——绑定核心技术与管理能力**

人才是具身智能的灵魂，但其流动性与依附性带来独特风险。

**（1）竞业限制与商业秘密风险**

**行业现状：**具身智能行业专家和技术人员总体而言供给有限，企业之间的人员流动较为频繁。不少团队核心成员来自自动驾驶、机器人、AI大模型公司，跨赛道引进人才成为常态。在一些早期项目中，为快速组建团队，对新加入人员过往任职情况及竞业限制安排的审查并不充分。

**深度风险：**若企业的核心技术人员来自竞争对手公司，且未度过竞业限制期，或虽已形式上离开原单位，但在新单位研发时使用了原公司的未公开技术秘密（如特定的参数调优方法、测试数据或失效案例库），原公司可能发起诉讼。在此类案件中，原单位不仅可要求该员工停职，还可主张目标公司承担连带侵权赔偿责任，并申请行为保全，从而对相关技术路线的研发造成实质影响。

**尽调关键：**建议对CTO、首席科学家及其他核心技术人员进行必要的背景访谈与有限度的合规调查，重点关注其过往任职情况、离职证明、竞业协议状态，并评估公司现有的研发隔离措施、保密制度以及技术管理流程，判断其是否足以防御潜在商业秘密侵权指控的风险。

**（2）股权激励的潜在隐患**

**复杂性：**为吸引人才，公司可能设置复杂的期权、限制性股票或虚拟股权计划。若结构设计不当（如行权价格不公、归属条件苛刻、退出机制模糊），不仅无法起到激励作用，反而会在融资或上市时引发大量内部纠纷与诉讼，成为公司治理隐患。

**尽调关键：**详细审查所有股权激励计划文件、与核心员工签署的协议，并模拟在下一轮融资、并购或IPO等场景下，可能引发的税务、会计处理及控制权问题。

**（3）能力错配与商业化瓶颈**

**结构性失衡：**当前许多具身智能公司的人才结构存在“重研发、轻工程”的倾向。团队核心多为学术研究或算法背景，虽在实验室环境中能实现技术突破，却普遍缺乏将技术转化为可靠产品并实现规模量产的系统工程能力与产业经验。这种能力缺失直接导致三大商业化瓶颈：1）供应链与管理短板：无法有效管理复杂的硬件供应链、控制成本与交付周期；2）质量体系缺失：缺乏搭建产品级测试、可靠性验证与持续品控体系的经验，导致产品故障率高；3）市场衔接不畅：缺乏搭建售前售后支持、客户培训与维护体系的能力，产品难以真正融入实际场景。

**尽调关键：**在评估技术团队时，需穿透性审视负责产品化、工程化与量产的关键岗位（如产品总监、供应链负责人、质量负责人）的背景。重点核查其是否拥有在成熟硬件或机器人公司负责过从0到1量产交付的成功经历，而非单纯的科研或实验室背景。团队核心成员的背景互补性，是判断公司能否跨越“演示原型”与“商业产品”之间鸿沟的关键指标。

- 

**维度三：产品与责任——物理交互带来的“不可逆”风险**

全球市场对具身机器人的监管仍处于快速演进阶段，企业面临标准不统一与供应链透明的双重压力。

**（1）市场准入与合规性：碎片化标准与供应链追溯的双重挑战**

**认证标准碎片化与缺失：**全球范围内，针对具身机器人的整机安全认证标准尚未统一，且各国监管要求各异。企业常面临以零部件（如电机、电池、控制系统）的分散认证来应对准入要求，但这无法完全替代整机安全评估，留下责任隐患。值得注意的是，行业标准正在积极构建中，例如中国已发布《人形机器人人机交互与安全技术规范》团体标准（T/CAMETA001067—2025），标志着标准化进程的启动。

**供应链制裁与物料追溯：**主要进口市场（如欧美）会严查整机是否包含受制裁或出口管制的核心部件（如特定芯片）。若无法清晰追溯并证明所有核心物料来源合规，将导致整机被扣押、罚款乃至市场禁入。

**售后体系与高故障率：**行业初期产品成熟度低，售后需求极高。若缺乏完善的全球售后网络、快速备件供应及远程诊断能力，高频故障将迅速转化为大规模的产品责任索赔与品牌信誉崩塌。

**尽调关键：**尽职调查需超越简单的证书清单核查，应深入评估：1) 目标市场所需的整机与关键部件的强制性认证现状、差距及获取周期成本；2) 核心零部件的全链条溯源文件，以验证无制裁合规风险；3) 应对高故障率的售后服务体系能力，包括全球服务网络、备件库存、远程诊断与技术支持数据。

**（2）产品责任：复杂系统下责任划分的复杂性**

当伤害发生时，由于其系统高度复杂（融合硬件、软件、算法与环境交互），责任认定极其复杂：

**责任划分的复杂性：**一次物理伤害（如机械臂撞击）可能源于硬件故障、传感器失灵、算法误判或系统集成缺陷。这导致责任在整机厂、算法供应商、关键部件供应商乃至使用者之间难以清晰划分。欧盟《新产品责任指令》确立了“因技术复杂性导致受害者难以举证时，推定产品存在缺陷”的原则，这大幅加重了企业的举证责任。事故发生后，企业能否从机器人系统中提取清晰、连续、可被司法鉴定的全链路数据日志（涵盖传感器输入、算法决策逻辑、控制指令输出），将成为抗辩或厘清责任的核心依据。若无法提供，则很可能承担败诉风险。

**尽调关键：**核实产品是否具备硬件级紧急停止功能（符合ISO 13849等安全标准），而非仅依赖软件。同时，评估其数据记录系统是否能可靠存储并输出用于事故责任分析的关键技术日志，此能力是应对产品责任诉讼的“技术生命线”。

**（3）全生命周期责任：软件迭代带来的延伸责任**

**新问题：**机器人出厂时安全，但通过软件更新（OTA）或在线学习获得新能力后造成伤害，责任归属模糊。当前监管趋势倾向于要求制造商需对“可预见的软件进化风险”负责。

**尽调关键：**审查企业的软件更新与算法更新管理流程。重点包括：重大算法更新是否重新进行了全面风险评估与测试？是否有可靠的版本回滚机制？用户协议是否对“自主学习功能”及其潜在风险进行了充分且明确的提示？

**结语：构建体系化合规能力，穿越创新周期**

具身智能的长期发展，依赖于技术、法律、伦理与社会信任的协同共建。

对投资人而言，最深远的洞察在于：在这个高度复杂的赛道，长期的竞争优势将不属于那些仅有尖端技术的公司，而属于那些能将法律合规、产品安全与伦理要求深度融入其研发体系、运营管理和公司文化的组织，它们是能在创新前沿主动建立系统化规则能力的先行者。

对具身智能企业而言，应对尽调的最佳策略是变被动为主动：建立常态化的合规内审与管理体系，将风险防控深度融入研发与运营流程，方能在资本审视中从容应对，彰显长期价值。

因此，一次极致深入的法律尽调，其意义远超风险规避。它是一次对企业“系统韧性”和可持续经营能力的一次全面诊断与压力测试。

具身智能浪潮澎湃，与之共舞的前提是步伐稳健。唯有充分认知并管理好其中的法律风险，才能护航创新行稳致远，真正释放其商业与社会价值。
