# 甘肃2027年上半年机制电价竞价：4月3日提交材料，30亿kWh，0.1954~0.2447元/kWh

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/nJIHJiauQqnz6VBj0uTricSqbFeTjYA87gs8c7tpsicGRfrlUcwWwHsxaJoevJOHwvOvRbTfcB01miciaXxavYHG1GjdMuvhAUPg8G4MjUP2yOAw/640?wx_fmt=jpeg&from=appmsg)  

储能与电力市场获悉，3月5日，甘肃省电力公司2027年上半年增量新能源项目机制电量竞量竞价组织公告发布。  

2027年度分上半年和下半年两个批次分场组织风电、光伏项目竞价。上半年批次纳入机制范围的电量总规模为30亿千瓦时，其中，风电机制电量17亿千瓦时，光伏机制电量13亿千瓦时。

  

2027年度上半年批次竞价范围主要包括2027年1月1日至2027年6月30日期间已投产和计划投产的新能源项目，以及此前未纳入过机制电量规模的增量新能源项目（2025年6月1日（含）后全容量并网）。

  

申报价格上下限：风电、光伏竞价上下限相同，竞价上限0.2447元/千瓦时，竞价下限0.1954元/千瓦时。  
执行期限：确定为12年。  
机制电量分解方式：单个项目每年纳入机制的电量，入选时未投产项目从申报投产时间至当年12月31日按天数平均分解至月度。入选时已投产项目从竞价周期1月1日至当年12月31日按天数平均分解至月度。  
竞价工作程序：

  

资质材料提交（4月3日-4月12日）  

资质材料审核（4月13日-4月23日）

  

资质审核公示（4月24日-4月30日）

  

竞价申报（5月6日-5月8日）

  

竞价出清（5月9日-5月10日）

  

结果公示（5月11日-5月15日）

  

结果公布（5月20日前）

  

全容量投产申报
