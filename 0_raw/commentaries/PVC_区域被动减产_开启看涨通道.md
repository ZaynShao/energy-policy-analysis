# PVC | 区域被动减产 开启看涨通道

![公众号广告图-星标.jpg](https://mmbiz.qpic.cn/mmbiz_jpg/jB59BB1tXAUcg8ccNABsWLoDbCFzttd3Jpb5RI1Y8icgq8sB754HGg82d4RjmbDpCSZicp4Kf9ewflw7wgd9owkqaWasvNKHPu1oiawzsUeibIM/640?wx_fmt=jpeg&from=appmsg)

背景：2026年春节过后，中东地缘冲突骤然加剧，霍尔木兹海峡成为搅动全球能源格局最不稳定因素，随着中东原油、石脑油、甲醇等一些列运输终端，国际原油重回历史高位，供应收紧及成本增加乙烯价格涨幅也接近翻倍，乙烯衍生品面临原料供应减少及成本大幅推高双重压力，乙烯法PVC不同程度减产及不可抗力预期，随着事态延续预计区域供应格局将迎来重塑。

**蛇打七寸 原料紧缺卡住区域乙烯与衍生品供应**

全球PVC产能主要集中在东北亚、北美、欧洲等区域、占全球总产能的84%，东北亚3530万吨/年产能中主要集中在中国大陆、日本、韩国、中国台湾地区，除中国大陆7成为电石法工艺外，其余装置均为乙烯法工艺，较为依赖乙烯原料。

另据数据，年通过霍尔木兹海峡运输的原油占全球的五分之一，卡塔尔液化天然气通过该区域外运销售的总气量占全球供应的20%左右，而该区域运输的原油近9成运往亚洲，37%运往中国，14%运往印度，12%运往韩国、10%运往日本，区域供应可谓亚洲能源七寸。

受局势影响，YNCC、LG、韩华、台塑、东曹、东南亚及印度多个公司均发布了不可抗力，能源货紧及成本推高亏损加速，导致众多企业面临减产而交付存在不可抗力；韩国乙烯为净出口国家，其原料主要依赖进口石脑油原料，且主要进口地集中在中东地区，日本则是乙烯净进口国，超过6成来自韩国。中国乙烯年产能突破6000万吨，然仍为净进口国，2025年进口超过280万吨，主要进口来自韩国、日本、阿曼等地区。

整体来看，中东基础原料供应受限，乙烯及衍生品市场面临生产停摆与出口阻断的双重困境，全球约15%的乙烯供应直接受损，其他替代方案由于运力损耗及运输成本增加等间接推升产品价格，相对于中国区域的“相对稳定”，日本、韩国及东南亚区域则因乙烯原料断供或由传统乙烯及衍生品的供应商转变为需求方。

**PVC供应区域性收紧 推升全球价格**

乙烯供应不可抗力，成本及价格飞涨，亚洲多家PVC重点供应商发布了不抗抗力，3月中下旬及4月PVC交付面临供应减少或无法交付的困境，日本与韩国超过300万吨PVC年产能均将受到影响，而区域产量预计6万吨/周上下，月产量预计在24-26万吨，月出口量达10万吨，3月日韩减产超过2成，局势发展至4月减产规模预计超过5成以上，且日本、韩国亦是传统的氯乙烯原料出口地区，主要目的地在中国大陆、东南亚区域，月出口量达5-8万吨。

中国台湾地区台塑等企业也发布了不可抗力，乙烯价格快速上升产业成本压力加大，初步来看，局势紧张延续，PVC预计4月减产超过5成。

中国大陆地区乙烯法生产企业也面临原料紧张与成本转亏的双重压力，开工率已经延续超过2周下降至69.24%，环比前2周下降接近15%，同比下降3.27%，中国877万吨乙烯法工艺中原料分别依赖进口乙烯、国内采购乙烯、进口甲醇、进口氯乙烯、外采氯乙烯、煤制乙烯、乙烷制乙烯等等渠道，且国内有庞大的乙烯供应渠道，因此短期来看原料对供应的限制影响尚为有限，但成本加速上涨带来的亏损叠加远期乙烯供应的不确定性迫使企业调整生产负荷，未来进口乙烯、进口氯乙烯叠加亏损压力预计PVC乙烯法开工仍有20%左右的降幅空间。

4月亚洲区域出口预售因成本及当前超过2成的减产迟迟未能公布计划与价格，料东北亚乙烯法PVC整体减产超过一半的预期推动当前全球PVC市场价格，中国大陆离岸价乙烯法价格涨至1000-1100美元/吨，亚洲主要港口到货价格涨至1050美元/吨附近，涨幅超过300美元/吨，美国与欧洲等地涨幅也超过200美元/吨。

**供应结构重塑 电石法出口或迎来机遇**

亚洲多地乙烯法PVC减产目前来看持续加剧，而中国大陆电石法供应因上游资源特点未收限制，开工连续走出了上涨趋势，本周电石法开工在84.71%环比增加1.79%，为22年3月以来最高值，同比增加2.09%，结束了2022年以来的亏损局面，提振了行业开工积极性，亚洲乙烯法整体的减产而引发的区域出口紧张局势或为供应充足的电石法企业带来出口机遇。

短期，由于一季度中国因取消出口退税带来的抢出口市场尚在消化期，前期签订的低价货源集中到港导致印度、东南亚等多地区客户尚对于当前高价市场有抵触情绪，再就是因中东局势影响的4月船期紧张与海运费波动，叠加主要出口商因原料供应问题无法保证装运等矛盾引发断供的忧虑情绪，预计出口成交尚需时间发酵，然则区域局势延续的话，上游资源短缺事实势必导致市场转向采购性价比更有优势的中国电石法PVC。

这场地缘影响，不仅推高了化工品的价格，更是暴漏了全球供应链的隐患，使的区域PVC供应结构短期重塑，也为产业供应链安全与多元化布局带来警示。
