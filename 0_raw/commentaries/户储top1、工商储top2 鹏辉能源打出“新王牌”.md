# 户储top1、工商储top2 鹏辉能源打出“新王牌”

当下，储能正从“新能源配套”迈向“能源保障基础设施”，并进一步成为新型电力系统的关键支撑，全球储能市场迎来爆发式增长。
在储能高增长时代，安全、能效、寿命与场景适配能力，已成为产品决胜未来的核心指标。
6月3-5日，SNEC 2026现场，鹏辉能源聚焦大储、户储、AIDC三大细分场景，推出三大重磅新品，直击行业痛点，助力储能产业迈向高价值时代。
多年来，鹏辉能源始终秉持“技术鹏辉”的初心与追求，持续以场景化的产品创新，满足客户多元化需求，回应绿色时代的能源使命。
凭借场景化定位与硬核技术，鹏辉能源连续制霸储能细分市场：高工产研数据显示，2025年，其工商业储能稳居行业TOP2阵营；而相关数据显示，2026年第一季度，鹏辉能源户用储能电池、便携式储能电池做到了第一。
高能户储电芯122Ah,
能量密度＞200Wh/kg
面对全球户储市场“家电化”与“价值化”两大发展趋势，鹏辉能源推出具备高能量密度的全新户储电芯122Ah，并首次亮相SNEC 2026。
在兼具安全与循环的前提下，鹏辉能源122Ah户储电芯质量能量密度突破200Wh/kg，精准匹配户储系统“All-in-One”极简设计需求，解决了户储一体机在集成化潮流下的“集成密度”痛点。
在市场大变局下，鹏辉能源希望助力客户研发出更高能的户储柜体方案，高能量密度的电池单元是实现“All-in-One”一体化设计的基石。目前，鹏辉能源122Ah户储电芯已通过IEC、UN38.3等多项严苛国际认证，助力客户产品全球通行。
鹏辉能源高能户储电芯122Ah
AIDC储能专用电芯瀚海85Ah
满足10C高倍率放电
AIDC作为数字经济的核心算力底座，正迎来前所未有的高速增长，单机柜功率正从20-50kW向100kW以上跃升，GPU负载呈现毫秒级的瞬态脉冲特征，传统供电模式已难以支撑AIDC对供电连续性、毫秒级响应与零中断的严苛要求。
鹏辉能源精准锚定AIDC场景对毫秒级响应与高功率备电的刚需，于2025年率先推出高倍率瀚海电芯85Ah，为智算时代夯实能源底座。
瀚海电芯85Ah具备10C高倍率放电性能，瞬时达12C，在10C放电条件下容量保持率超97.5%，可在供电中断瞬间为AIDC提供巨大功率支撑。同时，基于AIDC高密度机柜的瞬时功率需求，瀚海电芯85Ah针对高备电场景实现性能突破，在2500W高功率放电条件下，能够稳定支撑分钟级备电时长，覆盖从市电中断到备用发电机启动的关键切换窗口，全力保障数据安全不丢失。
同时，针对AIDC瞬时负载波动调频需求，瀚海电芯85Ah具备毫秒级瞬时响应速度，可实现高频次毫秒级充放电切换，在高频脉冲测试中，瀚海电芯85Ah充放电循环超60000次。
AIDC储能电芯技术的发展，是一场围绕“安全、功率、循环”铁三角的角逐，鹏辉能源愿以瀚海85Ah之力高效赋能AIDC。

风鹏大电芯588Ah
全温域高能效，助力储能价值时代
SNEC 2026现场，鹏辉能源重磅展出风鹏大电芯588Ah。通过材料体系与结构设计双重创新，实现可靠与高效双向突破，为客户带来了新一代储能大电芯方案。
安全层面，风鹏大电芯588Ah融合三重安全技术，构筑了硬核安全防线。目前，风鹏大电芯588Ah已通过针刺、热失控、短路等严苛测试。能效层面，依托自研离子海绵平台技术，风鹏大电芯588Ah全温域能效表现卓越，5℃能效达85%，25℃能效突破95%，45℃能效超过96%。同时，基于高温长循环平台技术，显著提升了风鹏大电芯588Ah在高温环境下的循环稳定性，显著提升储能系统在全球多气候、多场景下的应用价值。

能源变革浪潮奔涌，新型储能正加速迈向价值化时代。未来，鹏辉能源将持续围绕电池核心技术实现场景化创新，为全球客户带来高可靠、高性能、高价值的储能产品方案。鹏辉能源愿与全球伙伴同频共振，共赴零碳未来。
