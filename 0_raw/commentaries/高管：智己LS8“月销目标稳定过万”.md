# 高管：智己LS8“月销目标稳定过万”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/RaRCbSicibjeX4LIHGP3soh9ial5OjpbQCCxlWLy20x8XBibOrRQasYF9kudPo9AgSTSvLMic6G3emEB1F7s7qzIh3lrsjria3sRElc5EJ5HSHAcc/640?wx_fmt=png&from=appmsg)****

作者 | 王凌方  
编辑 | 邱锴俊****

“用户要的不是参数，是‘不纠结’。”

智己汽车CMO李微萌在LS8预售发布后的交流中，反复提及这个判断。在她看来，当下的用户已经被各种参数、配置、行业黑话包围，选车变成了一场需要做大量功课的“信息战”。而智己要做的，就是替用户把这些复杂的决策消化掉。

李微萌认为，用户想要的从来不是一张写满参数的表格，而是一台方方面面都无需妥协的车：既有传统豪华车的机械素质、内饰质感与安全品质，又有当下第一梯队的智能驾驶和AI能力，还能承载一家人的出行需求。

3月26日，智己LS8正式开启预售。新车提供大五座和大六座版本，25.98万元~30.98万元预售权益价。

![image](https://mmbiz.qpic.cn/mmbiz_jpg/RaRCbSicibjeWwkvfkydjsvqkf67nWMZT8yfYa4ShyGTpUgpBUBnyEVZukQ7iaTuVJ0KiaMhQ795PCSxpvp7l5r7LpHPk3WXG1tiaELZglgG3tZs/640?wx_fmt=jpeg)

对于智己LS8的销量，智己高层也是很有信心。李微萌表示，LS8的销量目标是——“月销过万”。

**01******

核心配置标配的取舍之道

智己的车向来喜欢“卷”黑科技，智己LS8也不例外。

智己LS8全系标配灵蜥数字底盘3.0、双向24°智慧后轮转向、德国大陆MK C2线控制动、四活塞固定卡钳、超大行程闭式空悬与CDC减振器——这套底盘硬件组合，放在任何一款百万级豪华SUV上都堪称“满配”。而它的实际效果也足够直观：车长超5米的旗舰SUV，转弯半径做到4.85米，比A0级小车更灵活；百公里刹停距离34.38米，优于同级别传统豪华SUV近1米。

在智能化层面，LS8全系标配英伟达Thor芯片（64GB LPDDR5X内存）与IM AD辅助驾驶系统，具备高速域全场景AEB、读懂交通指挥手势等能力。座舱内，中国首搭的B&O音响、4D机械按摩座椅、智控地暖系统等“新奢华三件套”，也试图在感官体验上建立差异。  

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeVLjsAmyCe3or2bzyTO1BZ4CeicOflw77To98r90hgYY4LxKMQTo0ibMMLibyYDia0zXejHnI8P2U73mgsxpvoG1tIOSrzYGjpnKIk/640?wx_fmt=png&from=appmsg)

但值得注意的是，这场“标配盛宴”并非毫无边界。根据官方信息，发布会上重点展示的520线超视域激光雷达与全线控四轮转向系统，均为收费选装配置。

前者具备智能凝视功能，最远有效感知距离300米，是L3级感知能力的硬件基石；后者则取消了传统机械转向管柱，实现4.5:1到14.2:1的超大范围可变转向比，半圈即可打满方向盘完成掉头，同时被视为L3/L4高阶辅助驾驶的核心技术基座。

这两项选装配置的存在，折射出LS8在产品定义上的现实考量。一方面，将基础配置拉满，确保用户在“不选装”的情况下依然获得远超同价位车型的体验；另一方面，通过选装项为“技术前瞻型”用户预留升级空间，同时也在成本与定价之间寻找平衡。

正如李微萌在交流中透露，Thor芯片与DDR5内存的原材料价格持续上涨，“每三天采购报一个价”，而B&O音响、线控转向等配置的成本压力，最终需要在产品定价与用户接受度之间找到平衡点。

02

如何在“8系”混战中的突围

2026年的中国新能源市场，中大型SUV的“8系”赛道已成红海。从理想L8、蔚来ES8到问界M8、小鹏G9等，各家都在这一细分市场布下重兵。在参数高度同质化的背景下，LS8选择了一条差异化的路径——不再单纯比拼续航、加速、屏幕数量，而是聚焦“中国品质家庭”的真实使用场景。

在尺寸上，LS8的5085mm车长、3060mm轴距、2000mm车宽，属于标准的大型旗舰SUV规格。但真正的差异在于空间利用率。据智己汽车CTO项娇介绍，为了在五座版二排膝部空间上多争取“厘米级”的改善，团队在模具已经开动的情况下仍决定推翻重做，“千万级别的模具投入，就是为了达到我们的要求”。

这种执着的结果是：LS8五座版后备箱可容纳6个28寸行李箱，全车最多可装下47个20寸登机箱；六座版的二三排膝部空间总和接近2000mm，被官方称为“不让任何一位家人妥协”的真六座。二排右侧的“柯布西耶”沙发椅拥有132°大躺角与8点SPA按摩，副驾“超级右排”可一键零重力躺平，配合15.6英寸专属娱乐屏——这些细节指向一个明确的用户场景：三代同堂的家庭出行，每一位乘员都不应是“将就”的那一个。

在空间之外，LS8的另一重差异化来自“大厂品质”的信任背书。作为上汽集团、张江高科和阿里巴巴共同打造的科创公司，智己在电池安全、车身结构、供应链整合等方面，强调其背靠传统车企的体系能力。52kWh“航盾”电池采用航空级PPB（十亿分之一）级电芯可靠性标准，通过30%极限挤压、整车烈火焚烧、电芯极限切割三大测试；车身采用十纵十一横全向闭环潜艇笼式结构，大量使用潜艇级热成型硼钢。

03

软件定义能力的护城河

如果说底盘硬件与空间设计是LS8的“硬实力”，那么智能驾驶的持续进化能力，则是其试图建立的“软壁垒”。

LS8搭载的IM AD辅助驾驶系统，背后是智己与Momenta的深度绑定。据项娇介绍，作为Momenta“行业唯一创始灯塔合作伙伴”，也是唯一与 Momenta 达成英伟达Thor平台+520线激光雷达合作的车企；双方合作覆盖 L2/L3/L4全级别，上汽L4级Robotaxi已在上海迪士尼运营，L3级智驾通过国家指南项目测试。  

LS8采用的英伟达Thor芯片，也是目前智驾域控算力的第一梯队。而520线激光雷达虽然为选装，但其L3级的感知能力，配合Thor芯片，为未来升级至IM AD ZETA系统（L4级模型能力降维赋能L2）预留了硬件冗余。

![image](https://mmbiz.qpic.cn/mmbiz_png/RaRCbSicibjeUayvDj9HfCkzhlwSlgrGSdibbDDbXqy526ubic7Uq0j8L83Ho5zMYT6FNvLXRTBPndpFyMKR82GToIVx4g7O8UjQd57fHjTskmY/640?wx_fmt=png&from=appmsg)

李微萌在交流中透露，LS8标配Thor芯片的决定“讨论了很久”，因为Momenta在Orin X平台上的算法已经可以做到“城市端对端NOA体验非常好”。但最终选择更高算力平台，是希望用户“在买这款车时不会只考虑当下，要考虑三年、五年之后”。

另一个值得关注的点，是IM Ultra Agent 1.0的上车。作为开源大模型“千问”首次上车的载体，LS8打通了阿里全场景生活服务生态，实现“一句话”完成出行需求。更关键的是，它能够联动底盘驾驶——当用户说“孩子睡了开稳点”，底盘会主动调整至更柔和模式，可以实现一句话操控汽车，成为消费者的专属司机助理。
