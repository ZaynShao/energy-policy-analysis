# 中电联供电质量提升专项行动工作启动会暨专项工作研讨会在京召开

8月13日，为深入贯彻落实国家发展改革委、国家能源局关于提升全国供电质量相关工作部署，中国电力企业联合会在北京召开中电联供电质量提升专项行动工作启动会暨专项工作研讨会。中电联党委委员、专职副理事长安洪光，国家能源局原监管总监黄学农出席会议并讲话，中电联监事长潘跃龙主持会议。
会上，专项行动工作组汇报了本次专项行动总体工作方案，围绕供电质量提升标准化专项工作、区域供电质量统计发布机制、高供电质量标杆园区技术指标体系建设、电能质量经济性损失评估及新质生产力用户分级分类摸排等五项重点任务开展专题汇报交流。与会代表充分认可工作组前期研究成果，并针对标准落地适配、区域供电质量指标科学表征、标杆园区评价指标体系合理设计、经济损失评估方法实操可行、用户分级分类细化管理等方面提出了优化完善意见。
黄学农充分肯定了中电联供电质量提升专项行动工作的重要意义，指出要依托中电联行业平台优势，深化政企联动，引导终端用户积极参与，聚焦技术、政策、机制等关键问题深入研究，形成可落地、可复制推广的解决方案，确保专项行动取得实效。
安洪光在总结讲话中指出，供电质量提升是一项专业性强、技术要求高、涉及面广的系统性工程。当前电力市场主体日趋多元，供电质量贯穿发电、电网、用户侧及各类电力新业态，需要系统梳理现存问题，精准锚定研究方向；各单位要压实工作责任，明晰分工边界，强化多方协同联动，统筹推进专项行动走深走实。
来自国家电网、南方电网、内蒙古电力、中国电科院，以及中电联可靠性管理部、标准化部、检测院、法律分会等专项行动工作组成员单位的近50位领导、专家参加了会议。
