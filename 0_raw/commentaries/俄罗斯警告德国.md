# 俄罗斯警告德国

俄外交部警告说德国参与袭俄不可接受。
俄罗斯外交部13日召见德国驻俄大使亚历山大·兰布斯多夫，向他通报德国参与乌克兰袭击俄民用设施情况，并警告德国此类支持乌方的行为不可接受。
据俄外交部网站发布的消息，俄方在召见兰布斯多夫时说，德方加大力度支持乌克兰不可接受，这类支持包括与乌方缔结军事和军事技术协定；直接提供装备；通过联合企业发展攻击俄民用目标的力量和手段，例如研制侦察和攻击型无人机、防空导弹和打击俄民用设施的火箭弹。此外，“德国试图对他国与俄如何发展关系指手画脚”同样不可接受。
另据今日俄罗斯通讯社13日报道，德国外交部当天就俄方疑似对欧盟方面实施网络攻击一事召见俄罗斯驻德国大使谢尔盖·涅恰耶夫。涅恰耶夫稍后通过社交媒体发文说，他驳斥了欧盟方面没有证据支持的臆测，并强调欧盟威胁扩大对俄制裁不会没有后果。
