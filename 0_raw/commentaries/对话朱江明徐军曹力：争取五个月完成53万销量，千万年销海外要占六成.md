# 对话朱江明徐军曹力：争取五个月完成53万销量，千万年销海外要占六成

零跑最便宜新车上市，朱江明：是零跑十款车中我对颜值最满意的一款车。车东西8月12日消息，日前，零跑A05正式上市。新车共有5个版本，其中405舒享版售价6.39万元，405悦享版售价6.79万元，510悦享版售价7.59万元，510激光雷达版售价8.59万元，510S版售价9.09万元。▲零跑A05售价与配置差异
在发布会后，零跑科技创始人、董事长、CEO朱江明，零跑科技高级副总裁兼首席运营官徐军，零跑科技高级副总裁曹力和零跑科技副总裁周颖接受了车东西在内的媒体采访。▲零跑科技创始人、董事长、CEO朱江明（左二）零跑科技高级副总裁曹力（左一）零跑科技高级副总裁兼首席运营官徐军（左三）零跑科技副总裁周颖（左四）
在采访现场，朱江明、徐军和曹力围绕着刚刚上市的A05、零跑汽车后续销量目标、产品规划、海外市场的进展等问题进行了详细的回答。以下为采访实录，车东西在不改变原意的情况下进行了部分编辑，对采访问题的顺序进行了部分调整。
在7月，零跑汽车全球交付量为10.13万辆，成为国内首个单月交付破十万的造车新势力品牌，而关于零跑年度销量目标的达成情况与接下来的规划，朱江明、徐军和曹力做了详细的解读。1、零跑七月份交付超过10万台，出海的销量大致占比多少？国内海外的销量比例是多少？朱江明：2025年是零跑出海的第一年，我们的销量是6.7万台，我们去年的全年销量是59万台，海外比例接近10%左右。刚刚过去的七月份我们的月销量是10万台，海外的销量接近2万台，占销量的20%。所以我们今年是从10%到20%，明年可能目标更高一点，逐步的在提升海外销量的占比。所以我相信未来我们还是按照预期的目标，不断的去提升海外销量占比。我觉得先做到海外国内四六开，再是五五开，再是六四开，我认为就是最理想的状况。如果要做到千万台年销量，我觉得肯定要做到海外国内销量六四开才能做到年销千万台，不然不可能。中国还没有车企年销量到过500万台，大众卖的最多的时候到过400多万台，如果零跑做到年销量1000万台，至少海外是600万台，国内400万台，不然的话难度就更大了。所以我觉得最终的终局应该是往这个目标去努力。2、零跑与斯特兰蒂斯合作，在西班牙落地产能的规划推进情况怎么样？朱江明：目前零跑在西班牙的工厂也在紧锣密鼓的推进当中，我们今年年内一定会以CKD（全散件组装，零部件出口到目的地国家后，再由当地工厂进行组装成整车）的形态，就是车身制造和主要的大部件会在西班牙制造，一些核心的三电的零部件还是以国内出口为主，用CKD的形式，争取第四季度能够在西班牙量产。3、之前朱总说造车的心情像过山车一样，想问一下您当时怎么想出这个词语的？您觉得零跑现在的市场表现处在过山车的哪个阶段，A05上市之后，是不是过程会更刺激一点？朱江明：对于造车这件事情，我形容像上了过山车一样，是因为速度很快，我在香港坐过过山车，太惊险了，完全超出我的承受能力范围。造车这件事也很类似， 一旦准备造车，中途就下不来，如果突然半途而废的话面子也挂不住，必须坚持下去。造车这件事情上去就下不来，只有过山车停下来的时候，才能走下来。零跑处在怎么样的阶段？就像坐过山车已经过了前面惊吓的环节，到了感觉有点快乐的阶段了，在享受坐过山车的过程，觉得还是挺开心的，可以看到很多风景，快要到达顶点，可能会达到更高的一个目标。我觉得从现在来看，我对零跑的现在的评价是处于这样的状态。4、零跑上个月销量已经10万+了，有没有可能在今年能超过15万辆，也就是超过南北大众之和？我们零跑的一贯作风是循序渐进，稳扎稳打，没有那种突变。近三年零跑的年销量、月销量，都是一条线性的曲线，没有大起大落，零跑整体的发展都在按照我们的预料循序渐进、稳扎稳打，一步一个脚印往上走。当然今年我们年初定的百万销量的目标，虽然受整个行业销量总量的下降，给我们带来了很大的难度，包括有材料成本的上涨带来的成本的压力，但是我们还是希望我们的团队能够继续努力，去完成我们全年的销量目标。5、零跑取得10万月销这个成绩，核心护城河是什么？朱江明：首先我觉得零跑定力非常好。这十年下来我们始终如一，一以贯之的去贯彻我们的策略，包括全域自研、深度自制。我们从成立那天到现在，能够一以贯之的执行，公司团队非常的稳定，这是最重要的一点。还有就是成本定价，我们贯彻的非常坚决，利用我们自己的能力，我们全域自研、深度自制，把零跑自己的利润，全部让给了我们的消费者。所以零跑的产品始终能保证在相同价位段做到更高配置、更有品质。我们发布的A05也同样做到了。相同的价位，友商能给到300公里的续航，那零跑就能给到400公里。友商给到400公里的续航，零跑就能给到500公里。续航接近的产品，零跑还能给到激光雷达和高阶智驾，这就是零跑自己的能力所在，就是我们的深度自制，把省出来的全部毫无保留地让利给消费者。所以才会有用户的口碑，才会有我们现在每个月能够非常稳定线性增长的销量。这些都来源于零跑产品真正的竞争力。这个竞争力也不是说深度自制就行了，而是体系化的能力、平台化的能力，形成了产品的绝对竞争力，这些结合在一起，我们才有了今天10万辆的月销量。同时从今天来看，零跑已经不仅仅是一家新造车势力。我们已经连续三个月位居中国新能源汽车销量的前三名，这是包含了所有的国内外车企，这绝对不是偶然，是我们日积月累，循序渐进，能够得到用户的满意、用户的支持所得到的结果。6、接下来的五个月，零跑是否有信心每个月都能够达到10万以上的单月销量，又如何去达到？朱江明：基本上每个车企都一样，前六个月能够做到35%到40%的销量目标，基本上对于达成全年目标来说没有落下那么多，当然我们七月份已经做到了10万辆，按照我们的100万辆目标的这个时间线，继续往前又迈进了一步。所以我觉得零跑还是非常有信心，争取在未来的五个月里，还要完成接近53万辆的销量，每个月要做到10万多辆这样的水平。我觉得机会还是有的，因为毕竟从下半年对全年的销量影响来看，相对是有机会的，我们也要想尽一切办法，要去达成这个目标。曹力：关于产能这块，我们零跑有一个特点，首先在产品上面，我们希望每推出的一个产品都是走量的爆款产品。同时对于我们的工厂产能也提出了非常高的要求，所以同样有可能也会是甜蜜的烦恼。但是零跑还有一个特点，就是稳扎稳打的风格。我们不会说去建大规模的产能，然后空在那里。我们还是会按照我们的既定的规划，让工厂处在一个非常饱和的运行状态。同时也是得益于我们整个架构和平台化做的非常好，所以包括工厂的前期设计、柔性化也做的很好，不同工厂之间可以无缝衔接，导入我们不同的产品，而且可以做到共线生产。徐军：我是不是可以替曹总承诺一下，当然也希望向所有用户传达，我们上市即交付，年轻人不要等待。8、如何看待A0级市场的一些发展？目前的一些热销车型，还有哪些用户没有满足的痛点？朱江明：首先大家看到A00级市场快速地萎缩，说明大家的消费在升级。因为随着新能源车规模的扩大，成本在下降，大家的需求在提升。续航200公里、300公里这些A00级的车，现在这个销量确实急剧下降。原来A00级的用户，现在要提升到A0，这是循序渐进往上提升的过程，所以我觉得现在的A0级基本上替代了原来的A00级。但是零跑的情况，和现有的友商A0级车型的客户群不一样。像零跑A10的用户是一二线城市最多，比如杭州销量是最大的，同时北上广深都是很大的。A10卖的很好，我们的很多友商也卖的很好，没影响，这就说明零跑现在所做的市场是更加细分的市场。更高配置、更有品质，对品质更有追求感的用户选择零跑A10和A05，无论是从颜值、质感、智能化和续航，我认为这四大部分应该是零跑A系列最有特点，和友商的竞品有差异化的地方。A10已经做到SUV第一了，原因就是找到了红海中的蓝海，就是差异化的竞争。500公里续航、激光雷达、城市NOA、8295芯片在A0级市场里首先大规模的使用，这些特点都决定了零跑在A0级这个细分市场是和友商是不一样的。
对于此次上市发布会的主角零跑A05，朱江明、徐军和曹力则在定位、同级竞争力和出海规划等方面进行了更详细的介绍。9、A系列第一款车A10上市以来，销量不断创新高，很快可能要超过3万台的月销，这款车为什么有这么高的销量？到底是哪些用户对它感兴趣，哪个版型更受欢迎一点？徐军：首先感谢所有选择我们A10用户的支持，其实他们用行动证明了一件事情，通过数据也能展现出来。杰兰路的报告里边有三个数字，我们都是冠军，销量、质量、口碑都是冠军。这也是代表了大家的选择是正确的选择。我们看了整体的客户人群画像，65%是男性，有增购换购，也有人是第一台车，这两种用户的输入是比较多的。大家对于配置选的最多的是505悦享版和激光雷达版，其中激光雷达版占50%以上。说明什么呢？说明大家选购零跑的车和过去不太一样，选择标准是起步即高配，一步到位。这也说明了他们对零跑造车理念的一种认同，也认同零跑有能力造出高品质的车。在造车理念上，我们践行了全域自研的这样的方式，把科技普惠在A0级的车上实现。当然大家选择A10最重要的一环，就是我们把激光雷达能够率先放到这个价位上，这是在同等竞争产品中没有的。朱江明：我补充一下，其实500公里续航也是A10非常大的亮点，70%的用户是选择500公里续航以上的版本。在这个产品段里，零跑A10是独一份的存在，还没有一款车在这样一个小车上能够做到500公里续航。我觉得这也是零跑为什么能热销，就是我们要从红海里面找到蓝海。10、零跑A05选择在西子廊桥举办上市活动，在场地选择上有怎样的考量？徐军：在西子廊桥，我全程看了直播，有一些媒体人说你们太赞了，可能会把这个地价给炒起来。因为接下来可能很多厂家都会考虑是不是以这样的方式开发布会，但实际上这个事情贯彻了整个零跑的两个核心价值观。第一个价值观就是以用户为中心。因为A05的定义是主打年轻，好看、好玩，好开心的逻辑。我们主要的用户实际上你就在今天开发布会的这条街上，每天的流量大概几十万人，其中有一半是我们要对话的人。所以有句话叫“山不过来我过去”，用户在哪里我们就去哪里。让用户能够真正地在逛街、喝奶茶的时候就能看到A05，就可能会停下来摸一摸、坐一坐、试一试，我相信年轻人想要的就是这种感觉。第二个践行是我们的核心价值观创新。在当下这种充分竞争的这样的市场，我们需要的不仅是产品创新，我们在营销方面也需要创新。创新不是乱创新，是要围绕着用户为核心的创新。年轻人最需要什么？A05不仅是给大家带来方便的交通工具，更多的是能给年轻人想要的情绪价值。所以我们希望A05给大家传递的印象是它是一个出行的好搭档，有颜值又智能，你想去哪里它都可以陪你去。我们希望能够让我们的用户感受到零跑的温度，零跑造出的车就是你最好的出行搭子。11、在零跑当前的产品矩阵中，A05扮演着什么样的角色？曹力：A05其实很好地体现了零跑一直在坚持的科技普惠理念。因为A05补齐了零跑从A0级小车到D级整个版图，虽然是一个小车，但是我们同样把所有全域自研的技术、高品质的要求、非常好看的颜值和安全系数拉满。可能在二三十万车上的这些高配的配置全部给它堆上去。价格的话，大家其实可以自己去比一比，同样的配置零跑A05的价格肯定是非常有杀伤力的。所以零跑A05其实非常完美地践行了我们全域自研，科技普惠的理念。同时，零跑A05在国内来说，可能不是家里的唯一的一台车。但是放在全球来说，A05其实是非常主流的车型，特别是在欧洲，大家也知道A05这个级别的车型，如果有这么好的续航，这么好的智能化和空间实用性，其实是非常的有竞争力的。12、零跑A10已经在市场上建立了非常鲜明的产品认知，为什么会选择在A10之后再发布A05呢？徐军：A10的表现是超出大家的期待的，产品是非常扛打的。从竞争角度来说，实际上所有的市场机会都来自于消费者细分。刚才谈到了A10的主要的用户群体65%是男性，以家庭全能用车为主，还有相当一部分小姐姐们属于自己的一辆车。小姐姐要开车，一是要求颜值，同时能够好开，然后也能玩起来，还有智能方面，这些都是我觉得目前为止，可以有很大作为的一个空间。A05和A10可以称之为兄妹组合，是同一平台的不同战场。我们把A10的技术平移到A05，还有A05S，有更加鲜明的颜值，就像开一个移动的闺房，有独属于自己的空间。▲零跑A05S
