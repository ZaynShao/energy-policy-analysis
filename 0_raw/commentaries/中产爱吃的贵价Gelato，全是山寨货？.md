# 中产爱吃的贵价Gelato，全是山寨货？

自从进入夏天之后，全国各地的年轻人都被热得呼哧带喘。因此最近大家的生活状态，都通通回到了最原始的需求，那就是先凉快下来再说。
为了避暑消热，有人像是寻着冷空气的候鸟，飞到凉爽的东北或是蒙古避暑；有人琢磨出了邪修避暑的法子，睡觉时抱着冬瓜避暑消热。但更多的人则采用最原始的避暑方式，炫一口冰到拔牙的冰淇淋，就能让自己浑身在40度的高温里呼呼冒冷气。
但谁能想到，在今年夏天，当其他年轻人还在满大街找老式冰棍，Gelato横空出世，如毛细血管般迅速占领了城市大街小巷。
图源：玫瑰
Gelato其实就是意大利冰淇淋，这个念出来就带着意大利口音的词，正在占领一大群年轻人的胃。有人把它读吉拉头，有人把它读成哥拉头，但如果你说这不就是个冰淇淋球，Gelato信徒们则会严肃地纠正你：
“它脂肪含量更低、空气含量更少、温度更高，所以入口更顺滑、风味更浓郁，而且吃起来更健康。”
当然，它的价格也更贵，一个双球杯轻易就能卖到四五十块，抵得上一顿正餐的钱。
当你花上几十块钱的入场券，来到Gelato的冰柜前，各个口味准会让你挑花了眼。“Gelato的名字们堪比咒语，什么香蕉马斯卡彭布朗尼、波多黎各假日、澳橙木姜子、青苹果白兰地……一个口味三个名词起步，而且必须参杂酒和甜品蛋糕的名字，主打的就是一个层次感。”
之前，Gelato是妥妥的上海特产。在上海潮人云集的时髦街区乌鲁木齐街，每走上十步就能遇到三家Gelato店。但今年夏天，Gelato的开始向上海以外的各大城市进攻，甚至如今连各大茶饮品牌都开始卷Gelato了。
先是一些奶茶品牌推出了自家的Gelato，售价18块到25块钱不等一个球；紧接着连炒货店的门口，也支起了卖Gelato的冰柜；
更别提各个主打Gelato的冰淇淋店，各大商场已经被Gelato围剿。这个在国外两三欧元的冰淇淋，到了国内则摇身一变，变成了啥都能往里装的瑜伽裤甜品。
更诡异的是，吃过正统的Gelato才能明白，国内很多店都是在cosGelato，说自己卖的是意大利的海风和阳光，实则大把店铺用冷冻奶浆、预制香精，纯纯把Gelato当马甲使。
“明明并不新鲜，但披上个Gelato的名字，却转头卖给你38块一个球的价钱，最关键的是，反正你也没吃过正宗的，让人无法选中。”

中产冰淇淋被刺打工人
第一批爱上吃Gelato的年轻人们，对这个小小的冰淇淋球比意大利人还虔诚。“正统Geoato应该被放在密封的金属桶里保存，挖的时候要用扁平的刮刀而不是圆勺；开心果味的Gelato必须是浅灰色的，绿得发亮的那是加了色素；配料表必须严格，里面不能有任何的植脂末和增稠剂。”
甚至有人定论，一个城市发不发达，就看Gelato店开得多不多、好不好吃。“因为只有顾客愿意消费，才会有人好好研究Gelato的各种口味，用高成本做出好吃的冰淇淋。”
对于Gelato信徒来说，吃冰淇淋也有鄙视链。“鄙视链最顶端是家附近的社区小店，他们的口味创意更大胆，而且也更贵；下一层是高端的Gelato连锁店，它们往往会宣称自己有来自意大利的主理人，而且还能自己DIY口味配料；最朴实也最便宜的则是大连锁Gelato店，开在商场B1B2层的那种，大家也最爱吃。”
第一次出于好奇围到Gelato的冰柜面前的年轻人，保准会被它的价格所震撼到。
“以前觉得哈根达斯就是冰淇淋的价格天花板，结果吃了Gelato才发现，这玩意比哈根达斯贵多了。一个球30块，两个球50块，三个球70块，上不封顶。要是想一次性多尝几个口味，几十块钱就水灵灵地花出去了。”
图源：逍遥
很多年轻人会奇怪，都是冰淇淋，为什么Gelato就卖得这么贵？有从业者解释道，Gelato的制作需要用到鲜牛奶和鲜水果，不加一滴水，而且需要人工搅拌，且必须当天现做、不能加防腐剂。
有人说，gelato这种高端冰淇淋只存在于经济发达的地方
但是对于年轻人来说，无论Gelato的制作过程有多复杂、原料有多高端，自己能感受到的只有好不好吃。
上周第一次去买Gelato的北漂姑娘yoyo，觉得Gelato就是丝滑版的冰淇淋。“它确实很细腻，比小时候吃的三色杯、便利店冰柜里的梦龙和麦当劳的甜筒都要更丝滑，第一口确实很封神，我甚至开始想贵有贵的道理。
图源：阳光开朗大女孩
但吃到第二口时，就发现好像它也没那么神。你说它不甜吧，糖分可一点没少，你说它清爽吧，吃完嘴里又会有种黏糊感。
后来想想，我明明就是想吃口冰淇淋凉快一下，结果这一小杯Gelato下肚，温度是降了，但心里那股火气却上来了，就这么一小杯四十五块？去雪糕批发的地方都能拎一兜子回家了。”
后来她才想明白，Gelato的竞品不是冰棍，而是网红甜品。“一小盒Gelato低脂健康，也不会对身体造成什么负担，但却能解馋。比起你急头白脸去炫蛋糕奶茶，Gelato显得清爽多了。”
为什么冰淇淋越来越贵了
自从年轻人开始称Gelato为新一代雪糕刺客时，有人会质疑，嫌贵可以不买。但在Gelato开得如火如荼的当下，很多年轻人都想去凑个热闹，尝尝冰淇淋贵族到底是怎么个事儿。
上周末和朋友去逛北京合生汇的北漂jing觉得，Gelato贵有贵的道理。“它的复合口味，冰淇淋很难实现，比如青苹果和白兰地的组合，或是柚子和金酒的组合，成本确实不低，而且口味也说得过去。”
但对于大部分年轻人来说，Gelato花里胡哨的口味，也就带来了过高的溢价。有业内人士说，Gelato的普遍毛利率在70%左右。
上周去上海旅游的00后幸幸，当时看社交媒体上的攻略，说武康路一家店的Gelato是上海必吃，排队一个小时也要等。“等到终于拿到手，发完朋友圈，才感觉跟从意大利吃的一模不一样，质地更柔软，更像是麦当劳那种甜筒冰淇淋，肯定不是正宗的。”
如今，国内的Gelato都走得一样的路子，统一的金属桶、统一的刮刀、统一的圆形纸杯，就连口味名字也是同样的风格，椰香斑斓黑糖珍珠、海盐芝士巴斯克、玫瑰荔枝覆盆子……一个比一个长，一个比一个拗口，名字越复杂，能卖到的价格也越贵。
“站在柜台前，我觉得自己不像在买冰淇淋，像是在做一道填空题，从这三个名词里选出你最不认识的组合，那就是你今天要吃的味道。”
对于幸幸来说，Gelato只能起到一个氛围感的作用，根本解不了暑。“老式冰棍的配料是水加糖精加色素，简单粗暴，但目的明确，就是让你凉快下来。但Gelato像是瑜伽裤一样，什么都装得下。每一口都是精心设计的层次感和惊喜感，但吃到嘴里一点也不爽。”
第一批Gelato受害者
正在找平替
即便后来年轻人被科普说，Gelato比传统的冰淇淋少了一些脂肪，而且里面的空气含量只有20%左右，所以吃起来又丝滑又绵密。但年轻人也并不买账，“但大多数普通人哪尝得出来冰淇淋20%的空气含量和50%空气含量的区别？你瞎糊弄我也不知道，我只知道自己的钱包被狠狠割了一刀。”
在广州生活的00后小徐，说Gelato并不是什么高级货。“刚开始听说Gelato时，还兴致勃勃地去买来尝着吃，但后来吃一口就明白了，这不就是我们老广从小吃到大的炒冰？
我们这里的炒冰全都是用鲜果加鲜奶炒的，最便宜的苹果炒冰10块，最贵的山竹炒冰40块，但是能用上三斤山竹，而且用大塑料盒装，和Gelato的口感非常类似。而Gelato一个球就能卖几十块，分量还不如炒冰的十分之一。”
图源：沐金舆🍃
实际上，对于年轻人来说，夏天的消暑很简单。“小时候的夏天，一根两毛钱的冰棍就能换来一整个下午的快乐。冰棍可能是甜得发腻的香精味，可能是色素染出来的草莓红，但一口咬下去，冰碴子在嘴里嘎嘣作响，那种透心凉的爽感，是任何绵密丝滑都替代不了的。”
无论Gelato的名字们起得再高端，一个词里塞进三个世界，椰香是热带，斑斓是东南亚，黑糖珍珠是台湾夜市，你花一个球的价钱，舌头绕着地球跑了一圈。
但对于年轻人来说，吃Gelato也就是凑个热闹，花里胡哨的名字再好听，夏日消暑之神永远是一口咬下去就知道是什么味儿的冰棍，和冰镇后的国窖冰红茶。
