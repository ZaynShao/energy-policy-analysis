# 南方电网经营区域新能源单日电力电量双创新高

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/3f8yKfXErDpYxZHc3XfQCDhYFxL97zuUGTibrVEuiaPD2aj5UzcLiaYyvearkD9RvkkYu4kic8SVu9TL4loSq4XZicQ/640?wx_fmt=gif&from=appmsg)

记者从南方电网获悉，4月9日，南方电网经营区域新能源电力、电量创历史新高，最大发电出力首次突破1亿千瓦大关，单日发电量达14亿千瓦时，占当日总发电量的30%。

  

中国南方电力调度控制中心副总经理丁晓兵表示，在当前复杂多变的国际能源形势下，绿色电力正成为保障能源安全、推动高质量发展的重要力量。2026年以来，南方电网经营区域新能源发电量同比增长超20%，有效填补了传统电源供应缺口。

  

2026年一季度，南方电网西电东送电量达415亿千瓦时，较计划增加47亿千瓦时，同比增长13.3%。

  

“下一步，南方电网将持续做好新能源调控与消纳工作，持续完善区域电力市场协同机制，推动新能源全面参与电力市场化交易，以新能源高质量发展助力‘双碳’目标实现，为南方五省区经济社会高质量发展提供稳定可靠的电力安全保障。”丁晓兵说。

  

截至目前，南方区域新能源总装机规模已超2.8亿千瓦，占总电源装机比重突破40%。（来源：中国电力报  李东海、黄勇华、刘佳乐、杜旭）
