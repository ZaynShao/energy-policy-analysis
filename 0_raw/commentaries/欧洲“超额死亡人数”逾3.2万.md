# 欧洲“超额死亡人数”逾3.2万

受今夏热浪不断影响，欧洲23个国家的“超额死亡人数”已经超过3.2万人。
欧洲死亡率监测网（EuroMOMO）最新估算数据显示，受今夏热浪不断影响，欧洲23个国家的“超额死亡人数”已经超过3.2万人。
“超额死亡人数”是指特定地点和特定时期估计的总死亡人数与没有健康危机情况下的估计死亡人数之间的差额。据法新社21日援引欧洲死亡率监测网最近数月收集的数据报道，6月最后一周成为欧洲今夏“最致命一周”，其间“超额死亡人数”接近1.6万人；7月第一周则成为今夏排名第二的“夺命周”，其间“超额死亡人数”约为8000人。鉴于夏天仍未结束，欧洲“超额死亡人数”或进一步攀升。
▲7月19日，在意大利罗马，人们在街头吃冰淇淋、喝冷饮消暑。新华社记者李京摄
欧洲死亡率监测网没有按国别发布死亡情况。另据法新社统计德、法、英等8个欧洲国家发布的数据，近来高温肆虐期间这些国家超额死亡或死因与高温有关的人数共计超过3.3万人。
德国罗伯特·科赫研究所说，截至8月9日，德国约有1.4万人死于高温相关原因，打破2016年有相关数据以来的最高纪录。
法国公共卫生部门数据显示，5月末至7月22日高温肆虐期间，法国“超额死亡人数”为7300人。6月22日至28日的一周，法国遭遇近80年来的最高气温，其间法国电子死亡证明系统记录到2025例全因超额死亡。全因指不区分具体死因，涵盖所有死亡病例。
西班牙卡洛斯三世健康研究所数据显示，6月1日至8月19日，西班牙将近4500人的死亡与高温有关，创2022年以来同期最高纪录。另据西班牙国家气象局数据，该国7月气温“追平”2022年7月，是1961年开始相关记录以来西班牙本土最热月份。
▲7月10日，在意大利罗马，游客在万神殿附近用手持风扇降温。新华社记者王楷焱摄
英国卫生部门说，5月至6月英国关联高温的死亡人数达2877人，今夏可能打破2022年夏天高温致死2985人的纪录，且关联高温的死亡人数或显著高于其他年份。
比利时国家公共卫生研究所数据显示，6月18日至7月17日该国“超额死亡人数”为2570人。值得注意的是，比利时8月中旬遭遇该国有记录以来规模最大的野火，过火面积至少3000公顷，或推高相关死亡数据。
据荷兰国家公共卫生与环境研究所数据，荷兰6月22日至7月5日“超额死亡人数”为968人；奥地利卫生与食品安全局数据则显示，该国6月关联高温的死亡人数为396人。另据葡萄牙卫生部门数据，6月中旬至7月末该国“超额死亡人数”超过600人。
