# 超6GWh订单，矿区微电网储能“上桌”

2026年上半年，又一个储能细分市场悄然爆发。
据高工产研（GGII）不完全统计，2026H1已披露的矿区微电网储能订单总规模超6GWh。
其中铜矿项目占比较高，分布在非洲、拉美、澳洲等矿业资源丰富、距离主网较远或电网条件受限的地区。
该类项目对离网功率支撑规模存在一定要求，具备已落地、可验证案例的企业更具竞争力，如阳光电源、中国能建、比亚迪储能、苏美达能源等企业。
随着一个个订单的接连落地，矿区微电网储能正从边缘走向舞台中央。
矿区和工业园区，微电网两大典型场景
微电网由分布式电源、储能、负荷及智能控制系统构成，其核心在于并网与孤岛双模式运行——正常工况下可与主电网双向交换电能，当外部电网故障或供电受限时，切换至孤岛运行，保障关键负荷连续供电。
其中，储能系统既承担能量时移功能，也是实现并离网平稳切换、黑启动、稳频稳压及新能源消纳的核心调节资源。
微电网储能需求主要分布于三种场景：1）电网覆盖不足或供电基础设施薄弱；2）负荷突增突降、功率波动明显；3）对供电连续性和电能质量要求高。
需求地区涵盖美国、欧洲、澳大利亚、非洲（埃塞俄比亚、刚果金、南非）、东南亚（菲律宾、马来西亚、印度尼西亚）、拉美（智利）以及马尔代夫为代表的海岛国家。
上述三类需求，在终端侧主要体现为偏远地区（海岛/矿区）、工业园区、数据中心等典型应用。
GGII分析认为，不同场景对储能系统的选型要求差异显著：
第一类场景是矿区，环境严苛，需重点关注高温、沙尘、盐雾耐受性及运输振动与弱电网适应能力，电池舱、PCS及控制系统须具备宽温域工作、消防联动与构网型支撑功能；海岛工况则对IP防护、防凝露、防腐及热管理冗余提出更高要求。
工业园区通常对应第二类场景，负荷波动频繁且峰谷差大，应结合温度条件及运行策略评估系统级寿命，并依据项目预期循环次数与全周期收益综合考量。数据中心则为第三类场景，选型重点关注响应速度、可靠性及与UPS和备用电源的协同能力。
其中，矿区项目通常具有容量大、负荷刚性强等特征，也是微电网储能较早实现规模化应用的领域。需求由早期“柴油机+储能”的保供模式，逐步转向风光储柴协同运行的高比例新能源微电网。
上半年超6GWh订单，以铜矿项目为主
据高工产研（GGII）不完全统计，2026H1在已披露的矿区微电网储能订单中，总规模超6GWh。订单以百MWh级大型项目为主，包括刚果金、智利、澳洲等地区的多个铜矿项目。

从投资及融资安排看，不同项目的建设逻辑亦存在差异。
矿区及发达国家工业园区项目通常由矿企、园区运营方或其他项目发起主体自行投资，更关注供电可靠性、综合用能成本和项目回收周期；
而亚非拉部分兼具能源可及性与基础设施建设属性的项目，则可能获得国际组织、开发性金融机构或援助计划的支持，项目推进也更易受到融资安排、招标规则和当地基础设施规划的影响。
除以偏远矿区稳定供电为核心的矿区微电网外，随着矿卡等设备电动化推进，围绕高功率充电建设的场站微电网成为矿区能源系统的新应用方向。该类场景侧重于在既有配电容量受限的条件下，协调充电桩、储能、分布式电源与场站负荷，保障集中充电时的功率供给，并降低配电扩容和高峰用电成本。
2026年4月，万帮数字能源与启源芯动力达成合作，聚焦海内外矿区电动化项目及场站微电网建设。万帮数字能源可依托启源芯动力在国内外矿区项目中的布局切入该场景，并结合其在充电设备、充电站运营及数字化平台调度方面的积累，开展储能充放电及充电功率调度，形成面向矿区车辆运营的“车—桩—站”协同管理能力。
基于全栈自研的“光伏+储能并离网无缝切换智慧微电网系统”，目前星星充电（万帮数字能源）已在全球落地300余个微电网项目。
以偏远矿区供电为代表的离网微电网项目对黑启动、构网支撑和高比例新能源消纳提出了更高要求，这些需求正在推动储能产品架构从单一电池舱＋PCS，向直流耦合光储一体机等集成化产品形态演进。
在交流耦合架构下，黑启动初期若未建立稳定交流母线，跟网型光伏逆变器无法启动，光伏难以接入；直流耦合则保留了光伏直充电池的路径，减少部分变流环节。
因此，在孤岛运行时间较长、光伏占比较高、黑启动要求较强的项目中，直流耦合通常具有更好的效率、控制一致性和工程适配性。
