# 综研观察｜胡振宇：从平陆运河到图们江：打开中国大西南与大北方出海口

打开中国版图，一南一北，一河一江格外引人注目。
西南方向，西江与北部湾之间，一条140公里长的人工运河正在日夜延伸，要把大西南腹地的货物，从绕道上千公里的原有路径解放出来，直插南海、连通东南亚。
东北方向，吉林省与日本海之间，只剩一道窄窄的图们江口，距大海仅15公里，而这一道窄口，又被一座低矮的界河桥横亘——新修的俄朝公路桥，据说比老铁路桥还低。
一北一南两个“出海口”，一个由通到堵，一个由堵到通，折射出国力兴衰和向海变迁。
平陆运河，山海互济大西南
1. 一条迟来之河，被孙中山写入《建国方略》
//平陆运河全线通水（新华社发 赵振宇摄）
广西的尴尬，全中国都看得懂：坐拥全国名列前茅的海岸线，西江浩汤穿行，可大宗货物偏偏运不出"家门口"的海，问题出在"江海不通"。
西江是珠江水系，天然通的是珠三角方向，而广西自己的北部湾，却被地势阻隔，与内河水网"老死不相往来"。于是几千万吨的广西货，只能绕道上千公里走珠三角——“广西货不走广西港”，成了西南经济圈多年解不开的心结。
有意思的是，平陆运河的构想，早在百年前就已写进孙中山的《建国方略》，它是我国自京杭大运河后千年来决定开凿的第一条运河。2021年，它被列入《国家综合立体交通网规划纲要》，国家"十四五"现代综合交通运输体系发展规划亦明确提出研究建设——一场跨越百年的"向海之约"终于梦想成真。
2. 一场“货运革命”，大西南“入海”缩短行程千里
平陆运河始于南宁横州市西津库区平塘江口，经钦州灵山县陆屋镇沿钦江进入北部湾，全长约140公里，按内河Ⅰ级航道（可通3000吨级船舶）标准建设，静态总投资约680亿元，以航运为主，兼顾供水、灌溉、防洪、改善水生态等功能，不仅是一条河，更是一台重塑西南物流版图的发动机。
运河一旦打通，西南货物出海的内河航程将直接缩短560公里以上。水运是能耗最低、成本最省的运输方式，当大宗货物从高耗能的公路铁路转上水路，每一块钱都是实打实省下来的。
3. 一次成长洗礼，打造万亿级运河经济带
平陆运河真正的高明之处，在于它不只是一条"运货的河"，而是一条"产业之河"，将催生万亿级运河经济带，带动广西及西南经济腾飞。
从空间布局看，平陆运河贯穿南宁、钦州、防城港等广西核心城市，连通北部湾经济区、成渝经济区与粤港澳大湾区，将形成“东盟—北部湾—成渝—粤港澳”跨境跨区域产业链供应链，成为国内国际双循环战略链接的枢纽，其经济带核心区涵盖南宁、钦州、北海、防城港、贵港5个设区市。沿运河将重点发展临港工业、现代物流、国际贸易、文旅康养等产业。
从第一产业看，灵山荔枝、浦北陈皮、三娘湾海洋牧场等特色产业集群因运河灌溉与物流受益。第二产业上，运河建设带动船舶制造、能源需求，未来将向石化、新能源、新材料产业链延伸。第三产业上，内河运输业成为新增长极，带动船舶咨询、金融、物流、文旅等服务业。
南宁将强化首府能级，打造内陆开放型经济高地。钦州定位以集装箱中转为主的区域性国际航运中心。北海、防城港、贵港则分别依托旅游、港口物流各展所长。一条“河带产、产促港、港富城”的现代化滨河经济带正在生长。
4. 一座绿智丰碑，服务国家双碳战略
平陆运河的另一半竞争力，在“智”与“绿”，是全生命周期数字孪生智慧运河，北斗、云计算、大模型纷纷上船，智慧调度贯穿始终，而水路运输天然的低碳属性，叠加清洁能源船舶推广，让运河将成为服务“双碳”目标的国家名片。
图们江，苍龙归海待何时？
如果说平陆运河是“希望之河”，那么图们江出海口，就是一部写了近百年的“困局档案”。
//（图片来自吉林省自然资源厅）
1. 被“封住”的出海口
今天的吉林省是一个彻头彻尾的内陆省份，但很少有人记得它曾经是沿海省份。
1860年《中俄北京条约》将乌苏里江以东40多万平方公里土地割让给沙俄，沙俄由此侵占东北东部沿海，中国丧失了图们江出海口，吉林仅剩珲春一带可望出海。
转折点出现在晚清一位读书人身上——吴大澂。1885至1886年，这位清代官员、金石学家亲赴中俄边境，主持重勘边界。他据理力争，提出图们江出海权应为中俄公共海口，“由土字牌至图们江口三十里与朝鲜连界之江面海口，中国有船只出入，不得拦阻”。1886年9月18日，俄外交部回复同意图们江为中俄公共海口，中国船只可自由出入。据此签订的《中俄珲春东界约》（1886年10月12日），让中国收回了黑顶子、补立了界碑，也争得了图们江出海权。但这份“近代主权”胜利并不完整——俄方拒绝设立乌字碑，吴大澂没能把已失去的海岸线进一步“索回”。
1938年夏，日苏两国在防川的张鼓峰爆发军事冲突。日本为试探苏联远东军事力量、同时妄图扩张远东势力范围，制造了此次冲突最终以失败告终。张鼓峰本属中国（当时被划入伪满洲国），可在苏日两强的争夺中，中国被彻底忽视，成为这场战争的最大受害者。战役结束后，日军为阻止苏军渡江，在防川附近的图们江上立桩堵江、封锁航道，撤退时更在图们江上打了不少石桩、堵塞河道。日军还把防川周边所有村民强行迁走，使这里沦为无人区，并把防川划为禁区，当地学者记载："从此，中国利用图们江航道的出海活动被迫终止"，当地民谣曰："图们江水奔海去，土字牌前无归途"，我国在日本海的唯一出海口由此封闭。
2. 被“锁住”的出海口
1950年朝鲜战争期间，苏联在图们江口修建铁路桥，因桥身低矮，中国船只根本无法通行。之后的七十多年里，靠着这道"低门槛"，东北的出海梦止步于离日本海仅十几公里的地方。
变化似乎出现在2025年，当年2月，俄罗斯委托建筑企业设计建造跨越图们江的俄朝公路桥，预计2026至2027年间建成，舆论一度燃起希望——普京2024年访华时曾承诺与中国东北在出海口方面展开合作。
然而，希望很快破灭。据多家媒体报道，这座新公路桥的高度很可能与旧桥相仿甚至更低，形成俄朝“双桥锁江”局面，无论新桥是7米高还是10米高，都不足以让大型货船通过。
3. 技术账与政治账：为什么"低桥"挡得住万吨轮
有人说，图们江本来就水浅、货运量小，通不了大船，不必介意。这话只对了一半。
技术上并非无路可走——图们江下游地势平坦，从珲春防川至出海口，完全可以通过清淤疏浚、把航道挖深到10至15米来实现万吨级货轮通航。至于让航道保持恰当水深是否可行，中俄近年来也在界河通航技术上持续磨合——如交通运输部2025年发布的《中俄界河通航标准（中方）》即界定了航道分级与通航尺度。
既然技术上可行，为什么迟迟不通？答案，藏在地缘政治的账本里，不在河道里。
大时空视角下的“大图们江”
要看懂图们江困局，就要回到三十多年前那项雄心勃勃的计划。
1. 曾经近在咫尺
上世纪九十年代初，世界曾给东北亚开过一扇窗。1991年，中国与苏联签订《中苏国界东段协定》，苏联同意中国船只沿图们江通海往返航行。随后，联合国开发计划署抛出了更为宏大的设想——投资300亿美元，把图们江下游建成多国合作的经济开发区。那一刻，东北的出海梦几乎伸手可及。可惜，窗口开得短，关得也快。
2. 为何梦碎？
大图们江开发计划最终不了了之，原因既离奇又现实。
一是苏联解体与地缘格局的崩塌，支撑图们江开发的国际框架，一夜之间土崩瓦解，这个"前所未有的大协作"设想，从一开始就失去了最坚固的基石。
二是朝鲜“急刹车”，上世纪九十年代中后期，朝鲜对市场化开放态度趋于保守，叠加朝核问题与半岛局势持续紧张，朝鲜对图们江开发的兴趣一路下滑，已规划项目一再搁置。
三是俄罗斯的“大国自尊”，俄罗斯大国复兴意识强烈，不甘心在图们江区域合作中当配角，更不愿别国成为主导，认定海参崴、纳霍德卡、东方港三港吞吐量已够用，再去开发扎鲁比诺港“完全没有必要”——图们江对俄罗斯而言，“没需求、没必要、没动力”。
四是日韩态度转变。这场由中、蒙、朝、韩、俄构成的五方博弈（日本作为观察员）中，韩国早期投入了极大热情，甚至提供了前期规划资金，但因朝核危机与半岛局势反反复复，再加上1997年亚洲金融风暴冲击，日韩最终转向观望与冷漠。
“大图们江”这扇窗在二十多年前就被缓缓合上了。
3. 通道经济学的残酷真相
图们江的失败，不是地理的失败，而是政治算术的失败。一条跨国出海通道要通航，需要的不仅是修桥挖河，更需要多方在利益、安全、主导权上达成精妙平衡。当朝鲜想要安全、俄罗斯想要主导、日韩选择观望、中国渴望出海这四股力量各怀心思时，一条本可共荣的通道，就又被搁置起来。
北极航道，东北亚棋盘的世纪变量
但历史没有终点，旧的困局尚未解开，一个全新的时代变量——北极航道——正在悄然改写整个格局，也让图们江“死局”有了翻盘的可能。
1. 必要性——北极航道的分量，正被一场又一场危机推高
东北航道是连接东北亚与西欧的最短海上航线——相比传统航线，航程可缩短约8000公里，节省时间10至15天，燃油成本降低约40%。以航运大动脉上最常见的航线为例，从上海至欧洲西部，走北极可缩短航程25%至55%，每年节省的运输成本以数百亿美元计。在传统海运咽喉要道频繁受扰、安全风险上升的今天，这条航道的开通无异于又一次“凿空西域”。
更现实的推力来自中俄合作。中俄合力推进的“冰上丝绸之路”已不止停留在构想——“亚马尔项目”正式投产，开辟北极航道助推“冰上丝绸之路”，中俄"冰上丝绸之路"北极航线也已实现首航，通过“中转枢纽＋冰上集运＋陆海转换”功能叠加，增强了国际供应链安全。
事实表明，这条冰海大动脉，正在从设想走向常态化运行。
2. 可行性——冰雪消融，技术成熟
自然条件上，全球变暖导致北极冰层减少，使北冰洋夏季可航行，冬季也能在部分航段保持通航；装备条件上，中国已具备破冰船能力，可保障航道安全；运营条件上，高冰级集装箱船舶、Arc7级（船级社冰区加强等级中的最高级别）船舶正在加紧建造，让航线运营更专业高效。
当然，北极航道并非坦途——仍面临航行资料不足、浮冰隐患、补给点少、需依赖俄罗斯破冰服务等挑战。但在“必要性”和“可行性”已同时具备的时代，它足以让东北亚棋局重新洗牌。
3. 落点——图们江、珲春与“北极航道东方入口”
视线拉回当下，图们江入海口，是中国距离北极东北航道最近的点。一旦北极东北航道常态化通航，图们江区域的战略价值将被彻底重估——它不再是那条“运不了货的小河”，而可能成为连接北冰洋与中国腹地的战略通道、中国北极战略的“观察哨”与“跳板”。
而这出戏的主角，很可能是珲春，这个长期被称为“中国距离日本海最近的城市”、位于中朝俄三国交界的东北亚门户，日本海近在咫尺，下海却寸步难行。珲春并非没有作为——早在2018年，“珲春—扎鲁比诺港—宁波舟山港”内贸跨境运输航线即已通航，“800海里海陆联运航线”规划也把珲春与俄罗斯、韩国、日本的港口连成一线。这些尝试，都印证着珲春作为东北亚物流枢纽的潜质。
而在更长远的剧本里，珲春乃至北方港口还有一个更“绿色”的想象：当北极航运遇上“双碳”热潮，给航行北极的船只提供清洁能源（氢能、绿电）加注，打造一座“北极绿色航运燃料加注港”（挪威政府已投资建设此类加注站）。
这些构想目前还停留在呼声与规划层面。
向南东南亚，向北东北亚
登高望远，再看这一河一江，你会发现，它们正在蓄积杠杆的力量。
1. 向南：直入东南亚的黄金水道
平陆运河的终点，不只是北部湾，而是整个东南亚，它是中国西部通往东盟的捷径，把西南腹地与大湄公河次区域、东南亚十国的庞大市场，用一条最省的水路缝合起来，将形成“东盟—北部湾—成渝—粤港澳”的跨境产业链供应链，让大西南从“地理末梢”翻身成为“对东盟开放新前沿”。当前，东盟稳居中国最大贸易伙伴、RCEP红利持续释放，这条河就是把“中国制造”与“东盟市场”更紧密连接在一起的经济纽带。
2. 向北：撬动东北亚的世纪变量
而图们江指向的，是东北亚——一个集中了中、俄、日、韩、朝、蒙的复杂棋盘。九十年来，这片海域的门始终没能真正打开，北极航道的冰川逐年消融，地缘棋局在重新洗牌。一旦北极东北航道常态化，图们江、珲春的价值将被彻底重估——它们可能从“东北的遗憾”变成“中国在东北亚的一把钥匙”。
