# “白海豚”将提前登陆，登陆后北上，残涡或致京津冀暴雨，今年第16号台风“琵鹭”生成

今年第13号台风“白海豚”将于今天傍晚前后在玉环到温岭一带沿海登陆。
据@央视新闻 消息，今年第13号台风“白海豚”将于今天傍晚前后在玉环到温岭一带沿海登陆（台风级或强台风级，12—14级）。登陆后“白海豚”向西偏北方向移动。今明两天，浙江、福建、上海、安徽、江苏等多地有大到暴雨，浙江中东部部分地区有特大暴雨，沿海局地阵风可达13至16级。
▲图源：@上海市天气
中央气象台8月9日10时发布台风红色预警。未来三天，受台风“白海豚”影响，浙江、上海、福建北部、江西北部、江苏、安徽、湖北东部、河南中东部、山东南部、河北南部等地有暴雨到大暴雨，局地有特大暴雨，部分地区并伴有雷暴大风等强对流天气。
台风“白海豚”登陆后将深入内陆北上，京津冀地区的降雨到底会有多强？对此疑问，中央气象台首席预报员进行了解答。
中央气象台首席预报员方翀介绍，从目前来看，预计11日至12日，台风“白海豚”残涡北上，如果在河南、湖北和安徽等地的交界处附近滞留，后期会给京津冀带来比较明显的降水。“预计河北中南部、北京、天津等地都会有暴雨，部分地区大暴雨，局地像河北南部可能还会有特大暴雨。”
至于“白海豚”给北京带来的降雨强度是否会达到2023年台风“杜苏芮”那般？方翀表示，目前来看，8月13日之后整个天气形势还不太稳定，不确定性较大，是否会达到台风“杜苏芮”的强度，还需要后续持续关注，中央气象台也将密切关注天气形势的变化。
北京下周有多轮降雨
未来一周，北京将迎来多轮降雨天气，大家出行需随时关注天气变化，提前做好防范。
具体来看，明天夜间云量增多，并有分散性雷阵雨出现，8月11日至下周末，受台风“白海豚”残涡影响，北京将可能出现多次较强降雨天气，且降雨呈逐渐增强趋势。其中，11日降雨较前期有所加强，12日起雨势进一步增大，对交通出行将有明显影响。
强降雨叠加前期降水，山区及浅山区发生山洪、滑坡、崩塌、泥石流等地质灾害的风险高，请尽量避免前往山区、河道、地质灾害隐患区域活动。由于台风“白海豚”的移动路径和强度变化仍存在不确定性，后续降水落区和强度可能有所调整，请持续关注临近预报预警信息，提前做好防范应对准备。
气温方面也是起伏多变，10日至11日，京城气温将再度反弹回升，白天最高气温可达33℃至34℃，同时空气湿度显著增大，高温高湿叠加，闷热感拉满，典型的三伏天桑拿天气再度来袭。大家在防范降雨的同时，千万不能忽视防暑降温。
好在持续降雨会有效带走燥热、降温解暑，从13日开始，京城气温迎来明显回落，白天最高气温将降至30℃以下，闷热体感大幅缓解，天气变得凉爽舒适不少，整体体感更加宜人。
今年第16号台风“琵鹭”生成 将向偏东方向移动强度缓慢增强
据中央气象台消息，今年第16号台风“琵鹭”（热带风暴级；英文名称：PEILOU）已于8月9日在西北太平洋洋面上生成，14时其中心位于关岛塞班北偏西方向约740公里的西北太平洋洋面上，就是北纬21.2度、东经142.6度， 中心附近最大风力有8级，18米/秒（约65公里/小时），中心最低气压为998百帕。预计，“琵鹭”将以每小时25—30公里的速度向偏东方向移动，强度缓慢增强。
