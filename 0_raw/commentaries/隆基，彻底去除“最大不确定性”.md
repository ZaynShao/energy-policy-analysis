# 隆基，彻底去除“最大不确定性”

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/bhqZZ4eZhItgLjmAtSqOmL3Rgraw1eXBogQzdvu6I0K92s2TNhLh3LzicLGzwnvVq26vMLBhE9AicmknmyoVKXLib4vjg1kXz7Py7icsv6xQzb4/640?wx_fmt=jpeg&from=appmsg)

全栈隆基将结束光储的拼凑时代。

在光伏多个周期中吃尽红利的隆基，究竟要在哪条赛道再次“重注”？一直是产业界和资本最为关注的话题。

复盘隆基绿能近几年来的发展，“坚定看好”的BC技术路线正在成为光伏的主流，出货量不断攀升，但这也在一定程度上延续了隆基绿能的光伏发展红利。以2025年为例，隆基绿能正是以HPBC2.0技术为核心塑造出差异化竞争优势，并凭借长期积累的领先产品、全球化渠道和品牌优势，在光伏组件领域市占率维持领先。

但这种“创新+规模化”光伏逻辑的潜在压力依旧明显：

从全球光伏产业的发展上，无论是现在的TOPCon还是正登上主流舞台的BC技术，未来很大可能依旧走上规模化制胜的高增长低利润之路。

而已经“优化收缩”的氢能业务在很长一段时间里依旧无法看到大规模落地的征兆。

继续寻找新的“增长曲线”就成为了必然的选择。

隆基绿能近两年的各种新动作越来越多，除了继续加大光伏本身的技术研发之外，子公司整合、参股公司的股权交易调整；并购精控能源，以此为基础打造以全栈隆基为核心的光储深度融合新业务，并将其推向全球市场。

这些新方向各有特点，但光储融合已然成为当下隆基新增长曲线中落地速度最快同时也是未来最具希望的一个。

“隆基结合在全球120个国家的光伏营销与服务网络，以及精控过去积累的全球交付经验，正式启动‘2830规划’，计划在2028年年底之前，在全球主要光储一体化市场构建30个全能型本地服务中心。”隆基绿能副总裁佘海峰在接受高工储能等采访时表示。

根据行业人士保守估算，叠加此前并购精控能源的投入，隆基启动的这一轮光储融合新战略业务，总体投入或将是百亿级别。

如此大手笔的投入，也体现了隆基在并购精控能源后对于这一业务的明确态度，“必须成功”。

也在很大程度上也意味着，隆基正在走进自己的新时期。  
  

****隆基为何“重注”光储融合？****  
  
  

隆基的光储融合“梦”早在2018年就初见征兆。

在当年举行的第二十四届联合国气候变化大会上，隆基创始人李振国就公开表示，“光伏+储能”会在10年之内成为主力能源。

而此次正式发布的“全栈隆基 LONGi ONE”光储融合战略及全场景光储一体化解决方案，充分展现了隆基对于光储融合的决心和信心。

从产业特性看，光储融合具备一系列场景、用户方面的好处：场景融合更多元化、深度融合后综合成本更低、客户渠道的匹配度高、对电网的友好支撑。

但本质上推动隆基大投入“押注”光储融合业务的，仍是明确的利益——做光储融合，能够打破隆基当下在光伏下行周期的 “桎梏”。

相比单纯的光伏业务，做光储融合实际上是能源转型进入下半场的“综合服务”。一方面，光储的深度融合能够将当下客户的综合解决方案成本极致摊薄，另一方面，新的广阔赛道也能创造出更大的收益。

虽然逻辑清晰可见，市场空间足够可观，但纵观当下行业纷杂的“光储融合”声量，言者虽多，但真正大规模投入，有着清晰底层逻辑和庞大战略规划者却寥寥无几，往往是雷声大雨点小更有甚者只是炒作概念。

最核心的问题在于大部分企业在光伏和储能两个领域的技术底蕴、创新投入和行业地位不足以支撑起光储融合的巨大体量。

而隆基则不然，其选择“豪赌”光储融合”关键原因主要有两点：一是隆基在光伏行业中的话语权够大；二是并购精控能源后，隆基显然已经具备了运营完整光储生态的能力，在客户资源、产能供给、技术产品配套等方面可以说在整个行业中暂时无人可以匹敌。

拿隆基以前最为“弱势”的储能部分来说，并购精控能源无疑补上了最大的短板。

目前精控能源在全球已经拥有31GWh自有产能，并已经实现13GWh以上的全球储能并网量。同时，精控能源全栈自研的储能“5S”系统，独特的BMS、iCCS产品设计以及多元化的场景解决方案都是隆基所迫切需要的。

在佘海峰看来，隆基+精控就等于三分之一的全球光伏市占率、13GWh+的储能交付底蕴、30000+全球能源客户、13年储能技术发展历史等的“集合体”。 

此外，隆基自身的生态体系也能延展到光储融合业务中。

而这也正是隆基“押注”光储融合的底气所在。

正如佘海峰所说，“彼此的互补性很强。”

高工储能在4月1日举行的“全栈隆基 LONGi ONE”光储融合战略发布会现场从众多行业人士处得到的看法也基本相同：隆基光储融合的战略能够取得成功，行业也需要隆基能够跑通这一新的赛道模式，为行业树立起一个可供参考的典型样本。  
  

****隆基光储融合“独门秘笈”****  
  
  

最关键的是，隆基精准地锚定了目前市场上光储融合的巨大痛点，同时给出了自己的产品最优解和“单一责任主体”承诺。

在隆基看来，光储市场长期存在着一个巨大的痛点始终未曾得到解决，即当下诸多光储一体化电站项目中光伏产品和储能产品来自不同品牌厂商，从而导致了系统损耗叠加、联调低效、责任模糊，这种系统“割裂”的损失最后都要由客户买单。

事实上，这种痛点已经由来已久。

此前，高工储能在与光储一体化电站项目方交流时就曾多次听到由于光储不同厂商产品带来的初期安装调试问题频出，调试周期过长，运行过程中两者协调效率低下、后期运维过程中出现问题难以追溯原因等。

而 “全栈隆基 LONGi ONE”光储融合战略的独特性就在于通过全栈自研的原生融合技术，以同一品牌打造全球效率与安全标杆的“阳光发电机”，从而彻底打破光储系统的孤岛效应，为全球客户提供统一、高效、安全的绿电解决方案与资产保障。

更为关键的是，选择隆基光储一体化解决方案，将彻底根除当下市场上由于多供应商并行导致责任边界模糊的关键问题。

“从光伏组件到储能系统，从硬件交付到全生命周期运维，客户只需对接隆基，即可获得从发电、储电到用电的全链条保障。统一的技术标准、统一的售后体系、统一的责任担当，让系统运行中的任何环节问题都能得到清晰溯源与快速响应，不再有推诿的空间，不再有责任的盲区。”佘海峰强调，隆基光储融合的“单一责任主体”就代表着未来不管是光伏还是储能产品的问题，都将由隆基全权负责。

这从根本上精准直击光储市场长期存在的痛点，不仅提升了效率，降低了系统的损耗，同时也为光储融合市场未来运维树立了典范。

“光储原生融合的核心就是光储耦合之后在技术上能够做到1+1>2。”佘海峰在发布会上表示，“全栈隆基”从底层逻辑重构光储关系，实现了从高效BC技术到储能全系统5S的原生融合，以One System、One Platform、One Responsibility为底座，正式推出覆盖了从大型电站到工商业园区的全场景光储产品矩阵。

此次发布会上，隆基也正式推出了大型储能旗舰产品OneBank 2.0、电站级的“积木式”交直流一体仓OneMatrix 2.0和工商业场景的智慧绿电方案Hi-MO One + EnergyOne等产品解决方案。

“全栈隆基将结束光储的拼凑时代。”在佘海峰看来，隆基希望打造的，是在一个系统里，实现光储一体化全部软硬件交付，客户端的功能、项目前期的规划，再到整个生命周期的运维，提供一站式服务和承担责任。  
  

****“2830规划”背后的隆基“野望”****  
  
  

战略已经划定，产品准备就绪，隆基光储融合正走在加速路上。

据佘海峰介绍，隆基结合在全球120个国家的光伏营销与服务网络，以及精控能源过去积累的全球交付经验，正式启动“2830规划”，计划在2028年年底之前，在全球主要光储一体化市场构建30个全能型本地服务中心。

“隆基要承担‘单一责任主体’所有的服务责任，网点布局就非常关键。”

30个全能型本地服务中心再叠加此前隆基和精控在全球已有的网点将构建成隆基光储全球化跃升的关键拼图。

“海外项目除了技术产品外，最为看重的就是服务。”此前有多家在海外深耕多年的储能企业就曾表示。

隆基的全球化网点就意味着，不管是从售前的技术沟通到客户交付，乃至于光储产品整个生命周期的服务管理，隆基都将比一般的企业更快速，更高效。

在品牌方面，未来在全球范围内都将统一“隆基”品牌，从而强化品牌效应，减少资源渠道内耗。

此外，佘海峰告诉高工储能，未来隆基将加大研发创新的力度和投入，涵盖了储能BMS、PCS的自主研发，以及按照灯塔工厂标准建设的新型储能工厂等。

佘海峰的判断是，未来储能市场60%可能是与光伏结合在一起。

隆基光储融合要做的就是紧紧抓住这60%，怀着“长跑”的心态，才有望看到终点。
