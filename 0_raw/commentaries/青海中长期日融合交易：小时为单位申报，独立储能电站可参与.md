# 青海中长期日融合交易：小时为单位申报，独立储能电站可参与

「储能与电力市场」获悉，7月1日，青海省能源局印发《青海电力中长期市场日融合交易工作方案》的通知。通知表示，为促进中长期市场与现货市场有效衔接和协同运行，特制定本方案。方案自2026年7月1日起执行，日融合交易进入季度结算试运行，结算试运行结束后，若无重大问题，直接转正式运行。
建立经营主体“自主挂牌、自由申报、即时成交”的滚动撮合交易方式，实现中长期市场连续运营。以小时为单位申报，各时段分别独立申报量、价、买方或卖方，形成分时段交易成交结果。
 
独立储能电站可参与电能量交易。充电时作为电力用户参与交易，按照电力用户进行结算，买入电量增加自身合同持仓量，卖出电量减少自身合同持仓量。放电时作为发电企业参与交易，按照发电企业进行结算，卖出电量增加自身持仓量，买入电量减少自身合同持仓量。
买方单元：可以是有剩余购电需求的电力用户、售电公司和新型经营主体（买入代表合同的增持），也可以是已签订合同，并有回购、调减需求的发电企业、独立储能（放电）等新型经营主体（买入代表合同的减持）；
卖方单元：可以是有剩余发电能力的发电企业、独立储能（放电）（卖出代表合同的增持），也可以是已签订合同，并有回购、调减需求的电力用户、售电公司和独立储能（充电）等新型经营主体（卖出代表合同的减持）。
融合交易按自然日连续组织，期间每日10:00-15:00进行交易申报，可申报D日至月底分时段电量，每日18:00前形成最终交易结果。现阶段，融合交易成交结果暂不经调度机构安全校核，交易出清结果即为正式结算依据。交易平台按照“价格优先、时间优先”的原则滚动撮合成交。现阶段，绿电交易合同电量暂不纳入融合交易范畴。小时级绿电交易单独组织，第一优先级结算。方案表示，当出现重大电源或电网故障，影响电力有序供应或电力系统安全运行时，市场运营机构应按照安全第一的原则，必要时可以中止中长期交易。在运行监测过程中，当发现有明显严重亏损风险的经营主体，运营机构应采取预警机制，并汇报国家能源局西北监管局、青海省发展和改革委员会、青海省能源局。当市场结算价格整体出现较大波动，偏离同期水平30%以上时，汇报国家能源局西北监管局、青海省发展和改革委员会、青海省能源局，启动相关调控措施。
