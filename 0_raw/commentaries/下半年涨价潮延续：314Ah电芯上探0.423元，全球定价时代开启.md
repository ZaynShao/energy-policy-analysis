# 下半年涨价潮延续：314Ah电芯上探0.423元，全球定价时代开启

8月1日，宁德时代商城314Ah电芯的价格，“悄悄”从之前的0.414元/Wh上涨到了0.423元/Wh。如果单看这个数字，涨幅并不明显，仅为0.009元/Wh，但这是在314Ah储能电芯已经持续涨价一年多的基础上，再度上涨。按照此前市场预计，今年下半年随着500Ah+电芯产能释放，314Ah电芯价格可能会有所回落，但实际情况是，下半年314Ah电芯不仅没有迎来下游市场期待的降价，反而继续上涨。7月以来，从电芯、材料到PCS、系统集成、光储充设备，多家企业陆续发布调价通知，涨价范围正在沿着产业链上下游扩散。从材料到电芯到PCS和系统集成，整个储能产业链都在涨价。随着“金九银十”及年底抢装潮的来临，储能产业链正在进入新一轮价格重估。314Ah储能电芯均价从2025年初的0.28元/Wh，上涨到2026年中约0.38元/Wh，此前，储能电芯涨价的最核心的原因在于产能供给跟不上需求增长，而现在涨价的驱动因素，更多是叠加了税费政策和上游材料成本。2026年7月17日，财政部、海关总署、税务总局联合发布《关于调整部分电池消费税政策的公告》，液态锂电池消费税将会逐步恢复到4%，其中2026年9月1日恢复到2%，2027年9月1日恢复到4%，固态锂电池和钠离子电池继续延后不缴纳消费税。政策一出，亿纬锂能率先发布调价通知，自2026年9月1日起，公司所有内销电池产品在原价基础上加收2%的消费税；出口产品先征后退，内外销同价。逾期未开票的订单，或需在2026年9月1日及以后开票的订单，以及已签未交付的框架订单，一概适用新价格。8月，宁德时代商城也将314Ah电芯价格上调0.009元/Wh，达到0.423元/Wh。按当前主流314Ah储能电芯0.4元/Wh的价格估算，2%税率下单位成本增加约0.008元/Wh。此外，储能电池出口退税政策退坡也进一步推动年底前抢出货。1月9日，国家财政部、国家税务总局联合发布了锂电池出口退税政策调整，自2026年4月1日起，相关电池产品出口的增值税退税率，将由原来的9%下调至6%，自2027年1月1日起，相关电池产品出口的增值税，将不再享有退税优惠。此前高工储能曾分析，电池出口退税下调3个百分点，大约对应0.01元/Wh的成本差异，9%的退税优惠彻底取消，电池成本将提升0.03元/Wh。除了政策和供需，储能电芯价格很大程度上受上游材料影响。上半年，碳酸锂价格从5月份短暂触及20万元/吨后，目前已经回落到15万元以内，但随着“金九银十”及年底抢装潮的来临，碳酸锂价格有可能重回上涨通道。根据高工产研(GGII)预测，20206年下半年碳酸锂价格大概会在15-18万元/吨，也有部分机构预测，下半年碳酸锂价格甚至可能再次触及20万元/吨。并且，除了碳酸锂，铁锂材料、负极材料、电解液、湿法基膜、铜箔加工费等等上游材料端都将面临涨价。湖南裕能此前宣布，自2026年8月1日起，将全系列磷酸铁锂产品加工费在原执行价格基础上统一上调2000元/吨。对于本次调价，湖南裕能解释称，自2026年3月起，受全球地缘局势波动、供应链流通扰动等多重因素影响，磷酸铁锂核心原材料价格持续上行。业内普遍预期，在成本压力和高端产能紧缺的背景下，其他头部企业跟进涨价的可能性较大。根据GGII预测，下半年，铁锂材料将从2026年6月的5.3~6万元/吨涨至6.5~7.2万元/吨；7μm湿法基膜将从0.55~0.75涨至0.65~0.85元/m²；5μm铜箔加工费将从2.4~2.8万元/吨涨至2.5~3.1万元/吨；负极材料和铁锂电解液也将微涨0.2万元/吨。如果说电芯涨价是此次储能产业链价格调整的起点，那么PCS、储能系统以及光储充设备的价格调整，则意味着成本压力正在进一步向下游传导。今年以来，不仅是储能电芯的原材料成本上涨，PCS、BMS以及电气设备等环节，同样面临上游成本上涨压力。在供不应求、交期显著延长的情况下，几家头部PCS企业在今年年初已经率先提价。年初至今，汇川技术已经宣布了好几轮涨价，覆盖产品线从电机到变频器再到储能PCS、系统产品。7月16号，盛弘股份正式发布调价函，自2026年7月21日起，全系列储能微网、电能质量、充换电设备、户用储能、检测设备等产品涨价10%-30%，存量已确认订单不追溯调价，同时设置订单过渡期，允许客户在调价生效前锁价备货。PCS等电气设备涨价，同样是上游原材料驱动：金、银、铜、铝、锡等有色金属价格涨幅达30%-200%；PCB、存储芯片、磁性器件、IGBT等核心电子元器件涨幅达到50%-800%。高工产研储能研究所（GGII）的调研显示，进入2026年Q2后，储能PCS均价环比上涨2%-3%。从成本构成来看，PCS虽然不是储能系统中成本占比最高的环节，但却是受电子元器件价格影响较大的环节。尤其是在新能源汽车、光伏逆变器、储能PCS、AI服务器电源等多个高景气领域同时争夺功率器件资源的情况下，部分核心元器件价格压力明显增加。过去，系统集成商可以通过压缩利润、调整供应链采购价格来维持项目竞争力。但当电芯、PCS、材料等多个环节同时上涨时，系统集成商成为成本压力最直接的承担者。核心原因在于，谁在产业链里话语权高，谁的成本传导能力越强。在整个储能产业链中，头部系统集成商仍掌握一定话语权，但中小集成商基本没有成本传导能力，甚至面临有订单，但拿不到电芯和PCS的窘境，交付能力的缺失最终会导致订单流失，市场份额被头部企业进一步蚕食。业内人士透露，政策成本已经形成，上游材料价格存在上涨预期，随着三季度末项目集中交付以及四季度市场需求释放，产业链价格调整预计将更加明显。不过，成本能否顺利传导至终端客户？高工储能认为，海外市场能够通过涨价消化大部分成本压力，但国内市场竞争激烈、业主价格敏感度高，传导空间相对有限。根据韩国研究机构SNE Research发布的数据，2026上半年全球锂离子储能电池出货量达到461.3 GWh，同比增长71%。其中，中国出货202.5 GWh，同比增长49%，但出货占比从去年同期的50.5%下降至43.9%，海外市场合计占比首次超过全球中国，达到56%。本文属高工储能原创，转载请联系（微信号：15019438102）获得授权。
