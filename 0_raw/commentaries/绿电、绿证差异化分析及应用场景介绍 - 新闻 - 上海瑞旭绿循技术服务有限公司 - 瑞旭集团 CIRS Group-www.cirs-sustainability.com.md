# 绿电、绿证差异化分析及应用场景介绍 - 新闻 - 上海瑞旭绿循技术服务有限公司 - 瑞旭集团 CIRS Group

### 绿证、绿电的定义和区别

**什么是绿电及绿电交易？**

**绿电**指的是在生产电力的过程中，它的二氧化碳排放量为零或趋近于零，相较于其他方式（如火力发电）所生产的电力，对于环境冲击影响较低。绿电的主要来源为太阳能、风力、生物质能、地热等非水可再生能源。

**绿电交易**是指以绿色电力产品为标的物的中长期交易，用以满足电力用户购买、消费绿色电力需求。每次绿电交易完成后，买方可获得由交易中心出具并核验的绿色电力消费证明，该证明记录了每一兆瓦时绿色电力的交易、售电、生产、消费、结算等各环节数据，向电力用户提供消费绿色电力的查证服务，实现绿色电力全生命周期追踪溯源。

**什么是绿证？**

可再生能源绿色电力证书（简称“绿证”）是可再生能源绿色电力的“”电子身份证“”，作为绿色环境权益的唯一凭证，它记录了特定的**1000千瓦时可再生能源电量**。

### 绿电交易跟绿证有什么区别？

**以往：**

**绿电交易**采用“证电合一”方式（绿电物理属性和绿色环境属性的统一），绿色电力的生产者（新能源企业）与消费者（用电企业、售电公司等，含电网公司代理）直接签订交易合同，实现了绿电生产、传输、消费全流程闭环。

**绿证**是国家对发电企业每兆瓦时非水可再生能源上网电量颁发的具有唯一代码标识的电子凭证。绿色电力证书不可溯源，用户仅购买了绿色电力的绿色环境属性，并未真正使用绿色电力，不能实现“证电合一”。

**最新变化：**

2023年7月25日，国家发展改革委、财政部、国家能源局发布《做好可再生能源绿色电力证书全覆盖工作促进可再生能源电力消费的通知》（下文简称：通知1），明确了绿证地位、规范绿证核发、完善绿证交易、扩展绿证应用、鼓励绿电消费等相关要求。认定**绿证是我国可再生能源电量环境属性的唯一证明，是认定可再生能源电力生产、消费的唯一凭证**。

通过分析该通知文件，可以发现，新的绿证制度将与以往不同，**所有建档立卡的可再生能源发电项目均可申请绿证核发**，并且新的制度包括不可交易绿证与可交易绿证，对于未上网的可再生电力、存量常规水电项目（2023年1月1日（不含）以前投产），只能申请不可交易绿证。在电力交易机构参加绿色电力交易的，电力交易机构按交易合同或双边协商约定将**绿证随绿色电力一同交易，**可交易绿证仅可交易一次。

2024年1月27日，国家发展改革委、国家统计局、国家能源局发布《关于加强绿色电力证书与节能降碳政策衔接 大力促进非化石能源消费的通知》（下文简称：通知2），进一步加强绿证与节能降碳政策衔接，激发绿证需求潜力，夯实绿证核发交易基础，拓展绿证应用场景，支持各地区、各类主体增加可再生能源消费，更大力度推进节能降碳。该通知解决了以往绿证交易电量重复扣除等问题，打通了绿证作为可再生能源电力消费基础凭证的关键环节。

根据国家能源局对十四届全国人大一次会议第3118号建议的答复、生态环境部对政协十四届全国委员会第一次会议第04111号提案的答复，两者均强调要研究加强碳市场与绿色电力市场、绿证交易市场的衔接。

可以认为，日后证明可再生能源电量环境属性的凭证只能是绿证。绿证将作为可再能源电力生产、消费的唯一凭证，更具权威，应用更加广泛。

### 如何购买绿电？

通过电力直接交易方式购买绿电产品，由电力用户（含售电公司）与发电企业直接通过**双边协商、集中撮合、挂牌**等方式达成交易。开展绿色电力交易后，电力系统由绿色发电企业发电后汇入，通过国有电网公司进行输送，售电公司进行配电售电，将电力通过电力合同签订形式卖给电力用户。

|
|
| 参与绿色电力交易的发电企业初期主要为风电和光伏等新能源企业 |
| 电力用户或售电公司 |
| 为各省区省级电网企业 |
| 北京电力交易中心、广州电力交易中心（2024年2月22日，内蒙古获批成为第3个绿电交易试点，绿电交易试点基本覆盖全国各电网区） |
| 在确保电网安全的前提下，提供安全约束条件，开展安全校核，合理安排运行方式，优先执行绿色电力交易合同 |
| 根据区域绿色电力交易需要，会同电力交易中心向发电企业 |

绿色电力交易主要包括**省内**绿色电力交易（直接交易）和**省间**绿色电力交易（初期由电网企业汇总跨省购买绿电，后期将建立多元市场主体）。

在当前国内绿电市场规模较小且价格波动较大的背景下，企业往往不能直接按需购买绿电。因此，绿电交易主要通过售电公司进行，这些公司帮助企业从发电企业购买所需的绿电。企业与售电公司签订合同，约定代购的绿电数量。售电公司根据汇总的需求，在绿电市场开放时通过竞价方式采购所需绿电。

### 如何购买绿证？

个人可通过中国绿色电力证书认购交易平台（网址：https://www.greenenergy.org.cn）、微信小程序“中国绿色电力证书交易平台”、微信公众号“国家可再生能源信息管理中心”购买绿证。

企业主要可以通过4个途径来购买绿证:

绿证交易平台购买 | 找绿证咨询,中介公司代采购 |
找新能源电站持有方购买 | 通过专业碳管理系统平台来购买 |

### 几种常见绿证

目前国内买家更多会选择购买国际绿证：I-REC、TIGR，原因主要是国际绿证价格便宜且国际上接受度更高（被ESG，RE100，CDP等组织认可)。下表是目前的几种常见绿证：

|
|
|
|
GEC |
| 以往仅支持前期国家1-6批补贴的陆上风电和集中式光伏项目申请；平价项目绿证已放开申请且开始交易。 项目范围：现已扩展至水电、分散式风电、海上风电、分布式光伏发电、光热发电、地热能发电、生物质发电、海洋能发电。 |
|
APX TIGR |
| 主要的差异化是背后大多是无补贴项目生产的绿证。 项目范围：包括生物质能、地热能、氢能发电、聚光太阳能发电、光伏发电、风电等。 |
|
I-REC |
| 已开放对非国有的项目的注册申请，且2023年后不再签发有补贴项目的I-REC。 项目范围：包括多种可再生能源，除光伏、陆上和海上风电之外还有水电、潮汐发电、生物质发电、沼气发电等多种形式 |
|

随着中国绿证（GEC）制度的推进和《通知1》的实施，强调中国绿电只能申请国内绿证并推动国际互认，预计国内绿证项目将更多样化，需求量增加。截至2024年2月27日，中国绿证交易平台数据显示，月均成交价为23元/个，表明绿证价格呈下降趋势。

### 绿电与绿证的应用场景

### 支撑绿色电力交易

#### 核算可再生能源消费

#### 认证绿色电力消费

绿证作为电力绿色消费和绿电属性的唯一凭证，以**两年**内的绿证开展绿色电力消费认证。

#### 衔接碳市场

研究推进绿证与全碳市场的衔接协调。研究核算**扣除绿证的修正电网排放因子**。

### 支撑产品碳足迹管理

绿证纳入产品碳足迹核算标准，探索**体现可再生能源电力消费占比的差异化产品标识**。

### 推动绿证国际互认

推动绿证与国际绿色消费、碳减排标准衔接，参与制定国际标准增强绿证的国际影响力。

CDP是非营利性国际组织碳信息披露项目（Carbon Disclosure Project）。 RE100（100% Renewable Electricity）是一项全球性、合作性的商业倡议。RE100的使命是加速实现全球电网零碳排放，加入RE100的公司，须承诺不晚于2050年全部使用绿电。
CDP（即权威碳排放披露项目）要求的“21个月原则”内发电所产生的绿证。RE100也采取相同的有效期。 这里的“21个月原则”指的是企业当年财务报告期的十二个月，再加上前六个月和后三个月，加起来也就是共21个月。例如，如果一个企业在2023年1月到2023年12月是其2023年财务报告期，那么他想要完成在这期间内的绿电履约，就必须去购买2022年6月到2024年3月期间内发电所产生的绿证。在国内，新的规定把绿证认证时间设置为两年内，这与国际要求存在差异。如果国内新绿证的购买方想被CDP认可，就必须留意绿证的有效期问题，确保它们在被认可的有效期内使用。
目前CDP认可的是国际绿证TIGR和I-REC。 以往RE100认可的是国际绿证TIGR和I-REC。2023年8月30日，国家能源局在对十四届全国人大一次会议第7024号建议的答复中明确：我国绿色电力证书已获得RE100组织认可。 |

### 企业建议

通知1规定我国可再生能源电量原则上只能申领核发国内绿证，提升了中国绿证的权威性和优先级。绿证、绿电和碳交易市场的互补互动，既避免环境价值重复计算，又通过市场手段促进绿色消费和可再生能源发展，支持能源结构绿色转型。

重点用能单位将承担可再生能源消纳责任，并受化石能源消费预算管理。超额部分需通过购买绿证或绿电抵消。单位需了解绿证市场，制定相应管理制度，提前规划应对策略。

随着中国绿证覆盖更多可再生能源项目，缺乏绿电使用条件的企业可通过购买绿证来提高绿色能源使用比例，助力实现环境目标，同时提升品牌形象和竞争力。

此外，随着绿色投资兴起，企业通过参与绿电和绿证市场，能够满足投资者和消费者的环保期望，从而获得财务和市场优势。
