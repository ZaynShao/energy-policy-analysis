# 通知 | 关于举办Wan 3.0发布暨AI+营销专场活动的通知

一、组织单位
联合举办：杭州市工业和信息化服务中心（杭州市中小企业服务中心）、未科阿里中心、TBH
二、时间地点
时间：2026年8月10日（星期一）14：00半天
地点：阿里中心·杭州未科 模域空间（余杭区思凯路与爱橙街交叉口东南200米）
三、活动议程
1. 阿里新一代视频生成模型发布
2. Al+营销&电商解决方案分享
3. 聚焦AIGC、内容营销、AI直播带货等真实场景的案例分享，看头部玩家如何用AI重做内容生产，提升创意产能、降低制作成本、找到可复用经验。
4. AI营销场景实操课程。
四、活动亮点
1. 了解Wan 3.0最新能力：现场了解新一代视频生成大模型的技术演进及功能特点，掌握从Prompt撰写到批量出片的基本方法。
2. 获取AI业务落地方案：围绕营销与电商核心场景，了解模型选型、应用部署及业务流程设计，形成可执行的AI应用思路。
3. 学习企业真实实践：通过不同行业企业案例，了解AI在实际业务中的应用方式、实施过程及效果验证方法。
4. 参与现场实操：结合Wan 3.0开展实操演练，将现场学习内容转化为可直接使用的AI视频生产经验。
五、报名方式及其他事项
1. 报名方式：请扫描二维码报名参会（详见附件）。
2. 请报名人员提前安排时间，按活动通知要求参加；具体活动议程及现场安排，以主办方最终通知为准。
