# 能源早新闻丨亚洲最大海上原油处理平台完成封顶

◐国家能源局：1—7月份全社会用电量同比增长4.7%。8月21日，国家能源局发布7月份全社会用电量等数据。7月份，全社会用电量10400亿千瓦时，同比增长1.7%。从分产业用电看，第一产业用电量167亿千瓦时，同比下降2.0%。第二产业用电量6116亿千瓦时，同比增长3.0%。第三产业用电量2183亿千瓦时，同比增长4.8%。1—7月，全社会用电量累计61399亿千瓦时，同比增长4.7%。【更多详情】
◐我国牵头的固态电池首项国际标准正式立项。据央视新闻报道，8月21日从国家标准委获悉，由我国提出的国际标准提案《电动汽车驱动用二次锂离子电池 固态电池应用指南、测试项目及条件》近日在国际电工委员会成功立项。该标准是固态电池领域全球首个国际标准。该国际标准将使未来全球车企在研发和生产固态电池时拥有统一的“标尺”，有助于加速更安全、长续航的电动车走进千家万户，推动新能源产业快速发展。该标准由我国牵头提出，法国、韩国、日本等多国专家参与研制。
◐我国自研11.5万吨成品油轮正式交付。据央视新闻报道，从中船集团获悉，8月21日，我国自主研发建造的11.5万吨成品油轮正式交付用户。船舶发动机等核心设备实现国产化，载货量、航速、油耗指标均达到国际先进水平。此次交付的11.5万吨成品油轮总长249.8米，型宽44米，满载载货量达到11.5万吨，可一次性运载约83万桶成品油。港口适配能力强，能够停靠全球多数主流油品港口，服务于国际能源贸易干线运输。
◐国内首例百万千瓦二次再热机组实现高比例生物质掺烧发电。据央视新闻报道，8月22日从国家能源集团获悉，广东清远电厂2号机组成功实现10%能量比生物质掺烧，这是国内首例百万千瓦二次再热机组实现高比例生物质掺烧发电，填补了国内技术空白，为火电机组清洁低碳转型注入新动能。
◐我国自研新一代深水多功能海洋工程船完工交付。据央视新闻报道，8月21日从中国海油获悉，我国自主研发的新一代深水多功能海洋工程船“海洋石油292”在江苏完工交付，进一步提升了我国水下工程和海洋在役设施专业服务能力，为加快深海能源资源开发提供关键装备保障。
◐S4000浮空风电系统完成全流程放飞验证。据央视新闻8月22日报道，近日，我国高空风电领域取得重大工程突破。由我国自主研制的S4000浮空风力发电系统，在西北某试验基地顺利完成全流程放飞验证，标志着我国平流层高空风电技术正式从技术迭代走向工程化落地。
◐霍尔果斯压气首站累计输气突破6000亿立方米。据央视新闻8月23日报道，8月22日从国家管网集团获悉，西气东输二线三线首站——霍尔果斯压气首站累计输送天然气突破6000亿立方米，为国内天然气市场稳定供应、能源结构低碳转型提供了保障。霍尔果斯压气首站负责将中亚跨国天然气和伊犁煤制气输送至我国中东部地区，年输气能力达600亿立方米，单站装机容量居亚洲首位。
◐平陆运河三大枢纽实现双电源供电。据中新网8月22日报道，日前，平陆运河电力工程建设迎来历史性时刻——青年枢纽、企石枢纽第二回外部电源线路接续投运。至此，平陆运河三大核心枢纽全面实现双电源供电，标志着这条世纪工程正式装上“电力双引擎”，驶入通航倒计时的“全速冲刺阶段”。
◐乌能源部长：越冬能源准备已接近或超额完成计划指标。据新华社报道，乌克兰媒体消息，乌克兰能源部长什梅加尔8月21日表示，乌克兰今年越冬所需的天然气、煤炭等能源储备已接近或超额完成计划指标。什梅加尔说，预计到今年底，乌克兰全国发电装机容量将达到19.6吉瓦，超过乌越冬最低发电装机容量需求。
◐伊拉克希望伊朗向其油轮发放特别通行许可。据新华社报道，伊朗伊斯兰共和国通讯社8月22日消息，在伊朗伊斯兰议会议长卡利巴夫访问伊拉克期间，伊拉克方面提出，希望伊朗给伊拉克油轮发放通过霍尔木兹海峡的特别通行许可。伊拉克此前已通过各种渠道多次向伊朗提出该请求，伊朗目前允许部分伊拉克油轮通过霍尔木兹海峡。
◐匈牙利保克什核电站3号机组恢复发电。据新华社报道，匈牙利总理毛焦尔·彼得8月22日宣布，得益于紧急工程施工作业及多瑙河水位回升，该国唯一的核电站——保克什核电站3号机组已于当天恢复发电。毛焦尔当天在核电站现场表示，3号机组的6号汽轮机已重新联网恢复发电。本月早些时候，干旱引发的多瑙河极低水位严重限制冷却水吸入，导致部分机组被迫停运。
◐亚洲最大海上原油处理平台完成封顶。据央视新闻报道，8月22日从中国海油获悉，亚洲最大海上原油处理平台——惠州19-6平台主体结构在珠海完成封顶，平台建成后将用于珠江口盆地大型亿吨级整装油田开发生产。完成主体结构封顶后，项目将转入管线安装、电缆敷设、设备调试等阶段。平台建成后，将应用于我国首次探获的海上深层—超深层碎屑岩大型亿吨级整装油田——惠州19-6油田，为亿吨级油田高效开发和国家能源保供提供支撑。
◐中企参建的坦桑尼亚一水电站项目正式投入使用。据新华社报道，由中国电建集团和中国东方电气集团参与建设的坦桑尼亚朱利叶斯·尼雷尔水电站8月22日正式投入使用。该水电站目前能提供的电力约占坦桑尼亚全国电力供应总量的一半，新增发电能力将有效缓解长期困扰坦桑尼亚的电力短缺问题。该项目将进一步改善当地居民生活和公共服务用电条件，增强坦桑尼亚在东非区域能源市场中的地位，为区域互联互通和经济社会发展提供能源支撑。
