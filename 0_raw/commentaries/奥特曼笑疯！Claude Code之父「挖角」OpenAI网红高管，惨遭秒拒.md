# 奥特曼笑疯！Claude Code之父「挖角」OpenAI网红高管，惨遭秒拒

新智元报道
「欢迎来Anthropic上班！」
就在刚刚，Claude Code之父Boris Cherny亲自下场，当着几十万人的面，向OpenAI核心产品负责人甩出了入职邀请。
起因荒诞到离谱。
一个头铁的开发者照着OpenAI高管的教程，硬生生把GPT-5.6 Sol塞进了Claude Code的harness里跑。
Anthropic反手就是一记封号。
50分钟后，被挖的Tibo当场拒绝。又过了7分钟，他一不做二不休，直接重置了全体付费用户的额度。
全程围观的奥特曼在X上笑出了声，留下一句「lol，OpenAI最让我喜欢的事情之一就是Tibo。」
时间回到7月12日，Tibo在网上甩出了一份操作指南。
五个步骤，五分钟，一行alias命令，GPT-5.6 Sol就堂而皇之地在Claude Code的harness里跑了起来，还被起了个名字叫claudex。
技术上毫无门槛，在本地起个代理服务，把Claude Code的请求劫持转发到OpenAI的API就行。工具链、权限、记忆全保留，换的只是底层调用的模型。
帖子最后他还挑衅地补了一句，说如果这招被封了，他欠所有人一次重置。
没想到，半个月后一语成谶。
8月8日，开发者alex getman发帖求助。
他几乎原封不动照搬了Tibo的教程，代码刚跑没多久，Anthropic直接把他号封了。
他把代码开源到GitHub，@了所有相关方，就想要一个明白的答案，这到底算不算违规。
Tibo的回应，把Anthropic按在了地上摩擦。
我很想帮你，但我又不在Anthropic上班。他们因为你在自家harness里跑了别的模型就封你号，这事确实挺奇怪的。
社区瞬间炸锅。
一直以来，Claude的封号系统在开发者圈子里早就臭名昭著，误判频发、申诉无门、退款石沉大海，付费用户被当嫌疑人一样对待，敢怒不敢言。
评论区里涌出一大批同病相怜的付费用户。
有人前脚刚交完订阅费，后脚账号就被封了，钱扣了人锁了，连个解释都没有。
有人申诉了46天，杳无音信。还有人三个月前就被封了，工单石沉大海，退款也没着落。
最让人破防的是，原来得闹到全网围观的程度，Anthropic才肯正眼看一下你的申诉。

眼瞧着舆论越烧越旺，Claude Code之父Boris Cherny坐不住了，火速空降评论区灭火。
他表示官方绝不会因为用户替换底层模型就封号，几乎可以确定是另一个账户分类器误触发了，正在查，感谢把事情公开。
很快，alex getman的账号恢复了。
全程不到8小时。
Boris那句「来Anthropic上班吧」放在X的公开时间线上，等于Claude Code负责人公开向竞争对手的大将挖角。
直接把Tibo架在了火上烤。
而Tibo的回绝也相当有水平：「我太爱现在的团队了，而且接下来几周要发布的东西太让人兴奋了。」
一句话，不仅宣誓了自己的忠诚，而且还明示了OpenAI还有重磅产品蓄势待发。
然后他选了一种最嚣张的庆祝方式，直接给所有付费用户充满额度。
过完瘾还不够，又放话周一再来一次表演性重置。
他在AI编程圈封神，靠的就是「重置」这么一手，而且硬生生做成了社区文化。
截至目前他已经按下了43次重置按钮，平均每7.5天就来一次。有人统计过，Tibo每6分钟就收到一条请求重置的私信。
Codex周活4月300万，7月下旬突破1000万，最快的时候每天涨100万。
对此，开发者不仅自发建了codex-resets.com追踪重置记录，搞了TiboGPT网站和Codex Radar追踪App，甚至还发明了「重置前冲刺」工作流。
而这不是心血来潮的慷慨，而是Codex最狠的获客武器，一场在X时间线上实时直播的秒杀级价格战。
Tibo每一次重置都在喊同一句话：来我这边，管够。
至此，两家公司在这8小时里展示了两套截然不同的用户哲学。
一边封号限流；一边额度充满，有求必应。
奥特曼看似随意的回复，实则是一种战略上的默许。
Tibo是OpenAI在AI编程战场上最能打的一张牌，靠的便是人格魅力加上真金白银的慷慨。
别人家的产品负责人在写roadmap，他在X上跟上千万开发者称兄道弟。
这种打法没有第二个人学得来，奥特曼的心胸在于看懂了这一点，然后把缰绳彻底松开。
但这场事故的高潮不在解封，真正的大戏在账号恢复之后才刚刚上演。
开发者们在复现Tibo教程的过程中，意外撞开了一扇门——
Claude Code的核心体验，根本不是来自Claude这个模型。
MBZUAI最新的研究，给出了精确数字。
Claude Code 98.4%的功能来自harness架构，模型本身只贡献了不到2%。
从项目上下文管理到跨session记忆，开发者每天依赖的核心功能都长在harness上。
模型随时可以拔下来换新的，但这副承载着记忆和习惯的harness，一旦穿上就再也脱不下来。
论文地址：https://arxiv.org/pdf/2604.14228
Anthropic的工具装得了OpenAI的模型，反过来大概率也行。第三方开源harness更是把解耦推到了极致。
于是，这个事实把整个AI编程的竞争逻辑翻了过来。
过去的逻辑是，模型越强，用户越多，数据越多，模型被喂得更强。
而Harness时代的逻辑是，工具的体验做得好，用户就留在这里，不管里面跑谁的模型，工具的提供者就是入口。
开发者用谁的工具写代码，比用谁的模型更重要。
皮衣老黄曾说过，token正在走向大宗商品化——利润趋零，差异化消失。
如果模型层真的沿着这条路走下去，真正值钱的东西只会在模型的外面。
而这场8小时闹剧，正是这个判断最直观的表演。
也许未来某一天人们回头会发现，2026年夏天AI编程圈最激烈的战场不在模型层——
谁的工具能把开发者的整套工作方式牢牢栓在自己的地盘上，谁就赢了。
