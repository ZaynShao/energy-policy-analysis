# 氯化铵：待发量积极执行 稳价出货占主导

【导语**】**氯化铵国内需求旺盛，产销活动保持平稳，新订单稳定跟进，价格维持横盘状态。联碱双吨利润略有恢复，生产装置开工率较高，部分计划内的检修进行中，供应端保持中等水平。供需端基本平衡，4月主稳价落实前单出货，企业库存水平保持低位。

氯化铵4月市场表现出较强活力，工厂待发订单量大，支撑出货顺畅，价格稳定横盘运行。供应端利润虽有恢复，但增幅一般，装置开工率维持稳定为主。下游春季肥产销旺季，氯化铵阶段性供需平衡。原料端煤炭价格小幅波动，对成本影响有限。外贸方面，国际氮肥价格高位，氯化铵出口意愿及价格空间存在，实际出口量主受政策面影响，处于暂停阶段。国内需求方积极补库，企业按计划落实前单，整体库存水平较低。回顾2024-2026年氯化铵企业库存量变化情况如图1，2025年中国联碱企业氯化铵月度库存量震荡在32万-70万吨的,2026年预计4月底库存量处于低位。据卓创资讯预估，联碱企业氯化铵库存量4月底或在18万吨左右，环比3月底降幅约10%，同比降幅51%。

**供应：开工中高位，供应平稳为主**

氯化铵及纯碱双吨利润部分修复，联碱企业开工稳定推进为主，少量计划内检修落实。4月国内春耕肥产销活跃，企业交投意愿积极，供应预期中高位运行。预计4月中国氯化铵月度产量140万吨左右，环比降幅6.29%；同比增幅1.41%。4月中旬联碱双吨利润150元/吨左右，企业产销理性，需求跟进平稳，支撑后市价格稳定。

**需求：下游备货稳健，刚需持续跟进**

氯化铵主力下游复合肥4月产能运行率预计在45%左右，环比降低6个百分点，同比提高2个百分点，开工降低主受春季刚需减弱影响。氯化铵性价比优势持续存在，下游复合肥采购按需跟进。外贸方面，3月份肥料用氯化铵月度出口量预估在25万吨左右，4月受国内保供禁止出口政策面影响，出口量预估降为0。氯化铵需求端减弱，4月份国内复合肥对氯化铵的消耗量预估157万吨左右。需求面表现较为活跃，价格稳定信号持续释放。

![image](https://mmecoa.qpic.cn/mmecoa_png/9w7iaKkib7mX2OHBeeagY8CIMF3ZUjFSo9awHCBCaJMDS6KAFYicjERXRwmb2RIDYKEHibH6NMaWiaQVn0NYrI2MiaOfgB7Fic4hbysfOdKI8lzW6w/640?wx_fmt=png&from=appmsg)

**展望：出货顺畅，企业库存低位运行**

综上所述，氯化铵供应面稳定释放，下游补货跟进平稳，刚需旺季带动4月出货顺畅。后期待发量充足，整体供需平衡，卓创资讯预计4月底华东及华中干铵主流出厂价大概率运行于620-660元/吨，月末中国联碱企业氯化铵库存量或将震荡在15万吨左右的低位水平。
