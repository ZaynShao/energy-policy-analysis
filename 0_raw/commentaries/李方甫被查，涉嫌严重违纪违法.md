# 李方甫被查，涉嫌严重违纪违法

青川县委书记李方甫涉嫌严重违纪违法，目前正接受四川省纪委监委纪律审查和监察调查。
李方甫简历
李方甫，男，汉族，1976年3月生，重庆城口人，在职研究生学历。1999年7月参加工作，1998年5月加入中国共产党。
1999年7月至2003年2月，先后在广元市元坝区太公镇政府、区招商局、区政府办公室工作；
2003年2月至2009年12月，历任广元市元坝区企业局党组成员、副局长，广播电视局党组成员、副局长，明觉乡党委副书记、乡长，香溪乡党委书记、人大主席；
2009年12月至2019年6月，历任广元市天然气综合利用工业园区管委会党委委员、副主任，剑阁县副县长，广元经济技术开发区党工委委员、管委会副主任；
2019年6月至2023年6月，历任广元市利州区委常委、副区长，区委副书记，青川县委副书记，县委副书记、县长；
2023年6月至今，历任青川县委书记、县长，县委书记。
