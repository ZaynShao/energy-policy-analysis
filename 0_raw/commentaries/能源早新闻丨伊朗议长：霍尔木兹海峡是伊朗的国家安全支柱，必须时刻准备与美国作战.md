# 能源早新闻丨伊朗议长：霍尔木兹海峡是伊朗的国家安全支柱，必须时刻准备与美国作战

◐生态环境部：我国已成为全球规模最大的碳市场。据央视新闻报道，7月16日是全国碳排放权交易市场上线交易5周年。从生态环境部了解到，5年来，我国碳排放权交易市场从无到有、从小到大，已成为全球规模最大的碳市场，在倒逼行业降碳、降低全社会减排成本等方面发挥了重要作用。截至今年6月，全国碳排放权交易市场配额累计成交量突破9.17亿吨，成交额超过617亿元。2026年上半年成交量为5296万吨，同比增长约37%。
◐我国首个全链条绿色低碳乙烯工程投产。7月16日，中国石油独山子石化公司塔里木120万吨/年二期乙烯及配套绿色低碳示范工程正式投料开车一次成功，全面进入生产运行阶段。工程位于新疆巴音郭楞蒙古自治州库尔勒市上库工业园区，该园区是全国首批国家级零碳园区中唯一以高耗能石化产业为主的园区。工程总投资256.56亿元，是国家石化产业规划布局重点项目，建成全球首个乙烯裂解炉烟气碳循环利用示范基地，为零碳园区建设提供了石化工业绿色低碳发展范本。【更多详情】
◐我国发布首个水风光一体化智慧运营大模型。据新华社报道，我国首个面向千万千瓦级水风光一体化清洁能源基地的智慧运营大模型7月16日在四川发布。此模型融合人工智能、大数据等技术，贯通预测预报、电力调度、生产运行、市场营销等业务场景，为大型清洁能源基地智能化运行提供支撑，推动人工智能在能源领域应用进一步深化。
◐事关节能环保、安全生产等，一批重要国家标准发布。据新华社报道，7月16日获悉，国家市场监督管理总局（国家标准委）近日批准发布508项重要国家标准，涉及高新技术领域、传统产业、节能环保、服务民生、安全生产、百姓生活等方面。在节能环保方面，发布碳足迹等14项国家标准，推动绿色低碳产业规范发展。发布钢筋、不锈钢绿色产品评价等45项国家标准，支持促进绿色发展。
◐6月份，新能源汽车零售渗透率达到62.8%。据央视财经7月16日报道，国家统计局相关负责人表示，今年上半年，新消费增长点活力显现。今年以来智能绿色消费逐渐成为新的消费风尚：上半年包括智能眼镜在内的可穿戴智能设备零售额增长超过1倍，高能效等级家电零售额增长超过30%，6月份，新能源汽车零售渗透率达到62.8%，连续三个月超过60%。
◐江苏最高用电负荷刷新纪录。据新华日报微信公众号报道，从国网江苏省电力获悉，7月16日11时15分，江苏电网最高用电负荷达到1.5759亿千瓦，刷新历史纪录。截至7月16日中午，苏州、常州、南通、泰州等4个地市全网用电负荷已相继创下历史新高。其中，苏州电网最高用电负荷达3583.5万千瓦，负荷规模稳居全国地级市首位。
◐南方电网上半年完成固定资产投资892.62亿元。据南方电网消息，今年1—6月，南方电网累计完成固定资产投资892.62亿元，同比增长14.79%，创历史同期最高，完成全年1800亿元投资目标的49.59%。二季度完成投资508.09亿元，投资节奏较一季度进一步提速。
◐沙特红海延布港原油装运量接近峰值。据新华社7月16日报道，霍尔木兹海峡受战事影响航运受阻，沙特阿拉伯转而通过曼德海峡出口原油。专业机构提供的数据显示，沙特位于红海沿岸的延布港最近日均原油装运量已接近峰值。6月以来，延布港装运原油量为日均400万桶，而去年同期这一数字仅为日均97.3万桶。
◐伊拉克和叙利亚将合修跨国石油管道。据新华社7月16日报道，美国政府知情官员7月14日披露，伊拉克和叙利亚将重修一条荒废多年的石油管道，把伊拉克北部油田生产的石油运输到叙利亚地中海港口，从而避开霍尔木兹海峡。这条管道的泵站和电力系统损坏严重，需要全面维修，修好可能要花两三年时间。
◐伊朗议长说霍尔木兹海峡是伊朗的国家安全支柱。据新华社7月16日报道，伊朗迈赫尔通讯社7月15日，伊朗议长卡利巴夫说，霍尔木兹海峡是伊朗的国家安全支柱，必须维护伊朗在这一重要航道的既有安排。卡利巴夫在当晚发表的致伊朗全国人民的讲话中说，伊朗正与美国进行一场复杂的斗争，必须时刻准备与美国作战。
◐中广核“元曜一号”光热熔盐槽式集热器型号发布。据证券时报报道，从中国广核集团获悉，7月16日，全球首个8.6米开口光热熔盐槽式集热器型号中广核“元曜一号”在青海西宁发布。该型号在光电转换效率与全链条自主可控方面取得重要进展，为我国光热发电规模化发展提供核心技术支撑。
