# 日本排放核污染水已三年，22轮累计排放超17万吨

截至8月24日，日本排放福岛第一核电站核污染水已整整3年。共进行了22轮核污染水排放，累计排放量约17.3万吨。
▲福岛第一核电站（资料图）
截至8月24日，日本向海洋排放福岛第一核电站核污染水已整整3年。其间共进行了22轮核污染水排放，累计排放量约17.3万吨，厂区储罐中储存的水量较排放开始前减少了约7%。
日本东京电力公司计划从本财年度起增加排放量，目标于2051年完成的核电站报废工作，但能否在此之前将核污染水全部排放完毕，目前仍不明朗。
2023年8月24日，日方无视国际社会的强烈质疑和反对，单方面强行启动福岛第一核电站核污染水排海。
