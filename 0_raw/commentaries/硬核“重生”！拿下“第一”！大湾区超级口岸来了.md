# 硬核“重生”！拿下“第一”！大湾区超级口岸来了

2019年6月，皇岗口岸重建正式拉开序幕。如今，这座实现了空间、功能全方位重构的口岸，以超级口岸的昂扬之姿焕新归来。
重建后的皇岗口岸迎来硬核“重生”。“两地两检”升级为“一地两检”，更在深港间第一次落地“合作查验、一次放行”的崭新通关模式，旅客排一次队、连过“三道门”，即享畅快“丝滑”的出入境体验。作为全球最大的陆路口岸单体建筑，重建后皇岗口岸联检大楼采用立体垂直布局，高效组织口岸出入境及公共交通换乘。口岸更引入多条轨道线路，打造综合交通枢纽，大大强化超级口岸的辐射力。
万众瞩目的皇岗口岸，开通脚步已越来越近。
通关更“丝滑”
深港间首个“合作查验、一次放行”口岸
2026年7月30日，《深圳市人民政府与香港特别行政区政府关于在皇岗口岸实施“一地两检”的合作安排》正式签署，落实深港在重建后的皇岗口岸实施“一地两检”的合作框架，这是皇岗口岸开通筹备工作的重要里程碑之一。
过往“两地两检”模式下，旅客经皇岗口岸往返深港，需要在深圳皇岗口岸和香港落马洲管制站分别排队过关，即要排两次队，而且中途还要乘车过落马洲大桥，整个通关流程相对耗时。而皇岗口岸重建后，在“一地两检”模式下，两地查验集中到了同一栋联检大楼，旅客也不需要中途乘车了。
对于不时往返深港的陈先生来说，周末陪老婆赴港购物常常是一场“体力战”。他记得有次深夜归来，两人拖着满满的行李经皇岗口岸通关，当天两人本来就逛得很累了，再经历“两地两检”、两次排队通关，都快累趴了。知道重建后皇岗口岸将实施“一地两检”，陈先生满怀期待。
相较于深圳湾口岸实行“一地两检”，重建后皇岗口岸的重大升级在于叠加了“合作查验、一次放行”的崭新通关模式。皇岗口岸将成为深港间首个实施“合作查验、一次放行”通关模式的口岸，进一步提升旅客通关效率和体验。
//皇岗口岸合作查验快捷通道。
重建后皇岗口岸将设置134条合作查验快捷通道及68个人工柜台。
旅客使用合作查验快捷通道，只需排一次队，通过“三道门”一体化设计，即可完成两地的出入境手续。“三道门”一体化，第一道闸门读取旅客证件信息，核验通道使用资质；第二道闸门采集指纹、面相等生物信息，完成身份比对；第三道闸门正常放行。
至于人工柜台，口岸边界线上将并排设置人工柜台，旅客也只需排一次队，并分别向出境方及入境方出示证件，就能够完成两地出入境手续。
“一地两检”叠加“合作查验、一次放行”，以后旅客经皇岗口岸通关的效率将大幅提升，体验更加友好，通关更加“丝滑”。
//皇岗口岸合作查验快捷通道。
跨境往来“说走就走”
深港间唯一旅检24小时通关口岸
“除了香港居民‘北上’消费、深圳居民赴港旅游这类民生往来外，深港两地科创人才、商务人士的往返同样更加便利，进而深化双城民生、产业协同联动。”综合开发研究院（中国·深圳）港澳及区域发展研究所副主任研究员杨秋荣表示。
杨秋荣指出，皇岗口岸实施新通关模式，将大幅提升通关效率，带动更多人使用皇岗口岸通关。尤其是对跨境求学、跨境通勤等高频往来人员而言，时间成本将显著降低。与此同时，客车通关效率也将同步大幅提升，缓解节假日通关拥堵的情况。
据了解，在新的通关模式下，针对跨境客车，传统深港两侧出入境车辆的两次查验、两次核验，将优化为“一次停靠、一次查验、协同验放”。跨境客车及司机在皇岗口岸联检大楼车检层“五合一”通道内即可完成两地5家查验单位的监管手续。
值得一提的是，重建后的皇岗口岸定位为深港之间最重要的24小时客运陆路口岸，皇岗口岸仍将是深港间唯一实行旅检24小时通关的口岸。
在杨秋荣看来，乘坐深圳地铁7号线直达皇岗口岸，只排一次队就能快捷通关，早上去香港，当天任意时间都能经口岸回深圳。这让大湾区生活圈的时空距离进一步缩短，跨境往来也不受时间限制，“说走就走”，大大便利大湾区居民的工作生活。
垂直布局高效组织出入境及交通换乘
全球最大的陆路口岸单体建筑
重建后的皇岗口岸实现了空间、功能全方位重构，空间格局的重塑不乏看点。
作为目前全球最大的陆路口岸单体建筑，重建后皇岗口岸联检大楼总建筑面积达68.97万平方米。口岸为综合立体垂直布局口岸，联检大楼有地上五层、地下四层。
皇岗口岸联检大楼的设计概念取意“湾区基石，国之重器”，大楼整体形态对称、稳固、庄重，外观以流畅的曲面造型呈现。近日，南都N视频记者提前探营时看到，大楼内部空间开阔明亮，L4层天花板设计以深圳市花簕杜鹃为设计原型，展现设计美感。整座大楼采用综合立体垂直布局，高效组织口岸出入境及公共交通换乘。
地上部分：地上一层为香港往深圳方向车检层；地上二层为港方非过境交通接驳层并包含深港跨境巴士接驳区域；地上三层为深圳往香港方向车检层；地上四层为深圳往香港方向旅检层；地上五层为香港往深圳方向旅检层。
地下部分：地下一层为深方非过境交通接驳层；地下二层为预留的轨道查验层；地下三、四层为停车场。
整栋大楼通过垂直布局和分流动线设计，实现出境入境客流分隔、人车流线互不干扰。
引入多条轨道线路
辐射大湾区的未来枢纽
“作为大湾区核心通关节点，重建后的皇岗口岸将推动人流、物流、资金流、信息流跨境高效便捷流动，助力大湾区建设。”杨秋荣表示。
据了解，重建后的皇岗口岸变身超级口岸，更将与多条轨道交通线路相连，串联广深港澳科技创新走廊，打造综合交通枢纽，进而大大强化这座超级口岸的辐射力。
目前，已开通运营的深圳地铁7号线设皇岗口岸站，在深圳一侧实现了地铁直达口岸。穗莞深城际前海至皇岗口岸段正在加快建设中，未来在皇岗口岸可便利搭乘城际铁路。港铁北环线支线规划接入皇岗口岸，据港方此前消息，北环线支线预计于2034年或之前与北环线主线同步开通。此外，规划中的深广中轴城际同样拟在皇岗口岸设站，目前该项目还有待落地。
“这带来的变化，是把皇岗口岸从深港口岸升级为辐射大湾区的枢纽口岸。比如，未来一位东莞或广州的科研人员、产业人才，可以便捷搭乘城际到皇岗口岸，直通河套深圳园区和香港园区，人才腹地由此进一步扩展。”中国人民大学深圳研究院研究员陈嫣嫣说。
陈嫣嫣指出，皇岗口岸枢纽功能将分阶段兑现，接下来相关轨道线路的落地进度，将决定皇岗口岸辐射能力兑现的节奏。（南都N视频记者 王睦广 黄璐 / 摄影：南都N视频记者 赵炎雄）
