# 曹俊文辞职

曹俊文辞去山煤国际能源集团股份有限公司（以下简称“山煤国际”）副总经理职务。
7月8日，山煤国际发布公告称，公司董事会于2026年7月7日收到副总经理曹俊文先生提交的书面辞职申请，曹俊文先生因工作变动原因申请辞去公司副总经理职务。辞职后曹俊文先生将不再担任公司任何职务。根据《公司法》和《公司章程》的有关规定,辞职申请自送达公司董事会之日起生效。
