# 具身智能由“计算智能”转向“行动智能”，推动产业升级与社会变革

人民网研究院组织编写的智能互联网蓝皮书《中国智能互联网发展报告(2026)》7月29日在北京正式发布。其中，中国科学院计算技术研究所副研究员宋新航、助理研究员张思贤、研究员蒋树强共同撰写的《2025年具身智能发展状况与趋势》一文指出，2025年，具身智能由“计算智能”迈向“行动智能”，在世界模型、群体协同、数据基建等方面取得显著进展，成为推动产业升级与社会变革的重要力量。
文章详细梳理了2025年具身智能多项关键技术成果：基础模型完成“离线预训练”到“在线进化”的跨越，机器人本体与零部件性能持续优化，虚实融合训练平台大幅提升机器人训练效率，数据合成技术有效补齐长尾场景数据短板。依托技术进步，具身智能在工业、医疗、商业服务、高危能源等场景落地大量标杆案例。
文章分析了当前行业发展面临的核心问题，包括物理世界精准交互与理解技术尚存瓶颈、具身智能生态尚不完整、技术和产品标准尚不统一等。文章认为，面向未来，具身智能技术将走向“认知—感知—行动”一体化，场景将从标准化环境延伸至农业、建筑、深海、太空等极度非结构化领域，中国有望成长为全球最大的具身智能生产与应用市场。对此，我国应统筹推进人才培养、数据基建、标准法规、技术攻关，搭建产业创新联合体，完善伦理与法律框架，多措并举推动具身智能持续健康发展。
