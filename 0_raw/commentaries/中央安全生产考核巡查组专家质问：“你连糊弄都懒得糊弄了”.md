# 中央安全生产考核巡查组专家质问：“你连糊弄都懒得糊弄了”

7月下旬，中央安全生产考核巡查组第十九组对甘肃省安全生产工作进行明查暗访。
在陇南市金徽酒股份公司考核巡查组发现，该公司未开展粉尘爆炸风险评估，原粮粉碎车间粉尘涉爆干式布袋除尘器，未采取泄爆、抑爆等爆炸防控措施。
在陇南祥宇油橄榄开发公司考核巡查组发现，该公司日常安全管理流于形式。
专家质问该公司负责人，“你连糊弄都懒得糊弄了，安全意识、现场、应急预案等环环失控。”
