# 德国：计划建立国有战略天然气储备以应对能源紧急情况

德国计划打造国有战略天然气应急储备。
德国经济与能源部7日宣布，计划建立国有战略天然气储备以应对能源紧急情况。
德国经济与能源部当天表示，该战略天然气储备总量约24太瓦时，相当于德国天然气总储备量的近10%。采购将在两三年内分批完成，预计2027年夏季首次向储存设施注入天然气。
德国方面称，建立战略天然气储备旨在应对关键能源基础设施遭破坏或全球天然气严重短缺等极端状况。但路透社的报道说，自2022年乌克兰危机全面升级以来，德国一直谋求加强能源安全，以摆脱对俄罗斯能源的依赖。
另有消息人士披露，该储备项目预计耗资12亿欧元至15亿欧元，年运营成本约1.5亿欧元至1.8亿欧元。相关资金将通过向天然气消费者征税筹得。项目预计将在8月中旬获内阁批准。
