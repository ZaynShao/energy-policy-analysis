# C Talk | 倍耐力首席执行官安德烈亚·卡萨卢奇：全球轮胎巨头如何响应中国汽车产业之变

对话 | C Talk栏目主理人、盖世汽车CEO兼资讯总编 周晓莺
撰文 | 盖世汽车编辑 刘彩君
如今的中国汽车市场，“快”早已不只体现在新车上市的速度上。整车架构与动力系统持续演进，车型迭代周期不断缩短，这种变化也在向产业链上游传导。对国际轮胎企业而言，跟上中国车企的步伐，不只是加快供货，还要在有限时间内完成从需求分析、产品开发、测试验证到量产交付的全过程，并应对新能源汽车带来的多重性能要求。
在这样的趋势下，“全球研发、中国落地”也有了更丰富的内涵：它不再只是把海外研发的成熟产品引入中国，而是要让全球技术能力与中国市场的需求、开发节奏和制造体系真正衔接起来。
倍耐力首席执行官安德烈亚·卡萨卢奇（Andrea Casaluci）对这一变化有切身体会。2015年，他来到中国担任倍耐力亚太区首席商务官。彼时，中国主要被视为一个具有竞争力的制造基地。倍耐力在这里开发并生产轮胎，为在华的西方汽车制造商提供配套；而绝大部分研发工作仍在欧洲完成，之后才导入中国市场。
十余年过去，中国在倍耐力全球体系中扮演的角色已大不相同。正如卡萨卢奇先生近日在接受盖世汽车专访时所说：“中国汽车产业发生了巨大的变化，已经成为了全球汽车产业重要的创新中心。”
盖世汽车CEO兼资讯总编周晓莺（图左）与倍耐力首席执行官安德烈亚·卡萨卢奇（Andrea Casaluci）
这一判断有着具体的产业背景。2026年以来，中国新能源汽车的单月市场渗透率一度超过60%；软件定义汽车架构、自动驾驶以及由新型动力系统推动的电动化等前沿技术，也在加快发展并得到广泛应用。过去五年，倍耐力与一批中国新兴高端电动汽车制造商建立了紧密合作，其中一些品牌已经开始走向海外。
面对这样的市场，倍耐力需要做的已不只是本地生产和配套，还要更早理解客户需求，让全球研发力量与中国团队协同起来，并推动新技术更快完成产品化和产业化。
承担这一任务的，正是倍耐力亚太区研发与创新中心。该中心于2022年在山东省济宁市兖州区华勤工业园区落成，并被纳入倍耐力全球研发网络。它并非单向承接总部研发成果的本地执行机构，而是连接全球技术开发与中国市场应用的重要节点。
按照卡萨卢奇先生的介绍，倍耐力的新技术大多由米兰总部负责开发，亚太区研发与创新中心则在中国同步推进相关技术的应用和产品产业化。随着本地研发能力不断提升，中国团队还能够更早、更准确地洞察本土客户需求，并将来自中国市场的参考和建议反馈给总部研发中心。
研发体系更贴近市场，只是第一步。中国车企产品更新快，整车架构和动力系统仍在快速演进，留给轮胎开发与验证的时间也随之缩短。卡萨卢奇先生坦言，这给倍耐力带来了不小的挑战，而研发流程虚拟化正是应对这一节奏的关键。
借助建模、仿真和数字孪生等方法，倍耐力可以较为准确地模拟轮胎在实际使用中的动态表现，在虚拟环境中完成大部分开发工作，直到研发流程的最后阶段才制作实体样胎。据卡萨卢奇先生介绍，这种方式可以使开发速度提升至少30%，同时减少样胎数量，降低对环境的影响。
虚拟化的价值还不止于缩短开发周期。面对新能源汽车，轮胎需要在多项性能之间重新寻找平衡：电池带来的额外重量要求轮胎具备更高的负荷指数，电驱系统输出的更大扭矩对抓地力提出了更高要求；为了支持车辆续航，滚动阻力还要进一步降低。与此同时，传统发动机噪声减弱后，轮胎与路面接触产生的噪声更容易被车内乘员感知，静谧性和舒适性也变得更加重要。
这些复合性能要求，在与中国车企的合作项目中变得更加具体。针对轮胎需要在不同使用温度下保持较低滚动阻力的需求，倍耐力已在中国开发出超低滚动阻力解决方案；面对电动SUV因搭载电池而增加的整车重量，则推出了高负荷指数解决方案。
不过，中国市场带给轮胎行业的变化并不只发生在物理性能层面。软件定义汽车和车辆互联能力的发展，也在重新定义轮胎与整车系统之间的关系。
在卡萨卢奇先生看来，未来轮胎“不再只是将车辆作用力传递至路面的关键部件，而将成为能够采集数据、并为车辆动态控制系统提供信息与指令的智能载体”。
这一判断在Cyber™ 轮胎上有了更具体的体现。该系统通过轮胎内置传感器采集行驶过程中的相关数据，经倍耐力专用软件和算法处理后，实时传输至车辆电子系统，使轮胎所感知的信息能够进一步参与车辆驾驶控制。Cyber™ 轮胎由倍耐力意大利总部研发，目前，倍耐力正与部分中国本土车企开展合作，推动该技术尽快在中国落地。
Cyber™ 轮胎技术；图片来源：倍耐力
无论是回应中国市场的新需求，还是推动全球技术在本地落地，最终都离不开制造体系的承接。目前，倍耐力在中国拥有三座工厂，本地制造已成为其服务中国市场的重要基础。
此次中国之行，卡萨卢奇先生也到访了升级改造后的山东兖州工厂。对于总部规划如何落实到生产一线，他由此有了更直观的感受。在他看来，该工厂的自动化、数字化和电气化水平已经达到较高程度。
而倍耐力对制造升级的思考，并未停留在设备和产线层面。在自动化、数字化和电气化持续推进的同时，数据也被置于更重要的位置。卡萨卢奇先生表示，倍耐力希望将自身打造为一家数据驱动型企业，“让数据成为各项业务流程的核心，贯穿生产、研发、物流、行政管理等各个环节”。
工厂内部的数字化之外，倍耐力也在重新审视生产布局与市场之间的距离。过去五六年间，新冠疫情、物流危机、俄乌冲突，以及欧洲能源成本上涨等，接连给跨区域生产与供应带来压力。卡萨卢奇先生表示，这些经历让倍耐力更加坚定地将“本地服务本地”（Local for Local）作为供应链战略的首要原则。目前，倍耐力在中国销售的产品中超过90%在本土生产，而在欧洲市场，这一比例同样超过90%。
