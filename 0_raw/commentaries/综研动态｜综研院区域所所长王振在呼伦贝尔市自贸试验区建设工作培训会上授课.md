# 综研动态｜综研院区域所所长王振在呼伦贝尔市自贸试验区建设工作培训会上授课

7月8日，呼伦贝尔市全市自贸试验区建设工作培训会召开，全面落实自由贸易试验区提升战略，精准对接国际高标准经贸规则，进一步明确呼伦贝尔市建设中国（内蒙古）自由贸易试验区的具体实施路径。呼伦贝尔市委副书记、市长及永乾主持并讲话。
会上，综合开发研究院（中国·深圳）区域发展规划研究所所长王振作专题授课。
会议强调，建设中国（内蒙古）自由贸易试验区，是国家立足构建新发展格局、筑牢向北开放重要桥头堡作出的全局性、战略性重大部署，满洲里片区的成立，开启了呼伦贝尔全市以口岸为引领、加快推进全域协同开放的崭新一页。全市上下要牢固树立“一盘棋”思想，强化责任担当，凝聚攻坚合力，敢于突破创新，高标准建好内蒙古自贸试验区满洲里片区，带动全市全域开放提档升级。
会议要求，要按照《中国（内蒙古）自由贸易试验区总体方案》，立足满洲里片区功能定位，加快推进试点任务和改革举措，因地制宜大胆创新，力争早见效果、多出成绩。要积极学习其他沿边自贸试验区的成功经验，能够直接复制的要充分利用现有条件加速落地，需要优化适配的要结合实际进一步进行本土化改造，下功夫探索出一批可复制推广的新鲜成果。要全面落实呼伦贝尔市自贸全域联动发展思路，用好用足自贸试验区金字招牌，加大招商引资、引企引智、平台集聚力度，做实做优外贸进出口各项工作，全面激活全市口岸经济、外向型经济新动能。（呼伦贝尔新闻）
