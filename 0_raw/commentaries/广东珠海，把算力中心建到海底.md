# 广东珠海，把算力中心建到海底

//珠海。（观海融媒李建束 摄）
继2025年8月在全国首提“海上新基建”，10个月后，广东珠海拿出了更具体的行动方案，在6月29日发布全国首个城市级“海上新基建”建设行动方案及首批投资机会清单。
根据《珠海市“海上新基建”建设行动方案（2026-2028年）》，到2028年底，珠海将全面建成物理、数字、生态空间深度融合的现代化海上新基建体系。33个投资机会清单涵盖智慧航运、深远海绿能、海底算力、海洋牧场、海岛开发等领域，包括万山海域海底数据中心、海上综合能源岛、具身智能海洋特色模拟训练区等。
作为海洋大市，珠海在2024年海洋产值首次突破千亿大关，2025年，海洋经济占地区生产总值比重达22.4%。但要成为海洋强市仍有距离。
通过此次发布，珠海正在试图回答一个关键问题：当AI算力需求呈指数级增长，“算力的尽头是电力”成为行业共识，一座拥有9348平方公里海域和262座海岛的沿海城市，能否找到一条不同于内陆数据中心集群的发展路径？
把数据中心“沉”进海里
传统算力产业的增长瓶颈，在沿海核心城市愈发凸显：需求高度集中、负荷密度大，土地资源紧缺，同时绿电占比、数据安全与跨境合规的要求不断提升。
最新发布的行动方案将珠海的海上新基建拆解为六个可落地的产业赛道：在交通层，数字孪生港口与低空物流航线构成海上运输的数字化底座；在能源层，深远海风电与绿色能源岛试图解决离岸供电这一核心痛点。
在通信层，海底光缆、5G网络与卫星通信为海上作业提供实时数据传输能力；安全层，立体安防与生态监测系统承担风险预警功能；在产业层，智慧养殖与智能装备指向海洋经济的产值转化；而算力层——海底数据中心与海洋大模型被定位为整个体系的决策中枢，承担数据处理和智能调度的功能。
//珠海海上新基建蓝图（界面新闻记者拍摄）
海洋基建属于高投入、长周期的重资产赛道，当前整体以央企国企龙头为核心牵头主体，主导核心技术验证与重大项目落地。国家电投集团副总经理陈海斌在6月29日的“海上新基建”融合发展大会上提到，将与珠海市合作推进90万千瓦海上风电直连海底数据中心项目。此前，集团已在珠海落地横琴综合能源项目，并建造了全球首台20兆瓦级“图强号”漂浮式风电机组浮体工程。
诸多赛道中，海底算力中心被视为有望率先突破的领域。南方海洋实验室首席科学家孙冬柏接受界面新闻采访时指出，未来将在珠海落地基于岛礁连廊的海底算力中心，“过去五年多来，我们解决了一系列核心关键技术，包括岛礁连廊的整体设计，海底地基的设计打造。针对海水腐蚀环境，我们发展了一种新型的材料，叫钛钢复合材料，用于构造数据方舱。同时采用新的换热材料，开发了新型热交换系统，以提高换热效率。”
孙冬柏提及，现有实践证明，海风直连海底数据中心可实现绿电直供率超过95%，PUE降至1.15以下，节水节地成效显著。
珠海市海洋发展集团有限公司副董事长胡正然向界面新闻分析指，珠海的最大优势在于场景，包括海洋产业投资、海工装备、海洋智慧养殖、海洋能源等领域，“珠海的陆地面积有限，而海洋面积非常广阔，开发海洋既有经济上的效益，也有出于安全战略的考量。”
能源侧如何破局？
不过，海上算力的落地，不能只靠海底数据舱单点突破，更需要源侧的风电平台担任海上公共载体。国华能源投资有限公司副总经理马艺峰告诉界面新闻，目前正和珠海科技产业集团合作推进 50万千瓦海上风电项目，预计今年四季度开工、明年三季度投产，每年能提供15亿度绿色电力。
“我们对珠海进行了资源评估，珠海具备海洋油气，以及海洋风电，也有丰富的渔业资源，已经有了较好的资源开发场景。另外，珠海具备深水港区和群岛的开发条件，适合于落地综合能源开发项目。”远景能源有限公司粤海区域总经理李鹏告诉界面新闻。他是粤港澳海上风电核心落地企业负责人，主导大兆瓦多功能海上风机规模化建设。
李鹏认为，海洋风电和绿色航运有望最先突破。公司目前正在珠海落地相关项目，包括海上风电、高栏港建设和综合能源岛等。今年行业最大的变化是对绿色算力的需求大幅上涨，“比起以前集中式、大型的万匹级算力，目前还出现了分散式算力，特别是集中应用场景的周边，类似于珠三角、长三角和周边的城市。例如深圳有大量中小创新企业需要分散式算力，珠海就能承接这个需求。”
//海上综合能源岛沙盘 （界面新闻记者拍摄）
“算力需求，特别是低延时高品质绿色算力呈指数级增长。特别是随着‘云上智城’算力战略的实施与千万千瓦级海上风电基地的加速谋划，珠海也在加快探索算电协同新业态。” 陈海斌提到。
布局海上新基建，一个底层动力来自珠海人工智能产业扩张带来的算力刚需。当地正以“云上智城”战略搭建全域算力体系，本土企业也不断迎来技术新突破。以“云上智城”的共建者跃昉科技为例，公司在近期完成了第一代自研高性能RISC-V处理器核LeapFive F1的研发。作为面向后续SoC集成与研发的CPU IP Core，LeapFive F1面向服务器、AI计算和高性能计算等应用场景，可作为后续高性能RISC-V SoC研发的核心计算底座。
跃昉科技方面告诉界面新闻，LeapFive F1是跃昉科技高性能处理器核F系列的首款内核。此次研发完成，意味着公司在高性能CPU IP、服务器级规范适配、AI推理支撑和复杂SoC系统集成等方向形成自研能力基础。后续将推进面向服务器、AI计算和高性能计算场景的大芯片架构研发。
“基于高主频、高指令并行度和多级缓存体系，F1可为高并发服务、复杂数据处理、高性能计算等任务提供更强的通用计算性能和系统响应能力，支撑后续高性能RISC-V SoC面向更大规模计算系统演进。”跃昉科技方面表示。
从本地供给到湾区辐射
在区域协同的视角下，珠海的海上新基建体系还将向外辐射，覆盖周边区域的产业需求。
孙冬柏认为，基于岛礁连廊的海底算力中心，不仅为珠海提供算力服务，也为香港和大湾区其他城市提供算力支撑，实现算力出海。
站在全省海洋经济的维度看，珠海的海上新基建并非孤立的城市布局。综合开发研究院（中国·深圳）前海分院副院长、可持续发展与海洋经济研究所所长胡振宇向界面新闻分析指，作为全国海洋经济第一大省，广东提出集合广州、深圳、珠海三大核心城市之力，打造“科创引领+高端产业集聚+深远海资源经略”三位一体的全能型海洋经济示范区。
“在这一格局中，深圳主打科技创新和产业资本，涉海企业超11万家；广州侧重于港口航运和海洋科研，集聚了大批国家级海洋科研机构；而珠海的优势则在于海域空间和海岛资源，以及国家海洋综合试验场这一独一无二的国家级平台。三者各有侧重、互补协同。珠海的海上新基建，不仅是自身发展的需要，更是支撑‘海上新广东’战略向深远海延伸的关键支点。”胡振宇提出。
从地理位置来看，珠海具备区位优势——地处珠江入海口西岸，是内地唯一与港澳陆路相连的城市。
//珠海与澳门相邻 （界面新闻记者拍摄）
胡振宇表示，横琴粤澳深度合作区作为“一国两制”下的制度创新试验田，正在打造数字贸易国际枢纽港，获批国家数据基础设施先行先试等两项国家级试点，“国际跨境可信数据空间-澳琴站”落地，可成为Token出海、AI资源汇集、智能结算的前沿阵地。
陈海斌指出，计划到“十六五”末，在珠海率先实现100万P规模化算力产业集群落地，建成一个集智能计算赋能、海量数据存储、安全备份、海底科学试验、科普观光体验于一体的系统性国家级算电协同示范工程，最终形成“陆数海算”“澳数珠算”的战略布局。
不过，海上新基建作为重资产、长周期的系统工程，规模化落地仍面临统筹与融资的现实考验。IDG旭智资本CTO郭宗林向界面新闻分析指，珠海岛屿分布零散、项目实施主体多元的现状，对全域能源底座的统筹构建提出了更高要求。发电、供电、储能等多能源一体化布局需要在现有海域空间规划之上，叠加离岸能源供给的专项顶层设计，以此规避重复建设与资源浪费，保障能源系统的稳定可靠。
投融资模式创新同样是破局关键。郭宗林认为，可探索设立海洋新基建专项产业基金，同时由政府引导多方资本联动，培育完整产业集群，有效降低企业前期投资风险。（界面新闻 记者 张熹珑）
