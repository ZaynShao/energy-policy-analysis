# CEO还是「教主」？Anthropic正遭受「信仰」反噬

Anthropic，一家估值逼近万亿美元、站在 AI 浪潮最前沿的明星公司，眼下最棘手的问题，可能不是模型性能，而是员工还信不信老板描绘的未来。
科技博主 Brian Roemmele 近日爆料称，他刚与一名 Anthropic 早期投资人通话。对方透露，公司投资者和员工的士气已经降至低谷，对日渐封闭的高层愈发不满，甚至向 Brian 征询：Anthropic 究竟该怎样才能继续作为一家独立公司生存？
Brian 随后给出了一番极具冲击力的描述：Anthropic 早期围绕 AI 安全、政治哲学和人类未来建立了一套高度统一的价值观，但随着公司扩张，一批新员工并不买账，部分老员工的观念也在生活经历中发生变化。
公司内部据称已经出现私下沟通渠道，用来宣泄对管理层的不满；一些员工则卡在两难之间：离开，意味着放弃价值不菲的股权，留下，又可能继续承受精神压力。
不过需要说明的是，这些说法来自匿名投资人和 Brian 的单方转述，目前尚未得到 Anthropic 证实，也没有足够证据说明公司正在「崩盘」。但这则爆料之所以引发关注，是因为其中描绘的文化裂缝，并非全无公开信息支撑。
CEO 亲自「布道」，愿景让人脊背发凉
Anthropic 从诞生起就不像一家普通科技公司。
2021 年，Dario Amodei 与妹妹 Daniela Amodei 等人离开 OpenAI 创办 Anthropic，核心主张是：能力越强的 AI，越可能带来灾难性风险，因此研发速度必须受安全机制约束。公司员工自称「蚂蚁」，不少人会在内部 Slack 开设个人「笔记本」，分享自己的想法、担忧和价值判断。
应聘者除了接受技术考核，还要通过专门的「文化面试」。《时代》杂志披露，其中一道示例问题是：如果 Anthropic 因为无法保证模型安全而决定不发布产品，你是否愿意承受所持股票价值归零？
更具 Anthropic 特色的是每两周举行一次的全员会「Dario Vision Quest」，简称 DVQ。
Dario 通常拿着三四页材料讲上约一个小时，内容从产品战略一路延伸到政治、战争、地缘竞争和人类命运。他本人曾表示，自己约三到四成的时间都花在维护公司文化上。
在公司规模较小时，这种强使命感可以让团队高度一致；当员工扩张至数千人，它也可能变成一道思想门槛。
《连线》采访的前员工给出了两种截然不同的描述：有人认为 Anthropic 内部辩论活跃，高层会认真回应批评；也有人称，真正尖锐的意见往往停留在私人群聊，DVQ 则像「听祭司布道」。这不能证明 Brian 所说的「士气触底」，却说明 Anthropic 内部确实存在使命凝聚力与思想多元化之间的拉扯。
而就在今天，还有更让人感觉不安的消息流出，根据网友分享的著名科技投资人 Gavin Baker 的播客片段，Dario 曾在 Anthropic 内部表示：「Anthropic 未来某天可能会成为世界上唯一的私营公司。」
不得不说，这个所谓的「愿景」听起来有些可怕，让人不免想起那些科幻故事中的反派科技寡头，比如《赛博朋克 2077》中控制城市、军队和数字生命的荒坂集团、《银翼杀手》中垄断仿生人技术的 Tyrell Corporation 以及《异形》中把殖民、科研乃至人命都纳入利润计算的维兰德-汤谷公司……
只是这一次，被垄断的可能是生产所有商品、知识和决策的「智能」本身！
想象这样一种未来：Claude 及其后继系统接管了编程、科研、金融、法律、医疗和企业管理。其他公司表面上仍拥有品牌、办公室与董事会，实际上却只剩下一层外壳：产品由 Anthropic 的模型设计，代码由它编写，风险由它评估，员工由它调度，经营决策也由它给出。企业之间看似仍在竞争，背后租用的却是同一个「大脑」。收入、数据与算力不断向这个大脑集中，直到其他公司不再是真正独立的经营主体，而只是 Anthropic 智能基础设施上的应用程序。
更糟糕的情景是就连各种公共服务都离不开这一系统，Anthropic 便不再只是市场中的一家公司，而会成为整个社会的「操作系统」：它可以决定哪些研究足够安全、哪些行业值得继续存在、谁有资格获得高级智能，以及什么样的价值观能够写进模型。
到时，社会看起来还是各司其职，但所有选项早已由一家私人公司的系统筛选、排序和解释。届时，所谓「世界上唯一的私营公司」，意味着它不仅赢下了商业竞争，也让传统意义上的市场、劳动和公共权力逐渐失去存在的基础。
也因此，这段视频引发了强烈的警觉和嘲讽：如果一家企业坚信自己最有资格保护全人类，那么人们自然会追问：究竟是谁授权它代表全人类？
一边高举安全，一边把油门踩到底
回看 Anthropic 近年的一系列「骚操作」，这种矛盾感更加明显。
它一面不断警告超级 AI 可能制造生物威胁、失控乃至危害人类，一面又必须训练更强的模型、争夺客户和算力。2026 年 2 月，Anthropic 修改其「负责任扩展政策」，收窄了必须推迟模型开发或发布的条件。公司的解释是，单方面停下并不能阻止竞争对手前进，安全承诺也必须考虑中美竞争和行业现实。
它还曾为阻止外国对手借 Claude 推进前沿 AI 研究，给模型加入可能暗中干扰相关工作的机制。研究界质疑这等同于让 AI「秘密搞破坏」后，Anthropic 几天内又撤回方案，承认没有把握好边界。参阅报道《刚刚，Anthropic道歉了》。
更戏剧性的一幕发生在五角大楼。Anthropic 愿意让 Claude 服务美国国防和情报系统，却拒绝放开两条红线：完全自主武器，以及针对美国民众的大规模监控。这一坚持令其与特朗普政府关系急剧恶化。支持者认为它守住了底线，批评者则认为一家私人公司试图替政府决定战争规则。无论如何，这场冲突已经从价值观争论变成了真实的政治和商业风险。
前些天，Anthropic 在 Claude 文本输出中加水印的政策也引发了广泛不满。
就在今天，Anthropic 发布了一份 FAQ，回应外界近期对 Claude 文本水印机制的疑问。
简单来说，Anthropic 表示，其引入水印主要是为了遵守欧盟《人工智能法案》的相关要求。其他签署同一份《行为准则》的主要模型开发商，未来也将实施类似机制。
按照 Anthropic 的说法，这套水印不会对 Claude 输出的质量和内容产生实际影响，普通读者也无法分辨一段文本是否带有水印。水印不会通过添加额外文字或隐藏字符实现，也不会消耗额外 Token，因此不会增加使用成本。
此外，Anthropic 强调，这类水印无法追溯到具体个人、组织或某一次聊天记录。

万亿估值也开始「打折」
偏偏在此时，Anthropic 正在冲刺资本市场。
《华尔街日报》称，公司正密集会见潜在投资者，为可能创下纪录的 IPO 稳定信心。投资人追问的重点包括：中国低价模型会不会击穿其商业护城河，与特朗普政府的摩擦是否会影响订单，以及疯狂扩建数据中心最终能否获得足够回报。
5 月 28 日，Anthropic 完成 650 亿美元融资，投后估值达到 9650 亿美元，并称年化收入已突破 470 亿美元。此后更是估值突破万亿美元，峰值时接近 1.4 万亿。
但截至今天，Stock Analysis 依据 Hiive 二级市场价格计算出的隐含估值约为 8166.5 亿美元，较正式融资估值低 15.37%。需要注意的是，正式融资与流动性有限的二级市场并非同一口径，这个差额不能简单理解为公司价值已经「蒸发」，却足以说明市场热度有所下降。
不过，如果因此判断 Anthropic 已经开始失去吸引力，恐怕又太早了。
硬币的另一面：Anthropic 依旧在「生长」
就在外部投资人不满，内部矛盾不断、士气低迷，困于离开还是留下的「抉择」时，依然不断有顶尖人才主动登上这艘船。
最近，谷歌研究员 Justin Gilmer 被曝已经离开 Google Brain，加入 Anthropic。
Gilmer 在 AI 圈之外还有另一段颇具传奇色彩的经历。2022 年，他利用信息论方法研究困扰数学界数十年的「并封闭集猜想」（Union-Closed Sets Conjecture，又称 Frankl 猜想），首次给出了一个常数下界，将此前随着集合规模不断趋近于零的最好结果直接推进到固定常数 0.01。这项工作虽然没有彻底解决猜想，却被视为该问题几十年来最重要的突破之一。
而在产品端，同时也有人才流入。
近日，在微软工作约 15 年、长期参与 VS Code 开发的 Benjamin Pasero，发文宣布自己于今年 8 月加入 Anthropic，新工作是负责 Claude Code 开发，尤其是其桌面应用程序。
当下，Claude Code 无疑已经成为 Anthropic 商业增长的重要引擎之一，在 AI 编程市场愈发火热的时刻，Anthropic 仍然能从 VS Code 这样的成熟开发者产品团队中吸引核心工程人才，至少说明 Claude Code 对顶尖开发者仍有足够强的吸引力。
而更直观的信号还是来自于钱。
近日，彭博社披露了 Anthropic 最新的二季度数据，2026 年第二季度初步营收已经超过 115 亿美元，相比 2025 年同期约 7.87 亿美元的收入，增长超过 14 倍；相比今年一季度约 47.3 亿美元，也已经翻了一倍有余……
因此，Anthropic 虽然争议越来越大，但看起来依旧如日中天，Claude 依然是全球最强的 AI 产品之一，人才磁力、公司收入和企业客户仍在快速增长。真正危险的是：其最重要的资产（那套曾帮助它凝聚人才、区别于 OpenAI 的信仰）正在变成一道治理难题。
