# 融科热控：储能温控如何实现大功率+小身体？

在北京储能展首日，高工储能走进融科热控展台。

高工储能在现场了解到，作为深耕热管理领域多年的标杆企业，融科热控此次携13款储能热管理核心产品重磅参展，全面覆盖风冷、液冷两大品类，功率跨度从2kW至120kW，形成了完整的产品矩阵，精准适配261kWh、522kWh工商业储能集成柜，以及5-20MWh长时储能系统等多元应用场景。
