# 国际原子能机构：俄乌冲突给核电站安全带来持续风险

国际原子能机构总干事格罗西表示，俄乌冲突给核电站安全带来持续风险。
▲国际原子能机构总干事格罗西（资料图）
国际原子能机构总干事格罗西当地时间7月9日表示，近日驻扎在乌克兰各核电站的国际原子能机构团队多次听到军事活动的声音，包括无人机和枪声。目前尚无关于核电站受损的报告。
驻赫梅利尼茨基核电站的国际原子能机构工作组于7月8日凌晨听到了军用飞机的声音，随后获悉在该站以北探测到了无人机。南乌克兰核电站报告称，7月5日凌晨探测到6架无人机，7月2日探测到3架无人机。在扎波罗热核电站，国际原子能机构工作组于7月6日听到枪声，随后在室外时又听到了无人机从头顶飞过的声音。
格罗西表示，这些报告凸显了在当前冲突中核安全与安保面临的持续风险，也反映出各类核设施所处形势严峻。他呼吁在核设施周边保持最大限度的军事克制，并全面遵守核安全与核安保七项支柱原则。
