# 张深秋，涉嫌受贿、挪用公款、挪用资金案，数额特别巨大

日前，内蒙古矿业（集团）有限责任公司原党委委员、工会主席张深秋涉嫌受贿罪、挪用公款罪、挪用资金罪一案，由内蒙古自治区监察委员会调查终结，移送检察机关审查起诉。经内蒙古自治区人民检察院指定管辖，由内蒙古自治区人民检察院锡林郭勒盟分院依法向内蒙古自治区锡林郭勒盟中级人民法院提起公诉。案件正在进一步办理中。
检察机关在审查起诉阶段，依法告知了被告人张深秋享有的诉讼权利，并依法讯问了被告人，听取了辩护人的意见。内蒙古自治区人民检察院锡林郭勒盟分院起诉指控：被告人张深秋身为国家工作人员，利用职务上的便利，为他人谋取利益，非法收受他人财物，数额特别巨大；利用职务上的便利，挪用公款归个人使用，进行营利活动，情节严重；利用管理私营公司的便利，挪用资金归个人使用，进行营利活动，数额巨大，依法应当以受贿罪、挪用公款罪、挪用资金罪追究其刑事责任。
