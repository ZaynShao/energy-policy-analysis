# 金风科技20MW及650余台海上机组顺利通过台风“巴威”考验

7月11日至12日，台风“巴威”在浙江沿海两次登陆，中心附近最大风速约40米/秒（风力13级）。其环流云系覆盖福建北部、浙江全境、上海东部及江苏东南部，随后一路北上至山东半岛海域，南北影响跨度近千公里，影响持续至14日。面对台风威胁，金风科技自7月11日14时便启动预警响应，截至7月14日11时正式结束预警响应。期间，约14个已投运海上风电项目、总容量约495万千瓦的近650台机组，凭借成熟的抗台风体系与“一项目一策”精细预案，全部顺利通过台风考验，目前正有序开展过境后机组检查工作。台风是海上风电面临的最严峻考验之一。当台风中心风速达到40米/秒（13级）时，其强湍流和风向突变将严重威胁机组安全，极可能导致叶片断裂、倒塔等重大事故。因此，抗台风技术是海上风电发展不可或缺的“保护伞”。台风尚在西北太平洋洋面孕育之时，金风科技自研智能气象预警系统已提前锁定其动向。7月2日，台风过境9天前，系统就精准捕捉到热带扰动信号，即刻触发台风动向跟踪流程。基于高精度气象数据与海量历史台风样本库的智能算法，系统持续推演“巴威”的可能行进路径及对各风场的风圈影响，提前55小时向14个相关项目发出分级预警，为现场部署预留充裕的应对窗口。台风“巴威”路径横跨千里，不同海域风况差异显著：江苏、上海海域以持续大风为主，福建海域则面对台风与涌浪的复合冲击。2025年，金风科技在上述区域新交付的230米以上大叶轮机组超过240台，全部进入台风影响范围。预警启动后，金风科技迅速集结气象专家、载荷工程师与一线运维工程师，针对不同项目的机组型号、海域条件，依托数字平台为每台机组定制“一项目一策”抗台策略。从变桨控制策略调整、偏航逻辑优化到塔基螺栓紧固，数百台机组提前调整至最优姿态，在台风中灵活应对变化，面对近30米/秒的最高瞬时风速，全程平稳度过台风考验。今年2月在福建并网的金风科技20MW海上机组，同样处于“巴威”云系覆盖之中。该机组从设计之初即植入抗台风基因：在IEC标准之上，额外完成18个台风工况仿真验证，可承受80米/秒瞬时风速。台风逼近前，技术团队远程完成抗台模拟与备用电源切换测试。台风过境期间，机组各项指标平稳，更在真实台风工况下开展机组抗台风测试，测试结果表明，机组三支叶片载荷均匀，机舱振动稳定，整体表现稳健，以实战校验超大叶轮机组可靠性。“确保风机安全稳定运行，最大限度保障客户资产安全”，是金风科技迎战台风等极端天气始终坚守的核心目标。此次成功抗击“巴威”，是客户企业与金风科技联合团队深化抗台方案的又一成果，也是抗台技术积淀与智能运维体系协同的集中体现，为海上风电应对极端环境再添宝贵经验。
