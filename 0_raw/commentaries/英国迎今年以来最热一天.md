# 英国迎今年以来最热一天

英国气象局表示，8月13日成为英国今年以来最热一天，也是英国有记录以来第五热的一天。
英国气象局当地时间8月13日表示，当天在伦敦西南部的英国皇家植物园邱园初步录得高达38.1摄氏度的气温。这使得13日成为英国今年以来最热一天，也是英国有记录以来第五热的一天。
英国气象局说，这是今年第二次气温达到38摄氏度。此前仅有2022年曾在一个自然年内两度出现38摄氏度高温。此外，英格兰的伍斯特郡珀肖尔当天最高气温达到38摄氏度，英格兰中部和南部共有40个观测点录得不低于36摄氏度的气温。
英国气象局说，今年夏季已打破多项气温纪录，英格兰和威尔士大部分地区异常干燥。据英国广播公司报道，英格兰和威尔士今年已记录1017起野火。
