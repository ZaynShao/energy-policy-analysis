# 绿金新闻 | 消费品以旧换新带动绿色、智能消费增长

8月20日，商务部消费促进司负责人在介绍2026年7月我国消费市场运行情况时表示，7月份新能源乘用车零售渗透率达65.1%，再创历史新高。同时据商务部商务大数据监测显示，7月份重点电商平台具身智能机器人销售额同比增长95.1%，外骨骼助力器销售额同比增长39.5%，运动相机销售额同比增长24.7%，扫地机器人销售额同比增长19.4%。
“消费品以旧换新带动绿色、智能消费增长。”该负责人说。他还指出，今年以来，我国消费市场保持向新向优发展态势，市场规模稳步扩大、发展质量不断提升。
除绿色、智能消费成新风尚外，商品消费提质升级趋势明显。7月份，商品零售额增长0.5%。基本生活类商品增长平稳，限额以上单位粮油食品、饮料、日用品零售额分别增长5.3%、3.5%、1.8%；部分升级类商品增长较快，限额以上单位通讯器材、文化办公用品、化妆品零售额分别增长20.4%、7.4%、6.8%。
服务消费亮点纷呈，暑期服务消费潜力充分释放。1-7月，服务零售额增长5.0%，持续高于商品零售额增速。其中，餐饮收入增长2.6%；旅游咨询租赁服务、文体休闲服务零售额增长超过10%。暑期档电影火热，7月份电影总票房超50亿元，增长超过20%。
城乡结构持续优化。1-7月，乡村消费品零售额3.8万亿元，增长2.4%，增速比城镇快1.3个百分点。县域消费市场动能不断加强，包含镇区和乡村的县乡消费品零售额占社会消费品零售总额的比重达39.1%，比上年同期提高0.3个百分点。
