# 申报即将截止！余杭区“好苗子”企业速看 “好苗保” 申报指南

政策详情
Project Information
近期，由市科技局、市财政局联合实施的统一保障计划——“好苗保”科技保险正在申报中。
“好苗保”由杭州市科技局作为投保人，统一为全市首批研发强度高、成长潜力大、抗风险能力较弱的“好苗子”企业投保，保费由财政全额承担。企业不用花一分钱，即可享受为期2年，覆盖研发到成果转化到中试再到示范应用全链条保障。
“好苗保”采用“基础版主险+产业拓展版附加险”的组合方案，每家企业申报一个研发项目，配备五项主险加一项产业定制附加险，六项合计最高保障160万元。
其中五项主险合计140万元，覆盖五大风险：研发失败、成果转化失败、中试转化失败、产品研发责任、关键设备损毁。每一项都有明确的保额和赔付标准。例如，项目因故终止或失败，已发生的研发费用最高可赔25万元；设备坏了、资料丢了，维修重置费也能报。
此外，附加险针对杭州市“296X”先进制造业集群涵盖的17个产业，定制化推出“一产一策”（保额20万元）。集成电路企业最怕流片失败，人工智能怕算法缺陷，生物医药怕临床试验出事，低空经济怕飞行器坠落……不同产业的最核心风险，都有专属保障。
保得上更要救得活。“好苗保”突破传统保险“只赔钱”的被动模式，创新推出“承保-理赔-救济-减量”四段式服务。
当研发走进“死胡同”，保险公司根据企业意愿，可以启动“研发救济”服务：安排行业专家上门会诊、驻场攻坚，尽力帮项目“起死回生”。若企业整体理赔率较低，则启动“风险减量”服务，把省下的保费转化为技术攻坚、工艺优化、产业交流等增值服务。不管出没出险，这笔钱最终都花在企业身上，真正成为创新的“护航员”。
2026年杭州市“好苗保”科技保险项目招标遴选的三家保险公司为太平洋产险、人民财险、平安产险。
申报期间，3家承保保险公司将主动联系名单内的“好苗子”企业，上门讲解政策、一对一指导准备材料。企业只需在“科技大脑”平台或“五位一体”杭创E站线上提交申报材料，全程不需要缴纳任何费用。所有企业材料收齐后，保险公司将一次性集中承保，届时企业可在“科技大脑”平台查看参保凭证。
申报指南
线上登录杭州科技大脑，网址如下：
https://ypt.kj.hangzhou.gov.cn/dn/src/pms/index.html#/portal/home
进入“用户中心”→选择“科技保险”业务栏目发起投保
选择所属产业→申报参保项目→填报相关信息
填报提示：申报阶段如研发项目、研发设备栏目暂无合适内容，可先行提交；后续支持新增相关条目，但已填报内容不可修改。
企业请于8 月31日前填写完成申报信息填报并提交。
