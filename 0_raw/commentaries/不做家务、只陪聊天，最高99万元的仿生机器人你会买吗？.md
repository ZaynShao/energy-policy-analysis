# 不做家务、只陪聊天，最高99万元的仿生机器人你会买吗？

13361台，这是仿生机器人有史以来最高预售量。
作为对比，优必选2025年全年全尺寸人形机器人的销量才1079台。不过预售数据不代表最终销售额，7月15日交完尾款后的锁单量才更代表真实成绩。
但预售的热度仍旧反映了这场活动带给外界的新鲜感，6月30日，优必选在深圳举办的2026年度全球发布会上，一个穿着黑白蕾丝裙的“女性”缓缓走上台，突然展开双臂，开始机械地独舞。随后，一位人类男性上台搭手，在《La La Land》同款蓝黄背景下，共同完成了一支“人机共舞”的华尔兹。
发布会的尾声，还有一支机器人“模特团”绕台一周走秀。虽然偶有步伐踉跄略显僵硬，但从远处看，已经极其逼真。
走台中也混进了“人类”
这就是优必选旗下消费级品牌“优世界”交出的第一份答卷——全尺寸超仿生人形机器人U1系列。和数码产品相似，款型、定价分为了三档：半身版U1 Lite、高配全身版U1 Pro及高动态全身版U1 Ultra。
其中，U1 Lite售价11.98万元；U1 Pro 16.98万元；U1 Ultra男版99万元，女版88万元。
唯一可行走的仿生机器人，是价格直逼百万的Ultra系列；价格更“亲民”、已上京东天猫官方旗舰店的Lite、Pro系列，则是无法自主行走、但身躯关节柔软，能够“任人摆布”的坐立款。
但仿生机器人和工业级机器人面向不同市场，挑战有所不同。凤凰网科技在现场注意到，优必选为了为仿生机器人“正名”可谓做足了功课：签约海外合作大使、联合媒体成立伦理委员会、推出100台可定制的“人机伴独”公益项目……想从推出“优世界”这个单独品牌的初期，就把一系列后续可能出现的争议、问题尽可能扼杀在摇篮。
这一切背后，是一个深耕机器人14年的公司，试图从工厂流水线一步跨入人类卧室的巨大野心。
皮肤细腻、睫毛植绒，“任人摆布”
当你近距离观察仿生机器人时，最直观的冲击来自视觉和触觉。细腻的硅胶肌肤纹理、骨节分明血管凸起的手部、甚至唇纹都清晰可见。甚至，“女性”手部还做了美甲。
据凤凰网科技了解，这是优必选特意请来了外部设计师对此次“出展”的机器人们进行了“化妆”和“妆造”。在展示现场，有好奇的观众想要伸手抚摸机器人的肌肤纹理，一旁的工作人员会提醒，“脸不可摸，妆会蹭掉。”
据优必选介绍，优世界U1系列拥有88个自由度及独创双支点仿生颈椎，覆盖人类90%基础动作。该产品搭载全球首个针对长期陪伴的情感大模型，可识别20余种细粒度情绪，准确率超90%。其仿生快慢脑架构借鉴认知神经科学，实现500ms直觉反应与千亿级参数深度推理的协同。仿生表达驱动系统则是通过自研控制器将语音-唇形延迟控制在20ms内，尽可能减弱“机器人感”。
不过，从现场展示的互动来看，机器人的语音和唇形很难同步，比起“恐怖谷”效应，更多的感受是“头部会动的硅胶娃娃”。优必选展示了不同风格、造型的仿真机器人，但除了逼真外观外，机器人的互动感还是略显笨拙，只会机械地眨眼、歪头。有路过的观众评价，“挺像那些呆萌的网红小姐姐”。
在优必选的畅想中，优世界U1系列的应用场景能够覆盖日常陪伴、情绪支持、生活美学、社交辅助等消费类场景，以及迎宾接待、养老陪伴、心理疗愈、文旅展览、科研教学、高端家政服务等商用类场景。也因此，在现场设置了类似“医疗问询”、“儿童疗愈”等场景，但互动体验上只能近距离感受到机器人的“仿真”，对话智能部分还是略显迟缓。
这种极其逼真的背后是优必选独创的“三层肌肤建模”和仿真油性材料，模仿真人皮肤的温润触感和弹性。然而，想要将这种堪比蜡像的艺术品进行流水线量产，难度堪称“地狱级”。
“它的零部件，光头部就有两三千颗，这几乎占到了我们上一代工业机器人S2全身物料的百分之六七十。”优必选研究院院长焦继超在会后群访中向我们透露，这个小小的头部集成了19个自由度，能做30多种微表情。
更让人头疼的是外观一致性。创始人周剑坦言，早期的眉毛、睫毛完全依靠人手工植入。为了让这上万台机器人的妆容保持一致，而不是“千人千面”，团队正在摸索一套极度保密的量产工艺。“我们要把手工的艺术变成标准化的量产，用设备去模仿人手，这条生产线在人类历史上是前所未有的。”
这也是为什么，尽管线上线下的预定已经爆单，周剑却决定踩下刹车：“如果今年敞开来拿订单，我觉得三五万台至少，但我只能全心交付这一万多台。”他的目标是在今年完成1万台的交付，并在明年冲击5万台的产能。
硬件会沦为平庸，生态才是未来
要做全尺寸的仿真机器人，且有“性别”，一定绕不过的是涉及到伦理的“赛博伴侣”问题。
虽然优必选强调U1系列机器人提供的仅是“情绪价值”，没有性功能，但就从对外展示的造型来看，女性机器人仍拥有显著的第二性征。在会场展示区，观众可以近距离触摸的机器人们中，身着热辣短裤露着大腿的坐立机器人，也是当场被“抚摸”最多的。
在会后群访中，当被问及是否考虑跟乙游公司合作，且机器人是否“防水”的问题时，全场响起了不言而喻的笑声。周剑则回答，在适当时机、适当的阶段，不排斥和乙游公司的IP进行合作，“而且实实在在讲这个需求已经开始了，已经有非常多的头部IP在找到优必选了。”
据凤凰网科技了解，在发布会前就有乙游头部公司前来拜访、体验过仿真机器人，或在考虑合作中。
“如果伦理科技各个方面都是在符合条件的情况下，同时能够把一些东西避开掉的话，优必选是非常有可能进入到这个行业的。”周剑总结道。
从官方说明来看，目前产品防护等级为“非防水设计”｜图源：京东优世界官方旗舰店
而当外界还在用工业机器人的标准去衡量关节、电机和负载时，周剑的思考已经跳出了硬件的逻辑。在回应为何切入C端时，他抛出了一个犀利论断：“工业制造机器人有一天可能会沦为硬件。因为大家水平都差不多，都能搬箱子、打螺丝，没有家庭端这个生态的平台可想象力大。”
在优必选的叙事中，U1的第一属性不是工具，而是情绪价值的载体。周剑和优必选首席品牌官、机器人大消费创新事业部总裁、优世界总经理谭旻也反复强调，这款仿生机器人的首要任务是情感陪伴，而非做家务。在发布会展示现场，也请来了真人上演了一场“机器人提醒老人吃药”的小剧场。
这种定位决定了其商业模式。周剑表示，U1的定价是可以盈利的，但他更看重的是生态的持续性收费。他描绘了这样一个场景：当机器人与你建立情感链接，它会在日常聊天中判断你喜欢周杰伦，然后主动提醒你大麦网有演唱会；或者注意到你常穿深色T恤，建议你今天换件白色。
从“被动点击”到“主动交互”，这种入口的迁移意味着巨大的服务分发价值。为了构建护城河，周剑提出了“一硬一软一生态”三层壁垒：以情绪情感大模型为核心的软件、以超仿生量产工艺为代表的硬件、以及连接硬件软件与内容的生态。
不过，要完善这一切，最大的瓶颈仍是数据。谭旻直言，情感大模型和工业模型一样面临数据匮乏。优必选的解法是“正向数据循环”——率先量产铺货，用真实的用户交互反哺模型。“最后决定性的就是场景，只有场景才能积累足够的数据。”
在隐私保护方面，优世界采用方案是用户控制自身数据，用户可随时查看、导出与删除。同时，数据优先本地处理，非必要不上云。
看上消费级市场，海外将是重阵
这场豪赌背后，优必选的收入结构也可预见地会发生巨变。
周剑在群访中透露，去年工业机器人已占据相当一部分收入，而今年，“相信人形机器人的收入会超过优必选整体的80%”。这意味着，这家曾饱受质疑的公司，正将命运押注在具身智能的C端爆发上。
面对汽车巨头等跨界玩家的入局，周剑则认为，汽车公司受限于利润结构，很难像优必选这样在研发上不计成本。他将自己的核心能力归结为“能看到未来画面感”的想象力。
谈到机器人取代人类工作的经典焦虑，周剑则在演讲中谈及：“人体结构似乎不太适合长时间劳作……搬砖、拧螺丝，这些不是人类的爱好。人类寒窗苦读18年，结局不应该是像机器人一样去重复枯燥的劳作。”他玩笑般提醒大家，好好珍惜人类作为“牛马”最后的光阴，“可能就是5年、10年、20年的事了”。
在优必选的愿景中，未来机器人负责生产，人类负责创造和消费。为了将这份想象推向全球，谭旻和周剑也透露，将在今年下半年启动多国合规认证，最迟明年就要全方位布局和进军海外，覆盖东亚、东南亚、欧美等核心市场。在发布会现场，也出现了不少外国媒体、KOL和观众。
当穿着黑裙的“小优”在台上完成那支华尔兹时，周剑想表达的或许是他演讲中的那句话：“这次轮到我们告诉全世界，什么叫人形机器人。” 只不过，在抵达人机共生的彼岸之前，优必选需要先用这一万多台交付，迈过最为艰难的量产鸿沟。
