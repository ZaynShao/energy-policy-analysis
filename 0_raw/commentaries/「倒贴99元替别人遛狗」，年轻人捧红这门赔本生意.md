# 「倒贴99元替别人遛狗」，年轻人捧红这门赔本生意

从狗主人花钱请人遛狗，到打工人自掏腰包“代遛”，宠物经济的逻辑被悄悄改写的同时，围绕宠物租赁生意的合法性、安全保障的讨论从未停歇。
“原来借别人的狗玩这么爽！”
最近，社交媒体上“租狗”主题vlog越来越多。视频里，租宠人牵着小狗在公园里散步、拍照，非常和谐。
只需要15元甚至更少的花销，就可以和一只宠物狗共度一段温馨的时光。如果是名贵品种，租金则可能达到每小时99元。
（图/小红书截图）
理论上，租赁宠物生意完美契合了两类人的诉求：宠主需要短暂的休息，而因为各种原因无法养宠的人希望短暂地拥有宠物，双方一拍即合。在付费时段，租宠人可以像主人一样与小狗互动、玩耍。许多体验过的年轻人说，这样既能短暂地过一把瘾，又不必承担养宠的长期责任，是一种比较务实的选择。
随着宠物租赁的规模逐渐扩大，互联网上也掀起了一阵抵制宠物租赁的声音。反对者普遍认为，宠物因此成了商品，同时存在多方面的安全风险与权责模糊地带，为虐狗、贩狗人士提供可乘之机，一旦出事，难以定责。
宠物经济的逻辑被悄悄改写的同时，围绕宠物租赁生意的合法性、安全保障的讨论从未停歇。
为了了解这门生意如何运作，我在一个名为“汪步”的平台预定了一只宠物狗。
租宠人在注册时需上传身份证照片。我上传的身份证时间刚好过期，但还是注册成功。
有些小狗的时薪，已经比人的还高了。（图/汪步小程序截图）
小程序上的租宠价格大都在5元到50元之间，最便宜的一只2岁边境牧羊犬只需要1元/小时，而一些热门宠物要价200元/小时甚至更高。
综合时间与距离因素，我选择了一只雪纳瑞犬。它的主人设定的是“独立共享模式”，宠主不需要在场陪同，只有我和小狗单独相处。
每一只宠物都有自己的主页，会显示其他宠客的评价，主要分为宠物友好、接宠便利、服务态度三个方面。根据这只雪纳瑞犬的主页介绍，它性格安静、黏人，同时疫苗齐全、未绝育，不佩戴摄像头与定位器。
在“是否乘车出行、与其他犬只互动、接触儿童及用于商业拍摄”等方面，宠主也全部表示允许。
一些小狗被主人允许商业拍摄和与小朋友互动。（图/汪步小程序截图）
付费后才能查看宠物的具体信息，到指定小区楼下交接。宠主给了狗绳、拾便袋和狗用水杯，提醒我不要带小狗走太远，也不要喂食，并让我打开定位共享。
在一段和谐的相处后，我发现这只雪纳瑞并不排斥陌生人，非常乖巧。但当它嗅闻路边草丛、与路过小狗互动时，我突然担心，既怕小狗出事，也怕自己担责——宠物投毒案件、犬只互相撕咬也很常见，如果出现意外伤人或受伤的情况，租赁者要负哪些责任？这个规定的空白让我在享受遛狗的满足感时，一直有隐隐的不安。
遛狗时除了快乐，更多的还是谨慎。（图/新周刊记者 摄）
一小时后，我准时向宠主归还小狗，好奇主人是否担心遇到动机不良的租宠人。她表示多少还是有点担心，但“没有办法，平时实在太忙，每天又需要遛狗。如果有人帮忙，就只能冒点险了”。她会在交接时观察租宠人，发现不妥便取消订单，同时为小狗购买了宠物保险。
宠物主人可以为宠物购买保险，以防万一。（图/汪步小程序截图）
雪纳瑞的主人似乎觉得我和小狗相处很融洽，表示如果下次我还想遛，可以直接和她说，不收钱。
我答应着，但想起遛狗的辛苦还是其次，关于小狗安全和租赁责任的担忧，更让人觉得疲惫。
“这几十块钱，非得让狗赚吗？”
养宠人孟孟没有其他宠主那么“心大”。她养了一只名叫“狗剩”的黑色泰迪犬。狗剩非常亲人，喜欢人类摸它。孟孟不介意遛狗时有人摸它，但她不允许有人把它带离她的视线。
她不理解为什么有宠主愿意出租自己的宠物，“我接受不了我的狗出去‘打工赚钱’”。
孟孟的小狗“狗剩”。（图/受访者供图）
汪步小程序上，有些宠主允许宠客带着宠物与小朋友、其他牵绳动物互动，孟孟对此完全无法接受。她强调，有些犬类非常好斗，狗剩就曾被柴犬和柯基没来由地咬伤。
对宠主来说，安全问题是首先要考虑的：“如果小狗被咬或者咬人，该怎么定责呢？”孟孟觉得最后的责任大概率会算在宠主的头上，但这并不公平。
（图/《爱情而已》）
在她看来，无论是已经上线一段时间的小程序，还是社交媒体上由个人发起的租赁宠物服务，都缺乏足够的安全保障机制，有诸多风险。
“只要花几十块，就有可能带走一只品种犬，主人根本无从监督。”联想到社会上频发的毒狗、偷狗先例，孟孟不愿拿自己的爱犬赌这个概率。
狗剩被其他狗攻击的时候，孟孟会上手拉架，根本顾不上自己是否被咬。如果有意外发生，她可以不顾危险保护小狗，但她不相信花几十元租狗的人能做到。
孟孟的疑问，代表了一些爱犬者的心情：“这几十块钱，非得让狗赚吗？”
汪步客服表示，每一单宠物共享，平台会收取20%的抽成，这笔钱会全部返给宠客。
有网友发帖反对租宠小程序，汪步官方回复称，做宠物共享的初衷是“让宠物们拥有更多快乐出游的机会”，把这份互相陪伴的温暖传递给更多人：“我们始终把大家的体验放在首位，而非以盈利为目的。”
根据汪步客服的说法，每一单宠物共享，平台会收取20%抽成，这笔钱会全部返给宠客，目的是鼓励大家多约小狗出来玩。
但我打开账户，显示首次约宠收到1.67元奖励。
宠物自己愿意吗？
围绕宠物租赁的讨论与争议，其实很早就开始了。
2021年，四川成都一家宠物店推出“共享猫咪”的有偿服务，日租金只需要9.9元，此举随即引发爱宠人士强烈反对。如今虽然遍地猫咖，但“人类的乐园就是猫咪的囚笼”的批评之声从未停止。
最常见的猫咖，也一直存在争议。（图/视觉中国）
犬类租赁也有类似的争议。
韩国建国大学兽医学教授李重馥认为，从伦理上不提倡租赁宠物的行为。频繁地更换环境和主人，容易让猫狗应激。美国马萨诸塞、伊利诺伊、华盛顿等9个州甚至明确规定禁止出租犬只，违规者可能受到罚款的处罚。
有国外网友认为，犬类租赁是消费至上观念的不良产物：“狗是有血有肉的生命，不应成为周末的生活点缀和休闲用品。把狗当作汽车一样租来租去，有什么意义呢？这样的狗不会与租赁主人建立感情，还可能在新环境中不知所措，受到精神上的折磨。”
（图/unsplash）
现代犬类租赁生意或许始于2007年的FlexPetz公司，它采取会员制，出租多款犬类宠物，这些宠物都来自于动物收容所，费用并不便宜，一个月会员费达到279.95美元，会员单月仅可免费租用4天。如果继续租用，客户们需要另外支付每天45美元的租金。
客户在网站注册后，Flexpetz会针对客户养宠资格提出许多问题，包括是否具备养宠经验、租赁目的等。此外，客户要参加1个小时的强制性培训，通过后才可以挑选中意的宠物狗。
汪步的创始人曾接受过媒体采访表示，她非常喜欢小狗，因工作经常需要长途出差，没办法自己养，只能偶尔撸一下别人的狗。后来她想自己在英国读书时，学校在考试期间把小狗带到校园，让学生撸狗解压。
（图/《摩登家庭》）
她认为，狗狗带来的安慰不应该只是宠主才能享有的特权，这同样是很多人的需要。
这种分享精神既是宠物租赁生意的来源，也是潜在的风险。
宠主承担了养育宠物的全部成本与精力，宠物属于私人所有的实体与情感双重资产；没有为宠物付出前序精力和金钱的人，只是花钱的租宠人，谈不上有什么权利；而别人的小猫小狗作为，没有向租宠人提供安慰的责任，还要警惕沦为没有保障的损耗品。
我们谈论了得利者与潜在的受害者——从头到尾，做出决定、得到精神或物质收益的平台、宠主和宠客。而作为最关键的主体，宠物是否受到伤害，如何保障它们的权益，这门新兴生意暂时还没准备好答案。
