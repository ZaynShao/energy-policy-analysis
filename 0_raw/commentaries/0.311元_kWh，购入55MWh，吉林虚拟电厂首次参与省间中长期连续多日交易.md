# 0.311元/kWh，购入55MWh，吉林虚拟电厂首次参与省间中长期连续多日交易

「储能与电力市场」获悉，为加快构建全国统一电力市场建设体系，破除区域内省间市场壁垒、统筹优化能源资源配置，东北能源监管局推动吉林电力交易中心组织吉林虚拟电厂参与东北区域省间电力中长期连续多日交易。
东北能源监管局持续关注新型经营主体参与电力市场有关工作。组织修订《东北区域省间电力中长期交易实施细则（试行）》过程中，充分考虑虚拟电厂等新型经营主体发展趋势，适时扩大市场成员范围。组织电力交易机构跟踪服务，推动吉林虚拟电厂首次参与省间中长期连续多日交易，以311.41元／兆瓦时（0.31141元/kWh）价格购入电量55兆瓦时，实现东北区域新型经营主体参与省间交易历史性突破。
虚拟电厂参与省间电力交易将有效降低企业综合用能成本，深度挖掘负荷灵活调节价值，提升用能效益，为培育新型经营主体、深化跨省资源配置积累经验。下一步，东北能源监管局将持续落实国家能源局工作部署，组织电力市场运营机构引导虚拟电厂等新型经营主体参与电力市场，不断扩大可调节负荷资源规模，持续探索电力市场建设新路径，助力东北电力市场高质量发展。
