# 全市场首单储能机构间REITs获批

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)

「储能与电力市场」获悉，近日，据上交所显示，“财通资管-阿特斯持有型不动产资产支持专项计划（碳中和）”项目状态为“已受理”。成为全市场首单以储能电站作为基础资产的机构间REITs产品。  
该债券品种为ABS，拟发行金额4.51亿元，原始权益人为苏州阿特斯新能源开发有限公司，计划管理人为财通证券资产管理有限公司，受理日期为2026年1月21日。

![image](https://mmbiz.qpic.cn/mmbiz_png/nJIHJiauQqnycdj7Ye7meAcpUOjzmmySrM3oq7GyobbkY6L8FxXHWxxtBve8RiaKPj4diafcAp6GnFP30ZKTxCPgkKHlJtccWJF8icANicDuO090/640?wx_fmt=png&from=appmsg)

  

据悉，由财通证券资管担任管理人及独家销售机构，底层资产为位于甘肃酒泉的电网侧独立储能电站。财通证券资管表示，该项目将打通储能电站“投-融-管-退”的资金闭环，标志着储能基础设施证券化实现关键突破。

  

看个广告休息一下![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ibQ6Q066YicvUrISt2HTHibzQLHagVXTI0icHuu8j9l7VicIMYkGQ4a0sZubzCiaYLVbnQtvbYmZqkYcicIBJRaHbpdXQ/640?wx_fmt=jpeg&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=1)

  

阿特斯甘肃省酒泉市肃州区独立储能电站项目**一期已于2025年12月完成并网投运**。项目整体规划总装机规模500MW/2000MWh，分两期分步建设；其中一期建设规模200MW/800MWh，总投资10亿元。一期项目共配置54套储能子系统，同步新建330kV升压站及配套辅助设施，电能送出接入酒泉750kV变电站，整套储能系统采用阿特斯自研SolBank储能系统。
