# 普京：这是海盗行为和抢劫！

俄罗斯总统普京表示，北约正在向太平洋地区渗透，发生冲突的潜在风险在加剧。
▲俄罗斯总统普京（资料图）
当地时间8月12日，俄罗斯总统普京在观摩太平洋舰队演习过程中表示，北约正在向太平洋地区渗透，发生冲突的潜在风险在加剧，该组织部署系列武器装备的计划是对俄罗斯的威胁。
普京还表示，一些国家违反国际海洋法，企图限制俄罗斯经济经营主体所属船只的航行，甚至指望扣押俄方船只并出售掠夺而来的俄方财产。这是海盗行为和抢劫。如果这种做法被采用，俄方将不得不采取对等的回应措施。俄方将在这些企图实施的海域和包括太平洋舰队责任区域在内的其他任何海域进行回应。
