# Q1储能AB面：139%的狂欢，0.8元/Wh的焦虑

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhItBtlGJ95r0bemU7qI250LySmvwwaeibs3u1ibMpLPjZCuvmlxhSKGpxVJMZ8xrFGwRHic5JNsLrJLP5KQnl0wa12aD4CBOuhAp6I/640?wx_fmt=png&from=appmsg)

2026年一季度，传统淡季却展现出超级火热行情。储能电芯出货量大涨139%，有头部企业订单甚至排产至2027年Q2。与此同时，电芯价格稳步上涨，下游集成商纷纷长协锁单。而项目端已出现成本倒挂的隐忧，碳酸锂价格成为全行业心照不宣的警戒坐标。在一季度收官之际，4月13日，高工储能、高工产研以一场深度直播剖析了2026年Q1储能市场全貌。高工储能董事长张小飞博士、明阳瑞源储能常务副总经理赵家欣博士、洛希能源董事长郝烨、星辰新能董事长柳娜、高工产业研究院院长高小兵、高工产研储能行业高级分析师方刚围绕2026年Q1储能市场趋势、企业战略布局等进行了深度交流。

**2026年Q1高增长背后的三个信号**

根据高工产研(GGII)调研，2026年Q1中国储能锂电池出货量达215GWh，同比增长139%，头部企业订单普遍已排产至2026年底至2027年上半年，产能饱和且优先承接高利润订单。GGII预测，2026年储能行业增速预计超40%，大储、户储、AIDC储能将是主要驱动力。具体来看，预计2026年大储装机增速在50%-60%，装机量将超过440GWh，中东、欧洲、南亚、东南亚等区域市场增速居前。2026年户储预计实现30%以上的装机增速，增长核心来自政策补贴与地缘冲突引发的刚性用电需求两大驱动力。AIDC储能市场潜力巨大，但当前处于起步阶段，整体规模较小，2026年全年AIDC储能锂电池出货量预计实现翻倍增速，2027年之后迎来规模化起量。国内工商业储能市场体量依旧居全球第一，但2026年新增装机增速将放缓，进入市场化过渡，海外工商储将延续2025年翻倍增长态势，2026年增速50%以上。整体来看，当前储能市场有三大显著变化：一是储能长时化，4小时向6-8小时过渡。2026年一季度市场招标来看，长时储能（6-8 小时及以上）成为重要趋势，储能时长从4小时逐渐向6-8小时长时储能进阶，同等功率下直接带动储能容量规模提升。二是设备企业转型资产运营商，自投电站成为趋势。储能投资主体不再局限于传统“五大六小”发电集团，传统基建巨头、地方央国企和民营设备企业这三类玩家均下场自投电站，海博、远景、赣锋等设备企业，从设备供应商向“设备+投资+运营”综合服务商转型，带动储能系统出货高增长。三是细分场景爆发，储充、台区储能、绿电直连配储成为热点。储充方面，已有多地政策要求新增480kW以上超充站必须配储，超充/闪充配储将成为必选项；台区储能方面，山东试点已验证台区储能商业模式，或将走向规模化发展；绿电直连方面，已有10地政策明确鼓励配储，高耗能、氢能、数据中心三大行业是绿电直连重点支持行业。

**电芯涨价这条传导链，卡在哪里？**

2026年一季度，储能电芯价格持续上涨。根据GGII调研，2026年3月储能电芯价格较2025年进一步上涨，4月初部分企业再次提价，全年来看价格仍有上探空间。从成本端测算，在上游六氟磷酸锂、碳酸锂等大宗商品价格波动影响下，预计2026年底电芯成本较年初上涨1-3分/Wh，产业链成本压力逐步传导。面对价格上涨，下游集成商已主动调整采购策略。一方面，2025年下半年起，大规模签订电芯长协订单锁定货源，保障供应链稳定；另一方面，采用价格联动机制，按月度采购报价，联动碳酸锂或六氟磷酸锂等大宗商品价格，规避成本波动风险，保障项目盈利性。作为全钒液流电池和磷酸铁锂电池储能的设备研发制造和投资运营商，星辰新能深谙上游原材料和电池价格对投资收益的影响。星辰新能董事长柳娜表示，由于全钒液流电池价格仍较高，业内目前更多是在储能项目中小比例配建液流电池，但随着锂电池价格上涨，2026年大储项目开发投资难度显著上升。“上游碳酸锂、铜、铝等金属价格纷纷上涨，储能系统价格普遍较去年上涨了0.1元/Wh，加上地方接入成本提升，目前国内大多数储能项目的投资成本已接近0.8元/Wh，在融资贷款成本不变的情况下，投资商面临巨大的压力。”柳娜直言。在明阳瑞源储能常务副总经理赵家欣博士看来，本轮电芯涨价与上一轮涨价潮全然不同：首先是驱动因素不同，本轮是国际政治、地缘冲突导致全品类原材料上涨，不只是碳酸锂，铜、铁、电解液、溶剂价格同步上涨，是全球性成本提升；其次是市场结构不同，此前涨价仅依赖国内市场，需求一降价格就跌，现在企业全面出海，海外市场对价格敏感度低，支撑储能售价稳步上涨。对此，赵家欣博士判断，2026年储能电芯涨价是缓慢、持续的，不会快速冲高，也不会快速回落，持续时间会远超以往。洛希能源董事长郝烨也表示，目前来看，储能电芯很难再回到0.2+元/Wh的非理性低价时代，而下游集成商客户也愿意接受价格联动。同时，头部、中部和中小电芯厂之间依然会保持比较明显的电芯价格分层。虽然集成商接受涨价，但若储能项目经济性大幅降低，投资方将显著放缓项目开发投建的步伐。“碳酸锂每涨1万元/吨，电芯价格大约会涨0.006元/Wh。”柳娜认为，如果碳酸锂价格超过20万元/吨，国内大量储能项目将取消或延期。高工储能董事长张小飞博士表示，在钠电、液流等多技术路线对冲下，储能电芯价格不会无限上涨。钠离子电池规模已从百MWh向GWh级别突破，已有万吨级产线落地，原材料自主可控，将对冲锂价上涨。

**美国AIDC储能高增长与高门槛博弈**

AIDC储能是当前最热的储能细分场景之一，不过，由于800VDC架构、SST技术仍处于试点和技术验证阶段，国内AIDC配储进度远不及海外市场。当前，美国、东南亚数据中心配储需求愈发凸显，AIDC需24小时不间断供电，对8-12小时长时储能需求明确，也成为长时储能技术落地的重要场景。AIDC储能是美国储能新增装机的第一大驱动力。张小飞博士表示，2025年，美国储能总装机约60GWh，其中AIDC配套储能约12-15GWh，预计2026年美国AIDC储能装机量将翻倍，达30GWh，将占全美储能增量的75%。要知道，美国AIDC对储能设备价格的承受力极高，美国AIDC储能系统价格是国内的3倍以上，电芯价格约100美元/kWh（0.7元/Wh），对温控、BMS、PCS要求也极高。然而，美国对中国锂电池企业设置了严苛的准入门槛，政治安全审查、实体清单、IEC与UL标准差异、融资与保险合规等多重障碍下，大部分中国锂电大厂智能在美国AIDC市场“门外”徘徊。不过美国当前对液流电池并未设置严格壁垒，且AIDC对安全要求极高、对价格敏感度低，张小飞博士判断，“AIDC将是中国液流企业弯道超车的机会。”值得关注的是，近期，星辰新能在国内推进了两个AIDC全钒液流电池配储项目落地。面对美国地缘政治壁垒，中国储能企业该如何应对？张小飞博士给出建议：首先，放弃“洗产地”模式。通过墨西哥、东南亚建厂的方式，已无法规避美国关税与合规压力，这个模式已经行不通了。其次，体系化出海。“单打独斗”的方式出海愈发难行，需要整体供应链出海，“光伏+储能+微网+燃气轮机”等整体解决方案形成合力。第三，关注中小厂商机会。大厂受上市公司合规限制，中小厂商灵活性更高，更方便切入美国市场。![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIuHQ5vK9uQ5ZpT0ibIViaNvfE8ONNPJp5uCibQmg5y7yShfKTdn9VCI6puuxA5AOh6Y2Y19RzibeFW0luYt3BmCOdwDZNDW71HprnA/640?wx_fmt=png&from=appmsg)
