# “乌克兰发动夜间突袭”

泽连斯基通报乌军夜间行动：俄海军基地、粮食出口码头遭突袭。
综合外媒报道，乌克兰总统泽连斯基当地时间12日表示，乌军对黑海沿岸的俄罗斯海军基地、港口基础设施等实施了夜间突袭。
据《基辅独立报》报道，泽连斯基称，乌克兰针对新罗西斯克海军基地实施了一次“独特”的行动。乌军在袭击中使用了“帕利亚尼察”喷气式无人机、“海王星”反舰巡航导弹和海军无人机等。泽连斯基还称，乌克兰军队袭击了俄军的防空阵地、码头和港口基础设施。
另据英国广播公司(BBC)报道，乌军动用无人机和导弹对俄罗斯新罗西斯克港发动“大规模袭击”。当晚，新罗西斯克不断响起爆炸声，防空部队击落空中目标。
据报道，此次袭击破坏了两大主要的粮食出口码头，并击中了俄罗斯在黑海的大型海军基地。
《基辅独立报》援引初步信息称，袭击对四艘俄军军舰造成“不同程度的损伤”。当地官员还称，夜间袭击造成三人死亡，其中包括一名八岁儿童，另有24人受伤。
报道指出，新罗西斯克是俄罗斯在黑海沿岸的主要港口，也是俄罗斯黑海舰队的海军基地所在地。在乌军多次袭击克里米亚半岛上的俄军军舰和海军设施后，俄军据称将部分舰队转移至新罗西斯克。
