# 地方绿金 | 山东日照：转型金融助推造纸行业绿色低碳发展

造纸行业是国家工业领域碳达峰八个重点控排行业、2026年度山东省工业节能降碳诊断重点行业。山东日照浆纸一体化产业集群规上企业35家，年产值超200亿元，入选2025年度山东省“十强产业”雁阵形产业集群名单。近年来，日照市加快推进传统产业高端化、绿色化、智能化转型，作为重点产业之一，造纸行业绿色低碳生产改造需求迫切，资金缺口大。
在中国人民银行山东省分行指导下，中国人民银行日照市分行立足地方产业实际，将造纸行业作为重点领域之一，因地制宜探索推进转型金融工作。2025年9月，中国人民银行日照市分行出台山东省首个造纸行业转型金融地方标准——《日照市造纸行业转型金融实施指引》，为银行精准识别造纸行业转型金融活动，为相关企业量身定制金融服务提供了依据。
造纸行业转型金融地方标准出台后，日照市银行、企业积极探索使用，实现了从首笔到多笔的突破。亚太森博（山东）浆纸有限公司是日照市造纸行业龙头企业、中国最大的商品木浆生产企业之一，具备360万吨的浆、纸、纸板生产能力，致力于打造成为浆纸行业产业升级、技术进步、绿色发展的标杆企业，转型融资需求大、基础好。中国人民银行日照市分行指导亚太森博（山东）浆纸有限公司科学制定转型计划，推动日照银行将开证手续费与企业减排绩效动态挂钩，在2025年12月为企业办理国际信用证1.2亿元，该企业成为标准落地的首个受益者。在此基础上，日照市银行机构深化产品创新，推动转型金融从单一企业向供应链上下游延伸，将造纸企业碳减排绩效与上游企业贷款利率挂钩，为浆纸产业链上游企业办理供应链融资500万元。截至2026年6月末，日照累计落地造纸行业转型融资6.25亿元，为企业节约融资成本14.1万元，初步形成“减排—降本—融资”的转型金融正向激励闭环。
2026年7月，日照市造纸行业转型融资在产品类型、融资规模上进一步实现重大突破。在中国人民银行日照市分行推动下，山东省浆纸行业首单15亿元转型金融银团贷款在日照签约，这是国内浆纸领域参贷银行最多、规模领先的转型专项贷款项目。该笔贷款由农业银行日照分行牵头，联合6家银行机构共同参贷，总规模达15亿元，专项用于支持亚太森博（山东）浆纸有限公司持续压降全流程碳排放。企业目标到2028年末单位产品碳减排强度较2024年末下降2%，实现0.1699吨/吨，银团贷款利率将与碳减排指标分段挂钩，利率优惠幅度随达标年限递增。该笔贷款的落地，标志着日照转型金融从试点探索迈入规模化推广阶段，为全省造纸行业提供了可复制的转型融资范本。
