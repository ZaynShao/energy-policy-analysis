# 俄罗斯开始进口燃料

俄副总理：俄罗斯已开始进口燃料。
据俄罗斯新闻频道网站19日报道，俄罗斯副总理诺瓦克表示，俄罗斯已经开始进口燃料，并通过必要法规允许生产部分低排放等级的燃料。
此前，一些国家表示愿为俄供应燃料，以缓解其燃料短缺状况。据国际文传电讯社7月2日报道，哈萨克斯坦能源部表示，在保障本国供应的前提下，如果收到俄政府正式请求，哈萨克斯坦准备向俄供应燃料。印度石油和天然气部长哈迪普·辛格·普里曾表示，如有需要，印度可能向俄供应燃料。
今年5月底起，俄罗斯多地燃油供应紧张，油价上涨、加油站限购和排队等情况频发。为稳定市场，俄政府7月8日宣布，自当日起至7月31日禁止柴油出口。7月30日，俄政府又出台了一项新的临时禁令，禁止出口汽油、柴油、船用燃油和轻质瓦斯油，该禁令于8月1日至2027年1月31日期间生效。
