# 能源早新闻丨徐大堡，最新消息！

◐5月核发绿证3.58亿个。据国家能源局6月30日消息，5月，国家能源局核发绿证3.58亿个，涉及可再生能源发电项目125.69万个，其中可交易绿证2.16亿个，占比60.41%，市场化流通绿证供给充足。本期核发2026年4月可再生能源电量对应绿证2.36亿个，占比66.06%，当期电量核发占比处于较高水平。本月各可再生能源发电类型绿证核发数量均有所增长，其中常规水电绿证核发增幅最大。【更多详情】
◐国家能源局：研发创新平台管理办法征求意见。国家能源局网站6月30日消息，为进一步完善国家能源局研发创新平台管理工作程序，结合创新平台新一轮考核评价以及“十四五”第一批“赛马争先”创新平台中期评估情况，国家能源局对《国家能源研发创新平台管理办法》进行修订，形成了《国家能源局研发创新平台管理办法（征求意见稿）》，现向社会公开征求意见。【更多详情】
◐国家能源局同意水布垭等28座水电站大坝安全注册登记。据国家能源局6月30日消息，近日，国家能源局复函大坝安全监察中心，同意水布垭等28座水电站大坝安全注册。【更多详情】
◐5月新增建档立卡新能源发电项目6173个。据国家能源局6月30日消息，2026年5月，全国新增建档立卡新能源发电（不含户用光伏）项目共6173个，其中风电项目27个，光伏发电项目6136个（集中式光伏发电项目39个，工商业分布式光伏发电项目6097个），生物质发电项目10个。【更多详情】
◐我国首个流域型国家排放标准发布。据央视新闻6月30日报道，近日，生态环境部与国家市场监督管理总局联合发布《丹江口库区及上游主要水污染物（总锑、总钼等）排放控制标准（试行）》，这是我国首个以国家标准形式出台的流域型排放标准。
◐我国首个550兆瓦F级燃机项目全容量投产发电。据新华社报道，6月30日凌晨，我国首个550兆瓦F级燃机项目——华电重庆潼南燃机项目实现全容量投产发电，为成渝地区双城经济圈迎峰度夏电力保供、绿色低碳转型注入清洁能源动能。【更多详情】
◐陕电入皖特高压工程正式投产。6月30日，陕北到安徽±800千伏特高压直流输电工程全面建成投运。这是我国“十五五”时期首个投运的特高压直流输电工程。工程投运后，每年可替代燃煤消耗550万吨，减少二氧化碳排放1420万吨。同时，工程还将为安徽迎峰度夏提供强大的电力供给，有力支撑安徽及华东地区可靠用电。
◐陕北—安徽±800千伏特高压直流输电工程建成投运。6月30日，国家电网有限公司陕北—安徽±800千伏特高压直流输电工程全面建成投运。工程起于陕西省延安市宝塔山换流站，途经陕西、河南、安徽三省，止于安徽省合肥市合州换流站，直流线路全长1055千米。工程额定电压±800千伏，额定容量800万千瓦，总投资205亿元。工程是我国“十五五”时期首个投运的特高压直流输电工程，也是国家电网公司服务国家“西电东送”战略的又一标志性工程。
◐两艘巨无霸液化天然气运输船同日交付。据央视新闻报道，6月30日，两艘“中国造”17.4万立方米巨无霸液化天然气运输船同日交付用户，每艘船总长299米，甲板面积相当于三个标准足球场，一次可运输17.4万立方米的液化天然气，航行单日碳排放量可减少约10吨。
◐上海国际航运绿色燃料交易平台开启试运行。据央视新闻报道，6月30日，从“上海国际航运绿色燃料可持续发展大会”上了解到，“绿色船用燃料国际认证体系事务中心”共建合作协议正式签署，我国自主研发的GSTC绿色船用燃料国际认证体系正式在上海启用运营。此举填补国内航运绿色燃料自主国际认证空白，是上海建设国际航运中心的核心软实力支撑。
◐美国战略石油储备降至43年来最低水平。据央视新闻报道，6月29日获悉，美国能源部公布的数据显示，美国战略石油储备上周减少550万桶，降至3.257亿桶，为1983年5月以来最低水平。这是今年2月底美以伊战事之后，美国政府为平抑油价而释放战略石油储备的持续举措。
◐印度东部一炼化厂发生火灾。据新华社报道，印度媒体6月30日消息，印度东部西孟加拉邦霍尔迪亚区一家炼化厂当天发生火灾，造成约20人受伤，其中数人伤势严重。
◐徐大堡核电500千伏送出工程全线送电成功。据央视新闻报道，6月30日，徐大堡核电500千伏送出工程全线送电成功，该工程是为徐大堡核电厂机组并网送电打造。工程全面投运后，每年可外送百亿千瓦时绿色电能，保障大量企业生产用电，同时大幅削减碳排放。
