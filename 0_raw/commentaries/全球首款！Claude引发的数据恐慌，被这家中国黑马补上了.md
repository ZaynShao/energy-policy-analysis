# 全球首款！Claude引发的数据恐慌，被这家中国黑马补上了

新智元报道
太魔幻了！
一家给国家命脉级基础设施做网络安全的公司，竟然跨界搞出了一个AI桌面助手。
上手一试才发现，这个名叫WinClaw的大招，玩得比谁都专业。
你电脑里沉睡多年的文件，不管是Word、Excel、PPT、PDF，还是藏在暗处的微信缓存、NAS网盘映射过来的资料库，统统能读懂。
它的核心引擎灵犀文脉，会把全部文件做向量化处理，在你的本地机箱里，建起一座AI专属的知识库。
有了这座知识库，你所有的文件从此彻底活过来了！
文件名秒搜只是基本操作，往下还有正文关键词全文检索，更绝的是大白话语义匹配。哪怕只勉强挤出一句大概意思，它照样能精准找回来。
本地翻个底朝天也没有的，200多个在线搜索源接着翻。
而且，「搜到」还只是开胃菜。
找出来的陈年文档，还能揪着继续追问，提炼总结、数据对比、自动摘表，每个回答都带着出处。
人在外面也不耽误，掏出手机发条微信，电脑直接自动开工。
用得越久，它越像个成了精的私人助理，到点该汇报的进度、该处理的事，主动送到你眼前。
当然，全场最炸裂的王牌，还是它的老本行——安全。
这么一个手眼通天的AI，你的文件却自始至终锁在本地。
毕竟它背后的威努特，是给核电站守了十几年大门的公司，没人比他们更懂，哪些东西绝对不能往外送。
话不多说，直接上实测！
材料是从2025年中到现在，编辑部一整年攒下的3467篇稿件，输入全凭编辑脑子里支离破碎的模糊记忆。
正巧，人刚出门，老板突然要电脑里那篇「AI圈乌龙稿」，脑子里偏偏只剩几个零碎数字。
好在WinClaw能绑微信，发条消息就能指挥电脑干活。于是我们在微信里把这段记忆原样丢了过去：
我已经出门了，老板突然要电脑里那篇AI圈乌龙稿。我记得里面既写了Claude Code漏了51万行源码和18个物种，又提到服务器遭到552次SSH登录。标题和放哪都忘了。你先帮我确认是不是这篇，别急着发文件。
但很明显，我们记错了。这篇稿压根不存在，三组数字分散在两篇完全不同的文章里。
而这种时候，AI最容易顺着错误的记忆，把两篇硬缝成一篇，发完了事。
不过，WinClaw没这么干。
电脑那头，它先跑了4轮检索，没直接命中标题，就自己换打法：列目录、按关键词搜文件，前后调用了10个工具，把两组线索分别核实清楚。
几分钟后，微信里弹回确认结果。
「51.2万行源码＋18个物种」来自Claude Code那篇，「552次SSH失败＋端口暴露」来自Moltbook那篇。
两篇是独立稿件，发布时间都不同，你可能是连续阅读时把它们记成了一篇。
这正是文件名检索帮不上忙的现场——标题、日期、位置全忘了，只能靠正文语义来捞。
而且这不是「没搜到所以拒答」，是搜到了两边、核完证据、再拒绝编造。一个敢说「你记串了」的AI，比一个永远点头的AI靠谱多了。
搜得准，只是起点。
接下来加大难度：不找某一篇，而是让它把散落在多篇稿里的OpenClaw爆火史，拼成一条完整的时间线。
收到命令后，WinClaw很快就拉出了五个关键节点：
1月26日首次报道，还叫Clawdbot，Star约2.07万。
1月29日搜一举反超Claude Code和Codex之和，冲出开发者圈。
1月30日Star冲破10万。
2月3日硬件被带火，Mac mini和国产算力开始被讨论。
2月4日越狱指令出现，安全争议登场。
可以看到，WinClaw把一个模糊问题拆成五路检索，20次文档读取校准日期和证据，再按时间归纳成线。
最后，它根据这些线索，给出了一个老辣的判断：10万Star是量变，搜索量破圈才是质变。
最后上一桩更乱的：这次考的不是事，是人。
在Claude Code 51万行源码意外泄露事件中，至少五个角色搅在一起。
华人辍学博士最先发现，有人在社交媒体上扩散，Claude Code之父出来回应说是「纯手误」，Bun一度被怀疑又被排除。
我们只丢了这些零碎记忆，让WinClaw自己去稿库里分清谁是谁。
WinClaw的打法依旧是先检索后读原稿，再按「发现、传播、回应、涉事、排除」给角色归位——
发现者Chaofan Shou，传播者Sigrid Jin，回应者Boris Cherny（Claude Code之父），涉事公司Anthropic，被排除对象Bun。
真相也水落石出。Anthropic发npm包时没删cli.js.map，51万行源码意外裸奔。Bun只是被技术线索误伤的「早期嫌疑人」。
连「发现者到Bun」这种八竿子打不着的关系，它也能沿证据走出最短路径：Chaofan Shou → Claude Code → Bun。
三案下来，考点连成了一条线：搜得准、读得深、理得清。
支撑它们的是同一条能力链——
文件名搜不到就钻正文，关键词不够就上语义，找到之后跨文档核验，最终拼成时间线、关系图和判案。
实测里的关系图和时间线不是临时画的，出自WinClaw的文档图谱。
它能自动从文档中抽取人物、项目、事件等实体，识别五种关系（参与、负责、关联、引用、产出），生成可视化网络。
点击任意节点，就能直接向AI追问这个人、这件事的来龙去脉。
文档图谱之外，是数字分身。
WinClaw能从你的文档里读出你的角色、手头项目、工作习惯，每天更新。
AI带着这份上下文跟你对话，吐出来的不再是通用模板，而是贴合你工作场景的个性化输出。
而且，用得越久它越主动。
WinClaw会基于你的文档行为和工作习惯主动推待办。
比如，最近频繁修改的「Q2项目进度表」，是不是该生成汇报了？又到周五，要不要汇总本周的周报素材？刚收到一份「技术方案评审意见」，需要帮你分析吗？
这个功能叫双通道推荐引擎。快通道30秒内就有反应，根据文件的修改频率、时间规律这些信号，先给一版初步推荐；深度通道再花5分钟真正读懂文档内容和你的意图，把推荐修得更准。
推荐也不是只提个醒。点开推荐卡片，WinClaw会自动创建会话、带上相关文档，AI直接开始处理。看到该做什么，点一下，做完了。
再加上语音输入和直接生成Word、Excel、PPT的办公引擎，从说一句话到拿到文档，全程不用切出应用。
看到这里你可能会问：WinClaw生成回答也要调大模型，内容照样得发出去，凭什么说数据是安全的？
这就说到了它跟所有竞品最本质的区别——三层防护。
第一层：文件不出本机。
原始文档、索引、知识图谱，统统存在你自己电脑上，不上传任何服务器。哪些文件能被AI读到，你说了算。
第二层：出去的内容过安全关卡。
WinClaw从本地文档中检索相关段落发给大模型生成回答，但在发送之前，银行卡号、身份证号、手机号等敏感信息自动识别过滤。发出去的是经过清洗的上下文片段，不是你的原始文件。
第三层：可以完全断网用。
通过Ollama接入本地大模型，从索引到检索到对话，全链路在你电脑上完成，一个比特都不经过网络。
这三层背后，是威努特的五重安全架构：身份认证、安装审查、消息拦截、执行约束、监测审计。做了12年核电站安全的公司，把同一套思路做进了AI助手里。
