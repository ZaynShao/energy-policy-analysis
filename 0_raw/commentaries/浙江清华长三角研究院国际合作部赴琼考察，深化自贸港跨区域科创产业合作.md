# 浙江清华长三角研究院国际合作部赴琼考察，深化自贸港跨区域科创产业合作

点击蓝字 关注我们
6月16日至17日，浙江清华长三角研究院国际合作部部长李元元一行赴海南考察，先后走访海南省贸促会、澄迈县老城科技新城、三亚崖州湾科技城管理局、三亚市贸促会等单位并座谈交流，聚力推动浙琼两地协同创新与产业联动。浙江京兰环保科技有限公司投资部总监钱明诚、海南区域副总经理余丽锋、投资部经理林大德作为企业代表随团考察，海南嘉兴商会会长林跃陪同。
在座谈和实地走访中，考察团与海南相关单位立足自贸港产业布局与长三角科创资源优势，围绕科技成果转移转化、科创平台共建共享、企业国际化配套服务等议题深入交换意见，就建立常态化资源对接机制、联合举办创新创业活动等达成多项初步共识。在浙琼合作产业园，考察团还与当地出海企业代表面对面交流，聚焦海外市场拓展中的共性需求与应对策略，探讨协同出海、抱团发展的可行路径。

此次考察进一步夯实了浙琼两地合作根基。研究院诚挚邀请海南各单位回访长三角地区，以双向联动实现互促赋能，并将紧抓海南自贸港封关运作带来的重大机遇，深耕专项政策研究，持续为在琼企业国际化战略布局赋能，助力海南科创产业提质增效与高水平对外开放。
