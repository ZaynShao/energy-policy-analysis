# 刚刚，Codex 首款硬件正式发布，1500 块的「AI 监工」外设

不是智能音箱，不是智能笔，而是一款名叫 Codex Micro 的键盘，配有 13 枚机械按键，加上触摸、旋钮和摇杆，共四种输入方式。Codex Micro 售价 230 美元（约合人民币 1556 元），现已开启预购，预计 7 月 24 日发货。好家伙，奥特曼开始卖外设了。AGI 还没造出来，AI 周边倒是先量产了。这块键盘是 OpenAI 和外设厂商 Work Louder 联合打造的，全名 kbd-1.0-codex-micro，官方定位相当唬人：简单来说，这是一块专门给 Codex 配的遥控器。它最核心的玩法是 RGB 灯，但不是电竞那种氛围灯，而是状态灯。每个 Agent 键会根据 Codex 智能体的实时状态亮起不同的 RGB 灯效，官方分了四档：思考中、运行中、等待中、已完成，外加一个空闲状态。哪个 agent 正在跑任务、哪个在等你拍板、哪个已经干完活了，瞄一眼灯就知道，连聊天窗口都不用切。有点像工厂车间的信号灯塔，只不过流水线上干活的换成了一群 AI。实际效果｜ 图片来自 OpenAI 开发者 Thomas Ricouard以前是领导瞄一眼工位就知道谁在摸鱼，现在这个待遇轮到 AI 享受了，而你就是那个领导。摇杆触发工作流：键盘上有一个平面摇杆（还配了橡胶摇杆帽），拨一下就能启动审查 PR、调试错误、重构代码这些常见 Codex 工作流。
命令键：接受、拒绝、按住说话（push-to-talk）、新建聊天等最常用的操作，都有专属实体按键，官方的说法是「减少切换，更快交付成果」。
旋钮调推理级别：这个最有意思：转动旋钮，实时调整 Codex 的 reasoning level（推理强度）。简单任务调低跑得快，硬骨头就拧到最大档。
对，就是字面意义上的「拧一下，给 AI 加点智商」。建议这功能尽快推广到人类身上（doge）。先看按键部分：13 个机械轴、1 个触摸传感器、1 个旋转编码器、1 个平面摇杆。轴体用的是 POM/POK 材质，提供段落轴（clicky）和静音轴（silent）两个版本。连接是蓝牙和 USB-C 双模，Mac、Windows 都能用，软件端对接 ChatGPT Codex 和 Work Louder 自家的输入设备软件。用料倒是不含糊：CNC 加工的 PC 和铝合金机身、喷砂阳极氧化底座，键帽是 PBT 和 PC 材质。键帽给得也大方，32 颗 Codex 定制图标键帽，外加 11 颗纯色键帽。包装清单里有：键盘本体、一根 USB-C 转 USB-C 线，以及一套 Codex 图标键帽。官方还标注了包含保修和支持。不过清单里还藏了个细节：键盘本体写的是 Work Louder 自家的 Creator Micro。也就是说，这本质上就是一次联名定制：Work Louder 出键盘，OpenAI 出信仰键帽和软件联动。Work Louder 本来就是做创意工作者小键盘起家的，这次相当于给老产品找到了一个新故事：从服务剪视频的，转向服务管 AI 的。本体就是 Work Louder 的现成产品 Creator Micro，本质上就是一块客制化键盘，在电商平台也有不少类似的产品，230 美元里显然有一部分是给 OpenAI logo 付的信仰税。普通键盘是单向的：人敲键，信息流向电脑。这块键盘反过来加了一条回路：RGB 灯把 agent 的状态实时传回给人。它一半是输入设备，一半是仪表盘。而且你可能注意到了，复杂指令的输入其实藏在那颗 push-to-talk 键里：按住说话，用电脑或外接麦克风收音，松开提交 Prompt。
也就是说，这套工作方式的完整分工是：语音负责下达复杂任务，按键负责执行高频操作，灯光负责回传 agent 状态。
再看它绑定的东西。Stream Deck 这类宏键盘，快捷键对应的是软件功能，切个场景、调个音量。Codex Micro 的按键对应的是 agent 的工作流和「脑力」：拨摇杆是派活，按键是批准或打回，拧旋钮是给 AI 分配多少推理资源。这里面藏着一个判断：一个操作只有高频到一定程度，才配得上一颗实体按键。鼠标之于图形界面，手柄之于游戏机，都是这个逻辑。现在 OpenAI 给「接受」和「拒绝」各配了一颗专属键，等于在说：AI 干活、人来拍板这套流程，已经高频且稳定到值得为它造外设了。程序员的日常，正在从自己写代码，变成同时盯着一排 agent 干活。这块键盘到底是新工作方式的先声，还是又一个吃灰的联名周边，取决于多 agent 并行的工作流能不能真正普及，以及语音输入的方式能否在未来的工作方式流行开来。至少现在，它体现了 OpenAI 的判断：未来打工人应该就是这么干活的。想象一下那个画面：上班坐下，面前一排小灯闪烁，左手拨摇杆派活，右手拧旋钮加智商，像在开塔吊。想抢先当「agent 监工」的朋友，预计 7 月 24 日发货，可以蹲一个了。https://openai.com/zh-Hans-CN/supply/co-lab/work-louder/
