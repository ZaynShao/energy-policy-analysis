# 新一代信息技术融合应用典型案例 | 数字领航

开栏语
日前，2025年新一代信息技术融合应用典型案例发布，浙江省10个案例成功入选，数量居全国前列。本次入选案例涵盖数字领航培育、工业互联网平台创新落地、通用数字化工具研发应用、重点行业数字化改造场景等领域，充分展现我省在新一代信息技术与制造业深度融合方面的前瞻布局与创新实践，沉淀形成一批标杆示范经验，为各地推进产业数字化转型提供有益借鉴。为强化示范推广，浙江经信开设“2025年新一代信息技术融合应用典型案例”专栏，分期详解案例转型具体做法，敬请关注。
新凤鸣集团股份有限公司
【案例名称】
化纤产业链全要素协同智能工厂领航实践
针对质量追溯困难、排产换产波动大、供应链协同难等行业痛点，新凤鸣集团应用AI+工业互联平台，赋能构建化纤产业链全要素协同智能工厂：一是联合创新解决聚合、纺丝等化纤核心生产环节装备国产化问题；二是创新应用新型聚合技术、在线添加技术等，构建规模化定制、柔性化生产典范；三是利用AI赋能，解决智能外检、质检、物料供给和辅助决策等问题；四是培育数智化队伍，形成和输出了13个AI场景应用和25个数字化产品解决方案，构建形成了化纤企业产业数字化，数字产业化，服务生态化和管理现代化的企业运营新样板，示范带动行业及区域企业转型升级高质量发展。新凤鸣集团解决方案已复制推广60家企业，十余次受邀在行业和国家级国际级大会上参赛参展和分享成果，相关成果8次获央视新闻联播、焦点访谈报道。
华立科技股份有限公司
【案例名称】
基于 AI+数据全贯通的智能仪表智造领航实践
针对立项流程不完善，跨部门协作不畅，技术资料分散，研发效率低等从研发设计到供应链协同等系列问题，华立科技通过：一是引入IPD集成产品开发体系，搭建西门子PLM系统，规范立项评审流程，实现跨部门协同、技术资料集中管理和项目动态跟踪，提升研发效率与质量。二是自主开发制程管理系统，实时采集产品、设备、人员、工序数据，自动控制工序流转并防止漏序；建立不合格品管控流程，支持全链路质量追溯；并通过移动报修、点检和预测性维护系统降低设备故障率。三是利用ERP实施成本精细化管理，细化成本核算到产品工序；利用成本中心和利润中心加强预算监控；打通信息孤岛，集成财务、销售、采购数据，为决策提供实时支持。四是构建“一云四网一AI”架构，本地部署AI大模型，自主开发智能体，人工智能技术在研发设计、计划排程、机器视觉检测、FCT测试、设备维修维护、质量追溯、能耗分析和公司知识库等场景得到应用。通过部署PLM、MES、ERP等系统及自研智能体，华立科技生产效率提升60%，一次交验合格率98.32%，客户满意度99%，绿色生产万元产值能耗下降30%，年减排CO₂近千吨。
