# 废油变身“抢手货”！出口订单排到2027年，价格还在涨→

餐厨废油大变身
垃圾油脂炼成工业高端原料
在江苏连云港的新能源企业厂区，每天上百辆油罐车往返忙碌。
全国各地餐厨垃圾处理厂的废弃油脂，每天约2000吨集中运抵厂区，经过精细化加工实现华丽蜕变。
江苏连云港威勒斯新能源有限公司董事长顾光阳介绍，废弃食用油进厂后，通过加热、沉淀、离心、过滤等多道工艺，有效降低油脂中的金属、磷、氯、氮等杂质，提纯后成为高品质工业级混合油。
这种再生原料用途极广，可生产生物柴油、可持续航空燃料、洗涤剂、工业润滑剂等，实现资源循环再利用。
行情火爆量价齐升
订单排到2027年，价格半年涨10%
据了解，今年以来，这家企业工业级混合油产量已超35万吨，一半产品远销海外。
顾光阳表示，企业上半年出口量同比增加20%，价格持续上行，年初每吨约7000元，7月涨到7800元，半年涨幅近10%。企业目前满负荷生产，订单已排至2027年。三期项目明年初投产，届时年产能将接近100万吨。
行业整体产能也在加速扩张。江苏多家企业向外布局建厂，其中，江苏维尔利科技集团股份有限公司计划在全国落地4至5座废弃食用油加工工厂，辽宁锦州基地目前年产能稳定在6万至8万吨。
出口数据增长
国内外需求双向爆发
我国每年可利用废弃食用油潜力超1200万吨，随着回收体系规范化，资源化价值持续释放。
卓创资讯能源分析师仇晓分析，2026年上半年国内工业级混合油价格震荡上行，供需持续紧平衡。1至6月国内相关产品出口177.29万吨，同比大涨40.55%，出口均价同比上涨8.23%，需求端呈现国内外双向提升。
低端油脂升级高端航油
生物航空煤油出口价格大涨
废弃油脂最大的价值跃升，就是加工成生物航空煤油，从普通工业燃料进阶为高端清洁能源。
连云港一家生物航空煤油加工企业负责人告诉记者，目前每个月都是满产，产量在3万到4万吨之间，出口订单已排到明年。
山东日照一家企业数据同样亮眼，去年10月拿到生物航空煤油出口资质，至今已累计出口超9万吨。企业负责人介绍，出口量从1月6300吨攀升至6月1.6万吨，二季度环比增幅102%；价格从每吨2100美元左右涨至2800多美元。
国家政策护航
独立税号打通出口快车道
今年1月起，国务院关税税则委员会在税则中增列“生物航空煤油”本国子目，确立了这一绿色产品的独立身份，正式赋予专用商品编码，为我国生物航空煤油产业打通了更加稳定顺畅的出口通道。
日照海关副关长崔建刚表示，独立税号启用之后，生物航油实行单独监管，不再占用传统成品油的出口配额，为生物航油的持续稳定出口创造了有利条件。今年上半年山东省累计出口生物航油突破20亿元，企业出口态势稳定向好。
需求叠加订单放量
生物航油企业扩产提速
8月1日起，《可再生能源消费最低比重目标和可再生能源电力消纳责任权重制度实施办法》正式实施。中国产业发展促进会副秘书长张大勇介绍，生物燃料纳入非电可再生能源消费强制考核制度，这将在一定程度上创造出更多国内市场需求。
多家生物航空煤油生产企业表示，稳定可预见的国内市场，叠加海外客户需求增加，正推动企业进一步加快扩产步伐。各大企业全速扩产：
河南君恒实业集团生物科技有限公司现有年产能24万吨，二期项目年内投产后，产能将是现在的四倍；
江苏连云港嘉澳新能源有限公司50万吨原料处理一期满产运行，二期计划2028年投产。
绿色价值凸显
中国技术助力全球航空减碳
相比传统航油，生物航空煤油全生命周期减少80%二氧化碳排放。
中国产业发展促进会副秘书长张大勇介绍，我国每年出口的废弃油脂和可持续航空燃料，碳减排贡献可达1200万吨二氧化碳当量。
中国科学院大连化学物理研究所研究员田志坚表示，我国生物航煤产业的发展，不仅助力国际航空业减碳，而且推动了绿色低碳技术的创新和产业升级。
