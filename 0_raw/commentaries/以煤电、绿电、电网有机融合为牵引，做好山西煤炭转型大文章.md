# 以煤电、绿电、电网有机融合为牵引，做好山西煤炭转型大文章

****文|孙予罕****

作为传统能源大省，山西的转型不仅关乎一省之发展，更对保障国家能源安全、实现“双碳”目标具有重要意义。

  

2026年山西省政府工作报告明确提出，着力推动能源转型，明确能源科技创新9条路径，加快构建新型能源体系，积极打造综合能源、绿色能源系统解决方案。这涵盖了煤炭智能绿色安全开采、新能源规模化基地化开发、新一代煤电升级、新型电力系统构建、非常规天然气发展、现代煤化工、先进高载能产业发展、煤矸石等固废多元综合利用、碳捕集利用与封存规模化示范应用等方面。

  

构建新型能源体系是一个系统性工程。做好山西煤炭这篇大文章，可以使山西煤炭资源由新型能源体系中的短板，转化为解决方案的关键一环。通过将煤电改造为支撑高比例新能源的灵活调峰电源，以煤电、绿电、电网有机融合为牵引，推动煤化工向高端化、差异化发展，可实现能源结构整体优化。

**技术突破驱动煤炭产业**

**高端化、低碳化**  
  
  

  

战略蓝图需要坚实的技术基石来支撑。

  

山西煤炭产业的转型，必须依靠持续且精准的技术创新，推动产业从规模扩张转向价值提升，从高碳路径转向低碳发展。具体而言，技术突破应聚焦于三个关键领域：煤电的灵活清洁调峰、煤化工的差异化高端化发展和全产业链的节水降碳。

  

在煤电领域，传统煤电机组并非为频繁启停和快速负荷调节而设计。技术创新的核心目标是实现灵活调峰与清洁排放。为此，提出了“综合能源系统解决方案”的构想，其核心目标是实现“双低一高”，即低电价、低排放的电力供应，用以支撑高附加值的战略性新兴产业。具体而言，就是通过技术创新将山西丰富的煤炭资源（尤其是其调峰能力）与本地及西部的绿色电力相结合，打造稳定可靠的低碳能源系统。这一系统不仅能保障本省能源需求，更可辐射京津冀、山东乃至整个北方地区，在特殊情况下发挥兜底保障作用，在正常情况下提供低碳电力。

  

怀柔国家实验室等已在此领域布局并取得重大进展。目前，相关技术问题基本得到解决且已进入示范阶段。这些技术旨在提升煤电机组应对可再生能源波动的响应速度，增加调节深度，使其成为电力系统可靠的灵活调节资源，而非仅仅是基荷电源。未来，还需要结合国家 2030 重大专项所布局的智能电网技术方向，将绿电、灵活煤电与电网更好地耦合为“三位一体”的稳定系统。

  

在煤化工领域，煤要从燃料走向原料。发展思路必须从过去的“以量取胜”转向“以质取胜”，走差异化、高端化路线。我国的煤制油等煤化工技术已达到国际领先水平，但面临同质化竞争和经济性挑战。未来须坚持“油化并举、以油促化、以化带油”的原则，并在此基础上增加“高端差异、节水降碳”的新内涵。高端化，意味着提升产品附加值，不再局限于大宗基础化学品。差异化，则是要发挥煤基产品的独特性，与石油化工形成互补而非竞争。

  

例如，在间接液化路线中，可以侧重生产长链α-烯烃、高碳醇等石化路线难以获得或成本高昂的高端化学品。在直接液化路线中，则可利用煤的结构特性，获取富含芳烃，尤其是含杂原子的多环芳烃化合物，这些是高端材料与精细化工的重要原料。这样的产品结构优化，不仅能提升经济性，更能开辟新的产业赛道。同时，所有技术路线都必须将“节水降碳”作为刚性约束，通过工艺流程再造和绿电耦合，大幅降低水耗与碳排放。

  

此外，碳减排技术是贯穿所有环节的主线，以碳减排与碳循环为核心，优先从煤炭利用的源头减碳。通过绿电耦合（如用绿电替代燃煤动力、用绿氢绿氧替代煤制氢）和工艺流程再造，可以大幅降低单位产品的煤耗与碳排放。对于无法避免的碳排放，应优先考虑将其作为资源进行循环利用，发展二氧化碳转化技术，以及在地质条件允许的情况下审慎开展封存。

  
  
  

**分“煤”施策**

**推进产业转型**  
  
  

  

山西的煤种复杂，需要分类施策。

  

怀柔实验室山西研究院是全球唯一一个煤的四种转化方式都有的研究机构，燃烧、气化、热解、液化齐全。我们主要做工程概念验证，希望建设一个中试集群，把热解、液化、气化、新型发电和绿电耦合放在一起，通过大模型做虚拟现实耦合。

  

第一类是低阶煤，其含碳量相对低、热值不高，但占比不小。煤的热解是把一部分油拿出来，同时把有机污染物通过气相拿掉，让剩下的固体热值增加，燃烧或他用均可。这是一个提质升级的过程。企业和科研人员攻关该技术多年，目前还没有实现连续稳定运行。我们做了布局，实验室层面的工程概念已获验证，下一步要和央企合作推进示范。

  

第二类是高灰熔点的劣质煤，其燃烧性能尚可，但含硫量高，液化和热解都不行，只能气化或燃烧。气化的问题在于不能在过高温度下进行，否则装置投资过大、寿命不长。这方面近期可能有重大突破，相关工艺路径已趋成熟，“十五五”上半期就能有明确进展，下半期可以实现产业化应用。

  

第三类是焦煤，关系到焦炭产业。焦炭产业是特殊的基础产业，只要钢铁产业存在，就离不开焦炭，绿色冶金领域同样对其有刚性需求。即便废钢循环利用与绿电耦合的技术路线逐步推广，或将替代部分焦炭需求，但现在的工艺里焦炭仍不可或缺。

  

山西省焦炭产量接近1亿吨，怎么发展是个大问题。我们的思路是，焦炭企业要从单一产品变成多元产品，必须重视焦化等特殊传统产业的“能力保全与多元化升级”。随着绿色冶金发展和废钢利用增加，焦炭市场需求可能达峰并下降。对此，不能简单淘汰产能，而应推动产业从单一产品向多元产品转型。例如，将焦化装置与煤的温和液化等技术结合，在生产焦炭的同时，联产高附加值化学品与清洁燃料。这样，在市场需要时全力生产焦炭，在需求下降时则调整产品结构，但核心的工艺装置和生产能力得以保留。产能可以下降，能力不能没有。这既保障了国家战略物资的供应弹性，也有助于提升我国在全球焦炭市场的话语权。

  
  
  

**搭建科技硬平台**

**打造创新软环境**  
  
  

  

对于山西而言，推动能源与煤炭产业转型，不仅需要项目落地，更需要构建能够持续孕育创新、支撑产业、吸引资源的平台与生态。这包括打造集成示范基地、创新产业组织模式及营造有利于创新的软环境。

  

建议从以下几方面着手。

  

第一，建议在晋北等条件适宜的区域，规划建设国家级“煤电化材一体化”综合示范基地。该基地应集成多个功能：利用当地煤炭资源与绿电资源，建设大型煤电调峰电站；发展高端差异化煤化工项目，实践“油化并举、高端差异”路线；同时，推动煤化工与绿电的深度耦合，落地节水降碳技术。这样的基地不是一个孤立的项目，而是一个系统解决方案的实体呈现，其目标是实现“双低一高”——为园区提供低电价、低碳排放的能源和原料，从而吸引算力中心、绿色冶金、高端材料等高载能、低排放的战略性新兴产业聚集。这样的千亿级园区若能成功，将成为可复制、可推广的转型范式。

  

第二，建议依托怀柔实验室，筹建开放式的“煤炭清洁高效利用技术中试集群”。这个集群不是单个企业的中试车间，而是一个面向全行业、提供从实验室成果到产业化验证全链条服务的公共平台。它应涵盖煤的热解、气化、液化、燃烧（如IGFC燃料电池发电）等多种转化路径，并与绿电耦合、碳管理模块集成。其价值在于三个方面：一是保持技术领先，为国内外先进技术提供工程验证环境；二是支撑产业发展，为企业的新项目、新煤种提供定制化试验与方案优化服务；三是引领国际合作，展示中国煤炭近零排放利用的系统解决方案，吸引全球资源。

  

第三，转型的成功离不开充满活力的创新生态。这需要强大的战略定力、持续的资源投入和宽容失败的制度环境。怀柔实验室“没有围墙的研究所”模式，为山西能源转型提供了重要启示：以国家重大任务为导向，打破单位壁垒，汇聚全国最优智力资源，实现“使命—成就—激励”的良性循环。

  

山西的能源转型是一场深刻的系统性变革。它要求超越简单的“去煤化”思维，通过战略调整、技术革新与生态构建，让煤炭这项传统资源在新发展阶段焕发新生，成为支撑国家能源安全与低碳转型的可靠力量。从时间表来看，“十五五”期间是关键窗口，技术验证和示范应用要在这个阶段完成；“十六五”期间大规模推广。我们要做的，就是把技术路线夯实，把解决方案做扎实，提供一个可复制、可推广的山西模式。

  

（作者系怀柔实验室山西研究院院长、第十四届全国政协委员）
