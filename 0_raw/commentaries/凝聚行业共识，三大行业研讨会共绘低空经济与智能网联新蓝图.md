# 凝聚行业共识，三大行业研讨会共绘低空经济与智能网联新蓝图

近日，国家智能网联汽车质检中心（广东）（筹）+广东省低空经济中试平台（筹）能力发布会暨南方试验场启用仪式在广东韶关举行。发布会同期举行中国汽车工业协会汽车试验场分会2026年技术研讨会、路空一体安全技术研讨会及中国航空学会飞行汽车分会2026年年会。三场行业研讨会汇聚了来自汽车、航空、交通等领域的院士、专家、企业领导及政府代表，共同探讨产业协同发展的新路径。
中国汽车工业协会汽车试验场分会2026年技术研讨会上，与会嘉宾围绕汽车试验场高标准建设、数字化运维及复杂场景验证体系展开深入探讨。中国汽车工业协会副秘书长杨中平指出，汽车试验场是汽车产业的重要组成部分，协会将引导行业立足产业发展新趋势，以科技创新驱动高质量发展，为汽车产业高质量发展筑牢硬件基础。作为承办方，南方试验场公司在会上描绘了南方试验场发展愿景，表示将加速二期项目建设，持续完善测试道路、空域设施等硬件条件，提升数智化建设与运营水平，打造 “全场景、全天候、全时域” 的一站式测试服务平台。
低空经济新赛道上，“推飞行汽车上天，助低空经济落地” 路空一体安全技术研讨会、“创新引领，安全为先” 中国航空学会飞行汽车分会2026年年会相继举办。中国工程院院士向锦武、中国航空研究院首席专家舒振杰等出席会议并致辞。
为践行低空经济国家战略、凝聚政产学研用合力，路空一体安全技术研讨会发布 “路空一体安全宣言”，倡导以安全为根基、以标准为准则、以创新为动力，共建开放协同、规范有序、技术可靠的发展生态。两场会议均把安全放在核心位置，围绕低空经济标准体系、适航技术、运行安全等关键议题开展深入研讨。
从汽车试验场分会的 “高标准设施建设”，到飞行汽车分会的 “适航技术与标准制定”，再到路空一体研讨会的“技术验证与应用示范”，三场行业研讨会集中展现了我国在智能网联汽车、低空经济与飞行汽车等领域的战略布局与技术积累，通过跨行业、多层次对话搭建起政产学研用深度融合的交流平台。
作为国内首个“路空一体”国家级测试基地，中国汽研南方试验场已正式启用，为智能网联汽车及飞行汽车提供高标准研发验证支撑。未来，中国汽研将持续强化技术创新与行业协同，助力我国智能网联汽车与低空经济产业高质量、可持续发展。
