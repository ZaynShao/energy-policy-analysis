# 区经信局召开传达学习区委十五届十四次全会精神暨拼抢三季度攻坚会议

7月31日下午，区经信局召开专题会议，传达学习区委十五届十四次全会精神，研究贯彻落实举措，部署三季度攻坚任务。局党委书记、局长徐春主持并讲话，全体干部职工参加会议。
会议强调，全局上下要紧扣“以创新余杭建设推动新质生产力发展，全力打造人工智能创新发展第一城核心承载地”战略部署，对标对表抓好落实，立足余杭产业发展，以“两新”深度融合推动创新余杭建设全面成势。
会议要求：
一是全力抢抓人工智能发展机遇。坚定不移服务好龙头企业，加快培育壮大Token经济，完善“高算力+强算法+大数据”产业生态，夯实“算力券+模型券+词元券”等创新政策矩阵，以数实融合推动数字经济二次攀峰。
二是聚力创新“296X”培育范式。坚持把“296X”先进制造业集群培育建设作为推进新型工业化、打赢工业经济翻身仗的重要举措，纵深推进制造业“智转数改网联”，精准开展“强链延链补链”，聚力推动集成电路、具身智能等重点赛道攻坚突破，以“296X”集群稳进提质赋能工业经济再创新高。
三是着力打造“四最”一流创新生态。加快“专精特新”强区建设，完善梯度培育体系，加大专精特新“小巨人”、制造业单项冠军、独角兽企业等培育力度，持续强化创新成果转化、城市机会场景改革等要素支撑，积极引导新锐科创企业制造业回流，推动更多“杭州新八骏”“科技新小龙”在余杭竞相涌现。
下一步，区经信局将全面贯彻落实区委全会精神，以“忠诚担当实干争先”的姿态拼抢三季度、决胜全年红，为加快建设率先呈现“生动图景”的城市新中心贡献全部经信力量 。
