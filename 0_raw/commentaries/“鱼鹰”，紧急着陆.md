# “鱼鹰”，紧急着陆

驻日美军一架“鱼鹰”运输机紧急着陆。
▲“鱼鹰”运输机（资料图）
当地时间8月10日，驻日美军横田基地的一架CV—22“鱼鹰”运输机紧急降落在栃木县陆上自卫队宇都宫飞行场。日本防卫省截至12日，已向相关地方政府通报了这一情况。美方称，此次降落是为避免发生事故而采取的“预防性降落”。该机已于11日离开该飞行场。
据日本防卫省介绍，这架“鱼鹰”在当地时间10日15时左右降落在宇都宫飞行场。目前尚未确认有人员受伤或财物损失。防卫省没有公布有关飞行路线以及降落原因等详细情况。
横田基地的“鱼鹰”运输机紧急降落事件接连发生。今年以来，类似情况已发生两起，分别于2月在岩手县花卷机场、5月在神奈川县美国海军厚木基地发生。
“鱼鹰”运输机事故多发。2023年11月，美军一架“鱼鹰”运输机在鹿儿岛县屋久岛附近海域坠毁，机上8人全部死亡。
