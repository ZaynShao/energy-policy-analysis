# 团标落地难、适配难？深圳如何让标准“写出来”又“用起来”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/QIJgF5A55WaIdLbbaVUw03tdM0mAc7QsEK280gvoUia6O46oFvxBRgFonYTLmOeCasiaCqF7CP2o4P9ibb3qrdL2YAUUl1Y5iay64KowZAm1sic4/640?wx_fmt=png&from=appmsg)

面对团体标准制定滞后、适用性不足成为行业共性难题，深圳正探索创新标准供给模式。

南都记者注意到，近日，深圳市市场监督管理局发布了深圳市2026年团体标准创新实践“揭榜挂帅”项目榜单，68个项目覆盖面广、现实针对性强，既有人工智能、低空经济、新型储能等战略新兴产业，也有智慧养老、宠物寄养等民生场景。

“政府定位是规则制定者、环境营造者、服务提供者、监督管理者，不干预标准的具体技术内容与编制过程。”专家分析指出，榜单背后折射出深圳正以更灵活、更贴近市场的标准供给机制，为产业创新和城市治理提供支撑，实现有为政府与有效市场的结合。

**让标准“写出来”且“用起来”**

标准，常被视作产业发展的“技术尺子”和市场运行的“共同语言”。而团体标准，因制定周期更短、市场响应更快、机制更灵活，正越来越成为连接技术创新与产业应用的重要一环。

不过，团体标准领域还存在一些共性难题：有的标准供给跟不上产业变化，有的标准质量参差不齐，还有的标准“写出来”了，却没有真正“用起来”。

针对这些堵点，深圳在全国率先推出团体标准“揭榜挂帅”模式，按照“市场驱动、政府引导、企业为主、社会参与”的思路，将过去相对偏“指定编写”的方式，转变为面向需求公开征集、择优遴选，让标准研制从源头就更加贴近产业实际、市场痛点和应用场景。

综合开发研究院（中国·深圳）企业与市场研究中心执行主任郑天骋在接受南都记者采访时指出，深圳此次核心创新点在于，彻底转变了标准供给逻辑，将传统模式下政府主导、自上而下指定编制主体的“被动供给”，转变为需求导向、自下而上竞争揭榜的“主动对接”，将“指定编写”变为“竞争遴选”，核心制度优势体现在建立了市场化的遴选机制、精准化的需求匹配、高效化的资源整合与落地约束，发挥团标制定周期短、市场响应快、机制灵活的先天优势，

“这一模式解决了团标领域长期存在的三大堵点，通过前期广泛调研梳理出46个真实需求方向。在政府资金有限的情况下，通过多方参与筹资的方式，充分调动企业资金的方式，高质量完成课题需求。”郑天骋分析认为，本次团标揭榜挂帅的全流程实现了全方位落地，在揭榜征集环节，需求榜单核心来自产业一线与市场主体的真实诉求。

**专家：揭榜项目与城市发展战略深度对接**

记者了解到，本次团标“揭榜挂帅”工作从46个需求方向、近200份申请中最终选出68个项目。从入选项目看，“揭榜”项目紧密围绕深圳城市发展战略与产业发展实际，体现了极强的实践导向与应用价值。

在新质生产力领域，涵盖人工智能、低空经济、新型储能、半导体、基因技术等前沿赛道，着力推动产业高端化与智能化升级；在可持续发展领域，围绕近零碳社区园区建设、工业碳数据管理、产品碳足迹评价、新型电力系统（虚拟电厂）及光伏组件循环利用等提供了全面技术指引；在城市治理领域，覆盖物联感知、应急安全管理、智能环卫及电梯托管等新型城市服务场景；在民生幸福领域，纳入了从干细胞与基因治疗质量控制、智慧医疗、妇幼及慢性病健康管理，到智慧养老评价、青少年脊柱健康等一系列技术与管理规范；在品质消费领域，囊括了共享经济、潮流玩偶、高端食材与宠物经济等新消费场景的系列标准。

郑天骋表示，本次成功揭榜的68个项目整体与深圳城市发展战略实现了深度对接。其中，新质生产力领域的项目直接覆盖深圳“20+8”产业集群中的人工智能、低空经济、新型储能、半导体与集成电路、生物医药等核心战略性新兴产业与未来产业，聚焦产业发展关键环节、共性技术、安全规范制定标准，补全产业链标准短板，有助于推动“20+8”产业从“技术领先”向“标准领先”跃升。（南都N视频 记者 张艳丽）
