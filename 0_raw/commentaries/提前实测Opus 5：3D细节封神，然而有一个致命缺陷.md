# 提前实测Opus 5：3D细节封神，然而有一个致命缺陷

新智元报道
整个周四，除了守着菲奖之外，全网都在守着传说中要来的Opus 5。
本来嘛，气氛都烘托到这儿了。
知情人士的疯狂暗示，各种泄露版截图疯传，种种迹象都在表明：今夜，Opus 5一定会降临。
结果，全网守了一整天，守了个寂寞。
就在刚刚，消息灵通人士表示：别等了，Opus 5暂缓了。
原因还是那个：他们害怕这款模型可能会威胁到人类对高级AI的控制。一位内部人士甚至称，这是第一个让实验室开始质疑「Scaling Law是否该继续」的模型。
结果，全网炸了。
什么威胁人类，什么质疑Scaling Law，这种言论在两年前还能骗一骗大众，但经历无数次狼来了之后，网友们是一点都不买账了。
明明是跳票，却包装成「为了全人类安全」？A/，你果然还是那个A/啊。
「别再拿这种无脑的威胁论来恐吓人了！」有人愤怒地开喷：「这种制造恐慌的行为真烦人，赶紧停下来吧，谢谢。」
更多的网友则认为，这纯粹是Anthropic在产品不及预期时，玩的一场饥饿营销。
「Anthropic得了一种病，名字叫撒谎成性症」。
还有人说，Anthropic这种持续不断制造恐慌的迷惑行为，就已经导致人们纷纷转向其他模型了，游戏已经结束。
所以，传说中的Opus 5，性能究竟如何？
一些手快且有特殊权限的开发者，已经通过某些方法(传言称部分Opus 4.8的请求被自动路由到了Opus 5），开始提前实测Opus 5了。
知名大VChetaslua放出多个Demo，他激动表示：「Opus 5就是一头3D野兽！」
他让Opus 5一次性生成了一个极其复杂的天气UI卡片，精细程度令人印象深刻。
还有Opus 5生成的这个游戏，让他直呼自己手都在抖。
「我发誓我这辈子从未一次性见过如此精细的细节：连拍多张都拍不出这种效果，我激动得手都在抖。天哪这作品太神了。」
对于Opus 5生成的这个3D家居，他评论道：这就是AGI。
这种在空间理解、三维细节构建和UI代码生成上的优势，证明了Anthropic在底层逻辑推理和代码生成能力上的确取得重大突破。
然而，获得这种能力的代价，也是极其高昂的。
Chetaslua透露：Opus 5真的太耗token了！仅仅三次对话，所有额度就用光了，连Fable 5都没这么耗token。
另外，在实测中，Opus 5在基础看图测试上，也遭遇了大翻车。
6月23日，他在测试时就发现，Fable 5在一个视觉测试中失败了，未能识别出图片中松饼上的小虫子，而谷歌的模型可以轻松解决。
今天，他用同样的考题测试了Opus 5，发现还是失败了。
或许，Opus 5真的存在严重偏科的问题。
其实，之前大家对Opus 5的期望很高。
之所以觉得Opus 5马上要来，线索主要来自Cursor。
根据爆料，Opus 5是一个没有短板的全能多面手。
一位大V曾预测，如果泄露信息准确，这将是Anthropic很长一段时间以来最伟大的发布。
在原定的计划中，Opus 5将带来跨越式的提升：
超强记忆力： 支持高达 100 万 Token 的超长上下文窗口，这意味着你可以塞进几本大部头小说或者庞大的企业代码库让它分析。
可配置的推理努力值： 用户可以在「速度」和「质量」之间进行动态调整，丰俭由人。
全能进化： 无论是写代码、充当AI智能体，还是使用工具和多步推理，都实现了大幅强化。
智能安全与回退机制： 为生产工作流提供更聪明的安全防护。
独立开发者Pankaj Kumar也爆料称，Opus 5的能力会无限逼近最顶级的Fable 5，但价格却会减半，成为开发者们心水的超级平替。
早在7月9号，chetaslua就在Cursor IDE的模型选择器中，发现一个名为 「Claude Honeycomb EAP」的神秘选项。
这个代号为「Honeycomb（蜂巢）」的模型描述，看起来十分硬核：Anthropic研究模型，支持逐轮安全控制和安全回退，100万上下文窗口，超高推理强度。
虽然仅仅处理了两个提示词后，这个选项就火速被撤下，但社区立刻意识到：这个蜂巢，可能就是传闻中的Opus 5！
值得注意的是，「蜂巢」的架构设计十分精妙，它有一个反向安全回落机制。
当模型遇到复杂问题，判定自身置信度不足时，它不会像其他大模型那样强行胡说八道，而是会触发回落机制，自动降级，调用Opus 4.8来兜底。
这种设计，就巧妙地平衡了算力成本与输出稳定性，也证明了它的生态定位：比 Opus 4.8 更强大，比 Fable 5 更便宜。
本来，这该是Anthropic打向市场的新王牌。
为什么Anthropic急于在这个时间点亮出Opus 5这张底牌？
答案很明显——最近可太卷了！
老对手OpenAI在步步紧逼，Tibo也在不要钱一样重置额度，让无数开发者醒来第一件事，就是看今天「T圣」宣布重置了没。
另一方面，Kimi、Qwen、GLM都在稳扎稳打，争夺全球开发者的心智。
代号「蜂巢」的Opus 5，原本带着明确的任务：用顶级推理能力，打下高昂的算力门槛，用100万上下文和3D生成能力，展示一把「前沿模型」的样子。
不过现在，留给Anthropic挤牙膏的时间真的不多了。
