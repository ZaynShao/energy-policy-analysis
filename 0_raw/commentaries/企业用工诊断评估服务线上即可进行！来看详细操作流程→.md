# 企业用工诊断评估服务线上即可进行！来看详细操作流程→

登录浙江政务服务网
浙江政务服务网登录地址：
https://mapi.zjzwfw.gov.cn/web/mgop/gov-open/zj/2001999689/reserved/index.html
打开浏览器，在地址栏中输入浙江政务服务网地址访问地址，切换为法人登录。
登录后，搜索并进入“浙里人社”，然后点击主题服务中的“企业用工登记（书面审查）一件事”。
企业用工“体检自测”
选择企业用工“体检自测”模块，点击“快捷检测”，进入快捷检测答题。
初次答题需要填写企业基本信息，下次答题无需再次填写。
和谐劳动关系创建自测进行答题，作答完毕点击提交，在“报告查询”模块可查看诊断报告。
余杭区和谐劳动关系创建服务人员：姚老师，联系方式：19016986757。
如有疑问可咨询区人力社保局劳动仲裁科，联系方式：0571-89517022。
