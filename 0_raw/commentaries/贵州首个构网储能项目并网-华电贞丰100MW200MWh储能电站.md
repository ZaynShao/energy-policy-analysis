# 贵州首个构网储能项目并网-华电贞丰100MW/200MWh储能电站

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)  

储能与电力市场获悉，近日，贵州省首座构网型储能电站华电贞丰100MW/200MWh电化学储能项目全容量并网，正式投运。项目由中国能源建设集团浙江火电建设有限公司承建。

  

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/nJIHJiauQqnxMReeqWI7dRv9Sb58YJibQk7b7CO7I2IlcOVVjIeJ5Bo5aJUo8cvDgBBrOKnq9oucHUzt4hOpqctqOSF3u0KjIwlWvraNzMT38/640?wx_fmt=jpeg&from=appmsg)

信息来源：中国能建浙江火电

  

项目位于贵州省黔西南州贞丰县，总占地面积约25亩，是2025年贵州省重大工程和重点项目。建设规模为100MW/200MWh，采用构网型磷酸铁锂电池储能系统，由40套2.5MW/5MWh储能单元构成，配套1座220千伏升压站，配置1台容量为100兆伏安的主变压器，以1回220千伏线路送出。

  

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/sHxXAO72z0jbykZaVuFf9DPPiaTNicnoCQ6zKpuqm8wU6C8oo1EvSwymYkYyNvQeDr6AVord3DTDAeZ5iaAenRiajscTUFSXPycgaSN4r8m4uFM/640?wx_fmt=jpeg&wxfrom=13&tp=wxpic#imgIndex=2)

信息来源：中国能建浙江火电

  

看个广告休息一下![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ibQ6Q066YicvUrISt2HTHibzQLHagVXTI0icHuu8j9l7VicIMYkGQ4a0sZubzCiaYLVbnQtvbYmZqkYcicIBJRaHbpdXQ/640?wx_fmt=jpeg&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=1)

  

贞丰电站集成了先进电池管理、能量转换及电网调度通信技术，能够实现毫秒级快速功率实时响应电网需求，精准执行调峰、调频、备用、需求侧响应等多种功能。投运后年均充电储能43.86GWh、放电供能37.39GWh，年循环次数超210次，处于行业领先水平。
