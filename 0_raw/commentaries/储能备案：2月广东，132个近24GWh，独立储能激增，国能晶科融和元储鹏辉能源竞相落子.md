# 储能备案：2月广东，132个近24GWh，独立储能激增，国能/晶科/融和元储/鹏辉能源竞相落子

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/nJIHJiauQqnz6VBj0uTricSqbFeTjYA87gs8c7tpsicGRfrlUcwWwHsxaJoevJOHwvOvRbTfcB01miciaXxavYHG1GjdMuvhAUPg8G4MjUP2yOAw/640?wx_fmt=jpeg&from=appmsg)  

储能与电力市场统计，2月份广东省共备案储能项目**1****32****个**，总规模超**11.7****GW/****23.8****GWh****。其中，**独立式储能项目备案了65个，总规模达**11.62****GW/****23.59****GWh****，****占总备案规模的99%（GWh)**。此外，还有66个用户侧储能项目备案，项目类型以工商业储能为主，还涵盖充储一体化、光储一体化等。  

根据2025年10月至2026年2月表格数据，广东省储能市场在2026年2月出现结构性转变：市场重心已从数量多、单体规模小的用户侧储能，转向了单体规模大、数量集中的独立式储能。独立式储能项目占当月总备案项目数量的比例从3.5%上升至49.2%。

  

广东省2月份的储能项目备案数量较1月份163个有所下降，但整体备案规模却实现爆发式增长，相较于1月3.52GW/7.06GWh的备案规模，2月备案规模环比增长237%**（GWh)**。这背后主要是独立储能项目的贡献，1月广东仅有14个独立储能项目备案，2月直接跃升至65个，拉动整体规模大幅走高。

  

![image](https://mmbiz.qpic.cn/mmbiz_png/nJIHJiauQqnxaJakw1gMr9Tu6czicFrnWDPia77JUHn83xaUFAQTIC5tx4xrIadfmpWpBXdSK0tDhm4ncVSnYibSkIfOR26MARHEnSS37bVFDGM/640?wx_fmt=png&from=appmsg)  

本月备案中还有两个值得关注的项目，一个是单体规模超过2GWh的大型储能项目，另一个则是采用了锂电+钠离子相结合的混合技术路线：

  

五华嘉星新能源有限公司五华县河东镇1300MW/2600MWh独立储能电站项目  
  
汕尾市200MW/800MWh锂钠新型储能示范项目

  

广东省2月份储能备案项目遍及19个地市。**广州****市以备案****2.4G****W/****4.81G****Wh的规模居首位**。**东莞市****、****梅州市**的备案规模分别位居第二、第三，分别为**1.6G****W/****3.28G****Wh、****1.55G****W/****3.1G****Wh**。佛山市、深圳市、中山市、汕尾市紧随其后，**备案规模均在GWh级以上。**

投资规模方面，**广州****市****投资规模最大，达到了****67.37****亿元**；其次是东莞市，**43.07****亿元**。江门市投资规模相对较小，投资金额未超2000万元。（深圳市项目投资金额未明确）

  

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/nJIHJiauQqnxYIG54fMiczGd2tX05HQtFD90JnUqgomiat8R78iapugoCoCecTqzVzpGkd9tdhDPtmjVsIyr9lrqRHRiccnSmYo2veBl9Ypf7Hzk/640?wx_fmt=png&from=appmsg)

  

项目业主方面，涵盖了国家能源集团、晶科、融和元储、鹏辉能源等。其中，消费电子设备制造企业品胜电子也跨界入场，在深圳市部署了3个用户侧储能项目。品胜电子成立于2003年，总部位于深圳，是一家**专注于消费电子领域，集研发、设计、生产、销售于一体的国家级高新技术企业**。产品主要围绕新能源电能支持、音视频传输等领域。

  

2020年，品胜进军新能源赛道，成立新能源事业部。品胜新能源以停电宝、外接电池户外电源（放电宝）、电动汽车充放电一体化系统、便携储能、家庭储能、工商业储能、储能充电桩一体化系统、绿色能源投资开发运营（新能源开发、投资、设计、安装、运维）等领域为发展核心。
