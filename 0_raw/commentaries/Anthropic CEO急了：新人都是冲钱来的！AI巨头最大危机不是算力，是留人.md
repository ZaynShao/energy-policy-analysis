# Anthropic CEO急了：新人都是冲钱来的！AI巨头最大危机不是算力，是留人

新智元报道
7月27日，AI科学家、北大校友Lilian Weng几乎以「逃命」的姿态，宣布离职。
作为独角兽Thinking Machines Lab的联合创始人，她直言身体吃不消，身心俱疲，只好「艰难而悲伤」决定离开。
然而，仅仅48小时后最富戏剧性的一幕上演了。
7月29日，病榻上的余温似乎还未退去，她就被曝加入OpenAI，执掌递归自我改进（Recursive Self-Improvement，简称RSI）研究的帅印。
一年内，Thinking Machines已经失去了四位联合创始人。
同一个月，谷歌先后失去了Tranformer共同发明人Noam Shazeer和诺贝尔化学奖得主John Jumper。
招到顶尖AI人才本就很难。但事实证明，想把这些人留住，难度也几乎一样大。
AI巨头都面临人才的「忠诚问题」。Anthropic的CEO Dario Amodei，已经向内部发出警告：「越来越多的人，就是为了钱，而不是冲着使命。」
5月19日，AI大神、OpenAI联合创始人Karpathy单飞多年后，突然宣布加入Anthropic，重返AI研发一线。
同一天，传出Twitter创始人Jack Dorsey加入Anthropic。
推文简短：「BREAKING: Jack Dorsey has joined Anthropic. 」（突发： Jack Dorsey已加入Anthropic。）
原帖上了X热搜，但热搜不代表真相。这其实是假消息。
然而，X上迅速掀起一波模仿式玩梗热潮，大量用户套用「BREAKING: ____ has joined Anthropic」的格式，把各种名人「安排」进了Anthropic。
从科技圈名人到政客，从体育明星到卡通角色，从已故物理学家到成人影星，无人幸免。

恶搞归恶搞，但Anthropic对人才的吸引力，从中可见一斑。
6月，Anthropic更让人震惊！当月19日，诺奖得主、谷歌9年老将、AlphaFold核心负责人John Jumper宣布离职，加入Anthropic。
当时，就有大V惊呼：「Anthropic一定有什么惊天秘密，要不然为什么这么多人加入Anthropic?」
随后，AlphaFold 3 核心作者、Gemini团队成员Jonas Adler和Alexander Pritzel也加入了Anthropic。
6月30日，当今最重要的经济学家之、斯坦福大学终身教授Chad Jones休假期间加入Anthropic研究所，从事AI与经济增长的研究。
7月9日，前美联储主席、诺贝尔经济学奖得主伯南克被任命为Anthropic长期利益信托（LTBT）新成员。
此外，在过去6个月内，xAI联创Ross Nordeen、微软AI平台负责人Eric Boyd、Meta前数据中心建设负责人Tim Hughes、耶鲁法学院驻校研究员Matt Botvinick、弗吉尼亚大学经济学教授Anton Korinek等业界学界领袖级人物加入Anthropic。
Meta去年砸重金搞出来的AI梦之队，Anthropic悄无声息毫不费力的组建了AI梦之队。
此外，上月包括UC Berkeley EECS计算机科学部主任Jelani Nelson、「硅谷黄埔军校」YC合伙人Tom Blomfield等重磅人物加盟Anthropic。
Anthropic可谓「人满为患」，即便在硅谷也非同凡响。
从2024年底到2026年中，据DINGQ不完全统计，至少有6家独角兽企业CTO加入Anthropic，其中就有Transfomrer唯一的女性合著者Niki Parmar。
Claude则找到了8位独角兽的CTO加入Anthropic，而且7位放弃了管理岗，以Member of Technical Staff「技术团队成员」入职。
这些原CTO背景天差地别，来自不同行业，毫无共同点可言。
唯一的合理解释是：他们看到了一条能力曲线——一条我们普通人还没看到的曲线。
历史反复证明，每当这种信号出现，公众要等12到24个月之后才会得知真相。
而现在，这个信号已经出现了。
不过，并非所有人都从内心认可Anthropic的使命，Dario Amodei的担忧并非空穴来风。
比如，有网友就介绍了他所知的一个例子。为了能通过企业文化面试，有人删除了网上所有支持开源的内容，甚至不断练习「开源就是安全风险」。
最后，这名申请人顺利入职，年薪100万美元。
虽说Anthropic拒绝像Meta砸钱挖人，但他们的薪水也绝对具有市场竞争力。
按Anthropic内部职级划分的中位数总薪酬，即便是初级软件工程师一年底薪也有25万美元，还有12.5万美元期权。高级软件工程师年包择优56.2万，足以媲美甚至超过很多美国公司的高管。
这种高薪不让人注意到也难啊！
阿莫迪明确表示，Anthropic不会为了防竞争对手挖人而涨薪。如果OpenAI或谷歌DeepMind开出更高的价码，Anthropic会选择放人走。
他的理由是：跟着对手加薪会引发内部公平问题，还会腐蚀公司文化——而正是这种文化，才让公司估值做到了3000亿美元。
请注意：Dario Amodei本人目前净值156亿。
更值得玩味的是大背景。阿莫迪曾预测，AI可能在五年内取代高达50%的初级白领岗位。一个正在研发可能让数百万工作岗位消失的技术的人，同时却在担心自己的员工不够关心他们所做事情的社会影响。
这种使命和金钱之间的拉扯，并不是Anthropic独有的。
OpenAI也经历过类似的危机——先是把自己从非营利组织改成利润上限模式，后来又发生了董事会大地震，一度把奥特曼赶下了台。
