# 北京怀柔丨构建覆盖重卡自动驾驶全场景的数字化、智能化产业生态

为深入贯彻党的二十大和二十届历次全会精神，落实有关文件精神以及北京市高精尖产业发展相关要求，加快推进怀柔高精尖产业高质量发展，结合本区产业发展实际，北京市怀柔区经济和信息化局制定了《怀柔区“十五五”时期高精尖产业发展规划（征求意见稿）》并于近日发布。
《征求意见》明确：
高端汽车装备制造：以高端重卡智能化、轻量化、绿色化为核心方向，突破高端重卡自动驾驶技术，吸引氢燃料动力系统、智能驾驶传感、高端车载电子等核心零部件企业落地，完善新能源重卡核心零部件配套体系。实施高端重卡智能工厂关键零部件工艺升级及智能化改造，提升整车生产效率与质量稳定性。提升整车智能制造系统集成能力，构建覆盖重卡自动驾驶全场景的数字化、智能化产业生态。强化重卡产业链闭环韧性，重塑重卡整车、零部件到后市场生态，推动重卡集群化发展，建设具有全球竞争力的高端汽车装备智造高地。
