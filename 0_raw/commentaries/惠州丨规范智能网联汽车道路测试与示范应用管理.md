# 惠州丨规范智能网联汽车道路测试与示范应用管理

为指导和规范惠州市智能网联汽车道路测试、示范应用工作，推动汽车智能化、网联化技术应用和产业发展，依据有关法律、法规、规章和政策文件规定，结合本市工作实际，惠州市工业和信息化局、公安局、交通运输局联合制定《惠州市智能网联汽车道路测试与示范应用管理实施细则（试行）》并于近日印发。
《细则》适用于惠州市行政区域范围内进行的智能网联汽车道路测试与示范应用活动。
总则：明确制定目的、政策依据及适用范围，并对核心概念进行界定。
管理机构及职责分工：确立由市工业和信息化局、公安局、交通运输局组成的“惠州市智能网联汽车道路测试与示范应用联合工作机制”，并明确三部门具体职责分工。
道路测试与示范应用申请条件：分别对道路测试主体、示范应用主体、驾驶人车辆的资格条件作出详细规定。
申请程序：核心是通过提交“安全性自我声明”及相关材料，经市联合工作机制确认后，向公安交管部门申领临时行驶车号牌。明确材料审核、专家评审、实车审查等环节的时限(20个工作日），并对测试车辆增补、信息变更等情形作出规定。
道路测试与示范应用管理：对道路测试和示范应用过程中的具体管理要求进行细化。道路管理：明确由交通部门对测试道路进行分级、隐患排查和标识设置，并对在快速路、高速公路测试的时段和路况提出限制要求。车辆与人员管理：要求车辆必须进行显著标识，驾驶人须全程监控并随时准备接管。严格禁止搭载与测试无关的人员或危险货物，示范应用载人需提前告知风险。动态监管与退出机制：要求主体定期提交阶段性报告和总结报告。同时，明确列举六种应当终止测试或示范应用的情形（如严重交通违法、发生严重事故等），建立退出机制。
事故和违法处理：明确交通违法和交通事故的处理原则。特别强调了事故发生后，主体须在24小时内上报，并按要求提供事故前后至少90秒的车辆状态数据，强化事后追溯和主体责任。
附则：对关键术语进行解释说明，并明确细则解释权和有效期。
