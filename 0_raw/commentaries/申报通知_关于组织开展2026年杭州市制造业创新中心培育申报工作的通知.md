# 申报通知|关于组织开展2026年杭州市制造业创新中心培育申报工作的通知

各有关企业：
为布局制造业创新体系关键节点，加快推进科技创新和产业创新深度融合，根据《杭州市制造业创新中心管理办法》（杭经信技创〔2025〕3号，以下简称《管理办法》），现组织开展2026年杭州市制造业创新中心培育申报工作。有关事项通知如下：
一、重点领域
重点围绕市“296X”先进制造业集群相关细分领域进行布局培育。
二、申报要求
市级制造业创新中心申报和组建工作由牵头单位负责，基本条件及要求参照《管理办法》第六条、第七条。申报材料包括：
（一）创建方案。由牵头单位编制《杭州市***创新中心创建方案》（编写提纲见附件1）。
（二）证明材料。包括但不限于以下证明材料：
1.创新中心运营主体（独立企业法人）注册证明或各股东出资协议证明；
2.牵头单位符合创建要求的相关证明材料;
3.产业联盟成立证明或拟建设产业联盟主要成员单位协议书等。
三、其他事项
此次市级制造业创新中心培育申报可分两个批次报送，第一次批次考虑衔接省级制造业创新中心申报时间节点，截止时间为9月29日；第二批次截止时间为11月20日。请各企业根据自身需求，任选一个时间节点，在截止日期前将《杭州市***创新中心创建方案》及相关证明材料（装订纸质版一式1份）、《2026年杭州市制造业创新中心推荐汇总表》（电子版1份）报送至余杭区经信局，材料寄送地址：杭州市余杭区文一西路1500号余杭区经信局8号楼605室，杨老师0571-89515942。
