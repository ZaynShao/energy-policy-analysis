# 苹果起诉OpenAI：系统性窃取商业机密

OpenAI CEO山姆·奥特曼 vs 苹果CEO蒂姆·库克。图片由AI生成
文丨博阳
编辑丨徐青阳
美国当地时间7月10日，苹果公司正式在加州北区联邦法院对OpenAI提起诉讼。两家公司的关系，在短短两年间从亲密合作走到了对簿公堂。
苹果在诉状中的核心指控是“窃取商业秘密”，声称OpenAI为了加速开发自己的硬件设备，秘密发起了一场协调行动，系统性地获取了苹果未发布产品的机密信息。
对此，OpenAI发言人德鲁·普萨特里（Drew Pusateri）予以否认，声明称：“我们对其他公司的商业秘密没有兴趣。我们始终专注于构建创新技术，以赋能全球各地的人们。”
这场突如其来的官司，让OpenAI初生的硬件业务和即将到来的IPO前景，都站到了悬崖边上。
01
离职员工组团“带货”
苹果在长篇诉状中，以详细证据披露了OpenAI前苹果员工盗窃商业秘密的固定模式。
苹果诉OpenAI起诉书
诉讼将矛头直指OpenAI的两位核心硬件员工：首席硬件官Don Tan和技术团队成员刘畅（Chang Liu）。
其中，Don Tan在苹果工作了24年，曾升任产品设计团队高级主管及产品设计副总裁，领导了iPhone、智能手表（Apple Watch）、AirPods等核心硬件的开发。
他于2024年初离开苹果，与苹果原首席设计官乔尼·艾维（Jony Ive）及苹果设计资深人士埃文斯·汉基（Evans Hankey）共同创立了AI设备初创公司io Products Inc.。
2025年，OpenAI以高达65亿美元的全股票交易将这家仅成立一年的设计工作室整体收购，Don Tan也顺理成章地出任OpenAI的首席硬件官，全面主导其硬件产品线的研发。
但在这场诉讼中，艾维和汉基未被列为被告。
苹果在诉状中详细列举了Don Tan的“窃密”手段。诉讼称，Don Tan在离职前就通过电子邮件将苹果重要供应商的信息发送给自己，并与OpenAI或其合作者秘密会面。
在全面负责OpenAI的硬件项目后，他更是成为了针对苹果员工的“挖角总指挥”。
为了获取技术细节，Don Tan在招聘面试中甚至直接使用苹果内部的机密项目代号，并指示仍在苹果工作的求职人员将电池、逻辑板、屏蔽罩等“实际零部件”和原型机从苹果带到面试现场进行“展示和讲解”。
此外，Don Tan还带走了一份解释苹果内部管理人员离职安全程序的机密文件。据称，他和OpenAI的招聘人员利用这份文件，指导即将离职的苹果员工如何规避公司的安全程序。
比如，建议他们不要透露下一任雇主是OpenAI，延长对公司系统的访问权限，以及拒绝签署任何离职文件，从而避免触发“可怕的离职护送”，即让安全人员立即切断其访问权限并护送离开。
苹果在审计中发现，一名当时仍在苹果工作的员工，在与Don Tan进行OpenAI面试前的几小时内，“截屏并下载了与一个高度机密的苹果项目相关的文件”。
另一位在诉讼中被点名的关键被告是刘畅，他在今年1月离职加入OpenAI，曾是苹果高级系统电气工程师，在苹果工作了八年。
苹果的设备监控记录显示，刘畅在离职后故意不归还公司配发的工作笔记本电脑。在加入OpenAI后的几周内，他甚至利用苹果公司系统此前未知的一个身份验证漏洞，秘密访问并下载了数十份苹果机密的硬件文件。
这些文件包含了大量关于苹果未发布产品、工程演示文稿、技术规格以及专有项目数据的详细信息，甚至包括一份关于苹果硬件中使用的复杂电路板制造和测试的演示文稿。
不仅如此，刘畅在招募其他苹果同事跳槽到OpenAI时，还详细指导对方在面试前应该针对哪些未发布产品的秘密信息进行研究，并传授他们如何在复制苹果机密文件时“避免与安全团队发生麻烦”的技巧。
苹果表示，在刘畅离职时，公司曾联系他，提醒他保密协议的存在，安排离职面谈并确认他已归还公司设备，但刘畅未予回应。
除了Don Tan和刘畅两条明线，苹果在文件中声称，已有超过400名前苹果员工在OpenAI工作。这些前员工不仅来自技术团队，还涉及产品设计、显示屏、天线以及硬件采购等多个部门。
OpenAI的触角并未止步于挖人。苹果在诉状中指控，OpenAI还将手伸向了它的供应链，至少接触了两家苹果的长期供应商。
其中一次，OpenAI误导了一家中国主要组装商，这家组装商同时也为苹果组装iPhone和AirPods。OpenAI让其相信已获得苹果官方许可，从而诱使对方执行了一项专属于苹果的机密金属表面处理技术。
另一次，OpenAI接触了一家电池供应商，通过提出“有针对性的问题”来套取苹果核心组件的工艺细节。
据The Information此前报道，中国iPhone和AirPods的主要组装商立讯精密已获得一份合同，负责组装OpenAI至少一款设备，OpenAI也已接触AirPods、HomePods和Apple Watch的组装商歌尔股份，为其未来产品供应组件。
02
硬件梦挖了苹果的根
回顾苹果和OpenAI的过往，两家公司曾经是站在同一条战壕里的盟友。
2024年，双方达成深度合作，OpenAI的ChatGPT被正式整合进苹果的智能平台和Siri数字助手中。
在当时的苹果全球开发者大会（WWDC）上，OpenAI CEO山姆·奥特曼（Sam Altman）是苹果的座上宾。苹果软件负责人克雷格·费德里吉（Craig Federighi）也公开称赞OpenAI是AI领域的“先驱和市场领导者”。
彼时，两家公司看起来正要开启一段广泛的战略伙伴关系。苹果允许用户在Siri中访问ChatGPT，并利用AI技术通过iPhone的视觉智能功能生成文本、分析周围物体。
随后，双方合作进一步扩大，苹果还将ChatGPT作为在Image Playground应用中创建图像和分析屏幕内容的选项。
然而，在合作的表象之下，裂痕早已出现。
按照苹果在诉讼中的说法，OpenAI对苹果技术的兴趣，远不止软件层面的合作。这家AI公司正在构建自己的消费硬件产品线，目标直指智能手机之后的新硬件时代。
苹果在诉状中措辞严厉。他们指出，从技术成员到硬件负责人，OpenAI在各个层面都在获取苹果的商业秘密和机密信息，商业伙伴也参与其中。苹果认为，靠这种方式搭建的硬件业务，根基从一开始就是烂的。
双方关系的恶化实际上有迹可循。
今年早些时候，彭博社就曾报道过，OpenAI因为对合作收益不满，甚至考虑过对苹果采取法律行动并发出违约通知。与此同时，苹果自身也在加速AI设备的研发，正在开发智能眼镜、挂坠和配备摄像头的AirPods等多种设备，以适应AI时代。
今年4月，负责苹果智能眼镜项目的高管跳槽去了OpenAI，直接加剧了双方的对立。
其实在2月份，苹果就曾致函OpenAI，对机密信息可能“以不当方式流向OpenAI”表示担忧，试图在庭外解决争端，并要求对方停止相关行为、清除任何专有材料。
但苹果表示，那封信石沉大海，没有收到任何回应，这最终促使苹果决定提起诉讼。
03
IPO前夜的“惊雷”
这起诉讼的时机，对OpenAI来说非常微妙。
这家公司正准备在未来几个月内进行首次公开募股（IPO），且已向监管机构秘密提交了上市文件。法律纠纷带来的不确定性和潜在的赔偿责任，无疑会给投资者信心蒙上阴影，上市的具体时间目前仍悬而未决。
苹果与OpenAI的合作已经明显降温。虽然ChatGPT仍然是苹果设备上的一个选项，但苹果在2026年6月发布的新版Siri AI，其底层技术已转而由谷歌的Gemini提供支持。
双方在消费硬件市场的直接竞争，已经不可避免。
奥特曼对硬件早就有想法。他想要造的AI设备，可以像首饰一样戴在身上，也可以放进口袋，能录音、录像，也能听懂语音指令。OpenAI对外很少谈及硬件进展，只说过在开发一个AI设备“系列”。目前已知的是一款桌面设备，外形像圆盘，用户可以通过语音来操控。
正是这些硬件野心，让苹果觉得不能再等了。苹果发言人汉娜·史密斯（Hannah Smith）表示，公司“将始终捍卫我们团队的努力工作和创新，我们正在采取一切适当措施来做到这一点。”
为此，苹果在诉讼中提出了多项要求：法院下令禁止OpenAI继续使用或披露任何商业秘密；要求OpenAI归还所有专有材料并销毁相关记录；甚至要求OpenAI重新设计其即将推出的产品，以确保不包含任何苹果的技术。
此外，苹果还要求进行陪审团审判，并寻求金钱赔偿以及归还任何被盗财产和数据。
苹果在诉状中写道：“这只是冰山一角。苹果无法看到OpenAI闭门之后发生的事情，在那里，这种不当行为已被常态化并受到领导层的示范。”
这起案件让许多人联想到2017年谷歌对Uber提起的诉讼。当时，谷歌自动驾驶汽车团队的长期负责人安东尼·莱万多夫斯基（Anthony Levandowski）在离职前往Uber建立竞争项目之前，下载了多份秘密文件。
莱万多夫斯基承认窃取谷歌机密
谷歌与Uber最终达成和解，但美国司法部起诉了莱万多夫斯基，他最终认罪。2020年被判处18个月监禁，并被要求支付约76万美元的罚款和赔偿。但唐纳德·特朗普总统随后在他第一个任期结束时赦免了他。
在OpenAI诉讼中，苹果表示，在2月份调查的早期阶段，它曾致函OpenAI，对机密信息可能流向该公司表示担忧，并询问OpenAI正在采取哪些措施来避免这种情况，但OpenAI从未回应。
苹果在通过监控和对在职及离职员工采取法律行动来保护其知识产权方面，有着悠久的记录。
2019年，苹果起诉了前芯片首席架构师杰拉德·威廉姆斯三世（Gerard Williams III），因为他与人联合创立了芯片初创公司Nuvia，苹果声称他还在苹果工作时就启动了他的公司概念并招募员工，违反了苹果的雇佣合同。双方最终于2023年达成和解。
苹果与OpenAI这场科技巨头间的对撞，才刚刚拉开序幕。
