# 江西首家虚拟电厂入场，实现电能量市场全品类交易

「储能与电力市场」获悉，近日，国网江西综合能源服务有限公司虚拟电厂顺利完成中长期月度、D-2及日前现货全品类电能量市场交易，成为江西省内首家打通电能量市场各交易环节的虚拟电厂，标志着江西虚拟电厂进入全流程市场化运营新阶段。
近年来，江西可再生能源装机占比持续提升。随着波动性、随机性电源在能源供应结构中的比重日益增大，电力系统对灵活调节能力的需求愈加迫切。今年年初以来，国网江西省电力有限公司积极组织12家试点单位开展虚拟电厂建设。作为首批试点单位之一，江西综能服务公司开展资源潜力评估与签约聚合，同步推进平台开发及系统接入，积极参与电力市场交易规则研究，完成能力校核、注册公示并取得运营牌照，实现平台建设、系统接入、资源聚合、市场注册、电力交易全链条贯通。目前，该公司已聚合用户20户，涵盖负荷类与发电类资源，总聚合容量达16.43万千瓦。
江西综能服务公司虚拟电厂发挥“源-荷”协同互动优势，在用电高峰电力供应偏紧、新能源大发时段，通过主动调节出力、引导用户错峰用电，发挥削峰填谷作用，缓解电网运行压力，促进新能源的充分消纳。同时，该虚拟电厂依托多市场、多品种交易能力，实现电能量市场、辅助服务市场和需求响应业务的有效衔接，推动各类可调资源收益多元化。国网江西电力持续助力全省虚拟电厂深挖分布式储能等资源调节潜力，积极参与调频辅助服务市场，丰富拓展商业模式，打造聚合规模大、调节能力强、响应速度快的虚拟电厂集群。责任编辑：一口仙气儿
