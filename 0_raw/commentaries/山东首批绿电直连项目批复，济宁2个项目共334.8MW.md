# 山东首批绿电直连项目批复，济宁2个项目共334.8MW

项目地点：山东济宁兖州区
计划投产时间：2027年10月
项目规模：风电、光伏共计18.6万千瓦（186MW）
项目简介：项目负荷由山东时代新能源科技有限公司投资建设运营。电源（风电、光伏及配套送出系统）、储能、直连线路由时代绿色能源有限公司投资建设运营。
项目地点：山东济宁邹城市，
时间安排：2026年10月开工，2028年12月投产
项目规模：电源侧规模14.88万千瓦（148.8MW），其中风电装机13万千瓦、光伏1.88万千瓦
项目简介：项目负荷由山东恒信集团有限公司投资建设运营，电源（风电、光伏及配套送出系统）、储能、直连线路由上海电气新能源发展有限公司与山东恒信集团有限公司合资成立的电源合资公司建设运营。电源侧通过直连线路约20公里连接至负荷侧的可降解塑料一体化项目，并配建5000标方/小时的电解水制氢项目进行负荷调节。
