# 不是，小米怎么又造了台“不太好卖”的车？

这个星期四，终究还是疯狂起来了。
就在今天晚上，小米的第三台车，也是澎程 skynomad 系列的第一台车，澎程 N 级（ 我知道不算准确，但咱们先这么叫吧 ）开了一场技术发布会，顺便公布了一波顶配车型的预售价格。
虽然脖子哥有预感,定价鬼才雷军会给到一个相对低的价格，但不是哥们，五座 N70 Max 卖 25.99 万，七座 N90 Max 卖 29.99 万？
而且这还只是预售价，等到正式上市标准版和 Pro 车型发布，估计五座 N70 的门槛价都要往 20 万以内去了。
好了好了，这下好了。
本来觉得大军压境的各种 9 系 SUV 瞬间松了口气，本来隔岸观火的理想要紧张起来了：好家伙，这个正好卡在 L6 和 L7 中间的定价，原来这波是冲我来的。。。
当然出去有些惊喜的定价，在看完雷总对澎程 N 级的介绍以后，脖子哥的感触还是比较复杂的。
总结来看，这其实是一台长板和短板都非常明显的车型，它和友商们不同，戳中的是一个很小众的需求，市场还没被验证过。和 SU7、YU7 一样，很难在发布初期预测它的市场表现。
相信在看完我的介绍以后，你会同意我的看法。
首先就是外观，澎程 N 级的整体设计风格和 YU7、SU7 的运动化风格截然不同，走的是方盒子路线，横平竖直，线条并不复杂，很有 “ 亦庄大揽胜 ” 的感觉。
好不好看咱们各有喜好，但脖子哥觉得小米在家族化语言的继承上功力真的相当深厚，即使放到了这样直线为主的车上，米字灯、星环尾灯、进气口这些小米标志性的元素也还都在，并且和整体融合的很好，这一点很难得。
外观上的亮点不算多，可以更换的前脸面板算是一个。
当然个人觉得，小米官方的这个几个除了银色以外都有点别扭，所以后市场改装的朋友们，可以加紧开模开起来了。
打开门走到内饰，风格依旧是简单为主，但家族化的继承就没有那么明显了。中控部分增加了一个垂直于地板的储物空间，方向盘也变成了三九点贯穿的两幅结构。
我个人比较喜欢的部分是上面这个，用来控制风向的金属拨杆，属于是保留了机械控制的味道又把出风口隐藏起来了，而且做工也挺精致，整挺好。
再往后，就是这台车绝对的，重点中的重点了：空间布置。
按照雷军的话说，澎程 N 级这台车是从车内空间开始定义，再慢慢配套其他设计的。所以哥们在空间布置的灵活性上，确实也是足够独特的。
传统的七座 SUV ，车里的布局都是 2+3+2 ，如果最后两个座不坐人的话可以收起来变成一个五座车。但七座的澎程 N90 却用上了 2+2+3 的布局。并且，用上了一个从前到后几乎纯平的车内地板。
对比传统 SUV 车型逐级抬高的地板，真的很平有没有。
因为地上没有了各种凸起作为障碍，澎程的三排座椅都可以跟扫地机器人似的，在地面上非常灵活的移动。
比如它的第一排，就可以像这样向后翻转。加上前排的扶手中岛也可以前后移动，就可以和二排变成一个对坐的空间。这个功能即使在五座的 N70 上也有，算是比较基操的部分。
然后是不基操的部分。
在二排和三排座椅下面，N90 设计了四条共用的滑轨，也就是说在传统 SUV 里面没法移动的三排，现在可以和二排一样，移动到滑轨上的几乎所有位置。
比如你想让二排的空间大一点，就可以像这样翻转第三排，直接坐到后备厢里。
如果你想 cosplay 一下运兵车，在装满七个人的时候还能塞点行李，也可以像这样把二三排都挪到比较靠前的位置，把车里的空间都压榨干净。
甚至你还可以选择各种不同的部件，比如床，比如桌子，只要适配澎程 N 级的滑轨规格，就都可以往里头装。压力依旧给到后市场。
而这也是我觉得澎程这台车最有意思的部分。
毕竟虽然雷军说了，澎程 N 的座椅场景设计比友商都要好，都更细节，但无论是座椅翻转还是三排座椅自由移动，在我看来都不算什么用车的重要诉求。
目前新车上的各种旋转座椅，似乎也只有在理想 MEGA Home 这样的 MPV 上使用率会高一些，SUV 因为地台高、车门的门洞小，做移动会客厅啥的其实是有劣势的。
但为了实现这个大概率会吃灰的功能，小米却在工程上花了不少功夫，真的不少。
就比如前说到的纯平地板，为了实现这种的效果，澎程白车身的后地板部分也变成了几乎全平的。
传统 SUV 上面很明显的 C ring 和 damper ring 结构，在澎程的车上都不见了。对比一下它跟标轴路虎卫士的车身区别，是不是还挺明显的。
视觉上少了这么多结构，说明小米要么是为空间权衡了一些车身强度，要么是把传统的加强结构挪到了其他地方，比如车底的反面。
我的倾向是，小米大概率是两头都做了一点，然后找到他们认为合适的平衡点。雷军在发布会上提到的前排地板处的加强架构设计，或许就是这个平衡方案里的一部分。
另一个设计就是后轮包。
要知道在其他三排座 SUV 上，第三排座椅的边上都会有两个这样隆起的结构。
它们的作用，一是为了放下车轮和对应的隔音结构，更重要的是给复杂的悬架腾出空间。
毕竟现在的 SUV 动不动就是五连杆悬架+空气弹簧，组合以后的体积基本小不了一点，自然而然就会占用一些车内空间。
但澎程不行，因为太大的轮包不仅会挡着第二排座椅往后移动，还会让 N90 要坐三个人的第三排座椅变得很挤。所以，小米在澎程的后桥用上了这个悬架结构，学名 integral link suspension 整体连杆悬架。
结构示意，非澎程实际搭载
大伙可能更熟悉的叫法，是 H 臂多连杆。
它本质上是一个多连杆悬架的变种，下面这个巨大的黄色 H 型摆臂，相当于是把好几根连杆集成到了一起，这不仅可以强化后轮对侧向力的支撑，更重要的是可以让连杆结构更靠下、更靠近轮毂，这样就可以省下不少垂向和横向空间。
还有一个比较有意思的点，是在传统 H 臂结构里面，减振器和 H 臂的连接点大概是下面第一张图这样的。
但在澎程上头，小米特意在 H 臂上做了一个图二里的转折，来进一步的降低减振器筒身的高度，减少减振器对车内空间的侵占。
再加上小米还把减振器的位置往外挪了一些 、重新布置了后排空调的出风管路、甚至牺牲掉了后轮后转向机，这一大溜连招下来，澎程后轮轮包在车里的体积，就这么肉眼可见的变小了。
N90上的二三排座椅，也可以靠着这四根笔直的滑轨，实现非常自由的前后滑动了。
而这，也是澎程身上为数不多工程上的亮点了。
没错，抛开座椅空间以及围绕它做出的设计以外，澎程身上的技术和配置亮点其实并没有很多。
即使是四驱车型，前后双电机拢共也就只有 310kW 的峰值功率，并且偏向前驱（ 前轴 210kW 后轴 100kW ）；增程器虽然是和东安深度联合开发的，但无论是热效率还是亏电油耗也都没有断档级的领先。
友商身上频繁出现的磁流变减振器、双腔空气弹簧、主动悬架啥的，澎程的身上都没有。
唯一值得说道说道的，其实就是在友商们增程器都只能加 95 号汽油的时候，澎程可以加 92 。并且很有意思的是，雷军给到为什么这么设计的原因也很简单，就是能在全国几乎所有加油站都加上油。
只能说，哥们是认真开过油车的。
到这，我其实本来准备了两套说辞。
正面一点的，就是现在增程 SUV 的配置内卷已经卷麻了，澎程删掉了很多没那么实用的配置，其实是回归了汽车的工具属性。没那么正面的，则是因为灵活空间需要的研发和工程成本其实并不低，配置的删减本质上是价格和成本的妥协。
但想来想去，我觉得事情可能也没这么复杂，或者说，没这么理性。因为小米目前造的每一台车，都是市面上很少有\友商们也一直不看好的车型。
市面上的纯电轿车都在卷得房率、做舒适性？SU7 就是首要做操控，然后放弃一些空间和舒适性。友商们的 SUV 都在卷家用和实用性？YU7 依旧是用车内空间做代价，把设计放在了第一位。
然后，还都做成了。
这些车型的成功，我觉得已经足够让小米形成一套自己的成功路径了。
那就是友商是 XX ，之前的市场逻辑对自己并不适用，更重要的是，也的确会有很多潜在的消费者为自己叛逆买单。
所以，澎程就来了。它很有 “ 亦庄大揽胜 ” 的气质，却没有瞄准现在很火、产品利润很高的商务领域，而是把矛头指向了家用车的老大、最早喊出了移动的家的理想。
它没有卷配置，也没有在豪华感上太费时间，而是用上了友商们已经不太抱信心的旋转座椅，然后把三排座椅的空间组合玩出了花，选择用更灵活的空间和理想更精致的氛围硬碰硬。
但凡换个别的牌子，我都会觉得这个产品经理脑子有点不正常。
你没参数、没配置，唯一的长板可能还不是大伙的用车刚需，就算价格还不错，但要怎么和别人竞争？
但这是小米，是一个刚出两款车，就被友商当成成功路径的企业。
所以还能说啥呢，只能希望在九月份正式上市的时候，它能拿出一个和 YU7 一样让人大喊卧槽的成绩吧。
