# 伊朗环境署：格什姆岛海滩受到原油污染

伊朗环境署：伊朗格什姆岛沿岸3.2公顷海滩和9公顷近岸水域受到原油污染。
据伊朗塔斯尼姆通讯社14日援引伊朗环境署消息报道，初步评估显示，伊朗格什姆岛沿岸3.2公顷海滩和9公顷近岸水域受到原油污染。
报道援引伊朗环境署一名官员的话说，污染源据信来自海上，在洋流和季风的作用下漂向海岸。这名官员表示，监测、控制和清理工作仍在进行中。
格什姆岛位于霍尔木兹海峡北侧，紧邻伊朗海岸。近期，多艘油轮在附近海域遭袭。
