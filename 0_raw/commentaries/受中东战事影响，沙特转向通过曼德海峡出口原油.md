# 受中东战事影响，沙特转向通过曼德海峡出口原油

产油大国沙特阿拉伯通过曼德海峡出口原油。
霍尔木兹海峡受战事影响航运受阻，产油大国沙特阿拉伯转而通过曼德海峡出口原油。专业机构提供的数据显示，沙特位于红海沿岸的延布港最近日均原油装运量已接近峰值。
英国西格纳尔大洋公司的数据显示，13日前后，沙特阿拉伯延布港原油装运量达到日均470万桶，较10日前后的336万桶增长近40%。6月以来，延布港日均装运原油量高于400万桶，而去年同期这一数字仅为日均97.3万桶。
伊朗战事爆发后，为了避开受阻的霍尔木兹海峡，沙特阿拉伯国家石油公司利用一条横贯东西的输油管道，把沙特东部波斯湾产油区生产的原油输送到延布港。这条管道日均输送能力峰值达700万桶，其中约500万桶用于出口。
然而，沙特与也门胡塞武装最近再次爆发严重冲突，威胁红海地区局势稳定。消息人士表示，能源领域人士担心延布港可能成为胡塞武装的打击目标。胡塞武装13日表示，如果紧张局势进一步升级，恐将导致曼德海峡关闭，全球能源供给将因此再次受到冲击。
据卡塔尔方面消息，途径曼德海峡的海上贸易占全球海上贸易的11%。
