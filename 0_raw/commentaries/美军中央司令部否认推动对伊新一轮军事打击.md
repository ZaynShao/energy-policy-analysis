# 美军中央司令部否认推动对伊新一轮军事打击

美军中央司令部发言人蒂姆·霍金斯否认军方高层正推动对伊朗发起新一轮军事打击。
据以色列《耶路撒冷邮报》当地时间8月14日报道，美军中央司令部发言人蒂姆·霍金斯否认军方高层正推动对伊朗发起新一轮军事打击。
霍金斯在接受《耶路撒冷邮报》采访时说，有关美军中央司令部司令布拉德·库珀推动对伊朗发动新一轮打击的报道“纯属捏造，根本不是事实”。
据以色列13频道电视台13日报道，库珀日前访问以色列时说，正推动对伊朗基础设施发动新一轮军事打击，以迫使伊方改变当前立场。美方很可能“别无选择”，必须重启对伊朗天然气、石油、电力等基础设施的打击，届时需要以色列配合进行联合打击。他称，这“将改变游戏规则”。
该报道还称，库珀甚至已经向美军参谋长联席会议主席丹·凯恩提出相关建议，美国总统特朗普也已知悉。
以色列公共广播公司8日报道说，库珀当天抵达以色列进行短期访问，并同以色列国防军高层讨论“多战线局势”。
