# 原料与特钢丨需求回暖 原料价格稳中趋强 结构钢市场迎利好

【导语**】**原材料价格震荡回升，得益于钢厂复产带动的需求回暖和补库需求支撑。结构钢市场需求温和复苏，供应稳中偏紧，社会库存连续两周下降，成交稳步增加。成本与利润方面，45#结构钢产品成本跌幅收窄，利润水平有所回升。4月结构钢市场有望延续供需改善逻辑，价格或呈震荡偏强走势。

**需求回暖原料价格稳中趋强**

2026年3月，特钢主要原料价格稳中趋强。铁矿石、焦炭及钢坯价格整体呈现震荡回升态势。铁矿石在钢厂复产带动下需求回暖，港口主流PB粉价格由月初约740元/吨反弹至月末815元/吨附近，涨幅超10%，主要受高炉开工率回升及补库需求支撑。焦炭方面，随着成本端炼焦煤企稳及钢厂日耗增加，主产区开启首轮提涨，涨幅50-55元/吨，但钢厂对提涨抵触情绪较高，暂未执行。钢坯受原料成本抬升与下游轧材订单好转推动，唐山地区价格从2915元/吨上行至2995元/吨左右，市场情绪由谨慎转为偏强。整体来看，成本价格随着终端逐步复产得以支撑，价格稳中趋强。

**供需维持紧平衡，利润稳中有涨**

2026年3月，结构钢呈现需求温和复苏、供应稳中偏紧的运行特征。月初受春节后终端复工节奏偏慢影响，成交略显清淡；但中下旬随着机械制造、轴类加工等下游行业订单逐步释放，市场交投活跃度明显提升，价格亦稳中有涨。供应端方面，部分优特钢企业因产线检修及品种结构调整，45#钢排产量环比微降，社会库存连续两周去化，支撑价格企稳反弹。卓创资讯数据监测，本月结构钢45#产品成本均值为3332.81元/吨，较上月跌幅0.34%，本月结构钢产品45#利润均值为245.84元/吨，较上月利润上涨8.25%。利润水平有所回升

**社会库存继续消化，成交稳中有增**

月初受春节假期余波及终端复工节奏偏缓影响，下游采购谨慎，市场交投清淡；进入中旬后，随着机械制造、汽车零部件及轴类加工等行业订单陆续释放，叠加部分贸易商低位补库，成交明显回暖，尤其华东、华南地区出货量环比显著提升。结构钢社会库存为99.2万吨，环比下滑1.2%。2月日均成交量约2.5万吨，环比上涨8.2%。其中杭州、无锡等主导市场库存去化尤为明显。钢厂端亦主动控产，部分优特钢企业调整排产结构，减少普材投放，进一步助力库存消化。

**4****月市场有望延续震荡偏强**

展望4月，结构钢市场有望延续供需改善逻辑，价格或延续震荡偏强。需求端，在制造业景气度回升及设备更新政策持续推进下，机械、汽车、通用零部件等下游行业订单保持韧性，终端采购节奏趋于稳定。供应方面，钢厂后续增量有限，预计供应趋稳；叠加前期社会库存已连续去化，市场资源结构趋于紧平衡。成本端，铁矿石、焦炭价格高位盘整，生产成本下移空间有限，对价格形成较强支撑。综合来看，卓创资讯预计4月主流市场报价或在3250–3320元/吨波动，需重点关注下游实际去库速度及宏观消息对市场情绪的影响。
