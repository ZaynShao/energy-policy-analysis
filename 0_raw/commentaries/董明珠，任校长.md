# 董明珠，任校长

格力电器董事长董明珠担任珠海市格力技工学校校长。
8月18日，“格力文化”微信公众号发布消息称，近日，经珠海市人力资源和社会保障局批准，由格力电器创办的珠海市格力技工学校正式获得招生资格，将于2026年秋季正式启动首届招生。格力电器董事长董明珠担任学校校长。
据介绍，学校坐落于珠海市香洲区香山路3200号，占地面积约19.1万平方米，建筑面积约12.4万平方米。
该校首批开设九大核心专业，涵盖制冷设备运用与维修、模具制造、智能装备运行与维护、机电一体化技术、电气自动化设备安装与维修、机电产品检测技术应用、物联网应用技术、多媒体制作、计算机应用与维修，全面对接智能制造、电气技术、信息技术等当下重点产业领域。
已发布的招生简章显示，本次首届招生名额共计300人，学费标准为9000元至15000元/年。招生面向全国15至18周岁的应届、往届初中毕业生。
师资方面，学校组建了由“格力电器资深工程师、高级技师+学校专业教师”构成的一体化教学团队，全面推广工学一体化培养模式。
值得注意的是，就业方面，该校构建起“入校即入企，毕业即适岗”的办学模式。学生入学即可对接企业资源，毕业后优先进入格力电器及产业链企业实习就业。
