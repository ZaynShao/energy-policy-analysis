# 全球人工智能伦理步入场景化治理新阶段

人民网研究院组织编写的智能互联网蓝皮书《中国智能互联网发展报告(2026)》7月29日在北京正式发布。其中，上海社会科学院新闻研究所互联网治理研究中心主任方师师、上海社会科学院新闻研究所互联网治理研究中心研究助理叶梓铭撰写的《2025年全球人工智能伦理的“场景化治理”：风险、实践与未来路径》一文指出，人工智能伦理治理已从原则倡议迈入制度落地阶段，应用场景成为衔接技术与伦理的关键维度。全球呈现先发国家调适、后发国家跟进的格局，但数智鸿沟与地缘政治分歧仍制约国际合作。
文章聚焦政治、教育、科技、文化、医疗五大核心应用场景，逐一拆解各领域AI落地过程中凸显的责任界定、公平秩序、隐私安全、价值守护等伦理难题。同时，研判了智能感知设备、物理智能体、脑机接口等新兴智能技术形态带来的隐私与个人信息治理、职业结构与社会价值观冲击、伦理与治理要素竞合等全新挑战。
文章强调，新兴人工智能应用的伦理风险呈现出风险位置前移、治理对象复杂化、价值冲突显性化等显著特征。面向人机共生未来的伦理治理，应进一步强化伦理原则，构建智能社会软性基础设施，同时，积极创新治理模式，落实混合智能应用伦理约束。
