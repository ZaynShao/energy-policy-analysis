# Gemini凉了！创始人布林杀回AI一线，谷歌人心惶惶

新智元报道
Gemini，可能彻底凉透了。
就在刚刚，AI算力圈「风向标」SemiAnalysis直接下达了死亡判决：Gemini is Cooked。
他们断言，谷歌重新夺回SOTA桂冠的概率，约等于零。
与此同时，大地震正在谷歌内部疯狂蔓延。
而在这一地鸡毛中，重新坐回驾驶舱的，是连一个正式头衔都没有的联合创始人Sergey Brin。
想当初，Gemini 3横空出世时，不仅全面碾压GPT-5.1和Claude Sonnet 4.5。甚至逼得Sam Altman直接拉响了「红色警报」。
9个月后，下一代旗舰3.5 Pro连内部编程测试都没跑通，水平顶多和Opus 4.5打个平手，直接被中国各大顶尖模型按在地上摩擦。
谷歌干脆手起刀落给砍了，连发布的勇气都没有。
而硬着头皮顶上来的替补3.6 Flash，同样没有逃过被xAI和Meta按着打的命运。
眼瞧着这条推文的影响越来越大，谷歌AI产品负责人Logan Kilpatrick坐不住了，火速在X上下场，坚称团队仍在创造奇迹。
SemiAnalysis当场硬刚回去：「Gemini的地位自去年11月起就在直线下坠，最近发生的一切，没有一件把信心救回来。」
Kilpatrick再也没能憋出一句反驳。
Transformer是谷歌发明的，AI聊天机器人也是谷歌先捏出来的。
可最后拿着这两样东西颠覆世界的，偏偏是别人。
如今在OpenAI掌管Codex的前DeepMind研究员Tibo亲口证实——
他们当年做的内部代号叫LMChat，基本上就是比ChatGPT早一年的ChatGPT。
但谷歌就是不敢发布，因为DeepMind被明令禁止推出任何可能颠覆自家业务的产品。
对此，SemiAnalysis的病理诊断就一句话：缺乏足够坚定的信念。
谷歌造得出来，只是从来不敢赌命。
时间拉回2024年8月，谷歌砸下27亿美元，硬是从Character.AI把Noam Shazeer挖了回来。
作为Transformer共同发明人、Gemini的联合操盘手，全公司上下都把他当成了救星。
2026年6月18日，Shazeer反手就宣布加盟OpenAI。不到两年，27亿打了水漂。
字面意义上的第二天，AlphaFold核心缔造者、2024年诺贝尔化学奖共同得主John Jumper，也宣布转投Anthropic。Hassabis强颜欢笑，把这次离别美化成「科技圈最体面的告别」。
随后是谷歌第30号员工，Jeff Dean。
入职27年的他在8月5日正式拂袖而去，联合创办了Discovery Loop。同时带走的，还有Sanjay Ghemawat、Quoc Le、Oriol Vinyals，和加起来80多年的谷歌技术底蕴。
Dean和Ghemawat都是Google Senior Fellow，谷歌L11，工程师职级的绝对天花板。公司36年历史上，只有他俩拿过。如今，却已经人去楼空。
至此，Gemini 3的四大联合负责人，Shazeer、Dean、Vinyals、Quoc Le，已经走了三个。
最荒诞的是Alphabet自己投钱入股了Discovery Loop，还成了它的云合作伙伴。核心班底另立山头，老东家拦不住，只能卑微地掏钱买个保险。
一位Transformer论文联合作者一针见血：「谷歌的官僚主义已经病入膏肓，在这地方根本干不成任何事。」
聚是DeepMind，散是满天星。
可惜这些星星，全落到了对手的天上。
更深的危机，埋在TPU的分配账本里。
DeepMind与Google Cloud正在争夺同一批芯片。前者需要TPU训练下一代Gemini，后者却要把TPU尽快变现，租给外部客户。
在这场内部博弈中，赚钱的一方已经踩住了油门。
据估算，从2026年第三季度到2027年第四季度，谷歌两成以上的TPU出货将直接输送给Anthropic。
而且，这还没有算上已经租出去的份额，以及未来承诺给Meta的算力。
也就是说，当Gemini还在为训练资源苦战时，谷歌正源源不断地把最精良的芯片送进对手的数据中心，孵化下一代Claude。
Google Cloud CEO Thomas Kurian的算盘打得很响：
谷歌是一家平台公司，TPU理应服务所有客户，哪怕买家是自己的头号竞争对手。
这套逻辑放在云生意里，的确是无懈可击；但砸到Gemini头上，却是「杀人诛心」。
DeepMind现在每多争取一块TPU，都得先证明把芯片留给自己能比卖给对手创造更大的回报。
最新财报已经把这场内耗摆到了台面上。
谷歌第一方模型API的调用量增速，从第一季度的60%直接腰斩到第二季度的38%。
Gemini仍在增长，但速度明显放缓。另一边，Google Cloud营收却以82%的同比增速狂飙。
一个危险的循环正在成型。
Gemini越是掉队，谷歌就越愿意把算力卖给外部客户；对手吃饱算力，反手造出更强的模型；Gemini继续下坠，Google Cloud继续数钱。
DeepMind的长期溃败，正在铸就Google Cloud的短期辉煌。
就是在这片废墟上，Sergey Brin杀回来了。
只见他手起刀落。
Kavukcuoglu从伦敦火速搬到Mountain View，办公桌直接靠在Brin隔壁，从底层模型到Gemini App的全部事务一手接管。
废掉的3.5 Pro直接扔进垃圾桶，大军直扑Gemini 4。
Brin重掌大权后的第一件事是搬了把椅子坐在工程师旁边死磕bug。
Hassabis满脑子AGI路径和诺贝尔级突破，Brin只想把延迟砍一半、把被抢走的客户夺回来。董事会毫不犹豫选了后者。
但诡异的是，Brin至今没有挂上任何正式的工牌。
Pichai在官方博客里洋洋洒洒写了上千字人事变动，全文也没有出现Brin的名字。
反攻的代价也在伦敦浮现。
DeepMind从诞生起就扎根在King's Cross，这里的人相信论文比KPI重要，开源比营收重要。
但现在安全和伦理团队，大概率要被移交给法务和公关部门。
Hassabis撑起的保护伞让伦敦的研究信念存活了十年。此时此刻，却已经荡然无存。
一位跳到竞争对手的前高管说，他的电话已经被前同事打爆，所有人都在找下家。
不过，谷歌手里还握着这个星球上最强大的流量机器。
Gemini App月活9.5亿，日活同比增长三倍，搜索AI Mode月活超过10亿。只要按下一个按钮，谷歌全家桶就能把Gemini送到几十亿人面前。
但这台分发机器只能决定覆盖面，裁决不了谁才是最强模型。
SemiAnalysis在那篇长文的结尾，把谷歌与当年的IBM和Intel放在了一起。
这些巨头都没有轰然倒塌。它们依然攥着大把钞票、资产和客户，只是在旧业务最赚钱的时候，放弃了通往下一个时代最艰难的道路。
谷歌当然也不会轻易死去。云业务会继续印钞，TPU会卖向全球。Alphabet依然可能是一头令人战栗的现金巨兽。
但这才是最令人毛骨悚然的结局。
也许未来某一天，人们回头会发现——
那个发明Transformer、收购DeepMind、手握全球最大流量入口的屠龙少年，最终变成了一个精明的算力商人。
它把最锋利的宝剑，亲手卖给了最终赢下AI战争的人。
如今，Gemini 4现在要击败的，或许根本不是GPT，也不是Claude。
它要对付的，是那个已经发现「不争第一，也能暴富」的谷歌自己。
如果Gemini 4再次跳票，或者只能依靠流量霸权苟住市场，Gemini 3的背影就可能成为这个AI帝国最后的高光。
