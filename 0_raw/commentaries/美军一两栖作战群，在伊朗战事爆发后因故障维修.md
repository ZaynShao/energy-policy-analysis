# 美军一两栖作战群，在伊朗战事爆发后因故障维修

美军“拳师”号两栖攻击舰因发动机故障，改道驶向“美英联合军事基地”迪戈加西亚基地维修。
▲美军“拳师”号两栖攻击舰（资料图）
美国方面当地时间7月9日消息，美军“拳师”号两栖攻击舰在伊朗战事爆发后因发动机故障不得不中断其既定的增援计划，改道驶向位于印度洋中部的“美英联合军事基地”迪戈加西亚基地维修。
“拳师”号两栖作战群3月中旬从美国加利福尼亚州圣迭戈出发，运载美军第11海军陆战队远征队前往中东地区。美国方面援引3名知情人士说法称，“拳师”号任务为增援美军对伊朗军事行动，但其冷却发动机的主循环泵在航行途中发生故障，“拳师”号不得不改道驶向迪戈加西亚岛的军事基地更换零部件并维修。
维修完成后，“拳师”号两栖作战群被调往马六甲海峡执行伊朗相关海上拦截任务，后重新部署至中东地区。
今年3月，美军“福特”号航母在对伊朗的军事行动期间也曾发生火灾，航母洗衣房起火，造成3名水兵受伤，另有200多名水兵因吸入浓烟接受治疗。据美国方面消息，“福特”号航母火灾持续超过30小时。
