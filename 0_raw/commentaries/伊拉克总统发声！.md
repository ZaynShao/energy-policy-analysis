# 伊拉克总统发声！

伊拉克总统阿米迪表示，已有部分装载伊拉克石油的船只获准通过霍尔木兹海峡。
当地时间8月22日，伊拉克总统阿米迪表示，伊拉克方面此前已与到访的伊朗伊斯兰议会议长卡利巴夫进行了沟通，并向伊朗方面转达了关于重新审视两伊关系的讯息。阿米迪还表示，已有部分装载伊拉克石油的船只获准通过霍尔木兹海峡。
阿米迪强调，伊拉克政府必须与民兵组织进行对话、实现互谅，通过符合伊拉克国家和民族利益的方案解决武器管控问题。他表示，伊朗方面没有要求伊拉克推迟国家武器管控进程。
