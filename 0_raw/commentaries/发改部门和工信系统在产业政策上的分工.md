# 发改部门和工信系统在产业政策上的分工

在地方产业政策落地过程中，围绕制造业、高新技术、绿色发展，发改部门和工信系统都发文、都受理申报，职能似乎交叉。
但实际上，二者在产业政策上的分工逻辑清晰：发展改革部门侧重宏观统筹、项目投资和布局准入；工信系统侧重行业管理、企业培育和技术改造。厘清这一差异，对企事业单位精准对接政策、提高申报效率至关重要。
一、工信与发改系统的职能定位
发改是综合经济管理部门，管规划、管项目、管资金盘子、管能耗指标。在产业政策上，发改系统主要回答“能不能干、符不符合布局、有没有政府投资”。
地方发改委通常内设工业发展处、高技术产业处、资源节约和环境保护处、服务业处等，主要抓手包括国民经济和社会发展五年规划、产业指导目录、企业投资项目核准和备案、政府投资项目审批、能耗双控、碳达峰碳中和、战略性新兴产业集群等。
工信系统是工业和信息化行业主管部门，管行业、管企业、管产品、管技术。在产业政策上，工信部门主要回答“行业往哪走、企业怎么培育、技术改造怎么支持”。
地方工信厅（局）通常内设原材料工业、装备工业、消费品工业、电子信息、软件服务业、中小企业、无线电管理等处室，主要抓手包括行业规划、行业规范条件、产能置换、专精特新培育、智能制造、绿色制造、工业互联网、中小企业服务等。
可见，发改部门管“宏观与项目”，工信系统管“行业与企业”。同一家制造业企业，新建项目要过发改的立项和能评关，日常升级改造和资质培育则更多对接工信。
二、具体政策工具差异
1.项目投资类政策发改部门主导
固定资产投资项目核准、备案一般在发改部门或集中行政审批局，但由发改统筹。中央预算内投资、省级预算内投资、地方政府专项债、重大产业项目、先进制造业和现代服务业发展专项、污染治理和节能减碳专项等，大多由发改部门组织申报。这类政策强调项目前期手续完备，支持方式以投资补助、贷款贴息为主。
工信部门也有项目类政策，但重心在技术改造和设备更新。例如技术改造专项资金、制造业高质量发展专项、产业基础再造和制造业高质量发展专项、工业强基工程等，通常由工信部门组织。
2.企业培育类政策工信系统主责
专精特新中小企业、专精特新“小巨人”、制造业单项冠军、创新型中小企业、中小企业公共服务示范平台、小微企业创业创新基地等，基本由工信系统负责。
发改部门也有企业创新平台类政策，如国家企业技术中心、国家工程研究中心、国家地方联合工程研究中心、产业创新中心、双创示范基地、产教融合型企业等。这些更偏向研发平台和创新能力建设，与工信部门的“企业梯度培育”形成互补。
3.试点示范类政策，两部门各有侧重
发改部门侧重战略性新兴产业集群、先进制造业和现代服务业融合发展试点、承接产业转移示范区、老工业城市和资源型城市产业转型升级示范区等。
工信部门侧重先进制造业集群、国家新型工业化产业示范基地、中小企业特色产业集群、消费品工业“三品”战略示范城市、产融合作试点城市等。
4.绿色低碳和数字经济政策各有侧重
节能审查、能耗双控、碳达峰碳中和、循环经济、大宗固废综合利用、零碳园区等，主要由发改部门牵头；绿色工厂、绿色园区、绿色供应链、零碳工厂、工业节能监察、落后产能退出、工业资源综合利用等，主要由工信部门负责。
数字经济方面，数字经济发展规划、全国一体化算力网络枢纽节点、新基建项目等偏发改；工业互联网创新发展工程、5G+工业互联网、两化融合贯标、智能制造示范工厂等由工信负责。
三、结束语
企事业单位GR应建立双线对接机制，战略规划、重大项目、能耗指标、政府资金申请，明确对接发改系统；行业政策、企业资质、技术改造、中小企业扶持，向工信系统申报。
当然，各地存在一定差异， 比如上海、深圳等地发改部门对总部经济和服务业支持突出；中西部地区发改部门对承接产业转移和园区基础设施支持力度大。GR应建立本地主管部门权责清单，不能照搬其他省份经验。
