# 【唱好杭甬“双城记”】平台互促 研产协同

“十四五”期间，杭甬两地以重大战略平台共建为纽带，推动创新要素跨城高效配置，在科创走廊协同、高新区联动、开放平台共建等方面形成一批标志性成果，构筑起双城协同发展的“四梁八柱”。
2025年8月，杭甬两地签订《杭州城西科创大走廊 宁波甬江科创区战略合作协议》。2026年2月，进一步联合制定《深化合作工作方案》，建立常态化月度会商机制，两地廊区负责人多次带队互访对接，推动廊区开展全方位、深层次、实质性合作：浙江大学与宁波东方理工大学签订战略合作协议，杭州师范大学、宁波大学联合发起成立杭甬“双城记”城市大学技术转移转化联盟；廊区多家单位联合组建浙江省人形机器人产业技术联盟和浙江省绿色石化技术创新中心。2026年以来，廊区已共同举办“科技创新及成果转移转化”专题培训等活动6场，联合培养国际技术转移职业经理人60余名。
今年以来，两地高新区积极互访考察，充分发挥各自特色优势，着力构建“杭州研发、宁波转化，杭州总部、宁波基地”的跨域协同格局。2026年5月，杭甬高新区签订战略合作框架协议，明确聚焦科技创新、产业升级、人才交流等方面开展深入合作：企业院所深度联合，共建省微结构特种光纤重点实验室；吉利、零跑等杭州整车企业与宁波均胜电子等零部件企业双向入链；宇树科技等整机龙头与宁波韵升新能源等企业深化伺服电机、减速器零部件配套合作；士兰微与宁波企业建立智能功率模块产业供应合作。通过常态化产学研对接与供应链精准匹配，两地高新区正打造双城科创产业“链式融合”、产业链上下游深度咬合的协同样板。
两地以自贸片区联动为抓手，协同建设大宗商品贸易枢纽。杭州发挥金融、数字经济和期现结合优势，宁波舟山港发挥储运、吞吐核心优势，两地初步建立协同联动机制：协同构建价格指数体系，完成大宗商品“杭州指数”核心框架搭建与方案编制；联动深化产业金融支撑，杭州创新“期货+保险+担保”专属产品，宁波上线离岸贸易数字化综合服务平台，离岸贸易印花税优惠政策带动与30个国家266个贸易伙伴的结算突破45亿美元。目前，两地协同构建起覆盖大宗商品全链条的金融服务体系，已累计服务全国超5000家实体企业，区域定价话语权和产业联动效能持续增强，平台化服务正成为双城开放协同的重要载体。
