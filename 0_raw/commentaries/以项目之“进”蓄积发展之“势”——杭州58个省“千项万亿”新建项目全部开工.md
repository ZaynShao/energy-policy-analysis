# 以项目之“进”蓄积发展之“势”——杭州58个省“千项万亿”新建项目全部开工

项目兴则产业兴，项目强则经济强。今年上半年，杭州以省“千项万亿”工程为总牵引，掀起项目建设提速提效热潮——紧扣年度新开工节点，58个省“千项万亿”新建项目全部完成前期审批并实现开工，总投资928.78亿元，为全市经济社会高质量发展注入强劲动能。
“从新开工项目领域来看，先进制造业基地、科技创新强基和民生设施三个领域最多，合计共有48个项目；先进制造业基地、数字经济（人工智能）和科技创新强基三个领域投资最大，占全部新建项目总投资的79.7%。”市发展改革委相关负责人介绍。
一批标志性项目率先突破、加快建设，正成为全市投资稳增长的坚实支撑。
作为省“千项万亿”工程项目，位于富阳区的杭州芯光半导体有限公司高端先进芯片全国测试基地项目是今年我市最大的新建项目，截至目前，该项目地下配套工程已全部完工，预计今年12月实现部分产线投产运营。弓叶科技AI具身智能总部项目是省“千项万亿”工程数字经济（人工智能）领域新建项目，建成后将成为弓叶科技全球研发生产总部；位于淳安县的浙江柒淼智能科技有限公司智能家居生产项目计划于7月底进行试生产。
这些标志性项目建设快马加鞭，生动勾勒出杭州重大项目建设的昂扬态势。目前，杭州共有两批269个项目纳入省“千项万亿”项目，总投资7371.9亿元、年度计划投资948.1亿元。
聚焦重点支持新质生产力高质量发展，杭州优先支持重点产业与新质生产力项目，全力支撑“415X”先进制造业集群发展。作为该领域落地的标志性工程，位于萧山区的中国视谷芯机终端制造基地项目已于今年一季度顺利开工，未来将加速赋能区域产业向新跃升；奥展实业年产10万吨精密零部件智能工厂项目也在加紧建设中，聚力打造集研发、生产、销售、服务于一体的智能化工厂。
要素保障精准有力，为项目快速推进提供了坚实支撑。杭州积极探索土地、资金等关键要素向优质项目倾斜。西湖区云栖未来产业智造基地项目就成为全市首例低效工业用地“并宗再开发”试点。
此外，杭州还以数字化改革驱动项目管理模式变革，推动项目进度可视、节点可控、风险可预警。余杭区创新搭建了前期、储备、计划、在建、全生命周期管理五大项目库，聚焦可研审批、征迁净地、考古意见、施工许可等9个关键节点，通过数字化平台实行清单化、节点化、时限化闭环管理。
