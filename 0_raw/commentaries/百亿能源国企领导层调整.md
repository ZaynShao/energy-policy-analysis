# 百亿能源国企领导层调整

孙方辞去淮北矿业控股股份有限公司（下称“淮北矿业”）董事长等职务，周二元任公司总经理。
7月11日，淮北矿业发布公告称，公司于近日收到孙方先生的书面辞职报告，申请辞去公司董事，董事长，董事会战略委员会、提名委员会主任委员职务；同时周二元先生因工作调整，申请辞去公司副总经理职务。
此外，经公司董事会提名委员会资格审查同意，第十届董事会第十二次会议审议通过，同意聘任周二元先生为公司总经理。
公司官网信息显示，淮北矿业于2018年8月完成重大资产重组，主营业务为煤炭采掘、洗选加工、销售，煤化工产品的生产销售等业务，是华东地区煤种较为齐全和重要炼焦精煤生产企业。公司现拥有煤炭生产矿井16对，动力煤选煤厂5座，炼焦煤选煤厂4座。
据《淮北矿业控股股份有限公司2025年年度报告》信息显示，截至2025年末，公司资产总额890.30亿元，2025年度营业收入411.25亿元。
