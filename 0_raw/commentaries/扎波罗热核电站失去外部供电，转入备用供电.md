# 扎波罗热核电站失去外部供电，转入备用供电

扎波罗热核电站辅助设备供电的330千伏“铁合金-1”高压输电线路因线路受损，被保护自动装置切断。失去外部供电后，核电站机组按规定切换至备用柴油发电机供电。
8月20日，扎波罗热核电站官方通报，为该核电站辅助设备供电的330千伏“铁合金-1”高压输电线路因线路受损，被保护自动装置切断。失去外部供电后，核电站机组按规定切换至备用柴油发电机供电。设备运行正常，安全系统未发生故障。
通报称，核电站人员密切监控设备运行参数，为维持机组安全状态所必需的全部措施均已全面实施。核电站厂区及观测区内的辐射背景值处于天然本底水平，未超过规定标准。目前情况处于该核电站专家的持续监控之下。
扎波罗热核电站原有10条外部输电线路，目前仅剩一条330千伏线路维持外部供电，已发生多次外部供电中断事件。在机组冷停堆状态下，仍需外部电力维持反应堆冷却系统和安全设备运转，外部供电中断后须立即启动柴油发电机保障供电安全。
