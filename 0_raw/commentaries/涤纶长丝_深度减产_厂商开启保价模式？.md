# 涤纶长丝 | 深度减产 厂商开启保价模式？

**导语**

上周五涤纶长丝行业再现减产消息，龙头生产企业计划将减产力度扩增至30%，减产周期延续至二季度末，以应对市场下行格局。然上下游市场乏善可陈，且目前涤纶长丝加工费尚可，部分厂商“落袋为安”心态引导下，库存积极变现，市场难掩下行态势。

二季度以来涤纶长丝厂商产销承压，不断扩大减产力度，截至上一交易日涤纶长丝行业平均产能利用率83.96%，环比下降4%。周五晚间，龙头生产企业发布减产消息，鉴于二季度上游PX、乙二醇供应短缺局面，为维护产业链健康发展，增强下游信心，主流长丝工厂决定继续执行减产保价，将减产比例由20%提升至30%，减产时间持续至二季度末。

据隆众统计，周末安徽地区一套30万吨的涤纶长丝装置停车检修，截止发稿涤纶长丝产能利用率进一步下降至82.8%，后期龙头企业减产逐步落实，而前期减、停装置暂无明确重启消息，因此中长期来看涤纶长丝产能利用率或呈现持续下行的状态。若减产落实到位，预计涤纶长丝产能利用率或维持在7成附近。

然而不可忽视是，自4月份以来涤纶长丝库存持续增长，行业平均库存30余天，DTY个别企业库存40余天，龙头企业带头减产实则为企业的自发性去库、保价。近期下游纺织行业开工趋于平稳，尤其喷水订单尚可，开机率远高于其他机型，织造厂商消化库存为主，成品库存呈现下滑趋势，而目前地缘局势带来的市场影响较前期有所缓解，海外订单小量下达，使得织造订单量小幅回升。终端纺织行业表现尽管不如预期，但相较于3月而言，已有明显改善。反观涤纶长丝行业，高库存、低需求的困境难解，成本端宽幅波动，加重市场观望情绪，涤纶长丝市场多空博弈的局面延续，市场能否保价未可知。

周末至今涤纶长丝部分厂商率先让利出货，局部产销回暖，而目前涤纶长丝POY、FDY加工费在1500-1700元/吨，属于聚酯品种中加工费较高的品种，因此不乏部分厂商让利出货。龙头生产企业挺市意愿犹存，扩大减产规模后，优惠力度有限，因此市场商谈趋于平稳，其余厂商库存变现为主，市场商谈仍有下探的预期，若无其他突发性因素影响，预计五一节前涤纶长丝市场仍有下调空间。
