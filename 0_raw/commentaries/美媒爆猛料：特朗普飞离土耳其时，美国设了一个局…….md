# 美媒爆猛料：特朗普飞离土耳其时，美国设了一个局……

美媒：特朗普7月8日在北约峰会闭幕后乘坐一架旧的“空军一号”离开土耳其，目的是为了掩盖特朗普的行踪，保护其安全。
《华盛顿邮报》8月11日报道，白宫称美国总统特朗普7月8日在北约峰会闭幕后乘坐一架旧的“空军一号”离开土耳其，然而这其实是一个精心设计的局，目的是为了掩盖特朗普的行踪，保护其安全。
▲视频截图
7月上旬前往土耳其参加北约峰会时，特朗普乘坐的是卡塔尔此前赠送的波音747-8飞机。而在他离开前，特朗普在社交媒体上宣布将使用旧的“空军一号”飞机。7月8日，特朗普在摄像机前登上了旧“空军一号”。不过，《华盛顿邮报》称，该媒体通过查阅资料以及采访一位美国匿名知情官员发现，在登上旧“空军一号”几分钟后，特朗普通过一辆机场配餐车秘密转移到一架较小的空军C-32A飞机上，后者载他飞往英国，而媒体和一些官员当时被引导相信特朗普仍在旧“空军一号”上。
《华盛顿邮报》报道中的视频显示，7月8日，特朗普走上舷梯进入旧“空军一号”几分钟后，一辆配餐车从该机降下。随后可以看到配餐车在远处向较小的C-32A飞机移动。《华盛顿邮报》称，载有特朗普的C-32A于当地时间7月8日晚10时20分左右抵达英国，而旧“空军一号”和媒体人员则晚几分钟到达。有视频拍到特朗普从旧“空军一号”走下舷梯。《华盛顿邮报》称，目前尚不清楚他是如何转回旧“空军一号”的。
《华盛顿邮报》向白宫提供了其报道中的详细信息以及一系列提问。作为回应，白宫通讯主任发表声明，为卡塔尔赠送的那架飞机辩护。声明称：“新的‘空军一号’是一架最先进的飞机，配备了高级安全协议，可确保总统及其工作人员的安全。正如总统最近所说，美国有许多敌人正盯着他，我们利用一切可用手段来应对这些威胁。”五角大楼发言人将相关问题转给了白宫。美国特勤局发言人也未回应置评请求。
报道称，类似行动曾在2000年发生过，当时美国总统克林顿乘坐一架无标志的行政专机进入巴基斯坦，同时将其正式的“空军一号”作为诱饵。在此次行动中，那些以为自己正与特朗普同乘旧“空军一号”的记者们报道称，他们被建议将媒体舱的舷窗遮光板保持关闭。《华盛顿邮报》称，除了记者外，一些白宫工作人员也以为总统在机上。
