# 聚焦392Ah电芯！新巨能与中创新航达成10GWh战略合作

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/nJIHJiauQqnz6VBj0uTricSqbFeTjYA87gs8c7tpsicGRfrlUcwWwHsxaJoevJOHwvOvRbTfcB01miciaXxavYHG1GjdMuvhAUPg8G4MjUP2yOAw/640?wx_fmt=jpeg&from=appmsg)  

近日，广东新巨能能源科技有限公司（简称“新巨能”）与中创新航科技集团股份有限公司（简称“中创新航”）正式签署《合作协议》。双方约定，在2026年1月1日至2027年12月31日期间，新巨能将向中创新航采购392Ah电芯及直流侧设备，累计不低于10GWh。这一大规模长期采购协议的达成，标志着新巨能在供应链稳定性与成本控制方面获得关键支撑，为公司储能业务的规模化、高质量发展奠定了坚实基础。  
![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/nJIHJiauQqnw5MqmUSoPoYZG9qk8XId3uJTojEBwN4cCnREP67E4r86hAYHH5GdSYuT16UZNXiafqvrwFV1sa8VGKq3bC0bbjfCm2FvvhibGKs/640?wx_fmt=jpeg&from=appmsg)  

新巨能副总经理姚远、中创新航储能事业部总经理朱肃然携双方核心团队负责人出席了签约仪式，共同见证了这一重要时刻。

  

作为国内领先的一站式数智化储能投资运营商，新巨能一直致力于推动储能应用的商业化落地与规模化发展。中创新航作为全球领先的锂电企业，凭借其在电芯技术、智能制造和系统集成方面的深厚积累，已成为新能源领域的重要力量。

  

**双方此次合作，不仅是采购关系的深化，更是优势资源的战略整合，充分体现了产业链上下游协同发展的趋势。**双方将重点围绕工商业储能、独立储能项目，共同探索商业模式创新，推动供应链资源的高效配置，实现互利共赢。

  

看个广告休息一下![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ibQ6Q066YicvUrISt2HTHibzQLHagVXTI0icHuu8j9l7VicIMYkGQ4a0sZubzCiaYLVbnQtvbYmZqkYcicIBJRaHbpdXQ/640?wx_fmt=jpeg&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=1)

  

新巨能表示，此次与中创新航达成10GWh级别的战略采购协议，是新巨能在产业链布局上的重要一步。在此次合作中，双方确定选择392Ah电芯路径，是基于技术成熟度、供应链稳定性和系统经济性的综合考量。目前新巨能在西北电网、山西等区域的独立储能立项已超12GWh，同时正快速拓展台区储能等配网侧应用场景，面对储能行业快速发展的窗口期，稳定的电芯供应和优质的直流侧组件将成为项目落地和系统性能保障的关键。

  

中创新航方面也表示，作为储能系统的核心部件，电芯的性能、安全与可靠性是一套系统乃至项目的根基，聚焦整体系统的优化配置和性能提升，**392Ah电芯沿用双方已成熟的电化学体系，与现有产线高度适配，可实现快速规模化量产，同时具备更高的能量密度、统一标准的规格尺寸，可在****保障高安全性的前提下显著提升系统集成度。**中创新航作为电芯及系统解决方案提供商，将继续依托自身在材料、电芯、系统集成等方面的技术优势，与新巨能携手打造高质量、高安全、高经济性的储能项目，助力构建清洁低碳、安全高效的新型电力系统。

  

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/nJIHJiauQqnwf1BeSJ517QO3JXNic56FJc8fgBqUWsZ0hAsqmuWQPx2wcR62kia9m9FGWb4AicgM6aGjDImIX92UicpmBOqiaEviaXNvAJITI5DoSM/640?wx_fmt=jpeg&from=appmsg)

  

展望未来，新巨能与中创新航将以此次合作为新起点，聚焦行业关键挑战，深化协同创新机制，携手推动储能产业的技术进步与生态升级，为我国能源结构的优化和新型电力系统建设贡献力量。
