# 地方绿金 | 青海省发布首批自然相关信息披露（TNFD）报告

近日，在中国人民银行青海省分行指导下，邮储银行青海省分行和果洛农村商业银行发布全省首批自然相关信息披露（TNFD）报告，填补了全省金融机构自然相关信息披露空白，标志着青海省在引导金融机构开展生物多样性信息披露方面迈出关键一步。
自然相关信息披露是全球金融领域应对生物多样性丧失、防范自然相关风险的重要举措，TNFD框架作为国际主流标准，为金融机构系统识别、评估、管理自然相关风险与机遇提供方法路径。在TNFD试点中，中国人民银行青海省分行重点抓好四方面工作。一是筛选确定首批试点机构。综合考虑网点覆盖面、经验可复制性等因素，选取邮储银行青海省分行和果洛农村商业银行作为首批试点金融机构，前者网点覆盖广，碳核算基础较好，后者地处三江源核心地区，金融业务与生态环境高度相关，可为高海拔民族地区金融机构应用TNFD框架提供典型样本。二是加强能力培训。先后四次组织试点机构参加人民银行总行、联合国开发计划署、山东省金融学会和安徽省金融学会举办的TNFD专题培训，系统学习TNFD框架和风险识别工具，为报告编制奠定基础。三是强化编制指导。引导试点机构按照LEAP（定位、评价、评估、准备）方法论，运用低成本在线数字工具，开展基于项目地理信息的生态保护红线、水资源压力等精细化空间评估，从治理、战略、风险管理、指标目标四个维度系统评估重点投融资行业与自然的交互关系，明确设定短中期自然风险管理及转型目标，详细披露信贷风险管控措施。四是融入区域生态文明建设战略。结合区域生态特点，对畜牧业、盐湖资源开发、清洁能源等高度依赖生态系统服务的重点行业开展生态敏感性评估，主动识别和披露自然相关转型机遇，推动经营决策从追求“财务收益”向兼顾“自然正收益”转变，引导金融资源更多流向自然受益领域，助力筑牢青藏高原生态安全屏障。
首批TNFD报告的发布，是青海省金融机构主动对标国际前沿标准、积极探索金融服务生态文明建设的重要实践，为全省其他金融机构开展自然相关信息披露提供了经验参考，也为生物多样性保护提供了坚实的资金支撑。截至2026年5月末，全省生物多样性相关贷款余额超172.19亿元。
