# 聚焦 | 杭州加速建设“人工智能创新发展第一城”

近日，中国新闻报整版刊发专题报道
《杭州加速建设“人工智能创新发展第一城”》
点赞杭州一流创新生态，一起来看看！
近期，一场特殊的开学典礼在杭州举行。30台来自不同厂家的机器人、机器狗整齐列队，成为杭州机器人学校的首批“新生”。该校面向机器人本体开展“职业技能”培养与认证，让它们从“裸机”“样机”真正成为各行各业的“智能技工”。
人工智能不只是一个产业，更是一个时代。国内首座机器人学校的落成，折射的正是杭州在人工智能时代的发展姿态。
在全球人工智能（AI）浪潮快速演进的背景下，杭州于2025年12月提出建设“人工智能创新发展第一城”目标，传递出以人工智能核心变量催生高质量发展最大增量的城市态度。半年多来，从写好人工智能产业叙事，到优化“四个最”的创新生态，再到推动人工智能与社会发展互相赋能，杭州在人工智能赛道上逐渐跑出加速度，在加快建设更高水平创新活力之城方面系统性发力。
回顾上半年的中国外交，杭州成为北京之外“出镜率”最高的城市之一。对多国领导人而言，杭州的最大吸引力在于机器人。
1
不论是德国总理默茨、缅甸总统敏昂莱参观的宇树科技，还是老挝人民革命党中央总书记、国家主席通伦访问的云深处科技，无不是中国具身智能机器人产业中的佼佼者。
这些企业吸睛全球，是杭州持续以人工智能塑造经济发展新优势的体现。
如何让人工智能核心变量催生出高质量发展最大增量？去年，杭州将构建“296X”先进制造业集群列为经济发展顶层框架。其中的“2”即打造人工智能、视觉智能2个万亿级世界级产业集群，“9”所代表的要提升的千亿级产业集群中，则包含具身智能机器人及其他智能终端、集成电路等产业。
在具体打法上，杭州也划定了清晰路径。例如聚焦具身智能机器人产业，杭州出台“强链补链”行动方案，从实施创新链强化提升、产业链集群培育、创新创业生态圈建设等三大工程入手，抢占新质生产力制高点。
去年，杭州的人工智能核心产业营收规模达4600亿元，同比增长23.1%。今年1至5月，这一数字为2116亿元人民币，同比增长23.4%，势头可谓强劲。
在杭州，人工智能的引擎作用也体现在深度赋能实体经济中。
位于杭州萧山的浙江恒远化纤集团有限公司，通过纺织化纤人工智能机器人全流程上丝项目，车间实现丝锭搬运全流程无人化作业。企业相关负责人介绍，该项目采用3D视觉识别系统，识别率达98%以上，能在45秒内完成上丝操作，行走速度超过0.3米/秒。项目可使产线连续运行能力提升30%。
通过从政策、资金等维度鼓励传统制造业企业进行智能化升级，杭州的制造业“硬度”持续提升。截至3月底，当地有12家企业入选工业和信息化部卓越级智能工厂。上半年，杭州规模以上工业增加值2370亿元，同比增长6.5%，其中高技术制造业增加值增长12.8%。
瞄准“AI+制造”，杭州今年还提出，在年内培育50家以上“AI工厂”。以此为代表的一系列加力，正为杭州经济增长带来更多可期待空间。
2
近期在杭州举办的首届“AI+OPC”创新发展大会上，《杭州市打造全国“AI+OPC”创业新高地行动计划（2026—2028年）》及政策措施对外发布，明确将实施社区引领工程、要素融通工程、人才舒心工程、金融护航工程、服务助跑工程等。
例如在要素融通工程中，该市将为OPC（一人公司）提供低成本算力、模型等服务，探索设立“AI产品体验券”；对采购智能算力和模型服务的OPC，每年申领算力券金额最高1000万元，大幅降低创业成本。
打造“人工智能创新发展第一城”，杭州将建设一流创新生态作为重中之重。对OPC的呵护正是杭州朝“四个最”发力的缩影。
杭州一直把创新生态建设放在突出位置，按照人才成长“最佳沃土”、企业发展“最好摇篮”、融合协同“最高质效”、政策服务“最为有感”要求，创新优化人才政策，做优金融服务，做强产业基金，强化“政研学、校企地”协同融通，完善企业有感的政策体系，促进人工智能生态不断完善、更加繁荣。
今年，杭州围绕完善创新生态密集出招。在深化制度创新方面，出台实施全国首部聚焦具身智能机器人的地方性法规——《杭州市促进具身智能机器人产业发展条例》，为产业发展筑牢法治根基。
此外，杭州正制定人工智能产业发展的促进条例，持续升级人工智能的政策体系；探索Token创新基地和结算枢纽建设运营机制，抢占“Token经济”新赛道。
▌5月16日，国家人工智能应用中试基地（具身智能）在高新区（滨江）正式揭牌
在平台支撑方面，杭州目前已落地4个国家级人工智能应用中试基地。以二季度揭牌的国家人工智能应用中试基地（具身智能）为例，其通过搭建公共技术服务平台，助力市场主体获取低成本、低门槛、快迭代的各类国产创新资源，推动具身智能从概念走向成熟解决方案。
基地相关负责人说，基地要做“串珠子的人”，把算力、数据、模型、场景等关键要素串成完整产业链，让企业“进场即入链”。
此外，基金力量也是杭州组合拳的重要组成。在不断加大“3+N”基金集群、润苗基金、人才基金等产业基金对人工智能领域投资力度的基础上，今年当地新成立人工智能创业投资基金、杭数人工智能壹号产业投资基金等，让耐心资本持续赋能硬科技。
3
在中国谈及人工智能，杭州是绕不开的城市。其中原因在于产业活力、创新生态，也在于人工智能与城市“双向奔赴”所涵养的城市气质。
场景是人工智能技术从研发走向产业落地的核心载体。杭州实施“AI+”场景开放示范工程，面向政府和市场开展人工智能场景需求清单征集，促进技术供给与需求端的联动。当地提出力争每年培育和开放200个以上高质量场景资源，促成50项以上场景合作项目。
这种让城市成为“最佳试验田”的魄力，推动杭州的社会发展不断呈现新气象。
比如在“人工智能+政务”领域，杭州市余杭区市场监管局打造的AI选址工具“余小帮”，就成为浙江深化“放管服”改革的亮点举措。
商户通过该工具输入目标位置、预计租金、店铺面积等关键数据，很快就能收到包含租金建议、客流热力图和消费画像等内容的个性化选址报告，获得实用的参考意见。余杭区市场监管局相关负责人介绍，“余小帮”上线以来已经吸引超过8万人次使用。
此外，在人工智能为城市发展拓展广度的同时，杭州也从人工智能通识教育改革入手，为人工智能发展积蓄长远人才动能。
去年，杭州制定推出《杭州市中小学人工智能教育地方课程纲要（试行）》和《杭州市中小学教师人工智能素养框架（试行）》，并在中小学各学段实现人工智能通识课程全覆盖，每学年不少于10课时。
前不久，杭州还成立人工智能通识教育联盟，以“提高素养，促进就业，赋能产业”为核心任务，聚焦人工智能通识课程体系开发，师资素养提升与教学资源共享，打造集标准研制、教学实践、资源共建、创新孵化于一体的新型教育和产业协作平台。
这样的“双向奔赴”，本质上是技术演进与城市治理、产业发展及民生需求之间的深度耦合与价值共生，考验的是各地的开放发展理念、改革创新能力以及以人为本的治理智慧。这一条路上，杭州正走出具有自身特色的发展范式，也为实现“第一城”目标，增添了又一重底气。
