# 华为｜从“竹知了”事件看企业GR/PR职业发展

华为法务部门的傲慢和自大非今日方知，起码我这种不足十万粉丝的小IP都被投诉删文多次。
强大的HW终于也有扛不过民意的时候，最近以“损害企业商誉”为由发起投诉“竹知了”相关视频，却演变成了一场全民狂欢式的舆情反噬。
对于每一位从事GR（政府关系）和PR（公共关系）工作的从业者而言，“竹知了”事件不只是一则新闻，更是一面镜子。它照出了当下企业品牌传播、舆情管理、政策应对工作中正在发生的深层变革。
二、GR/PR工作正在失去路径依赖
传统做法是规则和强权，但在新的传播技术发展、网络社会形态、经济政治转型之下呈现结构性变化。
1.政策环境趋严，维权通道拓宽，但“泛侵权化”风险加剧
中国网信办近年来持续开展“清朗·优化营商网络环境”专项行动，官方优化营商环境的决心明确。这意味着企业依法维权的通道更加畅通，华为的投诉能够被平台受理和下架，本身就是政策红利的体现。
但华为维权在实操上有“投诉扩大化”之嫌。
当一些“与事实没有直接相关的投诉也能通过”，企业容易陷入“泛侵权化”的陷阱，反而引发更大的舆情反弹。
我们应该认识到，政策工具是双刃剑，用得过宽过猛，合法合规的操作也可能演变为舆论灾难。
2.公众表达方式多元化，“玩梗”成为新的舆论形态
“竹知了”事件中，不少网友通过发布视频等形式参与讨论，并非否定企业技术实力，而是围绕企业某些传播符号展开的民间表达。
这种表达更多是在探讨商业维权与网络玩梗的边界。
当“玩梗”从亚文化走向主流，它就不再是企业可以简单用“侵权”来定义和封堵的对象。公众对头部企业有着更高的审视标准，这种审视本身就是一种软性的舆论反馈。
3.品牌与公众的关系从“单向传播”走向“双向博弈”
过去，企业可以通过发布会、广告、公关稿来定义自己的品牌形象。但在社交媒体时代，品牌形象是企业和公众共同“协商”出来的。
当华为这些年吃着爱国流量红利时，它就不再只是企业内部的商业元素，也是社会文化的一部分。企业可以说爱国，公众并不一定要买账，而是要观其言行，双向博弈决定品牌的社会认知。
三、结束语
“竹知了”事件给所有GR/PR从业者上了深刻的一课。
在政策环境持续优化、社会表达日趋多元、公众审视标准不断提高的今天，传统的“发声明、删帖子、走法律”三板斧已经远远不够。
新的GR/PR范式，要求从业者同时具备政策敏感度、舆情感知力、沟通共情力和品牌叙事力。它要求我们在依法维权的同时保持对公众情绪的敬畏，在坚守底线的同时展现品牌的温度与格局。
水能载舟，亦能覆舟；公众可以捧华为，也可以抛弃华为。
如果这篇文章未被投诉删掉，估计华为认识到了问题并在积极矫正；反之亦然。
