# 洪水+山火，美国正经历“水火两重天”

美国肯塔基州因强降雨引发洪灾，该州已进入紧急状态。同一天，当前规模最大的山火正在犹他州持续肆虐
当地时间6月27日，美国肯塔基州因强降雨引发的洪灾已造成4人死亡。肯塔基州州长安迪•贝希尔当天宣布该州进入紧急状态。
据美国国家气象局发布的天气预报，肯塔基州大部分地区的强降雨将持续至当地时间27日23时，部分地区的降雨量将高达7英寸（近180毫米），部分区域短时间内降雨量远超往年同期水平。美国国家气象局针对肯塔基州和印第安纳州部分地区发布了山洪暴发预警。
同一天，当前规模最大的山火正在犹他州持续肆虐。
气象与林业数据显示，犹他州刚经历有记录以来积雪最少、冬季最暖的极端气候，地表植被极度干燥。而本轮高危天气具有超低湿度、持续高温、阵风频发的典型特征，是山火快速蔓延的核心诱因。受严峻火情影响，犹他州已宣布进入紧急状态，并出台烟花燃放管控措施。
游客 金•詹森：“看到这边的美景都被烧毁了，真是可惜。门罗那边很多地方都烧没了，不过山上仍然有很多风景优美的地方，只是去的时候要小心。”
目前，全美12个州出现火情，至少有37处火情持续燃烧，多地同步发布火灾高危“红旗警告”，全域防火形势严峻。今年以来，全美山火过火面积已接近300万英亩（约12000平方公里），远超近十年同期平均水平。
近年来，美国多地极端天气现象频发，包括洪水、龙卷风、暴风雪、高温热浪等多种灾害，引发广泛关注和担忧。
