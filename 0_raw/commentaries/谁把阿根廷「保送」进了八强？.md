# 谁把阿根廷「保送」进了八强？

阿根廷队与埃及队比赛，
VAR判罚起争议。
北京时间7月8日，2026美加墨世界杯1/8决赛，阿根廷在2球落后的情况下连入3球，最终将比分定格3-2，完成大逆转，晋级八强。
赛后，埃及前锋莫斯塔法·齐科在采访中哭泣，“不公平！太不公平了！那个裁判极其不公平！”，这与他在比赛中的一次进球得分，被VAR（Video Assistant Referee，视频助理裁判）系统检视后遭取消有关。
在本届世界杯，VAR系统改写了许多场赛事的走向，如7月4日法国对巴拉圭的比赛，VAR干预和处罚了法国；在7月3日葡萄牙对阵克罗地亚时，VAR显示克罗地亚进球因越位而无效。而被VAR审查改写走势的比赛，往往也会成为当天最具“争议”的话题。
一项出于保证比赛公平采用的VAR系统，它的技术原理是什么，为什么在应用过程中又会引发争议，它会如何保证足球“公平的判罚”？
还有一个终极问题：技术在大型体育赛事的应用，是让比赛更好看了，还是让赛事失去了“感性”的乐趣？
无形的助理裁判
足球作为世界第一运动，很大的魅力源于“不可预测”，但与此同时误判、漏判等引发的争议事件，也长期伴随着足球赛事的发展。
为了保证公平性、减少争议，在2016年世界俱乐部杯上，VAR系统首次试用，自2018年俄罗斯世界杯起，VAR系统开始在世界杯赛事中正式使用，被媒体誉为“世界足坛的技术革命”。
VAR系统核心采用多机位高清视频回放技术，通过球场上多达30余台高清摄像机提供比赛画面，再通过专用工作站支持慢动作、逐帧播放及多角度同步，由VAR团队复核争议画面。
在2022年卡塔尔世界杯引入的进阶版本SAOT（半自动越位识别）中，包含球内传感器、光学追踪摄像头以及AI数据处理建模，以提升越位判罚精度。
VAR团队人数依据赛场摄像头数量确定。一般而言，视频裁判团队包括1名视频助理裁判（VAR）和3名视频助理裁判（AVAR）。此外还需要多名回放专员（RO）为视频裁判团队提供协助，从现场拍摄到的各种角度中筛选出有用信息。
2022世界杯上的VAR团队，图源：FIFA官网
为了确保裁判之间没有“暗箱操作”，视频回放室内还会安排一名国际足联官员，负责监督所有视频回放及裁判之间的沟通。
传统VAR的介入范围限于以下四类情形：
包括进球、点球、红牌和错认身份，核心在于复核关键判罚中的事实性错误或严重遗漏，例如是否存在犯规、手球、越位或对象识别错误等问题。
2026年世界杯新增了两类情形：
角球方面，若判罚存在明显错误，且该纠正能够在不延误比赛恢复的前提下即时完成，VAR即可介入。
第二张黄牌方面，由于同一场比赛中累积两张黄牌即导致球员被自动罚下，其所在球队在剩余时间内将少一人作战，影响重大。因此VAR现可对该类判罚进行复核，确保第二张黄牌的出示恰当无误。
图源：FIFA官网
在具体执行层面，部分事实性判罚已可实现自动化处理。例如，越位认定与球是否整体越过门线等情形，可通过内置于足球中的传感器及配套定位技术实时获取球的位置数据，从而作出客观判断。
2026年世界杯更进一步，利用AI技术，每位球员都拥有基于自身真实体型的“AI虚拟形象”，用于越位判罚。
该技术建立在半自动越位技术（SAOT）基础之上，国际足联此次引入个性化3D虚拟形象，即便球员快速移动或被遮挡，系统仍能可靠追踪。
用于世界杯的国际足联AI VAR虚拟形象。图源：卫报
然而，对于点球判定、犯规性质认定等涉及主观裁量的情形，仍须依赖VAR团队通过视频回放进行人工审查。
VAR的运作遵循既定程序，主裁判作出初始判罚后，VAR团队即自动启动对该判罚的复核。
若复核中发现可能存在重大误判或遗漏事件，VAR可主动发起审查，并通过耳麦提示主裁判。此时，主裁判须以双手画框的手势示意启动视频审查，随后前往场边监视器观看回放影像，在此基础上作出最终裁决。
目前，该审查过程不设时间上限。
VAR的“黑箱”
据公开数据显示，从2018年至今，VAR系统已在世界杯、各大洲联赛及杯赛中应用数千场。
作为一种技术手段，VAR系统对于裁判来说是辅助裁决的工具，但对于观众、球员来说仍是一个“黑箱”。
7月8日，阿根廷与埃及赛后，一段比赛影片在网络流传，阿根廷球员在防守埃及前锋时疑似有拉人、推挤及肢体接触，但主裁判未判犯规，也未通过视频助理裁判介入。
因此部分球迷表达不满：为什么某个动作回看？另一个却不回看？同样的身体接触，为什么有的被认定犯规，有的却被放过？
VAR系统示意图，涵盖赛场音视频采集、VAR后台研判、场边回放终端等。来源：网络
埃及主帅胡萨姆·哈桑在赛后接受采访时愤怒表示：不如直接把冠军判给阿根廷算了！当值的法国主裁和VAR搞“双重标准”。
“且在恩佐打入致胜进球前的瞬间，裁判未对麦卡利斯特的疑似犯规动作进行核查。”对于VAR没有提醒裁判回看麦卡利斯特那次“疑似犯规”，让主帅哈桑感到更加不满。
在第59分钟，埃及前锋齐科进球，将比分改写为2-0。随后此球被VAR介入，追溯埃及队断球时存在对利桑德罗·马丁内斯的犯规，因此此球被判无效。
VAR系统可以追溯那么远吗？前英格兰门将格林也震惊道：“这可是一整个球场的长度，肯定不该在VAR的回看权限范围之内。”
曾执法2022年世界杯的前墨西哥裁判费尔南多•格雷罗直言VAR介入有误。他认为阿根廷球员并没有遭到犯规，且即便VAR认为那是犯规，也不能作为“进攻控球阶段”的一部分进行回看。
但也有媒体援引VAR分析机构Archivo VAR的解读，认为本场几次关键判罚在规则上并无明显错误，包括埃及进球、裁判回溯等等。
不过，据《阿斯报》报道，埃及将向国际足联申诉1/8决赛对阿根廷的判罚，他们不认可比赛里的问题，及机构解释。
这抛出下一个问题，为了公平而使用的技术手段？是否真的能够杜绝不公平、减少纷争？
《福布斯》认为，技术并未消除争议。相反，争论已经从裁判是否看到了某个事件，转变为技术是否被正确且一致地应用。
一些专家表示，最新技术在场内和场外都让足球受益，而另一些人则警告不要过度使用。
“所有这些判罚都剥夺了足球的乐趣，”克罗地亚主教练兹拉特科·达利奇称。“应对这一切并不容易。足球应该是公平的，判罚也应该是公平的，但我们在VAR的使用上走得太远了。”
美国波士顿的独立足球教练库达·穆劳里表示，过度干预有可能降低比赛的刺激性，并让球员在进球确认之前不敢庆祝。他补充说，技术应主要用于客观判罚，如越位判罚和假摔认定。
“当你试图控制每一次跑动和每一个细节时，它就剥夺了足球被称为‘美丽运动’的魅力。”
