# 新突破！长晶科技牵头筹建江苏省新型功率半导体重点实验室

新突破
长晶科技牵头筹建江苏省
新型功率半导体重点实验室
7月11日，江苏省科技厅公布企业主导省重点实验室筹建名单。由长晶科技牵头、联合南京邮电大学共建的“江苏省新型功率半导体重点实验室”成功入选！
实验室立足国家“双碳”目标、能源安全与集成电路全产业链自主可控的核心方向，瞄准江苏省“1650”现代化产业体系中新型功率半导体领域的共性技术瓶颈，聚焦高性能SGT产品及封装研究、极致CSP器件特性研究、高功率密度 IGBT产品研究、第二代1200V SiC MOSFET功率器件关键技术及产业化研究四大方向开展技术攻关。
实验室将整合长晶科技IDM全产业链优势，融合南京邮电大学在功率器件、器件物理、集成技术和先进封测领域的学术积淀与人才团队，从“器件理论模型创新—新型功率器件创新—智能设计方法学创新—系统应用集成创新”四大维度协同推进，打通基础研究、技术攻关到成果转化的完整链路，打造高压高频功率半导体领域的原创技术策源地。
此次获批筹建省重点实验室，是长晶科技创新平台建设的重要里程碑。未来，长晶科技将严格按照省级重点实验室建设标准推进筹建工作，聚力攻坚功率半导体关键核心技术，加速科研成果转化落地，为功率半导体产业高质量发展提供有力支撑，为国家高水平科技自立自强、抢占产业科技创新制高点贡献更大力量！
