# 甘肃白银丨推动低速无人自动驾驶车辆(装备)技术研发与应用

为加快推动本市低速无人自动驾驶车辆(装备)技术研发与应用，指导和规范低速无人自动驾驶装备道路测试与示范运营工作，白银市交通运输局牵头组织市公安局、市工信局起草了《白银市低速无人自动驾驶车辆(装备)道路测试与示范运营管理办法(试行)(征求意见稿)》并于近日发布。
《征求意见》适用于在白银市范围内进行的低速无人自动驾驶车辆（装备）道路测试与示范运营及相关监督管理活动。
总则：明确制定目的、适用范围、管理原则，强调企业安全主体责任和县区属地责任。
组织管理：设立市联席工作小组（交通局、公安局、工信局联合），明确各部门分工，并委托第三方机构提供技术支撑和日常监管。
一般要求：规定测试示范主体、安全员、申请车辆（装备）须满足的资质条件，包括主体能力、安全员资格、车辆技术标准、保险（不低于300万元）及数据记录要求。
道路测试申请：列明申请材料清单、审核流程（第三方初审→专家评审→联席小组核发通知书和号牌），说明测试有效期（不超过18个月）及延期规则。
示范运营申请：要求车辆须先完成规定里程或时间的道路测试且无主要责任事故，明确申请材料、审核流程，示范运营有效期原则上不超过12个月。
运营管理：规定车辆增加、行驶规则（如顺向行驶、禁止借道超车）、安全员实时监控责任、数据安全保护及软硬件变更需审核等要求。
监督管理与违规处理：要求定期提交阶段性报告，对材料造假、违规操作等行为设取消资格、1年禁入、三次违规不再受理等处罚措施，并列举可终止运营的情形。
交通违法与事故处理：明确违法按现行交规处理，事故后安全员须立即停车报警，并规定8小时内（严重事故1小时内）书面报告，事后须提交事故分析报告。
附则：对低速无人自动驾驶车辆（装备）、道路、道路测试、示范运营、自动驾驶系统重大升级等关键术语作出定义，并明确办法施行日期及上级新规适用原则。
