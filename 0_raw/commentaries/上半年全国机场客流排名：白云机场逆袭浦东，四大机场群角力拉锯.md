# 上半年全国机场客流排名：白云机场逆袭浦东，四大机场群角力拉锯

近日，CADAS交通大数据公布2026年上半年中国内地机场（未统计港澳台地区，下同）旅客吞吐量数据。
据统计（实时数据，非最终统计），今年1-6月全国旅客吞吐量排名前四的机场依次为广州白云机场、上海浦东机场、北京首都机场、深圳宝安机场，分别达到4329.1万人次、4267.2万人次、3576.5万人次、3361.3万人次。
与去年同期榜单相比，上半年客流量突破千万人次的机场仍为24家，阵容稳定。其中，成都天府、北京大兴、上海虹桥、重庆江北、杭州萧山、昆明长水、西安咸阳机场在上半年旅客吞吐量均超2000万人次。
不过，千万级机场的排名则多有变动。比如，广州白云机场超越上海浦东机场登顶榜首，上海虹桥机场越过重庆江北机场升至第7，海口美兰机场上升3位，长沙黄花机场下降4位。
从增速看，年客流量千万级机场中，揭阳潮汕机场、南宁吴圩机场、石家庄正定机场旅客吞吐量同比增速均超10%，天津滨海机场、长沙黄花机场、太原武宿机场客流降幅居前。
机场位次变动，显示出当前航空市场恢复过程中，不同类型枢纽机场的结构性差异，以及各地激烈的“流量之争”。
白云机场重回榜首
上半年，地缘冲突、油价波动、极端天气等因素交织影响国内民航业。据统计，上半年全国机场旅客吞吐量约7.5亿人次，同比增长约1%。相较于2025年同期5%的增速，航空客流进入韧性增长的阶段。
这样的形势下，机场流量集中化趋势愈发明显。从上述榜单看，四大一线城市所管理的6座机场吸收了全国近三成（约27.8%）的客流量，成都、重庆、杭州、昆明等区域中心机场也表现稳定。
在强者恒强、竞争加剧的格局中，上半年中国头号流量机场迎来“易主”，广州白云机场以4329.1万人次的旅客吞吐量、8.1%的增长速度，成功超越上海浦东机场。两者相差约60万人次，这也折射出头部机场胶着的竞争态势。
近年来，“中国最繁忙机场”的称号在浦东机场和白云机场之间反复交替。2020年—2023年，广州白云机场连续四年蝉联全国流量第一，2024年上海浦东机场首次超越白云机场成为榜首，2025年继续蝉联。
为什么此次广州白云机场能重回榜首？
一大原因在于基建升级带来的扩容。2025年10月，白云机场T3航站楼与第五跑道同步启用，终端设计容量跃升至1.4亿人次，产能大幅提升并得到集中释放。
其次是国际航线网络的持续扩张。据海关数据，今年以来截至6月24日，广州白云机场口岸新增、加密国际客货运航线14条，目前白云机场口岸国际及地区通航点突破100个。
在国际客流结构上，今年上半年国际地缘政治环境仍较复杂，部分国际远程航线面临不确定性。上海浦东机场以欧美、日韩航线为主，白云机场主要连接东南亚、中东、非洲，这些市场恢复相对更快。
另外，T3航站楼建成后，白云机场优化通关流程，国际中转效率提升约40%，中转能力有了较大提升，贡献了新的客流增量。近期暑运数据显示，白云机场国际中转客流居全国首位。
机场表现离不开直接的区域支撑。惠誉评级亚太区企业、基础设施建设及项目融资董事汪湛表示，广州背靠粤港澳大湾区，人口规模、产业活动和商贸往来都比较活跃，节假日消费、会展和跨城流动共同带动了航空出行增长，白云机场因此受益。
“相比之下，浦东的优势更多体现在国际航线、洲际连接和高端商务客流上，其表现和国际市场修复的关联度相对更高。”汪湛认为，往后看，机场之间比拼的不只是吞吐量排名，更关键还是航网的韧性、腹地的支撑能力，以及连接全球市场的能力。
综合开发研究院（中国·深圳）物流与供应链管理研究所所长王国文提到，浦东机场主要看欧美航线恢复情况，广州七八月份会受台风影响比较大，今年全年预计双方差距还是会比较小。“长远看，双方的竞争存在一定的时间差，白云机场占了硬件和产能的先机。”
据悉，浦东机场四期工程正加紧建设，其中T3航站楼计划2028年具备投用条件，机场容量再增5000万人次，达到1.3亿人次。“同样有三座航站楼，浦东T3航站楼设计的近机位更多；同样有五条跑道，但浦东机场有一条是商飞专用。双方各有优势，未来的竞合可期。”王国文对南方财经记者说。
四大机场群建设竞速
超级枢纽的腕力较量，需要放在更大的区域版图来审视。
国家“十五五”规划纲要明确提出，提升京津冀、长三角、粤港澳大湾区、成渝四个世界级机场群能力。机场群的能级，将直接决定所在城市群参与全球竞争的广度和厚度。
《2025年全国民用运输机场生产统计公报》显示，2025年全国完成旅客吞吐量15.29亿人次。其中，京津冀机场群、长三角机场群、粤港澳大湾区机场群珠三角九市、成渝机场群分别完成1.59亿人次、3.06亿人次、1.68亿人次、1.51亿人次，撑起了全国的半壁江山。
在今年上半年客流量排名前十的机场中，来自四大机场群的机场占据了九席，它们之间的角力拉锯也相当激烈。而一些客流增长强劲的“黑马”机场，有不少也属于四大机场群的范围，或与之形成协同互补的关系。
例如，作为全国第41个、目前最年轻的“千万级机场”（2025年旅客吞吐量），揭阳潮汕国际机场今年上半年旅客吞吐量同比增长15.8%，达到579.1万人次。其正通过基建扩容、拓展航线网络和中转服务，拟在2030年冲击2000万人次客流量。
石家庄正定国际机场上半年旅客吞吐量同比增长10.3%，达618.5万人次。今年夏秋航季，该机场进一步优化航线布局，计划运营航线达115条，通航城市扩展至87个，同时积极推进“航文旅”融合，推出多种乘客权益产品，提升客流吸引力。
无锡硕放机场作为江苏第二大机场，上半年完成旅客吞吐量567.9万人次，同比增长8%。“十五五”期间，无锡硕放机场将启动机场二跑道、T3航站楼、GTC综合枢纽建设，商业升级同步进行，近年在服务创新和货运能力方面取得显著突破。
“这些‘黑马’机场的腹地市场更加明确，承接的并不只是单一城市客流，而是服务于更大范围的都市圈、城市群或具有鲜明特色的区域市场。它们的增长更多受益于区域出行需求释放、旅游属性提升、航线网络补强以及枢纽功能进一步细化。”汪湛向南方财经记者分析。
总体来看，四大机场群的发展各有侧重：京津冀机场群枢纽层级高，国际交往和全国航网组织功能突出；长三角机场群腹地经济强，商务和国际航空需求最活跃；粤港澳大湾区机场群开放度高，跨境联系密集，国际化优势明显；成渝机场群则是西部增长最快的航空板块，内陆门户和辐射带动作用持续增强。
在高密度、高流量的基础上，这些区域的机场新建和改扩建还在加速。例如，广州新机场正在建设，广州有望在“十五五”形成双机场格局；上海与南通共建南通新机场，将迈向全国首个“三机场”航空枢纽；成渝机场群中，重庆第二机场、成都天府机场二期等也在推进；“三地四场”的京津冀机场群，预计到2035年将拥有12条跑道、11座航站楼……
“未来机场群竞争力的关键，已不仅限于规模大小，而更聚焦资源配置能力和枢纽运行效率。”汪湛说。这意味着，谁能形成更高效的机场分工协同、更强的航网组织能力、更顺畅的综合交通衔接以及更稳固的腹地经济和国际连接能力，谁就将实现领跑。（南方财经 记者 伍素文）
