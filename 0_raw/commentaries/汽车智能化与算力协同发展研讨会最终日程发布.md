# 汽车智能化与算力协同发展研讨会最终日程发布

会议介绍
当前，国家“东数西算”战略深入推进，庆阳作为全国一体化算力网络国家枢纽节点，凭借绿色低耗、规模充足的智算优势，成为承接东部算力需求的重要载体。与此同时，智能驾驶产业快速发展，算法训练、仿真验证、数字孪生、云端协同等环节的高算力需求日益迫切，东部算力成本高、能耗约束强的问题凸显，算力西移成为产业发展必然趋势。在此背景下，特举办本次汽车算力研讨会，旨在解读庆阳算力产业政策与优势，搭建车企、算力企业、科研机构的对接平台，探讨汽车高算力需求的解决方案，推动庆阳承接汽车产业非核心研发算力负载，助力“东数西算”战略落地见效，实现庆阳算力优势向产业优势转化，赋能智能驾驶产业高质量发展。
