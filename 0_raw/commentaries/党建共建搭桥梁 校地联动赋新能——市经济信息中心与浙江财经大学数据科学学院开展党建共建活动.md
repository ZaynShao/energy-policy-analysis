# 党建共建搭桥梁 校地联动赋新能——市经济信息中心与浙江财经大学数据科学学院开展党建共建活动

为持续擦亮“信连心”特色党建品牌，加快推进“数智智库”建设，推进校地党建融合共建，7月8日下午，市经济信息中心党支部与浙江财经大学数据科学学院教工第二党支部开展党建共建活动。市发展改革委组织人事处、浙江财经大学党委组织部领导到场指导，双方单位全体党员、青年干部共同参与。
中心党员依次走进诺贝尔经济学奖文献馆、孙冶方经济科学奖文献馆，近距离研读珍贵学术典籍、一手研究史料与学界名家著作，系统梳理国内外顶尖经济理论演进脉络与前沿学术成果，沉浸式体悟经济学者潜心治学、求真务实的优良学风，深刻把握新时代经济建设的理论本源与实践路径。
共建签约：校地联动聚合力
活动现场，浙江财经大学党委组织部副部长李伟与市发展改革委组织人事处处长高燕分别致辞。双方一致表示，校地党建共建是深化联动、优势互补的重要载体。市经济信息中心在数字化改革、经济监测、信用建设领域实践积淀深厚，数据科学学院学科与科研优势突出，双方业务契合度高、合作空间广阔。下一步，双方将建立常态化交流机制，推动党建与业务、科研、人才培养深度融合，携手实现共建共享、协同发展。
双方党支部代表共同签署《党建共建协议书》并完成授牌，标志着校地党建共建合作机制正式落地。
签约仪式后，双方开展“行业实务+学术前沿”专题党课分享。市经济信息中心副主任王超围绕杭州社会信用体系建设工作，结合一线实践案例，全面介绍了杭州信用数字化、智慧化建设的阶段性成果。学院党支部书记许林聚焦数智前沿赛道，围绕AI赋能数据转型主题展开深度分享，为中心业务创新、科研协作提供了全新思路。
本次活动搭建起校地联动、产学研深度融合的交流平台，有效推动党建工作与中心主责主业同频共振、互促提升。下一步，双方将持续开展组织共建、人才共育、科研共研，聚力打造校地党建融合示范样板，为杭州经济社会高质量发展赋能增效。
