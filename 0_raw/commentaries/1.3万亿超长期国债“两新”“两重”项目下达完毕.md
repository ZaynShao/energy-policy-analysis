# 1.3万亿超长期国债“两新”“两重”项目下达完毕

1.第一批（2月底至3月初）1700亿
2026年第一批“两重”建设项目清单下达，共安排超1700亿元超长期特别国债。这一批聚焦重大工程和重大科技基础设施，本批次还同步配套了2950亿元中央预算内投资，形成了“超长期特别国债+中央预算内投资”的组合方案。
2.第二批（4月初）2168亿
4月下达第二批“两重”建设项目清单，共安排超长期特别国债资金2168亿元支持336个重大项目；加上此前已下达的3897亿元，今年累计安排“两重”建设资金6065亿元，占全年8000亿元的76%。
3.第三批（6月底） 1935亿元
第三批“两重”建设项目共安排超长期特别国债资金1935亿元，全年共安排8000亿元支持了1417个重大项目建设，全部资金下达完毕。
8000亿元资金支持1417个重大项目，平均每个项目获得约5.64亿元的超长期特别国债资金支持。
二、2000亿“两新”设备更新项目下达完毕
7月3日国家发改委消息，今年2000亿元超长期特别国债支持“两新”设备更新资金已全部下达。
国家发展改革委会同有关部门，优化支持范围，完善申报流程，强化审核把关，加快工作节奏，分三批下达设备更新资金。
1.第一批（1月） 936亿元
超长期特别国债支持设备更新资金下达，支持工业、能源电力、教育、医疗、粮油加工、海关查验、住宅老旧电梯、节能降碳环保、回收循环利用等领域约4500个项目。
2.第二批（4月） 915亿元
“两新”设备更新项目清单和资金安排下达，支持工业、能源电力、电子信息、交通运输、物流、教育、文旅、医疗、设施农业、粮油加工、住宅老旧电梯、安全生产、消防救援、检验检测、节能降碳环保、回收循环利用等16个领域超过6700个项目。
3.第三批（7月初） 149亿元
2000亿元资金支持约1.1万个项目，平均每个项目获得约1818万元。
