# 虚拟电厂：山西现货市场中的消纳“新力量”

****文|本刊记者　郝怡柯****

1月底的太原，寒意正浓。记者来到山西风行测控股份有限公司的虚拟电厂运营中心，看到电子屏幕上跳动着密密麻麻的数据：冶铸厂的负荷曲线正在下滑，充电站的充电桩功率逐步攀升……调度员轻点鼠标，几分钟内，分散在山西各地的数十家工业企业、充电站、储能设备便协同完成了一次负荷调整。

  

“这座看不见的电厂，正实实在在地参与着电力系统的平衡调节。”风行测控副总经理、虚拟电厂研究院院长南豆告诉本刊记者。

  

在“双碳”目标引领下，山西作为全国重要的能源基地，正加速构建新型电力系统，推动能源结构向绿色低碳转型。截至2025年底，山西的新能源装机容量达7880.8万千瓦，占全省装机容量的近50%。如何高效消纳波动性强的新能源电力，成为山西能源转型中的必答题。而依托电力现货市场的虚拟电厂，正是这道题的解题关键之一。

2月2日，山西运城，风力发电机源源不断地生产绿电。

  
  
  

秒接真实供需，“就像网约车平台”  
  
  

  

2023年12月22日，山西电力现货市场在全国率先由试运行转入正式运行。这一里程碑为虚拟电厂的商业化运营提供了理想沃土。同年，山西首批虚拟电厂入市交易。随着市场走向成熟，越来越多的电力用户开始认识到虚拟电厂在节能降碳中的价值，主动跟随电价信号调整生产计划。

  

“电力现货市场的核心优势，是价格信号真实反映供需关系。”山西电力交易中心市场处处长弓健华告诉记者，“接入现货市场的虚拟电厂能更及时地响应价格信号，并据此向工商业企业下达生产调整指令。因此，虽然山西虚拟电厂聚合的负荷体量可能不如一些省份大，但其优势在于灵活、精准、高效，调节能力并不弱。”

  

与部分仅允许储能参与现货市场的省份不同，山西形成了15分钟一次的高频次实时电价形成机制。一天96个分时电价，真实反映电力供需波动，让虚拟电厂可精准响应、精细调节。据国网山西电力调控中心现货市场处专家董建鹏介绍，山西正推动现货市场出清周期从15分钟缩短至5分钟。更精准的价格信号，是其他省份暂未具备的核心优势。

  

日前，山西虚拟电厂以“报量报价”方式每日常态化参与现货交易，自2023年9月入市以来已不间断运行超过24个月，结算电量超13亿千瓦时，市场化运营的活跃度、成熟度都走在全国前列。

  

风行测控正是这一领域的先行者。作为全国首家基于电能量市场分时价格信号交易的“负荷类”虚拟电厂，它凭借在工业用户综合能源服务领域的深厚积累和领先的电力交易能力，自主研发了虚拟电厂技术平台，率先探索出一条市场化、可复制的运营路径。

  

谈及现货市场下虚拟电厂的运营方式，南豆向记者打了个比方：“这类虚拟电厂就像网约车平台，我们是做运力调度的，核心是需求匹配。电价高的时候，说明系统缺电，我们就引导用户少用；电价低的时候，说明绿电发得多，我们就鼓励用户多用。调节效果和收益挂钩，供需关系越紧张，价格越高。”

  

从2023年成立至今，风行测控平台聚合的用户从最初的5家增至54家，涵盖建材企业、铸造厂、工商业储能、分布式光伏、充电桩等多种负荷资源；聚合容量从8万千瓦跃升至223.8万千瓦，可调节容量达54.3万千瓦，年用电量达60亿千瓦时；调控成功率从2023年的33%提升至2025年的80%。这些数字背后，是平台资源整合与调度能力的持续优化。

  

数据显示，从2023年8月到2026年2月，风行虚拟电厂累计促进新能源消纳增量达2.9亿千瓦时，相当于减少二氧化碳排放约29万吨，节约电量约1.8亿千瓦时，节约的电量相当于14万～23万户居民家庭一年的基本用电需求。部分收益反哺用户，平均降低用户侧度电成本约3～5厘钱。这种“虚拟电厂 +新能源消纳” 的深度融合模式，相较于深圳、上海等以城市楼宇、充电桩为主的虚拟电厂，更适合能源大省、工业大省的能源转型需求，对全国能源基地具有更强的借鉴意义。

  
  
  

收益共享激励，“真的挣到钱了”  
  
  

  

在风行测控的技术平台，记者看到了一套完整的“数据采集—分析—交易决策—负荷调节”系统。物联网技术实时采集用户侧的能耗数据，包括工业企业的生产用电曲线、储能设备的充放电状态、充电桩的实时功率等，再与电力现货市场分时价格信号融合，构建起动态负荷预测算法模型。

  

这套模型能精准预测不同时段用电需求，提前规划负荷调节策略。据介绍，其响应速度较同类产品提升20%，能在市场价格突变时迅速调整策略，帮用户锁定收益。

  

山西某冶铸企业年用电量约7000万千瓦时，具备约10兆瓦的调节能力。2023年虚拟电厂运行之初，它便成为第一批“吃螃蟹的人”。

  

“核心动力就是客户真的挣到钱了。”南豆笑着说。2023年以来，该企业累计获得红利超过269万元。这笔收益被转投到低碳工厂的建设上：分布式光伏、中频炉余热供暖系统、智慧能碳平台……一套覆盖全厂的数字能源与碳资产管理体系逐步成形。

  

更深刻的变化发生在用电习惯上。过去，生产负荷全凭经验安排，峰谷时段用电无序；如今，在分时电价信号引导下，企业主动在午间谷段集中生产，晚间高峰时段减少用电。

  

“调节结果和收益是强挂钩的。”南豆解释收益分配机制，“还是用网约车平台类比，完成一单是一单的报酬，完成得好还会得到额外的奖励系数。供需关系紧张的时候，价格高；供需宽松的时候，价格低。我们还参照网约车的激励手段，对积极参与的用户给予额外奖励，让他们愿意跟着我们的节奏走。”

  
  
  

迈入“百万千瓦级”的价值空间  
  
  

 电力现货市场下，虚拟电厂的商业模式如何跑通？答案是聚合可调节负荷资源并进行“低买高卖”，在电价低谷时多用电，在电价高峰时少用电，从中获取价差收益。这部分收益本质上是对其提供调节服务的市场化回报，体现了虚拟电厂在电力系统中的独特价值。

  

南豆说：“我们相当于是负荷资源的代理商，在电力市场中进行博弈。我们在市场里挣的钱，其实是电网付给我们的调节服务费。在山西，这个费用不是固定的，取决于你对价格的判断和对可调节负荷的协调能力。理想状态下，如果通过博弈能在电价最低的时候用最多的电，电价高的时候用最少的电，成本自然能压到最低。我们也是在不断低买高卖中赚取差价的。”以工商业储能为切入点，风行测控正在构建“峰谷收益+电力交易收益+虚拟电厂收益”的多维度收益模型。这意味着，储能设备不再仅仅依赖峰谷价差，还可以通过参与电力市场交易和虚拟电厂调度，获得多重回报。

  

对于虚拟电厂，在企业积极探索的同时，政策层面也在持续规范与引导。2022年，山西省能源局出台了《山西省虚拟电厂建设与运营管理实施方案》，明确了虚拟电厂项目组织、建设流程、并网运行技术规范、运营管理规范等重点内容。2025年8月，山西省能源局、国家能源局山西监管办公室印发《虚拟电厂建设与运营管理暂行办法》，以规范虚拟电厂运营管理全流程，进一步推动虚拟电厂标准化、规模化、智能化发展。

  

山西电力市场化改革坚持鼓励民营企业参与虚拟电厂投资、建设和运营。以风行测控为代表的民营企业成为虚拟电厂运营的核心主体，形成了“政府引导、市场主导、多元参与”的产业生态。截至2026年2月，进入山西电力市场的虚拟电厂聚合容量从82.18万千瓦大幅跃升至406.48万千瓦，最大可调节负荷达到109.64万千瓦，正式迈入百万千瓦级行列。山西已有10座虚拟电厂入市交易，聚合用户283户，民营企业经营主体数量突破2万家，远高于国内部分仍采取电网企业、发电集团为主导模式的省份。

  

同时，山西通过批发与零售市场协同机制，确保虚拟电厂的市场化红利向用户侧传导，部分工业企业累计获得红利超269万元。这种 “收益共享” 的模式极大提升了市场主体的参与积极性，形成了可持续的发展生态。

  

2025年8月，国网山西省电力公司首次集中调度47座储能电站、16座虚拟电厂参与用电负荷调节，供电、用电双向调节最大功率达225万千瓦，其中虚拟电厂贡献84万千瓦，占实时用电负荷的6%。这次实战检验证明，虚拟电厂已具备在关键时刻“顶得上”的能力。

  

价格信号指导下，一个“看不见的电厂矩阵”，正在成为电网调峰的重要补充力量。
