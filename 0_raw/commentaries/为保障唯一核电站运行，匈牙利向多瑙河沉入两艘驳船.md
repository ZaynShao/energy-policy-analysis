# 为保障唯一核电站运行，匈牙利向多瑙河沉入两艘驳船

外媒：为保障唯一核电站运行，匈牙利向多瑙河沉入两艘驳船以抬高水位。
据美国“政治新闻网”欧洲版报道，匈牙利总理毛焦尔15日表示，为保障该国唯一的保克什核电站正常运行，匈牙利方面已开始向多瑙河沉入两艘驳船以提高水位。此举源于欧洲今夏的极端高温导致多瑙河水位创下历史新低，影响到保克什核电站的发电能力。
▲当地时间8月14日，一艘满载石料的驳船停靠在匈牙利保克什核电站附近。图源：美媒
毛焦尔当天在社交媒体X上发文称，匈牙利唯一的核电站附近水位目前比正常值低122厘米，预计到8月17日将降至132厘米以下，到时将迫使核电站两座涡轮机中的一座停运。
报道称，保克什核电站供应匈牙利超过三分之一的电力需求。为应对危机，匈牙利方面于15日上午开始沉没两艘80米长的驳船，匈牙利媒体援引毛焦尔的话称，此次行动已使保克什核电站的水位上升了1厘米。
毛焦尔此前还宣布计划用15万立方米石料建造河床堰，以减缓水流并抬高水位。“匈牙利国防部已调派100名士兵全天候参与此项目。”毛焦尔在社交媒体上说。
美媒称，极端高温和干旱已影响欧洲多地的核能设施。罗马尼亚国家核电公司8月13日说，由于多瑙河本周水位降至历史新低，该国唯一核电站切尔纳沃德核电站冷却水供应不足，于当天起全面停运。作为欧洲最大核电生产国之一的法国，其57座核反应堆中已有六座因热浪关闭。此外，气候变化引发的“水母入侵”也迫使法国另一座核电站的部分机组暂停运行。
