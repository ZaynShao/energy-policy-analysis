# 麸皮：3月价格跌后反弹 4月上行空间或受限

【导语**】**3月麸皮市场供应量增加，下游需求相对疲弱，价格重心明显下移，临近月底窄幅反弹；4月市场供应量存在季节性下降预期，价格或继续回升，但下游需求难有起色，或牵制涨幅。

3月麸皮市场价格先跌后涨，月环比偏低。中上旬面粉企业开工负荷恢复性提升，麸皮供应量增加，但下游询采不积极，价格重心震荡下移；下旬部分粉企开工负荷下调，麸皮产出量有减，叠加下游部分低位补库，价格出现反弹。截至3月31日，主产区混合麸皮月均价1724.26元/吨，月环比下跌6.59%。

**开工负荷先升后降，加工亏损扩大，对麸皮价格影响由利空转利多**

3月中上旬，面粉企业全面恢复生产，开工负荷恢复性提升，叠加小麦价格上涨，价值链传导较为顺利，带动面粉价格上行、订单增多，部分面粉企业开工负荷提升至阶段性高位，麸皮产出量增加，供应压力凸显。3月下旬，小麦价格高位回落，面粉终端销售不快，部分价格承压，面粉企业亏损压力持续加大，部分下调开工或短时停机检修，麸皮产出量下降，对价格带来提振。卓创资讯调研数据显示，截至3月31日，主产区中小企业月均开工负荷41.98%，较上月上升18.53个百分点，较去年同期偏高3.1个百分点；小麦月均价环比上涨45.98元/吨，特精粉月均价环比上涨75.27元/吨，麸皮月均价环比下跌122.51元/吨。

**需求端支撑不足，对麸皮价格带来利空影响**

需求方面，卓创资讯监测样本企业前置10个月（2025年5月）能繁母猪存栏量环比增幅1.44%，2026年3月份生猪理论出栏量增加，但生猪养殖深度亏损，部分养殖端下调麸皮添比，且饲料厂大面积采购小麦替代玉米，同样挤占部分麸皮需求，对麸皮价格带来利空影响。

**4****月麸皮市场供应量预期减少，价格重心会回升，但需求依然缺乏利多支撑，或牵制涨幅**

供应方面，4月属于面粉传统淡季，销售迟缓叠加运营压力突出，面粉企业开工负荷面临继续下调可能，不定时开停机企业或增多，麸皮产出量预期下降，对价格带来利多提振。

需求方面，卓创资讯监测样本企业前置10个月（2025年6月）能繁母猪存栏量环比增幅0.75%，2026年4月份生猪理论出栏量继续增加，但小麦饲用替代持续，且生猪产能过剩，行业深度亏损，叠加政策力度加码，规模企业或保持减产节奏，养殖端或被动开启减重策略，或影响麸皮上涨节奏。

其他方面，麸皮经历了近一个月的下跌历程后，与玉米纤维、米糠粕等相关品价差扩大，价格优势显现，为4 月份的配方替代增加提供比价基础。截至3月31日，卓创资讯监测混合麸皮市场均价1751.88元/吨，玉米纤维市场均价1372.95元/吨，两者价差378.93元/吨，较上月底缩窄169.47元/吨；米糠粕江苏泰州地区部分企业出厂报价在1980元/吨，混合麸皮当地部分大厂出厂报价在1804元/吨，米糠粕与麸皮价差176元/吨，较上月底扩大130元/吨。

综合判断，4月份麸皮价格预计维持回升态势，面粉企业开工负荷环比预期有所下调，麸皮产出量减少，供应趋于紧张，对价格带来有效支撑，但下游生猪养殖亏损局面或难扭转，叠加部分饲料企业添加小麦替代玉米，或限制价格反弹幅度。预计4月份主产区混合麸皮均价在1720-1870元/吨区间波动，月内振幅150元/吨左右。后期需重点关注面粉企业开停工节奏、米糠粕等相关品价格走势、小麦饲用替代变化情况及下游补库节奏等。
