# 中方：坚决反对在人工智能问题上搞选边站队、阵营对抗，希望各方摒弃零和思维，坚持和衷共济，尊重各国的数字主权

据报道，美方已致信《人工智能机遇伙伴关系联合声明》联署国，要求各方不得同时加入美方相关倡议和与美方倡议冲突的其他机制。外交部发言人林剑19日在例行记者会上答问时表示，各国有权根据自身国情和发展需要选择合作伙伴。中方坚决反对在人工智能问题上搞选边站队、阵营对抗，希望各方摒弃零和思维，坚持和衷共济，尊重各国的数字主权，携手构建公正合理的全球人工智能治理体系，让人工智能成为促进共同繁荣、维护共同安全的重要动力源。
