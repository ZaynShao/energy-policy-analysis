# 中方呼吁构建能源转型关键矿产治理体系

中国常驻联合国代表团临时代办孙磊在联合国呼吁构建开放包容、公正合理、合作共赢、绿色清洁的关键矿产治理体系。
中国常驻联合国代表团临时代办孙磊当地时间7月14日在联合国能源转型关键矿产高级别会议上发言，呼吁构建开放包容、公正合理、合作共赢、绿色清洁的关键矿产治理体系。
他说，当前全球能源转型加速推进，绿色低碳可持续发展成为时代潮流。关键矿产作为支撑能源转型和绿色发展的重要资源，面临需求激增、供应链不稳定等诸多挑战，国际治理赤字愈发凸显。中方支持联合国发挥领导力，推动构建开放包容、公正合理、合作共赢、绿色清洁的关键矿产治理体系。
第一，坚持开放包容，促进自由贸易。各方应秉持共商共建共享理念，强化政策协调和产业对接，深化技术交流和投资合作，维护健康、稳定的产业链供应链。同时，各方应促进关键矿产贸易自由化，塑造开放、透明、非歧视的贸易环境。
第二，坚持公正合理，促进平等普惠。要充分发挥联合国作用，倾听各方意见，凝聚各方共识，制定符合各方利益的规则，确保公平参与、平等获益。要坚持以人民为中心，建立普惠包容的治理机制，让资源红利惠及各国人民。
第三，坚持合作共赢，促进共同繁荣。充分尊重关键矿产资源主权，确保发展中国家利用资源禀赋实现经济社会发展，提升当地附加值。资源富集国也应营造稳定、透明、可预期的法律政策环境，充分保障关键矿产投资方合法权益。
第四，坚持绿色低碳，促进清洁利用。推动绿色矿产技术创新，提高开采、冶炼、加工、循环利用全生命周期的资源利用率。协调制定国际通行的绿色标准，推进关键矿产行业节能减排、降本增效，提升“绿色化”，实现可持续发展。
他说，中国是全球能源转型的引领者和推动者，是关键矿产治理的建设者和贡献者。中国秉持“绿水青山就是金山银山”理念，大力推进关键矿产领域国际合作。中国发挥绿色勘探开发、清洁冶炼等技术优势，为发展中资源国提供可复制的绿色矿产解决方案。中方愿与各方携手前行，加强全球能源转型关键矿产治理体系建设，共建清洁美丽繁荣世界。
