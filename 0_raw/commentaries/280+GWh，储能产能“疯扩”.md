# 280+GWh，储能产能“疯扩”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhItBtlGJ95r0bemU7qI250LySmvwwaeibs3u1ibMpLPjZCuvmlxhSKGpxVJMZ8xrFGwRHic5JNsLrJLP5KQnl0wa12aD4CBOuhAp6I/640?wx_fmt=png&from=appmsg)

据不完全统计，近期国内宣布新建的储能电池及系统项目合计规划产能已超过280GWh，这一轮扩产浪潮的驱动力量来自政策和市场的双重共振。  

  

![image](https://mmbiz.qpic.cn/mmbiz_png/bhqZZ4eZhIsZfSK1WnVicWNnXOEN6ibsZ12nBucPJAgb0DF4NtQAnos7S8LEmFaYb4dEkIXSIQLme7PnTznKoXeCpkDODuibc78RMOhuNDUPibw/640?wx_fmt=png&from=appmsg)

  

GGII数据显示，2025年中国储能锂电池市场迎来爆发式增长，全年出货量达630GWh，同比增长85%，增速远超行业预期。全球大储装机规模也再创新高，2025年中国大储交流侧储能系统出货量达到330GWh，同比增长94%。  

  

储能行业已经迎来了新一轮爆发式增长周期，企业也纷纷上马新的产能项目。

  

其中，既有头部企业如宁德时代、亿纬锂能的大规模产能卡位，也有新兴力量如固一新能、当卓能源在固态电池、钠离子电池等细分赛道上的差异化布局。

  

新一轮的产能建设周期，不仅关乎企业自身的市场卡位，更将决定未来五年全球储能产业的主导权归属。

  

短期来看，大规模产能释放将有效缓解当前储能电芯供不应求的紧张局面，为正在快速扩张的国内外储能市场提供充足的供给保障。

  

中长期来看，随着固态电池、钠离子电池等新技术路线逐步实现规模化量产，储能产业也将加速从单一技术依赖走向多元技术互补的供给格局。

  

不过，产能集中释放后可能出现的结构性过剩风险也需警惕。

  

4月9日，四部门联合召开座谈会，强调要深入推进产能预警调控、规范价格竞争、加强产品质量监管、打击知识产权侵权、治理“内卷外化”等工作，16家重点动力和储能电池企业参与了会议。  

  

储能行业需告别低价内卷的初级阶段，迈向以技术和价值为核心的高质量竞争新阶段。

  

以下是部分企业的最新产能规划：

  

亿纬锂能

日前，亿纬锂能密集宣布了四份投资公告，分别落子福建省龙岩市上杭县、江苏省启东市、广东惠州、湖北荆门，合计规划新增230GWh电池产能。

4月8日，亿纬锂能拟与江苏启东市人民政府就公司在启东经济开发区投资建设50GWh储能（动力）电池生产基地相关事宜签订《投资合作协议书》。项目投资总额约50亿元，用地面积约332亩，建设50GWh储能（动力）电池生产基地。

4月8日，亿纬锂能拟与上杭县人民政府签订《亿纬锂能储能电池生产基地项目投资协议》，与福建龙净环保股份有限公司签订《合资协议》，公司拟与龙净环保共同投资，设立合资公司并通过合资公司在福建省上杭白砂新材料科创谷投资建设年产60GWh储能电池生产基地相关事宜，项目计划总投资约60亿元（具体金额以实际投入为准）。

此前3月28日，亿纬锂能公告，拟与广东惠州仲恺高新技术产业开发区管理委员会签订投资合作协议，计划在仲恺高新区投资建设“亿纬锂能60GWh储能（动力）电池生产制造项目”。

3月30日，亿纬锂能公告称，子公司“亿纬动力”拟与沙洋县政府、荆门高新区管委会，就亿纬动力在荆门市投资建设60GWh动力储能电池项目签订合同书，项目计划总投资60亿元，建设60GWh动力储能电池项目。

豪鹏科技

4月9日，豪鹏科技公告更新定增方案，拟定向募资8亿元，用于扩建3GWh储能电池产能和AI端侧应用领域的钢壳叠片锂电池产能。

豪鹏科技称，公司储能电池客户需求持续攀升，但现有产能已无法满足客户交付需求，产能瓶颈成为制约储能业务扩张的主要障碍。为此，公司拟总投资4.47亿元在惠州现有厂房及公用工程设施基础上开展建设。项目预计两年后实现试生产，达产年预测毛利率为14.74%、未来将提升到17.09%，项目内部收益率（税后）为12.68%，动态投资回收期（所得税后）为9.79年。

闽储新能源

4月7日，闽储新能源（三明）有限公司与明溪经济开发区管理委员会在福建省明溪县就新型储能智能制造产业园项目签署合作协议，总投资约3.6亿元的储能产业项目在此正式落户。

该项目总投资3.6亿元，用地94.5亩，主要建设年产0.8GWh电芯PACK生产线，同步打造年产3.0GWh电芯及3.0GWh储能配套生产线。

据悉，闽储新能源（三明）有限公司为国有企业，为中国物流信息中心全资控股公司。

首通新能源

3月4日，广东省能源局发布了《关于江门首通新能源科技有限公司磷酸铁锂电芯及储能电源系统生产制造项目节能报告的审查意见》公告，同意该项目节能报告。

该项目选址新会睦洲镇江睦双碳新能源产业园，总投资约20亿元，预计2026年12月投产。根据公告，项目预计建成达产后，年产固态磷酸铁锂电芯（314安时）5GWh、家储及工商业储能2GWh、大型储能系统4GWh。

耀宁科技

据利星能消息，3月25日，耀宁科技集团江西储能系统二期项目签约仪式在杭州举行。江西余江工业园区管委会、鹰潭市余江区工业投资集团有限公司与浙江耀宁科技集团及旗下江西利星能科技有限公司共同签署合作协议。

作为利星能的核心智造基地，耀宁科技集团江西储能系统二期项目全面达产后，利星能鹰潭智造基地总产能规模将达16GWh。

据悉，当前利星能已在江西鹰潭、鄱阳及江苏盐城完成三大智造基地布局，建成多条GWh级自动化储能系统产线，其自主研发的源特流®系列储能产品已应用于亚、欧、非等地区。

长虹能源

4月3日，长虹能源发布对外投资公告，其控股子公司长虹三杰新能源有限公司计划在马来西亚柔佛州投建高倍率圆柱锂电生产基地，项目总投资约9.99亿元（近10亿元），规划年产1.7亿只18650/21700系列电芯，应用于电动工具、园林工具、便携储能、无人机、轻型电动车等高增长领域。

该项目拟作为长虹能源2026年度向特定对象发行股票的募投项目，其中8.03亿元拟使用募集资金，剩余资金以自有或自筹方式解决。

这也是长虹能源继泰国基地后，第二次海外重大产能布局，构建“国内+海外”双基地运营体系。

三晶电气

4月2日，三晶电气正式签约落户佛山市南海区狮山镇。三晶电气计划总投资2亿元，打造集工商业储能系统、电池PACK等智慧储能产品的生产制造、销售运营及仓储物流于一体的综合性产业基地，项目预计于今年6月正式投产，全面达产后，可实现工商储年交付3.6GWh+，预计年产值可达 30 亿+。

甘肃新西部锂业

4月2日，甘肃省张掖市人民政府发布关于作出新西部锂业5GWH钠离子电池制造项目环境影响评价文件审批决定的公告，该项目建设单位为甘肃新西部锂业有限公司，总投资约10.5亿元，拟建设钠离子电池及Pack生产基地，计划建设3条生产线。

项目分两期建设，一期建设1条生产线，实现年产2GWh钠离子电池生产规模，二期建设2条生产线，实现年产3GWh钠离子电池生产规模。

据此前招标信息，项目施工开工日期为2025年10月15日，工程竣工日期预计2026年9月14日。

三合正能源科技

3月30日，东安县政府和深圳三合正能源科技有限公司举行项目投资框架协议签约仪式。

根据协议，该项目拟总投资约32亿元，分三期投入，五年内完成建设并投产。

其中，一期拟投资约5.8亿元，建设年产1GWh固态锂电池生产线、第四代厂房及研发中心；二期拟投资约13亿元，建设年产2GWh新能源产业园及相关配套设施；三期拟投资约13亿元，建设年产2GWh新能源产业园及相关配套设施。

项目产品涵盖固态锂电池制造、电池PACK、家用移动电源、工业储能、集装箱储能、电动工程车、电动农机车等多个领域。

固一新能

4月1日，内蒙古自治区投资项目在线审批办事大厅信息显示，固一新能（内蒙古）科技有限公司2.2GWh高安全固态电池建设项目通过备案。据该项目位于呼和浩特市土默特左旗台阁牧镇，总投资8亿元，其中自有资金1.5亿元，银行贷款6.5亿元。

项目计划建设周期为2026年6月至12月，总占地面积77.75亩，建设内容包括2.2GWh准固态电池生产线和一条研发中试线，配套厂房、研发楼、仓库等设施。项目建成投产后预计年产值32.56亿元，年利税7.07亿元。

齐光新能源

徐闻发布消息，3月30日，2026年徐闻县与海南相向而行重大项目签约活动在湛江港徐闻港区举行，现场共签约17个项目。

其中，年产40亿安时量子芯片固态电池生产线及产业园建设项目签约。该项目由华南齐光新能源科技（广东）有限公司投资建设，选址湛江市徐闻县经开区，总投资48亿元。

当卓能源

3月31日，浙江省嘉兴市南湖区人民政府发布拟对浙江当卓能源科技有限公司年产5GWh新型电芯/模组（无负极固态）产业化项目（一期设备）环评文件作出审批意见的公告。

该项目总投资5.62亿元，建设地点为嘉兴市南湖区栖贤路以南，用地154.7亩，购置涂布机、搅拌机、模切机等先进设备，形成5GWh新型电芯/模组（无负极固态）产品的建设规模与生产能力。

据悉，浙江当卓能源科技有限公司成立于2023年7月，曾用名浙江湖钠能源有限责任公司，公司位于浙江嘉兴，致力于构建智能高效的储能生态系统和商用车动力电池生态系统。

当卓能源于2025年7月25日签约南湖区湘家荡区域新能源产业项目，分三期建设，总计规划40GWh年产能，预计5年内全部落地。目前在建项目一期投资约16亿元，年产能为10GWh，预计今年7月正式投产。

宁德时代

4月3日，宁德时代宣布变更部分A股募集资金用途，同意公司将截至2026年2月28日“广东瑞庆时代锂离子电池生产项目一期”尚未投入的募集资金48亿元用于“时代新能厦门电池产业基地项目”，不足部分由公司根据项目建设实际需要以自有资金或自筹资金投入。

据悉宁德时代“广东瑞庆时代锂离子电池生产项目一期”规划新增锂离子电池年产能约30GWh。截至2026年2月28日，该项目第一阶段已建设完成投产，第二阶段部分工序已建设完成；厦门电池产业基地项目总投资额不超过80.608亿元，其中48亿元募资专项用于工程建设，项目建设内容为锂离子电池系统生产线。
