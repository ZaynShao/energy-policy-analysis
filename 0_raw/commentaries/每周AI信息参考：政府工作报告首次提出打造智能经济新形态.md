# 每周AI信息参考：政府工作报告首次提出打造智能经济新形态

**01  政府工作报告首次提出打造智能经济新形态  
**国务院总理李强3月5日在政府工作报告中指出，打造智能经济新形态。深化拓展“人工智能+”，促进新一代智能终端和智能体加快推广，推动重点行业领域人工智能商业化规模化应用，培育智能原生新业态新模式。支持人工智能开源社区建设，促进开源生态繁荣。实施超大规模智算集群、算电协同等新基建工程，加强全国一体化算力监测调度，支持公共云发展。加快发展卫星互联网。打造“5G+工业互联网”升级版。深化数据资源开发利用，健全数据要素基础制度，建设高质量数据集。完善人工智能治理。  
**02  “十五五”规划纲要部署提升数智化发展水平  
**“十五五”规划纲要在第四篇就“深入推进数字中国建设  提升数智化发展水平”作出部署。规划纲要提出，把握数字化、网络化、智能化发展大势，充分发挥我国数据资源丰富、产业体系完备、应用场景广阔优势，激活数据要素潜能，加快数智技术创新，深化拓展“人工智能+”，赋能经济社会发展和治理能力提升，促进生产方式深层次变革和生产力革命性跃迁。规划纲要提出，强化算力算法数据高效供给，统筹推进算力设施建设、模型算法发展和高质量数据资源供给。促进模型算法迭代创新，鼓励多模态、智能体、具身智能、群体智能等技术创新，探索通用人工智能发展路径。深化数据资源开发利用，统筹推进政务数据共享、公共数据开放和授权运营。完善数据标准体系和质量管理体系，加快建设人工智能语料库，面向能源、交通、制造、教育、健康、金融等领域建设高质量数据集。加强数据领域关键技术和设备研发应用，培育壮大数据产业，深入开展“数据要素×”行动。建设和运营国家数据基础设施，实施可信数据空间发展行动计划。规划纲要提出，全方位推进数智技术赋能，全面实施“人工智能+”行动，加强人工智能同科技创新、产业发展、文化建设、民生保障、社会治理相结合，抢占人工智能产业应用制高点，全方位赋能千行百业。促进实体经济和数字经济深度融合，创造美好数智生活，丰富智能家居、智慧出行和智慧社区场景，发展智能终端产品和服务，构建数智便民服务圈。提高政府治理数智化水平，发展泛在可及、智慧便捷、公平普惠的数智化政务服务。安全稳妥有序推进政务领域人工智能大模型部署应用，探索构建精准识别需求、主动规划服务、全程智能办理的服务新模式。深化人工智能赋能安全治理，提升感知预警、指挥决策、精准管理和即时响应能力。规划纲要提出，营造健康有序的发展生态，加强数据基础制度规则建设和人工智能治理。建立健全数据产权、流通利用、收益分配、安全治理等数据要素基础制度。建设开放共享安全的全国一体化数据市场。建立数据要素价格形成机制。完善科学有效监管机制，推动建立人工智能全生命周期风险管理制度，健全覆盖安全监测、风险预警、应急响应的风险防控体系。拓展数智领域国际合作。  
**03  工业和信息化部启动工业数据筑基行动  
**工业和信息化部近日印发通知，启动工业数据筑基行动，组织开展面向人工智能赋能的高质量行业数据集建设先行先试，着力突破工业数据“采”“集”“用”瓶颈。通知提出，到2026年底，培育一批行业数据合作联合体，建设重点行业数据可信互联平台，汇聚一批行业数据资源，攻关一批数据关键技术，研制一批工业数据标准，打造一批高质量、标准化、可流通的行业数据集，赋能一批行业大模型、工业智能体等应用落地。通知明确实施主体，聚焦数字化转型基础好、数据价值挖掘潜力大的制造业重点行业，依托重点行业企业、平台机构、先进制造业集群、中小企业数字化转型城市试点四类主体，推动成立一批联合体开展先行先试。通知提出重点任务，依托联合体建设重点行业数据可信互联平台，打造行业数据资源库、数据技术攻关库、工业数据标准库、高质量行业数据集库等四大资源库，围绕研发设计、中试验证、生产制造等关键环节，开展行业大模型应用、工业智能体研发等场景落地。  
**04  微软发布Copilot Cowork智能体  
**当地时间3月9日，微软宣布推出全新智能体Copilot Cowork。据介绍，该智能体采用Anthropic的Claude模型作为推理引擎，并使用与Anthropic Claude Cowork相同的智能体管控框架，让AI模型能够调用其他软件工具并为其运行设置安全边界的系统。微软表示，Copilot Cowork是其首个能在Outlook、Word、Excel、PowerPoint中直接执行任务的智能体，旨在处理长时间、多步骤的复杂任务，例如，仅通过一条指令就能完成客户会议筹备：制作演示文稿、汇总财务数据、向团队发送邮件、安排准备时间等。
