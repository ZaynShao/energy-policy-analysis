# 辽宁葫芦岛发生疑似液化气泄漏闪爆事故，致3人失联，正在全力联系和搜救中

辽宁葫芦岛发生疑似液化气泄漏闪爆事故致3人失联。
记者从辽宁省葫芦岛市消防救援局获悉，6月29日7时11分，葫芦岛市消防救援局指挥中心接到报警，位于葫芦岛市南票区九龙街道兴北社区一居民楼3单元发生疑似液化气泄漏闪爆。指挥中心立即调派95名消防救援人员、14辆消防车赶赴现场处置。
目前，事故导致3人失联，正在全力联系和搜救中。8人轻微伤，已送至医院救治。事故原因正在调查中。
