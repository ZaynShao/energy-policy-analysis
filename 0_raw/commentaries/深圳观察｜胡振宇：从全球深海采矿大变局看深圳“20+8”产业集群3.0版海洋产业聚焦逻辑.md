# 深圳观察｜胡振宇：从全球深海采矿大变局看深圳“20+8”产业集群3.0版海洋产业聚焦逻辑

//我国自主研制的深海重载作业采矿车工程样机“开拓二号”海试现场。（新华社无人机照片）
全球新能源转型催生钴、镍、锰、稀土等关键矿产刚性需求，陆地资源储量稀缺、供应链地缘风险持续走高，深海多金属结核、富钴结壳成为各国博弈核心战略资源，深海采矿由此从实验室技术攻关升级为大国竞争前沿赛道。
美国依托单边国内法绕开国际海底管理局（ISA）、联合盟友构建排他矿产供应链，在国际海底与太平洋岛国两大战线同步布局；欧、日、加加速海试验证、抢占矿区勘探先机，全球深海采矿进入规则博弈、技术竞速、产业落地三重叠加大变局。
上海、青岛、天津深耕国际航运、海洋造船、海工装备、海洋养殖等存量赛道，深圳最新3.0版“20+8”产业集群进行精准对焦，将深海采矿列为未来产业核心突破方向，依托招商局、中集、汇川等开采装备产业链龙头，叠加电子信息、高端工控等本土长板，锚定“深海进入—深海探测—深海开采”国家三步走战略和开采环节“少量试采—量化试采—商业化开采”三阶段实施路径，打造深海采矿产业高地。
全球深海采矿大变局：大国双线竞速，三阶段竞争全面拉开
（一）国家顶层战略框架：两大三步走体系
1. 国家深远海开发总路径：深海进入—深海探测—深海开采
深海进入是基础，依托深潜、大洋钻探船、无人潜航器突破万米极端海域作业门槛；深海探测是源头，完成海底资源普查、靶区圈定、生态本底监测，锁定可开采矿区；深海开采是目的，实现集矿、输送、海面分选全系统工程化落地，是转化深海资源价值、保障关键矿产自主可控的载。三大环节环环相扣，缺一不可，共同构成我国经略深蓝完整技术与产业链条。
2. 深海开采落地实施细分路径：少量试采—量化试采—商业化开采
少量试采：百公斤至吨级海试验证，仅验证装备基础行走、采集、输送功能，我国2024年招商局6000米海试采集3吨多金属结核，处于该阶段；
量化试采：千吨至万吨级连续长周期海上作业，验证系统稳定性、开采效率、生态扰动控制，加拿大TMC、比利时GSR已完成4500米量化试采；
商业化开采：年产百万吨级常态化运营，匹配全球矿产市场供给，当前全球暂无国家实现，预计2028—2030年进入首批商采窗口期。
（二）全球主要国家深海采矿关键进展对比表（2017—2024）
（三）ISA与美深海博弈及我国应对
ISA遵循《联合国海洋法公约》“人类共同继承财产”原则，实行协商一致决策、保留区、国家担保三重机制，但规则谈判长期僵局。刚刚结束的ISA深海采矿谈判再次无果而终，监管框架仍遥遥无期。
美国未加入公约，出台国内法单边发放采矿许可，2025年4月24日，特朗普签署第14285号行政令《释放美国近海关键矿产与资源》，授权NOAA向本国企业颁发国际海底区域采矿许可证，制度性绕开ISA审批流程，挑战以《联合国海洋法公约》为核心的多边治理体系。
在此形势下，深海采矿不再单纯是产业赛道，而是事关关键矿产安全、国际海洋规则话语权的战略抓手，也是沿海城市差异化竞争的核心突破口。我国手握5块国际海底勘探矿区，数量全球第一，但受多边决策机制约束，商业化推进节奏受限，需要在国际海底和岛国专属经济区双向发力，技术地盘岂能缺位！
深圳“20+8”产业集群3.0版未来产业：海洋产业表述从泛化到聚焦深海采矿
（一）“20+8”产业集群海洋产业表述迭代对比
1. 2.0版：未从海工装备拎出深海装备
在未来产业保留深地深海大类，但水下机器人、深海开采装备统一归入海工装备，未将深海采矿独立拎出；深海矿产开发作为海工附属分支。
2. 3.0版：深海采矿列为未来产业一级目录
构建“战新海洋稳底盘、深海采矿拓增量”双轮结构。
存量层（战略性新兴产业・海洋经济）：做大海洋油气、绿色航运、船舶制造、海洋电子、远洋渔业等成熟业态，稳定海洋经济基本盘，筑牢现有产业基础；
增量层（未来产业单列）：首次将深海采矿、可燃冰单独列为攻坚赛道，配套深海采矿装备制造、海底资源冶炼、深海环境保障完整项目清单，纳入市级重大工程、“十五五”专项规划，产业基金、试验海域、产业用地定向供给，实现资源集中投放。
（二）核心表述变化体现聚焦、具象、前瞻升级
变化一：赛道做减法，放弃同质化近海内卷
对比青岛、天津、舟山主打近海造船、海上风电、滨海养殖，3.0版主动弱化深圳无优势的海洋业态（普通水产粗加工、小型滨海文旅、近岸小型船舶维修），政策资源向深海采矿、水下智能装备、海洋信息三大长板赛道集中，避开国内城市红海竞争，打造产业标识。
变化二：目标具象，项目化替代模糊定性
1. 指标量化。2030年深海采矿配套产业增加值设置硬性突破目标，同步规划少量试采、量化试采、商业化分阶段时间表，匹配6000米采矿系统迭代计划；
2. 项目清单化：配套招商局深海采矿保障基地、深海采矿整机产业园、深海环境监测验证场、海底矿产中试冶炼基地四大实体载体；
3. 产业链具象化：完整梳理采矿车、海底混输管道、深海电机、湿插拔连接器、深海环境监测设备全链条招商目录，精准补“卡脖子” 零部件短板。
变化三：重心切换，从通用海工转向资源开采全链条
前两版产业集群政策海洋部分重心集中在近海船舶、风电装备等海洋装备，3.0版切换赛道主线，将深海采矿资源开发作为蓝色新质生产力主抓手，依托深圳产业禀赋形成竞争优势。
1. 工程龙头壁垒：招商局2024年完成国内唯一6000米级深海采矿系统全链路海试，具备整机设计、总装、海上试验完整能力；
2. 配套产业全域覆盖：汇川深海电控、中集深海平台、潜行/鳍源水下机器人、光峰深海光学、金信诺水下通信构成完整配套，深圳电子信息、工控、新材料产业可全链条下海赋能采矿装备；
3. 湾区协同得天独厚：形成“南沙探测、南山开采”广东深海“梦之队”分工格局，广州广海局“梦想号”完成资源勘探、靶区锁定，深圳承接装备制造、海试验证、工程化落地，形成探采一体化闭环。
（三）深圳聚焦深海采矿底层逻辑
1. 资源安全逻辑：破解关键矿产对外依赖
新能源电池所需钴、镍、锰、稀土对外依存度超85%，陆地矿产集中在刚果、印尼等单一国家，地缘扰动极易造成供应链断裂。太平洋CCZ区多金属结核钴储量为陆地4倍，深圳打造深海采矿产业，可构建国内自主矿产供给第二曲线，落实国家资源安全战略。
2. 错位竞争逻辑：避开传统海洋赛道内卷
上海、青岛、天津依托深水岸线、老工业基地，深耕造船、近海风电场。深圳陆域、近海岸线稀缺，传统海洋产业无规模优势，但拥有深海采矿全产业链龙头与电子信息配套长板，布局深海采矿赛道可形成全国差异化海洋核心竞争力。
3. 新质生产力逻辑：陆海产业双向循环
深圳陆上芯片、伺服电机、特种合金、人工智能产业全部可向深海采矿转化。深海采矿极端环境需求反向牵引陆上高端制造迭代，形成“深海需求牵引陆上科创、陆上产业支撑深海工程”双向新质生产力循环，区别于其他城市单一海洋制造模式。
广深“南沙探测+南山开采”协同：深圳深海采矿产业实施核心载体
（一）广州南沙：全国深海探测科学源头
广州海洋地质调查局作为国家队，运营万米级“梦想号”大洋钻探船，具备全球顶尖海底资源普查、靶区圈定、深海生态本底调查能力，所有深海开采项目以南沙探测数据为前置基础。广东智能无人研究院构建海斗、海星全谱系潜航器，完成开采前期地形、资源勘察，为深圳采矿装备海试划定作业海域，实现“探得准、采得成”无缝衔接。
（二）深圳南山：全国深海开采工程化高地
1. 链主企业支撑：招商局工业是国内唯一完成6000米采矿系统海试企业，未来将通过集矿机、矿浆提升、海面分选全系统技术实现量化试采，规划深海采矿两船一基地重大项目；
2. 配套集群完整：中集模块化海上采矿平台、汇川深海专用变频驱动、深海智人作业机器人、天海防务辅助船舶、佛山照明万米深海照明形成上下游完整配套；
3. 产业服务完善：深圳拥有前海船舶租赁、海洋产业基金、国际海事仲裁中心，覆盖深海采矿投融资、保险、法律、运维全链条高端服务业，弥补国内深海产业服务短板。
（三）双城协同闭环价值
南沙负责基础科学、资源勘探、环境评估，深圳负责装备研发、系统集成、海上试采、商业化运营，打通“科学发现—装备制造—海上开采—矿产加工”完整产业链，广东可成为全国唯一具备探采一体化能力省份，深圳作为开采核心承载区，可成为全省乃至全国深海采矿产业承载地，这也是“20+8”3.0版聚焦该赛道的基础。
