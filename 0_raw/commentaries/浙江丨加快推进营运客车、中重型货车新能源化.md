# 浙江丨加快推进营运客车、中重型货车新能源化

《规划》明确：
优化交通装备结构：加快推进营运客车、中重型货车新能源化，基本淘汰国四排放营运货车。完善机动车维修危废回收协同机制，推进新能源汽车维保体系建设。
杭州市：加快绿色低碳转型，推进车辆更新和新能源化，加快新能源重卡在干线运输等环节的规模化应用，力争建成具有全国影响力的跨区域新能源重卡运输廊道。
宁波市：推动交通运输绿色低碳转型，推动城市新能源公交车比例达到100%（应急保障和特殊需求除外）。
温州市：积极开展运输装备迭代升级，推广新能源车辆。
湖州市：推进在固定运输线路、港口集疏运等场景优先应用新能源重型货车。完善新能源汽车保障体系。持续推进国家级车联网先导区、智能网联汽车“车路云一体化”试点建设，探索无人公交、自动驾驶网约车等应用。
嘉兴市：优化交通运输结构，推广新能源营运货车等绿色交通运输装备。
金华市：拓展交通产业，培育新能源汽车及配件产业等领域龙头企业。
衢州市：加快交通运输设备更新，推广新能源重卡。推进普通国省干线服务站充电设施全覆盖。
