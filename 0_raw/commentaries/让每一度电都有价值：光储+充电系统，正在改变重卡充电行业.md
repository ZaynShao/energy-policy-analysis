# 让每一度电都有价值：光储+充电系统，正在改变重卡充电行业

这几年，充电行业已从“跑马圈地”的野蛮生长阶段，向精细化运营阶段蜕变。当充电站的每度电都要精打细算，供电链路和能量效率就至关重要。在今年上海充换电与光储充展上，相比往年各家企业集中展示大功率充电桩、液冷终端和充电模块，星星充电、安世博等多个企业推出了“高低压一体化充电箱变”，将高压舱、变压舱、低压舱、充电主机四大功能区重新优化集成，系统效率显著提高。传统“箱变与充电主机”分体布置的方案，存在电缆长，损耗较高、占地面积大、施工周期长等痛点，再加上光伏、储能，接口越来越多，系统越来越复杂，综合效率并不高。高低压一体化充电箱变，究竟改变了什么？为何对重卡充电如此重要？山西运城一座新能源重卡充电站给出了答案。过去，一座传统重卡充电站的供电链路非常长。电力从10kV中压电网接入后，需要依次经过中高压配电柜、工频变压器、低压配电柜、整流功率柜等多个环节，最终才能输出直流电给车辆充电。这种架构沿用了多年，在百千瓦级充电时代并没有太大问题。但随着重卡充电功率不断提升，MW级场站逐渐成为主流，传统方案的不足开始越来越明显。首先是设备分散，占地面积大，需要建设独立配电房，土建投资高，施工周期长；其次是供电链路过长，每增加一级变换都会带来一定能量损耗，系统综合效率受到影响。此外，大功率充电意味着低压侧电流越来越大，大量铜排、电缆不仅成本高，而且施工复杂，后期扩容也十分困难。正是在这样的背景下，高低压一体化充电箱变开始进入市场。它将高压柜、变压器、低压柜、整流系统等设备全部集成到同一个预制化箱体中，解决了上述一系列问题。近日，高工储能调研了山西运城聚通重卡超充站，集“光伏+储能+充电系统”于一体。这个重卡充电站一期建设了3.6MW分布式光伏（自发自用、余电上网）、100MWh储能系统、50台商用充电桩，配套30000KVA变压器，于2025年四季度建成，二期站点建设了42个充电枪、21个重卡充电车位，并采用3套星星充电星纪元A 2.4MW中压直挂充电系统系统，内置2500KVA移相变压器。如果说传统高低压一体化箱变的创新在于把设备集成到一个箱体，那么星星充电这个充电系统进一步创新的是重构电力变换架构，真正突破了传统方案效率的瓶颈。依托自研PSS移相赋形、DPA功率池打造的星纪元A中压直挂充电系统一站式解决方案，在保证电气隔离和电能质量的同时，减少多级电力转换带来的能量损耗，使充电系统最高效率超过97.5%，场站运行效率达96%。整站效率达到96%，比传统方案提升了4个百分点，这就意味着这个重卡充电站每年能够节省电费超过20万元。同时，这个充电系统的体积还比传统的箱充一体减少了30%，大幅减少占地面积和施工成本。随着新能源重卡迈向兆瓦级充电，大量重卡车辆集中补能，使重卡充电站逐渐成为大型工业负荷，对电网的影响远高于普通乘用车充电站。这就要求充电设备不仅要具备高效率，还要具备良好的电能质量控制。相比起传统高低压一体化箱变采用干式变压器的方案，星星充电星纪元A中压直挂充电系统依托移相变压器优化整流架构和波形控制，将系统总谐波畸变率（THD）控制在5%以下，在保证大功率输出的同时大幅减少对电网和园区设备的影响。与此同时，另一条技术路线——固态变压器（SST）也在快速发展。相比传统工频变压器，SST能够实现中压交流输入、低压直流输出的一次变换，系统效率可提升至98.5%以上，同时体积更小，更容易实现光伏、储能、充电以及V2G的直流耦合。目前，为光能源、星星充电等企业均已推出相关产品或解决方案。虽然SST距离大规模商业化还有一定距离，但业内普遍认为，它代表着下一代超充基础设施的发展方向。如果说充电系统解决的是建站效率和综合能效问题，那么光储充解决的是电力获取和用电成本的问题。过去几年，光储充一体化更多出现在乘用车充电站，但真正能够把经济账算清楚的，反而是重卡场景。主要原因在于三方面：一是重卡充电站的用电规模远远高于乘用车充电站，对电费成本更敏感。一座年耗电量超过1000万千瓦时的中型重卡充电站，电价每降低1分钱，每年都意味着十万元的成本节约。二是重卡运营场景相对封闭，充电需求稳定，车辆通常在固定时间集中回场充电，具有明显的集中补能特点，仅依靠光伏瞬时发电难以覆盖充电负荷，因此储能成为提升能源利用率的重要环节。三是重卡充电频次高、可预测性强，意味着投资回报周期短，场站收益的预期明确，对光储充一体化的投资意愿也更强。加上光储充一体化能够减少重卡集中充电对电网的冲击，这也是国家政策支持和加强补贴的重要方向。相比乘用车光储充电站，重卡光储充电站的经济模型更容易跑通，也更容易形成稳定收益。光储+充电系统的价值也因此进一步凸显出来。由于EMS、功率池、整流系统全部集成在同一个平台，它能够直接接入光伏和储能，实现发、储、充统一调度，根据实时负荷自动优化能源流向，实现光伏优先消纳、储能削峰填谷、充电功率动态分配等功能。过去的光储充，更像是三套设备简单组合，而如今的光储充，需要真正实现系统级一体化。山西运城聚通重卡充电站的运营相关负责人表示，这个场站将结合原有的LNG加气站，打造成一个“光储+充电+加气”为一体的“综合能源岛”。事实上，充电行业已经经历了三个发展阶段：第一阶段，比拼有没有站；第二阶段，比拼有没有液冷超充、兆瓦超充；而现在，行业进入第三阶段，比拼的是能源效率、运营成本和全生命周期收益。得益于光伏储能+低电损带来的成本优势，这个重卡充电站，60%充电需求来自自有车队，其余40%来自外部车辆，目前充电服务费定价0.2元/kWh，而周边场站服务费大约在0.23-0.25元/kWh。在光储+充电系统降本的基础上，未来重卡充电站还将通过虚拟电厂创造更高收益。充电负荷本身可调节性较强，尤其是叠加光储的重卡充电站，将成为虚拟电厂的优质调节资源，从车辆补能设施转变为集充电、绿电交易、需求响应、V2G等多种功能的区域能源枢纽。充电站运营商的收入来源，也将从单一充电服务费，逐步扩展到多个维度。未来，决定一家充电运营商竞争力的，不是谁拥有更多充电桩，而是谁拥有更低的度电成本、更高的能源利用效率，以及更强的“发、储、充、售、调”一体化能源运营能力。本文属高工储能原创，转载请联系（微信号：15019438102）获得授权。
