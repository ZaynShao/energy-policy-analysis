# 以色列发动打击

以军称打击黎南部真主党目标。
以色列国防军6日发表声明说，以军在过去24小时内对黎巴嫩南部的真主党目标实施了打击。
▲资料图。图源：央视新闻客户端
声明称，以军打击目标包括黎南部多个地区的真主党基础设施、武器储存设施和军事指挥中心等。
声明说，5日，一名以军预备役少校和一名预备役军士长在黎南部地区一起爆炸事件中死亡，另有4名以军士兵受重伤。以军过去24小时对黎南部真主党目标的打击是对该事件的回应。
声明还说，以军部队目前仍根据相关协议部署在黎南部“安全区”，并将继续采取行动，消除针对以色列平民和以军士兵的威胁。
