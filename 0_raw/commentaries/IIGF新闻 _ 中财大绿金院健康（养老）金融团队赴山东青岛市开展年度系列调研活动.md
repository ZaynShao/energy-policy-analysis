# IIGF新闻 | 中财大绿金院健康（养老）金融团队赴山东青岛市开展年度系列调研活动

近日，中央财经大学绿色金融国际研究院健康（养老）金融实验室主任任国征带领调研组赴山东省青岛市开展年度综合系列调研，以更好完善及修订年度报告。实验室助理、西安交通大学马克思主义理论博士生吴曼丽，实验室助理、北京大学外国语学院博士生张涵静，实验室专家、中国海洋大学马克思主义学院教授蔡勤禹，实验室成员、山东大学政治学博士生臧玲分别参加相关环节的调研考察。
在青岛调研期间，任国征应邀出席了中央社会主义学院主办的中国政党制度研究中心第二十四届年会暨中国新型政党制度理论研究基地（中央社院）理论研讨会，中国海洋学会牵头组织的海洋中药发展大会，青岛科技大学等单位主办的“铸牢中华民族共同体意识”学术研讨会，青岛日报主办的“‘中国康湾’新生态 重构地产新价值”圆桌论坛暨青报智库“青梅集”沙龙。调研组围绕绿色文旅发展、健康文旅服务、文旅资源开发、旅游融资扶持专题调研时，实地考察了大鲍岛文化休闲街区、中山路历史文化街区、青岛奥帆海洋文化旅游区、“丝路千古情”文旅演艺公园，参加了多场文化节、特色啤酒节、博览会等，并观看了《寻梦沧海》演出、2026：南区老字号嘉年华，实地体验特色夜游产品。听取了关于绿色文旅发展中的业态培育、商业布局、园区运营、融资支持、可持续发展的情况介绍。调研组认为，青岛市绿色文旅发展资源丰厚、经验突出，尤其是打造演艺精品，与金融部门、商业载体协同联动推出精品旅游线路，促进文商旅体深度融合，绿色旅游依托青岛海洋文化、上合地域文化、丝路开放文化创造性车技术性呈现，赋能全市绿色文旅提质增效。智慧养老和养老金融港也是调研组本次系列调研的考察重点。青岛医工融合起步较早，调研组重点走访和了解了康复大学青岛中心医院开设全省首个脑机接口门诊、青岛市市立医院开展非侵入式脑机接口康复训练和闭环脑起搏器手术、青大附院设立脑机接口与神经调控多学科门诊及研究型病房等情况。调研组随后详细学习了解青岛唯政府指导的城市定制型医疗保险“琴岛e保”的“降门槛、优保障、扩A+范围”典型做法。考察了为终末期患者提供专业、规范、优质、暖心的个体化疗护服务的青岛市公共卫生临床中心沐慈疗护中心，认真学习了其运用智能精准补齐生命末期健康服务的情况。调研组通过实地学习考察认为，青岛市加快推进医工交叉融合创新，推进手术机器人、脑机接口等成果临床转化，同时创新适配科技金融产品，助力“中国康湾”建设，值得进一步深入研究并形成专题调研报告。任国征表示，实验室曾多次赴青岛调研，并形成调研报告（《IIGF时评 | 山东青岛市健康食品产业的发展经验与政策建议》，2022年6月9日）。青岛是联合国评选的中国最宜居城市之一，也是新中国疗养事业的重要发祥地，享有“滨海疗养胜地”和国际滨海旅游度假目的地等美誉。国家《旅游强国建设“十五五”规划》中3次“点题”青岛在城市旅游、海洋旅游、入境旅游等领域的成绩探索，《青岛市加快推进“中国康湾”建设三年行动计划(2025—2027年)》中明确提出建设具有国际影响力的“中国康湾”。这次调研收集的这些先进理念和政策措施，以及青岛发展绿色文旅和智慧康养的典型做法，深具推广价值和学理意义，实验室将据此再进一步完善今年的年度报告。据悉，中财大绿金院今年将在即将举行的年会上公开《2026健康金融报告（绿色文旅专题）》和《2026养老金融报告（地方数智专题）》，并同期刊出第十版《健康（养老）金融目录集（2018-2026）》。此前已经发布公共卫生、红色文旅、冰雪前沿、中医中药、茶叶发展、食品安全等六个以健康产业为研究对象的年度健康金融报告，金融工具、服务体系、前瞻规划、案例剖析、社会保障、数据要素、国外借鉴等七个以养老要素为研究对象的年度养老金融报告，初步形成了健康与养老交叉、理论与实践结合、调研与文献并重、专题与系列呼应、数据与案例互证的智库报告发布体系。
