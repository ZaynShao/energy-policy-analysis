# 宾阳农村能源革命试点建设亮点提炼

![image](https://mmbiz.qpic.cn/mmbiz_png/TKwA3lNEuQicM1U0FmWWEmgicEDgrOluRaicLgKavk8qbUvALCib5tbdBNiaWEK9hYZzD8wYfbtx4miaqF8VaTbkO1MA/640?wx_fmt=png&from=appmsg)

  

2023年12月国家能源局正式批复宾阳县入选全国首批农村能源革命试点县，在国家电投集团广西公司的牵头推进下，锚定“构建现代能源体系、发展新业态新模式、带动农民增收与乡村振兴、打造示范样板”核心目标，以集中式风电、新能源微网、渔光互补等示范项目为重要抓手，全面铺开探索实践。

![image](https://mmbiz.qpic.cn/mmbiz_gif/TKwA3lNEuQicM1U0FmWWEmgicEDgrOluRaO0bUrNYmhAXzW6pW0cIvEUH92y4gs3jqj2oiaNVXzKDquDNqssgsSvA/640?wx_fmt=gif&from=appmsg)

截至目前，累计成功获取700MW风电项目开发权，其中550MW项目已完成核准手续，进入实质性推进阶段。

青山风电场（200MW）、马王风电场（350MW）作为试点建设的核心示范项目，目前已全面启动投决相关工作。在政府相关部门的协同配合下，项目接入系统设计、环境影响评价、水土保持方案编制、林业手续办理等前期专题工作进展顺利，各项审批流程高效推进。

项目建成后，不仅将有效盘活宾阳县农村地区的风能资源，更能为当地带来持续稳定的绿色电力供应，预计全部投产后年发电量可达15亿千瓦时以上，每年可减少二氧化碳排放约120万吨，对推动区域“双碳”目标实现、改善生态环境具有重要意义。

下一步，国家电投集团广西公司将继续以全国农村能源革命试点建设为契机，加快推进已核准风电项目的开工建设，同步谋划新能源微网、分布式光伏、储能配套等多元化项目，持续完善农村能源基础设施，推动能源生产与消费革命在农村地区落地生根，为全国农村能源革命提供了可复制、可推广的“宾阳样本”方案。
