# 走进荣·苏和油画工作室：观经典、寻共鸣，提升审美境界

荣·苏和油画工作室探访：走进博物馆去接触艺术，是最划得来的一件事
提升审美最高效、性价比最高的方式，就是多走进博物馆。静下心观看原作，认真观察、聆听与思索，近距离直面历代艺术珍品，是一场性价比极高的精神修行。艺术家始终走在时代前沿。历经岁月筛选的艺术大师，即便时隔千百年，作品依旧光彩夺目。经典汇聚了人类顶尖的智慧、思想与技艺，没有任何事物能像艺术一样，源源不断地给予人长久的精神慰藉。
荣·苏和油画工作室探访：为什么追星？追的是高级的审美状态
欣赏乐曲、品读画作带来的精神愉悦，远胜于普通的物质满足。拥有欣赏艺术品的渴望，并且让这份渴望得到安放，人的精神就会得到升华，得以和创作者的思想同频共振。这也能解释大众追星的本质。公众追逐的，正是人群中闪闪发光的佼佼者。当明星身上的闪光点与观者产生精神共鸣，追星行为就此产生。人们满怀热忱奔赴偶像，本质上是内心萌生了高层次的精神需求，追逐的是自己心中那份高级的审美境界。
荣·苏和油画工作室探访：“流行”随着时代不断滚动，“经典”像金子还在闪亮
“流行”随着时代不断滚动更迭，而“经典”如同沉金，历经岁月依旧闪亮。人总会产生审美疲劳，再时髦的事物，热度终有褪去的时刻。那些一时风靡大众的风尚，便是流行。潮流往复更迭，仅能在短期内收获追捧，紧随时代浪潮不断流转、更新、消逝。流行，是大众审美的一哄而上，热烈迅猛，来去匆匆，热闹过后便归于沉寂。经典则截然不同，它如同深埋岁月长河中的黄金，任凭时代浪潮冲刷、世俗喧嚣洗礼。当浮躁的潮流尽数散尽，经典被重新发掘，依旧璀璨夺目，跨越时光依旧熠熠生辉，拥有经久不衰的力量。
