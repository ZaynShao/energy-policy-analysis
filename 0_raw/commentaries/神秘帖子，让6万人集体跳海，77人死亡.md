# 神秘帖子，让6万人集体跳海，77人死亡

跟其他数万同胞一样，她急速跃入眼前的地中海，再也没有上岸。跟不少同胞一样，这一天，成了她的忌日。
对于法滕·本·奥马尔·阿齐兹来说，失去生命的这一天，刚好也是她的西班牙签证获批的一天。据摩洛哥媒体报道，这名20岁的女足球员此前多次申请西班牙签证均被拒绝；批准文件签发时，她正在海里挣扎，消息再也没能传到她耳边。
法滕是摩洛哥北部女足圈里小有名气的“战斗者”：她在马格里布得土安竞技忠诚效力数个赛季，新近才转会丹吉尔马格里布竞技。得土安俱乐部的悼词说，“她寻求的并非名利或冒险，而是一种更好的生活，一个她相信在边境另一边等待她的未来”。8月1日，大批得土安市民为她送葬，葬礼视频在摩洛哥社交网络上广泛传播。
法滕·本·奥马尔·阿齐兹
在7月底那场罕见的难民潮中，法滕是最为人知的一个受害者。
在7月30日至31日，约5万至6万名摩洛哥人毫无征兆地冲向跟摩洛哥本土接壤的西班牙飞地——休达。这里总面积只有18平方公里，却突然涌入数万名摩洛哥人，这在西班牙乃至欧盟层面引起了恐慌。
截至8月5日，西班牙宣称，大部分进入休达的摩洛哥人已经被遣返，西班牙和摩洛哥两国共确认了77名遇难者，但仍有更多失踪人员有待确认。
突如其来的难民潮，背后却是社交媒体上精心编造的帖子——它们诱导数万人扑向大海，其中77人再也没能上岸。而摩洛哥边防警察的一反常态，更让这次难民危机疑点重重。
8月1日，在西班牙飞地休达，从摩洛哥入境的非法移民被护送离境 / 图源：新华社
危机持续的时间并不长，但它引起的社交媒体狂欢和阴谋论，却席卷了全球网络平台。
这背后到底发生了什么？
人贩子操控？
今年7月8日，西班牙最高法院公布一则裁定：在海上被拦截、试图游泳进入休达和梅利利亚（西班牙另一处飞地）的人，不能被即时遣返，必须走完整的遣返程序；若提出庇护申请，则须先予审查。
不到一个月，这个裁定被别有用心之人扭曲利用，成了数以万计摩洛哥人扑向大海的导火索。在Instagram和X等各种平台，“游泳入境就不会被送回”等暗示性的帖子大量出现。
在YouTube平台上，“M News Pakistan”等账号大量转发的视频中，一个泡在海里的男子，举着自拍杆边游边拍，标题醒目写着：“自拍杆记录非法入境实况！摩洛哥移民到达了休达海岸。”
还有一些类似的视频：游泳“抵达”休达的人们，在岸上比出胜利手势庆祝。还有人分享休达周边的地图、卫星图像，以及游泳路线。一些帖子则鼓励年轻人结伴而行，组成至少七人的游泳小组，以降低个人风险，也让边境巡逻队更难拦截。
社交媒体上发布的海滩视频截图，视频里出现了不少准备游泳“抵达”休达的人们
这些视频，几乎都在暗示：从摩洛哥游泳到休达，是很容易的事情。效果也立竿见影——摩洛哥网络社区很快掀起一股怂恿偷渡的狂欢。到了7月底，数以万计的摩洛哥年轻人来到面向休达的海滩，纷纷跃入海中。
但跳海的人们不曾想到，要抵达休达彼岸，需要游完约5公里长的海路。很多人体力不支；不熟悉水性的人则被海浪越推越远。
尽管海路凶险，最终仍有超过5万名摩洛哥人成功进入休达。他们中的不少人，并非游泳抵达，而是绕行塔拉哈尔防波堤、翻越陆地边境围栏进入的。只有8.3万常住人口的休达，开始招架不住。
然而，并非所有人都那么“幸运”。直到现在，依有不少人在海上不知所踪。数以百计找不到亲属的摩洛哥人聚集在边境关卡，等候亲人的消息。“我们不知道他在哪里，也不知道他是否安全，是否被送往医院、被拘留，还是发生了其他情况，”一名亲属告诉守候在当地的媒体。
8月5日，在西班牙休达，来自摩洛哥的未成年移民在一处作为临时落脚点的墓地内休息 / 图源：新华社
根据休达当地政府的预估，约有800名未成年摩洛哥人下落不明。
难民大量涌上海滩的画面，以及大量鞋子、救生圈和各类私人物品被冲上岸的画面，开始出现在新闻报道中。
至此，这场风波的诡异之处，才开始被媒体和官方机构正视。到底是谁，操控了这突如其来的大规模越境潮？
人贩子集团最先被怀疑。
8月2日，国际安全观察站联合主任何塞·玛丽亚·希尔·加雷发布了一份70页的调查报告，试图还原这场网络动员的时间线。早在7月8日的判决公布当天，阿尔及利亚、突尼斯、法国乃至美国的一些账号，就开始发布“简化、去语境化”的判决解读。
8月1日，在西班牙飞地休达，西班牙士兵盘问一名从摩洛哥入境的非法移民 / 图源：新华社
一周后，Facebook群组开始交换路线、班次等实用信息。7月25日，游泳路线图、下水点、距离、基本建议开始流传。甚至有账号喊出“烧毁休达边境”的动员口号。其中，数十万粉丝的大账号发挥了关键作用，累计触达超过千万人次。
报告认为，这是一个分阶段推进的过程，符合有组织操盘特征，绝非纯粹的草根自发。
7月30日，西班牙内政部声明称，有组织贩运网络“工具化”了最高法院的判决，向摩洛哥年轻人兜售“游泳抵达就能留下”的假信息；8月2日，摩洛哥内政部也确认存在一场网络虚假宣传运动，把人口贩运网络列为推手之一。但耐人寻味的是，两国政府在提出指控时，都没有拿出任何证据。
而西班牙网络媒体Vozpópuli则报道，西班牙警方情报部门其实一直在监控这些群组，却没能阻止。
8月1日，在西班牙飞地休达，西班牙国民警卫队成员看守从摩洛哥入境的非法移民 / 图源：新华社
人贩子用社交媒体揽客，确实是惯用手法——欧洲刑警组织早有记录，走私集团在公开平台打广告，再把交易转入私密通讯软件。休达路线上也确有成熟的走私产业：西班牙警方2025年6月刚破获一个网络，用快艇和“游泳向导加水下推进器”送人过境，全程收费最高1.46万欧元，至少运送了200人。
但这也暴露了逻辑上的悖论：人贩子卖的是“普通人过不去的便利”，当谣言让人们相信边境洞开、游泳免费时，砸的正是他们自己的“饭碗”。
不过，进入8月，约50人乘快艇和水上摩托从休达渡海前往西班牙本土，单程收费4000至6000欧元——这成了本次危机中唯一清晰可见的犯罪牟利环节。
难民武器化
另一些疑点，也浮现出来。
一些渡海者来到休达后告诉英国《卫报》，平时试图阻止他们的摩洛哥边防警察，这次不仅没有阻止，甚至还给他们指路。其他一些媒体也有报道，有的摩洛哥边防警察不但袖手旁观，还给出各种提示。
突如其来的难民潮，再加上摩洛哥警察的“异常”态度，是偶然，还是别有用心？一些声音便指责摩洛哥当局蓄意给西班牙制造混乱。
摩洛哥跟西班牙素来多有摩擦，2002年夏天，两国曾围绕一座地中海无人小岛爆发一场持续9天的武装对峙。而那场被称作“21世纪的西班牙微型战争”的对峙，就发生在休达以西仅数公里处。
7月31日，在摩洛哥北部边境城镇夫尼代格，试图非法入境西班牙飞地休达的人们与摩洛哥安全部队人员发生冲突 / 图源：新华社
另一边，西班牙政府也试图澄清，坚称责任全在人贩子，但这种声音几乎被淹没在各种阴谋论狂欢中。
休达危机的特殊之处，在于每一类人，无论其政治光谱几何，都能找到看似合理的解释。
对于民粹右翼政党来说，一场轰动性的难民危机，就是他们现成的政治弹药。西班牙右翼政党VOX党魁圣地亚哥·阿巴斯卡尔把摩洛哥人的渡海行为描述为“入侵和宣战”，并且指责西班牙首相佩德罗·桑切斯是幕后推手。
来自民粹右翼阵营的意大利总理梅洛尼则干脆宣布，暂停与西班牙之间的申根免签政策（意方未公布具体期限）。意大利和丹麦牵头22个欧盟成员国联署致函欧盟机构，要求协调加强外部边境管控，矛头直指未能处理好难民问题的西班牙当局。让西班牙这个目前为数不多由社民党执政的欧盟国家被邻国孤立，恰好迎合了某些国家和势力的利益。
意大利总理梅洛尼 / 图源：新华社
这场危机的余波，还席卷到了美国和以色列。
欧盟国家中，西班牙对美国的立场最为强硬：首相桑切斯曾拒绝美军使用其境内的罗塔和莫龙基地参与对伊朗的军事行动，宣称绝不成为“对世界有害之事的同谋”，自然也没给特朗普什么好脸色。那个口中威胁着“切断一切跟西班牙贸易往来”的特朗普，素来不加掩饰地将桑切斯视为眼中钉。对以色列，桑切斯同样强硬，称其在加沙的作为，是“种族灭绝”，并宣布对以武器禁运。
在支持巴勒斯坦的人士看来，“反美反以”的西班牙，自然是帝国主义阴谋中的受害者。巴勒斯坦裔美国作家苏珊·阿布哈瓦（Susan Abulhawa）便说，渡海潮“完全由美国、以色列和摩洛哥策划”，意在倒逼西班牙回到“西方帝国主义轨道”。
美国左翼网红哈桑·派克也公开宣称：“以色列和美国让摩洛哥政府把差不多4万人送进了西班牙管辖的领土，这甚至不是什么阴谋论。”“这是典型的以色列做派。”
这种观点颇有市场，X上那张爆火的漫画就是注脚：一艘外形酷似以色列总理内塔尼亚胡张大嘴部的船，在休达海滩边停靠；大量摩洛哥难民从内塔尼亚胡的嘴中走出，在休达登陆。
社交媒体上流传的图
以色列官方则反击，这是典型的反犹舆论战术。
一起诡异的边境冲击，就这样被全球各方势力用作武器，而到底谁在社交媒体煽动了这场风波，则无人关心。
“难民武器化”，指的是一国在对另一国施压时，把难民用作要挟工具的做法。美国政治学家凯利·M·格林希尔认为“难民武器化”可以达到这样的目的：把移民作为外交政策工具，迫使其他国家改变政策、作出让步。
在社交媒体氛围变得更加情绪化的今天，“难民武器化”趋势更盛，就连难民本身的影像和画面，通过被转发、围观和议论，都会变成二次“武器化”。
7月31日，一名来自苏丹的男子游泳进入西班牙飞地休达 / 图源：新华社
在今天，这种武器更被滥用。阴谋论者各取所需，政客们互相甩锅，平台的算法继续转动——而下一次”毫无征兆”的越境潮，也许只差一条新的爆款视频。
如今，休达的海滩暂时恢复了平静，但悲剧何时重演，没人知道。
联合国国际移民组织”失踪移民项目”的记录显示，2014年以来，全球有超过8.4万名移民死在迁徙路上，其中3.5万多人沉在地中海；2025年，平均每天有21人没能走完自己的路。
法滕的名字被记住了，是因为她会踢球；更多人的名字，只存在于海关的编号和家属的等待里。
