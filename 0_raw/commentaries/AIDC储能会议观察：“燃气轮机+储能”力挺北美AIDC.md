# AIDC储能会议观察：“燃气轮机+储能”力挺北美AIDC

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhItBtlGJ95r0bemU7qI250LySmvwwaeibs3u1ibMpLPjZCuvmlxhSKGpxVJMZ8xrFGwRHic5JNsLrJLP5KQnl0wa12aD4CBOuhAp6I/640?wx_fmt=png&from=appmsg)

在全球人工智能算力爆发式增长的浪潮下，北美数据中心正面临前所未有的电力危机。面对AI数据中心疯狂的电力消耗，美国开始要求各大科技巨头，新建数据中心必须自建电厂，自担新增用电带来的电网建设成本。目前，燃气发电是解决北美AIDC供电难题的首要方案。数据中心需要的是持续稳定电源，燃气轮机启动快、出力稳、调度灵活，可模块化部署扩建，建设周期较短，综合成本较低，完美匹配数据中心快速投运的需求，成为当前北美AI数据中心供电的首选。同时，北美天然气资源丰富、成本低廉，为燃气轮机发电提供了充足的燃料保障，Meta、微软等科技巨头纷纷布局自建燃气发电厂，美国在建天然气发电装机容量位居全球第一，超三分之一直接服务于数据中心。当前，全球燃气轮机市场被西门子能源、GE Vernova、三菱重工三大巨头垄断，但三巨头的产能已严重饱和，订单排期延至2028年以后，交付周期从2年拉长至5-7年。北美数据中心客户面临“有钱有需求却买不到货”的困境。这一市场真空窗口，也为具备技术与交付优势的中国企业打开了大门。杰瑞股份凭借多年油气装备领域的技术积淀，正快速抢占美国AIDC供电市场。2025年，杰瑞股份成立全资子公司杰瑞敏电能源集团，整合燃气轮机技术、模块化集成能力与北美本土服务体系，打造出专为数据中心定制的燃气轮机发电机组解决方案。从2025年11月斩获北美首单超1亿美元合同起，杰瑞股份势如破竹，五个月拿下六笔订单、服务五大客户，累计金额超11亿美元，约合77亿元人民币，交付排期从2026年底一直延伸至2028年。作为国内重型燃气轮机龙头企业，东方电气2025年也成功切入海外数据中心领域，2026年，东方电气与加拿大企业合作签订，向加拿大出口燃气轮机设备。不过，燃气轮机并非尽善尽美，单靠燃气轮机，在动态响应、冗余可靠性、电能质量、经济性等方面都有明显短板。因此，燃气轮机+储能的一体化供电方案，成为高端AI数据中心的优质选择。在美国田纳西州，马斯克为了给它的AI公司xAI打造超级计算机中心Colossus，就选择了这一方案。整个集群拥有250MW的算力负载，电力供应的核心是192MW的燃气轮机，并配合了总装机150MW的特斯拉Megapack储能系统。储能系统可以作为动态缓冲，平抑GPU满载时的功率波动，调节电能质量问题，也可以在数据中心低负载时充电，高负载时放电，让燃气轮机尽量平稳运行在最佳区间。而且，即使燃气轮机再稳定，也无法实现供电“0毫秒中断”，储能可以起到类似“超级UPS”的作用，在燃气轮机切换瞬间顶上，提供足够的冗余和可靠性。在燃气轮机业务爆发式增长的同时，杰瑞股份同步布局储能赛道，构建“燃气轮机+储能”的一体化解决方案，实现两大业务的深度协同，为数据中心提供更安全、高效、稳定的供电保障。具体来看，杰瑞敏电推出直流800V供配电架构解决方案，采用三级储能结构与固态变压器降压设计，实现高每瓦效能、高密度部署与高可靠性供电，精准适配高算力场景的供电需求。同时，杰瑞敏电自研的JCS1725 HB 1725kW集中式PCS，具备强大的构网支撑能力，采用虚拟阻抗控制技术，可有效降低源网谐振风险，与燃气轮机协同构建稳定的离网供电系统。此外，一体化移动储能也是杰瑞针对油田领域、绿电转移、应急抢险、大型会场保电、电网检修等无电网覆盖或应急供电场景推出的解决方案。在场景应用层面，杰瑞敏电还覆盖离网/微网发电、园区光储充、电源侧储能三大应用场景的成熟解决方案，形成覆盖全场景、全链路的储能产品矩阵，与与燃气轮机形成互补。这种“燃机做主供、储能做调节”的模式，既保证了电力供应的稳定性，又提升了能源利用效率，完美解决数据中心的供电痛点。随着AI算力持续增长，数据中心对电力的需求将长期保持高位，电网建设滞后的矛盾短期内难以解决，离网式自主供电成为必然选择。从行业趋势来看，燃气轮机+储能有望成为北美数据中心供电的主流方案。燃气轮机提供稳定基础电力，储能系统保障供电灵活性与安全性，二者协同构建的能源解决方案，兼具经济性、可靠性与高效性，市场空间广阔。
