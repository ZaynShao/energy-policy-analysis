# 重庆丨到2028年底车网互动规模化应用范围持续扩大

为落实相关文件部署要求，持续健全充电网络、提升充电效能、优化服务品质、创新产业生态，推动充电基础设施从“规模建设”转向“高质量发展”，让有路的地方都能实现高质量充电。结合工作实际，重庆市经济和信息化委员会等部门联合制定《重庆市电动汽车充电设施服务能力高质量发展行动方案（2026—2028年）》（以下简称《方案》）并于近日发布。
《方案》明确：到2028年底，在全市范围内累计建成75万个以上充电设施，其中超充站2500座以上，提供750万千瓦以上的公共充电容量，满足超200万辆新能源汽车充电需求。持续健全“中心城区面状覆盖、公路沿线线状互联、农村地区点状延伸、重点场景特色突出、居住社区智能安全”的高质量充电基础设施网络体系。
公共充电设施提质升级行动中，《方案》提出，到2028年底，在城市区域建设100座以上超充站，高速公路服务区新建100座以上超充站，在农村地区新建100座以上大功率充电站，在旅游景区建设50座以上超充站，居住区新建私人充电设施20万个以上。
电动重卡补能效率提升行动要求，到2028年底，全市新建电动超充重型货车大功率充电站100座以上，推广电动超充重型货车1500辆以上。
车网互动规模化应用推广行动要求，到2028年底，新建V2G项目10个以上、双向充放电（V2G）桩100个以上，放电100万千瓦时以上，车网互动规模化应用范围持续扩大。
在充电运营服务质量提升行动中，《方案》特别强调，要探索市场准入机制，加强备案管理，设立全市统一的充换电客户投诉服务电话，畅通咨询投诉渠道。
