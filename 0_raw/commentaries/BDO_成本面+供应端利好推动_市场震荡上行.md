# BDO | 成本面+供应端利好推动 市场震荡上行

**导语**

进入3月后，多套装置检修，供应端支撑增强。原料电石、甲醇上涨，成本面压力增加。同时线上竞拍至高位成交，供方挺市意向强烈，限制操盘空间。贸易市场操盘心态谨慎向好，下游刚需节奏跟进，市场重心区间上探。截至3月13日，华东市场散主流在7700元/吨，较3月初上涨4.05%。后期随着检修利好等逐步兑现，BDO市场上涨空间或有限。

**原料偏强运行，成本面支撑增强**

甲醇方面：以陕西关中价格为例，3月受中东冲突加剧、霍尔木兹海峡关闭，使得甲醇价格大幅上涨，自2月28日的1970元/吨，上涨至3月9日的2330元/吨。3月10日受原油大跌等带动，期货大幅回落对交投情绪拖累明显，关中地区价格下跌至2280元/吨，但依然远远高于2月。电石方面：以西北地区为例，电石市场价格先抑后扬，整体呈现触底回弹走势。在高位库存压力下，电石价格震荡下行至2250元/吨，创下近十年历史新低。但后来在成本与供需共振下，市场价格企稳回升至目前的2600元/吨，且后期仍存上行空间。综合来看，BDO短期成本增加，亏损压力加剧，刺激工厂挺市心态。

**检修消息逐步落地，供应端利好兑现**

3月检修消息逐步落地：华鲁恒升两套各12万吨装置2月底轮流检修，预计影响各20天。内蒙古君正30万吨BDO装置及下游12万吨PTMEG装置3月3日-20日检修。中石化长城能源一套年产10万吨BDO装置3月2日-8日更换催化剂，，目前已重启稳定运行。宁夏惟远12万吨装置3月9日检修，预计一个月。截至本周BDO产能利用率降至52.8%，但3月下旬，随着部分检修装置重启，BDO行业负荷预计将提高至58.5%附近。而4月东景生物、曙光、黑猫等存检修计划，短期供应端支撑仍存。

**下游整体开工下滑，刚需订单跟进**

PTMEG行业君正装置3月3日-20日检修；陕化装置3月5日停车，重启时间未定，行业产能利用率下滑至73.02%，对原料消化量缩减。4月君正装置重启，而晓星嘉兴一套5万吨装置计划检修一周，行业整体对原料需求增加。

PBT行业目前负荷在42.5%，属于偏低位置。随着PBT价格大涨后，终端对高价接受能力偏弱，实单跟进一般。浙江长鸿装置开工延迟；仪征化纤12万吨大线2月底检修，计划3月下旬恢复生产，预计后期PBT产能利用率提升有限，对原料BDO消化增量有限。

GBL-NMP行业价格虽跟着原料涨势上行，但成本向下传导不畅，下游实际需求偏淡，工厂开工积极性一般，原料刚需跟进为主。

PBAT行业产能利用率在19.67%附近，行情在成本带动下涨幅明显，但下游多消化原料库存，新单跟进一般，导致行业库存积累，部分装置存降负或停车预期，行业负荷存下滑预期，对原料BDO刚需采购。

聚氨酯领域TPU及PU浆料行业当前负荷在54-55%附近，且跟随原材料上涨行情宽幅走高，工厂开工热情尚可，但成本向终端下游传导不畅，新单跟进情况一般，因此原材料消化增量短期有限，继续消化库存或刚需现货采购。

出口方面：2026年4月1日起取消增值税出口退税，4月出口方面存缩量预期，压力将转移至内贸方面。因此4月供需差距或扩大，进而压制BDO走势。

综合来看，3-4月装置方面检修较多，货源供应量缩减。而下游行业需求较春节前明显增加，且一季度出口量大幅增加，行业处于有效去库状态。叠加竞拍价格不断推高，推动BDO市场震荡上行。但长期来看随着出口缩量，原材料大涨压制下游行业负荷提高，BDO行业供需差距或扩大，将限制BDO涨势。隆众资讯预计，短期BDO行业存继续上探空间，长期走势需关注供需端波动影响。
