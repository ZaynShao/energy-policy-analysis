# AIDC微秒级供电困局：锂电池追不上的缺口，电容来填

![image](https://mmbiz.qpic.cn/mmbiz_png/bhqZZ4eZhIvwLt8WmpzNTG6MicaHWQlAn2L583UxZVGdmRrJBBUCWC76w7p7zzkE5j7icOgiaVF3DJudLDsiag4qhfjahMUWEcTMXW5ykZO1Gc4/640?wx_fmt=png&from=appmsg)

当单个AI机柜功率从10kW跃升至100kW，并继续逼近1MW，一个更隐蔽但更致命的问题正在浮现：算力系统的用电方式，已经彻底变了。GPU不再是稳定负载，而是一个“电脉冲发生器”：微秒级突增、毫秒级震荡、秒级波动叠加。这种负载模式，正在冲击现有数据中心供配电体系的设计边界。这意味着：过去几十年构建的UPS+电池体系，正在失去对算力的控制力。于是，一个关键问题摆在行业面前：当算力进入微秒时代，谁来兜住这0.0001秒的电力缺口？答案，正在指向一个曾被忽视的技术：电容器。  
  

****兆瓦级机柜背后的瞬时功率黑洞****  
  
  

AI基础设施的演进，正在以远超预期的速度发生。当前，英伟达GB200 NVL72整柜功率已高达125-130kW，即将登场的GB300将提升至140kW，未来基于Rubin架构的VR200 NVL系列，以及基于Rubin Ultra架构的VR300 NVL系列，单机柜功率更是剑指1MW。这不是简单的用电变多了，而是系统性质的变化：AI数据中心，正在从“用电终端”演变为“高动态电力系统”。更关键的是负载特性发生了根本改变：GPU负载并非平滑变化，峰值冲击可在毫秒甚至微秒内完成，空闲与满载之间瞬间切换。AI数据中心的问题，不仅是缺电，更是来不及供电。这种瞬态冲击，对传统供电体系构成了前所未有的挑战。问题的本质，不在于总能耗，而在于时间维度被压缩。英伟达在《面向下一代AI基础设施的800V直流架构》白皮书中明确指出，GPU的峰值功耗与瞬时冲击持续时间在100毫秒，典型工作负载的空闲周期亦在此范围内，检查点保存可能需要1至5秒，整个工作负载的升降过程则需数分钟。100毫秒，意味机柜的功耗，要瞬间经历从近乎空载到满载的剧烈跳变。这种“瞬时功率黑洞”，是传统平滑供电架构的噩梦。如果无法有效平抑，会发生什么？轻则导致GPU降频、算力利用率损失，重则引发配电系统过载跳闸，造成训练中断和巨额经济损失。  
  

****微秒级时代，锂电池开始“跟不上”****  
  
  

  

过去几年，数据中心备电储能经历了一次重要升级：从铅酸电池向高倍率磷酸铁锂电池演进。对比铅酸，锂电池有更高的高能量密度、更长寿命、更低运维成本，其优势毋庸置疑，但问题在于，AI负载的“时间尺度”，已经超出了锂电池的舒适区。首先是响应速度。锂电池响应时间通常几十毫秒至几百毫秒，对于平滑秒级波动绰绰有余，但面对需要微秒级响应的动态功率波动，锂电池明显滞后，就如同用水桶去灭瞬间爆燃的火花。第二是功率密度。即便功率型锂电，400-500+ W/L的功率密度基本上已接近工程极限。在兆瓦级机柜功率密度下，若分配大量宝贵的机房空间给响应速度不够快的缓冲系统，正变得越来越不经济。第三是温度适应性和循环寿命。数据中心内部设备密集，运行温度高，虽然磷酸铁锂电池设计循环寿命可达2000-5000次，但在高温环境下，锂电池会加速老化，寿命显著缩短。第四是安全边界。即便锂电池安全性不断提升，但紧贴核心算力设施部署电池，其固有的化学活性带来的安全风险，已成为云计算厂商和租赁客户评估数据中心时的“减分项”。于是，行业开始从根源上重新审视供电架构。数据中心传统供电架构是“电网-UPS-PSU-GPU”，将演进为“电网-高压直流配电-PSU-GPU”，新的供电架构并非简单拿掉UPS，而是将其功能拆解下沉了。英伟达对比了不同储能方案的体积与放电速度，提出电解电容器是100毫秒以下持续时间的最佳解决方案；在100毫秒至10秒区间内，混合储能方案更具优势；而超过这个时间范围，锂电池则是更优的选择。综合考虑，英伟达给出的方案是双层储能，在电气架构的“源端”和“荷端”分别部署。这本质上是一种“能量型储能+功率型储能”协同的混合供电架构：在数据中心供电侧，配置大型电池储能系统，平抑由大规模GPU集群整体工作状态升降引发的分钟级、稳态功率波动。在机柜侧，配置电容模组，在微秒至毫秒尺度内，精确响应并消纳因GPU瞬时指令风暴引发的动态功率浪涌（响应速度高达400微秒）。  
  

****超级电容+电解电容，专治“来不及的电”****  
  
  

  

很多人存在误解，不是800VDC供电架构中才需要用到电容器，即使是交流供电架构，配置的英伟达新一代服务器中已搭载了锂离子电容器。据了解，日本武藏精密已经为英伟达GB200服务器供应锂离子电容器（LIC），2025年英伟达发布的GB200服务器已内置了超级电容器，这些锂离子电容器也将嵌入GB300中。英伟达在新一代服务器机柜侧配置超级电容，主要在于三个维度的代差优势。一是响应速度领先。超级电容响应速度为微秒至20毫秒级，可直接对治GPU微秒级的动态波动。二是功率密度领先。超级电容功率密度可达1-100kW/L，是功率型锂电池的数十倍乃至百倍。这使得在狭小的机柜空间内，部署足以瞬间提供巨大缓冲功率的模组成为可能。三是极致可靠与全生命周期成本最优。超级电容充放电循环寿命高达数十万甚至百万次，在服务器全生命周期内无需更换，减少了运维成本和系统停机时间，可在-40℃至85℃宽温域稳定工作，有助于提高数据中心的PUE。而且，超级电容无热失控特性，显著降低了起火爆炸风险，是真正可贴身部署的无忧方案。高工储能调研了解到，在交流供电架构数据中心，目前，英伟达服务器配置的是LIC，但对于高压直流供电架构，机柜侧将配置电解电容。电解电容响应速度比超级电容还要快，主要用于滤波、稳定直流母线、吸收高频电流波动。高压直流架构更依赖电解电容的核心原因在于，电压越高，对纹波就越敏感，1%的波动在800VDC下被显著放大，这就必须强化滤波网络。从海外巨头企业来看，Meta在HVDC方案明确使用牛角电容（铝电解电容的一种），首个相关项目已落地；Google正推进正负400伏的高压直流项目，预计使用铝电解电容（牛角电容）。  
  

****谁在卡位AIDC电容蓝海？****  
  
  

  

AI数据中心电容是一条全新的价值链，嗅觉敏锐的全球供应链早已闻风而动。目前，日本Rubycon、Nichicon、Chemicon，美国Maxwell、伊顿，韩国VINATech、Korchip，中国台湾企业台达电子等巨头已深度布局，均瞄准英伟达供应链。国内电容企业包括江海股份、奥威科技、思源电气、中车新能源、今朝时代、风华高科、凯美能源、中科超容、清研储能、合众汇能、中天超容、力荣新能源、绿宝石等。高工储能了解到，诸多国内企业都在针对AIDC场景开发超级电容产品，有部分企业已推出了产品方案。江海股份是国内EDLC/LIC龙头企业，其LIC产品已通过向台达电子供货，间接配套英伟达服务器。江海股份LIC核心技术是基于2013年收购的日本ACT，技术先进性与日本武藏同属于全球领先。近日，合众汇能推出了针对AI服务器的高功率脉冲超容模组，功率密度最高可达到100kW/kg。通过AI服务器高功率脉冲超容模组的即时功率补偿，可消除因供电波动导致的GPU降频现象，使AI服务器始终运行在标称算力状态。据测试，在典型AI训练任务中，使用该超级电容可提升算力利用率约15-25%。前段时间展会上，今朝时代推出超低内阻超级电容电芯及模组系列。其中新一代3.0V300F超级电容单体尤为亮眼，实测内阻低至0.4mΩ，达全球行业领先水平，可精准匹配AIDC高功率、高可靠后备储能需求。阳光电源与普兰纳米已达成全面战略合作，双方将通过“资本+技术+市场”的深度绑定，共同推动干法超级电容器在AIDC这一高增长领域的规模化落地与应用创新。此外，还有头部数据中心UPS企业正在探索超级电容方案。在面向微秒级功率波动的AI基础设施中，超级电容正在演变为不可替代的关键层，不过，超级电容价值并不在于取代锂电池，而是在分层储能体系中承担瞬态调节这一独特角色，与锂电池“共舞”。
