# 惠州丨大力发展智能网联汽车产业

惠州市人民政府近日发布《惠州市国民经济和社会发展第十五个五年规划纲要》，《纲要》主要阐明“十五五”时期惠州经济社会发展的指导思想、基本原则、发展目标，谋划重大战略，部署重大任务，是战略性、宏观性、综合性规划，是政府履行经济调节、市场监管、社会管理、公共服务和生态环境保护职能的重要依据，是未来五年惠州经济社会发展的宏伟蓝图和全市人民共同的行动纲领。
《纲要》明确：
大力发展智能网联汽车产业：进一步增强在智能驾驶系统、智能座舱、信息娱乐系统、域控制器、智能传感器、车载摄像头、通信模组以及三电系统等领域核心竞争力，推动智能化路侧基础设施和云控基础平台建设，支持有条件的县（区）有序开放道路、街区，开展智能网联汽车道路测试与示范应用，推动“单车智能”向“车路协同”升级，加快构建智能网联汽车产业生态体系。
重点方向——智能网联汽车：重点发展无人驾驶系统、智能座舱、信息娱乐系统、智能传感器、车载通信模组、电机电控电池系统等，推进智能网联汽车道路测试及示范应用，成为国内重要的智能网联汽车创新应用示范区，打造国内领先的研发产业基地和国家级创新型产业集群。
重点领域——新材料：围绕新能源汽车等应用需求，加快发展电池正负极、隔膜、电解液、铝塑膜等功能材料。大力发展汽车轻量化材料。
重点推动新能源汽车等产业协同发展。联合广州、佛山等地打造智能网联新能源汽车产业集群。
打造一批重点应用场景，推动低速无人车加快应用，探索打造国内领先的低速无人车示范应用城市。
支持车载电子信息技术等省级重点实验室建设。支持智能网联汽车等龙头企业建设行业数据空间和数据集。
持续推进运输结构优化，加快运输车辆清洁化电动化，扩大新能源车辆应用规模。推动智慧交通基础设施提质扩面，大力发展车路协同系统。
扩大智能网联汽车等智能化产品消费。加强智能网联汽车等重点领域立法供给。
