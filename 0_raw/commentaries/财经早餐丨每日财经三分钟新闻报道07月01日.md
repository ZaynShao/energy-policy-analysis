# 财经早餐丨每日财经三分钟新闻报道07月01日

► 国家统计局：6月制造业PMI为 50.3%，重返扩张区间。
► A股上半年：科创50指数大涨 64.25%，创业板指涨 35.58%。
► 现货黄金：盘中下探至 3941.6美元/盎司，创年内新低。
01 今日财经头条
- 国家统计局：6月制造业PMI为 50.3%，环比上升 0.3个百分点，重返扩张区间；非制造业商务活动指数为 50.2%，综合PMI产出指数为 50.6%。
- A股上半年收官：上证指数累涨 3.16%，深成指涨 19.82%，创业板指涨 35.58%，科创50涨 64.25%。中船特气以 766.85% 涨幅居首。
- 现货黄金：6月30日盘中下探至 3941.6美元/盎司，创年内新低，较年内高点 5596.68美元/盎司 下跌 28%；美元走强及美联储独立性获司法支撑施压金价。
- 证监会：主席吴清主持召开资本市场财务造假综合惩防体系推进会，近两年查办案件 247起，罚没 90.51亿元，21家造假公司强制退市，将协力铲除造假土壤。
- 国务院：李强主持召开国常会研究外贸形势和贸易强国建设工作，同日中欧举行贸易投资磋商机制会议，释放稳外贸积极信号。
- 康卡斯特：宣布将旗下NBC环球与Sky分拆为独立上市公司，股价盘中一度大涨 17%，最终收涨 4.53%，华尔街普遍认为此举将释放巨大价值。
- 国家发展改革委：在南京召开促进民营经济发展壮大现场会，指出“十五五”时期六大新兴支柱产业产值将扩大到 10万亿元 以上，今年重点领域投资将超 7万亿元。
02 宏观与政策
- 国家统计局：6月制造业生产指数 51.4%，新订单指数 51.2%，环比分别上升 0.2和1.3个百分点，产需两端同步扩张。
- 财政部：前5个月国有企业利润总额 17258.0亿元，同比 增长3.5%；营业总收入 328221.6亿元，同比 下降0.7%。
- 国务院国资委：中央决定，程福波同志出任国务院国资委党委书记。
- 国务院：《对外投资规定》7月1日起施行，明确将个人投资者纳入适用范围，建立对外投资监测预警、风险评估及领事保护等制度机制。
- 民政部与人社部：出台养老服务师职业资格制度暂行规定，明确设置养老服务师职业资格，提出 23条 具体规定，聚焦失能照护、康复服务等专业能力。
- 市场监管总局：部署自6月至12月开展经营者集中反垄断监管效能提升专项行动，支持企业通过并购重组走出“内卷式”竞争。
- 中共中央政治局：6月30日召开会议研究部署防汛抗旱工作，指出今年主汛期极端天气偏多、旱涝并重，要求确保大江大河大湖防洪安全。
- 水利部：7月1日起全面进入主汛期，研判7月至8月北方洪涝偏重，海河、松辽、长江、黄河等流域部分水系可能发生较大洪水。
03 环球视野
- 美股市场：三大指数集体收涨，纳指涨 1.52%，道指涨 0.26%，标普500涨 0.78%；AMD涨幅超 7%，英伟达、苹果、特斯拉涨幅均超 2%。
- 日元汇率：东京外汇市场日元对美元跌破 162关口，跌至1986年12月以来最低水平，美日利差悬殊及日本结构性问题持续施压。
- 德国通胀：6月通胀率从5月的 2.7%降至2.4%，降幅超预期；法国通胀意外回落至欧央行 2% 目标水平，意大利放缓至 3.1%。
- 美国劳工部：5月JOLTS职位空缺录得 759.4万人，高于预期的 730万人，劳动力市场韧性犹存。
- 达拉斯联储：美国6月服务业活动指数升至 2.9，前值为 -7.7；六个月展望指数升至 17.2，经济信心明显回暖。
- 英国首相斯塔默：宣布新增 150亿英镑 国防支出，财政大臣称将通过调整政府支出优先顺序筹集资金。
- 伊朗外交部：发言人表示，未来几天基本没有与美方举行任何级别会晤的计划。
04 A股与港股
- A股上半年：全市场 5530只 个股中，上涨仅 1760只（31.83%）；平均涨幅 8.05%，但中位数涨幅为 -15.01%，头部少数个股拉高整体均值。
- A股上半年：融资余额突破 3万亿，净买入超 4600亿元；电子与通信板块领涨。
- 公募基金业绩：上半年超 400只 基金收益翻倍，方正富邦核心优势A以 183.67% 夺冠；绩优产品主要重仓AI相关板块。
- 上半年IPO：A股共 71只 新股上市，同比 增长39%，首发募资总额 695亿元，同比 大增86%；新股无一破发。
- 北向资金：6月30日成交额为 3644.52亿元，占两市总成交额 11.13%；沪股通成交前三为中微公司、澜起科技、寒武纪。
- 兆易创新：被规模突破 200亿美元 的全球头部纯存储主题ETF Roundhill Memory ETF纳入核心持仓，权重 3.21%，位列第八大重仓股。
- 寒武纪：发布风险提示公告，称股价累计涨幅较大，滚动市盈率、市净率显著高于行业水平，存在估值较高及供应链稳定等风险。
- A股创新高个股：6月共有 472只 A股股价创历史新高，主要集中在电子、机械设备及基础化工行业，创新高股平均上涨 35.92%。
05 产业与公司
- 中航光电：在互动平台表示，公司已布局数据中心电源全链路产品，覆盖从电网输入到芯片级垂直供电，包括大功率连接器及电源组件。
- 英飞凌：全球高级副总裁潘大伟称，AI需求远超预期，预计2026财年AI数据中心电源营收达 15亿欧元，2027财年增至 25亿欧元。
- 杰创智能：披露定增预案，拟募资不超 19.65亿元，投向智算云服务中心建设及AI+安全装备研发与产业化项目。
- Anthropic：发布Claude Sonnet 5中端模型，性能接近旗舰Opus 4.8，价格低约 60%，API定价每百万输入token 2美元。
- 锂矿板块：储能电池需求旺盛，2026年前五月累计销量同比增 87.7%；7月锂电排产预计约 283GWh，环比增 5.6%，连续五月刷新历史峰值。
- 特斯拉：德意志银行预计第二季度交付量较官方预估高约 1万辆，季度环比增 16%，主要受益于欧洲市场表现强劲。
- 苹果供应商塔塔电子：遭黑客攻击泄露机密，包括未发布的 iPhone 18 Pro 系列照片及零部件清单，或重创苹果全球供应链保密体系。
- 镇洋发展：证监会批复同意浙江沪杭甬高速以新增不超 5.41亿股 吸收合并镇洋发展的注册申请。
- 中远海发：通过子公司委托大连重工建造 15艘 8.7万吨级多用途粮食船，交易总金额 47.85亿元。
06 商业风向标
- 优必选：发布全尺寸超仿生人形机器人U1，上半身Lite版售价 11.98万元，全尺寸Pro版 16.98万元，Ultra版最高 99万元。
- 美团：发布万亿参数开源大模型LongCat-2.0，原生支持 1M超长上下文；华为openPangu-2.0-Flash模型同期开源上线。
- 海信与海尔：受欧洲罕见热浪影响，在西欧市场空调销量激增，海信西欧销售额同比增超 20%，显示中国制造从价格竞争转向精准洞察本地需求转型。
- 东鹏饮料：因AI造谣“老板不喝自家饮料”导致市值蒸发，造谣者被刑拘。AI生成“小作文”对资本市场干扰日益严峻。
- 上海：明确将大力发展首发经济、夜间经济、直播经济，推动跨境支付便利化，持续打造“上海之夏”国际消费季品牌。
- 房企销售：上半年前100家房企累计销售额降幅连续四个月收窄，6月环比增 11.8%；保利、中海、华润三家进入“千亿元阵营”。
07 投资与观察
- 任泽平团队：6月PMI显示制造业重回扩张，AI资本开支推动全球制造业回暖；生产经营活动预期指数升至 54.3%，企业对后续市场信心增强。
- 穆迪评级：将中国银行体系展望从负面调整为稳定，认为持续政策支持与稳健经济增长将支撑运营环境，净息差收缩幅度将收窄。
- 高盛：预测标普500指数成分股二季度盈利同比增长 22%，驱动力来自人工智能投资热潮及宏观经济稳健表现。
- “六张网”建设：2026年水网、新型电网、算力网等“六张网”相关投资规模预计突破 7万亿元，将成为拉动经济增长的重要“硬支撑”。
- 英国央行：副行长Breeden警告，自主型AI智能体可能引发“市场崩盘”，若面对相同提示做出同样反应，可能在金融市场承压时放大波动。
