# 以色列发动空袭

以军空袭加沙多地，致十余人死伤。
8月23日，以色列军方对巴勒斯坦加沙地带中部扎瓦伊达镇的一栋建筑发动空袭，造成严重损毁。尽管据称以军提前警告当地居民撤离，但医护人员称，飞散至数十米外的建筑碎片与弹片还是造成一名4岁的巴勒斯坦男孩死亡，此外还有至少5人受伤。
巴勒斯坦卫生官员表示，以军当天还空袭了加沙地带中部的努塞赖特难民营及南部的汗尤尼斯地区，造成至少1人死亡、约10人受伤。
根据加沙卫生部门数据，自去年10月停火协议生效以来，加沙地带已有超过1280名巴勒斯坦人死于以军袭击。
