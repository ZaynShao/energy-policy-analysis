# 户储第一、盈利大涨，瑞浦兰钧以全场景电芯矩阵领跑全球储能

2026年，全球户用储能市场延续高增长态势，行业的竞争逻辑也从“拼价格”转向“拼价值”。
终端客户不再单一看重采购成本，对电芯循环寿命、低温适配、系统能效、安全认证等核心性能标准大幅提升。产品技术路线日趋多元，50Ah、72Ah、100Ah仍为当前主力，280Ah、314Ah等高容量电芯正加速向户用市场渗透。2026SNEC展会上，已有多家厂商展出搭载314Ah电芯的相关产品。在这场行业价值升级竞争中，瑞浦兰钧凭借持续稳定的出货规模、完善的产品体系与全球化布局，交出2026上半年亮眼成绩单。7月14日，ICC鑫椤资讯与NECI追光新能源两大权威机构发布2026年上半年储能电芯出货量统计数据。数据显示，瑞浦兰钧户用储能电芯出货量位列全球第一，工商业储能电芯出货量位列全球第二。坐稳户储出货榜首的同时，公司的盈利能力也迎来拐点。上半年公司成功实现扭亏为盈，预计营收达145亿至152亿元人民币，同比大幅增长52.8%至60.1%；同期净利润预计为7亿至8.5亿元，为全年业绩奠定了坚实基调。
