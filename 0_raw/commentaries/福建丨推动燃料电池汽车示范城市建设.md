# 福建丨推动燃料电池汽车示范城市建设

为认真贯彻国家深入实施“人工智能+”行动的决策部署，深入落实工信部等部门《“人工智能+制造”专项行动实施意见》要求，抢抓人工智能赋能新型工业化机遇，加快人工智能与我省制造业全过程、全要素深度融合和赋能应用，结合工作实际，福建省工业和信息化厅、发改委等八部门联合制定《福建省“人工智能+制造”行动计划（2026—2028年）》并于近日印发。
《计划》明确：
立足福州、宁德、厦门等地产业基础，支持整车企业联合零部件企业打造融合算力资源、数据闭环、算法迭代和虚拟验证的智能研发平台，推动整车制造流程与人工智能模型融合创新。
抢抓厦门燃料电池汽车示范应用重点城市契机，推进人工智能在氢燃料电池等方向加速突破。
依托高通量计算与数据建模，推动燃料电池汽车示范城市建设。
面向智能网联汽车等各类AI终端需求，加快布局新一代人工智能应用芯片，为智能化应用提供底层支撑。
