# 应持续完善生成式人工智能服务平台版权侵权本土治理范式

人民网研究院组织编写的智能互联网蓝皮书《中国智能互联网发展报告(2026)》7月29日在北京正式发布。其中，中国政法大学教授、中国法学会知识产权法学研究会副会长、中国知识产权研究会副理事长冯晓青及中国政法大学民商经济法学院高源撰写的《生成式人工智能服务平台版权侵权治理》一文指出，在生成式人工智能服务平台蓬勃发展态势下，加强版权侵权治理，事关巩固技术发展的制度保障，具有必要性。以明晰智能背景下的版权治理框架，推动生成式人工智能服务平台合规有序发展为目标，我国应当综合考虑实践场景，系统构建生成式人工智能服务平台版权侵权责任体系，切实提升治理成效。
文章提出，现阶段关于生成式人工智能服务平台运营者的法律属性、侵权归责原则以及注意义务等关键问题，事关版权侵权责任边界，尚存在一定理论争议，亟待予以回应。面对生成式人工智能平台化发展进程中日渐累加的版权侵权风险，我国已在规范设计与司法领域展开积极的本土化创新，综合考量技术特性与平台责任边界，兼顾版权保护与促进新兴产业发展，走在世界前列。
文章认为，对于生成式人工智能平台的版权侵权治理这一新兴课题，应继续将自主创新与借鉴外部治理经验相结合，因应我国技术创新与产业发展的现实需求，从三方面持续完善本土治理范式。一是原则上将平台运营者定位于技术服务提供者范畴，并采用过错推定原则落实其版权侵权责任。二是合理设置平台运营者版权注意义务，既应注重覆盖平台运行的整体流程，确保风险治理的系统性，也需兼顾合理限度，避免因义务过重而抑制平台正常运营与新兴技术发展。三是逐步探索构建专门的生成式人工智能服务版权治理规则，结合我国本土版权治理实践，因应风险态势持续进行理论与规范创新。
