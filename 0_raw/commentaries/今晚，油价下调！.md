# 今晚，油价下调！

自8月14日24时起，国内汽、柴油（标准品）价格每吨分别下调230元、220元。
7月31日国内成品油价格调整以来，国际市场原油价格快速回落后震荡运行，本次调价的前10个工作日平均价格低于上次调价前10个工作日平均价格。根据国际市场油价变化情况，自8月14日24时起，国内汽、柴油（标准品）价格每吨分别下调230元、220元。
附：各省（区、市）和中心城市汽、柴油最高零售价格
全国平均来看，92号汽油、95号汽油和0号柴油每升分别下调0.18元、0.19元、0.19元。给您算了一笔账，本轮成品油零售限价下调确认后，私家车单次加满一箱50L的92号汽油，将少花9元。
