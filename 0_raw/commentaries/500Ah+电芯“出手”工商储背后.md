# 500Ah+电芯“出手”工商储背后

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIsObEicAfPoPHXgQLMx1qD0j6fWU8kkJ1X209ibq41RqZeLA8aSlknFVWyHJJASB6poD0X5XibIm3vZkqW6OBgrr0sHFvehqQ8WNg/640?wx_fmt=png&from=appmsg)

500Ah+储能大电芯正加速渗透包括大储、工商储在内的众多储能细分应用场景。

近日，华致能源发布了ES300-4L液冷工商业储能系统，这也是业内首款基于587Ah大电芯的300kW/4h工商储系统。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIuJoNYwFeyRIqBGsO5sib4xkxcmWMxbM2JgQDNk110Xdc3CBttoP14nOYCDic1jbbDkJ9c6H3LjniafcS51hmVGIcJyfZfZEEtwmk/640?wx_fmt=png&from=appmsg)

据高工储能调研了解，该系统单机突破了1MWh，占地面积仅 3.42m²，能量密度大幅提升至342kWh/㎡。相比市场主流的125kW/4h产品，占地面积节省35%-50%，综合建设成本下降5分/Wh，可以实现项目更快盈利。

此前在合肥市首个ES300-4L应用项目中，新品已连续稳定运行1个多月。该电站装机容量300kW/1172kWh，采用低压AC400V 接入，平均放电量高达1172kWh，运行效率近89%。

事实上，500Ah+大电芯适配工商储系统在2025年就已经开始。

亿纬锂能采用其628Ah电芯推出了836kWh工商业模块柜，该产品采用了分体设计，支持灵活并柜组合，最大可扩展至5MWh。

欣旺达推出的840kWh的CTR直冷一体柜也配置其自产的625Ah储能大电芯，该产品适用于大型工商业储能项目。

宁德时代推出的TENER FleX储能系统则采用了其587Ah电芯，该系统可与600 V到1500 V的PCS集成，满足大规模工业和分布式发电应用的多样化需求。

有储能系统企业技术负责人表示，目前应用500Ah+电芯的工商储系统基本瞄准了大型工商业项目，其优势是大电芯的应用可以显著减少系统内线束、连接器、散热通路等的设计应用，大大提升了系统的可靠性，同时进一步有效降低了系统成本。

高工储能此前调研了解到，受分时电价政策调整的影响，工商储重地江浙沪区域投资者更加趋向于选择高能耗用能稳定的大型工商业项目，应用500Ah+电芯的大容量工商储系统能够更好地适配大型工商业项目，显著降低投资成本，提升电站的稳定可靠运行效率。

在降本以及提升可靠性之外，500Ah+储能大电芯在工商储领域的应用也离不开其在技术性能和能效方面的突破。

目前头部企业的500Ah+大电芯已筑牢安全防线，顺利通过热失控、过充、短路等多项严苛安规测试。

此外，部分500Ah+电芯产品常温0.5P循环寿命突破10000次，部分型号更是达到12000次以上，可完美适配20年电站寿命，同时实现全温域高能效覆盖，精准匹配长时储能的长期运行需求。

这也意味着500Ah+储能大电芯能够适配包括工商储在内的多元储能应用场景。

事实上工商储系统电量提升已经趋势日趋明显。此前高工产研储能研究所（GGII）就曾分析指出，2025年随着10/20kV高压侧应用居多，836kWh及对应的418kW甚至更大容量产品预计将陆续推出。

500Ah+储能电芯正完美匹配了这一趋势。

500Ah+电芯应用工商储系统背后另一大推手则是针对工商业领域的长时储能。

随着各地分时电价政策调整，以往基于“两充两放”的峰谷价差套利模式基础已不复存在，取而代之的“更长时一冲一放”下的辅助服务、需求侧响应、电力市场交易等多元化收益模式。

工商业储能场景需要长时储能。500Ah+电芯适配的大容量工商业储能系统正好匹配了这一需求。

这也正是华致能源发布ES300-4L液冷工商业储能系统的原因所在。

弘正储能副总经理杨晓光就表示，587Ah+集装箱针对大工商业产品快速收割314Ah为代表的产品解决方案，系统降本方向清晰，系统更低成本支持远端长时更高渗透率应用。
