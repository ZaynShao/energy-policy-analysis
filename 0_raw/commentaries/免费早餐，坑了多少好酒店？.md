# 免费早餐，坑了多少好酒店？

昨天早上，我在上海一家外资五星连锁酒店用早餐前，遇到了个颇为尴尬的场景。
餐厅门口，服务人员压低声音，反复向面前客人道歉，姿态放得很低，大概意思是前面接到了投诉，酒店已经沟通过，这顿早餐就不收钱了。
客人点点头，脸上看不出太多表情，回头招呼同行朋友，几个人顺着餐厅入口走了进去。
门口那位姑娘松了口气，很快又恢复笑容，转身去核验后面客人房号和权益。
我站在后面，看完全过程，突然想起近几年，类似这样古怪的妥协，在许多商旅酒店门店屡见不鲜，早餐更是重灾区。
不久前，有家中端连锁酒店业主老高和我吐槽，被客人薅早餐这件事，简直可以拍成连续剧。
他说，酒店前台几乎每天都能遇到客人顺口问一句，能不能送份早餐。
即使前台解释他的房价不含早，系统里也没有赠送权益，还是有人不走，继续站在柜台前聊，“平台上订房说会员有礼，早餐又不值几个钱，怎么到你们这里就不行了？”
无论前台怎么解释，气氛只会越来越尴尬，最后，往往是值班经理出来打圆场，或者前台在系统备注里加上免费早餐。
客人拿到结果，事情立刻结束，只是门店多了笔成本。
类似通融，已经从偶发情况变成不少酒店的日常动作。
旅界此前也曾报道，一些二手平台上能搜到各种薅早餐攻略，话术大多千篇一律，先打电话去前台，报出房号，强调自己是高等级会员，或者说入住体验不佳，希望酒店补偿早餐。
对方若迟疑，就威胁差评，攻略里甚至会提醒语气要硬，前台怕麻烦，免费早餐成了一门低成本试探前台底线的薅羊毛小生意。
硬币的另一面是，这些年，一线酒店员工早已不堪重负。
前台每天要接住无数句为什么不送早餐，即使解释得再耐心，依然转头就被客人一句为啥别家可以免费噎住。
店长夹在中间，一边要哄客人情绪，另一边还得为快被薅秃的餐厅成本发愁，两头都得顾着。
再碰上拿差评威胁门店的客人，酒店员工的心理压力，外人很难真正体会。
于是，受现实压力影响，很多酒店的早餐收费政策逐渐形同虚设，即使高星酒店也没能完全躲开。
去年3月1日起，澳门瑞吉发布通告，取消万豪白金及以上会员免费早餐，仅提供20%的早餐折扣。
按理说，公告已经把边界说清楚了，但很快，社交媒体上出现不少经验帖，分享如何谈心换早餐，顺便提高套房升级概率。
政策写出来，只是开始，能不能稳稳落地，又是另一回事。
而据我观察，有时网上政策并不一定人人都看，但若门口立块牌子，反而会好些。
前段时间，我在武汉出差，住在漫心酒店，早上去餐厅时，入口位置立着块会员权益早餐说明，写得很清楚，哪些级别会员可以免费用餐，什么情况需要付费，没有太多解释空间。
旅界实拍
后来我和门口负责核验的姑娘聊了几句，她坦言，自从牌子立起来，争议反而少了，而以前每逢早高峰，最怕客人站在门口反复问，为什么别人能进，我不能进。
现在多数人看完说明，就会按订单来，真有疑问，再去前台查。
只要把规矩全摊在阳光下，那些挑衅底线的戏码自然就演不下去了。
问题来了，一顿早餐到底能值多少钱？
很多人觉得，酒店早餐无非粥、面包，最多来个鸡蛋，再整点蔬菜水果，那既然房费已经付了，送份早餐，好像只是顺水人情。
可免费听起来大方，成本不会凭空消失，伴随国内住宿业内卷升级，为了让客人早上能吃好，即使许多大众品牌的早餐标准都在悄悄提档。
老高称，如今哪怕是一碗看着普普通通的白粥，后厨熬煮用的也是成本不低的五常大米，放到每天几十上百位客人的早餐高峰里，背后全是采购、人工、设备和损耗。
客人端起的只是餐盘里的东西，门店承担的却是整条运营链条的转动。
有行业测算显示，酒店自助早餐综合成本能占到客房收入的8%到12%。
中国饭店协会去年底发布的行业报告也提到，人工，采购，还有物业几项成本，都在持续走高。
不难看出，所谓免收餐费仅仅是把酒店真实成本隐藏了起来。
但倘若账本上的窟窿无法通过正当途径填补，企业必然会在其他隐蔽角落找齐，而许多看似占便宜的举动早就暗中标好了高昂代价。
这些年，不乏一些住客抱怨国内酒店早餐降本增效，背后大多是酒店沉重的经营成本需要找到出口。
即使五星酒店也未必例外，据我观察，不少国内外资五星酒店台面看起来很丰盛，真正占据取餐区面积的，常常是面包、粥粉面饭，还有各种甜饮。
很多人把免费早餐当成薅羊毛，心里安慰自己，免费的热量不算热量，可吃到最后，真未必薅到多少便宜，碳水和糖分倒是实实在在留在了身上。
所以，既渴望低廉实惠的客房定价，又期盼不掏腰包便能大快朵颐，世界上很难寻觅如此稳赚不赔的完美买卖。
因为免费早餐最贵的地方，往往不在早餐本身，它贵在模糊了价格，也弄混了边界，让很多真正为早餐付费的客人也吃喝不好。
事实上，今年春节期间，我在纽约住酒店时有些完全不同的用餐感受。
半岛和柏悦这类高端奢华酒店，早餐都不再用传统自助摊开阵仗，而是改成单点，客人想吃什么，按菜单来，价格写得清清楚楚。

这背后其实有个很朴素的逻辑，价格本来就是商业社会里最重要的信息，明码标价以后，客人知道自己买了什么，酒店也知道自己该交付什么。
愿意为早餐付费的人，可以得到更稳定的出品和服务，不需要早餐的人，也不必被迫把成本摊进房价里。
在欧美成熟的商业体系中，客房售卖与餐厅运营往往是泾渭分明的独立板块，谈心要饭完全不好使。
越是顶尖奢华的品牌，越不愿将带有高昂刚性成本的项目打包成廉价噱头，管理层们心里也如同明镜，靠模糊规矩换取来的虚假繁荣根本无法支撑长久的品牌体面。
现在看回国内，这些年，酒店业越来越卷，赠送早餐这件事铺开以后，性质就变了，刚开始有酒店送，能换回头客。
等到家家都送，早餐两个字，就从加分项变成了及格线，线一旦划定，谁想往回收，都容易被读成克扣。
可长期看，受伤的却可能是愿意好好做产品的酒店，所以，若从一开始就守住规矩，在早餐区门口立块牌子，反而能减少很多不解和龃龉。
早餐这笔账，最终不会只停在餐厅门口，它会慢慢往外扩散。
近年来，凯悦旗下的部分凯悦嘉轩已将早餐从所有住客免费的标配中取消，改为仅限特定会员或需单独付费购买，华住、亚朵、锦江等国内连锁酒店集团也日益严格按照会员等级来划分是否早餐免费。
很多消费者或许一开始不适应，并非早餐突然变贵了，而是过去太多默认赠送的东西，开始到了重新定价的时候。
可酒店行业终归要从讨好式人格里走出来，那些认真做早餐的酒店，价格看起来不占便宜，但也有愿意为之买单的客群。
而消费习惯这东西，改起来比想象中快，等含糊不清的期待被磨平，谁也不用再靠嗓门大小分高下，对于付费的酒店客人又未尝不是好事。
再往深了看，早餐这件事，牵出来的其实也是酒店集团和加盟业主之间更大的账目。
过去很长时间里，客人要什么，很多时候是总部说了算，从赠早到升房，再到延退，政策定在千里之外，成本却要门店自己扛。
业主没什么议价权，赚多赚少，先替总部的慷慨买单再说。
现在，市场进入存量博弈，好地段有限，业主手里能选的品牌却越来越多，谁真正替他们省钱，业主心里门清。
突然想起，老高前阵子跟我念叨，他挺羡慕隔壁全季在送不送早餐这件事上的原则性，因为至少这笔账，业主能看得明白。
而他自己加盟的那家，前台为了拿好评，早餐几乎成了讨好工具，送出去多少，连他这位老板自己都说不清楚。
所以，早餐看起来只是餐厅门口的一道小题，实际考验的是酒店集团如何重新处理总部、门店、业主和客人之间的关系。
这层关系理顺了，后面谈服务升级和品牌价值，才不至于总停在漂亮话里。
对酒店集团来说，这可能比单看开店速度更值得盯紧，毕竟未来账算不算得清楚，才是判断品牌能不能陪业主走完周期的真正标准。
而愿意把一顿早餐到底值多少钱摆到台面上，正是国内酒店业回归商业常识的开始。
