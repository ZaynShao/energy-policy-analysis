# 俄罗斯：立案调查！

俄就扎波罗热核电站总工程师遭袭身亡一事立案调查。
▲亚历山大·雅科夫列夫（资料图）
俄联邦侦查委员会发言人彼得连科当地时间7月16日通报称，已以涉嫌恐怖主义行为就扎波罗热核电站总工程师亚历山大·雅科夫列夫及其司机遇袭身亡一事刑事立案。
通报披露了雅科夫列夫的遇袭细节。15日，在扎波罗热核电站所处的埃涅尔戈达尔市，乌克兰武装人员使用一架无人机袭击了一辆民用汽车，造成该车司机和雅科夫列夫死亡，另一名乘坐该车的核电站员工受伤。
