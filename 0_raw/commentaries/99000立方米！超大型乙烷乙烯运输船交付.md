# 99000立方米！超大型乙烷乙烯运输船交付

99000立方米超大型乙烷乙烯运输船今日交付。
今天（18日），我国自主研发建造的99000立方米超大型乙烷乙烯运输船正式交付用户，综合技术指标达到国际领先水平。
今天交付的99000立方米超大型乙烷乙烯运输船总长230米，适用于装运乙烷、乙烯和液化石油气等多种液化工业气体、能源气体，具有油耗低、维护成本低等优势，能适应长途运输，是一艘经济环保型船舶。
中船江南造船99000立方米超大型乙烷运输船系列船总建造师袁世振表示，这艘船主要是为国内石化企业的乙烷运输提供保障，同时配备了轴带发电机，还有乙烷主机发动机，可以减少99%的硫化物排放，以及18%的碳氢化合物排放，为绿色航运提供有力帮助。
