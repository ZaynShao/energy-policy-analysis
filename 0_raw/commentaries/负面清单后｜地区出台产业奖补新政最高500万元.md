# 负面清单后｜地区出台产业奖补新政最高500万元

国办推动地方财政奖补负面清单机制后，各地陆续启动存量政策清理。
坚决杜绝违规补贴增量，开展存量补贴自查自纠
比如，仁怀市现行53条财政补贴政策中44条被判定为负面清单项目；赣江新区废止了与营收挂钩的企业研发中心补助、发明专利产业化奖励等条款；南京市江宁区率先废止涵盖高企、科小、独角兽、瞪羚等一整套认定奖补条款的“腾飞4.0”政策。
江北新区新政围绕科技研发能力建设、场景建设和应用、人才培育和引进三个方面布局八条措施，核心变化在于奖补逻辑的根本重构。
1.支持科技研发能力建设
鼓励建设工业软件、人工智能领域国家级重点实验室等平台；支持产业平台发布重点研发计划，单个研发项目最高支持500万元，聚焦技术创新攻关。
2.拓展场景建设应用
对采购使用首版次、首台（套）工业软硬件产品的企业给予最高200万元支持；鼓励国产开源操作系统技术适配和改造，支持方式未明确。
3.聚焦人才培养引进
对获得多行业技术资格认证的人才给予奖励，单人最高10万元；对共建特色学院的企业给予最高200万元分阶段资助。
新政的合规性体现在三个方面：一是遵循《公平竞争审查条例》，无法律行政法规依据不得给予特定经营者选择性、差异化的财政奖励或补贴；二是对照负面清单规避红线，未设落户奖补、不与营收挂钩、不奖认定荣誉；三是契合国家政策导向，体现对研发创新和市场失灵领域（基础软件、工业软件、开源生态等）的外部性补偿，符合“补贴科技创新而非产能扩张”的原则。
江北新区新政的最大价值，在于为其他地市、区县提供了“负面清单之后产业政策往哪走”的完整样本。
1.支持方式的转变：从直接给钱到多元工具组合
从直接补贴转向间接支持，安排政府采购，新政对采购首版次产品的企业给予支持。各地可探索首购订购、单一来源采购等方式，让政府成为创新产品的“第一个客户”，以市场需求代替财政直补。
从撒胡椒面转向拨投结合。前期以科研项目经费形式拨付，后期转成股权，资金可回收再投，将无偿给钱转为有退出的投资。
这是多地正在尝试的新方向，值得深入挖掘更多合规模式和工具创新。
从普惠奖励转向绩效导向。新政明确“根据课题完成度”给予支持，要求“按照适配难度、改造投入和应用成效”给予支持，全部与实绩挂钩，不与注册地、营收等条件挂钩。
2.支持方向的转变：从奖补申报单位到赋能行业发展
从支持企业个体转向赋能行业生态。过去奖补直接给到企事业单位，现在资金投向研发平台建设、技术攻关、场景应用等公共属性强的环节，钱不直接进企业口袋，而是花在行业共需的“基础设施”上，撬动的是整个生态。
从支持产业化转向支持研发和终端市场。新政资金向研发前端和市场验证环节倾斜，而非产能扩张。
这既符合负面清单“不补贴产能”的要求，也切中了产业发展的真实瓶颈，同时兼顾了政府财政资金聚焦社会外部性补偿的公平性。
从单点政策转向生态构建。新政涵盖科技研发平台、技术攻关、场景应用、开源适配、人才认证、产教融合等全链条，不是零散几条奖励的拼凑，而是一个完整的产业生态培育方案。
三、结束语
存量政策要抓紧清理。国办发〔2026〕12号要求对现行财政补贴、产业扶持政策全覆盖排查。对照负面清单逐条筛查，该废止的废止、该修订的修订。
而更重要的是推陈出新，政策工具箱要丰富起来，比如场景开放、创新采购、算力券、拨投结合……这些工具基层部门都可以用。
法与时转则治，治与世宜则有功，此之谓也。
