# 2026-W35-周报 水涨船高，音箱一夜涨了六成

2026.08.17 - 2026.08.23 | 共 242 篇精选
内存这轮涨价，本周走完了传导链的最后一公里。上游是瑞银测算的美光通用 DRAM 毛利率将在 2027 年冲到 93% 至 95%、正式反超专为 AI 设计的 HBM，摩根士丹利预告成熟制程 DDR4 三季度还要涨 50%、四季度再涨 10%；中游是 TrendForce 算出的 iPhone 18 Pro 256GB 版本 BOM 成本上涨近 40%；下游则是亚马逊一夜之间把 Echo、Kindle、Fire TV 多条产品线提价，最高涨幅 60%，公告里给的理由直接写着内存成本。需求侧的读数同步到位：Counterpoint 统计的欧洲二季度智能手机出货 3500 万部、同比降 10%，创该地区三年来二季度最低；IDC 统计的全球平板出货 3361 万台、同比降 12.3%，是本轮周期最大同比降幅，归因也是内存危机。链条末端还出现了一个回头动作——微软开始重新优化 Windows 在 8GB 及以上设备的内存表现，而它主推的 Windows 11 AI+ PC 一开始就把门槛定在 16GB。
另一条主线在 XR，而且是换轨而不是此消彼长。Smart Analytics Global 的数据是二季度全球眼部可穿戴出货超过 400 万台、同比增长约 89%，其中 AI 智能眼镜同比大增 776%、占总出货 85% 以上，一年前这个比例还只有 19%；同期 VR 头显出货同比下滑 79%。苹果紧接着砍掉了 Vision Pro 游戏团队，本轮共削减约 200 个岗位；而雷鸟把 34 克、双目光波导的 AI 眼镜首发价打到 1996 元。第三条线藏在财报季里：歌尔和瑞声的营收都创了新高，利润却几乎原地踏步，同一周做镜片的康耐特光学 XR 业务收入涨了近 15 倍，做微显示的视涯科技营收涨 287.87%，做端侧芯片的瑞芯微净利涨 61.73%。同一条产业链上，赚钱的位置正在往上游挪。

Echo Dot Max 从 99.99 美元涨到 119.99 美元，Echo Dot 从 49.99 美元涨到 79.99 美元，Kindle 与 Fire TV 同步跟涨，Eero 也没躲过，亚马逊给出的理由只有一条：内存成本显著上涨。这条新闻的分量不在涨幅，在位置。过去两个月这轮涨价一直停留在财报和供应链爆料层面——美光的毛利率曲线、三星拿到的 40% 份额、TrendForce 测算的 BOM，都是产业内部才看得懂的读数。本周它第一次变成了普通人在购物页面上能看见的数字，而且挑中的是消费电子里最便宜、最没有溢价空间的那一档：一台 50 美元的智能音箱涨到 80 美元，涨幅 60%，远高于同期任何一款手机的调价幅度。越便宜的产品，内存在 BOM 里的占比越高，也就越没有别的地方可以吸收成本，这是低价位段永远最先被杀的结构性原因。更该留意的是亚马逊愿意公开归因这件事。以往厂商面对成本压力，标准动作是悄悄减配、缩包装、砍附件，宁可让用户自己发现，也不明说涨价；这次直接把内存写进公告，说明压力已经大到不必再粉饰，也说明后面跟涨的不会只有它一家。对硬件产品线的含义很直接：明年的入门 SKU 要么涨价，要么消失。

这一周 AI 耳机在三个层面同时动。形态上，苹果把摄像头定义成"只给 AI 看"、双耳各拍一张再合成，光帆已经把双目视觉感知模组塞进左右耳机，并把独立联网、位置感知、身份验证集成到耳机盒里。软件上，韶音在成熟的开放式硬件上接入千问，做长时录音、AI 多维会议总结和翻译，目标人群锁定强沟通的商务人士。芯片上，炬芯第一代搭载存内计算 AI-NPU 的三核异构 SoC ATS3231 拿下架构创新奖——耳机 SoC 开始堆 NPU，是因为端侧不跑模型就接不到 AI 耳机的单子。成本侧也在配合：DeepSeek 的多模态视觉理解模型上线 API 平台，一张图最高只要 0.001 元，视觉理解调用成本压到这个量级，摄像头就不再是硬件的成本项，而是数据入口。但这一轮最要命的问题还没有人回答，硬氪把它问得很直接：接 API 做转写谁都会，AI 耳机究竟解决什么真实场景问题，谁来做技术底座。
