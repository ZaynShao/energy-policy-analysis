# 从工业曲线看产业发展新风景

规模以上工业增加值同比增长5.4%，工业对经济增长贡献率超35%，规上工业企业利润同比增长18.7%……今年上半年，我国工业经济走出一条稳步向上的运行曲线，有效发挥着宏观经济“压舱石”作用。
稳中向好的态势，不仅写在亮眼的指标数据里，也鲜活呈现在各地工厂车间、产业园区的火热生产场景中。记者在近期调研中真切感受到，从这条向上的曲线看去，是产业向新向优发展的更多新风景。
透过这条曲线，可以看到新旧动能接续转换的节奏在加快。
经济发展到一定阶段，需要实现动能的转换，这是经济保持一定增速且实现健康发展的内在要求。
国家统计局数据显示，上半年，以高端制造、数字经济、现代服务为代表的新动能对经济增长贡献率超过四成。动力结构之变，折射出中国经济向高质量发展迈进的坚定步伐。
一线的变化更为直观。曾经的钢铁企业济钢集团跨界布局卫星制造、因煤而兴的枣庄全力攻坚锂电池产业、老牌化工城市淄博加速打造“氢能高地”……以工业大省山东为例，记者在多个城市采访时，充分感受到新旧动能转换激发出的强劲活力。
当地工信部门负责人的一句话令人印象深刻：“喜新不能厌旧，新的使劲往前赶，老的改造好了照样有前途。”科学把握稳与进、立与破的辩证关系，统筹好培育新动能与更新旧动能的节奏与力度，才能实现新旧动能的平稳接续转换。
放眼全国，传统产业正加快转型升级，新兴产业和未来产业持续发展壮大，新动能新优势不断聚集增强。
“加快推动新旧动能转换”——近日召开的中共中央政治局会议在部署下半年经济工作时提出进一步要求，将指引各方因地制宜、持续用力，让高质量发展的动能更加充沛。
从这条曲线望向更深处，可以看到智能化、绿色化、融合化发展正在深刻重塑产业肌理。
上半年，我国规上制造业企业人工智能技术应用普及率超30%；重点工业企业数字化研发设计工具普及率、关键工序数控化率分别达86.3%、69.5%；单位GDP能耗同比下降1.9%……
记者见闻中，有更多生动注脚：在江西，南昌华兴针织实业有限公司经过智能化改造，裁片到成衣最快只需60秒；在重庆，美的通用制冷设备有限公司提供定制化系统设计、智慧运维等服务，从设备制造商转型为综合能源服务商；在江苏，树上渔歌（沭阳）生态农业有限公司将工业理念融入水产养殖，探索循环经济的新路径……
以智能化激活数智引擎，以绿色化深挖节能减排潜力，以融合化促进各种生产要素跨界流通、高效配置……智能化、绿色化、融合化协同联动，正锻造出韧性更强、底色更绿、长远竞争力更足的现代化产业体系。
将这条曲线置于全球坐标中观察，中国在开放合作中推动产业高质量发展的坚定选择，更加清晰可见。
今年上半年，中国工业出口实现较快增长，以人民币计价货物贸易出口额同比增长13.4%；人工智能开源大模型全球累计下载量突破100亿次，工业机器人产品销往141个国家和地区，创新药对外技术授权交易额创新高……
开放是产业高质量发展的必由之路。合肥一家汽车安全系统供应商的实践很有代表性：向内扎根，立足国内科技创新和制造优势，持续打磨迭代产品；向外拓展，在海外开设数十个研发中心、生产基地，嵌入当地产业链供应链。
当前，一大批中国企业带着技术、资本、管理理念“走出去”。中国已在境外设立5万多家企业，投资存量超3万亿美元，近九成分布在发展中经济体。
同时，越来越多外资企业在中国找到丰富的应用场景、完整的配套体系和充满活力的创新生态。不久前，韩国三星在华首次设立生物医药全球研发中心，德国妥思集团将成立75年来本土以外的最大单笔投资落地苏州……
开放是“你中有我、我中有你”的交融共生。在开放中拓展产业空间、融入全球产业链，在合作中帮助更多国家补齐产业短板、增进民生福祉，中国带给世界的是机遇和红利，是互利共赢。
建设现代化产业体系、实现产业体系整体跃升，是“十五五”时期的重要战略任务。于技术变革中育新机，于应对变局中开新局，持续推动这条工业曲线向上延伸，将为中国经济稳健前行注入更强动能，也将为全球经济增长贡献更多力量。
