# 长兴：浙江工业重镇如何算清碳账

文|本刊记者 郝怡柯 特约撰稿 杨晨 赵吉康
位于浙江湖州的长兴县是浙江北部传统的工业重镇，形成了纺织、化纤、建材（水泥、耐火材料）、铅蓄电池、机械制造等特色产业集群。产业体量越大，减排压力越重。
面对“十五五”碳排放强度下降17%的目标，长兴县选择提前把碳排放变成可量化、可管控、可优化的精细账。4月21日，浙江省首个县域碳排放管控中心在长兴县揭牌成立，由县政府授权国网湖州长兴供电公司实体化运营。
对于以制造业为底色的县域经济而言，“碳”正从环境指标演变为关乎竞争力的核心标尺。
俯瞰长兴县，现代与自然和谐共生。
纺织、建材、蓄电池等传统高耗能行业，既是县域经济的支柱，也是碳排放的“主力军”。2021年，湖州市在全国首创“工业碳效码”，踏上了一条数字化、精准化管碳的探索之路：依托电力大数据平台覆盖面广、实时性强的优势，集成企业生产经营中产生的用电、用气、用煤、用油等各类能耗数据，按照统一的碳排放核算标准转换成碳排放量，再结合企业产值进行统计分析，最终对规上工业企业进行“碳效”赋码，1级最优，5级最差。企业的碳效等级，一“码”了然。
围绕“碳效码”，一个全新的职业—“碳效工程师”应运而生。国网湖州供电公司组建了专业的碳效工程师团队，日常工作主要是查看赋码企业的碳效等级，锁定碳排放量较高，碳效码长期停留在4级、5级的“低碳效”企业，通过分析用能设备、测算能源流向、比对行业标杆等方式，为企业“问诊把脉”，量身定制“降碳良方”。
长兴诺力电源有限公司是一家专业生产电动车用动力电池、储能电池的企业。由于生产工艺的特性，该公司碳效码一度在4级徘徊。高碳排放导致生产成本居高不下，企业申报国家级绿色工厂也屡屡受阻。碳效工程师团队实地走访后发现，该企业的“症结”主要在于重力铸板热处理工艺能耗高、效率低。在工程师指导下，企业实施了核心工艺技改，淘汰落后产能，引进绿色制造系统。改造完成后，碳效码升至2级，每年预计节省电费近百万元。
“十四五”期间，“工业碳效码”经历了从1.0到3.0的迭代。1.0版本解决的是“能不能算清”的问题，建立了基于电力大数据的碳效评价模型；2.0版本拓展了数据源；3.0版本则全新上线了碳足迹数智服务应用，不仅让企业碳排放状况“有迹可循”，更能够为企业出口产品出具符合国际规范的碳足迹报告，助力应对欧盟碳边境调节机制（CBAM）等碳规则。
五年间，“工业碳效码”从长兴试点走向湖州全市，并逐步向浙江全省推广。它所做的不仅仅是为企业赋码排名，更重要的是帮助政府、企业和第三方机构建立起一套共识，即“碳是可测的、可算的、可管的”。正是有了这套运行五年的成熟体系和扎实的数据基础，碳排放管控中心的设立才水到渠成。
在长兴这样电气化水平较高的工业县域，电力是最主要的终端能源消费形式。电力数据覆盖面最全、实时性最强、颗粒度最细，是碳排放核算中最可靠的基础信息源。
碳排放管控中心成立后，迅速归集了经济普查、电能计量等各类底层数据，横向打通了多个政府部门的数据壁垒，整合了煤、油、气等非电能耗数据。一张覆盖全县、贯穿“源头—过程—末端”的碳排放数字化治理网络就此铺开。在管控中心的大屏上，哪家企业是排碳大户、哪个生产环节在“跑冒滴漏”、哪个行业碳排放强度出现异常波动，都一目了然。这一切都得益于该中心“算碳—管碳—降碳”三步走的闭环管控体系。
第一步是算碳，即把看不见的排放变成看得见的数据。过去碳排放数据分散在多个部门，统计口径不一，企业自报数据也常常核验困难。碳排放管控中心的首要任务就是构建一个坚实、权威的数据基座。在核算标准上，中心严格遵循国家和省级权威碳排放核算规范，采用最新的华东区域电网统一排放因子（0.4974千克二氧化碳/千瓦时），确保数据可比、可溯。在数据归集上，依托电力大数据全覆盖优势，中心建立分区域、分行业、分企业的电能量数据库，同时横向打通多部门数据，将煤、油、气等非电能耗全面纳入，形成全县能源消费的“全集数据”。在此基础上，为每家规模以上企业建立贯穿“源头—过程—末端”的“全链条碳排放画像”。
第二步是管碳，即建立从预警到预算的硬约束。“十五五”期间，长兴面临极为严峻的碳空间紧平衡形势。中心建立了区域、行业、企业三个维度的“红黄绿”三色预警机制：碳排放强度低于目标进度的亮绿灯；接近临界值的亮黄灯；已超标的亮红灯。同时，重点抓住占全县用能60%的规上企业这个“牛鼻子”，建立用能和碳排放预算管理制度。依据省定强度下降目标与企业实际情况，科学“倒排”年度用能和碳排放总量预算值，进行季度动态调整，确保预算既“压得实”又“调得动”。相关监测分析结果经主管部门审核后，以月度通报形式直达乡镇一线，真正实现“管住存量、控住增量”。
第三步是降碳，即从企业痛点中挖出节能空间。节能降碳是一项系统性工程，需要政府、电网、企业等多元主体协同发力。中心的专业能效工程师团队深入纺织、化纤、建材等高耗能行业“把脉问诊”，建立节能设备改造清单库，并提供综合能源托管服务，对接绿色金融渠道，让企业用最小的成本即可完成技改。
纺织业是长兴的传统支柱产业，企业数量多、用能总量大。空气压缩机在纺织企业中一般占到总能耗的40%，但很多企业使用的空气压缩机老旧能效低，“跑冒滴漏”严重。浙江盛发纺织印染有限公司是长兴纺织行业的龙头企业。在碳效工程师团队的指导下，该公司率先完成了空气压缩机换新节能技改。改造后，年节约电量约100万千瓦时，相当于减少280吨标准煤消耗，年节约电费约70万元。
不久前印发的《碳达峰碳中和综合评价考核办法》首次将碳排放“双控”要求纳入党内法规体系，明确对各省（自治区、直辖市）党委和政府进行综合评价考核。在目标分解方式上，新办法采用了“上下结合”模式，由各省因地制宜提出碳达峰目标和行动方案，经国家审核后成为评价考核依据。
这意味着，地方不能“等靠要”，而必须自己先把“碳账本”算清楚，把行动路径设计好。长兴碳排放管控中心最基础的功能，恰恰就是数据归集和核算：先把底数摸清，后把目标算准，再把路径铺实。从这个意义上说，长兴的探索恰好为这份新考核办法的落地提供了县域层面的实践样本。
长期以来，不少地方和企业对“降碳”存在刻板印象，但长兴的实践表明，真正的碳排放“双控”，不是简单地关停或限产，而是通过精准的数据画像和科学的管理手段，把过去隐性化的环境成本显性化，助力地方重新评估自身产业基本盘，让真正有竞争力、有绿色含量的企业和项目脱颖而出。
有了碳排放管控中心的数据支撑，长兴县在项目招引上不再是“捡到篮里都是菜”。过去，招商只看投资额、产值、税收；现在，还要看项目的碳排放强度和能耗产出效益。中心可以精准测算每个拟引进项目的全生命周期碳排放，为政府决策提供科学依据：究竟哪些项目该引进、哪些该限制、哪些需要附加绿电消纳条件，都有了数据支撑。对企业而言，通过平台的“碳画像”和碳效工程师的“问诊把脉”，可以实现从“自主节能”走向“精准减碳”，也因此重塑了绿色发展的经营理念。
目前，长兴碳排放管控中心已经实现对全县规上工业企业的全覆盖，重点覆盖纺织、化纤、建材（水泥、耐火材料）、铅蓄电池、机械制造等传统行业，以及新能源等新兴产业。在碳“可测、可算、可控、可管、可优”五个目标中，前两者已全面实现，后三者正在加速实现。该中心计划下一步将管控范围从规上企业延伸至中小微企业，最终实现县域碳排放管理的全覆盖。
从更长远的视角看，长兴这套“政府授权+供电公司实体化运营”的县域碳治理架构，具备向湖州全市乃至浙江全省复制推广的价值。其核心经验可以概括为三个层面：体制机制上，形成了权责清晰、政企协同的治理架构；工作路径上，建立了“算碳—管碳—降碳”三步走的闭环体系；技术支撑上，打造了“碳效码+数字化管控平台”的精准治碳工具。
碳达峰是一场长跑，“十五五”时期是最吃劲的爬坡段。对县域经济体而言，应对碳约束不是追求“速胜”，而是把碳排放管理从一项被动的约束性任务，内化为常态化的治理能力。
