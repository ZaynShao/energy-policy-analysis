# 中电建贵州工程公司联合体中标新疆石河子2GWh独立储能EPC

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)  

储能与电力市场获悉，近日，新疆石河子市新能恒储新能源有限公司500MW/2GWh独立储能电站项目（EPC）总承包中标人公示。中电建贵州工程公司（含联合体：石河子市天富电力设计有限公司）预中标，设备采购及建筑安装工程费率99.45%，设计费中标价：6750000.00元。  
此前公布的中标候选人详情如下：

  

中电建贵州工程公司，设备采购及建筑安装工程费率99.45%，设计费报价675万元，成为第一中标候选人；  
中电建重庆工程公司，设备采购及建筑安装工程费率99.80%，设计费报价763.994万元，成为第二中标候选人；  
中电建河北工程公司，设备采购及建筑安装工程费率99.95%，设计费报价743.05万元，成为第三中标候选人。  
![image](https://mmbiz.qpic.cn/sz_mmbiz_png/nJIHJiauQqnw9wYvA0fdZDDgzrIRmFpPmZZlywdq33HVBu8FibHsf11JlibJxomx9yrTiaqXBB7UGwHxmzZY1oa9R6uDVFDShqFJjqWUorzdsPI/640?wx_fmt=png&from=appmsg)  

看个广告休息一下![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/ibQ6Q066YicvUrISt2HTHibzQLHagVXTI0icHuu8j9l7VicIMYkGQ4a0sZubzCiaYLVbnQtvbYmZqkYcicIBJRaHbpdXQ/640?wx_fmt=jpeg&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=1)  

根据招标公告，项目占地面积约140亩，建设500MW/2GWh独立储能电站，包括100套5MW/20MWh磷酸铁锂储能单元及其它配套设施。自筹资金21亿元。
