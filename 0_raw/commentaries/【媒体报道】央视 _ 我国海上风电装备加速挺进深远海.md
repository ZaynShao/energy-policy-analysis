# 【媒体报道】央视 | 我国海上风电装备加速挺进深远海

今年以来，我国海上风电装备创新不断涌现。从20兆瓦海上风机并网发电，到漂浮式风电装备完成安装，再到超高压柔性直流送出工程加快建设，我国海上风电装备产业正加速从近海走向深远海。
今年2月，全球首台20兆瓦海上风电机组在福建海域成功并网，实现关键部件100%国产化。不久前，全球单机容量最大漂浮式海上风电平台——“三峡领航号”在广东阳江海域完成安装，项目首次应用国产化特种聚酯纤维系泊缆，单根可承受约1300吨拉力。
中国电力企业联合会常务副理事长 杨昆：截至2026年一季度，我国海上风电装机4722万千瓦，占全球总装机的52%，稳居世界第一，已形成整机制造、勘测设计、施工安装、运行维护、并网管理等完整的产业链，规模化优势显著。
目前，我国海上风电产业链自主可控能力持续增强。在关键装备领域，大容量风机、超长叶片、漂浮式平台、永久系泊缆绳、柔性直流换流阀、动态海底电缆等核心设备和部件持续实现国产化突破。
中国电力企业联合会常务副理事长 杨昆：未来我国海上风电发展要以产业升级为突破口，一方面是加强技术储备，持续强化技术攻坚和国产化替代，巩固海上风电产业整体韧性与安全；另一方面要强化产业协同，推进海上风电与电力送出、海洋工程、储能、绿氢等多产业联动发展，提升上下游整体效率和质量，激发全产业链合力。
随着近海资源开发逐步趋于成熟，深远海将成为我国海上风电发展的主战场。“十五五”规划纲要明确提出，到2030年海上风电累计并网装机规模达到1亿千瓦。（来源：央视网）
