# 煤炭供应丨1-2月原煤产量同比微降 3月或延续同比下滑趋势

【导语**】**2026年1-2月国内仍处于迎峰度冬阶段，煤炭稳产保供背景下全国原煤产量虽有窄幅同比下滑，但仍处于历史第二高位水平，有效保障国内供应；进入3月煤矿处于复产工作持续推进过程中，市场供应逐步恢复，预计产量仍有同比窄幅下滑可能。

**1-2****月全国原煤产量同比微降，处于历史第二高位**

据国家统计局数据分析，1-2月，全国规上工业原煤产量7.6亿吨，同比下降0.3%，降幅比2025年12月份收窄0.7个百分点，日均产量1293万吨。整体来看，1-2月累计原煤产量仅略低于去年同期，仍处于历史同期第二位的高位水平。

具体来看，受去年同期基数较高、局部地区煤矿存在“以量补价”现象等因素影响，今年1-2月全国原煤产量略有同比下滑；但迎峰度冬及煤炭稳产保供的大背景下，全国尤其主产区煤炭供给整体仍较为稳定，未出现大幅度回落。

**产量结构基本稳定，主产区仍表现出较强韧性**

就分省产量结构来看，全国煤炭供应结构整体维持稳定，晋陕蒙新作为全国煤炭主产区，仍表现出较强韧性，有效保障国内煤炭供应。1-2月，全国23个产煤省份中9个省市实现原煤产量同比正增长，较2025年减少1地，其中增长最为明显的是陕西省；14个同比负增长的省份中同比减量最明显的为山西省。

同比增量及减量最为明显的均为主产区省市，而就晋陕蒙新四地来看，1-2月以上四地合计原煤产量在6.29亿吨，在全国原煤产量中的占比为82.46%，较2025年同期略降低0.41个百分点，较2025年全年水平则提升0.74个百分点。具体来看，陕西及内蒙古实现同比正增长，主要得益于当地产能继续有序释放。山西及新疆地区产量则出现不同程度下滑，其中山西地区同比下滑原因主要在于2025年在稳产及以量补价等因素影响下，去年同期基数整体较高，新疆地区则受制于全国煤价同比偏低，疆煤外运成本较高，缺乏与疆外资源竞争优势，煤矿销售有所承压，进而反作用于煤矿，制约煤矿生产积极性。

**头部煤企累计产量多继续保持同比正增长**

据中国煤炭工业协会统计与信息部统计，1-2月全国排名前10家企业原煤产量合计为3.9亿吨，同比减少483万吨，占规上工业原煤产量的51.3%。具体就前10家煤企来看，结构基本维持稳定，较2025年同期变化不大，仅平煤神马集团取代河南能源集团进入前10行列，并位于第七位，潞安集团及国电投集团则分别后退至第九位及第四位；另前10大煤企中6家企业原煤产量实现同比正增长，平均增速在1.23%。整体来看，大型煤企的资源控制率仍保持在高位水平。

![image](https://mmecoa.qpic.cn/mmecoa_png/9w7iaKkib7mX3CZZgCMUJmiajJbjuMZqTLBgWHIrJu1UH0Ew0Qh1hKQwEFDJ97y2dk6aHH6Bov6Q6icIK2Pjv3JJSRLNMRFJQbnlSBM3Xiaibnk4Q/640?wx_fmt=png&from=appmsg)

**3****月原煤产量仍有同比下滑可能，2026年全年同比增速明显放缓预期不改**

进入3月，正值春节假期结束，煤矿复工复产工作持续推进之际，同时需求逐步向传统淡季过渡，也对产量释放造成一定制约，整体来看，预计3月全国原煤产量仍有同比下滑可能；而考虑到反内卷及煤矿反超产工作仍将季度推进，2026年全国原煤产量继续大幅放量空间或仍较有限，全年原煤产量同比增幅或将出现明显收窄。
