# 大唐甘肃公司与海博思创、中车时代电气举行合作座谈

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)

内容来源：大唐甘肃  
储能与电力市场获悉，3月30日，大唐甘肃公司与北京海博思创科技股份有限公司、中车株洲时代电气开展座谈交流。大唐甘肃公司党委书记、董事长、总经理王建伟，海博思创公司国内销售中心总经理温之兴、中车时代电气西北公司总经理齐志高出席会谈。大唐甘肃公司党委委员、副总经理王效辉参加会谈。  
![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/leqgpMdQQJgIzo79oHATNYLq84icPPrPoBrSIPIgia0N6l4hJQdchFFDqlbYlK44dmesv89jEtWoBst4ibJG9mpcP3Xfjx1wSCeIZs8rKxqfKY/640?wx_fmt=jpeg&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=3)

  

王建伟对温之兴、齐志高一行的到访表示欢迎，并介绍了大唐甘肃公司项目发展、战略规划等情况。他表示，大唐甘肃公司紧紧围绕国家能源发展战略和甘肃省能源发展重大部署，全面打造区域一流千万千瓦级绿色能源创新发展高地。希望海博思创公司、中车株洲时代电气一如既往支持大唐甘肃公司发展，在重要项目开发、新能源产业升级、科技示范引领等方面进一步加强务实合作，促进三方融合发展，共绘高质量发展新蓝图。  

温之兴介绍了海博思创公司重点业务和市场布局，他表示，长期以来，海博思创公司与大唐甘肃公司建立了深度互信的合作关系，希望双方建立常态化对接机制，海博思创公司将发挥储能全产业链优势，结合大唐甘肃公司实际，积极组织力量、协调资源，进一步优化技术方案，探索绿色能源新路径，推动项目高质量落实落地。

  

齐志高感谢大唐甘肃公司给予中车株洲时代电气事业发展的支持，他表示，中车株洲时代电气实施"同心多元化"战略，从传统的轨道交通装备业务向"双主业并进"转型。希望双方强化优势互补，聚焦项目建设、提质增效、科技创新等方面，拓展合作深度和广度，全力以赴赋能大唐甘肃公司高质量发展。

  

海博思创公司、中车株洲时代电气相关部门负责人，大唐甘肃公司投资发展部、工程建设部、河西分公司相关负责人参加会谈。
