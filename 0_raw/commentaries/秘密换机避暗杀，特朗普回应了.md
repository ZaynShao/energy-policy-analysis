# 秘密换机避暗杀，特朗普回应了

特朗普回应秘密换机避暗杀威胁：所乘飞机“风险反而更大”。
当地时间8月11日，记者获悉，美国总统特朗普表示，他上个月从土耳其秘密搭乘军用飞机离开后，随后转乘的那架飞机“面临的风险反而更大”。
在《华盛顿邮报》率先披露此事后，特朗普向记者表示：“实际上，我认为我后来乘坐的那架飞机面临的风险更大。”
他补充说：“我认为那架飞机风险更大，因为在我看来，那反而可能是他们更有可能下手的目标。”
据美国方面8月10日消息，美国总统特朗普7月初在土耳其参加北约峰会后回国时，因收到可信暗杀威胁而秘密乘坐一架空军C-32A离开，实际并未搭乘旧总统专机“空军一号”。
