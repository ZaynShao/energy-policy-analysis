# 中国公民暂勿前往，我领馆紧急提醒

印尼一火山景区因山火关闭，我领馆提醒公民暂勿前往。
因山火持续蔓延，印度尼西亚的知名旅游景点——东爪哇省布罗莫火山景区自8日晚起暂时关闭。中国驻泗水总领馆9日发布公告，提醒领区中国公民暂勿前往该景区，已预订行程的游客及时办理改期或退票，并密切关注火情及景区解封信息。
布罗莫火山景区管理部门8日晚发布消息说，受山火持续蔓延影响，该景区已于当晚暂停所有旅游活动，恢复开放时间另行通知。景区管理部门表示，关闭景区旨在提高灭火效率并保障游客安全。已购票游客可改期游览或申请退款。
据当地媒体报道，此次山火自3日开始燃烧，过火面积已扩大至约170公顷。当地有关部门已出动直升机空中洒水，并用无人机协助灭火。
目前，火灾原因尚未公布，暂无人员伤亡报告。
