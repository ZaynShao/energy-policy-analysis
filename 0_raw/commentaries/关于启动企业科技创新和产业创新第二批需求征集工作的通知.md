# 关于启动企业科技创新和产业创新第二批需求征集工作的通知

各有关企业：
为贯彻落实省委省政府关于加快建设创新浙江、因地制宜发展新质生产力的部署要求，根据《浙江省经济和信息化厅关于启动企业科技创新和产业创新需求征集响应工作的通知》《浙江省企业科技创新和产业创新需求常态化征集响应管理办法（试行）》（浙经信软服〔2025〕252号，以下简称《办法》），拟开展企业“两新”需求常态化征集响应工作，现将相关事宜通知如下：
需求征集范围
重大技术难题、新产品开发需求、新技术应用需求、新材料及工艺改进需求、设备更新及技术升级需求、产线智能化改造需求、创新平台构建需求专利再研发需求、其他科技创新和产业创新需求。
需求征集路径
请区内相关企业通过浙企之家“两新专区”填写“两新”需求。企业可通过法人账号登录“浙企之家”（链接：https://zj87.jxt.zj.gov.cn/），在“主题服务”中点击进入“两新”深度融合专区，选择“需求征集”入口进行需求填报。系统操作的相关指南和手册可在“两新专区”首页最下方下载查看。
征集时间
需求征集工作采用集中征集和灵活申报相结合的方式开展。请相关企业于8月14日前完成企业“两新”需求填报工作。后续区经信局将联合渠道响应单位进行服务对接。
