# 隆基“技术森林”亮相，ACM领衔8项创新技术首发

7月14日，隆基绿能在上海交通大学举办2026光储创新技术发布会，正式发布“技术森林”概念，集中展示了ACM（纳米合金矩阵式接触）技术、一体化导电背板技术、叠片技术、隐藏汇流条技术、控温合金互联技术、智能组件技术、LONGi One OS技术、三防Pro组件等多项创新成果，并宣布晶硅—钙钛矿叠层太阳电池转换效率跃升至35.5%，再次刷新世界纪录。
技术创新是穿越周期的底层逻辑
本次发布会汇聚产学研各界代表。中国工程院院士、上海交通大学国家电投智慧能源创新学院创始院长黄震，上海交通大学国家电投智慧能源创新学院智创中心主任、上海交通大学原总经济师刘牧群，上海交通大学太阳能研究所所长、中国光伏行业协会咨询顾问沈文忠，隆基绿能董事长、总经理钟宝申，隆基绿能创始人、首席技术官李振国，以及TÜV莱茵、TÜV南德等国际权威机构代表共同出席见证。
中国光伏从落后到领先，靠的是持续的技术突破。
回顾光伏产业发展，钟宝申指出，一个产业可以没有规模，但不能没有技术；可以经历低谷，但不能失去创新。科技创新是打破内卷的第一生产力，安全可靠、降低度电成本是光伏行业的终极使命。只要还有人相信“技术才是第一性原理”，中国光伏就永远有未来。
而此次亮相的8项技术，不过是隆基“技术森林”露出水面的冰山一角。
ACM技术：多重创新突破瓶颈
近日，隆基绿能ACM（纳米合金矩阵式接触）电池项目在西咸生产基地正式量产，成为隆基新型电池技术规模化落地的关键里程碑。
ACM技术是隆基自主研发的一项创新栅线技术，是材料和工艺方面的重大创新。ACM采用专利授权的纳米合金材料和全新的矩阵式接触技术，实现了电池及组件产品的效率与可靠性升级。
在材料层面，ACM结合多种金属的优异特性，通过科学配比与表面纳米级抗氧化技术，实现了栅线导电性能的跃升——电阻值仅为常规TOPCon的一半，导电通道相当于从“双车道”扩建为高速“十车道”，传输效率大幅提升。在工艺层面，矩阵式接触技术实现了接触层与传输层的精准分区：电流收集层以最小接触面积减少复合损失，电流传输层则确保更均匀、更高效的电流输出，“让专业的人干专业的事”。
这项突破带来三大核心价值。在高效率方面，更小的电阻、矩阵式接触工艺叠加创新钝化技术，带来更高效率与更高功率——量产转换效率提升0.2%—0.3%，最高功率672W。在高可靠性方面，主栅位置焊接面积增加一倍，叠加BC电池特有的“一”字型焊接结构，基本解除了虚焊、断栅风险；纳米级抗氧化技术有效阻止空气、水汽与金属接触产生的氧化，实现全面抗老化，全生命周期发电更出色。在高发电能力方面，得益于更优的导电性能与更高的组件功率，ACM技术为客户带来更稳定、更充沛的发电输出。
一体化导电背板：取消焊带，以“面”代“点”
行业数据显示，在焊带上产生的线损占到整个组件线损的60%以上，传统组件内部焊带超过了400米，通过15000多个焊点将电池片串联，每个焊点都是应力集中点，在长期热胀冷缩和机械载荷下容易引发隐裂、脱焊，进而导致功率衰减甚至组件失效。
焊带——这一沿用了二十年的连接方式——正在成为制约组件可靠性提升的瓶颈。
本次隆基发布的一体化导电背板技术，创新性取消了传统焊带，用金属箔“全域面接触”替代传统“点接触”焊接，从根本上重构了组件的电路架构。相比传统焊带，电流传输截面积提升85%以上，电池片应力降低60%，水汽通过率降低90%，同时由于金属箔的反射作用，穿透硅片的长波光线被反射回电池进行二次吸收，可以使单块组件功率再提升3—5瓦。
一项技术从“芯”里解决问题，一项技术从“体”上解决问题。ACM与一体化导电背板两项技术叠加，将组件的可靠性提升到了全新高度。
多项创新齐发 构建完整“技术森林”
除ACM和一体化导电背板两大重磅技术外，隆基本次还集中发布了多项创新成果，构建起从电池效率到组件可靠性再到系统智能化的完整“技术森林”。
叠片技术采用0.4mm电池片边缘精密重叠的无缝排布方式，将原本2—3mm的无效间隙转化为有效发电区域，组件有效发电面积提升2%。依托一体化导电背板的40微米薄金属箔和低温互联工艺，一举攻克传统叠片工艺应力集中、易碎片的难题。
隐藏汇流条技术摒弃传统正面外露汇流条结构，消除正面遮光区域，组件有效受光面积再增加1.1%。配合40微米薄金属箔替代250微米以上传统厚焊带，从源头消除挤压损伤。
控温合金互联技术充分发挥BC电池正面无栅线的优势，依托高精度视觉定位系统实现微米级互联排布精度，配合低温熔合工艺有效释放界面热应力，保障长期可靠性。
智能组件技术为每块组件独立配置最大功率点追踪模块，彻底消除遮挡、多朝向场景下的“木桶效应”，发电量提升5%—30%。同时具备主被动双模式快速关断功能，组件异常毫秒级自动关断，电站异常快速关断，20秒内将直流侧高压降至30V安全电压以内，不仅可消除火灾风险，还能满足关断法规要求，保障消防救援环境安全。另外，智能组件技术搭载“隆基智能光伏”APP，实时掌握电站组件级的运行数据，可实现单块组件快速定位，提高运维效率。该技术已于2025年获得TÜV南德“智能光伏组件”认证。目前该技术已然成熟，将于8月25日在巴西举办智能组件全球产品发布会，预计10月可实现量产交付。
LONGi One OS技术是隆基面向光储充荷一体化场景、搭载AI智能体的新一代智慧综合能源管理平台。LONGi One OS可接入市场化电价数据，融合光伏发电预测、负荷预测、天气预报、用户历史用电负荷等多维参数，AI每15分钟输出最优充放电策略，实现储能资产收益最大化。平台搭载自研AI智能体，可实现AI使用指导、故障诊断及预警，让运维门槛降低90%。
“未来我们也可以从这个技术森林中，随意组合几棵科技树，就是一个能解决客户痛点的产品。”李振国表示。
值得一提的是，若这些技术在标准组件上汇聚叠加，2382mm×1134mm的标准尺寸组件功率可直接突破690W，效率达到25.54%。此次发布会，隆基同步公布了最新科研突破：经欧洲太阳能测试机构（ESTI）认证，隆基自主研发的晶硅—钙钛矿叠层太阳电池转换效率达到35.5%，再次刷新钙钛矿叠层电池效率世界纪录，为下一代光伏技术路线提供了坚实的技术验证。
BC路线：基于物理定律的战略笃定
本次发布的所有技术创新，均基于隆基坚定布局的BC技术路线。
“BC正面无遮挡，是一个完美的光伏电池结构。”沈文忠指出，BC的理论效率极限可以达到29.1%，不仅效率更高，而且在可靠性、美观度、应用场景适应性等方面均具有显著优势。
沈文忠教授强调，BC技术的结构优势赋予其更强的技术延展性与创新承载力。在他看来，银浆替代已是行业可持续发展的必由之路，而钙钛矿稳定性瓶颈短期仍难突破，业内正同步探索晶硅叠层等备选顶电池材料，为BC电池预留出8至10年的发展窗口。隆基“技术森林”理念的系统性落地，正推动行业从单点创新迈向全链条重构。
基于这一判断，隆基多年前便坚定选择BC技术路线并持续深耕。截至2025年底，隆基取得BC相关专利授权510件，其中发明专利330件。深厚技术储备支撑规模化落地，预计2026年底，隆基BC组件全球出货近100GW。布局BC技术的厂商已超过30家，BC成为主流技术已成行业共识。
三防Pro组件：“技术森林”首个落地成果
发布会现场，隆基绿能分布式中国区总裁牛燕燕正式发布Hi-MO X10三防Pro组件。这是隆基“技术森林”中首个实现量产落地的技术产品，搭载全向防积灰技术和ACM技术。
针对客户反馈的痛点问题，隆基Hi-MO X10三防Pro组件采用L型合金包边搭配高强度卡扣框（榫卯结构），实现全向防积灰、抗凹陷、抗风性、运装效率四大核心升级。
在防积灰方面，长短边边框均与玻璃齐平，横装、竖装均可防积灰。在抗凹陷方面，卡扣框为组件中部提供更大力度支撑。据宁夏兵沟项目实测显示，三防Pro组件较超大版型组件抗凹陷性能领先67%以上。在抗风性方面，产品通过±1500Pa、6万次以上动载测试（常规组件为1000Pa、2万次），耐撕裂性能通过5万次激振测试（常规组件6000次），耐撕裂性能较常规组件提升7倍。在运装效率方面，每托容纳41块（常规36块），以17.5m板车测算，单兆瓦运费直降2300元，T型螺栓安装效率提升30%。
此外，隆基Hi-MO X10三防Pro组件功率达670W，效率24.7%，具备防起火、防遮挡功能，首年衰减1%，线性衰减0.35%，产品质保15年，功率质保30年。
“横装、竖装、随心装，怎么装都能防积灰！”牛燕燕宣布，隆基Hi-MO X10三防Pro组件已实现量产，即日起可交付。
技术森林 生生不息
从ACM突破材料瓶颈，到一体化导电背板重构组件底层逻辑；从叠片、隐藏汇流条向每一毫米要效率，到智能组件、LONGi One OS让光储系统拥有“大脑”——隆基此次发布的每一项技术，都不是孤立的存在，而是“技术森林”中相互支撑、协同生长的有机整体。
“今天大家能买到的产品，是我们两三年前就开展放量验证的；今天大家听到的技术，是我们五至十年前就开始立项攻关的；隆基实验室里那些还没有命名的技术，正在为下一个五年、十年做准备。”正如李振国所言，“技术森林”的意义，不仅在于当下的果实，更在于持续生长的能力。
行业周期起伏，但技术之树常青。隆基“技术森林”所倚重的，不是某一项技术的领先，而是持续迭代、自我生长的创新能力。当一棵棵科技树根深叶茂、相互支撑，便构成了企业穿越周期最坚实的内生力量。
