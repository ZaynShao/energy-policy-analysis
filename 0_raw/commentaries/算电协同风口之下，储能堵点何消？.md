# 算电协同风口之下，储能堵点何消？

# ![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIsObEicAfPoPHXgQLMx1qD0j6fWU8kkJ1X209ibq41RqZeLA8aSlknFVWyHJJASB6poD0X5XibIm3vZkqW6OBgrr0sHFvehqQ8WNg/640?wx_fmt=png&from=appmsg)

  

“实施超大规模智算集群、算电协同等新基建工程。”

2026年政府工作报告明确提及这一概念，标志着算电协同正式从地方试点跃升至国家战略，成为“十五五”期间万亿级新赛道的核心增长极。

一边是AI大模型爆发催生的算力狂奔，一边是双碳目标下的能源转型压力，这场“算力与电力的双向奔赴”，既是产业发展的必然需求，也是国家战略的明确导向。

市场对这一万亿赛道的期待已然凸显：3月6日，“算电协同”概念首次亮相全国两会后，A股相关板块快速走强，中国能建、豫能控股等纷纷涨停。

金融街证券首席经济学家张一认为，在算电协同新模式下，通过拉动储能、智能电网、数据中心、绿电运营等大量相关产业联动发展，将形成至少万亿规模的市场增量。

但需求的迫切之下，横亘在二者之间的诸多堵点仍在阻碍落地，其中最为紧迫的便是储能——这一核心环节的瓶颈，直接制约着算电协同从政策蓝图走向产业现实。

事实上，产业界已普遍意识到储能的关键作用。

全国人大代表、天合光能董事长高纪凡强调，由于AI需要相对稳定的电力供应，新型储能的重要性日益凸显，需要构建“构网型”的储能系统，将不稳定的新能源供给与算力中心的稳定需求进行协同平衡，实现供需两端的智能联动。

全国人大代表、珠海冠宇董事长徐延铭指出，AI数据中心对储能提出了高安全、高倍率、高可靠性的新要求。

全国人大代表、中车株洲所董事长李东林建议，结合AI算力中心能耗大的特点，规划布局“绿氢制储+算力中心”一体化项目。

远景高级副总裁田庆军则明确，通过储能平抑波动，可为算力中心提供稳定绿色电力。更值得关注的是，海外企业调用中国大模型，实质上实现了“算力/token出口”，这背后正是储能支撑下的能源优势向数字服务优势的转化，助力实现能源价值的全球化闭环。  
  

****深度拆解，****

****卡脖子的核心堵点在储能****  
  

  

风口已至，赛道潜力初显。官方显示，“十五五”期间将培育数个万亿级新兴产业市场，算电协同凭借其“算优化电、电支撑算”的核心逻辑，成为最具潜力的赛道之一。

从产业基础来看，我国已具备推进算电协同的良好条件：作为协同核心的新型储能，2025年底累计装机已达139.2GW/373GWh，一年增长超86%，产业链势头迅猛；国内企业储能电芯出货量超630GWh，出口占比近半，前10名企业均为中国企业，产业链优势显著。

与此同时，我国算力产业快速发展，截至2025年，智能算力规模已超过1590EFLOPS，建成万卡智算集群42个，算力总规模与智能算力规模双双位居全球第二，为算电协同提供了坚实支撑。

但热潮之下，算电协同的落地之路并不平坦。结合2026年全国两会部署、发改委产业规划及产业一线实践来看，当前产业仍处于“政策热、落地难”的初级阶段，诸多堵点中，储能产业的协同不足最为突出，成为制约落地实效的关键，具体可从五大方面拆解：

其一，“东算西缺电、西电东难消”，储能协同破解供需割裂乏力。“东数西算”本是为破解算力与能源的空间失衡而推出的重要举措，初衷是实现“东部算力需求牵引、西部绿电供给支撑”的跨区域协同格局，但现实推进中却陷入供需错位的困境。

长三角、京津冀、珠三角等东部地区集中了全国60%以上的算力需求，却仅拥有20%的能源禀赋，多地出现“算力落地即缺电”的尴尬；而西部蒙西、甘肃等地区，风光绿电成本低至0.15元/度，仅为东部工业电价的1/3，却因本地算力需求不足，绿电“窝电”问题突出，优质绿电无法高效对接高价值算力。

2026年全国两会期间，全国人大代表、中国移动浙江公司党委书记、董事长、总经理杨剑宇也印证了这一现状，他认为当前算力需求与电力供给存在明显的空间错位：“长三角、京津冀、珠三角等东部地区算力需求占全国60%以上，但东部能源占比不到20%，电力供应的对外依存度高，随着人工智能应用快速普及，东部地区智算中心供电配套亟待加强。”  

更关键的是，跨区协同的核心壁垒尚未打破：跨省输电通道不足、网络时延过高、数据传输成本居高不下，导致西部绿电难以高效匹配东部算力需求；

再加上建设周期存在明显错配——智算中心建设仅需1-2年，而电网、新能源项目需3-5年，“算力等电、电等算力”的现象频繁出现，进一步加剧了供需割裂，而储能作为跨区能量调节的核心，其协同能力不足更让这一困境雪上加霜。

全国人大代表杨剑宇、李少平均指出，东部供电配套不足、中部试点空白、西部绿电价值未释放，这些问题共同制约了全国一体化算力网的整体效能，成为算电协同落地的首要空间障碍。

其二，“算力要稳，电力要绿”，时序匹配存在短板，储能调节能力不足。这一核心矛盾成为算电协同落地过程中的关键掣肘，本质是刚性算力需求与柔性绿电供给的时序错配问题——AI算力的连续性需求，与风光绿电的间歇性、波动性形成天然冲突。  

AI大模型训练、推理需要7×24小时高可靠、不间断供电，单柜功率超100kW，一次千亿参数大模型的训练，耗电量可达1200万度，相当于一个5万人口小镇全年的用电总量；而风光绿电天然具有间歇性、波动性，受天气、时段影响显著，直接用于供电无法满足算力中心的稳定性要求，这也导致部分数据中心PUE偏高，极端天气下供电韧性薄弱。

尽管新型储能被寄予“平抑波动”的厚望，2025年底装机规模已超1.3亿千瓦，但当前储能配置规模与响应速度仍显不足。由于算力负荷难以随绿电出力灵活调整，不仅导致绿电消纳率偏低，还大幅增加了电网的调频压力，进一步加剧了二者的矛盾。

高纪凡指出，基于光伏、储能和算力融合的“光储算一体化”系统，将是一个全新的、巨大的市场空间，天合光能已全面推动基于构网型技术的AIDC光伏一体化系统，以更好支持全球AI算电协同中心的绿色建设。

其三，投入高、回报慢，成本闭环难以形成，制约储能配套落地。算电协同的规模化落地，首先要攻克“成本关”。作为一项涉及多领域、多环节的系统工程，源网荷储一体化、构网型储能、液冷智算等协同方案的初始投资巨大，且不同环节的回报周期差异显著，这种收益节奏的不匹配，直接导致企业投入动力不足。

具体而言，电网、储能项目回报周期长达5-8年，部分电力设施投资回报周期甚至可达20年，而算力项目迭代速度快，回报周期仅需1-3年，这种“长投入、慢回报”与“短投入、快回报”的矛盾，让不少企业在布局算电协同项目时顾虑重重。

更核心的问题在于绿电价值未能有效兑现：西部绿电的成本优势，在跨省传输、能源损耗、通道费用等环节中被大幅抵消。

同时，绿电的碳减排环境价值，在电力、算力市场中缺乏明确定价，导致收益无法形成闭环，难以通过市场机制反哺前期储能及相关设施投入。此外，智算集群的高密度散热（液冷）、不间断供电（UPS+储能）等需求，进一步推高了运维成本——电费甚至占算力运营成本的50%-70%，这让不少中小企业望而却步，也制约了储能与算电协同的规模化普及。

其四，技术瓶颈突出，多领域适配性严重缺失，储能技术支撑不足。算电协同的落地离不开核心技术的支撑，其技术壁垒更是制约产业发展的“阿喀琉斯之踵”。当前，相关技术仍存在诸多短板，覆盖储能、算力调控、三网融合等多个领域，技术适配性不足的问题尤为突出，成为产业推进的“卡点”。

在储能领域，长时储能（小时级以上）成本高、循环寿命短，构网型储能、虚拟同步机等电网支撑技术的成熟度与规模化应用不足，难以满足智算中心高可靠供电的需求；在算力调控领域，AI任务的实时调度、弹性伸缩、错峰运行算法与平台尚未成熟，数据中心作为“虚拟电厂”参与辅助服务市场的响应速度、控制精度仍需提升，无法实现“绿电多时多算、绿电少时少算”的灵活运营，也难以充分发挥储能的调节价值。

此外，超大规模智算集群所需的高压直流供电、浸没式液冷等技术仍处于试点阶段，规模化降本与可靠性有待进一步验证；算力网、电力网、通信网“三网融合”的协同调度、安全防护技术体系尚未建立，不同技术体系之间难以实现高效联动，进一步限制了储能与算电协同效能的发挥。就连达卯科技等专注于算电协同的企业，也在通过融资加大能源大模型、协同平台的研发投入，试图突破这一技术瓶颈。

其五，标准缺失、人才短缺，难以形成规模化效应，间接制约储能协同发展。产业规模化发展，标准是前提、人才是支撑，但目前算电协同领域在这两大方面均存在明显短板，其中标准缺失是产业发展的“软肋”，人才短缺则是“隐形堵点”。

在标准层面，算电协同领域仍处于“无规可依”的状态。在能效与绿电认证方面，算力能效（PUE/算力能效比）、绿电算力认证、碳足迹核算缺乏统一的国家标准，企业“各自为战”，无法形成规模化效应；在接口与交互方面，数据交互、调度协议、设备接口没有统一规范，不同厂商、平台难以互联互通，形成了“算力孤岛”，阻碍了储能与算电协同效能的发挥。

在人才层面，算电协同需要既懂算力架构、AI算法，又精通电力系统、储能技术、电网调度的复合型人才，但当前这类跨界人才极度匮乏。由于算电协同涉及计算机、电气工程、能源经济等多个学科，传统人才培养模式难以满足产业需求，无论是技术研发、协同调度还是落地运营，都面临明显的人才缺口，直接制约了储能技术创新与算电协同落地进程。  
  

****储能快跑，****

****推动算电协同“落地生根”****  
  

  

尽管算电协同的落地面临诸多堵点，但随着国家战略持续发力、产业界不断探索，以储能为核心的破局之路已逐渐清晰。  

中国电力企业联合会统计与数智部主任助理吴立强判断，“拥有稳定电力资源的能源企业，具备向算力服务商转型的天然优势；而掌握电网调度自动化、电力AI大模型等核心技术的企业，将成为算电协同的‘神经中枢’，具备极高的技术壁垒和不可替代性。”  

这一论断不仅凸显了储能与电力、算力融合的重要性，更明确了储能在破局过程中的核心地位。

结合行业实践与两会代表委员建言，围绕储能破局，推动算电协同落地可从三大方面发力：

第一，在空间统筹上，推动储能与算电跨区协同，破解供需割裂难题。推进“东数西算+西电东送”深度协同，加快跨省特高压、柔性直流通道建设，发展“边缘算力+本地绿电”模式；充分利用西部地区可再生能源优势，建设非实时算力中心，引导国家枢纽节点优先对接大型风光基地，开展“光储算一体化”试点，实现“就地发电、就地计算”。

同时将算力基础设施布局纳入国土空间规划和电力专项规划，建立地方政府、算力企业、电网公司、发电企业的常态化沟通机制，同步推进储能与算电设施建设，破解建设周期错配难题，让储能真正成为跨区能量调节的核心纽带。

第二，部署长时+构网型储能，提升储能协同支撑能力，破解时序匹配短板。规模化部署长时储能+构网型储能成为未来的核心重点，完善储能系统的虚拟同步机控制算法与构网型PCS设备配置，提升储能响应速度与稳定供电能力；建立算力负荷弹性调度、错峰运行机制，推动算力中心参与电力辅助服务市场，提升绿电消纳率，实现“绿电波动由储能平抑、算力需求由储能兜底”，精准匹配AI算力的刚性需求与绿电的柔性供给，破解二者时序错配的核心矛盾。

第三，完善成本机制，打通储能回报闭环，激发市场投入动力。完善绿电价格、碳减排收益、调峰补偿三位一体的市场化机制，落实储能容量电价补贴政策，让绿电的环境价值得到有效兑现，弥补储能项目长周期回报的短板；推动储能、液冷、高压直流供电等技术规模化降本，降低算电协同运维成本；鼓励企业探索“绿电-算力-服务”的价值传导链，推出“绿色算力合约”等创新产品，让用户在购买算力服务时，同步获得绿色电力消费凭证和碳减排证明，形成“储能支撑绿电、绿电赋能算力、算力创造价值”的良性循环。

目前，已有不少企业率先探索储能与算电协同的破局之路，为行业提供了可借鉴的经验：中广核新能源与华为、腾讯等龙头企业达成绿电合作，2025年合作规模超30亿千瓦时，配套储能系统实现绿电稳定供给；内蒙古“中国云谷”依托本地绿电优势，打造算电融合示范基地，配套大规模储能设施，智算规模稳居全国首位；达卯科技等企业通过融资布局能源大模型、算电协同平台，推动储能技术与算电协同的商业化落地。

此外，全国已有84个绿电直连项目获批，装机超3200万千瓦，均配套储能系统，为算电协同落地提供了坚实支撑。

算电协同的万亿赛道，从来不是一场“速胜战”。这场算力与电力的“双向奔赴”之旅，仍是未来五年乃至十年最被看好的赛道。
