# 刘国洪兼任国家自然资源总督察

新任自然资源部党组书记刘国洪已兼任国家自然资源总督察。
近日，自然资源部官网更新显示，新任自然资源部党组书记刘国洪已兼任国家自然资源总督察。
刘国洪，男，汉族，1966年4月生，江苏江阴人，研究生学历，理学博士学位，中共党员。
曾任自然资源部耕地保护监督司司长，自然资源部国土空间规划局局长，自然资源部办公厅主任、党组机要秘书，自然资源部总工程师等职。
2022年任自然资源部党组成员、副部长，次年同时兼任国家自然资源副总督察。2025年任自然资源部党组成员，国家林业和草原局（国家公园管理局）党组书记、局长。
今年7月30日，刘国洪任自然资源部党组书记。至此番兼任新职。现任自然资源部党组书记、国家自然资源总督察。
