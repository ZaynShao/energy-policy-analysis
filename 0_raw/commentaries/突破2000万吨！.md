# 突破2000万吨！

中老铁路跨境货物运输量突破2000万吨。
从国铁昆明局了解到，截至7月8日，中老铁路跨境货物运输量累计突破2000万吨，开行跨境货物列车超2.3万列。
中老铁路自2021年12月3日开通运营以来，跨境货物运输量节节攀升——开通首年即突破100万吨，2023年突破500万吨，2024年突破1000万吨。今年以来，中老铁路跨境货物运输持续保持高位运行，日均运输跨境货物1.7万吨，同比实现稳定增长，全线累计货物运输量也突破2000万吨大关。
中老铁路开通以来，跨境运输的商品种类从开通初期的10余种扩展至3800多种，辐射南亚东南亚19个国家和地区。随着“澜湄快线”等国际联运品牌逐渐成熟，榴莲、山竹、龙眼等东南亚特色农产品从万象装车，26小时抵达昆明、两天内进入全国主要城市已成为常态。
为提升服务品质，提高运输效率，铁路部门持续优化跨境运输组织，推行“铁路快通”通关模式，磨憨铁路口岸智慧货场投入使用后，货物通关时间从开通初期的40小时大幅压缩至2至5小时，跨境货物在途时间不断缩减。同时，开行冷链班列、水果专列，保障东南亚热带水果“抢鲜”进入中国市场。
依托中老铁路，万象至昆明间陆路运输成本下降40%至50%。中老铁路带动沿线产业园区、物流枢纽加速布局，今年上半年，经中老铁路进出口货值达171.6亿元，同比增长33.7%，成为外贸增长新引擎。
