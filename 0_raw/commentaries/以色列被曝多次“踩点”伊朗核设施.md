# 以色列被曝多次“踩点”伊朗核设施

以色列情报和特勤局（摩萨德）前局长约西·科亨称以方人员多次“踩点”伊朗核设施。
▲伊朗福尔道核设施（资料图）
以色列情报和特勤局（摩萨德）前局长约西·科亨当地时间8月11日称，以色列秘密行动人员曾多次前往伊朗福尔道核设施。
据以色列方面消息，科亨在以北部城市塞费德举行的一场活动中说：“我们去过福尔道核设施许多次，以了解这一场所。”他没有披露详情，包括时间和具体行动。
去年6月，以色列和美国袭击伊朗，美方轰炸伊朗福尔道、纳坦兹和伊斯法罕三处核设施。美国媒体报道称，大约440公斤丰度为60%的浓缩铀被深埋在这些核设施的废墟下，但以方认为，伊朗在轰炸后把其中一些浓缩铀转移到纳坦兹核设施附近的“镐山”地下核设施。
美国方面消息还称，以色列情报部门认为，伊朗已于去年秋天将数千台铀浓缩离心机转移至“镐山”地下隧道内，以方已将上述情报通报美国。美国总统特朗普多次威胁空袭“镐山”核设施。
科亨2016年至2021年担任摩萨德局长。据悉，科亨今年1月接受媒体采访时披露，摩萨德曾策划对福尔道核设施实施一场大规模、高度复杂的秘密破坏行动，但因2015年伊朗核问题全面协议达成而搁置。
