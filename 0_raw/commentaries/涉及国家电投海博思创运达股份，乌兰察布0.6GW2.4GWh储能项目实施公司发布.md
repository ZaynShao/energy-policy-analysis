# 涉及国家电投/海博思创/运达股份，乌兰察布0.6GW/2.4GWh储能项目实施公司发布

![image](https://mmbiz.qpic.cn/sz_mmbiz_gif/UlFs2V2deGGKEDibhk7Eia22LDrNLxB6OgxVpll7E3b0mibBZia8uXbfbUsDemdSQhPzJ5VCQ9X8EPp3zQWJ5kCafQ/640?wx_fmt=gif&from=appmsg)

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/nJIHJiauQqnz6VBj0uTricSqbFeTjYA87gs8c7tpsicGRfrlUcwWwHsxaJoevJOHwvOvRbTfcB01miciaXxavYHG1GjdMuvhAUPg8G4MjUP2yOAw/640?wx_fmt=jpeg&from=appmsg)  

储能与电力市场获悉，3月11日，乌兰察布市2026年-2027年独立新型储能电站项目落地实施公司的公告发布。  
本次对此前乌兰察布市独立新型储能电站项目其中的3个项目落地实施公司进行公示。项目装机容量均为200MW/800MWh，总规模为0.6GW/2.4GWh。项目业主涉及国家电投、海博思创、运达股份。  
![image](https://mmbiz.qpic.cn/sz_mmbiz_png/nJIHJiauQqnzM6dExia3jjOLx3YIm24BC76YtE7Q6Hq6MbMjCW6x3tUvOD6RR09gnQzGA7CkTC80m90kEJdibYCuib6d6IibPPM9klTBJdHDvzY0/640?wx_fmt=png&from=appmsg)  

1月12日，乌兰察布市独立新型储能电站项目投资主体优选结果公示。详见：[2.2GW/8.8GWh，远景/运达/大唐/华润/中铁等入选乌兰察布独立储能优选](https://mp.weixin.qq.com/s?__biz=Mzk2NDQyNDY3OQ==&mid=2247566021&idx=1&sn=970ccfac3b58010bd096a3ed75838fa1&scene=21#wechat_redirect)

近日，阿拉善高新技术产业开发区、阿拉善左旗、额济纳旗、乌达区以及乌兰察布多个地区，相继发布电网侧独立新型储能电站项目开发主体变更的公告。共公示了14个项目，合计规模为2.6GW/10.4GWh。  
乌兰察布市：3个，项目规模0.6GW/2.4GWh；  
  
乌海市：3个，项目规模0.5GW/2GWh；  
阿拉善盟：8个，项目规模1.5GWh/6GWh。
