# 湖北、湖南、河南、江西电力互济市场正式启动连续结算试运行，157家参与，市场成交电量2438万kWh

来源：国家能源局华中监管局
「
储能与电力市场
」
获
悉，7月1日，
华中区域（东四省）电力互济市场正式启动连续结算试运行
，标志着覆盖
湖北、湖南、河南、江西
四省的日前/日内省间电力互济互保机制全面落地，区域资源统筹优化配置平台作用进一步提升。
首日交易数据显示，华中区域各省经营主体参与踊跃，交易技术系统运行平稳，互济交易成交结果有效支撑了电网调度运行实际需要。157家经营主体参与日前市场交易申报，中标主体96家，包括44台燃煤火电机组、51家新能源场站和1家电网企业。市场成交电量
2438万千瓦时
，跨省最大互济电力达
131.5万千瓦
。
看个广告休息一下
自年初《华中区域（东四省）电力互济交易实施细则》印发以来，华中能源监管局加强政企协同，推动国网华中分部及四省电力调度机构、交易机构、电网企业、发电企业密切协作，仅用时五个多月高效完成技术支持系统建设、政策宣贯、多轮联调联试及模拟试运行，实现了从机制设计到系统落地、从制度空白到具备正式运行条件的跨越式发展。此次连续结算试运行的启动，既是对前期建设成果的全面检验，也为应对迎峰度夏电力安全稳定供应提供了市场化调节手段，有力支撑华中区域新型电力系统高质量建设。
下一步，华中能源监管局将会同相关单位，
持续跟踪市场运行情况，动态完善交易规则和技术支持系统，持续扩大经营主体参与范围
，推动电力互济机制常态化、规范化运行，为华中区域能源低碳转型和电力保供大局作出更大贡献。
