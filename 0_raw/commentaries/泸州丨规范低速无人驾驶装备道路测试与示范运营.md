# 泸州丨规范低速无人驾驶装备道路测试与示范运营

- 总则：明确制定目的、适用范围（低速无人驾驶装备的定义、类型）、总体原则（安全第一、审慎包容、部门协同、总量控制等）。 
- 组织管理：设立市级领导小组、牵头部门及专家委员会；明确市级各部门（经信、公安、交通、网信等）和区（县）政府的职责分工。 
- 申请条件：规定测试与运营道路（区域）的选定流程；明确申请主体（企业）、无人驾驶装备（安全技术、保险、标识等）和安全员（资质、培训、响应能力）应满足的条件。 
- 道路测试与示范运营申请：分别列出道路测试和示范运营的申请材料、具体申请流程（区县初审→市级复审→核发通知书和标识牌），并规定许可有效期（不超过18个月）。 
- 道路测试和示范运营管理：实行总量调控、分区限额、动态调整；要求“一车一码”标识牌、数据实时上传；明确增加装备、异地互认、信息变更、运行要求（禁止载人载危货、数据存储等）；设立约谈整改、撤销许可、报告报送等监管措施。 
- 交通违法与事故处理：按现行交通法规处理违法和事故责任；事故后须立即停止、保护现场、限时报告；整改后可重新申请，测试里程重新累计。 
- 附则：非公开道路运营由场地管理方负责；各区（县）可制定实施细则；文件有效期2年，由牵头部门负责解释。
