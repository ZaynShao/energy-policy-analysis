# 跌破3亿桶！美国战略石油储备处于1983年1月以来最低水平

美国战略石油储备原油库存已降至3亿桶以下，为43年来最低水平，对伊朗持续的战事对全球原油库存造成压力。
据美国消费者新闻与商业频道（CNBC）报道，美国能源部当地时间8月10日发布的数据显示，美国战略石油储备上周减少了610万桶，降至2.987亿桶。美国战略石油储备于1975年成立，是美国政府为避免突发安全事件造成石油供应中断而建立的储备，目前处于自1983年1月以来的最低水平。
今年3月，当伊朗封锁关键能源运输通道霍尔木兹海峡后，美国总统特朗普下令以“交换”方式释放1.72亿桶原油。美国能源部表示，未来这些原油将全部返还战略石油储备，并额外归还3500万桶。
据报道，美国战略石油储备的授权储量为7.14亿桶，在美国和以色列于2月袭击伊朗之前，美国战略石油储备规模约为4.15亿桶。当特朗普下令的石油释放计划完成后，美国战略石油储备量将降至约2.43亿桶。
人们开始担忧美国政府的石油储备是否已经接近耗尽。美国能源部一名发言人7月份告诉CNBC，维持战略石油储备安全运行所需的最低数量约为7000万桶。
此外，美国原油出口近年来快速增长也推动了库存减少。据美国“政治新闻网”报道，7月底，美国原油出口量已升至每天约350万桶，较去年增长近30%；汽油、柴油等成品油出口量也增长约20%，超过每天800万桶。支持限制出口的人认为，大量能源流向海外推高了美国国内燃油价格。不过，目前白宫仍反对出口限制。
值得注意的是，美国战略石油储备设施正面临越来越大的运行压力。根据美国国会下属的政府问责局5月发布的一份报告，由于基础设施老化，战略石油储备的运行能力正面临风险。
CNBC称，调查人员发现，截至2025年12月，美国战略石油储备超过1/4的库存因“施工停运以及地下储油洞穴停运等多种原因”无法用于提取。有能源咨询机构在分析报告中称，这意味着目前美国战略石油储备中至少有1.03亿桶石油无法使用。
