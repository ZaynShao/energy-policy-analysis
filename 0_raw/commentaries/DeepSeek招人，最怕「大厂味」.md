# DeepSeek招人，最怕「大厂味」

刚刚过去的周末，对于DeepSeek招聘团队来说，大概无暇休息。
6月25日，向来秉持“小而猛”风格的DeepSeek，突然抛出一条重磅招聘信息，明确要将所有部门的规模扩大至少一倍，并一次性开放33个空缺岗位，涵盖算法、运维、产品、工程等7大业务线，甚至连医学法律、小语种的跨界人才都要，工作地点为北京和杭州。
“让新人承担最核心、最重要的任务”“在这里，许多同学迅速成为行业顶尖人才。”DeepSeek在招聘文案里表示。
消息一出，瞬间引发广泛关注。毕竟，梁文锋的天才光环、DeepSeek的传奇崛起，早已让这家公司成为无数人梦寐以求的下一站。社交平台上自称“DeepSeek招聘HR”的博主“一只大蜗牛”透露：“官网简历很快破万，私信也被问爆了，根本回不过来，建议大家最好过一两天再投。”
此前职场圈流传着一个梗：DeepSeek不看大厂履历，怕被“大厂味”带偏了。《财经天下》从上述HR处了解到，这并非段子。正如梁文锋对技术的极致热爱，DeepSeek的招聘理念也一脉相承。以AGI（通用人工智能）核心业务管培生为例，该岗位面向在校生及毕业三年内的年轻人，虽然梁文锋本人不一定参与面试，但面试将重点看人选的素质、对AI的热爱，而非经验对口程度。
DeepSeek缺人不是一天两天的事了。6月21日，刚入职不久的DeepSeek Harness团队负责人崔添翼曾在社交平台发文称，自己的部门工作繁重，非常缺人，“我每天都在面试，以及在各种地方张贴小广告”。
四天后，DeepSeek官方正式公开撒出英雄帖，算是彻底向外界亮明了公司全面扩张的决心。
《财经天下》在招聘平台上看到，DeepSeek实行14薪制度，其中大模型全栈工程师（校招社招均可）月薪在4万~7万元区间，深度学习研发工程师月薪在6万~9万元区间，Agent深度学习算法研究员月薪在7万~10万元区间。
这些岗位折算下来均为年薪百万元级别，如此大手笔的薪酬福利，背后离不开真金白银的支撑。
但问题是，DeepSeek的赚钱能力一直是个谜。
2025年3月1日，DeepSeek在知乎开设账号，曾首次发帖披露过成本和利润率，根据公司测算，V3/R1推理系统理论日利润高达346万元人民币，成本利润率为545%。
不过，DeepSeek方面表示，实际上并没有这么多收入，因为V3的定价更低，同时收费服务只占了一部分，另外夜间还会有折扣，所以实际收入低于理论值。
有信息通讯方面的答主在帖子下面质疑称，DeepSeek的计算方式不靠谱，“它假设所有的API（应用程序编程接口）都是对外出售，实际上得有相当大比例是供大家免费使用，只是说如果纯做API生意，不亏本而已”。
外界种种猜测之下，梁文锋大规模扩招的底气究竟何在？答案似乎很难绕开他个人的财富实力。
梁文锋最不缺的就是钱
公开报道勾勒出的梁文锋形象，仿佛是从小说中走出来的男主角，名校毕业、量化炒股积累巨额财富、创建AI公司，再用资本反哺自己的科技理想。
1985年，梁文锋出生于广东省湛江市一个教师之家。他的数学天赋从小便展露无遗，小学六年级获得数学奥林匹克竞赛全国二等奖。高考时，梁文锋以806分的成绩上了清华大学的录取分数线，但他选择的第一志愿是浙江大学的电子信息工程专业。
在浙江大学就读期间，梁文锋就对金融市场产生了浓厚兴趣，尤其2008年全球金融危机期间，市场急需抗风险的绝对收益策略，依托算法对冲控回撤、逆势盈利的量化交易迎来发展风口，他敏锐抓住机遇，开始探索机器学习技术在全自动量化交易中的应用潜力。毕业后，梁文锋如愿踏进金融市场，并于2015年创立量化私募公司“幻方量化”。
彼时正值中国量化私募高歌猛进期，一方面能够融券的股票数量激增，另一方面随着计算机技术进步，人工智能手段被大量应用，这些外界条件助力幻方量化在2019年管理规模突破百亿元，2021年一度超过千亿元，跻身国内量化私募“四大天王”之一。
2025年，私募排排网数据显示，幻方量化管理规模超700亿元，收益均值达56.55%。拉长时间看，幻方量化近三年的收益均值为85.15%，近五年的收益均值为114.35%。若以700亿元规模，1%的管理费和20%的绩效费计算，幻方年收入或超80亿元。
但故事的精彩之处不在于赚钱，而在于花钱。幻方量化拥有在成熟、可变现赛道持续产生现金流的能力，依靠这些财富，梁文锋转向另一个更具想象空间、但短期回报不确定性的领域，探索技术上限。
2019年开始，幻方量化累计投资超亿元、占地面积相当于一个篮球场的AI超级计算机“萤火一号”投入运作，号称可以匹敌4万台个人电脑的超级算力。2021年，幻方量化再斥资10亿元购买了1万张英伟达A100GPU芯片，建成“萤火二号”。那一年，ChatGPT还没出生，国内拥有超过1万枚GPU的企业不超过5家。
在算力上不计成本地投入，为日后DeepSeek的爆发埋下了伏笔。
2025年春节，DeepSeek-R1以开源、低成本、高性能的姿态横空出世，在AI圈激起一波惊涛骇浪，微信朋友圈被AI生成的诗歌、代码大规模刷屏，那个标志性的蓝色小鲸鱼图标迅速登顶中美等多国苹果App Store免费总榜。
同一时间，梁文锋以DeepSeek创始人的身份登上央视《新闻联播》，一时间，全国人民都认识了这位面容寻常的年轻人。梁文锋也由此迎来高光时刻：入选《时代》杂志2025年全球100位最具影响力人物榜单，与马斯克、扎克伯格等大佬并列，《财富》亦将其评为全球100位最具影响力商界人士。
随着聚光灯转向DeepSeek，更令人意外的细节浮出水面——这家公司2023年才成立，从未进行任何广告投放，团队成员仅100余人，且以本土高校人才为主，几乎无海归。相比之下，OpenAI拥有1200名研究人员。正是这支“小而纯”的中国团队，用极有限的资源，在全球AI竞赛中撕开了一道口子。
“DeepSeek从起步阶段就走出了一条区别于传统AI创业企业的发展路线。”一位AI技术从业者对《财经天下》评价道，“AI烧钱毋庸置疑，但DeepSeek不靠融资烧钱，无需通过路演PPT对外展示变现潜力，其持续的技术研发、算力采购、人才薪酬等开支皆由母公司幻方量化自有收益支撑，这条路很难再有同行能够复制”。
有钱为何还要融资？
长期依赖幻方量化“输血”，终究不是长久之计。虽然梁文锋在接受36氪采访时曾表示“短期内没有融资计划，我们面临的问题从来不是钱”，但AI赛道每天消耗的资金量级，对任何一家公司而言都是沉重的负担。
更何况，DeepSeek在竞争对手纷纷涨价的情况下，选择了一条相反的路——逆势降价换取增长。
2026年以来，由于芯片产能跟不上Token需求的爆发式增长，几乎所有的国内头部厂商都被迫调整定价策略。智谱于2月、3月、4月分三次上调API价格；MiniMax于6月初将29元的Token月租套餐直接涨至49元；一向亲民的豆包也推出了收费的“专业版”；Kimi、阿里云也相继收紧免费用量、切换Token计费方式。
反观DeepSeek，却在5月22日晚间官宣，将旗下旗舰通用大模型DeepSeek-V4-Pro的API价格永久调整为原定价的四分之一。
这套以低价抢占开发者生态的长期战略，自然离不开资金投入。为此，DeepSeek罕见地进行了融资。6月16日，多家媒体报道称，DeepSeek完成自成立以来的首轮外部融资，募资总额超500亿元人民币，创下中国AI行业单轮融资规模之最。本轮融资后，公司估值约3380亿元，跻身国内估值最高的AI企业行列。
不同于其他初创公司，DeepSeek的出资配比非同寻常，腾讯出资100亿元，宁德时代出资50亿元，京东、网易、IDG资本各出资30亿元，国家人工智能产业投资基金出资10亿元，梁文锋本人则以200亿元成为最大出资方。
工商信息显示，目前梁文锋直接持有DeepSeek公司34%的股份，最终受益股份约84.29%，拥有近乎100%表决权。这意味着，即使有了外部财力支持，DeepSeek仍不受资本束缚和操控，梁文锋拥有绝对话语权。
在奕丰基金投资经理、宏观策略分析师李净看来，DeepSeek近期的一连串操作，不排除是刻意安排的。先是4月进行工商变更，把控制权锁死，又是6月16日传出融资500亿元的消息，紧接着是6月25日的公开扩招。“如果没有融资给的估值锚，期权将是废纸，翻倍招人有可能被外界视为在用空头承诺抢人。”
李净还对《财经天下》提到，虽然量化公司很赚钱，但与DeepSeek的钱不能画等号。过去几年，所谓的“幻方量化养DeepSeek”的说法，实质上是幻方赚钱后，梁文锋作为股东拿分红，再以个人/股东借款或增资的形式投进DeepSeek。
“他现在愿意公开外部融资，不是幻方没钱了，是AGI烧钱量级已经超过一家量化私募分红能扛的上限。此外，往长远IPO方向考虑，DeepSeek也需要作为独立主体完成市场化融资布局。”李净称。
中国企业资本联盟副理事长柏文喜对《财经天下》表示，DeepSeek融资的核心原因是AI竞赛已进入“重资产消耗战”阶段，大模型训练成本呈指数级上升，GPT-4级别的模型单次训练成本已超过1亿美元。DeepSeek此前发布的模型已证明技术实力，但要与OpenAI、谷歌等巨头竞争，仅靠幻方输血已显不足。
值得一提的是，多金的梁文锋，并没有盲目烧算力堆大模型。日前，DeepSeek官方在Github低调发表了一篇最新论文，介绍其推理加速框架DSpark，试图解决大语言模型在高并发场景下的推理效率瓶颈，论文作者栏中，梁文锋位列其中。业内人士认为，DeepSeek此举旨在长期大幅压缩推理端持续算力开销。
前期DeepSeek因幻方量化不差钱养着它，后期则靠耀眼的实力吸引投资者争相加入。铅笔道报道称，过去数月，围绕DeepSeek表达投资意向的资金规模超过1000亿元，以500亿元最终落地规模计算，超过一半的意向资金被梁文锋拒之门外。
