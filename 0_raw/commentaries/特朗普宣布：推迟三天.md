# 特朗普宣布：推迟三天

特朗普宣布推迟对加拿大加征50%关税。
美国总统特朗普18日晚宣布，推迟三天对加拿大商品加征50%关税。该关税原定于美东时间19日正式生效，涉及价值约200亿美元的加拿大商品。
特朗普当晚在社交媒体“真实社交”发文说，加拿大和美国已达成协议，最终文件内容待敲定，美方将推迟三天对加拿大商品加征50%关税。
据加拿大媒体报道，加拿大总理卡尼18日晚与特朗普通电话，就避免美国对加拿大商品加征关税进行磋商。
通话结束后，加拿大政府负责加美贸易的部长多米尼克·勒布朗与美国贸易代表贾米森·格里尔及商务部长霍华德·卢特尼克进一步沟通。
特朗普7月20日签署多个公告，依据《斯穆特-霍利关税法》第338条款对从加拿大进口的红酒、曲棍球棒和水泥等数百项特定商品加征50%关税。
