# 拒绝做爱以后，我们分手了丨伴侣「越界」报告

在亲密关系里，“边界”很少被叫作边界。
它通常会被翻译成更简单的一句：
你到底爱不爱我？
“我想一个人待会儿”，是“我不想和你待在一起”；不肯交出手机，是心里有鬼；就连“我今天很累，不想上床了”，也可能被追问“你是不是对我没感觉了”。边界最尴尬的地方是，很少有人在恋爱刚开始时把它说清楚，而等恋爱程序启动后，再开口就晚了。
可人总有想自己待着的时候，总有不想被追问的事。伴侣之间到底要共享多少，又该各自留下多少空间？哪些要求算亲密，哪些已经越界？
今年七夕，为了聊清一个经常被“相爱”糊弄过去的问题，“后浪研究所”发起一项“伴侣越界小调查”，共收回有效问卷772份。
一起来看看，爱一个人，到底赋予了TA多少进入我生活的权利？
手机，大概是当代人最浓缩的一块私人空间。社交、花钱、爱好和工作，都叠在一块屏幕里，那么这块屏幕要在亲密关系中开放到什么程度？
“后浪研究所”的调研显示，在伴侣愿意分享的软件中，社交平台、购物平台、游戏账号都获得了半数人以上的选择。而大家不那么愿意公开的则是：网盘、支付宝和微信，中译中即“云端隐私、钱、聊天记录”。
而对于“查手机”这件事，多数人并没有把“亲密”理解为手机的无条件开放。
42.6%的人要求伴侣查手机前先征得同意，真正接受随时被查的人只有11.3%。潜台词就是：手机可以给你看，但什么时候看，得先问过我。
有意思的是，随着恋爱次数的增加，对手机的敏感度也在不断提升，恋爱次数在6段以上的人，“完全不接受查看”的比例最高，可能是实实在在经历过查手机导致的些许风霜吧🚬
至于说介意被查手机的原因，隐私空间、担心过度解读是核心。
介意被查的人，也并不是因为真的有什么不可告人的秘密。仅有12.2%的人表示手机里存在“不能”让对方知道的内容，34.8%的人则是“不想”让对方知道手机里的内容。
真正让人厌恶的，是被监视、被过度解读，以及失去对自己隐私的掌控的感觉。
好在查手机并没有变成伴侣间的高频动作。半数以上的伴侣平时不会翻看对方手机，偶尔心血来潮看一次，已经是最常见的状态。
不过，查得少也不能直接等同于更信任，真想藏起来的东西，可能在递出手机前已经删掉。
如今来说，接受查手机的意义，更多是代表一种态度确认而已。
那不想共享手机的伴侣又是咋想的呢？谈过和没谈过的想法差别很大，超过7成的“母单”认为这只是个人边界，而谈过6段以上的人中，近6成首先怀疑对方有秘密或心虚。
反差也正出在这群“恋爱达人”身上。他们中有五分之一完全不接受互查，却最容易对伴侣的“不共享”起疑。只能说，谈得多了，边界和警惕都可能变重。最想守住自己手机的人，也最难相信伴侣只是想守住手机。

查手机，只是边界的第一关。屏幕一锁，现实里的考题才刚开始：周末一定要黏在一起吗？半天不见算不算冷淡？消息没有秒回是不是太过分了？
想象中的恋爱，往往比现实里的恋爱更黏人。“后浪研究所”的调研显示，在大家的理想情况中，每周独处一天就够了，想要独处两天以上的只有11.7%。
然而目前正在恋爱中的年轻人现身说法：两天以上的独处时间很重要，占比达到28.2%，是前者的2倍多。两个人相处得越密，越需要放空一下自己。
看完了时间，我们再来看看空间。这种想象与现实的落差，到了物理空间上后更加明显。
理想中，能接受“没有独立空间”的只有不到2成人，现实里，近一半人的已婚/同居情侣都在完全共享全部空间。实际能拥有一间独立房的，不到1成。
不过即便独立空间如此稀缺，仍有38.3%的人表示，在黏糊的同居生活中，倔强地拥有一丁点儿独立区域，比如一张书桌或一个办公台。
大家的边界其实很清楚，可以独处，但不能失联。个人空间一旦落到聊天框里，另一道题就来了。对象要求我“秒回消息”，算不算是一种越界？
大多数年轻人的答案是“偶发可以理解，长期要求会感到压迫。”
在秒回这件事上，恋爱经历也会改变人们对越界的判断。恋爱经历为0的人，对秒回的要求很难理解，只有1.7%的人认为这种要求不算越界。而恋爱经历越多，人们越容易把催回复理解成“对方在乎我”。

你发现没有，高端的越界，往往以最亲密的形式出现。
好朋友间，我们几乎不会去问“你为什么不给我看微信”；同事间，我们尽量避免打探对方的私人信息。
可偏偏到了恋爱里，人经常有一种非常特殊的想象：既然我们这么亲密，就应该没有秘密、没有距离、没有拒绝。
很多日常不能容忍的越界行为，在亲密关系里反而容易获得一种“爱情豁免权”。但，亲密本身，从来不等于授权。
恋爱不意味获得能随便翻对方的微信，吃醋不等于能让伴侣跟自己的朋友断交，同样，爱不代表对方随时都愿意和你发生关系。
在电影《痴迷》中，男主Bear暗恋女主Nikki，于是借助“许愿柳”，让Nikki痴迷于自己。愿望真的实现后，女主变的无法忍受分离、让全部生活围绕男主运转。电影的最后，男主Bear终于得到了一个永远不会拒绝自己的爱人，但也完全被一种令人窒息的“爱”控制。
或许，没有拒绝的自由，“同意”就失去了意义；没有离开的可能，“留下”也很难证明是爱。
