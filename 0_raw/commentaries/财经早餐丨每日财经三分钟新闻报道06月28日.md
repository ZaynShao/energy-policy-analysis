# 财经早餐丨每日财经三分钟新闻报道06月28日

01 今日财经头条
- 国家发改委、国家能源局：发布《新型能源体系建设“十五五”规划》，预计能源重点项目投资超20万亿元，将实施非化石能源十年倍增行动，特高压直流通道新增投产15回，电网投资较十四五增长30%以上。
- 中国商务部：在柏林与德国工商大会共同举办“德国产品‘出口中国’”论坛，中德企业表示中国产业转型升级为合作带来新机遇，商务部副部长凌激强调愿扩大自德进口。
- 国家统计局：今年1—5月全国规模以上工业企业利润同比增长18.8%，较前4个月加快0.6个百分点，其中采矿业增长33.5%，制造业增长20.0%，工业品价格涨幅扩大推动营收提速。
- 新华社：文章深入探讨新发展理念引领中国经济高质量发展，强调内需主导在当前经济转型中的战略意义，为市场提供宏观定调，稳定了经济发展预期。
- 美银：发布警告称，上周美股基金净流入创纪录后资金流向迅速逆转，本周已录得85亿美元净流出，机构认为若流动性退潮，今年夏季市场或将迎来避险行情。
- 土地市场：深圳、杭州、长沙等城市核心地块高溢价成交并刷新楼面价纪录，业内分析认为热度回升源于供地“缩量提质”及房企聚焦核心资产，但市场整体仍呈结构性分化。
02 宏观与政策
- 国务院：对下一阶段财政工作进行部署，重点聚焦地方政府专项债券管理、财政补贴政策执行及中央财政资金使用效率，旨在进一步优化财政资源配置。
- 国家医保局：第12批国家组织药品集采启动申报，涉及65个品种，覆盖代谢性疾病、心血管、肿瘤等领域，本次集采沿用“稳临床、保质量、防围标、反内卷”原则。
- 中国人民银行：会同海关总署对《黄金及黄金制品进出口管理办法》修订征求意见，内容涉及简政放权、便民利企和加强监管三方面，旨在优化进出口管理。
- 国家知识产权局：批复同意雄安新区开展国家级知识产权保护中心建设，面向新一代信息技术和新材料两大领域提供快速预审、确权、维权一站式服务，专利平均授权时间将缩短70%。
- 中国证券投资基金业协会：证监会主席吴清在会员代表大会上表示，公募基金规模已突破39万亿元，五年来累计分红2.5万亿元，基金业正经历从“重规模”到“重回报”的重大转变。
- 四川省发改委：印发《四川省支持绿色低碳发展若干政策措施》，从资金补助、金融赋能、要素保障三个维度提出14条举措，其中工业及能源领域节能降碳改造项目最高可获2000万元补助。
- 郑州市民政局：自7月1日起，郑州最低生活保障标准由每人每月841元上调至899元，特困人员救助供养标准同步提升至不低于1349元/月。
- 上海市人社局：自7月1日起调整失业保险金支付标准，第1—12个月支付标准上调35元至2340元/月，第13—24个月及延长领取期间分别调整为1872元/月和1690元/月。
- 中信证券等12家券商：同日公布薪酬管理制度，目前超34家券商已完成修订，改革围绕绩效薪酬占比、递延支付及追索扣回机制，强化风险管控导向。
03 环球视野
- 美股：周五全线下挫，费城半导体指数重挫5.6%，核心科技股遭抛售，存储芯片三巨头跌幅超10%，中概股相对抗跌逆势上扬，资金流向医疗、金融等防御板块。
- 纳斯达克：本周连续五个交易日下跌，累计跌4.6%，标普500累计跌近2%，道指则涨0.6%，科技股因AI投入回报疑虑遭抛售，“美股七巨头”ETF较高点回落14%。
- 欧洲央行执委施纳贝尔：警告食品、商品和服务通胀面临上行风险，能源价格冲击可能加剧通胀动态，预计欧洲央行将进一步加息以将通胀拉回2%水平。
- 韩国综合股价指数：本周第二次触发熔断，盘中一度大跌超8%，数据显示外资年内净流出约950亿美元，散户加杠杆接盘导致波动剧烈。
- 标普全球：确认美国长期主权信用评级为“AA+”，短期为“A-1+”，展望稳定，评级确认缓解了市场对美债信用的短期担忧。
- 伊朗外交部：谴责美军对伊朗南部沿海发动空袭，称违反谅解备忘录，将依据国际法维护主权，中东局势再度趋紧，支撑油价风险溢价。
- 委内瑞拉：24日强震已致920人遇难，3360人受伤，超5.3万人下落不明，含7名中国公民，政府已评估国内库存，石油设施未受严重影响，日均原油产量维持120万桶。
- 瑞士能源企业阿克斯波公司：因高温导致河水温度过高，无法冷却核反应堆，欧洲最老核电站贝兹瑙核电站于26日暂停运行。
04 A股与港股
- 上证指数：本周（6月22日—26日）累计下跌1.55%，市场震荡调整，深证成指本周累计下跌1.55%，与上证跌幅同步。
- 科创50指数：本周逆势大涨6.32%，成为结构性行情中的亮点，中芯国际单周市值增幅超1000亿元，成为本周逆势市值增长的代表。
- 主力资金：本周沪深两市主力资金合计净流出2169.35亿元，其中光模块龙头中际旭创净流出超137亿元。股票型ETF和跨境型ETF合计净流出776.91亿元，宽基指数ETF净流出978亿元。
- Choice数据：近两周共263家上市公司接受机构调研，电子设备行业热度最高，调研超800次，国泰海通调研次数居首达42次，机构关注方向高度集中于科技成长领域。
- 市场观察：本周A股两市融资余额突破3万亿元，融券余额占比不足1%，表明市场多头占据上风，增量资金介入下日成交量再度见到3.59万亿元。
- 股票回购：Wind数据显示，27日38家公司发布39个回购相关进展，药明康德已完成10亿元回购，神州泰岳、儒意电影、可孚医疗拟分别回购不超6亿元、3亿元、2亿元。
