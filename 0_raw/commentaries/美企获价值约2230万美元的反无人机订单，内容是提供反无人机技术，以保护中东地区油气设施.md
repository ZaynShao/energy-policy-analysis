# 美企获价值约2230万美元的反无人机订单，内容是提供反无人机技术，以保护中东地区油气设施

美国一无人机生产商宣布获得一份商业合同，提供反无人机技术以保护中东地区油气设施。
美国无人机生产商自主能手公司当地时间8月20日宣布获得一份价值约2230万美元的商业合同，内容是提供反无人机技术，以保护中东地区油气设施。不过，该公司没有披露客户身份、反无人机系统部署位置等详细信息。
据悉，自主能手公司主营防务与基础设施的防护系统，包括空海装备及相关技术支持等。根据合同，该公司提供的反无人机系统完成部署后，能够侦察、跟踪空域内目标并研判无人机威胁等级，数据汇总至客户中央管控枢纽后生成统一空情态势图，帮助操作人员掌握空中动态。
据自主能手公司介绍，按照设计，这套系统未来可接入该公司研发的“卫士”无人机拦截器，以便在“威胁升级”情形下突破单纯探测预警的功能范畴。公司联合创始人兼总裁布雷特·韦利科维奇表示，这份商业合同印证了公司所预判的反无人机市场发展方向，即着眼于打造“针对关键油气设施的一体化、网络化防护体系”。
