# 奥托立夫与长城汽车签署全球战略合作协议

加入供应链产业群，请加微信gasgoo88，出示名片
盖世汽车获悉，7月6日，奥托立夫与长城汽车正式签署全球战略合作框架协议。此次签约标志着双方合作全面升级，将围绕多个关键领域展开深度协同。
图片来源：奥托立夫
根据协议，双方合作内容涵盖全球市场拓展与供应链保障、海外本地化生产、约束系统集成开发与前沿技术合作、产品共通化推进、可持续发展与品牌协同，以及人才与组织能力建设等方向。协议旨在以长期主义为导向，进一步巩固互信、稳定合作预期，通过构建长期稳定的全球战略合作关系，共同提升全球市场影响力，推动实现高质量发展。
长城汽车方面表示，此次深化合作基于双方对安全使命的共同坚守。在全球产业出海加速的背景下，奥托立夫在技术和服务方面提供的确定性、安全性与及时性，为未来共同创造价值、助力中国产品走向更广阔市场奠定了坚实基础。
奥托立夫方则认为，依托长城汽车的全球化发展布局和自身在汽车安全领域的全球领先能力，双方将进一步深化协同，构建更加紧密、更具韧性的战略伙伴关系。
本次全球战略合作的升级，是双方建立二十余年合作关系基础上的重要里程碑。双方表示，将以长期主义为核心导向，持续推进技术创新、全球布局与体系协同，构建稳定、可持续的合作生态。
