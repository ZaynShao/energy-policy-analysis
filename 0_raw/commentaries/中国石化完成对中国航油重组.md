# 中国石化完成对中国航油重组

中国石化完成对中国航油重组，发力绿色航空燃料产业。
从中国石化新闻办获悉，中国石化宣布完成对中国航油的重组工作，中国航油正式成为中国石化二级全资子公司。这是推进中央企业战略性、专业化重组的重要举措，也是服务国家战略、应对国际竞争的主动作为，将提升保障国家航空能源供应安全能力和水平，推动航空能源供应绿色低碳转型，更好地服务人民美好出行需要。
2025年底，经党中央、国务院批准，国务院国资委作出中国航油重组并入中国石化战略部署。
今年1月8日，国务院国资委召开重组大会，就积极稳妥推进重组工作提出明确要求。
两家央企依法合规履行重组前置程序，6月18日，重组事项获得境内外全部监管审批。
7月9日完成工商变更登记，标志着重组工作圆满完成。
