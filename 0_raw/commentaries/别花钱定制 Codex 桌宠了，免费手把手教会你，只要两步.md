形象。可以是人，也可以是你家的猫猫狗狗。emmm，宠物照片做成桌宠，某种意义上也算真正实现了赛博永生。这一步的关键是生成一张多视角、多表情的角色设定图，保证后续动画里角色不崩。提示词直接抄这段：请根据我上传的参考图片，将其中的主体重新设计为一个长期可复用、特征稳定、适合制作桌面宠物的原创 IP 角色。参考图片中的主体可能是人物、猫、狗、其他动物、玩偶、机器人、生物、物体或虚构形象。请先自动识别主体类型，再提取它最有辨识度的特征，包括整体轮廓、身体比例、头部形状、五官布局、毛发或发型、耳朵、尾巴、角、翅膀、花纹、配色、服装和配饰等。保留最关键的识别点，减少无关细节，不要随意增加原图中不存在的新设定。请把主体转化为一个简洁、清晰、容易重复生成的卡通 IP。整体使用明确轮廓、大色块和有限配色，减少复杂纹理、写实毛发、渐变、透明材质和细碎装饰。角色需要在小尺寸下依然容易识别，身体结构清楚，适合后续制作 Idle、Walk、Run、Jump、Sleep、Think、Happy、Error 等桌宠动画。请输出一张完整的角色设定图，展示同一个角色的正面、背面、左侧面、右侧面、左前 3/4 视角和右前 3/4 视角，并补充自然站立、行走、奔跑、坐下、跳跃、趴卧或漂浮等适合该主体的动作。不要强行让动物或物体采用人类姿态，动作方式应符合主体本身的身体结构。所有视角和动作必须保持同一个角色身份。角色的头身比例、身体结构、五官位置、耳朵大小、尾巴长度、毛发轮廓、花纹分布、服装、配饰和配色不能发生变化。不要让不同角度看起来像不同版本的角色，也不要因动作变化增减身体部位或装饰。另外展示默认、开心、困惑、专注、生气、受惊、得意和困倦等表情。表情变化应建立在固定角色结构之上，只调整神态，不改变脸型、五官比例或主体身份。最终效果应接近动画、游戏或品牌 IP 的正式 Character Sheet，而不是一张单独插画。请优先保证角色一致性、结构清晰度和后续动画适配性，为下一步调用 Hatch Pet 生成桌宠提供稳定参考。接着上传多视角图片，在聊天框里输入「/Hatch Pet」来调用 Hatch Pet 自动生成桌宠。这一步的提示词就一句话：友情提示：整个过程耗时其实相当慢，而且是妥妥的 Token 刺客。不过考虑到最近 OpenAI
