# “‘双碳’目标下支撑能源转型的电价市场化改革与价格监管”专题征稿启事

2015年新一轮电力改革以来，电价改革深入推进，有力支撑了能源转型与电力市场建设。发电侧，煤电、新能源先后全面入市，部分地区积极探索其他资源入市方式，初步形成了以电力现货为核心的电价市场化体系，有效反映市场供需与电力的时空价值。电网侧，自2017年已建立“1+4”输配电价政策体系，确立并巩固“准许成本+合理收益”定价方法，第三监管周期以来持续理顺输配电价结构，输配电价监管基础得到夯实。用户侧，工商业全部参与市场交易，创新建立电网企业代理购电机制，零售市场快速发展，涵盖分时电价、差别化电价、绿色发展电价等的销售电价体系持续完善。新时期，国家高度重视完善价格治理机制，能源清洁低碳转型和全国统一电力市场建设也对纵深推进电价改革提出新的要求。国家政策方面，党的二十届四中全会审议通过的“十五五”规划建议明确提出，要“加快健全适应新型能源体系的市场和价格机制”；两办联合印发的《关于完善价格治理机制的意见》，从强化自然垄断环节监管、深化电力价格市场化改革、优化能源转型价格政策等方面，对下一步电价改革提出具体要求。能源转型方面，新能源渗透率、电能占终端用能比例将持续提升，预计到2030年新增用电量需求主要由新增新能源发电满足，对通过价格机制引导新能源开发与消纳、推动新能源消纳新模式新业态创新、增强新型电力系统对新能源适配能力等提出更高要求。电力市场化建设方面，围绕电力“能量、调节、容量”多元价值的市场化定价体系将持续健全，随着电力市场在范围上扩大、在品种上细化，新矛盾、新问题将不断涌现，对健全市场化价格体系提出更高要求。  
为进一步向纵深推进电价改革，助力能源转型发展和电力市场建设，《中国电力》编辑部特邀国网能源研究院财会与审计研究所李成仁所长、中国社会科学院冯永晟研究员、华北电力大学谭忠富教授、华南理工大学荆朝霞教授、四川大学向月教授联合担任特约主编，组织“‘双碳’目标下支撑能源转型的电价市场化改革与价格监管”专题专栏，诚邀相关领域专家、学者积极投稿。

**征稿方向（包括但不限于）**  

  

1.电价理论及能源转型成本研究

• 适应能源转型和统一电力市场建设的电价改革路径研究；

• 电价改革与提升宏观经济治理效能的关系研究；

• “双碳”目标下电价与国民经济、产业发展的关系研究；

• 新型电力系统下能源电力供应成本及疏导机制研究；

2.自然垄断环节监管机制和价格机制创新研究

• 输配电价政策实施效果评估与适应性优化路径研究；

• 输配电激励性监管框架设计与动态调整机制研究；

• 输配电准许收入核定、清算与审计监督机制优化研究；

• 提供时空信号的输配电定价方式与实证模拟；

• 电力新型主体发展下的输配电价机制创新研究；

• 跨省跨区输电价格联动机制与输电权交易模式研究；

3.电力价格市场化改革深化研究

• 高比例新能源下电能量市场竞价机制研究；

• 辅助服务市场价格机制及辅助服务费用传导机制研究；

• 能源清洁低碳转型下的发电容量保障机制研究；

• 发电侧电源全量参与市场的路径及配套机制研究；

• 现货实时市场价格信号形成与传导机制研究；

• 促进市场健康发展的零售市场价格监管制度研究；

• “电-碳-绿证”市场机制协同机理及定价机制研究；

4.用户侧及其他适配能源转型价格政策研究

• 能源转型与市场化改革下的民生用电价格机制优化研究；

• 高耗能差别化电价机制优化研究；

• 用户侧需求响应价格机制创新研究；

• 数据中心等新兴产业电价政策研究。
