# 徐志升任市委书记，曾长期在安徽省发改委工作

安徽省委决定：徐志同志任芜湖市委书记。
日前安徽省委决定：徐志同志任芜湖市委书记。
▲徐志 资料图。图源“日新安徽”
徐志此前任芜湖市委副书记，市人民政府党组书记、市长。此前，安徽省委组织部发布干部任前公示公告，其中，徐志拟任省辖市市委书记。
公开简历显示，徐志，男，汉族，1972年1月出生，安徽枞阳人，1994年7月参加工作，在职研究生学历，经济学硕士，中共党员。
徐志曾在安徽省电力设计院、安徽省计委工作过。此后，徐志进入安徽省发展改革委工作，历任能源局副主任科员、主任科员，能源办主任科员，办公室主任科员、党组秘书、办公室副主任，能源局电力处副处长、处长，省发改委产业处处长等职。2017年11月，徐志到地方挂职，任阜南县委常委、副县长。2018年，徐志晋升副厅级，出任安徽省委军民融合发展委员会副主任。此后，他还担任过安徽省发展改革委副主任、党组成员。
