# 深圳观察｜汤婉月：飞地如何真正起飞？深汕合作区的四道关键考题

从空中俯瞰粤东，深汕这片多年前还是零散渔村与荒地的土地，如今已成为一座生机勃勃的滨海产业新城。从2008年设立的“深圳（汕尾）产业转移工业园”到2011年正式批准设立深汕特别合作区，从2011年的“深圳共管”到2017年正式成为深圳的“第10+1区”，再到2023年全国首部明确由“飞出地”全面主导区域协调发展的地方性法规《广东省深汕特别合作区条例》正式施行，深汕作为深圳的飞地，用15年时间走过了体制机制捋顺的艰难阶段，地区生产总值（GDP）从2018年的38.95亿元增长至2025年的250亿元，年均增速超过30%。
在产业领域，深汕紧密围绕深圳“20+8”产业集群布局，从“一主三辅”产业体系过渡到“1+1+3+2”产业体系，聚焦于新能源汽车的“链式跃升”和高性能材料的“前沿布局”，夯实工业基底，依托技术同源、制造同源优势持续推动高端制造业向深汕集聚。但随着产业新城的加速崛起，同时也要关注到，作为全国“飞地”标杆，深汕在“制度破冰-产业先行-城市筑基-城乡共富”的发展之路上依然任重道远。
“十五五”期间深汕飞地建设面临的“四道考题”
（一）要素导入：如何让“顶级配置”驱动“深圳标准”
吸引深圳的产业、资金和人才“飞”入飞地已非难题，真正的考验在于如何转变要素导入模式，让要素从“重”到“精”，由过去“土地换项目”转换到精准导入、高质量引育相结合的路径。一是实现土地高效集约利用，目前深汕开发边界已基本框定，如何挖掘存量、优化增量，需要模式创新；二是实现资本要素升级，除了政府投资，如何吸引深圳国资及社会资本更深度介入，为深汕提供强大的资本引擎；三是实现人才与产业同频，如何将教育、医疗、住房配套的顶配资源转化为吸引和留住高层次人才的“强磁场”，实现“以产聚人、以人兴城”。
（二）产业集群布局：如何从“一业独秀”到“群星璀璨”？
自2021年比亚迪落子以来，四期项目总投资超315亿元，深汕已成功打造出千亿级新能源汽车产业集群，但目前，区内缺乏能与比亚迪形成良性竞争或功能互补的第二家整车龙头，产业链生态优胜劣汰和创新迭代的动力相对不足。避免单一企业过度依赖，构建硬核多元产业体系成为深汕未来产业发展的关键考验。一是在新能源汽车方面，在做强“整车+零部件+出口”全链的同时，如何引领“深汕智造”向上游高附加值环节攀升，夯实制造业领先地位。二是培育新兴增长极，如何利用好战略级高端电子化学品产业园等产业平台，强化项目资源导入，加快培育新材料、智能船舶、低空经济等新兴产业，形成多点支撑。三是发展现代服务业，如何补齐制造业发展所亟须的生产性服务业支撑，以软实力保障硬产业的稳定扎根和长足进步。
（三）产城融合：如何从“产业新城”迈向“诗意栖居”
深汕正处于从“产业园区”向“城市新区”转型的阵痛期，商业、文化、娱乐等城市服务功能相对匮乏。面对来自全省乃至全国的“新深汕人”及其家庭，产与城如何从物理“拼接”走向有机融合，成为必须直面的深层次难题。一是公共服务体系建设方面，深中、深职大深汕校区、深汕人民医院虽已落地，但“深圳标准”的教育医疗资源能否真正让居民在家门口享受与深圳同城同质同效的服务，尚待时间检验。二是城市交通方面，骨干路网“大动脉”初步贯通，但内部循环的“毛细血管”路网仍不完善，真正的高效通勤与便利还未完全实现。三是高品质生活圈营造方面，商业配套、文化休闲、生态环境尚未充分融入“深圳基因”，如何优化居住空间布局，营造既能吸引企业更能留住人才的“诗意栖居”品质，仍是产城融合必须跨越的关键门槛。
（四）区域辐射带动：如何从经济特区的飞地，变为东部板块高质量发展的战略引擎
解决自身发展是浅层目标，能否真正承担起带动粤东、促进区域协调发展的国家战略使命，是衡量深汕飞地价值的深层标尺。当前，深汕仍面临区域辐射能力不足、可持续共赢模式尚未成型的难题。一是产业外溢方面，以深汕为核心与周边城市共建拓展区、形成梯度分工的布局尚未成型，能否有效带动周边配套产业发展，仍存在不确定性。二是港口辐射方面，小漠港被寄予厚望成为华南汽车出海、链接世界的重要门户，但其实际能级、航线网络和物流成本是否支撑这一战略构想，仍是待解难题。三是与深圳市各区协作方面，常态化的跨城通办和政务服务对接机制尚未全面落实，部分区域对口帮扶深度广度不足，系统赋能深汕路径有待明确。

对策建议
深化体制机制改革，以制度创新赋能飞地治理。在《广东省深汕特别合作区条例》基础上，进一步明确深汕在户籍、土地、薪酬等领域的改革方案，赋予深汕更大自主权，探索设立“深汕特别合作区综合改革试验区”。加快理顺“镇改街”后的财权、事权匹配关系，赋予街道在招商引资、行政执法、资金配置等方面更大自主权，激活基层治理活力。推动深汕公共服务事项全面接入省、市政务管理系统，实现“深圳标准、深汕服务”同城同质。总结提炼可复制推广的飞地经济制度经验，为全国区域协调发展提供参考。
优化产业布局与协同，推动各产业走向“雨林共生”。以深汕汽车城为整车制造核心，推动跨区域产业协作，加快产业链协同布局。以智能网联汽车为切入点，厚植深汕科技创新资源，引进培育新一代信息技术、物联网、智能制造等前沿技术，催生新产品、新工艺、新服务。加快高端电子化学品产业园等重大平台建设，为深圳“20+8”产业集群提供关键供应链支撑。加快布局高性能材料、智能制造装备等“卫星产业”，以产业链招商补全“断点”，积极吸引检验检测等生产性服务业集聚。引入第二家新能源整车龙头或差异化竞争企业，加大出口车型排产比例，实现“港厂联动”。
推进产城融合与公共服务提质，加快打造以人为本的“活力新城”。坚持“以城促产、以产兴城”，重点补齐商业、文化、娱乐等生活性服务业短板，引入大型商业综合体和品牌酒店，打造夜间经济集聚区。推动深汕教育医疗从基本覆盖迈向质量跃升，加快构建全链条高质量教育体系和整合型优质医疗卫生服务体系。建立与产业发展联动的就业收益分配机制，增强人口本地固化意愿。同步建设人才公寓和蓝领社区，让产业工人“进得来、留得住、过得好”。推动“百千万工程”深入实施，促进城乡融合发展。
打通要素通道，构建多层次、市场化的要素流通网络。加密深汕至深圳的高铁通勤班次，降低时空成本对人才流动的抑制。优化人才引进政策，建立与深圳市区更紧密的人才流动和交流机制。探索更加灵活的土地供应机制，开展宅基地、集体经营性建设用地入市试点，破解土地权属不清、流转效率低的问题。引入创投基金、产业引导基金等市场化资本，加速从行政推动向市场牵引转型。开展“车路云一体化”、数据资产化探索，依托智能网联汽车高数据密度特点大力培育数据要素，推动其成为深汕驱动新型工业化核心引擎。推动要素协同，加快实现数据对人才、土地、资本的乘数效应。
提升辐射带动能级，打造粤东发展战略引擎。推动省级层面出台粤东新能源汽车产业专项规划，统筹深圳市区、深汕、汕尾、惠州各类资源，将深汕的产业能级、深圳的研发优势与粤东各市的资源禀赋、市场腹地深度融合，实现“研发在深圳、制造在深汕、配套在粤东、出口向全球”的梯度分工，以及“资源在粤东、转化在深汕、增值在深圳”的价值循环。深化山海协作，探索“飞海”经济模式，推动深汕海上风电、现代化海洋牧场等蓝色产业与粤东海洋资源深度融合。强化“10区帮1区”机制，建立深圳各区与深汕各街道的“一对一”产业协作清单。
