# 前海书写深港合作新篇章

六月前海，热潮涌动。
前海与香港携手搭台，大戏连连，好戏不断。
月初，深港联合打造的前海新地标——前海深港汇双向总部基地正式迎来首批13家龙头企业的入驻，其将与“托举初创”的前海深港青年梦工场一起，共同构成推动前海深港合作的“双子星”。
6月12日，香港科技大学蓝海湾前海创新港正式启用。至此，5所香港顶尖高校的成果转化平台相继落地，前海也成为全国香港高校转化平台集成度最高的片区。
6月23日，“前海香港青年科创启航计划”在香港正式启动。与以往的人才引进不同，这次，前海与香港携手，将科创培育前移到中学阶段，希冀香港中学生日后成长为支撑“香港创科、深港合作”发展的参天大树。
汇龙头、聚高校、育青苗——三个领域、三件大事，一个月内密集落地，共同释放出一个清晰信号：前海深港合作，正在从“给政策、引项目”的单点突破走向“建平台、育生态”的系统布局。
“目前，前海各领域配套政策框架已基本完善，当下核心工作不再是单纯争取新增政策，而是推动各类平台协同联动，实现政策创新的系统整合。”综合开发研究院（中国·深圳）港澳及区域发展研究所所长谢来风表示，“前海的深港合作已从此前的‘前店后厂’1.0版经济合作模式、2.0版的经贸合作模式，进入到3.0版的全面深度融合模式，呈现出深度衔接、双向奔赴、面向全球的全新特征。”
筑总部引龙头，两地联动链接全球
前海深港汇双向总部基地，是理解前海深港合作底层逻辑变化的鲜活实践样本。
这片由前海原企业公馆建筑群改造而来的园区，拥有29栋独立建筑，定位为深港双总部最佳实践地、跨境要素流动集中试验地、国内大循环和国内国际双循环的战略链接点。
目前，已有香港中华电力、TVB、劳埃德银行、黑芝麻智能、普瑞金等13家企业确定入驻深港汇。
这些企业的目标很清晰：通过“前海+香港”双总部架构，把研发、产业化与内地市场运营放在前海，将资本运作、全球商务与前沿基础科研布局香港，充分利用深港优势，双向联动，走上一条全球拓业的新路。
“如今的TVB，已经是一家立足香港的大湾区媒体。”TVB行政主席许涛在“2026湾区融合·IP扩阵”发布会上表示，入驻深港汇后，香港总部持续发挥创意孵化、国际发行、海外渠道的传统优势；前海总部扎根大湾区，重点开展内容生产、本土运营与IP多元化开发，推动两地人才、创意、资源双向流通、高效联动。
“创新药的溢价，必须到国际市场上去实现。”深圳普瑞金生物药业股份有限公司董事长、总经理栗红建说，落地深港汇后，企业可充分利用人才跨境流通、科研物资通关便利，以及前海的国际化法治环境和开放政策，更好更快地实现全球化发展。
谢来风认为，推进深港合作的核心是服务国家发展大局。当下国家有两大核心对外开放需求：一是依托前海吸引全球优质外资进入内地市场；二是借助香港国际化通道，助力内地企业、资本出海开展投资、产能合作。面向全球双向链接资源，是当前及未来前海深港合作的核心使命。
全国港澳研究会副会长、综合开发研究院（中国·深圳）资深研究员张玉阁也认为，深港汇在此背景下被赋予三大“战略锚点”定位，跳出深港局部合作视角，践行“深港协同联动、扎根国内市场、深度融入全球”的发展思路，是承接双向发展需求的关键物理载体。
目前，深港汇正围绕资金、数据、人员、物资“四个跨境”开展一揽子制度创新试点，助力龙头企业走出一条独具特色的深港协同、全球布局之路。
聚高校汇科创，双向赋能激活成果
一个完整的创新生态，不仅要有产业的“龙头”，更要有研发的“源头”。
6月12日，香港科技大学蓝海湾前海创新港项目在前海启用，首批签约入驻的10个早期优质项目涵盖人工智能、机器人、生命科学及大健康等领域，项目均由港科大教授和港科大校友创立。
把时间维度稍微拉长，此前5月，香港浸会大学前海科技创新创业研究院运营；3月，香港中文大学新质产业中心在前海揭牌……还有早在今年之前，就已在前海落地成果转化平台的香港大学、香港理工大学。
这些高校选择的，都是“香港基础研究+前海应用转化+湾区生产制造+香港上市出海”的协同发展路径。
“香港大学拥有顶尖的科学家和基础研究能力，但产业落地生产空间有限且租金高昂。前海紧邻香港，通关和交通极为便利，也能提供足够的中试和量产场地，是最理想的承接基地。”香港大学前海青年科创学院首个孵化毕业的企业——大乙半导体科技有限公司创始人、首席科学家黄明欣道出了许多港校科研团队的心声。
数据显示，前海已集聚196家企业工程中心、工程实验室、技术中心等创新载体，并已构建起“6+4+2”现代化产业体系的“四梁八柱”，形成软件与信息服务1个千亿级产业集群和人工智能、数字创意、低空经济与空天等7个500亿级产业集群，为创新成果转化提供丰富的土壤。
更重要的是，前海背靠深圳完整的产业链、活跃的资本市场和庞大的应用场景，这些恰好补上了香港产业化落地的短板。
而在前海成功迈入产业化阶段的项目，可以研发中心、国际总部的形式，返投至香港北部都会区等重点片区或寻求赴港上市机会。
数据显示，截至目前，香港高校前海科技成果转化平台集群累计孵化项目超过150个。其中，从香港高校诞生的思谋科技、留形科技等企业，在前海孵化、湾区制造、香港市场的助力下，已迅速成长为各自赛道的佼佼者，其产品远销全球多个国家和地区。
育青苗培新力，深耕人才蓄力未来
生态要持续运转，既要有当下的产业和科研，也要有未来的新生力量。
6月23日，一场面向未来的科创活动——“前海香港青年科创启航计划”在香港启动。前海与香港携手，计划全年邀请1000名14岁至18岁的香港中学生走进前海，亲手操作无人机、参与机器人编程，与企业家及工程师面对面交流。
“创科是香港北部都会区未来核心发展方向，青年则是创科发展的核心力量。”香港特区政府劳工及福利局局长孙玉菡表示，此次前海与香港携手培育科创青年人才，一方面为香港长远发展积蓄动能，另一方面也让香港青年真切感知大湾区广阔的发展机遇，自觉主动融入国家发展大局。“这是为未来十年、二十年、三十年播种子。”
“人才是深港共同紧缺的核心生产要素。”谢来风认为，“前海香港青年科创启航计划”的启动，有着多重价值：对香港北部都会区及香港而言，创科产业是北部都会区发展的核心抓手，其联动前海定向培育适配产业需求的人才，能补齐香港创科人才短板；对于深港合作，能打通两地人才培育双向通道，实现人才培育、产业需求、空间载体的三方联动，搭建长期稳定的青年科创人才输送体系；对于粤港澳大湾区，大量的后备青年力量将成为区域产业协同发展的重要驱动力。
回看前海六月的三件事，共同回答了深港“优势如何互补、创新靠什么支撑、未来如何布局”的问题。当深港两地的产业优势、科研能力、青年力量在前海这片土壤上扎根、交织、生长，深港也从合作走向了融合。
在前海街头，粤语与普通话交织，港青与内地创客比肩，港式茶餐厅与新兴科技园区为邻——处处是深港合作“你中有我，我中有你”的鲜活印记。
“未来，前海要立足自身、深化改革，更要跳出前海、服务大局。”谢来风表示，前海要牢牢守住国家赋予的“深港现代服务业合作区”核心定位，推动更深层次的规则衔接，建成制度完备、流通顺畅的深港合作示范区；同时持续发挥链接内地与全球的“桥头堡”功能，放大深港合作生态示范效应，打造可复制、可推广的全国深港融合发展标杆。（深圳特区报 记者 曾逸敏 / 封面图片来自前海管理局）
