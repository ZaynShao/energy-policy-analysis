# 从“石油独大”到“矿业新势力”丨沙特EEP政策解读及中企出海机遇

如您希望下载PDF版本，请点击文末“阅读原文”获取。
题 述
沙特阿拉伯在“2030愿景（Vision 2030）”[1]战略框架下，正加速推进经济多元化转型，将矿业定位为继石油天然气与石化之后的第三大经济支柱。依托阿拉伯地盾约70万平方公里的广阔成矿带、持续推进的勘探赋能补贴计划以及与中国不断深化的全面战略伙伴关系，沙特正逐步成为全球矿业资本关注的新兴投资目的地。本文撰写团队深耕海外矿产投资以及中东地区投资业务多年，对沙特矿业投资的最新政策动态进行简析，为有意布局中东的中国矿业投资者提供参考。
01
沙特矿业现状与投资环境
1. 2030愿景与矿业战略定位
在沙特经济多元化转型的大背景下，2030愿景将矿业定位为继石油天然气、石化产业之后的“第三大工业经济支柱”。沙特近年矿产财富估值提高至约2.5万亿美元[2]，矿业在国家产业中的战略意义已超出传统资源开发本身。具体而言，沙特希望通过矿业开发带动更完整的产业链建设：金、铜、锌、铁、磷酸盐、铝土矿等矿产可支持基础工业、化工、建材和制造业发展[3]；同时，锂、稀土等与能源转型相关的关键矿产，也融合了新能源、电动车和数字经济的供应链布局[4]。
沙特2020年新《矿业投资法》将矿物分为需加工的金属及宝石类（Class A）、工业矿物类（Class B）及建筑用途类（Class C）三种，并对外资充分开放。根据该法第13条以及实施细则第14.1.1条的规定，许可持有人仅须为沙特注册的法人实体即可。这一外资准入的开放性安排，叠加沙特的勘探赋能计划（Exploration Enablement Program, EEP）[5]补贴机制与阿拉伯地盾丰富的未探明矿藏，正为国际矿业资本以及寻求资源多元化布局的中国投资人打开投资窗口期。
2. 从蓝图到项目落地
沙特矿业正逐步从资源潜力评估和政策倡议，进入到矿权出让、勘探许可和项目合作加速推进的新阶段，越来越多的国际矿业公司开始参与沙特矿权招标和勘探项目，亦有多家中国企业参与了沙特矿产勘探许可的竞争性程序。实操层面，沙特矿业投资机会正在从宏观层面的市场关注，逐步转化为可参与、可落地的项目机会。
3. 阿拉伯地盾与投资环境改善
沙特西部的阿拉伯地盾是全球尚未充分勘探的前沿成矿带之一，大量矿藏尚未充分探明，其进一步地质调查、绿地勘探和矿产开发空间巨大[6]。
与此同时，沙特正进一步推进国家地质数据库建设和许可流程数字化[7]，并通过新《矿业投资法》为投资者提供更清晰的法律框架[8]。在弗雷泽研究所发布的2025年度全球矿业公司年度调查中，沙特首次跻身全球十大矿业投资目的地（亚洲唯一入选辖区），活跃的勘探公司数量从2020年的6家增至2024年的226家，并在政策感知、税制、许可清晰度和地质数据质量等指标上显著提升[9]。
在此基础上，沙特进一步推出勘探赋能计划，通过财政激励降低早期勘探风险，并吸引国际资本、技术和专业服务进入矿业上游环节。该计划也是沙特矿业新一轮开放和制度改革的重要举措。
02
勘探赋能计划（EEP）
1. 概述与政策定位
EEP系沙特工业与矿产资源部（MIM，沙特工矿部）与投资部联合推出的矿产勘探财政激励计划，于2024年1月在未来矿产论坛（FMF）上正式启动。该计划总预算6.85亿沙特里亚尔（约合13.3亿人民币），实施周期覆盖2024至2030年，系沙特“2030愿景”框架下矿业领域的旗舰级激励项目。
该计划的核心政策逻辑在于：矿产勘探系整条矿业价值链中风险最高、不确定性最为集中的环节，许多优质矿权因早期资金投入不足而长期搁置。EEP通过政府与投资者共担勘探支出的方式，降低早期阶段的资金压力，加速矿产发现进程，同时推动本地技能转移与国家地质数据库（NGD）的数据积累，实现财政激励与战略目标的协同。
2. 补贴机制与资金结构
依据EEP指南，单个勘探许可证的最高补贴额度为700万里亚尔（约合1,350万人民币），由技术补贴与人才补贴两部分构成。[10]
图1 EEP补贴结构一览
技术补贴
每个勘探许可证可获得技术补贴的最高额度为400万里亚尔（约711万人民币），按照“合格勘探成本”（eligible costs）的25%计算，即按比例报销企业实际发生的勘探费用。勘探费用包括钻探、测井、经认可实验室开展的地球化学分析、矿物学测试以及地球物理数据采集等前期投入较大、对找矿成败影响直接的技术工作所发生的费用，具体见下表。
在实际计算技术补贴过程中，沙特政府采用递减报销机制，并叠加最高补贴额度和比例上限。具体而言，勘探支出在0至100万里亚尔区间内可获60%的报销；100万至200万区间降至50%；此后依次递减为40%、30%和20%，超过400万里亚尔的部分原则上按20%继续计算，直至累计补贴达到400万里亚尔为止。
举例：假设企业发生合格勘探成本550万里亚尔（约1000万元人民币），按照递减报销机制，前100万里亚尔可获补贴60万里亚尔，第二个100万里亚尔可获补贴50万里亚尔，依次计算，原则上共计可获得补贴约210万里亚尔（约380万元人民币），但由于25%比例上限的限制，企业最终可获得补贴137.5万里亚尔（550万×25%），约合人民币250万元人民币。
人才补贴
人才与劳动力补贴的最高额度为300万里亚尔，由两个子项构成。其一为高端人才补贴（最高150万里亚尔），覆盖高技能员工薪资的15%，前提条件为该员工须与一名沙特国民结成“师徒制”搭档（tag-teaming），以实现技能转移。其二为本地劳动力补贴（最高150万里亚尔），用于补充沙特国民薪资成本——前两年补贴本地薪资的70%，两年后提升至100%，由沙特人力资源发展基金（HRDF）协同执行。
追回机制
EEP设有追回（Clawback）机制：每家企业最多可提交15份申请（一证一申请），其中前5份享受人才补贴且无需偿还；第6至15份则不享人才补贴，技术补贴须在进入开采阶段后偿还。
较为广泛的技术补贴范围，使得企业在勘探初期有机会实质性降低试错成本和资金压力；同时，追回机制的设置也可以防止后期获得盈利能力的企业过度占用财政资源。
3. 申请资格与评审标准
EEP的申请门槛主要包括以下条件：申请者须持有沙特境内有效勘探许可证，且许可证授予期限不超过5年；勘探矿种须为Class A类矿产，即外资可100%持股的矿种类别；申请者须通过财务和技术能力审查，并承诺优先使用本地服务供应商、向沙特国民进行技能转移。每份许可证仅可提交一份申请，每家企业最多提交15份。
评审采用百分制打分体系。权重最高的评估维度为“勘探方案设计”（20分），其次为“勘探概念”（15分），即技术路线的合理性与创新性。地质认知、已有工作了解、区域知识贡献、目标描述、人才/劳动力与预算各占10分，还有其余几项占5分。由此可见，一份具有竞争力的申请，关键在于勘探思路的清晰性、技术方案的扎实程度，以及能否为沙特地质知识库做出实质性贡献。

4. 实施进展与未来展望
自2024年1月启动以来，EEP已推进至第三波。第三波（Wave 3）于2026年1月14日在第五届未来矿产论坛上启动申请，原定3月31日截止，后经沙特工矿部延长至5月3日。依据修订后的时间表，评审阶段为5月3日至6月30日，入选名单预计于7月1日至31日期间公布。截至目前，沙特官方尚未通过公开渠道发布第三波入选企业名单。[11]
前两波共18家企业入选：第一波6家、第二波12家。官方虽未披露完整名单，但结合公司公告、媒体报道及市场信息，外资身影清晰可见，且大多采用与本土企业合资的方式：如Royal Road Minerals与沙特MIDU合资、澳大利亚EV Metals经本地子公司运营，还有几家中国头部矿产企业亦通过合资方式获得补贴资格。
图3 EEP进展
鉴于EEP此前各波次均在未来矿产论坛上启动（第一波2024年1月、第三波2026年1月），展望第四波（Wave 4）有望在第六届未来矿产论坛（2027年1月）上正式启动。建议有意向的企业密切关注沙特工矿部及Ta'adeen平台的后续公告。
03
中企参与沙特矿业投资的机遇与布局要点
1. 抢占沙特矿业布局窗口，尽快卡位优质项目
在“2030愿景”推动下，沙特矿业正加快从政策倡议走向项目落地，矿权出让、勘探补贴和产业链建设同步推进，这为中国企业提供了较为难得的市场切入窗口。对于有资源布局需求的企业而言，当前的机会不仅在于进入沙特市场本身，更在于尽早卡位优质区块、积累本地项目经验，并在未来开发和产业链合作中占据先发优势。随着国际矿业资本持续关注沙特，越早完成项目筛选、进入路径设计和本地落点安排，越有可能在新一轮区域资源配置中取得主动地位。
2. 用好沙特外资开放红利，借助本地伙伴提升落地效率
Class A矿种已对外资开放，这为中国企业以控股甚至独资方式参与沙特矿业投资提供了明确的制度空间，也意味着中企在项目选择和交易结构上拥有更大的灵活性。在此基础上，如能进一步匹配合适的本地合作方，往往更有利于提高项目落地效率。实践中，本地伙伴通常掌握着外资单独进入时不易迅速取得的“钥匙”，包括政府沟通渠道、本地供应链资源、招采执行经验以及对许可和合规节奏的熟悉度。因此，对中企而言，外资开放提供的是进入沙特矿业市场的制度基础，而与优质本地伙伴合作，则有助于将这种制度空间更快转化为现实项目机会。
3. 善用EEP补贴工具，降低前期勘探投入压力
对中国企业而言，EEP的吸引力不仅在于政策信号，更在于其能够直接改善项目前期的成本结构。根据公开规则，技术补贴可覆盖部分钻探、实验室测试和地学研究等合格支出，人才和劳动力补贴则可对符合条件的用工成本提供支持。若企业能够在项目初期即将EEP要求纳入勘探计划、预算安排、合同结构和人员配置之中，就有机会将部分前期投入转化为可回收的政策资金，从而减轻勘探阶段的资金压力，优化项目现金流和投资回报预期。
4. 把握资源开发带动的贸易与产业链机会
沙特矿业升温带来的机会并不局限于矿权资源本身，围绕地勘服务、钻探施工、实验室检测、设备供应、工程配套以及未来矿产品承购和下游加工，均可能形成新的服务与贸易合作空间。对于矿业相关领域的中国企业而言，完全可以从单一资源投资进一步延伸至“投资+设备+服务+采购”的综合合作模式，在资源合作之外分享沙特矿业扩张带来的产业链红利。
结语
凭借新《矿业投资法》对外资的放开、6.85亿里亚尔的EEP补贴政策、国际投资人/头部中资矿企的先发布局，沙特正在逐步成为全球矿业的新晋核心势力，受到普遍关注。与此同时，面对沙特矿权分类监管的复杂性、本地化要求的刚性约束、EEP项下数据共享与追回机制等，投资者亦有必要充分开展当地法律环境调研，并通过相关协议锁定权利/防范风险，从而找到唤醒沉睡千年的阿拉伯矿藏的正确方法。欢迎有兴趣的中国企业与我们联系做进一步的交流！
