# 乌克兰遭大规模袭击

乌称基辅遭俄导弹袭击，已致8人死亡。
当地时间20日，乌克兰首都基辅市市长克利奇科通报称，俄方袭击已导致8人死亡。
基辅市长克利奇科称，当地时间8月19日深夜至20日凌晨，俄军弹道导弹袭击基辅，造成人员死伤，部分地区断电。
乌克兰空军20日凌晨在社交媒体发文称，俄军对乌克兰发动新一轮弹道导弹袭击，俄军的弹道导弹正在向乌首都基辅市方向移动。
当天零时许，乌空军发文提醒称，多枚弹道导弹正在从切尔尼戈夫州和波尔塔瓦州向基辅市方向飞来。之后，基辅市响起多次强烈爆炸声，随后第聂伯区电力供应出现短时间中断。此前，基辅市已响起两轮强烈的持续爆炸声。
截至目前，俄方对此暂无回应。
