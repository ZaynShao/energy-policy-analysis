# 广州丨加快推广电动汽车、氢燃料汽车等新能源车辆

优化充换电设施网络：以高速公路服务区、城市公共充电站等为重点场景，加快推进超快充网络建设。结合城市更新统筹布局公共充电设施，新建住宅小区严格落实充电设施配建要求，鼓励单位内部停车场改造建设充电设施。到2030年，力争建成充换电站X座、充电桩X万个。
多维布局车网互动发展：加快建设国家车网互动（V2G）试点城市，统筹政策、市场、基建、标准等多维度推进车网互动规模化发展。鼓励电网企业联合充电企业、整车企业等共同推进扩充V2G配套充电桩规模。完善V2G电池安全、热管理及场站防火全链条安全监管体系。聚合车网互动资源参与电网调峰，开展V2G参与城中村重过载治理试点。到2030年，常态化参与削峰填谷的V2G车辆达到X量级，V2G年放电量不低于250万千瓦时。
加强配电网对充电设施等多元负荷的大规模接入能力，到2030年，满足不低于200万辆电动汽车充电需求。
加快推广电动汽车、氢燃料汽车等新能源车辆。
交通领域重点在公共交通、货物运输中规模化推广氢燃料电池汽车。到2030年，投运5万台氢燃料电池汽车。
推动广州市特种设备检测研究院设立氢能装备检验检测点，聚焦燃料电池汽车上牌检测等开展全流程服务。
聚焦充电基础设施等新领域新业态，加强新能源新风险安全监管。
