# 金杜助力渤海汽车重大资产重组顺利实施

本次交易中，渤海汽车通过发行股份及支付现金的方式，收购控股股东北京海纳川汽车部件股份有限公司（简称海纳川）持有的北京北汽模塑科技有限公司51%股权、海纳川安道拓（廊坊）座椅有限公司51%股权及廊坊莱尼线束系统有限公司50%股权，交易作价合计约27.10亿元；同时向不超过35名符合条件的特定对象发行股份募集配套资金，总额不超过12.73亿元。
本次交易是北汽集团深化国企改革、提升上市公司质量、推动上市公司做优做强的重要举措。本次交易中，海纳川为北汽集团下属汽车零部件平台、京津冀地区最大的汽车零部件企业，具有完善的汽车产业链布局；渤海汽车为北汽集团旗下唯一的零部件上市公司和零部件板块的核心平台。通过本次交易，渤海汽车可以进一步整合资源，丰富产品矩阵，快速提升模块化供货能力，加快在乘用车和新能源汽车零部件领域的战略布局。
金杜作为本次交易的专项法律顾问，紧密围绕客户需求，充分把握监管政策导向，依托一站式、跨领域的综合法律服务能力，为渤海汽车提供了全面、专业的法律服务，涵盖交易方案设计、法律尽职调查、经营者集中、交易文件起草、国资监管、项目申报、审核反馈、信息披露及交割等各个环节。金杜团队凭借在上市公司并购重组和国资监管领域丰富的项目经验和深厚的专业能力，协助客户高效推进项目进程，助力项目顺利通过审核。
本项目的负责人为合伙人宋彦妍、王开定、董昀和柳思佳，项目团队主要成员包括杨柳、李松、孟繁卿等。公司业务部合伙人刘成在反垄断领域为本项目提供专业支持。
