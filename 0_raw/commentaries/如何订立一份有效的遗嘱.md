# 如何订立一份有效的遗嘱

遗嘱，作为最基础的财产传承工具，订立流程简便、成本低，却是关键时刻的“定海神针”——财产按个人意愿定向传承，避免法定继承的均等分配。因此，趁身体健康时提前订立遗嘱，为人生做好周全的兜底准备，是每个人都值得考虑的安排。基于此，本文整理了实务中客户在订立遗嘱时最常遇到的法律问题，以期为读者们提供一份实用的指引和参考。

**01**

**立遗嘱人有什么资格要求？**

立遗嘱人在订立遗嘱时，应当为完全民事行为能力人，无民事行为能力人或者限制民事行为能力人所立的遗嘱无效。根据《中华人民共和国民法典》（以下简称《民法典》）的规定，完全民事行为能力人是指年满18周岁、能够完全辨认自己行为的自然人；或虽未满18周岁，但年满16周岁，且能够以自己的劳动收入为主要生活来源的自然人。无民事行为能力人，是指不满8周岁的未成年人，或不能辨认自己行为的成年人。限制民事行为能力人，是指8周岁以上的未成年人，或不能完全辨认自己行为的成年人。“不能辨认/不能完全辨认自己行为的成年人”，常见人群包括智力障碍者、精神疾病患者、因疾病而意识不清的人等。

因此，只要是能够完全辨认自己行为的成年人，均可根据自己的意志订立遗嘱，并无年龄上限要求。但如果立遗嘱人年事已高，其精神意识状态常常会成为遗嘱效力被质疑的重点因素，我们建议，订立遗嘱时同步准备民事行为能力（精神状态）的证明文件，并可优先选择公证遗嘱方式，或自书遗嘱叠加其他形式相辅助（例如视频、见证）的遗嘱方式，以降低立遗嘱人去世后遗嘱效力受到挑战的风险。实践中，部分公证处亦要求年满七十周岁的立遗嘱人，需提交三甲医院开具的精神状态证明文件。

**02**

**夫妻双方共同订立遗嘱可以吗？**

《民法典》及最高人民法院相关司法解释未对共同遗嘱做出规定，法律上并无“共同遗嘱”的概念，但在日常生活中，夫妻共同订立一份遗嘱的情况并不少见。从遗嘱订立层面，司法部颁布的《遗嘱公证细则》第15条规定，遗嘱人坚持申请办理共同遗嘱公证的，共同遗嘱中应当明确遗嘱变更、撤销及生效的条件。从遗嘱效力层面，在司法实践中部分法院对共同遗嘱法律效力认定有成文的指导意见。例如，《北京市高级人民法院关于审理继承纠纷案件若干疑难问题的解答》第19条规定，以夫妻双方名义共同订立的处理夫妻共同财产的遗嘱，符合遗嘱形式要件的应为有效。当事人仅以遗嘱内容为一方书写，不符合代书遗嘱相关形式要件为由请求认定遗嘱无效的，人民法院不予支持。夫妻一方先死亡的，在世一方有权撤销、变更遗嘱中涉及其财产部分的内容；但该共同遗嘱中存在不可分割的共同意思表示，上述撤销、变更遗嘱行为违背该共同意思表示的除外。

共同遗嘱是存在被部分撤销、变更的现实可能性的，如果夫妻双方都有对夫妻共同财产订立遗嘱的想法，我们建议以个人名义分别对共同财产中属于各自的份额订立遗嘱，这是较为安全且稳定的做法，个人遗嘱内容相互独立，效力彼此不受影响，以保障个人遗愿在未来得以落实。

**03**

**遗产可以赠给与立遗嘱人无血缘关系的自然人或机构吗？**

根据《民法典》的规定，自然人可以订立遗嘱将个人财产赠与国家、集体或者法定继承人以外的组织、个人，这在法律上被称为“遗赠”。需要特别注意的是，受遗赠人接受遗赠有法定时限要求，其应当在知道受遗赠后六十日内，作出接受或者放弃受遗赠的表示；到期没有表示的，视为放弃受遗赠。

一般而言，对受遗赠人是没有特殊的资格条件限制的。但是，遗嘱也属于民事法律行为，根据《民法典》的规定，违背公序良俗的民事法律行为无效。因此，如果立遗嘱人在遗嘱中将遗产赠给婚外“第三者”，相关遗嘱内容的效力有较大可能被否定。在司法实践中，已有案例以违反公序良俗为由将此类遗嘱内容认定为无效。

**04**

**继承人通过遗嘱继承取得的财产属于个人财产还是夫妻共同财产？**

根据《民法典》的规定，婚姻关系存续期间，夫妻一方通过继承所得的财产，原则上属于夫妻共同财产；但如果遗嘱中明确写明遗产只归继承人个人的，则依据遗嘱继承所得财产属于继承人的个人财产。

因此，如立遗嘱人希望遗产由继承人个人单独继承，以避免遗产因继承人未来婚姻关系变动而被分割，我们建议，可以在遗嘱中明确表达意思，从而避免继承人继承所得财产被纳入夫妻共同财产范围，从根源上防止家族财富被分割。

**05**

**遗嘱必须公证才有效吗？**

《民法典》规定了遗嘱可以有自书遗嘱、代书遗嘱、打印遗嘱、录音录像遗嘱、口头遗嘱、公证遗嘱等六种方式。从内容来说，遗嘱应当是立遗嘱人的真实意思表示；从形式来说，各类遗嘱需要符合相应法定形式要件。只要遗嘱是立遗嘱人真实意思表示，符合对应形式的法定要件，即具备法律效力，并非必须办理公证手续。立遗嘱人留有多份遗嘱，内容相抵触的，以最后一份有效遗嘱为准。

虽然《民法典》取消了公证遗嘱的优先效力，但因公证遗嘱系在公证机构公证之下订立，具有公证程序的严谨性、公证文书在民事诉讼中的免证效力等特点，因此，立遗嘱人可以优先选择以公证方式订立遗嘱。如选择其他遗嘱方式，要特别注意应满足法定形式要件，比如自书遗嘱需由立遗嘱人亲笔书写，代书遗嘱、打印遗嘱、录音录像遗嘱、口头遗嘱均需两名以上无利害关系的见证人在场见证等，避免遗嘱存在效力瑕疵。

**06**

**可以找哪些人做遗嘱见证人？**

具有完全民事行为能力且与遗嘱受益人无利害关系的人，均可以做见证人。根据《民法典》及相关司法解释的规定，下列人员不能作为遗嘱见证人：（1）无民事行为能力人、限制民事行为能力人以及其他不具有见证能力的人；（2）继承人、受遗赠人；（3）与继承人、受遗赠人有利害关系的人。因此，继承人和受遗赠人的配偶、子女、债权人、债务人以及共同经营的合伙人等，均被视为与继承人、受遗赠人有利害关系的人，均不能作为遗嘱的见证人。生活中，可以由立遗嘱人的同事、朋友、同学作为见证人。需要注意的是，如果由立遗嘱人的亲属做见证人，该亲属与遗嘱中的受益人及被排除继承权的法定继承人的亲缘关系应当一致。简单来说，就是这位亲属不能和遗嘱中的受益人更亲近，也不能和被排除继承权的法定继承人更疏远，要做到“一碗水端平”，避免因亲属关系偏向，影响遗嘱的公正性。

**07**

**已婚人士订立遗嘱时，是否只能处分个人名下财产？**

自然人可依法订立遗嘱处分个人合法财产，该权利不受婚姻状态限制。婚姻关系存续期间，夫妻共同财产可登记在一方或双方共同名下。对于已婚人士来说，其个人合法财产既包括夫妻共同财产中属于其所有的份额，也包括其婚前个人财产或在婚后取得的、但根据法律规定或约定属于其个人所有的财产。立遗嘱人有权对夫妻共同财产中属于自己的份额订立遗嘱，无论该财产是登记在个人名下还是对方名下，或是夫妻共同名下。

**08**

**立遗嘱人订立的遗嘱可以处分不同国家/地区的财产吗？**

现行法律对遗嘱可包括的财产所在地域，均没有限制。立遗嘱人订立遗嘱时，所涉财产范围可以包括其所有的、位于中国境内或境外的合法财产。但是，由于不同国家/地区的法律对于遗嘱方式、效力认定条件等规定不同，考虑到遗嘱效力认定与执行的现实问题，在订立此类遗嘱时，需要兼顾遗嘱在不同国家/地区的效力认定与遗产过户的执行，遗嘱应当符合相关域外法律规定，并考虑遗产所在地具体实操要求。

《中华人民共和国涉外民事关系法律适用法》第32条规定，遗嘱方式，符合遗嘱人立遗嘱时或者死亡时经常居所地法律、国籍国法律或者遗嘱行为地法律的，遗嘱均为成立。第33条规定，遗嘱效力，适用遗嘱人立遗嘱时或死亡时的经常居所地法律，或其国籍国法律。因此，若立遗嘱人是中国国籍，或虽为外籍但经常居所地在中国，其所立遗嘱只要在实质内容和形式上符合中国法律规定，在中国内地即具有法律效力。

但需明确，订立遗嘱的最终目的是实现指定继承人或受益人对遗产的继承与过户，而位于中国境外财产的过户手续需在财产所在地办理，必然需要考量遗嘱在该国家/地区的法律效力认定问题。实践中，部分国家/地区的准据法规定，遗嘱效力适用被继承人死亡时的住所地法或国籍国法，即中国公民可以根据中国法律订立遗嘱，处分其在相关国家/地区的遗产，但是需要根据遗产所在地相关法律规定，履行遗嘱认证/认定程序。

综上，为确保遗嘱合法有效，保障不同国家/地区的遗产能够按照立遗嘱人遗愿处置，并提高遗嘱执行效率，建议提前咨询财产所在国家/地区的专业律师，了解当地法律对遗嘱效力、遗嘱方式的具体要求以及遗嘱执行的实际操作情况。若财产所在的不同国家/地区相关法律规定差异过大，则不适宜合并在一份遗嘱中处置，建议根据财产所在地法律分别订立遗嘱，以保障遗嘱效力认定及方便未来遗嘱的顺利执行。

**09**

**遗嘱中需要指定遗产管理人吗？**

遗产管理人是根据遗嘱指定的、或继承人推选的，在遗嘱生效后管理遗产的人或组织。遗嘱中不是必须指定遗产管理人。如果遗嘱中未指定遗产管理人，也可以根据《民法典》第1145条所规定的顺序确定遗产管理人：继承开始后，遗嘱执行人为遗产管理人；没有遗嘱执行人的，继承人应当及时推选遗产管理人；继承人未推选的，由继承人共同担任遗产管理人；没有继承人或者继承人均放弃继承的，由被继承人生前住所地的民政部门或者村民委员会担任遗产管理人。

遗产管理人在遗产处理中具有重要作用，其职责主要包括清理遗产并制作遗产清单，向继承人报告遗产情况，采取必要措施防止遗产毁损、灭失，处理被继承人的债权债务，按照遗嘱或者依照法律规定分割遗产以及实施与管理遗产有关的其他必要行为。

在遗嘱所涉财产类型复杂、继承人较多或存在未成年继承人等情况下，遗嘱中指定遗产管理人，一方面可以直接体现立遗嘱人意愿，避免继承人之间因推选遗产管理人产生纠纷，另一方面也可以有效提高遗产清点、债务清偿、遗产分配等的效率。

**10**

**遗嘱订立后还能修改吗？**

立遗嘱人订立遗嘱后，有权修改遗嘱。《民法典》第1142条规定，遗嘱人可以撤回、变更自己所立的遗嘱。

  

立遗嘱人可以通过如下方式修改遗嘱：一是立遗嘱人可以重新订立一份遗嘱，在新遗嘱中说明对原遗嘱的修改或撤销情况，或直接表达新的遗产安排内容。当立遗嘱人立有数份有效遗嘱且遗嘱内容相抵触时，以其最后的有效遗嘱为准。二是立遗嘱人也可以实施与已订立遗嘱内容相反的民事法律行为，以其主动处置财产的行为表明其对已订立遗嘱的撤销或变更。例如，立遗嘱人在遗嘱中安排由其子女继承房产，但在遗嘱生效前又将房产出售，此种行为将被视为立遗嘱人已对遗嘱中的相关内容进行了修改。

**结语**

人生无常、世事多变，我们无法预料明天与意外哪个会先到来。订立遗嘱并非消极面对生死，而是对生命负责、对家人负责的理性选择，是用法律方式守护挚爱、厘清财产的妥善安排。不妨未雨绸缪，提前订立一份合法有效的遗嘱，为“身后事”做好周全规划，让关爱不因变故而消散，让生活多一份确定性与安全感，真正做到身前从容、身后无忧。
