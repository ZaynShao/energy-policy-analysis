# 投资四年套现超3亿，章子怡一笔交易赚麻了

内部孵化超4年，上美股份出手买下了newpage一页品牌更多股份。
8月11日晚间，上美股份（02145.HK）公告称，通过旗下全资子公司上海青道分别以3.05亿元对标价收购共青城大脚投资合伙企业（有限合伙）（下称大脚投资）持有的上海怡页23%股权，以约7943.96万元收购刘明持有的上海怡页6%股权。两笔合计29%的股权收购，总耗资约3.84亿元。
另据上美股份与大脚投资交易附带的补充协议，大脚投资可在期权期内要求上海青道额外收购上海怡页的5%股权。
上海怡页是上美股份旗下婴童功效护肤品牌newpage一页的运营主体，上海青道、大脚投资、刘明是上海怡页的主要股东；此次交易完成前，三者持有上海怡页的股份比例分别为51%、29%和11%。此次交易完成后，上美股份通过上海青道，对上海怡页的持股比例将由51%提升至80%。
卖方一侧，大脚投资背后是影视演员章子怡，其持有大脚投资99%股份，刘明则是上美股份副总裁，也是newpage一页品牌的创始人之一。此次交易完成后，两人将合计套现约3.84亿元。
明星创始人的套现与上美股份的增持，对双方而言或许都是最优的进退方式。
孵化品牌4年，
章子怡、刘明套现超3.8亿元
newpage一页是上美股份2022年5月推出的婴童功效护肤品牌，由演员章子怡、育儿专家崔玉涛联合创立，主打婴幼儿敏感肌护理，是上美股份除韩束、红色小象之外，第三大核心护肤线。
这是一个典型的由核心人才与企业共同创业的品牌。其中，刘明在母婴行业有多年创业经历，2019年加入上美后开始筹备婴童护肤品牌，并在入职数月后提交了newpage一页的商业计划书。
在美妆品牌普遍依赖单一品牌驱动的背景下，newpage一页助力上美股份完成多品牌矩阵的初期布局。2023年，品牌成立次年，newpage一页的营收就突破亿元，达到1.52亿元，同比增长498.0%，占上美股份年内总收入的3.6%。
2024年-2025年，newpage一页依旧保持超100%的高增速，2025年，品牌营收约8.8亿元，占上美股份总收入的比例也提升至近10%，同期净利润约1.32亿元。
针对此次收购，上美股份对外透露，希望改变传统美妆集团与品牌负责人之间的关系，将集团定位为面向核心人才和合作伙伴的创业平台，让品牌负责人参与品牌长期价值创造；也使上美股份能够进一步受惠于上海怡页带来的正面盈利贡献。
对创始人而言，同样完成一笔收益颇丰的阶段性兑现。根据交易公告，大脚投资及刘明待售权益的原始收购成本分别为230万元及120万元。另据天眼查显示，大脚投资和刘明对上海怡页的认缴出资额分别为290万和110万元。
而通过交易，章子怡与刘明将合计落袋3.84亿元。以此计算，经过4年多的孵化，两人的投资回报率达到近100倍。
交易完成后，两人合计仍保留上海怡页11%股权及相应的代言、高管身份。
借上美线上基因起量，
但前面还有海龟爸爸们
newpage一页于2022年5月上市，成立至今不到5年，仍是一个年轻品牌。
品牌按婴童肌（0-6岁）、学龄肌（6-12岁）、青年肌（12-18岁）三大年龄段划分产品需求，而旗下产品的价格并不低。天猫newpage一页官方旗舰店页面显示，newpage一页产品涵盖面部护理、全身润护、沐浴清洁、夏日专研等系列，产品价格在79元至359元不等。
一支200g的“一页婴童舒润特护精华霜”定价259元，折后219元；一支400ml的“0岁+婴童身体乳”更是标价199元，逼近甚至超过成人身体乳价格。
时代财经注意到，newpage一页是典型的由电商平台孵化的婴童品牌，打法上延续了上美股份线上主导的战略，目前已进驻微信小程序、淘宝、抖音、京东等主流电商平台。财报中未单独披露newpage一页分渠道数据，但整体来看，2025年上美股份线上渠道营收86.18亿元，占总营收的93.9%。
线下渠道方面，newpage一页的布局并不算广，未像传统的母婴品牌在线下大规模铺开布局。据上美官方网站，2023年，newpage一页首家品牌线下体验馆在北京崔玉涛诊所落地；其余则仅通过屈臣氏、圣贝拉旗下小贝拉月子护理中心等进行线下铺店。
newpage一页在婴童市场的迅速增长，离不开品牌聚焦“婴童功效护肤”定位。它避开了红色小象所立足的大众母婴护理底盘，也避开了海龟爸爸专供的儿童防晒细分，精准切入学龄前儿童抗敏感、修护屏障等垂直痛点。
但在婴幼儿护肤这个赛道上对手也颇多。近年来，不少国货美妆集团都在切入婴童护肤赛道，以寻找业绩增长的新曲线。
按2025年营收对比，同属功效护肤赛道的薇诺娜宝贝、自然堂集团推出的“己出”虽同样主打科学功效护肤，但两者品牌体量均在2亿元级别。其中，“己出”所在的其他品牌2025年营收达2.31亿元，占自然堂集团总营收的4.4%；贝泰妮旗下的薇诺娜宝贝2025年销售收入达2.35亿元。
与此同时，新锐品牌也在抢夺这部分细分市场。据报道，海龟爸爸在2023年年营收已突破10亿元，以儿童防晒稳居抖音类目榜首，润本、贝德美则靠走性价比路线，快速起量。
值得注意的是，在上美股份内部，除了头部的韩束、快速增长中的newpage一页，安敏优、红色小象、一叶子等品牌仍处在年营收3亿元以下的培育初期。
在newpage一页之后，上美股份如何将这套“合伙人模式”复制到下一个孵化品牌，是其更重要的功课。
