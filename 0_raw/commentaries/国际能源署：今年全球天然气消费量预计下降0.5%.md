# 国际能源署：今年全球天然气消费量预计下降0.5%

国际能源署表示，今年全球天然气消费量预计下降0.5%，折合200亿立方米。
国际能源署当地时间7月7日表示，受中东局势减少天然气供应、天然气价格走高抑制需求的影响，今年全球天然气消费量预计下降0.5%，折合200亿立方米。
国际能源署称，美伊冲突令霍尔木兹海峡的液化天然气运输量大幅减少，该航道此前承担了全球约20%的液化天然气运输。
