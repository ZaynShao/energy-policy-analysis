# 痛悼！王希季院士逝世

中国共产党优秀党员，我国航天事业开拓者之一，著名空间技术专家，中国科学院院士，国家“两弹一星功勋奖章”获得者，中国航天科技集团有限公司科学技术委员会原顾问，中国空间技术研究院技术顾问王希季同志，因病医治无效，于2026年8月12日在北京逝世，享年105岁。
王希季是“两弹一星”元勋。他的逝世，是我国航天事业的巨大损失，是五院的巨大损失。我们沉痛悼念、深切缅怀这位为中国航天事业奉献了一生的杰出科学家。
国家需要建设，所以我们回来了
1921年7月26日，王希季出生于云南昆明。1933年，他以会考总分第一的好成绩从高小毕业。之后，以入学考试总分第一的成绩考入中学。1937年，他又以入学考试总分第一的成绩，被昆华高级工业职业学校土木工程科录取。
当时正值“七七事变”发生，全昆明新入学的高中生和大学生都要进行3个月的军事训练。在军训期间，抗击日寇、保家卫国的氛围深深感染着学生们。“国家兴亡，匹夫有责！”年少的王希季凭着一股朴素的爱国热情，萌生了报名参军上前线、抗击日本侵略者的念头。虽然因为年纪太小而未被军队录取，但从那时起，王希季的思想发生了很大的变化，想的已经不再是学手艺谋生的个人问题，而是要为抗日胜利学本领。
1938年暑期，西南联合大学在昆明面向全国招生，并允许不具备高中毕业资格的学生以同等学力报考。刚学完高一年级课程的王希季，抱着“开眼界，不论取否”的态度，以机械工程系为第一志愿报考，并被顺利录取。在这里，他深刻认识到能源是“工业的杠杆”，萌生了将来投身于建设和发展能源事业，为改变祖国落后面貌出力的意愿。
1948年，他怀着“工业救国”的理想，前往美国弗吉尼亚理工学院留学，攻读动力及燃料专业，并在次年以优异成绩获得科学硕士学位。就在准备进一步攻读博士学位时，他从报纸上得知了中华人民共和国成立的消息。他果断放弃了继续深造的机会，与一批中国留学生一起登上“克利夫兰总统号”轮船，踏上了归国之路。
▲王希季在“克利夫兰总统号”留影
有人问王希季，为什么不继续读博？即使一定要回去，为什么那么急，不等拿下博士学位再走？他回答：“从我出生时起，国家就一直在混乱中，支离破碎。我出去读书时国内还没统一，回来时已经统一了，这对我来说很重要。”
回国之初，王希季先后在多所高校任教。1958年，他光荣地加入了中国共产党。他坚定理想信念，不畏艰难险阻，并用数十年如一日的报国之行践行了一名共产党员的初心使命，用奋斗奉献的光辉一生诠释了“两弹一星”精神的深刻内涵。
确实是一个严重的挑战和难得的机遇
1958年11月，在毛泽东发出“我们也要搞人造卫星”的伟大号召后不久，王希季被调到中国科学院上海机电设计院，担任探空火箭的技术负责人。虽然这与自己之前的研究领域完全不一样，但他明白这是国家的需要，毫不犹豫地答应了。中国发展航天事业和空间技术，改变了王希季的人生轨迹。
任务开展之初，研制条件十分简陋，既没经验，又没资料，也没专家，一切都要从零开始。只有手摇式计算工具，为了计算一条弹道，几个人夜以继日干两个多月，计算用的纸比办公桌还高；没有发射场，他们把稻田当作发射场，用辘轳绞车把火箭吊上发射架，用打气筒加压给火箭加燃烧剂。1960年2月19日，王希季和他的团队在上海郊区的一处稻田里，成功发射了中国第一枚探空火箭“T—7M”。虽然飞行高度只有8公里，却标志着我国已经在奔向太空的征程中迈出了关键的第一步。王希季说，这是他航天事业中第一次也是最重要的一次成功。在此之后试验成功的18种探空火箭中，由王希季担任负责人的有12种。
▲王希季与钱学森等在T—7M发射塔架前合影
在后续“长征一号”的研制中，王希季创造性地把探空火箭技术和导弹技术结合起来，制定出我国第一枚卫星运载火箭“长征一号”的技术方案，主持了火箭方案和初样阶段研制，为我国之后首次发射卫星就获成功奠定了基础。1968年2月，王希季调入新成立的中国空间技术研究院，在航天报国的道路上继续奋斗。1970年4月24日，我国成功使用“长征一号”运载火箭将首颗人造地球卫星“东方红一号”送入太空，并由此成为第五个把卫星送入太空的国家。
20世纪六七十年代，我国国土普查、资源勘探的战略需求迫切呼唤“太空视角”，返回式卫星成为国家战略的必然选择。王希季受命投入到我国第一颗返回式卫星的研制中。返回式卫星是一个复杂的航天飞行器，有数万个元件和零件，要在极为复杂恶劣的宇宙空间环境中做到稳妥可靠、万无一失，是很不容易的。这“对研制人员来说，确实是一个严重的挑战和难得的机遇”，但他仍毅然决然接下挑战，并带领研究团队进行了一次又一次的争论、讨论，最终确定了充分利用“长征二号”运载火箭能力、采用弹道式返回方式、由返回舱和仪器舱组成大返回舱的方案。这个方案几十年来一直是我国返回式卫星的基本方案。
我是总设计师，一切由我负责
1975年11月26日，中国第一颗返回式卫星成功发射。当人们沉浸在发射成功的喜悦中时，王希季却提着行李匆匆赶往卫星测控中心——他要等卫星返回地面，发射试验才算真正成功。三天三夜没合眼，直到天空中出现了那顶红白相间的降落伞，他才放下心来。这次回收成功，带回了覆盖全国的首批高清遥感胶片，为国土普查、地形测绘等任务提供了基础数据支持，使中国成为继美国、苏联之后世界上第三个掌握卫星返回技术的国家。
在带领队伍开展卫星研制的过程中，王希季高度重视质量工作，不仅亲自在现场指导技术人员，采取提高可靠性措施，而且对卫星的情况和动态了如指掌，从不肯放过哪怕细小的疏忽。他对身边的研制人员讲：“我们这个发展中国家不能和那些发达国家相比，我们对风险的承受力低。要体谅国家的难处，尽我们最大的努力去保证每一颗卫星的可靠性，以期用最小的投入去获取最大的效益。”
王希季从不推诿责任，掷地有声地表示：“我是总设计师，一切由我负责。”对重要的数据，他会自己动手计算核实；对关键的部位，他甚至会打着手电筒钻进去亲自检查。一旦他提出问题，不仅问题尖锐具体，而且他总要刨根问底，容不得半点含糊。这样的作风深刻影响了整支队伍。
在返回式卫星研制中，王希季还首次提出了试验新型国产彩色胶片的想法，当时遭到了不少专家的反对：国家投资研制一颗卫星不容易，一旦试验失败就会造成重大损失。黑白片已经试验成功了，清晰度很好，何必再“锦上添花”？
王希季非常清楚这种不可小觑的风险，以及承担该风险要负的责任有多重。但他认为，这个风险值得承担。彩色片成功后会比黑白片获取到大得多的信息量，能为国家解决更多的问题，若能在万无一失的情况下创造更多的价值，“锦上添花”又有何不好？当装有大量彩色胶片的卫星成功回收后，一张张色彩纷呈、层次丰富、图像清晰的照片被冲洗出来，呈现了在众人面前。
有人称赞王希季胆大有魄力，他回答道：“不是胆子和魄力问题，而是责任感问题，负责一件事，就要把事情了解清楚。我了解胶片的研制情况，知道研制人员做了充分的论证和试验，才敢决定在国土普查卫星上装那么多的新型胶片。”
“有人说我一次又一次地充当开路先锋，其实我并无过人的胆识，只不过是对认定该做的事情不惜承担风险罢了。”
▲王希季在检查返回式卫星内部安装情况
太空的竞争非常激烈，我们应该具有开拓天疆的意识，不仅要争取拥有一席之地，还要争取一片之地
不止是返回式卫星，王希季在载人航天和现代小卫星等工程领域也作出了突出贡献。他始终以极高的热情关注世界载人航天发展动态，在“863”计划启动后深度参与天地往返运输系统的论证，坚定支持飞船方案，力主中国载人航天应从研制飞船起步。载人航天工程立项后，他持续思考工程的未来发展，并参与多项工程技术把关工作。
▲王希季与航天员在神舟五号飞船返回舱前合影
神舟七号载人飞船的主要任务，是实施中国航天员首次空间舱外活动。他鲜明提出“中国人第一次太空行走应该穿我们自己的航天服”。这个意见受到重视并被采纳。2008年9月，航天员翟志刚身穿由中国人自主研制生产的“飞天”舱外航天服在太空中挥舞五星红旗的精彩亮相，给世界留下了深刻印象。
王希季倡导产品化理念和小卫星“快、好、省”的研制模式，有力推动了我国现代小卫星领域的快速发展。作为实践五号卫星首席专家，他将研究多年的“集同工程法”引入卫星研制工作，大胆使用工业级和商业器件降低成本，应用星务管理概念实现星上电子设备功能集成设计，出色完成了卫星研制任务，并创造了多个“第一”。
在深厚的实践探索中，王希季始终科学求实、严谨务实，对我国航天事业发展有很多独到的见解，并持续推进空间技术发展战略研究，不断提出新概念、新思路。他曾经讲：“在技术问题上不能少数服从多数，而是要尊重客观规律，坚持实事求是，有时候少数人坚持的往往是正确的。”
王希季敏锐地意识到，发展空间技术的意义不等同于一般高技术，这是一项开拓天疆、造福中华民族和全人类的宏伟事业。王希季利用各种机会和场合，不遗余力地宣传空间技术对我国开发利用太空资源的重要作用和深远意义。
“开发利用空间资源与开发利用陆地、海洋和大气层资源一样，需要在空间建设适应国家和社会需求和促进其发展的、能为各行各业提供优质服务的空间基础设施。这就是在空间轨道上长期稳定运行的、具有提供给地上所需服务功能的各类航天器。”他在1998年发表的《建设我国的空间基础设施》等文章中，提出了“空间基础设施”的概念，并坚持不懈推动。他作为双组长之一，于2006-2007年主持完成了“高分辨率对地观测系统工程实施方案”的论证和编制，为该专项获得国家批准和立项研制奠定了基础。如今，国家民用空间基础设施早已变成实景图，天上的一系列高分卫星正在精准地遥瞰寰宇、感知天地。
在中国的航天事业中，我不过做了我应该做、又努力做的事情罢了
1999年9月18日，在庆祝中华人民共和国成立50周年之际，78岁的王希季被党中央、国务院和中央军委授予“两弹一星功勋奖章”，成为23位获此殊荣的科学家之一。面对这份至高的荣誉，他心中涌动着为祖国航天事业的进一步发展而奋斗的豪情，并以满腔热忱继续实干担当、强军报国。他说：“如果中国不发展空间技术，如果党、国家和人民不交给我负责研制火箭和卫星……我也不会成为现在的王希季。”
步入鲐背之年，王希季对专业技术与社会发展依旧保持高度关注，依然思考并探寻着中国航天的未来。他关注空间太阳能电站发展，主持完成《空间太阳能电站发展预测和对策研究》并上报。2016年，他还主持开展“互联网+航天”课题研究，被媒体称为95岁的“航天创客”。期颐之年，他仍组织开展“中国探月工程的研讨”“关于载人空间站应用问题的讨论”两项课题研究。
2020年4月，在第五个“中国航天日”和“东方红一号”卫星成功发射50周年到来之际，王希季和孙家栋、戚发轫等11位参与“东方红一号”任务的老科学家给习近平总书记写信，回顾了中国航天事业发展的辉煌历程，表达了对实现中国梦、航天梦的坚定信心。
习近平总书记给他们回信，向他们致以诚挚的问候，指出：“当年，你们发愤图强、埋头苦干，创造了令全国各族人民自豪的非凡成就，彰显了中华民族自强不息的伟大精神。老一代航天人的功勋已经牢牢铭刻在新中国史册上。”在回信中，习近平总书记就弘扬“两弹一星”精神、加快航天强国建设向广大航天工作者提出殷切期望。
2024年4月28日，在第九个“中国航天日”和“东方红一号”卫星成功发射54周年之际，经王希季本人授权的“两弹一星功勋奖章”与证书正式入驻五院展示中心。这一举动饱含着他对航天事业的无限热爱和对新一代航天人的热切期盼，给我们带来了巨大的勉励和鼓舞！
▲王希季院士本人授权的“两弹一星功勋奖章”与证书入驻五院展示中心
“我感到生活的意义主要的就在于自己参与了这伟大的社会主义建设事业，能为此尽一份力量。我了解党的事业，并下定决心要争取作为一个共产党人。”
这是王希季在入党申请书中的一句话。他认准了“做人还是要做共产党人”，用一生的行动践行了“我愿做太空的铺路石”的铮铮誓言！
