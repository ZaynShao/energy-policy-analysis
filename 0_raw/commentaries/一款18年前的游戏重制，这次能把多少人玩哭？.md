# 一款18年前的游戏重制，这次能把多少人玩哭？

曾几何时，一句“ P5 天下第一 ”，让女神异闻录系列被广大玩家所认识。然后的几年里，就是数不清的 P5 联动，甭管你是玩啥游戏的，可能都会跟 P5 梦幻联动一波，并被它这个预告信剪报、通篇黑红配色的视觉风格潮到。但作为当下 JRPG 的扛鼎系列，其实 P5 的前作，也就是《 女神异闻录 4 》，可能才是那个系列粉丝心中真正的白月光。P4 原版发布于 2008 年的 PS2 平台，后来又在 PSV 上推出完整版的 P4G，补完了完美结局，还增加了温泉旅行等新剧情，顺便带来了新的人气角色玛丽。与 P5 不同的是，P4 的故事发生在八十稻羽这个乡间小镇，虽然不如东京那么灯红酒绿，但却通过更加平易近人的小镇故事，牢牢拴住了每一个通关玩家的心，仿佛真的和每一个伙伴，相处了一整个学期。至于小发当年的存档，现在还在我那台 PSV 里，尤其在前两年玩过 P3R 这部重制后，就更加期待哪天 P4 也能来个重制。而最近 P4R 的消息正式公布，世嘉官方也进入了宣发期，每隔一段时间就会放出点宣传片和物料，等的人抓耳挠腮。好消息是前两天，小发受邀去了趟 B 站的“ 游先看 ”线下试玩，可算是亲自上手并体验到了这部作品的 DEMO 版本。尽管试玩一共才 30 分钟，其中还有十几分钟的纯剧情，但对于这部感兴趣的玩家来说，应该也能提供不少参考。首先说明一下，试玩内容一共两部分，都是游戏较为前期的部分。一段是主角鸣上悠刚刚觉醒 Persona 能力，另一段则是前期的迷宫探索。主要展现的内容分别有：回合制战斗、剧情、迷宫探索、菜单 UI，弱点击破效果、战斗结算动画等演示。在一开场，就先进了段剧情，比较让人欣慰的是，重制版在对话过程中的镜头调度更丰富，虽然整体的画面和建模依然是经典阿特拉斯水平，但起码也算有了重制的样子。而且这次重制的不止 3D 画面，2D 过场动画也制作了新的版本。就是整体来看依旧是阿特拉斯便宜动画，制作水准也基本和 P5R 看齐，用在一些剧情高光部分倒也完全够用了。顺便，给大伙再看一个重制后的 3D 版八十稻羽街道。可以看出，站次的站位和镜头位置，也变成了 P5 同款。
主题色因为是黄色，所以这一代主角的身边会有一圈黄色剪影，而敌人的建模精细度和打光，则感觉像是 P 系列有史以来最好的一次。
另外整个战斗场景，都被一个电视形状的 UI 外框包围，所以战斗菜单就被做成了老电视的旋钮放在右下角，还挺巧妙。
可以看出，战斗的站位和镜头位置，都变成了 P5R 同款，敌人的建模精细度也系列经典的弱点击破系统，这次也做了专门的特写动画。Demo 里展示了主角鸣上悠和阳介的部分，能看出来每个人打碎塔罗牌的方式都不一样。原版没有，但如今已经成 P 系列特色的总攻击、换手等战术，也不出意外地加了进来。不过因为试玩版只有 2 名角色，没有完整的 4 人圈踢场面，多少还是有点可惜。
另外，可能有不少人想看的 UI 部分，小发这次也录了。只能说神级 UI 这一块还在稳定发力，流畅度、华丽度，还有审美都强无敌。迷宫探索这一块，短暂体验下来应该还是和原版差不多。比 P3R 的爬塔好一点，但跟 P5 的迷宫肯定还是比不了。而且这次在探索时，新加入了一个“ 防御 ”键，切入敌人时，如果没信心触发先手攻击，就可以先防御，等待对方先攻击，防御下来之后，再趁着敌人的后摇发动战斗。因为大部分的内容，其实还是剧情相关的演示，为了不剧透，小发也不好放出太多画面。就是这次不少人一直都在吐槽的立绘问题，不知道正式版还会不会优化。像有玩家觉得，这次缺少一些脸部阴影的细节，导致人物立体感不足，尤其是在原版立绘的对比下，更显得重制版立绘有些单调。除此以外，如果真能优化一些流程，并把曾经 P4 的剧情和设定用更现代的方式还原出来，那已经算是圆满落地了。而且因为试玩时间有限，所以说不定还藏了不少新内容，只能等正式发售后再看。反正目前从官方放出的一些宣传片来看，很多经典场景都做了还原。像是海滩度假、摩的飙车、跟理世去 KTV、烟花大会、放学后的音乐社团等等，这些 P 系列核心的剧情、 coop 事件，应该都会保持一致，时隔多年，还是期待再经历一遍。最后，小发唯一希望的，就是 P4R  这次能带来点新东西。比如战斗相关的新机制，新的 coop 模式，或是其他一些更有趣的玩法。毕竟从 P5 到 P3R，再到暗喻幻想和如今的 P4R，类似的模式玩了一遍又一遍，多少还是有点审美疲劳。好在官方若有若无地透露，这次会有新要素加入，不过只能等待发售，大伙才能知道到底藏了哪些内容了。而你若本身就是 P4 老粉，那不用小发多介绍，肯定已经早早预购。但如果你从没接触过 P4 原版，但不排斥 JRPG 的回合制，或同样喜欢 P5，那十分建议搞一份亲自玩玩看。相信在结束大几十个小时的流程后，你也会和所有被这部游戏感动过的老玩家一样，感慨八十稻羽市的美好，代入、回忆一波自己曾经拥有的青春。撰文：赤膊朋克
