# WISE2026 商业之王系列年度名册调研重磅启动

纳西姆·塔勒布说过：“风会熄灭蜡烛，却能使火越烧越旺。”
2026年的商业世界，正站在这样一场大风之中。
全球经济颠簸前行，技术浪潮反复冲刷产业边界，旧秩序松动，新规则生长。对有些企业来说，这是令人窒息的逆风；但对另一些企业而言，这恰恰是让火焰烧得更旺的氧气。
回看上半年，中国GDP增速为4.7%，处于全球中高速增长梯队，同时，相较于稳健的总量增速，经济底层的结构性迭代，正成为本次发展的一个核心变化，高技术制造业增加值同比增长13.3%，数字经济总规模逼近50万亿元大关。增长的引擎，正从规模驱动，慢慢转向技术与效率驱动。
转向的底层动力，来自研发强度的持续加码。当全社会研发投入强度攀升至2.8%，AI、新能源、人形机器人等领域的渗透率与出货量接连跃升，技术已不再只是某个行业的加分项，而是正在重构所有行业的基础设施。与此同时，商业航天、低轨卫星、创新药授权、低空经济等前沿赛道正密集冲刺商用拐点，跨境电商与海外仓网络将中国产品送达全球超200个国家和地区，品牌出海与文化出海让企业从“走出去”进阶为“扎下根”。
这种系统性技术竞争力的崛起，在一级市场得到了清晰映射。上半年，资金高度向硬科技集中，AI大模型、具身智能、半导体成为三大吸金主力。其中，具身智能融资额同比暴涨5倍，量子科技、商业航天等前沿赛道的增速也都在两倍以上。资本的流向，正在为下一个时代划出轨迹。
当技术成为所有行业的基础设施，当资本坚定地为未来投票，商业本身也在被重新定义，它不再只是模式与流量的博弈，而是技术深度、产业厚度与全球视野的综合角力。
这正是36氪选择在这个节点，重新审视“商业之王”标准的原因。
作为深耕科技创新与商业生态的新型服务平台，16年来，36氪见证并参与了中国商业生态的演进与蜕变。我们发现，在变化不断发生的商业环境中，真正具有长期价值的企业，不仅需要抓住时代机会，更需要推动产业进步、创造新的增长可能。
他们不只适应风向，更善于把风变成自己的火焰。
基于此，36氪正式启动“WISE2026 商业之王系列年度名册”调研项目。面向年度人物、年度企业、年度焦点产品三大方向，寻找那些推动产业进化、创造商业价值、代表未来趋势的重要力量。
36氪将通过专业调研，深入洞察2026年商业生态领域的创新全貌，看见那些最具引领力、创新力与前瞻力的人；挖掘那些推动产业发展，为经济增长提供创新动能的企业；聚焦那些在不同场景中实现创新应用、重塑用户体验的产品。
