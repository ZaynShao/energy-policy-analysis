# 英伟达自动驾驶重磅人事调整，吴新宙收拢权力丨36氪独家

高通系、小鹏系在英伟达正式合流，
收拢到吴新宙麾下。
英伟达自动驾驶团队正在进行一次大型人事调整。
36氪独家获悉，英伟达自动驾驶团队近期发布内部信称，前高通自动驾驶工程副总裁Dheeraj Ahuja将加入吴新宙团队，而原英伟达自动驾驶软件副总裁，负责量产项目的Sarah Tariq则进入职务过渡期。今日，Sarah Tariq也发出了告别信。
Dheeraj Ahuja和吴新宙都曾在高通任职，在过去七年多里，Dheeraj一直负责高通的自动驾驶项目，2021年底至2022年，高通成功击退英伟达和Mobileye，拿下了宝马下一代ADAS和自动驾驶平台的订单，Dheeraj正是该项目的直接工程负责人。
另外，内部信还指出，系统软件副总裁Parixit Aghera及其负责的底层软件团队，将从Dwight Diercks（SVP，英伟达软件工程高级副总裁）领导的软件部门剥离，正式调入吴新宙领导的自动驾驶部门。
伴随着此次调整，“高通系、小鹏系在英伟达正式合流，逐步收拢到吴新宙的团队当中”，一位内部人士向36氪汽车分析。
调整还未结束。Dheeraj和Parixit加入之后，英伟达将在自动驾驶组织内部进行一轮调整以整合不同的团队和职能，具体的调整举措预计在7月底开始官宣。
吴新宙进一步收拢权力
拓宽团队
2023年，吴新宙担任英伟达汽车业务的一号位，开始全面统领整个智驾团队。但与许多空降高管“新官上任三把火”的作风不同，早期的吴新宙并没有大肆进行架构调整。
对当时的吴新宙来说，首要任务是平稳融入英伟达这头庞大巨兽的既有体系，要想真正撬动内部的深层资源，他需要更多的耐心与时间。
当时向吴新宙直接汇报的下属多是英伟达的老员工，Sarah Tariq便是其中之一。
早在2005年，她便以实习生身份加入英伟达，最初在开发者技术团队担任软件工程师，随后转向NVIDIA DRIVE部门，担任自动泊车项目的技术负责人。
在为英伟达效力9年后，她曾转战明星自动驾驶初创公司Zoox工作了六年，专门负责开发无人驾驶出租车（Robotaxi）的感知系统。2021年，Sarah重返英伟达，担任自动驾驶软件副总裁，领导软件开发工作，并一手搭建了早期的英伟达智驾团队。
在吴新宙空降初期，Sarah Tariq的团队依然保留着完整的建制，产品、算法、地图等各个研发单元俱全。而如今，随着Sarah Tariq退出核心实权、步入职务过渡期，吴新宙终于完成了在上层业务与算法层面的职权全面收拢。但这仅仅是他拓宽职能的第一步。
此次调整的另一关键动作，是系统软件副总裁Parixit Aghera及其负责的底层软件团队，正式划入吴新宙麾下。
Parixit Aghera是跟随吴新宙从小鹏转投英伟达的心腹之一，在加入英伟达之前，Parixit刚升任小鹏汽车北美软件工程副总裁（Engineering VP）。
不过，Parixit进入英伟达后并非直接向吴新宙汇报。一位知情人士向36氪汽车解读，客观上来看，Parixit与吴新宙之间有一道“隔离墙”：Parixit的直接汇报线并未指向掌管汽车业务的吴新宙，而是归属于英伟达软件工程高级副总裁Dwight Diercks，后者同样是英伟达的老员工。
在内部信中，Parixit及其部门的变动还特地强调了“特别感谢Dwight的100%支持”。
Parixit进入英伟达后，先是接手了DriveOS业务，而后又吃下了自动驾驶仿真业务，进一步实现版图扩张，此次重新被纳入吴新宙的组织下，某种程度上也是吴新宙到英伟达近三年时间的一次大型管辖权扩张。
这么做的好处是，吴新宙不仅有了其原来熟悉的作战团队，而且将底层操作系统和上层应用打通，这种组织上的“合体”，最直接的效果则是提升软硬协同的研发效率。
英伟达智驾
走向量产为重
英伟达引入有量产经验的Dheeraj最直接的考量，是英伟达现在急需用几个标杆车企量产交付成果证明自己的能力，在智驾的全球混战中站稳脚跟。
2025年3月，英伟达CEO黄仁勋在官宣与丰田、奔驰等车企的合作时也同步释放了对自动驾驶业务的期许，“英伟达自动驾驶业务将在2026年创造50亿美元的收入。”吴新宙和他的团队距离这一目标还有相当的距离（2024-2025年，英伟达汽车业务收入分别为11亿美元、23亿美元）。
要兑现这笔庞大的商业期许，英伟达必须跨越到“大规模量产交付”。
吴新宙加入英伟达后，打磨出了一套完整的智驾工程，构筑了“五层蛋糕”的技术服务架构，并陆续拿下了丰田等多家主流车企的量产定点。这种战略重心的转移，在今年的英伟达GTC大会上已经初见端倪。
过去，英伟达往往更热衷于展示前沿的AI模型与惊人的算力指标。但在2026年GTC上，英伟达在自动驾驶领域的更新主要集中在三个方向：模型能力、安全架构以及仿真与数据工具。
这些能力分别对应自动驾驶落地过程中的关键环节——能力上限、安全可验证性以及开发效率，旨在解决自动驾驶如何从小规模验证走向规模化应用。
过去几年，在极度内卷、追求极致性价比的中国智驾市场，英伟达曾一度掉队。但放眼更为广阔的海外市场，智能驾驶的格局尚未完全固定，这为英伟达留下了翻盘空间。
国内的智驾玩家也正加速智驾出海。近期，小鹏汽车和地平线等中国厂商已纷纷在德国慕尼黑等地展开海外智驾能力的实车测试与技术展示，Momenta等厂商也在为智驾出海做了充分准备。要在海外战场抢占更大的市场份额，英伟达急需通过这轮重组后快速提升工程交付力。
除了布局L2+的全球化量产，吴新宙的团队也在同步开发L3和L4方案。按照其内部规划，英伟达将在2026年实现L2++点对点功能在美国落地，并拓展至欧洲等地区；2027年计划与合作伙伴在部分城市开展L4试点；并计划在2028年洛杉矶奥运会期间，为20至30个城市提供L4级无人驾驶服务。
目前，奔驰、Lucid、Stellantis都已官宣了与英伟达在L4 Robotaxi上的合作，英伟达也预计在明年与Uber联合推出L4级别的试点。
在吴新宙看来，“提供全栈解决方案只是工作的一部分，对英伟达而言更重要的使命是赋能整个产业，推动其尽快向L3或L4级无人驾驶能力发展。”
不过，英伟达长远的野心不会只是拿下多少车企订单，而是复现它在AI领域那样的影响力，为物理AI的发展提供技术底座，而自动驾驶将是物理AI领域最早实现量产和大规模落地的场景。
