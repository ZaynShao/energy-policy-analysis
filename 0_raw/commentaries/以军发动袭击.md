# 以军发动袭击

以军称袭击黎南部三处真主党指挥中心。
▲以方发布本次打击画面
当地时间29日，以色列国防军发表声明称，作为对黎巴嫩真主党违反停火协议的回应，以军28日对位于黎巴嫩南部的三处真主党指挥中心实施了军事打击。
声明表示，黎真主党近期持续对位于“安全区”内的以色列国防军士兵发动袭击。作为回应，以军于28日空袭了真主党位于黎南部奈拜提耶和迈法敦地区的三处指挥中心。此外，以军在28日早些时候还摧毁了一个黎真主党的火箭弹发射装置。以军称，真主党此前曾持续使用该装置对前线以军士兵实施针对性袭击。
以色列国防军在声明中重申，以军将继续采取行动消除任何针对以方士兵的潜在安全威胁。
