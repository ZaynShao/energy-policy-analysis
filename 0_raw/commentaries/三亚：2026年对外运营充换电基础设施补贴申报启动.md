# 三亚：2026年对外运营充换电基础设施补贴申报启动

重磅报告 | 点击上图，下载重卡充电站行业报告
 本文来源  | 三亚市发改委
8月13日，三亚市发改委发布公告，组织申报2026年对外运营充换电基础设施补贴，申报截至8月20日。
补贴标准为充电桩建设补贴每千瓦100元（上限不超设备投资额10%）；换电站一次性补贴设备投资额10%；运营补贴按充电电量0.1元/kWh，且每个充电桩（站）补贴上限为每千瓦不超200元/年。
关于组织申报三亚市
2026年对外运营电动汽车
充（换）电基础设施补贴的公告
按照海南省发展和改革委员会《海南省电动汽车电基础设施建设运营暂行管理办法》（琼发改交能〔2019〕922号）《海南省电动汽车充电基础设施验收暂行办法》（琼发改能源函〔2019〕1334号）《海南省电动汽车充电基础设施建设运营补贴工作流程》（琼发改能源函〔2020〕57号）等文件精神，以及最新工作部署安排，我委将牵头开展全市对外运营充换电基础设施的建设和运营补贴申报工作。为切实做好此次申报，现将有关事项公告如下：
一、申报时间
公告之日起至2026年8月20日。
二、申报范围
在三亚市行政区域内建成并通过验收审核、投入对外运营、接入省级平台的充（换）电基础设施，可申报补贴。充（换）电基础设施包括充电桩、换电站。
（一）2025年1月1日至2025年12月31日期间新建成的充（换）电基础设施，可申报建设补贴。
（二）2025年12月31日前已建成的充（换）电基础设施，可申报2025年内的运营补贴。
（三）2024年1月1日至2024年12月31日期间建成，由于不可抗力因素在2025年未申报、获批的充（换）电基础设施，说明客观原因后，可继续申报建设和运营补贴。
三、补贴标准
（一）建设补贴
1.充电桩。以每个充电桩的额定功率为基数，按照每千瓦100元，补贴上限不超过设备投资额的10%。
2.换电站。一次性给予项目设备投资额的10%资金补贴。
（二）运营补贴
按照运营期间的充电电量，给予运营补贴，补贴标准0.1元每千瓦时。同时按照安装额定功率为基数，每个充电桩（站）补贴上限为每千瓦不超过200元每年。
四、申报要求
1.原则上由项目业主单位（以项目备案为准）进行申报。若由运营或代管单位申报补贴的，需项目业主单位出具书面委托书及相关佐证材料（包含项目运营或代管协议、合同等）。
2.填写《海南省电动汽车充电基础设施验收申请表》、《海南省充电基础设施建设运营补贴申请表》、《申报2026年电动汽车充换电基础设施验收及补贴场站基本情况表》（详见附件1-3）。
3.申报企业同步准备建设、运营补贴申请相关佐证资料。
4.请将上述纸质版材料于8月20日前（跨年度申报材料分开提供）提交至省级平台（冯先生电话:15289988191）。请将电子版发至邮箱yanshou@hainancce.com，邮件备注格式如下：“公司全称+三亚市2026年充（换）电基础设施补贴申报”。
5.在此之前已获得充（换）电基础设施建设或运营补贴的，不再重复申报和补贴。
6.按照《海南省电动汽车充电基础设施建设运营补贴工作流程》（琼发改能源函〔2020〕57号）中“相应责任”的要求，申报企业须承诺对提交申请材料的真实性负责（承诺书详见附件4）。
7.逾期未按要求提交材料将不再受理，提交材料后需补充完善的应按要求时间提供，若因提交材料未在规定时间完成，错失申报的由申报主体自行承担责任。
8.为节省申报时间，企业需同步提交建设、运营补贴申请相关资料。
五、开展审查
（一）验收组织。我委将会同各区、各园区有关单位、市自然资源和规划局、市住房和城乡建设局、市市场监督管理局、三亚供电局、省级平台组成专项联合验收小组开展验收及补贴申报工作，相关企业配合做好验收工作，并按要求及时间节点提供材料。
（二）验收流程
1.根据材料报送及初步审核情况，将同步开展现场联合验收及检查。
2.现场检查完成后，申报企业填写《海南省电动汽车充电基础设施联合验收报告》（详见附件5），按照前述申报材料方式予以提供。
（三）核定上报。经联合验收工作组审核合格后，核算建设、运营补贴并上报海南省发展和改革委员会。
六、沟通交流
为充分做好本次申报释疑和解答审核过程中的疑问，请联系省级平台冯先生，后续将对申报企业在申报过程中遇到的问题进行解答；申报材料不完善或有疑义的，后续将集中反馈。
七、注意事项
（一）为推动我市充电基础设施健康有序发展，提升充电服务便捷性和安全性，我市已建成“充电一张网”平台（简称“市级平台”），请各申报电动汽车充换电基础设施建设及运营补贴的运营主体在8月20日前完成市级平台的接入。
（二）为保证验收工作质量，企业须事先对充换电基础设施自检，对照《验收办法》中的不合格条目整改合格以保证验收工作顺利进行。同时建议企业安排专人对接，确保在各节点按照要求及时提供材料，避免逾期无法提交材料。
（三）为确保申请补贴场站用地的合规，除经审批停车场外，其他配套建设充换电基础设施场站需提供该地的红线坐标（大地2000坐标），已申请过建设补贴且核验过无需提供。
（四）对提供虚假信息、骗取财政补贴资金的，将追缴补贴资金、取消补贴资格，并按照《财政违法行为处罚处分条例》（国务院令第427号）予以处罚；构成犯罪的，依法追究刑事责任。
