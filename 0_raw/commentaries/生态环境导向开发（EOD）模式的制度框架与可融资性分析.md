# 生态环境导向开发（EOD）模式的制度框架与可融资性分析

如您希望下载PDF版本，请点击文末“阅读原文”获取。
EOD（Eco-environment Oriented Development，生态环境导向的开发）模式是结合国际上将生态修复与产业开发一体化推进的实践经验，逐步形成的具有中国特色的项目组织实施方式。2018年，生态环境部在《关于生态环境领域进一步深化“放管服”改革，推动经济高质量发展的指导意见》（环规财〔2018〕86号）中首次正式提出“探索开展生态环境导向的城市开发（EOD）模式”，EOD由此进入国家生态环境政策话语体系；此后经过备选项目征集、两批试点、储备库运行等阶段，逐步从政策倡导走向规则成型。
2023年12月，生态环境部办公厅、国家发展改革委办公厅、中国人民银行办公厅、国家金融监督管理总局办公厅联合印发了《生态环境导向的开发（EOD）项目实施导则（试行）》（环办科财〔2023〕22号，“《实施导则》”）。《实施导则》首次以四部门联合发文的形式，就EOD模式的核心要义、准入条件、组织实施主体、项目入库与融资对接、评估监督等作出系统规定，事实上确立了EOD项目在谋划、立项、融资、实施和监管各环节应予遵循的基本规则，是判断一个项目“是不是EOD”、“能否入库并对接融资”的核心依据。
从功能定位上看，EOD模式通过将公益性生态环境治理与经营性关联产业一体化实施，以关联产业收益反哺治理投入，并将生态环境改善产生的正外部性转化为项目经营价值。其特殊性决定了项目在准入、政企边界和融资结构方面具有不同于传统工程建设项目的要求。
本文旨在系统梳理EOD模式的规范定义与准入边界，回顾其从试点探索到制度成型的政策沿革，厘清项目申请与实施的关键程序，并围绕金融机构的核心关切，从现金流结构、风险分配、担保安排等维度解析EOD项目的可融资性要点，为政府、企业及金融机构参与EOD项目提供实务参考。
01
什么是EOD项目：定义、准入边界与政府—市场主体分工
1. EOD模式的定义与核心特征
根据《实施导则》第二条和第十二条，EOD模式是通过产业链延伸、组合开发、联合经营等方式，将公益性较强的生态环境治理与收益较好的关联产业融合实施，以生态环境治理提升关联产业经营收益，以产业增值收益反哺治理投入，实现生态环境治理外部经济性内部化的创新性项目组织实施方式。[1]
结合《实施导则》第二条以及其后各条的具体要求，EOD项目应当具备以下核心特征，理解这些特征也有助于把握EOD与其他相关模式（如传统片区综合开发、PPP、特许经营等）的实质性区别：一是内容构成上“二合一”：项目由公益性较强的生态环境治理内容与收益较好的关联产业内容共同构成，二者作为整体项目、由同一市场主体一体化实施，而非只做治理或只做产业；二是经济逻辑上“闭环”：生态环境治理直接或间接提升关联产业的经营收益，产业的增值收益反哺前期治理投入；三是资金结构上“自平衡”：项目原则上通过关联产业经营收益实现资金平衡，并应符合地方政府隐性债务监管要求；四是实施机制上“市场化”：由市场主体自主决策、自负盈亏，负责项目投资、建设与长期运维经营，不同于以工程建设为核心的EPC总承包，也不同于以政府付费或可行性缺口补助为主要回报机制的PPP/特许经营项目。
2. 组织与实施：政府组织谋划、市场主体一体化实施
EOD模式的一体化实施与市场化运作特征，决定了项目落地须明确政府与市场的权责边界。
在组织主体与实施主体的权责划分上，《实施导则》第四条确立了“政府引导、企业和社会各界参与、市场化运作”的基本格局：
一方面，市、县（区）人民政府或园区管委会作为项目组织主体，承担组织领导、项目谋划、统筹协调、督促推进与评估指导等职能，并鼓励有条件的乡镇探索组织实施；政府有关部门则各司其职，在项目立项、生态环境治理、资源要素保障、关联产业发展及融资支持等方面提供服务与技术指导。
另一方面，市场主体作为项目实施主体，遵循自主决策、自负盈亏的原则，具体负责项目落地实施与运维经营，并依据相关法律法规、标准及合同约定承担相应的生态环境治理责任。这一制度安排既发挥了政府在规划引导与要素配置中的统筹作用，又确立了市场在投资建设和运营维护中的主体地位，形成政企协同、权责清晰的实施机制。
3. EOD模式案例
前述定义、准入边界与主体分工，可以在已有的项目实践中得到直观印证。以两个进入生态环保金融支持项目储备库的项目为例：
宜兴市滆湖西岸生态治理及产业升级（一期）项目总投资约13.63亿元，其中80%资金可通过银行贷款筹措，完成10.8亿元银行授信。项目将湖滨生态缓冲带、入湖河道整治等治理内容与生态养殖、绿色科创园等产业组合实施，核心现金流来自生态养殖及园区厂房租售。[2][3][4][5]
马鞍山市向山地区生态环境综合治理EOD项目总投资约82.65亿元，将矿山修复、水环境治理与光伏发电、工业文旅、特种经济林等产业组合开发，采用“特许经营+投资人+EPC”的一体化实施模式，其偿债基础主要取决于发电、文旅及林业经营收入。[6][7][8]
02
法律与政策沿革：从政策倡导、试点探索到规则成型
1. 从政策倡导、试点探索到规则成型
2. 金融支持政策与生态环保金融支持项目储备库对接
如前所述，银发〔2024〕70号文已在国家层面明确要求加强对EOD模式的金融支持、完善相关投融资模式。这一要求在EOD项目层面的具体落地机制，是生态环保金融支持项目储备库。《实施导则》第十六条规定，EOD模式试点期间，应按照《生态环保金融支持项目储备库入库指南》的要求，通过生态环保金融支持项目管理系统开展项目信息报送、对接、反馈与完善等工作，并推送金融机构。据此，符合条件的EOD项目可以且应当对接生态环保金融支持项目储备库，这也是通常所称“EOD入库”的前端环节。
入库对EOD项目的作用主要体现在四个方面：一是建立标准化的推送通道，提高项目与合作金融机构之间的融资对接效率；二是对符合放贷或投资条件的项目，金融机构可在资源配置上予以倾斜，并优先给予优惠信贷等支持；三是储备库与生态环境领域重大工程项目台账管理系统相衔接，入库项目便于纳入重点工程跟踪管理；四是从实践看，已有大批EOD项目经储备库推送获得规模化授信与放贷。
需要指出的是，“入库”须区分两个层面。进入生态环保金融支持项目储备库并推送金融机构，并不等于当然获得融资。《实施导则》第十六条明确，有关金融机构遵循独立审贷、自主决策、自担风险的原则，仅将符合本机构信贷或投资支持条件的项目纳入其自身储备库，并推进信贷或投资审批；已发放贷款或资金支持的项目进入支持库，不符合金融资金支持条件的项目则予以淘汰。
上述机制已初见成效。据生态环境部2024年7月24日《关于政协十四届全国委员会第二次会议第04067号（资源环境类286号）提案答复的函》，2020年以来已指导260余个EOD项目（含两批试点）进入储备库并向金融机构推送，截至2024年6月底，已获得金融机构授信2000余亿元、发放贷款660余亿元。

04
EOD项目的可融资性分析
EOD项目虽具有绿色金融政策支持和储备库融资对接机制，但政策属性不能替代项目本身的可融资性。金融机构最终关注的，仍是项目在建设期和运营期形成的现金流、风险分配、合同结构和增信安排能否支持债务偿还。
从项目融资视角看，EOD项目应遵循以项目现金流为主要还款来源、通过合同和账户安排实现风险隔离与现金流控制的基本逻辑。判断重点不是“是否属于EOD”，而是项目能否形成可预测、可控制并经受压力测试的可供偿债现金流。
1. EOD项目融资边界特征
（1）项目自身经营与政府责任边界
《实施导则》第十二条、第十九条及实施方案编制指南共同划定了EOD项目的融资边界：项目应依靠自身经营实现资金平衡，合同不得约定政府支出责任、融资担保或者其他可能增加地方政府隐性债务风险的事项。
政府付费、固定回报、回购、保底收益、差额补足等安排，应结合其法律性质和经济实质，审查是否形成政府中长期支出责任或变相信用兜底。EOD项目的可融资性原则上应建立在项目本身的商业和财务可行性之上。
（2）可纳入资金平衡的项目收益边界
基础情景下可以确认的，应是实施主体在项目生产或服务经营过程中依法取得并能够归集的产业收入、资产经营收入等。预期土地出让收入、预期新增税收等政府收入，以及尚未落实的生态补偿、森林湿地碳汇等不确定收益，不宜纳入项目资金平衡。
上述边界并不排斥政府在土地、规划、许可、基础设施接入、经营权授予和协调等方面依法履职，也不排斥项目依法享有生态环境改善带来的资产或经营价值提升；其限制的是以政府信用或不确定收益替代项目自身商业可行性。
2. 基础融资结构
（1）资本金出资
《实施导则》要求项目实施主体按照相关要求及时筹措项目资本金，并明确资金来源、项目资本金筹集方式和比例。结合EOD市场化运作的要求，资本金通常由项目实施主体及其股东筹措，实践中可以包括社会资本、国有企业自有资本以及符合条件的绿色基金、产业基金等市场化权益资金。需要注意的是，《实施导则》明确要求EOD项目本身不得以中央或地方财政资金投入作为资金平衡来源。
在基金支持方面，生态环境部已与国家开发银行、中国农业发展银行、国家绿色发展基金等金融机构建立EOD项目融资对接机制。国家绿色发展基金按照市场化方式运作，其支持范围包括污染治理、生态修复等绿色产业，因此可以成为符合条件EOD项目潜在的权益性或其他市场化资金来源，但具体是否投资以及投资方式仍由基金按照市场化原则确定。
（2）中长期债务融资
在资本金之外，银行贷款是EOD项目的重要资金来源。《实施导则》明确要求项目实施主体加强与金融机构接洽、推进项目融资，并要求金融机构按照依法依规、独立审贷、市场化运作和风险可控原则，对符合条件的项目提供相应支持。早期EOD试点文件还专门提出，由国家开发银行发挥开发性金融“大额中长期资金优势”，对符合条件的EOD项目在资源配置上予以倾斜。
此外，如前文所述，2024年《关于发挥绿色金融作用服务美丽中国建设的意见》、2024年银发〔2024〕70号文以及2025年《银行业保险业绿色金融高质量发展实施方案》等国家层面文件，均对EOD项目融资提出了具体的绿色金融支持要求，实践中EOD项目可结合绿色信贷、开发性和政策性金融等中长期资金来源进行融资。
3. EOD项目的可融资性（Bankability）来源
如前所述，进入储备库并不等于必然获得贷款——金融机构仍须按“独立审贷、自主决策、自担风险”原则审批，只有符合其自身信贷或投资条件的项目才会进入其自身储备库并推进审批。这也意味着，EOD项目要真正获得金融机构支持，其可融资性最终仍取决于以下几项基本要素。
（1）稳定、可预测的项目经营现金流
从项目融资角度看，EOD项目的可融资性首先来源于能够覆盖项目运营成本和债务本息的经营现金流，而不是“EOD”这一政策标签。《实施导则》要求对项目投资、运营费用和营业收入进行完整测算，评价项目的盈利能力、债务清偿能力和财务持续能力；在实施方案中还需对关联产业的市场环境、市场容量、发展前景、市场需求和预期进行分析，并明确要求避免为追求资金平衡而虚列收益或进行不切实际的高估。
因此，文旅、生态农业、园区经营、清洁能源等关联产业本身是否具有可靠的市场需求和持续盈利能力，是判断EOD项目能否取得融资的核心因素。
以前述案例为例，宜兴项目的偿债基础在于园区租售和生态养殖等经营现金流；向山项目则需分别评估光伏发电、文旅和林业收入。生态治理改善产业价值只是传导逻辑，不能替代对各项收入可实现性的独立论证。
在收入预测基础上，贷款人并非仅判断项目是否盈利，而是根据可供偿债现金流、DSCR或LLCR等指标及压力测试结果确定债务承载能力。在项目收入下降、成本超支、投产延期和利率上升等情景下的偿债表现，对可融资性分析而言更加重要。
（2）生态治理与关联产业的价值关联
EOD并非将一个不盈利的治理项目与一个盈利项目简单拼接。《实施导则》第七条至第九条要求生态环境治理与关联产业具有真实的价值传导、空间或产业链联系。
金融机构需要能够合理解释“治理措施—环境质量改善—产业经营指标提升—现金流增加”的传导链条；关联性越弱，所谓“产业反哺”越接近项目间交叉补贴，现金流稳定性也越难获得认可。
（3）项目收益能够归集并受到有效控制
《实施导则》第十一条要求项目用地用海、经营权益和预期收益等能够依法依规归属于同一个市场主体，并由该主体统一推进项目投资建设和运维经营。
这一要求与项目融资的基本逻辑高度一致：不仅要有收益，还需要确保项目资产、经营权益和现金流能够法律上归属于融资主体，并通过账户监管、收益归集和担保安排形成有效控制。否则，即使关联产业具有较好的经济效益，也未必能够真正成为借款人的偿债来源。
这一原理与国际项目融资中的“项目围栏”（ring-fencing）安排相通。在实务中，金融机构通常通过一系列安排将项目资产、经营活动和现金流限定在融资项目范围内，包括将项目公司设为经营范围仅限于本EOD项目生态治理、关联产业投资建设及运营维护的单一目的公司（SPV），要求其将全部经营收入归集至贷款人指定的收入归集账户、监管账户和偿债储备账户等账户，并按照约定的资金流瀑布（waterfall）支付顺序安排项目运营支出、偿债和分红；同时，以项目公司的主要资产、股权、特许经营权及核心合同权利等依法为贷款人提供质押、抵押或权利让与等担保，并限制项目公司在贷款存续期内从事超出项目范围的其他投资或提供对外担保。这些安排共同构成项目融资“以项目自身现金流为主要还款来源”的制度保障。
（4）融资期限与项目生命周期相匹配
EOD项目通常具有建设周期较长、生态改善和关联产业培育需要一定时间等特点，因此融资期限、宽限期及还本安排应与项目现金流形成周期相匹配。国家开发银行在EOD试点阶段即被要求发挥开发性金融“大额中长期资金优势”，对符合条件的EOD项目在资源配置上予以倾斜，这也体现了EOD项目对长期资金的客观需求。从公开案例看，无锡滨湖太湖湾马山片区EOD项目获得的国家开发银行江苏分行9亿元贷款，总期限达23年、宽限期5年，客观反映了EOD项目融资对超长期限资金的实际需求[9]。
（5）项目合同与风险分配
生态治理与经营性产业往往具有不同的建设时序，贷款人需要审查EPC合同是否合理分配价格、工期、性能和超支风险，以及治理工程完成与产业投产之间是否设置清晰的接口条件；对于未能通过合同转移的完工风险，还应评估股东是否提供适当的完工或超支支持。同时，考虑到项目公司未必自行具备文旅、农业、能源或园区运营能力，如由其委任实际运营主体开展运营，融资文件和项目合同还应明确实际运营主体、绩效标准、成本机制、违约责任和替换安排；对于售电、租赁、招商、销售等收入，则应结合购售电、租赁、承购或营销合同评估承购方信用和市场风险。
4. 实施主体的三个融资实务提示
（1）将融资可行性测试前置
《实施导则》第十四条要求项目实施主体（即项目公司/业主）在实施方案编制阶段开展市场测试，获取潜在市场主体和金融机构对项目的响应情况，并根据反馈优化实施方案、提高项目可行性和可融资性；这是《实施导则》直接对项目业主一侧的要求，也是企业在项目融资准备中最重要的前置动作之一。
因此，企业不宜在项目方案、投资规模和产业内容完全确定后才开始寻找融资，而应在项目策划阶段即开展财务测算并与潜在金融机构沟通，根据银行对于收入预测、资本金、融资期限和担保结构的反馈调整项目边界和融资结构。
（2）从EPC承包思维转向“投资—建设—运营—偿债”思维
EOD实施主体同时承担投资、建设和长期运营责任，融资对象是项目公司未来经营现金流，而非施工合同标的额。企业需要从项目公司整体资本结构和全生命周期偿债能力出发安排投资、建设和运营。
相应地，企业需要重点关注资本金比例是否与项目投资规模相匹配、股东是否具备持续增资能力，避免因资本金未足额到位导致贷款条件无法成就；同时，还应确保项目公司自身具备生态治理及关联产业的持续经营能力，或通过长期运营合同取得相关能力。
（3）融资前解决关键合规前提
在进入融资审批前，应尽早形成清晰的项目边界、权利基础和合同体系，并使融资主体能够依法取得项目用地用海、经营权、核心合同权益和项目收益。
不能在融资文件中解决的土地规划、许可、主体确定或经营权瑕疵等问题，不应留待贷款发放后补救；其可能直接影响提款条件、担保有效性和项目持续经营。
实施主体应重点审查项目审批、立项、规划、用地、用海、环评等前置手续是否合规完备，实施主体是否通过依法合规的竞争性方式确定，以避免程序瑕疵影响项目稳定性；同时，还应确认核心项目合同是否完整、可执行，合同期限、终止补偿和权利转让安排是否与贷款期限及介入机制相衔接，以及项目关联产业所需的行业准入、环保、安全生产等专项许可是否已经取得。上述任何一项存在瑕疵，均可能在贷款审批阶段被认为是风险因素。
结语
一个能够真正落地并获得金融机构支持的EOD项目，必然是治理内容公益性充足、产业内容市场前景可靠、现金流预测经得起压力测试、担保结构与账户监管完善、风险分配清晰、合规基础坚实的项目。无论是政府组织主体、企业实施主体，还是提供资金支持的金融机构，均需在合规底线之上进行细致的商业与法律安排。
正因如此，EOD项目的谋划、方案设计、主体确定、投融资安排以及后续实施与评估，涉及生态环境法、地方政府债务合规、投融资合规、招投标与政府采购、公司法、金融法、合同法等多个法律领域的交叉判断，也需要在生态治理专业机构、财务顾问、投行、律师等专业服务机构之间形成分工协同。
企业在参与EOD项目时尽早引入具备生态环境法、投融资和项目融资综合经验的专业律师团队，不仅有助于项目更顺畅地取得金融机构支持，也有助于在合作期内有效识别、分配并管控法律与合规风险，让EOD模式真正从政策概念转化为可持续经营的项目实践。
