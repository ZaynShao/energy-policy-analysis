# 东风轻型车丨福瑞通首批百余台定制车辆交付三棵树

近日，东风汽车股份有限公司（以下简称"东风股份"）与三棵树涂料股份有限公司（以下简称"三棵树"）战略合作定制车辆在湖北襄阳完成发运前集结，首批百余台车辆率先发运，后续批次将按交付计划有序推进，标志着双方在物流用车定制领域的合作正式落地。
此次交付的东风福瑞通V6具备出色的载货能力与灵活车身设计，货厢空间利用率高，适配建材家居行业高频次、多品类的城配运输场景；车辆传承东风军工造车底蕴，历经高原、高寒、高温极端环境测试，品质可靠耐用。
同时，东风股份依托"一车一策"深度定制能力，为三棵树量身打造专属版本。外观采用三棵树品牌标识搭配专属绿色贴画，行驶辨识度高；货厢内部针对涂料类货品特点，地板做加厚处理，大幅提升耐损耐磨性能，适应高频装卸场景。
从2026年4月双方签署战略合作协议，到7月首批交付落地，东风股份与三棵树稳步推进合作。三棵树作为绿色环保涂料领军企业，遍布全国的实体门店网络对物流配送有刚性需求。三棵树最终选择东风福瑞通V6作为城配用车，充分验证了东风股份在定制化能力和产品品质上的市场竞争力。
未来，双方将继续在汽车装备、汽车漆国产化、物流用车定制等方向深化合作。东风股份将以央企军工品质与深度定制能力，持续赋能行业客户高效运营，助力绿色产业链协同发展。
