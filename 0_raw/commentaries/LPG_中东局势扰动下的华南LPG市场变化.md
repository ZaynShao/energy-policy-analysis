# LPG | 中东局势扰动下的华南LPG市场变化

**导语**

中东作为全球油气资源核心产区，自2月28日中东地缘冲突爆发以来，原油和LPG供应持续收紧，推动国际油价及LPG外盘价格大幅上行，为国内LPG市场提供强劲成本支撑。而华南LPG高度依赖进口，进口资源市场份额占比超70%，其中80%以上进口资源来自于中东地区。因此此次冲突加剧了市场对远期供应担忧，推动华南市场积极跟涨国际行情，价格迅速攀升。但随着价格升至高位，下游用户接货压力逐步显现；叠加近期码头供应偏宽松的影响，市场上行动力减弱，进入高位僵持阶段。整体来看，华南LPG市场呈现出“急涨后高位僵持”的运行态势。  

中东地缘冲突升级后，霍尔木兹海峡航运受阻，作为全球LPG核心产区的中东出口严重受限。由于中国是全球最大LPG进口国，同时华南地区进口依赖度较高，因为其地理位置，中东的货源在华南进口结构中占比高达83%，因此受冲突影响，市场对后续进口到货中断的担忧迅速发酵，推动价格快速跟涨。

冲突初期（3月上旬）——冲突导致断供担忧进而价格跳涨。此阶段液化气市场的定价逻辑已从“供需基本面”转向“事件驱动”，核心特征是情绪的主导下，市场交易重心转向对远期供应中断的担忧，从而推动价格迅速攀升。

进入3月中旬，市场进入第二阶段，价格上涨节奏放缓。尽管地缘风险带来的成本支撑依然强劲，推动价格惯性冲高，但历史高价对下游需求的抑制效应逐步显现，出货节奏放缓。同时，供应端短期内并未出现实质性收紧，冲突对供应的实际影响主要体现在远期（3月底或4月），当前炼厂供应保持平稳，3月华南进口到船基本未受影响，且月中珠三角集中到货后港口需高效周转，反而形成阶段性供应宽松局面。因此市场上行动力受限，尤其是进口码头跟涨不足，甚至出现暗惠现象。市场由此进入“横盘整理”阶段，涨势放缓，部分单位因出货承压而出现价格松动。

自2月28日中东冲突爆发以来，华南液化气市场表现强于全国，却不及国际走势。这主要是由于华南进口成本多以CP价格为基准，而3月CP在冲突爆发前便已确定，使得本月进口成本已提前锁定。在国内外价格持续攀升而本月实际成本相对平稳的背景下，进口利润空间被迅速拉宽，在动荡局势下，且因时间节点错配带来的高额利润，进口商更倾向于“落袋为安”，在高位积极出货，从而在一定程度上抑制了现货价格的跟涨幅度。

3月份，华南液化气进口利润表现尤为亮眼。由于3月沙特CP价格在冲突爆发前便已确定且环比上月持平，本月进口成本得以在动荡中保持平稳。而现货市场受地缘紧张局势驱动，价格迅速攀升。成本与销售价格在时间节点上的错配，拉宽了进口气内销的利润空间。面对利润丰厚，且进口码头阶段性船货充裕、地缘局势不确定性较高的背景下，纯贸易库并未出现捂货惜售行为，而是普遍选择积极出货、加快周转。因此，华南市场呈现出“远期紧张、近期宽松”的供应格局，这也是当前价格陷入僵持，涨势放缓的主要原因。

自2月以来，华南进口库区库存持续攀升，3月更是在此基础上进一步累库，平均库存水平多维持在50%以上。这一数据表面了当前进口码头并未出现实质性的供应短缺。因此，近期市场的上涨行情，其核心驱动力并非实质性的供应紧张，而是基于对4月供应收紧甚至可能中断的远期预期。

当前市场仍受中东动荡局势主导，地缘风险带来的远期担忧与短期基本面宽松持续博弈。供应端来看，炼厂下旬存在降量预期，为市场提供一定支撑；但码头供应相对宽松，成为现阶段行情推涨的主要阻力。后市来看，随着3月底集中到船陆续消化，加之4月进口到船大幅度减少，供应端压力将逐步缓解，并逐步趋向于紧张。同时，4月进口成本预计大幅度走高，为市场提供强劲底部支撑。综合来看，在地缘局势出现实质性缓和之前，3月底至4月市场有望酝酿新一轮上涨行情。
