# 特朗普威胁轰炸阿曼

美国总统特朗普17日对盟友阿曼发出威胁，称如果阿曼干预围绕霍尔木兹海峡控制权的潜在协议，美国将对阿曼发动打击。
据《华盛顿邮报》17日报道，特朗普当天在接受福克斯新闻采访时发出了上述威胁。当被福克斯新闻记者特雷·英斯特问及伊朗与阿曼之间关于霍尔木兹海峡控制权的谈判时，特朗普说道：“如果阿曼挡路，我们就把他们炸个稀巴烂。”
▲《华盛顿邮报》报道截图
据英斯特称，特朗普还表示伊朗应该“举起白旗投降”。不过，特朗普也说，自己并没有结束对伊战事的具体时间表。
据美国全国广播公司报道，当天晚些时候，特朗普在白宫椭圆形办公室接受记者采访时，被要求进一步解释这些言论。特朗普说：“我认为他们的行为不太好，但我们会轻松应对，就像我们处理其他事情一样。”
阿曼与伊朗目前正就霍尔木兹海峡的通航和管控安排展开磋商，美国也在寻求与伊朗达成单独协议。伊朗迈赫尔通讯社此前报道称，伊朗已与阿曼就霍尔木兹海峡的通行计划达成协议。
今年5月，特朗普就曾威胁如果阿曼试图与伊朗一起控制霍尔木兹海峡，将对其进行打击。
《华尔街日报》在分析特朗普为何威胁轰炸阿曼时表示，数周以来，白宫一直承诺伊朗即将签署核协议，并表示阿曼可以帮助重新开放霍尔木兹海峡。然而，这项协议却迟迟未能达成。特朗普对这种僵局感到沮丧。此外，美国政府内部存在一种挥之不去的担忧，即阿曼可能会帮助伊朗斡旋达成一项对德黑兰更有利的核协议，这加剧了特朗普的愤怒。
