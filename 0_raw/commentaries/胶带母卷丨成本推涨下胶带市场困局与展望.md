# 胶带母卷丨成本推涨下胶带市场困局与展望

【导语**】****2026年3月，受中东地缘局势持续发酵推动，上游原料大幅上行，胶带母卷市场价格紧跟成本端走高。截至3月13日，华东市场价格涨至13500-13600元/吨，突破近4年价格高位。当前高价货源向下游传导不畅，前期订单价格低于生产成本，企业生产承压，行业开工负荷走低。预计3月下旬市场维持高位震荡，波动区间500-1000元/吨，单边大幅波动空间有限，需关注下游价格接受度及供需成本博弈下价格平衡点的形成。**

**成本驱动价格突破近4年高点**

**3月国内胶带母卷市场呈现上行趋势，报价及意向出货价格跟随成本端持续冲高，截至3月13日华东市场价格已攀升至13500-13600元/吨，价格水平突破近4年高位，较春节前累计上涨61.31%。其他区域也有不同上涨：山东市场涨至13000-13500元/吨，华北市场13100-13700元/吨，华南市场13300-13600元/吨，东北市场13200-13600元/吨。**

**本轮行情并非需求端拉动的主动上行，而是成本压力下的被动上涨。中东地缘局势的持续扰动，引发国际原油价格大幅冲高，而原油作为化工产业链的基础原料，其价格波动直接传导至胶带母卷的两大核心原料端-BOPP以及丙烯酸丁酯，两大原料价格近期同步大幅走高，直接推高胶带母卷单吨生产成本，成为本轮价格上涨的核心底层支撑。据了解，胶带母卷单吨生产成本大幅跳涨，生产企业成本端压力达到近四年来的高位，多数厂家出现生产成本与出货订单价格倒挂，厂家普遍被动上调报价及出货价格。**

**生产端承压挺价，开工负荷小幅下调，需求仍需传导**

当前胶带母卷行业难点集中在高成本压力与下游需求承接能力的双向博弈上。面对上游原料价格的持续冲高，胶带母卷生产企业均面临极大的生产经营压力，挺价意愿偏强。从盘面上看，胶带母卷紧跟成本涨势顺利，截至3月13日盘面月均毛利达518.75元/吨。但在成本快速上涨过程中，厂家心态谨慎，多数厂家限量接单及封盘，高价订单偏少。而合约原料的成本已完全计入合约落地生效，企业快速调涨价格后，缺乏大规模备货的需求支撑，面对大幅冲高的原料价格，下游终端用户抵触情绪较强，普遍采取“小单、高频、刚需”的采购模式，随用随采，备货意愿极低。这就导致生产企业以12000+元/吨的生产成本，交付前期7400-8600元/吨的订单。市场陷入“意向成交价格高位、成交僵持”的局面，故行业内厂家出货价格维持高位运行，或采取提前期低价单搭配高价订单的操作，以保证企业装置平稳运行。

原料采购成本高企、下游对高价货源接受度有限双重因素影响，胶带母卷行业整体开工负荷率出现下降。厂家多采取稳价控量的经营策略，主动下调开工负荷，一方面规避高价原料采购带来的现金流与成本倒挂风险，另一方面通过适度收缩供给，缓解库存压力，避免出现价格冲高后快速回落的情况。截至3月12日，胶带母卷行业开工负荷率已降至 47.93%，较去年同期回落3.85个百分点；而截至3月17日的最新跟踪情况来看，行业开工负荷的下行趋势仍未止步，生产端降负态势仍在持续。

**后市展望：高位震荡为主 涨跌均有限 成交有望逐步回暖**

综合来看，本轮胶带母卷价格上行核心源于成本端刚性支撑，短期行业成本压力难以实质性缓解，预计3月下旬市场整体维持高位震荡：成本强支撑下缺乏大幅下跌基础，终端需求偏弱也难以支撑宽幅拉涨，单边大幅波动空间均有限，华东市场价格波动或在12500-13600元/吨。

当前中东局势复杂多变，原油维持高位波动，核心原料BOPP、丙烯酸丁酯价格高位窄调。后续随着成本端走势明朗、行业开工低位平稳，叠加下游刚需买盘释放、上下游博弈缓和，预计高价货源进入集中消化期，市场流通逐步顺畅，成交有望缓慢回暖。4月仍需密切关注宏观局势、原料波动、市场需求传导等重要因素。
