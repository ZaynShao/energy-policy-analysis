# 辰致集团丨东安动力半年回望 中流击水 动力如潮

时节如流，答卷有声。站在2026年年中节点回望，东安动力以中国长安汽车“十六字”经营方针为牵引，市场开拓连获突破、核心技术相继落地、全员价值创造成效显著，在行业深度转型的关口，交出一份沉甸甸的“期中答卷”。
市场突围，增量向新
今年以来，东安动力市场开拓捷报频传：从地面到天空，从水域到水下，从传统车企到造车新势力，“四维全生态”市场体系多点开花，新市场项目与战略合作齐头并进。
新能源混动系统新基地一期机加线
从订单到增量，项目为证。上半年，东安动力新能源市场项目数量大幅增长，生命周期规划销量超百万台。从岚图汽车到一汽奔腾，从江淮汽车到福田汽车，东安动力以“一对一”定制化动力方案，拓展合作版图覆盖全部造车新势力及多家头部汽车集团。5月，搭载东安动力高效发动机的一汽奔腾悦意08开启预售，标志着双方战略合作从技术协同迈向市场化成果落地；与一汽解放联手打造的悦图小卡项目同步量产，为城配物流再添可靠选择。
市场拓展
从地面到天空，边界为疆。增程发动机已成功配套飞行汽车，转子发动机与近30家客户达成合作意向，基本覆盖全部造车新势力和多家低空经济头部企业。低空经济的蓝海里，东安动力正全速争先。同时，广交会上，搭载2.0TG+AT动力系统的赛格威全地形车成功完赛北美顶级越野赛事Mint400，一举打破外资长期垄断；上海国际汽车技术展上，核心增程动力、混动DHT产品、前沿转子发动机技术集中亮相，吸引众多整车厂商与合作伙伴驻足交流，上下游合作桥梁越筑越宽。
新能源高效发动机装配线
从协同到共赢，合作为锚。在新能源汽车产业加速迭代、增程赛道竞争白热化的关键阶段，东安动力锚定头部客户，与小鹏汽车构建深度战略合作生态。截至目前，双方合作的五大主力车型已全部量产上市，另有一款新车型完成工信部公告。六款车型全系落地，标志着双方战略合作正式进入规模化周期。
技术破局，核心在握
今年2月，中国长安汽车批复设立“中国长安汽车集团有限公司先进动力系统研究院”，成为东安动力核心技术攻关与创新成果转化的孵化基地。截至目前，东安动力拥有授权专利765项，其中发明专利140项（含海外11项），参与制定国家标准7项、行业标准15项。1—6月共推进240个新品项目，其中22个平台项目、162个车发匹配项目、56个应用研究项目，已完成4项平台项目开发、26项车发项目量产。
核心技术突破接续落地。5月，DHR50T后驱四挡强越野混动专用变速器首台样机下线，液力变矩器实现发动机零车速介入驱动，攻克极限爬坡热平衡与馈电失速等行业难题，核心零部件100%自主国产化。6月2日，东安动力航空专用第二代AHT22混动变速器首台样机点火成功；6月17日，国内首台双转子增压发动机R10TE点火成功，这一组“黄金搭档”的动力总成，可适配零下40℃至80℃宽温域及3000米高空与粉尘、潮湿等复杂环境，为低空经济注入强劲“中国心”。
研究院大楼
研发端同样捷报频传。CAE中心将PID控制算法与一维热力学仿真深度融合，转子发动机仿真效率提升80%以上，年省研发成本数十万元。通过PID控制的深度应用，仿真过程彻底摆脱人工依赖，具备“自动调参、精准收敛、快速迭代”的能力，为后续研发积累了可复用的数据库，形成了“一次突破、持续赋能”的良性循环。
降本增效，全员行动
在东安动力生产一线，员工通过自己动手维修、改造、制作，年省外委费用上千万元，主人翁意识已在一线落地生根，人人成为降本增效的践行者。
“5020”质量效率提升行动——机加效率提升
上半年，东安动力全员创造价值超1.35亿元。其中，装试二厂用2100元自制气门自动擦拭设备，替代13万元外购方案，不良率从5%降至0.05%以下；变速器厂自主开发AI视觉检测系统，条码错装、插针缺陷“零发生”，年综合降本112万元。
“5020”质量效率提升行动——机加质量提升
效率提升同样显著。MRP系统打通全链路数据，主力机型装试线、机加线效率分别提升3%和3.6%。“5020”质量效率提升行动稳步推进，质量提升50%、效率提升20%的目标正从纸面走向产线。
奋斗作答，热爱领航
今年以来，东安动力党委部署开展正确政绩观学习教育，紧扣“学、查、改”一体推进，引导党员干部在创业征程中校准价值坐标。党员突击队扎根数智转型、新品研发一线，把党旗插在产能建设最前沿，用行动诠释“奋斗者为本”的文化底色。
媒体开放日新华网海外版
与此同时，东安动力敞开大门讲好企业故事。6月17日，东安动力举办媒体开放日活动，来自行业内外的主流媒体走进工厂、走近产线，近距离见证数字化车间的高效运转和新品项目的加速落地。一系列硬核成果和鲜活案例，赢得媒体记者频频点赞，7天时间52家主流媒体相继发表文章、发布视频，全网浏览量突破6000万，不仅提升了品牌声量，更向社会传递出中国动力自主创新的信心与底气。
半年回望，动力如潮。从生产线上AI赋能的“毫秒找茬”，到海拔三千米高原环境中航空混动变速器的极限验证；从厂区内自主实施升级改造的一线员工，到远赴四川山路开展标定试验的八人工程师团队。东安动力以一个个可量化的突破、可感知的变革，将战略目标转化为现实成果。
奋斗者不舍昼夜，热爱者无惧风浪。在这场与时代同行的远征中，东安动力人正以真诚热爱拥抱变革，向着世界一流汽车动力科技企业的目标坚定迈进，用实干实绩书写未来考卷。
