# 海南中长期：不再人为规定分时电价水平和时段，独立储能可参与

交易品种
现阶段电力中长期交易包括省内中长期直接交易、电网企业代理购电交易、合同转让交易；省内中长期直接交易包含绿色电力交易。
根据交易标的物执行周期不同，海南电力中长期交易品种划分为数年、年、月、月内等交易品种。数年、年度、月度交易定期开市，探索连续开市；月内交易原则上按日连续开市。
根据交易标的物组织方式不同，海南电力中长期交易包括双边协商交易和集中交易。其中集中交易包括集中竞价交易、滚动撮合交易和挂牌交易等。
价格机制
除执行政府定价的电量外，海南电力中长期市场的成交价格应当由经营主体通过市场形成，第三方不得干预。
绿电环境价值不纳入峰谷分时电价机制、力调电费以及各类市场交易价格统计等计算，具体按照国家有关政策规定执行。
