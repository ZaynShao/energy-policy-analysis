# 天然气 | 投放量减半倒逼气源多元化：国际局势下国内LNG工厂的运行新态势

![公众号广告图-星标.jpg](https://mmbiz.qpic.cn/sz_mmbiz_jpg/jB59BB1tXAXV44victMJXedxpsoJyL8BGicz1p8Cf0PTBGvbxReOE9iaCibhBWdiaVA9se0LbRPvfvibg2EccfW9hEssicRb2uvs6ZdvdpmcrSY6Ms/640?wx_fmt=jpeg&from=appmsg)

3月以来，国际局势持续演变，国内LNG工厂作为“第一可中断用户”，其气源供应受到显著影响。中石油大幅减少了气源竞拍投放量，使国内LNG工厂运行进入新局面。本文将从气源投放变化出发，观察国产LNG工厂的实际运行与未来趋势。

**气源投放量腰斩，现货占比大幅收缩**

1月份，中石油日均气源投放量为2300万方，其中现货资源占比达76%。而3月中下旬，日均投放量降至1120万方，不及1月份的一半；现货占比也回落至18%左右。4月以来虽小幅回升至1200万方/日，现货占比提升至23%，但整体投放规模仍仅为1月的五成左右。这显示，自3月中旬起，中石油已基于国际形势预判，重新调配资源池，LNG工厂成为保供调节的“首要环节”。

**竞拍依赖度降低，气源结构趋于多元**

1月，气源竞拍投放量占管道气工厂日均产量（2650万方）的比重高达87%，反映出当时工厂对竞拍气源的高度依赖。随着竞拍价格上升与投放量缩减，两者关联性明显减弱。4月上半月，竞拍投放量同比下降48%，而常规气工厂产量仅下降20%，竞拍占比降至56%，较1月下降31个百分点。调研显示，不少工厂已转向CNG、延长、大唐等其他气源，以维持生产负荷，气源多元化趋势增强。

若完全按竞拍价格测算，一季度内蒙古地区LNG工厂平均每吨亏损约330元，3月中旬部分时段亏损甚至近2000元/吨。但实际中，多数工厂通过多气源组合调控成本——如CNG价格在2.3–2.8元/方，其他管道气源含管输价在2.6–2.8元/方，实际利润情况优于理论测算。当然，部分工厂受硬件条件限制仍完全依赖竞拍气源，只能通过调低负荷来控制亏损，这也是3月以来行业开工率小幅下滑的原因之一。

**后续展望：价格有支撑，供应趋稳，大涨难现**

当前国际局势尚未明朗，在资源方供应稳定前，竞拍气源价格预计保持高位，对LNG市场形成支撑。但随着工厂气源结构逐步调整，价格对开工的影响进一步减弱，预计不会出现大规模停机，国内LNG供应将保持相对稳定。因此，尽管4月管道气订单高价成交，市场仍有一定承接能力，但在整体供应平稳的背景下，LNG价格大概率呈现稳步上行态势，难以出现暴涨行情。
