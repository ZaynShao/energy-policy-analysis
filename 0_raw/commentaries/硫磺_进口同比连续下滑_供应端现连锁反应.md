# 硫磺 | 进口同比连续下滑 供应端现连锁反应

**全文1012字3图，预计阅读需4分钟**

海关总署数据显示，2026年1-2月中国硫磺进口量达103.53万吨，同比减少35.03%。其中，1月进口量49.72万吨，同比降幅达42.67%；2月进口量53.81万吨，同比减少25.91%。这一数据表现并未超出业内人士预期，因为早在数据公布前，依据本网监测的月度船期数据，就已提前预示出相关月份国内硫磺进口的疲态。不仅如此，依据当下相关局势的动荡表现，在随后的3、4月份，国内硫磺进口数据恐依旧乏力，难以在与去年同期的对比中实现反转回升；而进口端的这一系列不佳表现，也会进一步引发国内硫磺供应端相关数据的连锁反应。

**1、进口量少、中东资源占比恐愈发收紧**

相比之下今年前两个月中国硫磺进口的表现基本符合此前的市场预期，价格高位震荡以及业者对于春节长假后下游复工和采购节奏的保守评估，使其对美金资源的追逐兴趣被抑制。而2月底随着中东地区地缘冲突的开启且不断持续升级，不可避免的波及相关海峡航道运行，即便后续有所恢复，然并非是全面开放而是选择性通航。如此中东地区硫磺资源外发受阻不可避免，不仅会影响到3、4月该地涉及到国内的资源进口数据，还会使得相关月份中中东资源的占比明显下降。

**2、港存销库进程持续、并有阶段性加速预期**

从数据视角来看，去年四季度中国硫磺进口量下降至不足160万吨，环比减少约四成，同比减少32.92%。进口数据如此呈现，使得港口库存由9月底的238.86万吨，降至12月底的198.48万吨，降幅16.91%。至于今年1、2月的进口数量上文已有提及，港存方面则是由年初的195.42万吨，降至2月底的173.98万吨。截止到3月26日，隆众资讯数据显示全国硫磺主要港口库存量已降至155.44万吨。

截止目前，隆众资讯数据显示3月主要港口涉及的进口资源量（含固、液）45万吨左右，与此前的2月数据并无明显变化，由此预判3月国内进口数据大概率会维持同比明显下降表现。结合1-2月海关发布的进口数据，今年一季度国内硫磺进口累计量恐要少于去年四季度，且在与2025年同期对比中，降幅或近四成。不仅如此，据本网已获悉的大致情况来判断，四月份国内依然会面临进口资源量有限的局面，且到四月底港存有望降至近五年的低点。
