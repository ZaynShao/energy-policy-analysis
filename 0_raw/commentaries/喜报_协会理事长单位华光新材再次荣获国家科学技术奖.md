# 喜报|协会理事长单位华光新材再次荣获国家科学技术奖

2026 x WORK SUMMARY
7月8日，国家科学技术奖励大会、两院院士大会、中国科协第十一次全国代表大会在京召开。协会理事长、杭州华光焊接新材料股份有限公司董事长、正高级工程师金李梅参与的“异质复杂多腔构件精准钎焊制造技术及应用”项目荣获国家科学技术进步奖二等奖，这是继2016年之后华光新材再次荣获国家科学技术进步二等奖。
“异质复杂多腔构件精准钎焊制造技术及应用”项目由中国机械总院集团郑州机械研究所有限公司牵头，哈尔滨工业大学、核工业西南物理研究院、中铁工程装备集团有限公司、青岛海尔空调器有限总公司、杭州华光焊接新材料股份有限公司等多家单位共同完成。项目围绕国之重器和民生产品中异质复杂多腔构件钎焊难题，从钎焊材料、钎焊工艺和钎焊装备三方面创新，实现了聚变装置、高速高温风洞燃烧室喷管、大型运输机消声器、光刻机静电吸盘、工业母机刀具等百余种关重件精准钎焊制造，为我国国防建设和产业发展提供关键支撑，引领行业技术迈向国际领跑；产品和技术推广应用到30多个行业数千家企业。公司参与本项目并开发了多项先进的钎料成形技术、20多种钎料品种，研制出多种类型的钎料生产专用设备，为项目推进作出重要支持。
自1995年创立以来，华光新材始终秉持“提升工业连接水平，实现产业链价值共赢”的企业使命，始终以科技创新驱动企业质量，始终以专注极致的匠人精神深耕主业，聚焦高端焊接材料与智能高效焊接解决方案，致力不断实现行业关键核心技术突破，坚守实业报国初心。
两项国家科技进步奖的斩获，是公司全体科研人员数十年潜心钻研的心血成果，更是助推企业高质量发展的雄厚底蕴。未来，华光新材将永葆创新初心与实干本色，持续开展新产品新技术创新，不断夯实高端钎焊材料国产化、产业化根基，致力于智能、绿色、高效的焊接解决方案，努力实现产业链价值共赢，为我国科技自立自强与高端制造高质量发展不断贡献华光力量。
