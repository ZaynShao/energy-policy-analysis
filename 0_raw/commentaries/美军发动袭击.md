# 美军发动袭击

美军：使用导弹袭击一艘驶往伊朗的货轮，并致其停航。
当地时间11日，美军中央司令部在社交媒体发布消息称，美军一架直升机当天向一艘“违反美国对伊朗海上封锁”的货轮开火，致使其转向装置失效而停止航行。
美军称，这艘悬挂巴拿马国旗的货轮当时试图穿越阿曼湾驶往伊朗港口。在该货轮船员无视美军多次警告后，一架美国海军直升机向该船机舱发射了两枚“地狱火”导弹。
消息说，截至8月11日，美军已迫使55艘商船改变航向，令3艘船只丧失航行能力，并登船检查2艘船只。
