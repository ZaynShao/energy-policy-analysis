微信地震预警功能上新
（ 新浪科技 ）中国地震台网今日宣布，微信地震预警上线新功能：“ 震感汇聚 ” 与 “ 位置更新 ” 。
据介绍，新上线的 “ 震感汇聚 ” 功能可用于地震发生后的公众震感信息快速收集与综合展示。在收到预警快速避险后，用户可通过微信地震预警小程序的预警详情页便捷反馈所在地震感情况，地图精准定位、快捷选择对应震感，相关信息经专业算法规则处理后形成震感分布地图，为公众快速了解不同地区的实际震感提供参考。
谷歌地球紧急叫停AI生图
英国广播公司（ BBC ）报道，这项新功能把谷歌图像生成器 Nano Banana 2整合进 Google Earth 。用户只须输入文字指令，就能在真实卫星图像、航拍图像或三维地图上生成虚构场景，并下载后分享到其他平台。
BBC核查团队测试时，成功生成埃菲尔铁塔倒塌、巨大天坑吞没埃及金字塔，以及俄军坦克出现在基辅等假图像。
专家指出，虚构内容与真实地理坐标和谷歌地图底图结合后，容易让人误以为图像来自可靠卫星资料。在战争、灾害等信息混乱时期，这类图像尤其可能误导记者和公众。
谷歌说，AI 生成图像含隐形水印，用户可通过 Gemini 或 Google Lens 核查。不过，BBC 测试发现，部分验证机制可被绕过，外部检测工具有时也无法识别假图。
特朗普发帖成了生意
（ 新浪科技 ）当地时间 8 月 1 日，据美联社报道，美国总统特朗普旗下真实社交平台（ Truth Social ）于当天推出名为 “ Truth API ” 的高速信息服务，向华尔街交易机构收费提供特朗普社交媒体帖文的快速访问渠道，引发有关内幕交易、利益冲突以及利用公职谋取私人利益的质疑。
报道称，Truth API 收费高达每月10万美元，目标客户主要是高频交易公司。报道指出，特朗普近期越来越频繁地在社交媒体上点名上市公司。4月，他发文称赞Palantir Technologies后，该公司股价一度大涨；随后发文祝贺英特尔“表现出色”后，英特尔股价也立即在盘后交易中上涨。
IF 椰子水市值蒸发近九成
（ 新浪科技 ）此前，IF 椰子水凭借 46 名员工打造了超百亿市值，但如今，一纸业绩预告让其跌落神坛。今年上半年，IFBH 预计营收和净利润将双双腰斩，尤其是净利润，相较 2025 年预计同比减少最多 75%。
IFBH 将业绩下滑原因归结为供应链问题。但专家指出，其 IP 没有护城河，椰子水一个品类贡献 97.5% 营收，中国市场占九成以上，轻资产代工模式让其经营太过脆弱。
IFBH 寄希望于明星代言拉升业绩，但目前来看这一策略无法继续奏效。目前其股价为 6.16 港元，市值仅剩 16.31 亿港元，较最高点已经蒸发超 87%。
不久前，有媒体发布的一份送检结果显示，四款市面上常见的以 “ 100%椰子水 ” 为卖点的产品，经同位素检测，均存在添加外源水、外源糖的情况，引发大众对于椰子水是否存在勾兑、造假现象的广泛质疑，IF椰子水也在其中。
