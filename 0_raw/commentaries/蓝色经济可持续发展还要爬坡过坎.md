# 蓝色经济可持续发展还要爬坡过坎

联合国、世界经济论坛、世界银行相继发布有关海洋经济发展的报告，不约而同指出发展可持续蓝色经济的重要性和紧迫性，强调平衡开发与保护是决定海洋经济能否持续繁荣的关键命题。
海洋经济作为全球经济版图中最具活力的板块之一，正以前所未有的速度扩张，从渔业捕捞到海上风电，从油气开发到远洋航运，经济价值逐年递增。然而，繁荣背后暗藏危机，联合国、世界经济论坛、世界银行相继发布有关海洋经济发展的报告，不约而同指出发展可持续蓝色经济的重要性和紧迫性，强调平衡开发与保护是决定海洋经济能否持续繁荣的关键命题。
发展模式亟需调整
联合国《第三次世界海洋评估》指出，海洋经济体量庞大但发展模式不可持续，涵盖捕捞、养殖、油气、海上风电、航运、滨海旅游等行业，全球海洋经济年产值达1.5万亿美元，预计2030年将突破3万亿美元，过度捕捞、非法渔获、深海采矿、船舶碳排放带来长期生态代价。
在此背景下，推动可持续蓝色经济发展是大势所趋，强调通过对海洋和沿海区域的可持续包容性利用，实现经济增长、环境健康和社会公平。世界经济论坛全球未来可再生蓝色经济理事会联席主席、瑞典大瀑布电力公司环境副总裁赫尔·赫克-汉森表示，可持续蓝色经济旨在将海洋及海洋和沿海生态系统再生和保护与可持续、低碳或无碳经济活动结合起来，为人类和地球现在及未来创造公平繁荣。
当前，海洋生态系统支撑着各行各业，并在气候减缓和韧性方面发挥着关键作用。然而，来自过度捕捞、污染和气候变化的日益增长的压力正在造成严重破坏，导致经济损失并加剧经济风险。世界银行估计，到2030年，应对这些挑战至少需要投入1万亿美元，突显出扩大投资的紧迫性。
根据世界经济论坛《可再生蓝色经济报告》，全球海洋经济持续扩张，但维系海洋经济可持续发展的海洋生态系统却在不断恶化。过去10年，每年只有不到1%的海洋经济年价值投资于可持续性。
公共资源无法单独满足保护和恢复海洋所需的投资规模，弥合这一缺口需要释放私营资本，以支持海洋保护、可持续渔业、有韧性沿海基础设施和基于自然的解决方案，但资本只有在风险得到管理、回报可行且治理健全的情况下才会流动。在此背景下，需建立清晰、稳定且对投资者友好的政策和监管环境，构建稳健的数据、指标和方法体系，从而更好地吸引投资。
顶层设计尚待完善
《第三次世界海洋评估》指出，中国海洋可持续发展可圈可点，正转向“生态优先、陆海统筹”，生态保护修复成效显著，陆海统筹治理体系持续完善，海洋尖端科技全球领跑，涉海产业绿色升级持续提速。
我国已成为推动蓝色经济可持续发展的引领者。自然资源部日前发布上半年海洋经济运行情况，上半年我国海洋生产总值同比增长5.1%至5.5万亿元。6月，国家海洋信息中心发布《2026中国海洋经济发展指数》，以2015年为基期，基期指数值为100，2025年中国海洋经济发展指数为128.8，比上年增长2.2%。
具体来看，海洋资源供给平稳增长，上半年海洋原油、天然气产量同比分别增长3.6%、0.6%；海洋工程装备制造业加速提质升级，上半年海洋工程装备新接订单金额同比增长121.9%，占全球市场份额八成以上；海洋清洁能源开发利用有序推进，2025年海上风电发电量1092.74亿千瓦时；海洋新兴产业扩容增效，海洋信息服务蓬勃发展，去年以来，“海上风电+”融合发展成效显著，多项深远海风电技术成果投入示范应用。
我国海洋经济稳步增长，发展势头良好、韧性持续彰显，海洋产业结构进一步优化，科技创新能力不断增强，这离不开顶层设计的持续加码。“十五五”规划纲要设立海洋专章，围绕“提高经略海洋能力，加快建设海洋强国”作出系统部署，提出打造海洋经济发展示范区、现代海洋城市等动力引擎。
在加快海洋科技高水平自立自强方面，国家发展改革委秘书长袁达指出，“十五五”时期，强化海洋战略科技力量，加快突破一批关键核心技术和装备，打造更多“国之重器”。完善海洋科技创新生态，促进海洋领域数字化、智能化转型，推进海洋教育、科技、人才发展。
科研短板有待补齐
值得注意的是，全球范围内，海洋科研存在明显短板。联合国强调，长期监测缺乏稳定资金支持，是制约海洋科学研究的主要瓶颈。
根据《第三次世界海洋评估》，截至2025年，全球仅27.3%的海底完成高精度测绘，深海生态、生物演化等领域仍存在大量认知盲区。尽管海洋观测监测、基因测序、人工智能等技术快速迭代，但长时间序列监测网络不完善、生物分类学人才短缺等问题，持续制约海洋保护与精细化管理。
世界经济论坛指出，以人工智能为代表的创新技术是推动可持续蓝色经济发展的关键杠杆之一。海洋生态系统难以监测且成本高昂，遥感、自主平台、环境DNA、数字孪生和机器学习正在改变经济性，人工智能越来越多地通过整合这些技术，带来更好的经济和环境效益。
在行业层面，人工智能赋能海洋经济，可以提高生产力、减少环境足迹。比如，在北海等拥挤的海洋区域，人工智能赋能的建模工具现在可以用于将渔船、运输船、海豹和海鸟的每日活动图与石油基础设施、风力涡轮机和养殖场的高分辨率卫星图结合起来，促进综合的、跨部门的再生规划。
世界经济论坛调查发现，生态系统恢复、蓝色生物技术、海洋数据与监测服务等前沿海洋经济行业，以恢复自然资本和创造生态价值为主要发展方向，整体市值已从2010年的仅11亿美元增长到2025年的247亿美元。
世界经济论坛全球未来可再生蓝色经济理事会联席主席、加拿大不列颠哥伦比亚大学海洋与渔业研究所及公共政策与全球事务学院渔业经济学研究部主任拉希德·苏迈拉表示，迈向可持续蓝色经济离不开新技术，包括使用先进技术弥补直接观测的局限性、利用人工智能解读巨量海洋大数据等。
