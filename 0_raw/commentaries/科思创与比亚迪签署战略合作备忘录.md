# 科思创与比亚迪签署战略合作备忘录

加入供应链产业群，请加微信gasgoo88，出示名片
7月13日，盖世汽车获悉，科思创与比亚迪宣布签署谅解备忘录，正式确立长期战略合作伙伴关系。双方将不再局限于传统供需模式，而是转向跨价值链的联合创新，重点围绕新能源汽车、动力电池、储能系统及下一代前沿技术，共同开发高性能聚合物解决方案。
图片来源：科思创
此次合作的核心在于材料科学的深度协同。
科思创将向比亚迪开放专属研发资源，并提供创新成果优先获取权及定制化技术支持；比亚迪则承诺将科思创纳入全业务版图的新项目规划中。
根据协议，双方将在车灯、智能内外饰、电子元器件等领域推进轻量化与美学兼具的材料方案，同时针对动力电池和储能设备开发兼顾安全性、热管理及成本效益的聚碳酸酯与聚氨酯产品。面向未来更极端工况的技术平台，双方还将合作研发高强度、耐热、耐电气老化的特种聚合物。
值得注意的是，低碳与循环材料成为本次合作的另一重点。科思创旗下含至少25%替代性原材料的CQ（循环智慧）系列将被优先引入比亚迪产品线，以降低下一代交通、能源及智能系统的全生命周期环境足迹。
随着汽车智能化与电动化进入深水区，材料性能正成为产品竞争力的关键变量。科思创作为全球聚碳酸酯和聚氨酯巨头，亟需绑定头部客户以稳固市场地位；而比亚迪庞大的产能和多元化场景，则为材料创新提供了快速验证与落地的土壤。
在新能源汽车价格战与技术竞赛并行的当下，这种“材料商+整车厂”的深度绑定模式，或将为行业树立新的协作范式。双方尚未披露具体投资金额与研发周期，但明确表示将探索联合投资机会。目前，合作已进入具体项目对接阶段。
