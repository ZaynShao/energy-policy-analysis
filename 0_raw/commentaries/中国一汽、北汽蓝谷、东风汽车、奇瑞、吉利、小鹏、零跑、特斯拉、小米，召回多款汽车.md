# 中国一汽、北汽蓝谷、东风汽车、奇瑞、吉利、小鹏、零跑、特斯拉、小米，召回多款汽车

涉及门把手缺陷，9家车企召回多款汽车。
8月21日，市场监管总局发布公告，多家车企因车内应急机械拉手相关问题召回多款汽车，包括中国一汽、北汽蓝谷、东风汽车、奇瑞、吉利、小鹏、零跑、特斯拉、小米等在内。
据悉，本次召回原因包括，车内应急机械拉手与内饰颜色接近，不易识别和操作。当发生严重碰撞导致整车低压系统失效等极端情形时，可能影响驾乘人员快速开启车门逃生和车外人员救援，存在安全隐患。
小米汽车科技有限公司召回部分2024款小米牌SU7系列纯电动汽车
日前，小米汽车科技有限公司根据《缺陷汽车产品召回管理条例》《缺陷汽车产品召回管理条例实施办法》的要求，向国家市场监督管理总局备案了召回计划。
一、召回编号S2026M0096V：自即日起，召回2024年8月8日至2026年3月4日生产的部分2024款小米SU7系列纯电动汽车，共计339069台。
二、召回编号S2026M0097V：自即日起，召回2023年12月27日至2024年8月16日生产的部分2024款小米SU7系列纯电动汽车，共计51366台。
本次召回范围内的车辆，由于车内应急机械拉手与内饰颜色接近，不易识别和操作。当发生严重碰撞导致整车低压系统失效等极端情形时，可能影响驾乘人员快速开启车门逃生和车外人员救援，存在安全隐患。
小米汽车科技有限公司将免费为召回范围内的车辆在车内应急机械拉手处加贴警示标识；并通过汽车远程升级（OTA）技术升级软件，优化中控解锁逻辑及降窗策略，以降低安全隐患。因部分车辆已加贴警示标识，本次召回此部分车辆无需再次加贴。
特斯拉（上海）有限公司、特斯拉汽车（北京）有限公司召回部分国产及进口纯电动汽车

召回编号S2026M0099V：自2026年9月25日起，召回2018年8月22日至2019年11月20日期间生产的部分进口Model 3电动汽车，共计35590辆；2022年10月27日至2026年2月13日期间生产的部分进口Model X电动汽车，共计8328辆；2023年1月18日至2026年2月10日期间生产的部分进口Model S电动汽车，共计2123辆。

二、特斯拉（上海）有限公司
召回编号S2026M0039I：自即日起，召回2019年3月4日至2025年12月7日期间生产的部分国产Model 3、Model Y电动汽车，共计2740642辆。
本次召回范围内的车辆，在辅助转向功能开启、车辆进入组合驾驶辅助系统状态下，现有注意力监测机制不足以为驾驶员提供视线脱离提示，若驾驶员不及时干预可能增加碰撞风险，存在安全隐患。
特斯拉（上海）有限公司将通过汽车远程升级（OTA）技术，为召回范围内的车辆免费升级软件，以降低可能增加的碰撞风险。在现有的方向盘扭矩监控的基础上，增加舱内摄像头监测，进一步促使驾驶员在启用组合驾驶辅助功能时，及时提示驾驶员，履行驾驶职责并遵守驾驶规定，且随时注意周围交通状况。用户无需到店即可完成软件升级。对于无法通过OTA技术升级的车辆，将通过特斯拉服务中心联系相关用户实施召回，以消除安全隐患。
