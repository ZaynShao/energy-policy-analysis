# 我国智慧体育发展呈现政策引领、标准推进、技术开拓三大导向

人民网研究院组织编写的智能互联网蓝皮书《中国智能互联网发展报告（2026）》7月29日在北京正式发布。其中，深圳大学体育学院助理教授李晨曦，清华大学经济管理学院领导力与组织管理系长聘副教授、清华大学经济管理学院体育产业发展研究中心主任王雪莉共同撰写的《2025年中国智慧体育发展态势及展望》一文指出，2025年，我国智慧体育发展的价值目标与核心任务已明确，数智体育标准化工作深度推进，为行业规范持续发展奠定基础。第十五届全运会数智技术应用、多种垂类大模型和智能体、机器人运动会等创新探索，彰显出我国智慧体育发展的蓬勃生机。
文章分析认为，当前中国智慧体育发展呈现三大核心导向。
首先，重大政策与规划引领方向，数智技术已成必备要素。政策指引从宏观走向具体，不再仅是加快数智化转型和数智技术应用的宏观号召，更给出了研制与试点全民健身“运动码”、建立学生体质健康数字画像等具体方向，体现出相关部门在近年来数智赋能实践中对于重点议题的逐步明确。与此同时，强调公共体育空间、平台和服务的智慧化建设，关注数智技术的平等可得性，如建强用好国家全民健身公共服务信息平台等，是对实现全体人民共同富裕的中国式现代化和坚持以人为本的发展观的充分实践，旨在以负责任、包容性的数智创新消弭数字鸿沟等潜在的技术伦理风险。此外，关注数据的平台与制度建设，充分认知高质量数据积累、数据要素价值释放与完善的数据基础制度对于数智体育科技创新、体育数智化转型的根本性意义。
其次，标准化工作深度推进，引导我国智慧体育规范发展。国家体育总局继发布《2024年体育标准化工作要点》并指明大力实施标准化战略的重点工作内容及聚焦领域之后，2025年4月又对《数字体育标准体系建设指南》《数字体育平台总体架构》两个体育行业标准项目予以拟立项公示，既给出了宏观的政策导向，又着手研制顶层设计与规范。与此同时，为落实《2025年群众体育工作要点》中的要求，国家体育总局信息中心还组织召开了39家单位参加的“全民健身运动码、运动积分标准工作推进会暨数字体育标准研讨会”。上述工作均展现了国家体育管理部门对于智慧体育标准化的重视。
最后，具身智能开拓新方向，机器人技术成为聚焦热点。近年来，具身智能与机器人成为全球关注的热点技术方向，体育场景再次成为测试、展示和优化相关前沿技术的理想试验田。依托中国具有全球领先地位的机器人和具身智能产业，背靠完善的本土产业链和高速技术迭代能力，我国智慧体育或许能够开辟出全新赛道，实现弯道超车。
