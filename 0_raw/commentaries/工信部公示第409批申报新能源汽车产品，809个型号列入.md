# 工信部公示第409批申报新能源汽车产品，809个型号列入

导读
第409批
申报新能源汽车产品的共有241家企业的809个型号，其中：
纯电动产品共209家企业689个型号
插电式混合动力产品共59家企业94个型号
燃料电池产品共13家企业26个型号
工业和信息化部装备工业一司近日公示申报的第409批《道路机动车辆生产企业及产品公告》新产品。
经统计，申报新能源汽车产品的共有241家企业的809个型号，其中纯电动产品共209家企业689个型号、插电式混合动力产品共59家企业94个型号、燃料电池产品共13家企业26个型号。
动 力 类 型
1、从动力类型看：纯电动产品共209家企业689个型号申报（含乘用车74个；客车58个；客车底盘5个；专用车489个；专用车底盘63个）；插电式混合动力产品共59家企业94个型号申报（含乘用车38个；客车2个；专用车48个；专用车底盘6个）；燃料电池产品共13家企业26个型号申报（含客车1个；专用车20个；专用车底盘5个）。
产 品 类 型
2、从产品类型看：新能源乘用车共26家车企的112个型号申报；新能源客车共21家车企的61个型号申报；新能源专用车共221家车企557个型号申报；新能源底盘产品共35家车企79个型号申报（含专用车底盘74个；客车底盘5个）。
换 电 产 品
3、换电式产品：本批次公示的换电式纯电动产品共有7家企业11个型号申报（含专用车7个；专用车底盘4个）。
