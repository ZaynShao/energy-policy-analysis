# PBAT | 3月出口暴涨 创下五年新高

**导语**

3月PBAT出口量约1.83万吨，创5年新高。受地缘政治影响海外集中备货，叠加欧盟、东南亚塑料禁限令落地，可降解材料需求激增，并延至4月份，出口增长缓解国内供应压力，推动近期市场价格偏强震荡。意大利、印度仍是核心出口目的地，合计占比超五成。广东、新疆、辽宁三地贡献主要增量，依托各自产能与物流优势，实现出口量价齐升，行业出口格局持续向好。

2026年3月份我国PBAT出口量18282.011吨，环比增幅61.28%，同比增幅70.19%，月均价1307美元/吨，涨幅4.76%。2026年1-3月PBAT出口量44992.189吨，同比增幅39.97%。

3月PBAT出口创下近5年历史新高。主要是受地缘政治局势影响，海外市场掀起集中备货潮，订单量显著攀升。再是欧盟、东南亚等地区持续加码塑料禁限令，政策落地推动海外对可降解材料的需求增加，带动订单释放。

PBAT出口规模的扩大，有效缓解了国内市场的供应压力，同时推动PBAT市场价格呈现偏强震荡态势。

从注册地来看，广东省以9529.78吨的出口量稳居第一，占比超52%，出口规模较去年全年月均水平提升46.7%，龙头地位持续强化，是拉动3月整体出口大幅反弹的核心动力。这一增长主要由省内PBAT龙头企业——珠海金发的订单交付带动，依托其产能规模与产业链配套优势，持续释放出口增量，进一步巩固了广东作为全国PBAT出口核心阵地的地位。

新疆以3241.05吨的出口量位居第二，依托中欧班列的地缘通道优势，保持稳定的出口输出，占全国出口总量近18%，是国内PBAT出口的重要支撑极。省内核心供应企业新疆蓝山屯河反馈，3-4月PBAT出口呈现“量价同增”的良好态势，出口订单与产品价格同步回升，这也为区域出口的稳定增长提供了坚实支撑。

辽宁成为最大亮点，出口量达1766.2，环比2月暴增361.4%，份额跃升至9.7%，成为第三大出口地。反观上海、浙江等传统贸易地，出口量持续萎缩，上海仅713.2，占比不足4%，贸易中转优势弱化。整体来看，PBAT出口正加速向具备产能与地缘优势的生产地集中，区域分化趋势在3月进一步凸显。

PBAT出口从贸易伙伴结构来看，意大利、印度为核心增长引擎，3月出口量分别达5260.8吨、4655吨，合计占比超54%，稳居前两大市场，且较2月均实现翻倍级反弹，是拉动整体出口增长的核心动力。欧洲市场整体表现亮眼，西班牙、荷兰出口量分别达1549.5吨、1636吨，环比均实现明显回升，延续了传统优势市场的稳定表现。越南出口量增至1137.9吨，同比增速亮眼，东南亚市场拓展成效显著。

结合出口注册地看，广东、新疆、辽宁的出口增量，分别对应印度、欧洲、意大利市场的订单交付，市场与产地的匹配度进一步提升。

当前华东PBAT市场价格波动区间在11900-12500元/吨,，均价12200元/吨，环比3月初涨幅25.8%。供应端方面，PBAT延续低负荷运行，规模企业生产集中，维持高负荷运行，市场货源供应宽松，国内高价出货速度较慢，出口订单好转缓解一定供应压力。国内需求端增量不明显，规模企业改性及降解膜袋生产相对稳定，部分中小型企业订单跟进不畅，且终端生产消化库存原料为主，低价询盘少量采购，对市场支撑弱。成本端方面，原料价格持续上涨，成本压力不断扩大，推动PBAT市场价格震荡上行。
