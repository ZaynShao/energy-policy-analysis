# 欣旺达全球新总部正式启用

加入供应链产业群，请加微信gasgoo88，出示名片
盖世汽车获悉，近日，欣旺达全球新总部在深圳宝安正式启用。 新总部园区总建筑面积达18.5万平方米，是集智能制造、智慧管理、智慧生活于一体的现代化产业园区。
图片来源：欣旺达
园区以数字化为核心，依托自研的数字化管理平台，构建了全数字化运营的统一指挥调度中心。通过AI与大数据分析技术的深度融合，园区实现了设备互联、数据共享和运营全链条的可视化、可感知、可控制、可管理、可决策，构建起智能工厂神经网络。
此外，园区还兼顾人才居住与体验需求，全域覆盖智能办公、生态绿化、休闲服务等设施，打造绿色低碳的智慧生活配套生态圈，为全体员工提供宜居宜业的优质环境。
欣旺达表示，新总部不仅是物理空间的全面升级，更代表着公司在智能制造和数字化管理领域的深层能力跃迁，为公司从消费类电池向动力电池、储能电池全面布局提供了新的战略支点。
