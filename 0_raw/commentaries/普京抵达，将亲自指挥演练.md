# 普京抵达，将亲自指挥演练

俄罗斯总统普京已抵达南萨哈林斯克，指挥俄罗斯太平洋舰队演习的最后阶段。
据俄罗斯卫星通讯社8月12日报道，俄罗斯总统普京已抵达南萨哈林斯克，指挥俄罗斯太平洋舰队演习的最后阶段。俄罗斯太平洋舰队演习4日启动，此次演习共出动约60艘水面舰艇、潜艇及保障船只，近30架海军航空兵飞机、直升机及无人机系统，以及超过1.3万名军事人员。
