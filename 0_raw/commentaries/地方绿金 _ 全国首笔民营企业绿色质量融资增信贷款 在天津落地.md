# 地方绿金 | 全国首笔民营企业绿色质量融资增信贷款 在天津落地

记者日前从中国人民银行天津市分行获悉，借助该行“民营企业再贷款+绿色质量融资增信”的政策“组合拳”，天津滨海农商银行为天津东大化工集团发放全国首笔民营企业绿色质量融资增信贷款，金额1000万元，期限1年，有效破解了民营中小微企业绿色转型中“认证难、融资难、成本高”的痛点，为金融服务民营企业绿色发展树立全新实践示范。
天津东大化工集团有限公司是一家集科研开发、生产销售于一体的专业化食品添加剂生产企业，拥有多项发明专利和科技成果，目前已建成全自动化生产线，配套建设热能循环利用、发电设施，具备良好的绿色质量基础和可持续发展潜力。此笔贷款一方面依托天津市金融学会发布的全国首个《绿色质量融资增信评价规范》团体标准，将企业绿色生产、质量诚信、科技创新、低碳运营等核心软实力纳入授信评价体系，打破传统融资依赖抵押物的局限；另一方面依托中国人民银行天津市分行发放的民营企业再贷款低成本专属政策资金，定向撬动金融资源向民营中小微企业倾斜，降低企业贷款利率，从源头为企业减负。
今年以来，中国人民银行天津市分行不断丰富金融管理服务政策工具箱，以政策创新引领服务升级，同时注重内外部统筹联动，强化和天津市有关部门的政策协同，多维发力支持天津民营经济高质量发展。该行联合天津市多部门印发《天津市金融服务民营经济发展若干措施》，并创新推出“民营企业再贷款+绿色质量融资增信”政策组合，形成“央行资金+评价标准”的双向配套，为金融机构创新绿色信贷产品、服务民营中小微企业构建完整政策框架，进一步推动金融机构“敢贷愿贷”、绿色民营企业“想贷能贷”的良性循环。
