# 大储厮杀！思格、派能、德业、奇点等细分龙头集体“扑进来了”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIsObEicAfPoPHXgQLMx1qD0j6fWU8kkJ1X209ibq41RqZeLA8aSlknFVWyHJJASB6poD0X5XibIm3vZkqW6OBgrr0sHFvehqQ8WNg/640?wx_fmt=png&from=appmsg)

# 

当下，海外大型电网侧、utility scale 储能市场正迎来爆发式增长。

繁荣之下，激烈的市场厮杀更甚从前。

最为明显的迹象就是，一批深耕户储、工商储赛道的龙头企业，正集体跳出中小储能的舒适区。

凭借多年积累的产品、渠道与供应链优势，它们大举切入大储战场，尤其紧盯海外大储的“超级蛋糕”。

据高工储能不完全梳理，思格新能源、首航新能源、德业股份、派能科技、固德威、奇点能源、亿兰科等企业，正是从原有的户用或者工商业储能赛道，延伸到大储领域。

在这一轮新打响的卡位战中，部分企业甚至已经实现GWh级大储订单在手或项目落地，它们的野心也尽显无疑。

** 全球大储出海2.0**

##   

工商储、户储龙头的集团转向的首要条件，不难想象，那就是全球范围内，大型储能市场的加速爆发。

从全球能源格局来看，碳中和进程持续推进，欧洲、中东、澳洲、北美等地区风电、光伏等新能源装机量大幅提升，但其间歇性、波动性短板对电网稳定提出了更高要求，而大型储能作为“调峰填谷、平抑波动”的核心装备，成为新能源规模化发展的必备配套，市场需求随之持续激增。

政策层面的持续发力，进一步催化了全球大储需求的释放：欧盟受中东局势冲击能源市场，进一步强化储能的刚需属性，通过补贴、产能激励等举措推动大型储能项目落地。

美国《通胀削减法案》及其延续性政策为储能项目提供投资税收抵免，有效降低了项目前期资本开支。

澳洲则通过“容量投资计划(CIS)”密集释放大规模储能订单，仅2025年9月就授出4.13GW/15.37GWh项目，成为全球大储需求的重要引擎。

除此之外，全球算力爆发推动AI数据中心用电激增，而海外电网升级滞后，储能设备成为数据中心实现“虚拟增容”、保障电力稳定的核心支撑，这一需求进一步放大了大储市场的增长空间。

同时，储能技术的不断迭代推动度电成本持续下降。

据测算，2025年下半年国内独立储能电站度电成本已降至0.35—0.60元，配合现货价差和容量电价机制，海外大储项目的盈利能力显著提升，吸引各类资本与企业纷纷入局。

海外大储市场的爆发态势也体现在订单数据之上。  

据行业数据统计，2025年中国储能企业海外新增订单达366GWh，同比大增144%，其中澳大利亚和美国是中国储能产品出口前两大目的地，海外大储市场全面释放。

种种迹象来看，全球大储出海2.0战役打响了。

**工商储及户储玩家扑向大储**

  

回溯过往，工商储、户储赛道因门槛适中、竞争缓和，成为众多企业切入储能领域的“黄金切口”。  

思格新能源等当下转型大储的细分龙头企业，正是在此赛道中积累了扎实的技术、品牌与渠道基础。

如今，随着海外大储市场的爆发式增长，这些企业纷纷顺势开启转型之路，凭借自身已有的核心优势，快速在海外大储市场抢占份额。

思格新能源成立于2022年5月，聚焦可堆叠分布式光储一体机赛道，核心团队多有华为背景，技术实力雄厚，主打SigenStor系列五合一光储充一体机，凭借差异化产品成功打开储能细分市场。

近期，其转型动作备受行业关注：3月13日，全资子公司思格源中标阿曼杜库姆500MW/2000MWh储能项目电池舱采购，该项目作为中东典型的大型电化学储能项目，标志着思格新能源正式切入大储赛道，实现了从分布式储能向大型储能的关键跨越。

德业股份作为全球户储逆变器龙头，过去以户用逆变器与中小型储能系统见长，近年来逐步向上延伸至工商业及中大型储能领域。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIsapSIkZt50LSK45ZsCeZAurMLib9tgTRVRtKcwViaiajVCwriav0EmtR46f8VMybRJNk4GX0oAicrwLd7HQeBm1NR5sqic0z1Kq8T5A/640?wx_fmt=png&from=appmsg)

依托成熟的海外渠道，德业股份推出2MWh、4.3MWh、5MWh等公用事业级储能系统方案，重点开拓欧洲、中东等核心市场；同时加大PCS、储能系统的出货力度，投建大功率工商储产线并在东南亚布局制造基地，成功转型为海外大型储能整体解决方案商。

派能科技作为国内户储电芯与系统龙头，长期深耕欧洲家用储能市场，如今已全面拓展至海外工商业及电网侧大储领域。

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIvMhIrUKqiaUoa9nxZmIxeJv7NQBfKd9rXdzMlKjQzwNS7lAvMFunmOVMkct8kiaQnz1nSLPZznQ9wAv5mQCzFkaicFJoY3AV29gA/640?wx_fmt=png&from=appmsg)

依托自研电芯、BMS与系统集成优势，派能科技在欧洲建设本地化生产基地，贴合欧盟相关要求缩短交付周期，同时携手欧洲大型能源企业，将业务延伸至园区级、电网级大规模储能项目。截至2025年9月，派能科技已在多个重点市场设立子公司，构建起覆盖全球五大洲90多个国家和地区的业务网络，欧美大储订单与落地规模持续走高。

首航新能源主营光伏逆变器（2025年上半年收入占比58%）及储能产品（2025年上半年收入占比37%），是欧洲户用光储差异化细分市场的龙头企业。

随着全球光储行业的持续增长，首航新能源将目光投向海外大储，明确了未来的核心增长驱动力：依托全球储能需求攀升的趋势，开拓亚非拉新兴市场，布局工商储+大储+大大组串等大功率产品，同时挖掘AIDC储能机遇，逐步实现向大储赛道的稳步延伸。

奇点能源则凭借核心技术优势在转型浪潮中快速突围，其自主研发的分布式智慧能量块eBlock开创了储能系统产品化的先河，全球累计交付项目超2000个，单体项目规模最高达2000MWh，已形成全链条能力体系。

![image](https://mmbiz.qpic.cn/sz_mmbiz_jpg/NKyhsaKovicIkKXic1PJ2MsQyicKWuibwWDDoEhkJqMbKzkegIrZBMqGIIu2DrUdqfYC7vBg4iciaMqAM6fdtpxHjY3Q/640?wx_fmt=jpeg&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=2)

近年来，奇点能源深化全球化布局，推进本地化运营，产品顺利通过欧洲相关认证并落地多个重点项目；同时创新推出组串式预制舱Galaxy-1，通过一体化集成多系统，适配多种应用场景，有效解决了现场施工与运输难题。2025年，奇点能源交付多个标杆大储项目，其中内蒙古磴口500MW/2000MWh项目是其首个GWh级大储项目，截至2025年末，其业务已成功拓展至欧洲、美洲、亚太地区。

值得注意的是，除了储能系统企业，储能PCS企业也纷纷加入大储转型的行列。

当前，大储系统正朝着“两大一小”的方向双向发展：一方面，直流侧与PCS功率持续提升；另一方面，为适配运输需求，直流侧走向模块化，亟需更小功率的组串式PCS，这也为PCS企业的转型提供了契机。

亿兰科凭借在工商储PCS领域积累的出货量与丰富经验，于2025年10月推出215kW模块化PCS产品，正式切入大储市场。

其Monet-215kW模块化PCS采用进口IGBT与“一簇一管理”组串式架构，IP66防护等级可适配复杂户外环境，是1500V高压系统的理想核心单元。

而更早实现转型的禾迈股份，则从户用储能PCS逐步扩展至工商业和大型储能领域。  

2025年，其推出2.5MW构网型液冷储能变流器HPCS2500，以“液冷架构+全域构网型+高功率密度”的技术突破，精准适配大储行业的竞争需求。

2026年开局，禾迈接连斩获两大头部央企储能项目：在能建时代新能源科技有限公司年度集采中，以第一中标单位身份一举囊括两个标段；在中国石油集团变电舱系统项目中，同样拔得头筹。

**转向背后四大动因 **

  

这些龙头企业从工商储、户储赛道向海外大储转型，并非盲目跟风。

其一，企业自身实力积累到位。经过多年在户储、工商储赛道的深耕细作，这些企业已积累了良好的品牌声誉、成熟的产品技术与完善的供应链体系，这不仅为其切入大储市场奠定了坚实基础，也有效降低了转型门槛，使其能够快速适配大储项目的技术标准与交付需求。

其二，市场增长需求驱动。户储、工商储市场的体量相对有限，难以满足企业上市融资、规模化扩张的长远发展需求；而海外大储市场正处于爆发期，据东吴证券预测，全球储能装机2026年将增长60%以上，2027—2029年复合增长率达30%—50%，布局大储赛道可为企业开辟全新的增长空间，实现规模与利润的双重突破。

其三，海外大储市场机遇凸显。欧洲、中东等地区受新能源转型、政策扶持、数据中心用电激增等多重因素影响，大储需求持续爆发；且海外大储项目具有订单规模大、盈利能力强的特点，中国企业凭借国内完善的储能产业集群优势，能够有效抢抓出海机遇，抢占全球大储市场份额。

其四，行业竞争加剧倒逼转型。如今，阳光电源、华为、比亚迪等行业巨头已纷纷切入户储、工商储赛道，天合储能等企业也在加速进击，使得户储、工商储领域的竞争日趋激烈，利润空间不断压缩。

在此背景下，切入海外大储赛道，既是企业主动抢抓市场机遇的战略选择，也是规避行业内卷、实现可持续发展的必然路径。

奇点能源董事长刘伟增曾表示：“工商业储能这池塘已经撑不起奇点的规模化，20%-30%的行业增速太慢，我们必须抢先去更大的海里（大储）。”

亿兰科创始人何少强也早有判断，他认为工商储与大储的界限正逐渐模糊，模块化储能凭借高效、安全的核心优势，具备向大储领域渗透的先天条件。

整体来看，思格、德业等工商储、户储龙头企业的集体转向，不仅重塑了海外大储市场的竞争格局，也成为中国企业“出海升级”的典型样本。

随着全球大储市场的持续升温，市场厮杀将愈发激烈。在未来户储、工商储、大储领域的厮杀，会更集中在头部企业之间，而行业新一轮卡位赛悄然开启。
