# 美国战略石油储备，降至43年来最低水平

据美国能源部公布的数据，美国战略石油储备上周减少550万桶，降至3.257亿桶，为1983年5月以来最低水平。
总台记者当地时间6月29日获悉，据美国能源部公布的数据，美国战略石油储备上周减少550万桶，降至3.257亿桶，为1983年5月以来最低水平。这是今年2月底美以伊战事之后，美国政府为平抑油价而释放战略石油储备的持续举措。
根据美国能源部今年3月11日发布的计划，美方将在约120天内从战略石油储备中释放1.72亿桶原油，以应对美国和以色列军事打击伊朗所引发的油价上涨压力。
