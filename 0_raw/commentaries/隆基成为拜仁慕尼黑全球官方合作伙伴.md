# 隆基成为拜仁慕尼黑全球官方合作伙伴

8月6日，隆基宣布正式成为拜仁慕尼黑足球俱乐部全球官方合作伙伴。当日在香港瑰丽酒店举行的启动仪式上，隆基董事长、总经理钟宝申、拜仁慕尼黑市场营销与销售董事会成员鲁文·卡斯帕共同宣布这一合作，拜仁慕尼黑传奇球星罗伊·马凯到场见证。
▲图为隆基副总裁、光伏产品管理中心总裁蒋东宇，隆基董事长、总经理钟宝申，拜仁慕尼黑市场营销与销售董事会成员鲁文·卡斯帕，拜仁慕尼黑传奇球星罗伊·马凯（从左至右）出席合作启动仪式。
全球光伏冠军牵手足坛纪录之王
拜仁慕尼黑成立于1900年，是全球最具影响力和球迷基础的足球俱乐部之一，拥有跨越百年的辉煌历史与“Mia san Mia”（我们就是我们）的独特精神标识。隆基成立二十六年来始终致力于清洁能源技术的创新和突破，其晶硅—钙钛矿叠层太阳能电池转换效率达35.5%，持续刷新世界纪录，并连续26个季度蝉联PV Tech最高“AAA”可融资性评级。
启动仪式上，双方共同发布合作主题“POWER ON, GAME ON”。“POWER ON”代表隆基为电站、工商业及家庭提供清洁能源的使命，“GAME ON”则承载拜仁慕尼黑的竞技精神与全球球迷的激情。该主题将成为双方后续联合推广、内容创作及球迷互动活动的统一核心理念。
▲图为隆基董事长、总经理钟宝申致辞。
“足球连接数百万人，能源则触达每一个人。”隆基董事长、总经理钟宝申致辞称：“拜仁慕尼黑与隆基来自不同领域，但我们拥有相同的本能驱动力——持续进步、不断挑战自我，从不将任何一次成就视为终点。”
▲拜仁慕尼黑市场营销与销售董事会成员鲁文·卡斯帕致辞。
拜仁慕尼黑市场营销与销售董事会成员鲁文·卡斯帕表示：“拜仁慕尼黑代表着赛场上的卓越追求。我们与隆基绿能，同样秉持对卓越的不懈追求，真心致力于共创更可持续的未来。我们期待与这家全球行业领军企业携手，让可再生能源持续获得广泛关注。”
此次合作是隆基本年度在欧洲体育领域的第二次重要布局，此前已与柏林马拉松达成合作。
从世界纪录，走进日常生活
在欧洲市场，隆基产品已获得广泛认可与信赖，其高端户用品牌EcoLife更成为众多家庭追求品质生活的优选。
作为隆基面向全球户用市场推出的高端品牌，EcoLife集高效光伏技术、可靠品质与设计创新于一体，其组件转换效率最高可达25%，功率输出达510W。自2026年4月以来，EcoLife持续位列TaiyangNews商业化量产组件效率排行榜榜首。
▲图为隆基副总裁、光伏产品管理中心总裁蒋东宇致辞。
“隆基每一款产品的研发，都始于同一个问题：如何把顶尖光伏技术，转化为客户日常可以信赖的产品。这份研发准则贯穿我们全部产品阵容，既包括为全球大型光伏电站供货的组件，也包含面向家庭的能源系列 EcoLife。产品，正是我们兑现技术承诺的载体。”隆基副总裁、光伏产品管理中心总裁蒋东宇表示。
基于“Solar for Solar”理念，隆基正加速推进2050年净零排放目标。拜仁慕尼黑也通过“Mitnand”（携手共进）战略，将环境与社会责任纳入俱乐部整体运营。双方未来将探讨将隆基太阳能解决方案引入拜仁慕尼黑训练设施及体育场馆等项目中的可行性。
