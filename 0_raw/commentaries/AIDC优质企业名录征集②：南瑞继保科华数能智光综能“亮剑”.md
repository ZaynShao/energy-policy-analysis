# AIDC优质企业名录征集②：南瑞继保/科华数能/智光综能“亮剑”

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/bhqZZ4eZhIvkAen9S6XF07oChz9czicgoxuFy48ObpkYF6lP8W7UtX3eX0rjovr5qDaEmMpATXU3aLFpP4FX0T7uQgQ5gBD1fftqW9rS3wpg/640?wx_fmt=png&from=appmsg)

5月20日，高工储能、高工产业研究院(GGII)主办的2026AIDC算电协同产业峰会（[点击查看详细议程](https://mp.weixin.qq.com/s?__biz=MzIyOTQxMjk3Ng==&mid=2247529867&idx=2&sn=ab085ce5eb7b4624c0db6ed9baf16483&scene=21#wechat_redirect)）将在上海虹桥新华联索菲特大酒店举行。500+互联网巨头及云厂商、AI芯片及服务器提供商、第三方专业及电信运营商、HVDC及SST供配电设备厂商、UPS厂商、储能产业链企业齐聚。

  

为表彰在AIDC细分领域具备核心技术、成熟产品和卓越服务能力的供应商，推动产业链协同创新与高质量发展，高工储能组委会将在入选名录企业评选出AIDC产业链：技术先锋、市场先锋、出海先锋三大先锋奖项。

据组委会透露，2026AIDC 产业链优质企业名录征集活动（[戳此查看申报规则](https://mp.weixin.qq.com/s?__biz=MzIyOTQxMjk3Ng==&mid=2247528358&idx=2&sn=fa9119f10a9f3d45ac37d9d7b282b859&scene=21#wechat_redirect)）正在火热进行中，目前已收到一大批企业的自主申报材料，将分批对外展示（排名不分先后；篇幅有限，仅展示企业部分资料；名单持续更新中）。

最终优质企业名录及先锋奖获奖名单将在5月20日颁布，同期举办2026AIDC算电协同产业峰会，敬请持续关注！  

南瑞继保

南京南瑞继保电气有限公司（简称“南瑞继保”）专业从事电力保护控制装备、智能电力装备及工业过程控制设备的研发和产业化，是国家能源局电力控制保护技术研发(实验)中心依托单位、国家技术创新示范企业。获评国家卓越工程师团队、国家制造业单项冠军、国家绿色工厂、智能制造示范工厂等多项荣誉。中国工程院沈国荣院士担任公司董事长。

南瑞继保坚持“解决问题就是创新”的理念，持续推进科研与产业深度融合。产品及服务在继电保护、电网安全稳定控制、特高压交直流输电、柔性交直流输电、工业控制等领域具有极高的知名度和占有率。

南瑞继保长期关注新能源规模化开发后电力系统特性的演变，在多年研究积累和工程实践的基础上，南瑞继保在行业率先提出基于储能系统打造同步电源的理念，成功研发理想同步电源型构网技术，研制出构网型储能、构网型SVG、静止同步调相机、构网柔直等全套构网型装备，已在新能源大基地、偏远矿产开发、绿电直连、新能源制氢、AIDC智算中心等场景大量应用，在海内外实施超过150多个工程，累计功率超19GW。

AIDC相关装备主要项目：苏州同里综合能源示范区项目；浙江海宁尖山主动配电网试点工程；江苏连云港连岛交直流配网项目；天津交直流互联城市配电网项目；杭州江东新城智能柔性直流配电网示范工程；苏州吴江中低压直流配电九里数据中心站。

科华数能

厦门科华数能科技有限公司是科华数据股份有限公司（股票代码：002335）的全资子公司。

依托母公司近四十年深厚的电力电子技术积淀、产业资源与全球化能力，科华数能自成立之初便站在高起点之上，在AI 算力硬件、供配电与储能、AI 软件与平台三大业务领域形成显著领先优势，以技术传承与创新突破，构筑起强劲的综合竞争力。

在数据中心领域，科华数能为客户提供数据中心选址咨询、规划设计、产品方案、集成管理、工程实施、运维管理、IDC主机托管、增值业务在内的全生命周期服务。作为业界领先的高安全数据中心服务提供商，公司拥有10年以上数据中心建设运营经验，在北京、上海、广州及周边城市自建10大数据中心，在全国10余城市运营20多个数据中心，拥有机柜数量3.5万+架，形成华北、华东、华南、西南四大数据中心集群。

科华数能服务于中国移动、中国电信、中国联通三大运营商，护航国有六大银行、商业银行、证券、保险等金融机构的100多个省级数据中心，产品方案入驻国内大型互联网企业、大型云计算服务商、中科院超级计算青岛分中心、国家测绘局、国家工商总局、中国工商银行总行、中国航天二院、清华大学、中国科学院、中国商飞、平安集团、中冶集团等项目。  

智光综能

作为聚焦新能源与数字经济融合发展的科技型企业，智光综能以“赋能能源高效利用，助力双碳目标落地”为核心使命，深耕源网荷储一体化、SST固态变压器、算电协同三大核心赛道，构建“核心技术+产品体系+项目落地”的全链条发展模式，致力于成为新型电力系统与绿色算力领域的领军企业。

数据中心源网荷储协同项目：针对大型AI数据中心高耗能、高可靠供电需求，构建源网荷储协同体系，配套光伏绿电直供、储能备用电源及负荷智能调控设备，实现算力负荷与电力供给动态匹配，保障数据中心供电稳定性，将数据中心PUE值控制在1.15以下，年减少碳排放超万吨。

SST固态变压器核心技术研发项目：自主牵头SST固态变压器系列产品研发，突破高频隔离、精准调压等核心技术瓶颈，完成中低压、高频隔离等多规格产品研发与性能测试，产品效率达98.5%以上，体积较传统变压器缩减40%，填补企业在新型配电设备领域的技术空白，为算电协同落地提供核心硬件支撑。

智算集群算电协同示范项目：为区域智算集群打造算电协同一体化解决方案，搭建智能调度平台，实现算力资源与绿电资源时空匹配，支持跨区域算力调度与任务迁移，让算力“追着绿电跑”，年提升绿电消纳率40%，降低算力运营成本25%，助力智算产业绿色高效发展。

数据中心算电协同优化项目：为大型互联网数据中心提供算电协同优化服务，配套负荷调控模块、能效监测系统，优化算力调度策略，结合源网荷储系统实现能源高效供给，同时提供全流程运维与碳核算服务，助力客户实现绿色算力与高效用能双重目标，项目落地后数据中心年用电成本降低20%-30%。
