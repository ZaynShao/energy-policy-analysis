# 综研动态｜综合开发研究院与山东省电力行业协会签订战略合作协议

6月1日，综合开发研究院（中国·深圳）与山东省电力行业协会在CDI大厦举行战略合作签约仪式，同时，聘任协会执行会长徐震为综研院智库专家咨询委员会专家。双方将围绕能源转型、新型电力系统建设等重大议题，开展全方位、深层次合作，共同打造智库与行业协同发展的新范式。
山东省电力行业协会是省级行业性AAAAA级社会团体，现有会员单位1000余家，在电力行业具有深厚的专业根基和广泛的影响力。双方携手，正是国家级智库的宏观视野与地方行业实践的一次深度握手。
刘国宏院长对徐会长一行表示热烈欢迎。他指出，作为面向市场的社会智库，研究院正处在转型发展的关键阶段，必须深耕行业、融入产业，才能更好地承载高端智库的功能与使命。此次合作，既是双方资源禀赋的精准对接，更是双向赋能的战略选择。他期待与协会在山东与大湾区之间架起一座桥梁，在课题研究、行业培训、论坛交流等方面结出丰硕成果。
徐会长建议，依托综研院的国家级平台优势，围绕新型电力系统建设中的顶层设计、产业补链强链、零碳园区规划等方向，联合开展政策性、前瞻性研究，同时积极对接电网企业、地方政府和市场主体，让研究成果真正“解渴”“能用”，为委托方创造看得见的价值。
刘国宏院长为徐震执行会长颁发了智库专家咨询委员会专家聘书。
财税贸易与产业发展研究中心主任韦福雷与山东省电力行业协会副秘书长邱娜娜代表双方签署了协议。
在随后的座谈中，双方还就如何发挥深圳的民营企业创新优势、链接大湾区智慧能源产业资源等话题进行了深入探讨。大家一致认为，当下能源领域投资热度高、政策变化快，合作空间极为广阔，关键在于找准真实需求、做实具体项目，以务实的态度把协议内容转化为可落地、可持续的合作成果。未来，双方将以常态化的沟通机制和项目化的工作推进，共同书写智库与行业协同赋能、服务区域高质量发展的新篇章。
