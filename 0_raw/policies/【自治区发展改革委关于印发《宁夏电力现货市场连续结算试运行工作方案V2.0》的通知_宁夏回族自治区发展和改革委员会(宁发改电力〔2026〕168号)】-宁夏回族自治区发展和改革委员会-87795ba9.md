# 自治区发展改革委关于印发《宁夏电力现货市场连续结算试运行工作方案V2.0》的通知_宁夏回族自治区发展和改革委员会

## 政策原文

宁发改电力〔2026〕168号

国网宁夏电力有限公司、宁夏电力交易中心有限公司、有关电力市场经营主体：

为进一步贯彻落实全国统一电力市场体系建设要求，自治区发展改革委组织制定了《宁夏电力现货市场连续结算试运行工作方案V2.0》，现予以印发，2026年4月1日起开始执行。


附件：宁夏电力现货市场连续结算试运行工作方案V2.0

宁夏回族自治区发展改革委
