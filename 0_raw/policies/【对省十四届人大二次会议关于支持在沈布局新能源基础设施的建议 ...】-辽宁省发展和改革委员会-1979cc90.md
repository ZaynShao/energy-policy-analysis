# 对省十四届人大二次会议关于支持在沈布局新能源基础设施的建议 ...

## 政策原文

来源：

发布时间：2024年08月28日

左俊杰代表：

您提出的关于支持在沈布局新能源基础设施的建议收悉，现答复如下：

一、关于您提出的建议支持沈阳市加快新能源基础设施布局的建议

2月29日，习近平总书记在中共中央政治局第十二次集体学习时强调，要大力推动新能源高质量发展。同时，党中央、国务院印发了加快规划建设新型能源体系的指导意见，要求必须适应新形势新要求，推动化石能源和非化石能源协同互补、融合发展，牢牢把握清洁低碳、安全高效的本质特征，加快规划建设新型能源体系，为助力经济高质量发展、推进中国式现代化实践提供能源支撑。

我委以清洁能源强省建设为抓手，依靠丰富的资源条件、坚强的电网结构为沈阳清洁能源强省建设提供有力支撑，全市清洁能源建设取得新突破。

在风电光伏建设方面。截至2023年底，沈阳市风电累计并网装机规模146.8万千瓦，在建装机规模198.4万千瓦；光伏累计并网装机规模107.3万千瓦，其中户用分布式15.9万千瓦，工商业分布式20.7万千瓦。在氢能产业方面。沈阳市组建了氢氨清洁能源产业技术创新联盟，瞄准“加快前沿新兴氢能产业发展”这一战略机遇，从氢能产业工程示范、技术创新、科技成果验证及转化、联合创新平台建设等方面积极推动战略性新兴产业融合发展，加快产业链向上下游延伸。目前，盟主单位华电辽宁能源发展股份有限公司已成功制出我省第一罐绿氢。同时，与华中科技大学、厦门大学、哈尔滨工业大学等省外高校开展产学研合作，持续集聚创新资源要素。在新型储能产业方面。惠州亿纬锂能作为国内新型锂电能源行业的标杆型、领军型企业，拥有较强的自主研发能力和产品竞争优势。2023年，沈阳市人民政府与惠州亿纬锂能股份有限公司签订了亿纬锂能储能与动力电池项目投资协议及补充协议。项目拟投资100亿元，规划产能40GWh，建设储能与动力电池智能制造工厂及配套设施，将对沈阳发展新型储能起到积极作用。沈阳微控作为全省首家制造业独角兽企业，凭借全球领先的磁悬浮飞轮技术，年初以来，沈阳微控飞轮的订单总额近8亿元，预计产值同比增长超400%。

下一步，我委将与省电力公司配合积极推动沈阳市新能源高质量发展，统筹考虑各县区分布式电源承载力和新能源消纳率，科学规划集中式和分布式新能源，合理安排新能源在康平、法库、新民及辽中等资源丰富地区发展规模和建设时序，促进新能源高质量跃升发展。

二、关于您提出的支持沈阳市具备条件的地区建设共享储能电站的建议

我委高度重视储能发展，新型储能作为能源领域的重要组成部分，对于保障能源安全、促进可再生能源发展、能源转型、碳减排以及电力系统优化具有重要意义和作用。“十四五”以来，我省出台了一系列政策文件，初步建立了新型储能行业管理体系，统筹推动全省新型储能试点示范，为新型储能技术创新应用和产业高质量发展奠定了基础。一是在《辽宁省国民经济和社会发展第十四个五年规划和二〇三五年远景目标纲要》中提出“推进发电侧和用户侧新型储能设施建设,发挥调峰调频作用，为电网平稳运行提供支撑”。二是我委配合有关部门经反复论证，规划布局了一批新型储能项目，对布局区域、电网接入点、容量等予以明确，涉及项目27个，总装机容量350万千瓦，其中沈阳市布局新型储能装机容量60万千瓦。这批项目将为我省构建新型电力系统，缓解电网调峰、调频资源不足等问题起到关键作用。

下一步，我委将进一步强化沈阳市储能体系建设，支持沈阳市打造“千亿储能之都”的目标。一是推进新型储能技术试点示范，聚焦各类应用场景，关注多元化技术路线，积极开展新型储能试点示范，加强示范项目跟踪评估。二是推进新型储能规模化发展，持续优化建设布局，促进新型储能与电力系统各环节融合发展，支撑新型电力系统建设。

感谢您对我省新能源产业和储能产业发展的关心和关注。

辽宁省发展和改革委员会

2024年6月14日
