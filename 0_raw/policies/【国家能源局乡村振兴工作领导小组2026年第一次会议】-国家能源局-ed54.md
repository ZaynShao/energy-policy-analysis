# 国家能源局乡村振兴工作领导小组 2026 年第一次会议

**发文机构**: 国家能源局  
**主持人**: 王宏志(国家能源局党组书记、局长、局乡村振兴工作领导小组组长)  
**会议性质**: 部委专项工作领导小组会议(年度首次)  
**发布日期**: 2026-03-04  
**类型**: 会议纪要(政策信号 / 工作部署)  
**来源**: https://www.nea.gov.cn/20260304/80c9f9ca71e14e9ab49751d0aad97f72/c.html

## 摘要

国家能源局召开 2026 年首次乡村振兴工作领导小组会议,审议通过《国家能源局 2026 年定点帮扶和对口支援工作要点》。**会议明确部署"扩大农村充电设施覆盖范围"** + 大力推进农村风电/光伏 + 北方清洁取暖 + 农网升级。是国家能源局对 2026 年农村能源工作的最高级部署。

## 初步影响分析

**加油业务**: 无直接影响(本次会议未提及农村加油站升级)
**充电业务**: **中等利好** — 会议明确"**扩大农村充电设施覆盖范围**",是国家级首次将农村充电纳入年度部署的明确表态;但**未给具体数字目标 / 试点城市 / 招标项目**,仅为方向性信号
**电力业务(储能/V2G/电力交易)**: 弱关联 — 农网升级 + 农村风光,部分跟分布式储能 / 农村虚拟电厂沾边,但与滴滴主战场关联较弱
**乡村业务(若有)**: 强关联 — 县域充电下沉 / 农网协同 / 风光储一体 是该方向核心命题

## 政策原文(全文)

近日,国家能源局乡村振兴工作领导小组召开 2026 年第一次会议,深入学习习近平总书记关于乡村振兴工作的重要讲话精神,贯彻落实 2026 年中央一号文件部署要求,审议通过《国家能源局 2026 年定点帮扶和对口支援工作要点》等文件,研究部署 2026 年相关工作。国家能源局党组书记、局长、局乡村振兴工作领导小组组长王宏志主持会议并讲话。

会议强调,要始终将"三农"工作作为全局和能源行业的重要政治任务,扛牢政治责任,深入推进农村能源革命,着力提升农村电网供电保障和综合承载能力,大力推进农村风电、光伏开发利用,**扩大农村充电设施覆盖范围**,持续做好北方地区清洁取暖,因地制宜推广农村可再生能源供暖,以能源发展带动村集体和村民增收。

要高质量完成定点帮扶和对口支援任务,坚持好经验好做法,持续创新帮扶举措。

## 关键工作部署

| # | 任务 | 滴滴关联 |
|:-:|------|:-:|
| 1 | 推进农村能源革命,提升农村电网供电保障和综合承载能力 | 弱(农网建设非滴滴) |
| 2 | 大力推进农村风电、光伏开发利用 | 弱 |
| 3 | **扩大农村充电设施覆盖范围** | **中等(充电下沉)** |
| 4 | 持续做好北方地区清洁取暖工作 | 无 |
| 5 | 因地制宜推广农村可再生能源供暖 | 无 |
| 6 | 高质量完成定点帮扶和对口支援任务 | 无 |
| 7 | 以能源发展带动村集体和村民增收 | 无 |
