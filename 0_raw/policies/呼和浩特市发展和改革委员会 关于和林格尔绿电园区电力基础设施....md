# 呼和浩特市发展和改革委员会 关于和林格尔绿电园区电力基础设施项目牵头企业竞争性优选结果的公示

_发布日期：2026-08-07 16:21:42　来源：呼和浩特市发展和改革委员会_

![](http://fgw.huhhot.gov.cn/material/images/zz_tu60.jpg)![](http://fgw.huhhot.gov.cn/material/images/zz_tu61.jpg)![](http://fgw.huhhot.gov.cn/material/images/zz_tu62.jpg)

[分享到微信](http://fgw.huhhot.gov.cn/fgdt/tzgg/202608/t20260807_2027490.html# "分享到微信")[分享到新浪微博](http://fgw.huhhot.gov.cn/fgdt/tzgg/202608/t20260807_2027490.html# "分享到新浪微博")[分享到QQ空间 ](http://fgw.huhhot.gov.cn/fgdt/tzgg/202608/t20260807_2027490.html# "分享到QQ空间 ")

根据《内蒙古自治区能源局关于印发<关于促进增量配电网高质量发展的若干措施（试行）>和<内蒙古自治区增量配电业务管理细则（试行）>的通知》（内能源电力发〔2026〕2号）、《内蒙古自治区能源局关于印发<和林格尔绿电园区电力基础设施方案（1.0版）>的通知》（内能源电力发〔2026〕340号）等文件要求，呼和浩特市发展和改革委员会组织开展和林格尔绿电园区电力基础设施项目牵头企业竞争性优选工作。

经第三方机构评估优选，拟确定内蒙古能源集团有限公司为和林格尔绿电园区电力基础设施项目牵头企业。现将竞争性优选结果予以公示，公示期为2026年8月8日—2026年8月10日。

对结果有异议的，请在公示期结束前以书面形式提出意见并反馈至呼和浩特市发展和改革委员会，逾期不再受理。
