# 国家发展改革委环资司 市场监管总局食品协调司联合发布制止餐饮浪费典型经验做法（第九批）

为营造“厉行节约、反对浪费”的良好氛围，交流制止餐饮浪费工作经验，国家发展改革委环资司、市场监管总局食品协调司现发布制止餐饮浪费第九批典型经验做法如下：

一、江西省吉安市探索“弹性供餐＋家校共治＋食育浸润”机制。围绕“供得准、管得住、育得实”三个关键环节，推动校园餐饮由“要我节约”向“我要节约”持续转变。目前，全市学生光盘率由整治前的85%提升至96%，餐余垃圾量同比下降约12%。创新“弹性供餐+数据反馈”机制，从供给端破解“供需错配”。构建弹性供给、餐余计量、数据反馈环环相扣的供餐新机制，实现以需定供、以供控量。创新“家校陪餐+闭环督办”机制，从治理端破解“管理乏力”。以构建家长进校陪餐机制为抓手，打通“扫码反馈—当日交办—限期办结—回访销号”全链条，推动反浪费由学校“单管”走向多元“共治”。创新“食育浸润＋正向激励”机制，从育人端破解“知易行难”。将餐桌作为育人课堂，构建“餐前引导、餐中践行、餐后实践”一体化食育链条，让节约意识真正落地生根，形成“学校引领、学生主导、家庭参与”的共育合力。

二、山东省聊城市“小手拉大手”合力推进制止餐饮浪费。将制止餐饮浪费与精神文明建设有机结合，充分发挥青少年学生、党员志愿者的主力军作用，强化部门联动，常态化、长效化深入社区开展“厉行勤俭节约、反对餐饮浪费”主题宣传活动。通过悬挂横幅、发放宣传册等多种方式，向广大群众普及反食品浪费法相关内容以及节约粮食的重要意义，详细讲解餐饮浪费对资源、环境以及社会可持续发展的负面影响，倡导践行“光盘行动”。通过分享日常节约小窍门，引导群众合理规划家庭餐食、避免过量购买食材、妥善处理剩菜剩饭，鼓励群众从自身做起，从小事做起，共同营造“崇尚节约、反对浪费”的浓厚氛围。

三、甘肃省金昌市创新举措推进反餐饮浪费走深走实。积极优化职工食堂供餐方式，推行“职工食堂小碗自选菜”，将原有的套餐打饭改进为小碗菜自选，小碗自带智能芯片，按照标准克重打菜装碗，做到精准定量供餐，智能自动结算；实行菜品动态调整，持续减少因“不合口味”而造成的餐饮浪费。在农村地区倡导自办宴席简化，推动文明用餐、厉行节约新风尚，杜绝农村婚丧嫁娶集体聚餐自办宴席中的浪费行为。建立健全食品安全协管员队伍，强化流动厨师管理培训，推动消费者文明用餐、增强节约意识。

四、青海省以标准化促进餐饮节约反对餐饮浪费。制定地方标准《网络餐饮厉行节约实施指南》，紧紧围绕防范外卖餐饮浪费的重点、痛点、难点问题，着眼外卖行业点餐、餐饮制备、打包、配送等全链条，系统提出厉行节约措施。引导网络餐饮平台畅通消费者和社会公众反食品浪费信息反馈通道，要求网络餐饮服务平台在点餐、提交订单、订单完成等页面，以显著方式提示消费者按需点餐；优化满减凑单机制，最大限度避免食品浪费。着眼精细管理，从各个环节减少原料成品浪费，提升餐饮供给质量，合理设置起送价格；鼓励通过建立环保虚拟账户、授予节约积分、发放优惠券等方式引导消费者购买小份餐品。通过线上线下各种方式持续开展相关标准宣贯活动，以标准化促进餐饮节约，让制止餐饮浪费理念更加深入人心。

## 国家发展改革委环资司 市场监管总局食品协调司联合发布制止餐饮浪费典型经验做法（第九批）

信息来源：国家发展改革委

发布日期：2026-10-15 18:22:36

为营造“厉行节约、反对浪费”的良好氛围，交流制止餐饮浪费工作经验，国家发展改革委环资司、市场监管总局食品协调司现发布制止餐饮浪费第九批典型经验做法如下：

一、江西省吉安市探索“弹性供餐＋家校共治＋食育浸润”机制。围绕“供得准、管得住、育得实”三个关键环节，推动校园餐饮由“要我节约”向“我要节约”持续转变。目前，全市学生光盘率由整治前的85%提升至96%，餐余垃圾量同比下降约12%。创新“弹性供餐+数据反馈”机制，从供给端破解“供需错配”。构建弹性供给、餐余计量、数据反馈环环相扣的供餐新机制，实现以需定供、以供控量。创新“家校陪餐+闭环督办”机制，从治理端破解“管理乏力”。以构建家长进校陪餐机制为抓手，打通“扫码反馈—当日交办—限期办结—回访销号”全链条，推动反浪费由学校“单管”走向多元“共治”。创新“食育浸润＋正向激励”机制，从育人端破解“知易行难”。将餐桌作为育人课堂，构建“餐前引导、餐中践行、餐后实践”一体化食育链条，让节约意识真正落地生根，形成“学校引领、学生主导、家庭参与”的共育合力。

二、山东省聊城市“小手拉大手”合力推进制止餐饮浪费。将制止餐饮浪费与精神文明建设有机结合，充分发挥青少年学生、党员志愿者的主力军作用，强化部门联动，常态化、长效化深入社区开展“厉行勤俭节约、反对餐饮浪费”主题宣传活动。通过悬挂横幅、发放宣传册等多种方式，向广大群众普及反食品浪费法相关内容以及节约粮食的重要意义，详细讲解餐饮浪费对资源、环境以及社会可持续发展的负面影响，倡导践行“光盘行动”。通过分享日常节约小窍门，引导群众合理规划家庭餐食、避免过量购买食材、妥善处理剩菜剩饭，鼓励群众从自身做起，从小事做起，共同营造“崇尚节约、反对浪费”的浓厚氛围。

三、甘肃省金昌市创新举措推进反餐饮浪费走深走实。积极优化职工食堂供餐方式，推行“职工食堂小碗自选菜”，将原有的套餐打饭改进为小碗菜自选，小碗自带智能芯片，按照标准克重打菜装碗，做到精准定量供餐，智能自动结算；实行菜品动态调整，持续减少因“不合口味”而造成的餐饮浪费。在农村地区倡导自办宴席简化，推动文明用餐、厉行节约新风尚，杜绝农村婚丧嫁娶集体聚餐自办宴席中的浪费行为。建立健全食品安全协管员队伍，强化流动厨师管理培训，推动消费者文明用餐、增强节约意识。

四、青海省以标准化促进餐饮节约反对餐饮浪费。制定地方标准《网络餐饮厉行节约实施指南》，紧紧围绕防范外卖餐饮浪费的重点、痛点、难点问题，着眼外卖行业点餐、餐饮制备、打包、配送等全链条，系统提出厉行节约措施。引导网络餐饮平台畅通消费者和社会公众反食品浪费信息反馈通道，要求网络餐饮服务平台在点餐、提交订单、订单完成等页面，以显著方式提示消费者按需点餐；优化满减凑单机制，最大限度避免食品浪费。着眼精细管理，从各个环节减少原料成品浪费，提升餐饮供给质量，合理设置起送价格；鼓励通过建立环保虚拟账户、授予节约积分、发放优惠券等方式引导消费者购买小份餐品。通过线上线下各种方式持续开展相关标准宣贯活动，以标准化促进餐饮节约，让制止餐饮浪费理念更加深入人心。
