# 六安市市场监管局关于规范教育收费行为的提醒告诫函

浏览次数：129信息来源：市市场监管局价监局发布时间：2026-09-03 11:29

_字号：_大中小下载我要纠错打印收藏

全市各类学校（幼儿园）、学科类校外培训机构：

当前正值2026年秋季开学季，为进一步规范教育收费行为，维护学生及家长合法价格权益，根据《中华人民共和国价格法》《价格违法行为行政处罚规定》《明码标价和禁止价格欺诈规定》及有关教育收费政策文件，结合我市实际，现对全市各类学校（幼儿园）和学科类校外培训机构（以下简称学校和培训机构）提醒告诫如下：

一、规范教育收费公示

学校和培训机构要全面落实教育收费公示制度、明码标价规定，通过招生简章、入学通知书、办学场所公示栏、单位网站等渠道，公示收费项目、收费标准、收费依据、收费范围、计费单位、投诉电话等内容，收费项目、收费标准等变动后，要及时变更，确保公示内容全面、准确。未经公示或公示内容与规定不符的收费，不得收取。

二、规范学费和住宿费收费

学校要严格执行价格主管部门批准的学费、住宿费等政府指导价、政府定价项目和收费标准，不得通过自立收费项目、分解收费项目、自定收费标准、提高收费标准、扩大收费范围、重复收费等方式多收费。

三、规范教育服务性收费和代收费

学校要严格遵守自愿、非营利性原则收取服务性收费和代收费，不得只收费不服务或少服务，不得与学费、住宿费等捆绑收费，不得强制或变相强制开展研学旅行、课后服务、社会实践等活动并收费，不得强制或变相强制购买校服、教辅材料、学习用品和报刊等，不得将由财政保障的项目作为服务性收费和代收费向学生收取。

四、规范校外培训收费

学科类校外培训机构收取培训费，要严格执行政府指导价规定，不得超时段、超限额收费，不得利用虚假的或者使人误解的价格手段诱骗学生和家长进行收费，不得在标价之外加价收费或收取任何未予标明的费用。

五、严禁其他乱收费

学校和培训机构要严格执行教育收费政策规定，不得收取或变相收取与招生录取挂钩的赞助费、捐助费、共建费等，不得通过社会中介等关联交易第三方变相收取借读费、择校费、转校费等，不得以信息化教学等名义强制学生购买平板电脑、教育APP并收费，不得借家委会、第三方机构等名义搭车收费、变相收费。

学校和培训机构要切实履行教育收费主体责任，依法合规收费，主动接受社会监督。各县区市场监管部门会同教育等主管部门加强教育收费监管，依法履行监督检查职责，对经提醒告诫仍不整改的违规收费行为，将依据价格法律法规严肃查处，典型案件公开曝光。

社会各界、学生及家长如发现教育收费违法违规线索，请拨打12345或者12315进行投诉举报。
