# 智能网联新能源汽车产业发展“十五五”规划亮点详解

新华社北京9月11日电 **题：智能网联新能源汽车产业发展“十五五”规划亮点详解**

新华社记者 唐诗凝、周圆、李倩薇

“持续提升动力电池安全、充电倍率、低温适用、循环寿命等性能水平”“促进汽车与智能机器人、智能家居、智能穿戴等生态互联”“推动降低维修费用，提升维修服务能力”……《智能网联新能源汽车产业发展“十五五”规划》9月11日对外发布，一项项部署关乎你我出行生活，勾勒未来汽车产业新图景。

“十四五”期间，我国智能网联新能源汽车产业发展取得显著成效，整车集成、动力电池、智能座舱、激光雷达等技术水平进入全球前列，市场规模实现从百万级到千万级的跃升，并为全球汽车产业绿色低碳转型贡献了积极力量。

工业和信息化部装备工业一司司长郭守刚在工业和信息化部当天举行的新闻发布会上表示，“十五五”期间，全球智能网联新能源汽车发展处于变革机遇期，我国产业发展前景广阔、未来可期。

“为进一步推动我国智能网联新能源汽车产业高质量发展，加快汽车强国建设，工业和信息化部联合相关部门编制这一规划，进一步明确发展目标和重点任务，加快向绿色化、智能化、高端化、国际化方向迈进。”郭守刚说。

规划按照“1+4”的结构提出发展目标：到2030年，我国智能网联新能源汽车全产业链优势进一步巩固，进入世界汽车强国行列，国内市场新能源乘用车、商用车在各自领域新车总销量的占比分别达到70%、40%，具备自动驾驶功能的汽车实现规模应用，在关键技术、产业结构、国际化发展、社会经济效益等方面进一步提升。

规划明确部署多项重点任务，“提高技术创新能力”位列首位，要求强化关键核心技术攻关、提高产业链韧性和安全水平、提升创新体系效能。

“技术创新是产业发展不变的底色。”国家发展改革委产业发展司副司长邵稷表示，接下来将聚焦新型电子电气架构、全固态电池、汽车操作系统等前沿领域，支持骨干企业联合产业上下游开展协同攻关，加快突破一批关系产业长远发展的共性技术、基础技术和前沿技术。

翻阅这份规划，“自动驾驶”是反复提及的高频词：高速公路、城市快速路、部分城市道路等场景实现高度自动驾驶；积极稳妥推进自动驾驶技术规模应用；完善组合驾驶辅助和自动驾驶系统准入管理要求……

“当前，驾驶辅助和自动驾驶技术进入加速发展期，广大消费者对其的期望也很高。我们将始终把安全放在首位，在确保安全的前提下推动技术创新和产业发展，让人民群众既享受到科技进步的便利，又有充分的安全保障。”郭守刚说。

今年以来，我国汽车出口保持良好增长态势，中国品牌国际认可度不断提升，为海外消费者出行提供了优质优价的更多选择。面向“十五五”，国际化如何推进？

规划提出“开创全球产业合作新局面”，强调加强汽车产业国际化发展顶层设计，引导企业综合运用贸易、投资、技术合作等方式深化国际合作，提升海外发展服务能力等。与此同时，支持外资企业在华深耕发展，鼓励中外企业在整车、关键零部件研发投资方面深度合作，加速产品转型升级。

商务部合作司副司长曹文介绍，下一步，将会同有关部门完善汽车产业出海政策举措，健全海外综合服务体系，加强企业出海合规建设，同时强化企业海外利益保护。

从单纯交通工具向移动智能终端、储能单元和数字空间转变，汽车跨界融合成为产业发展的鲜明特征。未来五年，促进产业融合发展新生态的着力点在哪？

规划明确，进一步深化汽车与信息通信、能源以及交通、城市发展融合。具体举措包括，提升车端5G/5G-A与C-V2X直连通信能力渗透率；推动自动驾驶与物流、出行深度融合；加快完善充换电基础设施，科学合理布局大功率充电设施等。

维护健康有序市场环境也是产业高质量发展的应有之义。

规划部署加强市场监管执法，强化反垄断、反不正当竞争和价格执法司法，加强质量监督检查、缺陷调查和产品一致性监督检查力度，形成优质优价、良性竞争的市场秩序等。

郭守刚介绍，为进一步守牢车辆产品安全底线，维护消费者合法权益，工业和信息化部近期联合相关部门组织开展了道路机动车辆产品生产一致性和质量提升专项行动。

“下一步，我们将加快产品可靠性、环境适应性等标准制修订，防范不合理创新设计和未经充分研发测试验证的产品进入市场；对重点汽车生产企业及检验检测机构实现检查全覆盖，加大典型案例曝光力度，进一步规范产业竞争秩序。”郭守刚说。
