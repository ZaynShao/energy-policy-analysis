# 交通运输部关于继续暂停对美船舶收取船舶特别港务费、暂停开展航运业造船业及相关产业链供应链安全和发展利益受影响情况调查的公告

# 文号：交通运输部公告2026年第90号        文号  ：交通运输部公告2026年第90号      索引号  ：000019713O08/2026-00051      公开日期  ：2026年11月09日      主题词  ：船舶特别港务费；航运业造船业；调查      机构分类  ：水运局      主题分类  ：其他      公文类型  ：部公告通告

字号: 【大】【中】【小】【打印】

为落实中美第八轮经贸磋商成果，经国务院批准，继续暂停实施《交通运输部关于对美船舶收取船舶特别港务费的公告》（交通运输部公告2025年第54号）、《交通运输部办公厅关于印发〈对美船舶收取船舶特别港务费实施办法〉的通知》（交办水〔2025〕59号）、《交通运输部关于启动航运业、造船业及相关产业链供应链安全和发展利益受影响情况调查的公告》（交通运输部公告2025年第55号）至2027年1月10日。

特此公告。

交通运输部

2026年11月9日

分送：外交部、工业和信息化部、国家安全部、财政部、商务部，各省、自治区、直辖市交通运输厅（委），各直属海事局。
