# 关于发布《射线装置分类办法》的公告

为贯彻《中华人民共和国生态环境法典》《放射性同位素与射线装置安全和防护条例》（国务院令第449号），适应射线装置技术迭代、产业应用发展和辐射安全监管新形势，生态环境部、国家卫生健康委对《射线装置分类》（环境保护部 国家卫生计生委公告2017年第66号）进行修订完善，制订了《射线装置分类办法》。现予以公布，自公布之日起施行。环境保护部、国家卫生计生委公告2017年第66号同时废止。

特此公告。

附件： [射线装置分类办法](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202610/W020261016366234807143.pdf)
