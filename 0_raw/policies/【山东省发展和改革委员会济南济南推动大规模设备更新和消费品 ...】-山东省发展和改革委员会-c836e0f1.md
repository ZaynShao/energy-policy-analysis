# 山东省发展和改革委员会济南济南推动大规模设备更新和消费品 ...

## 政策原文

济南推动大规模设备更新和消费品以旧换新

**济南推动大规模设备更新和消费品以旧换新**

**明确60项重点工作26条支持政策**

近日，《济南市推动大规模设备更新和消费品以旧换新工作方案》（以下简称《工作方案》）印发实施。到2025年，济南规模以上工业企业数字化研发设计工具普及率、关键工序数控化率分别超过90%和70%，装备制造业营业收入达到5000亿元左右；新能源汽车保有量达到30万辆以上，国三及以下非营运柴油货车基本淘汰；二手车交易量达到30万辆，废旧家电回收量较2023年增长15%。

**实施六大行动**

《工作方案》提出，实施六大行动，建立全市推动大规模设备更新和消费品以旧换新工作台账，明确60项重点工作。

在实施多领域设备更新行动方面，济南将深入实施“千项技改、千企转型”工程，每年实施亿元以上重点技术改造项目300个以上；实施“工赋泉城”行动，每年培育工业互联网标杆工厂、5G工厂、晨星工厂30家以上；发展多能互补的“源网荷储一体化”智慧能源系统和微电网，加快新型储能设施建设。到2025年，力争累计培育10家工业互联网园区，累计建成市级以上绿色工厂350家、绿色工业园区30个，全市建成充换电站1000座，充换电基础设施保有量超过10万个。

在实施多维度以旧换新行动方面，济南主要针对汽车、家电和家装三个消费领域，通过政企联动，开展换新补贴、让利促销、成套消费品协同推广和售后服务升级等活动，促进新能源汽车、智能家居等消费。

在实施高品质供给升级行动方面，加大高端服务器、高速冲压线、激光切割设备、新能源重卡、智慧矿山机械等优质工业品推广力度，借势提升济南市产业链科技创新能力和品牌价值。到2025年，省级及以上产业创新平台达到1000家以上，累计培育“好品山东”品牌（制造业）50个以上。

在实施高效能循环利用行动方面，在全市逐步推广建设现代化回收网点和绿色数智化分拣中心，健全机动车回收拆解、废旧家电家具回收处理等处置体系，培育二手车出口市场。

在实施全方位标准提升行动方面，深入实施《济南市落实国家标准化发展纲要推动高质量发展的实施意见》，推进科技创新标准化城市试点建设；开展新能源汽车电池及充电设施关键技术标准、制造业企业标准数字化转型等标准化战略性重点项目建设，加强前瞻性、先导性关键技术标准布局。

在实施全要素保障服务行动方面，强化政府引导作用，统筹相关专项资金支持设备更新和消费品以旧换新；用好再贷款政策工具，引导金融机构加强对设备更新和技术改造的支持。

**建立政策清单**

济南市充分发挥“财政+金融”政策联动作用，扩充政策“工具箱”，将设备更新、以旧换新、回收处理等政策进行整合，建立了“济南市推动大规模设备更新和消费品以旧换新政策清单”，梳理支持政策26条。

工业领域设备更新。实施企业技术改造投资补贴，对普通技改项目给予实际设备投资额10%的奖补，单个企业最高不超过1000万元；对整生产线、整车间和整工厂的智能化改造项目，分别给予设备投资（含软件）12%、15%和20%的奖补，单个企业最高不超过2000万元。

耐用消费品换新。在汽车以旧换新方面，制定《济南市2024年汽车以旧换新补贴实施细则》，按照新车购买金额给予一定比例的置换补贴。在家电以旧换新方面，引导家电销售企业联合生产企业、回收企业通过换新折扣、旧品抵现等各种让利模式，积极开展线上线下以旧换新促销活动。

回收利用体系建设。支持再生资源回收网点、分拣中心、再生资源产业园建设，对符合条件的企业（个体工商户）回收网点补贴最高20万元，对申报期内创建为山东省再生资源产业园、山东省再生资源回收分拣中心（山东省再生资源绿色分拣中心），分别给予最高30万元和20万元的一次性奖励。

此外，按照全市“项目深化年”工作部署，聚焦工业、建筑市政、交通运输、文教卫生、循环利用等五大领域，初步梳理并储备重点设备更新改造项目183个，总投资705.99亿元。项目清单将实行动态调整、规范管理。
