## 海口市发展和改革委员会关于海口市2025年度充换电基础设施验收及补贴申报的公告

|     |     |     |
| --- | --- | --- |
| ![](http://drc.haikou.gov.cn/material/images/2018_tyxl_time.png) 2026-08-07 15:45:30 | 来源： 市发改委 |  |

根据海南省发展改革委《海南省发展和改革委员会关于开展2025年度（第七批）电动汽车充电基础设施补贴申报工作的函》（琼发改便函〔2026〕1354号）《海南省电动汽车充换电基础设施建设运营暂行管理办法》（琼发改交能〔2019〕922号）《海南省电动汽车充换电基础设施验收暂行办法》（琼发改能源函〔2019〕1334号）等文件要求，我市拟于2026年8月30日前完成海口市行政区域内2025年1月1日至2025年12月31日期间建设运营符合验收条件的充换电基础设施联合验收工作。为切实做好此次验收和补贴申报工作，现将有关事项公告如下。

一、验收对象

海口市行政区域内对外运营、满足准入、完成备案及接入海南省充换电一张网服务平台（以下简称“省级平台”）的充换电基础设施。

二、验收组织

我委联合各相关单位（各区、各园区、市资规局、市住建局、市市场监督管理局、海口供电局、省级平台等）成立专项联合验收工作组。验收组织由联合验收工作组负责，相关申请企业配合做好验收工作。

三、验收时间及流程

验收时间为发布公告之日起至8月30日，流程如下：

（一）企业在省级平台官网（https://www.hainancce.com/）下载并填写《海南省电动汽车充换电基础设施验收申请表》及《海南省充电基础设施建设运营补贴申请表》，于8月20日前提交电子版及纸质版（一式一份）提交至省级平台（冯先生电话：15289988191，邮箱：yanshou@hainancce.com），邮件备注格式如下：“公司全称+2025年度充换电基础设施验收及补贴申报材料”），逾期未按要求提交材料将不再受理，提交材料后需补充完善的应按要求时间提供，若因提交材料未在规定时间完成，错失申报的自行承担责任。

（二）根据材料报送及审核情况，联合验收工作组制定现场检查计划，于8月25日前完成现场检查工作。

（三）现场检查完成后，企业在省级平台官网（https://www.hainancce.com/）下载并编制《海南省电动汽车充换电基础设施联合验收报告》，于8月28日前提交电子版及纸质版（一式两份）至省级平台。

（四）经联合验收工作组审核合格后，核算建设运营补贴并报送省发改。

注：为节省申报时间，企业需同步提交建设、运营补贴申请相关资料。

四、注意事项

（一）为保证验收工作质量，企业须事先对充换电基础设施自检，对照《验收办法》中的不合格条目整改合格以保证验收工作顺利进行，并建议企业安排专人对接，确保在各节点按照要求及时提供材料，避免逾期无法提交材料。

（二）为确保申请补贴场站用地的合规，除经审批停车场外，其他配套建设充换电基础设施场站需提供该地的红线坐标（大地2000坐标），已申请过建设补贴且核验过无需提供。

（三）根据《海南省电动汽车充电基础设施建设运营补贴工作流程》（琼发改能源函〔2020〕57号）关于“申请财政补贴资金的单位，对提交申请材料的真实性负责；各市县承担对省级补贴资金的管理责任”规定，对提供虚假信息、骗取财政补贴资金的，将追缴补贴资金、取消补贴资格，并按照《财政违法行为处罚处分条例》（国务院第427号）予以处罚；构成犯罪的，依法追究刑事责任。
