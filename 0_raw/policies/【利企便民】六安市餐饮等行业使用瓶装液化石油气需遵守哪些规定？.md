# 【利企便民】六安市餐饮等行业使用瓶装液化石油气需遵守哪些规定？

浏览次数： _179_ 次发布时间：2026-07-01 11:44信息来源： 12345热线

问 题：

六安市餐饮等行业使用瓶装液化石油气需遵守哪些规定？

答 复：

需安装可燃气体报警装置，并保障其正常使用；气瓶存放场所、数量，气瓶和燃气燃烧器具的连接等，应当符合有关标准和规范要求；建立健全用气操作规程等制度，明确安全用气责任；接受瓶装液化石油气经营企业的安全检查和安全用气指导，对瓶装液化石油气安全隐患应当立即整改；遵守法律、法规、规章的其他规定。

标签：[水电气](https://www.luan.gov.cn/site/tpl/4620?code=zwbq_rdzw_sdq&name=%E6%B0%B4%E7%94%B5%E6%B0%94) [生活消费](https://www.luan.gov.cn/site/tpl/4620?code=zwbq_zt_xfwq&name=%E7%94%9F%E6%B4%BB%E6%B6%88%E8%B4%B9) [公共安全](https://www.luan.gov.cn/site/tpl/4620?code=zwbq_zt_ggaq&name=%E5%85%AC%E5%85%B1%E5%AE%89%E5%85%A8) [经营](https://www.luan.gov.cn/site/tpl/4620?code=qybq_asmzqfl_jy&name=%E7%BB%8F%E8%90%A5) [住宿和餐饮业](https://www.luan.gov.cn/site/tpl/4620?code=xybq_xybq_zshcyy&name=%E4%BD%8F%E5%AE%BF%E5%92%8C%E9%A4%90%E9%A5%AE%E4%B8%9A)
