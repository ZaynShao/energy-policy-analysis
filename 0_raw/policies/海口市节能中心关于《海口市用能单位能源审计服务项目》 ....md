## 海口市节能中心关于《海口市用能单位能源审计服务项目》 询价比选公告

|     |     |     |
| --- | --- | --- |
| ![](http://drc.haikou.gov.cn/material/images/2018_tyxl_time.png) 2026-07-24 10:00:25 | 来源： 海口市节能中心 |  |

根据《中华人民共和国节约能源法》、《重点用能单位节能管理办法》、《海南省节约能源条例》、《海南省公共机构节能管理办法》的要求，为推动本市用能单位节能降碳，强化对用能单位的监督管理，提升用能单位能源利用效率和能源管理水平，降低能耗和碳排放强度，助力全市碳达峰工作，我中心将在近期组织开展能源审计，决定通过比选方式选取具备相应资质的能源审计服务机构，提供海口市能源审计服务。现欢迎各有关机构参与询价比选，我中心将对各机构上报的材料进行综合评定，本公告发布期限为5个工作日，请有意向机构在规定时间内准备并提交相关材料。

**一、项目名称：** 海口市用能单位能源审计服务项目

**二、服务内容：** 对市内3家用能单位开展2025年度能源审计，提出合理性节能降碳增效建议，并出具能源审计报告。

**三、服务期限：** 2026年7月-2026年10月底以前。

**四、预算金额：** 总额不超过2.4万元。

**五、申请人资格要求。**

1、具有独立承担民事责任能力的法人或其他经济组织（提供企业有效的营业执照副本复印件）(加盖公章)。

2、具有良好的商业信誉和健全的财务会计制度（提供承诺函原件或2025年1月至今任意3个月的单位财务报表复印件、格式自拟）(加盖公章)。

3、具有依法缴纳税收和社会保障资金的良好记录（提供承诺函原件或2025年1月至今任意3个月的纳税证明和社保缴费记录证明复印件、格式自拟）(加盖公章)。

4、具有履行合同所必需的专业技术能力，须满足：（1）提供近三年来单位承办类似项目的能源审计案例；（2）为本项目配备固定专职审计团队，每组不少于3名持证人员，均须提供能源审计师或相关专业工程师证书、近6个月本单位社保缴纳证明（提供证书及社保材料，并加盖公章）；（3）承诺项目执行期间不擅自更换核心人员，不转包、不分包、不临时拼凑人员。

5、参加本次采购近三年内（成立不足三年的从成立之日起算），在经营活动中没有重大违法记录的声明函原件 (加盖公章)。

6、未被列入信用中国网站 ( [www.creditchina.gov.cn](https://www.creditchina.gov.cn/))、中国政府采购网 ( [www.ccgp.gov.cn](https://www.ccgp.gov.cn/)) 渠道信用记录：“失信被执行人、税收违法黑名单、政府采购严重违法失信行为记录名单”(证明材料：提供本项目公告发布后在信用中国网站或中国政府采购网查询结果截图）。

7、项目方案。

8、报价书。

9、现场审计服务硬性要求（实质性条款）：（1）单家用能单位现场审计时间不少于1个完整工作日，严禁一天审计多家、压缩现场时长；（2）审计过程须留痕备查（现场签到、工作记录、影像资料等）；（3）中标后3个工作日内提交驻场人员名单，接受采购人审核与考勤。

10、业绩成果佐证材料：申请人可提供近3年内已完成的能源审计报告样本1份（公共机构或重点用能单位项目），用于评审报告编制质量与专业能力。电子光盘为 PDF 格式（隐去单位名称、涉密数据、商业秘密），编入响应文件电子文档；纸质版自愿提供简装本1份，不作强制要求。未提供者，仅在评审对应分值中不予得分，不按无效响应处理。

**六、提交文件要求**

所提交文件资料必须装订成册，放入密封袋中加贴封条，并在封套封口处加盖单位公章，封套上写明：海口市用能单位能源审计服务项目、单位名称、启封时间、联系人及电话。未按以上规定装订密封提交的文件，我中心将拒收。

**七、成交机构的确定**

审查递交响应文件机构的资格等条件符合要求后，从业绩经验、机构综合实力、项目需求响应情况、合理报价、服务方案、团队配置稳定性、专业人员配备、现场审计时长保障、报告样本质量等方面综合比较。未满足“每组≥3 名专职持证人员、单家单位现场审计≥1 个完整工作日、不转包不分包” 等实质性要求的，按无效响应处理。在同等条件下，对人员配置充足、服务响应高效、承诺规范执行现场审计标准的机构优先选择作为本项目的成交机构。在海口市发展和改革委员会网站发布公告（公告期限：5个工作日）。
