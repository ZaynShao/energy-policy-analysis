# 发挥新型储能作用构建新型电力系统——省能源局召开推进新型储能 ...

## 政策原文

发挥新型储能作用 构建新型电力系统——省能源局召开推进新型储能体系建设专题会

为深入贯彻国家构建新型电力系统决策部署，系统破解我省新型储能产业发展瓶颈，8月14日，省能源局组织召开新型储能体系建设专题会议。省能源局主要负责同志，国网青海省电力公司总经理和相关部门参会。

新型储能是青海构建新型电力系统的关键支撑，对推动青海能源绿色低碳转型和保障国家清洁能源产业高地建设具有不可替代的战略作用。省能源局，国网青海省电力公司将紧密协作、凝聚合力，一是围绕新能源发展、电网结构与负荷需求，前瞻规划储能类型、规模及时序，重点破解接入堵点，服务电网安全稳定与新能源高效消纳。二是优化调度释放储能潜力，建立适配储能的调用机制，优化调用策略与频次，加速推进参与电力现货市场，确保项目“应调尽调、能用尽用”。三是加快完善市场规则体系，突破准入、成本疏导与结算等环节壁垒，激发产业活力。

下一步，省能源局将按照省委、省政府工作部署，在省发展改革委党组领导下，牢固树立全省能源发展“一盘棋”思想，全力推动我省新型储能体系建设取得突破性进展，助力实现国家清洁能源产业高地建设目标。
