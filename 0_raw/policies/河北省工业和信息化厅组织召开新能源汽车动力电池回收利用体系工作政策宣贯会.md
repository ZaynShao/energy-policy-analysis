# 河北省工业和信息化厅组织召开新能源汽车动力电池回收利用体系工作政策宣贯会

发布时间：2026-06-18来源：节能与综合利用处,省工业和信息化发展研究院,信息宣传中心

6月12日，河北省工业和信息化厅在石家庄市举办新能源汽车动力电池回收利用体系工作政策宣贯会，进一步统一思想，提升相关部门及企业对动力电池产业的认识，用法治化手段规范废旧动力电池回收利用。工业和信息化部节能与综合利用司相关处室负责同志到会致辞。

![](https://gxt.hebei.gov.cn/hbgyhxxht/xwzx32/stdt65/2026061815163142427/2026061815154578273.png)

会议指出，要深入贯彻落实国家关于废旧动力电池回收和综合利用相关政策，健全工作机制、明确各方职责、抓住关键环节，协同推进全省废旧动力电池回收利用产业规范、安全、高效、绿色发展。会议邀请中汽数据有限公司研究员详细讲解了《新能源汽车废旧动力电池回收和综合利用管理暂行办法》，废旧动力电池贮存、运输、拆解及综合利用技术规范，以及“全国新能源汽车动力电池溯源信息平台”操作注意事项。

会议采取视频会议方式召开，省直相关部门、各市工业和信息化主管部门、电池生产企业、新能源汽车生产企业及其回收服务网点、电池综合利用企业等60余人在石家庄市现场参加会议，各市商务部门、报废机动车回收拆解企业代表近400人通过视频参加会议。
