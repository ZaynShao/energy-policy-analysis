# 关于发布国家生态环境标准《非道路移动机械环保信息公开技术规范》的公告

为贯彻《中华人民共和国生态环境法典》，持续改善环境空气质量，加强移动源管理，规范非道路移动机械环保信息公开，现批准《非道路移动机械环保信息公开技术规范》为国家生态环境标准，并予发布。

标准名称、编号如下：

[《非道路移动机械环保信息公开技术规范》（HJ 1493-2026）](http://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/dqhjbh/dqydywrwpfbz/202611/t20261105_1185603.shtml)。

本标准自2027年7月1日起实施。

标准内容可在生态环境部网站（http://www.mee.gov.cn）查询。

特此公告。

生态环境部

2026年10月21日
