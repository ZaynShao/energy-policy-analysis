# 对政协河北省第十二届委员会第五次会议第441号提案的答复

胡建昭委员：

您提出的“关于统筹我省能源安全与清洁能源发展的提案”已收悉，现答复如下：

“十四五”时期是开启全面建设社会主义现代化国家新征程、向第二个百年奋斗目标进军的第一个五年，也是我省加快建设现代化经济强省、美丽河北的关键五年，保障全省电力安全可靠供应至关重要，您的提案非常及时必要，我委进行了认真研究，结合您的建议，着力从以下几个方面统筹全省电力安全供应和清洁能源高质量发展。

**一、着力夯实电力保障基础，提升安全保供水平**

适应经济社会发展需要，统筹资源条件，加强托底保供能力建设，提高安全保供水平。一是积极扩大区外受电规模。加快推进已列入国家电力规划的蒙西—冀南、大同—怀来—天津南—天津北、张北—胜利等区外送电通道前期工作，按照国家总体要求部署，力争年内核准，2025年投产发挥作用，目前我委正在积极配合电规总院开展预可研研究，会同省电力公司、冀北电力公司组织开展换流站、变电站选址等相关工作的同时，积极与内蒙古等相关省份沟通接洽，共同全力推进。同时，研究论证山西、陕西等其他能源资源富集省份以大型电源基地形式送电河北，并支持省属企业参与区外送电电源点的投资和建设。二是着力提高电力自给水平。筑牢电力安全供应基础，按照“等容量、减煤量、减排放”原则，建设超超临界支撑电源或超临界热电联产项目，加快保热九期、邯热退城进郊替代等项目建设，力争2023年底前投产，加快陡河电厂、秦皇岛热电、廊坊热电二期扩建等项目前期工作，争取尽早核准开工。三是加快发展应急备用调峰电源。多渠道组织应急备用和调峰电源，有序淘汰煤电落后机组，鼓励符合环保、性能要求的煤电机组“关而不拆”，关停后作为应急备用电源，到2025年，形成1400万千瓦以上应急调峰能力。

**二、统筹清洁能源高质量发展，助力碳达峰目标实现**

着力构建可再生能源与其它能源发展相协调相匹配的新局面，大力推动全省能源绿色低碳转型。一是推进可再生能源高质量开发建设。优化发展方式，深入开发全省风光资源，按照规划引领、合理布局、因地制宜、有序开发的原则，统筹做好开发规模时序、电网建设衔接，推动实现倍增发展的同时，提高可再生能源开发效率。二是全面实施煤电机组调峰能力提升工程。优先提升30万千瓦级及以上煤电机组的深度调峰能力，按照纯凝工况调峰深度降至30%的标准，加快实施灵活性改造，到2025年调峰能力提高470万千瓦以上；完善相关支持性政策，鼓励煤电企业进一步增加机组深度调峰能力，调峰深度争取达到20%以下额定容量或国内同类机组最好水平。三是加快抽水蓄能电站建设。加快推动丰宁、易县、抚宁、尚义抽水蓄能电站建设，确保丰宁项目2025年全部建成投产，全省抽水蓄能装机达到487万千瓦；积极推进徐水、滦平、灵寿、邢台、阜平、隆化一期、迁西抽水蓄能电站前期工作，力争2025年前开工建设；继续谋划一批抽水蓄能站点选址，争取更多项目列入国家抽水蓄能中长期规划。四是加快推动新型储能及氢能应用。统筹规划建设新型储能，推动储能设施向电力系统发输配用各环节提供服务，推动电网侧储能合理化布局，加强电源侧储能配置管理，确保储能配置容量达到保障性、市场化项目要求，并与新能源项目同步建设、同步投产，提升系统灵活调节能力和安全稳定水平。积极发展氢能产业，充分发挥可再生资源优势，大力发展绿氢制备基地，强化氢能全产业链优势，推动氢能产业链联合技术攻关。

**三、整合用户侧灵活性资源，深入挖掘需求侧响应能力**

优化负荷侧资源，着力推动“发输储用”各环节协调发展，适应新型电力系统发展需要。一是推动将需求侧可调节资源纳入电力电量平衡，拓宽电力需求响应实施范围，建设运营需求响应市场，发挥市场在资源配置中的决定性作用，建立需求响应资金用户分摊机制，建设运营需求响应市场。二是组织省电力公司、冀北电力公司建设省级智慧能源服务平台，服务市场主体高效参与市场，计划2022年5月份模拟运行、6月份正式运行。三是建设产业生态，培育能效服务提供商、负荷聚合商、虚拟电厂等新型市场主体，提供专业化服务，引导工业可调节温控负荷、充换电站、智能家居等负荷进入市场，实现市场化削峰填谷。
