# 提振消费专项行动典型案例之十八 大理州洱源县：“电商+节庆”助力本地农产品消费_云南省发展和改革委员会

## 政策原文

编者按：消费是拉动经济增长的“主引擎”，也是民生幸福的“晴雨表”。2025年，全省大力实施提振消费专项行动，消费领域新产品、新业态、新模式不断涌现。各地结合发展优势积极实践，探索总结出一批提振消费“小切口”典型案例。现陆续推送，供学习交流、参考借鉴。

**大理州洱源县：“电商+节庆”助力本地农产品消费**

**一、案例背景**

近年来，大理州洱源县紧紧围绕“建设温泉康旅度假胜地，打造世界一流绿色食品牌示范基地”的发展目标，立足资源禀赋，以“政府搭台、电商赋能、节庆引流、全民共享”为核心思路，将节庆文化与电商模式深度融合，探索破解本地农产品“藏在深山人未识”的销售困境，构建起“产、销、品”协同发展的良性生态。

**二、主要做法**

（一）政府搭台，筑牢节庆电商保障基石

制定《洱源县电子商务发展规划（2022—2025）》《洱源县跨境电商工作方案》等政策文件，聚焦企业面临的痛点、难点、堵点问题，深入开展政策宣传、政策服务、政策兑现进经营主体活动，将大理宏福农业科技有限公司、大理天秀农业有限公司、洱源忆园家庭农场有限公司3家具有出口潜力的企业作为重点培育对象，不断提升外贸进出口体量和质量。

同时，以夯实县域流通基础设施、推动县域商业转型升级为主线，实施县域商业补短板、农产品上行、城乡物流体系建设3个项目，不断完善县域商业基础设施建设。建成电子商务公共服务中心与直播基地，提供免费直播空间、网络及设备支持，实施“带货主播”孵化计划与企业“互联网搭桥”服务，2024年，全县电商交易额突破1亿元。

（二）电商赋能，创新节庆农产品销售模式

一是“线上+线下”场景融合。节庆期间打造“主会场+分会场+云展厅”立体空间，线下在县城设置农产品展位、直播专区，开展产品品鉴、农事体验活动；线上整合中央及省、州（市）、县主流媒体网站、融媒体中心及微博、抖音、快手等多个新媒体平台联合直播。在洱源县凤羽镇举办的2025云南风吹稻浪音乐会共吸引全国4600万网民在线观看，全网观看量（阅读量）突破22亿次，其中，微博相关话题阅读量达20.3亿次，2个子话题成功登上微博热搜榜。同时，联合全县文旅企业推出“赏稻浪·泡温泉·游洱源”系列优惠活动，极大调动了企业的参与积极性，有效拉动了消费市场。

二是“达人+数字人”全域带货。建立“本土达人库+外部专家团”主播矩阵，筛选培育10多名“三农”达人，精选蝶泉牛奶、洱宝话梅、青梅爽、核桃、野生菌等多种名特优农产品，通过现场展示和趣味互动推向全国市场。“云南美好生活・2025 风吹稻浪”网络主题音乐暨直播带货活动中，主播丽江石榴哥单场直播2小时实现销售1200余单，推动多款“云品”热销。


“云南美好生活·2025风吹稻浪”网络主题音乐暨直播带货活动上主播正通过网络直播销售洱源的梅子酒、苹果等农特产品

三是“品牌+IP”价值提升。凌福苹果等9个品种获国家绿色食品A级证书，秀源农业“凤羽白米”以生态种植为基底打造高端品类，青梅产业依托“中国梅子之乡”IP，开发雕梅、青梅酒等非遗产品。同时通过多元业态融合，成功将文化流量转化为经济流量和产业动能。凤羽空中稻田剧场成为新晋网红打卡地，带动了当地乡村旅游发展，2025年国庆假期共有万余名游客到凤羽空中稻田剧场参观、拍照打卡。“梅果+乳业+电商”产业链进一步深化，2025年1—9月洱宝实业、秀源农业等企业订单量同比增长34%。活动还培育了大理小黑哥、大理大浩、白水等一批本土网络达人，为乡村振兴注入了新动能。

（三）节庆引流，放大农产品消费聚合效应

一是文化赋能强化吸引力。通过线上直播与线下体验联动，成功地将本地高原特色农业、自然人文生态与数字经济紧密结合，探索出“以文化人、以产富民、以媒塑形”的乡村振兴县域新范式，生动展示了洱源县产业兴旺、生态宜居、生活富裕的现代化新面貌。

二是全媒体宣传引爆热度。以田园为舞台、以稻浪为背景，洱源高原特色农业与数字经济深度融合的模式，取得了“小活动、大传播”的显著效果。2025年活动传播数据实现跨越式增长，全网观看量（阅读量）已突破22亿次，较去年增长107.5%；在线观看人数突破4600万人，较去年增长820%，并实现2个子话题登上微博热搜榜。

三是产销对接精准匹配。2025年2月组织9家电商企业参加“云上赏梅”专题活动；积极发动电商企业参加“线上三月街”“双品网购节”等线上活动，累计实现销售额约50万元；6月份组织5家企业及网络名人参加青梅采摘季直播带货活动，持续组织电商企业参加“双品网购节”“彩云电商消费券”等活动；9月底组织电商企业及网络达人参加“云南美好生活·2025风吹稻浪”网络主题音乐暨直播带货活动。通过线上线下的方式不断宣传推广全县农产品，建立供需合作关系，加快农产品“走出去”步伐，扩大了产品知名度。

**三、取得成效**

洱源县以节庆为切入点，依托电商重构农产品流通体系，实现本地农产品从“种得好”到“卖得好”再到“品牌响”的跨越。一是建立跨部门协同机制，将基础设施建设、政策扶持与节庆规划有机结合，为电商助农提供稳定保障。二是打破“节庆办会、电商卖货”的简单叠加，将“梅花文化季”“水上火把节”“风吹稻浪网络主题音乐暨直播带货节”等节庆转化为农产品销售的“黄金窗口”，通过场景融合、技术赋能、文化加持实现“1+1>2”的效果。三是依托品牌建设、供应链升级、产销对接，将短期热度转化为长期竞争力，推动农产品从“季节性热销”走向“全年常态化畅销”。2025年1—10月，电子商务交易额（网络交易额）累计达10422.83万元，同比增长5.4%，在大理州排名第四，成为县域电商助农的鲜活样本。
