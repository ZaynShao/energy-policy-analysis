# 省能源局电力处、国网山东电力发展策划部党支部联合开展“党建赋能 ...

## 政策原文

省发展改革委体改处、省能源局电力处、国网山东电力发展策划部党支部

联合开展“党建赋能山东电力市场建设综合改革试点”主题党日活动

为深入贯彻党的二十届四中全会精神，全面落实全国统一电力市场体系建设决策部署，12月29日，省发展改革委体改处、省能源局电力处、国网山东电力发展策划部党支部联合开展主题党日活动，进一步发挥党建引领作用，全方位、深层次融入山东省全国统一电力市场建设工作，为电力体制改革提供有力保障。

全体党员首先在山东电力交易中心观看全国统一电力市场省级示范区建设汇报片以及山东电力市场运营体系建设有关情况，重点学习了山东省打造电力市场规则制度体系、市场基本框架、特色交易机制、两级市场衔接、合规运营体系、团结治市文化6个方面“省级示范”的经验做法，我省完整稳定的电力市场构架初步建成。随后，全体党员又来到山东电力史迹馆，近距离领略了山东电力工业早期的艰难发展、先模前辈的奋斗足迹、户户通电工程的艰难险阻和代代传承的山东电建的铁军精神，深刻认识了山东电力人“自我加压、顽强拼搏、无私奉献、争创一流”的精神财富和艰苦卓绝、奋力前行的卓越之路。

大家一致表示，要以此次主题党日活动为契机，深入学习党的二十届四中全会精神，全面落实党中央、国务院关于加快建设全国统一电力市场的部署要求，紧盯国家电力体制改革动向，压实工作责任、出台务实举措、强化协同配合，建好全国主体类型最全、要素最完整的电力市场，确保改革红利惠及更多用户，为全国统一电力市场建设贡献山东力量。
