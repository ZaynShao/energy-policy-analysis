# “食”刻守护 快检护航 —— 霍邱县市场监管局筑牢高考食品安全防线

浏览次数：669信息来源：霍邱县市场监管局发布时间：2026-06-08 09:17

_字号：_大中小下载我要纠错打印收藏

为切实保障高考期间考生饮食安全，筑牢食品安全防护屏障，近日，霍邱县市场监督管理局启动高考食品安全专项快检行动，启用食品快检车进驻全县9个高考供餐点，以 “全覆盖、零死角、严排查”的标准，开展食品安全快速检测保障工作。

![](https://scjgj.luan.gov.cn/group4/M00/18/6B/wKgSHGomGSSAGYbcAA3cRPPE_YA915.png)

本次专项行动中，执法人员在各供餐点现场抽取食材样品，重点对水果、蔬菜、肉类等高频食用食材的农药残留、兽药残留、非法添加物等项目开展快速检测，实现风险隐患早发现、早处置。截至目前，累计检测食材48批次，所有样品检测结果均为合格，从源头有效防范了食品安全风险。

此次快检实现了全县高考供餐点位全覆盖，快速排查食材安全隐患，切实守住了考生“舌尖上的安全”。下一步，县市场监管局将持续压实监管责任，常态化开展巡查快检，同步强化供餐单位主体责任落实，全力保障高考期间食品安全形势稳定，为广大考生保驾护航。
