# 关于发布国家生态环境标准《难测试化学物质水生毒性测试技术指南》的公告

为贯彻《中华人民共和国生态环境法典》，规范难测试化学物质水生毒性测试工作，加强化学物质污染风险评估和管控，进一步建立健全新污染物协同治理和环境风险管控体系，现批准《难测试化学物质水生毒性测试技术指南》为国家生态环境标准，并予发布。

标准名称、编号如下：

[《难测试化学物质水生毒性测试技术指南》（HJ 1492-2026）](http://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/gthw/qtxgbz/202610/t20261023_1184567.shtml)。

本标准自2027年2月1日起实施。

标准内容可在生态环境部网站（http://www.mee.gov.cn）查询。
