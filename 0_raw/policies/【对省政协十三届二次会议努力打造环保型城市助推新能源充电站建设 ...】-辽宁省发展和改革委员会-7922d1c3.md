# 对省政协十三届二次会议努力打造环保型城市助推新能源充电站建设 ...

## 政策原文

来源：

发布时间：2024年08月29日

吴刚委员：

您提出的努力打造环保型城市 助推新能源充电站建设发展的提案收悉，现答复如下：

我省全面贯彻落实国家和省委省政府关于扩大新能源汽车消费、构建高质量充电基础设施体系工作部署，全力推动电动汽车充电基础设施建设。为加快电动汽车充电基础设施建设，编制了《辽宁省“十四五”电动汽车充电基础设施专项规划》（以下简称《专项规划》），加大充电设施建设力度，推动《专项规划》顺利实施，提升电动汽车充电保障能力。

以促进新能源汽车推广应用为出发点，提升电动汽车充电保障能力为目标，大力推进充电基础设施建设。截至2024年5月末，全省已建设充电设施终端10.9万个，比2023年底新增2.1万个，其中公共充电设施保有终端1.56万个，新增0.05万个；自用9.34万个，新增2.05万个，已超过“十四五”建设目标，初步形成了覆盖全省“适度超前、布局均衡、智能高效”的充电基础设施体系，推动电动汽车应用快速发展。

一、注重规划衔接

**一是**各地市以《专项规划》为引领，以区县为基本单元编制充电基础设施布局规划，以“两区”、“三中心”为重点，分场景优化充电基础设施结构，加强公用桩和专用桩布局，并纳入国土空间规划“一张图”监督信息系统。**二是**加强顶层设计，加大发展改革、自然资源、住房和城乡建设、交通运输等部门的协同力度，依据属地国土空间规划，推动与电网规划、综合交通规划一体衔接。省自然资源部门在各市国土空间总体规划中均对新能源汽车充电桩等配套设施建设预留发展空间，为住宅、商业、办公等场所按比例设置充电桩。

二、简化报建手续

各地住房建设部门、街道办事处（乡镇人民政府）、社区居委会加强对业主委员会的指导和监督，引导业主支持充电基础设施建设改造，统一改造居住（小）区停车场，建设安装充电设施。结合老旧小区改造，为用户充电创造条件。发挥物业服务企业积极作用，鼓励物业服务企业根据用户需求及业主大会授权，利用公共停车位建设相对集中的公共充电基础设施并提供充电服务

三、降低运营费用

实行用电价格优惠政策，明确已安装独立电表的充电设施实行大工业峰谷电价。各级电网公司高度重视充电设施配套电网建设服务工作，压减报装环节，对居民个人充电桩和低压公共充电桩，实行“三零”服务，报装流程压减至2个环节，高压公共充电桩报装流程压减至4个环节；压减接电时长，居民个人充电桩压减至5个工作日以内，公共充电桩压减至15个工作日以内；压减接电成本，充电桩项目配套电网工程接到红线外，并免费安装计量装置。

四、提供优质服务

省电力公司积极推进充电服务向智能化、数字化转型。按照“有序充电、车网互动”的宗旨，通过开展台区智慧用能服务平台建设，实现台区内电动汽车负荷的统筹管理和协调控制，提升台区用能服务智能化水平，提高台区用能效率，平抑台区负荷峰谷差，保障配电网稳定运行。

省内用户可通过国家电网“e充电”APP，精准定位充电站位置完成充电，每次充电根据“峰谷平”时段电费价格收取电费及服务费。加快引导充电服务商设施直联至车联网平台，对充电车辆数、充电时间、充电桩利用率等数据实时监测，提高结算准确性，提升车联网平台的服务能力。

五、出台支持政策

各地利用中央对充电设施的奖补资金，对作为公共设施的充电设施建设给予支持。沈阳、大连市出台了充电设施建设运营奖补办法，统筹利用中央奖补资金、市预算内资金，建立与服务质量挂钩的运营补贴标准，向充电设施优质场站倾斜。

下一步，将按照《专项规划》要求，充分吸纳您的建议，进一步加大工作力度，通过加快构建完善充电设施体系、合理提高电动汽车充电设施配置率、支持鼓励加强技术攻关等措施，持续推进新能源汽车充电设施建设，提升充电设施服务保障能力，打造环保型城市。

最后，感谢您对我省充电基础设施建设关心、重视、理解和支持。

辽宁省发展和改革委员会

2024年6月12日
