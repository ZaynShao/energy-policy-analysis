# 高气质”产品向世界展示宁德高质量发展新成果_ 市县 ... - 福建省发改委

## 政策原文

作为世界规模最大的车展，2019年法兰克福车展于本月12日至22日在德国法兰克福会展中心举行。电动汽车电池技术和制造领域的重要参与者、锂电巨头宁德时代为此次车展带去多项硬核技术，以其“高颜值”“高气质”的产品技术，向世界展示“宁德制造”高质量发展新成果。

关键词一

CTP电池

传统电池包采用的是从单体——模组——电池包的成组方式，多层级的成组方式会降低空间利用率，损耗电池能量密度，提质降本是全球所有电池企业都面临的问题。宁德时代在提升能量密度和降低电池成本方面找到了新路径。

此次宁德时代推出了全新的CTP高集成动力电池开发平台，即电芯直接集成到电池包。由于省去了电池模组组装环节，较传统电池包，CTP电池包体积利用率提高了15%-20%，电池包零部件数量减少40%，生产效率提升了50%，将大幅降低动力电池的制造成本。

同时，得益于内部结构的化繁为简，CTP电池包能量密度较传统电池包提升了10%-15%。传统的电池包能量密度平均为180Wh/kg，而CTP电池包能量密度可达到200Wh/kg以上。目前，宁德时代已经取得超70项CTP核心专利。

关键词二

超级快充

续航里程短、充电速度慢、残值低、安全差是电动汽车车主的使用痛点。宁德时代不断引领技术突破，直击用户痛点。

此次宁德时代针对市场需求量身定制的超级快充产品备受瞩目。宁德时代超级快充电池只需要15分钟，就可以充电80%。针对一些定制化需求，宁德时代还研制了9分钟内充满80%的涡轮充电解决方案。

关键词三

超长电池寿命

电池使用过程中的容量保持率也是用户最为关心的话题之一。为避免更换电池带来的成本增加及使用不便，宁德时代根据用户的不同使用场景，研发了匹配整车使用寿命的电池产品。

针对日常使用的私家车，电池可满足8年以上行驶需求；针对运营车辆，则提供可运营6年60万公里的长寿命电池产品，真正达到产品全生命周期无忧。长寿命的电池产品还可满足V2G，梯次利用等多元应用场景，从而提高电动汽车的经济性。

此外，宁德时代的自加热技术通过BMS电池管理系统识别电池状态，拟定速热控制策略，能够使电池温度在15分钟内从-20℃提升到10℃，充电能力提高5倍，放电能力提高7倍，从而让电池无惧严寒，维持最长的电池寿命。（记者 张文奎）

关键词四

动力安全

用户最为关心动力电池安全。宁德时代始终将安全作为企业的生命线，将安全作为产品开发的首要考虑。从产品设计、电芯制造、系统集成、BMS管理、售后服务、报废回收等建立了完整的安全保障体系。2017年7月，宁德时代的售后服务体系获国家五星级认证。同年成为工信部第一批的《锂电池行业规范条件》合规企业，越来越多国家层面的标准为宁德时代动力电池安全提供可靠有力的背书。

当前，以宁德时代为龙头的锂电新能源产业作为我市四大主导产业的重要一极，其领先的技术将为经济高质量发展提供更为强大的技术支持。宁德时代有关负责人表示，其正加快研发先进的电池技术，以科技创新为引领，拥抱全面电动化时代，驱动新能源革命。
