# 运行办赴陕西省电力负荷管理中心开展虚拟电厂平台建设工作调研

## 政策原文

运行办赴陕西省电力负荷管理中心开展虚拟电厂平台建设工作调研

来源：运行办
发布时间：2025-04-29

4月27日，委运行办赴陕西省电力负荷管理中心调研，听取省级虚拟电厂运营管理平台各模块功能讲解，针对虚拟电厂发展趋势和下一步重点工作进行了探讨交流，就得宝门虚拟“微电厂”示范项目运营成效、受限断面负荷管理创新应用场景构建等内容进行了充分沟通。

通过座谈交流，大家一致认为虚拟电厂将是电力市场的重要组成部分，对于构建新型电力系统具有积极作用，加快推进虚拟电厂平台建设，引导虚拟电厂接入平台参与电力市场各类交易，促进陕西电网“削峰填谷”意义重大。

下一步，委运行办将持续按照“换脑子、改作风、促发展”要求，立足全省能源运行管理职能，加强与陕西省负荷管理中心对接交流，通过强化科技赋能，探索“源荷互动”的智慧用电新模式，共同推进虚拟“微电厂”建设、受限断面负荷管理等关键技术，年内实现30万千瓦虚拟电厂灵活调节能力建设目标。为陕西打造“清洁低碳、安全充裕、经济高效、供需协同、灵活智能”的新型电力系统提供支撑。
