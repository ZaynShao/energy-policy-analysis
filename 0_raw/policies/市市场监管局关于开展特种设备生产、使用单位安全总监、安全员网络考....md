# 市市场监管局关于开展特种设备生产、使用单位安全总监、安全员网络考核工作的通知

###### 信息来源：深圳市市场监督管理局信息提供日期：2026-08-13 16:28 【字体：大中小 】 _视力保护色：_

各特种设备生产单位、使用单位：

根据市场监管总局颁布的《特种设备生产单位落实质量安全主体责任监督管理规定》（总局73号令）、《特种设备使用单位落实使用安全主体责任监督管理规定》（总局74号令）、《特种设备质量安全管理人员考核指南》、《特种设备使用安全管理人员考核指南》的相关规定，以及上级要求，为进一步提升我市特种设备安全生产管理水平，强化特种设备生产、使用单位安全生产主体责任落实，增强本辖区内特种设备生产、使用单位的安全负责人、（质量）安全总监、（质量）安全员的专业素养与应急处置能力，我局将组织开展特种设备生产、使用单位安全负责人、（质量）安全总监、（质量）安全员网络考核工作，现将有关事项通知如下：

一、特种设备网络考核目的

1.落实特种设备生产单位、使用单位企业安全主体责任。

2.增强特种设备生产、使用单位安全负责人、（质量）安全总监、（质量）安全员专业素养及应急处置能力。

二、特种设备网络考核对象

全市在我局“特设e管”小程序中登记注册的所有特种设备生产、使用单位安全负责人、（质量）安全总监、（质量）安全员。

三、特种设备网络考核内容

按照《特种设备生产单位质量安全总监和质量安全员考试指南》（TSG Z0007-2023）、《特种设备使用单位安全总监和安全员考试指南》（TSG Z0008-2023）要求编制考试题库，题库涵盖锅炉、压力容器、气瓶、压力管道、电梯、起重机械、客运索道、大型游乐设施、场（厂）内专用机动车辆9类特种设备的通用要求、风险控制、应急处置、事故处理、专业知识等内容。

四、特种设备网络考核平台开放时间及网络考核时限要求

1.特种设备网络考核平台自2026年8月10日起开放，各特种设备生产、使用单位安全负责人、（质量）安全总监、（质量）安全员可进入平台进行自学、自测及网络考核。

2.各特种设备生产、使用单位安全负责人、（质量）安全总监、（质量）安全员网络考核工作需在2026年11月30日前完成。

五、特种设备网络考核平台登录方式

参考人可通过以下三种方式登录特种设备网络考核平台：

1.搜索微信公众号“深圳市场监管”关注公众号，在“政民互动”选择“特种设备网络考核”登录。

2.可扫描本通知附件内二维码登录。

3.我局委托东莞市理工软件公司代发出短信或电话通知，各特种设备生产、使用单位安全负责人、（质量）安全总监、（质量）安全员如果有收到短信通知，点击短信中的链接登录。

建议使用第1种方式，参考人如对本次考核有任何问题需要咨询可直接在“特种设备网络考核”平台上联系客服。

六、特种设备网络考核的组织与实施

1.各特种设备生产、使用单位安全负责人、（质量）安全总监、（质量）安全员如果在我局“特设e管”小程序已绑定相关信息，可以直接输入手机号码进入特种设备网络考核平台。如果在我局“特设e管”小程序信息发生变化或存在缺失的，参考人需要在考核平台联系客服补齐相关资料。

2.特种设备网络考核平台的题库按照特种设备专业类型向参考人公开，学习和考核不收取任何费用。

3.特种设备网络考核是按特种设备种类和从事的岗位进行，如参考人员兼任多类特种设备岗位，需要进行多次网络考核并合格。比如：张三在A单位兼任电梯设备安全总监岗位、安全员岗位和锅炉设备安全员岗位，则张三需要进行一次电梯类设备的安全总监岗位考核、一次电梯类的安全员岗位考核、一次锅炉类设备的安全员岗位考核，共3次。

4.特种设备网络考核采用开卷、理论考核方式，可以查阅纸质资料，但不得使用电子辅助设备作答。

5.参考人自学、自测完成之后，可以根据从事的岗位和特种设备种类进行网络考核，参考人需要在15分钟内完成系统随机抽取的20道题目，答对90%以上为合格。考核不合格的可在5个工作日内申请补考。

七、特种设备网络考核结果处理

1.参考人网络考核合格后，特种设备网络考核平台自动生成年度《2026年特种设备在线学习考核证明》，参考人可下载保存证明文件，监督检查时可出示本年度在线学习考核证明。

2.参考人网络考核补考不合格，用人单位需进行整改，调整参考人岗位，不能继续任职。

八、请各特种设备生产、使用单位高度重视，积极组织相关人员参加特种设备网络考核工作，提高特种设备安全管理水平。

九、受深圳市市场监管局委托，由东莞市理工软件有限公司承担特种设备网络考核平台技术支持、系统使用咨询、对所有参考人进行电话或短信等通知、考核过程跟踪、考核结果公布、考核情况的汇总、统计分析等工作。

特此通知。
