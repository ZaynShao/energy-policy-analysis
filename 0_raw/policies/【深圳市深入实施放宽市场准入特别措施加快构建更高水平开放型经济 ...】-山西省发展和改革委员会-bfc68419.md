# 深圳市深入实施放宽市场准入特别措施加快构建更高水平开放型经济 ...

## 政策原文

来源：深圳市发展和改革委员会 发布时间：2026年2月9日

经党中央、国务院同意，2022年1月，国家发展改革委、商务部印发《关于深圳建设中国特色社会主义先行示范区放宽市场准入若干特别措施的意见》，在科技、金融、医疗、教育文化、交通和其他等六大领域提出24条具体措施，支持深圳围绕放宽市场准入，积极探索更加灵活、更加科学的政策体系和管理体制。获批实施以来，深圳市紧紧抓住国家赋予的重大机遇，围绕战略性新兴产业、未来产业重点领域和重大生产力布局，以法规政策、技术标准、检测认证、数据体系为抓手，在重点领域率先突破，持续破除准入壁垒，优化市场准入环境，创新支撑高质量发展的体制机制，不断激发各类市场主体发展活力与创造力。

一是推动降槛扩增，激发经营主体活力。积极推动电子元器件和集成电路国际交易中心做大做强，高标准建设深圳数据交易所，揭牌成立国际先进技术应用推进中心（深圳），为上下游企业搭建起高效便捷的资源对接平台，畅通要素流通渠道、赋能产业协同发展。创新推出“鹏农贷”，为涉农企业搭建“一点对全国”“一点对全球”的农产品供应链金融服务体系，累计提供支持427亿元，以金融活水助力服务新发展格局。制定低空经济创新发展行动方案，发布低空经济标准体系2.0及标准化路线规划，累计建成各类型低空起降点1284个，有效支撑物流配送、载人飞行、应急救援等商业化运营，充分释放产业发展潜能。

二是强化试点示范，典型经验全国推广。基础设施REITs领域实现多项突破，取得全国基础设施REITs首批试点数量第一、首批覆盖领域第一、首单清洁能源REITs、首单保障性租赁住房REITs，深圳安居REIT和深圳港REIT扩募项目被列为国家发展改革委盘活存量资产扩大有效投资典型案例在全国推广。率先启动“超充之城2.0”建设，累计建成超充站超1098座、充电设施53.6万个，构建起全域覆盖、高效便捷的充电服务网络，成功入选国家车网互动规模化应用试点城市，通过多场景车网互动示范，建成国内可调能力占负荷比重最高的城市虚拟电厂并入选2025年“全球能源互联网十大引领工程”。

三是注重融通国际，提升国际竞争力。推动香港大学深圳医院成为“港澳药械通”首家试点，全市17家医疗机构实现“港澳药械通”政策覆盖，累计获批进口药器械达80种，打通国际先进药械进入内地临床应用快速通道。发布《前海绿色建筑评估标准》，为粤港澳大湾区首个实现深港标准联通的绿色建筑评估体系。开展跨境贸易高水平开放便利化试点，前海合作区累计166家优质企业纳入跨境贸易高水平便利化试点，办理便利化收支金额超270亿美元。推动首批境外不落地购汇业务、首批开展取消人民币资本金专户业务、首次实现前海联合交易中心大宗商品跨境交易以人民币计价结算等便利化举措落地。打造国内首个、目前唯一的河套“1+6”国际性产业与标准组织聚集区，编制推广我国首部国际医院评审认证标准——《国际医院评审认证标准（中国）》（CIHA），高分通过ISQua权威认证，评审覆盖17省市80余家医院，12家境内外医院（包括4家香港医院）通过认证。
