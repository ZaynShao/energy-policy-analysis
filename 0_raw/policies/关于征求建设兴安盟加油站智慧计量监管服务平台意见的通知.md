# 关于征求建设兴安盟加油站智慧计量监管服务平台意见的通知

征集部门：兴安盟市场监督管理局征集开始时间：2025-08-30 09:29:28征集结束时间：2025-09-30 09:29:28状态：-

字体大小：A+AA-![](https://www.xam.gov.cn/uiFramework/commonResource/image/2024081515212564064.png)打印

各有关单位：

为深入贯彻落实《国务院办公厅关于推动成品油流通高质量发展的意见》(国办发〔2025〕5号)和《自治区市场监督管理局贯彻落实〈市场监督管理总局关于支持内蒙古贯彻落实习近平总书记考察内蒙古重要讲话精神高质量完成“五大任务”的实施意见〉重点任务分工清单的通知》（内市监综发〔2023〕44号）等文件精神，进一步加强全盟成品油市场监管，有效防范加油机计量作弊等行为，保护消费者合法权益，盟市场监督管理局拟在全盟范围内建设加油站智慧计量监管服务平台，推动成品油市场监管数字化、精准化、智能化。现向社会公开征求意见。

请各有关单位和社会公众于本通知发布之日起30日内，通过指定邮箱反馈意见建议。逾期未反馈的，视为无异议。
