# 重庆市发展和改革委员会关于市五届人大五次会议第0630号建议办理 ...

## 政策原文

重庆市发展和改革委员会关于市五届人大五次会议第0630号建议办理情况的答复函

陈晓兵代表：

您提出的《关于建设以纯电动汽车为核心的储能和光、储、充一体化的智慧能源系统网络建议》（第0630号）收悉。经与市经济信息委共同研究办理，现答复如下：

一、我市具备以纯电动汽车开展储能的条件

截至2021年底，全市电动汽车保有量13.7万辆，占全市机动车总量的2.72%，其中电动私家车6.87万辆，占全市电动汽车保有量的50.2%。全市累计建成充电站2080座，建成公共和居民自用充电桩4.99万个，充电桩总数同比增长41%。全市38个区县（自治县）均已布局充电设施，全市138个高速公路服务区已布局建设充电站，中心城区充电服务平均半径1公里，处于西部领先水平。全市现有充电基础设施总体上能满足当前电动汽车发展需求。据测算，2025年全市纯电动汽车将达到50万辆，年充放电量突破20亿千瓦时。我市用电高峰主要在白天，而居民自用充电则多集中在夜间，能起到一定削峰填谷作用。

二、我市将加快推动光、储、充一体化智慧能源系统建设

目前，我市正积极开展车—桩—网互动试点，已将车—桩—网互动、虚拟电厂、储能互动等新模式示范应用纳入了《重庆市充电基础设施“十四五”发展规划（2021—2025年》；市财政局、市经济信息委已印发《2022年度新能源汽车与充换电基础设施财政补贴政策》（渝财规〔2022〕3号），其中明确对居民小区“统建统营”交流充电桩及小功率直流充电桩给予倾斜性建设补贴，将为推动建设居民小区有序充电桩群、形成以电动汽车为核心的，具备用电负荷“削峰填谷”作用的一体化负荷聚合商创造有利条件。

下一步我市将创造条件推动以电动汽车为核心的光—储—充智慧能源系统建设。积极推动国家工信部等有关部门在电动汽车行业标准修订中充分考虑未来车载电池向电网返送电力的应用场景需求；推动居民小区智能有序充电桩建设，研究出台鼓励配建光伏、储能的支持性政策；研究制定全市新型储能示范应用实施方案，将重点鼓励电动汽车、充换电设施等用户侧分散式储能聚合利用，形成源网荷互动；研究完善我市电力市场交易机制，抓紧推动储能、负荷聚合商以独立市场主体资格参与交易，推动实现合理的辅助调峰收益。

衷心感谢您对我们工作的关注和支持，此答复函已经我委董建国主任审签。对以上答复的意见，请您及时通过填写回执反馈市人大常委会人代工委。
