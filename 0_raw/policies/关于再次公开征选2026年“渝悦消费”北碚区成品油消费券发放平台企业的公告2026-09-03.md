关于再次公开征选2026年“渝悦消费”北碚区成品油消费券发放平台企业的公告


![](https://www.beibei.gov.cn/material/PcWapStyle/imgs/bg_guidang_tb.png)

日期：2026-09-03来源：区商务委![](https://www.beibei.gov.cn/material/PcWapStyle/imgs/yjtc_img_fontdx2.png)_大_ _中_ _小_

![](https://www.beibei.gov.cn/material/PcWapStyle/imgs/ico_dayin.png)![](https://www.beibei.gov.cn/material/PcWapStyle/imgs/ico_weixin.png)![](https://www.beibei.gov.cn/material/PcWapStyle/imgs/ico_weibo.png)

    根据我委公开挂网的《关于公开征选2026年“渝悦消费”北碚区成品油消费券发放平台企业的公告》，由于在规定时间内未收到符合要求数量的企业报名材料，为做好北碚区2026年“渝悦消费”成品油消费券发放工作，现再次向全社会公开遴选消费券发放平台企业，现将相关内容公告如下：

一、入选平台企业工作任务

（一）制定消费券发放具体实施工作方案。

（二）加强风险监测。完善风险管控机制，防范和阻止外挂软件虚构信息领券、消费券套现等不法行为发生，若有前述情形或迹象，应当及时报告、有效处理，保障资金安全。

（三）充分调动和利用平台企业资源，加大宣传力度，提高消费者知晓率及参与度。

（四）组织专业服务团队，受理解决消费券发放、使用过程中的咨询、投诉等相关问题，及时回应社会关切，确保消费券发放平稳有序。

（五）主动接受政府部门监督管理，及时提供消费券发放相关情况，包括消费券发放数据、核销数据及分析报告等相关信息，主动接受审计，开展绩效评估等工作。

二、入选平台企业具备的条件

平台应依法注册并合法经营，具备资金支付、数据核对和自动化监控、防治集中套取（套刷）等功能，有相关项目的实施经验。对参与商户、交易数据、核销进程等情况进行全过程监测和监管。

三、报名时间

2026年9月3日至9月9日。（逾期不予受理）

四、材料报送

报名资料须采用信封包装并密封。信封上注明项目名称、供应商名称等字样。信封的封口应加盖供应商公章或法人授权代表签字。报名资料包括如下内容：

（一）消费券发放方案。具体内容包括评审标准中涉及的相关内容。

（二）平台认为需要提供的其他佐证材料。

五、评审标准

|     |     |     |     |
| --- | --- | --- | --- |
| **序号** | **评分因素及权值** | **分值** | **评分标准** |
| 1 | 消费券发放方案 | 100分 | 1.平台规模（10分）。按照北碚区注册商户数量多少，横向比较从高到低分别得分。优：10分，良：7分，一般：4分，未提供：0分。 |
| 2.商户入驻便捷性（20分）。可提供简洁的商户入驻平台手续，对入驻商户不收取任何佣金，不额外收取费用的，得20分。 |
| 3.消费者消费便捷性（20分）。可发放现金红包，可绑定任意银行卡的，得20分。 |
| 4.宣传渠道的广泛性（20分）。可提供的宣传途径、物料设计等，横向比较打分。优：15（含）分-20分，良：10（含）分-15分，一般：10分以下。未提供：0分。 |
| 5.人员保障的充足性（20分）。有专门的消费券发放团队，得20分。 |
| 6.风险防控的专业性（10分）。有专业的风险防控团队，提供数据分析报告等材料，并能配合做好审计等，得10分。 |
| 2 | 加分<br>部分 | 不超过5分 | 2021年以来，参与过政府消费券发放的平台，每一次加1分，最高不超过5分。 |

六、资料提交方式

请符合要求的意愿企业按照入选条件，于2026年9月9日18：00前将上述材料提交到区商务委304室。联系人：陈老师，联系电话：68863649。
