# 陕西省发展和改革委员会陕西省市场监督管理局关于进一步加强售电 ...

## 政策原文

国网陕西省电力有限公司、陕西电力交易中心有限公司、各售电公司、有关经营主体：

为进一步打造公平公正市场环境，引导售电市场规范运营秩序，强化售电公司合规经营，保障各类经营主体合法权益，现就进一步加强售电市场规范运营有关事项通知如下。

**一、提高思想认识，维护市场稳定**

随着陕西电力现货市场进入连续结算试运行，售电公司作为连接发电侧与用户侧的桥梁，与电力用户签订零售合同，为用户提供售电和增值服务，在促进售电侧改革落地实施、释放市场活力方面发挥着重要作用。各售电公司需从电力市场化改革全局出发，深刻认识自身职责。一是明确角色定位。切实发挥 “政策传递、服务落地、风险缓冲”作用，既要推动改革红利向用户侧传导，也要协助防范市场价格异常波动、用户用电偏差等风险。二是强化责任意识。将“诚信经营、合规交易”纳入企业核心经营准则，定期开展政策学习与风险自查。三是聚焦用户服务。以“降本增效、保障供电” 为目标，结合合作用户行业特性提供差异化用能方案，不得因市场波动推诿服务责任，共同推动电力市场从规范运营向优质运营升级。

**二、依法合规经营，保障服务质效**

（一）严格执行电力交易政策规则。售电公司要加强对有关法律、交易规则的学习领会，严格遵守中华人民共和国《电力法》《反垄断法》《价格法》及《电力市场运行基本规则》《售电公司管理办法》《电力市场监管办法》等法律法规规定，依规开展市场注册、市场交易。不得提供虚假或伪造材料，按要求持续满足注册条件；不得通过虚假宣传，诱导、误导电力用户注册入市、违规代办，禁止在用户非真实意愿下获取用户电子营业执照授权，在用户不知情情况下将其用于企业管理员授权、电子合同签订、套餐变更等，导致用户权益受损。

（二）切实履行应有责任与义务。售电公司应尽到告知义务，向零售用户准确宣传政策规则，提供真实、准确、全面的市场信息。与用户签订零售合同时，主动告知电力用户登录交易平台签约，保证用户充分知悉交易价格形成机制、入市交易风险及市场价格信息获取途径等内容，不得对用户进行虚假营销宣传或作出虚假承诺。要为电力用户提供优质服务，满足用户合理诉求，提高交易能力、技术水平，综合施策优化用户用能方案，降低用户用能成本；如遇投诉举报，积极主动配合问询，不得进行虚假性、误导性陈述或提供虚假材料。

（三）持续规范企业管理与运营。禁止不正当价格行为，售电公司不得与发电企业签订阴阳合同，损害用户利益，不得与用户签订明显低于市场均价的合同，降低自身零售侧均价，损害其他签约用户利益。不得与转供电主体串通签订明显高于市场均价的合同，损害最终用电户利益；要规范开展售电业务，直接对接服务零售用户，与用户签订零售合同，开展注册入市、合同调整、政策告知等服务。发售一体的售电公司要确保发电业务与售电业务在人员、财务、信息等方面的独立性，严禁利用“发售一体”关联关系操纵市场价格，进行不正当竞争。

**三、强化协同监管，优化服务保障**

（一）提升服务水平。国网陕西省电力有限公司要持续加强四级服务体系建设，依托营销专业队伍推进电力市场穿透式服务，重点针对用电量较小、用电价格不敏感的小用户，持续加强政策宣传和市场行情信息传递，切实向用户提供政策告知、价格行情、用电咨询等各类服务。

（二）防范市场风险。陕西电力交易中心要严格履行市场监测和风险防控责任，提高交易风险辨识能力，加强经营主体行为监测，及时发现违反交易规则、扰乱市场秩序行为，完整记录并报告省发展改革委及相关监管部门，依法依规采取必要的干预措施，针对违反政策规则的行为及时制止；经省发展改革委或监管部门认定的违规行为、市场干预情况向市场主体通报，防范更大市场风险。遇重大政策变化，出现异常交易价格，向相关主体发送提示书和告知函。要加大对零售高价售电公司、新增批发交易高价售电公司、高批零价差售电公司披露力度，增强市场透明度和公平性。要面向市场主体做好政策宣贯，提供必要的业务指导和服务，引导市场主体合规参与交易。

（三）规范经营行为。售电公司要严格落实本通知要求，树立合规经营理念，依法依规参与市场交易，切实履行自身责任与义务，通过加强专业服务水平、技术创新能力，持续提升企业核心竞争力，促进我省电力市场健康有序发展。

（四）净化市场环境。省发展改革委、省市场监督管理局将发挥部门协同监管机制作用，指导各地持续加大电力交易市场监督检查力度，依法严厉查处串通涨价、哄抬价格、价格欺诈等违法违规行为，严惩虚假宣传、商业贿赂等不正当竞争行为，对性质恶劣、情节严重的典型案例，及时公开曝光，形成有力震慑。通过部门联动、多措并举，进一步规范全省电力交易市场秩序，维护诚实守信、公平竞争市场环境。
