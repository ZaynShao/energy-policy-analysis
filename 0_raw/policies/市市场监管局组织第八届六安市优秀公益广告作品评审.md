# 市市场监管局组织第八届六安市优秀公益广告作品评审

浏览次数：1833信息来源：广告科发布时间：2025-11-10 16:00

_字号：_大中小下载我要纠错打印收藏

11月9日，六安市市场监管局邀请广告传媒行业相关专家学者、优秀从业人员，对征集的第八届六安市公益广告作品进行评审。

![](https://scjgj.luan.gov.cn/group4/M00/16/C4/wKgSHGkRnimAUuLFAAEB95kGEjQ860.jpg)

此次公益广告征集推选活动由市市场监管局、市文明办、市教育体育局、市文化和旅游局、市城管局联合举办，市广告协会具体承办。活动主题为“创益无限 皖美六安”，作品范围以彰显时代华章，树立文明新风，突出六安地域特色,体现乡村振兴成果、红色文化底蕴，展示六安市场监管成就、城市发展成就，宣扬法治护航等方面为主要内容，形式包括平面和视频两个类别作品。各企事业单位、普通高校以及社团组织等热心公益广告事业的单位和个人均可报名参加。

![](https://scjgj.luan.gov.cn/group4/M00/16/C4/wKgSHGkRnkqAXmLjAAEbFYbZY6A945.jpg)

活动自9月1日启动以来，各高校、部分中小学校、广告企业、社会人士积极参与了投稿，截止10月31日，共征集到平面类公益广告作品192件，视频类公益广告作品21件，所征集作品数量及质量较往届均为较大提升。评选出的优秀作品在公示后再向社会公布。
