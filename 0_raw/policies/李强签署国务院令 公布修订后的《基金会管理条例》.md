# 李强签署国务院令 公布修订后的《基金会管理条例》

**李强签署国务院令**

**公布修订后的《基金会管理条例》**

新华社北京11月10日电 国务院总理李强日前签署国务院令，公布修订后的 [《基金会管理条例》](https://www.gov.cn/zhengce/content/202611/content_7085661.htm)（以下简称《条例》），自2027年1月1日起施行。

《条例》旨在加强基金会公信力建设，促进基金会健康有序发展。《条例》共8章79条，修订的主要内容如下。

一是完善总体原则要求。明确基金会工作坚持中国共产党的领导，强化党建工作要求，规定基金会从事公益活动应当遵循合法、自愿、诚信、公开、透明、非营利的原则。

二是健全登记管理制度。明确登记管理层级和注册资金，稳妥推进直接登记，明确变更登记程序要求，细化注销前清算程序。

三是完善内部治理机制。强化发起人、负责人责任，健全组织机构职权及议事规则，禁止负责人、理事、监事等利用关联关系损害基金会、受益人的利益和社会公共利益。

四是规范活动管理。完善募捐、捐赠、资助等活动要求，对互联网公开募捐、合作公开募捐进行规范。加强财产管理，明确收益应当全部用于公益目的。严格项目管理，要求对项目实施情况跟踪管理。

五是加强信息公开和行业自律。明确基金会信息公开义务，畅通社会监督渠道，建立健全行业规范。

六是强化综合监管。明确登记管理机关、业务主管单位和行业管理部门等的职责，压实各方责任，形成监管合力。
