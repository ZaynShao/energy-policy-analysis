# 辽宁绿源配售电有限公司与国网辽宁省电力有限公司签订增量配电 ...

## 政策原文

来源：省发展改革委

发布时间：2019年01月23日





1月15日，大连瓦房店市增量配电改革试点项目业主--辽宁绿源配售电有限公司与国网辽宁省电力有限公司在瓦房店市举行签约仪式。

该项目为首批增量配电改革业务试点，项目位于瓦房店市西部的三台子新材料工业园区，面积12.98平方公里，一期规划建设220千伏变电站一座，内建4台220千伏变压器，总投资36,411万元。

在我委大力推动下，在国网辽宁省电力有限公司公司积极参与和支持下，项目进展总体顺利，已于2018年7月开工建设，2018年8月28日，取得全国首张民营控股的配售电公司电力业务许可证（供电类），预计于今年8月份建成投运。

电力体制改革是党中央、国务院根据电力快速发展和发展中面临的问题，所做出的重大决策部署。鼓励社会资本投资增量配电业务，对促进电网的建设与发展，提高配电网的运营效率和服务质量具有重要意义。

国网辽宁省电力有限公司与辽宁绿源配售电有限公司成功签约，既是贯彻落实中央电力体制改革重要精神的具体行动，也是双方深化合作、整合资源的选择，对于纵深推进售电侧改革试点、加快释放改革红利、发挥示范引领作用具有重要的里程碑意义，必定开启我省增量配电改革试点项目的新篇章。合作双方将坚定开放发展理念，本着平等互利、合作共赢的原则，发挥各自优势，以服务地方经济发展为己任，加快研究改革试点电价形成机制，最大限度降低园区企业的用电成本，为园区企业提供高效、安全、稳定的用电保障，为园区高质量发展提供坚强的能源支撑和优质的电力服务。

省、市发展改革委，国家能源局东北监管局相关部门负责同志和瓦房店市政府主要领导出席并见证签约仪式。
