养老机构安全有了“硬杠杠”

市市场监管部门宣贯培训新标准

2026-11-14 07:58来源：石家庄日报

|     |     |     |     |     |     |
| --- | --- | --- | --- | --- | --- |
| 发布时间：2026-11-14 07:58 | 来源：石家庄日报 | 【字体： [大](https://www.sjz.gov.cn/columns/b1855634-b82b-436a-bca6-ffeca1413036/202611/14/03deee76-631a-40b1-8fb6-24b68dcff666.html#) [中](https://www.sjz.gov.cn/columns/b1855634-b82b-436a-bca6-ffeca1413036/202611/14/03deee76-631a-40b1-8fb6-24b68dcff666.html#) [小](https://www.sjz.gov.cn/columns/b1855634-b82b-436a-bca6-ffeca1413036/202611/14/03deee76-631a-40b1-8fb6-24b68dcff666.html#) <br>】 | ![](http://www.sjz.gov.cn/atm/1490064706815/20170629193031397.png) | 打印 |  |

11月11日，市市场监督管理局组织全市养老机构主要负责人举办《养老机构基本规范》《养老机构重大事故隐患判定准则》宣贯培训，进一步推动新版强制性国家标准落地实施，切实保障老年人合法权益，促进养老服务高质量发展。

近期，市场监管总局会同民政部制定并发布了《养老机构基本规范》《养老机构重大事故隐患判定准则》两项强制性国家标准，聚焦养老机构运营、服务安全的关键环节和核心要素，织密养老机构的安全网。两项标准将于2027年8月1日起实施，过渡期1年。

培训邀请专家对这两项强制性国家标准，进行深入解读。《养老机构基本规范》对养老机构从设立、运营到退出的全周期应具备的安全与服务质量划出了底线。标准针对养老机构的选址与建筑、设施与设备、入院出院管理、基础服务、安全管理、运营管理、评价与改进等7个方面，系统提出了90项具体要求，给养老机构合规运营画了一条清晰的底线，什么事必须做、做到什么程度，一目了然。

《养老机构重大事故隐患判定准则》在总结全国养老机构安全管理经验的基础上，明确了养老机构重大事故隐患的判定程序，重点根据事故隐患危险程度，将养老机构可能存在的重大事故隐患划分为25条直接判定要素、28条综合判定要素和2类排除情形共三种判定规则。这套规则既科学又实用，帮助一线管理人员迅速“对号入座”，精准识别风险，不再靠经验“拍脑袋”，让隐患排查有了“铁规矩”。

下一步，市市场监督管理局将联合市民政部门积极推进两项强制性国家标准宣贯工作，指导养老机构学懂弄通、执行到位，把养老服务的“安全网”织得更密、兜得更牢。
