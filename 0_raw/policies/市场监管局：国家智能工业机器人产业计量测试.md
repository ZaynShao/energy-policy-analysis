| 市场监管局：国家智能工业机器人产业计量测试联盟在常成立 |
| 发布日期：2026-07-14  来源：市场监管局浏览次数：  字号：〖默认大超大〗 AI智能导读 |

|     |     |
| --- | --- |
| 近日，国家智能工业机器人产业计量测试联盟在常州科教城揭牌成立。联盟通过整合全国智能工业机器人领域产学研检用优势资源，构建跨区域、跨学科、跨行业的协同创新平台，为产业高质量发展夯实计量测试根基。<br>联盟由常州检验检测标准认证研究院牵头组建，首批成员单位51家，汇聚全国范围内智能工业机器人产业链上下游的各类优势单位，涵盖企业、检测机构、研究机构、行业协会、高等院校、认证机构等。联盟秘书处设在常州检标院。<br>当前，常州已集聚智能工业机器人相关企业200余家，产业规模突破300亿元，形成了从关键零部件、整机制造到系统集成、行业应用的完整产业链。全市主导、参与制定机器人相关标准20余项，在性能检测、校准服务及可靠性评价等方面形成特色优势。<br>计量测试是保障产品质量、推动技术创新的关键支撑。联盟将聚焦产业全溯源链、全生命周期、全产业链的计量测试需求，组织制定产业亟需的技术标准，推动计量测试与智能机器人产业深度融合，向“测不了、测不全、测不准”的技术壁垒发起联合攻关。<br>扫一扫在手机打开当前页<br>![](https://www.changzhou.gov.cn/tools/generate_qr.php?data=https%3A%2F%2Fwww.changzhou.gov.cn%2Fns_news%2F846178399824871) |
