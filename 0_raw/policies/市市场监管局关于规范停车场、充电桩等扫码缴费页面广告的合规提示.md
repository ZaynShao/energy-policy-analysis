# 市市场监管局关于规范停车场、充电桩等扫码缴费页面广告的合规提示

浏览次数：116信息来源：广告科发布时间：2026-07-13 15:09

_字号：_大中小下载我要纠错打印收藏

为规范我市停车场、充电桩等扫码缴费页面广告发布行为，维护公平有序的市场环境，保障消费者的合法权益，依据《中华人民共和国广告法》《互联网广告管理办法》等法律法规的规定，现对全市相关经营主体作合规提示如下：

一、广告内容的合规要求

1.广告应当真实、合法，不得以虚假或者引人误解的内容欺骗、误导消费者。

2.广告应当以健康的表现形式表达广告内容，不得含有淫秽、色情、赌博、迷信、恐怖、暴力，以及民族宗教、性别歧视、妨碍社会公共秩序或者违背社会良好风尚的内容。

3.广告应当具有可识别性，能够使消费者辨明其为广告，利用扫码缴费页面发布广告应当显著、清晰标明“广告”字样，字体清晰、位置突出。

二、广告设置及关闭功能的规范要求

1.扫码缴费页面广告不得干扰正常的缴费流程，广告按钮位置不得紧邻缴费按钮，且不得设计与缴费按钮相似，防止消费者在缴费时误点。

2.不得在广告中使用与当前扫码缴费业务模糊关联、模棱两可的文字内容，刻意隐蔽关闭按钮，突出展示勾选控件，诱导消费者误将附加勾选当作办理当前业务的必要流程，造成误勾选、误操作，进而引发无故扣费。

3.不得利用广告遮挡、覆盖付费页面的核心信息或关键操作区域（如支付、登录、确认等），影响用户正常使用网络；不得遮挡扫码缴费页面上的关键信息（如缴费金额、二维码、操作指引等），确保消费者能顺利完成缴费操作，保障其自主选择权。

4.以弹出形式发布的广告应当显著标明关闭标志，关闭标志应位置明显、大小适中、颜色对比鲜明,足以引起消费者注意,不得以模糊、隐蔽、与背景混淆等方式降低辨识度。

5.弹窗广告应当确保一键关闭。不得有倒计时结束或者两次以上点击才能关闭的情形；不得利用大众普遍认知的传统叉号图标充当虚假关闭标识，或以不可清晰辨识、提高关闭操作难度等方式，为关闭广告设置障碍；不得在浏览同一页面过程中，关闭后继续弹出广告，影响用户正常使用；不得有其他影响一键关闭的行为。

6.不得在扫码缴费页面以下列形式诱导、欺骗用户点击、浏览广告：虚假的系统或者软件更新、报错、清理、通知等提示；虚假的奖励承诺；虚假的播放、开始、暂停、停止、返回等标志；其他欺骗、误导用户点击、浏览广告的方式。

三、广告相关主体合规义务

1.广告主、广告经营者、广告发布者等设计、制作、代理、发布广告的各方主体，应当遵守法律法规规定，严格落实主体审查责任，切实规范广告发布行为。

2.各停车场、充电桩等运营单位应当履行管理责任，确保扫码缴费系统符合法律法规及相关规定的要求，发现存在违法违规营销行为的，应当及时予以制止。

3.利用扫码缴费页面发布其他非广告信息，还应当遵守《中华人民共和国个人信息保护法》《互联网弹窗信息推送服务管理规定》等法律法规、规章的规定。

市场监督管理部门将持续加大对停车场、充电桩扫码缴费页面广告的监管力度，依法查处相关违法行为。欢迎广大消费者积极参与监督，如发现违法线索，请保存好相关证据（如缴费页面截图、广告跳转记录、扣费凭证等），及时拨打12315投诉举报。
