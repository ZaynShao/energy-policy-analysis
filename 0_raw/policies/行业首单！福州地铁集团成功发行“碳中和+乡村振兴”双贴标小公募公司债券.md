# 行业首单！福州地铁集团成功发行“碳中和+乡村振兴”双贴标小公募公司债券

来源：福州市国资委发布时间：2026-04-30 16:11浏览量：2072

_![](https://gzw.fujian.gov.cn/images/20210907-ndzy-xlicon1.png)__![](https://gzw.fujian.gov.cn/images/20210907-ndzy-xlicon2.png)__![](https://gzw.fujian.gov.cn/images/20210907-ndzy-xlicon3.png)__![](https://gzw.fujian.gov.cn/images/20210907-ndzy-xlicon4.png)_

近日，福州地铁集团有限公司在上海证券交易所首次面向专业投资者公开发行“碳中和+乡村振兴”双贴标公司债券，发行规模3亿元，期限5年，由中信证券、兴业证券担任主承销商，票面利率1.88%，创2026年福建省内同期有限公司债票面利率新低。

这是全国轨道交通领域首单融合碳中和与乡村振兴双重贴标的公司债券，将两大创新品种有机融合，募集资金将专项用于福州地铁线路运营绿色发展，既通过轨道交通这一低碳出行方式助力交通运输领域碳减排，又通过项目建设带动沿线县域经济发展和就业，实现绿色发展与乡村振兴的协同推进，标志着福州地铁集团在创新融资工具、服务国家战略方面迈出重要一步。

![](https://gzw.fujian.gov.cn/zwgk/gzdt/gzyw/fzsgzw/202604/W020260430583809284847.jpg)

福州地铁集团将持续秉承“提速福州、添福榕城”使命，实施“轨道交通+”多元化战略，致力“建设好、运营好、经营好”绿色、便捷的现代化城市轨道交通网络，继续为福州市民及八方来客提供更加安全、高效、绿色的出行体验。
