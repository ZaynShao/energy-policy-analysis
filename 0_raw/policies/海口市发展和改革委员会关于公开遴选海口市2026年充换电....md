## 海口市发展和改革委员会关于公开遴选海口市2026年充换电基础设施验收咨询服务采购项目结果的公示

|     |     |     |
| --- | --- | --- |
| ![](http://drc.haikou.gov.cn/material/images/2018_tyxl_time.png) 2026-07-20 08:35:00 | 来源： 市发改委 |  |

2026年6月24日至2026年7月1日，我委在市发改委门户网站发布《海口市2026年充换电基础设施验收咨询服务采购项目比选公告》，面向社会公开选取具备相应能力的咨询服务机构。截至申报截止日期，共有4家机构完成报名。经遴选小组严格按评审评分表要求对报名单位申报材料开展综合评审，拟确定海南省充换电一张网服务有限责任公司为本项目服务承担机构。

现就遴选结果予以公示，公示期为2026年7月20日-2026年7月21日。公示期内，如对评定结果有异议的，可通过书面或电子邮件形式向海口市发展和改革委员会提出异议，须详细列明异议理由及佐证材料。单位提出异议的，材料需加盖单位公章并注明联系信息；个人提出异议的，需注明本人真实姓名、身份证号及联系方式。
