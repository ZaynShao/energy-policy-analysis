# 叶集区市场监管局多方位织牢中高考期间市场监管安全网

浏览次数：75信息来源：叶集区市场监管局（知识产权局）发布时间：2026-06-01 15:39

_字号：_大中小下载我要纠错打印收藏

为给广大考生营造良好的考试环境，叶集区市场监管局扎实开展中高考期间市场监管工作，多方位织牢中高考期间市场监管安全网。

严格落实开展食品安全监管。重点针对中高考考生定点餐饮饭店及周边商超等场所，重点检查餐饮和食品经营单位三防措施（防鼠防蝇防灰尘）落实情况、工作人员健康证明情况、进销食材索证索票情况、食品安全制度建立情况、后厨和存储间操作管理情况等。

扎实开展特种设备安全监管。重点针对中高考定点及考点周边住宿酒店电梯，重点检查电梯紧急救答装置响应情况、电梯使用单位“日管控、周排查、月调度”工作机制落实情况、检验检测情况和人员持证上岗情况，并督促做好中高考期间应急值班值守。

全力做好价格消费监管。重点针对中高考定点餐饮和酒店住宿等商家开展价格提醒告诫检查并张贴提醒告诫函，督促商家在中高考期间加强价格自律，不随意涨价，做到诚信守法经营，严格落实明码标价制度，严禁价格欺诈、哄抬价格等价格违法行为。

下一步，叶集区市场监管局将继续织牢织密中高期间食品、特种设备和价格消费等市场执法监管安全网，严厉打击相关非法行为，全力为我区中高考考生考试保驾护航。
