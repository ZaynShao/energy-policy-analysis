# 《辽宁省电力市场运营规则及配套细则（试行3.0版）》印发为我省 ...

## 政策原文

来源：辽宁日报

发布时间：2024年07月25日

日前，省工信厅、省发改委和国家能源局东北监管局联合印发《辽宁省电力市场运营规则及配套细则（试行3.0版）》（以下简称《细则》），为我省电力现货市场结算试运行提供了规则依据，标志我省电力市场建设又迈出重要一步。

据了解，此次印发的《细则》包括《辽宁省电力市场运营规则》以及七个配套实施细则，覆盖了电力市场各个方面，从中长期交易衔接、现货市场、辅助服务市场、电费结算、市场准入与退出、计量管理以及零售市场等方面，为经营主体提供了明确的操作指南。

国网辽宁省电力有限公司相关人士表示，《细则》的实施将有助于推动各类经营主体积极参与市场竞争，提升电力市场的整体效率。据悉，国网辽宁电力同步更新优化技术支持系统，并召集发电主体开展“百日”系统联调，扎实做好试运行准备工作。下一步，国网辽宁电力将加强对《细则》的宣传和培训工作，确保各市场主体能够准确理解和执行各项规定，全面检验电力市场经营工作质效，努力打造高效、公平、开放、可持续的电力市场。
