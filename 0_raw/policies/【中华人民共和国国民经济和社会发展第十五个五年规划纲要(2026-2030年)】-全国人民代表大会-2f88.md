# 中华人民共和国国民经济和社会发展第十五个五年规划纲要(2026-2030 年)

**发文机构**: 第十四届全国人民代表大会第四次会议(表决通过)/ 新华社受权播发  
**通过日期**: 2026-03-12  
**播发日期**: 2026-03-13  
**适用周期**: 2026-2030 年  
**来源**: https://www.acfic.org.cn/szyw/202603/t20260313_325038.html

## 摘要

《十五五规划纲要》是 2026-2030 年中国国家级 5 年战略大纲,共 18 篇。**纲要将"加快经济社会发展全面绿色转型 建设美丽中国"列为单独一篇(第十三篇)**,在第四十七章"积极稳妥推进和实现碳达峰"中给出能源转型路径。**与本届政府工作报告联动**:能源相关量化目标(非化石能源占比 21.7% / 新型储能装机 1.3 亿千瓦 / 单位 GDP 碳强度累计降 17%)是十五五承诺的开局年指标。**纲要为新能源汽车、充电基建、新型储能、电力市场化、加油站综合能源转型五条业务线给出顶层政策授权**,后续各部委 / 省市级实施细则陆续出台。

## 初步影响分析

**加油业务**: 战略级影响 — "全面绿色转型 + 建设美丽中国"是十五五主线,意味着传统油品销售长期承压;成品油零售网络向"光储充氢一体"升级是政策授权下的确定方向
**充电业务**: 战略级利好 — "建设现代化产业体系"和"绿色转型"双框架下,新能源汽车 + 充电基建是国家明确扶持赛道,2026-2030 是规模化关键期
**电力业务(储能/V2G/电力交易)**: 战略级核心利好 — 十五五是电力市场化进入 2.0 阶段(NDRC 1656 全国统一电力市场体系)的执行期;新型储能 / 虚拟电厂 / V2G 进入"做大规模"的窗口
**乡村业务**: 中等关联 — 第八篇"加快农业农村现代化 扎实推进乡村全面振兴"涉及农村能源转型,与国家能源局乡村振兴会议形成上下呼应

### 与政府工作报告联动的量化承诺

(摘自 2026 年政府工作报告中"十五五规划目标指标"章节)

- **非化石能源消费占比**:十五五末力争 21.7% 以上(2026 当年达成)
- **新型储能装机规模**:十五五末超 1.3 亿千瓦(2026 当年达成)
- **单位 GDP 二氧化碳排放**:十五五累计降低 **17%**
- **能源综合生产能力**:58 亿吨标准煤
- **数字经济核心产业增加值占 GDP 比重**:12.5%

### 滴滴四大业务的战略地位映射

- **加油** ← 第十三篇 + 第四十七章("绿色转型"主框架),油品零售向综合能源站迁移
- **充电** ← 第二篇(现代化产业体系)+ 第四十七章(碳达峰),新能源汽车 + 充电基建国家战略续航
- **储能/虚拟电厂** ← 第十三篇 + 政府工作报告"新型电力系统",1.3 亿千瓦储能任务的承接载体
- **电力交易/V2G** ← 第十三篇 + 政府工作报告"扩大绿电应用",V2G 绿色属性的政策化前提
