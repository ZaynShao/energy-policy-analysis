关于沈阳市2026年第一批风电项目竞争性配置结果的公示

发布时间：2026年06月22日 作者： 来源： 新能源处


按照我市2026年第一批风电项目竞争性配置工作安排，我市于2026年5月29日发布了《沈阳市2026年第一批风电项目竞争性配置公告》。期间，共收到8个符合要求企业提交的申报资料。经第三方机构组织专家对项目进行评审，推荐以下企业为各标段中选企业：

|     |     |     |
| --- | --- | --- |
| **标段列表** | **企业名称** | **配置容量**<br>**（万千瓦）** |
| **LZ-** **1** **标段** | 沈阳辽中锦惠新能源有限公司 | 15 |
| **LZ-2** **标段** | 沈阳辽中锦惠新能源有限公司 | 20 |
| **XM-1** **标段** | 北京天润新能投资有限公司 | 17 |
| **XM-2** **标段** | 新民市风润新能源有限公司 | 30 |
| **XM-3** **标段** | 长风源新能源（新民）有限公司 | 30 |
| **XM-4** **标段** | 沈阳轩景能源有限责任公司 | 30 |

现将结果予以公示，公示期：2026年6月22日-2026年6月24日。相关申报主体或其他利害关系人如有异议，可在公示期内以书面形式（以署名加盖公章）向我委提出。
