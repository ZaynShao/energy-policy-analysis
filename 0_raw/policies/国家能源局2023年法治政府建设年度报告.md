国家能源局2023年法治政府建设年度报告

发布时间：2024-04-19

来源：国家能源局
**大** **中** **小**

|     |
| --- |
| 按照《法治政府建设实施纲要（2021—2025年）》和《法治政府建设与责任落实督察工作规定》的要求，现将国家能源局2023年法治政府建设工作情况和2024年工作安排报告如下。<br>**一、2023年法治政府建设重点举措和成效**<br>2023年，国家能源局党组以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大精神，按照党中央、国务院建设法治政府的工作要求，把建设高水平高标准法治机关摆在重要位置，加快能源法律制度体系建设，扎实推进依法行政，健全行政权力制约和监督机制，推动构建现代化能源治理体系，为能源高质量发展提供坚实法治保障。<br>（一）深入学习贯彻习近平法治思想<br>国家能源局党组理论学习中心组专题组织学习习近平法治思想，切实把习近平法治思想贯彻落实到局党组“三重一大”决策和工作部署全过程。将习近平法治思想作为全局党员干部教育培训的必修课，开展宪法宣传周、民法典宣传月、行政复议法宣传月等活动，邀请专家解读重要法律知识，提升全局党员干部知法懂法、依法行政的法律意识。坚持把宪法宣誓仪式作为弘扬宪法精神、坚定法治信仰的具体实践，激励和引导广大党员干部自觉维护法律权威、弘扬法治精神、依法履职尽责。<br>（二）系统谋划法治政府建设工作<br>坚持和加强党对法治政府建设工作的领导。局党组及时传达学习习近平总书记关于法治建设的重要论述，局主要负责同志认真履行法治政府建设第一责任人职责，定期召开局法治建设领导小组会议，研究谋划法治政府建设各项工作，部署推动能源立法任务，确保党中央、国务院的决策部署依法依规落地实施。<br>（三）推动能源法律制度体系建设<br>认真落实习近平总书记“加快完善以宪法为核心的中国特色社会主义法律体系”的重要指示精神，健全完善能源法律制度体系。<br>推动能源立法取得重大进展。局党组高度重视立法工作，将能源法立法作为年度工作重点，推动各方面对能源法基本原则和主要制度等达成共识，2024年1月能源法草案经国务院常务会议讨论通过后提请全国人大常委会审议。推动电力法、可再生能源法修订列入十四届全国人大常委会立法规划。<br>加强规章规范性文件管理。全面开展规章和规范性文件“立改废”，对原能源部、电力部、煤炭部、国家经贸委、国家电监会时期的规章进行系统清理，修订11件、废止8件，进一步完善行业管理制度。组织开展规范性文件集中清理，废止51件不再适用的规范性文件。全年对9件规章、14件规范性文件严格进行合法性审核和公平竞争审查，确保文件内容合法有效。<br>（四）健全政府机构职能体系<br>认真落实习近平总书记“优化政府职责体系和组织结构，推进机构、职能、权限、程序、责任法定化”等重要指示精神，加快推进政府职能转变，提高行政效能和政府公信力。<br>持续优化营商环境。学习贯彻习近平新时代中国特色社会主义思想主题教育期间，在全国集中开展为期三个月的频繁停电专项整治，督办解决典型性、代表性问题510个，受益群众超过200万人。全面落实反垄断和公平竞争审查制度，持续推进电力、油气等自然垄断环节监管，保障能源市场平稳有序运行。持续加强“获得电力”服务监管，推动用电报装“三零”“三省”服务举措常态化，为电力用户节省办电投资累计超过2000亿元。<br>建设服务型政府。完善一体化政务服务平台建设，推行电子证照，实现电力业务许可证“一网通办、一网通查”。加快绿色电力证书核发信息化建设，进一步提升“互联网+政务服务”水平。建立国家能源局网络安全信息通报平台，及时通报能源领域突发网络安全事件，增强应对网络安全攻击的能力。<br>（五）深入推进依法行政<br>认真落实习近平总书记“各级行政机关必须依法履行职责，坚持法定职责必须为、法无授权不可为”等重要指示精神，严格依法履行行业监督管理职责，推动能源行业在法治轨道上健康发展。<br>坚持科学民主依法决策。修订《国家能源局工作规则》，制定《国家能源局机构编制管理暂行办法》，进一步完善行政决策制度。严格落实重大决策程序，召开局党组会议、局务会议、局长办公会议，研究审议法律法规草案、重大能源规划、重点建设项目等重大事项。<br>依法依规履职尽责。按照党中央、国务院有关决策部署，依法依规制定能源规划、产业政策、标准体系，规范开展项目核准。全年新增电力装机约3.3亿千瓦，开工建设一批大型水电、“沙戈荒”大型风电光伏基地、核电、抽水蓄能项目。在项目核准工作中严格执行标准和程序，对核准文件进行合法性审查。<br>严格规范公正执法。印发《国家能源局行政处罚案由规定》《国家能源局行政执法证管理办法（试行）》，进一步完善行政执法制度。落实行政处罚裁量权基准，依法规范行政处罚行为。严格规范开展行政执法，全年累计作出行政处罚决定521件，严肃查处一批违法违规问题。<br>做好行政复议和应诉工作。落实新修订的《行政复议法》，制定《国家能源局行政复议和行政应诉工作规定》。依法依规办理行政复议和行政应诉，全年办理行政复议案件21件，行政应诉案件37件。<br>**二、2024年法治政府建设的重点任务**<br>2024年是建国75周年，是完成“十四五”规划目标任务的关键一年。国家能源局党组将深入贯彻落实习近平法治思想，按照党中央、国务院关于法治政府建设的工作部署，聚焦现代能源治理体系目标任务，重点推进立法、执法、普法和依法行政工作，全面建设权责法定、公开公正、执法严明、廉洁诚信的法治机关，推进能源治理能力现代化。<br>（一）深入贯彻落实习近平法治思想<br>深入开展习近平法治思想学习宣传，重点学习蕴含其中的法治思维、法治精神。召开局法治建设领导小组会议，对2024年全局法治建设工作作出总体部署，印发实施2024年法治建设重点任务清单并督促落实。<br>（二）扎实推进能源立法<br>配合做好能源法立法审议工作，开展能源法出台配套法规和政策预研，为能源法顺利实施营造良好的法治环境。推动将电力法修订列为优先立法事项。积极推进可再生能源法、煤炭法、石油储备条例、核电管理条例等制定修订。<br>（三）健全依法行政制度体系<br>严格按照权责清单规范履职。根据权责清单，系统梳理、补充完善行政许可事项实施规范，进一步细化行政确认、行政检查、行政处罚等权责事项的实施条件、流程、期限和幅度。加强规范性文件管理，做好规范性文件合法性审核，及时废止、修订不适用的规范性文件。<br>（四）认真开展学法普法工作<br>以党章、准则、条例等为重点，组织学习宣传党内法规。组织开展新修订的行政复议法、行政处罚法专题学习和法院庭审旁听。继续组织开展“4·15”全民国家安全教育日、公平竞争政策宣传周、“12·4”国家宪法日等普法宣传活动，落实宪法宣誓制度。认真落实“谁执法，谁普法”普法责任制，推进能源行业学法守法用法。<br>（五）提高行政执法质量和效能<br>集中力量开展电力领域综合监管，着力解决制约行业高质量发展、影响群众用电满意度的深层次问题。围绕电力市场秩序突出问题开展专项监管，防止地方不当干预电力市场。加强对电网、油气管网等自然垄断环节监管，对电力安全等领域开展重点监管。研究制定电力市场信用体系建设指导意见，综合运用信用等手段协同推进专项监管。推广应用国家能源局行政处罚信息管理系统，提升行政执法数字化水平。<br>（六）做好矛盾纠纷行政预防调处化解<br>全面落实新修订的行政复议法，加强同当事人的沟通交流，努力将行政争议化解在基层、化解在行政机关内部。加强行政复议队伍建设，提升化解行政争议的能力。
