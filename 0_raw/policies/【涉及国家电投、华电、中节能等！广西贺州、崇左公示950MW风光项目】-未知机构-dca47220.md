# 涉及国家电投、华电、中节能等！广西贺州、崇左公示950MW风光项目

## 政策原文

12月16日，广西贺州市、崇左市公示2025年新能源项目回收指标再分配竞争性配置评分结果，共11个风光项目，规模合计95万千瓦。

其中，贺州市公示5个风电项目，规模合计25万千瓦，2个光伏项目，规模合计10万千瓦。项目业主涉及国家电投、华电、华能、中节能、广西投资集团。

崇左市公示4个陆上风电项目，规模合计60万千瓦。项目业主涉及中国能建、国家电投、中广核、南水北调集团等。

公告如下：

**贺州市发展和改革委员会关于2025年新能源项目竞争性配置评分结果的公示**

为加快我市新能源项目开发建设，根据《广西壮族自治区能源局关于做好2025年新能源项目回收指标再分配的通知》（桂能新能〔2025〕470号）和我市工作要求，我委组织开展2025年新能源项目竞争性配置评分工作，现将评分结果予以公示。公示期间，如有异议，请在公示发布之日起3个工作日内以书面形式向我委反映（信函以到达日期邮戳为准）。
