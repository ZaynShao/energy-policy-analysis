# 山东省发展和改革委员会德州德州消费市场动能强劲

德州消费市场动能强劲

德州消费市场动能强劲

4月20日，记者从市商务局获悉，一季度，全市实现社会消费品零售总额409.2亿元，同比增长5.6%，分别高于全国3.2个百分点、全省1.4个百分点，增速居全省第4位，为全年消费市场持续向好奠定坚实基础。“分行业来看，批发、零售、餐饮等领域协同发力、稳中有进，成为拉动消费增长的主力军，彰显我市消费市场的强劲韧性与活力。”市商务局党组成员孟繁云说。

今年以来，市商务局深入贯彻落实中央和省、市关于提振消费、扩大内需的部署要求，聚焦“优化供给、激发活力、提质升级”核心目标，打出节庆联动、以旧换新、电商赋能等一系列促消费“组合拳”，推动全市消费市场实现首季“开门红”。

政策赋能，以旧换新激活消费潜力

亮眼数据的背后，离不开精准有力的政策支撑。今年以来，市商务局聚焦大宗商品消费，统筹推进消费品以旧换新，通过政策宣讲、场景创新、线上联动等方式，让政策红利直达市场、惠及群众。

“报废旧车购置新能源汽车，最高能享2万元补贴，加上厂家优惠，算下来特别划算！”3月25日，在德州红旭汽车销售服务有限公司，市民宋宁听完销售顾问的讲解后，当即决定报废旧车，购置一辆新能源轿车。

“《2026年德州市汽车报废更新补贴实施细则》创新补贴方式，打破单一定额补贴模式，按新车销售价格比例核算补贴。”市商务局流通科科长孔国学说，报废旧车购置新能源乘用车的，按新车销售价格的12%补贴，最高2万元；购置2.0升及以下排量燃油乘用车的，按10%补贴，最高1.5万元。置换更新同样享受优惠，新能源车和燃油车分别按8%和6%补贴。

家电和数码产品领域同样福利满满。冰箱、洗衣机等6类1级能效家电按销售价格的15%补贴，单件最高1500元；手机、平板等4类数码产品享受同等比例补贴，单件最高500元，全方位覆盖群众日常消费需求。

一季度，全市享受补贴政策的汽车达5100余辆、家电65900余台、数码和智能产品113200余台，直接拉动消费15.5亿元，政策撬动效应显著。

为让政策红利精准送达各类群体，市商务局创新开展以旧换新“五进”活动——进社区、进企业、进机关、进农村、进商圈。在农村市场，我市同步启动绿色智能消费品下乡活动，通过流动“大篷车”、农村市集、网红直播等方式，实现政策宣传、业务办理、物流配送“三下沉”，计划今年在各县市区开展农村专项促消费活动30场以上，实现乡镇重点区域全覆盖。

线上线下联动，让补贴领取更便捷。线下，全市400余家家电、数码经营主体参与政策落实，实现市、县、乡镇（街道）三级网点全覆盖；线上，联动京东平台开设德州专场，消费者搜索“山东国补”，进入德州会场即可领取补贴，下单即可抵扣，让群众足不出户就能享受政策红利。

全域发力，多元场景点燃消费热情

一季度，市商务局紧抓元旦、春节消费旺季，联动文旅、体育、展会等多领域资源，举办各类促消费活动60余场、体育赛事36场、文旅活动16项，带动消费超30亿元，让消费市场热起来、市场主体活起来。

临邑、禹城、武城等县市区积极响应，争取财政资金570万元，通过“有奖发票”、发放惠民消费券等形式，实现全域联动，形成促消费强大合力。

新春消费活动精彩纷呈。2月1日，德州市2026新春消费季暨天衢新区“冰雪嗨玩·一票乐购”启动仪式在德百奥莱广场举行，天衢新区发行2万份实体消费券，联动60余家餐饮、零售商户，构建“吃住行游购娱”全链条消费场景。

各大商圈同步发力，打造特色消费场景。德百奥莱589街区的行进式沉浸巡游、澳德乐1899街区的老字号与网红美食融合、铜锣湾奥特莱斯小镇的马年主题花灯展，还有非遗打铁花、烟火表演、民俗演出等活动轮番上演，让市民在体验传统文化的同时，激发消费热情。

春日消费热潮涌动。4月14日，德州市“春趣州城·烧烤露营季”主题活动启动，联动商超、餐饮、露营三大业态102家企业，精选星海露营·减河基地、德城区“又见城南”露营地等热门露营地，融合特色烧烤、铜锅涮肉等美食，周末还推出户外音乐会、亲子嘉年华、露天电影节等。活动将持续至5月31日，进一步丰富消费场景，释放春日消费潜力。

精准施策，持续释放消费增长动能

线上消费的快速增长，为全市消费市场注入新活力，成为促进消费的重要支撑。

一季度，全市网零额达53.3亿元，同比增长8.7%，新业态新模式持续活跃，为消费市场增添新动能。

今年以来，市商务局大力推进“电商增效年行动”，成功举办首届大学生直播电商大赛，以赛育才、以赛促产，推动电商与特色产业深度融合，助力优质农产品走出德州、走向全国。

孟繁云表示，市商务局将锚定“双过半”目标，坚持稳住存量、扩大增量、激活变量，力争上半年全市社零额增速达到5%以上，推动批零餐行业指标增速持续高于全省平均水平，持续释放消费市场潜力，为全市经济高质量发展提供坚实支撑。

抢抓“五一”黄金消费窗口，是接下来的重点工作。市商务局已提前部署，广泛联动文旅、展会、赛事等资源，持续推进“烧烤露营季”活动，创新推广“票根经济”、跨界联动优惠等新模式，联合银联及商业银行开展“惠聚德州·乐享消费”金融赋能活动，通过发放全场景满减券，撬动重点领域消费潜力。

展会品牌建设方面，拟于5月中旬举办第二届中国北方蔬菜果品糖酒农产品交易大会，着力提升展会层级与行业辐射力，打造区域性展会标杆，进一步推动产销对接，激活农产品消费市场。

精准施策挖潜大宗商品消费，持续用足用好以旧换新政策工具，推动新能源汽车、绿色家电、数码产品消费提质增量；加强对成品油零售重点企业的运行监测和要素保障，指导企业优化油品供应、拓展非油品业务，稳住石油类消费基本盘；持续深化与电商平台合作，探索线上消费新模式，建设京东京造选品基地、京德直播基地等载体，为优质农产品进入头部电商渠道搭建直通平台。
