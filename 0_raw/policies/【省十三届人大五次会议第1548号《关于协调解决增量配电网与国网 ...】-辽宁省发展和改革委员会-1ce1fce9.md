# 省十三届人大五次会议第1548号《关于协调解决增量配电网与国网 ...

## 政策原文

来源：

发布时间：2021年07月20日

张春玉等代表：

你们提出的关于协调解决增量配电网与国网公司结算价格问题的建议收悉，现答复意见如下：

辽宁绿源配售电有限公司（下简称“绿源公司”）作为一家民营企业控股的配售电公司，投资建设的瓦房店市增量配电网业务改革试点项目是我省第一批增量配电网试点项目，其项目的建设及发展得到了包括我委在内的社会各界的广泛关注和支持。目前，绿源公司在与国网公司就增量配电网在与省电网公司结算电费时，是否应按照我省现行输配电价表中两部制基本电费标准执行的政策理解上出现了较为严重的分歧，影响了该企业与国网大连供电公司供电协议的签署进度。我委对此问题高度重视，2020年以来，我委多次牵头联系省电力公司、东北能监局等相关部门召开专题协调会议，探讨协商解决办法。

按照相关规定，增量配电网和电网公司的结算价格定价权限在国家。2020年5月，我委汇总绿源公司所遇到的有关问题，形成《辽宁省发展改革委关于增量配电网与省电网公司结算基本电费有关情况的请示》书面上报国家发改委。为进一步解决企业难题，明确相关政策，2020年7月23日，委领导亲自带队，赴国家发展改革委价格司作汇报。同时，再次上报了《辽宁省发展改革委关于大连绿源增量配电网与省电网公司电费结算有关事项的函》，请国家明确政策解读，完善增量配电网政策。

2021年2月22日，国家发改委以信访回复的形式明确“绿源公司提出的区域电网定价办法和送电省输电价格不得超过每千瓦时3分钱的有关规定，仅适用于跨省跨区电能输送价格核定情形，并不能简单套用于省内布局建设的增量配电网与省级电网结算。”按照《关于制定地方电网和增量配电网配电价格的指导意见》（发改办价格〔2017〕2269号）规定，配电网和省级电网企业之间的结算价格，按现行省级电网相应电压等级输配电价执行，配电网可根据实际情况，自主选择分类结算电价或综合结算电价与省级电网企业结算电费。不同电压等级输配电价与实际成本差异过大的，省级价格主管部门可根据实际情况，向国务院价格主管部门申请调整省级电网输配电价结构。”

2021年5月8日，我委根据我省增量配电网项目陆续建成并投入运行的现状，考虑增量配电网企业与电网企业的意见分歧，再次向国家发改委提出了《辽宁省发展改革委关于增量配电网交纳基本电费有关事项的请示》（辽发改价格字〔2021〕24号），提出鉴于国家目前对增量配电网基本电费交纳标准正在研究之中，暂时不能出台明确规定，为确保增量配电网能够及时运行，进一步推动电力体制改革，建议国家授权有关省份制定本地区增量配电网基本电费临时交纳标准，待国家明确相关标准和规定后，按国家规定执行。

据了解，国家发改委有关部门正在就我委提出的请示内容进行论证研究。下一步，我委将继续沟通国家，做好国家政策的贯彻落实工作，帮助企业解决实际困难。

辽宁省发展和改革委员会

2021年5月21日
