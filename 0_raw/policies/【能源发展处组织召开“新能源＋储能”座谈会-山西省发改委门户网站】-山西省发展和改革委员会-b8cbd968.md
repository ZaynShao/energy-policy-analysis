# 能源发展处组织召开“新能源＋储能”座谈会-山西省发改委门户网站

## 政策原文

5月28日上午，能源发展处组织召开“新能源＋储能”座谈会，就进一步明确我省“新能源＋储能”试点工作思路，加快推进试点任务进行了深入交流讨论。山西能监办、委能源发展处、商品价格处、省能源局新能源和可再生能源处等相关同志及省电力公司、省电力设计院和储能行业部分企业代表参加会议。

会议围绕推进“新能源＋储能”试点整体思路、进展情况、存在问题及下一步工作计划等相关内容进行深入交流讨论，并结合近期国家关于加快推动新型储能发展的征求意见稿及电力源网荷储一体化和多能互补发展的指导意见，对推动“新能源＋储能”试点的市场机制、商业模式和配套政策等进行研究。

下一步，我委将会同相关政府部门、电网公司、科研机构和储能企业等定期组织召开座谈会、开展实地调研，深化储能领域政策创新，统筹推进试点任务落地落实。
