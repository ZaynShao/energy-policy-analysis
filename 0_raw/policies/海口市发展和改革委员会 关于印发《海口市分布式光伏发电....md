## 海口市发展和改革委员会 关于印发《海口市分布式光伏发电项目备案服务指南》的通知

|     |     |     |
| --- | --- | --- |
| ![](http://drc.haikou.gov.cn/material/images/2018_tyxl_time.png) 2025-05-08 09:00:52 | 来源： 市发改委 |  |

各区人民政府，各开发区管委会，江东新区管理局，市营商环境建设局，海口供电局、有关电力企业：

为规范我市分布式光伏发电项目建设管理，促进分布式光伏产业健康有序发展，根据《分布式光伏发电开发建设管理办法》（国能发新能规〔2025〕7号）《海南省企业投资项目备案管理办法》（琼府办〔2018〕6号）《海南省发展和改革委员会关于推进分布式光伏发电高质量发展有关事项的通知》（琼发改能源〔2025〕440号）等文件精神，现将《海口市分布式光伏发电项目备案服务指南》印发你们，请结合实际，抓好落实。

附件：海口市分布式光伏发电项目备案服务指南

海口市发展和改革委员会

2025年5月8 日
