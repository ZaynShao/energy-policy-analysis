| 关于对《常州市公平竞争审查管理办法（征求意见稿）》 公开征求意见的公告 |
|  |

|     |
| --- |
| 为进一步规范我市公平竞争审查工作，防止出台排除、限制竞争的政策措施，市市场监管局起草了《常州市公平竞争审查管理办法（征求意见稿）》，现面向社会公开征求意见，希望有关单位和各界人士提出意见和建议。有关事宜公告如下:<br>一、意见征询期限：2026年8月21日至2026年8月24日。<br>二、意见反馈渠道：有关单位和各界人士可以将书面意见直接寄送至常州市市场监管局反垄断与反不正当竞争科（常州市新北区太湖东路105号，邮编：213022），书面意见中请写明联系人及联系电话，以便沟通联系。如为各界人士意见，请本人签字；如为有关单位意见，请加盖单位公章。<br>联系人:黄鹏，联系电话:0519-88588107;电子邮箱:czsj111@163.com。<br>附件： [1.《常州市公平竞争审查管理办法（征求意见稿）》](https://www.changzhou.gov.cn/upfiles/admininfo/20260821/20260821165308_39432.docx)<br>[2.《常州市公平竞争审查管理办法（征求意见稿）》起草说明](https://www.changzhou.gov.cn/upfiles/admininfo/20260821/20260821165327_98687.docx)<br>[下载本信息公开文件](https://www.changzhou.gov.cn/downxxgk.php?fid=788178730244436 "点击下载")<br>扫一扫在手机打开当前页<br>![](https://www.changzhou.gov.cn/tools/generate_qr.php?data=https%3A%2F%2Fwww.changzhou.gov.cn%2Fgi_news%2F788178730244436) | |
