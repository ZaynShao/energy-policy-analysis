# 自治区发展改革委召开《宁夏回族自治区虚拟电厂运营管理细则 ...

## 政策原文

11月14日，自治区发展改革委组织召开《宁夏回族自治区虚拟电厂运营管理细则》研讨会议，征求各方意见建议。国家能源局西北监管局宁夏业务办、国网宁夏电力有限公司相关部门、宁夏电力交易中心有限公司、国网宁夏电力科学研究院、国网宁夏电力经济技术研究院、西安广林慧智科技有限公司等5家虚拟电厂运营商，以及宁夏青龙塑料管材有限公司等部分电力用户有关负责人员参加了会议。

会议听取了《宁夏回族自治区虚拟电厂运营管理细则》起草背景、第一次征求意见情况和修订完善内容汇报。参会单位对照《细则》，坚持“公开、公平、公正”原则，结合宁夏实际，从运营实战、技术支撑和政策依据等方面进行了充分讨论研究，提出了针对性的修改意见和建议。

会议指出，今年以来，自治区虚拟电厂建设工作成效显著，建成并成功上线了虚拟电厂运营管理平台，虚拟电厂运营商充分挖掘工商业、电动汽车充电桩、用户侧储能等各类可调节资源，已聚合可调节资源规模总量接近200万千瓦。

会议强调，依托虚拟电厂充分聚合、释放供需两侧可调节资源，有助于新型电力系统的构建，有助于电力供需平衡调节。为推动《细则》尽早出台，**一是**加快《细则》修订，国网宁夏电力有限公司要结合参会各方提出的意见建议，进一步优化完善《细则》内容，尽早提报自治区发展改革委。**二是**加强程序规范性，甄别细则和相关附件的关系，确保细则合规。**三是**加强培训和宣传，电网企业要加强虚拟电厂工作层面的宣传，详细解读虚拟电厂概念、建设、接入、运营等方面的内容，鼓励电力用户充分挖掘可调节资源，积极参与虚拟电厂和系统调节。**四是**加强信息披露，进一步明确虚拟电厂信息披露渠道、内容、周期，做到公开透明。**五是**加强安全管理，重点要对网络安全、系统安全、运营安全方面加强设计和引导，坚持市场公平原则，充分尊重市场主体意愿，做到进出自如。

下一步，自治区发展改革委将加快虚拟电厂运营管理细则的完善和出台，为宁夏虚拟电厂实际运营提供政策机制保障，助力新型电力系统构建和能源安全保供。
