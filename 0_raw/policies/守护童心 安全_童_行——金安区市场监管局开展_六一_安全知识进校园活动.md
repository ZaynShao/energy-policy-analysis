# 守护童心 安全"童"行——金安区市场监管局开展"六一"安全知识进校园活动

浏览次数：83信息来源：金安区市场监管局发布时间：2026-06-01 10:53

_字号：_大中小下载我要纠错打印收藏

为切实增强少年儿童的产品质量安全和食品安全意识，在"六一"国际儿童节到来之际，金安区市场监管局质量股、消保委及投诉举报中心业务人员走进人民路小学，开展2026年安徽省第四届儿童用品暨“质量‘童’行你点我查”主题宣传活动，为该校师生带来了一堂生动实用的"安全知识课"。

活动现场，市场监管工作人员化身"安全老师"，围绕儿童和学生用品选购、食品安全注意事项及消费维权途径三大主题，通过图文并茂的PPT演示和互动问答等形式，将专业知识转化为孩子们听得懂、记得住的生活常识。在儿童和学生用品环节，工作人员重点讲解了如何识别"三无"产品、查看CCC强制性认证标识、根据年龄选择合适玩具等要点，并结合典型案例提醒学生们警惕网红玩具中可能存在的化学危害和物理伤害风险。针对食品安全，工作人员从查看食品标签、识别生产日期、保质期、辨别"三无食品"危害等方面入手，引导学生们养成健康饮食、科学消费的良好习惯。"如果发现玩具质量有问题，或者吃了不干净的零食肚子疼，应该怎么办？"在互动环节，工作人员向学生们普及了12315投诉举报热线，鼓励孩子们在遇到消费纠纷时勇敢维权，将安全知识传递给家长和身边更多人。

活动现场气氛热烈，学生们踊跃参与问答，纷纷表示"以后买零食一定要先看生产日期""要告诉家长买玩具要看3C标志"。此次进校园主题活动旨在通过教育宣讲营造安全放心的消费环境，筑牢儿童学生用品质量安全防线。下一步，我局将持续加大对校园周边经营场所的监督检查力度，严厉打击销售不合格儿童用品和食品的违法行为，全力织密儿童安全"防护网"，为辖区少年儿童健康成长保驾护航。
