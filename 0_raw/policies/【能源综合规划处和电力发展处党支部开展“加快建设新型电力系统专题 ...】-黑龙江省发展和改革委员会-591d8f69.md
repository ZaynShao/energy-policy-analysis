# 能源综合规划处和电力发展处党支部开展“加快建设新型电力系统专题学习交流”主题党日活动

**2025-03-18 10:53**来源：

**能源综合处**

*大*

*中*

*小*】

为深入学习贯彻习近平总书记关于“加快构建清洁低碳、安全充裕、经济高效、供需协同、灵活智能的新型电力系统”重要指示精神，深入了解电力行业前沿技术与发展动态，推进党建与业务工作互融互促，3月14日，省发展改革委能源综合规划处和电力发展处党支部赴国家电投集团黑龙江电力有限公司开展主题党日活动，重点围绕虚拟电厂等新型电力系统前沿理论技术进行交流研讨。

公司特邀专家为支部党员详细介绍了虚拟电厂的概念、技术路径和商业模式，虚拟电厂作为一种新型能源管理模式，利用数字化、智能化等先进技术将需求侧一定区域内的可调节负荷、分布式电源、储能等资源进行整合优化，实现了与传统电厂类似的调节作用。虚拟电厂技术打破了发电厂之间、发电侧和用电侧之间的物理界限，能够有效优化电网运行，为电力系统提供灵活调节能力。支部党员结合我省实际情况就虚拟电厂未来发展趋势和新能源消纳等问题进行了交流探讨。

通过此次主题党日活动，支部党员对习近平总书记关于国家能源安全重要论述有了更加深刻的理解，对“四个革命、一个合作”能源安全新战略的重要意义和实践路径有了更加深入的思考和体会，对如何在新能源装机增长速度明显快于负荷增长速度的情况下，确保电力系统安全平稳运行，支撑新能源快速发展有了新的思路和启发，纷纷表示这是一次理论与实践相结合的生动课堂，下一步要切实提高履职能力，谋划好“十五五”能源发展思路，加快规划建设新型能源体系，为高质量振兴发展提供坚实能源支撑。
