# 市城市管理委专题研究车网互动示范应用工作 - 北京市人民政府

## 政策原文

近日，市城市管理委组织专题研究车网互动示范应用工作，听取了在京主要充电设施运营企业、车企有关车网互动工作介绍和意见建议，委二级巡视员路根喜参加会议。与会人员围绕价格机制、商业模式、调控策略和车网互动标准等内容进行了讨论交流。

会议强调，一是坚持政府引导、市场参与、多方协同，结合首都新能源汽车推广与电力市场改革进展，积极探索兼顾多方利益的车网互动业务场景和商业模式，分类实施、有序推进车网互动建设。二是积极开展V2G示范试点应用，充分调动车端、桩端和电网端各方的创造性，积极参与削峰填谷、虚拟电厂、聚合交易等应用场景，降低高峰期充放电行为对电网的冲击影响，全力打造企业、单位用户、车主多方利益共赢新模式。三是强化政策支撑，研究将智能充放电设施建设和改造纳入充电基础设施建设支持范围，按需推动既有私人充电桩智能化改造，原则上新建充电桩应具备智能有序功能，推动有序充电场景下的交互接口、通信协议等关键技术攻关，更好支撑高质量充电基础设施体系构建和新能源汽车产业高质量发展。
