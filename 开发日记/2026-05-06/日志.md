# 2026-05-06 · Phase 1 信息源根治

## 触发原因

用户做"虚拟电厂主题江苏省 0 条"展示数据时发现 vault 漏抓江苏 VPP 政策。Web 搜索证实江苏是 VPP 全国第一梯队(43+ 家运营商,苏发改能源发〔2025〕1198 号《关于促进我省虚拟电厂高质量发展的通知》等)。诊断后是采集策略系统性偏向(国家级 + 直辖市倾斜)所致,不是个案。

## 决策

13 主题(9 现有 + 4 新增) × 31 省 × 重点地市 矩阵全量根治 + 持续机制建设。

新增 4 主题(原 vault 主题盲区):
- 加油零售/平台合规(滴滴加油合规底线)
- 居住区充电(私桩/统建统营)
- 配电网开放/增量配电(VPP/储能接入前置)
- 聚合商准入(VPP/V2G 商业化前提)

## 关键技术坑(已解决)

1. **trafilatura 编码乱码**: 第一轮抓取全是 `ä¸ãè¡¥è´´èå´` GBK→Latin1→UTF-8 错码。修复:用强 chardet detect(meta charset → http header → chardet → fallback) + GB2312 normalize 到 GB18030。
2. **DOCX 文件不可抓**: 42 个 fail 是 .docx,trafilatura 无法解析。Phase 2 加 mammoth/python-docx 兜底。
3. **江苏 jsdsm 站点 connection refused**: 6 个 URL `jsdsm.fzggw.jiangsu.gov.cn` 全部连接失败,需特殊代理路径。
4. **subagent context 爆**: 330 pid 一次喂 1 subagent 超 200K limit,拆 7 batch × 48 = 14 subagent 并发解决。
5. **5C schema 校验**: D1<3 时 影响分析=null 但 apply 校验要 dict,补 fix 脚本把 null 改成 {"加油":"无影响",...}。
6. **4 新主题 entities 未跑**: themes_registry 加了但 entities/_extractions.jsonl 没重抽,4 新主题 _input.json 当前 0 命中。Phase 2 重跑 extract_entities.py 解决。
