# 新型储能 主题综述

## 1. 主题界定与边界

**新型储能** 在政策语境下特指**电化学储能、压缩空气、飞轮、液流、重力等"非抽水蓄能"的新型储能技术**,与传统抽水蓄能并列构成系统调节资源体系。本主题的 79 篇政策围绕新型储能的**装机规模、调度运用、参与电力市场、容量电价/补偿机制、用户侧/独立/共享储能商业模式、产业培育**六条主线展开,从 2018 年发改能源〔2018〕364 号《关于提升电力系统调节能力的指导意见》起步,到 2026 年"十五五"规划纲要把"新型储能"写进国家级战略目标,跨度 8 年。

**与相邻主题的边界**:本主题与 V2G、虚拟电厂、电力市场三个主题强耦合,但有清晰边界——
- **V2G 主题**关注"车端电池作为分布式储能资源"的车网互动机制,新型储能主题关注的是**电网侧、电源侧、用户侧固定式储能装置**;两者在"储能资源调度"层面有交集(P_2025_NDRC_1360 / P_2025_SH_407 同时涵盖),但 V2G 政策更聚焦车桩协议、放电电价、电池质保;新型储能政策更聚焦电站并网检测、容量电价、辅助服务市场注册。
- **虚拟电厂(VPP)主题**关注"聚合商把分散资源打包参与市场"的运营机制,新型储能主题关注的是"储能这一类资源本身的商业身份";两者关系是"VPP 是壳、储能是核"。本主题的多篇核心政策(P_2024_NEA_93_a / P_2025_NDRC_1656_a / P_2025_NDRC_411)均把储能、虚拟电厂、智能微电网并列为"新型经营主体"。
- **电力市场主题**关注"中长期 + 现货 + 辅助服务"的整体市场架构,新型储能主题聚焦"储能如何作为主体进入这套市场";P_2022_NDRC_475 / P_2024_NEA_26 / P_2024_NEA_0528d977 三篇是本主题最直接的"市场参与"母文件。

**储能业态分类**(政策内置区分,本主题政策大量使用这一框架):
- **电源侧/新能源配储**:风光大基地、独立电站强制/自愿配建,2024 年起多地取消"强配",转向市场化(P_2024_GX_594、P_2024_SH_28)。
- **电网侧/独立储能**:接入电网作为独立电站参与市场,容量电价/电能量套利双收益模式;受 P_2022_NDRC_475 / P_2024_NEA_26 / P_2024_NEA_0528d977 多份"调度运用"文件直接规范。
- **用户侧储能**:工商业园区、零碳工厂、新型电力系统调节能力建设的载体,P_2024_JL_232(吉林)、P_2025_SH_5_c(上海)、P_2026_MIIT_13(零碳工厂) 等地方/行业政策密集出台。
- **共享储能**:多个新能源项目共用同一储能电站,本主题最具商业模式创新空间(P_2024_NDRC_0806117c 解读、P_2025_NEA_08060ff3)。
- **长时储能(4小时以上)**:P_2024_SH_28 是本主题最聚焦"长时储能"的政策,把固态电池、跨天/跨月/跨季节储能写入示范方向。

## 3. 时间脉络要点

新型储能政策呈"**起步—系统化—规模化**"三阶段演进:

**Stage 1: 国家级顶层设计(2018-2022)** — 从 P_2018_NDRC_364 系统性提出"提升电力系统调节能力"开始,经 2021 双碳顶层设计(P_2021_SC_0922fb2b / P_2021_SC_23 / P_2021_NDRC_0421ce4f 征求意见稿)的战略锚定,在 2022 年集中落地三份关键文件:**P_2022_NDRC_03213b6e_a / P_2022_NDRC_032146fe(十四五新型储能发展实施方案)+ P_2022_NDRC_475(参与电力市场和调度运用)**——把"新型储能"作为独立技术品类写入国家战略,提出"到 2025 年新型储能从商业化初期向规模化转变"的阶段性目标。这一阶段的核心特征是**有方向、缺机制**:政策重在描绘蓝图,价格、调度、市场三大机制尚未细化。

**Stage 2: 调度运用 + 经营主体 + 价格机制系统化(2023-2024)** — 政策密度急剧上升,2024 年是本主题政策最密集的一年(单年 22 篇,占总量 28%):
- **调度运用细化**:P_2024_NEA_26 / P_2024_NEA_0528d977 给出并网检测 + 调度协议的实操规范,新型储能"被电网调用"的物理路径打通;
- **经营主体合法化**:P_2024_NEA_93_a + P_2024_NEA_12055c06(答记者问)把储能/VPP/智能微电网定义为"新型经营主体",平等参与电力市场、原则豁免许可证;
- **价格/补偿机制起步**:P_2024_NDRC_02276bf1 提出市场化容量补偿、P_2024_SC_12_a(国发 12 号节能降碳)把 2025 年储能装机目标加码至 3000 万千瓦超预期、P_2024_SH_28(沪府办 28 号示范引领创新)+ P_2024_JL_232(吉林用户侧储能)+ P_2024_OTHER7F45_060777c1(深圳虚拟电厂措施)三省同步出台;
- **市场规则衔接**:P_2024_NEA_76(电力市场注册基本规则)+ P_2024_NDRC_0806117c(新型电力系统行动方案)把储能与现货市场、绿电交易、辅助服务市场全面衔接;
- **新能源消纳逻辑反转**:多省(广西 GX_594、上海 SH_28)开始**取消强制配储**,从"行政强配"转向"市场配储"。这一阶段的核心特征是**机制成型,模式分化**——独立储能、共享储能、用户侧储能、长时储能四条赛道分别成型。

**Stage 3: 规模化建设 + 全国统一市场(2025-2026)** — 政策从"鼓励"转向"考核":
- **统一市场规则形成闭环**:P_2025_NDRC_411(辅助服务)→ P_2025_NDRC_1656_a(中长期)→ P_2026_NDRC_02114da8(全国统一电力市场访谈)→ 储能进入"能量市场 + 辅助服务市场 + 容量补偿"三市场全覆盖;
- **试点工程具象化**:P_2025_NEA_53_a(新型电力系统建设第一批试点)+ P_2026_NEA_16(试点名单公布)开启"国家级名单制";
- **省级冲锋号落地**:**上海三件套(SH_5_c 调节能力奖励 + SH_407 用户侧 VPP + SH_61 节能减排重点工作)**形成全国密度最高的省级政策包;山东 SD_03271ffc / SD_0401ca27 在 2026 年密集出台两份省级方案;深圳光明区 OTHERCD44_1 出台扶持计划操作规程;
- **规模化专项行动**:P_2025_NDRC_0912b2a5(新型储能规模化建设专项行动方案 2025-2027)首次给出"规模化"国家级量化目标;P_2025_NDRC_1360(促进新能源消纳和调控)把虚拟电厂 + 车网互动 + 新型储能列为消纳重点方向;
- **十五五战略锚定**:P_2026_NPC_03132f88("十五五"规划纲要)+ P_2026_SC_0305e288(2026 年政府工作报告)把新型储能写为国家级战略产业,标志着主题进入"规模化兑现期"。

国家级演进 → 省级铺开 → 地市落地的 3-stage 总结:**"国家定方向(2018-2022)→ 国家定机制(2023-2024)→ 国家+地方共定考核(2025-2026)"**;空间维度是 **"国家 50 篇 / 省级 16 篇 / 市区 13 篇"** 的金字塔结构,国家级文件占比 63%,显示本主题仍以中央事权驱动为主,但上海(7 篇)、深圳(3 篇)、山东(2 篇,2026 集中)、北京(2 篇)开始形成"地方先行+国家追认"的反向输入路径。

## 4. 业务影响要点(对滴滴三大业务线)

### 加油:
- **加油站升级综合能源站(油气氢电充储一体化)是本主题给加油业务的最直接政策出口**:重庆黔江 P_2022_CQ_11、北京大兴 P_2024_BJ_0325555c、唐山 P_2024_NDRC_06275d0d、上海松江 P_2026_SH_03132bad 等多份地方碳达峰/能源规划都把"综合能源服务"+"新型储能"绑定写入,加油站存量场地可作为已规划用地承接储能/充电/制氢叠加。
- **零碳工厂场景的新机会**:P_2026_MIIT_13(零碳工厂指导意见)把新型储能列入工厂用能侧标配,滴滴若服务大型工业客户的"加油+综合能源"打包合约,新型储能是最直接的配套设备入口。
- **风险**:加油站储能需要场地评估(消防、电网容量),不能简单照搬充电桩业务模式;P_2024_NDRC_08218f52 大规模设备更新方案虽提及储能,但加油站储能是否纳入设备更新补贴范畴尚未明确——需要跟踪 2026 省级实施细则。

### 充电(储能 + 充电站协同):
- **光储充一体化在新建超充站的"政策默认标配"**:P_2024_CQ_020739ff 把"数字技术提升源网荷储一体化协同"+"数据中心绿电使用"列为重庆数字能源城市重点;P_2024_NDRC_0806117c 多源同向把"共享储能解决配储利用率低"+"新型储能优先调度"+"V2G 电池作储能资源"打包推进——**新建超充站若不配光储,在合规和经济性上都会吃亏**(尤其是大功率改造场站)。
- **储能 + 大功率超充"+电网协同"组合拳**:P_2024_NEA_26 + P_2024_NEA_0528d977 给出新型储能与电网调度的协议路径,叠加 NDRC 632 大功率充电(在充电主题中)——大功率超充站可同步申报"用户侧储能项目"拿 SH_5_c 类奖励(0.2 元/kWh 度电奖励)。
- **共享储能让分散场站打包成 VPP**:P_2024_NDRC_0806117c(www.ctg.com.cn 同源)指出"共享储能解决配储利用率低投资回收难问题"——滴滴若运营 5-10 个场站,可把储能集中建在地市级共享储能电站,以租赁/聚合方式服务多场站,降低单站投资。
- **强制配储退场带来的窗口**:P_2024_GX_594 / P_2024_SH_28 取消强配 → 储能从"成本项"变"收益项",滴滴新建场站不再需要被动配储,但要主动考虑"配储以套利"的资本配置问题——尤其是上海 SH_5_c 用户侧储能 0.2 元/kWh 度电奖励 + 独立储能 0.35 元/kWh 的差异化,意味着"独立储能"比"用户侧配储"补贴更高,**滴滴在上海应优先考虑用独立储能身份申报而非用户侧附属身份**。

### 电力(储能调用机制 / 价格政策 / 商业模式):
- **储能正式成为"新型经营主体",滴滴可作为独立主体参与多市场**:P_2024_NEA_93_a + P_2025_NDRC_411 + P_2025_NDRC_1656_a 三件套确认储能可独立参与中长期、现货、辅助服务、容量补偿四类市场,且原则豁免电力业务许可证——**滴滴 储能业务的合规门槛已被国家级政策清除**,业务起步不再需要绕开"无照经营"风险。
- **"能量市场套利 + 辅助服务双轮驱动"是当前唯一被验证的商业模式**:P_2024_FJ_1220060b(rmi.org.cn)中性指出"电能量市场套利是独立储能最主要收益来源",P_2025_NDRC_411 提出"双轮驱动盈利模式",P_2025_SH_5_c 给出"度电奖励 + 调节能力奖励"叠加路径——滴滴 储能业务的财务模型应当是"低买高卖电能量套利(60-70%) + 辅助服务收入(20-30%) + 容量补偿(10-20%)"三层收入,而非单一调度费。
- **136 号文取消保量保价后,储能与新能源的关系反转**:P_2025_NDRC_1360(www.cpnn.com.cn)mixed 指出"136 号文取消保量保价企业面临收益率风险"——新能源场站不再保量保价,自然需要储能平抑出力波动 + 参与现货套利,**储能由"配套设备"升格为"新能源场站盈利核心"**,滴滴若服务新能源运营商,储能是 2026 年起的强需求点。
- **绿证收益缺位 + 容量补偿与租赁冲突的盈利分歧**:P_2024_SH_28(www.zhonglun.com)critical 指出"独立储能放电电量不核发绿证无溢价收益"+"享受容量补偿独立储能不得再租赁容量"——意味着**滴滴决策时要二选一**:要么走"容量补偿"路径(电网调度优先 + 稳定补偿),要么走"租赁容量"路径(灵活市场化 + 短期高价),不能两端通吃。
- **长时储能(4小时以上)是独立赛道**:P_2024_SH_28(paper.people.com.cn)+ 山东 1.8 亿千瓦案例同源 → 缺口时长向 5-6 小时演变,固态电池被列为长时储能技术突破方向——滴滴若深度参与电力业务,**长时储能是 2027-2030 年的差异化赛道**(短时储能竞争已激烈)。

## 5. 演进逻辑总结

- **从"配套设备"到"独立经营主体"**:储能在 2018-2021 政策语境中是"调节资源"的补充选项,在 2022 年 NDRC 475 号正式获得"市场参与"身份,在 2024 年 NEA 93 号定义为"新型经营主体",在 2025 年 NDRC 411 + 1656 号获得"四市场全覆盖+原则豁免许可证"——主体地位八年完成升级。
- **从"行政强配"到"市场配储"**:新能源 + 储能强制比例从 2021 年起在多省落地,但因利用率低、投资回收难,在 2024 年 NDRC 136 号(取消保量保价)+ 多省取消强配后,储能与新能源的协同从"政府摊派"转向"市场套利驱动"——共享储能、独立储能、长时储能由此成为差异化赛道。
- **从"全国一刀切"到"国家+地方双驱动"**:2018-2024 国家级文件占主导(63% 总量),2025-2026 上海、山东、深圳、北京开始密集出台地方专项,**地方政策的"补贴密度"反而高于国家**(上海 SH_5_c 给出全国最具体的奖励标准)——滴滴的政策红利窗口从"等国家细则"转向"抢省级第一批试点"。
- **从"独立赛道"到"打包入 VPP"**:2024 年起储能与虚拟电厂、智能微电网、车网互动越来越多被打包列入"新型经营主体"名单,2025 年 NDRC 1360 + NEA 93 把储能 + VPP + 车网互动 + 源网荷储一体化绑定为"新能源消纳调节资源"——储能的"独立估值"模式正向"VPP 聚合估值"演进。
- **从"短时调峰"到"长时电量平衡"**:2025-2026 政策开始密集涉及"4小时以上"的长时储能(SH_28、山东案例),反映新能源占比上升后,系统从"日内调峰"需求转向"日间/季节性电量平衡"需求——这是滴滴选择储能技术路线(锂电 vs 液流 vs 压缩空气 vs 固态)时的关键政策风向标。
