## 2. 分歧

跨多评论方/多政策上的关键议题分歧:

- 🔴 **D1. 独立储能盈利模型——容量补偿 vs 容量租赁 vs 套利,三种模式互斥且各有缺陷**
  - 容量补偿派(supportive):P_2024_NDRC_02276bf1 / www.nea.gov.cn "建立市场化容量补偿机制引导稳定容量供应";P_2025_NEA_93 / www.ndrc.gov.cn "健全调节性资源容量电价机制";P_2025_NDRC_411 / www.cpnn.com.cn "能量+辅助服务双轮驱动盈利模式"
  - 套利派(neutral):P_2024_FJ_1220060b / rmi.org.cn "电能量市场套利是独立储能最主要收益来源";P_2025_SH_5_c / finance.sina.com.cn "用户侧储能度电奖励 0.2 元独立储能 0.35 元/千瓦时"
  - 反对派(critical):P_2024_SH_28 / www.zhonglun.com "享受容量补偿独立储能不得再租赁容量";P_2024_SH_28 / www.zhonglun.com "独立储能放电电量不核发绿证无溢价收益"
  - 风险派(mixed):P_2025_NDRC_1360 / www.cpnn.com.cn "136 号文取消保量保价企业面临收益率风险"
  - **判断**:容量补偿 + 容量租赁 + 绿证溢价三个收益渠道**两两互斥**,迫使运营商在"稳定低收益(补偿)"与"灵活高收益(租赁/套利)"中二选一。**对滴滴**:不同省份建议走不同路径——上海/北京/深圳走"度电奖励 + 调节能力奖励"叠加套利模式;新能源大基地配套场景走"容量补偿"长协稳定模式;不要试图同站两端通吃。

- 🔴 **D2. 新型电力系统建设的"机遇 vs 风险"分歧**(P_2024_NDRC_0806117c 已在 opinion 文件内标注为"分歧")
  - 机遇派:www.ctg.com.cn ——"构建新型电力系统是双碳目标关键载体";gjs.cssn.cn ——"十四五期间新型电力系统政策体系逐渐完善"
  - 风险派:gjs.cssn.cn ——"新型电力系统建设面临安全风险与问题需有针对性防范";P_2023_NDRC_1294_b / www.ndrc.gov.cn ——"高比例新能源电子设备使系统抗扰动能力弱"(双高特征风险)
  - **判断**:新型电力系统的"建设速度 vs 安全保障"在国家级专家圈层就已存在分歧,这意味着**储能作为"调节支撑资源"会越往后越被赋予安全责任**——并网检测、构网型技术、抗扰动能力等成为新增合规成本。**对滴滴**:储能项目设计初期就要考虑构网型技术(P_2023_NDRC_1294_b)+ 涉网性能并网检测(P_2024_NEA_26),不要等到运行阶段被监管追溯。

- 🔴 **D3. 新能源消纳与电网协同——"调节资源不足"vs"集成融合应对"的方法论分歧**
  - 问题派(critical):P_2025_NDRC_1360 / www.cpnn.com.cn ——"三北部分省份光伏利用率已低于 90%"+"新能源建设快于电网工程导致协同不足";P_2024_NDRC_02276bf1 / www.nea.gov.cn ——"新能源利用率同比下降部分省份消纳压力凸显";P_2024_NDRC_02276bf1 / www.nea.gov.cn ——"调节能力建设缺乏统筹存量资源未充分利用";P_2024_NDRC_02276bf1 / www.zhizhengce.com ——"电力系统调节能力难以适应新能源发展需要";P_2024_NEA_93_a / paper.people.com.cn ——"电网消纳能力滞后是限制风光发展的突出问题"(中性)
  - 解决派(supportive):P_2025_NEA_93 / www.nea.gov.cn ——"新能源发展从单兵作战向集成融合发展转变以应对消纳压力"+"支持源网荷储一体化、绿电直连、智能微电网等 4 类就近消纳新业态";P_2025_NDRC_1360 / www.cnste.org ——"意见明确将虚拟电厂和车网互动作为新能源消纳的重要调节资源";P_2024_SC_12_a / www.sxjzy.org ——"加快配电网改造提升新能源接入承载能力"
  - **判断**:核心张力在"**新能源建得太快还是电网/储能跟不上**"——问题派认为是"调节资源不够",解决派认为是"集成融合方法不到位"。对滴滴而言,无论哪种判断都指向同一商业机会——**储能 + VPP + 车网互动构成的"消纳调节包"**,且就近消纳新业态(源网荷储一体化、绿电直连、智能微电网)是 2026-2027 年新增赛道。

- 🔴 **D4. V2G 商业模式能否闭环**(同充电基建、V2G 主题 D1)
  - 支持方:P_2025_SH_407 / www.electricpower.com.cn ——"V2G 可降配变峰值负荷 30% 以上"+"通过 V2G 充电桩国家电网将节约投资 1750 亿";P_2025_SH_5_c / finance.sina.com.cn ——"V2G 项目按调节能力 50 元/千瓦年最高 150 万元奖励";P_2024_OTHER7F45_060777c1 / www.cls.cn ——"深圳 V2G 单企业最高 500 万元支持加速商业化"
  - 反对方:P_2024_OTHER7F45_060777c1 / www.cls.cn ——"V2G 商业模式尚不清晰,三方利益分配问题待解决"+"V2G 项目投资回报周期可能高达 10 年"+"车主担心频繁充放电影响电池寿命"
  - **判断**:在新型储能主题视角看,V2G 是"车端储能资源"的特殊形态,与固定式储能 IRR 模型不同——**车端电池要承担"原本主业是出行"的机会成本**,这是固定式储能没有的天然劣势。**对滴滴**:在新型储能业务范畴内,优先发展独立储能/用户侧储能,V2G 留给充电+V2G 主题专项推进,不要在储能业务里过早重投车端资源。

## 3. 中性观察

- ⚪ **电网消纳能力滞后是制约新能源发展的突出问题**(P_2024_NEA_93_a / paper.people.com.cn)——这是判断"储能业务的需求强度"的关键中性观察:消纳痛点越大,储能商业空间越大。

- ⚪ **节能降碳目标延续前期但十四五完成任务仍艰巨**(P_2024_SC_12_a / pdf.dfcfw.com)——意味着 2025 年底 + 2026 年的"双碳考核"会反向倒逼储能项目加速落地,是窗口期信号。

- ⚪ **高耗能产能约束明显加强**(P_2024_SC_12_a / pdf.dfcfw.com)——钢铁、石化等行业新增产能受限,反而催生用户侧储能 + 零碳工厂(P_2026_MIIT_13)的合规配套需求。

- ⚪ **2025 年现货价格普遍承压 + 煤电容量电价重构电源收入结构**(P_2024_FJ_1220060b / rmi.org.cn 两条同源)——意味着储能"低买高卖"的电能量套利空间在压缩,需更多依赖辅助服务+容量补偿+度电奖励等多收益叠加。

- ⚪ **独立储能收益依赖电能量市场套利,虚拟电厂仍处示范阶段**(P_2024_FJ_1220060b / rmi.org.cn 两条同源)——这是 RMI 第三方智库给出的最直接定调:储能盈利模式尚未跑通到"不依赖补贴"。

- ⚪ **奖励逐年退坡 5%-10%**(P_2025_SH_5_c / finance.sina.com.cn)——2026-2028 年上海调节能力奖励每年递减 5%-10%,**对滴滴**:抓 2026 年是补贴密集期,前置申报+前置投资,把补贴算进 1-3 年回本而非长期回收。

- ⚪ **广西分布式存量项目按现行燃煤基准价 0.4207 元/千瓦时执行机制电价 + 增量项目竞价上限 0.36/下限 0.131**(P_2024_GX_594 / solar.in-en.com 两条同源)——这是判断"分布式新能源 + 储能"商业模型能否成立的关键价格基准,**滴滴若在广西/类似省份做储能套利,需以这个价格区间反推 IRR**。

- ⚪ **地方政策严限独立储能项目投资主体变更**(P_2024_SH_28 / www.zhonglun.com)——意味着储能项目股权转让/出售存在地方限制,**滴滴若计划"建—持—卖"轻资产模式,需提前与地方政府沟通投资主体变更条款**,否则会卡退出。

- ⚪ **2025 年市场化交易电量占比提升至 64%**(P_2025_NEA_53_a / www.nea.gov.cn)——市场化电量占比已从 2020 年代初的 40% 量级提升至 64%,叠加 2030 目标 70%(P_2026_NDRC_02114da8 / lnsnyyjh.com),**储能业务的"市场化空间"持续扩张是基本面**。

## 4. 待跟进

- **2025 年新型储能规模化建设专项行动方案(2025—2027 年)的省级实施细则**(P_2025_NDRC_0912b2a5 国家级文件已落地,省级细则尚未集中出台)——优先关注上海、山东、广东、江苏、浙江五大用电高省。

- **新型电力系统建设第一批试点 + 第二批试点的具体奖励/补偿机制**(P_2025_NEA_53_a + P_2026_NEA_16 试点名单已公布,但每个试点的"调度优先权 + 财政奖励 + 绿证溢价"具体兑现尚未明确)——需跟踪 2026 下半年试点进度通报。

- **容量电价/容量补偿的国家级标准**(C3 共识但具体定价尚未明确)——P_2024_SH_28 提及"114 号文",但 114 号文细则与省级落地价格尚未集中梳理;山东 2026 年两份方案(SD_03271ffc / SD_0401ca27)是否给出补偿标准值得关注。

- **独立储能绿证溢价问题是否会有政策松动**(D1 反对派引用)——独立储能放电电量目前不核发绿证,这是制约储能"双重收益"的关键卡点;P_2025_NEA_08060ff3 提到 262 号文,可能是绿证制度后续扩围的政策线索。

- **构网型储能技术 + 涉网性能并网检测的强制要求**(D2 风险派伏笔)——P_2023_NDRC_1294_b 把构网型作为方向,后续可能从"鼓励"转向"强制",影响储能项目设计成本。

- **136 号文取消保量保价对新能源 + 储能的实际冲击程度**(D3 + D1 mixed)——目前只有 cpnn.com.cn 单源 mixed 评价,需要更多财经/智库测算补充。

- **长时储能(4-6小时以上)的国家级专项政策**(C5 弱共识)——目前只有上海方案聚焦,国家级专项尚未出台;P_2025_NDRC_1645 光热发电意见可能是间接路径。

- **新型储能与 V2G/虚拟电厂在同一项目身份上的"双重申报"是否被允许**(D1 / D4 交叉)——上海 SH_5_c 给出 V2G + 用户侧储能 + 独立储能三条不同奖励路径,但同一物理资产能否同时享受多种奖励仍需明确。
