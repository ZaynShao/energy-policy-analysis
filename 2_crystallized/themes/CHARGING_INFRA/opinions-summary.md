## 中性观察(关于现状的客观陈述)

- ⚪ **充电单枪平均功率偏低**:46.5 千瓦平均功率难以满足节假日高速等快速补能需求,大功率快充与乡村布局仍不足(P_2025_NDRC_632_c / finance.sina.cn)——这是当前充电业务最直接的痛点指标。

- ⚪ **充电运营商集中度下降**:TOP15 运营商集中度下降反映市场分散化趋势(P_2025_NDRC_632_c / finance.sina.cn)——这是判断"是否进入并购窗口期"的关键中性观察。

- ⚪ **V2G 项目国家级门槛**:试点 V2G 项目放电总功率不低于 500 千瓦、年放电不低于 10 万千瓦时(P_2024_NDRC_718 / www.cls.cn)——这是判断滴滴单个 V2G 项目是否具备规模的硬指标。

- ⚪ **上海 V2G 商业模式**:上海工商业用电比例极高、电动汽车保有量全国首位,V2G 可降配变峰值负荷 30%、节约电网投资 1750 亿(P_2025_SH_407 / www.electricpower.com.cn)——这是上海推 V2G 的强 ROI 数据基础,但来自媒体报道而非政策原文,需谨慎引用。

- ⚪ **V2G 三阶段发展路径(欧阳明高)**:孕育突破期、提升推广期、加速普及期(P_2025_OTHER0858_255 / www.ditan.com)——给到 V2G 长期判断框架,目前处于"孕育突破期向提升推广期"过渡阶段。

- ⚪ **奖励逐年退坡的明确节奏**:上海 SH_5_c "2026-2028 年奖励标准每年按 5%-10% 递减"(finance.sina.com.cn)——这是各省补贴退坡的标杆参照,投资节奏不能等到补贴退完。

- ⚪ **V2G 专用桩成本高需要商业模式让运营商有利可图**(P_2025_OTHER0858_255 / www.nea.gov.cn 中性)——这是国能局自己也承认的现实约束,非批评性语气但分量重。

- ⚪ **能耗强度滞后**:受疫情影响能耗强度降低指标完成滞后(P_2024_SC_12_a / www.sxjzy.org)——影响节能降碳行动方案对充电业务的间接拉动力度。

## 待跟进议题(评论里反复被提及但没结论的开放问题)

1. **V2G 大规模推广下的电池衰减经济模型**——技术界与厂商之间没有统一口径(P_2024_OTHER7F45_060777c1 mixed:"车主担心频繁充放电影响电池寿命,但厂商称可通过算法控制充放电频次保护电池";P_2025_OTHER0858_255:"多数车企未明确 V2G 场景下电池质保条款,制约规模化")——**这是 V2G 业务最大卡脖子,谁先解谁拿下市场**。

2. **统建统服 vs 特许经营垄断的边界**——NDRC 101520b2 全国 1000 个统建统服试点小区 vs 湖南 HN_289 反垄断条款的**潜在张力**,目前没有政策给出明确边界(经营权多长?排他性多强?如何"开放共享"?)——这是滴滴申报试点小区前必须前置思考的合规课题。

3. **大功率改造的"利用率 + 投资回报"模型**——节假日利用率 >40% 是改造门槛,但 finance.sina.cn 同时指出 46.5 kW 平均功率反映存量低利用率——**改造后到底多久回收成本?改造场站利用率会自然提升多少?**没有公开测算。

4. **县域单桩 IRR 与运维半径模型**——河南通许、湖南、四川各县级规划只给"建多少桩"没有"日均使用次数 / 运维半径 / 单桩 IRR"——**这是判断是否重投县域市场的关键缺口**。

5. **充电服务费上下限指引节奏**——湖南 HN_289 已经开了头,会扩散到广东/江苏/浙江等其他省份吗?上下限到底卡多严?——决定未来 3 年充电度电收益的关键不确定。

6. **2030 年市场化交易电量 70% 目标下的充电场站绿电直采空间**——1656 中长期 + NEA 107 绿证细则给到路径,但充电站作为电力用户的具体准入门槛、跨省直采规则、与 V2G 绿色属性的合并核算 都尚未明确。

## 决策层"应该信谁"指南

**口径冲突时的优先级排序**(从可信度高到中):

1. **政策方向判断 → 信人民日报 + 发改委/能源局官方解读**:政策方向上,paper.people.com.cn(车网互动 / 长时储能)+ www.ndrc.gov.cn / www.nea.gov.cn 是最权威的"已发生"数据。**但本主题国家级官媒在"商业模式可行性"上几乎不发 critical 信号——所以官媒只看进度,不看可行性**。

2. **商业模式 / IRR 测算 → 信律所 + 财联社/碳道 + 财经媒体**:中伦律所(D2 容量补偿 vs 租赁互斥)是**最值得听的合规警示**;www.cls.cn(D1 V2G 投资回报 10 年)+ www.ditan.com(D1 D4 商业模式不闭环 + 电池质保缺失)是**少数敢公开质疑的财经媒体**。**滴滴决策层在 V2G 重投决策前,务必复读 cls.cn / ditan.com 的反方立场,做风险测算**。

3. **赛道竞争格局 → 信财经媒体 + 二级市场研究**:finance.sina.cn(46.5 kW 平均功率 / TOP15 集中度下降)+ 21jingji.com(深圳 / 出口 / CBAM 视角)+ pdf.dfcfw.com(节能降碳目标艰巨 / 新型储能加码)——这三家是判断"赛道竞争格局 + 谁在跑谁在退"的最佳信源。

4. **行业垂媒(chd.in-en.com / electricpower.com.cn / cnfol.com)** 是政策落地节奏的快讯通道,在地方政策上常给独家数据(上海 V2G 降配变 30%)。**但行业垂媒 supportive 占比过高,只看进度数据,不信观点判断**。

5. **地方政府网站(cqnc.gov.cn / xuanzhou.gov.cn / cq.gov.cn)** 是实操样板的来源——重庆南川 / 安徽宣州 / 重庆超充行动 都是给到具体落地办法的好信号,值得复制。

**原则**:supportive 看进度,critical/mixed 看风险,neutral 看测算。**滴滴决策层在充电基建主题的判断,必须主动放大 critical/mixed stance(占比仅 ~15%)的权重,否则会被 78% 的 supportive 噪音淹没**——尤其是 V2G(D1)、大功率超充(D2)、县域(D3)、统建统服合规(D4)、服务费定价(D5)五大议题,每个都直接关系到几十亿 capex 的方向。
